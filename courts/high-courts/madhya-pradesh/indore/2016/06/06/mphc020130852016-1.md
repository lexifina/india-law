# High Court of Madhya Pradesh, MCRC/4832/2016, 2016-06-06

MCRC-4832-2016
(AKBAR Vs THE STATE OF MADHYA PRADESH)
06-06-2016
Shri Himanshu Thakur, learned counsel for the
applicant.
Shri Mukesh Kumawat, learned Panel Lawyer for the
Non-applicant/State.
Heard with the aid of case-diary.
O R D E R
THIS is second application under Section 438 of
the Code of Criminal Procedure. The applicant is
seeking anticipatory bail in connection with Crime
No.63/2007 for the offence punishable under
Sections 8/15 and 2 of NDPS Act, registered at
Police Station- Suwasra, District Mandsaur.
Earlier application was dismissed by this Court vide
order dated 10/01/2008, passed in M.Cr.C.
No.6905/2007.
At this juncture, learned counsel for the applicant
seeks permission to withdraw this application with
this liberty that he will file fresh application.
Prayer is accepted.
Thus, the application (petition) is dismissed as
withdrawn with the aforesaid liberty.
(JARAT KUMAR JAIN)

JUDGE
