# High Court of Madhya Pradesh, MCC/2758/2014, 2015-08-07

MCC-2758-2014
(KAMTA TIWARI Vs THE STATE OF MADHYA PRADESH)
07-08-2015
Shri Prashant Dubey, learned counsel for the applicant.
This application has been filed for restoration of W.P.
No. 1626/2014, which was dismissed on
account of peremptory order dated
21.4.2014 There being some delay in
filing the application for restoration I.A.
No.17122/14 has been filed seeking
condonation of delay. Both the
applications are supported by affidavit of
Shri Prashant Dubey, Advocate, and there
is no reason to disbelieve the same.
Finding the same to be bonafide, both the
applications are allowed.
Condoning the delay in filing the application,
restoration application itself is allowed.
W.P. No. 1626/14 is restored to its original number. It
be placed for orders before appropriate
Bench.
Application stands allowed and disposed of.
(VANDANA KASREKAR)
JUDGE
