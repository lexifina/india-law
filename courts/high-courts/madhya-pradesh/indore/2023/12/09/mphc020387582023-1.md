This application coming on for conciliation this day, the Bench passed
the following:
ORDER
This application has been preferred for restoration of M.A.
No.4449/2018 which stands dismissed for non-compliance of common
conditional order dated 02.01.2019.
2. Since the same is barred by time an application bearing I.A.
No.9363/2023 has been filed for condonation of delay in filing the same.
3. For the reasons stated in the application, the same is allowed and the
delay in filing the restoration application is condoned.
4. Heard on the main application as well.
5. For the reasons stated in the application, the same is allowed and M.A.
No.4449/2018 dismissed for non-compliance of common conditional order
dated 02.01.2019 is restored to its original number for hearing on merits.
6. Let the order dated 02.01.2019 passed in M.A. No.4449/2018 be
complied with within a period of six weeks.
7. Let a copy of this order be kept in the record of M.A. No.4449/2018.
8. Accordingly, this MCC allowed and disposed off.
