JUDGMENT
This original petition is filed challenging an order in
I.A.No.1266/2019 in OP(MV)No.2779/2016, on the file of Motor
Accidents Claims Tribunal, Ernakulam. By the impugned order the
application submitted by the petitioner has been dismissed stating
that evidence is already started in connected matters. The petitioner
submitted that all other connected matters have not been disposed of
so far. If the connected matters are pending, the tribunal shall try all
the cases jointly, in the light of application submitted by the
petitioner. The impugned order is set aside.
 This Original petition is disposed of as above.
