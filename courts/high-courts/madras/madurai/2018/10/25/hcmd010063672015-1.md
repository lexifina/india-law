O R D E R
This quash petition is filed to quash the First Information
Report in Crime No.300 of 2015 on the file of the first respondent
police.
2.There are specific averments in the First Information
Report. The First Information Report is not an encyclopedia to
contain all the materials. Therefore the First Information Report
cannot be quashed at the threshold stage. It has to be gone into
full fledge investigation.
3.Therefore, this Court is of the view that this criminal
original petition is liable to be dismissed.
4.Accordingly, this criminal original petition is
dismissed. consequently connected miscellaneous petition is
closed.
