# High Court of Uttarakhand, ABA/3/2019, 2020-10-09

ABA No. 3 of 2019
Hon’ble Ravindra Maithani, J.
None is present for the applicant.
Mr. V.K.Jemini, Deputy A.G. for the State.
This is an anticipatory bail application, which
was filed in the year 2019. It was listed on 8th
January, 2019, for the first time. State was required
to file the counter affidavit but no counter affidavit
has been filed.
Today, none is present for the applicant.
On behalf of the State it is submitted that the
investigation is still pending against the applicant.
Since the applicant is not present, the Court
sees no reason to continue this proceeding,
therefore, the anticipatory bail application is
dismissed in non-prosecution.
 (Ravindra Maithani, J.) 09.10.2020 Kaushal
