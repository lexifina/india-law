# Gauhati High Court, AB/2871/2013, 2013-07-23

AB 2871/2013
BEFORE
THE HON’BLE MR. JUSTICE T. VAIPHEI
Heard Mr. B.N. Gogoi, the learned counsel for the petitioner and Ms S. J
ahan, the learned Addl. Public Prosecutor appearing for the State.
The learned Addl. Public Prosecutor strongly objects to the application for pre-arrest bail on the ground that the petitioner did not surrender before the polic
e, as directed by this Court in the earlier bail rejection order. I agree.
Having refused to comply with the order of this Court, this second bail
application cannot be entertained. Confronted with the situation, the learned c
ounsel for the petitioner seeks to withdraw this bail application with liberty
to file fresh application.
The bail application stands withdrawn in the manner indicated above.
