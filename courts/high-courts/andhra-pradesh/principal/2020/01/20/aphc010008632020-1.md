# High Court of Andhra Pradesh, CRLP/138/2020, 2020-01-20

SMT JUSTICE T. RAJANI
CRIMINAL PETITION NO.138 of 2020
ORDER:

This criminal petition filed under Section 482 Cr.P.C seeking
to set aside the order dated 27.11.2019 in C.C.No.90 of 2019 on
the file of I Special Magistrate Court at Vijayawada and quash the
same.
2. Heard the learned counsel for the petitioner and the Public
Prosecutor appearing for the first respondent. Notice to the 1st
respondent is dispensed with as prayer is only to set aide the order
dated 27.11.2019, by virtue of which, the lower Court has
dismissed the complaint of the petitioner. Considering that it
would be better for every case to be decided on merits, this Court
finds that the impugned order needs to be set aside. More so,
considering the contention of the petitioner that he was not
informed about the date of adjournment properly. The order does
not spells that the complainant was consistently absent, it only
shows that he was absent on given date of adjournment. Hence,
the impugned order is set aside.
4. In the circumstances, this criminal petition is allowed, the
impugned order dated 27.11.2019 is set aside and the complaint is
restored to file. As a sequel, miscellaneous petitions, pending if
any, in the criminal petition shall stand closed.
