# Allahabad High Court, WRIA/18767/2018, 2018-09-05

Court No. - 58
Case :- WRIT - A No. - 18767 of 2018
Petitioner :- Urmila Devi
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Sunil Kumar,Prithi Pal Verma
Counsel for Respondent :- C.S.C.
Hon'ble Ashwani Kumar Mishra,J.
Basic facts with regard to petitioner's grievance have not been
disclosed. Learned counsel for the petitioner has orally
submitted that petitioner is not receiving salary since 2016, but
neither this fact has been pleaded nor details have been
disclosed. It is also not disclosed as to at which place petitioner
is posted now. It is only submitted that petitioner has joined at
Shravasti in 2017, but salary has not been paid.
Since basic facts are lacking, at this stage, learned counsel for
the petitioner comes up with the prayer to withdraw this petition
with liberty to file a fresh with better particulars and details.
Prayer made is not opposed.
Writ petition is accordingly dismissed as withdrawn with liberty
prayed for.
Order Date :- 5.9.2018
Ashok Kr.
