# Bombay High Court, APPLN/629/2008, 2008-05-02

( 1 )
 IN THE HIGH COURT OF JUDICATURE AT BOMBAY
 CRIMINAL APPELLATE JURISDICTION
 CRIMINAL APPLICATION NO.629 OF 2008
 Mr.Asif Sabazkar .. Applicant.
 Versus
 Abbas Akbar Qureshi & Ors. .. Respondents.
 Mr.Laxman Kanal for the applicant.
 Mr.K.H.Giri for the respondent No.1.
 Mr.H.J.Dedhia, A.P.P. for the State.
 CORAM : R.Y. GANOO, J.
 DATED : 2nd May, 2008.
 P.C.:
 1. Heard Mr.Kanal for the applicant, Mr.Giri for
 respondent No.1 and Mr.H.J.Dedhia, A.P.P. for the
 State.
 2. If the applicant is aggrieved by the order
 passed by the learned J.M.F.C., Uran being order dated
 27.11.2007, it will be open for the applicant to file
 appropriate proceedings before the appropriate forum
 so as to put up the challenge to the said order. The
 present proceedings cannot be entertained by this
 Court as not maintainable. Hence the order :-

 ( 2 )
 a) In view of the aforesaid observations,
 Mr.Kanal is permitted to withdraw this
 application. The applicant is granted liberty
 to file appropriate proceedings before
 appropriate forum so as to put up the
 challenge to the order dated 27.11.2007 passed
 by the learned J.M.F.C., Uran.
 3. Application stands disposed off as withdrawn.
 (R.Y. GANOO, J.)
