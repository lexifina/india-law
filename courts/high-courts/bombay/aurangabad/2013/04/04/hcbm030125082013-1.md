ORAL JUDGMENT :
1. Heard.
2. Rule. Rule returnable forthwith. With
the consent of the parties, the petition is taken
up for final hearing.
3. The order U/s 45(2) of the Maharashtra
Land Revenue Code is passed. Mr.Choudhari,
learned counsel for the petitioner contends that
no show cause notice is issued to the petitioner
before passing the impugned order. The
petitioner is not heard. The amount calculated
is per-se illegal. If the notice would have been
issued, the petitioner would have been in a
position to prove the real state of affairs.
4. Mr.S.K.Kadam, learned Asstt. Govt.
Pleader supports the order.
5. It appears that prior to passing of the
impugned order, the petitioner was not given any

 3
hearing nor any show cause notice was issued to
him. The Division Bench of this Court in LPA No.
217/2009, has in similar set of facts set aside
the order and remitted the matter to the
Tahsildar.
6. In light of the above, the impugned
order is quashed and set aside. The Tahsildar
shall hear the petitioner and decide the
proceedings afresh. The petitioner shall file
reply before the Tahsildar on 22.4.2013. Upon
receiving the reply and after hearing the
petitioner the Tahsildar shall decide the
proceedings afresh.
7. Rule made absolute in above terms.
However, there shall be no order as to costs.
8. Authenticated copy be given.
