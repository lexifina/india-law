ORDER
Heard learned counsel for the petitioners.
 2. This petition is filed for quashing the entire
proceedings in Crl.Misc.No.192/2015 pending on the
file of JMFC-II Court, Mangalore.
 3. On perusal of the daily status report, it is
revealed that case number Crl.Misc./0000192/2015
(Abdul Hameed versus Usman Abdulla) on the file of
JMFC-II Court, Mangalore, is dismissed vide order
dated 11.05.2016.
 4. Under these circumstances, the present
petition does not survive for consideration. Hence, the
petition is dismissed as the same has become
infructuous.
