This application coming on for admission this day, the court passed the

ORDER
After arguing at length, the counsel for the applicant seeks withdrawal of
this bail application because the counsel for the State has raised objection that
earlier two bail applications have been dismissed, there is no changed
circumstance and all the facts as has been narrated by the applicant have already
been considered on earlier occasion.
Prayer is allowed.
Accordingly, this bail application is dismissed as withdrawn.
