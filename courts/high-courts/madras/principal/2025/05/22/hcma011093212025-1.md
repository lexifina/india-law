ORDER
Heard both sides. Since the impugned order was passed without
hearing the writ petitioner, the same stands set aside. The matter is
remanded back to the file of the second respondent.
2. The petitioner shall appear before the second respondent on
05.06.2025 at 4 p.m. The second respondent shall hear the petitioner and
pass orders afresh on merits and in accordance with law. Since the
impugned order has been set aside, there cannot be any impediment for
exporting the goods.
