O R D E R
This Criminal Original Petition has been filed to quash the
First Information Report in Crime No.9 of 2017, dated 14.07.2017,
on the file of the first respondent Police.
2.Today, when the matter is taken up for hearing, the
learned Additional Public Prosecutor, appearing for the first
respondent, on instructions, submitted that the investigation has
been completed and final report has already been filed before the
Judicial Magistrate Court No.III, Thoothukudi and the same has
been taken on file in C.C.No.484 of 2019.
3.In view of the above development, this Court is not
inclined to interfere with the First Information Report at this
stage. Liberty is granted to the petitioners to challenge the
final report, if so advised.
