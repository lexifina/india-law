# High Court of Orissa, WP(C)/1957/2004, 2019-03-11

08. 11.03.2019 None appears for the petitioner. Learned counsel for
the opposite party is present.
 On number of occasions the matter was
adjourned on the request of the learned counsel for the
petitioner.
 On the last occasion i.e. on 18.02.2019 also
learned counsel for the petitioner was not present, for which
this Court passed the following order:
 “Learned counsel for the opposite party is
present. Learned counsel for the petitioner is
not present.
 Last time learned counsel for the petitioner
had taken time to file rejoinder.
 As a last chance, the matter to come up on
11.03.2019.”
 In view of the above, this writ petition is dismissed
for non-prosecution.
