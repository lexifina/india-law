HON'BLE MR. JUSTICE VIJAY KUMAR VYAS
Order
17/05/2017
 Heard.
This revision petition has been preferred against the
order dated 22.7.2014 passed by learned Additional Sessions
Judge, Shahpura (Jaipur) u/s 311 Cr.P.C. The application was
preferred at the stage of defence evidence. Prosecution wanted
to get Ram Niwas - constable, examined who was a link witness
and whose name was not mentioned in the list of witnesses
submitted along with charge-sheet. Order passed u/s 311 Cr.P.C.
is an interlocutory order and the same is barred to be
challenged u/s 397 read with section 401 Cr.P.C.
Therefore, the revision petition is dismissed.
(VIJAY KUMAR VYAS), J.
