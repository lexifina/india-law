# Madras High Court, A/4074/2023, 2023-08-31

A.No.4074 of 2023
in TOS.No.38 of 2011
A.A.NAKKIRAN, J.
This application has been filed to
condone the delay of 690 days to restore
the suit dismissed for default on
17.09.2019 the above suit.
2. Heard both sides.
3. Learned counsel for the
respondents has strongly opposed to
allow this application.
4. Being satisfied with the
reasons stated in the affidavit filed in
support of this application, in order to
give one more opportunity to the
applicant, this Court is inclined to allow
this application on payment of cost of
Rs.3000/- (Rupees Three Thousand
Only) to the learned counsel for the
respondents on or before 12.09.2023.
 5. Accordingly, this application is
allowed.
6. Post the main case before this
court on 13.09.2023.
