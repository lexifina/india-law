This matter is taken up through hybrid mode.
2. The petitioner has filed this writ petition seeking
direction to the opposite parties for implementation of the
order dated 16.04.2021, which has been passed in compliance
of the order dated 11.11.2020 in W.P.(C) No.24208 of 2020.
3. If the order dated 11.11.2020 passed by this Court in
W.P.(C) No.24208 of 2020 has not been complied with,
remedy lies with the petitioner to file contempt application.
But instead of doing so, the petitioner has approached this
Court by filing the present writ petition and more so it is
contended that though Government has been pleased to allow
promotion to the petitioner retrospectively, but the same has
not been implemented till date. If that be so, the petitioner has
to file application for contempt instead of filing the present
writ petition. In such view of the matter, this Court is not

4. With the aforesaid liberty, the writ petition stands
disposed of.
