# Allahabad High Court, BAIL/31651/2023, 2023-07-19

Neutral Citation No. - 2023:AHC:143929
Court No. - 69
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 31651 of 2023
Applicant :- Raj
Opposite Party :- State of U.P.
Counsel for Applicant :- Tripurari Pal
Counsel for Opposite Party :- G.A.
Hon'ble Samit Gopal,J.
1. List revised.
2. Heard Sri Tripurari Pal, learned counsel for the applicant and Sri
Bade Lal Bind, learned counsel for the State and perused the
records.
3. This bail application under Section 439 of Code of Criminal
Procedure has been filed by the applicant-Raj, seeking
enlargement on bail during trial in connection with Case Crime
No.166 of 2023, under Sections 147, 148, 149, 302 IPC, registered
at Police Station Banna Devi, District Aligarh.
4. The argument of learned counsel for the applicant is that the
deceased was found to have received 11 injuries as per postmortem
report, photocopy of the same which is at page 32 of the affidavit
has been placed before the Court. It is argued by learned counsel
for the applicant that there is no such injury which would show the
cause of death as the injuries noted are not having any internal
damage and are not on the vital part of the body.
5. This Court has perused page 32 of the affidavit which is
postmortem report in which in column no.3 relating to brain, the
same is mentioned to be congested and haematoma present.
Further probe was done with regards to postmortem and from the
copy produced by the learned counsel for the State, it appears that
there is one more injury which is on top of the head which is not in
the postmortem report as filed with the present bail application.
6. Since there are incomplete pleadings and incomplete documents
filed in the bail application, the present bail application is, thus,
rejected.
(Samit Gopal, J.)
