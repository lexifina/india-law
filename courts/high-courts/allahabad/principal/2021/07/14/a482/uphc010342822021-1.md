Case :- APPLICATION U/S 482 No. - 5943 of 2021

Counsel for Applicant :- Rakesh Kumar Verma
Counsel for Opposite Party :- G.A.

due to inadvertence neither the copy of summoning order has
been appended alongwith present application nor same has been
challenged. He therefore submits that present application be
dismissed as not pressed with liberty to file fresh.

learned counsel for applicant.
3. Accordingly, present application is dismissed as not pressed
with liberty to file fresh application.
