ORAL ORDER
2 30-06-2016 Learned counsel for the petitioners submitted that by
the impugned order dated 19.05.2015 the learned Subordinate
Judge-III, Hajipur (Vaishali) rejected the injunction application
filed by the petitioners under Order 39 Rule 1 of the Code of Civil
Procedure in Partition Suit No.620 of 2012.
Since the petitioners have got the remedy under the
Code of Civil Procedure as the order impugned in this case is
appealable under Order 43 Rule 1 (r) of the Code of Civil
Procedure, this writ application is not maintainable. Accordingly,
this writ application is dismissed.
Harish/-
