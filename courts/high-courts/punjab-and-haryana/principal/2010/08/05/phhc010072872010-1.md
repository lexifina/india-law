ALOK SINGH, J. (ORAL)
1. Present petition is filed against the order dated 5.5.2010
passed by ADJ, Sonepat.
2. ADJ, Sonepat vide impugned order dated 5.5.2010 has
struck of the defence of the defendants/petitioners herein on the
ground that defendants appeared before the Court on 4.2.2010 and
despite availing 90 days from the date of appearance they did not file
any written statement. It has further been observed by the learned

C.R. No.4880 of 2010 -2-
ADJ, Sonepat that no request was made before him for more time to
file written statement.
3. In view of the observations made by the learned Addl.
District Judge, Sonepat in the impugned order dated 5.5.2010, there
is no sufficient ground to extend the time to file written statement.
4. Hence, the petition is dismissed.
( ALOK SINGH )
