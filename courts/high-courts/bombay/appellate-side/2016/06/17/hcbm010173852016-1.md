P.C. :
1. Heard the learned counsel for the Applicant.
2. By this application, the applicant seeks restoration of Criminal
Application No.53 of 2015 which came to be dismissed for non-prosecution vide order dated 18th March, 2016 as none appeared for the
applicant.

2/2 30-appr.214.2016
3. For the reasons set out in the application, more particularly para 3 of
the application, the application is allowed. The order dated 18th March,
2016 is recalled and Criminal Application No.53 of 2015, is restored to
file.
4. The Application is accordingly disposed of.
5. Criminal Application No.53 of 2015 be listed on 1st July, 2016.
 REVATI MOHITE DERE, J.
