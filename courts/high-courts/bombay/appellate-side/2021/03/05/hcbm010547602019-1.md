1. The Registrar (Judicial-II) of this Court by an order dated
31st July, 2019 rejected the application for registration of the Civil
Application as the office objections were not removed.
2. Heard Mr. Shirke, learned Counsel for the applicants.
3. For the reasons stated in the application, the order of
rejection, dated 31st July, 2019 is set aside and Civil Application
(St.) No. 8238 of 2019 is restored to the file by condoning the
delay of 111 days in filing the present Interim Application for
restoration of Civil Application.
4. The application is disposed of.
