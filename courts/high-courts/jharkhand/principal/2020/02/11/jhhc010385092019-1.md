5/11.02.2020 Heard the parties.
 The petitioner, in this application, has challenged the order dated
22.12.2017, by which processes under Sections 82 Cr.P.C., has been
issued against her.
 Learned counsel appearing for the petitioners submits that within
seven days of dismissal of her anticipatory bail petition by the Sessions
Judge, the Judicial Magistrate, 1st Class, Giridih vide order dated
22.12.2017 has issued process under Section 82 Cr.P.C.. He submits that
the petitioner was preparing to file anticipatory bail application before the
Hon’ble High Court, but in the meantime the impugned order was passed,
which resulted in filing this application. He also submits that impugned
order is absolutely cryptic and bad and does not reflect any subjective
satisfaction as required by the law. Thus, the same needs to be quashed.
 After hearing the counsel for the parties and on going through the
impugned order, I find that no subjective satisfaction has been recorded
while passing the impugned order. The order has been passed in a most
mechanical manner without recording any substantive reason.
 Thus, this criminal miscellaneous petition same is hereby
allowed. The impugned order dated 22.12.2017, by which processes under
Section 82 of the Code of Criminal Procedure has been issued, is hereby
set aside. The matter is remitted to the court below to pass a fresh order in
accordance with law.
 This criminal miscellaneous petition stands allowed.

 (Ananda Sen, J)
