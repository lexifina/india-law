# High Court of Madhya Pradesh, MCRC/10922/2018, 2018-03-19

THE HIGH COURT OF MADHYA PRADESH
MCRC-10922-2018
(LAXMIBAI Vs THE STATE OF MADHYA PRADESH)
Indore, Dated : 19-03-2018
Shri Harshwardhan Pathak, learned counsel for the applicant.
Shri Bhuwan Deshmukh, learned Public Prosecutor for
respondent/State.
This is an application for correction in the order dated
09.03.2018 passed in M.Cr.C.No.7137/2018.
Learned counsel for the applicant submits that the correct crime
number is 53/2018.
Considering the aforesaid, the prayer for correction of Crime
number is allowed. In the order dated 09.03.2018 in place of Crime
No.423/2018 it be read as 'Crime No.53/2018'. This order shall be
read conjointly with the order dated 09.03.2018 passed in
M.Cr.C.No.7137/2018.
With the aforesaid, M.Cr.C.No.10922/2018 is allowed.
(P.K. JAISWAL)
JUDGE
