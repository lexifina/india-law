# High Court of Madhya Pradesh, MP/1016/2018, 2018-03-06

THE HIGH COURT OF MADHYA PRADESH
MP-1016-2018
(SMT. NIRMALA DEVI CHATURVEDI Vs SHRI RAMBABU JAIN S/O SHRI BHIKARAM JAIN (DEAD)
LRS. MOTILAL JAIN)
Gwalior, Dated : 06-03-2018
Shri Brijesh Tyagi, learned counsel for the petitioner.
Petitioner's only grievance which has been raised in this petition
is that learned trial Court before which execution proceedings are
pending is not deciding the execution case expeditiously.
Therefore, this petition can be disposed of with a request to the
Executing Court i.e. the Court of 4th Civil Judge, Class I, Gwalior, to
take all possible steps for expeditiously deciding the execution
proceeding and if possible decide it within a period of three months
from the date of receipt of certified copy of the order.
Accordingly, this petition is disposed of.
(VIVEK AGARWAL)
JUDGE
