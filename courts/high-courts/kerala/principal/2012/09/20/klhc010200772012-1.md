ORDER
An order refusing to set aside the ex-parte decree after
condoning the delay in a suit for eviction is under challenge in
this Civil Revision Petition. I.A. No. 1614/2010 was filed to
condone the delay and I.A. No. 1615/2010 was filed to set aside
the ex-parte decree. I.A. No. 1615/2010 in O.S. No. 114/2008
was obviously filed under Order IX Rule 13 of the Code of Civil
Procedure.
2. The orders rejecting an application to set aside an
ex-parte decree is appealable under Order XLIII Rule 1 (d) of
the Code of Civil Procedure. The grounds now urged to
condone the delay in filing the application to set aside ex-parte
decree can also be urged in the appeal. The Civil Revision
Petition under Section 115 of the Code of Civil Procedure is
misconceived.
The Civil Revision Petition is dismissed without prejudice
to the right of the petitioner to prefer an appeal as above.
V. CHITAMBARESH
 JUDGE
