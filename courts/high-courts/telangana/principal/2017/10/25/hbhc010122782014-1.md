# High Court for the State of Telangana, CC/155/2014, 2017-10-25

THE HONOURABLE SRI JUSTICE M.S.RAMACHANDRA RAO
CC.No.155 of 2014
ORDER:
 This Contempt Case has been filed by the petitioner
alleging willful disobedience of the order dt.21.11.2013 in
W.P.No.14352 of 2003.
2. Admittedly the said order of the learned Single Judge was
set aside in Writ Appeal No.550 of 2014 on 02.06.2014.
3. In this view of the matter, though the Contempt Case was
filed on 04.02.2014, before the order in the Writ Appeal, once
the order of the Single Judge is set aside by the Bench, no
relief can be granted in this Contempt Case, since the order of
the Single Judge is no longer in existence and is therefore
incapable of implementation.
4. Accordingly, the Contempt Case is dismissed. No costs.
5. Consequently, miscellaneous petitions pending if any
shall stand closed.

M.S.RAMACHANDRA RAO, J
