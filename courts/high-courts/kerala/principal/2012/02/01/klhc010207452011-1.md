 O R D E R
In this petition under Section 482 of the Code of
Criminal Procedure, petitioner seeks an order to quash
Annexure A1 Final Report in C.C. 246 of 2008 on the file
of the Chief Judicial Magistrate, Ernakulam. The offence
alleged is under Section 420 I.P.C. The plea is that the
matter has been settled between the parties along with
another case. If that be so, since the offence under
Section 420 IPC is compoundable, petitioner can file a
petition under Section 320 of the Code of Criminal
Procedure for compounding the offence.
In the result, this petition is disposed of with liberty
to the petitioner to file a compounding petition under
Section 320 of the Code of Criminal Procedure.
