# Calcutta High Court, CO/1104/2023, 2023-05-08

08.05.2023
 715
 Naren
 Ct.237
 C.O. 1104 of 2023

 Anupam Ganguly.
Vs.
 Dasnagar Prem Priti Sangha & Anr.
 Mr. Pranit Bag,
 Mr. Debdutta Saha,
 Mr. Pradyut Das,
 Mr. Tirthankar Nandi … for the petitioner.
This revisional application has been filed with a
prayer for expeditious disposal of an application under
Order VII Rule 11 of the Code of Civil Procedure, 1908,
which is pending for last four months.
Learned Civil Judge (Junior Division), 6th Court
at Howrah is requested to dispose of the application
under Order VII Rule 11 of the Code of Civil Procedure,
1908 within six weeks from the date of communication of
this order.
No notice is required to be served upon the
opposite parties. Thus, service of notice is dispensed
with.
Learned Advocate appearing for the petitioner is
at liberty to communicate the order to the learned Trial
Court.

With the aforesaid observation, this revisional
application stands disposed of.
All parties shall act on the server copies of this
order duly downloaded from the official website of this
Hon’ble Court.

 (Bibhas Ranjan De, J.)
