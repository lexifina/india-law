Mr. Peyush Jain, learned counsel for the respondent

This is the second bail petition u/S. 438 of the Code
of Criminal Procedure, 1973. The first application was
dismissed vide order dated 24/7/2017 passed in
M.CR.C.No. 7336 / 2017. The same reads as under :
MCRC No. 7336/2017
24-07-2017
Mr. N.J. Dave, learned counsel for the
applicant prays for withdrawal of the present bail
petition with liberty to file an application u/S. 439 of
Cr.P.C.
The same is dismissed as withdrawn with the
aforesaid liberty.
If such application is preferred, it shall be
heard on the same date.
In the light of the aforesaid, the question of
entertaining the second bail application u/S. 438 of the
Code of Criminal Procedure, 1973 does not arise.
It is accordingly hereby dismissed.
