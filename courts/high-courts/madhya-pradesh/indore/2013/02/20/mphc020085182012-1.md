# High Court of Madhya Pradesh, WP/3179/2012, 2013-02-20

W.P.No.3179/2012
20.02.2013
Shri S.C.Sharma, learned counsel for the petitioner.
Shri G.S.Patwardhan, learned counsel for the respondent.
Learned counsel for the respondent has raised objection
about the tenability of the writ petition at the instance of the present
petitioner.
In view of the aforesaid, learned counsel for the petitioner
seeks leave to withdraw this petition with liberty to file fresh petition
with modification in the name of the petitioner.
With the aforesaid liberty, the petition is dismissed as
withdrawn.
Certified copy of the order challenged in this petition be
returned to the petitioner on filing attested true copy of the same.
C.C.as per rules.
 (SHANTANU KEMKAR) ( M. C. GARG )
 JUDGE JUDGE
