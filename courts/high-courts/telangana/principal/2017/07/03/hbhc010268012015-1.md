# High Court for the State of Telangana, WP/37748/2015, 2017-07-03

THE HON'BLE SRI JUSTICE S.V.BHATT
WRIT PETITION No.37748 of 2015

ORDER:
Through letter dated 30.06.2017 learned counsel for the
petitioner requests the Court to permit the petitioner to
withdraw the writ petition with liberty to file a fresh writ
petition for comprehensive reliefs if cause of action subsists
and circumstances warrant.
 The Writ Petition is dismissed by granting the liberty
 as prayed for. No order as to costs.
Miscellaneous petitions, if any, pending, shall stand
closed.

 ______________
 S.V.BHATT, J
3rd July, 2017.
