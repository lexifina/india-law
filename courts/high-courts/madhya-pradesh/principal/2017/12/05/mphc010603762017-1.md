# High Court of Madhya Pradesh, MCC/3343/2017, 2017-12-05

THE HIGH COURT OF MADHYA PRADESH
MCC-3343-2017
(MOHD. ILAHI Vs SAVANIYA BAI BACHLE)
Jabalpur, Dated : 05-12-2017
Shri K.P.Patel, learned counsel for the applicant.
Heard on I.A.No. 17237/2017, which is an application for
condonation of delay in filing the present application. As per the
office report, there is a delay of 11 days in filing the application.
Keeping in the view the averments made in the application
which is duly supported by affidavit, I.A.No. 17237/2017 is
allowed. Delay caused in filing the application is hereby
condoned.
Also heard on restoration application.
This application has been filed for restoration of M.A.No.
1577/2017 which was dismissed default due to non-compliance
of common conditional order dated 29.08.2017. The application
is duly supported by an affidavit.
Looking to the facts mentioned in the application, the same
is allowed. M.A.No. 1577/2017 is restored to its original
number.
The MCC stands allowed and disposed of.
Let a copy of this order be kept in the file of M.A.No.
1577/2017.
(SMT. ANJULI PALO)
JUDGE
