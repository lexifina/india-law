# High Court of Madhya Pradesh, MCRC/9073/2016, 2016-07-21

MCRC-9073-2016
(GOLU Vs THE STATE OF MADHYA PRADESH)
21-07-2016
Shri Jafar Khan, learned counsel for the applicant.
Shri Y. Dwivedi, learned P.L. for the State.
Learned counsel for the applicant prays for withdrawal of the
instant bail application u/s 438 of the Cr.P.C.
Prayer allowed.
However, the applicant is given the liberty of moving an
appropriate application before the learned Court below and if
such an application is moved, the learned Court below is
requested to deal with it expeditiously and if possible on the same
day on which it is filed in the light of the order granting bail to the
father of the applicant.
The instant bail application u/s 438 of the Cr.P.C. stands
dismissed with the aforesaid liberty.
C.C. as per rules.
(ATUL SREEDHARAN)
JUDGE
