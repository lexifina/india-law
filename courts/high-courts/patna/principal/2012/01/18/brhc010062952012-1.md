2 18-01-2012 Heard learned counsel for the parties.
This is an application seeking restoration of Cr. Misc. No.
23403/2011 which was dismissed for non-prosecution vide order dated
18.10.2011 in connection with Complaint Case No. 860 of 2001.
This Court does not find any merit in this application.
Accordingly, the same stands dismissed.
Further, the petitioner is at liberty to file fresh application,
if mandatory requirement for an application under Section 438 of the
Code of Criminal Procedure is available.
