# High Court of Orissa, WP(C)/3379/2003, 2019-04-16

03. 16.04.2019 Learned counsel for the petitioner seeks
permission to withdraw the writ petition with a liberty to the
petitioner to file a fresh application, if any cause of action
survives. A memo filed to that effect is taken on record.
 Permission for withdrawal is granted.
 Accordingly, the writ petition stands disposed of as
withdrawn with the liberty to the petitioner to file a fresh
application, if any cause of action survives.
 Misc. Cases/I.As. connected to this writ petition, if
any, are disposed of accordingly.
 Interim order passed in this case stands vacated.
