ORDER
Petitioner is fourth accused in Crime No.557/2011 of
Chadayamangalam Police Station, registered for the offence
punishable under Sections 379 and 381 r/w 34 IPC. Petition is
filed under Sec. 438 of the Code of Criminal Procedure for
anticipatory bail, apprehending arrest.
2. Learned counsel appearing for the petitioner and the
learned Public Prosecutor were heard.
3. Petitioner earlier filed Bail Application No. 891/2012
for the same relief. By Annexure A2 order finding that petitioner
cannot be granted anticipatory bail, on the request of the
petitioner, he was directed to surrender before the investigating
officer. Instead of surrendering, the second petition is filed.
Having already found that petitioner is not entitled to anticipatory
bail, petitioner is not entitled to file similar application for the
same relief again. Petition is dismissed.
M. SASIDHARAN NAMBIAR, JUDGE..
