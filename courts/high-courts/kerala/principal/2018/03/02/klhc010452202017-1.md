ORDER
On hearing both sides, it seems that, both these cases,
which are pending as C.C.No.140 of 2017 and C.C.No.141 of
2017 before the Judicial First Class Magistrate's Court,
Erattupetta can be transferred to the Judicial First Class
Magistrate's Court, Pala.
2. In the result, these Transfer Petitions are allowed
and C.C.No.140 of 2017 and C.C.No.141 of 2017 pending
before the Judicial First Class Magistrate's Court, Erattupetta
are transferred to the Judicial First Class Magistrate's Court,
Pala.
The accused in both these cases shall appear before the
Judicial First Class Magistrate's Court, Pala on 02.04.2018.
