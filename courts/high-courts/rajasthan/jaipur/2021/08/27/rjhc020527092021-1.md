Order
27/08/2021
Heard on application for correction in the order dated
06.08.2021 passed in S.B. Criminal Misc. 2nd Bail Application
No.11521/2021.
Counsel for the petitioner submitted that due to
typographical error in para No.2 of the order dated 06.08.2021
passed in S.B. Criminal Misc. 2nd Bail Application No.11521/2021,
it has been mentioned that the petitioner is in custody since
08.02.2021 whereas the petitioner is in custody since 08.04.2021.
In that view of the matter, in Para No.2 of the order dated
06.08.2021 passed in S.B. Criminal Misc. 2nd Bail Application
No.11521/2021, the word 08.04.2021 be read in place of
08.02.2021.

(2 of 2) [CRLMA-251/2021]
The order dated 06.08.2021 stands corrected accordingly.
This order be treated to be part of the order dated
06.08.2021.
The application stands disposed of.
(INDERJEET SINGH),J
