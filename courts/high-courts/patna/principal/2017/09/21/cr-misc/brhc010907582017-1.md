ORAL ORDER
4 21-09-2017 It has been submitted that petitioner’s name is Ram
Pravesh Rai and not Ram Pukar Patel. In the accused column of First
Information Report the name Ram Pukar Parel has been mentioned.
Case diary has been received in this case. From case
diary it appears that there is no apprehension of arrest to this petitioner.
The application is dismissed as withdrawn.
The counsel for the petitioner is given liberty to file
necessary petition before the Superintendent of Police, showing that he
is Ram Pravesh Rai and not Ram Pukar Patel. The Superintendent of
Police concerned, will initiate necessary enquiry and pass appropriate
order.
