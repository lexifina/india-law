# Allahabad High Court, WRIC/39903/2019, 2019-12-07

Court No. - 33
Case :- WRIT - C No. - 39903 of 2019
Petitioner :- Asha Ram
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Bhupendra Singh
Counsel for Respondent :- C.S.C.
Hon'ble Dr. Kaushal Jayendra Thaker,J.
Heard Shri Bhupendra Singh, learned counsel for
petitioner and learned Standing Counsel for the State.
The Sub Divisional Magistrate, Phoolpur wherein under
demarcation of land filed by the petitioner is pending
wherein the objection has been filed in 2014 by the
respondent. This statement is a wrong statement, as a brief
holder, as intentionally made a wrong statement, the
objection of the petitioner has been rejected by the Sub
Division Magistrate, Phoolpur.
The recall application filed by respondent No.3 is pending
since 2018, once the main matter is deemed to be allowed.
The recall application which is pending should have been
decided as expeditiously as possible.
The main matter of the petitioner was deemed to be
allowed despite that the Sub Divisional Magistrate,
Phoolpur has not decided the recall application which has
prejudiced the petitioner herein.
The S.D.M. shall decide the recall application and decide
the main matter on or before 31st March, 2020.
With the above observations, this petition is partly
allowed.
Order Date :- 7.12.2019 / A.N. Mishra
