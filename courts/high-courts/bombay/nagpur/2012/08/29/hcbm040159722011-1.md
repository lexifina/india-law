Heard Advocate for the applicant.
The chargesheet is filed for the offences
punishable under Section 465, 467, 420 read with Section 34
of the Indian Penal Code.
It is submitted that no application of discharge
was moved before the trial Court.
In view of the circumstance, this Court holds that
this Court is not expected to use powers under Section 482 of
the Criminal Procedure Code. There are provisions in
Criminal Procedure Code which allow filing of the application
for discharge. So, the application is disposed of as withdrawn
with liberty to file discharge application.
Interim relief, if any, be vacated.
