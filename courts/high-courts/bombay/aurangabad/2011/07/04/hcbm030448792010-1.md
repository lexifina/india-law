1. Heard learned counsel for the parties.
2, This is an application preferred by the
applicant seeking condonation of delay of 227
caused in filing accompanying application seeking
leave to file appeal.
3. Learned counsel for the respondent opposed
present application vehemently. He submits that
present application bears no substance, it is devoid
of merits and therefore same be rejected.

present application as well as submissions
