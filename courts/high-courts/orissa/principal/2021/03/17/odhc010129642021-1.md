# High Court of Orissa, BLAPL/1426/2021, 2021-03-17

BIKI @ BIKASH NAIK ……. PETITIONER
 -VRS.-
STATE OF ODISHA ……. OPP. PARTY

 02. 17.03.2021 This matter is taken up through Hybrid
arrangement (video conferencing/physical mode).
 Learned counsel for the State submits that he
has not received the case diary and seeks some time
to obtain the same.
 It appears from the rejection order that there
are as many as eleven criminal antecedents against
the petitioner.
 Let the learned counsel for the petitioner file a
comprehensive affidavit in that respect and if the
petitioner has been released on bail in any case, the
copy of the bail order shall also be annexed to the
comprehensive affidavit.
 A copy of the affidavit be given to the learned
counsel for the State in advance in order to enable him
to obtain instruction in that respect.
 Learned counsel for the State shall obtain the
case diary, in the meantime.
 List this matter in the week commencing from
12.04.2021.
