ORDER
This Criminal Original Petition has been filed seeking to direct
the first respondent to file a final report in Crime No.887 of 2017
within a time frame.

2. Heard the learned counsel for the petitioner and the learned
Additional Public Prosecutor appearing for the first respondent.
3. The learned counsel appearing for the petitioner would
submit that though the first respondent registered a case in the
above said crime number on 16.5.2017, no final report is filed till
date.
4. The learned Additional Public Prosecutor appearing for the
first respondent would submit that the first respondent may be
permitted to file a final report within a period of one month.
5. In view of the above, the first respondent is directed to file
either a final report or closure report, as the case may be, within a
period of one month from the date of receipt of a copy of this order
under due intimation to the defacto complainant.
6. With the above direction, this Criminal Original Petition is
disposed of.
