P.C.:-
Learned counsel Shri Kulkarni submits on instructions that
learned trial Court rejected application of the applicant for bail. Thereafter,
the applicant filed for bail before the Sessions Court which was also rejected.
Thereafter, he filed this application for bail in this Court. During the pendency
of this application it was brought to the notice of this Court by the learned
counsel assisting the APP that an application for bail was pending before the
learned Magistrate. Learned counsel Shri Kulkarni states on instructions that
it was for interim bail. Learned counsel Shri Kulkarni on this backdrop states
on instructions that he would like to withdraw this application with liberty to
file another application before this Court. Application is disposed of as
withdrawn with liberty to file application for bail before this Court.
2. Application for assist to APP is also disposed of.
