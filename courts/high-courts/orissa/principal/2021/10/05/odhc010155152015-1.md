Order No.
 ORDER
 05.10.2021
02. This matter is taken up through video conferencing mode.
 This application has been filed by the petitioner for
restoring W.P.(C) No.8595 of 2014 to file which was dismissed
for default on 02.04.2015.
 Heard Mr. Sahoo, learned counsel for the petitioner.
 Considering the submissions made and grounds taken in
this application, the prayer for restoration is allowed and W.P.(C)
No.8595 of 2014 is restored to file.
 The CMAPL is disposed of.
 Urgent certified copy of this order be granted on proper
application.
Prasant ( Biswajit Mohanty)
