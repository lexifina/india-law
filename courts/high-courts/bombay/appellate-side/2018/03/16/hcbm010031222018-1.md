P.C. :-
1. Learned counsel appearing for the applicant prays that the
order dated 12th April, 2017 passed by the learned Registrar (Judicial-I) be set aside and undertakes to remove all the office objections
within one week from today. The undertaking is accepted. Learned
counsel for the respondents have filed the affidavit in reply.
2. For the reasons recorded in the civil application, the order
dated 12th April, 2017 passed by the learned Registrar (Judicial-I) is
set aside on the condition that the applicant removes all the office

extension would be granted. If all the office objections are not
removed within one week from today, the order passed by this Court

civil application is allowed in aforesaid terms. No order as to costs.
3. If the office has construed the order dated 12th April, 2017
as if the petition is dismissed against all the respondents, it is made
clear that by an order dated 12th April, 2017, the learned Registrar
(Judicial-I) has dismissed the petition only against the respondent
no.6 and not against all the respondents. If any such endorsement is
made by the office, the same stands set aside.
4. The interim order which was in force on the date of
dismissal of the order passed by the learned Registrar (Judicial-I)
stands restored.
