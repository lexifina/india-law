JUDGMENT
When this contempt case came up for consideration
on 24.01.2023, this Court passed the following order:
“This Court as per judgment dated 16.12.2022 in
WP(C) No.40197/2022 was pleased to set aside
Annexure-A2 order and observed that there is no
independent consideration by the authority concerned.
Now after Annexure-A3 judgment, Annexure-A4 order
is passed which is a word for word reproduction of
Annexure-A2 order. In such circumstances, I am of the
prima facie opinion that the respondent committed
contempt. Therefore, the respondent will appear in
person before this Court on 13.02.2023. In the
meanwhile, if the order is recalled and a fresh order is
passed, the respondent
 need not appear before this Court. I also make it
clear that, if the judgment is varied or modified, then
also, the respondent need not appear before this
Court.”

CO(C).No.152/2023
3
2. Today, the Government Pleader submitted that
the earlier order is recalled and a modified order is
passed.
3. If that be the case, this contempt case need not
be retained. The petitioner is free to challenge the
modified order, if he is aggrieved.
With the above observation, this contempt case is
closed.
