ORDER
This Criminal Miscellaneous Case is filed challenging
Annexure-A1 Preliminary Order passed under section 111 of Cr.P.C.
No interim order is passed in this case. This Criminal Miscellaneous
Case is pending before this Court from 2017 onwards. I am of the
considered opinion that, this Criminal Miscellaneous Case need not
be retained here. If there is any fresh cause of action to the
petitioner, the same is left open.
With the above observation, this Criminal Miscellaneous Case
is disposed of.
