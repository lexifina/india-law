It is argued that the instant revision is
preferred against an order by which the interim
maintenance was modified under Section 127
of the Code of Criminal Procedure, 1973 (“the
Code”). But, it is argued that now the
application under Section 127 of the Code has
finally been decided and that order is
separately challenged. It is argued that the
instant criminal revision has rendered
infructuous.
In view thereof, the criminal revision
stands dismissed as having been rendered
infructuous.
