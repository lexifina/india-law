 PC
 1. This application is filed for
 setting aside an order dated
 25.8.2003 passed in Criminal
 application no.1629/2003 and for
 restoration of the said
 application to the file and to be
 decided on merits. On perusal of
 the impugned judgment and order,
 it is found that the same has been
 passed on merits. It is true that
 the applicant was absent and none
 was present for him. That by
 itself would only render the

 : 2 :
 impugned order as ex-parte.
 However, the order remains as
 being an order passed on merits.
 It is well settled that there
 cannot be review in the criminal
 law. In the circumstances, the
 remedy of the applicant would lie
 elsewhere. In the circumstances,
 application styled as an
 application to quash another order
 on merits passed by my brother
 Judge, cannot lie. Hence,
 application is rejected.
 (R.S.Mohite,J)
