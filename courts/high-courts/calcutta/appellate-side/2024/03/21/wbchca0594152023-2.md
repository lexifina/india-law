 Mr. Niladri Sekhar Ghosh
 Ms. Sompurna Chatterjee.
 ...for the petitioner.
Mr. Niladri Sekhar Ghosh, learned advocate appearing
for the petitioner intends to withdraw the present revisional
application and file afresh.
Accordingly, CRR 4868 of 2023 is dismissed as not
pressed.
Liberty is granted to the petitioner to file afresh with the
documents under Section 207 of the Code of Criminal Procedure
and the latest order-sheets in connection with Burdwan Police
Station Case No.587 of 2022.
Department is directed to return the certified copy to the
advocate on record of the petitioner on the same being replaced by
photostat copy.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
 (Tirthankar Ghosh, J.)
