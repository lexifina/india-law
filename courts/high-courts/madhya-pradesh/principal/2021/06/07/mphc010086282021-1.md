# High Court of Madhya Pradesh, MCRC/9929/2021, 2021-06-07

(SANJAY DWIVEDI)
JUDGE
The High Court Of Madhya PradeshThe High Court Of Madhya Pradesh
MCRC-9929-2021
(SHIKHAR @ SHEKHAR Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 07-06-2021
Heard through Video Conferencing.
Mr. Vikash Jyotishi, Advocate for the applicant.
Mr. Akshay Pawar, Panel Lawyer for the respondent/State.
Learned Panel Lawyer submits that though in the impugned order
offence relating to the SC/ST Act has not been mentioned, but the same has
been added later on, therefore, the present application filed under Section 439
of the Code of Criminal Procedure is not maintainable and instead of filing the
same, an appeal should have been filed.
Faced with the this, learned counsel for the applicant seeks withdrawal
of this application with liberty to file an appeal.
With the aforesaid liberty, the application filed by the applicant stands
dismissed as withdrawn.
Devashish
