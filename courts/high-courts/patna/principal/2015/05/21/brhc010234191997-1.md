ORAL ORDER
9 21-05-2015 The petitioners are aggrieved by order dated 6.11.1996 passed by the
Collector, Madhubani in Homestead (Appeal) Case No.51/1996-97
affirming the order dated 24.5.1996 passed by the Circle Officer, Rahika.
It appears that the learned Collector did not admit the appeal and held
it to be non-maintainable as the petitioners did not file the certified copy of
the impugned order which was imperative in view the rules.
I find no illegality in the impugned order passed by the Collector,
Madhubani. However, if the petitioners file a fresh appeal annexing all the
relevant documents before the Collector, Madhubani, the same would be
considered in accordance with law.
With the aforesaid observations, this writ application stands disposed
of.
KHAN/-
(Samarendra Pratap Singh, J)
