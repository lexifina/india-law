# High Court of Madhya Pradesh, MCC/1737/2015, 2015-07-13

MCC-1737-2015
(PREM SHANKAR TIWARI Vs THE STATE OF MADHYA PRADESH)
13-07-2015
Shri Praveen Pandey, learned counsel for the applicant.
Shri Pushpendra Yadav, learned Govt.Adv. for the respondents.
This application has been filed for restoration of W.P.No.6723/2015(PIL), which
was dismissed for want of prosecution on 11.5.2015. The application is supported
by affidavit of the counsel himself. Finding the same to be bonafide, the
application is allowed. W.P. No.6723/2015 is restored to its original file. It be
placed for orders before an appropriate Bench.
Application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
(SUSHIL KUMAR GUPTA)
JUDGE
