Heard Mr.Anil Mardikar, learned counsel for the applicant
and Mr S. Ahirkar, learned Special Counsel for the non-applicant.
This is an application for conversion of Criminal Revision
Application No.157 of 2012 into criminal application under Section 482
of the Code of Criminal Procedure. Since the applicant had earlier
exhausted the remedy available under Section 397 of the Code of
Criminal Procedure, another criminal revision under Section 397 of the
Code of Criminal Procedure is not maintainable. Therefore, leave was
granted to file this application for conversion of revision application to
application under Section 482 of the Code of Criminal Procedure.
The prayer is granted.
Criminal Revision Application No. 157 of 2012 shall be
converted into Criminal Application under Section 482 of the Code of
Criminal Procedure.
After conversion, the criminal application be listed on 25th
February, 2013.
The application stands disposed of accordingly.
