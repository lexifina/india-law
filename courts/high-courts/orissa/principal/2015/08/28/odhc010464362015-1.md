# High Court of Orissa, WP(C)/9850/2015, 2015-08-28

W.P.(C) No.9850 of 2015
28.08.2015 Heard Mr. B. Satapathy, learned counsel for the petitioner and Mr. S.S. Rao, learned c
ounsel for the opposite party-Board of Secondary Education, Odisha.
 The petitioner has filed this application seeking for a direction to evaluate her answ
er paper in Second Language English (objective) as per Question Set Code C and re-publish her
result within a time stipulated.
 Mr. B. Satapathy, learned counsel for the petitioner submits that the petitioner appea
red in Annual H.S.C. Examination-2015 having Roll No.500CA030 in R.K. Jew High School, Sindhia
 in subject Code SLE-English. Accordingly, she had been provided with OMR Sheet to answer the
questions with objective OMR processing and Objective Question Booklet. But, she wrongly fille
d the Question Set Code in the OMR sheet by using blue or black ball pen darkening the circle
B, whereby she committed mistake which she brought to the notice of the invigilator. It is sta
ted that the invigilator instructed the petitioner to indicate the Question Set Code C outside
 the box and he put his signature. Accordingly, the petitioner mentioned C outside the box in
the OMR sheet. It is stated that the petitioner demanded for supply of a fresh OMR sheet, but
the same has not been provided with her and as per direction she proceeded with answering the
Question Set Code C. Her answer sheet has not been properly evaluated as the same has been don
e by computer.
 Pursuant to order dated 21.05.2015, Mr. S.S. Rao, learned counsel for the opposite par
ty produced the answer sheet of the petitioner which is annexed as Annexure-3 to the writ peti
tion. As it appears though the petitioner answered the Question Set C, she has darkened the bo
x of Question Set Code B in the OMR sheet which she has been awarded mark accordingly to Quest
ion Set Code B. It is further stated that as per Clause-5, 6 and 7 of the instructions in Anne
xure-5, the petitioner has to abide by the same.
 Considering the contention raised by the learned counsel for the parties, it appears t
hat initially the petitioner darkened the circle B of the Question Set Code. When she found it
 incorrect answer, she asked the invigilator to supply another answer sheet. Though there is a
 provision to return the defective OMR sheet immediately and obtain another correct OMR sheet,
 the invigilator cancelled the darkening of the Question Set Code B by putting his signature a
nd instructed the petitioner to write Question Set Code C outside the box. Therefore, the invi
gilator has not discharged his duty properly by providing separate OMR sheet and no responsibi
lity can be fixed on the Board of Secondary Education, Odisha in evaluating the Question Set C
ode of the petitioner.
 In that view of the matter, the petitioner cannot be suffered due to latches of the in
vigilator. This Court directs the petitioner to file a fresh representation within two weeks f
rom today ventilating her grievances before the authority. In the event the petitioner files s
uch representation, the authority shall consider and pass appropriate order within a period of
 two months from the date of communication of this order. It is needless to say that the autho
rity shall take into consideration that the student has appeared in the examination and answer
ed the Question Set Booklet C on the subject SLE-English OMR Sheet and accordingly dealt with
the same.
 With the aforesaid observation and direction, the writ petition is disposed of.
 Urgent certified copy of this order be granted on proper application.

 Dr. B.R. Sarangi,J.
