ORDER
This civil revision petition is filed challenging the order passed by the
Trial Court, dismissing the application filed by the petitioner to condone the
delay of 2686 days in filing the application to set aside the exparte order dated
26.08.2016.

2. It is seen from the typed set of papers that the petitioner was set exparte
on 26.08.2016. Thereafter, trial in the suit was proceeded exparte and exparte
decree was passed on 18.04.2023. It is also seen from the typed set of papers
that the petitioner has filed a separate application in I.A.No.10 of 2025 to set
aside the exparte decree dated 26.08.2016. Since the exparte decree was already
passed, the petitioner has to challenge the exparte decree alone and the instant
application filed by the petitioner to set aside the exparte order dated 26.08.2016
with a petition to condone the delay is not at all maintainable, after passing of
exparte decree. In fact before passing exparte decree, the defendant is entitled
to seek setting aside of the exparte order and he need not file any petition to
condone the delay. In the case on hand, the petitioner unfortunately filed the
petition to condone the delay in filing the petition to set aside the exparte order.
In any event, the application filed by the petitioner need not be adjudicated at
this stage, when separate application has been filed by the petitioner in
I.A.No.10 of 2025 to set aside the exparte decree passed on 18.04.2023.
Therefore, this court is not inclined to entertain the civil revision petition.
