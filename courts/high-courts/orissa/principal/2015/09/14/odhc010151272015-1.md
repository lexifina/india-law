# High Court of Orissa, WP(C)/16593/2015, 2015-09-14

W.P.C NO.16593 of 2015
14.09.2015 Heard Mr. P.C. Mohanty, learned counsel for the petitioner.
 The petitioner has filed this application challenging the order passed by the learned S
tate Consumer Disputes Redressal commission, Odisha, Cuttack.
 Since against the order passed by the learned State Consumer Disputes Redressal commiss
ion, Odisha, appeal forum is available, this Court is not inclined to entertain this applicati
on. However, liberty is granted to the petitioner to approach the appropriate forum, if he is
so advised.
 The writ petition is disposed of.
 Urgent certified copy of this order be granted on proper application.

 Dr. B.R. Sarangi, J.
