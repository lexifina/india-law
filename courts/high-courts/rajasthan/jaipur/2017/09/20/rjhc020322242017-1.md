Order
20/09/2017
Admittedly, the points which are argued now were not raised
before the learned Single Judge. However, it is contended that
before the learned Single Judge, the petitioner was not
represented and therefore, it would not be open for them to file a
review before the learned Single Judge.
We are of the considered opinion, it will not be appropriate to
allow the petitioner to raise the point at this stage which was not

(2 of 2)

raised before the learned Single Judge. No case is made for
review.
Hence, the review petition stands dismissed.
