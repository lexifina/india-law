1. The hearing has been conducted through Video Conferencing.
2. By this petition, the petitioner seeks regular bail/interim bail in case
FIR No.209/2020 under Sections 380/34 IPC registered at P.S. Lodhi
Colony.
3. Though in the petition, it is stated that no other similar petition has
been filed, however, learned APP for the State points out that a petition for
same relief is pending before the learned Additional Sessions Judge.
4. Learned counsel for the petitioner thus seeks leave to withdraw the
present petition with liberty to file fresh petition, if need arises.
5. Petition and applications are dismissed as withdrawn with liberty to
file a fresh petition and application on the same grounds if so advised.
