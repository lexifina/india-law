PER COURT :
 Heard both the sides.
2. This is an application by the Acquiring Body for seeking
condonation of delay of 263 days in preferring the appeal.
3. The learned advocate for the Acquiring Body submits that it is a
State machinery which has to function through its officers. Besides, it has to
undergo set procedure before preferring the appeals. The time was spent in
completing all these formalities. There was no ill-intention. Its right to
prefer appeal cannot be deprived for the technical reasons.
4. The learned advocate for the claimants opposes the application.
5. For the reasons mentioned in the application, the delay is
condoned.
6. The Civil Application is disposed of.
