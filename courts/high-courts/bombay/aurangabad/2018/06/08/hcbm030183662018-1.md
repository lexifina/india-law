PER COURT:-
1. This is an application seeking recall of the order passed by
this Court on 21.03.2018, dismissing the petition for want of
prosecution.
2. Heard. For the reasons recorded in the application, the
application deserves to be allowed and same is accordingly allowed.
The delay occurred in presenting the instant application stands
condoned. The order passed by this Court on 21.03.2018 contained
in para no. 2 stands quashed and set aside. The directions contained
in para no. 3 shall remain operative.
