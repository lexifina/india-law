O R D E R
This petition is filed to withdraw the S.T.C.No.100/2016
pending on the file of the Fast Track Court (FAC),
Thiruvannamalai and transfer the same to Learned Judicial
Magistrate, Palacode and tried along with S.T.C.No.546/2016 on
the file of Learned Judicial Magistrate, Palacode.
2. Today, when the matter was taken up for hearing, the
learned counsel for the petitioners as well as the respondent
agreed that they have no objection with the proceedings in STC
No.100 of 2016 pending on the file of the learned Fast Tract
Court, Thiruvannamalai being transferred to the file of the
learned Judicial Magistrate, Fast Tract Court, Dharmapuri and
S.T.C.No.546 of 2016 pending on the file of the learned Judicial
Magistrate, Palacode being transferred to the file of the
learned Judicial Magistrate, Fast Track Court, Dharmapuri.
3. In view of the above submissions made by both the
counsels, the proceedings in STC No.100 of 2016 pending on the
file of the learned Fast Tract Court, Thiruvannamalai is
directed to be transferred to the file of the learned Judicial
Magistrate, Fast Tract Court, Dharmapuri and STC.No.546 of 2016
pending on the file of the learned Judicial Magistrate, Palacode
https://hcservices.ecourts.gov.in/hcservices/

is directed to be transferred to the file of the learned
Judicial Magistrate, Fast Track Court, Dharmapuri. Such an
exercise shall be completed within a period of two weeks from
the date of receipt of a copy of this order. The learned
Judicial Magistrate, Fast Track Court, Dharmapuri shall
endeavour to complete the proceedings as expeditiously as
possible.
4. With the above observations, this criminal original
petition is allowed. Consequently, connected miscellaneous
petitions are closed.
