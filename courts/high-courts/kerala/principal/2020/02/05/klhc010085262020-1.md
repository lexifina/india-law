JUDGMENT
This writ petition is prima facie premature
as there is no impugned order so far, except that
there is Ext.P4 show cause notice calling the
petitioner to file the reply. The show cause notice
dated 27.01.2020 was replied on 30.01.2020. There
is no decision thereon. The apprehension as
expressed as on today is far fetched.
Learned counsel for the petitioner seeks
liberty of this Court for withdrawal of the writ
petition.
Petitioner shall be at liberty to file a writ
petition afresh as and when a fresh cause of action
arises.
