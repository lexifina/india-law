The present application is filed for speaking to minutes.
2. It is contended that while passing the order on 08/06/2023,
twelve weeks’ time was granted to file private paper book,
inadvertently, it is referred as “one week time” instead of “twelve
weeks’ time” and the Office kept this matter for dismissal. It appears
that there is an inadvertent mistake.
3. By the consent of parties, the order dated 08/06/2022 be
corrected by substituting the word “one week” with “twelve weeks”.
4. The First Appeal be restored. The learned counsel to file
private paper book within a stipulated period.
5. Accordingly, the application stands disposed of.
