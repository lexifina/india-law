 ORDER
The petitioner in the Review Application has come out with the
present Review Application to review the order dated 02.04.2008 made
in C.R.P(PD).No.1318 of 2008 on the file of this Court.
2. Though the Review Application is pending from the year 2008,
no notice was ordered. A reading of the order sought to be reviewed
reveals that there is no error apparent in the order. Under these
circumstances, the Review Application is dismissed. No costs.
