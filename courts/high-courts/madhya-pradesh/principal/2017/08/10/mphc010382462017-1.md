# High Court of Madhya Pradesh, MCRC/13051/2017, 2017-08-10

MCRC-13051-2017
(ABDUL SHARIF Vs THE STATE OF MADHYA PRADESH)
10-08-2017
Shri S.N. Saraf, learned counsel for the applicant.
Shri Vivek Shukla, learned Govt. Advocate for the respondent/State.
Heard.
This is an application for modification of the bail order dated
27.7.2017 passed in M.Cr.C.No.12153/2017.
Learned counsel for the applicant submits that in the order passed by
this Court dated 27.7.2017 in M.Cr.C.No.12153/2017, Crime No.343/2017
has wrongly been mentioned, whereas, the correct one is, 'Crime
No.343/2017'.
Considering the aforesaid, this application is allowed. Let Crime
No.343/2015, registered at Police Station Hatta, District Damoh, mentioned
in the order dated 27.7.2017 in M.Cr.C.No.12153/2017 be read as Crime
No.343/2017. This order shall be read conjointly with the order dated
27.7.2017.
Let a copy of this order be kept in the record of
M.Cr.C.No.12153/2017.
Certified copy as per rules.
(H.P. SINGH)
JUDGE
A.Praj.
