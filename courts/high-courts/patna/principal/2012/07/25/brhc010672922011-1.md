ORAL ORDER
4 25-07-2012 Heard learned counsel for the petitioner as also the
University.
It is submitted on behalf of the University that
appropriate order has been passed and as such, this contempt
application deserves to be dismissed.
Learned counsel for the petitioner submits that since the
order is not correct, the petitioner proposes to assail the same
before an appropriate forum.
Be that as it may, since admittedly the order has been
passed, the contempt application need not proceed further. The
same stands disposed of.
 PNM
