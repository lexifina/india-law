# Allahabad High Court, A482/42339/2022, 2023-02-02

Court No. - 72
Case :- APPLICATION U/S 482 No. - 42339 of 2022
Applicant :- Mohsin
Opposite Party :- State Of U.P And 2 Others
Counsel for Applicant :- Anubhav Pandey,Aftab Ahamad
Counsel for Opposite Party :- G.A.,Zainul Abdin
Hon'ble Umesh Chandra Sharma,J.
By this application the order passed under Section 12 of Domestic
Violence Act by the Judicial Magistrate, Thakurdwara, Moradabad
has been challenged against which there is provision to file an
appeal. Hence, this application under Section 482 is not
maintainable.
Accordingly, this application is dismissed as not maintainable with
liberty to file an appeal before the competent court.
Order Date :- 2.2.2023
