ORDER
16.11.2021

This matter is taken up through hybrid mode.
2. Mr. P. Das, learned counsel for the petitioner contended that the order
dated 23.11.2020 passed in W.P.(C) No.28020 of 2020 has not yet been
complied with. Therefore, the petitioner has approached this Court by filing
the present writ petition.
3. If the order of this Court has not been complied with, remedy lies
with the petitioner to file contempt petition. Instead of doing so, the present
writ petition has been filed for the selfsame cause of action. Therefore, this
Court is not inclined to entertain this writ petition. However, liberty is granted
to the petitioner to pursue his remedy before the appropriate forum by filing
appropriate application in accordance with law.
4. With the aforesaid liberty, the writ petition is disposed of.
(Dr. B.R. Sarangi)
