1. The present application is for bail under
Section 439 of the Code of Criminal Procedure.
2. After hearing the learned Counsel for the
applicant to some extent, the Court has expressed
disinclination to grant bail, the learned Counsel for the
applicant seeks permission to withdraw the application
with liberty to file after six months, if the trial is not
commenced.
3. After considering the facts on record, the
learned Counsel for the applicant is permitted to
withdraw the application with liberty to file after one
year, if the trial is not commenced within one year.
4. The application is disposed of as withdrawn.
