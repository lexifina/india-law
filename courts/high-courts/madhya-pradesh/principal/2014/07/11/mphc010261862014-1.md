# High Court of Madhya Pradesh, MCRC/8862/2014, 2014-07-11

M.Cr.C. No.8862/2014
11/07/2014
Shri Akhilesh Kumar Giri, Advocate for the applicant.
This application is ill-advised. It is second application
for grant of anticipatory bail filed under Section 438 of the
Code. The first application, being M.Cr.C. No.6067/2014,
having been rejected on 16th May, 2014, by a speaking order,
no interference is warranted in this successive application for
the same relief.
Application is rejected.
 (A.M.Khanwilkar) (K.K. Trivedi)
 Chief Justice Judge
