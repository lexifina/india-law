# High Court of Madhya Pradesh, MCC/847/2017, 2017-03-27

MCC-847-2017
(AJIT YADAV Vs THE STATE OF MADHYA PRADESH)
27-03-2017
Ms. Sonali Paroche, learned counsel for the applicant.
Smt. D.K. Bohre, learned Government Advocate for the
respondents.
This is an application for restoration of W.P. No.
17557/2016 which has been dismissed for want of prosecution by
order dated 15.03.2017.
Considering the aforesaid averments which is supported by
an affidavit of the counsel, the application is allowed. W.P. No.
17557/2016 is restored to its original number.
A copy of this order be attached with the main file of
W.P.No. 17557/2016.
(VIJAY KUMAR SHUKLA)
