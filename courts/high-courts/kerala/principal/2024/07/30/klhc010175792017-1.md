ORDER
This Criminal Miscellaneous Case is filed to quash Annexure-B
final report in C.C.No.459/2016 pending before the Judicial First Class
Magistrate Court-I, Peerumed arising from Crime No.275/2016 of
Peerumed Police Station.
2. As per the e-court service website, it is stated that, based on
the further investigation report, the case is transferred to UD cases and
numbered as 20/2023.
3. The Public Prosecutor submitted that, it is undetected case.
4. In such circumstances, this Criminal Miscellaneous Case
need not be retained. If there is any fresh cause of action to the
petitioner, the petitioner is free to agitate the same separately.
With the above observation, this Criminal Miscellaneous Case is
disposed of.
