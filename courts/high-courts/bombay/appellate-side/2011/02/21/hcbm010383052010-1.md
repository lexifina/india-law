1. This writ petition has become infructuous
inasmuch as it is directed against an
interlocutory order while the appeal in which
the interlocutory order has been passed has
already been dismissed. The writ petition is
therefore disposed of as infructuous.
2. Liberty to the petitioner to file fresh
petition in the event the appeal is restored to
file and interlocutory order is revived.
