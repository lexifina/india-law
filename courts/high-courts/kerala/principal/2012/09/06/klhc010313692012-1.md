JUDGMENT
The common order disposing of I.A. Nos. 925/2012 and
1286/2012 filed under Order XXXIX Rule 1 of the Code of Civil
Procedure are under challenge. The former application is for
an injunction against alienation and the latter application is
for an injunction against committing waste in the property.
The orders so passed are appealable under Order XLIII Rule 1
(r) of the Code of Civil Procedure and this Original Petition is
misconceived.
The Original Petition is dismissed without prejudice to
the right of the petitioner to file appeals if so advised.
V. CHITAMBARESH
