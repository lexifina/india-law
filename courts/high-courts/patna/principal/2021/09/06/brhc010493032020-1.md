2 06-09-2021 Heard learned Counsel for the parties concerned.
Learned Counsel for the petitioner submits that the
petitioner had earlier filed a writ petition in this Court through
electronic mode, challenging the same impugned order as
challenged in the present writ application, but due to some
technical issue, the case number of that writ application was not

2020. He, accordingly, seeks permission to withdraw this writ
application.
Permission is granted.
This writ application is dismissed as withdrawn.
