Order
11/01/2021
1. Being aggrieved of the order dated 7-8-2020 passed by
learned Single Judge in SBCWP No.8271/2020, this Special Appeal
has been presented.
2. Learned counsel for the appellant submits that due to Covid-19 pandemic the application could not be filed before the last date
stipulated by the Single Bench. So many applications are pending
consideration before the State Government, therefore, the

(2 of 2) [SAW-611/2020]
appellant institute should also be allowed to file application for the
purpose.
3. Learned Additional Advocate General has vehemently
opposed the prayer with the submission that the petitioner
institution itself has not availed of the opportunity given by this
court. Instant appeal deserves to be dismissed.
4. In view of the impugned order passed by learned Single
Judge, we find no substance or valid reason to intervene in the
process. The Special appeal is dismissed.
(SATISH KUMAR SHARMA),J (INDRAJIT MAHANTY),CJ
