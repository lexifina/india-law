This matter is taken up through hybrid mode.
2. Heard Mr. Rajit Roy, learned counsel for the
petitioner and Mr. M.K. Balabantaray, learned Standing
Counsel for the State.
3. Mr. Roy contended that the order of the tribunal
having not been complied, the petitioner has approached this
Court.
4. Mr. M.K. Balabantaray, learned Standing Counsel for
the State contended that if the order of the tribunal has not
been fully complied with, then the same will be complied if
some time is given.
5. Considering the rival contentions of the parties, this
Court directs the opposite parties to comply the order of the
tribunal in letter and spirit, if the same has not yet been done,
within a period of three months from the date of production of
