ORDER
This application has been filed to condone the delay of 23 days in
filing an application challenging the order passed by the learned Master.
2. The learned counsel for the respondent has stated that he has no
objection for allowing this application.
3. This Court is also satisfied with the reasons contained in the
affidavit filed in support of this application, as sufficient cause has been
shown by the applicant for condonation of delay of 23 days in filing the
application.
4. Accordingly, this application is allowed as prayed for. Registry
is directed to number the main application if it is otherwise in order and
list the same for admission by printing the name of Mr.A.J.Mohamed
Kassim, as the counsel for the respondent.
