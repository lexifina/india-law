ORAL ORDER:
1. Admit. With consent of learned counsel for
both the parties, heard finally.
2. It is the contention of the appellant that
since the reference application was pending for a
long period and since the same was transmitted from
one court to another court and though the appellant
was pursuing his advocate to communicate the progress
in the matter, the reference application was
dismissed in default for non-appearance of the
appellant.
3. The judgement of the learned reference court
shows that in absence of the appellant and his

 (2) fa120-12
advocate, the reference application was dismissed.
4. Considering the above facts on record, the
impugned award of the learned reference court is
hereby quashed and set aside. The case is remanded
back to the learned reference court. The appellant is
directed to appear before the reference court on 30th
April, 2012. The reference court is directed to
proceed with the hearing of the reference
application. The first appeal is accordingly disposed
of, with no order as to costs.
 [M.T. JOSHI, J.]
