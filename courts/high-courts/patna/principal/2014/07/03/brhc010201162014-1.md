ORAL ORDER
5 03-07-2014 The present application has been filed for
setting aside the order dated 12.05.2014 passed by learned
Sub-Divisional Judicial Magistrate, Patna in Economic Offences
P.S. Case No. 33 of 2013, whereby petitioner’s application for
release of Rs. 49.5 lacs has been rejected.
Since the order has been passed by learned
Sub-Divisional Judicial Magistrate, Patna, the application is
disposed off with liberty to the petitioner to file appropriate
application before the concerned Sessions Judge.
The question of limitation will be considered
by learned Sessions Judge in view of the pendency of the
criminal revision application before this Court.
Shageer/-
