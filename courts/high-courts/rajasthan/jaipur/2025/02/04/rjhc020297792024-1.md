Order
04/02/2025
1. Matter has come up on an application (IA No.1/2025), filed
by petitioner, stating inter alia that in view of subsequent
development, petitioner does want to press this writ petition and
seeks permission to withdraw the same with liberty to file afresh,
in case need arises.

[2025:RJ-JP:4922] (2 of 2) [CW-6456/2024]
2. No reply to the application has been filed and same has not
been opposed by the respondents.
3. Permission is granted.
4. Accordingly, the application (IA No.1/2025) is allowed and
the present writ petition is dismissed as withdrawn with the liberty
prayed for.
However, respondents would be at liberty to take all valid
and legal objections in the fresh writ petition, if same is filed.
5. All pending application(s), if any, stand(s) disposed of.
