P.C.
1 The order impugned is one rejecting the Application to frame a
preliminary issue under Section 9A of the Code of Civil Procedure. It is an
undisputed position that the Application for temporary injunction has already
been decided long back and the proceedings are at the stage where the Plaintiff
has sought police aid for execution, in respect of which the application was
pending. It is at the said stage that the said Application for framing of the
preliminary issue under Section 9A of the Code of Civil Procedure was filed. In
the fact situation of the present case where application for interim injunction
was already decided, the trial Court held that the stage for framing an issue
under Section 9A of the Code of Civil Procedure had long passed and therefore
the application could not be entertained.

2 In my view, in the light of the position in law as regards the stage
at which the issue under Section 9A of the Code of Civil Procedure can be
framed, no fault can be found with the order impugned in the present Petition.
The above Writ Petition is accordingly dismissed.
[R.M.SAVANT, J]
