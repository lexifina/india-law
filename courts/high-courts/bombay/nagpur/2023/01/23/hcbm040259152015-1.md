1. None appears for the appellant.
2. By order dated 23.2.2021, the appellant was directed to file
paper book within six months.
3. Thereafter, by order dated 16.3.2022, again eight weeks’
time was granted to file paper book.
4. As the paper book was not filed, this Court passed following
order on 1.12.2022, as under:
“Six weeks’ time is granted to file private paper book, if
already not filed. In case, it is not filed within the
aforesaid time, the appeal/cross objection in which the
same is not filed, shall stand dismissed without
reference to the Court.”
5. Thereafter, also a last chance was granted to the file paper
book.
6. Learned counsel for the appellant submitted that on last
occasion though he connected to the appellant, the appellant has not
responded to the notice.
7. In this view of the matter, it seems that the appellant is not
interested in prosecuting the appeal.
8. The first appeal is dismissed in default.
