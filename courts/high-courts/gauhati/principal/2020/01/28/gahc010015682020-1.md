Heard Ms. K. Gangawat, learned counsel for the applicant. Also heard Mr. K. Gogoi,
learned standing counsel, Higher Education Department.
The present application is filed for correcting certain typographical error which has
crept in the order dated 16.12.2019 passed by this Court in WP(C) No.6119/2017 in the last
paragraph of the order, the date of the impugned order has been wrongly typed as

Page No.# 3/3
“01.04.2017”, whereas the order impugned in the said writ petition is dated “01.02.2017”.
In view of the above, the present application is allowed, correcting the typographical
error.
The impugned order set aside by this Court will be now read as “01.02.2017” in the
order dated 16.12.2019 passed in WP(C) No.6119/2017.
