# Allahabad High Court, TACR/121/2019, 2019-03-05

Court No. - 71
Case :- TRANSFER APPLICATION (CRIMINAL) No. -
121 of 2019
Applicant :- Mahmood @ Bodhi
Opposite Party :- State Of U.P. And 2 Others
Counsel for Applicant :- Kashif Gilani,Siraj Ahmad Khan
Counsel for Opposite Party :- G.A.
Hon'ble Siddharth,J.
Learned counsel for the applicant has submitted that this
application has been wrongly filed showing the name of
applicant as Mahmood @ Bodh, when the correct name
of the applicant is Naim S/o Zahir. Therefore, he wants to
withdraw this application.
The present application is, accordingly, dismissed as
withdrawn.
However, liberty is granted to the learned counsel for the
appellant to file a fresh application with the correct name
of the applicant. Certified copy of impugned order should
be returned to the learned counsel for the applicant after
keeping the photocopy on record.
Order Date :- 5.3.2019
Ruchi Agrahari
