# Allahabad High Court, A482/9030/2020, 2020-06-19

Court No. - 74
Case :- APPLICATION U/S 482 No. - 9030 of 2020
Applicant :- Smt. Usha Devi
Opposite Party :- State Of U.P. And 3 Others
Counsel for Applicant :- Nitesh Kumar Srivastava
Counsel for Opposite Party :- G.A.
Hon'ble Neeraj Tiwari,J.
Learned A.G.A. has raised preliminary objection that present
Application U/S 482 Cr.P.C. is not maintainable as applicant
have alternative remedy to file revision under sections 397-401
Cr.P.C., which learned counsel for the applicant could not
dispute.
Accordingly, present Application U/S 482 Cr.P.C. is dismissed
as not maintainable with liberty to the applicant to approach
appropriate forum, if so advised.
Let certified copy of the order of court below be returned to
counsel for the applicant after keeping the photocopy of the
same on record.
Order Date :- 19.6.2020
Sartaj
