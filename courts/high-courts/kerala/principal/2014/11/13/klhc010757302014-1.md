Ashok Bhushan, Ag.CJ
Heard learned counsel for the petitioner and the learned
State attorney. No notice need be sent to respondents 3 to 5 in
view of the order which is being passed.
2. The petitioner claims to be running a power stone
crusher unit with all relevant permissions including environmental
clearance by the State Environmental Impact Assessment
Authority. It is submitted that obstruction has been created by
respondents in running the unit. A complaint was submitted on
29.10.2014, which is Ext.P9.
3. The learned State Attorney submitted that on a
complaint, which was submitted by the petitioner, enquiry was
made and it was found that there is no obstruction as on date.
4. In view of the above submission, we see no reason to
continue the writ petition any further. However, we observe that

WP(c). No. 30111/14
2
in the event, there is any obstruction in running the unit, it shall
be open for the petitioner to file a proper complaint before the
first respondent, who may look into the same and take
appropriate action.
With this observation, this writ petition is disposed of.
