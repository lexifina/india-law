This petition coming on for conciliation this day, the Bench passed the
following:
ORDER
Petitioner alleges non-compliance of order dated 06.09.2018 passed by
this Court in Writ Petition No.95/2017.
However, the said order was challenged in Writ Appeal No.1600/2018
which was allowed vide order dated 23.01.2020 and the order of the Single
Judge was set aside. Hence, no cause now survives in the present contempt
petition. Therefore, the same stands dismissed as infructuous.
