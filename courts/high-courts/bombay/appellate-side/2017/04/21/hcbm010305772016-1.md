above Civil Revision Application which has stood dismissed on account of the
conditional order dated 14/06/2012. The above Civil Revision Application has

to allow the above Civil Application and restore the above Civil Revision
Application to file. The above Civil Application is accordingly allowed.
Resultantly the above Civil Revision Application is restored to file. The above
Civil Application is accordingly disposed of.
