JUDGMENT
Kurian Joseph,J.
Delay condoned in all these appeals.
These appeals are filed by the State aggrieved by the
fixation of land value by the reference court, Sub Court, Thrissur.
The acquisition is for the purpose of setting up of industrial
development plot. The Land Acquisition Officer fixed land value
at Rs.2,525/- per cent after deducting 45% of the value shown in
the basic document. The Reference Court, on the basis of
evidence adduced by AW1 and AW2 and also referring to the
report of the Advocate Commissioner Ext.X1 and on referring to
Ext.A8 document, fixed land value at Rs.4,591/- per cent. It is to
be noted that, that is the value shown in the basic document
also. The Reference Court has correctly found that the deduction
made by the Land Acquisition Officer from the value shown in the
basic document is not supported by any valid grounds. Only if
there is justifiable reason for an obvious differentiation with

The property is situated near to Mundur Junction, within 2 kms.
