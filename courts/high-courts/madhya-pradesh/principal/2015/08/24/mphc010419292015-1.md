# High Court of Madhya Pradesh, MCC/2499/2015, 2015-08-24

MCC-2499-2015
(THE STATE OF MADHYA PRADESH Vs ISRAR KHAN)
24-08-2015
Ms. S. Fatima, learned GA for the applicant/State.
This application has been filed for restoration of Writ Petition
No.5478/2012, which was dismissed on account of peremptory
order dated 13/02/2014. There being some delay in filing the
application for restoration, therefore, I.A. No.10939/2015 has been
filed seeking condonation of delay. Both the applications are
supported by an affidavit and there is no reason to disbelieve the
same. Finding the same to be bona fide, both the applications are
allowed.
Condoning the delay in filing the application, restoration
application is itself allowed.
Writ Petition No.5478/2012 is restored to its original number.
After restoration, Writ Petition No.5478/2012 be placed for
orders before appropriate Bench.
Application stands allowed and disposed of.
Certified copy as per rules.
(VANDANA KASREKAR)
JUDGE
