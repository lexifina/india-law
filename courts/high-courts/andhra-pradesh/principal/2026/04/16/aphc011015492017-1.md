:: ORDER ::
The above contempt case was filed complaining that the respondent /
judgment debtor violated the award dated 10.01.2017 passed in OS No. 78 of 2014
on the file of the learned Principal District Judge, Kadapa.
2. When the matter is taken up, it is brought to the Court’s notice that pending
the above contempt case, execution petition was closed on 17.12.2021. The docket
proceedings reads as under:
“Learned counsel for DHr is present. Notice to JDr is served. P.S.
report is received as delivery warrant executed. The relief is already
complied with. EP is hereby closed.”
3. Given the order dated 17.12.2021, whereby the execution petition was closed,
this contempt case is dismissed.
As a sequel, pending miscellaneous petitions, if any, shall stand closed.
