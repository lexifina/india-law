ORAL ORDER
2 05-07-2016 Heard the learned counsel, Mr. Tribhuwan Narayan for
the petitioners.
It appears that by the impugned order dated 03.10.2015,
the learned Sub Judge I, Kaimur at Bhabhua decided the
application under Order 40 Rule 1 C.P.C. in Title Suit No.440 of
2011. This order is appealable under Order 43 Rule 1(s) C.P.C,
therefore, the petitioner has got remedy under the Code.
In such circumstances, this writ application is not
maintainable. If so advised, the petitioners may file appeal before
appropriate forum.
Accordingly, this writ application is dismissed as not
maintainable.
