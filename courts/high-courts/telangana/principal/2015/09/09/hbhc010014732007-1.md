Writ Petition No.19860 of 2007
ORDER: (Per the Hon’ble the Acting Chief Justice Dilip B. Bhosale)
Learned counsel for the petitioner submits that on 16.9.2014, an
order winding up the petitioner-company has been passed and in view
thereof, this petition does not survive. He seeks disposal of the writ
petition as infructuous with liberty to the petitioner to file appropriate
proceedings in the event the winding up order is set aside.
The writ petition is disposed of as rendered infructuous. If the
winding up order is set aside, it is open to the petitioner to take up
appropriate remedy, if any, available in law.
Consequently, pending miscellaneous applications shall also stand
closed. No costs.
