Heard.
1. This petition under Section 482 of Cr.P.C. has been brought for
correction of typographical error in the order passed by this Court in
M.Cr.C.(A) No.796/2107 dated 24.11.2017.
2. It is submitted by learned counsel for the petitioner in the description
given in cause title of the order, the police-station Nawagarh has been
wrongly mentioned in the details of the State of Chhattisgarh which
would have been Police-station-Tarbahar, District-Bilaspur.
3. Learned counsel for the State has no objection, if, the order is rectified
accordingly.
4. Heard both the parties and perused the material on record.
5. Considering the submission and the grounds in the application, the

2
petition is allowed. It is ordered that the description of State of
Chhattisgarh showing Police-station-Nawagarh, District-Bemetara (C.G.)
shall be read as Police-station-Tarbahar, District-Bilaspur forthwith. A
copy of this order shall be attached with the original file of bail
application.
6. Accordingly, this petition stands disposed off.
