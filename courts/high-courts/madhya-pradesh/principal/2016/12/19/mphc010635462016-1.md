# High Court of Madhya Pradesh, MCC/3343/2016, 2016-12-19

MCC-3343-2016
(MANISH RAI Vs THE STATE OF MADHYA PRADESH)
19-12-2016
Shri Gopal Singh Baghel, learned counsel for the
petitioner.
Shri Punit Shroti, learned Panel Advocate for the
respondents.
This is an application for restoration of W.P. No.
17676/2016 which was dismissed for want of prosecution
by order dated 05.12.2016 passed by this Court.
Considering the grounds mentioned in the
application for restoration which is duly supported by an
affidavit of counsel, W.P. No. 17676/2016 is directed to be
restored to file in its original number.
Accordingly the application for restoration is
allowed.
A copy of this order be placed on the file of W.P. No.
17676/2016.
(VIJAY KUMAR SHUKLA)
JUDGE
Amitabh
