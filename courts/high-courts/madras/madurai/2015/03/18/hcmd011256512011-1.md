2008 pending on the file of the first respondent police.

Government Advocate (Crl.side).
3. A reading of the complaint informs that on 02.11.2008, the
petitioner has damaged the de-facto complainant's motor cycle and set the
same on fire and this is a matter for investigation.
4. This Criminal Original Petition stands dismissed. Consequently,
the connected Miscellaneous Petition is closed.
