1. The petitioner is aggrieved that an application
for licence to run a private security agency has
not been considered by the State.
2. Mr. Banerjee, learned senior advocate for the
State submits that a licence to run a private
security agency has been granted on 6th April,
2023.
3. Copy of such licence is taken on record.
4. The writ petition is disposed of.
5. There will be no order as to costs.
6. All parties are directed to act on a server copy of
this order duly downloaded from the official
website of this Court.
 (Rajasekhar Mantha, J.)
