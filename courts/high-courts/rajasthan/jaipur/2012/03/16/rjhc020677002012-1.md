# High Court of Rajasthan, CRLMB/2479/2012, 2012-03-16

CRLMB2479/2012
// 1 //
IN THE HIGH COURT OF JUDICATURE FOR RAJASTHAN
BENCH AT JAIPUR
ORDER
IN
S.B. Cr. Misc. Bail Application No.2479/2012
Raghuveer Sansi Vs. The State of
Rajasthan through Public
Prosecutor
Date of Order ::: 16.03.2012
Hon'ble Mr. Justice Mohammad Rafiq
Shri Vivek Goyal, counsel for petitioner
Shri Paresh Choudhary, Public Prosecutor
####
By the Court:-
Conduct of the petitioner is reprehensible,
in that he filed Bail Application No.1209/2012
before this court on 03.02.2012 on the basis of
rejection order dated 01.02.2012 of learned trial
court. The said bail application was dismissed by
this court vide order dated 08.02.2012. The
petitioner then filed another application for bail
before the court below and same was rejected on
13.02.2012. Then the petitioner has filed this bail
application describing the same to be first bail
application with declaration that no such bail
application has been previously filed. But for the
reporting by the registry about the earlier bail
application filed by the petitioner and rejection
thereof by this court, this application has been
listed along-with earlier bail application. Had
this been listed as first bail application before
the regular bench, there could be possibility in
that event of a different view.
This bail application is rejected.
Learned counsel for the petitioner submits
that he immediately, on knowing about this fact,
filed an application for withdrawal of this bail
application. However, the bail application itself
is rejected.

CRLMB2479/2012
// 2 //
The Deputy Registrar (Judicial) of this
court is directed to alert the stamp report section
of the registry to be watch about such unhealthy
tactics being adopted by the litigants in styling
the second bail application as first bail
application and factum about rejection of the
earlier bail application.
(Mohammad Rafiq) J.
