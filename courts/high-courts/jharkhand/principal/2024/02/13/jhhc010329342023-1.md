Order No. 05: Dated: 13th February, 2024
After some argument, since the impugned order, which is
challenged before this Court is appealable, learned counsel for the
petitioner seeks permission to withdraw this application to file an
appropriate appeal to challenge the impugned order before the
appellate authority.
Considering the aforesaid submission, the prayer is allowed, if
any appeal is file along with the petition of condonation of delay the
said petition for condonation of delay should be considered
sympathetically considering that this writ petition was pending
before this Court.
This writ petition is dismissed as withdrawn with the aforesaid
liberty.
 (ANANDA SEN, J.)
