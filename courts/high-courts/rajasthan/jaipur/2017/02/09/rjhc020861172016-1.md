HON'BLE MR. JUSTICE DEEPAK MAHESHWARI
Order
09/02/2017
 Heard learned counsel for the petitioner and perused the order
dated 28th September, 2016, under review.
Vide order dated 28th September, 2016, the order passed by
learned trial Court on 2nd September, 2016, has been modified to the
extent mentioned in the order dated 28th September, 2016 and has not
been quashed and set aside in toto.
On perusal of the order dated 28th September, 2016, the intention
of this Court is very clear and the order dated 2nd September, 2016,
passed by learned trial Court has not been quashed and set aside.
In view of above, there is no substance in this application, hence,
this application is dismissed accordingly.
