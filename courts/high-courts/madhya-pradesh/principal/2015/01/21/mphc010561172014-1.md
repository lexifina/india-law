# High Court of Madhya Pradesh, MCC/2687/2014, 2015-01-21

M.C.C.No.2687/2014
Harish Shivhare Vs. State of MP & Ors.
 Lok Adalat
21/01/2015
Shri Brindavan Tiwari, learned counsel for the applicant.
This application has been filed for restoration of
W.P.No.5283/2012, which has been dismissed on 14.11.2014.
Having heard learned counsel for the parties and finding
reasonable justification for the defaults committed, this
application is allowed. W.P.No.5283/2012 be restored to it's
original file. It be placed for orders before an appropriate bench.
With the aforesaid, this application stands disposed of.
