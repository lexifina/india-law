ORAL ORDER
1. The petitioner is before this Court seeking for the
following reliefs;
i. SET-ASIDE the impugned order dated 13.01.2025
passed by the Xth Additional Chief Metropolitan
Magistrate, Mayo Hall, Bangalore in CC
No.58569/2023
ii. Allow the Application filed by the Petitioner under
Section 451 and 457 of Code of Criminal Procedure
in CC No.58569/2023
iii. Pass any such other order as this Hon'ble Court
deems fit under the facts and circumstances of the
case.

2. Learned HCGP submits that post the impugned order
dated 13.01.2025 having been passed, the gold has
been released to the complainant who had claimed
the said gold to be of his own, and as such even if
the impugned order was to be set aside, there is no
gold available for return to the petitioner.

3. In that view of the above, even if the impugned
order dated 13.01.2025 passed by the X Additional
ACMM in CC No.58569 of 2023 where be set aside,
the same would not result in the said application
being allowed, inasmuch as the gold is not available
with the said Court for being given to the petitioner
by allowing the application filed by the petitioner
under Sections 451 and 457 of Code of Criminal
Procedure.
4. The consideration of the above petition would be an
empty formality so long as the order returning the
gold to the complainant remains in force.
5. In that view of the matter, reserving liberty to the
petitioner to challenge the said order and if
successful, file a fresh application under section 451
and 457 of Code of Criminal Procedure, the petition
stands disposed.
