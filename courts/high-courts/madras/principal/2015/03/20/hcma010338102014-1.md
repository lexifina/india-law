# Madras High Court, A/2297/2014, 2015-03-20

Application No.2297 of 2014
R.MAHADEVAN,J.
This application has been filed,
seeking appointment of Advocate
Commissioner to seize and deliver the
vehicle/equipment in question to the
applicant. By order dated 04.04.2014,
this Court appointed an Advocate
Commissioner.
2. Today, when the matter is
taken up, learned counsel for the
applicant submitted that till date, the
warrant is not able to be executed by
the Advocate Commissioner and hence
sought for further extension of time to
enable the Advocate Commissioner to
execute the warrant.
3. Taking into consideration the
fact that the application is pending
right from the year 2014, I am of the
considered opinion that there is no
point in keeping the application
pending any further. Hence recording
the above submission of the learned
counsel for the applicant, this
application is closed, however, liberty
is given to the applicant to file fresh
application, at a later point of time, if
so advised.
