For the State : Mrs. Ruby Pandey, APP

 --------
02/23.02.2024 Learned counsel for the petitioner and learned APP for the State
are present.
Learned counsel for the petitioner has submitted that by way of
this criminal revision the order by which the interim maintenance has been
granted by the learned court below has been assailed. Indeed against the
same order, he wants to file the application under section 482 of Cr.PC and,
therefore, he wants to withdraw this criminal revision.
Learned APP for the State has no objection for the same.
In view of the submission made, this criminal revision is
dismissed as withdrawn with liberty to seek the appropriate remedy against
the impugned order.
 (Subhash Chand, J.)
