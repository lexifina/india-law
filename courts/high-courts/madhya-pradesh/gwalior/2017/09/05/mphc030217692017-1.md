# High Court of Madhya Pradesh, RP/567/2017, 2017-09-05

1 R.P.No.567/2017
Smt. Ranjana Kushwah Vs. The State of M.P. & Ors.
05.09.2017
Shri J.S. Rathore, learned counsel for the petitioner.
Shri Ashish Saraswat, learned Government Advocate for
the respondents/State on advance notice.
From perusal of order dated 28-08-2017, it appears that
due to typographical mistake, case number has been
mentioned as W.P.No.5525/2015, whereas it ought to have
been W.P.No.5525/2017 which is clear from the first page
bearing title of the said writ petition wherein case number is
clearly referred as 5525/2017.
Application for review is duly supported with affidavit,
therefore, in the interest of justice, the same is allowed. It is
ordered that in the order dated 28-08-2017, case number be
read as W.P.No.5525/2017. The order dated 28-08-2017 be read
in conjunction with the instant order.
Copy of this order be kept in the file of W.P.No.5525/2017.
Accordingly, the review petition is disposed of.
 (Anand Pathak)
 Judge
