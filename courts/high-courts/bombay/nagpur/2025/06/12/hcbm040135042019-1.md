 Heard.
2. By this application, the State has sought
permission to file charge-sheet in view of the order dated
02.05.2019 whereby it was ordered not to file the charge-sheet
without seeking leave of this Court.
3. The present petition is pending since last six
years. Now the charge-sheet is ready. Considering the
allegations and nature of the offence we are of the opinion
that permission needs to be granted.
4. Accordingly, the application is allowed.
5. Permission is granted to the State to file the
Charge-sheet.

6. Since we have granted permission to file charge-sheet to the State, learned counsel for the applicants wants to
raise a challenge to the same.
7. In the circumstances, we permit the applicant to
withdraw the present application and file a fresh raising a
challenge to the charge-sheet.
8. Accordingly, the application stands disposed of,
as withdrawn.
