# High Court of Madhya Pradesh, MCC/3465/2016, 2017-02-07

MCC-3465-2016
(JAGESHWAR Vs THE STATE OF MADHYA PRADESH)
07-02-2017
Smt. T.Gulatee, learned counsel for the applicant.
Shri Puneet Shroti, learned panel lawyer for the
respondent/State.
This is an application for restoration of
W.P.No.15970/2016 which was dismissed for want of
prosecution on 21.12.2016.
Learned counsel for the petitioner submits that no notice
was issued to the respondents in the said petition and no one was
appearing for them.
For the grounds mentioned in the application for restoration
which is supported by an affidavit, the application is allowed.
W.P.No.15970/2016 is restored to its original number.
(VIJAY KUMAR SHUKLA)
JUDGE
