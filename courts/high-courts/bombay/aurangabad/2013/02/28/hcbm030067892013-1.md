# Bombay High Court, APPLN/911/2013, 2013-02-28

1
IN THE HIGH COURT OF JUDICATURE AT BOMBAY
BENCH AT AURANGABAD
CRIMINAL APPLICATION NO. 911 OF 2013
Gopal Onkar Chavhan
.. PETITIONER/S
VERSUS
The State of Maharashtra and others.
.. RESPONDENT/S
 Mr.Joydeep Chatterji , Advocate for petitioner.
 Mr.K.G. Patil, AGP for respondent No. 1
CORAM :- A.H. JOSHI, J.
 DATE :- 28TH FEBRUARY, 2013.
ORDER :-
1] Heard learned Advocate for the applicant.
2] It is not in dispute that the charge
sheet is already filed. In this background, this
court sees no ground to entertain this
application, and hence this application is
dismissed.
3] Oral request is made by learned Advocate
for the applicant before this court, that the
applicant would surrender in Sessions Court and
would file an application for bail, and in that
event the learned Sessions Judge be directed to

2
consider bail application expeditiously and
preferably on the same day.
4] Learned Advocate for the applicant states
that :-
[a] The notice of application for bail and
intended surrender, would be given to the
Public Prosecutor, Dhule on 6th March, 2013.
[b] The applicant would surrender before the
Sessions Court on 11th March, 2013 and tender
application for release on bail.
5] If the compliance as stated before this
Court is made, learned Sessions Judge, would
decide the application for bail on its on merits
on 11th March, 2013 or as expeditiously as
possible.
6] With the observations and order in para.
Nos.2 and in foregoing para. No.5, this criminal
application is disposed of.
[A.H. JOSHI,J]
grt/-.
