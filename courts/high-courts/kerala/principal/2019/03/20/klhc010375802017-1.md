JUDGMENT
The petitioner has filed this original petition seeking the
following reliefs:
''i. To set aside the interim order in C.M.P.No.4971/17 in M.C.(DV)
No.186/2015 dated 14/6/17 pending before the Judicial First Class
Magistrate Court-I, Kayamkulam.
ii. To modify the condition in the interim order in C.M.P.
No.4971/17 in M.C(DV).No.186/2015 dated 14/6/17 pending
before the Judicial First Class Magistrate Court-I, Kayamkulam by
reducing the amount already paid.''
2. When the case has come up for hearing, the learned
counsel for the petitioner submits that M.C.No.186/2015, pending
before the Judicial First Class Magistrate Court-I, Kayamkulam
has been disposed of and the cause of action to pursue the
original petition does not survive. The submission is recorded.
In the result, the original petition stands dismissed as
infructuous.
