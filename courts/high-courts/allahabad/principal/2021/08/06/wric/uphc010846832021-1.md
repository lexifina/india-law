# Allahabad High Court, WRIC/13647/2021, 2021-08-06

Court No. - 2
Case :- WRIT - C No. - 13647 of 2021
Petitioner :- Khyali Singh
Respondent :- State Of U.P. And 7 Others
Counsel for Petitioner :- Bhupendra Pal Singh,Satyawati
Counsel for Respondent :- C.S.C.
Hon'ble Suneet Kumar,J.
Heard the learned counsel for the parties.
The instant petition has been filed for flouting the interim injunction
granted by the Revenue Court in a suit for partition.
Learned standing counsel submits that petitioner has remedy to file an
application under Order XXXIX Rule 2A of C.P.C. This fact is not being
disputed by learned counsel for the petitioner.
In view thereof, writ petition is disposed of as withdrawn with liberty to
the petitioner to file appropriate application before the competent court, if
so advised.
