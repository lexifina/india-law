# Calcutta High Court, CRR/2517/2012, 2021-09-14

D/L 47.
September
14, 2021
Bpg.
C.R.R. No.2517 of 2012
(Via Video Conference)
In Re: An application under Section 397 and Section 401 of the Code of
Criminal Procedure read with Section 482 of the said Code for quashing
the proceeding under Section 144 of the Code of Criminal Procedure,
1973.
 Jiban Sao & Ors.
 Versus
 State of West Bengal & Anr.
The revisional application was preferred in respect of the
order dated 20.06.2012 passed by the learned Executive Magistrate
in a proceeding under Section 144 of the Code of Criminal
Procedure.
Having regard to the time constraint provided under the
said provision, I am of the view that the main proceeding before the
learned Executive Magistrate has become infructuous.
As such, CRR 2517 of 2012 is dismissed.
Pending application, if any, is consequently disposed of.
Interim order, if any, is hereby vacated.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
 (Tirthankar Ghosh, J.)
