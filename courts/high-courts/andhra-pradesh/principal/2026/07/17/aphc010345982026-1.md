ORDER: (Per Hon’ble Sri Justice Battu Devanand)
Heard learned counsel for the petitioner.
2. Smt. Santhi Chandra, learned Standing Counsel for the
Respondent Nos.3 to 5 has raised a preliminary objection about
maintainability of this writ petition.
3. Admittedly, the petitioner has to file Central Excise Appeal
against the impugned order.
4. At this stage, learned counsel for the petitioner sought
permission of this Court to withdraw this writ petition with a liberty to file a
Central Excise Appeal.
5. Considering the request of the learned counsel for the
petitioner, this Writ Petition is dismissed as withdrawn. Liberty is granted to
the petitioner to file a Central Excise Appeal against the impugned order.
6. Registry shall return all original documents filed by the learned
counsel for the petitioner along with the writ petition.
