respondent no.1 has been dismissed for default and the
application filed by respondent no.1 for restoration is pending.

infructuous. The appellants are at liberty to file fresh appeal
from order in the event the suit filed by respondent no.1 is
restored to file along with the interim order. In view of
dismissal of the appeal from order, the civil application does
not survive. The same is accordingly disposed off.
