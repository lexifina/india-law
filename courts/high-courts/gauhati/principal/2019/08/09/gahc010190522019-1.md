ORDER
Date : 09-08-2019
This is an interlocutory application, filed by the applicant seeking some correction
in the order dated 05.08.2019 passed by this Court in B.A. No.2209/2019.
Perused the application. It appears therefrom that in the B.A. No.2209/2019, the
accused-petitioner was granted bail vide order dated 05.08.2019 in connection with Bihpuria
PS Case No.259/2017. However, the applicant has submitted that the Police Case No. ought
to have been written as Bihpuria PS Case No.253/2017. However, it is submitted that
inadvertently the same was written as Bihpuria PS Case No.259/2017 and accordingly, the
order was passed granting bail to the petitioner in Bihpuria PS Case No.259/2017.

Page No.# 2/2
Now, the applicant has sought for correction of the Police Case No., praying that wherever in
the order dated 05.08.2019, referred above, the Police Case is referred as “Bihpuria PS Case
No.259/2017”, the same be read as “Bihpuria PS Case No.253/2017”.
Accordingly, the application stands allowed with the above modification in the order
dated 05.08.2019 passed in B.A. No. 2209/2019.
This order shall form part of the order dated 05.08.2019 passed in B.A. No.
2209/2019.
The IA stands disposed of.
