Order
11/11/2022
It is brought to the notice of this Court that in the order
dated 07.11.2022, rendered in S.B. Criminal Misc. Bail Application
No.11803/2022 (Kalu @ Kaliya Vs. State), due to some
typographical error in para No.2, some discrepancies have crept in
in para No.2 of the order.
For the reason aforesaid, the order dated 07.11.2022 passed
in S.B. Criminal Misc. Bail Application No.11803/2022 (Kalu @
Kaliya Vs. State) is corrected in the original order itself. The
original order dated 07.11.2022 is directed to be off-loaded and
the corrected order dated 07.11.2022 is directed to be up-loaded.
The hard copy of the original order dated 07.11.2022 be kept
in the ‘D’ part of the file.
(KULDEEP MATHUR),J
