# High Court of Madhya Pradesh, WP/20457/2017, 2018-02-02

THE HIGH COURT OF MADHYA PRADESH
WP-20457-2017
(DHANNU DHURVE Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 02-02-2018
Shri Sushil K. Tiwari, learned counsel for the petitioner.
Mrs. Namrata Agrawal, learned Govt. Advocate for the
respondents.
Counsel for the petitioner submits that on 1.12.2017 he had
taken time to file an application for converting this petition into Public
Interest Litigation. Accordingly, he has filed application I.A.
No.18281/2017.
However, the format of Public Interest Litigation is different
under the Rules.
Therefore, counsel for the petitioner prays for withdrawal of the
petition with liberty to file fresh Public Interest Litigation.
Accordingly, the petition is dismissed with the aforesaid liberty.
C.C. as per rules.
(VIJAY KUMAR SHUKLA)
JUDGE
