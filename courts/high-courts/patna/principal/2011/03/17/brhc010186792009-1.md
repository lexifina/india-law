-------- Opp. Parties/Contemnors
-----------
2 17.03.2011 Heard learned counsel for the
petitioner and counsel for the State.
Counsel for the petitioner would
submit that the order of this Court dated
13.5.2008 in CWJC No. 6234 of 2008 has not
been complied as yet.
Counsel for the State has produced a
copy of the order dated 17.3.2011 to show
that a final order has already been passed by
the Principal Secretary of the Health
Department.
Counsel for the petitioner would
submit that the said order is not in keeping
with the observations made by this Court in
the earlier order.
In the opinion of this Court, when a
reasoned order has been passed, the direction

2
given by this Court stands complied. The
issue as to whether such order is not in
keeping with the observations made or there
is some infirmity including discriminating
the petitioner among the same set of persons
can now be gone into only if the petitioner
would assail the said order dated 17.3.2011
in a fresh proceeding.
That being so, this contempt
application has become infructuous and is
dismissed accordingly with a liberty to the
petitioner to avail appropriate remedy
against the order dated 17.3.2011.
Let a copy of the order dated
17.3.2011 produced by the counsel for the
State be kept in the record of this case.
Rsh (Mihir Kumar Jha, J.)
