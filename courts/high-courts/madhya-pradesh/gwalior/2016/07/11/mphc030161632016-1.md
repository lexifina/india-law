# High Court of Madhya Pradesh, RP/221/2016, 2016-07-11

1 R.P.221/2016
(Om Prakash Rathore Vs. State of M.P.)
 11.07.2016
Shri Pratip Visoria, counsel for the petitioner.
Shri Amit Bansal, Govt. Advocate, for the
respondent/State.
Heard.
This application has been filed for correction in
the cause title of the Writ Petition No.2984/2016
which was disposed of vide order dated 10.05.2016
in the light of Lalita Kumari's case.
Counsel for the petitioner submits that certain
typographical errors have been crept while filing the
petition, therefore, the same needs to be corrected.
Accordingly, this application is allowed and the
order dated 10.05.2016 passed in Writ Petition
No.2984/2016 be modified as mentioned in the cause
title as well as application.
This Review Petition is disposed of accordingly.
 (S.A. Dharmadhikari)
 mani Judge
