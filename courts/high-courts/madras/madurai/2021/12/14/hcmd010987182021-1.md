COMMON ORDER
**************
After some arguments, Mr.G.Sankaran, learned Counsel for the
writ petitioners in the captioned four writ petitions sought leave
of this Court to withdraw the captioned writ petitions but made a
fervent plea to preserve the rights of the writ petitioners to file
writ petitions afresh inter alia assailing the 12.11.2021
communication from second respondent [assailed in the captioned
writ petitions] in a suitable / appropriate manner. This request is
acceded to.
2.Learned Counsel on record Mr.F.Deepak has also made an
endorsement in the case file which reads as follows:
'Permitted to withdraw the writ petition'
