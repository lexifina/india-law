PRITAM MAROTI ADE

THE STATE OF MAHARASHTRA
...
Advocate for Applicant : Mr. Kulkarni Suvidh S. & Mr. Rathod Vivek U.
APP for Respondent – State : Mr. N. T. Bhagat
...
CORAM :SMT. VIBHA KANKANWADI, J.
DATE : 07.12.2021
ORDER :-
. Learned Advocate Mr. Kulkarni submits that he has instructions to
say that the applicant would like to withdraw the present application
with liberty to file application before the Sessions Court for bail in view
of the fact that now the charge-sheet is filed.
2. In view of the circumstance that the charge-sheet is now filed i.e.
after the presentation of this application, this application is allowed to
be withdrawn with liberty to file bail application afresh before the
learned Sessions Judge.
3. Accordingly, present application stands disposed of as withdrawn.
 [SMT. VIBHA KANKANWADI, J.]
