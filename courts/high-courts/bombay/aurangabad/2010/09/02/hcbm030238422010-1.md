PER COURT :
1. Heard learned counsel.
2. It is stated that the applicants have been released on
ad-interim bail by the Sessions Court. Hence, no need to grant any
further protection.
3. So far the investigation is not completed, at the
premature stage, the F.I.R. need not be quashed. If no evidence is
found to implicate the applicants, the Investigating Officer is likely
to file final report and if there is some evidence, the charge sheet is
likely to be filed. Therefore, at the present no substantial case is

2
found for quashing of the F.I.R. itself. The application is disposed
of. Ad-interim relief, if any, is vacated.
