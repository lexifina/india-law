Judgment / Order
20/09/2017
1. Heard on application for modification of order.
2. Ir is contended that amended cause-title has been filed.
F.I.R. number has been wrongly mentioned in the Main Bail
Application as 159/2017 whereas, it is 159/2015.
3. It is also contended that the petitioner is in custody since
August, 2015 but in para 3 of the order, May 2015 has been
mentioned which is typographical error.
4. Considering the contentions of counsel for the petitioner,
application is allowed.
5. The amended cause-title is taken on record in the main bail
application. In the order dated 14.09.2017 in para 2, F.I.R.
159/2017 be read as F.I.R. 159/2015.

(2 of 2)
[CRLMA-509/2017]
6. May, 2015 appearing in second line of para 3 of the order be
read as August, 2015.
