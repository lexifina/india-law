 CORAM: A.I.S. CHEEMA, J.
 DATE : 22ND DECEMBER, 2014
ORDER :
1. In Criminal Application No.1638 of 2014,
heard learned A.P.P. for Applicant and learned
counsel for Respondent. Learned counsel for
Respondent submitted that copy of the Application
has not been served. In this matter, already once
notice was served on the Respondent and it seems,
there has been change of Advocate for Respondent.
The matter was kept back so that the learned
counsel for Respondent can go through the
Application.

cra1638.14
3
2. Going through Criminal Application
No.1638 of 2014, it appears that order dated
February 12, 2014 was passed in Criminal
Application No.2032 of 2012 on the ground that the
matter was not within limitation and there was no
application for condonation of delay. This order
is sought to be set aside. It appears that the
State has subsequently filed Criminal Application
No.1637 of 2014 for condonation of delay caused in
filing Criminal Application No.2032 of 2014.
3. Main matter relates to Prevention of
Corruption Act. In the interest of justice,
present Criminal Application No.1638 of 2014 is
allowed. The impugned order dated February 12,
2014 passed in Criminal Application No.2032 of
2012 is set aside. Criminal Application No.2032 of
2012 is restored to File. The same be taken up
along-with Criminal Application No.1637 of 2014 to
consider the question of delay, on the next date.

cra1638.14
4
Criminal Application No.1638 of 2014 stands
disposed of, accordingly.
4. List Criminal Application No.1637 of 2014
with Criminal Application No.2032 of 2012 on 12th
January, 2015.
5. Learned A.P.P. submits that he will
supply copy of Criminal Application No.2032 of
2012 to the learned counsel, who is now appearing
for Respondent.
