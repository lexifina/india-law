 ORDER
This Criminal Miscellaneous Case is filed to quash the
proceedings in C.C.No.973/2023 on the file of the Judicial
First Class Magistrate Court, Thiruvalla based on settlement.
2. When this Crl.M.C came up for consideration, this
Court directed the Registry to get a report from the Judicial
First Class Magistrate about the time required to dispose the
main case itself. The learned Magistrate submitted a report
stating that the case can be disposed of within two months. If
that is the case, this Crl.M.C can be disposed of directing the
trial court to dispose the matter expeditiously.
Therefore, this Crl.M.C is disposed of directing the
Judicial First Class Magistrate Court, Thiruvalla to dispose
C.C.No.973/2023 as expeditiously as possible, at any rate,
