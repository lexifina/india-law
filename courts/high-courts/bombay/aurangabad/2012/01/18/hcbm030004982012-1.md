Heard learned counsel for the
respective parties.
The petitioner challenges the
impugned order vide which the existing auto
rickshaws have been directed to install
electronic meters prior to 31.12.2012. The
learned counsel for the petitioner submits
that insofar as the existing auto rickshaws
are concerned, such a compulsion cannot be
made.
We find the decision of the authorities

 WP 332/12
2
in directing the electronic meters to be
installed is rather in the public interest. In
any case, sufficient breathing time has been
given to the existing auto rickshaws up to
31.12.2012 to install such meters. No case
is made out for interference. Hence, the
petition is rejected.
