 ORDER
Heard Mr.M.Venkadesh Kumar, learned Counsel appearing for the
petitioner and Mr.K.Raja, learned Counsel appearing for the respondents 1 to 3
and Mr.P.Balathandayutham, learned Special Government Pleader appearing for
the fourth respondent.
2. The learned counsel appearing for respondent 1 to 3 submitted that
if the petitioner appears before the third respondent and file necessary
application they will immediately pass an Order in this regard. The petitioner
would submit that they will file an application within a week.
3. The petitioner is directed to appear before the third respondent and
file an application and on such application being filed, the third respondent shall
process the application and Orders shall be passed expeditiously.
4. With the above direction, this Contempt Petition is closed.
