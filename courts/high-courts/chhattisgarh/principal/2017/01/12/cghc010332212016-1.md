Heard.
The instant petition is filed for correction of
Kh.No.149/1, which is shown at Para-2 of the bail order
dated 23.09.2016, passed in M.Cr.C.(A). No.715/2016.
It is contended that Kh.No.149/1 was old khasra
number, which has been subsequently re-numbered as
Kh.No.99. Therefore, in Para-2 of the order dated
23.09.2016, passed in M.Cr.C.(A) No.715/2016,
Khasra No.149/1 be corrected as Kh.No.99.
State counsel submits that as per case diary old
Khasra number is 149/1 and the new Khasara number
is 99.
T

balram
Perused the case diary, wherein new khasra
number is shown as Kh.No.99 and the old khasra
number is shown as 149/1.
Consequently, it is observed that in the order
dated 23.09.2016, passed in M.Cr.C.(A) No.715/2016,
khasra number 149/1 shown at Para-2 of the order be
read as Khasra No.99.
With such observation, the petition stands
disposed of.
Sd/-
(Goutam Bhaduri)
Judge
