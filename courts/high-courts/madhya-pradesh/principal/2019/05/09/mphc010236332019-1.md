(RAKESH KUMAR AWASTHY Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 09-05-2019
Shri Pranay Choubey, learned counsel for the applicant.
When confronted with the fact that the applicant is required to file a
review application and not an application for restoration in view of the order
passed by this Court on 10.12.2018 in W.A. No. 322/2017, the learned
counsel for the applicant prays for and is permitted to withdraw this
appilication with liberty to file an application for review.
Certified copy of the impugned order be returned to the applicant
subject to the same been substituted by a photocopy.
With the aforesaid liberty, the application for restoration filed by the
applicant is dismissed as withdrawn.
C.C. as per rules.
