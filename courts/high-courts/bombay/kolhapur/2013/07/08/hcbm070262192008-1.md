1. This is a criminal revision application at the behest of the
complainant, who also challenges the acquittal of original accused Nos.3
and 4. This revision application was heard and was admitted and was
directed to be heard along with the criminal application No.2902 of 2008
filed by the State seeking leave to file appeal.
2. When this matter was on Board before the Court on 20th June, 2013,
this Court had adjourned the hearing to 4th July, 2013 at the request of the
learned Counsel. However, on 4th July, 2013, when this application was

3. In the light of the fact that we have dismissed the application filed by
the State seeking leave to file appeal against the judgment of acquittal, this
application is also liable to be dismissed. However, since none appears on
behalf of the applicant, this application is dismissed for default.
