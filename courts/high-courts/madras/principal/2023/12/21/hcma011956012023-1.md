ABDUL QUDDHOSE,J.
Learned counsel for the respondents has stated no objection for allowing
this application, which has been filed to set aside the exparte order dated
06.07.2023.
2.This Court is satisfied with the reasons stated in the affidavit filed in
support of this application as sufficient cause has been shown.
3.Accordingly, this application is allowed as prayed for.
4.Registry is directed to number the condone delay application filed by the
defendants to condone the delay of 78 days in filing the written statement, if the
said application is otherwise in order.
