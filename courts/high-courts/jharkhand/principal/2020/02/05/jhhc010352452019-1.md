# High Court of Jharkhand, Cr.M.P./3493/2019, 2020-02-05

5/ 05.02.2020 Heard learned counsel for the parties.
 2. Petitioner challenges the orders dated 31.07.2013 and
13.09.2013 passed in Complaint Case No.1033 of 2010, by which process
under Section 82 of the Code of Criminal Procedure and attachment order
under Section 83 of the Code of Criminal Procedure have been issued.
Petitioner also challenges the order dated 23.03.2018 by which permanent
warrant of arrest has been issued.
3. Counsel for the petitioner submits that summons were not
even served nor the warrant. He submits that the order issuing process
under Section 82 of the Code of Criminal Procedure is absolutely cryptic
and no subjective satisfaction has been recorded by the Court below. He
submits that without complying the provisions of Section 82(3) of the Code
of Criminal Procedure, order of attachment under Section 83 of the Code
of Criminal Procedure has been passed.
4. I have heard learned counsel for the parties and have gone
through the impugned orders. I find that the order dated 31.07.2013 is
absolutely cryptic and does not reflect any subjective satisfaction. The
order by which attachment in terms of Section 83 of the Code of Criminal
Procedure has been issued is also bad because the same is also cryptic
and has been passed without complying with the provisions of Section
82(3) of the Code of Criminal procedure. Both these orders, i.e., order
dated 31.07.2013 and 13.09.2013 are, accordingly, quashed and set
aside. The consequential order dated 23.03.2018 declaring the petitioner

 -: 2 :-
as permanent absconder is also hereby quashed and set aside. The
matter is remanded to the Court below to proceed further and pass fresh
order in accordance with law.
 This criminal miscellaneous petition is, accordingly, allowed.

(Ananda Sen, J.)
