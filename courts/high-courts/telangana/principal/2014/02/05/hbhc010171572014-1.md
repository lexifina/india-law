JUDGMENT: (per Hon’ble the Chief Justice Sri Kalyan Jyoti Sengupta )
At this stage, we are not interfering with the judgment and
order of the learned single Judge dated 22
nd January 2014, as the
application for interim relief is still pending for hearing. We grant
liberty to the appellant to file a counter-affidavit stating all facts,
which are sought to be brought before us. The counter-affidavit is to
be filed within a fortnight from date without fail. If the counter-affidavit is filed, it would be open for the other party to file an
affidavit in reply within two weeks thereafter. We request the
learned single Judge to decide the application for interim relief, on
which the impugned order was passed, as early as possible,
preferably within a period of one month from the date of completion
of filing the counter-affidavit. All the points are kept open. We
clarify that the earlier observations and findings, though prima facie,
will not be a binding factor at the time of final hearing of this
application for interim relief.
Accordingly, the Writ Appeal is disposed of. Pending
miscellaneous Petitions, if any, shall also stand closed. No costs.
