Applicant :- Duryodhan
Opposite Party :- State Of Up And 03 Others
Counsel for Applicant :- Kamlesh Kumar Tiwari
Counsel for Opposite Party :- G.A.

objection that against the order impugned, the applicant
has remedy to file revision under Section 397/401 Cr.P.C.,

applicant.

application may be dismissed as withdrawn with liberty to
file a revision.
This application is dismissed as withdrawn with liberty to
file revision, if so advised.
