ORAL ORDER
2 11-03-2015 This application has been filed on behalf of the writ
petitioner for correction of the order dated 30-4-2014 passed in
C.W.J.C. No. 11605 of 2012.
 Inspite of the notice having been duly served, no one has
appeared for the Bihar Bhoodan Yagna Committee.
 Having heard the learned counsel for the State and the
learned counsel for the petitioner, in my view the corrections are
formal in nature.
 In the cause title of the aforesaid order, the name of the
petitioner has been wrongly typed as ‘Ram Chandra Prasad Sinh’
instead of ‘Ram Chandra Prasad Sinha’. Let it be so correctly read.

Patna High Court MJC No.4110 of 2014 (2) dt.11-03-2015
 2 / 2
2
 In the order aforesaid of this Court it has been noted as if
Plot No. 5798 falls in Khata No. 133 and Plot No. 5799 falls in
Khata No. 138. The correct position ought to be that both the Plot
No. 5798 and Plot No. 5799 appertain to Khata No. 138. Let the
order of this Court be read accordingly.
 Again, wherever there is reference to 20 decimals of land,
the same should be read as 29 decimals.
 There is yet another mistake in page 3 of the said order.
There is a reference to the original Danpatras, as executed by
Bhubaneshwar Shekhar Dhari Singh. This should be read as
Tripud Dhari Shekhar Singh instead.
 Let the order dated 30-4-2014 passed in C.W.J.C. No.
11605 of 2012 be read accordingly.
 This application is, accordingly, disposed of.
B.Roy/-
