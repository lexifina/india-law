# Madras High Court, A/987/2020, 2020-03-04

A.No.987 of 2020
N.SATHISH KUMAR, J.
This application has been filed
to extend the mandate of the arbitral
Tribunal by 6 months to conclude the
arbitral proceedings.
2. The learned counsel for the
respondent has no objection in
allowing this application.
3. Having regard to the fact
that substantial number of witnesses
have already been examined and only
a few witnesses have to be examined,
the period is further extended to four
months for completion of arbitral
proceedings.
4. This application is Ordered
accordingly.
