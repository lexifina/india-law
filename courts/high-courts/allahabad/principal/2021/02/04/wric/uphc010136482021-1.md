# Allahabad High Court, WRIC/2623/2021, 2021-02-04

Court No. - 34
Case :- WRIT - C No. - 2623 of 2021
Petitioner :- Smt. Gulaicha Devi
Respondent :- State Of U.P. And 4 Others
Counsel for Petitioner :- Ramesh Chandra Mishra
Counsel for Respondent :- C.S.C.
Hon'ble Yashwant Varma,J.
Heard learned counsel for parties.
Undisputedly the application for mutation has come to be
dismissed for want of prosecution and a restoration application
is still pending. In view of the aforesaid and since the
restoration application has been moved only in 2019, no cause
arises to issue any peremptory direction.
Writ petition is dismissed.
