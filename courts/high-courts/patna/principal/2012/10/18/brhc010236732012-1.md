3 18-10-2012 It is pointed out that there is a typographical error in the
order dated 03/10/2012 by which these applications were disposed
of. In the very first line, a reference has been made to the
judgment and order passed in CWJC No. 3438 of 1998 being
dated 18.11.2012 that should read as 18.11.2010.
Similarly, on page 2, there is a reference to CWJC No.
5911 of 2001 that should read as CWJC No. 5911 of 2011.
Let the order aforesaid be read accordingly.
