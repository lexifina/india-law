# High Court of Jharkhand, Cr.M.P./2428/2020, 2020-12-03

02/3-12-2020 Heard the parties.
 Defect No. 9 (i), as pointed out by the office, is ignored.
 In this application, the petitioner has prayed for modification of the
order dated 3.11.2020 passed in B.A. No. 7626 of 2020.
 It has been stated that name of the petitioner is Rama Ram @ Ram
Charan Ram but on account of an error, the same has been mentioned in the
cause title of the order dated 3.11.2020 as Rana Ram @ Rama Charan Ram.
 In such view of the matter, therefore, the order dated 3.11.2020 passed
in B.A. No. 7626 of 2020 is modified to the extent that in the cause title, the name
of the petitioner-Rana Ram @ Rama Charan Ram shall now be read as Rama
Ram @ Ram Charan Ram.
 This application stands allowed with the aforesaid modification.
 Let a copy of this order be sent through Fax.
 ( Rongon Mukhopadhyay, J)
