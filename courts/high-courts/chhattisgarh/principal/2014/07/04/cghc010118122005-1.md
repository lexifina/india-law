ORDER
(4-7-2014)
1. This is an application for compliance ofthe order dated 27.3.1999 passed
by the Madhya Pradesh Administrative Tribunal, Jabalpur, in
O.A.No.1129/92.
2. At the time of filing the application age of the applicant was 52 years and
today it would be more than 67 years. He would have been retired.
3. We are unable to accept that till today order has not been complied with.
4. Consequently, the application stands disposed of reserving liberty to the
applicant to file afresh if cause survives and so advised. No order as to
costs.
