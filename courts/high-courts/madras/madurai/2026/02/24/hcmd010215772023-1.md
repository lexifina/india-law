ORDER
When the Writ Petition was taken up for hearing on 09.12.2025, the learned
counsel for the petitioner sought time to file the translated versions of the
documents, which are in the Tamil language. Accordingly, the matter was directed
to be listed on 16.02.2026 with a specific condition that, in the event of failure to
file the same, the Writ Petition shall stand dismissed. Again, when the matter was
taken up for hearing on 16.02.2026, the learned counsel for the petitioner sought
time to file the translated versions of the documents. Therefore, the matter was
directed to be listed on 24.02.2026 (today) under the caption “for dismissal”.
2. Today, when the Writ Petition was taken up for hearing, the translated
versions of the documents have not been filed and the learned counsel for the
petitioner again seeks time for filing translated versions of the documents, though
this Court has already granted time on two occasions.
