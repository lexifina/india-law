# High Court of Madhya Pradesh, WP/13074/2017, 2017-08-30

WP-13074-2017
(RAJENDRA SINGH Vs THE STATE OF MADHYA PRADESH)
30-08-2017
Shri Rajendra Kumar Singh, learned counsel for the petitioner.
Shri Vishal Dhagat, learned Government Advocate for the
respondents/State.
Learned counsel for the petitioner submits that against the order
(Annexure P-3), petitioner has already preferred an appeal which is
pending before respondent No.2. The petitioner may be permitted to
file stay application before respondent No.2 seeking stay of New
N.I.T.
Shri Vishal Dhagat, learned Government Advocate for the
respondents/State has no objection.
Petition is dismissed as withdrawn with a liberty to file such
application before respondent No.2.
(SUJOY PAUL)
