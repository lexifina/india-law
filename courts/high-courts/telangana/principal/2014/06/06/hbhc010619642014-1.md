ORDER : (per Hon'ble Sri Justice Ashutosh Mohunta)
The petitioner has impugned the penalty order dated
18.03.2014 passed under Section 53(1)(i) of Andhra
Pradesh Value Added Tax Act, 2005 (for short the
A.P.VAT Act) for the assessment period from March, 2010
to January, 2012.
2. Learned counsel for the petitioner states that
against the assessment order for the period from March,
2010 to January, 2012, an appeal was filed by the
petitioner in which the assessment order has been set
aside and the matter has been remanded back to the
original authority.
3. Learned counsel further submits that as the
assessment order has been set aside, the penalty orders
are also liable to be set aside.
4. The aforementioned facts are not disputed by the

learned counsel for the respondent.
5. A copy of the order dated 30.04.2014 passed by the
Appellate Deputy Commissioner (CT), Kurnool, has been
filed.
6. A perusal of the aforesaid order shows that the
assessment order has been set aside and the case has
been remanded back to the original authority.
7. In view of the above, the penalty order dated
18.03.2014 passed under the A.P.VAT Act is also set
aside.
8. With the above observation, the writ petition is
allowed. There shall be no order as to costs.
9. Miscellaneous Petitions pending, if any, shall stand
closed.
