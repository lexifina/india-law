PER COURT :
1. The application for calling the file of R.C.S. No. 112 of 2007
is rejected.
2. Mr. Kotkar, the learned counsel for the petitioner submits
that the said Suit was in respect of the same parties and same suit
property. The said Suit was filed by the respondent, which came
to be dismissed. The documents would be relevant. The said file
is in the same Court. There is no hurdle to call the said file.
3. I have gone through the order and the application made.

 2 W.P. 5769.2013
4. The application does not state as to which are the
documents, which the petitioner feels it relevant for adjudication
of the present dispute. The Court has allowed the petitioner to
file the certified copies of the orders passed therein. The Court
has also observed that there is nothing in the application as to for
what purpose the record and proceedings is required to be called.
In light of that, the order can not be faulted with.
5. The petitioner is at liberty to file certified copies of the
relevant documents of earlier Suit.
6. If the petitioner is in a position to point out the relevancy of
the documents in the earlier Suit, then the petitioner may file
specific application to that effect, which application would be
considered by the Court on its own merits.
7. The Writ Petition is disposed of. No costs.

 [ S.V.GANGAPURWALA, J. ]
