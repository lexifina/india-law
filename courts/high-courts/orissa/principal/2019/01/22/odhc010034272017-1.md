# High Court of Orissa, CONTC/432/2017, 2019-01-22

03. 22.01.2019 Heard Ms. P. Pattnaik, learned counsel for the
petitioner and Mr. A.K. Mishra, learned Addl. Govt.
Advocate.
The petitioner has filed this application alleging
non-compliance of the order dated 06.05.2016 passed by
this Court in CRLMP No.386 of 2016.
Mr. A.K. Mishra, learned Addl. Govt. Advocate
states that there was no time limit fixed in the order
dated 06.05.2016 to register the written report of the
petitioner as FIR. In any case, if the petitioner so desires,
she may file appropriate application in the respective
CRLMP, but instead of doing so, the petitioner has
approached this Court by filing the present application.
 Considering the contention raised by learned
counsel for the parties and after going through the
records, since no time limit has been fixed in the
aforesaid order for compliance of the same, it cannot be
construed that there was any violation of the order. In
any case, if the petitioner so aggrieved, she may file
appropriate application in the CRLMP application for fixing
the time limit for registration of the FIR.
With this observation, contempt application
stands disposed of.
