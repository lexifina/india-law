 O R D E R
This Criminal Original Petition has been filed to change
the investigation in Crime No.492 of 2015, pending on the file of
the second respondent to any other investigating agency.
2.It is seen that already this Court by an order dated
08.02.2016 made in Crl.O.P.(MD).No.2208 of 2016, directed the second
respondent herein to file a final report as expeditiously as
possible. But the second respondent did not complete the
investigation and file a final report as directed by this Court.
3.Today, when the matter is taken up for hearing, the
learned Government Advocate (Criminal side) appearing for the
respondents, on instructions, submitted that now the second
respondent Police is ready to file final report before the concerned
jurisdictional Magistrate.
4.Considering the above facts and circumstances of the
case, the second respondent is directed to complete the
