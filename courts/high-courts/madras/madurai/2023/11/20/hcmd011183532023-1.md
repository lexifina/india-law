2. There is no disputation or contestation that the point on
which aforementioned HCP was allowed is available to the detenue in the
case on hand also. Therefore, captioned HCP will also stand allowed on
the same point with the same observation more particularly, the
observation vide paragraph 13 of the earlier order in Abinaya's case.
3. Ergo, the sequitur is, captioned HCP is allowed. Impugned
preventive detention order dated 17.05.2023 bearing reference in C.No.
45/Detention/C.P.O/T.C/2023 made by the second respondent is set aside
and the detenue Tmt. Banu @ Rammeeja Banu, aged about 50 years, wife
of Thiru.Muthu, is directed to be set at liberty forthwith, if not required
in connection with any other case / cases. There shall be no order as to
costs.
