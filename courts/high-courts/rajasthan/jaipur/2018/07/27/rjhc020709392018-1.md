HON'BLE MR. JUSTICE PANKAJ BHANDARI
Judgment / Order
27/07/2018
1. An application has been filed for correction in the order dated
25.7.2018.
2. It is contended by counsel for the petitioner that in Para 3 of
the order dated 25.7.2018 the amount of rupees one crore thirty
seven lakh has wrongly been mentioned. Infact the amount
deposited by both the persons is to the tune of Rs.1,09,38,699/-.
3. I have considered the contention.
4. From the report submitted by police it is revealed that
Rs.1,09,38,699/- was repaid.
5. Hence, in para 3 of the impugned order in place of
“Rs.1,37,00,000/-” the same be read as “Rs.1,09,38,699/-”.

(2 of 2) [CRLMA-428/2018]
6. The order dated 25.7.2018 is modified and the application
stands allowed.
(PANKAJ BHANDARI),J
