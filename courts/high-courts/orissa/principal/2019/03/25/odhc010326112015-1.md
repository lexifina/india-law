# High Court of Orissa, WP(C)/16000/2015, 2019-03-25

07. 25.03.2019 It appears that this writ petition was filed on 31.08.2015.
Thereafter, the following orders were passed in this case:
On 12.05.2016, following order was passed:
“List this matter next week.”
On 19.05.2016, following order was passed:
 “ Learned Addl. Government Advocate prays for some
time to obtain instructions.
 List this matter on 30.6.2016, by which time
learned Addl. Government Advocate may obtain
instructions or file counter affidavit.”
 On 30.06.2016, following order was passed:
“ As prayed for by the learned counsel for the
petitioners, list this matter after a week.”
On 18.02.2019, following order was passed:
“ None appears for the petitioners.
 In the interest of justice, as a last chance, the
matter to come up on 11.03.2019.”
On 11.03.2019, following order was passed:
 “ Learned counsel for the petitioners requests for
time.
 Accordingly, list this matter on 25.03.2019.”
 Even today, learned counsel for the petitioners requests for
time.
 We decline the requests for further adjournment of the
matter.
 Accordingly, the writ petition stands dismissed for non-prosecution.
 Misc. Cases/ I.As. connected to the writ petition, if any, are
also dismissed.
