Order
24/09/2026
1. The matter comes upon an application for correction in the
order dated 14.09.2026 passed by this Court in SB Criminal Misc.
Bail Application No.11189/2026.
2. Learned counsel for the applicant submits that inadvertently
in the order dated 14.09.2026 in Para No.6, Police Station Kaman,
District Bharatpur was typed, instead of Police Station Vaishali
Nagar, Jaipur.
3. Heard and perused the application.
4. Considering the submissions of learned counsel for the
applicants, the application deserves to be and the same is
accordingly, allowed.

[2026:RJ-JP:38862] (2 of 2) [CRLMA-445/2026]
5. In the order dated 14.09.2026, in Para No.6, “Police
Station Vaishali Nagar, District Jaipur” be read in place of
“Police Station Kaman, District Bharatpur”.
6. This order be treated as part and parcel of the order dated
14.09.2026.
