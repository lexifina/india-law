petitioner has challenged the order dated 07.09.2021 (Annexure P/5) on the
ground that the respondent authorities are not allowing the petitioner to run the

of action to file this writ petition at this stage.
The petition is hereby dismissed at the admission stage itself.
However, petitioner would be at liberty to file afresh, if occasion so
arises.
