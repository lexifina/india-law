# High Court of Orissa, WP(C)/4455/2017, 2017-03-22

W.P. (C) No.4455 of 2017
22.03.2017
Heard.
 Considering the request made by the learned counsel for petitioner, this writ petition
 is permitted to be withdrawn with liberty to the petitioner to file an appeal alongwith an ap
plication for interim protection.
 Since the time for filing appeal is still there, it is open to the petitioner to file
appeal alongwith an application for interim protection immediately.
 It is directed that in the event, the petitioner has not been evicted from the dispute
d property in the meantime, he will not be evicted from the disputed property till considerati
on of the application for interim protection to be filed alongwith the appeal.
 This writ petition stands disposed of as withdrawn but with liberty as prayed for.
 Issue urgent certified copy on proper application.
 ...
 Biswanath Rath, J.
