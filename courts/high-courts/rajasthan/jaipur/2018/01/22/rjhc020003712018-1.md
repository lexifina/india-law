HON'BLE MR. JUSTICE PANKAJ BHANDARI
Judgment / Order
22/01/2018
1. Counsel for the petitioner has moved an application for
modification of order dated 27.10.2015.
2. It is contended by counsel for the petitioner that erroneously
in the bail application in the cause-title, Police Station Halina
District Bharatpur has been mentioned, whereas it should be
Police Station Udhyog Nagar, Bharatpur. It is also contended that
in the cause title name of the accused-petitioner has been
mentioned as Sursh, whereas it should be Suresh.
3. Considering the contentions of counsel for the petitioner,
application is allowed. Order dated 27.10.2015 in the cause-title
Sursh be read as Suresh and Police Station Halina be read as
Police Station Udhyog Nagar, Bharatpur.

(2 of 2)
[CRLMA-35/2018]
4. In the operative portion of the order also in last paragraph
Police Station Halina District Bharatpur be read as Police Station
Udhyog Nagar, Bharatpur.
5. Application is, accordingly, allowed.
(PANKAJ BHANDARI), J.
