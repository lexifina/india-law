SANJEEV PRAKASH SHARMA, J.(Oral)

1. Learned counsel for the petitioner submits that the tentative seniority
list of Lecturer Computer Engineering is not accordance with the Rules.
2. This Court finds that the petitioner has challenged the tentative
seniority list against which he has already submitted his representation.
No final seniority list has been drawn.
3. Writ Petition is therefore found to be premature and the same is
accordingly dismissed with liberty to the petitioner to file afresh when
the cause of action actually arises.
