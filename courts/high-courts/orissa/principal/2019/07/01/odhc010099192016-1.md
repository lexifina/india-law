# High Court of Orissa, CRLMP/1581/2016, 2019-07-01

03. 01.07.2019 In view of the submission of the learned counsel for
the State that pursuant to the written report of the
petitioner, Nayagarh P.S. Case No. 43 of 2017 has been
registered, learned counsel for the petitioner prays for
disposal of this application with necessary observation
relating to completion of investigation, if the same has not
yet been completed.
 In view of the above, the application stands disposed
of with the observation that in the event the investigation of
the above noted case is not yet over, the same be completed
in accordance with law within one month hence.
 Issue urgent certified copy as per the rules.
