19. Order VI Rule 17 of the Code of Civil Procedure was
amended in the year 2002. Before the amendment, the power
of the Court to allow the application for amendment was wider
as compared post-amendment of the Code of Civil Procedure in
the year 2002.
20. However, the power to amend the pleading at any
stage of the proceeding is not taken completely taken away
though it is restricted to some extent. Consequent to the
amendment of Order VI Rule 7 of the Code of Civil Procedure,
in the year 2002, the party seeking amendment has to
establish that despite diligence, he could not have raised
matter before the commencement of the trial.

"26. Order VI, Rule 17 of the Code deals with the

of 1999, this provision was deleted. It has again

amendment at any stage. Now, if an application is

could not have been sought earlier. The object is to
prevent frivolous applications which are filed to delay
