# Bombay High Court, APPLN/1942/2014, 2015-01-21

IN THE HIGH COURT OF JUDICATURE OF BOMBAY
BENCH AT AURANGBAD
CRIMINAL APPLICATION NO. 1942 OF 2014
YOGAJI HARI BAHADURE AND ANOTHER
VERSUS
THE STATE OF MAHARASHTRA AND ANOTHER
...
Advocate for Applicants : Mr. Rakhunde Pravin B.
APP for Respondent/State : Mr. S. G. Karlekar
...
CORAM : S.S. SHINDE & A.M. BADAR, JJ.
Dated: January 21, 2015
…
PER COURT :-
The learned counsel appearing for the applicants, on
instructions, seeks permission to withdraw application with liberty
to file application for discharge before the concerned Court.
2. The application is dismissed as withdrawn, with liberty
as prayed.
3. The learned counsel appearing for the applicants, on
instructions, submits that, the applicants will file application for
discharge within four weeks from today. We make it clear that, in
case, no application is filed within four weeks from today, liberty
granted to the applicants will not be available thereafter. In case,
the discharge application is filed, the concerned Court to decide the
same expeditiously.
4. We make it clear that, in case, if the charge is already
framed, there is no question of liberty to the applicants to file
application for discharge.
( A.M. BADAR, J. ) ( S.S. SHINDE, J. )
