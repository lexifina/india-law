# High Court of Madhya Pradesh, WP/23458/2017, 2018-02-07

THE HIGH COURT OF MADHYA PRADESH
WP-23458-2017
(SHAKUNTALA VISHWAKARMA Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 07-02-2018
Mr. S.D. Mishra, learned counsel for the petitioner.
Mr. Rahul Mishra, learned G.A. for the State.
Mr. Ashok Lalwani, learned counsel for the respondent No.5.
Mr. Mishra, learned G.A. submits that an FIR has already been
registered against the respondent No.5.
Faced with this, learned counsel for the petitioner fairly submits
that then nothing remains to be done in this petition and this petition
has rendered infructous.
Accordingly, this petition is dismissed having rendered
infructous.
(SUJOY PAUL)
JUDGE
