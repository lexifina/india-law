ORAL ORDER

=========================================
3 16-01-2012 Learned counsel for the petitioner fairly submits
that since this writ application relates to the Panchayat
election held in 2006 and in view of the fact that fresh
Panchayat election has taken place in the year 2011 itself
and the result has already been declared, this writ application
has become infructuous.
Learned counsel appearing for the State Election
Commission submits that L.P.A. No. 831 of 2006 has already
been dismissed on 19.7.2010.
Accordingly, this writ application is dismissed
as having become infructuous.
 Spd/- ( Dr. Ravi Ranjan, J.)
