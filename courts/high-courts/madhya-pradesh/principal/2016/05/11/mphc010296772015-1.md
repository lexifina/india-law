# High Court of Madhya Pradesh, WP/9863/2015, 2016-05-11

WP-9863-2015
(DR. PRABHAT PANDEY Vs THE STATE OF MADHYA PRADESH)
11-05-2016
Shri Sunil Kumar Tiwari, counsel for the petitioner.
Shri Sanjay Dwivedi, Dy. AG for the respondents No.1 and 2/State.
Learned Dy. AG submits that the impugned order of transfer dated
15.6.2015 may be set aside by reserving liberty to the State to pass a
fresh order if administrative exigency so requires.
Learned counsel for the petitioner has no objection.
Accordingly, the order dated 15.06.2015 (Annex.P/12) to the extent it
relates to the petitioner, is set aside. Respondents are given liberty to
pass appropriate order if administrative exigency so requires.
Petition is disposed of.
(SUJOY PAUL)
JUDGE
