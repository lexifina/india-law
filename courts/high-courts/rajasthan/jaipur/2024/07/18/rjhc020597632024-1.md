Order
18/07/2024
Present application is filed for typographical correction in the
order dated 02.07.2024, wherein the name of the District i.e.
“District Ajmer” has been wrongly mentioned instead of “District
Alwar”.
For the reasons mentioned in the application, same is
allowed and typographical error needs to be corrected.

[2024:RJ-JP:29907] (2 of 2) [CRLMA-281/2024]
It is directed that in the order dated 02.07.2024, the name
of the District i.e. “District Ajmer” be read as “District Alwar”.
Rest of the order dated 02.07.2024 be maintained as such.
Accordingly, present Criminal Miscellaneous Application is
allowed.
