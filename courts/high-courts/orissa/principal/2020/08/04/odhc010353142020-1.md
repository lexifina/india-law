# High Court of Orissa, ABLAPL/7285/2020, 2020-08-04

03. 04.08.2020 The matter is taken up through video conferencing.

for the State that no criminal case has yet been
registered against the petitioner at Junagarh P.S. in the
district of Kalahandi, learned counsel for the petitioner
prays for withdrawal of this application with liberty to file
the same in case cause of action so arises in future.
 Granting the liberty, as aforesaid, this application
stands disposed of as withdrawn.
