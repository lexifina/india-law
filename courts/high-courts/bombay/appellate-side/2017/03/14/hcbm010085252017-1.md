1 This is an application by the respondent / original
accused no.2 for permission to apply for fresh and valid passport
as well as for permission to travel abroad as and when necessary.

2 Heard learned advocate for the applicant / original
accused no.2 as well as the learned advocate appearing for the
original complainant / appellant, as also the learned APP.
3 The applicant herein i.e. original accused no.2 came to
be acquitted of offence alleged against him and the complainant
has lodged an appeal challenging the acquittal. The applicant /
original accused no.2 is desirous of applying for passport. I see no
hurdle in his request for making an application for getting a
passport. So far as permission to travel abroad is concerned, no
blanket order as prayed, can be granted. Therefore, the order :
i) The application is partly allowed.
ii) The applicant / original accused no.2 is
permitted to apply for fresh valid passport.
iii)He can apply for permission to travel abroad by
giving necessary details and tour itinerary.
(A. M. BADAR, J.)
