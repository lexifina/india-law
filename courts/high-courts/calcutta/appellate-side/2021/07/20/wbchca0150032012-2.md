# Calcutta High Court, CRR/1034/2012, 2021-07-20

20.07.2021 IN THE HIGH COURT AT CALCUTTA
 Item No.2 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
 C.R.R. 1034 of 2012
 (Via Video Conference)
 Biswanath Simlai
 versus
 State of West Bengal & Anr.
In Re: An Application under Section 482 of the Code of
Criminal Procedure, 1973.
Ms. Sayanti Santra … For the Petitioner.
Mr. Arijit Ganguly,
Mr. Sandip Chakraborty ... For the State.
The present revisional application was preferred
challenging the proceedings in connection with B.G.R. No.
1887/10 arising out of Jadavpur P.S. Case No. 196 dated
13.04.2010 under Sections 498A/406/34 of the Indian Penal
Code.
On an earlier occasion, a report was called for. Mr.
Sandip Chakraborty, learned advocate appearing for the State
submits a report dated 19.07.2021 before this Court from
which it is reflected that the case has been transferred to the
learned Judicial Magistrate, 2nd Court, Alipore on or about
31.01.2011 for trial.
The report so submitted by the learned advocate for the
State be kept with the record.
Ms. Sayanti Santra, learned advocate appearing for the
petitioner submits that there has been change of
circumstances since the revisional application was preferred

2
before this Court and as such, the petitioner is not willing to
pursue the present revisional application.
In view of the above, the learned trial court is directed
to proceed with the trial and take the same to its logical
conclusion, if the same, till date, has not been completed.
With the aforesaid directions, CRR 1034 of 2012 is
disposed of.
Interim order, if any, is hereby vacated.
All pending applications, if any, are consequently
disposed of.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
 (Tirthankar Ghosh, J.)
