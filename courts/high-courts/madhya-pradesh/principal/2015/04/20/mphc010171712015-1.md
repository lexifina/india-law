# High Court of Madhya Pradesh, MCRC/5946/2015, 2015-04-20

M.Cr.C. No.5946/2015
20.04.2015
Shri Pushpendra Dubey, Advocate for the applicant.
Shri P.K. Kaurav, Additional Advocate General with Shri
Prakash Gupta, Panel Lawyer for the respondent-State.
Learned counsel for the State on instructions submits that
investigation qua the applicant is still incomplete. No charge-sheet
has been filed so far. Further, the role ascribed to the applicant is
that of a beneficiary. Realizing this position, counsel for the
applicant seeks liberty to withdraw this application with leave to the
applicant to file fresh bail application after filing of the charge-sheet
before the Trial Court in the first place.
Accordingly, application is allowed to be withdrawn with
liberty to file fresh bail application after filing of charge-sheet
against the applicant. All questions are left open.
Certified copy as per rules.
(A. M. Khanwilkar) (K.K.Trivedi)
