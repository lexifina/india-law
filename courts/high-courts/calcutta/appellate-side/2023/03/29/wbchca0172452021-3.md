# Calcutta High Court, CRR/1148/2021, 2023-03-29

29.03.2023 IN THE HIGH COURT AT CALCUTTA
 Item No.44 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
 C.R.R. 1148 of 2021
 Om Prakash Mall & Ors.
 versus
 AVS Global Private Limited & Anr.
In Re: An Application under Section 401 read with Section
482 of the Code of Criminal Procedure, 1973.
Mr. Pran Gopal Das,
Mr. Shuvojeet Gupta … For the Petitioners.
Learned advocate appearing for the petitioners submits
that the petitioners are not inclined to proceed with the
instant revisional application as there has been change of
circumstances.
Accordingly, the revisional application being CRR 1148
of 2021 is dismissed as not pressed.
All pending connected applications, if any, are
consequently disposed of.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance with all
requisite formalities.
 (Tirthankar Ghosh, J.)
