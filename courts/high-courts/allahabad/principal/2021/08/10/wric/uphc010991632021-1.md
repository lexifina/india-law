# Allahabad High Court, WRIC/16141/2021, 2021-08-10

Court No. - 40
Case :- WRIT - C No. - 16141 of 2021
Petitioner :- Dashrath And Another
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Harish Kumar Tripathi
Counsel for Respondent :- C.S.C.
Hon'ble Manoj Misra,J.
Hon'ble Jayant Banerji,J.
Heard learned counsel for the petitioners; learned Standing
Counsel for the respondents 1 to 3; and perused the
record.
The petitioners have prayed for compliance of an order
dated 28th October, 2016, passed under Section 133 CrPC.
As the Code of Criminal Procedure is a complete code in
itself wherein procedure for implementation of the order is
also prescribed, no specific direction need be issued in a
writ petition. It is expected that if the petitioners take
recourse to the appropriate provisions, appropriate
measures shall be taken to implement the order if there is
no legal impediment in doing so.
With the aforesaid observation, this petition is disposed
off.
Order Date :- 10.8.2021.
Rks.
