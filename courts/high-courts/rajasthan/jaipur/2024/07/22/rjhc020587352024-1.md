Order
22/07/2024
This bail application was filed on 08.07.2024 under Section
439 of the Code of Criminal Procedure, 1973. The Code of Criminal
Procedure, 1973 has been repealed by an enforcement of the
Bharatiya Nagarik Suraksha Sanhita, 2023 w.e.f. 01.07.2024.
Since the Code of Criminal Procedure, 1973 has already been
repealed, no application can be entertained under the repealed
provisions.
The petitioner has already allowed time on two occasions for
amending the cause-title but he has failed to do so.
Accordingly, the present bail application is dismissed as filed
under non-existing/repealed provisions.
