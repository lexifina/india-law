# High Court of Rajasthan, CW/2646/2003, 2006-07-26

SB Civil Writ. Petition No.2646/2003
Date of Order: 26th July, 2006.
PRESENT
HON'BLE MR.JUSTICE BHAGWATI PRASAD
Mr.Vijay Bishnoi for the petitioner/s.
Mr.G.R.Punia for the respondent/s.
Mrs.R.R.Kanwar, Addl.G.A.
Heard.
The objection of the learned counsel for the petitioner is
that it was wrongly stated in the order that it was the Gram
Panchayat alone who will discharge the functions for the
development of the Gramdani Villages. In a Gramdani Village the
Village Body can also do it. The argument is impregnated with the
thought that in the instant scenario of law it is not only the Gram
Panchayat but the Gram Sabha can also do it.
 In the instant case if the State Government considers it
proper that it is the Gram Panchayat alone which can do it then it
can pass an order to that effect. It is not to be stated that it is only the
Gram Panchayat , instead it will be stated that it will be done by the
Gram Panchayat. With this modification the State Government may

pass an order notwithstanding the earlier orders passed. The writ
petition is accordingly disposed off.
( BHAGWATI PRASAD), J.
