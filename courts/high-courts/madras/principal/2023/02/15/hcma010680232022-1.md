C.SARAVANAN, J.
The application has been filed to set aside the order dated 04.08.2021
dismissing the suit for non-prosecution and to restore the suit on file. On the
previous occasion on 08.02.2023, A.No.5415 of 2022 was allowed for
condoning the delay of 267 days in filing application to set aside the order
dated 04.08.2021. Considering the fact that the delay has been condoned,
the above application is taken up for hearing today. It is noticed that the
judges summons was served on the counsel for defendant as early as
30.06.2022. However, no steps have been taken by the defendant to file any
written statement.
2.On the other hand, the 3
rd
 and 4
th
 defendants died during the
pendency of the proceedings. Considering the above fact to allow the above
application to restore the suit to the file of this court deserves to be allowed.
Accordingly, application stands allowed. The suit stands restored to the file
of this court.
