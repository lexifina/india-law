This is an application filed by the
petitioner for appropriate order and directions. By
order dated 8th August, 2008, this court has
recorded the purpose of this application in para-2.
We have also noted that on the application filed by
the petitioner, this court by order dated 7/8/2002
has directed to stay further proceedings pending

 2
before the M.A.T. Vide O.A.1396 of 2001. Now, in
view of subsequent developments, the petitioner
himself is seeking to vacate the said order dated
7/8/2002. We see there is no reason not to allow
this application at the instance of the petitioner. In
view of this, the application is allowed. The interim
order dated 7/8/2002 stands vacated. The
Tribunal to proceed with O.A. The application is
accordingly allowed.
