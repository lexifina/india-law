# High Court for the State of Telangana, CRLP/3672/2012, 2012-04-16

THE HON’BLE SRI JUSTICE K.C.BHANU
CRIMINAL PETITION No.3672 OF 2012
ORDER:
This Criminal Petition is filed by the petitioner under Section 482
of Code of Criminal Procedure, 1973 (for short, ‘the Code’) to quash
the proceedings in C.C.No.2 of 2009 on the file of the II Additional
Judicial Magistrate of First Class, Tirupati.
2. When there is no provision under the Code, which will take care
of redressal of the petitioner, then only powers under Section 482 of
the Code can be exercised. If there is no prima facie material to
proceed further in the trial, the petitioner can as well file an application
before the trial Court under Section 239 of the Code to discharge him.
3. Accordingly, the Criminal Petition is dismissed giving liberty to
the petitioner to approach the trial court to file an application under
Section 239 of the Code to discharge him. On such filing, the same
shall be disposed of in accordance with law.
4. Miscellaneous Petitions, if any, pending in this Criminal Petition
shall stand dismissed.
