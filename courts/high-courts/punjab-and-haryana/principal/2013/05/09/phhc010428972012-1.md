RAM CHAND GUPTA, J.(Oral)
The present petition has been filed by the petitioner under
Section 482 of the Code of Criminal Procedure for issuance of directions to
the respondents for fair investigation of FIR No.31 dated 27.03.2012
registered under Sections 448, 457, 380, 427, 506, 148 read with Section 149
of Indian Penal Code at Police Station Dayalpura, District Bathinda and to
file final report in the Court.
It has been stated by learned counsel for the respondent-State on
instructions from ASI Jaspal Singh that investigation in this case has already
been completed and challan has been filed.
In view of the same, it has been stated by learned counsel for the
petitioner that he be permitted to withdraw this petition as the same has
become infructuous.
Dismissed as withdrawn as rendered infructuous.
( RAM CHAND GUPTA )
