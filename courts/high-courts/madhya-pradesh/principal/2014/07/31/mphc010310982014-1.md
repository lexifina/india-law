# High Court of Madhya Pradesh, MCC/1270/2014, 2014-07-31

MCC No.1270/2014
31/07/2014
Shri Sameer Chille, learned Government Advocate for
the applicant/State.
This application has been filed for restoration of Writ
Appeal No.317/2014, which has been dismissed for non
compliance of peremptory order dated 14/06/2014. There
being some delay in filing the application for restoration,
I.A.No.10420/2014 has been filed for seeking condonation of
delay.
Keeping in view the reasons given in the application for
restoration, which is supported by affidavit, finding the same
to be bonafide, both the applications are allowed.
Writ Appeal No.317/2014 is restored to its original file.
It be placed for orders before an appropriate Bench.
MCC stands allowed and disposed of.
(Rajendra Menon) (Alok Verma)
