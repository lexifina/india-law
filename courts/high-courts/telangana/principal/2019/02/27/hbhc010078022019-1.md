# High Court for the State of Telangana, WP/4094/2019, 2019-02-27

HONOURABLE SRI JUSTICE SANJAY KUMAR
WRIT PETITION No.4094 of 2019
ORDER:
Sri K.V.Simhadri, learned counsel for the petitioners, after
arguing for some time, seeks leave to withdraw this Writ Petition
reserving liberty to the petitioners to file a fresh case, if so advised.
Leave granted.
The Writ Petition is accordingly dismissed as withdrawn with
the liberty aforestated.
Pending Miscellaneous Petitions, if any, shall also stand
dismissed. No order as to costs.
