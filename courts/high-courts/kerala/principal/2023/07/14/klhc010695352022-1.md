 ORDER
When this bail application came up for consideration, learned
Public Prosecutor submitted that the final report in Crime
No.634/2022 of Kanjar Police Station, Idukki is already submitted
before the jurisdictional court. If that is the case, the petitioner can
approach the jurisdictional court, on getting summons, if not already
appeared. If the petitioner surrender before the jurisdictional court
with bail application, jurisdictional court will consider the same in
the light of the fact that, there was interim order from this court.
With the above observation, this bail application is closed.
