4. Learned counsel for the petitioner submits that he has filed I.A.

4
No. 03/2025 i.e. application for exemption from payment of
security deposit amount.
5. No reason has been assigned by the petitioner as to why he
should be exempted from depositing the security amount and as
such, the I.A. No. 03/2025 i.e. application for exemption from
payment of security deposit amount is rejected.
6. In view of the above, learned counsel for the petitioner prays for
withdrawal of this petition with liberty to file afresh along with the
security amount.
7. Learned counsel for the other side has no objection.
8. Accordingly, this petition is dismissed, with liberty to file petition
afresh after depositing the security amount.
