# High Court of Orissa, WP(C)/13581/2018, 2018-11-29

03. 29.11.2018 Heard learned counsel for the parties.
 It is stated by learned counsel for the State Pollution
Control Board that the relief sought for in the writ
application has already been granted to the petitioner.
Hence, nothing remains to be adjudicated in this writ
application and the same has become infructuous.
 Accordingly the writ application is dismissed as
infructuous.
 All connected Misc. Cases/I.As are accordingly
disposed of.
