# High Court for the State of Telangana, CRLP/8256/2018, 2018-08-06

THE HON’BLE SRI JUSTICE M. SATYANARAYANA MURTHY
Crl.P.No.8256 of 2018
ORDER

Learned counsel for petitioner seeks permission to withdraw
the criminal petition with liberty to file appropriate application.
2. Granting liberty as prayed for, the Criminal Petition is
dismissed as withdrawn. Registry is directed to return the certified
copy of the order under challenge under proper acknowledgment of
the counsel for petitioner to file appropriate application before the
appropriate Court.
3. Miscellaneous petitions, if any, pending in this criminal petition
shall stand dismissed.
