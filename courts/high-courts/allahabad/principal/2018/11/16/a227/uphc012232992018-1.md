# Allahabad High Court, A227/8551/2018, 2018-11-16

Court No. - 55
Case :- MATTERS UNDER ARTICLE 227 No. - 8551 of 2018
Petitioner :- Kamil And 3 Others
Respondent :- State Of U.P. And Another
Counsel for Petitioner :- Rajeshwar Singh
Counsel for Respondent :- G.A.
Hon'ble Vivek Kumar Singh,J.
Heard Sri Rajeshwar Singh, learned counsel for the petitioners, Sri
Akhlesh Kumar Mishra, learned counsel for the respondent and learned
A.G.A for the State.
Learned counsel for the respondent submits that an application under
Section 482 Cr.P.C. No.37878 of 2017 has been filed for the same relief
before this Court which was dismissed for want of prosecution vide order
dated 27.11.2017 and the restoration/recall application No.2 of 2018 for
the same has been pending before this Court and when the same is pending
before the Court, there is no reason to file a fresh petition for the same
relief.
Learned counsel for the petitioners does not dispute the same.
After hearing the learned counsel for the petitioners, learned A.G.A. for
the State and learned counsel for the respondents and after perusing the
order dated 27.11.2017, this Court is of the opinion is that no fresh petition
will lie when an application is already pending before this court for the
same relief. Hence, petition lacks merit and is hereby dismissed.
Order Date :- 16.11.2018
