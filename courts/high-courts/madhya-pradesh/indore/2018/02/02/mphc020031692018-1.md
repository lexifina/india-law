# High Court of Madhya Pradesh, RP/149/2018, 2018-02-02

Indore, dated : 02.02.2018
Shri V.K. Patwari, learned counsel for the
petitioner.
 Ms. Nidhi Bohara, learned Govt. Advocate for
respondents, on advance copy.
 The petitioner has filed the present review
petition for correction in the last para of the order
dated11.10.2017 passed in W.P. No.995/2017, in which the
date of the impugned order has wrongly been typed.
 The petitioner filed the aforesaid writ petition
challenging the orders dated 10.6.2016 and 4.7.2017, but the
date of impugned order has wrongly been mentioned as
8.8.2014 in the order dated 11.10.2017.
 This review petition is allowed. The date of
impugned order mentioned as 8.8.2014 be read as 10.6.2016
and 4.7.2016.
 With the aforesaid, this review petition is
disposed of. Let a copy of this order be placed in the record
of W.P. No.995/2017 and both the orders be read cojointly.
 ( VIVEK RUSIA )
 JUDGE
