# Calcutta High Court, CRR/1605/2020, 2023-02-07

07.02.2023
Ct. 30
Sd./33 CRR 1605 of 2020
Mr. Mritunjoy Halder ..For the O.P.
This revisional application has been preferred
against an order in a proceeding under section 138 of the
N.I. Act.
Learned counsel for the opposite party is present
but there is no representation on behalf of the petitioner
since the date of listing.
Considering the conduct of the petitioner, the
present revisional application stands dismissed for
default.
All connected applications stand disposed of.
Interim order, if any, stands vacated.
Let a copy of this order be sent to the learned trial
court for information and compliance.
 ( Shampa Dutt (Paul), J. )
