ORDER
Today, when the matter was taken up for hearing, the learned counsel for
the petitioner sought further time to file the translated copies.
2. On the last hearing dated 10.06.2026, this Court had given
sufficient time to the learned counsel for the petitioner to file the translated
copies. However, the same was not complied with. Therefore, this Court
directed the Registry to list the case under the caption ‘For Dismissal’ as a last
chance to file translated copies.

3. Despite the case being listed under the caption ‘For Dismissal’, and
sufficient time having been granted, the learned counsel for the petitioner has
failed to file the translated copies as directed by this Court, since, this Court
proceed without the translation, the petition deserves to be dismissed due to
non-compliance.
4. Accordingly, this Writ Petition is dismissed for non-compliance with
the directions of this Court. No costs.
