# Madras High Court, COMP.A/218/2017, 2023-03-10

Comp.A.No.218 of 2017
in C.P.No.281 of 2012
KRISHNAN RAMASAMY, J.
This application is filed to
condone the delay 160 days in filing the
set aside application setting aside the
order dated 11.01.2016 in C.P.No.281 of
2012 on the file of this Court.
2. Initially on 06.01.2023, a
learned counsel appeared for the
applicant and reported that he has no
instructions and also requested to delete
his name.
3. Accordingly, the name of the
learned counsel was deleted and the
name of the applicant was printed in the
cause list.
4. However, in spite of the
opportunities given to the applicant, none
appeared on behalf of the applicant
today.
5. This shows that the applicant is
not interested to contest this matter.
Therefore, this application is dismissed
for non-prosecution.
10.03.2023
