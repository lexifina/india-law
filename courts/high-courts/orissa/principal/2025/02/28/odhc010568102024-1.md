Order No.
01. 1. This matter is taken up through Hybrid Arrangement
(Virtual/Physical Mode).
 2. It is alleged by the learned counsel for the Petitioner that
although the order dated 22.02.2024 passed by this Court in
W.P.(C) No.3798 of 2024 has been communicated to the
Opposite Party-Contemnor, however, the Opposite Party-Contemnor has not been implemented the same as of now.
 3. Learned counsel for the Opposite Party-Contemnor, on
the other hand, sought for some time to implement the order of
this Court in the event the same attains finality.

 Page 2 of 2.
 4. Considering such submission, as a last chance, further
six weeks’ time is granted to the Opposite Party-Contemnor to
implement the order dated 22.02.2024 passed by this Court in
W.P.(C) No.3798 of 2024. It is made clear that in the event the
order of the Court is not given effect to within the time
stipulated hereinabove, it will be construed to be deliberate
violation of this Court’s order.
 5. With the aforesaid observation and direction the
contempt petition is disposed of.
 (A.K. Mohapatra)
