circumstances, is not in a position to inform this Court
as to whether the grievance, for which this application
was filed, is still persisting. He accordingly would seek
leave to withdraw this application with a liberty that in

allowed to pursue internal remedy.
Accordingly, this application is permitted to be
withdrawn with the aforementioned liberty.
