ORDER
 As early as on 11.03.2025, this Court had appointed an Advocate
Commissioner to re-possess the vehicle from the respondents. Earlier on
15.04.2025, a request was made for extension of time for the Advocate
Commissioner to execute the warrant of commission. Based on the said
request, extension was also granted by this Court. Till date, the Advocate
Commissioner has been unable to re-possess the vehicle. One more
extension is now sought for, which cannot be granted.
https://www.mhc.tn.gov.in/judis

ABDUL QUDDHOSE, J.
KKN
2. No useful purpose will be served, if this application is allowed to
be kept pending, that too, when the vehicle is yet to be located.
Accordingly, this application is closed. However, liberty is granted to the
applicant to file a fresh application seeking for appointment of an Advocate
Commissioner, once the vehicle is located.
3. While considering the fresh application, this Court shall consider
retaining the very same Advocate Commissioner appointed in this
application, since the applicant has already paid the initial remuneration to
the Advocate Commissioner.
