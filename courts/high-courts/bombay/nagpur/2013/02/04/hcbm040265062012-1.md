Heard.
By this petition, the petitioners impugn an order
passed by the Principal District Judge, Amravati on
28.6.2012, allowing an application filed by the respondents
for transfer of Misc. Civil Application No.30/2006 to the
court of District Judge-II, Achalpur, where a similar matter
Misc. application No. 31/2006 was pending.
The Principal District Judge, Amravati rightly
directed the withdrawal of Misc. Application No. 30/2006
from the file of District Judge-I file and transferred the same
to the District Judge-2, Achalpur for disposal in accordance
with law. The District Judge-2 Achalpur had already decided
Misc. Application No. 33/2006 on merits. The issues involved
in Misc. Application No. 33/2006, Misc. Application No.
30/2006 and Misc. Application No. 31/2006 were similar.
The subject matter involved in both the applications was
similar and the issues involved were also the same. If that
was so, with a view to avoid the conflict in findings, the
learned Principal District Judge, Amravati rightly transferred
Misc. Application No. 30/2006 on the file of District Judge-2

Achalpur to the file of District Judge-I, where Misc.
Application No. 31/2006 was pending. There is no error
whatsoever in the impugned order so as to interfere with the
same in exercise of the writ jurisdiction.
In the result, the writ petition is dismissed with
no order as to costs.
