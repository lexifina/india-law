ANOOP CHITKARA, J. (ORAL)
Aggrieved by a crypc response dated 24.11.2022, the complainant has
come up before this Court.
2. A perusal of the representaon which was decided reveals that it is
unnecessarily lengthy and not dra-ed in a proper way, as such, in case the representaon is
not appropriate, the concerned officer alone cannot be put to fault for crypc response. Let
the peoner file a proper precise and clear representaon with paragraph numbers
properly dra-ed and the same be done within one month. If such representaon is filed
within one month, then the concerned officer of respondent -agency shall decide the same
in para wise manner apart from observaons within two months therea-er.
3. Given above, the present peon is disposed of. It is clarified that if the
representaon is not filed within one month from today then this order shall eclipse
automacally therea-er. All pending miscellaneous applicaons, if any, stand disposed of.
