Dated this the 01st day of July, 2014
JUDGMENT
An order refusing to set aside the ex-parte decree after
condoning delay is impugned in this Original Petition. Such an
order is very much appealable under Order XLIII Rule 1(d) of the
Code of Civil Procedure. Moreover the petitioner has concededly
challenged the final decree itself in R.F.A. No. 249/2014 on the
file of this Court. The petitioner is free to urge his contentions in
the Regular First Appeal if so advised.
I decline jurisdiction and the Original Petition is dismissed.
V.CHITAMBARESH
JUDGE
