# High Court of Rajasthan, WMAP/129/2015, 2015-07-02

IN THE HIGH COURT OF JUDICATURE FOR RAJASTHAN AT
JODHPUR
O R D E R
S.B.CIVIL MISC. APPLICATION NO. 129/2015
IN
S.B.CIVIL WRIT PETITION NO. 2781/2011
Date of order : 2.7.2015
HON'BLE MR. JUSTICE SANDEEP MEHTA
Mr. H.S.Rajpurohit, for the petitioner.
<><><>
An application has been moved for reconstitution
of file of S.B.Civil Writ Petition No. 2781/2011 filed on behalf
of the petitioner which is reported to have gone missing from
the Registry. The Dy. Registrar (Judicial) has reported that the
file is not traceable. In this view of the matter, the file is
directed to be reconstituted. Learned counsel to file the
pleadings and complete documents on record within a week.
Reconstituted file be placed for orders on 18.7.2014.
(SANDEEP MEHTA), J.
/Sushil/
