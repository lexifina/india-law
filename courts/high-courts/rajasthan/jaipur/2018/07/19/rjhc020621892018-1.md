(2 of 2) [CRLMA-402/2018]
1. Counsel for the applicant has moved this application seeking
modification of the order dated 04.07.2017 passed by this Court.
2. It is contended by counsel for the applicant that in para
No.15 of the order dated 04.07.2017, in place of protest petition,
FR should have been mentioned.
3. I have perused the order dated 04.07.2017.
4. Application is, accordingly, allowed.
5. In line 3 of para No.15 of the order dated 04.07.2017, in
place of protest petition, the same be read as Final Report (FR).
