This application coming on this day before this
court for hearing and the court made the following order:

2
The learned counsel appearing for the applicant
submits that, the issue between the parties raised in this
application has been settled between them and recording the
same, the learned counsel wants this matter to be disposed
of.
2. Recording the said submission made by the learned
counsel appearing for the applicant, as the matter has been
already settled between the parties, no further order is
required to be passed in this application, hence, this
application is closed.
