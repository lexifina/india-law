# High Court of Madhya Pradesh, MCC/2046/2015, 2016-10-24

MCC-2046-2015
(SMT AFSHANA TABASSUM Vs THE STATE OF MADHYA PRADESH)
24-10-2016
The case is listed for correction of typographical error in the order
dated 18.08.2015, wherein W.P. No.19852/2014 has been wrongly
mentioned instead of W.P. No.6287/2015.
Vide order dated 18.08.2015, W.P. No.19852/2014 has been wrongly
mentioned instead of W.P. No.6287/2015. The above typographical
error needs to be corrected. It is therefore made clear that in the
aforesaid order wherever W.P. No.19852/2014 is mentioned be read as
W.P. No.6287/2015.
This order shall be read in conjunction with the order dated 18.08.2015
in M.C.C. No.2046/2015.
Certified copy as per rules.
(MISS VANDANA KASREKAR)
JUDGE
