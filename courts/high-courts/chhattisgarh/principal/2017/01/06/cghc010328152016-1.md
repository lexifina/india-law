Hon'ble Shri Justice Goutam Bhaduri
Order on Board
06-01-2017
1. Learned counsel appearing for the applicant would submit that by
mistake name of the applicant has been wrongly mentioned in the
cause title and the present applicant is already on bail and actual
name of the applicant is Saiyad Shabir Shabri who is in custody.
Therefore, he wants to withdraw the instant bail application with
liberty to file duly constituted petition with correct name of the
applicant.
2. Accordingly, the instant bail application is dismissed as withdrawn
with aforesaid liberty. Registry is directed to return the certified
copy of the order dated 9-12-2016 to counsel for the applicant after
retaining the photo copy of the same.
3. Applicant is at liberty to file duly constituted bail petition with correct
name of the applicant.
Sd/-
