# Madras High Court, A/559/2019, 2020-06-05

A.No.559 of 2019
N.SATHISH KUMAR,J.
This application has been filed to direct the respondent furnish
security for a sum of Rs.3,39,855.17 failing which to attach the immovable
properties of the respondent morefully described in the schedule, till the
enforcement of the Award that may be ultimately passed in the arbitration
proceedings.
2. This Court by an Order dated directed the respondent to furnish
security for the suit claim on or before 17.10.2019 and on failing to furnish
security, there shall be Order of attachment.
3. Despite the Order of this Court directing the furnish security, the
respondent have not furnished any security and none appeared for the respondent.
4. In view of the same, there shall be an Order of attachment of the
immovable properties described in the schedule. The registry is directed to
communicate this Order to the concerned Registrar.
