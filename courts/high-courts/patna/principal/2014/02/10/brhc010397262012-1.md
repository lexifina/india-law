ORAL ORDER
3 10-02-2014 Learned counsel appearing for the State produces a
copy of the order dated 03.10.2012 by which final order regarding
confiscation of the seized articles has been passed by the
competent authority and the authority concerned has already
passed necessary order for sale of the seized fertilizers which has
already been done and the sale proceed has already been deposited
in the Treasury. A copy of necessary document showing such
deposit has been produced which is in BTC Form – 4.
In above view of the matter, learned counsel for the
petitioner seeks leave to withdraw this application to prefer appeal
