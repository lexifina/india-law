Mr. Loney prayed for withdrawal of this application with liberty to
file a fresh application for discharge under section 482 in the
proper Court, if the State files a charge sheet. P.C. Request is
fair. Application is allowed to be withdrawn. Liberty is granted to
the petitioners to file discharge application before the competent
court if charge sheet is filed. Petition does not survive in view of
withdrawal of Criminal Application No.2015 of 2008 and is
accordingly disposed of.
