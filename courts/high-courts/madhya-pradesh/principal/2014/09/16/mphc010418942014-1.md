# High Court of Madhya Pradesh, MCC/1953/2014, 2014-09-16

M.C.C.No.1953/2014
1
Mohammad Saleem Vs. State of MP & Ors.
16/09/2014
Shri Sanjay Seth, learned counsel for the applicant.
Shri Amit Sharma, learned Panel Lawyer for the State.
Shri Rohit Jain, learned counsel for Respondent No.2.
This application has been filed for restoration of
W.P.No.884/2013, which has been dismissed for want of
prosecution.
There is a delay of 30 days' in filing of this application and,
therefore, I.A.No.12800/2014 has been filed for condonation of
delay.
Having heard learned counsel for the parties and taking note
of the reasons indicated in the application and finding the same to
be bonafide, both the applications are allowed. Condoning the
delay in filing of this application, the restoration application is
itself allowed. W.P.No.884/2013 be restored to it's original file. It
be placed for orders before the appropriate bench.
The application stands allowed and disposed of.
(Rajendra Menon) (Anil Sharma)
