HON'BLE MR. JUSTICE BIRENDRA KUMAR
Order
29/06/2022
This application is for correction in the order dated
23.05.2022 passed in S.B. Criminal Misc. Petition No.3609/2022,
whereby, the petition was disposed of.
Correction has been sought to the extent that name of
District is “Dausa”, which is wrongly typed in the said order as
“Alwar” due to identical typing error in the petition.
Since, the error is clerical one, Police Station-Mandawar falls
within District-Dausa and not within District-Alwar. Hence, order
dated 23.05.2022 is corrected to the extent that wherever name
of District is mentioned as Alwar, be read as Dausa.
With the aforesaid, application stands disposed of.
(BIRENDRA KUMAR),J
