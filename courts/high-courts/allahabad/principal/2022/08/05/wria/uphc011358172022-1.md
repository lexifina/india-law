# Allahabad High Court, WRIA/11513/2022, 2022-08-05

Court No. - 34
Case :- WRIT - A No. - 11513 of 2022
Petitioner :- Smt. Kalawati
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Ashok Kumar Singh Bais,Arvind
Kumar Mishra
Counsel for Respondent :- C.S.C.
Hon'ble Neeraj Tiwari,J.
Heard learned counsel for petitioner and Ms. Sushma Singh,
learned standing counsel for State-respondents.
Learned standing counsel has raised objection and submitted
that this petition is not maintainable as it is filed for execution
of judgment and decree dated 27.05.1988 passed in Original
Suit No. 292 of 1984 for which, there is separate provision in
Code of Civil Procedure, 1908.
Learned counsel for petitioner could not dispute the aforesaid
facts, but submitted that he may be given liberty to file
execution proceeding before the Competent Court, for which
learned standing counsel has no objection.
Accordingly, writ petition is dismissed with liberty to the
petitioner to file execution case, if so advised.
