# High Court of Madhya Pradesh, MCC/1744/2015, 2015-07-13

MCC-1744-2015
(M/S KHARE MINIRALS Vs THE STATE OF MADHYA PRADESH)
13-07-2015
Shri D. K. Khare, learned counsel for the applicant.
Shri Pushpendra Yadav, learned Govt.Adv. for the respondents.
This application has been filed for restoration of W.P.No.8691/2015, which was
dismissed for want of prosecution on 19.6.2015. The application is supported by
affidavit of the counsel himself. Finding the same to be bonafide, the application
is allowed. W.P. No.8691/2015 is restored to its original file. It be placed for
orders before an appropriate Bench.
Application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
(SUSHIL KUMAR GUPTA)
JUDGE
