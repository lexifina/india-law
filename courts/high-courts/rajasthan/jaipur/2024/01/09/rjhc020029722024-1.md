Order
09/01/2024
1. Defects pointed out by the Registry are waived.
2. Applicant has moved this application seeking
correction/modification in the order dated 08.01.2024 in D.B.
Criminal Appeal No.347/2023 passed by this Court.
3. It is contended by counsel appearing for the applicant that in
the order dated 08.01.2024, in Para No.8, erroneously, “order
dated 06.07.2023” has been typed, whereas, it should be “order
dated 06.11.2023”.
4. In view of the above, Criminal Misc. Application is allowed.
5. In the order dated 08.01.2024, in Para No.8 “order dated
06.07.2023” be read as “order dated 06.11.2023”.
6. Order dated 08.01.2024 stands modified accordingly.

7. This order shall be treated as part and parcel of the order
dated 08.01.2024.
