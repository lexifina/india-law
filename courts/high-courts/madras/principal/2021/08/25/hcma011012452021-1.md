ORDER
 The petitioner has filed this writ petition for a Mandamus,
to direct the second respondent to reinstate the petitioner into
service as per statutory order passed by the first respondent
dated 08.03.2021.
2. The petitioner was terminated from the service of the
second respondent by an order dated 10.11.2020. Aggrieved by
https://hcservices.ecourts.gov.in/hcservices/

the same, the petitioner has filed a revision petition before
the first respondent under Section 153 of the Tamil Nadu Co-operative Societies Act, 1983. The first respondent by an order
dated 08.03.2021 has set aside the order of termination passed
by the second respondent vide order dated 10.11.2020.
3. After the aforesaid order was passed, the Deputy
Registrar (Vellore) has directed the second respondent to
reinstate the petitioner and implement the order of the first
respondent dated 08.03.2021. However, the order has not been
implemented till date. There is nothing to indicate that
further any proceedings has been initiated to put the order
dated 08.03.2021 to jeopardy.
4. Considering the same, the respondents are directed to
comply with the order of the first respondent within a period of
fifteen days from today.
5. This Writ Petition stands allowed with the above
observations. No costs. Consequently, connected Writ
Miscellaneous Petition is closed.
