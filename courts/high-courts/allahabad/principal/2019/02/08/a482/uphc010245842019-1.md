# Allahabad High Court, A482/4740/2019, 2019-02-08

Court No. - 73
Case :- APPLICATION U/S 482 No. - 4740 of 2019
Applicant :- Smt. Reema
Opposite Party :- State Of U.P. And 5 Ors
Counsel for Applicant :- Mohd. Aslam
Counsel for Opposite Party :- G.A.
Hon'ble Neeraj Tiwari,J.
Learned AGA has raised preliminary objection that against the
order impugned, there is statutory remedy of filing revision
under sections 397/401 I.P.C., which has not be disputed by
learned counsel for the applicant.
Accordingly, the application is dismissed on the ground of
alternative remedy with liberty to the applicant to file revision,
if so advised.
Office is directed to return the certified copy of the order of
court below to the counsel for the applicant after keeping the
photocopy of the same on record.
Order Date :- 8.2.2019
Arvind
