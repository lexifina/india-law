Order
14/08/2026
Learned counsel appearing for the petitioner submits that the
order in respect of which this contempt petition has been filed, i.e.

[2026:RJ-JP:32359] (2 of 2) [CCP-840/2026]
order dated 07.03.2026, passed in S.B. CWP No. 3502/2024, the
same has been recalled vide order dated 08.07.2026, and
therefore the cause of action for this contempt petition no more
survives.
In view of the submissions made by learned counsel for the
petitioner, this contempt petition is dismissed.
However, it is made clear that in case the subsequent order
dated 08.07.2026, whereby the earlier order dated 07.03.2026
has been recalled, is either recalled or set aside, the petitioner
would be at liberty to make an application for revival of this
contempt petition.
