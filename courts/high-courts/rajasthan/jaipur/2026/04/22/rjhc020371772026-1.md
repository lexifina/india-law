Order
22/04/2026
1. This is an application filed by the accused-petitioner seeking
correction/modification in the order dated 06.04.2026 passed by
this Court.
2. Learned counsel for the petitioner submits that the present
application has been filed for correction in the order dated
06.04.2026, wherein the FIR number has been erroneously
mentioned as 61/2025-26 instead of 06/2025-26.
3. Heard learned counsel for the parties and perused the case
file.
4. As per the record, the correct FIR number is 06/2025-26.
Accordingly, wherever FIR No. 61/2025-26 has been mentioned in
the order dated 06.04.2026, the same shall be read as FIR No.
06/2025-26.
5. The application stands disposed of accordingly.
