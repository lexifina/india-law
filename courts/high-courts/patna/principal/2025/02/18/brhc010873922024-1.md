CORAM: HONOURABLE MR. JUSTICE RAJESH KUMAR VERMA
ORAL ORDER
3 18-02-2025 Heard learned counsel for the petitioner and learned
counsel for the respondents.
Learned counsel for the petitioner has filed a mentioning
slip stating therein that during pendency of this writ application
subsequent development and additional cause of action have created
a situation to file a fresh writ application after the withdrawal of
present writ application.
In view of the aforesaid, learned counsel for the petitioner
seeks permission to withdraw this writ application with liberty to file
a fresh writ application.
Permission is accorded.
Accordingly, this writ application stands dismissed as
withdrawn with aforesaid liberty.
