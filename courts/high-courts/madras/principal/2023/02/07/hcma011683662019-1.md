# Madras High Court, A/613/2023, 2023-02-07

A.No.613 of 2023
in
C.S.No.224 of 2018
SENTHILKUMAR RAMAMOORTHY, J
By order dated 03.01.2023, the application to condone the delay
in filing the application to set aside the ex parte decree was allowed on
condition that the applicant pays a sum of Rs.15,000/- as costs. The said
order was complied with. This application is consequential thereto.
2. Upon examining the affidavit in support of this application and
being satisfied that sufficient cause is shown, this application is allowed as
prayed for and the ex parte decree dated 19.11.2018 is set aside.
