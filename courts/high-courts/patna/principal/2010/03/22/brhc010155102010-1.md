# Patna High Court, CR. MISC./7531/2010, 2010-03-22

IN THE HIGH COURT OF JUDICATURE AT PATNA
 Cr.Misc. No.7531 of 2010
 SRI LAL DEV SINGH
 Versus
 STATE OF BIHAR
 -----------
2. 22. 03. 2010. Heard Mrs. Shashi Priya Pathak, learned
counsel for the petitioner and Mr. Ram Priya Sharan Singh,
learned Additional Public Prosecutor for the State.
From the impugned order passed by the learned
Sessions Judge, Darbhanga, it appears that petitioner has
already been granted anticipatory bail with certain conditions.
In that view of the matter, the present
anticipatory bail application is not maintainable. Accordingly,
this application is dismissed.
Learned counsel for the petitioner submits that
certain conditions put in the impugned order are very harsh,
which requires some modification.
In that view of the matter, if so advised,
petitioner may approach learned Sessions Judge, Darbhanga,
seeking clarification/modification in the impugned order, by
which prayer for anticipatory bail of the petitioner has been
allowed.
With the aforesaid observations, this application
stands dismissed.
 m.p. (Birendra Prasad Verma,J.)
