Order
13/05/2024
1. Instant criminal miscellaneous application has been filed by
petitioner-applicant, seeking correction in the order dated
22.04.2024 passed in SB Criminal Miscellaneous (Petition)
No.2132/2024 by this Court, wherein in Para No.3 of the order,
reference of date of dishonour cheque has been mentioned as
“20.09.2014” instead of “25.02.2020”.
2. Heard learned counsel for petitioner-applicant.
3. It appears that in Para No.3 of the order dated 22.04.2024,
reference of date of dishonour cheque has been mentioned as
“20.09.2014” while in fact it should be “25.02.2020”, which error
occurred inadvertently.

[2024:RJ-JP:22530] (2 of 2) [CRLMA-219/2024]
4. In view of above, in Para No.3 of the order dated
22.04.2024, date of dishonour cheque as mentioned “20.09.2014”
be corrected in red ink as “25.02.2020” and the correction made
in the original order be upload online showing asterisk (*) mark in
the order that date of dishonour cheque has been corrected
subsequently. Rest part of the order shall remain unchanged.
5. Accordingly, the misc. application stands disposed of.
(SUDESH BANSAL),J
