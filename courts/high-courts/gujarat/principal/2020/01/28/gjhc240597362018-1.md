ORAL ORDER
1. Learned advocate for the applicant is absent even in the
second call. By way of the present application, the applicant has
prayed for the following relief:-
“7(b). This Hon’ble Court may be pleased to quash and set
aside the FIR being I-C.R.04 of 2018 registered with CID
Crime, Ahmedabad Zone, Ahmedabad and consequent
proceedings thereon.”
2. Learned APP upon instructions states that the chargesheet
is filed on 19.09.2019.
3. Having heard submissions made at bar and considering the
averments made in the present application, no case is made out
to entertain the present application without availing alternate
remedy to file discharge application. Therefore, the present
application is not entertained at this stage. However, the
applicant is at liberty to file discharge application and also to file
appropriate proceedings either u/s 397 or 482 of the Code of
Criminal Procedure, 1973 before appropriate competent Court,
after remedy to file discharge application is availed.
