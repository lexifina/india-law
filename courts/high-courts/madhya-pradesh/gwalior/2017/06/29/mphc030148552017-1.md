# High Court of Madhya Pradesh, MCRC/6806/2017, 2017-06-29

MCRC-6806-2017
(MONU BAGHEL Vs THE STATE OF MADHYA PRADESH)
29-06-2017
Shri AK Jain, counsel for the applicant.
Dr.(Smt.) Anjali Gyanani, Public Prosecutor for the State- respondent.
Learned counsel for the applicant submits that the applicant has filed this
second application of the same crime whereas the first application is
