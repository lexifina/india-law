# Section 4. Reference to Lushai Hills District to be construed as reference to Mizo District

4. Reference to Lushai Hills District to be construed as reference to Mizo District.—Any reference to the Lushai Hills District in any law, instrument or other document shall, unless the context otherwise requires, be construed as a reference to the Mizo District.
