# High Court of Madhya Pradesh, MCRC/976/2017, 2017-02-01

MCRC-976-2017
(VISHRAM SEN Vs THE STATE OF MADHYA PRADESH)
01-02-2017
Ms. Gayatri Ladiya, counsel for the applicant.
Shri Akshay Namdeo, P.L. for the State.
The present application has been filed for restoration of M.Cr.C.
No.17351/2016, which was dismissed on 6.1.2017 for want of
prosecution.
For the reasons mentioned in the application, which is supported by an
affidavit of Maneesh Soni, the present application is allowed.
M.Cr.C. No.17351/2016 is restored to its original number.
Let a copy of this order be kept in the file of M.Cr.C. No.17351/2016
(SMT. ANJULI PALO)
JUDGE
