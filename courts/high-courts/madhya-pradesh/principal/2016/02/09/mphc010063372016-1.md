# High Court of Madhya Pradesh, MCRC/2182/2016, 2016-02-09

MCRC-2182-2016
(SMT. MUNNI BAI Vs THE STATE OF MADHYA PRADESH)
09-02-2016
Shri K.B. Singh, learned counsel for the applicant.
Shri R.N. Yadav, learned PL for respondent -State.
This application has been filed for typographical error in
the M.Cr.C. No. 19250 of 2015, vide order dated 21.1.2016.
It is submitted by the applicant's counsel that in the
aforesaid application the name of the applicant has been
mentioned as Smt. Munni Bai Widow of Late Shri Jagdish
Yadav. However, the correct name of husband of the applicant
is Shri Dwarika Yadav.
In this view of the matter, this application is allowed and
correct description of the applicant be read as Smt. Munni
Bai, wife of Shri Dwarika Yadav in place of Smt. Munni Bai,
Widow of Late Shri Jagdish Yadav.
C c as per rules.
(S.K. GANGELE)
