RAM CHAND GUPTA, J.(Oral)
The present petition has been filed by the petitioner under
Section 482 of the Code of Criminal Procedure for quashing of FIR
No.73 dated 10.05.2006 under Sections 323, 324 148 read with Section
149 of Indian Penal Code (Section 326 IPC added vide order dated
10.03.2011 passed by Co-ordinate Bench of this Court) registered at
Police Station Goraya, District Jalandhar alongwith all consequential
proceedings taken on the basis of FIR.
It has been stated by learned counsel for the State that the
main case has since been decided by the trial Court.
Hence, it has been stated by learned counsel for the
petitioner that he does not want to proceed further with this petition.
Dismissed as withdrawn as rendered infructuous.
( RAM CHAND GUPTA )
