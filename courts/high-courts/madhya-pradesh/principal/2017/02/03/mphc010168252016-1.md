# High Court of Madhya Pradesh, MCRC/5541/2016, 2017-02-03

MCRC-5541-2016
(RAM LUBHAYA JAIRATH Vs THE STATE OF MADHYA PRADESH)
03-02-2017
Dr. Anuwad Shrivastava, learned counsel for the applicant.
Shri R.N. Yadav, learned PL for respondent No.1/State.
Shri Sanjay Sharma, learned counsel for the respondent No.2.
Learned counsel for the respondent No.2 submits that this
application is not maintainable because Criminal Appeal
No.733/2002 is still pending in which the bail order was
passed on 10.6.2002 in favour of the respondent No.2.
Learned counsel for the applicant wants to withdraw this
application due to the objection raised by the learned counsel
for the respondent No.2 with a liberty to file an appropriate
application in Criminal Appeal No.733/2002.
The prayer is allowed.
This application is dismissed as withdrawn with the liberty as
prayed for by the applicant.
C.C. as per rules.
(SMT. ANJULI PALO)
