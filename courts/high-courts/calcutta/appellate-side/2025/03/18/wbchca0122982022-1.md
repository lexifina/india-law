1. None appears for the parties on call. No
accommodation has been sought for.
2. It appears that the petitioner is not willing to proceed
with this revisional application further which is
pending since 2022.
3. Accordingly, the revisional application stands
dismissed for default.
4. Interim order, if any, stands vacated and connected
application, if any, also stands disposed of
accordingly.
5. Department is directed to intimate the order to the
learned Trial Judge for information.
6. All parties shall act on the server copy of this order
duly downloaded from the official website of this
Court.
