ORDER
The above application is filed for interim injunction restraining the
respondents from in any manner preventing the petitioners from using
the plaint 'B' schedule property for the purpose of assessing 'A' schedule
property and by maintaining the drainage lines passing under the 'B'
schedule property.
2. Only notice was issued in the year 2012. As there seems to
be no necessity for granting an interim order in this application, the
application is closed for the present with liberty to the applicants to file a
similar application, if need arises.
