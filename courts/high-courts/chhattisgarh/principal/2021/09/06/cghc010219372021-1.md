Heard
1. Learned counsel for the petitioner would submit that an order under
Section 250 of the C.G. Land Revenue Code was passed in favour
of the petitioner on 25.03.2008 whereby the respondent No.4 was
ordered to be ejected from the land bearing Khasra No.742/2
admeasuring 0.30 acre. After that the execution was filed but it was
dismissed without any reason only by holding that the execution
application is belated. Learned counsel submits that the execution
of an order which has not been set aside cannot be said to be
belated and there was no exorbitant delay. Subsequently, the
application has been filed by the petitioner in the year 2016 again

to execute the earlier order dated 25.03.2008, which is still pending
before the Tahsildar, which would be evident from the order sheet
dated 20.07.2021.
2. Considering the fact that the earlier order exits in favour of the
petitioner dated 25.03.2008 wherein the ejectment order was
passed in favour of the petitioner, the same has not been carried
out and one execution is still pending. Presently, the order sheet
shows that the execution is pending, the last date was on
20.07.2021. Considering the same, it is directed that the Tahsildar
Dabhara, District Janjgir-Champa shall conclude the proceeding of
execution within 60 days from the date of knowledge of this order.
3. With the aforesaid observation, the petition stands disposed off.
