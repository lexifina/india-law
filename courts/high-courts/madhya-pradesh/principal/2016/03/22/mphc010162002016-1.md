# High Court of Madhya Pradesh, MCRC/5312/2016, 2016-03-22

MCRC-5312-2016
(RAMCHARAN AHIRWAR Vs THE STATE OF MADHYA PRADESH)
22-03-2016
Shri B.J. Chaursaiya, learned counsel for the applicant.
Shri S.S. Chauhan, Dy. Government Advocate for the respondent/State.
Heard.
This is an application for amendment in the application filed on behalf
of applicant Ramcharan Ahirwar for grant of bail under Section 439 of
the Cr.P.C.
Learned counsel for the applicant submits that due to mistake, the
name of applicant's father is mentioned as Kalloo in the application
whereas applicant's father name is Jhalloo.
Looking to the grounds mentioned in the application, the same is
allowed.
It is directed that in place of Kalloo, applicant's father name be read as
Jhalloo.
M.Cr.C. stands disposed of.
Let a copy of this order be retained in the file of M.Cr.C.No.4487/2016.
(S.K. SETH)
JUDGE
