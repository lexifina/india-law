Order
09/05/2019
Appellant-applicant Smt. Gulab Kanwar has filed this
application praying for correction in the order dated 26.07.2018 of
this court.
It is stated in the application that this court passed the order
as per the arrangement and settlement between the parties and
also interfered and set aside the order under challenge, whereas,
as per the arrangement and settlement between the parties, the
order challenged was not to be interfered and set aside rather the
appeal was to be disposed of. It is submitted that both the parties

(2 of 2) [CMAP-105/2019]
are living separately as per the divorce decree passed by the
Judge, Family Court. Therefore, prayer is made that in para 3 of
the order dated 26.07.2018 the words “and accordingly, the order
challenged herein is interfered and are set aside.” be deleted.
For stated reasons, the application is allowed. The words in
para 3 of the order, i.e., “and accordingly, the order challenged
herein is interfered and are set aside.” are deleted.
(NARENDRA SINGH DHADDHA),J (MOHAMMAD RAFIQ),J
