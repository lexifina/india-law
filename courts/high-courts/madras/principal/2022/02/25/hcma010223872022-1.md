This Application has been filed by the second respondent to set
aside the ex-parte order dated 24.01.2022 passed in O.P.No.485 of 2016,
setting the applicant/second respondent as exparte.
2. Reasons stated in the accompanying affidavit are being
satisfied. This application is allowed and the order passed by this Court on
24.01.2022 setting the applicant/second respondent ex-parte, is set aside.
3. Now, the applicant/second respondent is directed to file his
written statement in O.P.No.485 of 2016 on or before 14.03.2022.
4. List the matter on 15.03.2022 for compliance, failing which,
the order passed by this Court stands dismissed automatically without
further reference to this Court.
