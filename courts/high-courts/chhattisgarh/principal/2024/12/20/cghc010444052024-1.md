1. Heard.
2. Learned counsel for the petitioner submits that petitioner has filed
application in pursuance of advertisement issued by respondent No.2. He
further submits that petitioner has also filed application /representation for
age relaxation on 28.2.2024 (Annexure-P/7), despite that, the same has
not been decided yet.
3. In reply, learned counsel appearing for the respondent No.2 would submit
that application /representation filed by petitioner has already been
decided on 21.3.2024 and the same has been rejected.

2
4. On this, learned counsel for the petitioner would submit that copy of the
aforesaid order has not been served to the petitioner.
5. On above contention, learned counsel appearing for respondent No.2
would submit that he will supply the copy of that decision to the petitioner,
within a week.
6. In view of above contention, learned counsel for the petitioner seeks
permission of this Court to withdraw this writ petition with liberty to file
fresh petition, if occasion arises.
7. Prayer is allowed. The petitioner is permitted to withdraw this writ petition
with liberty, as sought for.
8. Accordingly, this writ petition is dismissed as withdrawn with aforesaid
liberty.
9. Pending application(s), if any, stands disposed of.
