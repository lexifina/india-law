# High Court of Madhya Pradesh, WP/5204/2014, 2017-01-03

WP-5204-2014
(MILIND KUMAR MAGDEVE Vs THE STATE OF MADHYA PRADESH)
03-01-2017
Shri Jai Shukla, learned counsel for the petitioner.
Shri P.N. Dubey, learned counsel for the intervenor.
Shri Manoj Kushwaha, learned Panel Lawyer for the
respondents/State.
The petitioner has filed the present petition challenging the
transfer order dated 21.03.2014 by which the petitioner has been
transferred from District Umaria to District Bhind on
administrative exigency. The aforesaid transfer order is stayed by
this Court vide order dated 04.04.2014.
In view of aforesaid, the impugned order dated 21.03.2014
is hereby set aside. However, the respondent is at liberty to pass a
fresh order, if need so arises.
Accordingly, the petition stands disposed of.
(MISS VANDANA KASREKAR)
JUDGE
