# High Court of Orissa, ABLAPL/14767/2020, 2021-02-11

03. 11.02.2021 As pandemic situation for COVID-19 is
continuing, this case is taken up through Video
Conferencing mode.
 Heard learned counsel for the parties.
 As the earlier anticipatory bail application has
been disposed of, subsequent to which the gravity of offence
has been changed in the cognizance order of the learned
Magistrate, the petition for anticipatory bail is not an
appropriate petition. The petitioner, if so advised, may file
appropriate application before the appropriate forum.
 With the aforesaid observation, the ABLAPL is
disposed of.
 Authenticated copy of this Order downloaded
from the website of this Court in the manner prescribed
in this Court’s Notice No.4587, dated 25.03.2020 shall
be treated at par with the certified copy of this Order.
 Balaram ……………………….
 C.R. Dash, J.
