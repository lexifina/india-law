# Allahabad High Court, WRIC/13/2018, 2018-01-04

Court No. - 29
Case :- WRIT - C No. - 13 of 2018
Petitioner :- Deepak Kumar
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Om Prakash Mishra
Counsel for Respondent :- C.S.C.
Hon'ble Tarun Agarwala,J.
Hon'ble Saumitra Dayal Singh,J.
Having heard learned counsel for the petitioner,
we are of the opinion that if an ex-parte order has
been passed by the Consumer Forum, the remedy
available to the petitioner is to file a recall
application or file an appeal before State
Consumer Forum.
Accordingly, the writ petition is dismissed.
If such an application for recall or an appeal is
filed by the petitioner within four weeks, the
same shall be entertained without going into the
question of limitation.
Order Date :- 4.1.2018
A. Singh
(Saumitra Dayal Singh, J.) (Tarun Agarwala, J.)
