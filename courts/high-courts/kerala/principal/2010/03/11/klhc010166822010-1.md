ORDER
This petition is filed under section 482 of
the Code of Criminal Procedure for a direction
to Judicial First Class Magistrate's Court,
Payyannur to accept and number Annexure AII
petition for return of the records and to pass
orders in Annexure AVII petition to return some
other records and to set aside Annexure AIX
order dismissing a petition filed under section
173(8) of Code of Criminal Procedure in
C.C.554/2001. Learned Public Prosecutor
submitted that learned Magistrate has
subsequently acquitted the accused in
C.C.554/2001 on 27.2.2010. In such
circumstances, the petition is dismissed as
infructuous.
