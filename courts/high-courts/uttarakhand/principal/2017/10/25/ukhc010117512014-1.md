# High Court of Uttarakhand, CRLA/147/2014, 2017-10-25

MCRC No.271 of 2017
In
CRLA No.147 of 2014
Honíble Lok Pal Singh, J.

Ms. Razia Sultan, Advocate holding
brief of Mr. Abhishek Verma, Advocate for
the appellant.
This is restoration application MCRC
No.271 of 2017 moved by the appellant to
restore the appeal and to recall the order
dated 27.07.2017 by which the appeal has
been dismissed in non-prosecution.
On the previous occasion, time was
granted to the learned counsel for the
appellant to file supplementary affidavit.
On 20.09.2017, as a last opportunity,
further two weeksí time was granted to the
counsel to file supplementary affidavit, but
instead of filing the same, learned counsel
appearing for the appellant again seeks
time to file the supplementary affidavit.
This Court further finds that leave
was granted by this Court vide order dated
21.08.2014. Thereafter, this appeal was
listed a number of times, but it got
adjourned on the request of appellantís
counsel. Not only this, after filing of the
restoration application also, this appeal
was got adjourned several times on the
request of appellantís counsel.
In the light of aforesaid, the Court
does not find any reason to allow the
application. Restoration application is
accordingly dismissed.

 (Lok Pal Singh, J.)
 25.10.2017
