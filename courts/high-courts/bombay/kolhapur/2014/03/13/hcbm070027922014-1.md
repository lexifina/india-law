Petitioners, we are not satisfied that there is adequate explanation for
delay in filing this Petition. This Petition has been filed on 21.01.2014
for challenging the order dated 02.07.2011. However, the learned
Counsel appearing for the Petitioner seeks time to file an additional
affidavit to explain the delay. Only by way of indulgence, we grant three
weeks' time to file an additional affidavit. If additional affidavit is not
filed within the stipulated time, the Petition shall stand dismissed for non-
