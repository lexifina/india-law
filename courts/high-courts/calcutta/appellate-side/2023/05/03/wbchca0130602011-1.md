# Calcutta High Court, CRA/158/2011, 2023-05-03

03.05.2023
Court No.35
Item No. 98
D.Hira
CRA 158 of 2011
Samser Ali Mondal
Vs.
The State of West Bengal & Ors.
None appears on behalf of either of the parties. This matter is
pending in the list since 17.04.2023 and has been called on each day of
working of this Court since that date. In spite of that no one is
appearing. The petitioner is found to be not interest in this case.
Therefore, the same is taken up today for disposal on merit.
It appears that the appellant was given liberty vide this Court’s
order dated 04.05.2011 to file proper application for condonation of
delay. The same has not yet been preferred by the appellant. Since this
appeal is pertaining to the year 2011 and pending for considerable long
period of time. It is found proper that the same has taken up for
disposal as it is.
The appeal is dismissed being barred by limitation.
All pending applications, if any, are consequently disposed of.
 Certified website copies of this order, if applied for, be supplied to
the parties subject to compliance with all the requisite formalities.
 (Rai Chattopadhyay, J.)
