2. 16.11.2009 Heard learned Counsel for the petitioner and the learned
Counsel for the State as also the learned Counsel for the State
Advisory Committee.
 Learned Counsel fairly acknowledges that the petitioner is
not a state cadre employee but a regional cadre employee.
 The matter relates to a claim for allocation of cadre to
Bihar from Jharkhand consequent to the reorganization of the
State. It is only the State Cadre level employees who are
amenable to such consideration.
 In reply to the last submission of the petitioner learned
Counsel for the State Advisory Committee fairly submits that any
request for mutual transfer is an entirely different issue to be
considered according to the guidelines.
 This Court finds no error calling for interference in this
writ application. It is dismissed.
