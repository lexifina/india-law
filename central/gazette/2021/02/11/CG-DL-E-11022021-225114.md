# There is a mistake in village name in Paonta Saheb District Sirmaur, State Himachal Pradesh

MINISTRY OF ROAD TRANSPORT AND HIGHWAYS NOTIFICATION New Delhi, the 11th February, 2021 S.O. 647(E).—There is a mistake in village name in Paonta Saheb (District Sirmaur, StateHimachal Pradesh). The village name should be Upsampada Shamsherpur instead of Shamsherpur.

There is a mistake in village name in Paonta Saheb (District Sirmaur, State-Himachal Pradesh).
