% 22.07.2016
1. The writ petitioner had on the same cause of action filed a petition
before the Madras High Court which was withdrawn unconditionally.
2. Unless the petitioner obtains liberty from the Madras High Court to
file a fresh petition on the same cause of action the second petition on the
same cause of action will not be maintainable.
3. Conceding so learned counsel for the petitioner seeks leave to
withdraw the writ petition with it being observed that if the Madras High
Court grants liberty to the petitioner to file a fresh petition on the same cause
of action, annexing said order the petitioner would be entitled to file a fresh
petition.
4. Needless to state instant writ petition is being withdrawn because as
of today there is no liberty granted by the Madras High Court enabling the

petitioner to file a fresh petition on the same cause of action. If such liberty
is granted the petitioner would be entitled to the benefit thereof.
5. The petition is dismissed as withdrawn observing as above.
6. No costs.
