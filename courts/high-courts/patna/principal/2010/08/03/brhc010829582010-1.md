02. 03.08.2010 After some argument learned counsel for the petitioner has
chosen to withdraw this writ application with liberty to the petitioner
to file second show cause reply in response to the office order bearing
No.1194 dated 27.4.2010, Annexure-15 highlighting the submission
made in the writ application that the aforesaid notice is a composite
notice giving the reasons for difference as also proposing punishment,
which is not permissible in law. Petitioner should file show cause
reply before the authorities of the Bihar State Electricity Board within
four weeks from today, which should be considered by the authorities
before passing the final order as early as possible, in any case within
three months from the date of receipt of the second show cause reply
of the petitioner.
With the liberty aforesaid, the writ application is permitted
to be withdrawn.
Rajesh/
(V.N. Sinha, J.)
