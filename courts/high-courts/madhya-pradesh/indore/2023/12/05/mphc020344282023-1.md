This appeal coming on for admission this day, Justice Sushrut Arvind
Dharmadhikari passed the following:
ORDER
Heard on I.A. No. 17300/2023, which is an application for the change in
counsel has been directly filed by one Smt. Shivkanya w/o Shivraman.
At this stage, Smt. Shivkanya is personally present before this Court and
makes a prayer to withdraw this application i.e., I.A. No. 17300/2023.
In view of the aforesaid, the application is permitted to be withdrawn.
Accordingly, the same is dismissed as withdrawn.
Also heard on I.A. No. 17299/2023, which is an application for
withdrawal of CRA No. 13538/2023 has been filed.
In the application there are some allegations leveled against the learned
counsel appearing for the appellant.
The appellant is present in person before this Court and submit that they
want to withdraw the appeal as well as the allegations leveled against the learned
counsel.
For the reasons stated in the application, the same is hereby allowed.
Accordingly, this appeal is dismissed as withdrawn.
The note-sheet with signatures of parties identified by learned counsel is
attached with original records separately.
