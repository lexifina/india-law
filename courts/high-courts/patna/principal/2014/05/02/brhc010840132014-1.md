ORAL ORDER
2 02-05-2014 After some argument, the learned senior counsel,
Mr. A.B.Ojha appearing on behalf of the petitioner seeks
permission to withdraw this writ application with liberty to file
application before the court below for marking the documents, he
has filed or may be filed as exhibits which are admitted documents
in the court below.
Accordingly, in view of the submission of the
learned senior counsel, this writ application is permitted to
withdrawn with liberty to the petitioner to file appropriate
application before the court below praying for the aforesaid relief
and if such application is filed, the same may be disposed of
according to law by the trial court.
With this observation, this writ application is
permitted to be withdrawn. Therefore, this writ application is
dismissed as withdrawn.
Saurabh/- (Mungeshwar Sahoo, J)
