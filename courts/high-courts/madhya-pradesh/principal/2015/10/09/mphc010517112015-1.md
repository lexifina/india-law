# High Court of Madhya Pradesh, MCRC/17799/2015, 2015-10-09

MCRC-17799-2015
(SACHIN Vs THE STATE OF MADHYA PRADESH)
09-10-2015
Shri Nishant Datt, learned counsel for the applicant.
Shri R. N. Yadav, learned P. L. for respondent/ State.
Heard.
This application has been filed for correction of
typographical error in the order dated 5.10.2015.
It is submitted that in the order dated 5.10.2015 case
number is mentioned as M. Cr. C. No.15661/2015, however
correct number is M. Cr. C. 15574/2015. Similarly, the name of
the accused is mentioned Banati @ Devendra Choudhary,
however, correct name is Sachin.
After verification of the record, the contention of the
applicant is found correct. Hence, application is allowed and in
the order dated 5.2.2015 where the case number is mentioned as
M. Cr. C. No.15661/2015, it be read as M. Cr. C. 15574/2015.
Similarly, where the name of the accused is mentioned Banati @
Devendra Choudhary, it be read as is Sachin S/o Shri Krishnan
K. Shashidharan.
Petition is disposed of accordingly.
C. C. as per rules.
(S.K. GANGELE)
