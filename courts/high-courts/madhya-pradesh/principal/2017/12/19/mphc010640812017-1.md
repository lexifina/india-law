# High Court of Madhya Pradesh, MCRC/27314/2017, 2017-12-19

M.Cr.C.No.27314/2017
Jabalpur :
19.12.2017
 Shri Siddharth Datt, learned counsel for the applicant.
Shri V.S. Mishra, learned Dy. Govt. Advocate for the
respondent-State.
Heard.
This is an application for modification of the bail
order dated 4.12.2017, passed in M.Cr.C.No.24946/2017.
Learned counsel for the applicant submits that in the
order passed by this Court dated 4.12.2017 in
M.Cr.C.No.24946/2017, name of applicant has wrongly
been mentioned as Tammi @ Harishankar Tiwari, whereas,
the correct one is “Raj Bahadur @ Rajju Pandey”.
Considering the aforesaid, this application is allowed.
Let name of applicant mentioned in the order dated
4.12.2017 passed in M.Cr.C.No.24946/2017 be read as
Raj Bahadur @ Rajju Pandey in place of Tammi @
Harishankar Tiwari. This order shall be read conjointly
with the order dated 4.12.2017.
Let a copy of this order be kept in the record of
M.Cr.C.No.24946/2017.
Certified copy today.
 (H.P. Singh)
 JUDGE
