# Allahabad High Court, A482/7891/2023, 2023-03-02

Court No. - 67
Case :- APPLICATION U/S 482 No. - 7891 of 2023
Applicant :- Arjun
Opposite Party :- State of U.P. and Another
Counsel for Applicant :- Ashish Goyal
Counsel for Opposite Party :- G.A.
Hon'ble Rahul Chaturvedi,J.
Heard Shri Ashish Goyal, learned counsel for the applicant as
well as learned A.G.A. and perused the record.
The present 482 application is targeted against the discharge
application dated 27-06-2022. Since it is a final order and in the
Code of Criminal Procedure the revision is only maintainable
and thus this application under Section 482 Cr.P.C. is not
maintainable.
The application is accordingly dismissed. If so advised, he may
file a revision before the appropriate Court.
Order Date :- 2.3.2023
