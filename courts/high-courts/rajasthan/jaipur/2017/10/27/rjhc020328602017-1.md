D.B. Civil Misc. Application No.895/2017 :
For the reasons mentioned in the application, delay in
filing the appeal is condoned. The application is allowed.
D.B. Civil Special Appeal (Writ) No.1622/2017
1. Having heard learned counsel for the appellant, we find
no case to grant relief to the appellant for the reason as per the
website of this Court after the appellant accessed the site and
filled up the online application form he had to press the icon
“Make Payment” thereafter he has to wait for the application ID
number (usually called token number) to be generated. The
appellant did not ensure that when he logged in the site the
application ID number was generated.

(2 of 2)
[SAW-1622/2017]
2. After the advertisement inviting application was issued
a corrigendum was also issued by this Court on 22.4.2017
informing all the online applicants to ensure that a token number
was generated online. The appellant did not ensure that a token
number was generated online.
3. What had happened is that the E-Mitra site through
which the appellant applied showed application fee being deducted
from the appellant’s account but it was not deposited in the
account of High Court and this resulted in application ID number
not being generated.
4. The writ appeal is dismissed.
