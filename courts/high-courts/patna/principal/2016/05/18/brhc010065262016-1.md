ORAL ORDER
2 18-05-2016 Heard learned counsel for the petitioner.
The prayer for bail has already been rejected by this
Court on 17.12.2015 passed in Criminal Miscellaneous No.55755
of 2015 on the ground that 108 kg. ganja was recovered from the
truck, which was being driven by the petitioner.
On the same set of fact again this bail application has
been filed. I, therefore, find no reason to allow the bail application.
Thus, this application for regular bail is rejected.
Harish/-
