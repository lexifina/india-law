3. 23.9.2011 Heard learned counsel for the petitioner and the State.
A show cause has been filed on behalf of the State stating
their that the order of this Court has been complied with by passing
the necessary order as per Memo No.1691 dated 23rd of January,
2010, as contained in Annexure 3 to the contempt application.
Learned counsel appearing for the State submits that the
order has already been complied with before filing of the contempt
application and, therefore, this contempt application should be
dismissed.
In this view of the matter, since the order of this Court has
been complied with, this contempt application need not proceed
further. The same is, accordingly, dismissed.
 PNM (Shailesh Kumar Sinha, J.)
