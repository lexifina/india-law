HON'BLE MR. JUSTICE PANKAJ BHANDARI
Order
08/08/2024
1. Petitioner has filed this review petition for correction in
the order dated 08.02.2022.
2. It is contended by counsel for the petitioner that in the
order dated 08.02.2022, there is a typographical error in Para
No.4 wherein, ‘tehsildar not to pass any mutation entries’ is
written, however, the same should be written as ‘tehsidar to not
make any correction/modification (तरमम) in revenue map.’
3. I have considered the contentions.
4. Considering the typographical mistake, I deem it proper
to modify the order dated 08.02.2022. Accordingly, in Para No.4,
in place of “tehsildar not to pass any mutation entries”, the same
be now read as “tehsidar to not make any correction/modification
(तरमम) in revenue map.”
5. Review petition is accordingly, disposed of.
(PANKAJ BHANDARI),J
