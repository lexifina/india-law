# High Court of Madhya Pradesh, MCC/325/2016, 2016-01-28

MCC-325-2016
(ASHOK KUMAR SHARMA Vs THE STATE OF MADHYA PRADESH)
28-01-2016
Shri R.P. Mishra, learned counsel for the petitioner.
This application has been filed for restoration of M.C.C.
No.3718/2015, which was dismissed for want of
prosecution on 07.01.2016.
Keeping in view the reasons given the application which
is supported by the affidavit of counsel himself and
finding the same to be bonafide, the application is
allowed.
The restoration application is allowed, M.C.C.
No.3718/2015 is restored to its original file. It be placed
for orders before an appropriate Bench.
Application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
(SUSHIL KUMAR PALO)
JUDGE
