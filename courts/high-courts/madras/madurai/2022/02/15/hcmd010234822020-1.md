ORDER
This petition has been filed seeking for a direction to the
resppondents to file the final report in Crime No.170 of 2008 on the
file of first respondent within the time stipulated as fixed this
Court.
2.Heard the learned counsel appearing for the petitioner and
the learned Additional Public Prosecutor appearing for the
respondents.
3.The learned Additional Public Prosecutor would submit that
FIR in Crime No.170 of 2008 on the file of the first respondent has
been transferred to the file of the Inspector of Poice, District
Crime Branch, Tirunelveli and it is pending for investigation.
4.In the circumstances, the second respondent is directed to
complete the investigation and file a final report before the
concerned Magistrate within a period of four weeks from the date of
receipt of a copy of this order.
