This Writ Petition is filed under Articles 226 and 227
of the Constitution of India praying to set aside the
impugned order dated 03.01.2019 in O.S.No.80/2000
passed by the Principal Civil Judge and JMFC at Lingasugur
produced at Annexure-A.

3
This petition coming on for Preliminary Hearing in ‘B’
Group, this day, the Court made the following:-
ORDER
This writ petition is filed challenging the Order dated
03.01.2019 passed by the Principal Civil Judge and JMFC,
Lingasugur, in O.S.No.80/2000 returning the plaint filed on
the ground of want of pecuniary jurisdiction which power is
referable to Order VII Rule 10 of the Code of Civil
Procedure.
2. It is noticed that against an Order passed under
Order VII Rule 10 of the Code of Civil Procedure, an appeal
under Order XLIII Rule 1(a) of the Code of Civil Procedure
is provided. Thus, this writ petition is not maintainable.
3. Without considering the contentions urged by the
petitioner, this writ petition is dismissed as not
maintainable reserving liberty to the petitioner to file an
appeal, if so advised.

4
If the appeal is filed, the time consumed in
prosecuting this writ petition would be set off.
