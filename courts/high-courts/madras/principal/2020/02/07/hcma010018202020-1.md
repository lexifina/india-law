This petition has been filed to direct the respondent
police to file a final report before the Learned Judicial
Magistrate – II, Attur, Salem District in so far relates to
Cr.No.185 of 2014.
2. Heard the learned counsel appearing for the
petitioner and the learned Additional Public Prosecutor
appearing for the respondent.
3. The learned Additional Public Prosecutor has
submitted that already investigation has been completed and
charge sheet also filed on 03.02.2020 vide E-Filing No.203 of
2020 before the Judicial Magistrate -II, Attur, Salem District,
but so far, the said case was not taken on file.
https://hcservices.ecourts.gov.in/hcservices/

4. Recording the abovesaid submissions, this Criminal
Original Petition is closed. The learned Judicial Magistrate,
Attur, Salem District, is directed to verify if any such charge
sheet is filed and if it is in order, it should be taken on file
without any further delay.
