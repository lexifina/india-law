ORDER
23.03.2023
Heard the learned counsel for the applicant.
This is an application filed for correction of typographical error which crept
in the order dated 20.03.2023 passed in CRP(IO)/76/2023.
The learned counsel for the applicant submits that the sentence written as
“in the written statement and objection filed under Order 39 Rule 1 and 2”

Page No.# 7/7
ought to have been written as “in the written statement and vacating
application filed under Order 39 Rule 4”.
Perused the pleading and petition. Prayer is allowed.
Accordingly, the sentence as aforesaid in the order dated 20.03.2023 passed
in CRP(IO)/76/2023, is corrected as “in the written statement and vacating
application filed under Order 39 Rule 4”, in place of “in the written statement
and objection filed under Order 39 Rule 1 and 2”.
I.A. stands disposed of.
This order be made as a part of the order dated 20.03.2023 passed in
CRP(IO)/76/2023.
 JUDGE
