 ORAL ORDER
2. 05.11.2014 Learned counsel for the petitioner submits that
though he has filed an application for bail before the Sessions
Judge, Sitamarhi but the same has not been disposed off as
yet and that is why he was compelled to file the present
petition. However, after some argument, he seeks permission
to withdraw the application to file an appropriate petition
before the Sessions Court, Sitamarhi for hearing of the bail
application which has already been filed in Sessions Trial No.
337 of 2012 arising out of Sitamarhi P.S. Case No. 265 of
2001.
In view of the aforesaid, the application stands
disposed off as withdrawn with the liberty aforesaid. It is
expected that the Court below shall pass appropriate order on
the bail application already filed by the petitioner before it
expeditiously.
