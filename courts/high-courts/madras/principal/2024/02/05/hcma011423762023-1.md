# Madras High Court, OA/899/2023, 2024-02-05

O.A.No.899 of 2023
in
C.S.(Comm. Div.)No.247 of 2023
ABDUL QUDDHOSE.J.,
Pleadings are complete in O.A.No.899 of 2023. Learned counsel for
the respondent / defendant is ready. However, the learned counsel applicant /
plaintiff seeks for an adjournment once again. There is no interim order
granted by this Court in this application. The learned counsel for the plaintiff
must always be ready to argue the interlocutory application, that too when
no interim order has been granted in favour of the plaintiff till date.
2. Since the learned counsel for the plaintiff is seeking adjournment
and being a commercial suit, this Court is of the considered view that no
useful purpose will be served if this application is allowed to be kept
pending. Instead the parties can go for trial. Learned counsel for the plaintiff
has not raised any serious objection if this Court directs both the parties to
go for trial instead of this Court deciding this interim application.
