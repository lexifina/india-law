 05/22.02.2019. Heard, learned counsel for the petitioner and learned counsel for
the State.
At the very outset learned counsel for the State has submitted that
process under Section 82 Cr. P.C. has already been issued against the
petitioner vide order dated 16.12.2018 as such, this application is not
maintainable.
Learned counsel for the petitioner seeks permission to withdraw this
application so as to enable the petitioner to pray for grant of regular bail.
Learned counsel for the State has no objection in this regard.
Considering such submission, this application is dismissed, as withdrawn.
