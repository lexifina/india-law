HON'BLE MR. JUSTICE SANJEEV PRAKASH SHARMA
 Order
05/07/2017
 Instant Misc application has been filed by the applicants-respondents seeking modification/correction in the order dated
21.2.2017 passed by this Court in S.B.Civil Writ Petition
No.4383/1999.
It is stated that due to some typographical error in para 8 of
order dated 21.2.2017. The order dated 21.9.1996 has been typed
instead of order dated 30.9.1993 passed by the Disciplinary
Authority. After perusal of the order dated 21.2.2017, this court
finds that vide order dated 21.9.1996 the petitioner was
discharged in criminal case vide order dated 30.9.1993. The
petitioner was dismissed from service by the Appellate Authority
and as a matter of fact, instead of order dated 21.9.1996 the
order dated 30.9.1993 should have been typed in the order dated

(2 of 2)
[WMAP-314/2017]
21.2.2017.
Consequently, the Misc. Application stands allowed.
It is therefore ordered that at para No.8 of the order dated
21.2.2017 passed by this Court instead of order dated 21.9.1996,
the order dated 30.9.1993 shall be read as having set aside. The
rest part of the order dated 21.2. 2017 shall remain the same.
(SANJEEV PRAKASH SHARMA)J.
