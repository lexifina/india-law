# High Court of Madhya Pradesh, MCRC/8942/2016, 2016-10-26

MCRC-8942-2016
(SUBHAM Vs THE STATE OF MADHYA PRADESH)
26-10-2016
Ms. Archana Kher, learned counsel for the applicant.
Shri R.S.Parmar, learned counsel for the respondent/State.
Counsel for the respondent has filed a report from the
concerning police station in which it is mentioned that the CD
in question shall not be used during trial, however, if need
arises, then it would be used.
Implying that in any case the CD will be used in the trial and in
such premises under Section 207 Cr.P.C., it is mandatory for
the prosecution to provide copy of the CD to the accused. The
reasons stated by both the Courts below are not convincing.
There is no exception to the provisions of Section 207 Cr.P.C.
and in this premises, this application is allowed.
Accordingly, the order of both the Courts below are set aside.
The trial Court is directed to supply copy of the CD to the
accused person on an undertaking given by him that contents
of the CD will be used only for the purpose of the trial and will
not be made public by uploading them through any electronic
device.
With directions as aforesaid, this matter stands disposed of.
C.C.as per rules.
(ALOK VERMA)
JUDGE
