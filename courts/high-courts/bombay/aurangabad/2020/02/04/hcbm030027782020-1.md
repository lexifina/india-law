PER COURT:-
1. Mr. Chavan, learned counsel for the
petitioner submits that on technical ground the
application of the petitioner is rejected. The
petitioner had signed on his photograph. The
petitioner has also signed the declaration of small
family. Only below the undertaking, the petitioner
inadvertently did not sign. On such technical
ground the application ought not to have been
rejected. The notice was also issued that, if
anybody has objection with regard to the
eligibility / ineligibility of the candidate, the
same can be raised. The petitioner had raised an
objection that his candidature was erroneously
rejected. The same has not been considered.

2. Mr. Navandar, learned counsel submits that
signing the agreement was an essential term and
conditions. The petitioner failed to sign the
application itself.
3. We have considered the submissions
canvassed by the learned counsel for the respective
parties.
4. It is stated by respondents on affidavit
that 13 posts of Senior Research Assistant were
advertised. 1151 applications were received. 980
applications were held to be valid. Others were
rejected.

6. Clause as reproduced supra specifically
requires the application to be signed, failing
which the application would not be considered. The
petitioner had not signed on the application. The
last part of the application was declaration on
oath that the contents of the application are true
and correct. The petitioner did not sign the same.
The application of the petitioner was unsigned.

7. When there are large number of
applications, the scrutiny would be strict. There
are many candidates whose applications are rejected
on such ground.
8. In light of the above, as the petitioner
had not signed the application itself, the case of
the petitioner cannot be considered.
9. Writ Petition as such is disposed of. No
costs.
