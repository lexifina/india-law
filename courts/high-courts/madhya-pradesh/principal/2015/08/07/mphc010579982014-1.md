# High Court of Madhya Pradesh, MCC/2806/2014, 2015-08-07

MCC-2806-2014
(THE STATE OF MADHYA PRADESH Vs M/S. SAFARI BIKES LIMITED)
07-08-2015
Ms. Vandana Shrivastava, learned Panel Lawyer for the
applicants/State.
This application has been filed for restoration of W.P.
No.7027/2014, which was dismissed on
account of peremptory order dated
25.08.2014. There being some delay in
filing the application for restoration I.A.
No.17339/14 has been filed seeking
condonation of delay. Both the
applications are supported by affidavit of
Smt Malti Mishra, and there is no reason
to disbelieve the same. Finding the same
to be bonafide, both the applications are
allowed.
Condoning the delay in filing the application,
restoration application itself is allowed.
W.P. No. 7027/2014 is restored to its original number. It
be placed for orders before appropriate
Bench.
Application stands allowed and disposed of.
(VANDANA KASREKAR)
JUDGE
