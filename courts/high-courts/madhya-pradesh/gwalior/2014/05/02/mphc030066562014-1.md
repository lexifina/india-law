# High Court of Madhya Pradesh, MCRC/2759/2014, 2014-05-02

M.Cr.C.No.2759/2014 (Sonu Singh Yadav Vs. State of M.P.) 1
2.5.2014.
None for the applicant.
Respondent/State by Shri Mukund Bharadwaj, Public
Prosecutor.
None is appearing on behalf of the applicant.
This application has been filed under section 439 of
Cr.P.C. It is submitted that this is first bail application under
Section 439 of Cr.P.C.
From the record it appears that earlier the application was
under section 439 of Cr.P.C. in connection with Crime
No.19/2013 was filed which has been registered as
M.Cr.C.No.6897/2013 and the same has been dismissed vide
order dated 21.10.2013. Thus, considering that first application
of the applicant has already been dismissed, this application
cannot be treated as first bail application, and therefore, this
application is also dismissed.
(D.K.Paliwal)
