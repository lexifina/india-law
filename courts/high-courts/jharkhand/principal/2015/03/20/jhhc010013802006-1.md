07/Dated: 10th October, 2014
 In the instant writ petition, petitioner has challenged the
order of removal from service dated 5.6.2005, from the order sheet it
appears that several adjournments have been permitted to the counsel for
the respondents but no counter-affidavit has been filed as yet.
 As a last chance, one more opportunity is being granted to
the respondents authority to file counter-affidavit. It is made clear that if
no counter-affidavit has been filed, the case will be decided on the next
date on the materials available on record.
 Counsel for the respondents is directed to file counter
affidavit within two weeks with a copy to the counsel for the petitioner
so that this petitioner may be able to file rejoinder, if any.
 Put up after two weeks.

 (Sujit Narayan Prasad, J.)
Nibha/Tarun
