# Calcutta High Court, CRR/795/2020, 2022-03-11

11.03. 2022
 item No.63.
 n.b.
 ct. no. 34
CRR 795 of 2020
Sandip Sarkar @ Bapi Sarkar & Anr.
Vs.
The State of West Bengal & Ors.
Mr. Anwar Hossain
Ms. Sujata Das
…..for the State
The present revisional application reflects that till date
none appears on behalf of the petitioners to present the case.
A report has been submitted by Ms. Sujata Das, learned
advocate for the State.
Report reflects that already charge-sheet has been
submitted in connection with this instant case, I find that there has
been a change of circumstance since the petitioners’ approached
before this Court. No interference is called for
Accordingly, CRR 795 of 2020 is dismissed.
All pending connected applications, if any, are
consequently disposed of.
Interim order, if any, is hereby vacated.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
 ( Tirthankar Ghosh, J.)
