Heard on application for modification in the order dated
03.12.2019 passed in WPS No. 10042 of 2019.
It is contended that in the order dated 03.12.2019 in WPS
No. 10042 of 2019 in para 2 the date of retirement of the petitioner
has been mentioned as 30.06.2019 whereas it should be
30.06.2016. Likewise in para 3, State has not specified any year in
the circular dated 11.06.2019, however, in the order the last line in
para 3 has been written as 30th June, 2018 which may be read as

Jyoti
30th June.
Accordingly, as has been mentioned in para 2, the date of
retirement shall be read as 30.06.2016 and in para 3 it should be
read as 30th June.
Accordingly, the MCC is disposed of.
