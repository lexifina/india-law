Order
03/03/2020
1. Petitioner has preferred this Criminal Writ Petition seeking
fair investigation.
2. Learned Public Prosecutor has submitted a report. As per
report, Police has already filed negative final report on
13.01.2020. Report submitted by learned Public Prosecutor is
taken on record.
3. In view of the same, Criminal Miscellaneous Petition is
accordingly disposed.
4. However, petitioner would be free to file protest petition, if so
advised.
