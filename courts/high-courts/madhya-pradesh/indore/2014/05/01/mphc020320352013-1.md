# High Court of Madhya Pradesh, MCRC/8787/2013, 2014-05-01

1
M.Cr.C. No.8787/2013
01/5/2014
Shri T.C. Jain, learned Counsel for the applicant.
Heard on I.A. No.260/2014, which is an application
for condonation of delay in filing this application. One day
delay has occasioned in filing the application for grant of
leave to file appeal.
For the reasons stated in the application, I.A.
No.260/2014 is allowed and the delay is hereby condoned.
Considering the application under Section 378(4), I
find that the appeal is arguable. Counsel has pointed out
that under identical matter the leave has already been
granted in M.Cr.C.No.8786/2013 on 10/3/2014.
In view of the above, this application is allowed and
leave is granted to file appeal.
Registry is directed to register it as Criminal Appeal
and list thereafter for admission.
Record of the lower Court be called.
With the aforesaid, this M.Cr.C. No.8786/2013 is
disposed of accordingly.
C.c. as per rules.
 (Mrs. S.R. Waghmare)
Judge
moni
