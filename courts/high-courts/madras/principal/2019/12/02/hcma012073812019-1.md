(crime No.440/2019) ... Respondent
PRAYER: Criminal Original Petition filed under Section 482
Cr.P.C, to direct the respondent to file a final report in
Crime No.440 of 2019 on the file of the respondent.
For Petitioner : Mr.M.G.Udayakumar
For Respondent : Mr.M.Mohamed Riyaz
 Additional Public Prosecutor
O R D E R
This Criminal Original Petition has been filed to direct
the respondent to file a final report in Crime No.440 of 2019
on the file of the respondent.
2.Heard the learned counsel appearing for the petitioner
and the learned Additional Public Prosecutor appearing for the
respondent.
3.The learned counsel appearing for the petitioner
submitted that though respondent has registered a case in the
above said crime number on 20.06.2019, no final report is
filed till date.
4.The learned Additional Public Prosecutor appearing for
the respondent submitted that the respondent police may be
permitted to file a final report as early as possible.
5.In view of the above, the respondent police is directed
to file a final report as early as possible.
https://hcservices.ecourts.gov.in/hcservices/

6.With the above direction, this Criminal Original
Petition is disposed of.
