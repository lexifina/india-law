ORAL ORDER
Learned advocate for the applicant seeks
permission to withdraw this application, at this stage.
Permission, as prayed for, is granted. The
application stands disposed of, as withdrawn. However,
liberty is reserved to the applicant to file a fresh
application under Section 482 of the Code of Criminal
Procedure, 1973 (‘the Code’ for short), if the charge-sheet is filed against the applicant and if there is no
material in the papers of the charge-sheet against him.
It is clarified that this Court has not examined the
merits of the case and, therefore, as and when the
applicant files an application under Section 438 of the
Code before the concerned Sessions Court, the said
application shall be decided on its own merits.
(VIPUL M. PANCHOLI, J.)
