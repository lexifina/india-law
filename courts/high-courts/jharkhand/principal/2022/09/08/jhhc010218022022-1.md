For the Petitioner : Mr. Tejo Mistry, Advocate
For the Respondents : A.C. to G.P. II
3/ 08.09.2022 Petitioner has challenged the order dated 30.06.2020, by which
the petitioner has been punished after a departmental proceeding.
2. Both the parties admitted that there is a provision of departmental
appeal. Counsel for the petitioner fairly submits that no appeal has been
preferred against the aforesaid order before the appellate authority. He seeks
leave of this Court to file an appeal before the appellate authority.
3. Leave, as sought for, is granted. This writ petition is disposed of
with a liberty to the petitioner to file an appeal before the appellate authority. If
any appeal is filed, the same will be disposed of within four weeks from the
date when the same is filed, in accordance with law on merits of the case.
4. With the aforesaid liberty and direction, this writ petition is
disposed of.
