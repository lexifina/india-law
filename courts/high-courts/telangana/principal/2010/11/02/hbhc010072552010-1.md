# High Court for the State of Telangana, WP/26000/2010, 2010-11-02

HON’BLE SRI JUSTICE S.V. BHATT
W.P.No.26000 OF 2001
ORDER:
On 27.08.2009, the writ petition was dismissed for default.
Through order dated 24.10.2011, the default order was set aside and
writ petition was restored to file.
There is no representation for petitioners on 06.02.2014 in the
forenoon and afternoon. Since it is an old matter, the same was
directed to be listed today. Even today, there is no representation for
the petitioners either in the forenoon or afternoon. This Court has no
option except to dismiss the writ petition for non-prosecution.
The writ petition is, accordingly, dismissed for non-prosecution.
There shall be no order as to costs.
Miscellaneous petitions, if any, pending in this writ petition shall
stand disposed of.

S.V. BHATT, J
