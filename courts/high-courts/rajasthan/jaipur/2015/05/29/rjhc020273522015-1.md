##
This application has been filed by the
petitioner for correction in the order dated
19.5.2015.
It is contended that in para no.3 of the order
aforesaid it has inadvertently been mentioned in
first line that ìin CW No.6014, petitioner appeared
in senior secondary examination, 2014. However, it
should be read as ìin CW No.6014/15, petitioner
appeared in secondary examination, 2014.
The order is corrected accordingly. The
application is allowed.
