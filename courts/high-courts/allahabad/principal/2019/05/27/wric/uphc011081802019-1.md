# Allahabad High Court, WRIC/18285/2019, 2019-05-27

Court No. - 39
Case :- WRIT - C No. - 18285 of 2019
Petitioner :- Devi Prasad
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Ram Prakash
Counsel for Respondent :- C.S.C.
Hon'ble B. Amit Sthalekar,J.
Hon'ble Piyush Agrawal,J.
Heard Sri Ram Prakash Pandey, learned counsel for the
petitioner and the learned Standing Counsel for the respondents.
The petitioner in the writ petition is seeking quashing of the
demolition order dated 18.04.2019 regarding constructions
made on Araji No.1662, House No.135-C, Panki, Gangaganj,
Kanpur Nagar.
We find that State of U.P. has been arrayed in the writ petition
through Chairman, Kanpur Development Authority, Kanpur
Nagar which is not permissible. The petitioner has also
mentioned that there is no counsel for the Kanpur Development
Authority which is also not correct.
This writ petition is therefore dismissed with liberty to the
petitioner to file fresh writ petition impleading the proper
parties and serving the copy of the writ petition on the counsel
for the Kanpur Development Authority.
Order Date :- 27.5.2019
N Tiwari
