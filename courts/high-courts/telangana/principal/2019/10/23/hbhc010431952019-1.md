# High Court for the State of Telangana, WP/23147/2019, 2019-10-23

HONíBLE SRI JUSTICE ABHINAND KUMAR SHAVILI

ORDER

permission to withdraw the writ petition with liberty to the
petitioner to file a writ petition afresh.

dismissed as withdrawn giving liberty to the petitioner to file a
writ petition afresh. No costs.

closed.
