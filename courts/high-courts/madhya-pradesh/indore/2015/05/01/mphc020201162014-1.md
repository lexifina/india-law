# High Court of Madhya Pradesh, WP/6051/2014, 2015-05-01

1
W.P. No.6051/2014
1.5.2015
Ms. Nidhi Bohra, learned counsel for the petitioner.
Shri Mukesh Parwal, learned counsel for the State has
raised an objection that the petitioner has no personal
grievance against the impugned order and the writ petition is of
public nature.
Counsel for the petitioner seeks permission to withdraw
the writ petition with liberty to file the fresh appropriate petition,
if the need so arises.
Writ petition is accordingly dismissed as withdrawn with
the liberty, as prayed.
C.C. as per rules.
