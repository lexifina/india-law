THE HON'BLE MR. JUSTICE BIRAJA PRASANNA SATAPATHY
ORDER
17.05.2024
Order No.3
 1. This matter is taken up through hybrid mode.
2. Heard learned counsel appearing for the parties.
3. Learned counsel for the petitioner contended that
similar benefit though has been extended in number of
cases, but order passed in the present case is yet to be
implemented.
4. Learned Addl. Govt. Advocate appearing for the
State-Opp. Parties while not disputing the extension of
benefit while complying similar order, contended that the
order in question will be implemented positively by
31.07.2024.
5. Considering the submissions so made, this Court
while disposing the CONTC directs the Opp. Parties-contemnors to comply with the order in question by
31.07.2024.

 If the order in question will not be complied with
by 31.07.2024, then suo motu contempt will be initiated
against the Opp. Parties/contemnors.
6. Accordingly, the CONTC is disposed of.
