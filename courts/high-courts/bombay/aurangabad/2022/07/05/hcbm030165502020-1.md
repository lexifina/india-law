PER COURT:
1. Learned Counsel for the Applicant seeks
liberty to withdraw this Application to explore
alternate efficacious remedy of preferring an
Application for discharge if and when charge-sheet
is filed.
2. Considering this request, the Application
is allowed to be withdrawn with liberty to the
Applicant to prefer an Application for discharge
before the Trial Court if and when charge-sheet is
filed. If such an Application is preferred, it
shall be decided on its own merits in accordance
with law.
3. Criminal Application stands disposed of.
