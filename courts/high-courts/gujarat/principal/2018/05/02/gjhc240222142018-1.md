ORAL ORDER
It is brought to the notice of this Court, parties
have amicably settled the disputes. The application
under Section 482 of the Code of Criminal Procedure being
Criminal Misc. Application No. 6108/2018 for quashing and
set aside of FIR/order was filed. On 22.3.2018 the
application was accepted and FIR in question had been
quashed and set aside.
In view of the above, this application does not
survive. This application is accordingly disposed of.
Rule is hereby discharged.
Xerox copy of the order is produced on record.
(A.J.DESAI, J)
