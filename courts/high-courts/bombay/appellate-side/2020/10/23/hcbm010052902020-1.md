P.C. :
1. A praecipe is moved for withdrawal of this application.
The learned counsel appearing for the applicant states that, some
other advocate has filed similar application for the same relief
before this court and it is still pending. Learned counsel for the
applicant, therefore, seeks withdrawal of this application, so that,
there should not be duplicity of the application. The request
appears to be reasonable.
2. The application is allowed to be withdrawn and is
disposed of as such.
