# Gauhati High Court, WP(C)/5857/2011, 2011-11-23

WP(C) 5857/2011
BEFORE
HON’BLE MR JUSTICE A. K. GOSWAMI
Mr MH Choudhury, learned counsel for the petitioner, submits that some inadverte
nt mistakes have crept in while drafting the writ petition.
In that view of the matter, learned counsel for the petitioner, prays fo
r withdrawal of the writ petition with the liberty to file afresh, to which Mr I
