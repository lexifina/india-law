ORDER
When the matter came up for hearing today(07.06.2024), none
appears for the appellant. Learned counsel for the respondent is present.
It is seen that this Second Appeal was dismissed for non-prosecution on
13.12.2021 and restored to file on 29.03.2022, thereafter listed before
this Court. Inspite of repeated adjournments, there is no representation
for the appellant. Therefore, no purpose is going to be served in keeping
this Second Appeal, pending.
2. Accordingly, this Second Appeal is dismissed. Consequently,
connected miscellaneous petition stands closed. No costs.
