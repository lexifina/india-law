1. By order dated 15th September, 2017 the applicant in each of the Civil
Applications were permitted to withdraw 50% of the amount deposited by the
petitioner on submitting an undertaking that the same would be repaid to the
petitioner, if petitioners succeeds in the petition.

2. Today, it is stated that the undertaking could not be filed within time.
Learned Counsel for the respondents seek extension of time to file the undertaking.
He points out that the matter was mentioned on 19th December, 2017. However, on
that date the order dated 15th September, 2017 was not available as a result the
matter came to be adjourned to date.
3. None appears for the petitioner today. I see no harm in granting an
extension of time to file the undertaking as contemplated in order dated
15th September, 2017. Accordingly, extension of one week granted to file the
undertaking.
4. Stand over to 16
