# High Court of Uttarakhand, SPA/156/2006, 2008-06-18

SPA No.156/06
Honíble Prafulla C.Pant, J.
Honíble Dharam Veer, J.
(Delay Condonation Appln. No.3554/08)
(Review Appln. No.647/08)
 Sri Sudhir Kumar, learned brief holder for the State and Sri Dinesh
Gahtori, learned counsel for the applicant/respondents.
 There is only 3 days in delay in filing the review application which is
sufficiently been explained in the affidavit filed along with delay
condonation application. Hence, the Delay condonation application is
allowed. The delay in filing the review application is condoned.
 This is review application No.647/2008 moved by the applicant for
review of the judgment and order dated 5.5.2008 passed by this Court in
SPA No.156/2006 (with SPA Nos.166/06, 167/06 and 169/06).
 Having heard learned counsel for the parties, we do not find any
error apparent on the face of record which requires interference in the
judgment sought to be reviewed.
 The review application is rejected.
(D.V., J.) (P.C.P., J.)
18.06.2008
Rajeev Dang
