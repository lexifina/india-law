# High Court of Orissa, WP(C)/14744/2016, 2019-04-16

13. 16.04.2019 On 20.11.2018, the following order was passed:
 “Learned counsel for the petitioner
requests for two weeks time to file
rejoinder.
 The matter to come up on 11.12.2018.”
 On 15.01.2019, the following order was passed:
 “Learned counsel for the petitioner is
not present.
 Earlier on several occasions, none
appears on behalf of the petitioner and
learned counsel for the petitioner has
taken several adjournments.
 In the interest of justice, as a last
chance, the matter to come up on
05.02.2019.”
 Again on 26.02.2019, the following order was
passed:
 “In view of the rejoinder, learned counsel
for the State requests for time.
 This matter to come up on 19.03.2019.”
 Even today also none appears for the petitioner.
 Accordingly, the writ petition stands dismissed for
default.
