 ORDER
The Respondent in D.V.C.No.14 of 2023, on the file of the learned
Judicial Magistrate No.1, Kulithalai, has filed the present revision petition,
challenging the order of the trial Court wherein the application filed by the
petitioner to set aside the ex-parte order has been returned as not maintainable.

2.The respondent herein has filed the above said D.V.C.No.14 of 2023,
for various reliefs. The petitioner/husband herein was set aside ex-parte on
09.08.2024. The ex-parte orders were passed in D.V.C.No.14 of 2023 on
23.08.2024. The present application in C.M.P.SR.No.5313 of 2024 has been
filed on 11.12.2024 to set aside the ex-parte order, dated 09.08.2024. This
application has been returned by the Court on the ground that the application to
set aside the ex-parte order is maintainable only till the main petition is pending.
Since the main petition had already been disposed of on 23.08.2024, the Court
has proceeded to return the said application. Challenging the same, the present
revision petition has been filed.
3.The dates and events captured above will clearly indicate that the
petitioner/husband has filed an application to set aside the ex-parte order, dated
09.08.2024, after the main petition has been disposed of on 23.08.2024.
Therefore, this Court does not find any error in the order passed by the learned
Judicial Magistrate No.I, Kulithalai. Accordingly, this Revision Petition stands
disposed of with liberty to the revision petitioner to seek an order to set aside
the order dated 23.08.2024, if he is so advised.

closed.
