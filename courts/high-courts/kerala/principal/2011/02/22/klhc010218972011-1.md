 O R D E R
The appeal filed by the petitioners as A.S.No.405 of 2008,
District Court, Thrissur was dismissed for default. The petitioners
filed an application under Order XLI Rule 19 of the Code of Civil
Procedure for re-admission of the appeal. That application was
dismissed as per the order impugned in this Revision.
2. Rule 1(t) of Order XLIII of the Code of Civil Procedure
provides for an appeal against an order of refusal under Rule 19 of
Order XLI of the Code of Civil Procedure to re-admit an appeal.
Since the order impugned is appealable, no revision lies.
Accordingly, the Civil Revision Petition is dismissed as not
maintainable.
Dismissal of this Civil Revision Petition will not be a bar for the
petitioners to file an appeal. Registry will return the certified copy
