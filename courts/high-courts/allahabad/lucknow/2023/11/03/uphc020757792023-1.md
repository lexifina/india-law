# Allahabad High Court, /9653/2023, 2023-11-03

Neutral Citation No. - 2023:AHC-LKO:72429-DB
Court No. - 3
Case :- WRIT - C No. - 9653 of 2023
Petitioner :- Ashwani Kumar Sharma And Others
Respondent :- State Of U.P. Thru. Addl. Chief Secy. Revenue Civil Secrt. Lko. And Others
Counsel for Petitioner :- Satish Kumar Sharma
Counsel for Respondent :- C.S.C.
Hon'ble Vivek Chaudhary,J.
Hon'ble Manish Kumar,J.
1. Heard learned counsel for petitioners and learned Standing Counsel for State.
2. Petitioners have approached this Court claiming that their application for
demarcation is pending which not being decided as yet.
3. Learned Standing Counsel states that application of petitioners is not as per
rules and petitioners need to file fresh application as per rules which will be
considered and decided expeditiously.
4. Petitioners are permitted to file fresh application for demarcation as per rules,
fulfilling all the requirements before the respondent no.3 Sub Divisional
Magistrate, Tehsil Sadar, Hardoi within two weeks from today along with a
certified copy of this order.
5. In case such an application is filed by petitioners, respondent no.3 shall
consider and decide the same in accordance with law, by a reasoned and
speaking order within a period of three months from the date the application
along with certified copy of this order is placed before him.
6. With the aforesaid, the writ petition is disposed of.
Order Date :- 3.11.2023
