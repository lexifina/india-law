# High Court for the State of Telangana, TRCRLP/168/2018, 2018-12-18

HON’BLE Dr. JUSTICE B. SIVA SANKARA RAO
TRANSFER CRIMINAL PETITION No.168 of 2018
ORDER :
Heard both sides and perused the entire material on record.
2. From the consensus arrived by both sides, C.C.No.412 of 2014 on
the file of the learned Additional Judicial First Class Magistrate,
Kalwakurthy, is withdrawn and transferred to I Additional Judicial First
Class Magistrate, Mahabubnagar. Both parties are directed to appear
before the I Additional Judicial First Class Magistrate, Mahabubnagar,
without fail on 07.01.2019. The learned Judicial First Class Magistrate,
Kalwakurthy, immediately cause transfer the case for taken on file for
giving new calendar case number by learned I Additional Judicial First
Class Magistrate, Mahabubnagar.
3. Accordingly, the transfer criminal petition is disposed of.
 Miscellaneous petitions pending, if any, shall stand closed.
____________________________
Dr. B. SIVA SANKARA RAO, J
19th December 2018.
