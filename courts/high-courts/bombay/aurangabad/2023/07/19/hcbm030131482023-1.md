CORAM : S. G. MEHARE, J.
DATE : 19.07.2023
 PER COURT :-

1. None present for the applicant.
2. Learned APP would submit that after the last order of
rejection of bail dated 18.10.2022, the applicant did not
approach the Sessions Court, but directly approached this
Court. The procedure cannot be given go by. The applicant
ought to have applied before the Sessions Court for bail, if any,
after rejection of the earlier bail application by this Court.
3. Hence, the present bail application stands dismissed.
4. The applicant is at liberty to file a fresh bail application
before the Sessions Court, if he desires.
