# High Court of Orissa, WP(C)/7784/2004, 2019-12-05

10. 05.12.2019 Learned counsel for the petitioner seeks
permission to withdraw the writ petition with liberty to file
fresh application if any cause of action still survives. A
memo filed to that effect is taken on record.
 Granting such liberty, the writ petition stands
dismissed as withdrawn.
 All connected Misc. Case(s)/I.A(s), if any, is/are
accordingly dismissed.
