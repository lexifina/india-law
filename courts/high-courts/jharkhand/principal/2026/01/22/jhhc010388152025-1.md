02 /22.01.2026: Heard learned counsel representing the petitioner and
learned counsel representing the respondents.
2. The only grievance of the petitioner is that the petitioner
was allowed to work as In-charge Principal but now the petitioner
has been removed.
3. From the order which is impugned, that is removal of the
petitioner as In-charge Principal, I find that there is no allegation
leveled against the petitioner by the respondents. Thus, the order is
not stigmatic.
4. There is no substantive post as “In-charge Principal”. It is
merely an interim arrangement over which the petitioner has no

substantive right. To be an “In-charge” is not a substantive right.
5. When no substantive right is created which can be said to
have been infringed, I am not inclined to interfere with the
impugned order dated 08.08.2025.
6. Thus, this writ petition is dismissed.
