# Allahabad High Court, WRIC/20694/2019, 2019-06-26

Court No. - 35
Case :- WRIT - C No. - 20694 of 2019
Petitioner :- Rajendra Singh
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Ram Sanehi Yadav
Counsel for Respondent :- C.S.C.,Manoj Nigam
Hon'ble Rohit Ranjan Agarwal,J.
Heard Sri Ram Sanehi Yadav, learned Counsel for the petitioner
and learned Standing Counsel for the respondents.
After some length of arguments, Sri Ram Sanehi Yadav, learned
Counsel for the petitioner seeks leave of the Court to withdraw
the petition with liberty to file modification application.
In view of the above, writ petition is dismissed as withdrawn
with liberty to the petitioner to file a modification application.
Order Date :- 26.6.2019
S. Singh
