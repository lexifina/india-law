O R D E R
This Civil Revision Petition filed against the order returning
the petitioner's suit filed under Order 33 Rule 1 of C.P.C.
2. Mr. Abrar Mohamed Abdullah, learned counsel
appearing for petitioner submitted that, the suit has been filed
under Order 33 Rule 3 of C.P.C. to sue as an indigent person.
The suit has has been returned to comply with as many as 7
defects, which are extracted hereunder :
“1. Separate paper O.P. Petition to be filed.
2. Vakalath to be filed.
3. Necessary documents regarding 'B', 'C' schedule
property
4. District Collector to be added as a party.
5. Proof affidavit, duplicate plaint to be filed.
6. Para 17, 18 is incorrect.
7. Batta memo to be filed.
So far as first return is concerned, he has complied with. So far
as second return regarding filing of vakalat is concerned, the

ordered, the question of valuation can be considered. So far as
seventh return is concerned, the petitioner has to pay the batta,
the learned counsel submitted that, the petitioner is ready to
comply the same.
3. I have considered the arguments made by the learned
counsel appearing for petitioner and perused the relevant rules
as well as records.
