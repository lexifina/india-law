 ORDER
The petitioner filed this revision to set aside the return
order passed in unumnered MCOP.No.... of 2021, on the file of the
Motor Accidents Claims Tribunal (Additional District Court),
Virudhunagar.
2. Heard the learned counsel for the petitioners.
3. Since the order going to be passed will not cause any
prejudice to the rights of the respondent, no notice need be sent to
the respondent.
4. On perusal of the records it is seen that already the
matter was represented, again with the return order the Court

returned the petition stating that the petitioner has to file the
MCOP before the proper Court. The petitioner can file MCOP case
wherever the accident was occurred. Since the accident was
occurred at Madurai – Aruppukkottai Fourway track road, the MCOP is
very well within the jurisdiction of the Motor Accidents Claims
Tribunal (Additional District Court), Virudhunagar District and
also the petitioners are residing at Virudhunagar, the Motor
Accident Claims Tribunal (Additional District Court), Virudhunagar
is directed to number the MCOP if it is otherwise in order.
5. With the above direction, the Civil Revision Petition is
disposed of. No costs.
6. Registry is directed to return the original petitions
filed along with the revision petitions, after substituting the
xerox copy of the same.
