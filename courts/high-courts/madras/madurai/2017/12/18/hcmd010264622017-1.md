ORDER
This Criminal Original petition is filed for issuing a
direction to the respondent to file final report in Crime No.144
of 2017 pending investigation on the file of respondent police
within a time stipulated by this Court.
2.Heard the learned counsel appearing for the petitioner and
the learned Additional Public Prosecutor appearing for the
respondent.
3.Learned Additional Public Prosecutor on instructions
submitted that the enquiry is almost nearing completion and that
final report is likely to be filed within a reasonable time.
4. Considering the facts and circumstances of this case and
the statement made by the learned Additional Public Prosecutor,
this Court is inclined to pass the following direction:-
“The respondent police is directed to file final report

5.Accordingly, the Criminal Original petition is allowed.
