CORAM: HONOURABLE DR. JUSTICE ASHOKKUMAR C. JOSHI
Date : 07/07/2020
ORAL ORDER
Heard learned Advocate Mr. Hiren P. Kandera for the Applicant and
learned APP Mr. Chintan Dave for Respondent- State through video
conference.
The Applicant – Saibabibi Firjkhan Pathan has filed this Application
under Section 439 of the Code of Criminal Procedure for enlarging her on
regular bail in connection with the offences punishable under Sections 420, 406
and 114 of the Indian Penal Code fro which FIR being I-CR No. 71/2019 is
registered at Nadiad Town Police Station, District Kheda.
Learned Advocate for the Applicant seeks permission to withdraw the
present Application with liberty to file fresh application after some time.
Permission as prayed for is granted. The Application stands disposed of
as withdrawn with liberty to file fresh after some time.
Rule is discharged.
(DR. ASHOKKUMAR C. JOSHI,J)
SURESH SOLANKI / JNW / ZGS
