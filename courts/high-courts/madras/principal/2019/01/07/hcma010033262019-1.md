ORDER
This Criminal Original Petition has been filed to direct the
respondent to investigate the matter and file a final report
with connection of the FIR No.607 of 2018 on their file within a
stipulated time.
2. Heard the learned counsel appearing for the petitioner
and the learned Additional Public Prosecutor appearing for the
respondents.
3. The learned counsel appearing for the petitioner would
submit that though the second respondent has registered a case
in the above said crime number on 17.07.2018, no final report is
filed till date.
4. The learned Additional Public Prosecutor appearing for
the second respondent would submit that the second respondent
police may be permitted to file a final report as expeditiously
as possible.
https://hcservices.ecourts.gov.in/hcservices/

5. In view of the above, the second respondent police is
directed to either file a final report or closure report, as the
case may be, as expeditiously as possible, under due intimation
to the defacto complainant.
6. With the above direction, this Criminal Original
Petition is disposed of.
