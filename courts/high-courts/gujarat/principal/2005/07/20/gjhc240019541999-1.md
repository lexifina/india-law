ORAL JUDGMENT
1. Mr. D.V. Vaidya, learned advocate for Nanavaty Advocates, learned
advocate for the petitioners, seeks leave to withdraw this revision
application with a view to file substantive petition since this

CRA/1355/1999 2/2 JUDGMENT
revision application which is filed against an interlocutory order
is now not maintainable in view of the amendment made in Section
115 of the Code of Civil Procedure.
2. Ms. Archna Raval, learned AGP for respondent Nos.1 to 4 has no
objection if leave as prayed for is granted.
3. Hence, leave to withdraw the Civil Revision Application is granted.
The revision application stands disposed of as withdrawn with no
order as to costs. Rule is discharged. Interim relief granted
earlier stands vacated.
