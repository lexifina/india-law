JUDGE
For the reasons assigned therein, this petition too is disposed off for the
same reasoning therein as well as the same directions as stated therein.
The order dated 17.01.2023 passed by the M.P. Arbitration Tribunal,
Bhopal in Reference Petition No.33 of 2015 is partly set aside. The order
upholding the dismissal of the application for impleading, is upheld. The order
dismissing the application for amendment and filing additional documents is set
aside. Both the applications are allowed.
The parties to appear before the Arbitral Tribunal on 19.09.2023. At the
request of both counsels, the Tribunal shall dispose off the matter pending
before it within a period of three weeks from that date. Petitioner counsel
undertakes that he would not take any adjournment for any reason whatsoever.
Pending interlocutory application is disposed off.
