ORAL ORDER
2 08-04-2016 Heard learned counsel for the petitioner.
According to learned counsel for the petitioner since
the order dated 06.02.2015, whereby the injunction application has
been rejected, the order is appelable under Order 43 Rule 1
Clause-R C.P.C. Therefore, he seeks permission to withdraw this
application with liberty to file appeal before the appropriate
forum.
In view of the submission of the learned counsel for
the petitioner, this application is permitted to be withdrawn with
the aforesaid liberty. Thus, this writ application is dismissed as
withdrawn.
