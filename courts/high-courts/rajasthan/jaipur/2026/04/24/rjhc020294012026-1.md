1. The present writ miscellaneous application has been filed for
correcting a typographical error in the order dated 19.02.2026.
2. Both the parties are ad-idem that in Para No.(iii) of the order
dated 19.02.2026, instead of “learned Appellate Rent Tribunal,” it
should be read as “learned Rent Tribunal.”
3. For the reasons mentioned in the present writ miscellaneous
application, the same is allowed. In the order dated 19.02.2026,
in Para No.(iii), the correction is made to the effect that instead of
“learned Appellate Rent Tribunal,” it shall be read as “learned Rent
Tribunal.”
