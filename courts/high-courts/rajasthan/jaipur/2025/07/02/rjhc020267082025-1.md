Order
02/07/2025
1. Heard.
2. This PIL petition is not maintainable because on the same
issue, the petitioner himself had filed PIL which was disposed off on
04.12.2024. Second PIL on the same cause of action is not
maintainable. The petitioner, if aggrieved by order dated 04.12.2024,
should have availed appropriate remedy.

[2025:RJ-JP:24234-DB] (2 of 2) [CW-5631/2025]
3. This PIL petition is frivolous and the same is dismissed as not
maintainable with cost of Rs. 10,000/-. Remaining security amount
of Rs. 40,000/- be returned to the petitioner.
