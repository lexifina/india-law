JUDGMENT
An order allowing an application to set aside the sale under
Order XXI Rule 90 of the Code of Civil Procedure is impugned in
this Original Petition. The remedy if any of the petitioner is to
file an appeal under Order XLIII Rule 1(j) of the Code of Civil
Procedure.
The Original Petition is hence dismissed as not
maintainable without prejudice to the right of the petitioner to
file an appeal.
