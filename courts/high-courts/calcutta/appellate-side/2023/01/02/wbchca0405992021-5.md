 Ct.No.34
 dc.
 C.R.R. 2684 of 2021

 Sabita Kundu
 versus
 The State of West Bengal & Anr.
In Re: An Application under Section 482 of the Code of
Criminal Procedure, 1973.
Mr. Ayan Bhattacharjee,
Mr. Nirmalya Chatterjee … For the Petitioner.
Ms. Sreyashee Biswas … For the State.
Mr. Prantick Ghosh,
Mr. Siddhartha Sarkar … For the Opposite Party No.2.
Ms. Biswas, learned advocate appearing for the State
submits a further report dated 22.12.2022 in addition to the
earlier report dated 20.12.2022 wherein it was reflected that
charge-sheet dated 31.08.2021 was already filed before the
jurisdictional court. Let the report dated 22.12.2022 be kept
on record.
Mr. Bhattacharjee, learned advocate appearing for the
petitioner prays for liberty to withdraw the present revisional
application and file afresh.
Accordingly, the revisional application being CRR 2684
of 2021 is dismissed as not pressed.
All pending connected applications, if any, are
consequently disposed of.
The petitioner is granted liberty to file afresh as prayed
for.
