CORAM: HONOURABLE MR. JUSTICE AKHILESH CHANDRA
ORAL ORDER
2 01-08-2012 Heard.
This is an application seeking restoration of Cr. Misc. No.
29226/2011 dismissed for non-prosecution vide order dated 18.11.2011, in
connection with Paharpur P.S. Case No. 99/2007, pending in the court of
Judicial Magistrate, East Champaran at Motihari.
This Court does not find any merit in this application.
Accordingly, the same stands dismissed with a liberty to the petitioner, if so
wishes, to file fresh application, if mandatory requirements under Section 438
of the Code of Criminal Procedure are available.
