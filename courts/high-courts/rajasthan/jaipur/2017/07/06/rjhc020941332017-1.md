HON'BLE MRS. JUSTICE SABINA
Order
6/7/2017
Petitioners have filed this petition under Section 482
Code of Criminal Procedure, 1973 challenging the order dated
27.1.2017, whereby, application moved by the petitioners under
Section 70(2) Code of Criminal Procedure, 1973 was dismissed.
Heard.
Petitioners had jumped bail and was declared an
absconder on 23.10.2000. In these circumstances, trial court had
rightly dismissed the application moved by the petitioners under
Section 70(2) Code of Criminal Procedure, 1973.
No ground for interference is made out.
Dismissed.
 (SABINA)J.
