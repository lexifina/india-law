Order
12/05/2023
First bail application filed by the petitioner was
dismissed on merits by the Co-ordinate Bench of this Court vide
order dated 27.09.2021 in S. B. Criminal Miscellaneous Bail
Application No.11311/2021. The second bail application filed by
the petitioner was dismissed by this Court vide order dated
28.10.2021 in S. B. Criminal Miscellaneous 2nd Bail Application
No.17633/2021 on the ground that no new facts were brought on
record. Thereafter, the petitioner had filed 3rd bail application
before this court which was accordingly dismissed by this Court
vide order dated 17.12.2021 in S. B. Criminal Miscellaneous 3rd
Bail Application No.20697/2021. By the said order, no liberty was
granted to the petitioner to file a fresh bail application directly
before this Court.

(2 of 2) [CRLMB-14904/2022]
Instead of filing a fresh bail application before the trial
court, the petitioner has directly filed this 4th bail application
before this court, whereas he should have first approached the
trial court.
The 4th bail application filed by the petitioner is
disposed of accordingly.
(NARENDRA SINGH DHADDHA),J
