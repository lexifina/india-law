HON'BLE MR. JUSTICE PANKAJ BHANDARI
Order
20/12/2019
1. Matter comes up on application filed by the petitioner
seeking correction in the cause title.
2. It is contended that petitioner’s father name is Haburam in
the order dated 24.10.2019 passed by the Court below. It is
wrongly mentioned Baburam in the cause title of the bail
application and order dated 05.12.2019.
3. I have considered the contentions.
4. Typographical error needs to be corrected. Hence, in the
cause title of order dated 05.12.2019 father’s name of Lokesh
Kumar be now read as Haburam in place of Baburam.
5. Counsel for the petitioner is directed to file amended cause
title.
6. The application is accordingly allowed.
(PANKAJ BHANDARI),J
