# High Court of Madhya Pradesh, MCRC/12402/2015, 2015-07-27

MCRC-12402-2015
(RAHUL BANSAL @ VEER Vs THE STATE OF MADHYA PRADESH)
27-07-2015
Shri Amit Jain, Advocate for the applicant.
Ms. Hemlata Kshatriya, Panel Lawyer for the respondent-State.
Heard finally.
This application has been filed seeking modification of the order
dated 16.07.2015, passed by this Court in Misc. Criminal Case
No.10451/2015.
It is submitted by the learned counsel for the applicant that due to
typographical error the father's name of the applicant has
wrongly been mentioned as 'Shashi Bansal' in the title of bail
application whereas the correct name is 'Ramesh Bansal', as is
evident from the arrest/court surrender memo.
Keeping in view the aforesaid, this application is allowed. In the
order dated 16.07.2015, passed by this Court in Misc. Criminal
Case No.10451/2015 where the father's name of the applicant
'Shashi Bansal' is mentioned, it is hereby corrected and shall be
read as 'Ramesh Bansal'.
The order dated 16.07.2015, passed by this Court in Misc.
Criminal Case No.10451/2015 shall be read conjointly with this
order along with the aforesaid modification.
Cc as per rules.
(SUBHASH KAKADE)
JUDGE
