# Bombay High Court, APPLN/995/2009, 2009-03-02

IN THE HIGH COURT OF JUDICATURE AT BOMBAY
 CRIMINAL APPELLATE JURISDICTION
 CRIMINAL APPLICATION NO. 995 OF 2009
 Suresh Namdev Dedge Anr. ...Applicants
 vs.
 The State of Maharashtra ...Respondent
 Mr.M.S. Mohite for the Applicants.
 Mr.S.R. Shinde, APP for the State.
 CORAM : V.M. KANADE, J.
 DATED : MARCH 2, 2009
 P.C. :-
 1. This is an application for anticipatory bail.
 2. Counsel for the applicants seeks permission to
 withdraw this application with liberty to file an
 application before the appropriate court.
 3. The application is allowed to be withdrawn.
 Seven day’s time is given to the applicants to surrender
 before the Magistrate Court. The learned Magistrate
 shall decide the application for bail, expeditiously,
 taking into consideration the allegations which are made
 against the present applicants. The fact of withdrawal
 of the application for anticipatory bail shall not be
 construed in any other manner. The application be
 decided on merits.
 4. The application is disposed of.
