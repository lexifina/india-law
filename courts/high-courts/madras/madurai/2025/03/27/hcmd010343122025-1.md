O R D E R
 This writ petition has been filed for issuance of a writ of
mandamus, directing the first respondent to re-issue the petitioner's
passport vide Passport Application file No.MD1077301165125.
2.The petitioner has made an application in File No.
MD1077301165125, for issuance of passport. However, upon receiving
an adverse police verification report, the first respondent refused to issue
the passport. Hence, this Writ Petition has been filed by the petitioner.
3. The learned Government Advocate (criminal side)
appearing for the second respondent would submit that there are seven
criminal cases pending against the petitioner and he is a habitual
offender. Hence, the respondent police has strongly opposed for issuing
passport to the petitioner.
2/4
https://www.mhc.tn.gov.in/judis

4. Considering the notorious criminal antecedents of the
petitioner, this Court is not inclined to entertain this writ petition.
Accordingly, this writ petition is dismissed. No costs.
