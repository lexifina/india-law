# High Court of Madhya Pradesh, WP/11348/2012, 2012-08-06

W.P. No. 11348/2012
06.08.2012
 Shri Praveen Pandey, learned counsel for the
petitioner submits that vide order dated 27.2.2012 although
the Succession Certificate has been directed to be issued
to the petitioner but it has been directed that on submitting
a solvent surety of Rs. 18 lacs, the Succession Certificate
would be issued to the petitioner.
Learned counsel submits that he would like to
withdraw the petition and would like to assail the aforesaid
order dated 27.2.2012 passed by learned First Civil Judge,
Class I, District Jabalpur in Succession Case No. 26/2009
by filing an appeal to set aside that order.
This contention is accepted and this petition is
dismissed as withdrawn with liberty to raise this objection
before the Appellate Authority that such a condition cannot
be imposed.
With the aforesaid observations, this petition is
dismissed as withdrawn with the liberty as prayed.
Let certified copy of the impugned order dated 27.2.2012
be returned to learned counsel for the petitioner for filing an
appeal and a photocopy thereof be retained in the file.
This petition is dismissed as withdrawn with the
aforesaid liberty.
 (A.K. Shrivastava)
