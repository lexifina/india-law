 CORAM : URMILA JOSHI-PHALKE, J.
 DATED : 11/12/2024.
1. This is an application for seeking permission to
assist the prosecution.
2. The office note shows that learned counsel for the
intervenor has not filed an appropriate application for
seeking permission to assist the prosecution. It reveals
from the application that the intervenor is not the
complainant or the victim. The application nowhere
discloses regarding the locus to file this application.
3. In view of that, the applicant shall file the
appropriate application before this Court.
4. Present application is disposed of with liberty to file
the fresh application.
5. List the application after Christmas Vacation.
