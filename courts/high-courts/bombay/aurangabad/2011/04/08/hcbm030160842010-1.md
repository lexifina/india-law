PER COURT :
. This is an application seeking leave to file appeal. In fact,
the present applicant is an acquiring body. The acquiring body
was already before the Reference Court, but under wrong
nomenclature. In that light of the matter, no leave is required for
the applicant to file the appeal. It would be right of the applicant
to file an appeal. In view of that, the civil application is disposed
