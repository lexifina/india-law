# High Court of Orissa, WP(C)/19632/2012, 2019-01-15

7 15.01.2019 On 11.12.2018, the following order has been passed.
 “Learned counsel for the petitioner requests
for time.
 Accordingly, list this matter on
18.12.2018.
 Interim order, if any, shall continue till the
next date.”
 On 18.12.2018, the following order has been passed.
 “Learned counsel for the petitioner
requests for time.
 Accordingly, list this matter on
08.1.2019.”

 Again on 08.01.2019, the following order
has been passed.
 “None appers for the petitioner.
 List this matter on 15.01.2019.”
 Even today also none appears for the petitioner.
 Accordingly, this writ petition stands dismissed for
default with liberty to the petitioner to revive this petition
within thirty days from today, if cause of action still
survives.
