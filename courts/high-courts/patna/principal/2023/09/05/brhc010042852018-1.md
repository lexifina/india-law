CORAM: HONOURABLE MR. JUSTICE SANDEEP KUMAR
ORAL ORDER
3 05-09-2023 Heard the parties.
2. The present application has been filed for quashing
the order dated 18.08.2018 passed by Sub-Judge-II, Purnea by
which he has allowed the application of the defendants and held
that the correction in decree cannot be refused.
3. It has been submitted by learned counsel for the
petitioners that the impugned order should be set aside because
the corrections which the respondents wanted in a decree are
part of a civil suit filed by the respondents.
4. In my opinion, even some suit has been filed by the
respondents still there is some error in the decree the same can
be allowed to be corrected by the court below and the impugned
order has rightly been passed after correction, the respondents

Patna High Court C.Misc. No.1757 of 2018(3) dt.05-09-2023
3/3
have liberty to withdraw the suit.
5. With the aforesaid observation, this application is
dismissed.
