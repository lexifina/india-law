# Patna High Court, C.R./1413/2006, 2008-11-18

IN THE HIGH COURT OF JUDICATURE AT PATNA
 C.R. No.1413 of 2006
 SMT.REKHA DEVI
 Versus
 RAM SHANKER LAL & ORS
 -----------
 2. 18.11.2008 Heard counsel for the petitioner.
In the opinion of this Court when
an inter party order dated 21.12.1993 had
concluded the issue which was allowed become
final; the petitioner could not have
reopened the same before the court below.
That being so, this Court would not
find any error in the impugned order by
which the same prayer which was earlier
rejected by the court below pertaining to
the order under Order 1 Rule 10(2) C.P.C.
has been rejected. This application is
misconceived and is hereby dismissed.
 (Mihir Kumar Jha,J.)
Surendra/
