J U D G M E N T
Ext.P4 is under challenge. A money decree has been
passed, against which an appeal has been filed as A.S.27 of
2013. In the said appeal, IA 702/2013 was filed seeking the
stay of the execution proceedings. Even though it is a
money decree, it seems that the court below has passed
Ext.P4 order as against the statutory provisions contained
under Order XLI Rule 5(3)(c) of the Code of Civil Procedure,
1908. Ext.P4 order is illegal and is liable to be set aside.
In the result, this Original Petition is allowed. Ext.P4
order is set aside. The court below is directed to pass an
order in accordance with law, as contemplated under Order

O.P.(C) 1440 of 2015
-: 2 :-
XLI Rule 5(3)(c) of CPC by directing the appellants to
furnish security for the decree amount.
