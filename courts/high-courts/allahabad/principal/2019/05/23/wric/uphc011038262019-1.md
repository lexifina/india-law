# Allahabad High Court, WRIC/17608/2019, 2019-05-23

Court No. - 48
Case :- WRIT - C No. - 17608 of 2019
Petitioner :- Rohit Kumar
Respondent :- State Of U.P. And 5 Others
Counsel for Petitioner :- Onkar Nath
Counsel for Respondent :- C.S.C.
Hon'ble Siddharth,J.
Learned Standing Counsel has objected that the Pradhan cannot directly
file a writ petition without resolution from the Gram Panchayat concerned.
This writ petition is not maintainable. It is accordingly dismissed with
liberty to the petitioner to file fresh petition in accordance with the Rules.
Order Date :- 23.5.2019
