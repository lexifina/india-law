ORAL ORDER
1. Learned advocate for the Mr.Gandhi, appearing for the
petitioner seeks permission to withdraw this petition with a
view to file appropriate application before the appropriate
Authority, seeking clarification / recall of the communication
dated 29.03.2022. He has submitted that appropriate
application will be made by the petitioner within a period of six
weeks, however, he has requested that if any such application
is filed, the same may be ordered to be decided within a
reasonable time.
2. Learned Assistant Government Pleader Mr.Trivedi has
submitted that it goes without saying that if such an
application is filed, the same will be decided in accordance
with law.
3. Under these circumstances, it will be open for the
petitioner to file appropriate application before the respondent
