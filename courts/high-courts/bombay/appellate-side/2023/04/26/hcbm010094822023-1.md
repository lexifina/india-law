P.C. :
1. This is the second bail application filed by the
same applicant. The Applicant had earlier preferred Bail
Application No.LD/VC/DIST/Criminal Bail Application
No.166/2020. That application was argued for some time
and when I expressed my disinclination to grant relief,
learned counsel for the Applicant had sought unconditional
withdrawal of that application. The Application was allowed
to be withdrawn unconditionally and was disposed of as
such. That order was passed on 28.8.2020.
1 of 2
Deshmane(PS)

2. Today, again the matter was argued for quite
some time. When again I expressed my disinclination to
grant relief in this application, learned counsel for the
Applicant did not press this application and sought
unconditional withdrawal of the application. His only
request is that considering the fact that the Applicant is in
custody since 21.9.2019, the trial be expedited.
3. That request is reasonable. Hence, the
application is allowed to be withdrawn unconditionally. The
trial is expedited. The Application is disposed of accordingly.
