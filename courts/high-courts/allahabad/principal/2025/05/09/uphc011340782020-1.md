# Allahabad High Court, BAIL/41161/2020, 2025-05-09

Court No. - 45
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 41161 of 2020
Applicant :- Anish @ Nilesh
Opposite Party :- State of U.P.
Counsel for Applicant :- Prashant Verma,Sanjay Mishra,Shri Krishan Yadav
Counsel for Opposite Party :- G.A.,Janmed Kumar
Hon'ble Saumitra Dayal Singh,J.
1. This is a specially constituted bench to hear the second bail
application. The first bail application was rejected, vide order
dated 16.12.2019. More than five years have passed since then.
2. The order sheet reveals, earlier, opportunities were granted to
the applicant on request made on his behalf. The last order is dated
05.03.2022. The present bail application has been listed after three
years. No listing application exists on record to indicate that the
application survives.
3. Accordingly, the present application is dismissed for want of
prosecution.
4. If the trial survives, the applicant is at liberty to file a fresh
application, which may be listed before this bench at the earliest
date available.
