# High Court of Madhya Pradesh, MP/2591/2018, 2018-05-18

THE HIGH COURT OF MADHYA PRADESH
MP-2591-2018
(SARASWATI MANJHI Vs SMT. MANJU KOL)
Jabalpur, Dated : 18-05-2018
Shri Sushil Tiwari, learned counsel for the petitioner.
Shri Dinesh Upadhyay, learned counsel for the
respondent/caveator.
At the outset, learned counsel for the respondent contended that
this petition is directed against an interlocutory order passed in an
election petition, which has been decided today.
Learned counsel for the petitioner submits that he has no
instructions.
Considering the statement of learned counsel for the respondent,
this petition is dismissed as withdrawn. Liberty is reserved to the
petitioner to file an application for revival if said statement of the
learned counsel for the respondent is found to be incorrect.
SUJOY PAUL)
JUDGE
Pallavi High Court of Madhya Pradesh
