# Allahabad High Court, A482/17834/2019, 2019-05-03

Court No. - 67
Case :- APPLICATION U/S 482 No. - 17834 of 2019
Applicant :- Anuradha Shukla
Opposite Party :- State Of U.P. And Another
Counsel for Applicant :- Manoj Kumar Singh,Swatantra Singh
Counsel for Opposite Party :- G.A.
Hon'ble Rahul Chaturvedi,J.
Heard leaned counsel for the applicant and learned AGA for the State.
By means of the present application the applicant is assailing the order
dated 08.04.2019 by which the applicant's discharge application under
Sections 245(2) Cr.P.C. has been rejected by the Additional Sessions
Judge/ FTC (offence against women), Jaunpur.
The apt remedy lies somewhere else, if so advised the learned counsel for
the applicant may avail that remedy.
Office is directed to return back the certified copy of the order within
fifteen days.
Accordingly, the application is dismissed as withdrawn.
Order Date :- 3.5.2019
Abhishek Sri.
