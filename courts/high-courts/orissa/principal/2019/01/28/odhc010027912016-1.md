# High Court of Orissa, WP(C)/4616/2016, 2019-01-28

04. 28.01.2019 Learned counsel for the petitioner submits that the
petitioner may be permitted to withdraw this writ petition
with liberty to file fresh application with better particulars,
if cause of action survives.
 A memo has also been filed with the same prayer,
which is taken on record.
 Accordingly, the writ petition stands dismissed as
withdrawn with liberty aforesaid.
