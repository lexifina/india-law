CORAM: HONOURABLE THE CHIEF JUSTICE
 ORAL ORDER
2 11-10-2017 While disposing of Civil Revision No. 2023 of
2008 which was filed against the order passed on 07.11.2008 in
Execution Case No. 01/2003, the following directions were
issued:-
“This revision application is,
accordingly, allowed and the impugned judgment and
decree is set aside. In the facts and circumstances of the
case, there shall be no order as to costs.”
This is an error committed while passing the
order. In fact, the revision application was to be allowed and the
impugned order dated 07.11.2008 passed in Execution Case No.
01/2003 should have been set aside instead of the impugned

Patna High Court MJC No.2582 of 2017 (2) dt.11-10-2017
2/2
judgment and decree.
The order is corrected to the effect that “the
revision application is allowed and the impugned order dated
07.11.2008 passed in Execution Case No. 01/2003 stands set
aside”.
With the aforesaid correction to the order, this
application stands allowed and disposed of.
Shageer/-
