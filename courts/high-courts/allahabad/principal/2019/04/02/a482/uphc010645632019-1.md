# Allahabad High Court, A482/12242/2019, 2019-04-02

Court No. - 42
Case :- APPLICATION U/S 482 No. - 12242 of 2019
Applicant :- Devi
Opposite Party :- State Of Up And Another
Counsel for Applicant :- Ashok Kumar Upadhyay,Ajay Kumar
Upadhyay,Rajesh Tripathi
Counsel for Opposite Party :- G.A.
Hon'ble Ram Krishna Gautam,J.
Learned counsel for the applicant prayed for referring the
matter for mediation but when asked as to where is husband'
petition, it was replied that husband's petition is another.
Subsequently, it was requested to dismiss this application with
liberty to file a fresh application under Section 482 Cr.P.C. by
husband and applicant mother-in-law.
Under all above facts and circumstances, this application is
being dismissed with liberty to file afresh by adding husband in
it.
The certified copy be returned after getting a photostat of the
same on record for filing appropriate proceeding before
appropriate Bench.
Order Date :- 2.4.2019
Kamarjahan
