# High Court of Rajasthan, CW/4156/2006, 2006-08-03

SB Civil Writ. Petition No.4156/2006
Date of Order: 03rd August, 2006.
PRESENT
HON'BLE MR.JUSTICE BHAGWATI PRASAD
Mr. M.D.Boob for the petitioner/s.
Heard.
The court below has permitted filing of the rejoinder . If
some illegality has been committed then it cannot be said that it
should be corrected under Article 226 of the Constitution because
the civil Court is capable to function in accordance with the Civil
Procedure Code and if some latitude has been granted it is not for
this Court to interfere. The writ petition is dismissed. The
petitioner will however, be permitted to file reply to the rejoinder.
( BHAGWATI PRASAD), J.
L.George
