# Bombay High Court, MCA/677/2014, 2014-09-17

 Versus

FERNANDA DE SOUZA ... Respondent
Mr. Prasheen Lotlikar, Advocate for the Applicants.
Coram:- U. V. BAKRE, J.
Date:- 17th September, 2014
P.C:
 Heard Mr. Lotlikar, learned Counsel appearing on behalf of the
applicants.
2. This is an application for recall of the order dated 15.02.2013
and restoration of Stamp Number (Application) No. 3194/2009,
which is the application for bringing on record the legal
representatives of the deceased respondent in Second Appeal No.
23/2007. It is seen that the said order dated 15.02.2013 was self
operating in case, the service report is not filed. It is further seen that
Miscellaneous Civil Application No. 530/2014 for quashing and
setting aside the impugned order dated 15.02.2013 in so far as, said
second appeal is concerned, was allowed by order dated 06.08.2014.

2
3. The present application is supported by an affidavit.
4. In view of the reasons stated in the application and also because
the Miscellaneous Civil Application No. 530/2014 has been allowed,
the present application is also allowed. The Stamp Number
(Application) No. 3194/2009 stands restored.
5. The application stands disposed of, accordingly.
U. V. BAKRE, J.
