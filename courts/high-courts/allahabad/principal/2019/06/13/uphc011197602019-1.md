# Allahabad High Court, CRLP/16420/2019, 2019-06-13

Court No. - 1
Case :- CRIMINAL MISC. WRIT PETITION No. - 16420 of 2019
Petitioner :- Naseem And 2 Others
Respondent :- State Of U P And 2 Others
Counsel for Petitioner :- Jai Singh Yadav
Counsel for Respondent :- G.A.
Hon'ble Ramesh Sinha,J.
Hon'ble Vivek Varma,J.
Sri. Jai Singh Yadav, learned counsel for the petitioners as well as
learned A.G.A. for the State is present.
Learned AGA submits that there appears to be a suicide note of the
deceased which has not been annexed nor the post mortem report of
the deceased has been annexed with the writ petition.
Accordingly, the present petition is dismissed with liberty to file fresh
alongwith suicide note and post mortem report.
Office is directed to return the certified copy of the F.I.R. to learned
counsel for the petitioners after retaining a copy of the same.
(Vivek Varma, J.) (Ramesh Sinha, J.)
Order Date :- 13.6.2019/Kamarjahan
