# High Court of Madhya Pradesh, WP/1432/2016, 2016-02-29

WP-1432-2016
(SMT. INDRA VYAS Vs THE STATE OF MADHYA PRADESH)
29-02-2016
Shri C.L. Yadav, learned Sr.Counsel with Shri O.P. Solanki, learned
counsel for petitioner.
Shri A.Naik, learned counsel for respondents.
Heard.
This writ petition has been filed by the petitioner seeking a
direction to the respondent No.1 to return the sale deed after
registration.
The case of the petitioner is that he has purchased the property in
question from the respondent No.2 and 3 and the sale deed has
been executed and the petitioner and the respondent No.2 and 3
had produced the sale deed for registration on 28/3/2013. The said
document was presented before the respondent No.1 but till now
the sale deed has not been returned after registration nor any
reason for non return of the document has been disclosed.
Counsel for State has fairly stated that if the petitioner files an
application for return of the documents before respondent No.1,
the same will be duly considered and decided within a time bound
period.
In these circumstances, the writ petition is disposed off by
permitting the petitioner to file an appropriate application along
with the certified copy of this order for return of the documents. If
such an application is filed by the petitioner, the same will be
considered and decided by the respondent No.1 within a period of
two weeks from the date of receipt. If there is any reason for
retaining the documents, then the same will be duly disclosed by

the respondents and if there is no lawful reason for retaining the
same, the registered document will duly be returned to the
petitioner without any delay.
c.c as per rules.
(PRAKASH SHRIVASTAVA)
JUDGE
