# Bombay High Court, WP/8440/2020, 2020-12-18

VERSUS
THE STATE OF MAHARASHTRA AND OTHERS
...
Advocate for Petitioner : Mr Tarde Vivek V

SHRIKANT D. KULKARNI, JJ.
 DATE : 18th December, 2020
ORDER:
1. Heard Mr. Tarde, the learned Advocate for the petitioner. The
learned Advocate submits that name of the petitioner is not appearing in
the voters list of Grampanchayat Shimpora. Name of the petitioner is
included in the Vidhan Sabha voters list on 17.11.2020. The petitioner
raised objection on 28.11.2020 as his name did not appear in the
provisional voters list. The same is also not considered.
2. Mr. Kadethankar, the learned Advocate submits that name of the
petitioner did not appear in the Vidhan Sabha voters list as on 25.09.2020.
The petitioner also did not raise objection to the provisional voters list
within stipulated time.
3. Cut off date for the Grampanchayat election is 25.11.2020. Only
those names which are appearing in the valid voters list for Vidhan Sabha
as on 25.09.2020 are eligible to be considered. As the petitioner's name
for the first time was included on 17.11.2020, the respondents cannot be
faulted for non inclusion of name of the petitioner.
4. In light of above, no relief can be granted. Writ petition disposed
of. No costs.
(SHRIKANT D. KULKARNI, J.) (S. V. GANGAPURWALA, J.)
