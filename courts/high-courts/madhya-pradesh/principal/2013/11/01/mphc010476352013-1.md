# High Court of Madhya Pradesh, MCC/1306/2013, 2013-11-01

1
MCC No.1306/2013
1/11/2013
 Shri R. K. Pancholi, learned counsel for the
applicant.
This application has been filed for restoration of
W.P. No.1824/2001 which was dismissed for want of
prosecution on 23.7.2013.
Having heard learned counsel for the applicant and
on perusal of the reasons given in the application and
finding the same to be bonafide, this application is
allowed. Writ petition be restored in its original file and it
be placed for orders before the appropriate Bench.
Accordingly, this application stands allowed and
disposed of.
 (RAJENDRA MENON)
