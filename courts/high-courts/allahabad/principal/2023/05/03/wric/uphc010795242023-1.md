# Allahabad High Court, WRIC/12166/2023, 2023-05-03

Chief Justice's Court
Case :- WRIT - C No. - 12166 of 2023
Petitioner :- Ikrar Hussain
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Subhash Chandra Pandey
Counsel for Respondent :- CSC,Tarun Agrawal
Hon'ble Pritinker Diwaker,Chief Justice
Hon'ble Saumitra Dayal Singh,J.
1. Heard learned counsel for the petitioner, learned Standing
Counsel for the State and Sri Tarun Agrawal learned counsel for
the State Election Commission.
2. Petitioner claims error in the voters list. The last date with
respect to making correction, if any, has expired on 24.04.2023
being the last date of filing of nomination.
3. In view of the above, no interference is warranted. Accordingly,
petition is dismissed.
Order Date :- 3.5.2023
