# Madras High Court, A/589/2023, 2023-02-09

A.No.589 of 2023
A.No.589 of 2023
in C.S.No.45 of 2021
SENTHILKUMAR RAMAMOORTHY, J.
The plaintiffs have presented this application for permission to file a
reply to the written statement. On instructions, learned counsel for the third
defendant submits that he has no objection to this application being allowed.
In the affidavit in support of this application, it is stated that it is necessary
to file a reply statement in view of the numerous defences raised in the
written statement. On examining the affidavit and being satisfied that
sufficient cause is shown, this application is allowed. Consequently, the
Registry is directed to receive the reply statement of the plaintiffs.
