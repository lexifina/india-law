# High Court of Madhya Pradesh, MCC/3142/2017, 2017-12-05

THE HIGH COURT OF MADHYA PRADESH
MCC-3142-2017
(CHANDULAL JAIN Vs MADANLAL JAIN)
Jabalpur, Dated : 05-12-2017
Shri S.K.Verma, learned counsel for the applicant.
Heard on I.A.No. 17368/2017, an application for
condonation of delay in filing the present application. As per the
office report, there is a delay of 1 day in filing the application.
Keeping in the view the averments made in the application
which is duly supported by affidavit, IA No. 17368/2017 is
allowed. Delay caused in filing the application is hereby
condoned.
Also heard on restoration application.
This application has been filed for restoration of S.A.No.
692/2017 which was dismissed in default due to non-compliance
of common conditional order dated 03.07.2017. The application
is duly supported by an affidavit.
Looking to the facts mentioned in the application, the same
is allowed. S.A.No. 692/2017 is restored to its original number.
The MCC stands allowed and disposed of.
Let a copy of this order be kept in the file of S.A.No.
692/2017.
(SMT. ANJULI PALO)
JUDGE
