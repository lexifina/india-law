ORAL ORDER
2 03-05-2016 Heard the learned counsel for the petitioner.
By the impugned order dated 25.01.2016, the learned
Munsif, Araria only allowed the application to mark document as
exhibit.
Therefore, in my opinion, only the Court below has passed
the order for marking the document which neither occasioned
failure of justice nor it prejudices the petitioner. The petitioner
may raise all the points which is being raised before this Court in
this writ application before the Court in the final hearing of the
suit itself.
Thus, this writ application is dismissed with the aforesaid
liberty.
Sanjeev/- (Mungeshwar Sahoo, J)
