# High Court of Madhya Pradesh, WP/100/2013, 2013-01-29

WP 100/2013
( Brajesh Sharma Vs. State of MP and Anr. )
29/01/2013
Mr.Anand Bhardwaj, Advocate for the petitioner.
Ms Sudha Shrivastava, Panel Lawyer for the
respondents/State.
The petitioner has moved an application IA
619/2013 submitting that since the matter is sub judice
before the State Government, therefore, he does not
wish to press the present writ petition, but prays for
liberty to file afresh, if occasion does arise. The
application is allowed.
The petition is hereby dismissed as not pressed
with liberty as prayed for.

( A.K.Shrivastava ) ( G.D.Saxena )
