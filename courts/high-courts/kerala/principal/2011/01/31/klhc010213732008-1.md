 O R D E R
The revision is filed against the order dated 15th
December, 2004 in E.P.No.614 of 1989 in L.A.R.No.92 of
1987 on the file of the Sub Court, Ernakulam, by which full
satisfaction was recorded in the Execution Petition. The
case of the petitioner is that there is excess payment.
2. Learned counsel appearing for the respondents
submitted that let both parties to be permitted to file
statements, so that the executing court would be able to
arrive at the correct conclusion as to the amount payable to
the respondents. It is submitted by the learned counsel for
the respondents that for that purpose, the respondents
have no objection to set aside the order passed by the court
below.

CRP No.273 of 2008 G 2
Accordingly, the order impugned, by which full
satisfaction was recorded, is set aside. The other part of the
order by which the sale was set aside is not being interfered
with. The Execution Petition shall stand restored. Both
parties would be entitled to file statements showing the
correct amount due in the Execution Petition and both parties
would be entitled to get an opportunity of being heard. The
executing court shall dispose of the matter afresh.
 K.T.SANKARAN
 JUDGE
