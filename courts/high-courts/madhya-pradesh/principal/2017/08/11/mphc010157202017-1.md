# High Court of Madhya Pradesh, MCRC/5140/2017, 2017-08-11

MCRC-5140-2017
(SMT. KESAR BAI RAGHUVANSHI Vs THE STATE OF MADHYA PRADESH)
11-08-2017
Shri A.P. Shah, counsel for the applicants.
Ms. Shahin Fatima, Govt. Advocate for the State.
The present application has been filed for restoration of M.Cr.C.
No.4116/2013, which was dismissed on 11.1.2017 for want of
prosecution. Application is supported by affidavit of Ramesh Chandra.
Keeping in view the reasons stated in the application, the same is
allowed.
M.Cr.C. No.4116/2013 is restored to its original number.
Let a copy of this order be kept in the file of M.Cr.C. No.4116/2013.
With the aforesaid, present application is disposed of.
(SMT. ANJULI PALO)
JUDGE
