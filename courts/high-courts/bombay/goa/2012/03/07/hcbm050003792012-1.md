P.C.:
 Heard Shri V. Korgaonkar, learned Counsel appearing for the
applicants and Ms. K. Devgikar, learned Counsel appearing for the
respondent.
2. This is an application for correction of a typographical error in
the judgment dated 21/11/2011 at para 7 wherein instead of sum of
'Rs.45,000/-' mentioned therein the same should be read as
'Rs.45,00,000/-'. The learned Counsel appearing for the respondent
accepts that there is a typographical error. Hence, the application is
allowed.
3. The sum of 'Rs.45,000/-' shall be read as 'Rs.45,00,000/-' at para 7
of the said judgment. Registry to correct the records accordingly.
Application stands disposed of.
F. M. REIS, J.
