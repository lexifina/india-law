ORDER
This petition has been filed to quash the FIR in Crime
No.630 of 2013 on the file of the first respondent, insofar as
the petitioner herein is concerned.
2. Earlier, the petitioner had filed a petition before
this Court in Crl.O.P.No.5273 of 2016 to direct the respondent
police to file final report, which was considered by this Court
and by an order dated 04.04.2016, this Court directed the first
respondent police to investigate the matter and file final
report in Crime No.630 of 2013, within a period of six months
https://hcservices.ecourts.gov.in/hcservices/

from the date of receipt of a copy of that order. Even though
the order passed by this Court, the first respondent police did
not file final report till date.
3. Learned Additional Public Prosecutor submitted that
investigation is already completed and they are ready to file
charge sheet.
4. Considering the above facts and circumstances of the
case, the first respondent police is directed to file final
report within a period four weeks from the date of receipt of a
copy of this Order before the concerned Judicial magistrate.
5. With the above directions, this Criminal Original
Petition is disposed of.
