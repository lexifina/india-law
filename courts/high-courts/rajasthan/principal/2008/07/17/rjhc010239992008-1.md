# High Court of Rajasthan, CRLMB/3309/2008, 2008-07-17

S.B.CR. MISC. BAIL APPLICATION NO.3309/2008
(Kartar Singh Vs. State of Rajashan)
DATE OF ORDER : 17/7/2008
HON'BLE MR.BHANWAROO KHAN, J.
Mr.B.K. Vyas,for the petitioner.
Mr.S.K. Vyas, PP.

Heard learned counsel for the petitioner
and learned public prosecutor for the State.
There is no reason to grant application
for pre-poning the date because in this case
date has already been fixed on 22.7.2008.
Accordingly, the application for pre-poning the case is rejected.
