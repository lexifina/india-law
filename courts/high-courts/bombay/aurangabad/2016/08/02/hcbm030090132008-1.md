CORAM : T.V. NALAWADE, J.
DATED : 2nd August, 2016.
ORDER :
1. The application is filed for setting aside the order
made by the learned Registrar Judicial by which he refused the
registration as office objections were not removed. Both the
sides are heard. Notice was issued to respondents by this Court
(Other Hon'ble Judge). As the learned counsel for applicants is
taking blame to himself and in view of the contentions of the
application and submissions made, this Court holds that the
application needs to be allowed.
2. So, the application is allowed. Delay, if any, is
condoned. The order of learned Registrar Judicial is set aside.
The matter is restored to its original stage. If office objections
are not removed prior to 12.8.2016, it is to be presumed that the
present application is dismissed.
 [ T.V. NALAWADE, J. ]
