# Calcutta High Court, CRR/3500/2012, 2021-09-22

22.09.2021 IN THE HIGH COURT AT CALCUTTA
 Item No.8 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
 C.R.R. 3500 of 2012
 (Via Video Conference)
 Indus Towers Limited
 versus
 Purnendu Das
In Re: An Application under Sections 397/401 read with
Section 482 of the Code of Criminal Procedure, 1973.
Mr. Ayan Bhattacherjee … For the Petitioner.
Mr. Arijit Ganguly,
Mr. Sanjib Kumar Dan … For the State.
Mr. Ayan Bhattacherjee, learned advocate appearing for
the petitioner submits that the complainant has filed an
application for withdrawal in respect of compoundable
offences. As such, the petitioner is not inclined to proceed
with the instant revisional application.
Accordingly, the revisional application being CRR 3500
of 2012 is dismissed as not pressed.
All pending applications, if any, are consequently
disposed of.
Interim order, if any, is hereby vacated.
Photostat copies of the certified copy submitted by the
learned advocate for the petitioner be kept with the record.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
 (Tirthankar Ghosh, J.)
