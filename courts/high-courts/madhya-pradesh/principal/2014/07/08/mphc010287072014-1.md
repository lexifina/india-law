# High Court of Madhya Pradesh, MCC/1129/2014, 2014-07-08

M.C.C.No.1129/2014
1
Kunj Bihari Chouksey Vs. State of MP & Ors.
08/07/2014
Shri Pramendra Sen, learned counsel for the applicant.
This application has been filed for restoration of
W.A.No.455/2014, which has been dismissed for want of
prosecution on 16.6.2014.
Keeping in view of the reasons given in the application and
finding the same to be bona-fide, this application is allowed.
W.A.No.455/2014 be restored to it's original file, it be placed for
orders before an appropriate bench.
With the aforesaid, this application stands allowed and
disposed of.
(Rajendra Menon) (Alok Verma)
