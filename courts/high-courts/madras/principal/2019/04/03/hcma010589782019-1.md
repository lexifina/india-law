R.SUBRAMANIAN, J.
The application has been filed to set aside the ex-parte order dated
15.03.2019 passed in O.P.No. 749 of 2009. The respondent was set ex-parte for
non-filing of counter in the main original petition. The applicant has also filed
counter in the main original petition along with this application.
2. Considering the reasons set out in the affidavit filed in support of the
application, this application is allowed. The ex-parte order 15.03.2019 is set
aside and the counter is taken on file.
3. List the original petition on 11.04.2019.
