Tuticorin District. .. Respondent
PRAYER: Criminal Original Petition filed under Section 482 of
Cr.P.C. praying to direct the respondent police to file the final
report in Crime No.275 of 2012 on the file of the respondent
within the time stipulated as fixed by this Court.
 For Petitioner : Mr.T.Vadivelan
 For respondent : Mr.K.Anbarasan
 Government Advocate (Criminal side)
ORDER
This petition is filed seeking a direction to the respondent
to file the final report in Crime No.275 of 2012 on the file of
the respondent police and to file final report within a time
frame.
2.Heard the learned counsel for the petitioner and the learned
Government Advocate (Crl. Side) for the respondent.
3.The learned Government Advocate (Criminal Side), on
instructions, would submit that the respondent police have already
conducted the enquiry and filed final report before the learned
Judicial Magistrate, Sathankulam, which was taken on file as
P.R.C.No.32 of 2016.
4. Recording the above submission, this Criminal Original
Petition dismissed.
