delay.

application and the same found to be satisfactory, I.A. No. 1 is allowed.

32/2007 which was dismissed for want of prosecution vide order
passed by this Court on 27.10.2016.
4. For the reasons assigned in the said application and the same found to
be satisfactory, the present M.C.C. stands allowed.
