ORAL ORDER
(PER: THE HON'BLE MR JUSTICE ANANT RAMANATH HEGDE)
Heard the learned counsel appearing for the petitioner
and the learned counsel appearing for the respondents.
2. The petition is filed assailing the order dated
01.10.2024 passed in O.S.No.57/2023 on I.A.No.16,
dismissing the application filed by defendant No.5 seeking
amendment of his written statement.
3. At this juncture, the learned counsel for the
respondents would submit that the written statement filed by
defendant No.5 is not yet accepted by the Trial Court.
4. The learned counsel for the petitioner would submit
that it is deemed to have been accepted as issues are framed
incorporating the defence raised by defendant No.5.
5. Issue No.6 reads as under:
“Whether defendant No.5 proves that suit of the
plaintiffs is hit by res-judicata?”

 - 4 -
 HC-KAR
NC: 2025:KHC-D:15110
WP No. 106372 of 2024
6. However, it is fairly submitted that there is no
formal order accepting the application of defendant No.5
seeking to file written statement beyond 90 days.
7. Under these circumstances, this Court is of the
view that the application for amendment of the written
statement of defendant No.5 could not have been considered
on merit. The Trial Court should have passed an order on the
application filed by defendant No.5 to file written statement
beyond the stipulated period.
8. Hence, the following:
i. Writ petition is allowed.
ii. Impugned order dated 01.10.2024 is set aside
without entering into the merits.
iii. The Trial Court shall consider the application
filed by defendant No.5 seeking leave of the
Court to file written statement and if it is
accepted, then shall consider the application
for amendment of written statement.
