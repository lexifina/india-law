IN THE HIGH COURT OF JUDICATURE AT BOMBAY
BENCH AT AURANGABAD
BAIL APPLICATION NO.675 OF 2023
GANESH DANGAL KOLI (SONAWANE)
VERSUS
THE STATE OF MAHARASHTRA
...
Advocate for Applicant : Ms. Sunita G. Sonawane
APP for Respondent : Mr. K. S. Patil
...
CORAM : S. G. MEHARE, J.
DATE : 06-07-2023
PER COURT :-
1. After rejection of the application by this Court, with a leave
to file fresh bail application if there would not be any substantial
progress in trial in six months, instead of approaching the learned
Sessions Court, the applicant has directly approached this Court.
Now the applicant wish to seek bail before the learned Sessions
Court.
2. The learned counsel for the applicant, on instructions, seeks
leave to withdraw this application with a liberty to file fresh bail
application before the learned Sessions Court.
3. Leave granted as prayed.
4. The application stands dismissed as withdrawn.
5. It is clarified that this Court has not considered the merits of
the case. Barely a leave is granted to file fresh bail application
before the learned Sessions Court. So, the learned Sessions Court
should not treat this application as decided on merit and it would
be an impediment for him to decide the application for bail on
merit.
 ( S. G. MEHARE, J. )
