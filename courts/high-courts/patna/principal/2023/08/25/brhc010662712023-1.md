ORAL ORDER
2 25-08-2023 Heard learned counsel for the petitioner and learned
APP for the State.
2. Learned counsel for the petitioner is directed to
correct para 1 of the bail application in course of the day.
3. The petitioner apprehend his arrest in connection
with Khaira P.S. Case No.180 of 2023 dated 21.05.2023 for the
offences punishable under Sections 188, 420, 34 of the Indian
Penal Code but later on Sections 465, 467, 471, 474 of Indian
Penal Code were added which is pending in the Court of learned
Chief Judicial Magistrate, Chapra (Saran).
4. After some arguments, learned counsel for the
petitioners seeks permission to withdraw this application.
5. Permission is granted.
6. Accordingly, this application is dismissed as
withdrawn.
