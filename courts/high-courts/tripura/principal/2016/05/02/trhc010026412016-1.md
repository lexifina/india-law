# High Court of Tripura, IA./395/2016, 2016-05-02

Case No :IA. 0000395/2016
Party Name : MS PARAMITA SEN Vs THE STATE OF TRIPURA & ORS
HONBLE THE CHIEF JUSTICE DEEPAK GUPTA THE HONBLE MR. JUSTICE S.TALAPATRA
If we allow this application, it actually amounts to allowing the main writ petition. We,
therefore, feel that this application cannot be allowed at this stage.
Accordingly, this application stands disposed of.
However, the main writ petition [WP(C)(PIL) No.04 of 2015] shall be set down for hearing
on 25th July, 2016.
The petitioner is, however, allowed to raise the issues raised in this interim application even
while arguing the main writ petition.
