# High Court of Madhya Pradesh, MCRC/3282/2016, 2016-02-22

MCRC-3282-2016
(RAJESH PAURANIK Vs THE STATE OF MADHYA PRADESH)
22-02-2016
Shri Y.K. Gupta, learned counsel for the applicant.
Shri V.K. Pandey, learned Panel Lawyer for the State.
This application has been filed for correction in the order dated 29.1.2016
passed in M.Cr.C. No.236/2016.
It is submitted by learned counsel for the applicant that due to typographical
error, Police Station Gautam Nagar, Bhopal has been mentioned, whereas the
case is registered in Police Station Damoh Dehat, District Damoh.
In this view of the matter, application is allowed. It is directed that in the order
dated 29.1.2016 passed in M.Cr.C. No.236/2016, it shall be read Police Station
Damoh Dehat, District Damoh, instead of Police Station Gautam Nagar,
Bhopal.
With the aforesaid direction, the present application is disposed of.
C.C. as per rules.
(S.K. GANGELE)
JUDGE
