JUDGMENT
The petitioner has a three-storeyed building. He applied for
permit for constructing the fourth floor. He has been given an
order by the first respondent, Municipality, that the area is
earmarked to be a paddy field in terms of an Interim
Development Scheme and that therefore permission to build the
floors above the existing structure cannot be granted. Much
reasons do not deserve to be stated to set it aside. There is no
scheme that has become final. There is no statutory proceedings
for acquisition.
In the result, this writ petition succeeds and the impugned
order is set aside. The first respondent is directed to take up the
application of the petitioner and allow it, if it is otherwise in order
and without reference to the reasons stated in the impugned
order.
