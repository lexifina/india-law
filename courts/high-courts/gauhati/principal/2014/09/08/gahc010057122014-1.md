# Gauhati High Court, AB/3108/2014, 2014-09-08

AB 3108/2014
BEFORE
HON’BLE MR. JUSTICE C.R.SARMA
Heard Mr. S C Biswas, learned counsel appearing for the petitioner. Also heard M
r. B S Sinha, learned Additional Public Prosecutor appearing for the state of As
sam.
By this application filed under Section 438 Cr. P.C, the petitioner, namely, Md.
Jahiruddin Sheikh @ Md. Jahir Ali, has prayed for release on bail in connection
with Bongaigaon PS Case No.75/2014 under Section 498(A) IPC.
Learned Additional Public Prosecutor has submitted that police has already submi
tted the Final Report for want of evidence against the petitioner.
In view of above, this bail application is closed.
