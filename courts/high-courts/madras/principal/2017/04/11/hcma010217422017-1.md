ORDER
Challenging the order dated 28.02.2017 passed by the
respondent in Order No.TN/CHN/CC-1/12/TN/83842/Enf/2016, the
petitioner has come up with the present writ petition.
2.Admittedly, the order impugned is appealable. Since there
is a statutory remedy available to the petitioner, this Court
is not inclined to entertain this writ petition. Once an appeal
is provided, the issue pertaining to law and fact can always be
raised in the appeal.
https://hcservices.ecourts.gov.in/hcservices/

3.In such view of the matter, the writ petition stands
dismissed, however with liberty to the petitioner to file
statutory appeal, if so advised. Considering the facts and
circumstances of the case, the petitioner is given four weeks
time from the date of receipt of a copy of this order to file
such an appeal, if so advised. No costs. Consequently, connected
miscellaneous petition is closed.
