(RAJ KISHORE PATEL Vs THE STATE OF M.P.)
Jabalpur, Dated : 05-09-2020
Heard through Video Conferencing.
Shri Brajesh Rajak, counsel for the applicant.
Shri Sanjeev Kumar Singh, Panel Lawyer for the respondent/State.
It is submitted by learned counsel for the applicant that actually, this is
the third application but due to some mistake by the previous counsel, the
application has been filed as second application.
Therefore, he seeks withdrawal of the application with liberty to file
fresh application.
Permission is granted.
Accordingly, the application is dismissed as withdrawn with liberty to
file fresh application with appropriate details regarding previous application.
