# High Court for the State of Telangana, CRLRC/1183/2017, 2017-08-28

THE HON’BLE SRI JUSTICE M. SATYANARAYANA MURTHY
CRIMINAL REVISION CASE No.1183 of 2017
ORDER:
Learned counsel for petitioner seeks permission of this
Court to withdraw the Criminal Revision Case with liberty to
petitioner to file appropriate application.
Permission is accorded and the Criminal Revision Case is
dismissed as withdrawn giving liberty to petitioner to file
appropriate application before appropriate forum.
Consequently, pending Miscellaneous Petitions, if any,
shall stand dismissed.
Registry is directed to return the order under challenge to
the counsel on record under proper acknowledgment.
______________________________
 M.SATYANARAYANA MURTHY, J
28th AUGUST, 2017.
