# High Court of Madhya Pradesh, MCC/2857/2015, 2015-09-28

MCC-2857-2015
(ANAND RAO Vs SIDDHARTH)
28-09-2015
Ms. Smita Arora, learned counsel for the applicant.
This application has been filed for restoration of Second Appeal
No.998/2006, which was dismissed for want of prosecution vide
order dated 09/03/2015. There being some delay in filing the
application for restoration, therefore, I.A. No.12589/2015 has been
filed seeking condonation of delay. Both the applications are
supported by an affidavit and there is no reason to disbelieve the
same. Finding the same to be bona fide, both the applications are
allowed.
Condoning the delay in filing the application, restoration
application is itself allowed.
Second Appeal No.998/2006 is restored to its original
number.
After restoration, Second Appeal No.998/2006 be placed for
orders before appropriate Bench.
Application stands allowed and disposed of.
Certified copy as per rules.
(VANDANA KASREKAR)
JUDGE
