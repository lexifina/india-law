# High Court of Andhra Pradesh, WP/8613/2019, 2019-07-25

HON’BLE SRI JUSTICE U.DURGA PRASAD RAO
Writ Petition No.8613 of 2019
ORDER:
 When the matter is taken up for hearing, learned counsel for the
petitioner seeks permission of this Court to withdraw the Writ Petition
with a request to give liberty to the petitioner to file fresh Writ
Petition and also made an endorsement to that effect.
2. Permission for withdrawal is accorded.
3. Accordingly, this Writ Petition is dismissed as withdrawn
giving liberty to the petitioner to file fresh Writ Petition. No costs.
 As a sequel, interlocutory applications pending, if any, shall
stand closed.

U.DURGA PRASAD RAO, J
