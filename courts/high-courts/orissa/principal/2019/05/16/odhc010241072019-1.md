# High Court of Orissa, CONTC/583/2019, 2019-05-16

02 16.05.2019 Heard Mr. A.K. Pattnaik, learned counsel for the
petitioners.
 Since this application has been filed on
24.04.2019 alleging non-compliance order dated
03.07.2014 passed by this Court in W.P.(C) No. 1198 of
2006, this application is grossly barred by limitation.
 Accordingly, this Court is not inclined to entertain
this application. The contempt proceeding is hereby
dropped.
