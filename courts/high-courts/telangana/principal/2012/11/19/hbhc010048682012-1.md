# High Court for the State of Telangana, CRLP/8007/2012, 2012-11-19

THE HON’BLE SRI JUSTICE K.C.BHANU
CRIMINAL PETITION NO.8007 OF 2012
ORDER:
Learned counsel for the petitioners seeks permission to withdraw the
Criminal Petition with liberty to file Revision Petition challenging order of
discharge.
Permission is accorded.
Accordingly, the Criminal Petition is dismissed as withdrawn with
liberty to file Revision Petition challenging order of discharge. Registry is
directed to return the original papers. Miscellaneous petitions, if any, pending
in this Criminal Petition shall stand closed.
