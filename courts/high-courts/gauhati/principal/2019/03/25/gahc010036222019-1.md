ORDER
Date : 25-03-2019
Heard Ms. U. Sarma, learned counsel for the applicant as well as Ms. M.D. Bora,
the learned State Counsel.
This is an application for restoration of WP(C) 491/2011 which has been dismissed for
default vide order dated 09.12.2015. This application has been accompanied by another
application I.A. No. 701/2019 for condonation of delay which has been allowed and the delay
has been condoned vide order dated 25.03.2019.
In view of the above fact and circumstances, the present I.A. is allowed and the order
dated 09.12.2015 is recalled. Consequently WP(C) No. 491/2011 is restored to file and to its
original number.
The writ petition being of the year 2015, list the same for hearing in the 1st week of
May, 2019.
 JUDGE
