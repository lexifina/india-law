For Respondents: Mr.M.Mohamed Riyaz,
 Additional Public Prosecutor
 ORDER
This petition has been filed to transfer the investigation
concerned in Crime No.148 of 2014 on the file of the third
respondent to the file of the second respondent and consequently
direct the second respondent to conduct investigation and to
file a final report within the stipulated time.
2. The learned counsel for the petitioner would submit that
the investigation is still pending in Crime No.148 of 2014 on
the file of the third respondent and hence the petitioner has
filed this petition.
https://hcservices.ecourts.gov.in/hcservices/

3. In view of the above, the third respondent is directed to
complete the investigation in Crime No.148 of 2014 and file a
final report within a period of eight weeks from the date of
receipt of a copy of this Order, if not filed already.
4. With the above direction, this Criminal Original Petition
is disposed of.
