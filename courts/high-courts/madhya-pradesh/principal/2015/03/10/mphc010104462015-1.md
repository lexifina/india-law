# High Court of Madhya Pradesh, MCRC/3644/2015, 2015-03-10

M.Cr.C. No.3644/2015
10.03.2015 Shri Anurag Sahu, counsel for the applicant.
Shri Akhilendra Singh, Govt. Adv. for the
respondent/State.
Learned counsel for the applicant submits
that he wanted to file an application for the co-accused Vicky but due to clerical error, the
application was initiated for the present applicant
Raaj and therefore, he wants to withdraw the
present application with the liberty to file a fresh
application for the accused Vicky.
Prayer is allowed.
The present application filed by the applicant
Raaj is hereby dismissed being withdrawn.
