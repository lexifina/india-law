ORDER
The prayer in the petition is to transfer O.P.(C)96/2015 pending
before the Family Court, Kollam to Family Court, Kannur. Since there
was no stay after 23.07.2015, this court has called for a report
regarding the present stage of the case from Family Court, Kollam and
the Family Court, Kollam has sent a report dated 14.10.2016 stating
that an exparte order has been passed on 15.03.2016. Since the case
is already been disposed of by passing an exparte order, the remedy of
the petitioner is to set aside the exparte order and such an application
can be filed only before that court. So the present prayer in the
petition has become infructuous. So the petition is dismissed as
infructuous with liberty for the petitioner to move later for the same
relief, if the exparte order is set aside.
Sd/-
