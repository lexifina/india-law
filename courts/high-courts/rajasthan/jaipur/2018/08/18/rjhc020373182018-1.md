Order
18/08/2018
1. A common order dated 14.02.2018 disposing of SBCWP
Nos. 2199/2018 and 3080/2018 is challenged in the two captioned
appeals. In both writ petitions challenge was to an order dated
08.01.2018 passed by the Board of Revenue. The order disposed
of two appeals.
2. The case of the writ petitioners was that an application
filed under Order 41 Rule 27 of the Code of Civil Procedure was
filed before the Board of Revenue. Arguments were heard in the
said application in the year 2015. Without deciding the application
the appeals were disposed of by the order dated 08.01.2018.
Apart therefrom, even on merits of the order, challenge is made.
3. Disposing of the two writ petitions the learned Single
Judge has rightly held that prejudice was caused by not deciding
the application filed under Order 41 Rule 27 of the Code of Civil
Procedure. The learned Single Judge has without seting aside the
impugned order dated 08.01.2018, remanded the matter to the
Board of Revenue for passing orders on the application filed under
Order 41 Rule 27 of the Code of Civil Procedure with further
direction that if the application is allowed, the Board of Revenue
would hear arguments afresh and pass a final decision. Meaning
thereby, the learned Single Judge has held that upon the

(4 of 4) [SAW-292/2018]
application under Order 41 Rule 27 being allowed, the order dated
08.01.2018 would be deemed to have been set aside. However,
the learned Single Judge has held that if the application under
Order 41 Rule 27 is dismissed, then the order dated 08.01.2018
would stand.
4. In our opinion, if this was the appraoch to be followed
by the learned Single Judge, he ought to have granted liberty to
the appellants to challenge the order dated 08.01.2018 afresh if
their application under Order 41 Rule 27 of the Code of Civil
Procedure was dismissed for the reason in the writ petitions filed,
there was challenge to the order dated 08.01.2018 de hors the
additional challenge that it suffered from a procedural infirmity in
as much as the appeals were decided without deciding the
application filed under order 41 Rule 27 of the Code of Civil
Procedure.
5. Accordingly we disposed of the appeals declaring that if
appellants application under Order 41 Rule 27 of the Code of Civil
Procedure is dismissed, they would be entitled to file writ petitions
challenging not only said order but even the order dated
08.01.2018 on merits.
