# High Court of Madhya Pradesh, MCC/1627/2014, 2014-08-21

1
MCC No.1627/2014
21/8/2014.
Shri Sankalp Kochar, learned counsel
for the applicant.
Shri Samdarshi Tiwari, learned Govt.
Adv. For the respondents.
This application has been filed for
restoration of W.P. No.9290/2014 which has been
dismissed in view of the common conditional
order passed.
Keeping in view the reasons given in
the application which is supported by the Clerk in
the office of the counsel and finding the reasons
to be bonafide, this application is allowed.
Writ Petition is restored to its original
file. It be placed for orders before the
appropriate Bench.
With the aforesaid, this application
stands allowed and disposed of.
(Rajendra Menon) (Alok Aradhe)
