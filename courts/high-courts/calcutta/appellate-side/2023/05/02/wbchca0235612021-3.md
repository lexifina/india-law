# Calcutta High Court, CRR/1564/2021, 2023-05-02

 Sahinul Isalam @ Mukul
 -versus-
 The State of West Bengal and another

Mr. Arka Bhattacharya
Mr. Aniruddha Singh
Ms. Saloni Bhattacharya
 … for the petitioner
Mr. Arijit Ganguly
Ms. Sujata Das
 … for the State

Learned advocate for the petitioner is present.
The subject matter of challenge is the FIR of Dum
Dum Police Station Case No.852 of 2016 dated 08.09.2016.
Mr. Arijit Ganguly, learned advocate appearing for the
State points out that the charge-sheet in this case was
submitted on 30.06.2017.
Since a charge-sheet has been filed earlier to the
revisional application being preferred, I am of the view that
the revisional application which was preferred is
infructuous.
The petitioner would be at liberty to challenge the
charge-sheet which has been submitted by taking out a
proper fresh revisional application before this Court.
The present revisional application being CRR 1564 of
2021 is dismissed as infructuous.
Pending application, if any, is consequently disposed
of.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
