This application coming on for conciliation this day, the Bench passed
the following:
ORDER
Heard on I.A.No.15483/2017, an application for condonation of delay
in filing this MCC.
For the reasons mentioned in the application, the same is allowed.
Delay in filing the application is hereby condoned.
This MCC has been filed for re-admission of M.A. No.1573/2013 which
was dismissed for non-compliance of peremptory order dated 29.11.2016.
Application is supported by an affidavit of applicant No.1. There is no
reason to disbelieve the same.
Accordingly, application is allowed.
M.A. No.1573/2013 is re-admitted to its original file subject to
rectification of default within a period of seven days from today.
