ORAL ORDER
2 01-05-2013 Having regard to the fact that the petitioner for the
same cause of action had already filed a writ application and had
withdrawn it without obtaining leave for filing the fresh
application for the same cause of action, this writ application must
be held to be wholly misconceived.
 That being so this application is being dismissed.
 The dismissal of the writ application however will
not stand in the way of the petitioner, if he files a proper money
suit for the work done in respect of scheme allotted to him.
