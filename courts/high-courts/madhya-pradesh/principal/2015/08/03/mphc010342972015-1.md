# High Court of Madhya Pradesh, MCC/1964/2015, 2015-08-03

MCC-1964-2015
(SMT TARA BAI Vs THE STATE OF MADHYA PRADESH)
03-08-2015
Shri Umesh Pandey, learned counsel for the applicants.
Shri R.N.Yadav, learned PL for the respondents/State.
This application has been filed for restoration of Second Appeal
No.1745/2007, which was dismissed for want of prosecution by
this Court on 15/04/2015. There being some delay in filing the
application for restoration, I.A. No.8926/2015 has been filed
seeking condonation of delay. Both the applications are supported
by affidavit of the applicant Smt. Tara Bai and there is no reason
to disbelieve the same. Finding the same to be bonafide, both the
applications are allowed.
Condoning the delay in filing the application, restoration
application itself is allowed.
Second Appeal No.1745/2007 is restored to its original
number. It be placed for orders before appropriate Bench.
Application stands allowed and disposed of.
(VANDANA KASREKAR)
JUDGE
