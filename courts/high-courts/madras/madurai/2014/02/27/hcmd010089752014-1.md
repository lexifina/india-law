O R D E R
 This petition is filed seeking a direction to call for the records
pertaining to the proceedings in M.C.No.01/2014 dated 21.01.2014 on the
file of the second respondent and set aside the same insofar as the
petitioners herein are concerned.
2. The petitioners case is that there is no preliminary enquiry
conducted by the Magistrate which is a mandatory one as per Section 111
of the Code of Criminal Procedure. Section 107 of the Code of Criminal
Procedure clearly stipulates the condition when the Magistrate found that
there is a sufficient ground of show-cause. Since there is no
preliminary enquiry, the petitioner contended that the show-cause is bad.
He has also relied upon the decision of this Court in the matter of
K.V.Shanmugam -vs- State (Inspector of Poilice, Palladam) reported in
1978 LW 130.
https://hcservices.ecourts.gov.in/hcservices/

2
3. Taking note of the submissions and that in view of the decision
cited supra, the preliminary evaluation by the Magistrate is necessary
amd the order is set aside. This does not mean that the entire
proceedings are set at knot. It is open to the authorities concerned to
act in accordance with the Criminal Procedure Code and proceed further.
The period during which the matter is pending, before this Court cannot
be counted for any laches for initiating the proceedings.
4.Accordingly, the criminal original petition is ordered.
Consequently the connected Miscellaneous Petitions are closed.
