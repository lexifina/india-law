1. Heard Ms Manju M. Ghatode, learned counsel
for the applicants.
2. State has filed reply. In the said reply it is
stated that even prior to the order passed by this Court on
30.07.2021, the charge-sheet was already filed. In view of
that statement, Ms Manju Ghatode, learned counsel for the
applicants prays for withdrawal of this application with a
liberty to file fresh application under Section 482 of the
Code of Criminal Procedure to challenge this action.
3. Her prayer is accepted.
4. The application is disposed of with liberty as
prayed for.
