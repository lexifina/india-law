2.On the side of the petitioner, it is stated that the main
subject matter was already compromised between the parties and
hence, prayed for setting aside the order in unnumbered second
appeal in S.A(MD)SR No.21853 of 2010 dated 29.06.2015.
3.A perusal of the records shows that the order dated
29.06.2015 was passed on merits and not an ex-parte order and as
such it cannot be set aside. The petition filed by the petitioner
is to condone the delay in filing a set aside petition to set aside
the dismissal order dated 29.06.2015. When the order could not be
set aside, there is no question of filing a petition to set aside
the order dated 29.06.2020 and therefore, the condone delay petition
also could not be entertained.
4.Therefore, liberty is given to the petitioner to file a
petition to review the order dated 29.06.2015 and to file a fresh
petition for condone the delay in filing such petition.
5.With the above observation, this Civil Miscellaneous Petition
is dismissed.
