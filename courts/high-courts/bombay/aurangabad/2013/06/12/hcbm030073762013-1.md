ORAL JUDGMENT :
. Rule. Rule returnable forthwith. With the consent of
parties, taken up for final hearing.
2. The application filed by the present petitioner for setting
aside exparte order is rejected.
3. Heard, Shri Lakhotia, learned counsel for petitioner and
Shri Kasliwal, learned counsel for the respondent Nos. 1 & 2/
original plaintiffs. Shri Kasliwal learned counsel supports the
order and submits that the application is vague as no reasons are
given for setting aside ex-parte order. The petitioner was served
on 08-11-2012, the ex-parte order was passed on 06-02-2013. It is
only with an intention to delay the proceedings the petitioner
remained absent. No fault can be found in the order passed by
the Trial Court.

3 1603.2013 WP
4. The suit is still pending, the petitioner has right to appear
and prosecute the suit, from the stage he has appeared. The
petitioner is required to file written statement and for that
purpose petitioner is required to file an application for setting
aside the ex-parte order.
5. As the suit is still pending and has not proceeded further,
no prejudice would be caused to the plaintiffs, if the petitioner is
allowed to participate in the proceedings and file written
statement / say and contest the matter. However, the petitioner
also deserves to be mulct with cost.
6. In the result, I pass the following order.
ORDER
1] The impugned order is quashed and set aside,
and application Exhibit 22 is allowed on condition
that the petitioner pays cost of Rs. 5,000/- (Rs. Five
thousand only) to the plaintiffs by 25-06-2013.

4 1603.2013 WP
2] The petitioner shall also file written statement
on before 25-06-2013.
3] Rule is made absolute in above terms.
