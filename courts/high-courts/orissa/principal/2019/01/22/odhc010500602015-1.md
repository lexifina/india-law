# High Court of Orissa, CONTC/611/2015, 2019-01-22

05. 22.01.2019 Heard Mr. K.K. Pahil, learned counsel for the
petitioner.
Though the petitioner undertakes to file
amendment application, till date the same has not been
filed. It appears that the application does not contain
the order alleged to have been violated.
Therefore, in course of hearing, learned counsel
for the petitioner has made a prayer to withdraw the
contempt application with liberty to file a better
application with better particular.
Prayer is allowed.
The contempt application stands disposed of as
withdrawn with the liberty aforesaid.
