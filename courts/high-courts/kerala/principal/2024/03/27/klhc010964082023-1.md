JUDGMENT
This writ petition is filed seeking a direction to the third
respondent to issue a licence to the petitioner to run a cattle farm in
the subject property.
Learned counsel for the third respondent submits that no
application has been filed for the above purpose and what has been
filed is an application for a building permit, which was rejected as per
Ext. P4. No reliefs can be granted as there is no proper application by
the petitioner for the licence claimed. That apart, if the grievance is
regarding the rejection of the application for a building permit the
same has to be separately challenged. No reliefs can be granted in this
writ petition and the same is accordingly dismissed.
