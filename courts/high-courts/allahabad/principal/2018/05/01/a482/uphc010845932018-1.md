# Allahabad High Court, A482/15093/2018, 2018-05-01

Court No. - 53
Case :- APPLICATION U/S 482 No. - 15093 of 2018
Applicant :- Sukhraj Patel And Another
Opposite Party :- State Of U.P. And Another
Counsel for Applicant :- Santosh Dwivedi
Counsel for Opposite Party :- G.A.
Hon'ble J.J. Munir,J.
This is a second application for the same applicant, the first
application being Application (under Section 482 Cr.P.C.)
No.5502 of 2018.
A second application on the same cause of action with no
change in a background of facts where there is no fundamental
change to the cause of action is not maintainable.
This applicant is, accordingly, dismissed as not maintainable.
