04.08.2026
Order No.01
1. This matter is taken up through hybrid mode.
2. Learned counsel appearing for the petitioner produced
notification dated 01.08.2026 showing extension of the benefit of
promotion in favour of the petitioner w.e.f. 16.07.2021. It is, however,
submitted that necessary benefits has not yet been released in favour of
the petitioner.
3. Since the order in question has already been complied with by
extending the benefits of promotion, this contempt petition is disposed
of.
4. It is open for the petitioner to file an appropriate application
for release of benefits, if any.
5. With the aforesaid liberty, this contempt petition stands
disposed of.
