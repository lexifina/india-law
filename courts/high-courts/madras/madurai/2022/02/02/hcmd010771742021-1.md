ORDER
This petition is filed by the wife seeking transfer of the
petition in H.M.O.P.No.108 of 2020 filed by the husband from the
file of the learned II- Additional Subordinate Court, Coimbatore to
the file of Family Court, Madurai.
2. It is informed by the learned counsel for the petitioner
that the petitioner has been set ex-parte and a petition for setting
aside the ex-parte order is coming up before the learned II-Additional Subordinate Judge, Coimbatore tomorrow (03.02.2022).
3. Learned counsel for the respondent/husband assures this
Court that the respondent would be giving no objection for the order
being set aside and on instructions, he would submit that the
respondent has no objection to the transfer being ordered.
4. In the light of the above, this Court is inclined to order
transfer. Therefore, after the ex-parte order is set aside,
H.M.O.P.No.108 of 2020 pending on the file of the learned II-Additional Subordinate Court, Coimbatore shall be withdrawn and
transferred to the file of the Family Court, Madurai.
