# High Court for the State of Telangana, CC/728/2019, 2019-07-26

THE HON’BLE SRI JUSTI CE SANJAY KUMAR
CONTEMPT CASE No.728 of 2019
ORDER:
The respondent is present in person.
2. This contempt case was instituted alleging wilful disobedience to
the order dated 02.01.2019 passed in W.P.No.47191 of 2018.
3. However, Sri M.Satish Kumar, learned counsel for the petitioner,
states that the order has since been complied with.
4. Recording the said statement, the contempt case is closed. No
order as to costs.
 _______________________
 SANJAY KUMAR, J
