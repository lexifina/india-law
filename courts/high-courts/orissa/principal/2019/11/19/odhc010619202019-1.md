# High Court of Orissa, CMP/1223/2019, 2019-11-19

3 19.11.2019 Heard Sri Mishra, learned counsel for the petitioner.
 This writ petition involves allowing an application for
substitution along with condonation of delay and setting
aside abatement while rejecting the application under
Order 22, Rule 3 of the Code of Civil Procedure at the
instance of the defendants.
 For the reason assigned therein and the application
having been allowed but subject to cost, further there
being no prejudice to the defendants in facing litigation,
this Court finds no infirmity in the impugned order
required to be interfered with. Consequently, the C.M.P.
stands dismissed.
 If any defect is there in the substitution, it will be open
to the defendants to raise such objection taking
appropriate steps.
