# High Court of Himachal Pradesh, CWP/2746/2010, 2019-08-28

CWP No.2746 of 2010
28.8.2019 Present: Mr. Arjun K. Lall, Advocate, for the petitioner.
Mr. Kulwant Singh Katoch, Advocate, for the
respondents.
CMP No.8343 of 2019
By way of this application, a prayer has been
made for correction of the typographical error in order dated
20.05.2019, wherein it is not reflected that after hearing the
case for some time, the same was ordered to be listed for
21.06.2019. This factual position is not disputed and has not
been challenged by learned counsel for the respondent.
Accordingly, this application is allowed by modifying the
order dated 20.05.2019 to the effect that the said order shall
henceforth reads as under:-
“Heard for sometime. As the Court time is over,
list for continuation on 21.05.2019”.
Copy dasti.
 (Ajay Mohan Goel)
