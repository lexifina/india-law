The Petitioner moved this application u.o.6 rule 17 of
the Code of Civil Procedure to amend the written statement ,when
the matter was fixed for cross examination. The learned Judge
considering the fact that by this amendment the defendant /
tenant wants to convert the same in to standard rent application
as contemplated in Maharashtra Rent Control Act . Admittedly
there is procedure available to file such application separately . In
view of this I see there is no reason to interfere with the
order.However,it is made clear that the liberty is always available
to the petitioner /tenant to file such application for fixation of
standard rent. In view of this the petition is dismissed.
(Anoop V.Mohta,J.)
