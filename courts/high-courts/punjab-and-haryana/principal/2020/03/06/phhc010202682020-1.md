CRM-8734-2020
The applicant/petitioner, whose application for grant of bail
stands adjourned to 14.7.2020, has filed this application seeking permission
to withdraw the main case.
In view of the reasons mentioned in the application, the same is
allowed and the main case which is fixed for 14.7.2020 is preponed. The
same is taken on board today.
In view of the specific prayer made in the application for
withdrawal of the main case i.e. CRM-M-6697 of 2020, the main case itself
is dismissed as withdrawn.
