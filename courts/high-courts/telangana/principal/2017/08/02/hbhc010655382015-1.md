# High Court for the State of Telangana, WP/21223/2015, 2017-08-02

THE HONíBLE SRI JUSTICE CHALLA KODANDA RAM
WRIT PETITION No.21223 OF 2015
ORDER:
 Learned counsel for the petitioner seeks permission of this Court
to withdraw the writ petition giving liberty to the petitioner to file a fresh
writ petition, if so desires.
 Permission is granted.
 Accordingly, the writ petition is dismissed as withdrawn giving
liberty to the petitioner to file a fresh writ petition, if so desires.
Miscellaneous petitions, if any pending in the writ petition, shall also
stand closed. No order as to costs.
