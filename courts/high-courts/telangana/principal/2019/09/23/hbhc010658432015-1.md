# High Court for the State of Telangana, CRLRC/976/2015, 2019-09-23

THE HONíBLE SRI JUSTICE P.KESHAVA RAO
CRIMINAL REVISION CASE NO.976 OF 2015
ORDER:
Mr. V. Ravi Kiran Rao, learned counsel for the petitioner,
seeks permission to withdraw the Criminal Revision Case with
liberty to file an appropriate application.
Permission is accorded.
Accordingly, the Criminal Revision Case is dismissed as
withdrawn giving liberty to the petitioner to file an application
before the appropriate Court.
Miscellaneous applications, if any, pending shall stand
dismissed.
