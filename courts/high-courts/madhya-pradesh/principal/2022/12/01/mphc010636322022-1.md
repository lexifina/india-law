ORDER
This is second application under Section 439 of the Code of Criminal
Procedure for grant of bail to the applicant.
Earlier application was dismissed on merits vide order dated 01.08.2022
passed in MCRC No.33946/2022 with liberty to file repeat application after six
months if trial is not concluded within six months.
Applicant has filed repeat application before lapse of six months. It is not
case of applicant that there is delay in trial. Repeat application has been filed on
ground that independent seizure witnesses have turned hostile and other
