ORDER
The accused in C.C.No.334/2009 on the file of
Judicial First Class Magistrate's Court-II,
Mavelikara filed this petition under Section 482 of
Code of Criminal Procedure for a direction to the
learned Magistrate to dispose the case within a
time frame contending that the case is not being
disposed.
2. A report was called for from Judicial First
Class Magistrate-II, Mavelikara stating the minimum
time required for disposing the case. Learned
Magistrate submitted a report stating that he will
dispose the case before 30.11.2010.
Petition is disposed directing Judicial First
Class Magistrate-II, Mavelikara to dispose C.C.No.
334/2009 before 30.11.2010.
