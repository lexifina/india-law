# High Court of Madhya Pradesh, MCRC/12614/2016, 2016-08-08

MCRC-12614-2016
(RITESH DAHERIYA Vs THE STATE OF MADHYA PRADESH)
08-08-2016
Shri Satyam Agrawal, learned counsel for the applicant.
Shri Y. Dwivedi, learned P.L. for the State.
Learned counsel for the applicant prays for withdrawal
of the instant bail application u/s 438 of the Cr.P.C.
Prayer allowed.
However, the applicant has given the liberty of moving
an appropriate application before the learned Court
below and if such an application is moved, the learned
Court below is requested to deal with it expeditiously
and if possible on the same day on which it is filed.
The instant bail application u/s 438 of the Cr.P.C. stands
dismissed with the aforesaid liberty.
C.C. as per rules.
(ATUL SREEDHARAN)
JUDGE
N.Mohan
