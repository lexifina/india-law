BEFORE
HON’BLE MR. JUSTICE T.NK SINGH
Record shows that this writ petition was dismissed for default vide order of thi
s court, dated 09.10.2011; later on restored this writ petition to file. Again o
n 02.01.2007 the writ petition was dismissed for non prosecution.
Earlier order shows that in a number of occasions none appeared
for the petitioner without showing any cause. Today also, when the case is calle
d out for hearing, none appeared for the petitioner without showing any cause. A
ccordingly, taking into consideration of earlier orders of this court, this writ
petition is dismissed for non prosecution.
