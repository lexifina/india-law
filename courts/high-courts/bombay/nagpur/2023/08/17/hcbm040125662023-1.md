of the Code of Criminal Procedure.

hearing the learned counsel for the applicant to some extent,
when I have shown my disinclination to grant bail, learned
counsel for the applicant seeks permission to withdraw the
application with liberty to file afresh if there is no progress in
the trial within six months.
3. Permission granted. The application is dismissed as
withdrawn with liberty to file afresh if there is no progress in
the trial within six months. The trial Court shall expedite the
trial.
