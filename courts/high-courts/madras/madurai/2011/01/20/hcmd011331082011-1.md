ORDER
This petition has been filed to direct the respondent police to
proceed with the investigation besides apprehending accused and file
final report with respect to Crime No.869 of 2009 on the file of the
respondent police within a time frame as fixed by this Court.
2. Heard Mr.Hall Mark Associates, learned Counsel for the petitioner
and Mr.L.Murugan, learned Government Advocate (Crl.Side) appearing for
state.
3. The case in Cr.No.869 of 2009 obviously is pertaining to the year
of 2010 and so far no final report has been filed. Hence, the following
direction is issued:
The respondent police is directed to complete the investigation in
Cr.No.869 of 2010 on the file of the respondent and to file final report
within four months from the date of receipt of a copy of this order and
report compliance.
4. With the above direction, this petition is ordered.
