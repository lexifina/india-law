ORDER
The present contempt petition has been filed alleging the violation of the
order of this Court dated 03.03.2025, made in WP(MD)No.5614 of 2025,
wherein this Court has passed an order directing the first respondent to consider
the petitioner's passport application and pass orders on merits.
2. In compliance with the order of this Court, the first respondent has
passed an order on 29.12.2025 rejecting the request of the petitioner.
3.Recording the same, this contempt petition is closed with liberty to the
contempt petitioner to challenge the order dated 29.12.2025, if she is so
advised.
