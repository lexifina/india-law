# High Court of Tripura, AB/78/2014, 2014-06-16

Case No :AB 0000078/2014
Party Name : PERA MIAH Vs THE STATE OF TRIPURA
THE HONBLE MR JUSTICE U. B. SAHA
When the instant bail application is taken up for hearing, Mr. RC Debnath, learned Addl. PP
for the State produced the Case Diary in terms of the earlier order of this Court. At this
stage, Mr. Bhattacharjee, learned counsel for the petitioner wants to withdraw the instant
bail application. Prayer for withdrawal is allowed. In view of the above, the instant bail
application is disposed of as withdrawn. Return the Case Diary.
