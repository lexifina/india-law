 ORDER
This Criminal Original Petition has been filed praying to
direct the respondent police to make proper investigations in
the Crime Number 727 of 2014 on the file of respondent Police
and to file a final report under Section 173 within a time frame
fixed by this Court.
ds
2. Heard the learned counsel for the petitioner and the
learned Additional Public Prosecutor appearing for the first
respondent.
3. The learned Additional Public Prosecutor appearing for
the first respondent submitted that a case in Crime No. 727 of
2014 has been registered by the first respondent Police.
https://hcservices.ecourts.gov.in/hcservices/

4. In view of the above, the Criminal Original Petition is
disposed of with a direction to the first respondent Police to
complete the investigation and file a final report as
expeditiously as possible
