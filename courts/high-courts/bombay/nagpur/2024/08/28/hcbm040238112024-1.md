1. This is an application for condonation of delay
caused for filing revision against the order of Registrar
(Judicial) dated 28.1.2020.
2. Perused the application.
3. Heard learned Advocate of the applicants.
4. Considering the peculiar set of facts, the
application deserves to be allowed in the interest of
justice.
5. The application is allowed.
6. The delay of 932 days caused in filing revision
application is condoned.
7. The application is disposed of.
