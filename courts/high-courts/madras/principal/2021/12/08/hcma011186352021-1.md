# Madras High Court, A/4502/2021, 2021-12-08

A.No.4502 of 2021
in C.S.No.506 of 2018
ABDUL QUDDHOSE,J.
This application has been filed to set aside the ex-parte order dated
31.08.2020 passed against the applicant/second defendant.
2. Along with this application, the written statement has also been
filed by the second defendant.
3. Learned counsel for the respondents 1 and 2/plaintiffs has not
raised any serious objection for allowing this application. The said
statement is recorded.
4. This Court is satisfied with the reasons contained in the affidavit
filed in support of this application.
5. Accordingly, this application is allowed as prayed for and the
ex-parte order dated 31.08.2020 passed against the second defendant is set
aside by this Court and the written statement is taken on record.
