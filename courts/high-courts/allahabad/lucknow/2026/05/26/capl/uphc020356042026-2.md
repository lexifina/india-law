# Allahabad High Court, CAPL/1852/2026, 2026-05-26

HIGH COURT OF JUDICATURE AT ALLAHABAD
LUCKNOW
CONTEMPT APPLICATION (CIVIL) No. - 1852 of 2026
Court No. - 7
HON'BLE SAURABH LAVANIA, J.
1. Affidavit of compliance sworn by Ms. Sarneet Kaur Broca, filed today by Sri G.K.
Singh, learned State Counsel before this Court, is taken on record.
2. Based upon the affidavit it is stated that application for issuance of arms license
which was directed to be decided, has been decided vide order dated 15.05.2026
against the applicant and order of Writ Court has been complied with and being so the
present contempt application is liable to be dismissed.
3. Accordingly, the present application is dismissed as having become infructuous,
with liberty to the applicant to impeach the order dated 15.05.2026 before appropriate
Forum/court.
4. Notice(s), if any, stands discharged.
