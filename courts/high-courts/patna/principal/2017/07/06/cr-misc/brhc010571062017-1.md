ORAL ORDER
2. 06-07-2017 Heard learned counsel for the petitioner and
the learned A.P.P. for the State.
Petitioner, in the present case, is seeking
regular bail in connection with Kasma P.S. Case No.
29/2016 registered for the offence punishable under
Sections 147, 148, 149, 341, 386, 387, 435, 427, 353, 504,
506 of the Indian Penal Code and Section 17 of C.L.A.
Act.
Learned counsel for the petitioner submits
that as per the First Information Report there is a vague
and omnibus allegation against some unknown persons
who allegedly raised the slogans and set the mixture
machine on fire. Learned counsel however submits that
