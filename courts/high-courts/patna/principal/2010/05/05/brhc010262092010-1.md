2. 05.05.2010 Heard learned counsel for the
petitioner and learned counsel for the State.
This application has been filed for
modification of the order dated 23.07.2009
passed in C.W.J.C.NO.15070 of 2007 by which
petitioner was given liberty to file an appeal
before the Appellate Authority.
Learned counsel for the petitioner
submits that the petitioner has filed an appeal
within the stipulated time but addressed the

- 2 -
same to the District Superintendent of
Education, Patna and, therefore, the appellate
authority is not entertaining the appeal.
There is no requirement of the
modification of the order dated 23.07.2009.
Petitioner will be at liberty to file another
memorandum of appeal before the Appellate
Authority, pursuant to the said order of this
Court, within two weeks from today.
This modification application is
disposed of.
