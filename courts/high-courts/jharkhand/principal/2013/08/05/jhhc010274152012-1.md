For the Petitioners: Mr.Rajesh Kumar Mahtha
For the State :A.P.P
 4/ 5.8.13. The order dated 22.6.2012 passed in Complaint Case no.483 of 2011
under which cognizance of the offence punishable under Sections 379, 323,
504/34 of the Indian Penal Code has been taken is being sought to be quashed
on the ground that for the same set of allegation, an FIR had been lodged but
that FIR has been lodged after the complaint case was lodged and as such,
ground taken never appears to be tenable for quashing of the order taking
cognizance.
However, the petitioner would have liberty to file proper
application before an appropriate stage.
With this observation, this application stands disposed of.

 (R.R.Prasad, J.)
