# Madras High Court, Arb Appln/333/2024, 2024-07-08

Arb.Appln.No.333 of 2024
& A.No.8973 of 2019
KRISHNAN RAMASAMY, J.
This application has been filed to raise
the order of attachment dated 04.09.2020 made
in A.No.8973 of 2019 attaching the immovable
property morefully described in the schedule to
the Judges Summons.
2. The learned counsel for the applicant
would submit that this matter has been amicably
settled between the parties. Hence, he requests
this Court to allow this application.
3. Considering the above submission and
the affidavit filed in support of this application,
this Court is satisfied and is inclined to allow
this application.
4. Accordingly, this Application is
ordered as prayed for.
