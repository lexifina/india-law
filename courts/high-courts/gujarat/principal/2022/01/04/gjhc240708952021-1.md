ORAL ORDER
Learned advocate for the applicants seeks
permission to withdraw this application with a view
to file an application under Section 438 of the Code
of Criminal Procedure, 1973 (“the Code” for short).
Permission, as prayed for, is granted. The
application stands disposed of as withdrawn. It is
clarified that this Court has not examined the merits
of the case of the applicants and, therefore, as and
when the application under Section 438 of the Code is
filed, the same shall be examined on its own merits.
