# High Court of Jharkhand, A.B.A./2214/2024, 2024-05-14

IN THE HIGH COURT OF JHARKHAND AT RANCHI
 A.B.A. No. 2214 of 2024
Mukesh Yadav @ Mukesh Kumar … Petitioner
 -Versus-The State of Jharkhand … Opposite Party
-----
CORAM: HON’BLE MR. JUSTICE SANJAY KUMAR DWIVEDI
-----
For the Petitioner : Mr. Awanish Ranjan Mishra, Advocate
For the State : Mr. Prabir Kumar Chatterjee, Spl.P.P.
-----
03/14.05.2024 Heard learned counsel for the petitioner and learned counsel for
the State.
2. The matter relates to Complaint (F) Case No.1838/2023, pending in
the Court of the learned S.D.J.M., Hazaribag.
3. A preliminary objection has been raised by Mr. Chatterjee, learned
counsel for the State that the prosecution report has not been filed as yet
and that has come in the order of the learned Sessions Judge. He further
submits that in view of that, apprehension is not there and only against the
complaint case, the present application has been filed.
4. Prosecution report has not been submitted as yet and in view of that,
Mr. Mishra, learned counsel for the petitioner seeks permission to withdraw
this application with liberty to file a fresh application if apprehension is
there.
5. Learned counsel for the State has got no objection.
6. Accordingly, this application is dismissed as withdrawn with the
aforesaid liberty.
 (Sanjay Kumar Dwivedi, J.)
