# Allahabad High Court, WRIC/3000084/1994, 2022-02-04

Court No. - 8
Case :- WRIT - C No. - 3000084 of 1994
Petitioner :- Ram Surat
Respondent :- State Of U.P. Thru Collector And Others
Counsel for Petitioner :- Umesh Kr. Srivastava
Counsel for Respondent :- C.S.C.
Hon'ble Dinesh Kumar Singh,J.
1. No one has put in appearance on behalf of the petitioner to
press this petition. However, Sri J.P. Maurya, learned Additional
Chief Standing Counsel is present.
2. The present writ petition has been filed in the year 1994 for
quashing of the order dated 11.7.1994 passed by the Chief
Revenue Officer/Prescribed Authority, Bahraich under the
provisions of the U.P. Imposition of Ceiling on Land Holdings
Act, 1960. The impugned order against which the writ petition
has been filed, on translation would read as under:-
" Heard learned counsel for both the parties and perused the
annexures.
From perusal of the case file, it is evident that original file of Case
No.161/146/588 got disappeared. Necessary action is being taken
against the concerned official/employee. The order has already been
passed for reconstructing the original file and till the original file is
reconstructed, no interim order can be passed.
Therefore, the application of the applicants dated 24.6.1994 is
rejected."
3. The prescribed authority had thus, only postponed the
application till reconstruction of the case file. This Court is not
able to comprehend that how this order prejudiced the petitioner
to come before this Court to file the present writ petition.
4. This Court vide interim order dated 7.1.1997 stayed the
proceedings for allotment of the land belonging to the
petitioner, which was declared surplus by the order of the
prescribed authority dated 8.6.1976.

5. In all likelihood, this writ petition would have been rendered
infructuous in view of the fact that original file would have
been reconstructed and before the interim order was passed by
this Court, the prescribed authority would have decided the
case. In case the case has not yet been decided, the prescribed
authority is directed to proceed with the matter and conclude
the same expeditiously within a period of four months.
6. Writ petition is accordingly dismissed.
7. Let a copy of this order be forwarded by Sri J.P. Maurya,
learned Additional Chief Standing Counsel to the prescribed
authority forthwith for compliance.
.
(Dinesh Kumar Singh, J.)
