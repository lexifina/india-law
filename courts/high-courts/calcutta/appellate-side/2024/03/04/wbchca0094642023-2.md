# Calcutta High Court, CRR/723/2023, 2024-03-04

M/L71
04.03.2024
Bpg.
 C.R.R.723 of 2023
In Re: An application under Section 482 read with Section 401 of the
Code of Criminal Procedure, 1973;
 Santanu Das
 Versus
 The State of West Bengal and another
 Mr. Imran Ali
 Ms. Debjani Sahu.
 ...for the State.
The revisional application appeared on 19th September,
2023 when none represented on behalf of the petitioner.
Ms. Debjani Sahu, learned advocate appears on behalf of
the State and submits a status report. Let the same be kept with
the record.
The revisional application was also called on 1st March,
2024 and today when the revisional application has been called on,
both dates none represented the petitioner.
Having considered the issues so canvassed in the present
revisional application which was in respect of a challenge to the
prayer for discharge which was rejected by the learned Judicial
Magistrate, 1st Court, Raghunathpur, Purulia in connection with
Raghunathpur Women Police Station Case No.25 of 2021 dated
27.12.2021, I am of the view that at this belated stage there cannot
be any interference.
Report submitted by the State reflects that date for
consideration of charges were fixed on 12th December, 2023. In case
the same has not yet been completed, the learned Magistrate is

2
directed to complete the said process and progress with the trial of
the case. Petitioner would be at liberty to canvass all the points at
the appropriate stage of the trial.
With the aforesaid observations, CRR 723 of 2023 is
disposed of.
Pending connected application, if any, is consequently
disposed of.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
 (Tirthankar Ghosh, J.)
