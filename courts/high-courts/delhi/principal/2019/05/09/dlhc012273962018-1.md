% 09.05.2019
 This petition challenges the order dated 09.08.2018 whereby an
application under Order VII Rule 11 CPC filed by the petitioner was
dismissed on the ground only the plaint need to be considered for
agitating an application under Order VII Rule 11 CPC. There is no
illegality in the order dated 09.08.2018 and as such the petition stands
dismissed. This order shall not cause any prejudice to the petitioner to
pursue his cause qua an application under Order XII Rule 6 CPC, if,
filed.
 Pending applications, if any, also stand disposed of.
 YOGESH KHANNA, J.
