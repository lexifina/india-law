# Allahabad High Court, CMRA/401/2023, 2023-11-16

Neutral Citation No. - 2023:AHC:217426
Court No. - 87
Case :- CIVIL MISC REVIEW APPLICATION No. - 401 of 2023
Applicant :- Smt. Shivani Tomar
Opposite Party :- State Of U.P. And 3 Others
Counsel for Applicant :- Subhash Chand Kanaujia
Counsel for Opposite Party :- C.S.C.,Sikandar Khan
Hon'ble Neeraj Tiwari,J.
1. Heard Sri Subhash Chand Kanaujia, learned counsel for the
applicant and Sri Uma Shanker Pandey, learned standing counsel
for State.
2. After some argument, learned counsel for the applicant
submitted that he does not want to press this review application
and the same may be dismissed as not pressed for which learned
standing counsel has no objection.
3. Accordingly, review application is dismissed as not pressed.
4. No further liberty is given to the applicant to file fresh review
application for the same cause of action.
