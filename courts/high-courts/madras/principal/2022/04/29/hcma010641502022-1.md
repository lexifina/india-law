P.VELMURUGAN, J.
This application has been filed to set aside the exparte order dated
25.03.2022 passed against the first defendant in C.S.No. 388 of 2020.
2. Learned counsel for the applicant/first defendant would submit
that the written statement of the first defendant was submitted on
24.03.2022 along with an application to condone the delay of 386 days in
filing the written statement. He would also submit that now the Registry has
returned the written statement as already exparte order has been passed.
3. Heard the learned counsel and perused the materials available on
record.
4. The suit summons served on the first defendant on 20.01.2021.
Till 24.03.2022, the applicant/first defendant has not chosen to file the
written statement, though no stay for filing the written statement has been
granted in the O.S.A filed by them. Therefore, under this circumstances, the
contention raised by the learned counsel for the applicant is not acceptable.
Since the written statement has not been filed within the stipulated time
mentioned in the suit summons, the Registry has returned the written
