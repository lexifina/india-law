ORAL ORDER
2 04-07-2018 Learned counsel for the petitioner submits that in the
order dated 04.05.2018 the registration number of the vehicle in
question has been wrongly described as BR-30M/4117 whereas it
should have been vehicle Registration Number BR-30M/4127.
The error has occurred due to the typographical error with respect
to the registration number in the main writ application.
Considering the submissions, let the order dated
04.05.2018 passed in Cr.W.J.C. No. 983 of 2018 be read in respect
of the correct vehicle Registration Number BR-30M/4127. Rest of

Patna High Court MJC No.2006 of 2018 (2) dt.04-07-2018
the order shall remain intact.
Application stands disposed of.
