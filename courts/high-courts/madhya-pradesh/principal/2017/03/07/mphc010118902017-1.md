# High Court of Madhya Pradesh, MCC/691/2017, 2017-03-07

1
M.C.C. No.691/2017
 7.3.2017
Shri Dharmendra Soni, counsel for the applicant.
Shri P. Yadav, Govt. Advocate for the respondents/State.
Heard counsel for the parties on I.A. No.3379/2017 –
application seeking condonation of delay.
This application has been filed for restoration of W.P.
No.9871/2016, which has been dismissed for want of
prosecution.
There is some delay in filing of the application. I.A.
No.3379/2017 has been filed seeking condonation of delay.
The application is supported by an affidavit of the counsel Shri
Dharmendra Soni and finding no reason to disbelieve the same,
the application is allowed. The delay in filing this application
is condoned.
Hearing counsel for the parties on M.C.C.
Keeping in view the reasons indicated in the application
and finding it to be bona fide, the application is allowed. W.P.
No.9871/2016 is restored to its file to the original number and
it be placed for orders before the appropriate Bench.
With the aforesaid, the application stands allowed and
disposed.
 (Rajendra Menon) (Smt. Anjuli Palo)
 Acting Chief Justice Judge
Anchal
