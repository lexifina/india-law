ORDER
This Criminal Original Petition has been filed to direct
the respondent police to file the final report in connection
with the Crime No.96/2019 registered for offences under
Section 408, 420 and 506(ii) IPC on the file of the respondent
police.
2.Heard the learned counsel appearing for the petitioner
and the learned Additional Public Prosecutor appearing for the
respondent.
3.The learned counsel appearing for the petitioner
submitted that though the respondent has registered a case in
the above said crime number on 24.01.2019, no final report is
filed till date.
4.The learned Additional Public Prosecutor appearing for
the respondent submitted that the respondent police may be
permitted to file a final report as early as possible.
5.In view of the above, the respondent police is
https://hcservices.ecourts.gov.in/hcservices/

directed to file a final report as early as possible.
6.With the above direction, this Criminal Original
Petition is disposed of.
