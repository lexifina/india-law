# Allahabad High Court, BAIL/8557/2023, 2025-05-09

Court No. - 45
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 8557 of 2023
Applicant :- Annu @ Anil Kumar Yadav
Opposite Party :- State of U.P.
Counsel for Applicant :- Ashwarya Singh,Kamla Singh
Counsel for Opposite Party :- Anurag Shukla,G.A.
Hon'ble Saumitra Dayal Singh,J.
1. This is a specially constituted bench to hear the second bail
application. The first bail application was rejected, vide order
dated 10.01.2020. The trial is of the year 2017.
2. The second bail application was filed in February, 2023. The
order sheet reveals it was listed on only two occasions on
23.05.2023 and 05.06.2023.
3. None has appeared to press this application. Also, there is no
listing application on record to indicate that the application
survives.
4. Accordingly, the present application is dismissed for want of
prosecution.
5. If the trial survives, the applicant is at liberty to file a fresh
application, which may be listed before this bench at the earliest
date available.
Order Date :- 9.5.2025
