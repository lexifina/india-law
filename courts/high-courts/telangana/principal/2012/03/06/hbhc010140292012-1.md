# High Court for the State of Telangana, CRLP/2449/2012, 2012-03-06

THE HON'BLE SRI JUSTICE K.C.BHANU
CRIMINAL PETITION NO.2449 OF 2012
ORDER:
 Learned counsel for the petitioners seeks permission to
withdraw the Criminal Petition with liberty to file application for
dispensing with the presence of the petitioners before the learned
Sessions Judge.
2. Permission is accorded.
3. Accordingly, the Criminal Petition is dismissed as withdrawn
with liberty to file application for dispensing with the presence of the
petitioners. On such application being filed by the petitioners, the
learned Sessions Judge shall consider the same in accordance with
law.
4. Miscellaneous Petitions, if any, filed in this Criminal Petition shall
stand closed.
 ______________________
JUSTICE K.C.BHANU
MARCH 06, 2012
