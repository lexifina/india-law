4. 18.5.2009. Heard learned counsel for the petitioners and learned
counsel for the opposite party no.2.
With the allegations made in the complaint, the basic
offence as alleged therein, prima facie, case is made out. If that is so then
there is nothing wrong with the order taking cognizance. Submission of
learned counsel for the petitioners is that there is no specific allegation
against petitioner no. 1, father-in-law, whatever is alleged is against
petitioner no.2, mother-in-law or the husband.
The Court is not satisfied with the said submission because
the complaint has to be read in its entirety and it cannot be said that there
is nothing alleged whatsoever against the petitioner no.1 though
something more is alleged against petitioner no.2. This Court, therefore, is
not satisfied that a case for interference under Section 482 Code of
Criminal Procedure is made out.
The application stands dismissed.
