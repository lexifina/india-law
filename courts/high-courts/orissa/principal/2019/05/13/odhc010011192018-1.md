# High Court of Orissa, WP(C)/4337/2018, 2019-05-13

9 13.05.2019 Heard learned counsel appearing for the
parties.
 This Court finds the writ petition involves
rejection of an application under Order 18, Rule
2 of the Code of Civil Procedure involving an
election petition.
 Considering the rival contention and going
through the allegation in the election petition so
also the claim made in the application under
Order 18, Rule 2 of the Code of Civil
Procedure, this Court looking to the document
at Annexure-4 sought to be introduced by way
of affidavit, observes that for the little disclosure
made in Annexure-4, this Court finds such
document has no relevancy so as to the
allegation involving the election dispute is
concerned. Perusing the impugned order, this
Court finds there is no infirmity in the impugned
order requiring of this Court interference in the
same.
 Consequently, the writ petition stands
dismissed.
