ORDER
 This is the second application filed by the applicant under Section 439
of the Code of Criminal Procedure for grant of regular bail relating to FIR
No.230/2023 registered at Police Station-Baheriya, District-Sagar (MP) for the
offence under Section 34(2) of M.P. Excise Act.
2. Counsel appearing for applicant submitted that earlier bail application
filed by applicant was dismissed as withdrawn with liberty to file repeat
application after examination of independent witnesses. It is submitted that
charge-sheet in the case is yet to be filed. Applicant is in jail since 23.06.2023.

JUDGE
In these circumstances, bail application filed by applicant is dismissed.
3. Learned Government Advocate appearing for the State opposed the
application for grant of bail. It is submitted that liberty was granted to applicant
to file repeat application after examination of independent witnesses.
Independent witnesses are yet to be examined. Applicant is having criminal
antecedents. In these circumstances, application be dismissed.
4. Heard the counsel for the parties.
5. Considering aforesaid circumstances, bail application filed by
applicant is dismissed.
6. Applicant will have the same liberty which was granted to him vide
order dated 04.07.2023 in M.Cr.C. No.28352/2023. Applicant is also at liberty
to file application before the trial Court for initiating proceedings under Section
299 of Cr.P.C.
