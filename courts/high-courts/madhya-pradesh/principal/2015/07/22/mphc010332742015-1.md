# High Court of Madhya Pradesh, MCC/1901/2015, 2015-07-22

MCC-1901-2015
(ROHNI PATEL Vs THE STATE OF MADHYA PRADESH)
22-07-2015
Shri Ankur Shrivastava, learned counsel for the applicant.
Shri Swapnil Ganguly, learned GA for respondents/State.
This application has been for restoration of Writ Petition
No.7133/2015 which was dismissed for non-prosecution on
10.7.2015.
Keeping in view the reasons indicated in the application which is
supported by the affidavit of counsel for the applicant and finding
the same to be bonafide, the application is allowed. Writ Petition
No.7133/2015 is restored to its original number.
This application is allowed and disposed off.
(RAJENDRA MENON)
JUDGE
(SUSHIL KUMAR GUPTA)
JUDGE
