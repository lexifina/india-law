Hon'ble Shri Justice Ram Prasanna Sharma
Order On Board
02/12/2019
1. Heard on I.A. No. 01/2019, which is an application for
condonation of delay in filing the instant MCC.
2. For the reasons mentioned in the application, the same is
allowed and the delay of 363 days in filing the MCC is condoned.
3. Also heard on application under Order 41 Rule 21 of the Code of
Civil Procedure, 1908 for re-hearing on FA No. 19/2004 which
has been decided on 27.08.2018.
4. The main issue which is raised in the present appeal is that
appellants have not been provided opportunity and case is
decided without issuing notices to them.
5. On perusal of record, it appears that applicants Narayan Singh
and Devendra Kumar Nayak both are served on 7th June, 2009.
When both are served with the summons it is not a case that
notice is not served to them, therefore, the application itself is
preferred on wrong notion which has no substance.
6. Accordingly, the application is dismissed at motion stage itself.
