Order
14/02/2024
Learned Public Prosecutor submits that after thorough
investigation, Police has already submitted the Final Report before
the competent court, wherein it has been mentioned that no case
is made out against the petitioner, therefore, in the subsequent
events, the present criminal miscellaneous bail application has
become infructuous.
However, liberty is granted to the petitioner to file an
appropriate application before the trial court or High Court, if any
occasion so arises.
Hence, the present criminal miscellaneous bail application is
hereby dismissed as having become infructuous.
