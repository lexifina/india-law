 O R D E R
This petition has been filed to quash the impugned First
Information Report registered in Crime No.493 of 2021, on the file
of the first respondent.
2. The petitioner is the accused in Crime No.493 of 2021, on
the file of the first respondent for the offences punishable under
Sections 109 and 309 I.P.C.
3. Mr.K.Sanjai Gandhi, learned Government Advocate (Crl.Side)
submitted that the investigation has been completed and the final
report was made ready and the same was presented before the learned
Judicial Magistrate-II, Madurai, but the learned judge has not taken
it on the file so far.
4.Since final report has been filed, this Criminal Original
Petition is disposed of, with a direction to the learned Judicial
Magistrate-II, Madurai to process the same as per rules, file a
Compliance report before the registry thereafter.
