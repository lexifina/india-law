HON'BLE MR. JUSTICE MANOJ KUMAR GARG
Order
27/11/2018
The instant misc. application has been moved for correction
in order dated 26.11.2018 passed in S.B. Crl. Misc. 2nd Bail
Application No. 11671/2018, whereby, while allowing the bail
application, the petitioner was ordered to be released on bail.
Learned counsel for the petitioner submits that inadvertently
in the order dated 26.11.2018 the name of Police Station has
wrongly been mentioned as “Naal” whereas, the correct name of
Police Station is “Sadar”. Therefore, necessary correction be made
in the order dated 26.11.2018.
In view of above, the present misc. application is allowed.
It is directed that in the order dated 26.11.2018, the name
of Police Station be read as “Sadar” instead of “Naal”. To that
extent, the order dated 26.11.2018 stands corrected.
(MANOJ KUMAR GARG)J.
