HON'BLE MR. JUSTICE SANJEEV PRAKASH SHARMA
Order
15/01/2020
This restoration application u/s 482 Cr.P.C has been moved
by the petitioner for recalling the order dated 14.8.2019 passed
by this court whereby the criminal misc. petition has been
dismissed on the ground of non prosecution.
It is a settled law that in criminal proceedings, there is no
provision for recalling the order.
 In view thereof, the restoration application is held to be not
maintainable. The same is accordingly dismissed. However, liberty
is granted to the petitioner to file fresh petition, if so required.
(SANJEEV PRAKASH SHARMA),J
