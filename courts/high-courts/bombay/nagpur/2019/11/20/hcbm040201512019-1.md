CORAM : MRS. SWAPNA JOSHI, J.
DATED : NOVEMBER 20, 2019.
The applicants have filed this application for condonation
of delay in filing criminal revision application.
Heard both the sides. Perused the application. On
perusal of the application, I am satisfied that the reason is
properly mentioned for condoning the delay and there is no
intentional delay as such to file the criminal revision application.
Hence the order.
The application is allowed. The delay is hereby condoned.
Criminal Application stands disposed of.
Criminal Application (APPP) No.1181/2019
The applicants have filed this application for grant of time
to file certified copy of order dated 2.3.2019.
For the reasons mentioned in the application, time of
three weeks’ is granted. Criminal Application stands disposed of.
