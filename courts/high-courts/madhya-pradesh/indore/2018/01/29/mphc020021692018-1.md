The petitioner before this Court has filed this present
writ petition being aggrieved by the 17/7/2017 whereby the
petitioner's application for grant of Arms Licence for non-prohibited bore pistol has been rejected.
Learned Counsel appearing for the petitioner submits
that the application has been rejected by a cryptic non-speaking order and identical order has already been set aside
by this Court by order dated 05.04.2013 passed in W.P. No.
8606/2011 in the matter of Kaushaldas Swami Vs. State of
M.P. And Another.
Learned counsel for the respondents though has
opposed the writ petition, but has not disputed that the case
is covered by the order passed in the matter of Kaushaldas
Swami (supra).

Resultantly, keeping in view the judgment delivered
in an identical case, Writ Petition deserves to be
allowed and is accordingly allowed. The impugned
order dated 2/01/2011 is hereby set aside. The State
Government is directed to pass a fresh speaking order
keeping in view the statutory provisions as contained
under the Arms Act 959 read with the Arms Rules, 962
within a period of 60 days from the date of receipt of
certified copy of this order."
In these circumstances, the impugned order dated
17.07.2017 is set aside since it is a non-speaking order, with
liberty to the petitioner to file a fresh application. If such an
application is filed by the petitioner, the same will be
considered by the competent authority in accordance with
law and is case if any adverse decision is taken, then a
reasoned speaking order will be passed on that application.
