PER COURT :-
1) This is an application for setting aside the order
passed by the Registrar, refusing registration of Letters
Patent Appeal as well as application seeking condonation of
delay.
2) Heard. For the reasons set out in the application,
the application deserves to be allowed and the same is
accordingly allowed. The order passed by the Registrar,
refusing registration of the LPA, as well as Civil
Application, is set aside. The delay occurred in presenting
the application is condoned.
3) Office to place this matter for admission in next
week, i.e. 19th March, 2015.
( P.R. BORA, J. ) ( R. M. BORDE, J. )
