# High Court of Madhya Pradesh, MCRC/51948/2019, 2019-12-16

(AKHIL KUMAR SRIVASTAVA)
JUDGE
The High Court Of Madhya PradeshThe High Court Of Madhya Pradesh
MCRC-51948-2019
(MOHIT MISHRA @ MAHENDRA KUMAR MISHRA Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 16-12-2019
Mr. Sanjay Kumar Patel, learned counsel with Mr. Sushil Kumar
Sharma for the applicant.
Mr. R.P.Singh, Panel Lawyer for the respondent-State.
This application has been filed for modification of name of the
applicant in the order dated 28.11.2019 passed in M.Cr.C.No.47202/2009
(Mahendra Kumar Mishra Vs. State of Madhya Pradesh).
In the cause title of the application M.Cr.C.No.47202/2019, the name
of the applicant is mentioned as Mahendra Kumar Mishra. It is submitted that
the applicant is also known as Mahendra Kumar Mishra, however, the name
of the applicant is Mohit Mishra but as in the order dated 28.11.2019, the
name of the applicant is mentioned as Mahendra Kumar Mishra, the CJM is
not releasing the applicant, therefore, this application for modification.
Keeping in view the aforesaid, the modification sought for is allowed.
In the order dated 28.11.2019 passed in M.Cr.C.No.47202/2019, name
of the applicant i.e. "Mohit Mishra @ Mahendra Kumar Mishra" be
read in place of Mahendra Kumar Mishra.
With the above modification, this petition stands allowed and disposed
of.
The order passed today shall be read conjointly with the order dated
28.11.2019 passed in M.Cr.C.No.47202/2019.
Let a copy of this order be retained in the file of
M.Cr.C.No.47202/2019.
