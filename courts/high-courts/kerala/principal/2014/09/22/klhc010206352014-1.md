 O R D E R
The petitioner has brought this petition under Section
482 of the Code of Criminal Procedure for getting some time to
file appropriate proceedings against an order passed by the trial
court under Section 451 of the Code of Criminal Procedure. It is
not known how this petition could be maintained under Section
482 of the Code of Criminal Procedure, and what orders can be
passed by this Court under Section 482 of the Code of Criminal
Procedure.
Anyway, now it is submitted by the learned counsel
that the petitioner has already obtained a copy, and he seeks
permission to withdraw this Criminal Miscellaneous Case. I find
that this Criminal Miscellaneous Case is not maintainable at all,
and it is accordingly dismissed.
 P.UBAID
