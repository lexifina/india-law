1. Heard learned counsel for applicant and learned APP for the
Respondent-State.
2. Learned counsel for the applicant submits that the applicant
is behind bar for more than four years, yet trial has not been
concluded. Learned counsel on instructions further submits that the
applicant be permitted to file a fresh bail application after six months
if trial is not concluded.
3. Considering the submission of learned counsel for applicant
Application is allowed to be withdrawn with aforesaid liberty.
4. Bail Application is dismissed and disposed off as withdrawn.
5. The applicant is permitted to file fresh bail application after
six months, if trial is not concluded.
