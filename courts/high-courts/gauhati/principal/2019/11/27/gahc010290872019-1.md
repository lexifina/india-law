ORDER
Date : 27-11-2019
By this interlocutory application, the applicant has sought for correction of police case no.
mentioned in AB No.4143/2019 wherein Hojai PS Case No.403/2019 has been mentioned in cause-title
instead of Daboka PS Case No.403/2019 which has been crept inadvertently as a result of which in
the order dated 20.11.2019, the same police station has been mentioned which needs to be rectified.
Having regard to the submission of learned counsel for both the parties and after going through
the bail application in A.B. No.4143/2019 and the order dated 20.11.2019, the prayer made in the
present application is hereby allowed.
The petitioner will correct the police case no. in the petition. Consequently, the order dated
20.11.2019 where Hojai PS Case No. 403/2019 has been mentioned, let now be read as Daboka PS
Case No.403/2019.
This order shall form part of the order dated 20.11.2019 passed in the connected AB
No.4143/2019.
IA stands disposed of.
