1] Heard learned counsel appearing for
the petitioner and the learned AGP for the
respondents.
2] Rule.
3] Learned AGP waives service of Rule
notices for the respondents.
4] Considering the limited controversy
involved in the petition, the same is taken up
for final disposal.
5] The Original Application preferred by
the petitioner has been rejected on the

 WP 1410/12
2
ground that the same is barred by limitation.
If the Tribunal was of the view that the
application was barred by limitation, the
Tribunal ought to have granted an
opportunity to the petitioner to file an
application for condonation of delay. The
learned counsel for the petitioner on
instructions states that the petitioner will file
an application for condonation of delay within
a period of four weeks from today.
6] We are of the view that an opportunity
deserves to be granted to the petitioner to file
an application for condonation of delay to
satisfy the Tribunal that a case for
condonation of delay was made out. Only on
this ground, we are setting aside the
impugned order.
7] Hence, we pass the following order:
[i] The impugned order dated 14.7.2011
is quashed and set aside and Original
Application No.427/2011 is restored to the file
of the Administrative Tribunal.
[ii] The Tribunal shall accept the

 WP 1410/12
3
application if made within a period of four
weeks from today. If the petitioner fails to
make an application for condonation of delay
within four weeks from today, the Original
Application shall stand dismissed without
further reference to the Administrative
Tribunal.
[iii] If application for condonation of delay
is made within the stipulated period of four
weeks, the same shall be decided by the
Administrative Tribunal in accordance with
law.
[iv] All contentions on merits are kept
open.
[v] Rule is made partly absolute on above
terms.
(Sunil P. Deshmukh, J.) (A.S. Oka, J.)
