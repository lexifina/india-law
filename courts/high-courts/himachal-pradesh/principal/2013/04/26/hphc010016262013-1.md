Justice A.M. Khanwilkar, C.J. (Oral)
 Heard counsel for the appellants and respondent-State. We find no ground to interfere with the discretionary
order passed by the learned Single Judge in condoning the
delay in filing written statement and permitting the
concerned defendants to file written statement, as prayed,
subject to payment of costs within the specified time.
2. The argument of the appellants, inter alia, is that, the
provisions of the Code of Civil Procedure ought to prevail.
This argument does not commend to us. This argument
clearly overlooks the provisions contained in Rule 18 of the
High Court of Himachal Pradesh (Original Side) Rules. By
virtue of Rule 18 read with Section 122 of the Code of Civil
Procedure, the provision contained in Rule 3 of Chapter VI of
the High Court Rules, authorizing the Court to grant

2
extension of time for filing written statement, ought to
prevail. The argument proceeds that the said Rule 3 permits
only one adjournment. Rule 3 reads thus:
ì3. Extension of time for filing written statement ñ
Ordinarily not more than one extension of time shall
be granted to the defendant for filing a written
statement; provided that a second or any further
extension may be granted only on an application made
in writing setting forth sufficient grounds for such
extension and supported, if so required, by an
affidavit.î (emphasis supplied)
3. On plain language of Rule 3, it is evident that the
defendant can move the Court for extending time to file
written statement successively. First such request can be
oral; and the subsequent requests must be in writing setting
forth sufficient grounds.
4. The argument of the appellants is that the Court had
already given more than one extension to the concerned
defendants and for which reason, Rule 3 will be of no avail.
This argument clearly overlooks the expression ìor any
further extensionî occurring in Rule 3. That pre-supposes
that even after the second extension granted by the Court,
the defendant, in a given case, can be permitted to file
written statement if further extension is sought by him upon
setting forth sufficient grounds for such extension. In other
words, it can be successive applications for extension of time
to file written statement. However, it is for the Court to
consider the grounds set forth by the defendant in writing as
to whether the same can be said to be sufficient or
otherwise. If the Court is satisfied that the ground so set
forth is sufficient, there is express power conferred in the

3
Court, by virtue of Rule 3, to permit the defendant to file
written statement by giving further extension.
5. The last submission made by the counsel for the
appellants is that no reason whatsoever has been assigned
by the learned Single Judge for rejecting the application filed
by the appellants being OMP No. 117 of 2011. This
argument will have to be stated to be rejected. The learned
Single Judge has elaborately dealt with the matter while
considering the application filed by the concerned
defendants for extension of time for filing written statement.
Having accepted the grounds so set forth by the concerned
defendants, in the formal application filed by them in that
behalf, as sufficient grounds for condoning the delay in filing
the written statement, as a natural consequence thereof, the
application filed by the appellants for striking off the defence
of the said defendants by invoking power under Order 8 Rule
1 read with Section 151 of the Code of Civil Procedure would
not survive for consideration. In other words, para 20 of the
decision of the learned Single Judge will have to be
understood to mean that for the reasons accepted by the
learned Single Judge for giving further time to the
defendants, the question of striking off defence of the said
defendants would not survive for consideration.
6. Accordingly, this appeal fails and the same is
dismissed.
(A.M. Khanwilkar),
 Chief Justice.
