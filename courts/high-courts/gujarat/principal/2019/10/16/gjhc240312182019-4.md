ORAL ORDER
Learned APP on instructions of Shri S.B.Zala, PSI,
Nanapondha Police Station, Valsad states at bar that
supplementary charge sheet is filed on 21.08.2019 with the
competent Court.
In light of this statement, learned advocate for the
applicants does not press present application with a liberty to
file discharge application and also to file appropriate
proceedings either u/s 397 or 482 of the Code of Criminal
Procedure, 1973 before appropriate competent Court, after
remedy to file discharge application is availed. The present
application stands disposed of as not pressed with above
liberty.
It is clarified that this Court has not examined the
merits of the present application.
