Order
19/01/2021
The present application has been filed seeking correction in
the order dated 02/12/2020 passed by this Court in S.B. Criminal
Misc. Bail Application No.4427/2020, wherein the F.I.R. number
has been shown as F.I.R. No.65/2019, whereas it should have
been F.I.R. No.65/2020.
For the reasons mentioned in the application, the same is
allowed. The F.I.R. number mentioned int the order dated
02/12/2020 be read as FIR No.65/2020 instead of FIR
No.65/2019.
