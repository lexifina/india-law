% 27.09.2019
The issue raised in the present petition has already been decided by
this Court in Crl. Rev. P. 995/2019 dated 20.09.2019.
Counsel for the respondent has not disputed the aforesaid fact.
Accordingly, I hereby set aside the impugned order dated 25.02.2019 to the
extent that summoning of FR-1/Crime File and remand the case back to the
learned Special Judge to pass order afresh by giving reasons as to what are
the exceptional circumstances due to which FR-1/Crime File is required.
This Court expects from the Trial Court to dispose of the complaint
which is of the year 2017 as early as possible but within six months in any
case.
SURESH KUMAR KAIT, J
