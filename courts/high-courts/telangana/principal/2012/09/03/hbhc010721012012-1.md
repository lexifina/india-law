# High Court for the State of Telangana, WP/25665/2012, 2012-09-03

THE HON’BLE SRI JUSTICE K.C.BHANU
WRIT PETITION NO.25665 OF 2012
ORDER:
Learned counsel appearing for the petitioner seeks
permission of this Court to withdraw the Writ Petition with a liberty
to file a fresh Writ Petition. Permission is accorded.
2. Accordingly, the Writ Petition is dismissed as withdrawn
giving liberty to the petitioner to file a fresh Writ Petition. No order
as to costs.
3. Miscellaneous petitions, if any, pending in this Writ
Petition shall stand closed.
----------------------
K.C.BHANU, J
DATED: 03-09-2012
