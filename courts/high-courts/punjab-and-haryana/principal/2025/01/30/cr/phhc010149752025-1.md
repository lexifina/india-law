ALKA SARIN, J. (Oral)
1. Learned counsel for the petitioner is wanting to inter-alia
challenge an order dated 21.08.2024 vide which respondent No.1 herein has
been permitted to file his written statement. Strangely, the copy of the said
order has not been appended with the petition nor challenged in the petition.
The learned counsel for the petitioner has passed it across the table and
states that this is the order which is under challenge. Without appending the
order with the petition, it is not understandable how the same can be
challenged.
2. Faced with the same, the learned counsel for the petitioner
seeks permission to withdraw the present petition with liberty to file afresh
with better particulars. Permitted to do so.
3. Dismissed as withdrawn with the liberty aforesaid. Pending
applications, if any, also stand disposed off.
