Order
23/02/2024
1. The instant criminal miscellaneous application has been
preferred seeking correction in the order dated 07.02.2024 passed
by this court in S.B. Criminal Misc. Petition No.3128/2023.
2. It is averred in the application that vide the aforesaid order,
this court allowed the miscellaneous petition, however, due to
inadvertence, some errors have crept in the order, which may be
rectified/corrected. The errors pointed out are as follows :-
(i) In para No.2 of the order, the number of FIR has been
mentioned as '389/2020' instead of '398/2020'.
(ii) In para No.2 of the order, date of incident has been
mentioned as '12.11.2020' instead of '12.10.2020'.
(iii) In para No.9 of the order, the number of Sessions Case has
been mentioned as '14/20221' instead of '14/2021'.

[2024:RJ-JD:9520] (2 of 2) [CRLMA-79/2024]
3. Having considered the submissions made and on perusal of
the file, it is felt essential to make necessary corrections in the
order dated 07.02.2024. Accordingly, it is ordered that :
(i) In para No.2 of the order, the number of FIR be read as
'398/2020' instead of '389/2020'.
(ii) In para No.2 of the order, date of incident be read as
'12.10.2020' instead of '12.11.2020'.
(iii) In para No.9 of the order, the number of Sessions Case be
read as '14/2021' instead of '14/20221'.
4. The miscellaneous application is allowed in these terms. This
order shall be treated as part and parcel of the order dated
07.02.2024.
(FARJAND ALI),J
