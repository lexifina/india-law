ORAL ORDER
2 02-05-2014 Heard learned counsel for the parties.
After some argument learned counsel for the petitioner
seeks permission to withdraw this writ application.
In the considered opinion of this Court, the recourse
adopted by the petitioner is absolutely justified.
Keeping in view the earlier finding recorded in the
order dated 19.02.2008 in C.W.J.C. No. 1288 of 2006, this writ
application is accordingly dismissed as withdrawn but it is also
made clear that if the petitioner approaches this Court for the same
cause of action as has been raised in the writ application, it will
impose a very heavy cost.
Sujit/-
(Mihir Kumar Jha, J)
