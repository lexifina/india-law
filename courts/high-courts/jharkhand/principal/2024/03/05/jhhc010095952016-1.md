for the petitioner argues that grievance of the petitioner has already been
redressed and as such he seeks liberty to withdraw the instant writ petition
with liberty to move before the authorities concerned, if any of the
grievance is still required to be redressed.
3. Learned counsel representing State does not object the submission.
4. In view of submission of learned counsel for the petitioner, this writ
petition stands disposed of. Petitioner is at liberty to file representation
before the authorities concerned raising his grievance, if so aggrieved.
5. With the liberty aforesaid, this writ petition stands disposed of.
