This application coming on for orders this day, the court passed the

ORDER
This is first application under section 438 Cr.P.C..
Learned counsel for applicant after arguing for some time seeks to
withdraw this application with liberty to surrender before the competent court
and to apply for regular bail.
If the applicant surrenders before the competent court and moves an
application for regular bail, the same shall be decided expeditiously, and if
possible, on the same day.
M.Cr.C. is accordingly dismissed as withdrawn with the aforesaid liberty.
