P.C. :-
1. Heard learned Counsel for the applicant on this application for
restoration of the earlier dismissed application for condonation of delay.
2. Said delay condonation application was filed for allowing the
applicant / original complainant to file an application for leave to file
appeal challenging the acquittal of the respondents. There was delay of
about 18 days in filing said application for leave.
3. For the reasons mentioned in the present application for
restoration, the same is allowed. Earlier dismissed application for
condonation of delay bearing No.894 of 2012 is restored to the file.
Application is disposed of accordingly.
