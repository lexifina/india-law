# Allahabad High Court, WRIB/5025/2018, 2018-10-11

Court No. - 9
Case :- WRIT - B No. - 5025 of 2018
Petitioner :- Ram Lakhan
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Ram Kumar Gautam
Counsel for Respondent :- C.S.C.,Brij Kumar Yadav
Hon'ble Anjani Kumar Mishra,J.
Heard counsel for the petitioner and Shri Brij Kumar Yadav,
counsel for the respondent no.4 Gaon Sabha.
The instant writ petition is directed against the order dated
18.12.2017 (Annexure-9) and the order dated 20.10.2011
(Annexure-7) passed by the respondent nos.2 and 3
respectively.
The dispute in this writ petition pertains to plot No.406 which
on the start of consolidation operations, appears to have been
reserved for a Kanya Pathshala.
It appears that on an application of the petitioner this
reservation for Kanya Pathshala was changed from plot No.406
to 407 by the Settlement Officer, Consolidation vide order dated
19.03.2005. This was so done because, it was claimed by the
petitioner that he has been allotted a patta for housing purposes
of plot No.406.
The contention of counsel for the petitioner is that the order
dated 19.03.2005 passed by the Settlement Officer,
Consolidation in favour of the petitioner was set aside suo moto
by the same authority vide order dated 20.10.2011. The
Settlement Officer, Consolidation has no power to review and
therefore, this order was patently illegal apart from being ex-parte against the petitioner.
Aggrieved by the order, the petitioner is stated to have preferred
a revision which has been dismissed on 18.12.2017.
A perusal of the revisional order reveals that it has been
dismissed on the ground that Ram Lakhan, the revisionist and
petitioner before this Court, has no jurisdiction to challenge the
order dated 20.10.2011 which had been passed against one
Kishnu, who appears to be father of the petitioner-revisionist.
It was accordingly, held that the petitioner has no locus to
challenge the order passed against his father.

In my considered opinion, the reasoning given in the impugned
order is perfectly justified. Even before this Court, counsel for
the petitioner could not show as to under what capacity he was
competent to challenge the order passed against his father. On a
pointed query by the Court, counsel for the petitioner has
admitted that his father Kishnu died in the year 2013. It is
therefore, clear that his father was alive for at-least two years
after came to be passed.
Apart from the fact that the petitioner has no locus to file either
the revision, there is yet another aspect which needs to be
noted.
Perusal of the order dated 31.12.2008 filed as Annexure-6 to the
writ petition reveals that, it is no doubt true that the order was
passed by the Settlement Officer, Consolidation in Appeal
No.17, on 19.03.2005. This is the order whereby the area
reserved for Kanya Pathshala was shifted from plot No.406 to
407. However, the same order dated 31.12.2008 reveals that
against the order dated 19.03.2005, a restoration application
was filed which was allowed vide order dated 22.09.2005. This
order has not been challenged any further.
Under the circumstances, therefore, the contention that the
order dated 20.10.2011 has been passed suo-moto does not
appear to be correct. In my considered opinion, the Settlement
Officer, Consolidation was not required to pass this order
because it merely sets aside an order which had already been set
aside on 22.09.2005 on a restoration application.
Under the circumstances and since the order reserving plot
No.407 for a Kanya Pathshala had already been set aside in the
year 2005 itself, the petitioner has no case. The writ petition not
only lacks merit, the revision wherein the impugned order was
passed, was not maintainable at the instance of the petitioner.
The writ petition is accordingly, dismissed.
Order Date :- 11.10.2018
