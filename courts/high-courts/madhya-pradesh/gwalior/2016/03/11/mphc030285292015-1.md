# High Court of Madhya Pradesh, MCRC/13483/2015, 2016-03-11

MCRC-13483-2015
(VIRENDRA SINGH Vs THE STATE OF MADHYA PRADESH)
11-03-2016
Shri SS Dhakad, learned counsel for the applicants-accused.
Shri Kuldeep Singh, learned PL for the respondent/state.
The case diary is available.
The order dated 25.1.2016 has not been complied with by the
applicants-accused. The counsel for the applicants-accused seeks
permission to withdraw this application with liberty to file the bail
application again after recording the statements of the witnesses
before the trial court.
The prayer is accepted.
This application is dismissed as withdrawn with the liberty as
stated earlier.
(M.K. MUDGAL)
JUDGE
