# High Court of Orissa, WP(C)/15943/2019, 2019-09-11

2
m
11.9.2019 Heard learned counsel for the petitioner and
learned State Counsel appearing for the opposite parties.
This is a writ petition making grievance that in
spite of filing the Encroachment Appeal since April, 2019
along with an application for interim protection, the appellate
authority is not taking up the interim application. As a
consequence, there is threat of eviction/demolition involving
the disputed property.
Considering this limited request involved herein,
this Court disposes of the writ petition with a surprising note
that when the Appeal is already filed since April, 2019, there
appears, there is no sound reason for not taking up the
interim application involving such serious matter and also
directing the appellate authority, i.e., Sub-Collector, Puri to
take up the interim application involving OPLE
Encroachment Appeal No.3/2019 forthwith, if possible on the
date of submission of copy of this order itself and pass order
on the interim application. This Court makes it clear that in
the event the petitioner is in possession of the disputed
property as of now and there is no demolition taking place in
the meantime, status quo as on date shall be maintained.
Issue urgent certified copy.
A free copy of this order be supplied to the
learned counsel for the State for necessary communication.

 Biswanath Rath, J.
