CORAM: HONOURABLE MR.JUSTICE VIPUL M. PANCHOLI
Date : 03/05/2019
ORAL ORDER
Learned advocate for the applicants submits
that the applicants have directly filed this application
before this Court without approaching the Sessions Court.
He, therefore, seeks permission to withdraw this
application with a view to file application before the
Sessions Court. Permission as prayed for is granted. This
application is disposed off as withdrawn. It is clarified
that this Court has not examined the merits of the case
and therefore as and when any application is filed by the
applicants before the Sessions Court, the same shall be
examined on its own merits.
(VIPUL M. PANCHOLI, J)
