IN THE HIGH COURT OF JHARKHAND AT RANCHI
A.B.A. No. 9057 of 2019
 ------
Saif Sultan … Petitioner
 Versus
The State of Jharkhand & Anr. … Opposite Parties
 ------
 CORAM: HON’BLE MR. JUSTICE ANIL KUMAR CHOUDHARY
 ------
For the Petitioner : Mr. A.K. Sahani, Advocate
For the State : Mr. Ravi Prakash, Spl. P.P.
 ------
Order No.05 Dated- 27.01.2020

 Learned Spl P.P. appearing for the State submits that in this
case police has already submitted final form against the petitioner
for having committed only the offences punishable under Sections
504/506 of the Indian Penal Code which are bailable in nature.
Hence, the anticipatory bail application is not maintainable.
 At this stage, learned counsel appearing for the petitioner
seeks permission of this Court to withdraw this anticipatory bail
application as the same has become infructuous.
Accordingly, this anticipatory bail application is dismissed
as withdrawn.

 (Anil Kumar Choudhary, J.)
