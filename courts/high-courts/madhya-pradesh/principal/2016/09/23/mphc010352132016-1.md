# High Court of Madhya Pradesh, RP/447/2016, 2016-09-23

RP-447-2016
(KAILASH KUMAR KHEDIA Vs THE STATE OF MADHYA PRADESH)
23-09-2016
Shri Mukesh Agrawal, learned counsel for the petitioner.
Shri B.D. Singh, learned Government Advocate for the
respondent-State.
This review petition has been filed for correction of typing error
in the order dated 23/06/2016.
It is contended by the counsel for the petitioner that a liberty was
sought to file an application for intervention in an appeal pending
before the Commercial Tax Appellate Board, Bhopal, at the time of
passing of the order, however this court has passed the order that
"learned counsel for the petitioner submits that this petition has
become infructuous. He further submits that petitioner be given a
liberty to file appear before the Commercial Tax Appellate Board,
Bhopal". The order is not clear.
After perusal of the order, in our opinion, the order passed by
this court is not clear. Hence where in the order it is mentioned
"petitioner be given a liberty to file appear before the Commercial
Tax Appellate Board, Bhopal" it be reads as " liberty is granted to
the petitioner to file an application for intervention in an appeal
pending before the Commercial Tax Appellate Board, Bhopal."
Petition is disposed of accordingly. No order as to costs.
C.C. as per rules.
(S.K. GANGELE)
JUDGE
