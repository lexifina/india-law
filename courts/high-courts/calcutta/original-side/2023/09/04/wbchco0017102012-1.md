# Calcutta High Court, EC/130/2012, 2023-09-04

O-3
IN THE HIGH COURT AT CALCUTTA
Ordinary Original Civil Jurisdiction
ORIGINAL SIDE
EC/130/2012
CALCUTTA TRAMWAYS COMPANY (1978) LTD.
VS
MILESTONE ADVERTISING & ORS.
 BEFORE:
 The Hon'ble JUSTICE RAVI KRISHAN KAPUR
 Date : 4th September, 2023.
Appearance:
Mr. Niladri Bhattacharjee, Adv.
Ms. Angana Dutta, Adv.
…for the decree-holder.
The Court: This execution application has been pending since 2012. The
decree-holder seeks an adjournment. Despite several orders, the decree-holder
has been unable to effect service on the judgment-debtors.
It is obvious that the decree-holder is not diligent in proceeding with the
execution application.
EC/130/2012 stands dismissed.
Liberty is granted to the decree-holder to file a fresh execution application
if and when the decree-holder has been able to ascertain the whereabouts of the
judgment-debtors.
(RAVI KRISHAN KAPUR, J.)
