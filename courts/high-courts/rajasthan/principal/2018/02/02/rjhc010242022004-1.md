Order
02/02/2018
1. Heard learned counsel for the parties.
2. Only contention argued in the appeals is that service of the
respondent No.1, as probationers, was terminated at the end of
the probation period. This overlooks the fact that the termination
has been held to be punitive by the learned Single Judge.
3. It is a settled law that if an order terminating service of a
probationer is punitive the same has to be set aside if it was not
preceeded with a proper enquiry. In the instant case none was
done.
4. In view of the limited submission made in the appeals, which
we have noted and dealt with, the appeals are dismissed.
