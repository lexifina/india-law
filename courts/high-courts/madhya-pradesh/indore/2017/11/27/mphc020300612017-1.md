# High Court of Madhya Pradesh, RP/1249/2017, 2017-11-27

1
R.P. No.1249/2017
Indore, Dated : 27.11.2017
Shri A.S. Bahrawat, learned counsel for the petitioner.
Ms. Nidhi Bohra, learned counsel for the respondent.
Heard.
This review petition has been filed for correction of
typographical error in the order dated 25.9.2017 passed in
MCC No.263/2017.
Learned counsel for the petitioner submits that due to
the typographical error the HMA Case No.1123-A/2016 and
1123-A/2006 has been mentioned in the order, whereas the
correct HMA case number is 626/2016.
Learned counsel for the respondent does not dispute it.
Having regard to the aforesaid the present review
petition is disposed off by directing that in the order dated
25.9.2017 passed in MCC No.263/2017 wherever the case
number is mentioned as “HMA Case No.1123-A/2016” or
“1123-A/2006”, the correct case number will be read as “HMA
Case No.626/2016”.
The review petition is accordingly disposed off.
C.C. as per rules.
 (Prakash Shrivastava)
