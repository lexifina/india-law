Order No.02 Dated: 3 rd
 July, 2015
This Cr.M.P. has been filed for restoration of A.B.A. No.1071 of 2015
which stood dismissed on 15.06.2015.
There is no bar bar to file another anticipatory bail petition, if the earlier
one stood dismissed for non-prosecution.
I do not feel inclined to allow this Cr.M.P. Accordingly, this Cr.M.P. stands
dismissed with liberty to the petitioner to file fresh anticipatory bail petition, if
he so wishes.

 (D. N. Upadhyay, J.)
