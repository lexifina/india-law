State has submitted a report which reflects
that in connection with Golabari P.S. Case No.78
dated 22.03.2023 already final report has been filed
before the jurisdiction court declaring the same to be
civil in nature. The report reflects that the number
which has been assigned to Golabari P.S. Case No.78
dated 22.03.2023 while submitting the report before
the jurisdictional court is FR No.214 dated
26.07.2024.
Petitioner claims that he has been very
recently informed regarding the outcome of the
investigation.
Having considered that the petitioner has
been informed and the fact that the petitioner is

2
aggrieved, I grant liberty that if the petitioner, if so
advised, will take an appropriate application under
Section 173(8) of the Code of Criminal Procedure
before the jurisdictional court in seisin of the matter.
It would be for the jurisdictional court to apply its
mind and take the decision in accordance with law.
With the aforesaid observations, WPA 1696
of 2025 is disposed of.
There will be no order as to costs.
Report so submitted be kept with the record.
A copy of the report be handed over to the
learned advocates appearing for both the parties.
All parties shall act on the server copy of this
order duly downloaded from the official website of this
Court.
Urgent photostat certified copies of this
order, if applied for, be given to the parties upon
compliance of all requisite formalities.
