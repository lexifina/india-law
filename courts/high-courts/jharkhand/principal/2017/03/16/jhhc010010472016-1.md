CORAM: HON’BLE MR. JUSTICE ANANDA SEN
For the Petitioner: Mr.D.K.Karmakar, Advocate
For the State :Mr.Mukesh Kumar, APP
02/ 16.3.17. Counsel for the petitioner submits that in this application he has
challenged the order dated 5.5.2016 passed by the Principal Judge, Family Court,
Jamshedpur by which ad interim maintenance has been granted to the applicant.
 It is submitted that final order has already been passed in Cr.Misc.
No.45 of 2015 by the Principal Judge, Family Court, Jamshedpur. He further submits
that he has already challenged the final order passed under Section 125 of the Code
of Criminal Procedure by filing Cr. Misc. No.256 of 2017 which is still pending before
this Court.
Since the final order under section 125 of the Code of Criminal
Procedure has already been passed, this application has become infructuous,
hence, this application is dismissed as infructuous.
 (Ananda Sen, J.)
