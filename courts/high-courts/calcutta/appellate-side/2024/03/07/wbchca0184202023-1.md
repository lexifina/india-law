# Calcutta High Court, CRR/1396/2023, 2024-03-07

D/L65
07.03.2024
Bpg.
 C.R.R.1396 of 2023
In Re: An application under Section 401 read with Section 482 of the
Code of Criminal Procedure, 1973;
 Jiten Roy
 Versus
 The State of West Bengal and another

The order dated 6th December, 2023 reflects that none
appeared on behalf of the petitioner. The revisional application is
running in the list for a considerable period of time and has been
called on several occasions. Today, when the revisional application
is called, none represented the petitioner.
Records reflect that the petitioner prays for quashing of
the proceedings in connection with Pukhuria Police Station Case
No.107 of 2022 dated 13.04.2022 which was registered for
investigation under Section 135(1)(b) of the Electricity Act. None of
the documents under Sections 207 of the Code of Criminal
Procedure have been enclosed along with the revisional application.
As such, I am of the view that the merit of the case is not possible to
be adjudicated.
Accordingly, CRR 1396 of 2023 is dismissed.
Pending connected application, if any, is consequently
disposed of.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
