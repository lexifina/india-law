# High Court of Orissa, CRLMA/146/2023, 2024-02-01

IN THE HIGH COURT OF ORISSA AT CUTTACK
CRLMA No.146 of 2023
Mohan Singh …. Petitioner
Mr. S.S.Das, Sr.Advocate
-versus-State of Odisha …. Opposite Party
Mr. P.C.Das, A.S.C.
 CORAM:
 JUSTICE A.K. MOHAPATRA

Order No.
ORDER
01.02.2024
02. 1. This matter is taken up through Hybrid Arrangement (Virtual
/Physical Mode).
2. Heard Mr. S.S.Das, learned senior counsel appearing for the
petitioner as well as learned Additional Standing Counsel for the State
Opposite parties.
3. The present CRLMA application has been filed for restoration of
CRLMC No.4349 of 2011, which has been dismissed due to non-prosecution vide order dated 30.03.2022.
4. Mr. Das, learned senior counsel appearing for the petitioner
submitted before this Court that on 30.03.2023, the matter was not
listed before the concerned bench. However, vide order dated
30.03.2022, the CRLMC No.4349 of 2011 has been dismissed due to
non-prosecution. In support of his contention learned counsel for the
petitioner has filed a copy of the cause list of the concerned Court dated
30th March, 2022. On perusal of the cause list so filed this Court
observes that the present CRLMC application was not listed before the
concerned bench on 30.03.2022. Therefore, this Court has no hesitation
in coming to conclusion that order has been passed without proper
notice to the present petitioner, as the same was not reflected in the
cause list of the concerned bench for 30.03.2022.

 // 2 //
5. Learned counsel for the State on the other hand submits that he
has no objection in the event the matter is restored.
6. The aforesaid factual background, as well as taking into
consideration the fact that the matter has been dismissed for default by
order dated 30.03.2022 without the matter being listed before the
bench, this Court is inclined to allow the CRLMA application.
7. Accordingly the CRLMA is allowed, as a consequence thereby
CRLMC No.4349 of 2011 is restored to file. Registry is directed to list
this matter before the appropriate assigned bench forthwith. Learned
senior counsel for the petitioner is granted liberty to file a separate
application for extension of the interim order dated 29.11.2011. The
fact that nothing has happened in the meantime has to be brought on
record by way of an affidavit. Liberty is granted to the petitioner to file
a separate application for extension of interim order dated 29.11.2011
which shall be duly considered by the appropriate assigned bench.
 ( A.K. Mohapatra )
 Judge
