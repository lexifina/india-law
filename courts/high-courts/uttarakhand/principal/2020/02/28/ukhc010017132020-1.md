# High Court of Uttarakhand, BA1/239/2020, 2020-02-28

BA1 No.239 of 2020
Hon’ble Alok Kumar Verma, J.
Mr. Navjot Singh, learned Advocate for the
applicant.
Ms. Meena Bisht, learned Brief Holder for the
State of Uttarakhand.
Learned counsel for the applicant seeks
permission to withdraw the first bail application as the
applicant has an alternative remedy to file a Criminal
Revision.
Permission is accorded.
The Bail Application is dismissed as withdrawn.
On the request of learned counsel for the
applicant, it shall be open to the applicant to file a
Criminal Revision according to law.
Certified copy of the impugned order may be
returned to the learned counsel for the applicant after
retaining the copy of the same to be kept on record.
 (Alok Kumar Verma, J.)
