# Madras High Court, A/5295/2023, 2023-11-03

A.No.5295 of 2023
in C.S.No.371 of 2019
N.SATHISH KUMAR, J.
This application has been
filed to set aside the ex-parte
order passed against the
defendants dated 10.01.2022 in
the above suit and also to condone
the delay of 60 days in filing the
written statement in the suit.
2.For non filing of the
written statement by the
defendants, they were set ex-parte on 10.01.2022. On the
same day, it was mentioned that
the written statement was ready
and they will file in due course.
However, this Court had directed
them to file an application to set
aside the ex-parte order. As per
the direction of this Court, the
present application has been filed.
3. Now, it is seen that
written statement has been filed.
This Court is of the view that to
meet the ends of justice, the
application has to be allowed.
Accordingly, the application stands
allowed and the ex-parte order
passed in the suit dated
10.01.2022 is set aside.
