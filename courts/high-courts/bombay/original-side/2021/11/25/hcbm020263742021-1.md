P.C. :
1. By this IA, the original defendant seeks to file Written Statement, which
is presently beyond time. True copy of the written statement has been handed
over to the learned counsel for the plaintiff in court.
2. In view of the above and the delay that has occasioned, Ms. Irani
opposed the application, however, there is no affidavit-in-reply.
3. In view of the above, considering the delay and the oral application
made today for condoning the delay, I pass the following order :-
