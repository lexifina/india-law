# Bombay High Court, APPP/1058/2015, 2016-06-17

1/2 28-appr.1058.2015
nsc.
IN THE HIGH COURT OF JUDICATURE AT BOMBAY
CRIMINAL APPELLATE JURISDICTION
CRIMINAL APPLICATION NO.1058 OF 2015
(For Restoration)
IN
CRIMINAL APPLICATION NO.552 OF 2013
(For Leave to Appeal)
M/s.Hubale Seles Corporation ...Applicant
 Versus
Heramb Food Products Private Limited and Ors. ...Respondents
Mr.Nikhil Pujari, for the Applicant
Ms.R.V.Newton, A.P.P for the Respondent-State
 CORAM : REVATI MOHITE DERE, J.
 DATE : 17th JUNE, 2016
P.C. :
1. Heard the learned counsel for the Applicant.
2. By this application, the applicant seeks recall of the order dated 16th
November, 2015 and prays for restoration of Criminal Application for
leave to file Appeal being Criminal Application No.552 of 2013 which
came to be dismissed for non- prosecution vide the aforesaid order as none
was present on behalf of the applicant.

2/2 28-appr.1058.2015
3. For the reasons set out in the application, the application is
allowed. The order dated 16th November, 2015 is recalled and Criminal
Application for leave to file Appeal being Criminal Application No.552 of
2013, is restored to file.
4. The Application is accordingly disposed of.
5. Criminal Application No.552 of 2013, be placed for
‘admission’ on 1st July, 2016.
 REVATI MOHITE DERE, J.
