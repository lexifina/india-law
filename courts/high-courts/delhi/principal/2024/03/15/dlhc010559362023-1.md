An application under Section 482 of the Code of Criminal Procedure,
1973 (‘Cr.P.C.’) has been preferred on behalf of the petitioner for
withdrawing the bail application with liberty to file afresh before the learned
Trial Court.
Learned counsel for the petitioner seeks to withdraw BAIL APPLN.
No. 4331/2023 with liberty to file afresh before the learned Trial Court.
Taking the statement of learned counsel for the petitioner on record,
the application is accordingly disposed of with liberty to file an application
before the learned Trial Court. Pending applications, if any, also stand
disposed of.
Next date of hearing, i.e. 14.05.2024 stands cancelled.
