Ms. Lipika Chatterjee
 ..for the State
This matter was dismissed for default on 25th
September, 2023. Thereafter one restoration application
has been filed. I have gone through the restoration
application and find that the petitioner has shown
sufficient reason for non-appearance on 25.09.2023.
Therefore, the restoration application is allowed. The
writ application is restored in its original file and
number.
Learned advocate for the State submits that the
grievance of the petitioner has been redressed.
Learned advocate for the petitioner submits that
she does not want to proceed with the matter any
further.
Therefore, the writ application is disposed of.
The document filed by the State is kept on record.
 (Abhijit Gangopadhyay, J. )
