Sivagangai,
In Crime No.775 of 2012. ... Respondent
Prayer: Criminal Original petition is filed under Section 482 of
Criminal Procedure Code, to direct the respondent to file final
report in connection with Crime No.775 of 2012 on the file of the
respondent police within a specified time as may be fixed by this
Court.
For Petitioner : Mr.R.Mohanasundaram
For Respondent : Mr.K.K.Ramakrishnan,
 Additional Public Prosecutor
ORDER
 This petition has been filed praying to direct the respondent
to file a final report in connection with Crime No.775 of 2012 on
the file of the respondent police within a specified time.
2. Heard the learned counsel appearing for the petitioner as
well as the learned Additional Public Prosecutor for the respondent.
3.The learned Additional Public Prosecutor on instructions
would submit that already the investigation has been completed in
this case and charge sheet has been filed before the learned
Judicial Magistrate No.I, Sivagangai and the same was not taken on
file.
4.Recording the above submission made by the learned Additional
Public Prosecutor, this Criminal Original petition is dismissed with
liberty to the petitioner to file a protest petition before the
concerned Magistrate.
Sd/-
