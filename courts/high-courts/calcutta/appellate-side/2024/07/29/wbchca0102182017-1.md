same was listed on 14.06.2024 and 15.07.2024 when
none represent the petitioner. Today, when the writ
petition has been called, none represented the
petitioner nor any accommodation has been sought
for.
Accordingly, WPA 5031 of 2017 is dismissed
for default.
There will be no order as to costs.
All parties shall act on the server copy of this
order duly downloaded from the official website of this
Court.
Urgent photostat copy of this order, if applied
for, be given to the parties upon compliance of all
requisite formalities.
