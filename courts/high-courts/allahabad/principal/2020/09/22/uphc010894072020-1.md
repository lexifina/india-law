# Allahabad High Court, CAPL/2926/2020, 2020-09-22

Court No. - 40
Case :- CONTEMPT APPLICATION (CIVIL) No. - 2926 of
2020
Applicant :- Charan Singh And Another
Opposite Party :- Vikash Gothalwal, Managing Director
Counsel for Applicant :- Subodh Kumar Rai
Hon'ble Ashwani Kumar Mishra,J.
This contempt petition has been filed alleging disobedience of
the order passed by Lucknow Bench of this Court in Service
Single No.28543 of 2019, dated 18.10.2019.
In the event the order passed by Lucknow Bench has been
violated, it would be appropriate for the applicant to file
contempt petition before the Lucknow Bench itself.
Leaving it open for the applicant to file contempt petition
before the Lucknow Bench, this petition is consigned to
records.
Order Date :- 22.9.2020
Ashok Kr.
