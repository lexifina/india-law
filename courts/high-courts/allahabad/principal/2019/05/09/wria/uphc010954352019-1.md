# Allahabad High Court, WRIA/7301/2019, 2019-05-09

Court No. - 2
Case :- WRIT - A No. - 7301 of 2019
Petitioner :- Shivendra Kumar Srivastava
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Prakash Narayan
Counsel for Respondent :- C.S.C.
Hon'ble Suneet Kumar,J.
Learned counsel for the petitioner on being confronted with the
order dated 5 October 2016, rejecting the claim of the petitioner
for regularisation, pursuant to the directions of this Court
passed in Writ - A No.38895 of 2016, having not been assailed.
The learned counsel for the petitioner prays for withdrawal of
the writ petitioner with liberty to file fresh.
In view thereof, the writ petition is dismissed as withdrawn
with liberty to the petitioner to file fresh assailing the aforesaid
order, if so advised.
Order Date :- 9.5.2019
