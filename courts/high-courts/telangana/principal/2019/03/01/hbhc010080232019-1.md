# High Court for the State of Telangana, WP/4256/2019, 2019-03-01

THE HON’BLE SRI JUSTI CE SANJAY KUMAR
WRI T PETI TI ON NO.4256 of 2019
ORDER:
Ms K. Swathi, learned counsel, representing Mr. Bethi
Venkateshwarlu, learned counsel for the petitioner, seeks leave to
withdraw this writ petition reserving liberty to the petitioner to file a
writ petition in public interest, if so advised.
Leave granted.
The Writ Petition is accordingly dismissed as withdrawn with
the liberty aforestated.
Pending Miscellaneous Petitions, if any, shall also stand
dismissed. No order as to costs.
