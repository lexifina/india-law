ORAL ORDER
2 01-12-2014 The learned counsel for the petitioner submitted that
because of mistake, the dead person has been made petitioner in
this MJC application and there are other serious defects also,
therefore, he may be permitted to withdraw this MJC application
with liberty to file a fresh correct MJC application for restoration
of First Appeal No.614 of 1986.
In view of the submission of the learned counsel for the
petitioner, the petitioner is permitted to withdraw this MJC
application with liberty to file fresh MJC application with correct
party position, etc. This MJC application thus stands dismissed as
withdrawn.
