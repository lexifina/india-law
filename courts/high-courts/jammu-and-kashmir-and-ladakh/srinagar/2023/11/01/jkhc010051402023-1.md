ORDER
 01.11.2023
This writ petition ex-facie suffers deficiency of essential
pleadings as the petitioners are 16 in number all claiming to be working as
numberdars but without any pleadings to the fact as to when each petitioner
came to be appointed as numbardar and vide which order.
When confronted by this deficiency state obtaining in the writ
petition, the learned counsel for the petitioners seeks to withdraw this writ
petition with liberty to file fresh writ petition carrying all the essential
pleadings. Accordingly writ petition is allowed to be withdrawn with liberty
granted to file fresh one with better particulars and pleadings.
 (Rahul Bharti)
