# High Court of Madhya Pradesh, MCC/303/2020, 2020-02-03

(AJAY KUMAR MITTAL)
CHIEF JUSTICE
(VIJAY KUMAR SHUKLA)
JUDGE
The High Court Of Madhya PradeshThe High Court Of Madhya Pradesh
MCC-303-2020
(DISTRICT MAGISTRATE/COLLECTOR JABALPUR Vs SATISH KUMAR VERMA)
Jabalpur, Dated : 03-02-2020
Shri Shashank Shekhar, learned Advocate General for the applicant.
Respondent in person.
This is an application seeking appropriate directions to allow the
applicant to issue permission for use of Ravi Shankar Shukla Stadium, Wright
Town, Jabalpur for holding a function organized by the State Government to
felicitate Hon'ble the President, Hon'ble the Chief Justice of India, Hon'ble the
Governor and other dignitaries/State Guest on 21.03.2020.
Notice of this application. Respondent accepts notice.
We have heard learned counsel for the parties. The Advocate General
has made a statement that the changes which are required to be made for the
security of the dignitaries would be restored after the function is over.
In view of the above, we permit the State Government to take steps for
carrying out the changes which are required to be made for the security of the
aforesaid dignitaries in the Ravi Shankar Shukla Stadium, Wright Town,
Jabalpur and in the vicinity thereof for the function scheduled on 21.03.2020.
The applicant shall restore the changes made to the previous status after the
function is concluded.
Aforesaid order has been issued keeping in view the exceptional
circumstances as the security measures of the aforesaid dignitaries are
required to be ensured.
Respondent has no serious objection to the aforesaid.
Accordingly, this miscellaneous application is disposed of.
