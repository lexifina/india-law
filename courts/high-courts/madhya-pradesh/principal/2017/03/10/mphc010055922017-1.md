# High Court of Madhya Pradesh, MCC/304/2017, 2017-03-10

MCC-304-2017
(THE DIRECTOR GENERAL OF POLICE Vs MANOJ AHIRWAR)
10-03-2017
Shri Ramesh Kushwaha, learned Panel Lawyer for the applicants-State.
Heard on I.A. No.1622/2017, an application for condonation of delay.
For the reasons mentioned in the application, the same (I.A.
No.1622/2017) is allowed. The delay in filing this application is hereby
condoned.
This application has been filed for restoration of M.A. No.2300/2015
which has been dismissed on account of the common conditional order
passed on 14.10.2016. The application is supported by an affidavit of
Shri Suresh Yadav, Assistant Commandant.
Keeping in view the reasons indicated in the application, the MCC is
allowed and it is directed that M.A. No.2300/2015 be restored to its
original number and list this case before the appropriate Bench.
Let a copy of this order be kept in the file of M.A. No.2300/2015.
(SMT. ANJULI PALO)
JUDGE
