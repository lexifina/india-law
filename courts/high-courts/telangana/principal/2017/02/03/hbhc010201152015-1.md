# High Court for the State of Telangana, CC/2311/2015, 2017-02-03

HONOURABLE SRI JUSTICE CHALLA KODANDA RAM
CONTEMPT CASE No. 2311 of 2015
ORDER:
 The contempt case is filed complaining inaction in
implementing the order of this Court in W.P.No.12272 of
2015 dated 24.04.2015.
 Respondent had filed a counter affidavit specifically
asserting that the order of this Court, in W.P.No.12272 of
2015 dated 24.04.2015, has been complied with by passing
orders in Appeal Case No.33/14 dated 26.12.2015. A copy
of the same is enclosed along with the counter affidavit.
 The order has since been complied with, the contempt
case is closed. No order as to costs.

JUSTICE CHALLA KODANDA RAM
