HON'BLE MR. JUSTICE M.N. BHANDARI
Order
06/04/2017
 This application has been filed for modification of the
order dated 22nd March, 2017 where while dismissing the writ
petition on withdrawal, a liberty was given to take appropriate
remedy, however, the petitioner prayed for a liberty to file a fresh
writ petition also.
In view of above, the application is allowed. The order
dated 22nd March, 2017 is modified to say that liberty to the
petitioner would not only to take appropriate remedy but even to
file a fresh writ petition also, if so maintainable.
