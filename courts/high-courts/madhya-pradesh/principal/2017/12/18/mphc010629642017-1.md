# High Court of Madhya Pradesh, MCC/3577/2017, 2017-12-18

1
MCC No.3577/2017.
Jabalpur, dated 18/12/2017.
Shri Pranay Verma, learned counsel for the petitioner.
Heard on I.A.No.18149/2017, which is an application
for Condonation of Delay supported by an affidavit of
counsel for the petitioner.
On due consideration, the same is hereby allowed. The
delay in filling the application is hereby condoned.
This MCC has been filed for restoration of First
Appeal No.477/2017 which was dismissed in view of
Common Conditional Order dated 28.08.2017. This MCC is
duly supported by an affidavit by the counsel for the
petitioner. Finding the same to be bonafide, the application is
allowed.
Accordingly, First Appeal No.477/2017 is restored to
its original number. Let a typed copy of this order be kept in
the original file of First Appeal No.477/2017.
After restoration, First Appeal be placed for orders
before appropriate Bench.
MCC stands allowed and disposed of.
Certified copy as per rules.
 (MISS VANDANA KASREKAR)
 JUDGE
