# High Court of Orissa, WP(C)/12837/2006, 2019-02-07

06. 07.02.2019 Learned counsel for the petitioner seeks permission to
withdraw this writ petition. A memo filed to that effect has been
filed indicating therein that the petitioner does not want to
proceed with the case with liberty to file fresh application if any
cause of action survives. The memo is taken on record.
 Permission for withdrawal of the writ petition is
granted.
 Accordingly, the writ petition stands dismissed as
withdrawn with liberty to the petitioner to file afresh if any
cause of action survives.
 All connected Misc. Cases/IAs, if any, are accordingly
disposed of.
