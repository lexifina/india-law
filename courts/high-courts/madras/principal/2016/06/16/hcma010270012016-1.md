 ORDER
This Criminal Original Petition has been filed, to quash the
proceedings in C.C.No.188 of 2015 on the file of the learned
Judicial Magistrate Court-II, Chengalpattu.
2. Heard the learned counsel appearing for the petitioner
and the learned Additional Public Prosecutor appearing for the
first respondent.
3. When this court was about to dismiss this petition on
merits, the learned counsel for the petitioner sought permission
to withdraw this petition, with liberty to raise all the points
before the trial Court.
https://hcservices.ecourts.gov.in/hcservices/

4. In view of the above, this Criminal Original Petition is
dismissed as withdrawn to raise all the points before the trial
Court. Consequently, connected miscellaneous petition is
closed.
