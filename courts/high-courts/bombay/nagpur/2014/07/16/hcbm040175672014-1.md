CORAM : P.N.DESHMUKH, J.
DATED : JULY 16, 2014.
Heard learned counsel for the applicant.
This is an application for leave to amend the application
filed under Section 482 of the Code of Criminal Procedure. According
to the learned counsel for the applicant, inadvertently it remained to be
prayed that “FIR No.3054 of 2008 registered by Ambazari Police
station, Nagpur on 9th of June, 2008 be quashed and set aside”. It is,
therefore, prayed that by deleting prayer Clause (a), substituted prayer
Clause (aa), as above, be allowed to be inserted.
For the grounds mentioned in the application, same is
allowed.
Applicant to carry out the amendment within a period of
one week. On effecting the amendment, as above, the matter be
placed before the appropriate Bench.
 JUDGE
Chute.
