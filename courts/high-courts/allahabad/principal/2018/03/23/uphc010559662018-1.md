# Allahabad High Court, WRIC/10744/2018, 2018-03-23

Court No. - 2
Case :- WRIT - C No. - 10744 of 2018
Petitioner :- Soran Singh
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Tapesh Kumar Agrawal
Counsel for Respondent :- C.S.C.,Manoj Nigam
Hon'ble Ram Surat Ram (Maurya),J.
Heard Sri Tapesh Kumar Agrawal for the petitioner, Standing
Counsel for State of U.P. and Sri Manoj Nigam for the
respondent-bank.
Admittedly, the petitioner is availing alternative remedy in O.S.
No. 299 of 2007, in which, the petitioner has secured an ex
parte decree dated 28.2.2011, which has been set aside on the
application of the Bank on 18.12.2017 and the suit is still
pending.
The petitioner may seek interim order in the suit itself. Writ
petition, which is a parallel proceeding for the same relief, is
not maintainable. It is accordingly dismissed.
Order Date :- 23.3.2018
