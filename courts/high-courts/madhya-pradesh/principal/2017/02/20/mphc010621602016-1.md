# High Court of Madhya Pradesh, MCC/3243/2016, 2017-02-20

MCC-3243-2016
(MUNNILAL MISHRA Vs THE STATE OF MADHYA PRADESH)
20-02-2017
Shri Rajesh Pandey, learned counsel for the applicant.
Heard on I.A. No. 16610/2016 which is an application for
condonation of delay.
Considering the averments made in para 4 & 5 of the
application that learned counsel for the applicant were not aware
from peremptory order passed by this Court, the application (I.A.
No. 16610/2016 ) is allowed. Delay in filing the MCC is condoned.
Also heard on admission.
This MCC is filed for for restoration of MCC No. 2388/2015
which was dismissed on account of peremptory order dated
25.04.2016 as the process fee was not paid as directed by this
Court.
Considering the grounds mentioned in the application which
is supported by an affidavit, the application is allowed.
MCC No. 2388/2015 is directed to be restored to its original
number.
Learned counsel for the applicant is granted three weeks
time to comply with the peremptory order passed by this Court
after restoration of MCC No. 2388/2015. It is made clear that if the
peremptory order is not complied with the MCC No. 2388/2015
shall stands dismissed without further reference to the Court.
(VIJAY KUMAR SHUKLA)
