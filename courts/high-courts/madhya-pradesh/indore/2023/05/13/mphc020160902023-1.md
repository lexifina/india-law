This application coming on for conciliation this day, the Bench passed
the following:
ORDER
Heard on I.A.No.3938/2023, which is an application for condonation of
delay.
The petition is barred by 260 days.
For the reasons stated in the application, I.A.is allowed. The delay is
condoned.
This MCC is filed for restoration of M.A.No.1397/2022 which was
dismissed for non-compliance of common conditional order.
Considering the averments made in the application, which is duly
supported by an affidavit, it is found that sufficient cause is shown for
restoration of the appeal.
Accordingly, the MCC is allowed. M.A.No.1397/2022 is restored to its
original number.
The default of Court fees as pointed out by the Registry be cured within
six weeks.
List after six weeks.
A copy of this order be kept in the file of M.A.No.1397/2022.
Certified copy as per rules.
