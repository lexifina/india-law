This is an application seeking correction of a typographical mistake in
the order dated 26.09.2016. It is stated that the registration number of the
hypothecated vehicle “SWIFT/ZDI” has wrongly been noted as “DL-6CM-6911” whereas the same has to be corrected as “SWIFT/ZDI” bearing
registration number “DL-6CN-6911”
The application is allowed.
Accordingly, in the order dated 26.09.2016 the registration number of
the hypothecated vehicle “SWIFT/ZDI” shall be read as “DL-6CN-6911”.
JAYANT NATH, J
