CORAM: HONOURABLE MR. JUSTICE JAYANANDAN SINGH
ORAL ORDER
3 19-06-2013 This restoration application has been filed for
restoration of C.W.J.C.No.6032 of 2012 which was dismissed for
non-compliance of the order dated 3.4.2012.
By the said order, this Court had directed for issue of
notice on respondent nos.4, 5 and 10 under registered cover with
A.D. as well as through ordinary process and petitioner was
directed to file requisites for the same within one week. Petitioner

Patna High Court MJC No.412 of 2013 (3) dt.19-06-2013
2/2
did not file requisites within the peremptory time granted and
therefore, the writ application stood dismissed.
Order was passed on 3.4.2012 and the petitioner has
filed this restoration application only in January, 2013 i.e. eight
months after. Delay in filing this application disentitles the
petitioner from getting an order of this Court for restoration of the
writ application.
This restoration application is dismissed.
However, since petitioner has filed this application
for restoration of the writ application, which stood dismissed due
to non-compliance of peremptory order, he will be at liberty to file
a fresh writ application
.
Pradeep/-
