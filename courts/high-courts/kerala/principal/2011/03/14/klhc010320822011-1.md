 JUDGMENT
On a complaint by the petitioner that in spite of the application
filed by the petitioner for copy of the judgment, it has not been given
a report was called for by this Court. It is pointed out in the report
submitted that the petitioner has filed only an ordinary application.
2. It is pointed out that it will take some time to draw up decree
in the usual course. If the appellant files an urgent application, the
decree can be drafted on priority basis.
3. The learned counsel for the petitioner points out that the
petitioner undertakes to file an urgent application. If such an
application is filed it will be considered in accordance with rule within
two weeks.
 P.BHAVADASAN, JUDGE.
