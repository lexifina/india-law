CORAM : SANDEEP V. MARNE, J.
DATE : NOVEMBER 8, 2023.
P.C.:
1 The Writ Petition will not survive as the same has been filed
challenging the orders passed in execution proceedings filed for
implementation of the order of the Co-operative Court. By separate order
passed today, this Court has set aside the order of the Co-operative Court,
whose order was sought to be implemented in execution proceedings.
Since main order of Co-operative Court is set aside, nothing would
survive in execution proceedings. The Respondent however shall be at
liberty to adopt such other legal remedies as advised.
2 With the above observations, the Writ Petition is disposed of.
