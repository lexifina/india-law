P.C. :
1. This is an application for condonation of delay in preferring an
application for leave to appeal. The application is moved by original
first informant. Acquittal of respondents 1 and 2 is sought to be
challenged but there is some delay in preferring the application for
leave to appeal.

2. Heard the learned Advocate appearing for the applicant as well
as the learned Advocate appearing for respondent no.2. None
appeared for respondent no.1. The learned Additional Public
Prosecutor appeared for respondent no.3 / State.
3. Though the learned Advocate appearing for respondent no.2
vehemently opposed the application for condonation of delay,
pleadings made in the application demonstrate sufficient cause in not
preferring the application for leave within limitation. In this view of
the matter, the following order;
:: ORDER ::
(i) The delay in filing the application for leave to appeal
is condoned.
(ii) The application is disposed of accordingly.
