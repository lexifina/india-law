ORDER:- This Petition coming on for orders on this day and upon perusing the
petition and the affidavit filed in support thereof and upon hearing the arguments of
M/s. R Sundar, Advocate for the Petitioner and of M/s. D.Balamurugapandi,
Advocate for the respondent, this Court made the following order:
 This Criminal Miscellaneous Petition is filed to restore the above Crl.R.C. to
file of this Court, which was dismissed for default on 23.11.2023.
2. Mr.D.Balamurugapandi, learned counsel appearing for the respondent has
no objection to set aside the order dated 23.11.2023 and to restore the Crl.R.C.
3. Therefore, the order dated 23.11.2023 passed by this Court in the above
Crl.R.C. is set aside. Accordingly, Crl.R.C.(MD) No.595 of 2021 is restored to the file
of this Court and is taken up for final hearing today itself.
