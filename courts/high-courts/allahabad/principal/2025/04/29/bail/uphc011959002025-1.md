# Allahabad High Court, BAIL/13677/2025, 2025-04-29

Neutral Citation No. - 2025:AHC:66163
Court No. - 65
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 13677 of
2025
Applicant :- Ghulam Mohammad
Opposite Party :- State of U.P.
Counsel for Applicant :- Sarve Nazir,Zafar Abbas
Counsel for Opposite Party :- G.A.,Keshari Nath Tripathi
Hon'ble Krishan Pahal,J.
1. After some argument, Sri Zafar Abbas, learned counsel for the
applicant states that he does not wish to press this application as
there is some error in the bail application, as such, a prayed has
been made that this application be dismissed as withdrawn with
liberty to file a fresh bail application.
2. Sri Pushpenra Vishwakarma, Advocate holding brief of Sri
Keshari Nath Tripathi, learned counsel for the informant as well as
Sri Sunil Kumar, learned AGA have no objection to the aforesaid
request.
3. The application is, accordingly, dismissed as withdrawn with
aforesaid liberty.
4. Office is directed to return the certified copies, if any, to the
learned counsel for the applicant as per Rules of this Court.
Order Date:- 29.4.2025
