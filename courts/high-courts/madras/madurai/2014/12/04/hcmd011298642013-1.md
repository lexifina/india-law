ORDER
Heard the learned Counsel for the petitioner as well as the
learned Additional Public Prosecutor appearing for the respondent.
2. This Criminal Original Petition has been filed seeking to
direct the respondent to file a charge sheet in Cr.No.125 of 2011
expeditiously, within a time stipulated by this Court.
3. The learned Additional Public Prosecutor for the respondents,
on instructions, submitted that after investigation, the charge sheet
has been filed on 05.11.2014 and the same has been taken on file in
S.T.C.No.97 of 2014 on the file of the learned Judicial Magistrate No.I,
Kuzhithurai, under Sections 279 and 338 I.P.C.
4. Recording the same, this Criminal Original Petition is closed.
