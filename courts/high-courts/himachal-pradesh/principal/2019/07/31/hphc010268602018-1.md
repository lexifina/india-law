1 Whether the reporters of Local Papers may be allowed to see the judgment?

2. Prayer so made is allowed with the observations that
if any fresh application is filed before the learned Trial Court, the
same be decided on merit, uninfluenced by any observation
made by the learned trial Court in its earlier order which was
passed in the application, which has now been permitted to be
withdrawn, because as a result of the application itself having
been permitted to be withdrawn, the order so passed on the
same is rendered inoperative.
3. Present petition having been rendered infructuous,
now is also disposed of as such. Pending miscellaneous
application(s), if any, stand disposed of.
