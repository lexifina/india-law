1. Heard the learned counsel for the Applicant and the learned
counsel for the Respondent.
2. This application is for condonation of delay in filing certified copy
of decree when the appeal was presented. The copy of Judgment was
already filed within time. The Appeal has already been admitted. Order
41 Rule 1 of the Code of Civil Procedure requires copy of the judgment to
be filed along with the appeal. In view of this, the delay if any stand
condoned. The Civil Application is accordingly disposed of.
[C.L.PANGARKAR]
