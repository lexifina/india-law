PER COURT:
This is an application seeking restoration of the main
criminal application for quashment, as it was dismissed by the common
order passed in several matters dated 29.01.2024 directing amendment
to be carried out and the charge-sheet to be annexed within four weeks
failing which the matters were directed to be dismissed.
2. The learned advocate for the applicants submits that a copy
of the charge-sheet was already placed on record but only the
amendment had remained to be carried out.
3. The application is allowed. The main criminal application is
restored. Amendment to be carried out within one week.
