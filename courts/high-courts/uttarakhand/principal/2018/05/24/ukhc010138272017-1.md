# High Court of Uttarakhand, WPMS/3150/2017, 2018-05-24

MCC No.650 of 2018
CLMA No.6205 of 2018
In:
WPMS No.3150 of 2017
Hon’ble Sharad Kumar Sharma, J.
Mr. Kurban Ali, Advocate for the
petitioners.
Mr. P.S. Bisht, Standing Counsel for
the State.
Mr. D.C.S. Rawat, Advocate for
respondent nos.2 & 3.
Heard on Delay Condonation
Application as well as Review Application.
Considering the grounds taken in
delay condonation application for filing the
review has been satisfactorily explained.
The delay condonation application is
allowed. The delay in filing the review
application is condoned.
However, after going through the
judgment which has been sought to be
reviewed and the grounds taken in the
review application, this Court does not think
that it is at all required to review the order as
passed by this Court on 13.12.2017, as only
an application under Section 201 has been
directed to be considered in accordance with
law.
Thus, the review application stands
rejected.
 (Sharad Kumar Sharma, J.)
