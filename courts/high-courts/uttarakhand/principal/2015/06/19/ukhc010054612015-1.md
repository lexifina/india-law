# High Court of Uttarakhand, WPSB/225/2015, 2015-06-19

WPSB No.225 of 2015
Honíble V.K. Bist, J.
Honíble U.C. Dhyani, J.
 Mr. D.S. Patni, Advocate for the
petitioner.
 Mr. Pradeep Joshi, Standing Counsel
for the State of Uttarakhand.
 Heard learned counsel for the parties.
Learned counsel for the petitioner seeks
permission of this Court to withdraw this writ
petition with liberty to file fresh.
Permission is granted.
The writ petition is dismissed as
withdrawn with liberty to file fresh.
Interim relief application stands
rejected.
Let a certified copy of this order be
supplied to the learned counsel for the
petitioner, today itself, on payment of usual
charges.
