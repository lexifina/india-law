# High Court of Madhya Pradesh, MCC/2847/2016, 2016-11-04

MCC-2847-2016
(M/S JAIN SONS Vs THE STATE OF MADHYA PRADESH)
04-11-2016
Shri Sanjay Mishra, learned counsel for the applicant.
 Shri Amit Seth, learned Govt. Adv. for the respondents on
advance notice.
 This application has been filed for restoration of WP
No.12480/2012, which was dismissed for want of
prosecution. There being some delay in filing of this
application for restoration, I.A. No.14764/2016 has been
filed. The application is supported by affidavit of the
counsel.
 Finding the same to be bonafide, both the
applications are allowed. Condoning the delay in filing
the restoration application, the restoration application
itself is allowed. 14764/2016 is restored to its original
file. It be placed for orders before an appropriate Bench.
 Application stands allowed and disposed of.
(RAJENDRA MENON)
ACTING CHIEF JUSTICE
(SMT. ANJULI PALO)
JUDGE
mrs. mishra
