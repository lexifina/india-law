HON'BLE MR. JUSTICE SANDEEP MEHTA
Judgment / Order
03/05/2017
Learned counsel Shri Joshi submits that as an order
prohibiting coercive action has been passed in favour of the
petitioner in S.B. Criminal Misc. (Pet.) No. 2570/2016, presently,
he cannot entertain any apprehension of arrest. He thus, craves
liberty to withdraw this pre-arrest bail application seeking leave to
file a fresh one if occasion so arises.
Learned Public Prosecutor and the learned counsel
representing the complainant do not object to the said
submission.
Thus, this application for pre-arrest bail is dismissed as
withdrawn with the liberty as prayed for.
(SANDEEP MEHTA)J.
