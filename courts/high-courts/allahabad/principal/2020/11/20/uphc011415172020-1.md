# Allahabad High Court, TACL/258/2020, 2020-11-20

Court No. - 65
Case :- TRANSFER APPLICATION (CIVIL) No. - 258 of 2020
Applicant :- Smt. Vibha
Opposite Party :- Ravi Pratap Singh
Counsel for Applicant :- Ram Sajiwan Prajapati,Munendra Nath
Chaubey
Hon'ble Saumitra Dayal Singh,J.
1. A report has been made that the proceedings being
sought to be transferred are pending before the Principal
Judge, Family Court, Lucknow. Therefore, the application
is entertainable by this Court at Lucknow Bench and not
at Allahabad.
2. The report appears to be correct.
3. Learned counsel for the applicant prays and is allowed
to withdraw the present application with liberty file a fresh
application before the Lucknow Bench.
4. Present application stands dismissed as withdrawn.
Order Date :- 20.11.2020
