# Madras High Court, A/6227/2019, 2019-10-01

A.No.6227 of 2019
in
C.S.No.480 of 2013
N.SATHISH KUMAR, J.
This application has been filed to
allow the plaintiff to amend the
typographical errors in the plaint.
2. The learned counsel for the
respondent has no objections in allowing
this application.

3. Having regard to the fact that
the amendment is sought only to amend
the typographical errors in the plaint,
this application is ordered as prayed for.
4. Post the suit on 18.10.2019 for
framing issues.
5. The plaintiff is permitted to
carryout the amendment and file the
amended copy of the plaint by then.
