# Calcutta High Court, CRR/2617/2021, 2023-04-03

03.04.2023 IN THE HIGH COURT AT CALCUTTA
 Item No.12 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
C.R.R. 2617 of 2021

 M/s Venagro & Ors.
 versus
 Incred Financial Services Ltd
In Re: An Application under Section 482 of the Code of
Criminal Procedure, 1973.
Mr. Gaganjyot Singh,
Mr. Abhishek Bagal … For the Petitioners.
Mr. Koushik Kundu … For the Opposite Party.
Learned advocates for the petitioners and the opposite
party are present.
Learned advocate for the petitioners files certified copy
of the order dated 28.03.2023 which reflects that the
complainant filed an application under Section 257 of the
Code of Criminal Procedure and the operative part of the
order so passed by the learned Metropolitan Magistrate, 19th
Court, Calcutta reflects that the accused persons have been
acquitted of the charges.
Having considered the order dated 28.03.2023 passed
by the learned Metropolitan Magistrate, 19th Court, Calcutta,
I am of the opinion that the purpose for which this revisional
application was filed has been subserved. No further
proceeding is required in the present revisional application as
the same is covered by the order passed by the learned
Metropolitan Magistrate, 19th Court, Calcutta in Case No.
CS/28381/21.

2
Consequently, the revisional application being CRR
2617 of 2021 is disposed of.
All pending connected applications, if any, are
consequently disposed of.
Let the certified copy so filed be kept with the record.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance with all
requisite formalities.
 (Tirthankar Ghosh, J.)
