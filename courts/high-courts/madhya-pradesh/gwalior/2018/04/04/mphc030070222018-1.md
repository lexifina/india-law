# High Court of Madhya Pradesh, MCRC/11515/2018, 2018-04-04

THE HIGH COURT OF MADHYA PRADESH
MCRC-11515-2018
(GIRISH SHARMA Vs THE STATE OF MADHYA PRADESH THR)
Gwalior, Dated : 04-04-2018
Shri Lokendra Shrivastava, Counsel for the applicant.
Shri S.S. Dhakad, Public Prosecutor for the respondent/State.
Shri Brajesh Tyagi, Counsel for the complainant.
Case diary is available.
This is second application filed under Section 439 of Cr.P.C. for
grant of bail. The first application was dismissed as withdrawn by
order dated 7.3.2018 passed in M.Cr.C.No.8210/2018 with liberty to
file a properly constituted application.
During arguments, again it was realized by the counsel for the
applicant that some more documents are to be filed in support of the
submissions and, therefore, he seeks permission of this Court to
withdraw this application once again with liberty to file a properly
constituted application with all possible documents in support of the
claim of the applicant.
With aforesaid liberty, the application is dismissed as
withdrawn.
(G.S. AHLUWALIA)
