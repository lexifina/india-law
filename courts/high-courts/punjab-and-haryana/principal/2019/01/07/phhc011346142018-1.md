Mr. K.S. Cheema, Advocate has put in appearance on behalf of
respondents-landlord and submits that original rent note has already been
produced on file and the same is admitted document and can be put to the
respondent-landlord Davinder Singh in his cross-examination.
Learned counsel for the petitioner-tenant submits that in his
statement, respondent-landlord Davinder Singh referred to the rent note,
produced the photocopy and original was not placed on file.
Learned counsel for respondents-landlord submits that in case,
original rent note has not been placed on file, the same will be placed on file
at the time of cross-examination of respondent-landlord Davinder Singh.
Learned counsel for petitioner-tenant submits that in case,
original is already on file or is produced on file, petitioner-tenant will refer
to that document in cross-examination. SACHIN MEHTA

HIGH COURT, CHANDIGARH

CR-8895-2018 -2-
As this petition is not contested, the same is disposed of with
order that respondent No.1-landlord Davinder Singh will put the rent note
(in original, if already not produced) or photocopy, if already produced by
the respondent-landlord. If the petitioner-landlord still has any objection to
the photocopy, he will produce original rent note on file and will be
confronted with the same.
It is, however, made clear that in case, the petitioner find any
difference between the photocopy and the original rent note produced by the
respondents-landlord, she can move an application before the Rent
Controller to this effect, which will be decided on merits.
