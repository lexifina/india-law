ORDER
This Crl.M.C is filed challenging Annexure A7 order of the
Judicial First Class Magistrate Court- II, Perambra. Annexure A7 is
an order passed in a petition filed under Section 451 Cr.P.C. There is
no interim order passed in this case. This Clr.M.C is pending before
this Court from 2015 onwards. Probably the challenge against the
impugned order might have been infructuous at this distance of time.
Therefore, this Crl.M.C is closed.
