ORDER
This case is taken up through video conferencing.
2. This Criminal Revision Petition has been filed to set
aside the order dated 30.07.2020 made in Crl.M.P.No.220 of 2020
on the file of the Principal Special Judge (FAC) under EC and
NDPS Act Court, Chennai.
3. In this case, the actual number of the vehicle is TN-05-
BM-2486 but whereas, the accused has been plying it with TN-05-
BM-8624. In such view of the matter, this is not a fit case for
return of the vehicle to the petitioner. https://hcservices.ecourts.gov.in/hcservices/

4. Accordingly, this Criminal Revision Petition is
dismissed.
