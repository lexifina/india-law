# High Court of Orissa, WP(C)/21698/2017, 2018-02-07

04. 07.02.2018 W.P.(C) No.21698 of 2017
 Learned counsel for the petitioner submits that inadvertently some important pleadings
 have been left out, as such prayer has been made to permit the petitioner to withdraw this wr
it petition with liberty to file better application.
 He has filed memo to that effect.
 In view thereof the case is permitted to be withdrawn.
 Accordingly the case is dismissed as withdrawn.
 The petitioner is at liberty to file better application, if he so wishes. With
drawal of this case will in no way prejudice the case of the petitioner in future.

 S.N. Prasad, J.
