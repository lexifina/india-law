JUSTICE DINESH MEHTA
Order
11/08/2021
Mr. Tanwar Singh, learned counsel appearing for the
applicant points out that in the order dated 6.7.2021 passed in
SBCWP no.4633/2020, the petitioner’s name has wrongly been
inscribed as “Kamlesh Chand Meena” instead of “Kailash Chand
Meena”.
Learned counsel further submits that when the application
(IA No.1/2021) was disposed of a liberty to file fresh writ petition
was prayed for, which was however, not inscribed in the order
dated 6.7.2021.

(2 of 2) [WMAP-194/2021]
In view of the above, the present application is allowed. The
name of the petitioner be read as “Kailash Chand Meena” in place
of “Kamlesh Chand Meena” and third para of the order dated
6.7.2021 be read as under:
“The writ petition stands dismissed as withdrawn with liberty
to file fresh”.
