P.C. :
1. Heard learned counsel for the applicant and learned
APP for the State.
2. This is a second application for bail in respect of the
offence punishable under Sections 302, 511 read with 34 of
the Indian Penal Code (hereafter ‘IPC’ for short) registered
on 17.06.2019 vide C.R. No.I-241 of 2019 with Ulhasnagar
Police Station.
3. Learned counsel for the applicant submits that the first
bail application was rejected on 16.02.2023 on merits. It is
submitted that there is no progress in the trial. The

5. The application is allowed to be withdrawn with liberty
as prayed for and disposed of accordingly.
