P.C.
This application is for restoration of the Second
Appeal No.921 of 2003 which was dismissed for non
compliance of the conditional order dated 2nd August,
2006. By that order, Second Appeal was admitted and
the appellants were directed to file private book along
with sufficient number of copies thereof within one year
from the date of order. Since the private paper book
was not filed, the Second Appeal stood dismissed.
2] Learned counsel for the applicant sates that within
one week from today they will file private paper book with
sufficient number of copies. In view thereof, Civil
Application is allowed. Second Appeal is restored to the
file of this Court. Time as originally fixed in the order
dated 2nd August, 2006 is extended till 10th March, 2011.
