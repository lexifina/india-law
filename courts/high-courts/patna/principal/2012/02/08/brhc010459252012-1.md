CORAM: HONOURABLE MR. JUSTICE AKHILESH CHANDRA
ORAL ORDER
2 08-02-2012 Heard learned counsel representing the parties.
This is an application seeking restoration of Cr. Misc. No.
42936 of 2011 dismissed for non-prosecution vide order dated 03.01.2012 in
connection with Bairgania P.S. Case No. 17 of 2011, pending in the Court of
Chief Judicial Magistrate, Sitamarhi.
This Court does not find any merit in this application.
Accordingly, the same stands dismissed with a liberty to file fresh application
within fortnight, if mandatory provisions under Section 438 of the Code of
Criminal Procedure is available.
