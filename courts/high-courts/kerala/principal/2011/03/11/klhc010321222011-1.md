JUDGMENT
The grievance of the petitioner is that carbon copy of the order in
O.P.(Arb) No.1257 of 2010 on the file of the Court of the Principal District
Judge, Ernakulam, was not issued. The Registry got information that no
application for carbon copy was filed by the petitioner and that an ordinary
application for certified copy was filed. The application for certified copy
will be complied with in accordance with the priority. It is also informed that
if the petitioner files an urgent application, copy can be issued within a day.
Learned counsel for the petitioner submitted that though an application for
carbon copy was filed and it can be seen from the records that such an
application was filed, to avoid any complication, the petitioner will file an
urgent application today itself. If such an application is filed, copy shall be
issued within a day.
The Original Petition is disposed of as above.
Issue certified copy of the judgment today itself.
(K.T.SANKARAN)
