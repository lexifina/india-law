# High Court of Madhya Pradesh, MCC/2397/2015, 2015-08-18

MCC-2397-2015
(RAMNATH Vs PARASRAM)
18-08-2015
Shri P.S.Das, learned counsel for the applicant.
Ms. Vandana Kasrekar, learned PL for the respondent No.2/State.
This application has been filed for restoration of Second Appeal
No.492/2003, which was dismissed for want of prosecution vide
order dated 09/12/2014. There being some delay in filing the
application for restoration, therefore, I.A. No.10464/2015 has been
filed seeking condonation of delay. Both the applications are
supported by an affidavit of the applicant himself and there is no
reason to disbelieve the same. Finding the same to be bona fide,
both the applications are allowed.
Condoning the delay in filing the application, restoration
application is itself allowed.
Second Appeal No.492/2003 is restored to its original
number.
After restoration, Second Appeal No.492/2003 be placed for
orders before appropriate Bench.
Application stands allowed and disposed of.
Certified copy as per rules.
(VANDANA KASREKAR)
JUDGE
