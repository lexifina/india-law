# High Court of Orissa, WP(C)/7017/2018, 2019-02-05

04. 05.02.2019 Heard.
 This writ application has been filed for a
petty matter like non-renewal of Pass to the Secretariat
Building and the petitioner is stated to be a Journalist.
 The petitioner, if so advised, may file a
representation/application in this regard before the O.P.
No.1 for renewal of Pass. If such a representation/
application is filed within a period of three weeks from
today, the same shall be disposed of on merit in
accordance with the relevant Rules.
 With the aforesaid observation, the writ
application is disposed of.
