P.C.:
1. Upon urgent mentioning, taken on production board.
2. This Application is moved for restoration of Writ Petition,
which was dismissed for non-prosecution by order dated 17th
September, 2018 passed by this Court.
3. The learned counsel for the applicant submitted that he could
not attend the matter on that day due to domestic problem and,
therefore, the matter was dismissed for non-prosecution. Hence,

he prays that the order dated 17th September, 2018 be set aside
and the Petition be restored.
4. The learned APP submits to the order passed by this Court.
5. In view of uncontroverted submissions and the reasons
mentioned in the Application, the order dated 17th September, 2018
is hereby set aside. Writ Petition is restored to its original file along
with interim orders, if any, passed therein.
6. Criminal Application is allowed and accordingly disposed of.
7. Place the Writ Petition for admission on 20th February, 2019.
