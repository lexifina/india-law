Judgment
Siri Jagan, J.
The State is the appellant herein. The State
acquired certain properties belonging to the first respondent
herein for the purposes of the second respondent by a
notification dated 27.09.2005 issued under Section 4(1) of the
Land Acquisition Act. The land acquisition officer fixed land
value Rs.65,824/- per are. On reference, the Third Additional
Sub Court, Ernakulam enhanced the land value to
Rs.1,86,939/- per are in L.A.R.No.307/2008. Aggrieved by the
land value fixed by the Sub Court, the State has filed this
appeal.
2. It is submitted that the Sub Court re-fixed the
land value on the basis of Ext.A1 sale deed, which was a
mutually agreed sale deed between the claimant in that case

LAA No.1186/10 2
and the requisitioning authority. The question as to whether
that value can be adopted for other lands, was considered by
this Court in L.A.A.No.272/10 against L.A.R.No.163/08 of the
same Court and ultimately, this Court re-fixed the land value @
Rs.57,000/- per cent. (Rs.1,40,790/- per are). Therefore, the
learned Government Pleader submits that insofar as the
property involved in L.A.A.No.272/10 is comparable to the land
involved in this appeal, same land value should be fixed for
this land also.
3. We have considered the contentions of both
sides.
4. In L.A.A.No.272/10, this Court was considering
the land value for a comparable land. The land acquisition
officer fixed land value @ Rs.65,824/- per are and the Sub
Court re-fixed the land value @ Rs.75,684/-per cent, which is
also equivalent to the land value fixed by the Sub Court in this
case. That being so, the two properties can be said to be
comparable. Since for comparable properties, this Court has

LAA No.1186/10 3
re-fixed land value Rs.1,48,847/- per are, we re-fix the land
value in this case also as Rs.1,48,847/- per are.
The appeal is disposed of as above.
