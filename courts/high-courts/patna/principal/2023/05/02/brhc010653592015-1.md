ORAL ORDER
2 02-05-2023 Heard learned counsel for the parties.
This application has been filed for quashing of the
order dated 08/07/2015 in Copml. Case No. 949/2013 by which
learned Magistrate has returned the original complaint case to
file before the competent court having jurisdiction in the matter.
By the impugned order, the complaint had returned to
the petitioner to file in the court of appropriate jurisdiction, I
don not find any illegality in the matter.
Accordingly, this application is dismissed.
