ORDER
Learned counsel for the petitioner would submit that the order granting time
to file the application to set aside the ex parte order was not communicated to the
petitioner and therefore he was not able to file the petition within the time and filed
this petition with a prayer to grant one week time to take out the necessary
application as ordered by this Court.
2. I have considered the submission made by the learned counsel for the
petitioner. This Court by order dated 02.08.2023, considering the facts and
circumstance of this case, had granted four weeks time to the petitioner to take out
the necessary application to set aside the ex parte order. Considering the fact that an
order of attachment to the properties has been made, the time is extended by a
period of one week from today(10.09.2025), to the petitioner to file an application to
