# High Court of Madhya Pradesh, MCC/161/2014, 2014-03-27

M.C.C.No.161/2014
27.03.2014
Ms. Bhagyashree Sugandhi, learned counsel for the
applicant.
Heard learned counsel for the applicant.
This is an application under Section 152 of CPC for
correction as typing mistake has occurred in the order dated
06.01.2012, wherein it was described that the appeal was
preferred against the award dated 15.04.2010 passed by the
MACT, Khargone.
Infact perusal of the original record shows that the
award was passed by 19th Member MACT, Indore. Thus, we
allow the application. In the order dated 6.01.2012 “MACT,
Khargone” be read as “19th Member MACT, Indore”
The application stands allowed and closed.
M.C.C. is disposed of.
A copy of the order be retained in the file of
M.A.No.2684/2010.
 (S.K.SETH) ( M. C. GARG )
 JUDGE JUDGE
