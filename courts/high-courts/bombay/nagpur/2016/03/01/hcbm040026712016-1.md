This application is filed by Gopal Durugkar. In this
application Criminal Application (APPP) No.240/2016 is filed
seeking amendment to the cause title of Criminal Application
(ABA) No.57/2016. It is stated that the name of the applicant
is Gopal Haribhau Dharpure and not Gopal Durugkar as stated
in Criminal Application (ABA) No.57/2016.

is filed by a person whose existence itself is in doubt and,
therefore, the application cannot be entertained. The
application is dismissed with liberty to Gopal Haribhau
Dharpure to file appropriate application, if so advised.
