PER COURT :
1. Heard both sides.
2. For the reasons stated in the application,
the delay of 571 days occurred in filing the first
appeal is hereby condoned. The application is
accordingly allowed.
3. The first appeal stands admitted, on

 (2) ca6473-13
registration thereof. Print of the paper-book is
dispensed with. By consent of learned counsel for
the parties, the appeal is taken up for final hearing
since the short issue of remand is involved.
4. The impugned award of the learned Reference
Court shows that the land acquisition reference was
earlier registered as Land Acquisition Reference No.
5/2001. It was, however, thereafter re-numbered as
Land Acquisition Reference No. 169/2010. The learned
Reference Court rejected the reference application as
the present appellant failed to appear in the
proceeding for a very long period. In the
circumstances, observing that the land acquisition
reference was pending for a period of ten years,
ultimately, for want of evidence, the reference
application was rejected.
5. The learned counsel for the appellant
submits that the advocate on record for the present
appellant in the proceedings before the learned
Reference Court did not at any time communicate to
the appellant that the reference application was
being adjourned for hearing. In the meantime, he

 (3) ca6473-13
went to Ahmednagar in order to earn the livelihood.
When he contacted the advocate, he came to know that
the reference application was already rejected.
6. Considering all these facts on record, the
impugned award of the Reference Court is hereby
quashed and set aside. Instead, the case is remanded
to the Reference Court to decide the reference
application afresh, on the condition that the present
appellant appears before the learned Reference Court
on 15th October, 2013 and within a period of sixty
days from the date of appearance of the present
appellant, concludes the evidence from his side.
Further, the present appellant would not be entitled
for statutory interest on the compensation, if any,
awarded by the learned Reference Court, from the date
of first default in appearance before the learned
Reference Court till this date. With these
observations, the appeal is disposed of, without any
order as to costs.
