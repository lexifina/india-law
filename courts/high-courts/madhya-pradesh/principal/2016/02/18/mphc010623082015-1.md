# High Court of Madhya Pradesh, MCRC/21545/2015, 2016-02-18

MCRC-21545-2015
(AVINASH MISHRA Vs THE STATE OF MADHYA PRADESH)
18-02-2016
Shri S.N. Vishwakarma, learned counsel for the
applicants.
Ms. Sharda Dubey, learned Panel Lawyer for the
respondent/State.
After arguing for some time, learned counsel for the
applicants seeks leave to withdraw this application with
liberty to the applicants to surrender before the trial
Court and file an application for regular bail.
With the aforesaid liberty, the M.Cr.C. is dismissed as
withdrawn.
In case the applicants submit an application for regular
bail, the trial Court shall consider and pass appropriate
order on it on the same day if possible.
Certified copy as per rules.
(SHANTANU KEMKAR)
JUDGE
