ORAL ORDER
1. By way of this application, the applicant-convict seeks parole
leave for a period of 30 days so as to enable him to file appeal
before this Court.
2. Learned advocate for the applicant states at bar that the
applicant though preferred parole leave application so as to enable
him to file appeal against the judgment of conviction recorded on
02.01.2019, but the competent authority has not accepted his
application.
3. In light of this position, the competent authority is directed to
consider present application as parole leave application of the
applicant-convict and decide the same as expeditiously as possible
in accordance with law.

4. With the above direction, present application stands disposed
of.
(S.H.VORA, J)
