Dated this the 16th day of June, 2014
JUDGMENT
Ext. P2 order passed on an execution application filed
under Order XXI Rule 97 of the Code of Civil Procedure is
impugned. Such order is appealable under Order XXI Rule 103 of
the Code of Civil Procedure and hence the Writ Petition is not
maintainable.
2. The Writ Petition is dismissed without prejudice to the
right of the petitioners to file a statutory appeal if so desired.
The fact that the Writ Petition has been pending on the file of
this Court shall be taken note of while condoning the delay. The
parties shall maintain status quo as on today for a period of one
month.
V.CHITAMBARESH
