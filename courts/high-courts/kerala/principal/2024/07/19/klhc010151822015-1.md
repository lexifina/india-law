ORDER
This Criminal Miscellaneous Case is filed to quash
Annexure A2 complaint. This Criminal Miscellaneous Case is
pending before this Court from 25.02.2015. No interim order
staying the proceedings of the lower court had passed in this
Court.
2. When this Criminal Miscellaneous Case came up for
consideration on 25.02.2015 this Court ordered notice but
process was not served even now. Hence, this Criminal
Miscellaneous Case is listed in the defect list. Moreover, the
number of the case which is pending before the trial court
based on Annexure A2 is not clear from the Criminal
Miscellaneous Case also. Therefore, this Court is not in a
position to verify with the trial court about the present stage of
the case.
3. Probably the case might have been disposed of.

CRL.MC 1003/2015
3
4. In such circumstances, I am of the considered opinion
that this Criminal Miscellaneous Case need not be retained
here. If the case is pending before the trial court, all the
contentions raised by the petitioner in this Criminal
Miscellaneous Case are left open. The petitioner is free to raise
the same before the trial court at the appropriate stage.
With the above observations, this criminal miscellaneous
case is disposed of.
