ORDER:
Heard both sides.
The petitioner appeared for the common entrance test for
admission into B.Ed. course for the academic year 2006-07. The
question papers in the entrance test were arranged in four different
series viz., A, B, C and D, and the questions in all the series are same
but they are arranged in different order. It is the grievance of the
petitioner that he was given ‘D’ code question paper, but subsequently
the invigilator took back the same and given another question paper
with ‘C’ code. It is the case of the petitioner that he had spent valuable
time by answering
‘D’ code question paper and the said question paper has to be valued.
This Court by order dated 30-10-2006 had directed the
respondent to value ‘D’ code question paper only answered by the
petitioner in the common entrance test, pending further orders. It is
stated that in compliance of the said order, ‘D’ code question paper
was valued and the petitioner was given a rank in the said
entrance test.
On instructions, it is not disputed that initially the petitioner
was given ‘D’ code question paper only. Inasmuch as there was no
mistake on the part of the petitioner and as ‘D’ code question paper

has already been valued, I dispose of the writ petition confirming the
rank given to the petitioner pursuant to the valuation of ‘D’ code
question paper for the purpose of admission.
Subject to above direction, the writ petition is disposed of.
No order as to costs.
