# Allahabad High Court, A482/4306/2010, 2022-07-11

Court No. - 81
Case :- APPLICATION U/S 482 No. - 4306 of 2010
Applicant :- The Ntpc Ltd/Singrauli Super Thermal Power
Station
Opposite Party :- State of U.P. and Another
Counsel for Applicant :- A.N. Singh
Counsel for Opposite Party :- Govt. Advocate
Hon'ble Mrs. Manju Rani Chauhan,J.
Ref:-Order on withdrawal application
Heard Mr. Vivek Ratan Agrawal, learned counsel for the
applicant and learned A.G.A. for the State.
This application has been filed seeking withdrawal of the
application U/s 482 Cr.P.C.
Learned counsel for the applicant states that the applicant does
not want to press the application, therefore, the same may be
dismissed as not pressed.
Learned A.G.A. has no objection to the same being allowed.
Accordingly, withdrawal application is allowed.
Order on Application
Since the withdrawal application has been allowed, the
application U/s 482 Cr.P.C. is, accordingly, dismissed as
withdrawn.
Interim order, if any, stands discharged.
