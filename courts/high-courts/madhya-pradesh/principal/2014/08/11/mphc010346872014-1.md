# High Court of Madhya Pradesh, MCC/1462/2014, 2014-08-11

1
MCC No.1462/2014
11/8/2014.
Shri O. P. Dwivedi, learned counsel for
the applicant.
This application has been filed for
restoration of W.A. No.1443/2010 which has been
dismissed for want of prosecution on 7.7.2014.
Keeping in view the reasons indicated
in the application which is supported by the
affidavit of counsel himself and finding the same
to be bonafide, this application is allowed.
Writ Appeal is restored to its original
file. It be placed for orders before the
appropriate Bench.
With the aforesaid, this application
stands allowed and disposed of.
(Rajendra Menon) (Alok Verma)
