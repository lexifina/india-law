ORDER
This petition is filed on behalf of the defendant being aggrieved of order
dated 16/1/2023 (Annexure-P/5) and order dated 24/6/20223 (Annexure-P/7).
2. Shri Patel, learned counsel for the petitioner, does not press this petition
in relation to order dated 16/01/2023 (Annexure-P/5) by which application under
Order 1 Rule 10, CPC was dismissed.
3. Accordingly, this petition is dismissed in relation to order dated
16/01/2023 (Annexure-P/5) as not pressed.
4. As far as order dated 24/06/2023 is concerned, it is submitted that the
original defendant is suffering from Hemiplegia with HTN and he had been
declared to be medically unfit vide certificate Annexure-P/3 issued by Dr.
Sushant Muley, MD, DNB Chest IDMC, Welltreat Multispeciality Hospital Pvt.
Ltd. It is submitted that overlooking to the condition of the defendant,
impugned order has been passed.
5 It is submitted that if some reasonable time is granted, then defendant will
file written statement.
6. Accordingly, looking to the medical condition of the defendant,
impugned order dated 24/6/2023 is set aside. It is directed that now written
