Coram : A.P. Lavande And
 P.D. Kode, JJ.
 Dated : 23rd March 2009.
Heard Mr. Mohta, learned counsel for the
applicant.
This is an application for permission to
amend Writ Petition No. 1594/1995 on the ground that
certain subsequent events have taken place during
pendency of the petition.
Mr. Patil, learned counsel for respondent
no.1 opposes the application on the ground that cause
of action mentioned in the application is an
independent cause of action and, therefore, the
petitioner has to file fresh petition.
In view of the above, Mr. Mohta, learned
counsel for the petitioner seeks leave to withdraw the
application with liberty to file petition. The application
is allowed to be withdrawn with liberty to the

2
petitioner to avail appropriate remedy available in law.
Application stands disposed of.
JUDGE JUDGE
Ambulkar.
