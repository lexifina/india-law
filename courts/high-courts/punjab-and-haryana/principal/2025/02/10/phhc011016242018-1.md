CM-1654-CWP-2025
 This is an application filed under Section 151 of the Code of
Civil Procedure seeking preponement of the date of hearing of the main case
(CWP-29634-2018).
 For the reasons mentioned in the application, the same is
allowed and the main case (CWP-29634-2018), which is otherwise fixed for
08.05.2025, is preponed and is taken on board today itself.

CM-1655-CWP-2025
This is an application filed under Section 151 of the Code of
Civil Procedure for withdrawal of the main case (CWP-29634-2018).
For the reasons stated in the application, the same is allowed as
prayed for and the main case (CWP-29634-2018), is dismissed as
withdrawn.
 Application stands disposed of accordingly.
