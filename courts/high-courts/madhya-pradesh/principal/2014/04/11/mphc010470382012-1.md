# High Court of Madhya Pradesh, WP/18425/2012, 2014-04-11

W.P. No.18425/12
11/04/14
Shri Dinesh Upadhyay, Advocate for the petitioner.
Shri Vivek Agrawal, Dy.A.G. for the respondents-State.
Shri T.K.Khadka, Advocate for respondent no.7.
We agree with the preliminary objection raised by the
respondents that this petition should not be entertained as
identical issue is already pending consideration before the
Apex Court.
The petitioner can await decision of the Apex Court and
if any issue raised by the petitioner is still required to be
redressed, will be free to get this petition revived, if so advised.
That application will be considered on its own merits.
Petition disposed of, accordingly.

 (A.M.Khanwilkar) (K.K.Trivedi)
 Chief Justice Judge
