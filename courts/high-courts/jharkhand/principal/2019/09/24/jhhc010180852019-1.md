3/ 24.09.2019 Heard learned counsel for the parties.
 Counsel for the petitioner confines this application only to
challenge the order dated 22.04.2019 passed by the Judicial Magistrate
First Class, Jamshedpur in C/1 Case No.589 of 2015, by which process
under Section 82 of the Code of Criminal Procedure has been ordered to
be issued against the petitioner.
 Perusal of impugned order dated 22.04.2019 does not reveal
any appropriate reason necessitating issuance of process under Section
82 of the Code of Criminal Procedure and accordingly, the said order is,
hereby, quashed and set aside.
 This application is allowed.
 However, the learned Court below is at liberty to proceed
further in accordance with law.
 Let a copy of this order be communicated through FAX to the
Court concerned at the cost to be deposited by the petitioner.
( Ananda Sen, J.)
