# High Court of Madhya Pradesh, MCRC/10731/2017, 2017-10-04

MCRC-10731-2017
(SANDIP Vs THE STATE OF MADHYA PRADESH)
04-10-2017
Shri Yashpal Rathore, learned counsel for the petitioner.
Shri Virendra Khadav, learned GA for the
respondent/State.
Heard.
This is a petition filed only for correction of FIR Number in
the order passed in M.Cr.C. No.9606/2017 on 15/09/2017
by this Court.
It is submitted by counsel for the petitioner that by
mistake FIR number is mentioned as 741, while it should
be 743.
The prosecution has not opposed the prayer.
Considering the facts and the mistake in the order,
petition is allowed. FIR No.741 be read as FIR No.743.
This order shall be read conjointly with the order dated
15/09/2017 passed in M.Cr.C. No.9606/2017.
C.C. as per rules.
(VIRENDER SINGH)
JUDGE
