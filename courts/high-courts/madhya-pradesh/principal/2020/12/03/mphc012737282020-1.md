# High Court of Madhya Pradesh, MCRC/40777/2020, 2020-12-03

THE HIGH COURT OF MADHYA PRADESH
M.Cr.C. No. 40777 / 2020
(Rajesh Mishra @ Arvind Kumar Mishra vs. State of Madhya Pradesh)
Jabalpur, Dated: 03.12.2020
Heard through Video Conferencing.
Mr. Kamlesh Kumar Dwivedi, Advocate for the petitioner.
Mr. Utkarsh Agrawal, Panel Lawyer, for the State.
Mr. Pushpendra Dubey, Advocate for the Objector.
Learned counsel for the petitioner wants to withdraw this bail
application filed under Section 438 of the Code of Criminal procedure, with
liberty to surrender and to move an appropriate application before the
learned trial court.
However, if such an application is moved before the learned court
below, it is requested to deal with the same expeditiously, if possible, on the
same day on which it is filed.
Accordingly, the application is dismissed as withdrawn with the
aforesaid liberty.
 (ATUL SREEDHARAN)
