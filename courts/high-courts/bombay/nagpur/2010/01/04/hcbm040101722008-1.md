C ORAM : F.M. REIS, J.
DATED : 4th January, 2010.
Heard the learned counsel for the applicant.
This is an application for restoration of Second Appeal
No.252/1993 which was dismissed for default on 29/4/2008.
The respondents though served neither remain present nor
filed any reply opposing the application for restoration. As such
the statements made in the application stand uncontroverted.
For the reasons stated in the application dated 6/5/2008
the Second Appeal No.252/1993 is restored.
Fix the matter for final hearing on 14/1/2010.
 JUDGE.
Tambaskar.
