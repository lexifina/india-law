1 The Writ Jurisdiction of this Court is invoked against the order
dated 23-7-2014, by which order the Learned Joint Civil Judge Senior Division,
Thane, allowed the application Exhibit 146 filed by the Defendants for
deciding the preliminary issue prior to considering the application for
amendment.
2 The said order is sought to be challenged on the ground that the
issue could be tried as a preliminary issue under Order XIV Rule 2 of the Civil
Procedure Code only if it is a pure question of law. In the context of the said
challenge, it is required to be noted that the preliminary issue as regards the
jurisdiction and limitation has been framed long back on 3-8-2011 which order
passed by the Trial Court was taken exception to by the Petitioners by filing
Writ Petition No.8068 of 2011 which was dismissed by this Court by order
dated 16-11-2011. It seems that after the matter in so far as the preliminary

issue has progressed substantially, that an application for amendment of the
plaint came to be filed. As indicated above, the framing of the preliminary
issue and trying the same prior to the application for amendment being
considered, is taken exception to by way of the above Petition. Since the issues
have not been framed in the Suit, the adjudication of the said preliminary issue
is not referable to order XIV Rule 2 of the Civil Procedure Code.
3 In my view, having regard to the fact that the preliminary issue
has already been framed, which has been confirmed by this Court by order
dated 16-11-2011, the logical corollary to the same would be that the same is
decided prior to deciding any other application. In that view of the matter, no
case for interference is made out. The Writ Petition is accordingly dismissed.
