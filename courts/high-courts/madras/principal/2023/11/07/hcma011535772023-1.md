# Madras High Court, A/5863/2023, 2023-11-07

A.No.5863 of 2023
in
C.S.(Comm. Div.)No.108 of 2023
ABDUL QUDDHOSE.J.,
This application has been filed to condone the delay of 48 days in
filing the written statement. The learned counsel for the respondent / plaintiff
has no objection for allowing this application. This Court is also satisfied
with the reasons stated in the affidavit filed in support of this application as
sufficient cause has been shown for condoning the delay.
2. Accordingly, A.No.5863 of 2023 is allowed as prayed for and the
written statement of the first defendant is taken on file.
3. Since the counter claim has been filed by the first defendant, as
seen from the written statement, the learned counsel for the plaintiff seeks
time to file a reply statement.
