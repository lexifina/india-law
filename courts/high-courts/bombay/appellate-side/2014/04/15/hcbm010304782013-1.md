1. By this application, the applicant seeks restoration of the Writ
Petition No. 11896/2012, which came to be dismissed for default vide order
dated 5th July, 2013.
2. For the reasons set up in the application, order dated 5th July,
2013 is recalled and the Writ Petition is restored to the file to its original
number. To be listed on 6th May, 2014 under caption `Admission (After
Notice)'.
3. Application disposed of accordingly.
