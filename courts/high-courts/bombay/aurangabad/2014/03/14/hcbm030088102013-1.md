 CORAM : A. M. BADAR, J.
 DATE : 14th MARCH, 2014.
PER COURT :
1. Learned APP for the State points out that order sought to be
impugned is passed by learned Judicial Magistrate, First Class, Amalner,
acquitting accused of the offence punishable under sections 279, 337 and
427 of Indian Penal Code. He further submits that appeal alongwith
necessary application needs to be filed before the learned Sessions Court in
view of provisions of Section 378(1)(a) of the Code of Criminal Procedure,
1973. Learned APP as such seeks permission to withdraw the application
with liberty to file the same before appropriate forum. Permission sought
for is granted. Time spent in bonafidely prosecuting this application before
this Court shall be considered while considering delay. With these
observations, criminal application is permitted to be withdrawn.
 ( A. M. BADAR )
