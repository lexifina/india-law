CORAM: HONOURABLE MR. JUSTICE JYOTI SARAN
ORAL ORDER
3 27-08-2013 This appeal has been filed questioning the order passed in an
application filed by the appellants under Order 21 Rule 97 of the Code
of Civil Procedure (hereinafter referred to as the ‘Code’).
 An order disposing of an application filed under Order 21 Rule
97 has been held to have the same force as if it were a decree in terms
of the provision of Order 21 Rule 103. The moment an order disposing
of an application filed under Order 21 Rule 97 of the Code is treated to
be a decree, the appropriate remedy for the person aggrieved would be
to file an appeal under Section 96 of the Code and not a miscellaneous
appeal.
 As prayed by Mr. R.C. Thakur, learned counsel for the
appellants, he is permitted to convert this miscellaneous appeal into an
appeal under Section 96 of the Code of Civil Procedure within a period
of four weeks from today.
 Upon such conversion being made the matter be posted before
the appropriate Bench as per roster.
 Learned counsel would be at liberty to move for early hearing of
the case.
Bibhash/- (Jyoti Saran, J)
