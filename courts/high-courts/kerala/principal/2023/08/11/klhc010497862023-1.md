 JUDGMENT
When this contempt case came up for consideration on
13.07.2023, this Court passed the following order :
“After going through the pleadings in this con. Case, I am of
the prima facie opinion that, the 3rd respondent committed
contempt. The 3rd respondent will appear in person before
this Court on 19.07.2023. The petitioner will take notice
through special messenger to the 3rd respondent. If the
directions are complied or if the judgment is varied or
modified, the appearance of the 3rd respondent is dispensed
with.
A copy of this order will be appended along with the notice
issued to the 3rd respondent.”
2. Thereafter, when the matter came up for
consideration on 09.08.2023, the counsel for the 3rd
respondent submitted that whichever document is necessary

will be handed over to the petitioner. Now, it is submitted that
all the documents are handed over to the petitioner. The
counsel for the petitioner submitted that the user id and
password are to be supplied. The 3rd respondent will supply
the user id and password to access the website.
3. In the light of the above submission, I think there is
no contempt.
Therefore, this contempt case is closed.
