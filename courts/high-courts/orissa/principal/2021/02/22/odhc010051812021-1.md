# High Court of Orissa, ABLAPL/928/2021, 2021-02-22

02. 22.02.2021 The matter is taken up through Hybrid arrangement
(virtual/physical) mode.
 Learned counsel for the Petitioner submitting that all
the offences for which the case is presently running against
the Petitioner are bailable in nature, prays for its withdrawal
seeking liberty to the Petitioner to file the application afresh in
case cause of action so arises in future.
 Granting the liberty as aforesaid, the ABLAPL stands
disposed of as withdrawn.
 Issue urgent certified copy as per rules.
