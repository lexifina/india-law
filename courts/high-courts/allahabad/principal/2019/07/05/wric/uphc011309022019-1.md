# Allahabad High Court, WRIC/21584/2019, 2019-07-05

Court No. - 6
Case :- WRIT - C No. - 21584 of 2019
Petitioner :- Gajednra Kumar
Respondent :- Manager Allahabad Bank And 3 Others
Counsel for Petitioner :- Shiv Narayan Pandey
Counsel for Respondent :- C.S.C.,Habib Ahmad
Hon'ble Yashwant Varma,J.
The only prayer which is addressed on this petition is for
quashing what is described to be an order dated 07 June 2019.
However as the record reflects there is no order of 07 June
2019. Annexure-5 which is impugned is only a notice issued by
the Permanent Lok Adalat.
In view thereof and since no adverse action has been taken
against the petitioner, this petition is dismissed.
Order Date :- 5.7.2019
