# Allahabad High Court, WRIC/2489/2025, 2025-03-24

Neutral Citation No. - 2025:AHC-LKO:16637-DB

Petitioner :- Alankita
Respondent :- State Of U.P. District Magistrate Sultanpur And 3
Others
Counsel for Petitioner :- Narendra Pratap Mishra
Counsel for Respondent :- C.S.C.
Hon'ble Rajan Roy,J.
Hon'ble Om Prakash Shukla,J.
1. Heard Shri Narendra Pratap Mishra, learned counsel
for the petitioner and learned Additional Chief Standing
Counsel for the State.
2. The petitioner has challenged consequential Recovery
Certificate for recovery of Rs.1,28,360/- which is an action
consequential to the main action which is the order dated
19.08.2021 by which the financial benefit granted to the
petitioner under the Pradhanmantri Avas Yojna has been
ordered to be refunded, as, the petitioner was not eligible
for the same. The order dated 19.08.2021 has not been
challenged.
3. The writ petition is dismissed, however, with liberty to
challenge the main order explaining the delay if the same
is otherwise permissible in law.
.
(Om Prakash Shukla,J.) (Rajan Roy,J.)
