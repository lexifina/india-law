Ram Chand Gupta, J.(Oral)
The present revision petition has been filed under Article 227
of the Constitution of India for setting aside order dated 15.4.2011
( Annexure P-1) passed by learned Civil Judge (Junior Division), Dasuya
vide which application dated 1.2.2011 moved by the petitioner for setting
ex-parte order dated 22.1.2011 in execution petition, was dismissed.
It has been stated by learned counsel for the respondent No.1-
Decree -holder that he is having no objection if the impugned order is set
aside and one opportunity is given to the petitioner to file objection, if any
and learned executing court be directed to decide the same within a
specified period, as the litigation is pending since the year 1980.
Hence, in view of these facts, the present revision petition is
accepted and the impugned order is set aside. Learned executing court is
directed to grant one opportunity to the petitioner -JD to file objection, if

Both the parties are directed to appear before learned executing
