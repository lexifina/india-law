02/ 21.07.2010 Heard learned counsel for the petitioner.
This writ petition has been filed challenging order dated
19.06.2010 by which the learned District Judge, Vaishali at
Hajipur allowed the petition of opposite party 1st set filed under
Order XXII Rule 3 of the Code of Civil Procedure as well as
Section 5 of the Limitation Act read with Order XXII Rule 9 of the
Code in Title Appeal No.262 of 2003 (24/07).
It is quite apparent that the said order is a well
considered order and only after fully considering the points raised
by the concerned parties, the said petitions under Order XXII Rule

- 4 -
3 of the Code of Civil Procedure as well as Section 5 of the
Limitation Act read with Order XXII Rule 9 of the Code have been
allowed. It goes without saying that when a petition under Order
XXII Rule 9 of the Code is allowed, it will be quite apparent that
abatement is set aside. Furthermore, the court below had full
jurisdiction to pass the said order and he has exercised the said
jurisdiction in accordance with law.
Accordingly, this writ petition is dismissed.
Sunil
(S. N. Hussain, J.)
