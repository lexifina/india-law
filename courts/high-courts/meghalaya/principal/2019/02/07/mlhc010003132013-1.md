Per Mohammad Yaqoob Mir, ‘CJ’: (ORAL)
1. Meghalaya Electricity Duty Act which is under challenge has
been amended in support whereof Notification bearing No.LL(B)
170/84/57 dated 18.12.2018 along with the copy of the Ordinance dated
18.12.2018 has already been placed on record copy whereof stands
furnished to the learned counsel for the petitioner on previous date of
hearing. Confronted with that position, learned counsel for the petitioner
had sought time to have instructions. Today, learned counsel would
submit that he may be given time to amend the petition but since the Act
has been amended, we allow him to withdraw the petition with liberty to
file a fresh one, same is also agreed to by both the learned counsel for
the parties.

2
2. Therefore, prayer of the learned counsel for the petitioner in the
aforesaid background is allowed. Petition is dismissed as withdrawn
with liberty to file a fresh one, if so advised or if so chooses.
3. Disposed of as above.
