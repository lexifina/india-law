Application praying that this Hon'ble Court be pleased
to set aside the exparte orders dated 22.08.2019 in
O.P.No.823 of 2012.
This Original Petition coming on this day before this
Court for hearing and the Court made the following order:-
This application has been filed to set aside the
exparte order dated 22.08.2019 in the above Original
Petition.
2.Mr.T.Jayaramaraj, learned counsel for the applicants
would state that this application came to be filed on the
wrong impression that the respondents in the Original
Petition were set exparte on 22.08.2019. Therefore, the
learned counsel seeks permission of this Court to withdraw
the application and he has also made an endorsement to that
effect.
3.In the light of the above submission, this
application is dismissed as withdrawn. No costs.
