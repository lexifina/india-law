# Calcutta High Court, CRR/1783/2021, 2023-04-24

24.04.2023 IN THE HIGH COURT AT CALCUTTA
 Item No.29 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
C.R.R. 1783 of 2021

 Suprabhat Basu
 versus
 The State of West Bengal & Anr.
In Re: An Application under Section 482 of the Code of
Criminal Procedure, 1973.
Mr. Arijit Ganguly,
Ms. Manisha Sharma … For the State.
None appears for the petitioner.
Mr. Arijit Ganguly, learned advocate appears for the
State. A report has been submitted which is dated
04.12.2021. Let the same be kept on record.
Learned advocate for the State submits that he has
instructions that subsequently charge-sheet has been
submitted before the jurisdictional court on 16.06.2022.
Having considered the changed circumstances, I grant
liberty to the petitioner to approach this Court in respect of
the present stage of proceedings. So far as the present
revisional application is concerned, the same has become
infructuous as charge-sheet has already been submitted and
the revisional application was preferred challenging the FIR.
Accordingly, the revisional application being CRR 1783
of 2021 is disposed of as infructuous.
Pending connected applications, if any, are
consequently disposed of.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.

 (Tirthankar Ghosh, J.)
