# Bombay High Court, APPLN/980/2008, 2008-04-02

vss
 IN THE HIGH COURT OF JUDICATURE AT BOMBAY
 CRIMINAL APPELLATE JURISDICTION
 CRIMINAL APPLICATION NO.980 OF 2008
 Balu @ balasaheb Baban Waghire ... Applicant
 V/s.
 State of Maharashtra ... Respondent
 Mr.J.B. Kocheta for Applicant
 Mrs.A.A. Mane, APP, for Respondent
 CORAM: SMT.NISHITA SMT.NISHITA MHATRE, J.

 DATED: APRIL 2, 2008
 P.C.:
 . This application challenges the order dated
 11.3.2008 by which the adhoc District Judge-4 and
 additional Sessions Judge, Pune has directed that the
 bail application of the applicant be placed before the
 District Judge No.5 and accordingly disposed of the
 application. This order has been passed although by an
 administrative order dated 29.1.2008, the Principal
 District Judge and Sessions Judge, Pune had directed the
 adhoc District Judge-4 to dispose of the bail
 application in accordance with law. An earlier bail
 application filed by the accused was decided by the same
 learned Judge and it is in these circumstances, the
 Principal District Judge has directed that the bail
 application be placed before the same learned Judge.
 These directions were passed although the case had
 already been filed. In fact, there is an office order

 : 2 :
 dated 29.1.2008 which directs that second bail
 application be assigned to the same Court which had
 disposed off earlier applications.
 2. In these circumstances, the order passed by the
 adhoc District Judge-4 is set aside and he is directed
 to hear the bail application No.623 of 2008 on merits.
 3. Criminal Application stands disposed of.
