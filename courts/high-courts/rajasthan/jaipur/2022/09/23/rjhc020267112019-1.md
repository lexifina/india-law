 Order

This misc. application has been filed for recalling the order
dated 06.02.2019.
This Court finds that on 06.02.2019 application for recalling
order dated 4.9.2017 was allowed and order dated 4.9.2017 was
recalled.
No one has appeared to argue the misc. application and this
Court has already exercised discretion in recalling the earlier order
and as such, it seems that counsel for the petitioner is not
interested in prosecuting the case in a proper manner.
The misc. application is accordingly dismissed.
