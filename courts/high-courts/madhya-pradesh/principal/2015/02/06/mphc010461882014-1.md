# High Court of Madhya Pradesh, MCC/2145/2014, 2015-02-06

M.C.C.No.2145/2014
Gopal Mukati VS. State of MP & Ors.
06/02/2015
Shri Navneet Dubey, learned counsel for the applicant.
Shri Sanjay Sarwate, learned counsel on advance notice for the
respondents.
This application has been filed for restoration of a Writ Appeal
No.1541/2013, which has been dismissed for want of prosecution. The
application for restoration is supported by affidavit of the applicant.
Keeping in view the reasons indicated in the application and
finding the same to be bona-fide, this application is allowed.
W.A.No.1541/2013 be restored to it's original file. It be placed for
orders before an appropriate bench.
With the aforesaid, this application stands allowed and
disposed of.
 (Rajendra Menon) (C.`V.Sirpurkar)
