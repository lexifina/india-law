# Gauhati High Court, WP(C)/6627/2017, 2017-11-03

WP(C) 6627/2017
BEFORE
HON’BLE MR JUSTICE ACHINTYA MALLA BUJOR BARUA
Mr. M.J. Quadir, learned counsel for the petitioner submits that there are some
inadvertent mistakes in the writ petition, which the petitioner desires to corre
ct.
In order to enable the petitioner to do the same, the petitioner desires
to withdraw this writ petition with liberty to file a fresh writ petition.
Prayer is allowed.
Writ petition stands closed with liberty to file a fresh writ petition.
