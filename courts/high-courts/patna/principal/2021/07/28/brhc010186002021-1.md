ORAL ORDER
2 28-07-2021 Heard the parties through virtual Court proceedings.
This application has been filed for modification in the
order dated 18.12.2020 passed in Criminal Miscellaneous No.
28340/2020.
Learned counsel for the petitioner submits that due to
poor connectivity of the internet, the voice of the learned
counsel for the petitioner has not been properly heard due to
which the submission of the petitioner has been inadvertently
typed as “learned counsel for the petitioner seeks permission to
withdraw this application submitting that the petitioner has
already surrendered before the learned court below and has
been granted bail, as such, this application has become
infructuous” instead of learned counsel for the petitioner seeks

Patna High Court CR. MISC. No.22247 of 2021(2) dt.28-07-2021
2/2
permission to withdraw this application in order to
surrender before the learned court below.”
In view of the above, in the order dated 18.12.2020
passed in Cr. Misc. No. 28340/2020, the submission of the
learned counsel for the petitioner shall be read as ‘petitioner
seeks permission to withdraw this application in order to
surrender before the court below’ instead of “learned counsel
for the petitioner seeks permission to withdraw this application
submitting that the petitioner has already surrendered before
the learned court below and has been granted bail, as such, this
application has become infructuous.”
The order dated 18.12.2020 passed in Cr. Misc.
No.28340/2020 is modified to the aforesaid extent.
