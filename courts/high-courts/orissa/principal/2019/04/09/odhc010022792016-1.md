# High Court of Orissa, WA/383/2016, 2019-04-09

06. 09.04.2019 Learned counsel for the appellant wants to
withdraw this W.A. with liberty to move the authority for
formation of new Governing Body of the College in question,
if not formed. He is directed to file a memo to that effect.
 With the aforesaid liberty, this W.A. is allowed to be
withdrawn.
 However, there will be no order as to costs.
 Urgent certified copy of this order be granted on
proper application.
