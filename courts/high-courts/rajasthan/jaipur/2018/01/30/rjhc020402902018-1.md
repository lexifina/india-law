Judgment / Order
30/01/2018
1. Applicant has moved an application for correction in the
order dated 24.01.2018. It is contended that in Para 2 in place of
“FIR No.316/2017” “FIR No.02/2018” has been wrongly
mentioned.
2. Prayer is made that the same be corrected.
3. Considering the contention of the applicant, application is
allowed. In para 2 in place of “FIR No.02/2018” the same be read
as FIR No.316/2017.
4. The application is accordingly allowed.
