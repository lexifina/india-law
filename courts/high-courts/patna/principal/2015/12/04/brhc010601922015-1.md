ORAL ORDER
2 04-12-2015 Learned counsel for the petitioner seeks leave to
withdraw the present application in order to file an appropriate
application either under Section 397 or under Section 482 of the
Code of Criminal Procedure (in short “Cr.P.C.”).
Leave is granted. The application is disposed of with
liberty to the petitioner to file another application under
appropriate provision of the Cr.P.C. on the same subject matter.
In case the petitioner files a Xerox-copy of the impugned
order, the Registry is directed to return the certified copy of the
impugned order to the learned counsel for the petitioner after
retaining the Xerox-copy on record.
