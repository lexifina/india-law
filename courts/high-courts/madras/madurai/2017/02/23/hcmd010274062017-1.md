# Madras High Court, CRL OP(MD)/2001/2017, 2017-02-23

1
BEFORE THE MADURAI BENCH OF MADRAS HIGH COURT
DATED: 23.02.2017
CORAM
THE HON'BLE MR.JUSTICE G.CHOCKALINGAM
Crl.O.P.(MD).No.2001 of 2017
K.Ganga ... Petitioner/Accused
 -Vs-K.Vallinayagam .. Respondent/Complainant
Prayer : Criminal Original Petition filed under Section 407 of the
Code of Criminal Procedure, to withdraw the case in S.T.C.No.156
of 2014 on the file of the Judicial Magistrate No.IV, Tirunelveli
and transfer the same to the file of Fast Track Court (Magistrate
Level), Tuticorin.
For Petitioner : Mr.R.Balakrishnan
 O R D E R
This petition has been filed to withdraw the case in
S.T.C.No.156 of 2014 on the file of the Judicial Magistrate No.IV,
Tirunelveli and transfer the same to the file of Fast Track Court
(Magistrate Level), Tuticorin.
2. Heard the learned counsel for the petitioner.
3. On a perusal of records it is seen that the present
petitioner has already filed an application in Cr.M.P.No.4181 of
2015 before the learned Judicial Magistrate No.IV, Tirunelveli,
for transfer of the case and subsequently the petitioner himself
withdrew the said petition and thereafter only, the petitioner has
filed this petition before this Court and hence, this Court is not
inclined to entertain this petition and the petition is liable to
be dismissed and the same is dismissed.
Sd/-
Assistant Registrar
