ORDER
When this bail application came up for consideration,
the Public Prosecutor submitted that the trial in
S.C.No.741/2024 of Fast Track Special Court, Koyiland is in
the final stage. If that is the case, this bail application need
not be entertained by this Court now. If there is any
unnecessary delay in completing the trial, the petitioner can
file fresh bail application before the trial court and if such a
bail application is filed, the trial court can consider the same.
With the above observation, this bail application is
disposed of.
