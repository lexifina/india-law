# High Court of Madhya Pradesh, MCRC/2286/2016, 2016-02-22

MCRC-2286-2016
(JITENDRA DWIVEDI @ JEETU Vs THE STATE OF MADHYA PRADESH)
22-02-2016
Shri Manish Datt, learned Senior Counsel with Shri Rahul
Sharma, learned counsel for the applicant.
Shri Pradeep Singh, learned G.A. for the respondent/State.
After arguing for some time learned senior counsel for the
applicant seeks leave to withdraw this M.Cr.C. with liberty to
the applicant to surrender before the trial Court and to file an
application for regular bail with a further prayer that in case
the application is filed, the trial Court be directed to take the
same for consideration at the earliest.
With the aforesaid liberty and direction to the trial Court that if
possible such application if filed be taken up for consideration
on the same day, the M.Cr.C. is dismissed as withdrawn.
C.c. as per rules.
(SHANTANU KEMKAR)
JUDGE
