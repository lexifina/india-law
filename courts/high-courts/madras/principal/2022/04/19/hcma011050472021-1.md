PRAYER: This Criminal Original Petition filed under Section 482
of Cr.P.C.to direct the respondent to complete the investigation
in Crime No.460 of 2021 pending on the file of Thiruvarur Taluk
Police Station, Thiruvarur District and file final report within
a time to be fixed by this Court.
For Petitioner : Mr.D.Arun
For Respondent : Mr.V.Meganathan
 Government Advocate (crl.side)
 ORDER
This Criminal Original Petition has been filed to direct the
respondent to file the final report in Crime No.460 of 2021 on
the file of the respondent police within a time frame.
2.Today, when the matter is taken up for hearing,
Mr.V.Meganathan, learned Government Advocate (Crl.side) would
submit that after completion of investigation, the final report
has been filed and the case has been taken on file in
P.R.C.No.35 of 2021 on the file of the learned Judicial
Magistrate, Thiruvarur, which has been pending for committal.
3. In view of the above, direction is issued to the learned
Judicial Magistrate, Thiruvarur, to commit the case at the
earliest.
https://hcservices.ecourts.gov.in/hcservices/

4. With the above direction, this Criminal Original Petition
stands disposed of.
