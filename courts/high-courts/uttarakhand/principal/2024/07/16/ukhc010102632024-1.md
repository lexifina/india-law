Mr. Shubhang Dobhal, learned counsel for the
petitioner.
2. Mr. Atul Bahuguna, learned Standing Counsel for
the State.
3. Petitioner has moved this Court by filing the present
writ petition for a direction to the respodnent to extend the
session end benefit to the petitioner which was according to
the petitioner was being denied without any cost.
4. Vide previous order dated 05.07.2024 instructions
were called from the State that as to why Session End
Benefit is not being extended to the petitioner.
5. Today instructions have been received, which are
taken on record, and it is contended by learned State counsel
that Session End Benefit has been granted to the petitioner
vide order dated 15.07.2024 by respondent no.4-Chief
Education Officer, Pauri-Garhwal.
6. In view of the aforesaid development of redressal of
the grievance of the petitioner nothing remains to be
decided in the matter.
7. Accordingly, writ petition stands disposed-off.
