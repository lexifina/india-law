ORDER
Date : 05-03-2020
By way of this Interlocutory Application, the petitioner has sought for correction of the
case number that was incorporated in the judgment dated 27.08.2019 passed by this
Court in Crl.A.77/2018.
It has been submitted that Sessions Case number has been mentioned as 30/2005 it should

Page No.# 2/2
be Sessions Case No. 30/2015 in the first para of the judgment.
I have heard the submission of the learned counsel for the parties as well as perused the
original record and cause title etc. and the impugned judgment. It appears that the case
number has been wrongly typed in the judgment which needs correction.
Accordingly, in the first para of the judgment, the Sessions Case number be read as “Sessions
Case No.30/2015” instead of 30/2005 other portion remaining the same.
Let a copy of this order be a part of the said order.
With this direction and observation this Interlocutory Application stands disposed of.
 JUDGE
