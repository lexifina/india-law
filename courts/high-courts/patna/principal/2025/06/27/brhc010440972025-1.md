ORAL ORDER
2 27-06-2025 1. Heard learned counsel for the petitioner and learned
A.P.P. for the State.
2. The learned counsel for the petitioner after some
argument seeks permission to withdraw the anticipatory bail
application with liberty to file afresh if need arises, as it has
been submitted on behalf of the petitioner that the petitioner had
earlier moved this court seeking anticipatory bail by filing Cr.
Misc. No. 59841/2024 and the same was disposed of by an
order dated 19.09.2024 in terms of the order dated 13.02.2024 in
Cr. Misc. No.3536/2024 (Naushad Ansari vs The State of
Bihar). It is further submitted that petitioner represented before
the concerned Superintendent of Police and the I.O. of the case
along with the copy of the order dated 19.09.2024 in Cr. Misc.

Patna High Court CR. MISC. No.30732 of 2025(2) dt.27-06-2025
2/2
No.3536/2024 but then the I.O. of the case has filed an
application before the learned trial court for adding Section 307
of the Indian Penal Code.
3. On query of the court as to whether section 307 of
the Indian Penal Code has been added to the FIR or not, on
which, the learned counsel submits that presently Section 307 of
the Indian Penal Code has not been added, thus seeks
permission to withdraw the anticipatory bail application.
4. Permission is accorded.
