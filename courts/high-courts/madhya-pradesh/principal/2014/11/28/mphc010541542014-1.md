# High Court of Madhya Pradesh, RP/724/2014, 2014-11-28

1
R.P. No.724/2014
28/11/2014.
Shri Rakesh Khare, learned counsel for
the petitioner.
Shri S. M. Lal, learned Govt. Adv. for
the respondents State.
Having heard learned counsel for the
parties, we find that inadvertantly the writ
petition was disposed of as having been rendered
infructuous. In view of the order dated
20.6.2014 it seems that order has been passed
wrongly typed in this case. There is an error
apparent on the face of the record.
In view of the above, this application is
allowed. Order dated 20.6.2014 passed in W.P.
No.17896/2013 is recalled. Writ Petition is
restored to its original file. It be placed for
orders before the appropriate Bench.
With the aforesaid, this review petition
stands allowed and disposed of.
(Rajendra Menon) (Ms. Vandana Kasrekar)
