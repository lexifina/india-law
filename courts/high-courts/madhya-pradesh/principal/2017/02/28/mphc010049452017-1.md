# High Court of Madhya Pradesh, MCRC/1703/2017, 2017-02-28

M.Cr.C.No.1703/2017
28/02/2017
 Shri Prabhat Singh, learned counsel for the applicant.
Shri A.N.Gupta, panel lawyer for respondent State.
This application has been filed for restoration of
M.Cr.C.No.22743/2015 which was dismissed for want
of prosecution vide order dated 21/6/2016.
On perusal of the application which is duly supported by
an affidavit, I find that sufficient cause for restoration of
M.Cr.C.No.22743/2015 is made out.
Accordingly, M.Cr.C.No.22743/2015 is restored to
its original number and be listed before appropriate Bench.
Let a copy of this order be kept in the record of
M.Cr.C.No.22743/2015
Accordingly, M.Cr. C is allowed.
Certified copy as per rules.
 (H.P. Singh)
