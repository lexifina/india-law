Heard.
2. This is an application filed by the State seeking
permission to file charge-sheet, as investigation is
complete. This Court has passed an interim order which
gave rise for seeking permission of this Court.
3. We see no reason to deny the State from filing of
charge-sheet. Hence, application stands allowed. The
State is permitted to file charge-sheet and also request to
tender a copy of charge-sheet in the proceeding.
4. Application stands disposed of in above terms.
