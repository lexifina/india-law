P.C. :
1. Learned advocate Mr. Hakani is present on behalf of the sole
respondents. Heard learned advocates on both sides. For the
reasons mentioned in the Civil Application, request for restoration of
the Civil Revision Application is required to be granted. Hence,
following order is passed.
U.S. Jagtap 1/2

ORDER
(i) The order dated 8th June, 2011 dismissing the Civil Revision
Application No.206 of 2006 is set aside.
(ii) The aforesaid Civil Revision Application is restored to the file of
this Court.
(iii) The Civil Revision Application is posted for final hearing in the
week commencing from 3rd February, 2014.
(iv) In the facts and circumstances of the case, there shall be no
order as to costs.
 [R.Y. GANOO, J.]
