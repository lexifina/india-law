J U D G M E N T
A conditional order of attachment was made in an
application filed under Order XXXVIII Rule 5 of the Code of Civil
Procedure. But the application was eventually dismissed under
Order XXXVIII Rule 6 of the Code of Civil Procedure as not
maintainable. Such order is appealable under Order XLIII Rule
1(q) of the Code of Civil Procedure and an original petition is
hence not maintainable.
2. The Original Petition filed against the order in I.A
No.1422/2013 in O.S No.356/2013 on the file of the Court of the
Additional Munsiff, Kollam is hence dismissed. The interim order
passed in I.A No.13866/2013 in this original petition would
however operate for a period of one month to enable the
petitioner to work out his statutory remedy as above
The Original Petition is dismissed subject to the above
clarification.
V.CHITAMBARESH
