# High Court of Orissa, WP(C)/12071/2019, 2019-11-05

08. 05.11.2019 Heard learned counsel for the parties.
 It is stated by the learned counsel for the petitioner
that the relief sought for in the writ application has already
been granted. Hence, nothing remains to be adjudicated in
this writ application and the same has become infructuous.
 Accordingly the writ application is dismissed as
infructuous.
