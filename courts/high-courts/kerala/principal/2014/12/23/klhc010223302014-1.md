 ORDER
The petitioner is the accused in Crime No.218/2012 on the
file of the Payyannur Police Station. Offences under Sections
447, 294(b), 341, 323, 354 read with Section 34 Indian Penal
Code are alleged. It is reported that the dispute with the first
respondent has since been settled. Annexure-II affidavit filed by
the first respondent is relied on.
No purpose would be served in prosecuting the case and
the proceedings can be nipped in the bud. Hence, all further
proceedings in Crime No.218/2012 on the file of the Payyannur
Police Station are hereby quashed.
V.CHITAMBARESH,
 JUDGE.
