ORAL ORDER
2/ 24-07-2019 This application has been filed for modification of the
order dated 24.06.2019 passed in Cr. Misc. No.37208 of 2019by
which petitioner has been granted bail in connection with
Maranchi P.S. Case No.19 of 2019 to the satisfaction of the
Additional Sessions Judge, XV, Patna.
Counsel for the petitioner submits that alias name of
father of the petitioner be also added in the order dated
24.06.2019 passed in Cr. Misc. No.37208 of 2019.
In the First Information Report, there is no alias name
of father of the petitioner.
Therefore, this Court does not find any merit in this
application.
The application is dismissed.

Patna High Court CR. MISC. No.45933 of 2019(2) dt.24-07-2019
2/2
The petitioner is directed to get father’s name of the
petitioner modified first in the First Information Report by the
police authorities and thereafter file necessary modification
application in the Court below itself.
