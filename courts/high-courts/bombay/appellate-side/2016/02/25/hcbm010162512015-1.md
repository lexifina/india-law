# Bombay High Court, CAF/710/2016, 2016-02-25

IN THE HIGH COURT OF JUDICATURE AT BOMBAY
CIVIL APPELLATE JURISDICTION
CIVIL APPLICATION NO. 710 OF 2016
IN
FIRST APPEAL NO. 1577 OF 2013
Madan Krushnadas Gujrathi ... Applicant
Vs.
Bumanna Balu Ramalu & Anr. ... Respondents
Mr. Saurabh Butala i/b. Mr. V.S. Talkute, Advocate for the applicant.
 CORAM: MRS.MRIDULA BHATKAR, J.
 DATE: 25th February, 2016.
P.C.:
 This Application is moved for restoration of the First Appeal, which
was dismissed for non-compliance of the order dated 12th March, 2014 by
which the appellant was directed to file private paper within one year from
the said date.
2. The learned counsel for the applicant submitted that Appeal is
admitted on 12th March, 2014 and now the paper book is ready and the
appellant can file the same, so the said order is to be set aside.
3. In view of the submissions of the learned counsel for the applicant,
the order dated 12th March, 2014 is recalled. First Appeal is restored to its
original file along with Application, if any. The appellant to file paper book
on or before 31st March, 2016.
4. Civil Application is allowed.
(MRIDULA BHATKAR, J.)
