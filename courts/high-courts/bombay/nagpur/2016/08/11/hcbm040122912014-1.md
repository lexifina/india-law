order 7 Rule 11(a) and (d) of the Code of Civil Procedure by
the application filed before the trial Court, with liberty to file
fresh application under Order 7 Rule 11(a) and (d) of the
Code of Civil Procedure.
Shri S.G.Jagtap, advocate for the respondent No.4

petitioners.

application under Order 7 Rule 11(a) and (d) of the Code of
Civil Procedure.
In view of the above, the order passed by the trial
Court on 2nd July, 2014 rejecting the challenge raised by the
petitioners under Order 7 Rule 11(a) and (d) of the Code of
Civil Procedure, does not survive.

2 wp3497.14
The order passed by the trial Court under Order 7
Rule 11(b) of the Code of Civil Procedure directing the
plaintiff to properly value the claim and to pay court fees is
maintained.
The petition is disposed in the above terms. The
parties to bear their own costs.
