HON'BLE MR. JUSTICE PANKAJ BHANDARI
Order
04/09/2019
1. Application has been moved by the accused-petitioner that in
the impugned order passed by the Court, father’s name of the
petitioner No.5 was mentioned as Aayaram, whereas father’s
name of petitioner No.5 is Aatmaram.
2. It is contended that correction in the father’s name has been
done by the Sessions Judge, Jhalawar. Prayer is made that
correction in the cause title be made.
3. I have considered the contentions.
4. In the order dated 20.08.2019, father’s name of the
petitioner No.5 is corrected and the same be now read as
“Aatmaram” in place of “Aayaram”.
5. Application is accordingly allowed. Amended cause title is
taken on record.
(PANKAJ BHANDARI),J
