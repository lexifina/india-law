# Allahabad High Court, TACR/103/2017, 2019-11-15

of 2017

Opposite Party :- State of U.P. and Another
Counsel for Applicant :- Akhilesh Kumar Singh,Raj Kumar
Singh
Counsel for Opposite Party :- G.A.,Swetashwa Agarwal
Hon'ble Ram Krishna Gautam,J.
Order on Criminal Misc. Converting Application
Learned counsel for both side are present.
This application has been filed for converting Transfer
Application (Criminal) No. 103 of 2017 into Criminal Misc.
Application U/s 482 Cr.P.C. and to pass appropriate order in it.
This Court has got jurisdiction for disposal of a proceeding filed
under Section 407 Cr.P.C. The same was filed and with report
of office, it was listed and numbered as Transfer Application
(Criminal) No. 103 of 2017. Now, a request has been made for
amending above proceeding as proceeding under Section 482
Cr.P.C., for which this Court is having no jurisdiction.
Accordingly, this application is rejected.
Order on Transfer Application
The transfer application too is for a relief which does not come
within the provision of Section 407 Cr.P.C. because prayer
made in relief is for quashing the order dated 10.06.2016,
passed by learned Civil Judge (J.D.)/Judicial Magistrate,
Gautam Budh Nagar, in Complaint Case No. 3095 of 2014,
under Section 138 N.I. Act and the same is not maintainable in
this proceeding under Section 407 Cr.P.C.
Accordingly, transfer application is dismissed. However,
applicant may file proceeding under Section 482 Cr.P.C. before
appropriate Bench.
Order Date :- 15.11.2019
