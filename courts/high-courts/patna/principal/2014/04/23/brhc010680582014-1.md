3 23-04-2014 Heard Mr.S. Alamdar Hussain, learned counsel for the
petitioner and learned counsel for the State.
This criminal revision is directed against the order dated
27.09.2013 passed by the Sub Divisional Magistrate, Biharsharif
(Nalanda) in Case No. 381(M.P.) of 2012 whereby the
proceedings initiated under Section 188 of the Indian Penal Code
has been dropped.
Mr. Hussain after some arguments seeks permission to
withdraw this application.
As prayed, this application is permitted to be withdrawn.
