Learned advocate Ms Avanika Panchal appearing for
learned advocate Mr. Vaibhav Vyas has submitted that the
learned advocate for the applicant has no contact with the
applicant no. 3 and as per the order dated 9.8.2018 the
applicant no. 3 has to file the purshis that he has not misused
the last cheque and also attempt is made to search out the
same. She submitted that the learned advocate for the
petitioner has no contact with the applicants.
2. Learned advocate Ms Avanika seeks withdrawal of the
present application with a liberty to file fresh application if
the need arises. In view of above the present application
stands disposed of as withdrawn with a liberty to file fresh
application when the need arises.
