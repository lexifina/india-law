# High Court for the State of Telangana, CRP/4683/2016, 2017-03-24

HON’BLE SRI JUSTICE SURESH KUMAR KAIT
CIVIL REVISION PETITION No.4683 of 2016
ORDER : (Oral)
 The present petition was listed first time before this Court on
08.11.2016. Appeared none on behalf of the petitioner. Vide order dated
15.11.2016, counsel for petitioner was permitted to file some docket orders
which are necessary to adjudicate the petition. Thereafter, consecutively on
four dates, matter is adjourned at the request of the petitioner.
2. Today appeared none on behalf of the petitioner. It seems the
petitioner is not interested in prosecuting the petition.
3. The petition is accordingly dismissed for default and for
non-prosecution as well. No costs.
Pending miscellaneous applications, if any, shall stand closed.
_____________________
 SURESH KUMAR KAIT, J
