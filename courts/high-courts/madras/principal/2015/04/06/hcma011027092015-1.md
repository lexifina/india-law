 ORDER
Heard the learned counsel for the petitioners and the learned
Additional Public Prosecutor appearing on behalf of the first
respondent.
2. The petitioners have come up with the present petition
seeking to quash the case in Crime No.3 of 2009 pending on the file
of the first respondent.
3. It is represented by the learned Additional Public
Prosecutor that the case in Crime No.3 of 2009 on the file of the
first respondent has been completed and final report also has been
filed before the learned Judicial Magistrate Court, Sirkali, which
has taken the same on file as C.C.No.231 of 2010.
https://hcservices.ecourts.gov.in/hcservices/

4. Under such circumstances, this petition is not
maintainable and accordingly, the same is closed. However, liberty
is granted to the petitioners to file a quash petition for quashing
the final report submitted in C.C.No.231 of 2010 on the file of the
learned Judicial Magistrate, Sirkali.
