# High Court of Madhya Pradesh, MCRC/4839/2017, 2017-07-24

MCRC-4839-2017
(GIRRAJ Vs THE STATE OF MADHYA PRADESH)
24-07-2017
Shri Brajesh Sharma, Advocate for applicant.
Shri Arun Barua, Panel Lawyer for respondent/State.
Case diary is available.
This is repeat application under Section 439 of Cr.P.C. for
grant of bail. First application was dismissed as withdrawn by
order dated 12/7/2016 passed in M.Cr.C. No.5994/2016 and the
second application was dismissed as withdrawn by order dated
3/1/2017 passed in M.Cr.C. No. 14579/2016.
The counsel for the applicant seeks permission of this
Court to withdraw this application with liberty to file a fresh
application with certain new documents.
The application is accordingly dismissed as withdrawn with
aforesaid liberty.
(G.S. AHLUWALIA)
