ORDER
The petitioner has challenged an order passed under
Order XXXVIII Rule 5 of Code of Civil Procedure. Office
has raised an objection regarding maintainability of this
writ petition, in view of the appeal remedy under Order
XLIII Rule 1(q) of Code of Civil procedure.
2. Learned counsel for the petitioner seeks
permission to withdraw the petition and to file an
appropriate appeal.
3. In view of the aforesaid submission, petition is
dismissed as withdrawn.
4. It is open for the petitioner to file an appeal as
provided under Order XLIII Rule 1(q) of Code of Civil
procedure.
5. Office is directed to return the certified copy of
the impugned order after retaining photocopy.
