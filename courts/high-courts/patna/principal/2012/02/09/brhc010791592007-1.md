ORAL ORDER
2 09-02-2012 Though there is no counter affidavit available on
record, however, learned counsel for the petitioner submits that in
view of the fact that a copy of the counter affidavit was served
upon him and a stand has been taken therein that there is no
encroachment on the public road concerned as the same has
already been removed, it would not be proper for him to pursue
this case any more.
Accordingly, this writ application is dismissed as not
pressed.
