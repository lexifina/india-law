ORDER
Today, when this writ petition was taken up for hearing, learned counsel
for the Petitioner sought permission of this Court to withdraw the present writ
petition with liberty to the Petitioner to file a fresh Application for surveying the
Petitioner’s land as per Patta. The learned counsel has also made an
endorsement to that effect in the petition.
2. Considering the request coupled with the endorsement made by the
learned counsel for the Petitioner, this Writ Petition is dismissed as withdrawn
and liberty is granted to the Petitioner to file a fresh Application for surveying
the Petitioner’s land as per Patta. No costs.
