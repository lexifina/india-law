# High Court of Rajasthan, CW/7645/2016, 2016-07-26

{1}
IN THE HIGH COURT OF JUDICATURE FOR RAJASTHAN AT JODHPUR
<><><>
:ORDER:
S.B. Civil Writ Petition No.7645/2016
Sunita Godar Vs. Board of Secondary Education & Ors.
26.07.2016
Hon'ble Ms. Justice Jaishree Thakur
Mr. SK Verma, for the petitioner.
Mr. Vinay Arora for Mr. Rakesh Arora, for the respondents.
Heard.
The petitioner sat for Rajasthan Eligibility Examination for
Teachers, 2015, which was conducted by the Board of Secondary
Education. The petitioner was allotted question book-let of Series Code
“Z” having S.No.1178808. She attempted the question paper and filled
the question book-let of Series Code “Z” in the Box, but at the same
time, inadvertently darkened the circle “W” on the answer-sheet.
Objections were called for by the respondent authorities on 15.03.2016.
However, no objections were invited with respect to any error on the
answer-sheet. The result of the examination was declared on 18.05.2016
and the petitioner found that her answer-sheet had been checked as per
the Series Code “W” instead of the Code marked on the book-let as “Z”.
Against the mistake that crept in, the petitioner moved a representation
for correction in the answer-sheet but no such decision was taken
thereon. Aggrieved, the present writ petition has been filed.
Mr. SK Verma, counsel appearing on behalf of the
petitioner, contends that the marking of “W” on the answer-sheet is
wholly inadvertent whereas in fact the question book-let Series Code
Column had been marked as “Z”. Copy of the same is annexed as Annex.
4 with the writ petition and a perusal of the same by this court shows
that the petitioner had marked “Z” in the said Column. Moreover,
Annex.3, which is question book-let No.1178808, which had been
allotted to the petitioner shows that it has been marked as Series Code
“Z”.
Per contra, counsel for the respondents submits that no
benefit can be given to the petitioner as the petitioner herself had
marked “W” and it was on that basis that the answers were checked. It

{2}
is further argued that if the petitioner had filled-in “Z”, then the
computer would have checked her answers as per the answer-sheet of
Code “Z”.
I have heard counsel for the parties and perused the record
of the case.
A perusal of Annex.4 annexed with the writ petition, which
is the candidate's copy, clearly shows that in the Box under “Question
Booklet Series Code “Z” had been marked by the petitioner. Moreover,
S.No.1178808, which is the answer-sheet provided to the petitioner,
pertained to the Series Code “Z”. It is only a circle around the Code “W”
that has made the respondent to mark the answers as per the Series
Code “W”. Since the booklet and the marking in the box pertained to
Series Code “Z”, the petitioner's answer-sheet ought to be checked as
per Code “Z”. The mistake of marking “W” seems to be inadvertent and
the petitioner should not be penalized on this account specially when
there is no discrepancy between the Code on the booklet and on the
answer-sheet.
In view of the above, the prayer made in the writ petition
is allowed. The respondents are directed to correctly assess the answers
of the petitioner as per the Code “Z”. Needful be done on or before
29.07.2016 and result be declared immediately.
With the aforesaid observations, the writ petition stands
allowed.
[Jaishree Thakur],J.
