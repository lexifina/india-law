HON'BLE MR. JUSTICE M.N. BHANDARI
Order
18/05/2017
 An application has been filed for correction in the order
dated 10th February, 2017.
It is stated that inadvertently, in concluding para of the
order dated 10th February, 2017, the word “auction” has been
mentioned, whereas, it should be “lottery”.

(2 of 2)
[WMAP-96/2017]
In view of the submission made above, the application
is allowed. The word “auction” mentioned in concluding para of the
order dated 10th February, 2017 be read as “lottery”.
This order be treated as part and parcel of the order
dated 10th February, 2017.
(M.N. BHANDARI)J.
