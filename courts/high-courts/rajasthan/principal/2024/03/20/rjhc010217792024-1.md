Order
20/03/2024
1. The present misc. Application has been filed seeking
modification/correction in the order dated 05.03.2024 passed by
this Court, wherein, instead of ‘Rent Tribunal, Sardarshahar,
Churu’ it has been mentioned ‘Rent Tribunal, Churu’.
2. For the reasons mentioned in the application and in the
interest of justice, the same is allowed. The ‘Rent Tribunal, Churu’
be read as ‘Rent Tribunal, Sardarshahar, Churu’.
3. The instant misc. application is allowed and the order dated
05.03.2024 is modified accordingly.
4. This order shall be read as part and parcel of the order dated
05.03.2024.
