ORDER
Challenge in this Revision is to an order passed in an application,
obstructing execution of a decree for specific performance.
2. Though the application has been filed under Order XXI Rule 58 of
the Code of Civil Procedure, it is clear that the provision of law stated is
incorrect. The application obstructing execution of a decree for specific
performance ought to have been filed under Order XXI Rule 97 of the Code
of Civil Procedure. Whether it is an application under Order XXI Rule 58 of
the Code of Civil Procedure or under Order XXI Rule 97 of the Code of Civil
Procedure, the orders passed thereon are made specifically appellable by
Order XXI Rule 58(4) and Order XXI Rule 103 of the Code of Civil
Procedure, hence this Revision under Article 227 of the Constitution of India
is clearly not maintainable.
