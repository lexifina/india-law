# Allahabad High Court, WRIC/3410/2025, 2025-04-09

Neutral Citation No. - 2025:AHC-LKO:19979-DB

Petitioner :- Zaffer Iqbal
Respondent :- State Of U.P. Thru. Addl. Chief Secy. Home U.P. Lko. And Others
Counsel for Petitioner :- Girdhari Lal Yadav,Nikhil Yadav
Counsel for Respondent :- C.S.C.
Hon'ble Rajan Roy,J.
Hon'ble Om Prakash Shukla,J.
Heard.
By means of this writ petition the petitioner has prayed for a
writ, order or direction in the nature of Certiorari quashing the
impugned order dated 28.3.2025 passed by the opp. party No. 2
(Annexure-1 to the petition).
The petitioner contends that on the portal concerned
information has been uploaded that the petitioner's license,
which had been granted for running for a security agency, has
been cancelled, but nothing else has been uploaded. The
information uploaded does not contain any information. It only
says "The PSARA Licence has been cancelled for AQSA
Security Services.' This cancellation has been done by opp.
party No. 2.
Let the opp. party No. 2 furnish a reasoned order to the
petitioner, if any such order has been passed cancelling his
license, because it is his claim that during subsistence of this
license which was till 6.12.2026 the aforesaid action has been
taken. Let this be done within 1 week.
Sri Dhawan, learned counsel for the State shall communicate
this order to the opp. party No. 2, for compliance. On receipt of
this order petitioner may avail the remedy as may be prescribed
in law.
If no such order is served upon the petitioner within 1 week, the
petitioner may approach the Court again.
With the above observations/directions this writ petition is
disposed of.
(Om Prakash Shukla, J.) (Rajan Roy, J.)
