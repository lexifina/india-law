# High Court of Madhya Pradesh, WP/15309/2016, 2017-02-08

WP-15309-2016
(SHAHEED KADARI Vs THE STATE OF MADHYA PRADESH)
08-02-2017
None for the petitioner even in the pass over round.
Shri Santosh Yadav, PL for the respondents/State.
This Court on 14.9.2016 passed a detailed order and directed
the petitioner to file certain notifications and undertake certain
exercise. The petitioner was given opportunity on 5.10.16,
21.10.2016, 24.10.2016, 9.11.2016, 25.11.2016 and 02.01.2017
but the petitioner did not comply with the aforesaid order.
Hence, petition is dismissed for want of prosecution by
reserving liberty to the petitioner to file properly constituted
petition by complying with the aforesaid order of this court.
(SUJOY PAUL)
JUDGE
MKL
