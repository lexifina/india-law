# High Court of Rajasthan, CRLMB/1141/2008, 2008-03-28

S.B.Cr.Misc. Bail Appli. No.1141/2008
(Shanker Singh alias Kishore Singh Vs. State of Rajasthan)
Date of order : March 28, 2008
HON'BLE MR.H.R.PANWAR,J.
Mr.Dhirendra Singh, for the petitioner.
Mr.Ashok Upadhyaya, P.P. for the State.
Learned counsel for the petitioner seeks to withdraw the
instant bail application without arguing it, however, seeks
liberty to file a fresh bail application, if occasions so arise.
The bail application filed by the petitioner under section
438 Cr.P.C. is, therefore, dismissed as withdrawn with the
liberty sought for.
 (H.R.PANWAR),J.
