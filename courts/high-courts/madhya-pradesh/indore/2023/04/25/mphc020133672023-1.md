This application coming on for admission this day, the court passed the
following:
ORDER
Heard.
This application has been filed for correction of date as recorded in the
order dated 18.4.2023 passed in M.Cr.C.No.15358/2023.
It is submitted by learned counsel for the applicant that in the order the
date which was to be mentioned was to be "25.4.2023" but due to
typographical error the same has been recorded as "25.3.2023". The same may
hence be corrected.
The aforesaid contention is found to be correct from the record.

JUDGE
Consequently, the application is allowed and the date "25.3.2023" as
mentioned in the order dated 18.4.2023 passed in M.Cr.C.No.15358/2023 is
directed to be read as "25.4.2023" in paragraph No.6 of the order wherever
the same occurs.
This order shall be read conjointly with the order dated 18.4.2023 passed
in M.Cr.C.No.15358/2023.
It is clarified that the order shall come into effect for a period of 3 weeks
from the date of release of the applicant.
