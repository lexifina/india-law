 Order
08/02/2021
An application has been moved for seeking extension of time
from 20.7.2020 on the ground that the petitioner could not file an
application upto 20.7.2020. The order passed by this court was for
all institutions. Even it was applicable to other institutions also
which were not before this court. Thus, the date was common for
all and no change in the date can be made merely because one of
them has not been able to file application within time.

(2 of 2) [WMAP-124/2020]
The application is wholly misconceived and is accordingly
dismissed.
(SANJEEV PRAKASH SHARMA),J
