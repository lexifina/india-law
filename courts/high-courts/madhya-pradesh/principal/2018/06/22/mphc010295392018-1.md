# High Court of Madhya Pradesh, MCRC/23721/2018, 2018-06-22

THE HIGH COURT OF MADHYA PRADESH
MCRC-23721/2018
(LAXMAN @ LACHHU Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated: 22.06.2018
Shri M.K. Tripathi, learned counsel for the
applicant.
Shri Aditya Pyasi, learned Government Advocate
for the respondent/State.
Heard.
This is an application for modification of the bail
order dated 3.4.2018, passed in M.Cr.C. No.
12402/2018.
Learned counsel for the applicant submits that in
the order passed on 3.4.2018 in M.Cr.C. No.
12402/2018, name of the applicant has wrongly been
mentioned, whereas the correct name of the applicant
is “Laxman”.
Considering the aforesaid, this application is
allowed. Let name of the applicant mentioned in the
order dated 3.4.2018 passed in M.Cr.C. No.
12402/2018 be read as Laxman in place of Salman.
This order shall be read conjointly with the order
dated 3.4.2018.
Let a copy of this order be kept in the record of
M.Cr.C. No. 12402/2018.
Certified copy as per rule.
 (H.P. SINGH)
 JUDGE
