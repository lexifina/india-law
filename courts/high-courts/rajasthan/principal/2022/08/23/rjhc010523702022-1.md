JUSTICE DINESH MEHTA
Order
23/08/2022
1. The present misc. petition filed under Section 482 of the
Code of Criminal Procedure, 1973 (hereinafter referred to as the
‘Code’) has been preferred against the order dated 01.07.2022
passed by learned Judicial Magistrate, First Class, Gadhi, District
Banswara by which the application filed by the petitioner under
Section 200 of the Code has been dismissed.
2. In the opinion of this Court, the petitioner is required to file a
revision petition under Section 397 of the Code and direct petition
under Section 482 of the Code before this Court is not
maintainable.
3. While giving liberty to the petitioner to file revision petition,
the present petition is dismissed.

(2 of 2) [CRLMP-4973/2022]
4. Stay application too stands dismissed.
