# High Court of Madhya Pradesh, MCRC/23863/2018, 2018-06-22

HIGH COURT OF MADHYA PRADESH
BENCH AT INDORE.
M.Cr.C. No.23863/2018
Indore, Dt.22.06.2018
Shri Apoorva Joshi, learned counsel for the applicant.
Shri Rakesh Maheshwari, learned Govt. Advocate for
the respondent/State.
Heard.
This is an application for correction of name of
applicant in order dated 14.06.2018 passed in M.Cr.C.
No.21874/2018 by this court. It is submitted that due to
typographical error name of applicant is typed as “Shaitanaram
@ Suresh” in place of “Arjunsingh S/o Udaysingh”.
Considering the fact that applicant's correct name is
Arjunsingh S/o Udaysingh, the petition is allowed with a
direction that in order dated 14.06.2018 passed in M.Cr.C.
No.21874/2018 the name of applicant be read as “Arjunsingh
S/o Udaysingh” in stead of “Shaitanaram @ Suresh”.
Copy of this order be read conjointly with the order
dated 14.06.2018.
With the aforesaid direction, present petition stands
disposed of.
C.c. as per rules.
 (Virender Singh)
 Judge
