CORAM: HONOURABLE MR. JUSTICE MUNGESHWAR SAHOO
ORAL ORDER
2 25-04-2014 Heard learned counsel Mr. Om Prakash Upadhyay
for the petitioner.
2. By the impugned order dated 03.03.2014 passed
by the Subordinate Judge-8, Patna in Title Suit No.145 of
1996 the injunction application filed by the petitioner under
Order 39 Rule 1 and 2 of the Code of Civil Procedure
(Annexure 1 to this writ application) has been rejected.
3. Admittedly, the impugned order has been passed
under Order 39 Rule 1 and 2 of the Code of Civil Procedure, as
such, the impugned order is appealable under Order 43 Rule 1
(r) of the Code of Civil Procedure. This appeal is maintainable
before the lower appellate court because of valuation of the
suit.
4. In view of the above facts and circumstances of
the case, this writ application is not maintainable. Thus, this

Patna High Court CWJC No.6220 of 2014 (2) dt.25-04-2014
2
writ application is dismissed. However, the petitioner, if so
advised, may file miscellaneous appeal before the appropriate
forum.
