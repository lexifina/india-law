4. 22.9.2011 Heard learned counsel for the petitioner and the
State.
A show cause has been filed on behalf of opposite
party no.2 stating therein that the order of this Court has been complied
with. Learned counsel appearing for the State submits that in this view
of the matter, the contempt application deserves to be dismissed.
Learned counsel for the petitioner submits that
although the order contained in Memo No.1364 dated 20th of July, 2010,
as contained in Annexure B to the show cause, has been passed pursuant
to the order of this Court, but the same is not correct. As such, the
petitioner proposes to assail the said order, as contained in Annexure B,
before an appropriate forum.
Be that as it may, since the order of this Court has
been complied with, this contempt application need not proceed further.
The same stands disposed of.
PNM (Shailesh Kumar Sinha,J.)
