P.C. :-
1. The present petition is filed against an order passed below Exh.
16 which was an application filed under order 21 Rule 97 of the Code of
Civil Procedure.
2. If the order is passed on an application under order 21 Rule 97,
then the same is appealable.
3. In view of the above, on this count also, writ petition is not
entertainable.
4. As such writ petition is dismissed. No order as to costs.
( S V GANGAPURWALA, J. )
