CORAM : M.T. JOSHI, J.
 DATED : 10th September, 2013
ORAL ORDER :
1. Heard both sides.
2. The Land Acquisition Reference preferred by
the present petitioners was dismissed by the learned
Reference Court on 21.6.2011, though on merit, in
view of the non-production of any evidence from the
side of the present petitioners. The judgement
impugned shows that since 15.4.2011, the present

 (2) cra192-13
petitioner remained absent and therefore, on
21.6.2011, the Reference came to be dismissed.
3. Mr. A.S More, learned counsel for the
petitioners submits that the judgement would show
that though on some occasions the petitioner remained
absent, on some occasions the matter was adjourned.
The learned A.G.P. opposed the revision application.
4. Considering all the material on record that
the petitioner used to remain present on some
occasions, however, the matter came to be adjourned
on some occasions, in my view, this is a fit case
where the order requires to be set aside,
particularly when the reference application was
pending since the year 1994. In that view of the
matter, the following order.
5. The Civil Revision Application is allowed.
The order passed by the Reference Court is hereby set
aside. The matter is remanded back to the learned
Reference Court. The learned Reference Court is
directed to hear the Reference on its merit afresh.

order as to costs.
