# Allahabad High Court, ABAIL/1545/2020, 2020-02-07

Court No. - 66
Case :- CRIMINAL MISC ANTICIPATORY BAIL
APPLICATION U/S 438 CR.P.C. No. - 1545 of 2020
Applicant :- Subash Chandra Upadhayay
Opposite Party :- State of U.P.
Counsel for Applicant :- Vijay Shanker Singh,Kamla Singh
Counsel for Opposite Party :- G.A.
Hon'ble Rajul Bhargava,J.
Heard learned counsel for the applicant and learned A.G.A. for
the State.
Present anticipatory bail application has been filed directly
before this Court. Learned counsel for the applicant has prayed
that he may be permitted to withdraw this application with
liberty to file fresh before the Sessions court.
Accordingly, the present anticipatory bail application is
dismissed as not pressed with liberty to file fresh before
Sessions Court in view of judgement passed by this Court in
Crl. Misc. Bail Application No. 53729 of 2019 (Vinod Kumar
Vs. State of U.P. and Another) vide order dated 6.12.2019.
Office is directed to return certified copy of F.I.R. to learned
counsel for the applicant.
Order Date :- 7.2.2020
Dhirendra/
