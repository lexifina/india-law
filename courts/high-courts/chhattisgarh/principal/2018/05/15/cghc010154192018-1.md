Order On Board
15/05/2018
1. This petition under Section 482 of Cr.P.C. has been brought with
prayer to modify the order dated 30.04.2018, passed in M.Cr.C.
No.1694/2018, in which the father's name of the applicant has been
wrongly mentioned as Rajkumar Singh, which should have been
Kameshwar Singh.
2. It is submitted that certified copy of the charge-sheet and arrest memo
has been filed for verification of the correct name of the father of this
applicant, hence, it is prayed that modification be made.
3. Counsel for the State opposes the application.
4. Perused the certified copy of the charge-sheet and the arrest memo
filed along with this application in which the father's name of this

2
applicant is shown as Kameshwar Singh, hence, it appears that
typographical mistake has been committed while preparing the
application for bail because of which, similar mistake has been
committed in the cause title of the order passed.
5. Hence for this reason and feeling satisfied, the petition is allowed. The
father's name of this applicant (as applicant No.2) mentioned in the
cause title of the M.Cr.C. No.1694/2018, order dated 30.04.2018 shall
be read as Kameshwar Singh in place of Rajkumar Singh hereinafter.
Copy of this order be made a part of the order passed dated
30.04.2018, passed in M.Cr.C. No.1694/2018.
6. Accordingly, the petition is disposed off.
Certified copy as per rules.
Sd/-
(Rajendra Chandra Singh Samant)
