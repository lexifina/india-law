# High Court of Madhya Pradesh, MCC/1196/2017, 2017-04-19

MCC-1196-2017
(SMT. PUSHPA TELANG Vs THE STATE OF MADHYA PRADESH)
19-04-2017
Shri Alok Naiyak, learned counsel for the applicant.
This application has been filed for restoration of WP
No.11408/11 which was dismissed for want of prosecution on
20.2.2017.
Considering the reasons mentioned in the application, which
is supported by an affidavit seems to be satisfactory and
bonafide, the application for restoration is allowed.
The aforesaid case is restored to its original file. The MCC
stands allowed and disposed of.
Let a copy of this order be kept in the file of WP No.11408/11.
(SMT. ANJULI PALO)
JUDGE
