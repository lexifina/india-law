ORDER: (per Hon’ble the Chief Justice Sri Kalyan Jyoti Sengupta )
In this writ petition, no cause of action discloses to take
action by this Court. When pointed out this difficulty, the learned
Counsel for the petitioner submits that he will file a fresh writ
petition with better affidavit.
Accordingly, we dismiss the writ petition. However, liberty
is given to the petitioner to file a fresh writ petition disclosing the
cause of action.
Miscellaneous Petitions pending, if any, in this petition shall
stand closed. No order as to costs.
