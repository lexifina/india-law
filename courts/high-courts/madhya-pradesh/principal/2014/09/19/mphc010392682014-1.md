# High Court of Madhya Pradesh, MCRC/13338/2014, 2014-09-19

M.Cr.C. No.13338 of 2014
19.09.2014
Shri Pratyush Tripathi, learned counsel for the
applicant.
Shri P.K.Kaurav, learned Additional Advocate
General with Shri Prakash Gupta, learned panel lawyer for
the respondent/State.
Heard counsel for the parties.
This is third bail application filed by the applicant.
The earlier bail application was rejected on 17.07.2014 by a
detailed speaking order. All aspects on merits as were
agitated have been dealt with in the said order. As a result,
this application can be entertained only if there is any
changed circumstance. According to the applicant, the
changed circumstance is that no investigation whatsoever,
has progressed after 17.07.2014 and in particular
concerning or involving the present applicant.
Assuming that this can be considered as a changed
circumstance, the response to the submission given by the
learned counsel for the State is that, investigating officer
has filed further police report under Section 173 (8) of
Cr.P.C. on 14.08.2014, which presupposes that further
investigation was done after 17.07.2014. The argument of
the applicant, however, is that further police report was not
pertaining to the applicant as such. That, however, does not
mean that no further investigation has been done in

connection with Crime No.12/2013 after 17.07.2014, as is
sought to be contended.
We, therefore, reject this argument. Suffice, it to
observe that there is no changed circumstance, since
passing of the order dated 17.07.2014 which necessitates
consideration of this third bail application filed by the
applicant and more so because the co-accused Vivek Yadav
with whom the applicant had constantly interacted is still
absconding.
Taking any view of the matter, this application is
rejected.
(A. M. Khanwilkar) (K.K.Trivedi)
 Chief Justice Judge
AM.
