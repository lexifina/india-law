# Calcutta High Court, CRR/1400/2012, 2021-09-22

25
 22.09.2021
 sb
 CRR 1400 of 2012
(Via video conference)
In re : An application under Section 482, 397 read with Section
401 of the Code of Criminal Procedure, 1973.
 In the matter of : Sk. Sabir & Ors.
 …….petitioners
Mr. Arijit Ganguly
Mr. Sandip Chakraborty ….for the State
Mr. Chakraborty, learned advocate for the State submits
the status report. Report has been submitted by Bauria Police
Station, Howrah. Report reflects that the next date has been
fixed for consideration of charge.
Report so submitted be kept on record.
The revisional application was preferred at a stage when
the charge-sheet was only submitted and none of the documents
under Section 207 of the Code of Criminal Procedure on which
the prosecution relied upon were enclosed.
Having regard to the fact that the petitioners will have
liberty to canvass the grievance before the learned trial court, I
am of the view that in no interference is called for at this stage.
Accordingly, CRR 1400 of 2012 is dismissed.
Pending application, if any, is consequently disposed of.
Interim order, if any, is hereby vacated.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
 (Tirthankar Ghosh, J.)
