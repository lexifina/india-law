O R D E R
Petition filed under Section 482 Cr.P.C.
2. The petitioner was the respondent in CMP No. 6827 of 2015 on
the file of the Judicial First Class Magistrate Court-II, Thrissur.
The latter's daughter was issued Secondary School
Examination Certificate by the petitioner. On the allegation
that there was some mistake in the name of her parents shown
in the certificate, he filed the application to issue a direction to
the petitioner to make correction. The learned magistrate has
allowed it by Annexure A3 order. This is challenged.
3. Heard the learned counsel for the petitioner and the learned
Public Prosecutor.
4. There is not statute conferring jurisdiction on a judicial
magistrate to pass an order like Annexure A3. The magistrate
passed the order without jurisdiction. The order is liable to be
set aside.
In the result, this Crl.M.C. is allowed. Annexure A3 order is set
aside.
