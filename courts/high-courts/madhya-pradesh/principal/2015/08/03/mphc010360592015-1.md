# High Court of Madhya Pradesh, MCC/2075/2015, 2015-08-03

MCC-2075-2015
(RAHUL CHATURVEDI Vs KENDRIYA SHASHAN RAKSHA VIBHAG)
03-08-2015
Shri Prashant Awasthi, learned counsel for the applicant.
This application has been filed for restoration of Misc. Appeal
No.2453/2003, which was dismissed in common conditional order
passed by this Court on 21/08/2014. There being some delay in
filing the application for restoration, I.A. No.9586/2015 has been
filed seeking condonation of delay. Both the applications are
supported by affidavit of the applicant himself and there is no
reason to disbelieve the same. Finding the same to be bonafide,
both the applications are allowed.
Condoning the delay in filing the application, restoration
application itself is allowed.
Misc. Appeal No.2453/2003 is restored to its original
number. It be placed for orders before appropriate Bench.
Application stands allowed and disposed of.
(VANDANA KASREKAR)
JUDGE
