# Calcutta High Court, CRR/1215/2012, 2021-08-26

Sr.29
 26-08-2021
 Subha.
 Court no. 34
 IN THE HIGH COURT AT CALCUTTA
 CRIMINAL REVISIONAL JURISDICTION
 APPELLATE SIDE
 ( Via Video Conference )
 CRR 1215 of 2012
In the matter of : Niranjan Paul & Ors. …..petitioners.
In Re : An application under Section 482 of the Code of
Criminal Procedure.
 The revisional application was preferred
challenging the proceedings relating to C.R. Case No. 442 of
2011 pending before the learned Judicial Magistrate, 4th court,
Burdwan.
 The issue so canvassed in this revisional
application reflects that the same is question of facts which
have been to be gone into by the learned trial court and this
court while exercising its jurisdiction under Section 482 of the
Code of Criminal Procedure is not empowered to address such
grievance.
 Accordingly, the revisional application being CRR
1215 of 2012 is dismissed.
 All pending applications, if any, are consequently
disposed of.

2
 Interim order, if any, is hereby vacated.
 All parties are to act on the server copy of this order
duly downloaded from the official website of this court.
 ( Tirthankar Ghosh, J. )
