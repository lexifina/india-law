JUDGMENT
The defendant in O.S. No.80/2022 on the file of the
Munsiff Court, Koyilandy filed an application under Section
151 read with Section 10 of the Code of Civil Procedure to
keep in abeyance the suit so as to facilitate her to file a
written statement after the disposal of the connected
criminal case. The said application was dismissed as per
Ext.P4 order. It is challenging the said order, the defendant
has approached this Court.
2. I have heard Sri. Santharam P., the learned counsel
appearing for the petitioner and Smt. K. V. Rashmi, the
learned counsel appearing for the respondent.
3. The suit is of the year 2022. It is submitted that
since the defendant did not file written statement, the
matter stands posted tomorrow for evidence. The defendant
cannot contend that till a connected criminal case is

3

disposed of, the suit has to be kept in abeyance. However, I
am of the view that the defendant can be granted three
weeks’ time to file written statement. Hence, this Original
Petition is disposed of as follows:
The petitioner/defendant shall file written statement
within three weeks from today. On filing the written
statement, the learned Munsiff is directed to receive it on file
and proceed with the case in accordance with the law,
without much delay. If the written statement is not filed as
aforesaid, the learned Munsiff shall proceed with the suit
exparte.
