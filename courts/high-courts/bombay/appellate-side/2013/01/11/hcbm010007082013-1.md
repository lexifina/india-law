IN THE HIGH COURT OF JUDICATURE AT BOMBAY
APPELLATE CIVIL JURISDICTION
WRIT PETITION NO. 175 OF 2013
K.N. Krishnamurthy ...Petitioner
Vs.
Kavita Krishnamurthy ...Respondent
Mr. A.S. Khandeparkar, Advocate for Petitioner
i/b. Shilpa A. Joshi
CORAM : MRS. ROSHAN DALVI, J.
 DATED : 11TH JANUARY, 2013
P.C. :
1. The learned Judge, Family Court No.3, Mumbai has passed
an order on 21st December, 2012 relating to access during
Christmas vacation, birthday access and directions in the
petition, which is challenged.
2. Notice is given to the respondent, which is received by the
respondent on 8th January, 2013. Despite notice the respondent
is absent.
3. The first part of the order is not challenged. For the order
relating to birthday access it is stated that further directions
were to be passed specifying the time of the access.
4. The last part of the order is challenged, which prevents the

2
parties from making interim applications, but to proceed with
the final hearing. The order is absolutely correct. The Petition is
of 2009. It has to be heard and finally disposed of. It is
counterproductive for the parties go on making applications
after applications and not getting the main petition disposed of.
The order is in the interest of both the parties, more specially for
the parties with merits. The order does not require to be set
aside, but in fact requires to be reiterated.
5. So far as the birthday access is concerned, if further
directions are required, the petitioner is not required to file a
Writ Petition and challenge the birthday access. The petitioner
must apply for those directions before the trial Court itself. The
directions would be passed so soon as they are applied for.
There is no need for challenge of any order.
6. I am told that earlier birthday accesses have been given.
Hence, this year's birthday access would be on the same lines.
7. With these directions the Writ Petition is dismissed.
 (MRS. ROSHAN DALVI, J.)
