HON'BLE MRS. JUSTICE SABINA
Order
17/08/2017
Petitioner has filed this petition under Section 482 Code
of Criminal Procedure, 1973 challenging the order dated
9.12.2014, whereby, J.C.B. machine was ordered to be taken in
possession by way of search warrants.
Learned state counsel on instructions from Sub-Inspector Surendra Malik, has submitted that the J.C.B. machine
has been located and will be taken in possession within fifteen days
from today from State of Orissa.
Since, the J.C.B. machine is liable to be recovered and
taken in possession being case property, the learned magistrate
had rightly issued warrants that the same be taken in possession.
No ground for interference is made out.
Dismissed.
(SABINA)J.
