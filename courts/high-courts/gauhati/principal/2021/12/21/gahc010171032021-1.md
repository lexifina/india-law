ORDER
Date : 21-12-2021
Heard Swati B. Baruah, learned counsel for the applicants.
The present application has been filed for restoration of the Review Petition
84/2021 which was dismissed for non-prosecution vide order dated 06.10.2021.
The reasons assigned for restoration seem to be bonafide.
Accordingly, this interlocutory application is allowed.
The order dated 06.10.2021 by which the review petition was dismissed, is
recalled.
Review Petition 84/2021 is restored to its original number and the same be
listed on 27.01.2022.
 JUDGE CHIEF JUSTICE
