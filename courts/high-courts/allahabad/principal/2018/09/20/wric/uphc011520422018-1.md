# Allahabad High Court, WRIC/27132/2018, 2018-09-20

Court No. - 34
Case :- WRIT - C No. - 27132 of 2018
Petitioner :- Smt. Rati
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Anand Kumar Pandey,Kamini
Pandey (Dubey)
Counsel for Respondent :- C.S.C.,Vivek Verma
Hon'ble Sudhir Agarwal,J.
1. Called in revise. None is present for the petitioner to press
this writ petition. Learned Standing Counsel as well as Sri
Jitendra Rana, Advocate, holding brief of Sri Vivek Verma,
learned counsel for respondents are present.
2. On 24.08.2018, counsel for petitioner sought time to file
supplementary affidavit mentioning therein the date on which
petitioner got admission in B.Ed. Course in the session 2013-14
but the order dated 24.8.2018 has not been complied, which
shows that result of petitioner has rightly been withheld. Hence,
petitioner is not entitled for any relief.
3. Dismissed.
