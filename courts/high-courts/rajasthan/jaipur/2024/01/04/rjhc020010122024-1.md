HON'BLE MR. JUSTICE SUDESH BANSAL
Order
04/01/2024
1. Instant miscellaneous application has been filed by appellants-applicants, seeking correction in the order dated 21.12.2023
passed in SB Criminal Appeal No.3097/2023 by this Court,
wherein in Para No.1, reference of FIR number has been
mentioned as “575/2020” instead of “575/2023”.
2. Heard learned counsel for both parties.

[2024:RJ-JP:534] (2 of 2) [CRLMA-7/2024]
3. It appears that in Para No.1 of the order dated 21.12.2023,
FIR number has been mentioned as “575/2020”, while in fact it
should be “575/2023”, which is error, occurred inadvertently.
4. In view of above, in the order dated 21.12.2023, FIR number
as mentioned in Para No.1 i.e. “575/2020” be corrected in red ink
as “575/2023” and the correction made in the original order be
upload online showing asterisk (*) mark in the order that
reference of FIR number has been corrected subsequently. Rest
part of the order shall remain as such.
5. Accordingly, the misc. application stands disposed of.
(SUDESH BANSAL),J
