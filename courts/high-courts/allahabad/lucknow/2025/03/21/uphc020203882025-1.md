# Allahabad High Court, A483/256/2025, 2025-03-21

Court No. - 12
Case :- APPLICATION U/S 483 No. - 256 of 2025
Applicant :- Meraj Khan @ Meraj Ahmad
Opposite Party :- State Of U.P. Thru. The Prin. Secy. Home
U.P. Lko. And Another
Counsel for Applicant :- Shadab Haider,Rizwan
Haider,Tanveer Haider
Counsel for Opposite Party :- G.A.
Hon'ble Alok Mathur,J.
1. Heard Sri Shadab Haider, learned counsel for petitioner as
well as learned A.G.A. for the State.
2. The prayer made in the present case is for deciding the
application for interim relief moved along with the application
for discharge before the Chief Judicial Magistrate, Sitapur.
3. It has been submitted that the applicant has approached this
Court previously by filing application under Section 482 Cr.P.C.
which was registered as Application U/S 482 No. 1589 of 2025
which was dismissed and the applicant was granted liberty to
move appropriate application for discharge through counsel
before the concerned court below within fifteen days and the
court was directed to decide the same within four months.
4. Learned counsel for applicant has submitted that application
for discharge has been filed on 01.03.2025 and the next date
fixed is 02.04.2025 and a prayer has been made for deciding
the interim relief application.
5. When a pointed query has been made as to whether any
provision exists for deciding any interim relief, learned counsel
for applicant could not show any provision.
6. Apart from the above, this Court finds that this Court has
already provided the time within which the application for
discharge has to be decided, accordingly, this Court does not
find any ground for interference in the matter, accordingly
present application under Section 482 of Cr.P.C. is dismissed.
(Alok Mathur, J.)
