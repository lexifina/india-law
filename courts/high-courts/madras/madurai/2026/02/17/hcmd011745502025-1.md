ORDER
When the Writ Petition was taken up for hearing on 06.01.2026, the
learned counsel for the petitioner sought time to file the translated versions of the
documents, which are in the Tamil language. Accordingly, the matter was directed
to be listed on 11.02.2026 with a specific condition that, in the event of failure to
file the same, the Writ Petition shall stand dismissed. Again, when the matter was
taken up for hearing on 11.02.2026, the learned counsel for the petitioner sought
time to file the translated versions of the documents. Therefore, the matter was
directed to be listed on 17.02.2026 (today) under the caption “for dismissal”.
