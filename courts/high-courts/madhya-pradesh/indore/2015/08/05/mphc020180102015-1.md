# High Court of Madhya Pradesh, MCRC/6652/2015, 2015-08-05

M.Cr.C. No.6652/2015
05.08.2015
Shri A.K. Saraswat, learned counsel for the applicant.
Smt. Mamta Shandilya, learned Dy. Govt. Advocate for
the respondent, State.
Learned counsel for the applicant submits that the
applicant had filed an application u/s. 438 of the Cr.P.C. And the
same was registered as M.Cr.C. No.5494/2015. Said M.Cr.C. Was
allowed on 13.7.2015. The said application was filed u/s. 438 of the
Cr.P.C. but inadvertently, the order is passed assuming as if it is u/s.
439 of the Cr.P.C. Therefore, this application is filed for
correction/modification of the order.
I have gone through the order passed in M.Cr.C.
No.5494/2015. It is true that inadvertently, this mistake has been
occurred. Thus, the order dated 13.7.2015 passed in M.Cr.C.
No.5494/2015 is hereby recalled.
It is not appropriate to pass any order in this petition
while exercising powers u/s. 482 of the Cr.P.C.
Thus, the petition is disposed of with the direction that
the applicant may file a fresh application u/s. 438 of the Cr.P.C.
( JARAT KUMAR JAIN )
 JUDGE.
