 ORDER
This Criminal Original Petition has been filed praying to
quash the case in Crime No.280 of 2015 on the file of the first
respondent.
2. Heard the learned counsel for the petitioner and the
learned Additional Public Prosecutor appearing for the first
respondent.
3. The respondent Police have filed a counter. When this court
was about to dismiss this petition on merits, the learned counsel
for the petitioner sought permission to withdraw this petition and
has made an endorsement to that effect.
https://hcservices.ecourts.gov.in/hcservices/

4. In view of the above, this Criminal Original Petition is
dismissed as withdrawn. Consequently, the connected miscellaneous
petition is closed.
