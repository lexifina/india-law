# Madras High Court, A/7740/2019, 2020-09-18

A.No.7740 of 2019
N.SATHISH KUMAR, J.
This application has been filed to
direct the respondent to furnish security for
a sum of Rs.8,97,684.70/-, failing which, to
order attachment of the immovable
properties morefully described in the
schedule to the Judges summons, pending
disposal of the arbitration proceedings.
2. This Court by an Order dated
20.07.2020, directed the respondent to
furnish security for the reduced amount of
Rs.6,32,896/- on or before 24.08.2020.
3. Despite the Order of this Court
directing to furnish security, the respondent
has not furnished any security and none
appeared for the respondent.
4. In view of the same, there shall be
an Order of attachment of the immovable
properties described in the schedule and
this application is closed. The registry is
directed to communicate this Order to the
concerned Registrar.
