CORAM : A.B.CHAUDHARI, J.
DATED : APRIL 16, 2014
Heard learned counsel for the applicant. None for
the non applicant.
The order rejecting application to frame and try the
preliminary issue is under challenge in the present application.
Perused the impugned order. I find no error of jurisdiction
committed by learned trial Judge since the learned trial Judge
has specifically framed preliminary issue in the operative part
of the order for being tried in the suit. The trial Judge has
given reasons for rejecting the application which, in my
opinion, are legal, correct and proper. Hence, I pass the
following order.
ORDER
Civil Revision Application No. 133/2013 is rejected.
No order as to costs.
