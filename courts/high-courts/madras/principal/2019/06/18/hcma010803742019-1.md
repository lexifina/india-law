 Application praying that this Honble Court be pleased to
set aside the order of dismissal for default dated
13.08.2018 passed in the above C.S.No.34/2017.
 This Application coming on this day before this court
for hearing the court made the following order:
 This application has been filed seeking to set aside the
order of dismissal for default dated 13.08.2018 and restore
the suit in C.S.No. 34 of 2017. The delay in filing this
application was condoned by an order dated 03.06.2019.
https://hcservices.ecourts.gov.in/hcservices/

2. Considering the averments made in the affidavit
filed in support this application, the order dated
13.08.2018 dismissed for default is set aside and the suit
is restored to file. The learned counsel for the
applicants in A.No. 4791 of 2017 would submit that his
application seeking to revoke the leave granted was closed.
In view of the restoration of the suit, the order dated
13.08.2018 closing the A.No.4791 of 2019 is recalled and
A.No. 4791 of 2019 will also stand restored.
