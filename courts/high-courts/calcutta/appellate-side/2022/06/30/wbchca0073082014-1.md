# Calcutta High Court, CRR/173/2014, 2022-06-30

30.06.2022
S/L No.12
 S.D.
 C.R.R. 173 of 2014
 M/s. Kitply Industries Limited & Ors.
 Vs.
 State of West Bengal & Anr.

The revisional application is listed today for hearing.
On call none appears for the petitioners and for opposite parties.
Petitioners have filed this revisional application under Section 401
read with Section 482 of the Code of Criminal Procedure assailing order
dated 11.12.2013 passed by Learned Metropolitan Magistrate, 6th Court,
Bankshall Court, Kolkata in C. Case No.14648 of 2011 whereby order was
issued for attachment of property against petitioner no.1.
Since none appears on repeated call, the revisional application is
dismissed for default.
It needs to be noted herein that on 20.01.2014 an order was passed
by this Court to the effect that the impugned order dated 11.12.2013 was
stayed till 28.02.2014 or till further order whichever was earlier and the
same would not prevent the Court below to proceed with the trial
according to law.
Let a copy of this order be communicated to Learned Metropolitan
Magistrate, 6th Court, Bankshall Court, Kolkata for information.
All parties shall act on the server copy of this order downloaded
from the official website of this Court.
 (Ananda Kumar Mukherjee, J.)
