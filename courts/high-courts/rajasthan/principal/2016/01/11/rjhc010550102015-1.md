# High Court of Rajasthan, CRLMB/11755/2015, 2016-01-11

S.B. CR. MISC. BAIL APPLICATION NO.11755/2015
Rekha Ram V/S State of Rajasthan
Date of order : 11.01.2016
HON'BLE MR. JUSTICE VIJAY BISHNOI
Mr. K.C. Choudhary, for petitioner.
Mr. K.V. Vyas, Public Prosecutor.
Learned counsel for the petitioner, without
arguing on merits, has prayed that he does not
want to press this criminal misc. bail
application as the charge-sheet has already been
filed, however, seeks liberty for the petitioner
to file fresh bail application before the trial
court.
Accordingly, this criminal misc. bail
application preferred by the petitioner under
Section 439 Cr.P.C. is dismissed as not pressed
with the liberty as prayed for.
[VIJAY BISHNOI],J.
