# Madras High Court, A/2096/2024, 2024-04-16

1
A.No.2096 of 2024
 in CS.No.730 of 2019
C.V.KARTHIKEYAN, J.
This application has been filed to set aside the exparte order dted 19.02.2021
whereby the applicant herein, the 4th defendant in the suit has been set exparte.
2. Earlier application filed by the present applicant in A.No.1046 of 2024
seeking to condone the delay of 1038 days in filing the application to set aside the
order dated 19.02.2021 was allowed by this Court by order 23.02.2024 subject to
condition that the applicant herein should pay a sum of Rs.10,000/- to Cancer
Institute (WIA), Adayar, Chennai. Now, the present application is consequential in
nature to set aside the exparte order. It is also contended by the learned counsel that
he had filed a separate application seeking to condone the delay in filing the written
statement of the 4th defendant.
3. Taking all these facts into consideration, this application is allowed.
4. Registry is directed to put up any other application which are pending for
numbering on 12.06.2024.
