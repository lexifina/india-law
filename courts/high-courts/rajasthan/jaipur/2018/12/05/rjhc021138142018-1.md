HON'BLE MR. JUSTICE ASHOK KUMAR GAUR
Order
05/12/2018
Matter comes up on the misc. application for correction in
the order dt.03.10.2018 passed by this Court. This Court at page
6 of the order has set aside the impugned order dt.07.07.2017.
Learned counsel for the petitioner has submitted that the
impugned order dt.07.06.2017 inadvertently has been mentioned
as 07.07.2017 in the order passed by this Court while deciding the
petition.
For the reasons stated/mentioned therein, the said misc.
application is allowed.
In the order dt.03.10.2018 at page 6 in 3rd para of the
second line, the impugned order “dt.07.07.2017” be read as
“07.06.2017”.
The correction so allowed will form part & parcel of the
original order.
(ASHOK KUMAR GAUR),J
A.Kumar/76
