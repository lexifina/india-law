# High Court of Tripura, CM Appl.(WP)/390/2014, 2014-09-24

Case No :CM Appl.(WP) 0000390/2014
Party Name : UNION OF INDIA Vs EMANUL ISLAM
HONBLE THE CHIEF JUSTICE DEEPAK GUPTA THE HONBLE MR. JUSTICE S.C.DAS
By means of this modification petition the petitioner-Union of India has prayed that there is
an error in the order dated 01.07.2014 inasmuch as the order dated 07.01.2006 has also
been set aside. It is contended that if this order is also set aside, then obviously no appeal
can be heard against such order by the Inspector General, BSF. There is merit in this
contention and therefore in para 5 the sentence which reads as follows:- "We, therefore,
allow this petition, set aside both the orders, dated 07.01.2006 & 23.02.2008 and direct the
Inspector General of Police, BSF to personally examine the matter and to pass a reasoned
order on the representation of the petitioner within 30 days from the receipt of the copy of
this order. He shall place the copy of the said order on the file of this case." is modified and
shall read as follows: "We, therefore, allow the petition, set aside the order, dated
23.02.2008 and direct the Inspector General of Police, BSF to personally examine the
matter and to pass a reasoned order on the representation of the petitioner within 30 days
from the receipt of the copy of this order. He shall place the copy of the said order on the
file of this case." Since we have modified the order today, time to dispose of the appeal is
extended upto 31st December,2014. CM application accordingly stands disposed of.
