 The learned counsel for the applicant/accused submitted that the
Application for bail is filed before filing of the charge sheet. As the charge
sheet is filed before the Sessions Court, he, on instructions, wants to
withdraw this Application with liberty to file fresh application before the
Sessions Court.
2. Hence, the Application is dismissed as withdrawn with liberty to file
fresh application before the Sessions Court.
