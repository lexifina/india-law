# High Court of Madhya Pradesh, MCC/797/2017, 2017-03-27

MCC-797-2017
(RAGHUVENDRA PRASAD SHUKLA Vs THE STATE OF MADHYA PRADESH)
27-03-2017
Shri K.K. Agnihotri, learned counsel for the applicant.
This application has been filed for restoration of W.P. No.19083/2015
which has been dismissed for want of prosecution on 20.02.2017. The
application is supported by an affidavit of Advocate-Shri K.K. Agnihotri.
Keeping in view the reasons indicated in the application, the M.C.C. is
allowed and it is directed that W.P. No.19083/2015 be restored to its
original number and list this case before the appropriate Bench.
Let a copy of this order be kept in the file of W.P. No.19083/2015.
(SMT. ANJULI PALO)
JUDGE
