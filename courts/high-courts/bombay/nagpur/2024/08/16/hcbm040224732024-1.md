1. This is an application for condonation of delay
of 1849 days caused for filing restoration application.
2. Perused the application.
3. Heard learned Advocate of the applicant.
4. Learned Advocate for the applicant submits
that delay is not deliberately caused.
5. For the reasons stated in the application, the
application deserves to be allowed in the interest of
justice.
6. The application is allowed.
7. The delay of 1849 days caused in filing
restoration application is condoned.
8. The application is disposed of.

MISC. CIVIL APPLICATION ST. No.15618 OF 2024.
1. This is an application for restoration of the first
appeal which was dismissed for non-filing of paper-book.
2. Paper-book is filed in First Appeal
No.189/2016, which is pending in this Court.
3. Considering this reason, filing of paper-book
can be dispensed with.
4. Filing of the paper-book is dispensed with, as it
filed in First Appeal No.189/2016.
5. The application is, therefore, allowed in the
interest of justice.
6. The appeal is restored on its original number.
7. The application is disposed of.
