# Allahabad High Court, A482/16597/2014, 2019-05-17

Court No. - 67
Case :- APPLICATION U/S 482 No. - 16597 of 2014
Applicant :- Smt. Shabana Begam
Opposite Party :- State Of U.P. And 3 Ors
Counsel for Applicant :- Harbansh Prasad Pandey
Counsel for Opposite Party :- Govt. Advocate,Brijesh
Sahai,Sandeep Kumar
Hon'ble Rahul Chaturvedi,J.
Heard learned counsel for the applicant, learned counsel for
opposite party no.2 as well as learned A.G.A.
By means of the present application, the applicant is assailing
the order dated 09.04.2014 passed by learned Judicial
Magistrate, Allahabad, Court No.3.
I have perused the order impugned and I find that this 482
Cr.P.C. application is not maintainable against the order
impugned. However, if so advised, the applicant may file
complaint for espousing his cause.
With the aforesaid observations, the present application stands
disposed of.
Order Date :- 17.5.2019
Sumit S
