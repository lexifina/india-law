# High Court of Madhya Pradesh, MCRC/2737/2015, 2015-03-03

M.Cr.C.No.2737 of 2015

1
Suresh Gautam vs Pooja Dubey and another
03/03 / 2015
Shri U.K. Tripathi, Advocate for the applicant.
Shri Ramesh Kushwaha, Panel Lawyer for the
respondent/State.
Heard finally.
This application has been filed seeking modification
in the order dated 25.11.2014 passed by this Court in
M.Cr.C.No.14827/2014.
It is submitted that due to some typographical error,
the word “Complaint Case No.990/2007” is not mentioned
in the application filed by the applicant and, therefore, the
same has not been mentioned in the order passed by this
Court.
Keeping in view the aforesaid, this application is
allowed. In the order dated 25.11.2014 passed by this
Court in M.Cr.C.No.14827/2014 after word “Crime
No.140/2007”, the word “Complaint Case No.990/2007”
is hereby added.
The order dated 25.11.2014 passed by this Court in
M.Cr.C.No.14827/2014 shall be read conjointly with this
order along with the aforesaid modification.
Certified copy as per rules.
 (SUBHASH KAKADE)
SJ JUDGE
