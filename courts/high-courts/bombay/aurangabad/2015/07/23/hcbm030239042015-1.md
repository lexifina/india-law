Per Court :-
The Applicant has directly filed Application for bail, before
this court. I have taken consistent view that prior to approaching
before this Court, the Applicant must avail the opportunity of filing an
Application for bail, before the trial court.
[2] In that view of the matter, the learned counsel for the
Applicant seeks permission to withdraw the present Application, so as
to enable him to file Application before the trial court. Criminal
Application is dismissed as withdrawn.
