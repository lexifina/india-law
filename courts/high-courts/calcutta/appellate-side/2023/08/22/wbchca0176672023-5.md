# Calcutta High Court, CRR/1324/2023, 2023-08-22

August 22, 2023 IN THE HIGH COURT AT CALCUTTA
 AD-43 CRIMINAL APPELLATE JURISDICTION
 Ct. 34
 SG CRR 1324 of 2023
 In the matter of: Balwinder Singh
 … petitioner
 Mr. Ayan Basu
 Mr. Sumit Routh
 … for the petitioner.
 Mr. Madhusudan Sur
 Mr. Manoranjan Mahata
 … for the State.

A report has been submitted to this Court regarding
the genuinity of the licence of the fire-arms and
ammunitions. The same be kept with the record.
Petitioner prays for return of the licensed fire-arms
and the ammunitions which were seized in connection with
the instant case. Petitioner is working as a professional
security of one Priyangu Pandey.
The investigation of the case is continuing whether
the arms and the ammunitions which have been issued for
personal security of the petitioner who happens to be an
ex-military personnel or the same is for being used
professionally is to be assessed.
Petitioner would be entitled to return of the licensed
arms and ammunitions on a bond to the satisfaction of the
learned Chief Judicial Magistrate, Howrah subject to the
condition that the same would not be used within the State
of West Bengal.

2
With the aforesaid observations, CRR 1324 of 2023 is
disposed of.
Pending application, if any, is consequently disposed
of.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
Urgent certified copy of this order, if applied for, be
urgently made available to the parties upon compliance of
all requisite formalities.
 ( Tirthankar Ghosh, J. )
