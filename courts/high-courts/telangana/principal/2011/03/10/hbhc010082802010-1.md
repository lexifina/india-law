# High Court for the State of Telangana, CRP/3569/2010, 2011-03-10

THE HON'BLE SRI JUSTICE B.PRAKASH RAO
CIVIL REVISION PETITION NO.3569 OF 2010
ORDER:
The petitioner filed this revision under Section 115 of the Code of
Civil Procedure, 1908 {“CPC” for brevity}, inter alia, seeking to assail
the order dated 12.07.2010 passed in E.A.No.288 of 2010 in
E.P.No.59 of 2010 in O.S.No.157 of 2009 on the file of the XI Junior
Civil Judge, City Civil Court, Secunderabad, in dismissing the
application filed under Order XXI Rule 26 read with Section 151 CPC
seeking to stay all further proceedings in E.P.
The main ground urged by the petitioner is that since it is an ex
parte decree, it could not have been executed. Further, it has been
pointed out that he filed an application to set aside the ex parte decree.
It is always open for the petitioner to file application to set aside
the ex parte decree but not to file revision. In view of the same, I do not
find any reason to grant the relief as sought for.
Accordingly, the Civil Revision Petition is dismissed with liberty
to the petitioner to file separate application in the application filed to
set aside the ex parte decree. No costs.
