# Allahabad High Court, BAIL/34505/2024, 2024-10-22

Neutral Citation No. - 2024:AHC:168765
Court No. - 49
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 34505 of
2024
Applicant :- Nizamuddin
Opposite Party :- State of U.P.
Counsel for Applicant :- Mrityunjay Dwivedi
Counsel for Opposite Party :- G.A.
Hon'ble Saurabh Shyam Shamshery,J.
Heard learned counsel for the applicant, learned A.G.A. for the
State and perused the record.
This is the second bail application. The first bail application was
rejected, vide order dated 301 of 2021.
The applicant has rushed this Court, despite while rejecting the
first bail application on 9.4.2024, this Court has provided eight
months time to conclude the trial, whereas this application is filed
within three months thereof, i.e prematurely.
In the aforesaid circumstances, this application is disposed of with
liberty to file a fresh after the aforesaid period is over along with
status report of the trial and the evidence, if so advised.
Order Date :- 22.10.2024
