ORDER
This petition is filed by the petitioner against the order dated
10/12/2021(Annexure-P-1), whereby the petitioner has been directed to be
transferred in pursuance to the panchayat election notified.
Counsel for the petitioner submits that Writ Appeal No.64/2022 has
been decided by the Division Bench taking note of the fact that the transfer
order was issued because of the Panchayat election, but later on panchayat
election has been withdrawn, therefore, the order of transfer is not sustainable
and the same was set aside by the Division Bench. He submits that the
impugned order passed in this petition is also required to be set aside.

JUDGE
Counsel for State submits that he may be granted some time to file
reply.
However, considering the fact that Division Bench has already taken a
view, I am not inclined to keep the matter pending. Accordingly, impugned
order dated 10/12/2021(Annexure-P-1) in respect of the petitioner is set
aside. Liberty is with the respondent-State and also the Election
Commission, if occassion so arises, they may issue a fresh order in
pursuance to the existing exigency.
