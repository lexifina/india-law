Order
27/07/2017
1. There is totally a non-application of mind in filing the present
restoration application. It is not a case where the caption of the
application inadvertently records the application to be a D.B. Civil
Miscellaneous Restoration Application. Even in the pleadings and
the prayer made it is stated that the restoration application may
be allowed and order dated 20.01.2017 be recalled. The order
dated 20.01.2017 does not dismiss the D. B. Special Appeal Writ
No. 640/2015 in default alone. It dismisses the appeal on merits
and records that since nobody appeared for the appellant it would
be treated as dismissed in default as well.
2. Learned counsel for the appellant states that the appellant

(2 of 2)
[WRES-61/2017]
actually instructed him to file a review petition.
3. We dismiss the aforesaid application. It would be open for
the appellant to file an application for review of the order dated
January 20, 2017. As and when the application is filed the same
shall be decided as per law.
(VIJAY KUMAR VYAS),J. (PRADEEP NANDRAJOG),C.J.
