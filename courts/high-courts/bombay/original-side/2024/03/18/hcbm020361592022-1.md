Advocate for the Petitioner
1. Read praecipe dated 18.03.2024 for correction in
name of the deceased in order dated 01.02.2024
stating that name of the deceased is mentioned as
“Suryakant alias Suryakant Nagshi Nagshi Shah
(Lodaya)” instead of “SURYAKANT NAGSHI SHAH
(LODAYA) Alias SURYAKANT NAGSHI,”. From the
face of the record, submission is accepted and
therefore, praecipe is allowed.
2. Hence, in order dated 01.02.2024 name of the
deceased be corrected and read as “SURYAKANT
NAGSHI SHAH (LODAYA) Alias SURYAKANT
NAGSHI”.
3. It is made clear that rest of the order will remain
same.
4. Removed from the board.
