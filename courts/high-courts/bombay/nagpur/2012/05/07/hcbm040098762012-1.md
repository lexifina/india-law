APPP NO. 518 OF 2012:
The application is filed for restoration of application
(ABA) No. 117/2012. This Court has dismissed the said
application as nobody was present for the applicant.
Both the sides are heard.
The Advocate for the applicant submitted that he is
from Amravati and he comes to Nagpur on every Monday. The
same Advocate is appearing today and he made some submissions.
In view of these circumstances, for the reasons given in the
application, the application for restoration is allowed.
Order dated 09/4/2012 of dismissal made by this Court
is set aside. Bail application is restored to file.
