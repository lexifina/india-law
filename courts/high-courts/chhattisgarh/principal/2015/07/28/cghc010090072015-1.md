Order On Board

Heard.
1. Grievance of the petitioner is that the petitioner's application for grant of permanent stage
carriage permit on the route Jashpur to Bagicha via Kunkuri, Kansabel Mahadevdand with
one return trip daily has been kept pending and not decided.
2. Though learned counsel for the petitioner submits that the application was filed on
28.02.2015, State counsel points out from petitioner's own application that it bears that
22.06.2015.
3. Be that as it may, considering that petitioner's application is pending before the Regional
Transport Authority. Let it be decided as early as possible.
4. Accordingly, the petition is disposed off.
