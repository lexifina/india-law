For the Petitioner : Mr. P.K. Mukhopadhyay, Advocate
For the State : A.P.P.
 02 /22.04.2013 It reveals that the petitioner was granted anticipatory bail by this Court
vide A.B.A. No.2494 of 2012 dated 27.09.2012 but the petitioner has again
preferred this anticipatory bail application against the same impugned order
which was passed by learned Sessions Judge in A.B.P. No.592 of 2012 dated
19.06.2012. Since the matter has already been considered by this Court, I do
not feel inclined to deal with the same matter again.
Accordingly, this anticipatory bail application stands dismissed as not
maintainable.
