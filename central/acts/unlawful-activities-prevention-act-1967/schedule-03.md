# The Third Schedule

[See clause (b) of Explanation to section 15(1)] SECURITY FEATURES TO DEFINE HIGH QUALITY COUNTERFEIT INDIAN CURRENCY NOTES Watermark(s), Security thread and any one of the following features:

(a) Latent image;

(b) See through registration;

(c) Print quality sharpness;

(d) Raised effect;

(e) Fluorescent characteristics;

(f) Substrate quality;

(g) Paper taggant;

(h) Colour shift effect in OVI;

(i) Colour shift effect in security thread.]

Notes in the official text:

- 1. Subs. by G.S.R. 231(E), dated 18-3-2014.
