# High Court of Madhya Pradesh, MCC/1510/2017, 2017-05-16

MCC-1510-2017
(SMT MAYA RAJAK Vs THE STATE OF MADHYA PRADESH)
16-05-2017
Shri S.K. Sharma, learned counsel for the applicant.
This application has been filed for restoration of W.P. No.5597/2017
which has been dismissed for want of prosecution on 25.04.2017. The
application is supported by an affidavit of Advocate-Shri S.K. Sharma.
Keeping in view the reasons indicated in the application, the MCC is
allowed and it is directed that W.P. No.5597/2017 be restored to its
original number and list this case before the appropriate Bench.
Let a copy of this order be kept in the file of W.P. No.5597/2017.
(SMT. ANJULI PALO)
JUDGE
