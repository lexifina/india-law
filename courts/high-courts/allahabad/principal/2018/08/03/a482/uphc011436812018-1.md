# Allahabad High Court, A482/25286/2018, 2018-08-03

Court No. - 53
Case :- APPLICATION U/S 482 No. - 25286 of 2018
Applicant :- Aasu Alias Aas Mohamad
Opposite Party :- State Of U.P. And Another
Counsel for Applicant :- Rajesh Kumar Pandey
Counsel for Opposite Party :- G.A.
Hon'ble J.J. Munir,J.
Sri Rajesh Kumar Pandey, learned counsel for the applicant
submits that he has not been able to annex the injury report
about which there is issue in the present application. Besides, he
wants to incorporate certain essential facts and enclose
documents. As such this application may be dismissed as
withdrawn with liberty to file a fresh.
The applicant's prayer is accepted.
This application is dismissed as withdrawn with liberty to file a
fresh.
Order Date :- 3.8.2018
