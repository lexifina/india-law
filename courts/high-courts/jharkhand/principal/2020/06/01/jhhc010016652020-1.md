# High Court of Jharkhand, Cr.M.P./182/2020, 2020-06-01

IN THE HIGH COURT OF JHARKHAND AT RANCHI
Cr. M.P. No. 182 of 2020
----
Mukesh Agarwal @ Mukesh Kumar … Petitioner
-versus-The State of Jharkhand … Opposite Party
----
CORAM : HON’BLE MR. JUSTICE ANANDA SEN
THROUGH : VIDEO CONFERENCING
----
For the Petitioner : Mr. Pratiush Lala, Advocate
For the State : Mr. Ashok Kumar, A.P.P.
----
4/ 01.06.2020 Heard Mr. Pratiush Lala, learned counsel appearing for the
petitioner and Mr. Ashok Kumar, learned A.P.P. appearing for the State
through Video Conferencing. They have no complain with respect to the
audio and video clarity and quality.
2. Petitioner, in this criminal miscellaneous petition, has
challenged the order dated 20.11.2019 passed by the Judicial Magistrate,
Dhanbad in Sindri Police Station Case No.67 of 2019, by which process
under Section 82 of the Code of Criminal Procedure has been issued
against the petitioner.
3. I have heard the counsel for the parties and have gone
through the impugned order. I find that just on asking of the investigating
officer, without recording any satisfaction, as mandated by Section 82 of
the Code of Criminal Procedure, the Court below, in a most mechanical
manner, has issued processes under Section 82 of the Code of Criminal
Procedure. The order does not reflect any subjective satisfaction. The
impugned order is perse bad and cannot be sustained in the eyes of law.
When liberty of a person is sought to be curtailed, the same has to be
done strictly in accordance with law and there cannot be any deviation to
the procedure laid down by the law. This Court in Cr. M.P. No.2722 of
2019 (Md. Rustum Alam @ Rustam & Others versus The State of
Jharkhand) has passed a detailed order on 27.04.2020 dealing with the
issues as to how and under what circumstances, processes under Section
82 and 83 of the Code of Criminal procedure have to be issued. The order
under Section 82 of the Code of Criminal Procedure cannot be passed in a

 -: 2 :-
mechanical manner without recording subjective satisfaction and without
following the procedure of law.
4. Considering the impugned order in the light of the aforesaid
judgment passed in Cr. M.P. No.2722 of 2019, I am inclined to allow this
criminal miscellaneous petition. Impugned order dated 20.11.2019 by
which process under Section 82 of the Code of Criminal Procedure has
been issued is hereby set aside.
5. At this stage, counsel for the petitioner submits that
attachment order under Section 83 of the Code of Criminal Procedure has
also been issued. An attachment order under Section 83 of the Code of
Criminal Procedure is a consequential order to the order passed under
Section 82 of the Code of Criminal Procedure. Since, I have already set
aside the order dated 20.11.2019 issuing process under Section 82 of the
Code of Criminal Procedure, the attachment order under Section 83 of the
Code of Criminal Procedure is also consequentially quashed and set
aside. The matter is remanded to the Court below to proceed afresh and
pass fresh order in accordance with law.
6. This criminal miscellaneous petition, accordingly, stands
allowed.
( Ananda Sen, J.)
