PC:
The earlier application No.465/09 for the very same relief was disposed
of as withdrawn by an order of this Court dated 2.2.2009.
2. Learned counsel for the appellant contends that the application was
disposed of with liberty to file application afresh by producing age proof of the
applicant.
3. This Court cannot go beyond the orders passed by this Court. The
application is allowed to be withdrawn with liberty to make application for
expeditious disposal of appeal. As such the application cannot be construed to
be disposed of as withdrawn with liberty to renew the request made in the said
application.
4. In that view of the matter application stands rejected.
