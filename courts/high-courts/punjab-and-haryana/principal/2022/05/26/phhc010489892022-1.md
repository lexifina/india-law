GURVINDER SINGH GILL, J . (Oral)
CRM-19204-2022
The instant application has been filed seeking preponement of
the main case which is fixed for 1.8.2022.
Learned counsel for the applicant-petitioner has submitted that
he may be permitted to withdraw the main case itself as there has been some
change in circumstances inasmuch as challan has now been presented.
In view of the specific prayer made by learned counsel for the
applicant/petitioner for withdrawal of the main case, the application is
allowed and the main case i.e. CRM-M-20134-2022, which is stated to be
fixed for 1.8.2022, is preponed and is taken on board today and the main
case itself is hereby dismissed as withdrawn.
