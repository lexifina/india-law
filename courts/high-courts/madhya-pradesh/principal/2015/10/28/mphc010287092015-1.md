# High Court of Madhya Pradesh, WP/9407/2015, 2015-10-28

WP-9407-2015
(SHRICHAND JAIN Vs THE STATE OF MADHYA PRADESH)
28-10-2015
Shri Pranay Gupta, learned counsel for the petitioner.
Mrs. Shaheen Fatima, learned G.A. for the State/respondents.
The petitioner has filed the present petition seeking a direction
against the State Government for filing an application for
restoration of Second Appeal No. 303/1995.
The State Government has filed a S.A. No. 303/1995 (State of
M.P. Vs. Mahendra Kumar Jain). The said appeal was dismissed
for non-compliance of the peremptory order dated 9.9.2004.
Thereafter, respondent no.1 has not filed any application for
restoration of the S.A. The petitioner has, therefore, filed an
application for restoration of S.A., which was registered as MCC
No.271/2012, the same MCC was also dismissed. After dismissal
of the application for the restoration, the petitioner has filed the
present petition praying for direction against the respondents to
file an application for restoration of S.A.
I am afraid that no such direction can be issued by this Court to
the respondents to file an application for restoration. The
respondents cannot be compelled to file an application for
restoration. The petitioner has no locus standi to file the present
petition and therefore, the petition is hereby dismissed with no
order as to costs.
(MISS VANDANA KASREKAR)
JUDGE
