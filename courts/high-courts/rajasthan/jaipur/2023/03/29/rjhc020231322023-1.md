Order
29/03/2023
First bail application filed by the petitioner was withdrawn by
learned counsel for the petitioner which was accordingly dismissed
by this Court vide order dated 19.12.2022 in S.B. Criminal
Miscellaneous Bail Application No.7047/2022. By the said order,
no liberty was granted to the petitioner to file a fresh bail
application directly before this Court.
Instead of filing a fresh bail application before the trial court,
the petitioner has directly filed this second bail application before
this Court, whereas he should have first approached the trial
court.
In this view of the matter, learned Senior Counsel appearing
for the petitioner wants to withdraw this criminal miscellaneous 2nd
bail application with liberty to file fresh bail application before the
trial court.

[2023/RJJP/005179] (2 of 2) [CRLMB-3354/2023]
The 2nd bail application filed by the petitioner is disposed of
accordingly. However of the petitioner files a fresh bail application
before the trial court, the trial court shall decide the same as far
as possible on the same day in accordance with law.
(NARENDRA SINGH DHADDHA),J
