# High Court of Madhya Pradesh, MCRC/10708/2016, 2016-07-12

MCRC-10708-2016
(SHAHID ANSARI Vs THE STATE OF MADHYA PRADESH)
12-07-2016
Shri Sanjeev Singh, learned counsel for the applicants.
Shri Y. Dwivedi, learned P.L., for the respondent/State.
Shri Umesh Shrivastava, learned counsel for objector.
Learned counsel for the applicant prays for withdrawal of the instant
bail application u/s 438 of the Cr.P.C.
Prayer allowed.
However, the applicant is given the liberty of moving an appropriate
application before the learned Court below and if such an application is
moved, the learned Court below is requested to deal with it
expeditiously and if possible on the same day on which it is filed.
The instant bail application u/s 438 of the Cr.P.C. stands dismissed with
the aforesaid liberty.
C.C. as per rules.
(ATUL SREEDHARAN)
JUDGE
