# Madras High Court, CMP/10833/2018, 2019-04-23

C.M.P. No. 10833 of 2018
in
S.A. No. 290 of 2015
P.D.AUDIKESAVALU, J.
The application has been filed to condone the delay of 47 days in filing
the petition for restoration of the Second Appeal, which was dismissed for
default on 05.02.2018.
2. There is no representation for the Respondents despite the name of the
Learned Counsel for the Respondents printed in the cause list.
3. Advance copy of the application has been served on the Learned Counsel
for the Respondents.
4. Having been satisfied with the reasons stated in the affidavit filed the
application to condone the delay in filing the Second Appeal, the delay is
condoned.
5. Registry is directed to number the restoration petition, if it is otherwise
in order and post the matter on 11.06.2019.
