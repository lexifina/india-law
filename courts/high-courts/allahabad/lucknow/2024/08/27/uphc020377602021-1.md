# Allahabad High Court, /1861/2021, 2024-08-27

Court No. - 15
Case :- CRIMINAL APPEAL No. - 1861 of 2021
Appellant :- Noor Ali @ Sonu
Respondent :- State Of U.P. And Anr.
Counsel for Appellant :- Ravindra Kumar Dwivedi
Counsel for Respondent :- G.A.
Hon'ble Mohd. Faiz Alam Khan,J.
1. None is present for the appellant when this case is taken up
for hearing while learned A.G.A. is available.
2. Perusal of the order sheet would reveal that on the last date
also i.e. on 02.08.2024, neither learned counsel for the appellant
was present nor any request has been made to adjourn the case.
3. Keeping in view the fact that none was present for the
appellant on 02.08.2024 when this case was taken up on last
date, Today also neither learned counsel for the applicant is
present nor any request has been made by himself or on him
behalf to adjourn the case, it appears that perhaps the applicant
is not interested in pursuing the instant appeal,
4. Thus, for the reasons mentioned herein-above, the instant
appeal is dismissed for want of prosecution.
5. It is, however, provided that if the appellant feels aggrieved
by this order, he can move an application for recall of this order.
