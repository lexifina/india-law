# High Court for the State of Telangana, WP/1150/2019, 2019-02-15

THE HONíBLE SRI JUSTICE ABHINAND KUMAR SHAVILI

WRIT PETITION NO.1150 OF 2019

ORDER:
Learned Counsel for the petitioner sought permission of this Court
to withdraw this writ petition with a liberty to the petitioner to file a writ
petition afresh.
Permission is accorded and the Writ Petition is dismissed as
withdrawn giving liberty to the petitioner to file a writ petition afresh, if he
is so advised. No costs. Consequently, miscellaneous petitions pending, if
any, shall stand closed.

____________________________
ABHINAND KUMAR SHAVILI, J
Dated: 15th February, 2019
