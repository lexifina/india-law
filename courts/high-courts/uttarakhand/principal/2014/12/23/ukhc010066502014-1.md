# High Court of Uttarakhand, WPMS/2828/2014, 2014-12-23

WPMS No. 2828/2014
Hon’ble V.K. Bist, J.
 Mr. Siddhartha Sah, Advocate for the
petitioner.
 Mr. SS Chauhan, Dy. Advocate General for
the State.
 Before the arguments could be advanced,
learned counsel for the petitioner seeks
permission to withdraw the writ petition with
liberty to file fresh petition, if need arises.
 Permission granted.
 The petition is dismissed as withdrawn.
However, the petitioner is at liberty to file fresh
petition, if he so chooses.
 Interim relief application also stands
disposed of.
