3/20.11.2013 This application has been filed for rectification of registered
patta, in which name of petitioner has not been mentioned in the jeeld
(cover) page, though, same appears in the index page.
Learned counsel appearing for the State submits that
petitioner has not filed application in appropriate form along with requisite
fee and stamp for rectification of aforesaid defect. If petitioner will file the
application, same will be considered by the concerned Registrar and
order will be passed in accordance with law.
In view of the aforesaid statement of learned counsel for the
State, I direct petitioner to file application for rectification of defect in the
registered patta in the prescribe form along with requisite fee and stamp
within 15 days from today.
If such application is filed, concerned Registrar is directed to
dispose of the same within one month from the date of receipt of
application in accordance with law.
With the aforesaid observation, this application is disposed
of.
(Prashant Kumar, J.)
