# Madras High Court, A/1945/2024, 2024-04-26

A.No.1945 of 2024
A.No.1945 of 2024
P.VELMURUGAN. J.
This application is filed by the plaintiff to grant leave to sue the
defendant.
2. The learned counsel for the applicant submitted that as per the
order of this Court dated 08.04.2024, two notices were taken to the
respondent, but the same were returned as "no such company" and "left"
respectively. The learned counsel has filed an affidavit stating that even in
the website of the respondent, the address is mentioned to which the notice
was sent, which shows that the respondent is purposefully evading the
notice. Since the address mentioned in the application is shown in the
website of the respondent, this Court considers it as deemed service.
3. Therefore, leave is granted. Registry is directed to take the plaint
on file if the same is otherwise in order.
