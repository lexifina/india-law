ORDER
This writ petition has been filed for direction to the first
respondent to dispose of the petitioners' petition to set aside the exparte
award passed in AROP.No.150 of 2010 on the file of the first respondent
dated 25.02.2010.
2. It is seen that as against the petitioners, award was passed
on the application submitted by the second respondent in AROP.No.150
of 2010 on the file of the first respondent. However, the grievance of the
petitioners is that the petitioners were not served with any notice and they
were not heard and as such, they were set exparte. Therefore, the
petitioners filed application to set aside the exparte award passed in
AROP.No.150 of 2010 dated 25.02.2010. However, there is no provision
to set aside the exparte award passed under the Chit Funds Act. But,
there is appeal provision to file appeal as against the award passed by the
first respondent before the State Government under Section 70 of the Chit
Funds Act.

3. Therefore, the petition filed before the first respondent to set
aside the exparte award is not maintainable and the direction sought for
in this writ petition cannot be granted. As such, this writ petition is
devoid of merits and liable to be dismissed.
4. Accordingly, this writ petition is dismissed. However, the
petitioners are at liberty to file appeal as against the award passed in
AROP.No.150 of 2010 on the file of the first respondent dated
25.02.2010, in the manner known to law, if so advised. There shall be no
order as to costs.
