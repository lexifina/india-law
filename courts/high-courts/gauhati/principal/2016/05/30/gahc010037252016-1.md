# Gauhati High Court, CRP/180/2016, 2016-05-30

CRP 180/2016
BEFORE
THE HON’BLE MR. JUSTICE N.CHAUDHURY
Mr. SA Ahmed, learned counsel for the petitioner submits that he be permitted to
withdraw the revision petition with liberty to file appeal under Order XLIII Ru
le 1 ( r ) of the Code of Civil Procedure.
Prayer is allowed.
Revision petition stands dismissed on withdrawal with liberty.
The petitioner is permitted to withdraw the certified copy of the order so as to
enable him to prefer an appeal.
