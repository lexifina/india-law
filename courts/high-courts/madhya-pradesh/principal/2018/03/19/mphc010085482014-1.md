# High Court of Madhya Pradesh, CONC/320/2014, 2018-03-19

THE HIGH COURT OF MADHYA PRADESH
CONC-320-2014
(MUNESH KUMAR MISHRA Vs SHRI SANJEEV KUMAR JHA)
Jabalpur, Dated : 19-03-2018
None for the petitioner.
Shri P.K. Mishra, learned counsel for the respondent.
Learned counsel appearing on behalf of the respondent submits
that he has already complied with the impugned order passed by this
Court. As per him, since the order has already been complied with,
this petition has become infructuous.
Accordingly, this petition is dismissed as infructuous with
direction that if there is any grievance, the petitioner can proceed
further in accordance with law.
Case be assigned to record room.
(H.P. SINGH)
JUDGE
