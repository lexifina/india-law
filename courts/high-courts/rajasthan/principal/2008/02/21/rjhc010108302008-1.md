# High Court of Rajasthan, CRLMP/215/2008, 2008-02-21

1
S.B. Cr. Misc. Application No. 215/2008
In
S.B.Cr. Misc. Bail Application No. 730/2008
(Moola Ram Vs. State of Rajasthan)
Date of order : 21.02.2008
HON'BLE MR.H.R.PANWAR,J.
Mr. Niranjan Singh for the petitioner.
Mr. Narendra Moolchandani, P.P.
 By the instant application under Section 482 Cr.P.C.,
the petitioner submits that petitioner Moola Ram filed a bail
application being S.B.Cr. Misc. Bail Application No.730/2008 which
came to be allowed by order dated 18.2.2008, however, in the
order, instead of Moola Ram, the name of petitioner has been typed
as Moda Ram. Learned counsel for the petitioner submits that
name of the petitioner was initially wrongly typed as Moda Ram,
however, by handwriting it was corrected to Moola Ram which also
appears like Moda Ram and that is how the typing error crept in the
order. In fact petitioner Moola Ram sought the bail.
I have heard learned counsel for the parties. Carefully
gone through the order passed by Additional Sessions Judge,
Anoopgarh. The order impugned in the application shows that the
bail application was filed by Moola Ram S/o Gigna Ram.
In this view of the matter, in the order dated 18.2.2008
passed in S.B.Cr. Misc. Bail Application No.730/2008, in place of
“Moda Ram”, the word “Moola Ram” is substituted and it is made

2
clear that in FIR No.149/2007 P.S. Ramsinghpur, district Sri
Ganganagar, petitioner Moola Ram S/o Gigna Ram has been
granted bail.
The application is accordingly disposed of.
(H.R.PANWAR), J.
