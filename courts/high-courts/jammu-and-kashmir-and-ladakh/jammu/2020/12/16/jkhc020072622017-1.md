ORDER
 Leave to file appeal has already been granted by this Court vide
order dated 29.10.2018. However, the delay in filing application seeking
leave to file appeal has not been condoned.
 A perusal of the application shows that there is delay of 75 days
in filing application seeking leave to file appeal.
 For the reasons stated in the application, the same is allowed.
The delay of 75 days in filing application seeking leave to file appeal is
condoned.
 The application stands disposed of.
 Let the main appeal be diarized.
 Admitted.
