# Calcutta High Court, CRR/2414/2012, 2021-09-14

Sr.26
 14-09-2021
 Subha.
 Court no. 34
 IN THE HIGH COURT AT CALCUTTA
 CRIMINAL REVISIONAL JURISDICTION
 APPELLATE SIDE
 ( Via Video Conference )
 CRR 2414 of 2012
 In the matter of : Snehashish Jana & Ors. ….petitioners.
In Re : An application under Section 401 read with Section
482 of the Code of Criminal Procedure.
 The revisional application was preferred in connection
with a proceeding being Case No. 43 of 2012 pending before
the court of learned Additional Chief Judicial Magistrate,
Haldia.
 Record of this revisional application reflects that the
interim order existed till 06. 12. 2012 and thereafter the same
was never extended.
 When the matter has been taken up today, none
appears before this court to represent the petitioner to apprise
this court regarding the present stage of the proceedings.
 Having regard to the contentions advanced in the
revisional application and the issues so addressed, I am of the
view that the same are question of facts which are to be
adjudicated in course of trial.

2
 Accordingly, the present revisional application being
CRR 2414 of 2012 is dismissed.
 All pending applications, if any, in connection with
revisional application, are consequently disposed of.
 Interim order, if any, is hereby vacated.
 All parties are to act on the server copy of this order
duly downloaded from the official website of this court.
 ( Tirthankar Ghosh, J. )
