ORAL ORDER
4 23-09-2014 The learned counsel, Mr. Rajiv Kumar Singh for the
petitioner submitted that pursuant to the order dated 09.12.2010
passed by this Court, the respondents have already paid all the
admitted dues payable to the petitioner. According to the learned
counsel, if anything remained dues, he will file representation
before the respondents.
In view of the submission of the learned counsel for
the petitioner, this writ application is disposed of with liberty to
the petitioner to file representation, if any further amount is dues
payable by the respondents to the petitioner.
