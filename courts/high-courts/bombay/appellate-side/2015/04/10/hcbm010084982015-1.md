P.C.:
Heard Mr. Shinde, learned Counsel for the applicant.
2. This is an application for recalling the order dated
27.01.2015 passed by this Court. By that order, Miscellaneous
Civil Application was dismissed in default. Mr. Shinde states
that he has served copy of this application on Advocate Sandip
Babar. However, none appears for the respondent. No
affidavit opposing application is filed.
3. In view thereof and for the reasons stated in the
application, Civil Application is allowed in terms of prayer
clause (b) with no order as to costs. Miscellaneous Civil
Application No.196 of 2014 is restored to the file of this Court.
