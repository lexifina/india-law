bail.

were heard.

in the offence or will not commit the offence
if bail is granted. In such circumstances
petitioner cannot be granted anticipatory bail.
4. Learned counsel then submitted that

petitioner is at liberty to file an application for

to pass appropriate orders in that application
without delay. If petitioner fails to report before
