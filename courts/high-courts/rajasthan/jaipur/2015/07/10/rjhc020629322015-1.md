# High Court of Rajasthan, CRLMB/6951/2015, 2015-07-10

1
IN THE HIGH COURT OF JUDICATURE FOR RAJASTHAN
 JAIPUR BENCH, JAIPUR
ORDER
SB Cr Misc II Bail Application No.6951/2015
Ajay Soni versus State of Rajasthan
10.7.2015
HON'BLE MR. JUSTICE MN BHANDARI
Mr Abdul Kalam Khan - for the petitioner
Mr Sudesh Saini, PP – for the State
BY THE COURT:
This second bail application has been filed but
learned counsel for petitioner could not show any change in the
circumstances. In view of above, I am unable to accept this bail
application. Hence, it is dismissed. However, petitioner would be
at liberty to file fresh bail application if there is any change in the
circumstances.
(MN BHANDARI), J.
