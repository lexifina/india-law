JUDGMENT
The ex-parte decree in a suit for realisation of money has
been set aside on condition that the defendants furnish security
for one half of the plaint amount. The defendants point out that
the plaint claim is fully secured in view of the attachment before
judgment. The defendants assail only the condition imposed by
the court below to set aside the ex-parte decree.
2. The effect of not complying with the condition
amounts to rejection of application under Order IX Rule 13 of
the Code of Civil Procedure. Such orders are appealable under
Order XLIII Rule 1 (d) of the Code of Civil Procedure. (See
Vargheshe Antony Vs. Fr. Antony Kochuveettil [2012 (3)
KLT 692].
The Original Petition is hence dismissed without prejudice
to the right of the petitioner to file an appeal as above.
V. CHITAMBARESH
