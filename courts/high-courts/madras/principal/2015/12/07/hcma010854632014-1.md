 ORDER
The petitioner has come up with the present writ petition with
the grievance that the proposed laying of the pipe line to the land
of the fifth respondent, since impleaded as per order dated
23.09.2015, would affect the existing pipe lines.
2. In the counter affidavit filed by the third respondent it has
been stated that no decision has been made as of now for granting
permission for laying pipe lines. Such permission would be granted
only when there is sufficient space for doing so, without disturbing
the existing pipe lines. Therefore, it has been stated that if at
all any such action has tobe taken, the same would be after thorough
analysis of the existing position qua the contract.
3. Therefore, the apprehension expressed by the petitioner has
been answered in the counter affidavit filed. As of now, there are
pipe lines going underneath the cart track. Thus, there is no
decision made as on today and if permission is granted by the
respondents 1 to 4, then certainly necessary care has to be taken as
stated in paragraph-5 (a) of the counter affidavit, to see to it,
that there is sufficient space without disturbing the existing pipe
lines, in which case, the petitioner cannot be stated to be a person
aggrieved.
The writ petition is disposed of accordingly. No costs.
Consequently, connected miscellaneous petitions are closed.
