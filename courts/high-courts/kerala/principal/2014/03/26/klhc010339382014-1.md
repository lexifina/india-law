JUDGMENT
The petitioners challenge the condition imposed while
allowing an application under Order IX Rule 13 of the Code of
Civil Procedure. It is obvious that the petitioners do not intend to
comply with the condition and the necessary consequence is the
dismissal of the application. The remedy for the petitioners is to
file an appeal under Order XLIII Rule 1(d) of the Code of Civil
Procedure and the Original Petition will not lie. The issue is
covered by Varghese Antony v. Fr. Antony Kochuveettil
[2012 (3) KLT 692].
I dismiss the Original Petition with liberty to file an appeal
as indicated above.
V.CHITAMBARESH
JUDGE
