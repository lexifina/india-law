# High Court of Jharkhand, Cr.M.P./862/2013, 2014-05-12

 For the Petitioner :None
 For the State :A.P.P
03/ 12.05.14. The order dated 27.4.2011 passed in M.P. Case no.142 of
2011 has been challenged whereby no adverse order has been passed
against the petitioner, rather only notice has been issued against the
petitioner and thereby no cause of action affecting the right of the petitioner
has accrued and thereby the order dated 27.4.2011 never warrants to be
interfered with. Accordingly, this application stands dismissed.
