CORAM: HONOURABLE MR. JUSTICE AKHILESH CHANDRA
ORAL ORDER
2 27-02-2013 Heard.
This is an application seeking restoration of Cr. Misc. No.
27136 of 2011 dismissed for non-prosecution vide order dated 19.03.2012 in
connection with Complaint Case No. 794(C) of 2010, pending before Sub-Divisional Judicial Magistrate, Danapur.
This Court does not find any merit in this application.
Accordingly, the same stands dismissed with a liberty to the petitioner, if so
wishes, to file fresh application, if mandatory provisions under Section 438 of
the Code of Criminal Procedure is available.
