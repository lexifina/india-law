# Madras High Court, CMP/10480/2021, 2021-09-08

C.M.P.No.10480 of 2021
in C.M.A.SR.No.25478 of 2021
ABDUL QUDDHOSE, J.
(The case has been heard through video conference)
This application has been filed to
condone the delay of 340 days in filing the
appeal.
2. Mr.M.J.Vijayaraghavan, learned
counsel appearing for the second respondent
submitted that he has no objection in allowing
this application. However, he submitted that
the appellant will not be entitled for any interest
for the delay period. The same is recorded.
This Court is also satisfied with the reasons
stated in the affidavit filed in support of this
application. Accordingly, this application is
allowed as prayed for. However, it is made
clear that the appellant is not entitled for any
interest for the delayed period if at all the
compensation is going to be enhanced by this
Court in the main C.M.A.
3. Registry is directed to number the
appeal if it is otherwise in order and print the
name of Mr.M.J.Vijayaraghavan for the second
respondent when the appeal is listed for
admission. Post the appeal for admission on
22.09.2021.
