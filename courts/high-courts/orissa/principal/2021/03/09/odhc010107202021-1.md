# High Court of Orissa, WP(C)/5427/2021, 2021-03-09

2. 09.03.2021 None appears for the petitioner at the
time of call.
 Mr.Dillip Kumar Mishra, learned
Additional Government Advocate is present
through virtual mode.
 This writ petition has been filed for a
direction to the Tahasildar, Odagaon (OP No.2)
to set aside the order passed in Mutation Case.
 On perusal of the writ petition, it appears
that neither the Mutation Case number has
been given nor the order sought to be set aside
has been annexed. Further, the Tahasildar,
Odagaon is not authorized to set aside the order
passed in Mutation Case.
 In that view of the matter, the writ
petition being misconceived stands dismissed
accordingly.
