P.C. :
1 The Appeal has been filed without seeking Special
leave to Appeal, as contemplated under section 378 of the Code of
Criminal Procedure. Even then, an opportunity was granted to the
appellant to make an application for leave to Appeal, and this was
expressed in the order dated 8th January 2016. Till today, no such
application has been made. Since the Appeal is not maintainable,
the same is dismissed.
2 It is clarified that this order shall not preclude the
appellant from making an application for leave to file an Appeal.
It is needless to say in the event of the leave being granted, the
applicant shall be permitted to file an Appeal. This Appeal is
dismissed only because it has been filed without obtaining leave.
