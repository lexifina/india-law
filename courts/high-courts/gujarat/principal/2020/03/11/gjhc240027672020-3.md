ORAL ORDER
1. This is an application for condonation of delay in filing
Second Appeal.
2. Heard learned advocates.
3. Mr.Majmudar, learned advocate for the respondent has
contested this application. Attention of this Court is also invited
to the contents of the affidavit-in-reply filed in this application.
4. Having heard learned advocates for the respective
parties and considering the material on record, delay needs to
be condoned.
5. This application is allowed. Delay is condoned. Rule is
made absolute.
(PARESH UPADHYAY, J)
