ORDER
The plaintiff has applied for leave to file a reply to the additional written
statement of the first defendant. In the affidavit in support of the application, it
is stated that false statements have been made in the additional written
statement.
2. Learned counsel for the first defendant has no serious objection to this
application being allowed.
3. Considering the reasons set out and being satisfied that sufficient cause
is shown, this application is allowed. Consequently, the Registry is directed to
receive the reply statement of the plaintiff.
