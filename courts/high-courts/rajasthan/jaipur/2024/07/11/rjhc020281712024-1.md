Order
11/07/2024
1. This writ petition has been filed by petitioners on
02.04.2024, impugning the order of transfer dated 04.03.2021
passed by Board of Revenue, which has already been
implemented.
2. Counsel for petitioner after arguing the petition for some
time, does not press this petition and seeks liberty to file afresh
transfer application before Board of Revenue, if any fresh cause of
action has arisen.
3. Accordingly, the instant petition is dismissed as not press,
with the liberty as prayed for.
4. Any other pending application(s), if any, stand disposed of.
(SUDESH BANSAL),J
