O R D E R
This Criminal Original Petition has been filed to direct
the respondent to file a charge sheet in Crime No.209 of 2019
on the file of the respondent police within a time frame to be
fixed by this Hon'ble Court.
2.Heard the learned counsel appearing for the petitioner
and the learned Additional Public Prosecutor appearing for the
respondent.
3.The learned counsel appearing for the petitioner
submitted that though respondent has registered a case in the
above said crime number on 01.03.2019, no final report is
filed till date.
4.The learned Additional Public Prosecutor appearing for
the respondent submitted that the respondent police may be
permitted to file a final report as early as possible.
5.In view of the above, the respondent police is directed
to file a final report as early as possible.
https://hcservices.ecourts.gov.in/hcservices/

6.With the above direction, this Criminal Original
Petition is disposed of.
