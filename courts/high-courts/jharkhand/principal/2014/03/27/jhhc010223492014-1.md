For the State : A.P.P.

2/ 27.03.2014 Heard learned counsel for the petitioner and learned A.P.P. for the
Prosecution.
This application has been filed for restoration of B.A. No. 9075
of 2012, which was dismissed for non-compliance of order dated 18.12.2012
passed therein.
It is apparent that the bail application was dismissed due to
non-compliance of order dated 18.12.2012 and the application for restoration of
bail application has been filed after undue delay in the year 2014.
This criminal miscellaneous petition is accordingly, dismissed.
 The petitioner, if aggrieved, may file a fresh bail application.
 ( H. C. Mishra, J.)
