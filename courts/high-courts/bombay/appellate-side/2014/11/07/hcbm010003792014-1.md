Vs
The State of Maharashtra & ors. .. Respondents

Mr.Manoj J. Bhatt, for the Petitioner.

CORAM: ANOOP V. MOHTA &.
 N.M.JAMDAR, JJ.
 Friday 07 November, 2014.
P.C.:
Petitioner has filed this application for clarification of order dated
29 September 2005 and contended in this Court after 11years, that though
this Court has passed the order “All these cases will be tried in one
Court” no Court is fixed which should decide / try the cases. No such
application and/or request is coming forth from the prosecution side. No
clarification sought till this date except by way of this application by the
Petitioner. The order is clear. The State / prosecution needs to take steps
in view of the order so passed as early as possible and proceed to conduct
the cases in one Court. No case is made out for any clarification.
Petition is accordingly disposed of. No costs.
 N.M.JAMDAR, J. ANOOP V. MOHTA, J.
