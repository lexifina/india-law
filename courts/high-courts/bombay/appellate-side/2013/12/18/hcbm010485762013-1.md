WITH

Mr. M.G. Ansari, Advocate for the Applicant.

Mrs. A.A. Mane, A.P.P. for the respondent- State.
Coram : Smt. R.P. SondurBaldota, J.
Date : 18th December, 2013.
P.C.
This application seeks recalling of the order dated 8th
September, 2009, by which the co-ordinate bench allowed
Criminal Revision Application No.86 of 2009. The applicant
desires that after recalling of the order, the Criminal Revision
Application be dismissed. The application as filed is clearly
misconceived. There cannot be a challenge to the order passed
before the same forum. The only remedy available to the

Dusane 2/2 APPR453.2013
applicant would be either to go for review of the order before
the same bench that passed the order or to approach the higher
forum. The application is therefore dismissed.
 (Smt. R.P. SondurBaldota, J.)
