# Madras High Court, Arb Appln/223/2024, 2024-04-18

Arb.Appln.No.223 of 2024
& A.No.347 of 2015
KRISHNAN RAMASAMY, J.
This application has been filed to
raise the order of attachment dated
13.08.2015 made in Application No.347
of 2015 attaching the immovable
property morefully described in the
schedule to the Judges Summons.
2. The learned counsel for the
applicant would submit that the entire
liability of the respondent has been
settled and hence, he requests this Court
to allow this application.
3. In view of the above
submission, this Court is inclined to
allow this application.
4. Accordingly, this Application is
ordered as prayed for.
5. Further, the Registry is directed
to send a copy of this order to the
concerned Sub-Registrar.
