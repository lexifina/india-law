1) The application is filed for permission to make
correction in the verification clause of Criminal
Application No.2538/2012 which was disposed of by this

Raosaheb Haribhau Bhosle, according to the learned
counsel for the applicant, the name is mentioned as
Raosaheb Laxman Bhosle.

 2 Application 5856/2014

Criminal Application No.2538/2012. Copy of the order
shows that in the title clause the name is correctly
mentioned. There is no need of making further correction.
The application is disposed of.
