Order
10/09/2021
The matter comes up on an application for correction in the
order dated 19.08.2021 passed in S.B. Criminal Appeal (Interim
Bail) No. 533/2021.
In the order dated 19.08.2021, the number of F.I.R. has
been shown as 06/2017, whereas it should have been 106/2017.
For the reasons mentioned in the application, the same is
allowed and in the order dated 19.08.2021 passed in S.B. Criminal
Appeal (Interim Bail) No. 533/2021, the number of F.I.R. be read
as 106/2017 instead of 06/2017.
