P.C.:
1. Learned Counsel appearing on behalf the petitioner submits that
in view of subsequent event, particularly that the advisory which has been
issued by respondent no.1 in view of which two impugned circulars were
withdrawn, he would like file a fresh comprehensive petition.
2. The present petition is therefore allowed to be withdrawn with
liberty as prayed. Liberty is granted to the petition to file a fresh
comprehensive petition and all contentions raised in this petition are kept
open.
3. The chamber summons taken out by intervener does not survive.
It is disposed of.
( G.S. KULKARNI, J ) ( V.M.KANADE, J )
