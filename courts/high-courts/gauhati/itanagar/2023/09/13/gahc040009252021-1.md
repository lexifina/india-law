Mr. Marto Kato, learned counsel for the petitioners, seeks leave of this Court, to
withdraw the instant writ petition with liberty granted to the petitioners to file a fresh
petition.

granted to the petitioners to file a fresh petition, if so advised.
Interim order passed by this Court, if any, stands vacated.
