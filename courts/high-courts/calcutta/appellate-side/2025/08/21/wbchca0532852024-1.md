# Calcutta High Court, WPA/27102/2024, 2025-08-21

21.08.2025
 Item No.249
 Ct. No.35
 dc. W.P.A. 27102 of 2024

 Sri Satadal Sardar & Ors.
 versus
 The State of West Bengal & Ors.

 Mr. Vimal Kumar Shahi, AGP,
 Mrs. Pratiti Das ... For the State.
Inadvertently in the order dated 05.12.2024,
the name of the learned advocate “Mr. Arijit
Mahinder … for the Petitioners” has been wrongly
transcribed when none appeared for the petitioners
on the said date. Let the same be expunged in the
order dated 05.12.2024.
Department is directed to incorporate
necessary correction as above.
Other portions of the order dated 05.12.2024
would remain unaltered.
Let this order be treated as part and parcel of
the order dated 05.12.2024.
Earlier on 05.12.2024 when the writ petition
was called, none appeared for the petitioners.
Today also when the writ petition has been
called, none represents the petitioners.
No accommodation is sought for on behalf of
petitioners.
Mr. Shahi, learned advocate appears for the
State.
Report submitted by the learned advocate
appearing for the State be kept with the record.

2
In view of the petitioners not interested to
pursue the writ petition, WPA 27102 of 2024 is
dismissed for default.
Interim order, if any, is hereby vacated.
All concerned parties shall act on the server
copy of this order duly downloaded from the official
website of this Court.
Urgent photostat certified copy of this order,
if applied for, be supplied to the parties upon
compliance with all requisite formalities.

 (Tirthankar Ghosh, J.)
