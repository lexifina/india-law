# Allahabad High Court, WPIL/4769/2018, 2019-01-31

Court No. - 37
Case :- PUBLIC INTEREST LITIGATION (PIL) No. - 4769 of
2018
Petitioner :- Narpati Singh
Respondent :- State Of U.P. And 15 Others
Counsel for Petitioner :- Pradip Kumar Srivastava
Counsel for Respondent :- C.S.C.,Tariq Maqbool Khan
Hon'ble Siddhartha Varma,J.
Instructions filed by the learned Standing Counsel be kept on
record.
This PIL has been filed for evicting the encroachers from plot
no.426 which was entered as Banjar, from plot no.427 which
was recorded as forest and from plot no.287 which was entered
as a pond.
Instructions have been filed by the learned Standing Counsel
from which it appears that plot no.287 has been cleared. With
regard to plot no.427, on 22.6.2018 an order was passed for the
eviction of the encroachers. However, it appears that
encroachment has not been removed because of the fact that
there is a Recall Application filed for recalling the order dated
22.6.2018.
Learned counsel for the petitioner submits that a direction be
issued that the Recall Application for recalling the order dated
22.6.2018 be decided expeditiously.
It is, therefore, directed that the Recall Application for recalling
of the order dated 22.6.2018 be decided within a period of one
month from the date of presentation of a certified copy of this
order.
However, with regard to plot no.426, the instructions revealed

that certain notices have been issued against nine persons who
have allegedly encroached the plot. These cases may now be
expeditiously registered and action be taken against the
encroachers.
The writ petition is, accordingly, disposed of.
Order Date :- 31.1.2019
GS
(Siddhartha Varma, J.)
