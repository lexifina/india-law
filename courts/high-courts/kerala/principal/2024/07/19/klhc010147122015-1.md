ORDER
This Criminal Miscellaneous Case is filed challenging
Annexure A1 order by which an application under Section 311
Cr.P.C is dismissed.
2. This Criminal Miscellaneous Case is pending before
this Court from 2015 on wards. Service to the party respondent
is not complete. Even though stay was granted, the stay was
not extended after 2015. Probably the main case itself might
have been disposed of. Moreover, there is no representation
for the petitioner. Hence, Criminal Miscellaneous Case need not
be maintained.
Therefore, Criminal Miscellaneous Case is closed.
