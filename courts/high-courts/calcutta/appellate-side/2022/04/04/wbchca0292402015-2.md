# Calcutta High Court, CRR/1875/2015, 2022-04-04

04.04.2022
S/L No.2
 KS

 C.R.R. 1875 of 2015
 Sk. Guljar
 -Vs.-
 The State of West Bengal & Anr.

 Mr. Binoy Panda
 Ms. Puspita Saha
 …. for the State
The revisional application was preferred under Sections 401/482
of the Code of Criminal Procedure is fixed up for hearing before this
Court for the second consecutive date. Petitioner prayed for quashing
of the First Information Report in connection with Uluberia Police
Station Case No.182 of 2015 dated 09.03.2015 under Sections 341/ 323/
326/ 379/354 of the Indian Penal Code now pending before Learned
Additional Chief Judicial Magistrate, Uluberia.
None appears for the petitioner.
Mr. Binoy Panda and Ms. Puspita Saha, learned advocates
appeared for the State.
The revisional application is dismissed for default and the same
is disposed of.
Interim order, if any, stands vacated.
Let a copy of this order be sent to Ld. Additional Chief Judicial
Magistrate, Uluberia for information.

2
(Ananda Kumar Mukherjee, J.)
