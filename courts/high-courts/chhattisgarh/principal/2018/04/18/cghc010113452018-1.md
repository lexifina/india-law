Order On Board
18/04/18
1. This writ petition has been filed by the petitioner against the order
dated 28.02.2018 (Annexure – P/1) passed by respondent No. 2- Nazul
Officer, Durg rejecting the petitioner's application /representation.
2. Learned counsel appearing for the petitioner would submit that the
impugned order passed is unsustainable and bad in law and is liable to be
set aside.
3. On the other hand, learned counsel appearing for respondent / State
would submit that representation preferred by the petitioner would lie before
the Commissioner, Durg Division.
4. I have heard learned counsel for the parties and perused the
impugned order with utmost circumspection.

2
5. In view of the aforesaid statement made by learned State counsel, the
writ petition is disposed of with liberty to the petitioner to file representation
under the Revenue Book Circular before the Commissioner, Durg Division
expeditiously. No order as to cost(s).
6. Certified copy of the impugned order be returned to the counsel for the
petitioner on furnishing attested photo copy thereof.
