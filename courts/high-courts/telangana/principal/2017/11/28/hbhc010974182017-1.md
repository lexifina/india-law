# High Court for the State of Telangana, WP/40121/2017, 2017-11-28

HONíBLE SRI JUSTICE A.RAJASHEKER REDDY
W.P. No.40121 of 2017

ORDER :
What is the common cause of action for the petitioners
for challenging several awards in the writ petition is not
stated, as such the writ petition is liable to be dismissed.
Accordingly, the Writ Petition is dismissed. However, it
is left open to the petitioners to challenge the awards
individually, if so advised. No order as to costs.
Miscellaneous petitions, if any, pending in this Civil
Revision Petition shall stand closed.
