Dated this the 20th day of February, 2014
 JUDGMENT
This original petition is filed challenging the order passed
under Order 26 Rule 14(3) of the Code of Civil Procedure to set
aside the commission report. The learned Munsiff as per Ext.P8
impugned order, dismissed the application on the sole ground
that the application is belated and filed after the commencement
of the trial. The commission report in this case was filed on
16.06.2009. Case was listed on 08.08.2013. The application to
set aside the commission report was filed only on 14.08.2013.
This Court finds that the learned Munsiff is therefore, justified in
dismissing the application as belated. However, during the
course of trial, if the learned Munsiff finds that objections to the
commission report is sustainable and it warrants remission or
setting aside, dismissal of this original petition will not stand in
the way of court below in exercising such power to remit or set
aside the commission report.

O.P.(C) No.3642 of 2013 2
With the above observation, this original petition is
dismissed.
