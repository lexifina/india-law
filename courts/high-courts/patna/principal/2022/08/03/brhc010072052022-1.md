CORAM: HONOURABLE MR. JUSTICE SANDEEP KUMAR
ORAL ORDER
3 03-08-2022 Heard the parties.
This modification application has been filed for
modification of the common order dated 17.01.2017 passed in
C.W.J.C. No. 213 of 2012 along with its analogous cases in
which the name of the father of the present petitioner has been
wrongly typed as “Sri Chandra Prasad Yadav” whereas it should
be Sri Chand Prasad Yadav.”
Let the name of the father of the present petitioner be
read as “Sri Chand Prasad Yadav” instead of “Sri Chandra
Prasad Yadav.”
The order dated 17.01.2017 passed in C.W.J.C. No.
213 of 2012 alongwith its analogous cases is modified only to
the extent as indicated above.
Learned counsel for the State has no objection,
therefore, this modification application is allowed.
Saif/-
(Sandeep Kumar, J)
