CORAM: HONOURABLE MR. JUSTICE SHIVAJI PANDEY
ORAL ORDER
3 14-05-2015 Heard learned counsel for the petitioner and learned
counsel for the State.
This application has been filed for quashing the FIR
vide Amdabad P.S. Case No.209 of 2012 registered under
Sections 406, 420, 468 and 471 of the Indian Penal Code.
Allegation has been of being involved in the illegal
appointment.
Learned counsel for the petitioner submits for the same
transaction another FIR has also been lodged.
This Court is not inclined to quash the FIR. However,
the police is directed to examine both the cases and if it is
found that it is for the same transaction both should clubbed
together and complete the same in one investigation.
With the aforesaid observation this application is
dismissed.
Vinay/- (Shivaji Pandey, J)
