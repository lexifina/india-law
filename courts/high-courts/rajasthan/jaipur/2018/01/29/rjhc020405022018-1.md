HON'BLE MR. JUSTICE PANKAJ BHANDARI
Judgment / Order
29/01/2018
Counsel for the applicant has moved an application for
modification in the order dated 22.01.2018.
It is contended that there is no recovery from the petitioner
as mentioned in para No.3 is not correct. A shirt has been
recovered from the petitioner but neither it is blood stained nor it
is connected with the accused or the deceased.
Considering the contentions of counsel for the applicant in
order dated 22.01.2018 in third line of para No.3 after “there is no
recovery”, following be deemed to be inserted “of any
incriminating material”.
Application for modification is, accordingly, allowed.
(PANKAJ BHANDARI)J.
