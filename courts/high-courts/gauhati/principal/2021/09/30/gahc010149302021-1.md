ORDER
30.09.2021
By this interlocutory application, a correction is sought to be made in the
array of the respondents provided in the certified copy of the order dated
02.09.2021 in WP(C)No.4221/2021. A certified copy of the order has two parts
i.e. the part containing the judicial order and the other part containing the array
of the parties which is extracted from the array of parties as depicted in the writ
petition. We can only correct the judicial part contained in the certified copy, but
for correcting the array of parties in the certified copy, the correction would
have to be made in the original writ petition.
In terms of the above, this interlocutory application stands closed.
The applicant is given the liberty to file an appropriate application before the
Registry for correcting the appropriate party arrayed in WP(C)No.4211/2021.
