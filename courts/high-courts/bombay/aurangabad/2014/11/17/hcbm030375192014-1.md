# Bombay High Court, APPLN/6012/2014, 2014-11-17

IN THE HIGH COURT OF JUDICATURE OF BOMBAY
BENCH AT AURANGBAD
CRIMINAL APPLICATION NO. 6012 OF 2014
AMAR S/O GOPALRAO PATIL
VERSUS
THE STATE OF MAHARASHTRA AND ANOTHER
...
Advocate for Applicant : Mr. Kale Gopal D.
APP for Respondent/State : Mrs. S.G. Chincholkar
...
CORAM : S.S. SHINDE & N.W. SAMBRE, JJ.
Dated: November 17, 2014
…
PER COURT :-
. The learned counsel appearing for the applicant, on instructions,
seeks permission to withdraw the application with further liberty to file application
for discharge before the trial Court.
2. The Criminal Application is dismissed as withdrawn, with liberty as
prayed for.
3. In case, the application is filed by the applicant, the concerned
Court to decide the said application, as expeditiously as possible, however
preferably within three months from filing such application.
4. The learned counsel appearing for the applicant submits that, the
application for discharge will be filed within two weeks from today. However, we
make it clear that, in case, if the charge is already framed, there is no question of
granting liberty to file application for discharge.
( N.W. SAMBRE, J. ) ( S.S. SHINDE, J. )
