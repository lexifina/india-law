Judgment
Siri Jagan, J.
The claimants in LAR No.585/2009 before the First
Additional Sub Court, Thiruvananthapuram, are the appellants
herein. Certain properties belonging to the appellants were
acquired by the State as per a notification dated 19.11.2005
issued under Section 4(1) of the Land Acquisition Act. The Land
Acquisition Officer fixed land value @ ₹ 2,45,369/- per are. On
reference under Section 18 of the Act, the reference court re-fixed
the land value @ ₹ 4,41,664.50 per are. Dissatisfied with the land
value fixed by the Sub Court, the appellants have filed this appeal,
seeking enhanced land value.
2. The learned counsel for the appellants points out
that the present L.A.R. was considered along with
L.A.R.No.580/2009 and a common judgment was passed, fixing
common land value for both, which is under challenge in this
appeal. Against the judgment in L.A.R.No.580/09, the claimant

LAA 535/12 2
therein filed L.A.A.No.453/2012, which was considered by a
learned single Judge of this Court and the land value was re-fixed
as ₹ 4,90,728.50 per are. The learned counsel foe the appellants
submits that both the properties are under the same category and
for both the properties, the reference court has fixed the same land
value. Therefore, the appellants are also entitled to land value, as
re-fixed by the learned single Judge in the said appeal, is the
contention raised.
3. We have heard the learned Government Pleader
also.
4. In L.A.A.No.453/12 against L.A.R.No.580/2009,
which was disposed of along with the L.A.R. in this case by a
common judgment, fixing the common land value for both cases, a
learned single Judge of this Court has fixed land value @ ₹
4,90,728.50. On going through the judgment of the learned single
Judge, we find no reason to differ with the same. In the above
circumstances, following the judgment ion L.A.A.No.453/12, we re-fix the land value in this case also as ₹ 4,90,728.50 per are.
Needless to say, the appellants would be entitled to all statutory

LAA 535/12 3
benefits as applicable to that land value.
With the above modification of the impugned judgment,
the appeal is disposed of.
