# Gauhati High Court, I.A./1917/2015, 2015-11-02

I.A. 1917/2015
BEFORE
HON’BLE MR. JUSTICE UJJAL BHUYAN
It is seen that applicant had earlier filed Misc. Case No. 191/2015 maki
ng a similar prayer.
In that Misc. case, this Court had passed an order on 09.03.2015 to the
effect that it would be heard alongwith the related writ petition. When the said
Misc. case is pending, filing of the present interlocutory application seeking
the same relief does not appear to be tenable.
Accordingly, this IA is dismissed.
