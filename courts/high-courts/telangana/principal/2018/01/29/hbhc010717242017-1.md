# High Court for the State of Telangana, CC/154/2017, 2018-01-29

THE HONOURABLE SRI JUSTICE M.S.RAMACHANDRA RAO
CC.No.154 of 2017
ORDER :
 Having regard to the order passed today in WP.No.42538 of
2016, the Contempt Case is closed granting liberty to petitioner to file
a fresh Contempt Case in case the final order passed in the Writ
Petition is not complied with.
2. Accordingly, the Contempt Case is closed. No order as to
costs.
3. As a sequel, miscellaneous petitions pending if any in this
Contempt Case, shall stand closed.
