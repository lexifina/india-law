# Gauhati High Court, FAO/31/2017, 2017-05-19

FAO 31/2017
BEFORE
HON’BLE MR. JUSTICE PRASANTA KUMAR DEKA
Heard Mr. A R Shome, learned counsel appearing on behalf of the appellant.
The impugned order dated 28.04.2017 is an order passed in Title Execution Case N
o.29/2015 against which no appeal lies. Accordingly, the appellant is given the
liberty to withdraw this appeal and file proper petition if so advised.
Accordingly, this appeal is dismissed on withdrawal.
The certified copy is allowed to be taken back by the learned counsel of the app
ellant by substituting the same by a photocopy of the said order of the certifie
d copy of this appeal.
