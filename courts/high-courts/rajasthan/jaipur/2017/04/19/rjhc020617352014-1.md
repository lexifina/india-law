Order
19/04/2017
 The matter comes up on an application (I.A.22089/2017),
with a prayer seeking permission to withdraw the writ application
in view of subsequent development.
For the reasons assigned in the application and in view of the
subsequent order dated 9th January, 2017, the petitioner is
permitted to withdraw the writ application to file substantive writ
application, if so advised.
Consequently, the application is allowed.

(2 of 2)
[CW-2267/2014]
The writ petition is dismissed as withdrawn with liberty
reserved to the petitioner to file substantive writ application, if
need be.
Stay application also stands closed.
