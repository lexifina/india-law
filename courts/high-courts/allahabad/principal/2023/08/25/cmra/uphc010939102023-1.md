1. Heard Sri Prabhakar Awasthi, learned counsel for the
applicant (in review) and Sri Sanjeev Singh, learned counsel for
the opposite parties.
2. The appeal was directed against an interim order. In any case,
the limitation to file the same had expired before the cause of
explaining the delay (as set up) had arisen.
3. Accordingly, the present review application lacks merit. It is
dismissed.
