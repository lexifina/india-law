 DATED : 27th September, 2011
P.C.
1. Heard learned counsel for the parties.
2. An application Exh.5 in Regular Civil Appeal No. 108 of 2010 was
filed under order 39 Rule 1 and 2 of the Code of Civil Procedure. If any order
passed below this application is to be challenged, the same will have to be
challenged by filing of Appeal from Order as per the provisions of order 43 Rule
1(r) of the Code of Civil Procedure. Hence, this writ petition is not
maintainable. the petitioner will have to file appropriate proceedings.
3. The petition is allowed to be withdrawn with liberty to file appropriate
proceedings.
4. There shall be no order as to costs.
 (R. Y. GANOO, J.)
