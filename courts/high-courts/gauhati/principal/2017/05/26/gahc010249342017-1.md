# Gauhati High Court, WP(C)/2852/2017, 2017-05-26

WP(C) 2852/2017
BEFORE
HON’BLE MR. JUSTICE ARUP KUMAR GOSWAMI
Heard Ms. M. Deori, learned counsel for the petitioners. Also heard Mr. C. Bhatt
acharyya, learned Standing counsel, Education, appearing for respondent Nos. 1 a
nd 2 as well as Mr. P. N. Sarma, learned Standing counsel, SSA, appearing for re
spondent No. 3.
According to the case projected by the petitioner, the petitioner No. 1 school,
namely, Uttar Geruati Pre-Senior Madrassa, in the District of Nagaon, was provid
ed with District Information System for Education (DISE) Code for the years 2009
, 2010 and 2011.
However, in subsequent years, DISE Code had not been allotted to the school. Thi
s writ petition is filed by the petitioners praying for a direction to the respo
ndents to provide DISE Code to the petitioner school from the year 2012 onwards.
It is submitted by Ms. Deori that because DISE Code is not provided, the petitio
ner school is losing out the benefits provided by the Government and the student
s are also not able to have mid-day meals as the same is not supplied to the sch
ool.
Mr. Sarma, learned Standing counsel, SSA, has submitted that DISE Code cannot be
granted to the petitioner school, now, from 2012 onwards as DISE Code cannot be
issued retrospectively. He, however, submits that if the petitioner school file
s appropriate application before the competent authority for grant of DISE Code
for the current year, the same shall be considered in accordance with law.
Ms. Deori has responded by submitting that the petitioner school will file appro
priate application before the competent authority for issuing DISE Code for the
current year.
Considering the above submissions of the learned counsel for the parties, the wr
it petition is disposed of providing that in the event of filing any application
by the petitioner school for allotment of DISE Code for the current year, the r
espondents shall consider the same with in accordance with law.
