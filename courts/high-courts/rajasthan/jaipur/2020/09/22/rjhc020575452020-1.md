HON'BLE MR. JUSTICE NARENDRA SINGH DHADDHA
 Order
22/09/2020
An application has been filed by the petitioner u/s 482 Cr.P.C.
for correction in the order dt.11.6.2020.
Heard learned counsel for the parties.
Inadvertently, in the order dt.11.6.2020 passed in S.B.
Criminal Misc. Bail Application No.6271/2020 “father’s name
Chutmal” has been mentioned, it be read as “father’s name
Ghutmal”.
This order shall be part of the order dt.11.6.2020 passed in
S.B. Criminal Misc. Bail Application No.6271/2020.
The application stands disposed of.
The amended cause title is taken on record.
(NARENDRA SINGH DHADDHA),J
