# Madras High Court, CRL OP/10736/2015, 2015-04-28

1
IN THE HIGH COURT OF JUDICATURE AT MADRAS
DATED : 28.04.2015
CORAM
THE HONOURABLE MR.JUSTICE P.N.PRAKASH
Crl.OP No.10736 OF 2015
V.ANDAVAR [ PETITIONER ]
Vs
THE SUB INSPECTOR OF POLICE
PERIYANAICKENPALAYAM POLICE STATION
COIMBATORE DISTRICT CR.NO.112/2015.
[ RESPONDENT ]
Prayer:- Criminal Original Petition filed under Section 482 Cr.P.C., to pass an
order directing the respondent police to do the proper investigation in Crime
No.112/2015 on the file of the Periyanaickenpalayam Police Station
Coimbatore District file final report as per law.
For Petitioner :Mr.R.Rajasekaran
For Respondent :Mr.C.Emalias,
Additional Public Prosecutor
ORDER
This Criminal Original Petition is filed to direct the respondent
police to do proper investigation in Crime No.112/2015 on the file of the
Periyanaickenpalayam Police Station, Coimbatore District, and to file final
report as per law.
2. Heard the learned counsel for the petitioner and the learned
Additional Public Prosecutor appearing for the respondent police.

2
P.N.PRAKASH,J
rg
3. It is represented by the learned Additional Public Prosecutor
that initially the case in Crime No.112 of 2015 was filed for the offences
punishable under Section 174 Cr.P.C. and now the same has been altered
into one under Section 306 IPC.
4. In view of the above, no further direction need to be given in
this Criminal Original Petition. Hence, the same is closed.
28.04.2015
