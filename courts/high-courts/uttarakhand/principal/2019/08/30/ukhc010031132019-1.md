# High Court of Uttarakhand, ARBAP/9/2019, 2019-08-30

IN THE HIGH COURT OF UTTARAKHAND AT NAINITAL
Application for Withdrawal 11909 of 2019
In
Arbitration Application No. 09 of 2019
Smt. Manju ...Applicant
Vs.
Sri Deepak Kaushik and others ...Respondents
Mr. Yashpal Singh, learned counsel for the applicant.
Dated: 30th August2019
Ramesh Ranganathan, C.J. (Oral)
 Mr. Yashpal Singh, learned counsel for the applicant, would
submit that, by mistake, respondents 2 and 3 have been arrayed as
respondents in this Arbitration Application; and this Arbitration
Application should have been confined only to the first respondent.
He, therefore, seeks permission to withdraw this application, with
liberty to file an Arbitration Application afresh.
2. Granting liberty, as sought for, this Arbitration Application is
dismissed as withdrawn. The application for withdrawal is,
accordingly, disposed of.
3. No costs.
 (Ramesh Ranganathan, C.J.)
 30.08.2019
Rahul
