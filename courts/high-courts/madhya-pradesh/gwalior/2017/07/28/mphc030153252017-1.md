# High Court of Madhya Pradesh, MCRC/7048/2017, 2017-07-28

MCRC-7048-2017
(DURGESH SHARMA Vs THE STATE OF MADHYA PRADESH)
28-07-2017
Shri JS Kushwah, counsel for the applicant.
Shri Prakhar Dhengula, Panel Lawyer for the respondent/ State.
Case Diary is available.
This is second application under Section 438 of CrPC for grant of
anticipatory bail. First application was dismissed as withdrawn by order
dated 21/06/2017 passed in MCRC 4158/2017 with liberty to file the same
again along-with the remaining documents which are to be filed.
The applicant apprehends his arrest in connection with Crime No.71/2017
registered at Police Station Civil Line, District Morena for the offence
punishable under Sections 120-B, 403, 406, 408, 417, 148, 420, 465, 468 of
IPC.
The counsel for the applicant seeks permission of this Court to withdraw
this application.
It is accordingly dismissed as withdrawn.
(G.S. AHLUWALIA)
JUDGE
MKB
