ORAL ORDER :
1. Counsel appearing for the applicants has tendered
across the bar rejoinder affidavit. Same is taken on record.
2. At the outset, learned A.P.P. makes a statement that
charge sheet is already filed.

2
3. Counsel appearing for the applicants, on instructions,
seeks liberty to withdraw the Criminal Application with further
liberty to file an application for discharge before the concerned
Court. Criminal Application is dismissed as withdrawn with
liberty as prayed for. However, we make it clear that if charge is
already framed, there is no question of filing application for
discharge. In case applicants wish to file application for
discharge, this liberty will be available for four weeks from today.
In case the application for discharge is filed, the concerned Court
shall decide the same expeditiously.
