This application is filed by the State of
Maharashtra for speaking to the minutes. It is submitted that
on 22nd June, 2017 a submission was made on behalf of the
applicants that they may be permitted to withdraw the
application filed by them under Section 438 of the Code of
Criminal Procedure, however, from the order passed by this
Court on 22nd June, 2017 it appears that this part remained to
be transcribed.
The learned advocate appearing for the applicants
does not dispute this fact.
In the order passed on 22nd June, 2017 the
following be added as first paragraph:
“The learned Senior Advocate for the
applicants seeks permission to withdraw the
application.
The application is dismissed as
withdrawn.”

The order be corrected accordingly.
The application is allowed.

survive, hence, both the applications are disposed of.
