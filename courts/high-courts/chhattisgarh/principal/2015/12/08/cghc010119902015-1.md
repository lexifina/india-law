Order On Board
08/12/2015
1. Heard on application for modification as well as correction in the crime
number of the order.
2. Learned counsel for the petitioner would submit that bail was granted
in M.Cr.C. No. 6265/2015 by order dated 24.11.2015, however, wrong
crime number was mentioned in the bail application as Crime
No.428/2015, which was as per order of the Trial Court. Subsequently
it was found that actually the crime number is 148/2015, therefore, that
may be corrected in the bail order.
3. The State counsel after going through the final report also affirms the
same and submits that actually the crime number is 148/2015.
4. Consequently, in the order dated 24.11.2015, passed in M.Cr.C.
No.6265/2015, the Crime No.428/2015 be read as Crime No.148/2015.
5. With such observation, the petition stands disposed off.
