# Allahabad High Court, WRIA/8080/2025, 2025-07-24

Case :- WRIT - A No. - 8080 of 2025
Petitioner :- Devendra Kumar
Respondent :- State Of U.P. Thru. Addl. Chief
Secy.,/Prin.Secy. Agriculture Deptt. Lko. And 2 Others
Counsel for Petitioner :- Rajendra Singh Chauhan,Manish
Kumar Srivastava
Counsel for Respondent :- C.S.C.
Hon'ble Manish Mathur,J.
1. Heard learned counsel for petitioner, learned State Counsel
for opposite parties.
2. The present petition has been filed by the petitioner
challenging an order dated 14.06.2025, whereby the petitioner
has been transferred from District Lucknow to Unnao.
3. Learned State Counsel based upon the instructions dated
21.07.2025, which is taken on record, states that petitioner's
representation has been rejected vide order dated 18.07.2025,
which has not been challenged.
4. In view thereof, learned counsel for the petitioner seeks to
withdraw the present petition with liberty to file a fresh.
5. Considering the aforesaid submission, the present petition is
dismissed as withdrawn granting liberty to file a fresh.
