ORDER
(23.07.2013)
1. By this application under Section t-1 (6) of the Arbitration and Conciliation
Act, 1996 the applicant has prayed for appointment of sole Arbitrator.
2. The Registry has pointed out default that requisite court fee has not been
paid.
3. Learned counsel for the applicant seeks to withdraw this application with
liberty to file duly constituted arbltration application along with requisite
court fee.
4. Consequently, the arbitration application stands dismissed as withdrawn
reserving liberty to the applicant to file duly constituted arbitration
application. No order as to costs.
