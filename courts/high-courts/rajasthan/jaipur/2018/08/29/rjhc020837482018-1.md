HON'BLE MR. JUSTICE PANKAJ BHANDARI
Judgment / Order
29/08/2018
1. Petitioner has moved an application seeking correction in the
order dated 06.08.2018.
2. It is contended by counsel for the petitioner that at Page 3
District Magistrate, Kota has been mentioned in the order dated
06.08.2018 whereas it should be District Magistrate, Jhunjhunu.

(2 of 2) [CRLMA-497/2018]
3. Taking note of the fact that the matter pertains to Jhunjhunu
and due to typographical error “Kota” has been mentioned in first
line at Page 3 of the order dated 06.08.2018.
4. The application is allowed. In place of “District Magistrate,
Kota” at Page 3 of order dated 6.8.2018 the same be read as
“District Magistrate, Jhunjhunu.”
(PANKAJ BHANDARI),J
