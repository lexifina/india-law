 02/ 09.07.2026: Heard the learned counsel for the petitioner and the learned counsel for
the respondents.
 2. This writ application was filed for the relief claimed, considering the
situation prevalent then, that the Debt Recovery Tribunal, Ranchi was not
functioning. It is submitted that now the Debt Recovery Tribunal, Ranchi is
functioning and the Presiding Officer is hearing the matter through virtual
mode or physical mode.
 3. Considering the said submission, I allow the petitioner to file an
appropriate application before the Debt Recovery Tribunal, Ranchi. If such
application is filed, the same should be disposed of as early as possible
without giving unnecessary adjournments.
 3. With the aforesaid observations and directions, this writ application is
disposed of.
 4. Consequently, I.A. No.8263 of 2026 is disposed of.
