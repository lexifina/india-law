# High Court of Tripura, IA./194/2017, 2017-02-14

Case No :IA. 0000194/2017
Party Name : SUKUMAR DAS Vs THE STATE CO-OPERATIVE BANK LTD & ORS
THE HONBLE THE CHIEF JUSTICE T. VAIPHEI
14.02.2017.

Heard Mr. Somik Deb, the learned counsel for the applicant. Also heard Mr. Sankar Deb, the
learned Sr. Counsel appearing for the respondent No.1 and Mr. T.D. Majumder, the learned Govt.
Advocate appearing for the respondent Nos.2 and 3.
The application is for restoring the connected writ petition [WP(C) No.85/2012], which was
dismissed on 12.01.2017 in default of prosecution.
As there is no objection, the application is allowed.
The application stands disposed of.
