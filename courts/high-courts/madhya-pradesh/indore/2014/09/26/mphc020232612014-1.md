# High Court of Madhya Pradesh, MCC/647/2014, 2014-09-26

MCC No.647/2014
26.09.2014
Smt. Karmendri Sharma, learned counsel for the applicant.
Smt. Neelam Abhyankar, learned counsel for the non-applicant/State.
Heard.
This MCC has been filed by the applicant for correction of
the cause title of W.P. No.6199/2014, which has been decided by
order dated 25/08/2014.
Learned counsel for the applicant submits that due to the
typographical error in the description of the respondents No.2 to 5
by mistake Ujjain and Shajapur has been mentioned whereas, the
correct address of the respondents No.2 to 5 is Indore, therefore,
such correction be done in the cause title.
Counsel for the State has no objection to the same.
In view of the aforesaid submission, the MCC is allowed. In
the above order, the description of the respondent No.2 instead of
Ujjain, it will be read as Indore and in the description of respondent
No.3 to 5 instead of Shajapur, it will be read as Indore.
C.c. as per rules.
 (Prakash Shrivastava)
