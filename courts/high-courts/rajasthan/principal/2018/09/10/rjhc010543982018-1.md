Order
10/09/2018
This misc. application has been filed by the petitioner for
reconstitution of the file of S.B.Civil Writ Petition No.13271/15.
As per the office report, the file was sent by the concerned
clerk to the cause list section on 5.4.16 and thereafter, the file is
not traceable.

(2 of 2) [WMAP-242/2018]
As per the report of the Deputy Registrar (Judicial), the
concerned clerk has made best and sincere efforts to search out
the file, but the same is not traced out.
The application is allowed. Let the file of SBCW No.13271/15
be reconstituted.
