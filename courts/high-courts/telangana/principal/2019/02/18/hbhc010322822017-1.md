# High Court for the State of Telangana, CRLP/2855/2017, 2019-02-18

THE HONOURABLE Dr. JUSTICE B. SIVA SANKARA RAO
CRIMINAL PETITION No.2855 of 2017
ORDER :
As per instructions of the learned Public Prosecutor, the
police filed the final report referring as action dropped.
 Hence, this Criminal Petition is closed as the relief became
infructuous. If at all any protest filed and any cognizance taken,
the remedy is left open.
 Miscellaneous petitions pending, if any, shall stand closed.
