# Madras High Court, CMP/22809/2024, 2024-11-07

C.M.P.No.22809 of 2024
in
C.M.A.No.2682 of 2017
M.DHANDAPANI, J.
This petition has been filed to
set aside the order passed in
C.MA.No.2682 of 2017 which was
dismissed for default on 14.07.2022 and
restore the appeal for disposal on merits.
2. Heard Mr.Jeny V.V.Sundar,
learned counsel for the petitioner.
Mr.N.Vijayaraghavan, learned counsel
appearing for the second respondent did
not raise any serious objection in allowing
this petition.
3. Satisfying with the reasons
stated in the affidavit filed in support of this
petition, this Court is inclined to accept the
prayer sought for herein. Accordingly, this
Miscellaneous Petition is ordered thereby,
the main C.M.A.No.2682 of 2017 is
restored to file.
4. Registry is directed to list
C.M.A.No.2682 of 2017 in the usual
course.
