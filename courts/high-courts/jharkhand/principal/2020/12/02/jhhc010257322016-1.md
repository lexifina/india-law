5/ 02.12.2020 Mr. Deepankar, learned counsel submits that his client is not in
touch with him.
 In this application under Article 226 of the Constitution of India,
petitioner has prayed to register a First Information Report on the written report
filed by him. It is the grievance of the petitioner that inspite of the written report
given by him, First Information Report has not been registered.
 If a cognizable offence is made out from the written report, police
cannot refuse to register a First Information Report nor then can keep the
matter pending for indefinite period of time. No sooner the written report is
received, which suggests cognizable offence is made out, immediately a First
Information Report is to be registered. If the First Information Report is not
registered, remedy is available to the petitioner in the Code of Criminal
Procedure itself. Chapter XII of the Code of Criminal Procedure provides for
the remedies available to the petitioner.
 Since there is alternative remedy available to the petitioner, I am
not inclined to entertain the prayer made by the petitioner in this writ
application. Petitioner is at liberty to invoke the alternative remedy.
 This writ application is, accordingly, disposed of.
(Ananda Sen, J.)
