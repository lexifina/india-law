This application coming on for conciliation this day, the Bench passed
the following:
ORDER
This is an application seeking restoration of SA No.119/2010 which has
been dismissed for non-compliance of peremptory order dated 12.04.2014.
2. The counsel for applicants contends that there was peremptory order
by this Court, by which the petitioner was directed to delete the name of
respondent No.1 from the array of appellant in memorandum.
3. The said order could not be complied with inadvertently, within the
stipulated period so granted by this Court, accordingly, the same was
dismissed.
4. Upon taking into consideration, the contents of I.A. No.227/2020
which is supported by affidavit of the counsel, the same is allowed. Delay is
condoned.
5. Upon taking into consideration, the application for restoration which is
supported by affidavit of the counsel, the same is also allowed.
6. Let SA No.119/2010 be restored to its original number.
7. With the aforesaid, MCC stands allowed / disposed of.
