# Madras High Court, A/842/2021, 2021-03-23

A.No.842 of 2021
in C.S.No.854 of 2016
R.PONGIAPPAN, J.,
This application has been filed
to set aside the ex parte order dated
11.02.2021 in C.S.No.854 of 2016.
2. Today, when the application
is taken up for hearing, both the
learned counsel appearing for the
applicants and the learned counsel
appearing for the respondent, are
present through Video Conferencing.
The learned counsel appearing for the
respondent did not raise any objection
in allowing this application.
3. Hence, this application is
allowed. Ex parte order dated
11.02.2021 passed against the
applicants, is set aside.
