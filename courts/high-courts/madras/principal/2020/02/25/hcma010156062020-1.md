A.No.802/2020:
This Application praying that this Hon'ble court be pleased to set
aside the exparte order passed in C.S.No.60 of 2018 dated 10/07/2019 in
the above suit.
This Application coming on this day before this Court for hearing the
court made the following order:
This application is filed to set aside the ex-parte order dated
10.07.2019 in C.S.No.60 of 2018.
2. I heard the learned counsel for the applicants and the learned
counsel for the respondent/plaintiff.
3. The learned counsel for the applicants submits that the parties had
discussions in order to arrive at a compromise as between the members of
the family and that therefore, the written statement could not be filed in
time. As a consequence, the applicants were set ex-parte on 10.07.2019.
Therefore, the present application is taken out.
4. The learned counsel for the respondent/plaintiff submitted that he
has no objection if this application is allowed.
https://hcservices.ecourts.gov.in/hcservices/

4
5. Upon considering the submissions of the learned counsel for the
respective parties and on examining the affidavit filed in support of the
application, I find that the applicants have made out sufficient cause to set
aside the ex-parte order dated 10.07.2019. Accordingly, this application is
allowed and the ex-parte order dated 10.07.2019 is hereby set aside.
