# High Court of Madhya Pradesh, MCRC/10051/2014, 2014-12-10

M.Cr.C. No.10051/2014
10.12.2014
Shri Nilesh Dave, learned counsel for the applicant.
Smt. Mamta Shandilya, learned PL for the
respondent/State.
Heard.
This application under section 482 of Cr.P.C. is filed for
correction of the order passed by this Court in M.Cr.C.
No.9681/2014 dated 03.12.2014.
It is stated by counsel for the applicant that due to
typographical error, the case number and crime number have
wrongly been mentioned in the order dated 03.12.2014. The
case number should be 9681/2014 instead of 9481/2014 and
the Crime Number should be read as 03/2014 instead of
03/2013.
After going through the order, I find that these were the
typographical errors and, therefore, the present application is
allowed. It is directed that in the order passed in M.Cr.C.
no.9681/2014 dated 03.12.2014, the Case Number should be
read as 9681/2014 in place of 9481/2014 and the Crime
Number should be read as 03/2014 in place of 03/2013.
With these observations, the application is allowed.
C.c. as per rules.
 (Alok Verma)
 Judge
