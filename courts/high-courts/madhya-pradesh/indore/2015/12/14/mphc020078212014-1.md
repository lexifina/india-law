# High Court of Madhya Pradesh, RP/130/2014, 2015-12-14

R. P. No.130/2014
14.12.2015
Shri Pranay Shukla, learned counsel for the petitioner.
Heard.
The impugned order has been challenged by the petitioner
by filing W. A. No.310/2014.
Learned Division Bench while deciding the writ appeal on
14.03.2014 passed the following order :-
He seeks leave to withdraw this appeal with a
liberty to file review petition, as according to the
learned counsel for the appellant, the reference of
pendency of appeal before the Sub-Divisional Officer
in para-12 of the order passed by the learned Single
Judge is not correct, as no appeal at the instance of
this appellant is pending. He also submits that there
appears to be error in the order passed by the learned
Single Judge in ordering that “Till disposal of the
appeal, the interim order passed by this Court on
20.04.2010 shall remain stayed”. He submits that
infact that the order ought to have been “till disposal
of the appeal”, the interim order passed by this Court
on 20.04.2010 shall remain operative.
If the appellant feels that there are some factual
errors in the impugned order, the appellant is at
liberty to file review petition.
In the circumstances, the appeal filed by the
appellant is allowed to be withdrawn with liberty as
aforesaid.
From perusal of the aforesaid, it is very clear that if there are
some factual errors in the impugned order, then only the petitioner
is at liberty to file review petition.
It is well settled that if there is no factual error, no review

petition is maintainable.
In view of the aforesaid, R. P. No.130/2014 has no merit and
is accordingly, dismissed.
(P. K. Jaiswal)
