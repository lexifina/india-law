 CORAM : S.C. GUPTE, J.

 DATED : 29 AUGUST 2019
P.C. :
. This civil application seeks a restraint order in a disposed of
appeal from order. The grievance raised in the civil application is of such
nature that it should have been addressed to the Court when it decided
the appeal from order. Learned Counsel for the Applicant submits that
the grievance was indeed addressed to the Court. If that is so, it should
have resulted in the order, which the Applicant is now seeking before this
Court. Since there is no such order, there is no merit in the civil
application. The application is dismissed.
( S.C. GUPTE, J. )
