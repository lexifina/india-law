CORAM: HONOURABLE MR. JUSTICE ANIL KUMAR SINHA
ORAL ORDER
2 06-09-2021 Heard Mr. Ratnesh Kumar Singh, learned counsel
for the petitioner and Mr. Vinay Kirti Singh, GA-2 for the State
through virtual mode.
Learned counsel for the State submits that petitioner
has been paid due salary as per the direction of this Court.

Patna High Court MJC No.4947 of 2018(2) dt.06-09-2021
2/2
Accordingly, the order has been complied with.
Learned counsel for the petitioner submits that while
disposing the writ application, the Hon’ble Court had given
liberty to the petitioner to file representation and in pursuance
thereof, the petitioner has filed representation claiming the grant
of MACP which is still pending for consideration. However, the
Respondents have passed order granting MACP to the petitioner
but the date of grant of MACP has wrongly been fixed inasmuch
as instead of fixing the date for the first MACP on 01.01.2008, it
has been fixed on 2016 and for the second MACP, instead of
01.01.2018, the same has been fixed w.e.f 05.09.2018.
Accordingly, learned counsel for the petitioner seeks
permission to withdraw the contempt application with liberty to
challenge the order granting MACP to him by way of separate
writ application.
Permission is granted.
This contempt application is dismissed as withdrawn
with the aforesaid liberty.

perwez/praful
(Anil Kumar Sinha, J)
