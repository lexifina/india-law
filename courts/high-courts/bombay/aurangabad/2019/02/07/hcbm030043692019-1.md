PER COURT :-
1 Heard learned counsel for the applicant.
2 Learned counsel for the applicant again makes a statement
that the applicant was not recruited as against reserved post and
he was recruited as against open post. Application is made for
granting permission to the applicant to file undertaking affidavit
which was a direction given against him by this Court in Writ
petition No.2889/2014 on 18.12.2018. This Court had asked him to
give some undertaking by making specific order in para No.8. As he
could not file undertaking within the time fixed by this Court,
permission is sought to file it.
3 As the applicant wants to file only undertaking, application is
allowed. Undertaking be accepted as per aforesaid order.
4 Application is disposed of.
( SUNIL K. KOTWAL, J. ) ( T.V. NALAWADE, J. )
