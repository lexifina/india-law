# Gauhati High Court, WP(C)/7482/2015, 2015-12-11

WP(C) 7482/2015
BEFORE
HON’BLE MR JUSTICE A. K. GOSWAMI
Mr MR Khandakar, the learned counsel for the petitioner, submits that after fili
ng this petition the petitioner came to learn about some notifications for which
he would like to withdraw this petition with liberty to file afresh, to which M
r R Mazumdar, the learned Standing Counsel for the Elementary Education and Mr S
Sarma, the learned Standing Counsel for the Sarva Siksha Abhijan, have no objec
tion. Accordingly, the petition is dismissed as withdrawn with liberty to file a
fresh one.
