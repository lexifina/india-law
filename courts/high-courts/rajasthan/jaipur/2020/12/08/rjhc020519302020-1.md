Order
Learned counsel for the petitioner submits that inadvertently,
he had filed criminal bail application u/s 438 Cr.P.C., there is a
requirement to file criminal appeal (Section 14-A). Therefore, he
wants to withdraw this bail application with liberty to file criminal
appeal (Section 14-A).
Prayer is allowed.
Therefore, the bail application is dismissed as withdrawn with
liberty aforesaid.
Office - is directed to return the certified copies of the
documents attached with the bail application to the learned
counsel for the petitioner after retaining photocopies of the same
in the bail application.
