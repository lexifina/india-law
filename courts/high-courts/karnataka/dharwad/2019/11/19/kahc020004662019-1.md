ORDER
Petitions are admitted for hearing. With the
consent of the learned counsel for parties, heard
finally.
2. In these petitions under Article 227 of the
Constitution of India, the petitioners inter alia have
assailed the validity of the order dated 09.01.2019, by
which application filed by the petitioner under Order
VI Rule 17, Order VII Rule 14 as well as Section 151 of
the Code of Civil Procedure, 1908, has been rejected.

4
3. When the arguments were heard to some
extent, the learned counsel for respondents submitted
that he be permitted to withdraw the aforesaid
applications with a liberty to file the same, if the
occasion so arises in the appeal. In view of the
aforesaid submission, the impugned order dated
09.01.2019 is set aside and the respondent is granted
a liberty to file applications in appeal, if occasion so
arises. Accordingly, the writ petitions are disposed of.
4. In view of disposal of the matter, pending
interlocutory applications, if any, does not survive for
consideration.
