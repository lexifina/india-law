ORAL ORDER
2 28-07-2026 Heard the learned counsel for the petitioner and the
learned counsel for the State.
2. The present application has been filed seeking
restoration of Cr. Misc. No. 29418 of 2023, which was
dismissed on 26.07.2023, by a learned Co-ordinate Bench of
this Court, which passed the following order:
“1. This application has been filed for
modification of the anticipatory bail order passed on
08-07-2020 in Cr. Misc No. 7613 of 2020.
2. Today is the second occasion, when there
is no representation on behalf of the petitioner. On
12.07.2023, the position was the same.
3. Application is dismissed for want of

Patna High Court CR. MISC. No.68806 of 2023(2) dt.28-07-2026
2/2
prosecution.”
3. The petitioner has now filed a second application
seeking restoration. In the opinion of this Court, the present
restoration application is misconceived and, therefore, is not
maintainable.
4. Accordingly, the present application stands
dismissed with liberty to the petitioner to file a fresh bail
application.
