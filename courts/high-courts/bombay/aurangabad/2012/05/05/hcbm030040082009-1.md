PER COURT:
1. By this application, the applicant State seeks
condonation of delay of 6 days in filing an application seeking leave
to file appeal against acquittal. We have heard learned APP for the
applicant and Mr.Joydeep Chatterji, learned counsel for the
respondents No.2 to 4. This application is abated as against
respondent No.1. In the light of the averments in the application,
the application is allowed and the delay is condoned.

PER COURT:
1. By this application, the applicant State seeks leave to
file an appeal against the judgment of the 3rd Additional Sessions
Judge, Dhule dated 23.10.2008 acquitting the respondents for the
offence punishable u/s 302 and 427 r/w 34 of the Indian Penal
Code.
2. We have heard learned APP and with his assistance we
have perused the findings recorded by the trial court. Upon such
perusal, according to us, this is a fit case for granting leave.
Accordingly, this application is allowed and leave, as prayed for, is

{3} Cri. Application No.508/2009
granted. Criminal Appeal against acquittal stands admitted. Action
u/s 390 of the Criminal Procedure Code be taken by the trial court
by issuing bailable warrants for Rs.10,000/- each against
respondents No.2 to 4. Criminal Revision Application No.10/2009
to be heard along with this appeal.
