TR.P(CRL.) NO. 100 OF 2017
2
ORDER
This transfer petition has been filed to transfer C.C No.831/2015 on
the files of Judicial First Class Magistrate Court-I, Hosdurg, Kasargod to
any Magistrate courts in Thrissur.
2. Heard both sides.
3. It is submitted by both counsel that a connected case
C.C.No.1328/2014 between the same parties, which was also pending at
Judicial First Class Magistrate Court-I, Hosdurg, was already transferred
to the Judicial First Class Magistrate Court-I, Ernakulam. In these
circumstances, the leanred counsel appearing for respondents 2 to 4
submited that he has no objection in transferring C.C.No.831/2015 to
Judicial First Class Magistrate Court-I, Ernakulam. The learned counsel
for the petitioner also has no objection in transferring the case to Judicial
First Class Magistrate Court-I, Ernakulam.
In these circumstances, this transfer petition is disposed of.
C.C.No.831/2015 pending on the files of Judicial First Class Magistrate
Court-I, Hosdurg is withdrawn and transferred to Judicial First Class
Magistrate Court-I, Ernakulam for trial and disposal.
