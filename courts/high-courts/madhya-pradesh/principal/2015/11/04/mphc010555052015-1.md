# High Court of Madhya Pradesh, MCC/3206/2015, 2015-11-04

MCC-3206-2015
(KU. PRITEE KORI Vs THE STATE OF MADHYA PRADESH)
04-11-2015
Shri S.A.Wakil, learned counsel for the applicant.
The applicant has filed this application for restoration of
W.P.No.17641/2014, which was dismissed for want of
prosecution order dated 13.5.2015. There being some
delay in filing the application for restoration, for which
I.A. No.14269/2015 has been filed seeking condonation
of delay. Both the applications are supported by
affidavit of the advocate.
Looking to the grounds stated in the application as well
as an affidavit the application for condonation of delay is
allowed.
Consequently, application for restoration is also
allowed.
W.P.No.17641/2014 is restored to its original number. It
be placed for orders before appropriate Bench.
MCC stands allowed and disposed of.
Let a copy of this order be kept in the record of
W.P.No.17641/2014.
C.C. as per rules.
(MISS VANDANA KASREKAR)
JUDGE
