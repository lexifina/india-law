ORAL ORDER
2 11-07-2017 This application has been filed for modification of the
order dated 21.6.2017 passed in Cr.Misc.No.19980 of 2017 in
which petitioner has been granted bail but petitioner has not been
released because of the fact that father’s name of the petitioner has
wrongly been mentioned in the bail petition as ‘Md. Rarukh’ in
place of ‘Md.Farukh’ and consequently in the order granting bail
the wrong name of father of the petitioner has been mentioned.
Heard learned counsel for the petitioner and learned
APP also.
In the said circumstances, the order dated 21.6.2017
passed in Cr.Misc.No. 19980 of 2017 is modified to the extent that
father’s name of the petitioner should be correctly read as ‘Md..
Farukh’ instead of ‘Md.Rarukh’.
Accordingly, this application is disposed of.
Let this order be communicated to the court concerned
forthwith.
spal/-
(Vinod Kumar Sinha, J)
