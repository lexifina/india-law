Heard.
2. The application is for grant of bail under
Section 439 of the Code of Criminal Procedure.
3. After hearing the learned Counsel and after
going through the investigation papers, this Court is
inclined to grant bail to the present applicant.
4. Learned Counsel seeks permission to
withdraw the application with liberty to file afresh, if the
trial is not commenced within six months.
5. Considering the request, the applicant is
permitted to withdraw the application with liberty to file
after one year, if trial is not commenced within one years.
6. The application is disposed of as withdrawn.
