02 19.08.2010 Heard both sides.
Learned counsel for the petitioner makes only one
submission. It is contended that subsequent to the order impugned
opposite party no.2 (Smt. Saroja Devi) has remarried on
08.04.2010. It is thus submitted that the impugned order requires
interference.
This Court finds that the order was passed on 21st
November, 2008. Thus, this Court without interfering with the
impugned order permits the petitioner to approach the learned
Court below (Principal Judge, Family Court, Aurangabad) by
filing application seeking appropriate relief.
With the aforesaid liberty, the application is dismissed.
Sym ( Kishore K. Mandal, J.)
