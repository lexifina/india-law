ORDER

 Learned counsel for the petitioner fairly submits that since this
petition pertains to Work Load Returns (WLRs) for the quarter ending
March, 2023 dated 3rd July, 2023, and, therefore, by efflux of time this
petition has been rendered infructous.
 In view of above, this petition is dismissed as having been
rendered infructous with liberty to the petitioner to file fresh in case Work
Load Returns (WLRs) for the subsequent period has been issued.
