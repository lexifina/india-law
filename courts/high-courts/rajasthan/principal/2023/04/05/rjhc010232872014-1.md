Order
05/04/2023
In the present writ petition, an interlocutory application
(No.01/2023) has been filed for challenging the impugned order
dated 11.03.2011 passed by Learned Judge, MACT No.01, Udaipur
and for withdrawal of the writ petition with a liberty to file a fresh
one, if the occasion so arises.
Considering the grounds set out in the application
(No.01/2023) to be germane, the same is accepted.
The petitioner is permitted to withdraw the instant writ
petition with a liberty to challenge the impugned order dated
11.03.2011, if the occasion so arises before the appropriate
forum.
All pending stay applications are also disposed of.
