ORAL ORDER
Order in Civil Application
Ms.Sunita Chaturvedi, learned advocate for the
applicant is not present.
This Application is filed praying for vacating interim
relief granted by this Court vide an order dated
17.12.2018.
Mr.Dharmesh Patel, learned advocate for the
Respondent herein who represents petitioner in main
Special Civil Application submitted that main Special Civil
Application is filed challenging the order granting
maintenance pendente lite under Section 24 of the Hindu
Marriage Act, however, main suit wherein the said
application was filed, has been disposed of and it is
Page 1 of 2

challenged by way of First Appeal.
In view of the fact that this main Special Civil
Application would become infructuous, nothing survives
to be done in this Civil Application praying for vacating
interim relief granted therein.
Hence, this Civil Application stands disposed of.
Order in Special Civil Application
Mr.Dharmesh Patel, learned advocate for the
petitioner submitted that this petition is filed challenging
an order passed below Exh.17 in HMP No.10 of 2018
whereby maintenance pendente lite was granted in favour
of the respondent herein but the main suit wherein this
order granting maintenance pendente lite is passed, has
been disposed of and therefore, this order would also
terminate the order granting maintenance pendente lite.
Therefore, according to his submission, main petition has
become infructuous.
In view thereof, this petition stands disposed of as it
has become infructuous. Rule discharged. Interim relief
granted earlier stands vacated.
