Date : 24-05-2019
Heard Mr. KN Choudhury, learned Senior counsel for the petitioner and Mr. NJ Dutta, learned
Addl. Public Prosecutor, Assam. Also heard Mr. Z. Kamar, learned Senior counsel, appearing for the
informant.
Mr. KN Choudhury, learned Senior counsel submits that this is the second bail application and
that a criminal petition, being Crl. Rev. Petition No. 563/2019 was filed before this court, in connection
with the case, wherein further proceeding of Morigaon PS Case No. 266/2018 under Sections 120B/
409 of the IPC read with Sections 13(1)(d)/13(2) of the Prevention Corruption Act, 1988 has been
stayed until further order and as such the petitioner is not willing to press the instant anticipatory bail
application and accordingly, the same may be treated as withdrawn with liberty to file afresh, if so
advised.

Page No.# 2/2
In view of the above, this anticipatory bail application is closed on withdrawal with liberty to file
a fresh, if so advised.
This disposes off this anticipatory bail application.
