HON'BLE MR. JUSTICE SANDEEP MEHTA
Order
06/03/2020
These misc. applications have been filed with the prayer to
make correction in the order dated 30.01.2020 passed by this
Court as inadvertently, learned counsel sought withdrawal of the
misc. petitions in place of misc. applications filed for seeking
extension of the interim relief granted by this Court vide order
dated 22.01.2019.
The prayer for correction is justified.
These misc. applications are allowed for the reasons
mentioned therein. Now the order dated 30.01.2020 shall be read
as under:-
“At the request of learned counsel representing the
applicants-petitioners, the misc. applications seeking

(4 of 4) [CRLMA-53/2020]
extension of interim relief regarding repayment of money as
directed by this Court vide order dated 22.01.2019 are
dismissed as withdrawn.”
A copy of this order be placed in each file.
(SANDEEP MEHTA),J
