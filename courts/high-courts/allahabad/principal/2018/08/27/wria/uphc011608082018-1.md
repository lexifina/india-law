# Allahabad High Court, WRIA/18146/2018, 2018-08-27

Court No. - 58
Case :- WRIT - A No. - 18146 of 2018
Petitioner :- Sanjay Kumar And Another
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Rajesh Kumar
Counsel for Respondent :- C.S.C.
Hon'ble Ashwani Kumar Mishra,J.
Heard learned counsel for the petitioner, learned Standing
Counsel for the State authorities and Sri K. S. Kushwaha,
learned counsel for the Commission.
This petition has been filed for a direction upon the respondents
to consider petitioners' representation dated 27.6.2018 and
30.6.2018.
Perusal of such representations would go to show that
petitioners are seeking extension in the last date specified for
filling up of the application form. The advertisement has not
been annexed. Advertisement usually contains a cut-off of date
upto which applications are to be entertained.
In case last date has already been expired, no direction can be
issued to extend the last date specified in the advertisement for
filling up the application form.
Writ petition is, accordingly, dismissed.
Order Date :- 27.8.2018
Ashok Kr.
