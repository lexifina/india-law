ORDER
This criminal original petition has been filed seeking direction to
the respondent to file the final report in Cr.No.1751/2020 on file of the
respondent police station within a time framed by this Court.
2.On the side of the prosecution it is stated that final report was
filed and the same was taken on file in C.C.No.365 of 2023 on the file of
the learned Judicial Magistrate, Thirumangalam.
3.In view of the same, this criminal original petition is dismissed
as infructuous.
