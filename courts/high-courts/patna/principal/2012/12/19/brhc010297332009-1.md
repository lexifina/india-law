ORAL ORDER
14 19-12-2012 This case has been listed today because there is a
discrepancy between the order sheet and the pronounced copy
of order dated 27.07.2011.
In the order sheet of order dated 27.07.2011, the
description of the court below has not been printed
inadvertently, whereas the pronounced order correctly shows
the name of the Court below as “Chief Judicial Magistrate,
Gaya”.
The order dated 27.07.2011 should be treated to
have been corrected so as to read that the petitioner has been
granted anticipatory bail to the satisfaction of the Chief
Judicial Magistrate, Gaya, as it is shown in the pronounced
copy.
The order dated 27.07.2011 is modified to the
extent indicated aforesaid.
Prabhakar Anand/- (Sheema Ali Khan, J)
