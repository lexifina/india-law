ORAL ORDER
2 07-05-2014 The impugned order dated 22nd March, 2013 is a final
order passed on an application filed under section 437 (5) of the
Code of Criminal Procedure. It is certainly not an “interlocutory
order”.
The petitioner, therefore, ought to have challenged the
same in revision.
At this stage, learned counsel for the petitioner prays to
convert the present application into an application under sections
397 and 401 of the Code of Criminal Procedure.
The prayer is allowed. Learned counsel for the petitioner
is permitted to convert the present application into a revision
application. The petitioner shall take steps in this regard within
one week failing which this application shall stand rejected
without further reference to a Bench.
Md.S./-
(Ashwani Kumar Singh, J)
