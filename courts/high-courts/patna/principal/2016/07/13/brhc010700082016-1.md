ORAL ORDER
2 13-07-2016 Heard the learned counsel for the petitioners.
Since by the order dated 10.11.2015 passed by Sub Judge
V, Saharsa in Title Suit No.180 of 2012, the injunction application
filed under Order 39 Rule 1 of the C.P.C. has been rejected, the
petitioners have got the remedy of appeal under the Code itself.
Therefore, this writ application is not maintainable. If so
advised, the petitioners may file appeal according to law before
the appropriate forum.
Thus, this writ application is dismissed.
