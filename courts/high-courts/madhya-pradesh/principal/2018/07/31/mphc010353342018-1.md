# High Court of Madhya Pradesh, MCC/1845/2018, 2018-07-31

(MISS VANDANA KASREKAR)
JUDGE
The High Court Of Madhya PradeshThe High Court Of Madhya Pradesh
MCC-1845-2018
(ANIL BAGHEL Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 31-07-2018
Shri H.S. Rajput, learned counsel for the petitioners.
Heard.
The applicants have filed this application for restoration of W.P.
No.21068/2017 which is dismissed in common conditional order vide
order dated 29.1.2018. The application is supported by an affidavit of
the Advocate.
Looking to the grounds mentioned in the application as well as
affidavit, the application is allowed. W.P. No.21068/2017 is restored to
its original number.
Let a copy of this order be kept in the file of W.P.No.21068/2017.
The MCC stands disposed of.
A.Praj.
