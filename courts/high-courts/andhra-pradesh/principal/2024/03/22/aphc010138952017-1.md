For Being

V
When the matter is taken up for hearing, learned counsel for the
petitioner/appellant would contend that he submitted a letter to the
Registrar (Judicial) for returning the original plaint, so as to enable the
petitioner to represent the same before the court below, pursuant to
the Judgment of this Court dated 24.11.2023. But the Registry took
objection that unless there is a direction from the Court to return the
same, it will not be returned to the counsel. Hence, this application
came to be filed.
Heard learned counsel for the petitioner.
For the reason set out In the application, the Registry is directed to
return the original plaint vide O.S.G.L.No.1710 of 2017 to the counsel for the
petitioner, so as to enable him to be presented before the court below on or
before 10.04.2024.
With the above direction, this application is allowed.
