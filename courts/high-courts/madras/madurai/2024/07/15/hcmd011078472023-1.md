O R D E R
When this case is taken up for hearing, the learned counsel for the
petitioner would submit that this Writ Petition has become infructuous as
during the pendency of this Writ Petition, an order has been passed
rejecting the request of the petitioner to refund the GST paid by the
petitioner. The learned counsel for the petitioner therefore seeks liberty
to file fresh Writ Petition against the said order rejecting the request of the
petitioner.
2. Recording the same, this Writ Petition stands dismissed as
infructuous with liberty to the petitioner to file fresh Writ Petition
challenging the order rejecting the request of the petitioner. No costs.
