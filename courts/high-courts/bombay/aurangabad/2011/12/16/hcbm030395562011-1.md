# Bombay High Court, APPLN/5486/2011, 2011-12-16

2. Ganesh s/o Prabhakar Kale
3. Kiran s/o Krishnarao Kadam
Applicants
 V E R S U S
 The State of Maharashtra & Anr. Respondents
 Shri H.V. Tungar, Advocate for the applicant
Shri B.J. Sonawane, APP for the respondent / State
 CORAM : R.Y. GANOO, J.
DATED : 16th December, 2011
PER COURT :
1. Applicants apprehend arrest in connection with
CR No. 91 of 2011, registered with Kadim Jalna Police
Station, District Jalna, under Sections 420, 468, 471
read with Section 34 of the Indian Penal Code.
2. Alongwith this application itself, orders
passed by this Court rejecting anticipatory bail
applications filed by both the applicants are enclosed.
3. I have heard learned Advocate for the
applicants.

 2 CA5486/2011
4. The learned Judge, who has rejected the
anticipatory bail applications, has clearly observed
certain things against the present applicants. If this
be so, there is no question of entertaining this
anticipatory bail application particularly when there
is no change in circumstance favourable to the present
applicants. In view of above, following order is
passed :
O R D E R
For the reasons aforesaid, this
application is not maintainable and is
accordingly rejected.
 ( R.Y. GANOO, J. )
