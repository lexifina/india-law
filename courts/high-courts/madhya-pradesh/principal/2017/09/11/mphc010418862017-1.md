# High Court of Madhya Pradesh, MCRC/14137/2017, 2017-09-11

MCRC-14137-2017
(SATYAM TIWARI Vs THE STATE OF MADHYA PRADESH)
11-09-2017
Shri N.K. Mishra, counsel for the petitioner.
Shri Deependra Mishra, Government Advocate for the
respondent/State.
Learned counsel for the petitioner on instructions submits that
this first application for anticipatory bail under Section 438 of the
Code of Criminal Procedure has become infructuous because the
petitioner has already been arrested.
In aforesaid circumstances, it is dismissed as having become
infructuous.
