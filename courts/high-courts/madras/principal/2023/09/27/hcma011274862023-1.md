# Madras High Court, WP/21520/2023, 2023-09-27

1
Crl.O.P.No.21520 of 2023
N.ANAND VENKATESH., J.
Pursuant to the earlier order passed by this Court on 20.09.2023, the CD file was
produced before this Court. On going through the same, it is seen that there has been
absolutely no progress in the investigation from the year 2011 onwards. There is not
even an indication in the CD file that the fabricated rubber stamps and other documents
were seized from the accused persons. In view of the same, no useful purpose will be
served in keeping the investigation pending. The fact that the FIR has been pending for
the last 12 years, itself is sufficient punishment to the accused persons.
2.The learned Additional Public Prosecutor is directed to file a status report in
this case. If ultimately, nothing turns out of the investigation, the case itself can be
closed.
3.Post this case under the same caption on 18.10.2023.
