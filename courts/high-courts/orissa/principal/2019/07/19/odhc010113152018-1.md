# High Court of Orissa, ABLAPL/2511/2018, 2019-07-19

04. 19.07.2019 Heard learned counsel for the parties.
 Learned counsel for the State on instructions
submits that no F.I.R. has been registered against the
petitioner for commission of any cognizable offences.
 In view of the fact that no F.I.R. has been lodged
against the petitioner, this application for anticipatory bail
is premature.
 ABLAPL is accordingly dismissed as not
maintainable.
 It is open for the petitioner to file fresh application
as and when any formal F.I.R. is registered against him for
commission of any cognizable offences.
