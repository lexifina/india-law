and

Prayer: Criminal Original petition filed under Section 482 of
Code of Criminal Procedure, to set aside the docket order dated
08.03.2019 passed in M.C.No.8 of 2018 on the file of the Family
Court, Puducherry.
For Petitioner : Mr.J.Bharathiraja
ORDER
 This petition has been filed challenging the docket order
passed in M.C.No. 8 of 2018, dated 08.03.2019, wherein the
petitioner has been set ex-parte by the Family Court, Puducherry.
2. Heard the learned counsel for the petitioner.
3.This Criminal Original Petition is disposed of by giving
liberty to the petitioner to file a petition to set aside the
order setting the petitioner ex-parte. The Court below shall
consider the same and permit the petitioner to participate in
the proceedings, before any final orders are passed in M.C.No.8
of 2018.
https://hcservices.ecourts.gov.in/hcservices/

4.Accordingly, this Criminal Original Petition is disposed
of. Consequently, the connected miscellaneous petition is closed.
