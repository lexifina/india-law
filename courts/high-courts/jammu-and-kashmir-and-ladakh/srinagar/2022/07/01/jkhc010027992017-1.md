ORDER

There is no representation on behalf of parties. As per the note
of Registry, the main petition bearing SWP No. 1764/2016 had been
ordered to be transferred to CAT Jammu, by this Court vide order
dated 26.08.2021, but there is no order passed on the instant
contempt petition which was ordered to be listed along with main
matter vide order dated 21.07.2017. Since the main matter has been
transferred to the CAT, Jammu Bench vide order dated 26.08.2021,
to be taken up on 04.10.2021, this contempt petition, is also
transferred to the CAT, Jammu for further consideration along with
main petition.
Registry is directed to transmit the file with convenient
dispatch.
Disposed of as above.
