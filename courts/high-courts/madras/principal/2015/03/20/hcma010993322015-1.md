ORDER
This petition is filed praying for a direction to the respondent
police to investigate the case in Crime No. 1137 of 2014 pending on
the file of respondent police and to file a final report within a
time frame fixed by this Hon'ble Court.
2. No representation for the petitioner. Heard the learned
Additional Public Prosecutor.
3. Considering the facts and circumstances of this case, this
Court deems it appropriate to direct the respondent police to file
final report in connection with the case in Crime No. 1137 of 2014,
on or before 31.08.2015.
https://hcservices.ecourts.gov.in/hcservices/

4.With the above observation, this criminal original petition is
disposed of.
