PER COURT :
1. Having heard this matter for some time, Shri Gaware
learned Advocate for the petitioner prays on instructions to
withdraw this petition so as to avail the remedy under Order XXI
Rule 58 of the Code of Civil Procedure Code to question the
attachment of property in execution.
2. In the light of the said statement, this petition is dismissed
as withdrawn with liberty as prayed. All questions under Order
XXI Rule 58 of the Code of Civil Procedure Code are kept open.
