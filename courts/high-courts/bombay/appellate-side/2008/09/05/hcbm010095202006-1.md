# Bombay High Court, APPLN/1131/2006, 2008-09-05

:1:
IN THE HIGH COURT OF JUDICATURE AT BOMBAY
CRIMINAL APPELLATE JURISDICTION
 CRIMINAL APPLICATION NO.1131 OF 2006
 Shri...Applicant. S.M.Ahirarao..
 Vs.
 Shri...Respondents. M.M. Bhamare and anr.
 Mr.Sagar Joshi for the Applicant.
 Mrs.A.A. Mane,APP. for the State.
CORAM : R.S. MOHITE, J.
DATE : 5th September,2008.
P.C.
 1. This is an application for leave to file appeal.
 It appears from the record that the process itself
 has been quashed in the revision. In my view,
 appeal against acquittal would not lie. Proper
 remedy will be to file revision. Hence, application
 is dismissed with liberty to file Revision. It
 however, does appear that this application was filed
 in bonafide manner.
(R. S. MOHITE, J.)
