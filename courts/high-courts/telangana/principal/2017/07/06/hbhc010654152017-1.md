# High Court for the State of Telangana, CRLP/5264/2017, 2017-07-06

THE HONíBLE SRI JUSTICE T.SUNIL CHOWDARY
CRIMINAL PETITION NO.5264 OF 2017
ORDER:
This Criminal Petition is filed under Section 482 Cr.P.C.
to quash the proceedings in C.C.No.242 of 2016 on the file of
the XIX Special Magistrate, Hyderabad.
 2. Learned counsel for the petitioner seeks permission
of this Court to permit the petitioner to withdraw the Criminal
Petition with a liberty to file fresh application before the trial
Court, if so advised. Permission is accorded.
3. Accordingly, the Criminal Petition is dismissed as
withdrawn granting liberty as prayed for. Miscellaneous
petitions, if any pending, in this Petition shall stand closed.
