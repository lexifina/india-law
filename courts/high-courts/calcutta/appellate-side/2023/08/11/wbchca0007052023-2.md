# Calcutta High Court, CRR/56/2023, 2023-08-11

11.08.2023
 Serial no. 41
 [G.S.D]

 CRR 56 of 2023

In the matter of : Raja Koley & Ors.
 … … Petitioners

 Mr. S. Bandyopadhyay
 … For the Petitioner
Learned Advocate for the petitioner do not intend to
proceed with the present revisional application.
Accordingly, CRR 56 of 2023 is dismissed as not
pressed.
Pending application, if any, is also dismissed.
However, the petitioner prays for liberty to file
afresh.
Accordingly, if fresh ground so arise, the petitioner
would have the liberty to file a separate revisional
application.
Department is directed to allow the Learned
Advocate on record to take back the certified copy, if the
same is replaced by the Photostat copy of the same.
Parties to act on a server copy of this order, duly
collected from the official website of the Hon’ble High Court,
Calcutta.

Urgent Photostat certified copy of this order, if
applied for, be supplied to the parties, subject to compliance
with all requisite formalities.
