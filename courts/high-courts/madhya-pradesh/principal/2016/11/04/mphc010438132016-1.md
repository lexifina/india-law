# High Court of Madhya Pradesh, MCRC/15524/2016, 2016-11-04

MCRC-15524-2016
(MANJHALE @ ROSHAN Vs THE STATE OF MADHYA PRADESH)
04-11-2016
None for the applicant.
Ms. Hemlata Kshatriya, Panel Lawyer for the respondent-State.
This is first application under Section 439 of the Code of Criminal
Procedure for grant of bail being filed by the applicant-Manjhale @
Roshan.
On last date of hearing time was granted to the learned counsel for the
applicant to file additional documents, however, no one has appeared
today nor the documents has been filed, it seems that the applicant has
lost interest in prosecuting this bail application, hence, this application
deserves to be dismissed for want of prosecution.
Accordingly, the application under Section 439, Cr.P.C. stands
dismissed for want of prosecution.
(SUBHASH KAKADE)
JUDGE
