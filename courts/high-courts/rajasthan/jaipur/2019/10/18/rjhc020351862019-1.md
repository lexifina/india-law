Judgment / Order
18/10/2019
1. Petitioner has preferred this Criminal Miscellaneous Petition
seeking fair investigation.

(2 of 2) [CRLMP-2708/2019]
2. Learned Public Prosecutor has submitted a report which is
taken on record. As per which Police has submitted a negative
final report way back in December, 2018.
3. In view of the same, Criminal Miscellaneous Petition seeking
fair investigation has become infructuous and the same is
accordingly dismissed as having become infructuous.
4. Stay application stands disposed.
5. However, petitioners would be free to file Protest Petition, if
so advised.
