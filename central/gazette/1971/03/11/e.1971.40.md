3. Definition of source and origin.—A commodity will be eligible for AID financing only if: —

(a) It is entirely produced in the eligible source country.

(b) The Imported raw-materials and components If any, going into it are from countries belonging to AID Geographic Code B9.9, and

(c) The cost, delivered to the point of production and including duties, of the imported componentry does not exceed 50 per cent of the lowest price (excluding costs of ocean transportation and marina insurance) at which the supplier makes the commodity available for export sale.

Components frcm India or other Code 941 countries can however, be incjuded without limitation.

Illustration.—A product from Malaysia will be eligible for AID financing if it lfl produced entirely in Malaysia without any imported items going into it. If It contains items imported from, say USSR or Poland (viz., non Code 899 countrias) it will be ineligible, whatever percentage of the import content. If it contains items imported say Canada or U.K. (viz. countries other than India In Code 899 but not in code 941) It will be eligible for AID financing provided the imported componentry cost is less than 50 per cent. If the imported items are from, say, India Qr Congo (viz., India and countries In Code 941) it will be eligible for AID financing, regardless of the percentage jf imported componentry cost i e., even If It is well above 50 per cent.

Exception.—In respect of phrmaceuticals. however, for which the source of procurement shall continue to be restricted to USA, the existing 10 per cent componentry limitation will Continue to be In force.
