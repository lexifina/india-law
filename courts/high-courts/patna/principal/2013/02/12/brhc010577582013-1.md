ORAL ORDER
2 12-02-2013 Heard Counsel for the petitioner.
This writ application has been filed challenging the
order by which the Court below has allowed the plaintiff to file
two sale deeds executed by Most. Singaro Devi and Most.
Sundari Devi on 11.06.1963 and 16.01.1964 respectively.
I find that there is no jurisdictional error in the
order impugned. This writ application is accordingly dismissed.
