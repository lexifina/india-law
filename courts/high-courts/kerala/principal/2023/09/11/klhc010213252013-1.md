ORDER
This Criminal Miscellaneous Case is filed under
Section 482 of the Code of Criminal Procedure, 1973
(“the Code” for the sake of brevity).
2. This case is filed to quash the proceedings
against the petitioner in S.T.No.1297/2013 on the file of
the Judicial First Class Magistrate Court, Vaikom. The
petitioner is the 1st accused.
3. This Court directed the Registry to get
instructions from the lower court about the present stage
of the case. The Judicial First Class Magistrate Court - I,
Vaikom, as per letter dated 23.08.2023, informed that
accused Nos.1 and 3 were already acquitted under
Section 255(1) of the Code. If that be the case, this case
is infructuous.

CrlM.C..No.6088/2013

Therefore, recording the above report, this criminal
miscellaneous case is closed.
