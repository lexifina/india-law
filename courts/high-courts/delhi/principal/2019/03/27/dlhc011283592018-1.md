CRL.M.A. 5506/2019 (for modification/correction)
1. The present application has been filed by the petitioner No.4 for
modification of the order dated 31.5.2018 passed by this Court.
2. Learned counsel for the petitioners submitted that in the order
dated 31.5.2018 due to a typographical mistake the FIR number has
been wrongly mentioned as 162/2018 instead of 162/2008.
3. Learned APP for the State submitted that the FIR number ought
to have been 162/2008 instead of 162/2018.
4. In view of the above submissions, it is ordered that FIR number
in the order dated 31.5.2018 passed by this Court shall be read as
162/2008 instead of 162/2018.

5. Application stands disposed of.
