ORDER
This petition has been filed to direct the second respondent to
file final report before the concerned Judicial Magistrate Court in
connection with the Crime No.72 of 2008 pending on the file of the
second respondent within the time.
2. Heard Mr.R.Suresh Kumar, learned Counsel for the petitioner
and Mr.L.Murugan, learned Government Advocate (Crl.Side) appearing
for state.
3. The case in Cr.No.72 of 2008 obviously is pertaining to the
year of 2008 and so far no final report has been filed. Hence, the
https://hcservices.ecourts.gov.in/hcservices/
following direction is issued:

2
The second respondent police is directed to complete the
investigation in Cr.No.72 of 2008 on the file of the second
respondent and to file final report within three months from the date
of receipt of a copy of this order and report compliance.
4. With the above direction, this petition is ordered.
Consequently, the connected Miscellaneous Petition is closed.
