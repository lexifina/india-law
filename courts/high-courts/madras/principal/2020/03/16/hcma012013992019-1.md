This Application coming on this day before this court for hearing

This application has been filed for interim measures for
appointing receiver to seize the vehicle.
2. When the matter is taken up today, the learned counsel for the
applicant submitted that Award has been passed in this matter.
3. Despite the award has been passed in this mater, the same has
not been enforced till date. Therefore, this Court is not inclined to pass any
interim order.
4.In such view of the matter, it is also for the applicant to take
appropriate steps to execute the award as per law.
5. With the above observation, this application is dismissed.
