05 / 26.06.2024: Learned counsel for the petitioners prays that suffice it would be
if a direction is given to the Circle Officer, Chatra to dispose of the
representation, which is annexed along with this writ petition at
Annexure-5 within specific time, considering the grievance of the
petitioners.
 2. Considering the said submission, the learned counsel for the
State has got no objection.
 3. Thus, I direct the petitioners to file representation along with a
copy of this order passed by this Court before the Circle Officer within
four weeks from today, if such application is filed the same should be
considered and appropriate order will be passed by the concerned
officer. If the entries made in respect of land of the petitioners needs to
be corrected, the same should be done thereafter immediately.
 4. With aforesaid observation, the instant writ petition is disposed
of.
