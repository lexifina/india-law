# Calcutta High Court, CRR/1240/2021, 2023-03-22

22.03.2023 IN THE HIGH COURT AT CALCUTTA
 Item No.37 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
C.R.R. 1240 of 2021

 Asgar Syed Ali @ Syed Ali Asgar
 versus
 The State of West Bengal
In Re: An Application under Section 401 read with Section
482 of the Code of Criminal Procedure.
Mr. Rudradipta Nandy,
Ms. Manisha Sharma … For the State.
The present revisional application has been preferred
for expeditious disposal of Domjur Police Station Case No.
896 of 2017 dated 17.10.2017.
The records of this revisional application reflect that
the first information report and the charge-sheet have only
been enclosed. None of the ordersheets of the learned trial
court has been enclosed for considering the stage of the case
before the learned trial court.
Having regard to the nature of the prayer so advanced,
I direct that the learned Magistrate will take appropriate steps
so that the case can be taken to its logical conclusion within
a reasonable period of time.
With the aforesaid observations, the revisional
application being CRR 1240 of 2021 is disposed of.
All pending connected applications, if any, are
consequently disposed of.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.

Urgent photostat certified copy of this order, if applied

requisite formalities.
 (Tirthankar Ghosh, J.)
