# High Court of Uttarakhand, WPMS/186/2013, 2013-02-28

WPMS No. 186 of 2013
Honíble Kalyan Jyoti Sengupta, J.
Mr. Neeraj Garg, Advocate, present
for the petitioner.
Mr. Piyush Garg, Advocate, present
for the respondents.
After hearing at length, learned
counsel for the petitioner upon instruction
submits that he does not want to press the
writ petition.
Accordingly, the writ petition is
dismissed as not being pressed. However,
when the argument is advanced, I feel that
some observation is required to be made.
This order will not prevent and prejudice
the petitioner before me to advance
argument on any point orally before the
learned revisional court, who will consider
and deal with the same in accordance with
law. If the practice and procedure permits
to file affidavit, it would be open, if so
advised, to file such affidavit. If the
practice and procedure does not permit
then obviously the petitioner is not entitled
to file such affidavit.
 (K.J. Sengupta, J.)
 28.02.2013
