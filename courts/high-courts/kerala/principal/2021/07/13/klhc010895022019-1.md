JUDGMENT
When this writ petition came up for
consideration, the learned counsel for the
petitioner submitted that, the construction of pipe
line for water connection is already completed.
The learned counsel for the petitioner submitted
that, the petitioner may be given liberty to file
it again, if there is any law and order issue.
Therefore, this writ petition is dismissed with
liberty to file it again, if there is any fresh
cause of action.
