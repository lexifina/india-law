CORAM : A.I.S. CHEEMA, J.
DATED : 31st July, 2014.
1. Heard learned A.P.P. Perused the application and
the judgment. Learned A.P.P. submits that, the
complainant was corroborated by panch Mali though
partially. According to A.P.P., the trap was complete and
the evidence was wrongly ignored.
2. Learned counsel for respondent seeks time. This
application is of 2013. There is no justification to adjourn
the matter. Request is declined.
3. Considering the application and the observations in
the judgment concerned, leave is granted. Application be
converted into Appeal.
4. Appeal is admitted.
5. Paper Book be got prepared.
6. Action under Section 390 of the Code of Criminal
Procedure be taken against respondent in the trial Court.
