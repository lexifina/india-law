# High Court of Uttarakhand, WPSS/1298/2015, 2020-02-12

Delay Condonation Application No. 3423 of 2019
Review Application No. 200 of 2019
In
WPSS No. 1298 of 2015
Hon’ble Alok Singh, J.
Mr. A.M. Saklani, Advocate for the
petitioner/ non applicant.
Mr. N.P. Sah, Standing Counsel for the State
of Uttarakhand / applicant.
There is delay of 210 days in filing the
review application. Reasons stated in the delay
condonation application are sufficient. Delay
condonation application is allowed. Delay in filing
the review application is condoned.
Facts mentioned in the review application
are already on record. No new ground has been
mentioned in the review application. Even otherwise,
Mr. N.P. Sah, learned Standing Counsel for the State
of Uttarakhand fails to point out any error apparent
on the face of record. Accordingly, review
application is dismissed.

 (Alok Singh, J.)
