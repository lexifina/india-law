This application has been filed by the applicant under Section 152 read
with Section 151 ofthe Code of Civil Procedure, 1908 seeking correction in the
judgment dated 19.03.2018 passed by this Court.
It is submitted that the number of the property has inadvertently been
typed as property no.30278 instead of 3078.
Notice. Counsels for the non-applicants/respondents accept notice.
The prayer made in this application is not opposed.
Accordingly, in the judgment dated 19.03.2018 wherever the number of
property has been shown as 30278, it shall be read as 3078.
Copy of this order be also provided if certified copy ofjudgment dated
19.03.2018 is applied for.
The application stands disposed of.
