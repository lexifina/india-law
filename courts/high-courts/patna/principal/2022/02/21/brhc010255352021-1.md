PANDEY
ORAL ORDER
6 21-02-2022 Vide impugned order dated 04.12.2020, the learned 5th
Additional Sessions Judge, Samastipur has rejected the restoration
petition filed by way of Misc. Case No. 30/2020 to set aside the order
dated 08.12.2019 passed in Misc. Case No.01/2016 dismissing that
Misc. Case No. 01/2016 in default of the petitioners.
The impugned order appears to be appealable under Order
43 of the Code of Civil Procedure, as such, this miscellaneous
petition is not maintainable, as the alternative statutory remedy is
available with the petitioners. Accordingly, it is dismissed.
