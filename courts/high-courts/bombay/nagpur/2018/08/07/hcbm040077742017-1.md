This is an application filed by the applicant-appellant for leave to
file appeal.
Heard the learned counsel for the parties. Perused the
application. I am satisfied that the leave needs to be granted. Hence,
leave is granted to file appeal challenging the judgment and award
passed by the learned Joint Civil Judge, Senior Division, Wardha in LAC
No.195/2007, decided on 3.8.2015.
The application stands disposed of.
CAF NO.152/2018
This is an application filed by the applicant for condonation of
delay.
Heard the learned counsel for the parties. Perused the
application.
For the reasons mentioned in the application, the delay of 449
days in filing the first appeal is hereby condoned.
The application stands disposed of.
