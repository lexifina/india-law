# High Court of Orissa, WP(C)/7347/2016, 2018-12-11

08. 11.12.2018 On 20.08.2018 the following order was passed:
 “Counter affidavit is taken on record.
 Rejoinder affidavit will be filed.
 The matter to come up on 03.09.2018.”

 Again on 20.11.2018 the following order was passed.
 “Learned counsel for the petitioner requests
for time.
 The matter to come up on 11.12.2018.”
 Even today learned counsel for the petitioner requests
for time to file rejoinder affidavit. We decline.
 Accordingly, the writ petition stands dismissed for
default.
 Learned counsel for the petitioner may file the
restoration petition within thirty days failing which the
restoration petition will not be considered.
