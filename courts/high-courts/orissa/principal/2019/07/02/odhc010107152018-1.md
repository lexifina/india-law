# High Court of Orissa, WP(C)/6189/2018, 2019-07-02

I.A. No.9139 of 2019
 26. 02.07.2019 Heard the petitioner in person.
 In this application the petitioner prays to withdraw the
writ petition with liberty to file better writ petition incorporating
all necessary facts.
 Permission is granted.
 Accordingly, the writ petition stands dismissed as
withdrawn with liberty to the petitioner to file better writ
petition.
 The I.A. is accordingly disposed of.
