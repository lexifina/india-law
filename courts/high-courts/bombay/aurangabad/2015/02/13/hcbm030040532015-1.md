# Bombay High Court, CA/1941/2015, 2015-02-13

...
PER COURT :-
1. This is an application for setting aside order passed by
the Registrar, refusing registration of the writ petition by order
dated 30/6/2014.
2. Considering the contentions raised in the application,
the application deserves to be allowed and the same is accordingly
allowed. The order passed by the Registrar dated 30/6/2014,
refusing registration of the writ petition is quashed and set aside.
Delay occurred in presenting the application stands condoned.
3. The petitioner shall remove office objections within a
period of four weeks from today. In the event of failure to comply
with the directions, the order passed in the instant civil application
shall be deemed to be recalled.
( SUNIL P. DESHMUKH, J. ) ( R. M. BORDE, J. )
