# High Court of Madhya Pradesh, MCRC/2260/2013, 2014-11-05

1
MCRC No.2260/2013
5.11.2014
Shri Pramod Meetha, learned counsel for the applicant.
Shri Ajay Bagadia, learned counsel for the respondent.
Shri A.S. Kutumbale, learned senior counsel with Shri
B.S. Gandhi, learned counsel for the complainant Bhavna
Kumari.
Heard counsel for the parties.
This application for recall of the order dated 28.2.2013
passed in M.Cr.C. No.1715/2013 is at the instance of the
State. This application was filed on 13.3.2013, thereafter
about one and half year has passed. The State had taken
repeated adjournment for as many as 22 times but the matter
has not been argued. Today inspite of the last opportunity,
the counsel for the applicant-State has failed to point out any
reason for recall of the order passed by this Court. On the
perusal of record it is noticed that this Court had passed the
order dated 28.2.2013 in M.Cr.C. No.1715/2013 after hearing
the counsel for the State as well as the counsel for the
applicant in that matter and considering the material which
was pointed out by counsel for the parties.
In these circumstances I do not find any ground for
recall of the order dated 28.2.2013 passed in M.Cr.C.
No.1715/2013.

2
Learned counsel appearing for the complainant submits
that the complainant also wants to file an application for
cancellation of bail based upon the subsequent event.
Since the scope of the application for recall of order is
different from application for cancellation of bail therefore, the
present M.Cr.C. is dismissed with liberty to counsel for the
complainant to file the application for cancellation of bail, if
he so desires which will be considered on its own merit.
C.C. as per rules.

 (Prakash Shrivastava)
