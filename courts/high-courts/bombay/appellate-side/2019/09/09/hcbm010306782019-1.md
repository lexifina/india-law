P.C. :
1. This applicant had filed bail application No.1158/19 and
this court vide order dated 22/08/2019 had granted him bail in
connection with C.R.No. I 267/18 registered with Pangari Police
station, Solapur. The present bail application No.1855/19 is filed for the
same relief. Since the applicant is already granted bail in connection
with the same offence, the present application does not survive and is
disposed of accordingly.
2. When this matter was called out, the learned counsel who
had filed this application was not present before the court to explain as
to why this application was filed.
