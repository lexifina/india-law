This is an application by which the applicant - State seeks leave
to file appeal against acquittal against the judgment of the Additional
Sessions Judge-3, Aurangabad, dated 10.8.2010, in Sessions Case No.
234 of 2006. We have heard the learned A.P.P. for the applicant and we
have perused the record and proceedings and upon such perusal,
according to us, this is a fit case for granting leave.
2. Accordingly, this application is allowed and leave as prayed for is
granted. Appeal stands admitted. Action under section 390 of the Code
