Hon'ble Rajan Roy,J.

Heard.
Admittedly, the order dated 31.07.2003 passed for demarcation
of Gata No.235, if implemented, would be in conflict with
another order dated 19.11.2018, which was passed for
demarcation of adjoining Gata No.234. The petitioner was
heard in the subsequent proceedings and being aggrieved, filed
an appeal, which was rejected, thereafter he preferred a Writ
Petition which is still pending. We fail to understand as to how
in these circumstances we can order implementation of the
order dated 31.07.2003 unless the subsequent order is set aside.
The petitioner should pursue the remedy in the pending Writ
Petition.
The Writ Petition stands disposed of.
