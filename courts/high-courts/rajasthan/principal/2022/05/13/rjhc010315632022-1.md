Order
13/05/2022
Instant misc. application has been filed by the petitioner-applicant seeking correction in the order dated 12.05.2022 passed
by this Court in SB Cr. Misc. Bail Application No.5599/2022 by
which the bail application was allowed.
Counsel for the petitioner-applicant submits that
inadvertently due to typographical error, in the order dated
12.05.2022 the FIR number has wrongly been mentioned as “CR
No.45/2022”, instead of “CR No.46/2022”. Counsel prays that
necessary correction be made in the order dated 12.05.2022,
passed by this Court.
In view of above submissions made and for reasons stated in
the application, the application is allowed. It is ordered that in the
order dated 12.05.2022, the FIR number be read as “CR
No.46/2022” instead of “CR No.45/2022”. To that limited extent,
the order dated 12.05.2022 passed by this Court in SB Cr. Misc.
Bail Application No.5599/2022 stands modified/corrected.
(MANOJ KUMAR GARG),J
