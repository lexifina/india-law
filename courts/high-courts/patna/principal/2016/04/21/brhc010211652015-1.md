ORAL ORDER
2 21-04-2016 Learned counsel, Mr. Chandra Kant, seeks
permission to withdraw this writ application with liberty to
convert this application to Miscellaneous Appeal according to the
provisions as contained in Order 43 Rule 1 Clause- R C.P.C.
According to the learned counsel, the prayer was
made for grant of injunction, which has been rejected, therefore,
the order is appealable.
In view of the submission of the learned counsel for
the petitioner, without going to the merits as to whether
miscellaneous appeal is maintainable or not, this application is
permitted to be withdrawn with liberty to file the appeal as
submitted. Accordingly, this writ application is dismissed as
withdrawn with the aforesaid liberty.
