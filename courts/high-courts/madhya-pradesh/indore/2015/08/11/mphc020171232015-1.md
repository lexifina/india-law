# High Court of Madhya Pradesh, MCRC/6335/2015, 2015-08-11

M.Cr.C. No.6335/2015
11.08.2015
Shri Manish Gupta, learned counsel for the
applicant.
Shri R.S. Parmar, learned P.L. for the
respondent/State.
Learned counsel for the State submits Penile
Doppler test report, according to which the results are
within normal limits indicating that the person is competent
of sexual intercourse.
After arguing the matter for sometime, learned
counsel for the applicant seeks to withdraw the application
with liberty to file a fresh application at an appropriate
stage.
Prayer is allowed.
The application is accordingly, dismissed as
withdrawn with the liberty as aforesaid.

( Alok Verma)
 Judge
