# High Court of Madhya Pradesh, WP/9631/2014, 2014-07-03

1
W.P. No.9631/2014
3/7/2014.
Shri Avinash Zargar, learned counsel
for the petitioner.
As the petitioner has a right to file a
second appeal against the impugned action i.e.
the order of assessment passed by the competent
Assessing Officer under Section 52(2), learned
counsel prays for permission to withdraw this
petition with liberty to file second appeal before
the competent authority under Section 46 of the
VAT Act.
Liberty is granted to the petitioner to
file second appeal as prayed for.
Petition is permitted to be withdrawn
with the aforesaid liberty.
It is accordingly dismissed as
withdrawn.
(Rajendra Menon) (Alok Verma)
