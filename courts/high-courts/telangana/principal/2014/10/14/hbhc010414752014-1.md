# High Court for the State of Telangana, TRCRLP/263/2014, 2014-10-14

HONOURABLE Dr. JUSTICE B.SIVA SANKARA RAO
Transfer Criminal Petition No.263 of 2014
ORDER :
Learned counsel appearing for the petitioner seeks permission of
this Court to withdraw the Criminal Petition with liberty to file a fresh
application with better particulars.
2. Permission as sought for is accorded.
3. Accordingly, the Transfer Criminal Petition is dismissed as
withdrawn with liberty to file fresh application, if necessary, with better
particulars.
4. As sequel to it, miscellaneous petitions pending if any in
this criminal petition, shall stand closed.
