Judge in allowing the Writ Petition No.9955/2022 by issuing various directions,
the instant writ appeal is filed by the respondents therein.
The writ petition was filed by the defendants aggrieved by order rejecting
his application under Order 7 Rule 11 of the Code of Civil Procedure for
dismissal of the suit on the ground that it has been undervalued. The learned
Single Judge set aside the order in the following terms:-
"Impugned order dated 23/112017 (Annexure P-5) is set
aside and trial court is directed to give opportunity to the
plaintiff to make necessary correction in the plaint for
doing proper valuation of the suit and if in the given time
it is not done, then pass appropriate order. It is further
directed that if valuation is made properly then trial court
can proceed further as per the pecuniary jurisdiction or
otherwise it may transfer to the Court which has pecuniary
jurisdiction to try the same.
With the aforesaid this petition is allowed."
Therefore liberty was granted to file an application for amendment and if
such an application is not filed, to dispose off the same by passing an
appropriate order and further if the valuation is made properly then the trial
court to proceed further with regard to the pecuniary jurisdiction of the
concerned court.
We do not find any ground to interfere in this matter. The order is clear
and unambiguous. The trial court would have to rehear the matter so far as
application under Order 7 Rule 11 of the Code of Civil Procedure is concerned.
However, learned counsel for the petitioner contends that the trial court is
insisting that he is bound to file an application under Order 6 Rule 17 of the
Code of Civil Procedure. We do not think that the order under challenge has
made such a reference. The order only indicates that a liberty be granted and if
