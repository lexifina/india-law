# High Court of Madhya Pradesh, MCC/1878/2015, 2015-08-03

MCC-1878-2015
(JAGDISH PRASAD Vs THE STATE OF MADHYA PRADESH)
03-08-2015
Shri R.M.Sharma, learned counsel for the applicants.
This application has been filed for restoration of Second Appeal
No.484/2014, which was dismissed on account of peremptory
order passed by this Court on 23/06/2014. There being some delay
in filing the application for restoration, I.A. No.8562/2015 has been
filed seeking condonation of delay. Both the applications are
supported by affidavit of the Shri K.K.Gautam, Advocate and there
is no reason to disbelieve the same. Finding the same to be
bonafide, both the applications are allowed.
Condoning the delay in filing the application, restoration
application itself is allowed.
Second Appeal No.484/2014 is restored to its original
number. It be placed for orders before appropriate Bench.
Application stands allowed and disposed of.
(VANDANA KASREKAR)
JUDGE
