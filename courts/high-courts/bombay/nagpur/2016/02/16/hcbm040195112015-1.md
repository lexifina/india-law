 -----
 CORAM : A.B. CHAUDHARI, J.
DATE : 16th February, 2015
This is Misc. Civil Application to restore Second Appeal No.
393 of 2013 which automatically stood dismissed on 8th June, 2015 as
per the order dated 26th March, 2015 on failure to file a private paper-book.
Accepting the reasons offered in the application explaining
the situation which led to dismissal of the Second Appeal to be
satisfactory, Misc. Civil Application is allowed. Second Appeal No. 393
of 2013 is restored to its file.
 -----
Second Appeal No. 393 of 2013 :
The appellant to file a paper-book within four weeks from
today, if not already filed.
