Mr. Trivedi, learned advocate appearing for the petitioner do not
intend to press the present revisional application as he has instructions to
pursue the remedy with the subsequent charge-sheet which has been filed
in connection with the instant case.
Mr. Bapuli, learned Additional Public Prosecutor appears on behalf
of the State.
In view of the prayers so advanced, C.R.R. 2223 of 2021 is dismissed
as not pressed.
Pending applications, if any, are consequently disposed of.
Written instructions so submitted be kept with the record.
Accordingly, the revisional application is disposed of with liberty to
file afresh in respect of the charge-sheet which has been filed in connection
with the instant case.
All parties are directed to act on the server copy of this order
downloaded from the official website of this Hon’ble Court.
