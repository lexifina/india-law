# High Court of Madhya Pradesh, MCC/581/2016, 2016-02-18

1
M.C.C.No.581 of 2016
18.02.2016
 Shri A.D.Mishra, learned counsel for the applicant.
 Shri Amit Seth, learned Govt. Advocate for the
respondent/State.
 Heard counsel for the parties.
 This application is filed for restoration of MCC which
was dismissed for non-prosecution vide order dated
10.02.2016.
 For the reasons mentioned in the application and as the
litigant should not suffer for the mistake of the Advocate, in
the interest of justice, the order passed on 10.02.2016
dismissing the MCC for non-prosecution is recalled.
Accordingly, MCC is allowed.
MCC No.499/2016 is restored to the file to its original
number.
MCC No.499/2016 restored in terms of this order is
taken up for hearing forthwith, by consent.
