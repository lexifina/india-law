ORDER
In this petition, the revision petitioners have filed an application to set
aside an exparte decree along with an application to condone the delay
of 1,746 days. This application was returned by the Court.
2. The learned counsel for the petitioner submitted that the returned
application was taken on file.
3. The learned counsel for the respondent would now intervene and
submit that as per his instruction, the petitioners have not even taken
the returned application for complying with the defects.
4. The petitioners are directed to approach the trial court with
appropriate application for condoning the delay either by representing
the delay for the returned application or file a fresh application and
work out their remedy before the trial court. For the present, there is
no order before this Court, from which, a case for interference by this
Court is made out.
http://www.judis.nic.in

3
5. With the above direction, this Revision Petition is disposed of. No
costs. Consequently, connected miscellaneous petition is closed.
