ORDER
1. This Criminal Original Petition is filed praying to quash the proceedings
in C.C.No. 2121 of 2019 on the file of Judicial Magistrate No.1, Coimbatore.
2. Today, when the matter came up for hearing, the learned counsel for
petitioner has filed a memo submitting that the case has became infructuous. In
view thereof, this Criminal Original Petition is having became infructuous.
Needless to mention that if the necessity arises, the petitioner can file an
appropriate application before this court if the case is restored.
3. With the above observation, this Criminal Original Petition stands
accordingly dismissed as infructuous. Consequently, connected Criminal
Miscellaneous Petition is closed
