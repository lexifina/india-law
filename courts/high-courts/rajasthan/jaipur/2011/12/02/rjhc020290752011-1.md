# High Court of Rajasthan, CRLMB/10510/2011, 2011-12-02

S.B. Criminal Misc. IInd Bail Application
No.10510/2011
(Mangal @ Kaptan Versus State of Rajasthan)
Date of Order :: 2nd December, 2011
HON'BLE MR. JUSTICE MAHESH BHAGWATI
Mr. Girish Khandelwal, Counsel for the petitioner
Mr. G.S. Fauzdar, PP for the State of Rajasthan
Learned counsel for the petitioner
submits that all the prosecution witnesses have
turned hostile and they have not supported the
case of the prosecution.
This is second bail application. The
first bail application was dismissed by this Court
on 17th February, 2011. Hence, learned counsel for
the petitioner is directed to first file the bail
application before the learned trial court and
thereafter if needed, he may come to the High
Court.
With the afore-stated observations, the
second bail application stands disposed of.

 (MAHESH BHAGWATI), J.
