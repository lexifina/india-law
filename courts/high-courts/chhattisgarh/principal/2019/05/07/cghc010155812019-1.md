OFFICE REFERENCE
Hon'ble Shri Justice Sanjay Agrawal
 Order On Board
07.05.2019
1. This is an Office Reference for modification/correction in the order dated
19.09.2011 passed in W.P.(S) No. 5551/2011 as due to inadvertence petitioner's
name “Fhirat Lal Sahu” has been mentioned as “Khusiram Sahu” in the cause
title.
2. The aforesaid error in the order dated 19.09.2011 is apparent on the face
of record, and therefore, needs to be corrected. It is made clear that petitioner's
name “Khusiram Sahu” appearing in the first page of the order shall now be read
as “Fhirat Lal Sahu”.
3. The Office Reference stands disposed of with modification in the order
dated 19.09.2011 to the above extent. A copy of this order be supplied to the
parties along with the copy of order dated 19.09.2011. Sd/-
 (Sanjay Agrawal)
