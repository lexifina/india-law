# High Court for the State of Telangana, WP/13022/2014, 2014-04-28

HONOURABLE SRI JUSTICE ASHUTOSH MOHUNTA
AND
HONOURABLE SRI JUSTICE M. SATYANARAYANA MURTHY
WRIT PETITION No.13022 OF 2014
ORDER : (Per Hon’ble Sri Justice Ashutosh Mohunta)
The petitioner has impugned the penalty order dated
09.04.2014 passed under Section 53 (1) (i) of Andhra Pradesh
Value Added Tax Act, 2005, (for short the ‘A.P.VAT Act’) for the
assessment year 2012-2013.
Learned counsel for the petitioner states that against the
assessment order for the year 2012-2013, an appeal was filed by the
petitioner in which the assessment order has been set aside and the
matter has been remanded back to the original authority.
Learned counsel further submits that as the assessment order
has been set aside, the penalty orders are also liable to be set aside.
The aforementioned facts are not disputed by the learned
counsel for the respondent.
A copy of the order dated 24.04.2014 passed by the Appellate
Deputy Commissioner (CT), Secunderabad, has been filed.
A perusal of the aforesaid order shows that the assessment
order has been set aside and the case has been remanded back to
the original authority.
In view of the above, the penalty order dated 09.04.2014
passed under the A.P.VAT Act is also set aside.
With the above observation, the writ petition is allowed. There
shall be no order as to costs.
Miscellaneous Petitions pending, if any, shall stand closed.
