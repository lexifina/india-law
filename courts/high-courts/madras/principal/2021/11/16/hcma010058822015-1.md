ORDER
This Criminal Original Petition has been filed to quash the
Crime No.2177 of 2014 pending on the file of the first
respondent police.
2. The learned Government Advocate (Crl. side) appearing
for the first respondent would submit that now final report has
been filed in Crime No.2177 of 2014 and the same has been taken
cognizance as C.C.No.28 of 2018 and the same is pending before
the Mahila Court, Egmore.
https://hcservices.ecourts.gov.in/hcservices/

3. Considering the fact that already final report has been
filed, and the matter is pending for trial, at this stage, the
First Information Report in Crime No.2177 of 2014 cannot be
quashed.
4. In view of the above, this Criminal Original Petition
is dismissed. Consequently, connected miscellaneous petition is
closed.
