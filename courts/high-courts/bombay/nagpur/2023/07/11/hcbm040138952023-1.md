This is an application under Section 439 of the Code
of Criminal Procedure for grant of bail.
2. After hearing the learned counsel to some extent and
on perusal of the investigation papers, when this Court
shown its disinclination to grant bail, learned counsel for the
applicant, on instructions, seeks permission to withdraw the
application with liberty to file fresh if the trial is not
commenced within six months.
3. Considering the submissions, trial is expedited and the
applicant is at liberty to move afresh before this Court if
there is no substantial progress in the trial within six months.
With this, the application is dismissed as withdrawn.
