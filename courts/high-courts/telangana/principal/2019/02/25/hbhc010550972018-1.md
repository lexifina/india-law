# High Court for the State of Telangana, WP/26096/2018, 2019-02-25

HONOURABLE SRI JUSTICE SANJAY KUMAR
Writ Petition No.26096 of 2018
ORDER:
 Sri Unnam Muralidhar Rao, learned counsel for the petitioner,
addressed letter dated 20.02.2019 to the Registry seeking
permission to allow his client to withdraw the present Writ Petition
with leave to file a fresh Writ Petition, if necessary.
 Sri K.Nikhil, learned counsel representing Sri Unnam
Muralidhar Rao, learned counsel for the petitioner, reiterates this
request in person.
 The Writ Petition is accordingly dismissed as withdrawn with
the liberty aforestated.
Miscellaneous Petitions pending, if any, in this Writ Petition
shall also stand dismissed. No order as to costs.
 ________________________
JUSTICE SANJAY KUMAR
