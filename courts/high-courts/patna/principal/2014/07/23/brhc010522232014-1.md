CORAM: HONOURABLE MR. JUSTICE JYOTI SARAN
ORAL ORDER
2 23-07-2014 This application has been filed for restoration of Cr.Rev.
No. 138 of 2012 which stood dismissed for non compliance of the
order dated 11.3.2014 which required the petitioner to carry out
the order passed on 19.12.2013 requiring the petitioner to convert
the criminal revision into a miscellaneous appeal within one week
peremptory. Since the order was not carried hence the Criminal
Revision No.138 of 2012 stood dismissed.
Having heard learned counsel for the parties and
considering the reasons assigned, the peremptory period granted
under order dated 11.3.2014 is extended upto 5.8.2014 before
which date the counsel for the petitioner would carry out the order
dated 19.12.2013 failing which this order would stand recalled.
This application is accordingly allowed with the direction
aforementioned.
Bibhash/-
 (Jyoti Saran, J)
