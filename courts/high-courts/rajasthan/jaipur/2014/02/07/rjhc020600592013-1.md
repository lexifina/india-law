# High Court of Rajasthan, CMA/1107/2013, 2014-02-07

SB Civil Misc. Appeal No.1107/2013
HON'BLE MR. JUSTICE ALOK SHARMA
7.2.2014
Mr.R.N. Vijay for the appellant
Mr. Madhu Sudan Shiromani Sharma for the
respondent
An application (inward No.
1425/13.1.2014) has been filed for withdrawal
of this misc. appeal in view of the
settlement between the parties. Along-with
the application settlement deed dated
20.12.2013 has been filed.
Consequently, the application is
allowed. The settlement deed dated 20.12.2013
is taken on record.
Resulting from the application for
withdrawal having been allowed, this civil
misc. appeal is dismissed as withdrawn.
(Alok Sharma) J
