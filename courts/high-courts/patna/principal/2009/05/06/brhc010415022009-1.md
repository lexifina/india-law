# Patna High Court, CR. MISC./15640/2009, 2009-05-06

MD.AJAMUL HUSSAIN,son of Hafij Khalilur
Rahman,resident of village-Madarganj,P.S.-
Simraha,District-Araria.
 Versus
 STATE OF BIHAR
 -----------
02/ 06-05-2009 Heard learned counsel for the petitioner and the State.
Petitioner is denying furnishing of the mark sheet, which
was found forged but there can be no substance in the submission as
process was there. Petitioner applied with documents, basing which he
was selected also. Only on complaint made by some one, this forgery
could be detected. So assuming innocence of the petitioner, no relief
can be provided to him.
Accordingly, this petition for anticipatory bail is rejected.
 AH/ ( Mandhata Singh, J. )
