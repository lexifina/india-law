# High Court of Orissa, BLAPL/6924/2015, 2016-03-11

BLAPL No.6924 of 2015
Misc. Case No.152 of 2016 11.03.2016
 Heard learned counsel for the petitioner and learned counsel for the State.
 This Misc. Case has been filed with a prayer for permission to take back the certified c
opy of the order dated 08.10.2015 passed by the learned Sessions Judge, Nayagarh, which was fi
led by the petitioner along with the bail application since he has to file a revision against
such order. The said document has been annexed to the bail application as Annexure-1.
 The Misc. Case is allowed.
 The original certified copy of the impugned order may be returned to the petitioner, on
substitution of the same by a true photo copy.
 Urgent certified copy of this order be granted on proper application.
