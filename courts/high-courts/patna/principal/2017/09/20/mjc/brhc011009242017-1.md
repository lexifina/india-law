ORAL ORDER
3 20-09-2017 This application has been filed for restoration of
C.W.J.C. No.177/2017 which stood dismissed for non-compliance of order dated 08.03.2017, which was eventually
complied on 17.03.2017, according to the petitioner.
On being satisfied with the reasons mentioned in this
application explaining omission on part of the petitioner, the
date of compliance of order dated 08.03.2017 is extended till
17.03.2017 and the C.W.J.C. No.177/2017 is restored to its
original file and number subject to the condition that the order
dated 08.03.2017 has fully been complied by 17.03.2017.
Accordingly, this application stands allowed.
