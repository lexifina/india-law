ORAL ORDER
3 13-12-2013 This writ application is dismissed taking into consideration
the fact that Bhojpuri Academy does not have any provision or
service condition providing for post retiral dues like pension,
gratuity etc. The society is a registered society and it has its own
terms and conditions of service.
The stand of the learned senior counsel representing the
petitioner that it is a State because funding is done by the State is
not required to be answered in this writ application. Petitioner,
however, is free to file writ application for appropriate declaration
and direction upon the State or the Academy to make provisions
