1. This matter is pending since 2017 for
quashment of First Information Report. The stay was
granted to the effect not to file charge-sheet. However, with
the lapse of a period in between and investigation is over,
hence the application came to be filed for permission to file
charge-sheet.
2. Considering the nature of offence and the
allegations, we are of the opinion that the State shall be
permitted to file charge-sheet. Accordingly, the application
is allowed.

CRIMINAL APPLICATION (APL) NO.723/2017
1. Since this Court has permitted the State to file
charge-sheet and as in the present matter, the challenge is
raised to the First Information Report only, the learned
Counsel for the applicants seeks permission to amend the
application to raise a challenge to the charge-sheet.
However, we are of the opinion that a purpose would be
served if the present application is disposed of with liberty
to the applicants to file afresh raising a challenge to the
charge-sheet, if the applicants so desire.
2. Accordingly, the application is disposed of with
liberty to the applicants to file afresh raising a challenge to
the charge-sheet if the applicants so desire or the applicants
may take any other recourse as available in the law.
