Order No.
ORDER
25.09.2024
01. 1. This matter is taken up through Hybrid Arrangement
(Virtual/Physical) Mode.
2. Heard learned counsel for the parties.
3. Petitioner has filed the present Writ Petition
challenging order dated 12.09.2024, so issued by O.P.
No.2 wherein petitioner has been removed as Sarapanch
of Paikbahal Gram Panchayat. But a wrong prayer has
been made that vide order dated 12.09.2024, petitioner
has been placed under suspension.
4. Be that as it may, since the impugned order is an
appealable one, this Court is not inclined to entertain the
Writ Petition. It is open for the petitioner to file
