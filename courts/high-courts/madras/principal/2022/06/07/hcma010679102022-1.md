# Madras High Court, CRL OP/10855/2022, 2022-06-07

Palladam Police Station,
Tiruppur District.
Crime No.22/2021 ... Respondents
Prayer: This Criminal Original Petition filed under Section
482 Cr.P.C. to issue a direction directing the respondent
herein to file a final report in First Information Report in
Cr.No.22 of 2021 on the file of the respondent herein within
time frame to be stipulated by this Hon'ble Court.
For Petitioner : Mr.G.Mageshkumar
For Respondents : Mr.A.Gokulakrishnan
 Additional Public Prosecutor
ORDER
This Criminal Original Petition has been filed to direct
the respondent herein to file a final report in First
Information Report in Cr.No.22 of 2021 on the file of the
respondent herein within time frame to be stipulated by this
Court.
2. Heard the learned counsel appearing for the petitioner
and the learned Additional Public Prosecutor appearing on
behalf of the respondent.
3. The learned counsel appearing for the petitioner would
submit that though the respondent has registered a case in the
Crime No.22 of 2021 on 04.01.2021, no final report is filed
till date.
4. Mr.A.Gokulakrishnan, learned Additional Public
Prosecutor appearing for the respondent would submit that the
respondent police may be permitted to file a final report
within a period of four weeks.
5. In view of the above, the respondent police is
directed to file a final report within a period of four weeks
from the date of receipt of a copy of this order under due
intimation to the defacto complainant.
https://hcservices.ecourts.gov.in/hcservices/

6. With the above direction, this Criminal Original
Petition is disposed of.
