04. 1. This matter is taken up through Hybrid Arrangement (Virtual
/Physical Mode).
 2. Challenging show cause notice under Annexure-6, the
present Writ Petition has been filed. Although the Writ Petition was
filed in the year 2013, the same is pending till now for final
adjudication. On perusal of the order sheets, it appears that the matter
was last listed on 14.03.2013 and thereafter it has not been listed.
 3. Considering the fact that the Petitioner has assailed only a
show cause notice, this Court is of the considered view that there is
no meaning for keeping this matter here.
 4. Accordingly, the Writ Petition is disposed of by granting
liberty to the Petitioner to file reply to the show cause if the same has
not already been filed. In the event show cause is filed, the same
