CORAM: HONOURABLE MR. JUSTICE MUNGESHWAR SAHOO
ORAL ORDER
2 18-05-2016 Heard learned counsel for the petitioner.
Perused the order passed by the learned A.D.J. IX,
Chapra at Saran dated 10.02.2016 in Title Appeal No.41 of 1996-
784 of 2014. The learned court below rejected the application
under Order 41 Rule 27 of the Code of Civil Procedure recording
a clear finding that in this present case none of the clauses
enumerated in Order 41 Rule 27 of the Code of Civil Procedure is
applicable and considering various decisions of the High Court as
well as the Supreme Court passed a reasoned order rejecting the
application under Order 41 Rule 27 of the Code of Civil
Procedure. Therefore, the order cannot be said to be illegal or the
order is passed in the manner not permitted by law. Therefore, I
find no reason to interfere with the impugned order.
Thus, this application is dismissed.
Harish/- (Mungeshwar Sahoo, J)
