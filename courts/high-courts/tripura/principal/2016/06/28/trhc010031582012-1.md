# High Court of Tripura, MAC App./126/2012, 2016-06-28

Case No :MAC App. 0000126/2012
Party Name : NIRMAL DEBNATH Vs RATAN SUTRADHAR & ANR
THE HONBLE THE CHIEF JUSTICE (ACTING)
Heard Mr. S.D. Choudhury, the learned counsel for the respondent-insurer.
No representation from the appellant.
Apparently, there has been no representation from the appellant for some time so much so that this
Court by the order dated 29.3.2016 observed that no further adjournment should be granted.
As the appellant is still unrepresented, the appeal is dismissed in default of prosecution.
