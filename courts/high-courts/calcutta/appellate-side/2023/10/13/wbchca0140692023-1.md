# Calcutta High Court, CRR/1074/2023, 2023-10-13

D/L14
13.10.2023
Bpg.
 C.R.R.1074 of 2023
In Re: An application under Sections 397/401 read with Section 482 of
the Code of Criminal Procedure, 1973;
 Mr. Laxminarayan R. Bhattad and another
 Versus
 The State of West Bengal and another
 Mr. Pawan Kumar Gupta
 Mr. Ganesh N. Jajodia
 Ms. Sofia Nesar
 Mr. Santanu Sett.
 …for the petitioners.
Mr. Gupta, learned advocate appearing for the petitioners
do not intend to press the present revisional application as there are
some technical issues involved in the vakalatnama filed before this
Court. Petitioners pray for liberty to file afresh on the same points.
In view of the prayer so advanced, CRR 1074 of 2023 is
dismissed as not pressed.
Petitioners are granted liberty to file afresh on the same
issues.
Department is directed to return the certified copy to the
learned advocate on record of the petitioners on the same being
replaced by photostat copy.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
 (Tirthankar Ghosh, J.)
