2.
Ayas
27.06.2019 Heard Shri G. Misra, learned
counsel for the petitioners and
Shri B. Behera, learned Additional
Standing Counsel for the State-opposite parties.
 Considering the request of
Shri G. Misra, learned counsel for
the petitioner, this Court permits
the petitioner to withdraw this Writ
Petition with liberty to file a fresh
Writ Petition involving the Caveator.
 Accordingly, this Writ Petition
stands disposed of as withdrawn
but with the liberty as prayed for.

learned counsel for the petitioner is
permitted to take return the
certified copy of the impugned order
by substituting a true Xerox copy
thereof.
