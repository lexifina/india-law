# Allahabad High Court, BAIL/37027/2023, 2023-08-29

Neutral Citation No. - 2023:AHC:174435
Court No. - 48
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 37027
of 2023
Applicant :- Dipanshu Sharma
Opposite Party :- State of U.P.
Counsel for Applicant :- Abhishek Mayank
Counsel for Opposite Party :- G.A.
Hon'ble Saurabh Shyam Shamshery,J.
This is second bail application on behalf of applicant.
The first bail application of applicant was rejected by this Court
by a reasoned order dated 16.05.2023.
Heard Sri Abhishek Mayank, learned counsel for the applicant.
The applicant has approached this Court by way filing the
present Criminal Misc. Bail Application under Section 439
Cr.P.C. in Case Crime No. 1457 of 2021 under Sections 302,
201, 34 IPC, P.S. Kavinagar, District Ghaziabad.
Learned counsel for the State submits that no subsequent event
is mentioned in the application, which could be considered for
the purpose of second bail application.
I have carefully perused the application and I found substance
in the argument of learned counsel for the State that no
subsequent event is mentioned in bail application. Counsel for
applicant has not been able to contradict above submission.
This bail application is accordingly rejected.
Learned trial Court is directed to conclude the trial
expeditiously.
Order Date :- 29.8.2023
A. Tripathi Digitally signed by :-
AKHILESH TRIPATHI
High Court of Judicature at Allahabad
