# High Court of Jharkhand, WPC/850/2014, 2016-02-11

IN THE HIGH COURT OF JHARKHAND AT RANCHI.

CORAM THE HON'BLE MR. JUSTICE PRASHANT KUMAR
 -----
 For the Petitioner : Mr. Rajeev Ranjan
 For the Respondents : JC to AG
 -----
03/11.02.2016. In this writ application, the petitioner has prayed
for quashing the entire departmental proceeding initiated vide
order dated 04.03.2013 passed by respondent no.3, on the
ground that for the same set of allegation, a criminal case vide
Kairo P.S. case no. 04/2013 is pending.
It is well settled that for the same set of allegation,
a departmental proceeding as well as criminal case can run
simultaneously.
Under the said circumstance, I find no merit in this
writ application. Accordingly, the same is dismissed.
 ( Prashant Kumar,J.)
