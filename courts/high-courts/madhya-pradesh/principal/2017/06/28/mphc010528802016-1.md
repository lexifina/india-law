# High Court of Madhya Pradesh, CR/380/2016, 2017-06-28

CR-380-2016
(KAILASH SONI Vs RAJESH KUMAR SHARMA)
28-06-2017
None for the applicant.
Mr. R.P. Dwivedi, learned counsel for the respondent.

application under Order 7 Rule 11 of the Code of Civil
Procedure.
Learned counsel for the respondent submits that the suit
itself has already been decided.

is dismissed as rendered infructuous.
