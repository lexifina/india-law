# High Court of Madhya Pradesh, MCRC/12051/2017, 2017-07-21

MCRC-12051-2017
(MANOJ Vs THE STATE OF MADHYA PRADESH)
21-07-2017
Ms. Neetu Prajapati, learned counsel for the applicants.
Shri Vivek Lakhera, learned Panel Lawyer for respondent-State.
This application has been filed for modification of order
dated 07.07.2017, passed in M.Cr.C. No.9719/2017.
Learned counsel for the applicants submits that in the order
dated 07.07.2017, passed in M.Cr.C. No.9719/2017, Crime
number is mentioned as Crime No.217/2017 while the correct
one is Crime No.257/2017.
Considering the aforesaid, this application is hereby
allowed.
It is ordered that in the order dated 07.07.2017, passed in
M.Cr.C. No.9719/2017, "Crime No.217/2017" be read as "Crime
No.257/2017".
In view of above, M.Cr.C. stands disposed of.
(H.P. SINGH)
JUDGE
