# High Court of Madhya Pradesh, CONC/1460/2016, 2017-03-28

CONC-1460-2016
(A.S. ANSARI Vs THE STATE OF MADHYA PRADESH)
28-03-2017
Shri Mukesh Mishra, learned counsel for the applicant.
Shri Amit Seth, learned counsel for the respondent no.2.
Counsel for the respondent no.2 submits that the order
passed by this Court has been complied with.
Counsel for the applicant submits that the order has not
been fully complied with.
In view of the submission made by counsel for the
respondent no.2, I do not find any case for contempt of the Court.
The contempt petition is dismissed.
Rule nisi is discharged.
However, applicant is granted liberty to raise the grievance
if any survives in accordance with law if so advised.
C.C as per rules.
(VIJAY KUMAR SHUKLA)
JUDGE
