# High Court for the State of Telangana, CC/173/2015, 2023-02-02

THE HONíBLE SRI JUSTICE C.V. BHASKAR REDDY
Contempt Case No.173 of 2015
ORDER:
This Contempt Case is filed by the petitioners for not
implementing the order passed by this Court in WP No.35890
of 2014 dated 25.11.2014.
2. Sri P. Sridhar Rao, learned counsel appeared for
respondents.
3. Sri Saketh, learned counsel appearing for petitioners
has fairly submitted that after filing the Contempt Case, the
respondents have implemented the orders passed by this
Court and the cause in the Contempt Case is no more
survives for adjudication.
4. Recording the said submission, the Contempt Case is
closed. No costs. However, liberty is given to the petitioner
to file appropriate petition if the contempt survives.
 As a sequel, miscellaneous applications pending if any
in this Contempt Case, shall stand closed.

 C.V. BHASKAR REDDY, J
