PER COURT :
1. This is an application for vacating /
modifying / clarification of the order dated
22nd October, 2010. The said Civil
Application is disposed of. If any order is to
be modified same would amount to a
review. So, unless the applicant files a
review application the same cannot be
considered, as the case does not fall within
the ambit of 39 Rule 4 of Civil Procedure
Code.

2
C.A. No. 16861.10
3. In that light of the matter, Shri P.V.
Mandlik, learned Sr. counsel seeks to
withdraw the application, with liberty to file
appropriate application for review.
4. Shri Kureshi, learned counsel for the
respondent No. 12, opposes the request.
However, taking into consideration the
above conspectus, the applicant is allowed
to withdraw the application, with liberty to
file appropriate application for review.
