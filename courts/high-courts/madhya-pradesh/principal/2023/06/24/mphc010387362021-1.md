This petition coming on for conciliation this day, the Bench passed the

ORDER
This petition arises out of transfer order dated 31.08.2021 passed by the
C.E.O., Jila Panchayat, Sidhi, M.P., which has since been stayed by this Court
vide interim order dated 16.09.2021 which is still subsisting.
2. The State has no objection if this petition is disposed of.
3. Accordingly, the impugned order of transfer is quashed and liberty is
granted to the State to pass fresh order in accordance with law.
4. With the consent of parties, the petition stands disposed of.
