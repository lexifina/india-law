# High Court of Madhya Pradesh, MCC/2922/2014, 2015-02-06

1
MCC No.2922/2014
6/2/2015.
Shri R. S. Verma, learned counsel for
the applicant.
While restoring W.P. No.1241/2014 vide
order dated 14.1.2015 passed in MCC
No.2922/2014, the number of the case has been
written as W.P. No.2922/2014 instead of
W.P.1241/2014.
Keeping in view the aforesaid, this
application is allowed. It is clarified and ordered
that what was restored on 14.1.2015 in MCC
No.2922/2014 was W.P. No.1241/2014 and not
W.P. No.2922/2014 as indicated therein.
The aforesaid correction be made.
With the aforesaid, this application
stands allowed and disposed of.
(Rajendra Menon) (S. K. Gangele)
