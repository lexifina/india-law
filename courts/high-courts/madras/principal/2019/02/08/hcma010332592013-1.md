O R D E R
Aggrieved over the dismissal of the Interlocutory Application filed for
marking the interim Order passed in W.P.No.2884 of 2011 in an application filed
under Order IX Rule 13 of Code of Civil Procedure, this revision came to be filed.
2. The main contention of the revision petitioner is that the trial Court has
simply rejected the interim Order sought to be marked in the application filed
under Order IX Rule 13 of Code of Civil Procedure and the interim Order has to
be marked to show the conduct of the parties. Therefore, the same has to be
allowed.
3. Whereas, the learned counsel for the respondent submitted that the
Writ Petition itself has been disposed of wherein the second respondent in the
Writ Petition had made an undertaking that he is not going to lay road in the suit
property. Since the main Writ Petition itself has been disposed of, the interim
Order passed in the Writ Petition is not at all necessary in the application filed
under Order IX Rule 13 Code of Civil Procedure to set aside the exparte decree.
Order IX Rule 13 petition has to be dealt with independently and in the event of
the petitioner succeeding in the petition filed under Order IX Rule 13 of CPC,
http://www.judis.nic.in

3
the petitioner can very well rely on the final Order of the Writ Petition.
4. In view of the above submissions, this Civil Revision Petition is
dismissed and the Order of the trial Court in I.A.No.333 of 2012 in I.A.No.419 of
2010 in O.S.No.76 of 2009 is confirmed. Consequently, the connected
miscellaneous petition is closed. No cost.
