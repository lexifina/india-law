# High Court of Madhya Pradesh, WP/14109/2013, 2014-08-27

Page no 1
W.P. no. 14109/2013
27/08/2014
Mr. S.N. Vyas, learned counsel for the petitioner.
We find that the issue involved in this writ
petition has become stale and only academic. The Hon'ble
Supreme Court has repeatedly observed that the matter need
not be decided only for academic purpose.
In the circumstance, we dismiss the writ petition
as rendered infructuous.
C c today.
 ( SHANTANU KEMKAR ) ( M.C. GARG )
