# Gauhati High Court, AB/3030/2012, 2012-08-21

AB 3030/2012
BEFOREL
HON’BLE MR JUSTICE UJJAL BHUYAN
Heard Mr KR Patgiri, learned counsel for the petitioners.
This is an application under Section 438 of the Code of Criminal Procedure, 197
3, for grant of pre arrest bail to the petitioners, namely, 1) Abdus Samad @ Abd
ul Samad 2) Md Kurban Ali and 3) Najira Khatun apprehending arrest in con
nection with Kalgasia PS Case No. 30/2012 (GR case No.419/201
2) under Sections 120(B)/468/420/406/323/294/506 IPC .
This Court by order dated 9.8.2012 while calling for the case diary had granted
interim pre arrest bail to the petitioners.
Mr Munir, learned Addl. PP, Assam, submits that charge-sheets have been submit
ted in this case.
In view of the above, interim pre arrest bail granted on 9.8.2012 is hereby made
absolute.
Bail application is disposed of.
