# High Court of Madhya Pradesh, WP/12088/2016, 2017-07-31

WP-12088-2016
(PRASHANT SINGH CHAUHAN Vs THE STATE OF MADHYA PRADESH)
31-07-2017
Mr. H.K. Golhani, learned counsel for the petitioner.
Mr. Vikram Johri, learned P.L. for the State.
Mr. Jorhi, leaned P.L. at the threshold submits that by order
dated 28.11.2016 (Annexure-R/1) the impugned order has been
cancelled and therefore this petition has rendered infructuous.
Mr. Golhani, learned counsel for the petitioner pointed out
that impugned order is dated 30.06.2016, whereas the order
allegedly cancelled is dated 01.07.2016.
Faced with this Mr. Jorhi, categorically submits that
Annexure-P/1 has been cancelled, which is clear from order
annexed as Annexure-R/1. Thus, his statement is that the
impugned order (AnnexureP/1) has been cancelled.
Considering the aforesaid statement nothing remains to be
adjudicated in this matter.
Petition is dismissed having rendered infructuous.
(SUJOY PAUL)
