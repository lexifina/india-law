1. The learned counsel for the applicant submits that
during the pendency of this application, charge-sheet has
already been filed.
2. He therefore, seeks leave to amend the application
to challenge the charge-sheet as well.
3. Mr. Gopal Lahoti, learned counsel for the non-applicant No.2 submits that the applicant can file a fresh
application to challenge the charge-sheet and therefore, no
leave to amend this application may be granted.
4. We have considered the objection.
5. According to us, if a fresh application is
maintainable to file the charge-sheet as well as the First
Information Report, which is already being challenged in this

2 17.Cri.APL No.996.19
application, there is no good reason not to grant leave to
amend this application. Adoption of such a course will in fact
prevent multiplicity.
6. Accordingly, leave is granted to amend this
application.
7. The amendment to be carried out within one week
from today. Copy of the same to be furnished to the learned
counsel for the non-applicants.
8. If the non-applicants wish to file any reply to the
amended application, they are at liberty to file the same
within two weeks thereafter.
9. The application seeking leave to amend the
original application is hereby disposed of.
