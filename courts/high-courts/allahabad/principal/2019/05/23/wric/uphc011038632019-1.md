# Allahabad High Court, WRIC/17627/2019, 2019-05-23

Court No. - 29
Case :- WRIT - C No. - 17627 of 2019
Petitioner :- Devi Singh
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Shyam Murari Upadhyay
Counsel for Respondent :- C.S.C.,Pranjal Mehrotra
Hon'ble Pankaj Mithal,J.
Hon'ble Prakash Padia,J.
Heard learned counsel for the petitioner and Sri Pranjal
Mehrotra, learned counsel appearing for the respondents
no.2 and 4.
A perusal of the petition reveals that there is probably no
cause of action for the petitioner to file the petition at this
stage.
Learned counsel for the petitioner submits that the writ
petition may be dismissed as withdrawn with the liberty to
file fresh petition.
The writ petition is dismissed as withdrawn, at this stage,
with the liberty aforesaid.
