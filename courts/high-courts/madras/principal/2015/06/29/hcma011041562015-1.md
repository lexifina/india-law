Vs
State rep. by

Kodungaiyur, Chennai-118. ... Respondent
Criminal Original Petition filed under Section 482 of Cr.P.C.,

 For Petitioner : No Appearance
 For Respondent : Mr.C.Emalias, Addl. Public Prosecutor

 O R D E R
 This petition has been filed to direct the respondent to file
final report in connection with Crime No.74 of 2011 on the file of
the respondent police within the stipulated time.
2. Heard the learned Additional Public Prosecutor appearing for
the respondent and perused the materials placed on record.
3. Today, there is no representation for the petitioner.
Mr.D.Jayachandran, Inspector [Crime], P-6 Kodungaiyur Police Station,
Kodungaiyur, is present before this Court. Learned Additional Public
Prosecutor on instructions from the Inspector submits that, the Final
Report has been filed on 26.06.2015 before the learned X Metropolitan
Magistrate, Egmore, Chennai.
4. Recording the submission, this petition is closed.
