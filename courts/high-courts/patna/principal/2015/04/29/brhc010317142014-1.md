ORAL JUDGMENT
Date: 29-04-2015
This application under Section 482 of the Code of
Criminal Procedure for quashing the order dated 13th August, 2014
passed by the learned Sub-divisional Officer, Patna in Case No.
778(M) of 2014 by which a proceeding under Section 144 of the
Code of Criminal Procedure has been initiated.
In view of Sub-section (4) of Section 144 of the Code
of criminal Procedure, this application has become infructuous as
no order passed in a proceeding under Section 144 Cr. P.C. shall
remain in force for more than two months from the making
thereof.
