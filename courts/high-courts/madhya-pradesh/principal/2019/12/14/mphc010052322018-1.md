Jabalpur, Dated : 14-12-2019
Shri Ajay Mishra, learned counsel for the applicant.
I.A. No.1390/2018 an application for condonation of delay is allowed
for the reasons mentioned therein.
Accordingly, the delay in filing the application for restoration is hereby
condoned.
Heard.
This application has been filed for restoration of M.A. No.1490/2010
which got dismissed for non compliance of Common Conditional Order
dated 30.07.2014.
For the reasons mentioned in the application for restoration, the same
is hereby allowed. Resultantly, M.A. No.1490/2010 is restored to its original
number.
Let a copy of this order be kept in the original record of M.A.
No.1490/2010.
Hence, the application filed by the applicant stands allowed and
disposed of.
