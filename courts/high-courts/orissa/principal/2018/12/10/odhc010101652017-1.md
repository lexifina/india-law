# High Court of Orissa, WP(C)/3137/2017, 2018-12-10

06. 10.12.2018 Learned counsel for the petitioner seeks permission to
withdraw the writ petition with liberty to file fresh application if
any cause of action survives.
 Permission is granted.
 Accordingly, the writ petition stands dismissed as
withdrawn with liberty to the petitioner to file afresh if any
cause of action survives.
