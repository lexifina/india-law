# Calcutta High Court, WPA/20974/2021, 2022-04-18

18.04.2022

 Ct. No.17

W.P.A. 20974 of 2021
Surongama Sinha Roy
-vs-The State of West Bengal & Ors.
Mr. Ashis Kumar Chowdhury
Ms. Sabnam Sultana
…for the petitioner
The petitioner has filed this application with
documents which are almost illegible.
I direct the petitioner to file a fresh application
after withdrawing it, if he thinks so, otherwise the
matter will not be heard.
The petitioner wants to withdraw this writ
application with liberty. Such liberty is granted. All
the annexures should be legible in the fresh
application.
This writ application is dismissed as withdrawn.
(Abhijit Gangopadhyay, J.)
