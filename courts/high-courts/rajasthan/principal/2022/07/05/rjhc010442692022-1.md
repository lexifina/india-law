Order
05/07/2022
The case comes up on an application preferred for correction
in the order dated 1.07.2022 passed by this Court in S.B. Civil
Writ Petition No.7973/2022.
Learned counsel for the applicant submits that in the order
dated 01.07.2022, the writ petition was not pressed with liberty to
file an application but it has been recorded as ‘the writ petition is
dismissed with liberty to file fresh writ petition’. He submits that
the liberty for filing an application was sought for, instead of filing
the writ petition.
In view of the submissions made by the learned counsel for
the applicant and the averments made in the application, the
same is allowed.

The order dated 01.07.2022 passed by this Court in S.B.
Civil Writ Petition No.7973/2022 is modified and it is ordered that
the writ petition is dismissed as not pressed with liberty to file
application before the competent authority, if the occasion so
arises.
