ORDER
This Crl.M.C is filed to quash the proceedings in
C.C.No.320/2017 on the file of the Judicial First Class Magistrate
Court-II, Mavelikkara arising from Crime No.424/2017 of
Nooranadu Police Station based on settlement.
2. It is submitted that the 2nd petitioner in this case is
already acquitted. It is also submitted that, only one victim is
arrayed as an accused and the affidavit is also filed only by one
victim.
3. If that is the case, the 1st petitioner can file a fresh petition
after impleading all the victims, if the matter is settled.
Granting liberty to the 1st petitioner to file a fresh Crl.M.C, this
criminal miscellaneous case is closed.
