ORDER
 Defendant No.7/purchaser is before this Court assailing
the order dated 05.01.2022 passed by the Court below by
taking the written statement of defendant as nil. The petitioner
appears to have filed one more application in I.A.No.VI seeking
extension of time under Section 148 R/w Section 151 of The
Code of Civil Procedure (for short ‘CPC’). Learned Judge has
rejected the said application.
2. Heard learned counsel appearing for petitioner and
learned counsel appearing for respondent No.2.
3. The present petitioner claims to be the purchaser of
joint family ancestral property. The petitioner contends that he
has purchased the property from the father of plaintiff under
registered sale deed dated 15.11.2003 insofar as property
bearing block No.93/2A. If this factual matrix is admitted, I am
of the view that petitioner deserves one opportunity to contest
the partition suit. If petitioner is not permitted to file written
statement that would seriously prejudice his rights in the

property purchased by him much prior to Amendment to
Section 6 of the Hindu Succession Act. The application filed by
present petitioner in I.A.No.VI is found to be totally
misconceived. If learned Judge had recorded that defendant
No.7 has not filed written statement within the stipulated time,
the petitioner ought to have filed an appropriate application to
recall the order and permit him to file written statement.
4. On the contrary, petitioner has filed an application
in I.A.No.VI under Section 148 R/w Section 151 of CPC seeking
extension of time to file written statement. Though, learned
Judge has rejected both these applications by cryptic orders,
however, the fault lies with the petitioner in not filing an
appropriate application. Though, I am not inclined to interfere
with the order passed by learned Judge on I.A.VI, the order
dated 05.01.2022 taking petitioner’s written statement as nil, is
not sustainable and same is liable to be rejected. Petitioner
shall file fresh application in the manner known to law and seek
leave of the Court to file the written statement. For the
foregoing reasons, this Court passes the following:
ORDER
i) Writ petition is allowed in part.
