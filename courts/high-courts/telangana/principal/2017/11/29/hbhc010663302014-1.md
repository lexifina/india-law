# High Court for the State of Telangana, CRP/3260/2014, 2017-11-29

THE HON’ BLE DR. JUSTICE B.SIVA SANKARA RAO
CIVIL REVISION PETITION No.3260 OF 2014
ORDER:
As per the note put up by the Registry main case itself was
disposed of on 20.01.2015, hence, there is nothing survives in this C.R.P.
to continue.
 Accordingly, this C.R.P. is dismissed as infructuous. It is made
clear that if at all the petitioner can show that the main case is pending
and the cause in C.R.P. still survives, he has to file application within
one week from today with proof for restoration. It is needless to say
against any interlocutory order if any revision is maintained, it is not a
bar if went unsuccessful for the main matter to urge as one of the
grounds in the appeal in impugning that interlocutory order as per
Section 105 C.P.C.
 Miscellaneous petitions pending consideration, if any, in this case
shall stand closed in consequence. There shall be no order as to costs.
