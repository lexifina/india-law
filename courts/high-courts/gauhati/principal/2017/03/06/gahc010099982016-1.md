# Gauhati High Court, WP(C)/5529/2016, 2017-03-06

WP(C) 5529/2016
BEFORE
HON’BLE MR. JUSTICE A.M. BUJOR BARUA
It is submitted by Mr. R. Sinha, learned counsel for the petitioner that
this writ petition, by which a direction has been sought for completing the ten
der process initiated pursuant to the re-sale notice dated 08.06.2016 in respect
of Madhura River Minor Mineral Unit No.1 (Sand) is not required to be further p
ursued, inasmuch as, the State authorities has given some assurance to the writ
petitioner that his grievance would be looked into.
Accordingly, the learned counsel for the petitioner prays that he be all
owed to withdraw this writ petition with liberty to file a fresh writ petition.
Prayer is allowed.
The writ petition stands closed with liberty to the petitioner to file a
fresh writ petition, if so advised.
