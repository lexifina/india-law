# High Court of Madhya Pradesh, MCRC/5206/2017, 2017-06-28

MCRC-5206-2017
(RAJKISHOR Vs THE STATE OF MADHYA PRADESH)
28-06-2017
None for the applicant even in the second round.
Shri JM Sahni, Panel Lawyer for the respondent/ State.
Learned Panel Lawyer for the State submits that the application was filed by
the applicant for grant of temporary bail to attend the marriage ceremony of
one Priyanka which was to be held on 26th May, 2017 and, therefore, the
application has already been turned infructuous.
Consequently, the application is hereby dismissed being infructuous.
(N.K. GUPTA)
