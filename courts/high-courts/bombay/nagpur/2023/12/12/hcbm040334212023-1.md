CIVIL APPLICATION (CAW) NO.3458 OF 2023
 This is an application for speaking to minutes,
seeking correction in para 1 of the order dated 01/12/2023.
2) Learned counsel for the petitioner submitted that
while passing the order dated 01/12/2023, in para 1
inadvertently the words “was from reserved category” were
mentioned instead of “was not from reserved category” and
therefore, prayed for correction of the same.
3) On perusal of the record, we found substance in his
contention. It seems that the same is a typographical mistake
and therefore, the same needs to be corrected. Hence, we deem
it appropriate to allow the present application.
4) Necessary corrections be made in an order dated
01/12/2023 and the corrected order be uploaded.
 ( ABHAY J. MANTRI, J. ) ( NITIN W. SAMBRE, J. )
