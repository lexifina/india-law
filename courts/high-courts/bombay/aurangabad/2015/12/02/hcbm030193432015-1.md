PER COURT :-
1) This is an application seeking condonation of delay, which has
occasioned in filing the application seeking leave to appeal against the
order passed by the learned Judicial Magistrate First, Class, Dhule on
07.02.2015 in S.T.C. No.751/2007. The learned A.P.P. submitted that,
delay of eight days has occasioned in filing the application under section
378(1)(b) of the Code of Criminal Procedure.
2) Heard. For the reasons stated in the application, the delay
so occasioned is liable to be condoned and is accordingly condoned.
 ( P.R. BORA, J. )
