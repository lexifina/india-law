The applicant has filed this application requesting the Court
to initiate preliminary enquiry as contemplated under Section 340 of
the Code of Criminal Procedure. The applicant wants to withdraw this
application. It is for the reason that in addition to the averments in the
application, there ought to have been some more particulars.
So, in stead of adding those particulars by filing amendment
application, the applicant seeks liberty to withdraw the application and
to file fresh application. Yet, no any order is passed on this application.
I do not find any reason to refuse the request.
In view of that, the application is disposed of as not pressed
and the applicant is granted liberty to file fresh application containing
all the particulars.
