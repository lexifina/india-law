# High Court of Madhya Pradesh, MCC/1825/2016, 2016-08-23

MCC-1825-2016
(RAVINDRA SINGH Vs THE STATE OF MADHYA PRADESH)
23-08-2016
Shri A.K.Pathak, learned counsel for the applicants.
Heard.
This application has been filed for restoration of WP
No.4547/2001, which was dismissed for want of prosecution
on 24.11.2015. There being some delay in filing of this
application for restoration, IA No.9762/2016 has been filed
seeking condonation of delay, which is supported by an
affidavit.
Keeping in view the reasons indicated and finding there to be
reasonable justification for the same, both the applications are
allowed. Condoning the delay in filing the restoration
application, the restoration application itself is allowed.
Accordingly, WP No.4547/2001 is restored to its original
number. It be placed for orders before an appropriate bench.
The MCC stands allowed and disposed of.
(RAJENDRA MENON)
ACTING CHIEF JUSTICE
(ANURAG SHRIVASTAVA)
JUDGE
Ansari
