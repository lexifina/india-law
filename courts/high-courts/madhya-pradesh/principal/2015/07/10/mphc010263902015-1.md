# High Court of Madhya Pradesh, MCC/1534/2015, 2015-07-10

MCC-1534-2015
(RAMJIYAWAN Vs THE STATE OF MADHYA PRADESH)
10-07-2015
Shri A.P.Shah, learned counsel for the applicant.
This application has been filed for restoration of a
review petition, which has been dismissed in view of a
common conditional order passed on 14.10.2014. There
being some delay in filing of this application,
I.A.No.7147/2015 has been filed for condonation of delay
and the delay and default is attributed to some lapses on
the part of the counsel, the application is supported by
the affidavit of the applicant himself.
Keeping in view the reasons indicated, the application
(I.A.No.7147/2015) is allowed. Condoning the delay in
filing of this application for restoration, restoration
application is itself allowed. Review Petition
No.159/2014 be restored to it's original file. It be placed
for orders before an appropriate bench.
With the aforesaid, this application stands allowed and
disposed of.
(RAJENDRA MENON)
JUDGE
(SUSHIL KUMAR GUPTA)
JUDGE
