Order on Board
3/7/2017
1. In the writ petition being WP (227) No.266 of 2015 preferred by the
petitioners/plaintiffs this Court vide order dated 9.3.2016 given liberty
to the petitioners to file an application before the trial court for
examination of any witness and after giving an opportunity of hearing,
fresh order will be passed on its own merit without being influenced
by the impugned order dated 18.3.2015.
2. On filing such an application, the trial Court has rejected the same on
the ground that earlier application has also been rejected.
3. Since this Court has given liberty to file fresh application which was
required to be considered by the trial Court on its own merit, but that
has not been done and it has been rejected, the impugned order is
set aside. The trial Court is directed to pass an order on the
application under Order 18 Rule 4 read with Section 151 of the CPC
strictly in accordance with law expeditiously.
4. The writ petition is allowed to the extent indicated hereinabove. No
order as to cost(s).
