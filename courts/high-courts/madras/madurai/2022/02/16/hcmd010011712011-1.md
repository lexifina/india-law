ORDER
This revision petition is filed to set aside the order dated
07.12.2009 in IA.No.58/2009 in OS.No.92/2007 on the file of the
District Munsif Court, Virudhunagar.
2. IA.No.58/2009 was filed by the petitioner / plaintiff to
amend the value of the suit property. The IA was dismissed by the
learned District Munsif, Virudhunagar on 07.12.2009. Challenging
the said dismissal order, the petitioner / plaintiff has come up
with this revision.
3. Heard the learned counsels appearing on both sides and
perused the materials on record.
4. The above said IA was dismissed on 07.12.2009 and on the
same date, the plaint was returned for presentation before
appropriate Court. Till date, the petitioner / plaintiff has
neither filed any appeal against the return of plaint nor
represented the plaint before appropriate Court. The petitioner /
plaintiff either ought to have questioned the return of plaint or
represented the plaint before appropriate Court as directed by the
learned District Munsif, Virudhunagar. Without doing so, the
petitioner / plaintiff cannot file the present revision petition
challenging the order passed in the amendment petition.
Furthermore, at present, there is no suit pending. Hence, this
Civil Revision Petition is liable to be dismissed.
5. Accordingly, this Civil Revision Petition is dismissed. No
costs. Consequently, the connected miscellaneous petition is
closed. However, if the suit is restored to file, the petitioner /
plaintiff is at liberty to file a fresh application for amendment.
