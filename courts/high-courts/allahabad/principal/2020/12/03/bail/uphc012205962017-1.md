# Allahabad High Court, BAIL/17388/2017, 2020-12-03

Court No. - 78
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 17388
of 2017
Applicant :- Keral Singh
Opposite Party :- State of U.P.
Counsel for Applicant :- Pushpendra Singh
Counsel for Opposite Party :- G.A.
Hon'ble Rajiv Joshi,J.
This is third bail application. First bail application as well as
second bail application has already been rejected on 9.10.2015
and 28.01.2016.
Heard Sri Pushpendra Singh, learned counsel for the applicant,
learned A.G.A. for the State and perused the record.
This application has been filed seeking the release of the
applicant on bail in Case Crime No. 125 of 2015, under
Sections 395, 412 IPC, P.S. Debai, District Bulandshahr, during
pendency of trial.
Submission so raised by learned counsel for the applicant is that
the co-accused has already been enlarged on bail by the co-ordinate Bench of this Court. This aspect has been considered in
second bail application.
I do not find any new ground for entertaining the present third
bail application.
Accordingly, the application is rejected.
Since, the trial has already been expedited and the witnesses are
started to be examined, under these circumstances, the trial
court is directed to conclude the trial as expeditiously as
possible, strictly in accordance with Section 309 Cr.P.C.
Order Date :- 3.12.2020
