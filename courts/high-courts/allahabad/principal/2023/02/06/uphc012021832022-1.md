# Allahabad High Court, WPIL/2019/2022, 2023-02-06

Court No. - 7
Case :- PUBLIC INTEREST LITIGATION (PIL) No. - 2019 of
2022
Petitioner :- Anil Tiwari
Respondent :- State Of U P And 13 Others
Counsel for Petitioner :- Chandrakant Tripathi
Counsel for Respondent :- C.S.C.,Rameshwar Prasad Shukla
Hon'ble Chandra Kumar Rai,J.
The instructions supplied by learned Standing Counsel are
taken on record.
Case Called out.
Learned Standing Counsel for the State and Shri Rameshwar
Prasad Shukla, learned counsel for the respondent-Gaon Sabha
are present.
The instant writ petition has been filed for mandamus
commanding respondents to remove the encroachment from
Plot Nos.84, 87, 89 and 90 which are recorded as 'public
property' and has been illegally encroached by private
respondent nos.6 to 14. It is also prayed that respondent no.3 be
directed to allot numbers of cases which has been initiated by
the petitioner under Section 67 of the U.P. Revenue Code-2006
and decide the same within stipulated period.
In the instructions dated 13.12.2022 supplied today, the
particulars of cases are mentioned which have been registered
against several persons under Sections 67(1) and 67-A of the
U.P. Revenue Code-2006 before the court of Tehsildar.
The details of the cases are as follows:-
1. Case No. T202215510111239 U/s 67(1) of the U.P. Revenue
Code 2006;
2. Case No.T202215510111240 U/s 67(1) of the U.P. Revenue
Code 2006;
3. Case No.T202215510111211 U/s 67(1) of the U.P. Revenue
Code 2006;
4. Case No.T202215510111242 U/s 67(1) of the U.P. Revenue
Code 2006;
5. Case No.T202215510111243 U/s 67(1) of the U.P. Revenue

Code 2006;
6. Case No.T202215510108719 U/s 67(1) of the U.P. Revenue
Code 2006;
7. Case No.T202215510108720 U/s 67(1) of the U.P. Revenue
Code 2006;
8. Case No.T202215510108721 U/s 67(1) of the U.P. Revenue
Code 2006;
9. Case No. T202215510108722 U/s 67(1) of the U.P. Revenue
Code 2006;
10. Case No.T202215510110449 U/s 67(1) of the U.P. Revenue
Code 2006;
Considering the instructions dated 13.12.2022, the instant writ
petition is finally disposed of directing the respondent no.4-
Tehsildar, Tehsil Sadar Maunath Bhanjan, District Mau to
decide the aforementioned cases under Sections 67(1) of the
U.P. Revenue Code-2006 expeditiously, preferably, within a
period of four months from the date of production of certified
copy of this order.
With the above observations and directions, the writ petition is
finally disposed of.
