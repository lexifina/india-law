ORDER
This criminal miscellaneous case is filed to quash the
proceedings in C.C.No.191/2016 on the file of the Judicial
First Class Magistrate Court, Palakkad, arising from Crime
No.685/2015 of Palakkad Town South Police Station.
2. As per the e-courts service website, the evidence
is already started in the case and the case is posted to
30.07.2024.
3. If that is the case, this case need not be
entertained by this Court. The petitioner can raise all the
contentions before the trial court at the appropriate state.
With the above observation, this criminal
miscellaneous case is closed.
