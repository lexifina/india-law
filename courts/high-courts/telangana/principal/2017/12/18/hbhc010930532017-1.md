# High Court for the State of Telangana, WP/42212/2017, 2017-12-18

THE HONíBLE SRI JUSTICE M.SEETHARAMA MURTI
WRIT PETITION No.42212 of 2017
ORDER:
When the matter is taken up for hearing, learned counsel for
the petitioner sought permission to withdraw the writ petition
reserving liberty to file a fresh writ petition, if necessary.
2. Learned Standing Counsel, Sri N.Praveen Kumar, appearing for
the 2nd respondent Municipality is present.

4. Accordingly, the Writ Petition is dismissed as withdrawn
reserving liberty as afore-stated.
Pending miscellaneous petitions, if any, shall stand closed in
the light of this final order. No order as to costs.
