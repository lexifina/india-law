This application coming on for orders this day, the court passed the
following:
ORDER
Heard on admission and I.A. No.3588/2022 which is an application for
condonation of delay.
This is an application for restoration of MCC No.869/2020 which was
filed for permission to file second appeal as an indigent person. The said
application has been dismissed because of non-compliance of peremptory
order dated 16.08.2021. It is stated in the application that the file was taken
from the Advocate to engage some other counsel, however, before he could
engage new counsel, the application suffers dismissal on account of peremptory
order. The application is supported by an affidavit.
For the aforesaid reason, I find sufficient cause has been shown for non-compliance of the peremptory order and, therefore, the application deserves to
be allowed. Accordingly, the application is allowed and the delay in filing the
application is also condoned.
Office is directed to restore MCC No.869/2020 to its original number.
