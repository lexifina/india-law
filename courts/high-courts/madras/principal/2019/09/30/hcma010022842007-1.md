# Madras High Court, AS/388/2007, 2019-09-30

C.M.P.No.7840 of 2019
C.M.P.No.7840 of 2019
in
A.S. No.388 of 2007
V.BHARATHIDASAN, J.
 This matter is posted today under the caption "for being
mentioned " at the instance of the learned counsel for the petitioner.
2. Earlier, this Court, vide order, dated 29.03.2019, in
C.M.P.No.7840 of 2019 directed the Registry to return the original
Settlement Deed dated 17.03.1975 registered as Doc.No.355 of 1975 on the
file of the Joint Sub-Registrar-I, Thirupur, which is marked as Ex.B2 to the
petitioner.
3. The learned counsel appearing for the petitioner submits that
Ex.B2 is only a certified copy of the original document, subsequently, the
original deed has been marked as Ex.B.14. But, due to oversight, it was not
brought to the notice of the Court, while passing the order . In the above
circumstances, the petitioner seeks to modify the order to return the original
document marked as Ex.B.14.
http://www.judis.nic.in

C.M.P.No.7840 of 2019
4. Heard the learned counsel appearing for both sides.
5. Considering the said fact, the order dated 29.03.2019, passed
in C.M.P.No.7840 of 2019 in A.S.No.388 of 2007 is modified to the effect
that "Registry is directed to return the original Settlement Deed dated
17.03.1975 registered as Doc.No.355 of 1975 on the file of the Joint Sub-Registrar-I, Thirupur, which is marked as Ex.B.14" .
