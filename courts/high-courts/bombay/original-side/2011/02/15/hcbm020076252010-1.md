P.C. :
1. Heard learned Counsel on both sides. There is no affidavit-in-reply filed by the defendants to this notice. Learned Counsel appearing
on behalf of the defendants submits that defendants be given time to
have the decree dated 20th December, 2005 set aside. Except this,
there is no objection. The argument that defendants want to apply for
setting aside ex-parte decree cannot be accepted in this proceedings
namely Notice under Order XXI Rule 22 of CPC. Notice will have to be
dismissed. Hence, following order is passed.
