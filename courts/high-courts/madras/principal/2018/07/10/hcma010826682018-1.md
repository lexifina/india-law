This Application coming on this day before this court
for hearing the court made the following order:

A.No.3587 of 2018 has been filed by the plaintiff
seeking appointment of an Advocate Commissioner to seize
the products of the defendants. Even when the application
was pending this court had occasions to examine the issues
raised in O.A. Nos. 331, 334 & 335 of 2018 and orders have
been passed. It is reliably understood that Original Side
Appeals have been filed.
2. Consequently, the learned counsel for the applicant
/ plaintiff made the following endorsement:
 “ May be permitted to withdraw,
with liberty to file later if
required.”
3. In view of the said endorsement, the application is
dismissed as withdrawn and liberty is granted to the
applicant / plaintiff to file similar application if need
arises.
https://hcservices.ecourts.gov.in/hcservices/

4. It is to be mentioned that application for
appointment of Advocate Commissioner can be filed at any

5. Accordingly, the application is dismissed as withdrawn.
No costs.
