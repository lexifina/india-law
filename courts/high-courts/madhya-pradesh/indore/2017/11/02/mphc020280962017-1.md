# High Court of Madhya Pradesh, MCRC/20057/2017, 2017-11-02

1

M.Cr.C. No.20057/2017
(Manish Yadav vs. State of M.P.)
Indore, Dated: 02/11/2017
Shri Amit Raval, learned counsel for the petitioner.
Shri Peyush Jain, learned Public Prosecutor for the
respondent / State.
This application under Section 482 Code of Criminal
Procedure has been filed for correction/ rectification of
typographical error which has occurred in order dated
25/10/2017 passed by this Court in M.Cr.C. No.18331/2017.
Due to error the crime number was stated as ‘513/2017’ in
place of ‘613/2017’.
It is submitted by the learned counsel for the
petitioner that the aforesaid error requires to be rectified /
corrected.
Prayer for rectification / correction is not opposed by
the learned Public Prosecutor.
Accordingly, this petition is hereby allowed and it is
directed that in order dated 25/10/2017, passed by this Court in
M.Cr.C. No.18331/2017, the crime number shall be read as
‘613/2017’ instead of ‘513/2017’. The present order shall be
read conjointly with order dated 25/10/2017.
Petition stands disposed of.
Certified copy as per rules.
