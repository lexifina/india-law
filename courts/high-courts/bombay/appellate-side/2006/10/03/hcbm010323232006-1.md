CORAM : A. S. OKA, J.

P.C.:
 1.Heard the Advocate appearing for the
 Petitioner. By this Petition under Article
 227 of the Constitution of India, a
 direction is sought for disposal of
 Application filed by the Petitioner for
 return of property within a time frame fixed
 by this court. The contention of the
 Petitioner is that though Application has
 been filed on 21st December, 2004, it has
 remained pending till today as a result of
 which the Petitioner has suffered heavy
 pecuniary loss.
 2.I have considered the submissions of
 the learned Advocate appearing for the
 Petitioner. As stated earlier, the only

 ... 2 ...
 grievance is that the Application for return
 of property filed on 21st December, 2004 is
 not being disposed of. It is not stated in
 the Petition that all the Applications for
 return of property which were filed in the
 concerned court before 21st December, 2004
 are disposed of. Priority cannot be given
 only because the Petitioner has approached
 this court. So far as the Applications for
 return of property are concerned, normally,
 the Applications must be disposed in
 chronological order as per the date of
 filing unless there are exceptional
 circumstances.
 3.Subject to what is stated above, no
 direction can be given. Petition is
 disposed of.
JUDGE
