# High Court for the State of Telangana, CC/593/2019, 2019-07-18

THE HON’BLE SRI JUSTICE CHALLA KODANDA RAM
CONTEMPT CASE No.593 of 2019
ORDER:
This Contempt Case is filed alleging non-compliance of the
order dated 15.03.2019 passed by this Court in Writ Petition
No.5337 of 2019.
It is submitted by the learned counsel for the petitioner that
the aforesaid order of this Court has since been complied with.
Accordingly, the Contempt Case is closed.
