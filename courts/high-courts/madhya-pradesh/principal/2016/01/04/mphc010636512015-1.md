# High Court of Madhya Pradesh, RP/918/2015, 2016-01-04

RP-918-2015
(VISHNU PRASAD PRAJAPATI Vs THE STATE OF MADHYA PRADESH)
04-01-2016
Shri Ajay Kumar Dwivedi, learned counsel for the petitioner.
Petitioner has filed the review application for correcting the
typographical error in the order dated 4.12.2015.
Vide order dated 4.12.2015 number of writ petition has wrongly
been mentioned as '20050/2015' instead of '19907/2015',
therefore, prays that necessary typographical error be corrected.
The application is considered and is allowed. W.P. No.
20050/2015 shall be read as W.P. No. 19907/2015 in the order
dated 04.12.2015.
This order shall be treated as a part of the order dated 4.12.2015
passed in W.P. No.19907/2015.
Accordingly, review petition stands disposed of.
(MISS VANDANA KASREKAR)
JUDGE
