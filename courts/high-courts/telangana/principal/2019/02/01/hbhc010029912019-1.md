# High Court for the State of Telangana, WP/1732/2019, 2019-02-01

HONOURABLE SRI JUSTICE SANJAY KUMAR
WRIT PETITION No.1732 of 2019
ORDER:
Sri Y.Nagaiah, learned counsel representing Sri C.Mallesh Rao,
learned counsel for the petitioners, seeks leave to withdraw the Writ
Petition reserving liberty to the petitioners to file a fresh case, if
warranted.
Leave granted.
The Writ Petition is accordingly dismissed as withdrawn with
the liberty aforestated.
Pending Miscellaneous Petitions, if any, shall also stand
dismissed. No order as to costs.
