2. Trial is scheduled to begin on 9th April, 2013. The
charge is under Section 302 of the Indian Penal Code. There
are three eyewitnesses. As such it is not desirable to hear this
application at this stage. The application deserves to be
dismissed. However, the applicant needs to be given a liberty
to file fresh application for bail after examination of
eyewitnesses.
Application is dismissed.
The applicant is at liberty to file fresh application
for bail before the trial Court, if so advised, after examination
of eyewitnesses.
