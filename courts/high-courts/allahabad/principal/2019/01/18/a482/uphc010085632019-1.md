# Allahabad High Court, A482/1466/2019, 2019-01-18

Court No. - 67
Case :- APPLICATION U/S 482 No. - 1466 of 2019
Applicant :- Vinay Tiwari And Another
Opposite Party :- State Of U.P. And Another
Counsel for Applicant :- Harish Chandra Pratap
Counsel for Opposite Party :- G.A.
Hon'ble Rahul Chaturvedi,J.
Learned counsel for the applicants submitted that there are some
infirmities in the instant petition, therefore, he wants to withdraw the same
with liberty to file fresh.
The prayer is acceded to. The instant application filed under section 482
Cr.P.C., is hereby dismissed as withdrawn with the liberty to file fresh
petition in future, if so advised.
Certified copy of order be returned within 48 hours, as per Rules of the
Court, keeping a photo copy of the same on record.
