# Allahabad High Court, A482/347/2020, 2020-01-31

Court No. - 74
Case :- APPLICATION U/S 482 No. - 347 of 2020
Applicant :- Shaukat
Opposite Party :- State Of Up And Anr
Counsel for Applicant :- Zafar Abbas
Counsel for Opposite Party :- G.A.
Hon'ble Ram Krishna Gautam,J.
Learned counsel for Opposite party no.2, put in
appearance, and filed Vakalatnma, today, the
same is taken on record.
He has submitted that he will not file any objection
to this proceeding.
Learned AGA, appearing for the State of U.P., has
not filed any objection and on being asked, he
prayed for time for filing objection. He submitted
that previously objection could not be filed
because opportunity to file objection was not given
to him, rather, notice to Opposite party no.2 was
issued.
At this juncture, learned counsel for applicant, Sri
Zafar Abbas, Advocate, submitted that this
Application be dismissed as not pressed.
In view of the submission made by learned counsel
for applicant for dismissing this Application as not
pressed, this Application is being dismissed as not
pressed.
Order Date :- 31.1.2020
