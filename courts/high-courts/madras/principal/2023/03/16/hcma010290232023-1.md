# Madras High Court, A/1491/2023, 2023-03-16

A.No.1491 of 2023 in
T.O.S.No.23 of 2019
R.N.MANJULA,J.
The applicant/plaintiff has filed
this application seeking permission to
file reply to the written statement filed
by the defendant.
2. The learned counsel for the
applicant submitted that in the written
statement, the defendant has raised
certain allegations and defamatory
remarks against the plaintiff and for
which he needs to file reply statement.
3. The learned counsel for the
defendant has no serious objection in
allowing this application.
4. Considering the above and in
the interest of justice, this petition is
allowed. The applicant is permitted to
file reply statement to the written
statement on or before 30.03.2023.
