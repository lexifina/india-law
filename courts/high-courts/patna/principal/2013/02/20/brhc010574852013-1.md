CORAM: HONOURABLE MR. JUSTICE ASHWANI KUMAR SINGH
ORAL ORDER
 2 20-02-2013 The present application has been filed under Section
482 of the Code of Criminal Procedure for restoration of Cr.
W.J.C. No. 314 of 2012 which stood dismissed for want of
prosecution on 05.02.2013.
In my view, an application under Section 482 of the
Code of Criminal Procedure would not be maintainable for
seeking restoration of a writ petition which stood dismissed for
want of prosecution.
Accordingly, the present application is dismissed with
liberty to the petitioner to file an appropriate application for
restoration of the aforesaid writ petition.
 Sanjeet/-
 (Ashwani Kumar Singh, J.)
