# High Court of Madhya Pradesh, MCC/2532/2015, 2015-09-18

MCC-2532-2015
(AKHILESH KUMAR UIKE Vs THE STATE OF MADHYA PRADESH)
18-09-2015
Shri Manoj Rajak, learned counsel for the applicant.
This application has been filed for restoration of W.P.
No.1079/2009, which was dismissed for want of
prosecution vide order dated 4.3.2015. There being some
delay in filing of this application for restoration, I.A.
No.11119/2015 has been filed. Reason for the delay is
attributed to some lapse in the office of the counsel and
the application is supported by affidavit of the applicant.
Finding the same to be bonafide, both the applications
are allowed. Condoning the delay in filing the restoration
application, the restoration application itself is allowed.
W.P.1079/2009 is restored to its original file. It be placed
for orders before an appropriate Bench.
Application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
