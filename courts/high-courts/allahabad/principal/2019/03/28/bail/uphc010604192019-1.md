# Allahabad High Court, BAIL/12480/2019, 2019-03-28

Court No. - 44
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 12480 of
2019
Applicant :- Priti Pahawa
Opposite Party :- State Of U.P.
Counsel for Applicant :- Om Prakash Mishra
Counsel for Opposite Party :- G.A.
Hon'ble Arvind Kumar Mishra-I,J.
Sri Om Prakash Mishra, learned counsel for the applicant
has submitted that this is second bail application, but
unfortunately, the applicant during the process of filing of
this bail application died while in custody. Therefore, now
this second bail application has rendered itself infructuous
and no order need to be passed.
Also heard the learned A.G.A.
Since, the applicant has died, no useful purpose will be
served by entertaining this bail application and it shall be
deemed to have been not presented and no positive or
negative order need be passed.
Accordingly, the bail application is disposed of.
Order Date :- 28.3.2019
S Rawat
