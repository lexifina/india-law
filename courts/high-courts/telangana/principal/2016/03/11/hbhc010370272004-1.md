# High Court for the State of Telangana, CC/1544/2004, 2016-03-11

HON’BLE SRI JUSTICE A.RAJASHEKER REDDY
Contempt Case No.1544 OF 2004
ORDER:
This Contempt Case is filed alleging violation of the interim
order dated 05.02.2003, passed by this Court in WP.MP.No.1188
of 2003 in WP.No.926 of 2003.
Now it is stated that the main writ petition itself is dismissed
for default on 16.06.2009.
Since it is stated that the main writ petition itself is
dismissed for default, the cause in the Contempt Case does not
survive for adjudication.
Accordingly, the Contempt Case is dismissed. No order as
to costs.
As a sequel thereto, miscellaneous applications, if any
pending, shall stand closed.
_____________________________
A.RAJASHEKER REDDY, J
11.03.2016
