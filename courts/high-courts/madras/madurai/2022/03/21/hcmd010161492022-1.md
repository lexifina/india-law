PRAYER :- This Criminal Original Petition filed under Section 482
Cr.P.C.to issue a direction to direct the Respondent No.5 to
withdraw the case in Crime No.62/2021 dated 08/08/2021 registered
U/s.174/Cr.P.C on the file of Respondent No.6 and entrust the same
to respondent No.4 for an investigation of the case by a Competent
Officer and file a final report before the Jurisdictional Magistrate
within the time stipulated by this Court.
 For Petitioners : Mr.T.Lajapathi Roy

 For Respondents : Mr.R.M.Anbunithi
 R1 to R6 Additional Public Prosecutor
 (Criminal Side)
ORDER
The Criminal Original Petition has been filed to direct the
Respondent No.5 to withdraw the case in Crime No.62/2021 dated
08/08/2021 registered U/s.174/Cr.P.C on the file of Respondent No.6
and entrust the same to respondent No.4 for an investigation of the
case by a Competent Officer and file a final report before the
Jurisdictional Magistrate within the time stipulated by this Court.
2.While pending this petition, the sixth respondent completed
investigation in Crime No.62 of 2021, registered for the offence
under Section 174 Cr.P.C and file final report before the learned
Judicial Magistrate No.VI, Madurai on 11.03.2022. Therefore, no
investigation is now pending, on the file of the sixth respondent.
However, the petitioner is at liberty to file a protest petition, in
the manner known to law, if so advised. It is made clear that the
petitioner is at liberty to raise all grounds which are raised
before this Court, before the learned Judicial Magistrate also.
3.With the above directions, this Criminal Original Petition is
disposed of. Consequently, connected miscellaneous petition is
closed.
