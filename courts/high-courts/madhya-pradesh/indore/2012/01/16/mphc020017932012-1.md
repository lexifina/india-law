# High Court of Madhya Pradesh, MCRC/487/2012, 2012-01-16

1
Miscellaneous Criminal Case No.487/2012
16.01.12
Shri Anand Soni , Advocate for the applicant.
Shri Manish Joshi, Panel Lawyers for the NA/State, on
advance notice.
Heard.
This is an application under Section 482 of the Cr.P.C. for
correction of crime number in order dated 11.01.2012 passed in
M.Cr.C. no. 10123/2011.
Learned counsel for the applicant submits that due to
typographical error in the aforesaid order instead of Crime
no.528/2010, the same has been typed as 529/2010.
On due consideration, the application is allowed. In order
dated 11.01.2012 instead of Crime no. 529/2010, it should be
read as 528/2010.
This order shall be read conjointly with the order dated
11.01.2012 passed in M.Cr.C. no. 10123/2011.
Certified copy as per rules.
(P.K. Jaiswal, J.)
