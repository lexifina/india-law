# High Court for the State of Telangana, TRCRLP/230/2012, 2012-11-23

THE HON’BLE SRI JUSTICE K.C.BHANU
TRANSFER CRIMINAL PETITION NO.230 OF 2012
ORDER:
This petition is filed under Section 407 Cr.P.C. to transfer
C.C.No.419 of 2012 on the file of the III Additional Judicial First
Class Magistrate, Chittoor to any other Court in the same District.
2. Without going into the merits of the case, C.C.No.419 of
2012 on the file of the III Additional Judicial First Class Magistrate,
Chittoor is transferred to IV Additional Judicial First Class
Magistrate, Chittoor, as it would not cause any inconvenience to
the parties. However, the learned Magistrate is directed to dispose
of the case within four months from the date of receipt of records
from the III Additional Judicial First Class Magistrate, Chittoor.
3. Accordingly, the Transfer Criminal Petition is allowed.
Miscellaneous petitions, if any, pending in this Petition shall stand
closed.
----------------------
K.C.BHANU, J
