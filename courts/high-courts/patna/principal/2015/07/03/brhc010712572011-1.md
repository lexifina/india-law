ORAL ORDER
4 03-07-2015 After some argument learned counsel for the petitioner
seeks permission to withdraw this application by giving an
assurance that now he will not file another writ petition for the
same cause of action.
This application is, accordingly, dismissed as withdrawn
by recording the aforementioned undertaking given by his counsel.
It is, however, made clear that if the petitioner is now
found to have filed fourth writ application, for the same cause of
action, this Court may impose very heavy cost against the
petitioner.
