PER COURT :
1. We have heard the learned counsel for the applicants in all
these criminal applications for some time.
2. The learned counsel for the applicants, on instructions, seeks
leave to withdraw all these applications with liberty to the applicants to file
the applications for discharge before the trial court.
3. Leave granted.
4. All the criminal applications are dismissed as withdrawn with
liberty to each of the applicants to file the applications for discharge before
the trial court, if so desired and in the event of filing of such applications,
the trial court shall decide the same as expeditiously as possible.
