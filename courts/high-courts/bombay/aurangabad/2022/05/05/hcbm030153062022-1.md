Respondent Nos. 9, 10, 11/A to 11/C have refused to accept the
notices. They are treated as duly served.
2. This is an Appeal from Order by the original plaintiff being aggrieved
and dissatisfied by the order passed by the lower appellate court under
Order XLI Rule 23A of the Code of Civil Procedure remanding the suit for
decision afresh.
3. By way of this application it is now being averred that during
pendency of this appeal, the original appellant/plaintiff has sold the suit
property and the purchaser is now being sought to be added as appellant
No. 2. The other side has not filed any reply.
4. For the reasons mentioned in the application, the application is
allowed. Necessary amendment to be carried out within six weeks.
