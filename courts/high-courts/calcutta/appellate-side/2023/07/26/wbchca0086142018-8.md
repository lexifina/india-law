This revisional application has been filed with a prayer for
quashing the proceeding in respect of New Town, Police Station
Case No. 37 of 2017 dated 25.01.2017 under Sections 420/ 406/
417/ 419/ 468/ 471 of the Indian Penal Code.
Both the learned advocates appearing on behalf the parties
to this revisional application are present.
Learned advocate appearing on behalf of the State has
submitted a status report communicated by Kazi Rafikul Islam,
SI, DD, Bidhannagar, Police Commissionerate, stating, inter alia,
that final report in connection with Newtown PS, FRMF No.
120/20 dated 16.07.2020 has been filed before the learned Chief
Judicial Magistrate, Barasat, North 24 Parganas. The status
report be kept with the record.
Considering the aforesaid facts and circumstances, I find
no reason to continue this revisional application with a prayer

for quashing of the proceeding in which final report has already
been submitted.
Accordingly, this revisional application stands disposed of.
Connected applications, if there be any, also stand
disposed of.
Interim order, if there be any, also stands vacated.
 (Bibhas Ranjan De, J.)
