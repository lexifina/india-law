RAJIVE BHALLA, J (Oral)
Prayer in this revision petition is, for setting aside the order
dated 17.1.2008 and for issuance of a direction to respondent no.1, to file
the amended plaint, in accordance with the order passed by the trial Court
dated 25.7.2005.
Counsel for the petitioners contends that pursuant to an order
dated 25.7.2005, respondent no.1's prayer for amendment of the plaint was
allowed. However, as respondent no.1 did not file any amended plaint, the
the petitioner filed an application before the trial Court, for issuance of a
direction to respondent no.1, to file the amended plaint. The learned trial
Court, vide the impugned order has dismissed the application.
I have heard learned counsel for the petitioners and perused the
impugned order.
Respondent no.1, filed C.R. No.4832 of 2005 in this Hon'ble
High Court and vide order dated 22.1.2007, the order dated 25.7.2005 has
been set aside. Consequently, respondent no.1 cannot be directed to file an

C.R. No.635 of 2008 2
amended plaint, as prayed.
At this stage, counsel for the petitioners states that there is an
error in the order dated 22.1.2007, passed in Civil Revision No.4832 of
2005. Be that as it may, no relief can be granted to the petitioners, as vide
order dated 22.1.2007, the order dated 25.7.2005 has been set aside.
Dismissed.
5.2.2008 ( RAJIVE BHALLA )
