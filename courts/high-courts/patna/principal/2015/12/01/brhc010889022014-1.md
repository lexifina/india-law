ORAL ORDER
2 01-12-2015 After some argument, the learned counsel, Mr. Naresh
Chandra Verma appearing on behalf of the petitioner seeks
permission to withdraw this writ application with liberty to file
application under Order 26 Rule 9 C.P.C. at appropriate stage, if
necessary.
In view of the submission of the learned counsel, this
writ application is permitted to be withdrawn. Accordingly, this
writ application is dismissed as withdrawn with liberty to the
petitioner to file application at appropriate stage and if such
application is filed and if the court below will find that it is
necessary to appoint Pleader Commissioner, the court below shall
pass appropriate order according to law.
