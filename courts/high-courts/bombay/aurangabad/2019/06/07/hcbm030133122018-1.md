CORAM : SMT. VIBHA KANKANWADI, J.
DATE : 07th JUNE, 2019
PER COURT :
1 Heard both sides. Present application has been filed for getting
delay of 18 days condoned. The application has been objected on the ground
that no details have been given. So also the appeal itself is not maintainable.
According to the learned Advocate for the respondents, the impugned order
should be challenged before the District Court. That point can be considered
at a later stage. However, as regards the delay is concerned, it is of only 18
days and therefore, the application is hereby allowed. The delay is
condoned. Registry to verify and registered it if found suitable and place it
before appropriate Bench for consideration.
( Smt. Vibha Kankanwadi, J. )
