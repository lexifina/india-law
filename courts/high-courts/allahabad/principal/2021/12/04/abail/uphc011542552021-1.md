# Allahabad High Court, ABAIL/18719/2021, 2021-12-04

Court No. - 68
Case :- CRIMINAL MISC ANTICIPATORY BAIL
APPLICATION U/S 438 CR.P.C. No. - 18719 of 2021
Applicant :- Sujeet Yadav
Opposite Party :- State of U.P.
Counsel for Applicant :- Jitendra Singh
Counsel for Opposite Party :- G.A.
Hon'ble Raj Beer Singh,J.
Learned counsel for the applicant, learned A.G.A. for the State
are present.
It has been pointed out that the instant anticipatory bail
application has been moved directly before this Court and thus,
the instant application for anticipatory bail may be dismissed as
withdrawn with liberty to file a fresh application for
anticipatory bail before the concerned Session Court.
In view of aforesaid, the instant application for anticipatory bail
is dismissed as withdrawn with liberty to file appropriate
application before the concerned Session Court.
Order Date :- 4.12.2021
