This application is filed for permission to file the reply to the
written statement.
2. I heard the learned counsel for the applicant and the
learned counsel for the respondent/defendant.
3. The learned counsel for the applicant submitted that it
became necessary to file reply to the written statement so as to
deal with certain averments in the written statement. Therefore, he
submitted that this application is filed.
4. In response, the learned Senior Counsel for the respondent
submits that the application has been filed belatedly i.e. beyond the
time limit of 30 days. Therefore, he submits that this application
is liable to be dismissed.
