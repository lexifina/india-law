Judgment / Order
09/03/2017
 Learned counsel for the review petitioner has moved an
application for withdrawal of the review petition with liberty to file
afresh, if occasion so arises.
On asking, learned counsel has mentioned that the execution
proceeding of the decree against which second appeal was filed
by the petitioner has concluded already.
In view of above, the application simpliciter for withdrawal
of the review application is allowed. The review petition is
dismissed accordingly.
