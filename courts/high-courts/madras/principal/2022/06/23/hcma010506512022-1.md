Application praying that this Hon'ble Court be pleased to set aside

This Application has been filed to set aside the exparte order dated
22.03.2022 in C.S.No.390 of 2020.
2.Heard both sides.
3.The learned counsel for the Applicant/first defendant submitted that

4.The learned counsel for the first respondent/plaintiff, though has
filed a formal counter, he has no serious objection in allowing this
Application.
