# High Court for the State of Telangana, CRLA/78/2011, 2011-02-21

HONOURABLE SRI JUSTICE GOPALA KRISHNA TAMADA
CRL.A.No.78 of 2011
JUDGMENT
Learned Counsel for the appellant seeks permission of this Court to withdraw the
Criminal Appeal enabling the appellant to file an appeal against the impugned judgment
before the appropriate Court.
Permission accorded.
Criminal Appeal is accordingly dismissed as withdrawn. Office is directed to return the
original papers to the learned Counsel for the appellant so as to enable him to file the same
before the appropriate Court.
