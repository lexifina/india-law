# Madras High Court, A/1049/2023, 2023-02-27

A.No.1049 of 2023
A.No.1049 of 2023
in
C.S.No.239 of 2021
SENTHILKUMAR RAMAMOORTHY, J
By this application, the sole defendant seeks to set aside the order
dated 14.09.2022.
2. In the affidavit in support of this application, it is stated that the
applicant/defendant had entrusted the matter to the previous counsel.
However, the matter was not attended to. Therefore, the applicant was set ex
parte on 14.09.2022. It is further stated that the written statement has been
made ready.
3. On instructions, learned counsel for the plaintiffs submits that he
has no objection to this application being allowed.
4. Upon considering the reasons set out in the affidavit and being
satisfied that sufficient cause is shown, this application is allowed and the
order dated 14.09.2022 by which the applicant was set ex parte is set aside.
