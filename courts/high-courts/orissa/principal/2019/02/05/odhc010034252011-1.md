# High Court of Orissa, WP(C)/23722/2011, 2019-02-05

20. 05.02.2019 On perusal of record, it is seen that on
15.01.2019, the following order was passed:
“On 28.08.2018, the following order has
been passed.
 “Learned counsel for the petitioners
requests for time.
 The matter to come up on 04.09.2018.”
 Again on 20.11.2018, the following
order has been passed.
 “Learned counsel for the petitioners
requests for time.
 The matter to come up on 11.12.2018.”
 On both the aforesaid dates, learned counsel
for the petitioners has taken time.
 In the interest of justice, as a last chance,
this matter to come up on 05.02.2019.
 It is made clear that no further time shall be
granted.”
 Even today, none appears for petitioners.
 Hence, the writ petition stands dismissed for non-prosecution.
 All connected Misc.Cases/I.As., if any are
accordingly dismissed.
