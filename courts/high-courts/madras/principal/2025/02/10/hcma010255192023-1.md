ORDER
This petition has been filed for direction to direct the second
respondent to implement the order of the first respondent dated 29.11.2022
and 23.01.2023 in proceedings No.F.No.1/328/2022 Rep. pending on the file
of the second respondent.
2. On perusal of the communication from the first respondent dated
23.01.2023 revealed that, the first respondent Commission directed the
second respondent to submit action taken report on the representation
submitted by the petitioner. Though this Court by an order dated 21.02.2023,
directed the second respondent to submit action taken report as directed by
the first respondent so far, no enquiry has been conducted by the second
respondent.
3. In view of the above, the second respondent is directed to
