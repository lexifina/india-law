ORDER
Date : 04-04-2019
This interlocutory application has been filed seeking some modification of the order, dated
29.03.2019 passed in Bail Application No. 738/2019.
The date mentioned in the 4th line of para 5 of the aforesaid order is 31.01.2018, which
according to the learned counsel for the petitioner and as per the statement made in this application,
ought to have been 31.05.2018. Accordingly, the mistake being clerical in nature, the same is
corrected to be read as 31.05.2018 instead of 31.01.2018.
This order be treated as part of the order dated 29.03.2019 passed in Bail Application No.
738/2019.

Page No.# 2/2
Interlocutory application stands disposed off.
