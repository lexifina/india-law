# High Court of Madhya Pradesh, RP/388/2016, 2016-09-20

R.P. No.388/2016
(Manorma Shakya Vs. State of M.P. & Others)

Shri Yash Sharma, Advocate for the petitioner,

opinion of this Court, no ground for review is made out.

However, petitioner is set at liberty to file a fresh petition, if so
advised and if law permits.
