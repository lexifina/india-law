# High Court of Rajasthan, WMAP/91/2015, 2015-05-14

1
S.B. CIVIL MISC. APPLICATION NO.91/2015
IN
S.B. CIVIL WRIT PETITION NO.8995/2014
Date of Order :: 14.5.2015
HON'BLE MR. JUSTICE ARUN BHANSALI
Mr. Vikram Choudhary, for the petitioner-applicant/s.
-----
An application has been filed by the petitioner-applicant
seeking amendment / correction in the order dated 18.3.2015
passed by this Court.
This Court while deciding SBCWP No.8995/2014, permitted
the petitioner to withdraw the writ petition with liberty to
question the order dated 27.9.2014 passed by the Rent Tribunal.
A prayer has been made that instead of order dated
27.9.2014, the petitioner should have been granted liberty to
question the order dated 21.11.2014.
The prayer appears to be just.
In view of the above, the application is allowed. It is
directed that in the order dated 18.3.2015 passed by this Court
instead of liberty to the petitioner to question the order dated
27.9.2014, order dated 21.11.2014 be read.
This order shall form part of the order dated 18.3.2015.
(ARUN BHANSALI), J.
