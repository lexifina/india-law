Order
07/05/2018
By this miscellaneous application, correction in the
order dated 06th March, 2018 is sought.
It is stated that due to typographical error, in last para
of the order dated 06th March, 2018, the date of order has been
mentioned as 27.02.2018, whereas, it is 27.10.2017.
As prayed, the date of order mentioned as 27.02.2018
in the last para of the order dated 06th March, 2018 is ordered to
be substituted by 27.10.2017.
With the aforesaid, the miscellaneous application is
allowed.

(2 of 2) [WMAP-198/2018]
This order be treated as part and parcel of the order
dated 06th March, 2018.
