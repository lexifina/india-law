This application under Order 22 Rule 9 of C.P.C. has been filed for setting

2

by order dated 28th of March, 2023.
2. Notices of this application were issued but no one has entered appearance.
3. The respondent No. 1/plaintiff had expired on 21.04.2016, whereas; the
present application for setting aside abatement has been filed on 13.04.2023. No
reasons have been assigned for not filing the application within a period of 90
days or no application has been filed for condonation of delay in filing an
application for setting aside abatement. However, by taking liberal view the
application in question is considered to be a composite application for setting
aside abatement as well as for condonation of delay.
4. Accordingly, the application is allowed. The abatement of First Appeal
No. 891/2011 is hereby set aside.
5. First Appeal No. 891/2011 is restored to its original file.
