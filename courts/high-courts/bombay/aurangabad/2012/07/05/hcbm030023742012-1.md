COURT'S ORDER :

1. Heard respective Counsel.
2. This is an application on behalf of respondent no.3 (original
claimant) in the First Appeal seeking to vacate interim relief granted
vide order dated 20-8-2011.
3. Perusal of the order dated 20-8-2011 reveals that stay was to
operate only if the amount, as directed, is deposited. The amount was

 ( 2 )
to be deposited within 12 weeks. That period has already expired and
the amount has not been deposited. It is apparent that there is no stay
in force. Hence, application is misconceived. Civil Application is
rejected.
