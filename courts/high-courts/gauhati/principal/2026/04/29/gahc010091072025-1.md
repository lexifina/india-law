ORDER
Date : 29.04.2026
Heard Mr. G. Kaushik, learned counsel for the applicant. Also heard Mr. M.
Hossain, learned counsel appearing on behalf of the Opposite Party.
2. It is submitted by the learned counsel for the applicant that at the time of
withdrawal of CRP(IO)473/2024, while granting liberty by this Court to the
petitioner to file an appropriate application before the Court of the learned Civil
Judge, Junior Division No. 1, Darrang, Mangaldai, vide order dated 07.04.2025;
inadvertently, it was reflected as “Order IX Rule 13 of the Code of Civil Procedure,
1908”, instead of “Order IX Rule 7 of the Code of Civil Procedure, 1908”.

Page No.# 5/5
3. By way of filing this interlocutory application, the applicant seeks correction
of the order dated 07.04.2025 to the extent that it shall be read as “Order IX Rule
7 of the Code of Civil Procedure, 1908” instead of “Order IX Rule 13 of the Code
of Civil Procedure, 1908”.
4. The prayer not being objected to by Mr. Hossain, learned counsel for the
Opposite Party, is accepted.
5. Accordingly, the order dated 07.04.2025; stands corrected to the extent
that it shall be read as “Order IX Rule 7 of the Code of Civil Procedure, 1908,
”instead of “Order IX Rule 13 of the Code of Civil Procedure, 1908”.
6. The interlocutory application accordingly stands allowed and disposed of.
JUDGE
Comparing Assistant
