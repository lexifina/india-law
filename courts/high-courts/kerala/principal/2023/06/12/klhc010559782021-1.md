This Bail Application is filed under Section 438 of
Criminal Procedure Code (Cr.P.C.)

report in Crime No.2535/2021 of Vellarada Police Station is

the Jurisdictional Court, If not appeared so far, with
appropriate application for bail, on getting summons.
With the above observation, this bail application is
closed.
