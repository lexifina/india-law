of 2014 from the file of the first respondent to the file of the
second respondent.

learned Additional Public Prosecutor, fairly submitted that he
has no objection for transfer of investigation pending in Crime
No.126 of 2014 from the file of the first respondent to the file
of the second respondent.
https://hcservices.ecourts.gov.in/hcservices/

3.Recording the above submission made by the learned
Additional Public Prosecutor, the Criminal Original Petition is
disposed of, transferring the investigation pending in Crime
No.126 of 2014 on the file of the first respondent police to the
file of the second respondent.
