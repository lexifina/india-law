# Madras High Court, A/3066/2023, 2023-06-20

A.No.3066 of 2023
in C.S.No.31 of 2010
S.SOUNTHAR, J.
This application has been filed by the
applicant/plaintiff seeking to condone the delay of
90 days in filing reply statement to the written
statement filed by the 3
rd
 defendant.
2. Under the Code of Civil Procedure as
amended by Commercial Courts Act, 2015, no
time limit is prescribed for filing reply statement
by the plaintiff. If the plaintiff wants to file reply
statement, it is for them to file appropriate
application seeking leave of the Court to file reply
statement to the written statement filed by the 3
rd
defendant.
3. In such circumstances, the present
application filed by the applicant/plaintiff seeking
condonation of delay in filing reply statement is
dismissed with liberty to the applicant/plaintiff to
file appropriate application seeking leave of the
Court to file reply statement, if so advised.
4. List the suit in C.S.No.31 of 2010 on
03.07.2023 for hearing.
