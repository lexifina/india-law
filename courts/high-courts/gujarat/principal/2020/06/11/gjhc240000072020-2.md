ORAL ORDER
Heard learned advocate Mr.Harshadkumar D. Panchal for the
applicant and learned Additional Public Prosecutor Ms. Chetna M.
Shah for the respondent- State through video conferencing.
Learned advocate Mr.Panchal for the applicant states that this
application was filed before charge-sheet, but now the charge-sheet
is filed. Therefore, under the instructions, he seeks permission to
withdraw this application so as to file appropriate application for bail
before the Court.
Permission, as prayed for, is granted. The Criminal Misc.
Application stands disposed of as withdrawn. Rule is discharged.
