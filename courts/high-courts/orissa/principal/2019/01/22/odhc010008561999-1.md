# High Court of Orissa, OJC/12417/1999, 2019-01-22

05. 22.01.2019 Learned counsel for the petitioner seeks permission to
withdraw the writ petition with liberty to file fresh application if
any cause of action arises.
 Permission is granted.
 Learned counsel for the opposite parties does not
object to the same.
 Accordingly, the writ petition stands dismissed as
withdrawn with liberty to the petitioner to file afresh if any
cause of action arises.
