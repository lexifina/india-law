This Criminal Original Petition has been filed, directing
the second respondent to file final report within the time
stipulated by this Court in connection with the case in Crime
No.231 of 2017 on the file of the second respondent.

the respondents would submit that charge sheet has been filed on
24.01.2018 before the Judicial Magistrate, Valliyoor and the same
is not yet taken on file and a copy of the charge sheet has been
filed before this Court.
3.Recording the said submission made by the learned
Government Advocate (Crl.Side), this Criminal Original Petition is
dismissed.
