# High Court of Orissa, WP(C)/6087/2018, 2018-07-03

02. 03.07.2018 It appears from the records that there is no cause of
action.
 However, learned counsel for the petitioner submits

petition with liberty to file fresh application, if cause of
action arose. A memo to that effect has been filed.
 In such view of the matter, this writ petition is
dismissed as withdrawn. The petitioner is at liberty to file
fresh application as submitted.
