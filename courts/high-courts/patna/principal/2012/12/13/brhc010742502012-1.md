ORAL ORDER
2 13-12-2012 No one appears for the petitioner.
This restoration application has been filed for
restoration of the writ application which stood dismissed for
default on account of non-appearance of learned counsel for the
petitioner on two dates.
Dismissal of a writ application in default does not
operate as res judicata. Petitioner has liberty to file a fresh writ
application.
In the restoration application, this Court has not found
any merit and the same is dismissed with the aforesaid liberty to
the petitioner.
