# High Court for the State of Telangana, CRLP/9472/2012, 2012-12-31

THE HON'BLE SRI JUSTICE K.C.BHANU
CRIMINAL PETITION NO. 9472 OF 2012
ORDER:
 The learned counsel for the petitioner/Accused No.5
seeks permission to withdraw this Criminal Petition with liberty
to the petitioner to file petition under Section 239 Cr.P.C before
the trial Court.
2. Permission is granted.
3. Recording the said submission, this Criminal Petition is
dismissed as withdrawn giving liberty to the petitioner to file an
application under Section 239 Cr.P.C for discharge before trial
court, if charges are not already framed. Miscellaneous
Petitions, if any, filed in this Criminal Petition shall stand
closed.
 ______________________
