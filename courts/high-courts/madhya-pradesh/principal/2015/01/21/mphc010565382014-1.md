# High Court of Madhya Pradesh, MCC/2722/2014, 2015-01-21

1
MCC No.2722/2014
21/1/2015.
Shri Arvind Shrivastava, learned
counsel for the applicant.
Shri J. K. Jain, learned Assistant
Solicitor General for the respondents on advance
notice.
This application has been filed for
restoration of W.P. No.3303/2007, which was
dismissed for non compliance of peremptory order
dated 7.5.2007. There being some delay, I.A.
No.16927/2014 has been filed.
Keeping in view the reasons given the
application which is supported by the affidavit of
counsel himself and finding the same to be
bonafide, both the applications are allowed.
Condoning the delay in filing the restoration
application, the restoration application itself is
allowed. W.P. No.3303/2007 is restored to its
original file. It be placed for orders before an
appropriate Bench.
Application stands allowed and
disposed of.
(Rajendra Menon) (S. K. Gangele)
