HON'BLE MR. JUSTICE ALOK SHARMA
Order
21/03/2018
Matter comes up on an application for correction of the
typographical error in the order dated 12.3.2018.
Counsel submits that in the order dated 12.3.2018,
name of Mr. J.P. Sharma has been shown as appearing for the
petitioner when in-fact he appeared for the respondent in the
contempt petition alongwith Raj Kumar Tongawat. It has been
prayed that typographical error in the order dated 12.3.2018 be
accordingly corrected.
The prayer in the application is innocuous. Resultantly
the application is allowed. Name of Mr. J.P. Sharma, Advocate be
taken as appearing for the respondent when the order was passed
on 12.3.2018.
The typographical error in the said order dated
12.3.2018 stands accordingly rectified. This order shall constitute
an integral part of the order dated 12.3.2018.

(2 of 2) [CMAP-87/2018]
Application stands disposed of accordingly.
 (ALOK SHARMA),J
