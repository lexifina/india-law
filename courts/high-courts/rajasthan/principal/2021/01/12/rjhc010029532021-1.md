HON'BLE MR. JUSTICE VINIT KUMAR MATHUR
Order
12/01/2021
 Heard learned counsel for the parties.
 The matter comes upon an application seeking correction in
the order dated 11/01/2021.
Learned counsel for the petitioner submits that inadvertently,
the number of CR/FIR number has been reflected as 591/2020 in
the order dated 11/01/2021, whereas the same may be reflected
as C.R./FIR No.264/2020.
For the reasons mentioned in the application, the same is
allowed. In the order dated 11/01/2021, the number of CR/FIR
be read as 264/2020 instead of 591/2020.
