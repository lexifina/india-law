# High Court of Madhya Pradesh, MCC/2824/2014, 2015-08-07

MCC-2824-2014
(THE JANPAD PANCHAYAT Vs DEVI)
07-08-2015
Shri Naveen Kumar, learned counsel for the applicant.
This application has been filed for restoration of Misc. Appeal
No.3822/2013, which was dismissed on account of common
conditional order passed on 27/01/2014. There being some delay
in filing the application for restoration, I.A. No.17407/2014 has
been filed seeking condonation of delay. Both the applications are
supported by an affidavit and there is no reason to disbelieve the
same. Finding the same to be bonafide, both the applications are
allowed.
Condoning the delay in filing the application, restoration
application is itself allowed.
Misc. Appeal No.3822/2013 is restored to its original
number. It be placed for orders before appropriate Bench.
Application stands allowed and disposed of.
A copy of this order be kept in the record of Misc. Appeal
No.3822/2013.
Certified copy as per rules.
(VANDANA KASREKAR)
JUDGE
