. Heard learned counsel for the parties.
2. By this Application, the Applicants seek re-call of the order
dated 28.03.2019 passed by this Court ( Coram : M. S. Sonak, J. ), by
which the Applicants’ Revision Application was dismissed for want of
prosecution, as none appeared for the Applicants.
3. For the reasons set out in the Application, the Application is
allowed. The order dated 28.03.2019 dismissing the Revision
Application for want of prosecution is re-called and the aforesaid
Revision Application is restored back to its original file. Delay of 91
days caused in filing the aforesaid Revision Application is also
