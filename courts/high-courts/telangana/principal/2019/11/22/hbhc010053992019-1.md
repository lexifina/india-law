# High Court for the State of Telangana, CRLP/825/2019, 2019-11-22

HONOURABLE JUSTICE G. SRI DEVI
CRIMINAL PETITION No.825 of 2019
ORDER:
1. This Criminal Petition is filed under Section 482 Cr.P.C. seeking
to quash the proceedings in Crime No.1878 of 2018 on the file of
Raj endranagar Police Station, Cyberabad.
2. Learned counsel for the petitioners addressed letter dated
20.11.2019 to the Registrar (Judicial) for posting this case for
withdrawing the same with liberty to file a fresh Criminal Petition.
3. At the hearing, learned counsel for the petitioners seeks
permission of this Court to withdraw this Criminal Petition with liberty
to the petitioners to file a fresh case.
4. Permission is accorded and the Criminal Petition is accordingly
dismissed as withdrawn with liberty to the petitioners to file a fresh
criminal petition.
5. As a sequel thereto, miscellaneous petitions, if any, pending
shall also stand dismissed.
________________
JUSTICE G. SRI DEVI
22nd November, 2019
