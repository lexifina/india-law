HARSIMRAN SINGH SETHI , J. (ORAL)
After arguing for some time, learned counsel for the
petitioner prays that he be allowed to withdraw this petition so as to
enable the petitioner to appear before the learned trial Court.
Ordered accordingly.
At this stage, learned counsel for the petitioner submits that
the bail application which the petitioner intends to file before the learned
trial Court, be ordered to be decided expeditiously.
This Court has no apprehension that in case the petitioner
files an application seeking bail, the same will be decided in accordance
with law without any unnecessary delay and therefore, no direction in this
regard is needed to be issued to the learned trial Court.
