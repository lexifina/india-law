# High Court for the State of Telangana, CC/698/2019, 2019-07-26

THE HON’BLE SRI JUSTI CE SANJAY KUMAR
CONTEMPT CASE No.698 of 2019
ORDER:
The respondent is present in person.
2. This contempt case was instituted alleging wilful disobedience to
the order dated 06.03.2019 passed in W.P.No.4552 of 2019.
3. Sri V.Venkata Mayur, learned counsel for the petitioner, would
however inform this Court that the order has since been complied with.
4. In that view of the matter, the contempt case is closed. No order
as to costs.

 SANJAY KUMAR, J
