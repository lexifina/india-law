16.09.2022
Heard Mr. Sourabh Sahu, learned counsel for the petitioner. Also
heard Mr. H.S. Ahluwalia, learned counsel, appearing for the
respondents.
2. Mr. Sahu submits that he has got instructions to file an application
for conversion of this public interest litigation to a writ petition.
3. Petitioner had deposited a sum of Rs. 5000/- as security deposit for
filing the public interest litigation.

2
4. We are of the opinion that the petitioner may file a writ petition, if so
advised, with regard to the grievance expressed in this public interest
litigation.
5. Taking that view, without expressing any opinion on the merits of
the petition, this public interest litigation is closed giving liberty to the
petitioner to file a writ petition.
6. The security deposit of Rs. 5,000/- be refunded back to the
petitioner.
