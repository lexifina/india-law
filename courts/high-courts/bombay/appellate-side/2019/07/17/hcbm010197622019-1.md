IN THE HIGH COURT OF JUDICATURE AT BOMBAY
CRIMINAL APPELLATE JURISDICTION
CRIMINAL APPLICATION NO.615 OF 2019
IN
ANTICIPATORY BAIL APPLICATION NO.1594 OF 2018
Rajesh Sitaram Halwai and Anr. ...Applicants
 Versus
The State of Maharashtra ...Respondent
Mr.A.R.Khairnar, for the Applicants.
Mr.V.V.Gangurde, A.P.P for the Respondent - State.
 CORAM : REVATI MOHITE DERE, J.
DATE : 17th JULY, 2019
P.C. :
1. Heard the learned counsel for the Applicants.
2. By this application, the applicants seek recall of the order dated
8
th January, 2019, and prays for restoration of Anticipatory Bail
Application No.1594 of 2018, which came to be dismissed for want of
prosecution.

2/2 906-appp.615.2019.doc
3. For the reasons set out in the application, the application is
allowed. The order dated 8th January, 2019, is recalled and Anticipatory
Bail Application No.1594 of 2018, is restored to file along with the interim
order granted on 10th August, 2018.
4. The Application is accordingly disposed of.

5. Anticipatory Bail Application No.1594 of 2018, be listed for
'admission' on 19th July, 2019.
 REVATI MOHITE DERE, J.
