HON'BLE MR. JUSTICE SANJEEV PRAKASH SHARMA
Order
02/07/2020
Learned counsel for the petitioners has pointed out that an
error has been erroneously crept in the order dated 30.6.2020 as

(2 of 2) [CRLMA-153/2020]
a line has been entered in the order dated 30.6.2020, which does
not relate to the case i.e. “charge sheet has already been filed”.
Taking into consideration that the bail application was under
Section 438 Cr.P.C., this court is satisfied that the line has
wrongfully and erroneously been typed in the order. The same is
directed to be treated as deleted for all intends and purposes.
The present order shall be treated as part and parcel of the
order dated 30.6.2020.
The application stands disposed of accordingly.
(SANJEEV PRAKASH SHARMA),J
