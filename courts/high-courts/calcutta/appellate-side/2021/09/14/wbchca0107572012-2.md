 CRIMINAL REVISIONAL JURISDICTION
 APPELLATE SIDE
 ( Via Video Conference )
 CRR 691 of 2012
 In the matter of : Subir Bhattacharjee . …..petitioner.
In Re : An application under Section 482 of the Code of
Criminal Procedure.
 Mr. Bidyut Kumar Roy
 Mr. Ashoke Das
 …..for the State.
 The revisional application was preferred challenging
the proceedings relating to quashing of the F. I. R being
Bagdogra P. S. Case No. 345 of 2011 dated 18.12.2011 under
Section 420 of the Indian Penal Code pending before the
learned Additional Chief Judicial Magistrate, Siliguri.
 Record of this revisional application reflects that by
an order dated 16.03.2012, a Co-ordinate Bench of this court
directed the investigation to continue but directed not to
submit chargesheet or FRT without the leave of this court.
 The report submitted by the learned Officer-in-Charge,
Bagdogra P. S., Siliguri Metropolitan Police be kept with the
record.

2
 The Officer-in-Charge, Bagdogra P. S., SPC is directed to
submit the chargesheet or FRT if the same is ready and has
not been submitted before the court.
 No interference is required to be made at the stage of
the proceedings by this court.
 Accordingly, the present revisional application being
CRR 691 of 2012 is dismissed.
 All pending applications, if any, in connection with
revisional application, are consequently disposed of.
 Interim order, if any, is hereby vacated.
 All parties are to act on the server copy of this order
duly downloaded from the official website of this court.
 ( Tirthankar Ghosh, J. )
