applicant/petitioner.
This is an application for speaking to minutes. According to
the learned counsel for the applicant/petitioner, name of the
petitioner has been wrongly mentioned as ‘Sachin Raman Dangre’
when, in fact, his name is Sachin Raman Dangra. This position
has not been disputed by the learned APP appearing for the
respondents. Hence, the application is allowed. The name of the
petitioner be corrected as ‘Sachin Raman Dangra’ instead of Sachin
Raman Dangre.
The application stands disposed of.
