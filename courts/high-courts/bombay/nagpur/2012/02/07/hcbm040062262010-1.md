None for the applicant. It appears that the
applicant is not interested in prosecuting the present
application. This Court (Coram : A.H. Joshi, J) on 5th
December, 2011 has passed following order :
“Learned Advocate for the applicant prays for
time to make a statement as to whether the
applicant is serious about pursuing the case.
 S.O. to 13.12.2011.”
It appears from the above stated order that the
applicant has lost interest in prosecuting the application.
The application is, therefore, dismissed.
Ad-interim relief, if any, stands vacated.
