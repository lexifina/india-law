# High Court of Uttarakhand, WPCRL/1499/2014, 2015-01-16

CLMA No.593/2015 (Application for Withdrawal)
In
WPCRL No.1499 of 2014
Honíble V.K. Bist, A.C.J.
Mr. Niranjan Bhatt, Advocate holding
brief of Mr. Suhail Ahmed Siddiqui, Advocate
for the petitioners.
Mr. H.S. Rawal, Assistant Government
Advocate for the State of Uttarakhand.
Mr. Parikshit Saini, Advocate for the
respondent no.3.
Heard learned counsel for the parties.
Learned counsel for the petitioners
seeks permission of this Court to withdraw
this writ petition with liberty to file fresh.
At this, learned counsel for the
respondent no.3 submitted that in case the
petitioners file fresh petition, the copy of the
same may been supplied to him.
The writ petition is dismissed as
withdrawn with liberty to file fresh. In case
petitioners file fresh petition, the copy of the
petition be served to the counsel for the
respondent no.3.
Withdrawal application stands disposed
of. Stay application stands rejected.

 (V.K. Bist, A.C.J.)
M.K. 16.01.2015
