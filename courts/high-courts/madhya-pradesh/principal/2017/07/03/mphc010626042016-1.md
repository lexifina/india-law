# High Court of Madhya Pradesh, MCC/3277/2016, 2017-07-03

M.C.C. No.3277/2016
03.07.2017
Shri Balkishan Choudhary, learned counsel for the applicant.
This MCC is listed today for correction of typographical error occurred in the
order dated 15.12.2016 passed by this Court.
Learned counsel for the applicant submits that in the aforesaid order, S.A.
No.1447/2015 has wrongly been mentioned as S.A. No.1447/2016 in para no.5, 7 & 9.
Considering the aforesaid and on perusal of the records, this Court finds that in
the order dated 15.12.2016 there is some typographical error. Hence, it is directed
that in the order dated 15.12.2016 be read as 'S.A. No.1447/2015' in place of 'S.A.
No.1447/2016'.
This order shall be read conjointly with the order dated 15.12.2016.
 (SMT. ANJULI PALO)
 JUDGE
