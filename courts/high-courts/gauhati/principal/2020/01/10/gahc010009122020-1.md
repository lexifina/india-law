Date : 10-01-2020
 Heard Mr. H. Das, learned counsel for the applicant.
The applicant has earlier approached this Court by an application under Section 439,
Cr.P.C. seeking his release on bail in connection with Hajo P.S. Case No. 1039/2019 which was
registered and numbered as BA No. 12/2020. The applicant has been allowed to be released
on bail by order dated 09.01.2020 but while passing the order, a typographical error had
crept in the said order and instead of “learned CJM, Kamrup, at Amingaon”, “learned CJM,
Kamrup (M)” has been reflected. As the same is a typographical error, this application has
been filed for rectifying of the same.

Page No.# 2/2
The applicant has further submitted that while preferring BA, there was an error on
the part of the applicant in correctly typing the name of the father of the applicant. As per
him, the same should have been “Late Bishnu Jyoti Kalita @ Bishnu Ram Kalita” instead of
“Lt. Bishinu Jyoti Kalitai @ Bishnu Ram Kalit”.
I have considered the averments made in the application and perused the order
dated 09.01.2020. As the same appears to be typographical errors which had crept in
inadvertently, the same requires correction and such correction will not prejudice any of the
parties.
Accordingly it is ordered that in the order dated 09.01.2020 passed in BA No.
12/2020 instead of “Lt. Bishinu Jyoti Kalitai @ Bishnu Ram Kalit”, the same should be read as
“Late Bishnu Jyoti Kalita @ Bishnu Ram Kalita” and instead of “learned CJM, Kamrup (M)”,
“learned CJM, Kamrup, at Amingaon” should be read.
This application stands disposed of in the aforesaid terms.
 JUDGE
