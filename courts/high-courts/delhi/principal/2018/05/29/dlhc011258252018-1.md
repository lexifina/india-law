 Learned counsel for the respondent states that provisional
release order has been passed.
 Learned counsel for the petitioner states that the said
provisional release order has not been served.
Without going into the controversy whether or not the
provisional release order has been served on the petitioner, the
respondent, it is directed, will send a certified copy of the provisional
release order to the petitioner as well as learned counsel for the
petitioner by speed post within four working days from today.
The petitioner, if aggrieved by the provisional release order,

would be entitled to challenge the same in accordance with law. We
clarify that we have not made any comments on merits.
Recording the above, the petition is disposed of, with no order
as to costs.
