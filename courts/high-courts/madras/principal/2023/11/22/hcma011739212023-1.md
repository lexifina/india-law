This application has been filed by the second and third defendant's to
reject the plaint filed under Order VII Rule 11 of Code of Civil Procedure.
2. The main ground on which the suit sought to be rejected is that
there was collusion between the plaintiff and the first defendant and having
received consideration, the document cannot be assailed. Hence, the plaint
is sought to be rejected.
3. I have heard the learned counsel on either side and perused
materials. A perusal of the allegations found in the affidavit, this
application cannot be entertained. The suit can be rejected only on the
grounds set out in Order XI Rule 7 CPC, which reads as follows :

(c) where the relief claimed is properly valued, but the

(d) where the suit appears from the statement in the

4. It is relevant to note that even clause b and c set out above will not
apply to the Chartered High Courts as per Order XLIX Rule 3 of CPC. In
such view of the matter, the suit can be rejected only if there is no cause of
action or the suit is barred by any law or it is not filed in duplicate and on
failure to comply the Rule under Order VII Rule 11 of CPC. Merely on the
