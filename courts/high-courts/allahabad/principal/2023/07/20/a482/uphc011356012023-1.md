counsel for the applicants that there is chances of conciliation
and mediation between the parties. Hence, a prayer has been
made to dismiss the present application as not pressed with
liberty to file afresh, if so required.
The prayer so made is allowed.
Accordingly, the present application is dismissed as not pressed
with the liberty as prayed.
