CM No.756/2026
This is an application seeking condonation of delay in filing the
application for restoration of appeal.
 For the reasons set out in the application which is duly supported by
an affidavit, particularly, as the prayer made therein is not opposed by the
other side, the same is allowed. Consequently, the delay in filing the
application for restoration of appeal is condoned.
CM disposed of.
CM No.757/2026
 For the reasons set out in the application, which is duly supported by
an affidavit, the same is allowed. Consequently, the order dated 20-05-2025
is withdrawn and the appeal bearing LPA No.02/2024 is restored to its
original number.
Application disposed of.
LPA No.2/2024
