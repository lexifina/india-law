ORAL ORDER
Learned APP, under the instructions of Head Constable
Shri P.R. Patel, Pandesara Police Station, states at bar that
the charge sheet has already been filed, therefore, learned
advocate for the applicant seeks permission to withdraw
present application with a liberty to file discharge application
and also to file appropriate proceedings either u/s 397 or 482
of the Code of Criminal Procedure, 1973 before appropriate
competent Court, after remedy to file discharge application is
availed. Permission is granted. The application stands
disposed of as withdrawn with above liberty.
It is clarified that this Court has not examined the merits
of the present application at this stage.
(S.H.VORA, J)
