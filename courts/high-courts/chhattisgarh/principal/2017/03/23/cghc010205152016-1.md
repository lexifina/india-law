Heard.
2. There is allegation that despite various orders of removal of encroachment,
encroachments are not being removed.
3. Referring to averments made in reply, learned counsel for State submits that the
encroachments have been removed.
4. This factual position is disputed by learned counsel for the petitioner by
submitting that the encroachments have not been completely removed. Let, the

Collector, Kondagaon examine this matter and obtain a fact-finding report from the
Tahsildar, whether the encroachments, which were directed to be removed, have been
removed or not and if that is not done, appropriate action should be taken towards
removal of encroachment as early as possible, if any, is still standing.
5. With the aforesaid observation, this petition is finally disposed off.
