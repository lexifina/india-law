ORDER
Date : 26-09-2019
This interlocutory application has been filed stating therein that the case number, name
of the advocate and petitioner, mentioned in the order, are not correct so far the order
dated 4.9.2019, passed in AB 2497/2019 is concerned.
But, on perusal of the said order itself, it is found that there is no mistake in the order so far
the number of case and the name of the petitioner and the advocate are concerned.
The learned counsel for the petitioner has produced before this court a certified copy of the
order dated 4.9.2019, passed in AB 2497/2019.
On examination of the said certified copy of the order, it is found that the case number
therein is shows as Baghbar PS Case No. 170/2019, the advocate for the petitioner is shown
Mr. M. Ahmed, and name of the petitioners shown thereto, do not tally with the order passed
by this court, in the aforesaid Anticipatory Bail application.

Page No.# 2/2
Accordingly, registry is directed to rectify the certified copy issued in respect of the aforesaid
order in the Anticipatory Bail application to be in accordance with the order actually passed in
the file.
The IA stands disposed of accordingly.
