# Gauhati High Court, I.A./615/2016, 2016-03-09

I.A. 615/2016
BEFORE
HON’BLE MR. JUSTICE N. CHAUDHURY
Heard Mr. A. Alam learned counsel for the appellant/petitioner.
By filing this application under Order 41 Rule 5 of the Code of Civil Procedure,
a prayer has been made for staying operation of the impugned judgment and decre
e dated 21.09.2015, whereby the suit of the plaintiff has been dismissed.
Since there is no decree to be executed, this application is infructuous. It is
accordingly closed.
