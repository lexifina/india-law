HON'BLE MR. JUSTICE VINIT KUMAR MATHUR
Order
06/07/2020
The matter comes upon an application seeking correction in
the order dated 24.02.2020 passed by this Court in S.B. Criminal
Misc. Bail Application No.2300/2020, wherein the F.I.R. number is
shown as 91/2018. This F.I.R. number and year has been
reflected in the order dated 24.02.2020 on the basis of same
having been recorded in the impugned order dated 19.11.2019.
Learned counsel for the petitioner submits that the F.I.R.
No.91/2018 was incorrectly mentioned as the same is 91/2019.
In pursuance of the same, the learned trial Court has corrected
the number of the F.I.R. in the order impugned dated 19.11.2019.
In these circumstances, the application preferred by the
learned counsel for the applicant for correction in the order dated

(2 of 2) [CRLMA-129/2020]
24.02.2020 is allowed. The “F.I.R. No.91/2018” wherever
reflected in the order dated 24.02.2020 be now read as “F.I.R.
No.91/2019”.
(VINIT KUMAR MATHUR),J
