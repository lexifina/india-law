J U D G M E N T
This writ petition is filed seeking to set aside the order
in Ext.P7. It is an interim application filed by the defendant
in the suit for the issuance of a Commission. The Court
below has allowed that application. It is against that
decision the plaintiff has come up with this writ petition. A
perusal of the order would reveal that already a
Commissioner has been appointed in the matter and he has
submitted his plan and report. If a person is having
objection to the Commissioner's plan and report or he is of
the view that it is to be set aside, the procedure to be
adopted is to set aside the first Commissioner's plan and
report, then apply before the Court for issuance of a
Commission. This Court has cautioned on so many occasions
that there cannot be issuance of successive Commissions in a
very same case because it will result in confusion rather than

resolution. Therefore, the very application filed by the
defendants in the case when there is a Commissioner's plan
and report on record should not have been entertained by
the Court below. Therefore, I set aside the order passed by
the Court below and the interim application will stand
dismissed but further I make it clear that this will not debar
the defendants from filing an application if they think to do
so for remitting the Commissioner's plan and report or
setting aside the Commissioner's plan and report and the
Court after hearing both sides shall dispose of the same in
accordance with law, if so filed.
The writ petition is disposed of accordingly.
