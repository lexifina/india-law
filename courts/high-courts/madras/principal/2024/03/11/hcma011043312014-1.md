# Madras High Court, OA/393/2014, 2024-03-11

and

ABDUL QUDDHOSE.J.,
M/s.Sun TV Network Ltd. ... Applicant
Vs.
M/s.Vijaya Productions and Others ... Respondents
*****
Learned counsel for the plaintiff seeks further time to file written
arguments. The defendants have already been set ex-parte by this Court.
Since O.A.No.393 of 2014 is kept pending from 2014 onwards and till date,
no interim injunction has been granted in favour of the plaintiff, it is not
necessary to keep the said application pending as the suit is ripe for
arguments. Accordingly, O.A.No.393 of 2014 is closed.
