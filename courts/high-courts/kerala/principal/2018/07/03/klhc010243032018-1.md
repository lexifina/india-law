 Dated this the 3rd day of July, 2018
JUDGMENT
This is an application for speedy disposal. A report
shows that 3rd defendant was set ex-parte and IA No.
11816/2016 to set aside the same is pending before the court.
Now the 3rd defendant has filed petition as IA No.11816/2016
along with written statement to set aside the ex-parte order
and the same is pending before the court. On a perusal it is
found that the 3rd defendant is none other than the state.
Keeping in mind the totality of the case, I feel that the time
bound disposal cannot be ordered. Surely an expedite
disposal is expected from the court below.
With the above direction, this petition is disposed of.
Sd/-
 K.P. JYOTHINDRANATH, JUDGE
