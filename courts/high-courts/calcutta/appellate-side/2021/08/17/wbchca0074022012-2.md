# Calcutta High Court, CRR/437/2012, 2021-08-17

17.08.2021 IN THE HIGH COURT AT CALCUTTA
 Item No.2 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
 C.R.R. 437 of 2012
(Via Video Conference)
 Kanai Mondal
 versus
 The State of West Bengal
In Re: An Application under Section 482 of the Code of
Criminal Procedure, 1973.
Mr. Arijit Ganguly,
Mr. Sandip Chakraborty … For the State.
This revisional application was preferred in connection
with Case No. N-126 of 2011 pending before the learned 6th
Additional District Judge, Barasat, 24-Parganas (North)
arising out of New Town Police Station Case No. 451 of 2011
dated 25.11.2011 under Section 20(i)(b) of the NDPS Act.
The purpose for preferring the application is for
expediting the proceedings. Earlier by an order dated
12.08.2021, a report was called for. Accordingly, Inspector-in-Charge, New Town Police Station has submitted a report
which reflects that the present petitioner has been acquitted
of the charges in connection with the said case.
In view of the aforesaid, the revisional application need
not be proceeded on merits. Accordingly, CRR 437 of 2012 is
dismissed.
Interim order, if any, is hereby vacated.
All pending connected applications, if any, are
consequently disposed of.

2
Report dated 17.08.2021, so submitted by the
Inspector-in-Charge, New Town Police Station, be kept with
the record.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
 (Tirthankar Ghosh, J.)
