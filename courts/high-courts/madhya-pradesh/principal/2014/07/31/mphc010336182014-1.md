# High Court of Madhya Pradesh, MCC/1406/2014, 2014-07-31

1
MCC No.1406/2014
31/7/2014.
Shri Ajeet Singh, learned counsel for
the applicant.
This application has been filed for
restoration of W.A. No.349/2014 which has been
dismissed for want of prosecution on 14.7.2014.
Keeping in view the grounds and
reasons indicated in the application which is
supported by an affidavit of counsel himself, this
application is allowed. Writ Appeal is restored to
its original file. It be placed for orders before
the appropriate Bench.
With the aforesaid, this application
stands allowed and disposed of.
(Rajendra Menon) (Alok Verma)
