P.C. :
Heard learned counsel for the applicant in both the bail
applications also heard learned A.P.P. for respondent – State of
Maharashtra. After prolonged hearing, when the Court started
dictating the order that this is not the case wherein bail can be granted
for various circumstances, learned counsel for the applicant prays for
withdrawal of both the bail applications with a request to again apply
for bail afresh if trial against the applicant in both the matter are not
completed within a specified time.
2 Considering the request, both the bail applications are
dismissed and accordingly disposed off. Directions are given to the

3 If there is no scope of conclusion of trial within one year,

these directions both the applications are disposed off.
