# High Court for the State of Telangana, CRLP/3576/2012, 2014-07-15

THE HON’BLE SRI JUSTICE S.RAVI KUMAR
CRIMINAL PETITION NO.3576 OF 2012
ORDER:
This Criminal Petition is filed to quash the order dated
27.02.2012 passed in Crl.M.P.No.5 of 2012 in Sessions Case No.212
of 2011 on the file of the VI Additional District and Sessions Judge,
Fast Track Court, Narsapur, seeking interim custody of case
properties.
Heard both sides.
It is represented that in main Sessions Case, trial is completed
and it is coming for arguments.
While disposing main case, Sessions Court is expected to pass
property order. If the property order is not passed, the petitioners can
as well approach the same Court seeking orders in respect of case
property, since order under challenge was only for interim custody
during pendency of the main case.
With this observation, this Criminal Petition is disposed of.
Miscellaneous petitions, if any, pending shall stand closed.
_______________
(S.RAVI KUMAR, J)
