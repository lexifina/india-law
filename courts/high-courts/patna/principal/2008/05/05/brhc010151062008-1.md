# Patna High Court, CR. MISC./12175/2008, 2008-05-05

IN THE HIGH COURT OF JUDICATURE AT PATNA
 Cr.Misc. No.12175 of 2008
 DINESH YADAV
 Versus
 STATE OF BIHAR
 -----------
3 5.5.2008 By order dated 17.3.2008 , the petitioner was directed to file
a copy of rejection order within a fortnight .However, the same has
not been filed and it is submitted before the Court that prayer for
Anticipatory bail before the learned Sessions Judge, Jehanabad has
been rejected on 3.5.2008, which apparently would mean that this
application was filed even prior to the rejection order by the Sessions
Judge and in that view of the matter this application for anticipatory
bail appears to be pre-mature.
Learned counsel for the petitioner prays for permission to
withdraw this application in view of the discussion made above.
Accordingly, this application is dismissed as withdrawn.
 ( Abhijit Sinha, J )
