# High Court of Madhya Pradesh, MCC/1221/2014, 2014-09-08

1
MCC No.1221/2014
8/9/2014.
Shri Sanjay Lal, learned counsel for the
applicant.
Keeping in view the provisions of High
Court Rules, as this is an application for restoration
of an appeal which has been dismissed the office
ojection is over ruled.
This application has been filed for
restoration of ITA No.189/2012, which was
dismissed for non compliance with the peremptory
order passed by this Court on 9.1.2014.
Keeping in view the reasons given the
application for restoration, which is supported by
affidavit of the competent officer, the same is
found to be bonafide and is, therefore, allowed. ITA
No.189/2012 is restored to its original file. It be
placed for orders before an appropriate Bench.
Application stands allowed and disposed
of.
(Rajendra Menon) (Anil Sharma)
