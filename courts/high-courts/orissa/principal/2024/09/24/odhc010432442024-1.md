 02. 1. This matter is taken up through hybrid mode.
2. The Petitioner by filing the application has prayed for
amendment of the writ petition.
3. Keeping in view the magnitude of the amendment sought
to be introduced, learned Counsel for the Petitioner fairly submits
that it would be ideal for the Petitioner to file a fresh writ petition.
She, therefore, prays for withdrawal of this petition seeking
liberty to file better petition.

 Page 2 of 2.
 4. Learned Counsel for the OSFC, being present raises no
objection to the same.
 5. Accepting the submissions of the learned Counsel for the
Petitioner, we dispose of this writ petition as withdrawn granting
liberty to the Petitioner to file better petition.
 The original demand notice annexed to the I.A. be
returned to the learned Counsel for the Petitioner on substitution
of attested photocopy thereof.
6. The writ petition and Interim Application are accordingly
disposed of.
 Issue urgent certified copy as per rules.
