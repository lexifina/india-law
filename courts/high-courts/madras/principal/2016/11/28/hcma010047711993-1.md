JUDGMENT
The learned counsel for the appellant submits that
despite a letter dated 11.11.2016, written by him to the
appellant informing that the matter will be taken on file by
this Court on 25.11.2016 and if there is no response from the
appellant, he report "no instruction" before this Court,
there is no instruction from the appellant. The same is
recorded.
https://hcservices.ecourts.gov.in/hcservices/

2.In view of the above position, it appears that the
appellant is not interested in prosecuting the matter
further. Accordingly, the Second Appeal is dismissed for non
prosecution. There shall be no order as to costs.
