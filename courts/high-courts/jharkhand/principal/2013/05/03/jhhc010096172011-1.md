6./03.05.2013 Having heard learned counsel appearing for the petitioner and the
learned counsel for the CBI, I do not find any illegality with the order taking
cognizance as the F.I.R. does constitute offence under which it has been
registered and, therefore, order taking cognizance never warrants to be
quashed.
However, the points, which have been raised in this application,
be raised at an appropriate stage.
With these observations, this application stands disposed of.
