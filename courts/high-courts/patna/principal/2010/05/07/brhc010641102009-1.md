02/ 07.05.2010 The grievance in this application for contempt is
that order dated 14.02.1995 passed in MJC No.1399 of
1994 has not yet been complied with.
Mr. Manoj Kumar Singh, learned counsel for the
State that the order has already been complied with as
reflectable from Annexure-6 dated 14th August, 1995.
In view of the aforesaid, nothing remains to be
adjudicated in this proceeding for contempt and,
accordingly, the same stands dropped.

- 2 -
Be it noted, after the order was complied with
in pursuance of the order passed in the writ petition,
some benefit has been withdrawn from the petitioner. If
the petitioner is grieved by the same, it is open to him to
file an independent proceeding as advised in law.
