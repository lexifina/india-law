P.C.:
The prayer for quashing the First Information
Report and the criminal proceedings on the ground
of settlement has been already rejected by an order
dated 9th August 2016. The learned counsel
appearing for the Applicant pointed out that now the
chargesheet has been filed. This is not the case
where the Applicant is relying upon any documents
which are not part of the chargesheet. Hence, the
appropriate remedy available for the Applicant is to

apply for discharge. Accordingly, we dispose of this
Application by granting liberty to the Applicant to
file an application for discharge. All contentions on
merits are kept open.
