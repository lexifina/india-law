ORDER
The petition has been filed seeking to quash the order in ID No.17 of
2005 on the file of the Labour Court, Salem the first respondent herein, dated
15.10.2008 passed herein.
2. When the matter is taken up for hearing, the learned counsel for the
petitioner as well as the second respondent fairly submitted that the award
passed by the first respondent is non-speaking order, which has to be
necessarily interfered with. Hence, this Court may set aside the impugned
order and remand the matter back to the first respondent for fresh
consideration.
3. In view of the fair submission made by the learned counsel on either
side, this Court is inclined to set aside the imugned order. Accordingly, the
same is set-aside and remands the matter back to the first respondent for fresh
consideration. The first respondent is directed to consider the same and pass
appropriate orders after providing opportunity to the petitioner Company as
well as the second respondent on merits as expeditiously as possible.
