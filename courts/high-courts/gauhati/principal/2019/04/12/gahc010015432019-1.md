HONOURABLE MR. JUSTICE KALYAN RAI SURANA
ORDER
Date : 12.04.2019
None appears on call for the applicant. However, Mr. G. Bordoloi, learned Govt. advocate for
State respondent as well as Mr. A. Kalita, learned standing counsel for the Industries
Department are present.
It is seen that in the order 03.04.2019, this Court had recorded that none had appeared on
call for the applicant and no one had pressed this application on 25.02.2019 as well as
15.03.2019. It appears that by order dated 15.03.2019, this Court had recorded that if there
is no representation on the next date, this court would be constrained to dismiss the
application for non-prosecution.
As no one is pressing for this application and the applicant is un-represented when the matter
is called, this Court is inclined to dismiss this application for non-prosecution.
 JUDGE
