# High Court of Tripura, Crl.Petn./36/2015, 2015-08-31

Case No :Crl.Petn. 0000036/2015
Party Name : THE STATE OF TRIPURA Vs NILANJAN DATTA @ PALTU
THE HONBLE MR JUSTICE U. B. SAHA
When the matter is taken up, Mr. Ghosh, learned P.P. wants to withdraw this petition with a
liberty to file appropriate application before the Special Court, Khowai, West Tripura, for
cancellation of the bail.
Prayer is allowed. It is made clear that if the application for cancellation of the bail is not
considered by the Special Court, then the petitioner State will be at liberty to approach this
Court, if so advised.
With these observations and directions this instant application is disposed of as withdrawn.
A copy of this order be supplied to Mr. Ghosh, learned P.P.
