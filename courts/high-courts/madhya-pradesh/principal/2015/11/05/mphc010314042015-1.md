# High Court of Madhya Pradesh, MCC/1782/2015, 2015-11-05

MCC-1782-2015
(THE STATE OF MADHYA PRADESH Vs M/S ARANYA CONSTRUCTIONS)
05-11-2015
Shri P. Jain, learned panel lawyer for the
applicants/State.
This application has been filed for restoration of C.R.
No.121/2003, which was dismissed for non-compliance of
the peremptory order on 08.12.2014. There being some
delay, I.A. No.8183/2015 has been filed.
Keeping in view the reasons given the application which
is supported by the affidavit of counsel himself and
finding the same to be bonafide, both the applications
are allowed.
Condoning the delay in filing the restoration application,
the restoration application itself is allowed, C.R.
No.121/2003 is restored to its original file. It be placed
for orders before an appropriate Bench.
Application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
(KESHAV KUMAR
TRIVEDI)
