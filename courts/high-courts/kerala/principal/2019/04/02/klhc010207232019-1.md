The learned counsel for the petitioner submits that there has been an
omission in the application to mention a few vital facts. Therefore the
learned counsel seeks permission to withdraw the application with liberty to
apply afresh for the very same relief. The permission sought for is only to be
granted. Hence granted. The application is dismissed as withdrawn. Its
dismissal will not stand in the way of the petitioner filing a fresh application
for the very same relief.
