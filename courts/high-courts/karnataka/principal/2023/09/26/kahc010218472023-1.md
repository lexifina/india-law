ORDER
 Learned counsel for the petitioners seeks leave of
this Court to withdraw the petition reserving the liberty to
file written arguments before the trial Court.
 2. The aforesaid submission is placed on record.
 3. Accordingly, petition is dismissed as withdrawn
reserving liberty to the petitioner to file written arguments
before the trial Court. If written arguments are filed
before the trial Court, the trial Court to consider the same
at the time of passing the final order.
4. In view of dismissal of the main petition,
pending interlocutory application does not survive for
consideration.
