Order On Board
14/11/2019
1. Heard on admission.
2. Admit.
3. Also heard on an application under Section 482 of Cr.P.C. for
correction in the order dated 22.10.2019 passed in MCRCA No.
1114/2019.
4. Learned Counsel for the Applicant submits that due to
typographical error the name of the Police Station has wrongly
been typed as Police Station Tarbahar Distt. Bilaspur,
Chhattisgarh in the bail application as a result of which the same
has been typed in the bail order dated 22.10.2019 of this Court.

The correct name of the Police Station should be mentioned in
bail application as well as in the bail order dated 22.10.2019 of
this Court as Police Station Khadgaonwa, District Koriya,
Chhattisgarh.
5. In view of the above submission, the name of the Police Station
Tarbahar, District Bilaspur, Chhattisgarh be read as Police Station
Khadgaonwa, District-Koriya, Chhattisgarh in order dated
22.10.2019 of this Court.
6. Accordingly, the instant CRMP is disposed of.
 Sd/-

(Arvind Singh Chandel)
