# Allahabad High Court, WRIC/10867/2018, 2018-03-23

Court No. - 2
Case :- WRIT - C No. - 10867 of 2018
Petitioner :- Yogendra Kumar Mishra
Respondent :- State Of U.P. And Another
Counsel for Petitioner :- Devendra Kumar
Counsel for Respondent :- C.S.C.
Hon'ble Ram Surat Ram (Maurya),J.
Heard Sri Devendra Kumar for the petitioner and Standing
Counsel for State of U.P.
This writ petition has been filed for mandamus directing
District Magistrate, Etawah to pass appropriate order on the
application of the petitioner for grant of Firearm License
dated11.2.2015.
In the meantime, Arms Rules 2016 has been framed, under
which, a different proforma has been prescribed, as such, the
petitioner is required to file a fresh application in the format as
provided under Arms Rules 2016.
The writ petition is disposed of giving liberty to the petitioner
to file a fresh application in new format, according to Arms
Rules 2016, along with certified copy of this order within one
month. In case any such application is filed, then District
Magistrate, Etawah shall pass appropriate order on it within
three months thereafter, as provided under Rule 13 of Arms
Rules 2016.
Order Date :- 23.3.2018
