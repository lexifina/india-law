CORAM: HONOURABLE MR. JUSTICE SHIVAJI PANDEY
ORAL ORDER
2 05-04-2012 Heard learned counsel for the petitioner and learned counsel
for the State.
This application has been filed for quashing the order dated
5.5.2010 passed in Complaint Case No.309 C of 2009 by the Judicial
Magistrate Ist Class, Katihar by which he has taken cognizance against the
petitioner under section 307/34 of the Indian Penal Code.
Learned counsel for the petitioner submits that the sessions
court has already framed the charge.
In this view of the matter, this application has been rendered
infructuous.
Accordingly this application is dismissed as having become
infructuous.
Vinay/- (Shivaji Pandey, J)
