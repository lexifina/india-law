Petitioner submits that he has instructions that a subsequent
revisional application was preferred at the instance of the private
opposite party/husband and there has been alteration in the amount of
maintenance. The same was without any notice being issued to the
present petitioner. The aforesaid submission of the learned advocate is
a change of circumstance. Petitioner, as such, would be at liberty to
approach this Court with the subsequent order so passed by the
revisional court/sessions court, so far as the present order is concerned,
since the same is not in existence, there is no interference by this Court.
Accordingly, C.R.R. 1252 of 2023 is disposed of.
Pending applications, if any, are consequently disposed of.
All parties are directed to act on the server copy of this order
downloaded from the official website of this Hon’ble Court.

 (Tirthankar Ghosh, J.)
