 versus
 Sanjivani ..Respondents. Sanjay Wadekar & Ors.
 ....
 Mr.V.V. Gangurde i/b. Satish B.Patil & Gopal
 V. Bhagat, Advocate for the Applicant.
 Mr.J.P.Yagnik, APP for Respondent No.3-State.
 ....
CORAM : A.S. OKLA, J.
DATE : 8TH JULY,2008.
 P.C.
 1.Heard the learned Advocate appearing for the
 applicant. The challenge in this application under
 section 482 of the Code of Criminal Procedure, 1973,
 is to the order dated 7th February 2008 passed by the
 learned Magistrate granting interim maintenance of
 Rs.1,000/-per month in pending application under
 section 125 of the said Code filed by the
 respondents.
 2.The applicant can always file a revision
 application for challenging the said order before the
 appropriate Sessions Court. Only on this ground, the
 application is not entertained and the same is
 rejected. Rejection of this application will not

 preclude the applicant from filing a revision
 application. All contentions on merits are kept
 open.
[ A.S.OKA, J.]
