# High Court of Madhya Pradesh, MCRC/12157/2017, 2017-07-24

MCRC-12157-2017
(VIJAY KUMAR @ MANNU GURJAR Vs THE STATE OF MADHYA PRADESH)
24-07-2017
Shri N.K. Shah, learned counsel for the applicant.
Ms. Anjana Shrivastava, learned Panel Lawyer for the
respondent/State.
Heard.
This is an application for modification of the bail order
dated 7.7.2017 passed in M.Cr.C.No.10230/2017.
Learned counsel for the applicant submits that in the order
passed by this Court dated 7.7.2017 in M.Cr.C.No.10230/2017,
Crime No.6217/2017 has wrongly been mentioned, whereas, the
correct one is, 'Crime No.62/2017'.
Considering the aforesaid, this application is allowed. Let
Crime No.6217/2017, registered at Police Station Jiyawan,
District Singrauli, mentioned in the order dated 7.7.2017 in
M.Cr.C.No.10230/2017 be read as Crime No.62/2017. This
order shall be read conjointly with the order dated 7.7.2017.
Let a copy of this order be kept in the record of
M.Cr.C.No.10230/2017.
Certified copy as per rules.
(H.P. SINGH)
JUDGE
A.Praj.
