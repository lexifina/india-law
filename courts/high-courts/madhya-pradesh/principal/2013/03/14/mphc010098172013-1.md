# High Court of Madhya Pradesh, MCC/311/2013, 2013-03-14

M.C.C.No.311/2013
14/03/2013
Shri P.K.Saxena, learned counsel for the applicant.
This application has been filed for restoration of
W.P.No.5133/2012, which has been dismissed due to peremptory
order passed by this Court on 4.4.2012.
Keeping in view the reasons indicated in the application,
which is supported by the affidavit of the counsel himself and
finding the same to be bona-fide, this application is allowed.
W.P.No.5133/2012/2012 be restored to it's original file, it be
placed for orders before the appropriate bench as per roster.
With the aforesaid, the application stands disposed of.
(Rajendra Menon)
Judge
