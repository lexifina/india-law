PRAYER: Petition filed under Section 24 of the Code of Civil
Procedure, to withdraw H.M.O.P.No.152 of 2021 on the file of the
learned, Family Court, Pudukkottai and transfer the same to the
file of the learned Sub Judge, Ponneri.
For Petitioner : Mr.G.Mohana Krishnan
For Respondent : Mr.PM.Sheik Dawar
ORDER
The wife has filed this Transfer Civil Miscellaneous
Petition, seeking to transfer the H.M.O.P.No.152 of 2021 filed
by the husband for divorce pending on the file of the learned
Judge, Family Court, Pudukkottai, to the file of the learned Sub
Judge, Ponneri.
2.It is informed that the H.M.O.P.No.152 of 2021 which the
petitioner seeks to transfer had been decreed ex parte by the
learned Family Judge, Pudukkottai, on 11.01.2022. Therefore,
this Transfer Civil Miscellaneous Petition has to be dismissed.
3.However, the learned counsel for the petitioner seeks
liberty of this Court to file a fresh Transfer Civil
Miscellaneous Petition in the event the ex parte order is set
aside.
Accordingly, this Transfer Miscellaneous Petition is
dismissed with liberty to the petitioner to file a fresh
Transfer Civil Miscellaneous Petition in the event the ex parte

Miscellaneous Petition is closed.
