# Allahabad High Court, A482/40124/2018, 2018-11-28

Court No. - 49
Case :- APPLICATION U/S 482 No. - 40124 of 2018
Applicant :- Smt Prabhawati
Opposite Party :- State Of U.P. And 3 Others
Counsel for Applicant :- Pradeep Kumar
Counsel for Opposite Party :- G.A.
Hon'ble Ved Prakash Vaish,J.
Mr. Pradeep Kumar, learned Counsel for the applicant and Mr. D.K.
Srivastava, learned A.G.A. for the State are present.
An affidavit has been filed by learned A.G.A. for the State today,
which is taken on record.
This application under Section 482 of the Code of Criminal
Procedure, 1973 has been filed seeking direction to comply with the
order dated 26.7.2018 passed by learned Additional Chief Judicial
Magistrate, Maharajganj for registering the F.I.R..
Learned A.G.A. submits that the learned Chief Judicial Magistrate,
Maharajganj has passed an order dated 26.7.2018 on the application
under Section 156(3) Cr.P.C. and in compliance of the said order,
F.I.R. has been registered on 16.11.2018.
Learned Counsel for the applicant submits that since the F.I.R. has
been registered and present petition has become infructuous.
As prayed, the present application is dismissed as infructuous.
(V.P. Vaish, J.)
Order Date :- 28.11.2018
