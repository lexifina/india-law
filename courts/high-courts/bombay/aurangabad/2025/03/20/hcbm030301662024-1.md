PER COURT : -
1. A spelling mistake in the order dated 17th March, 2025 is
noticed in the last paragraph, as “Part-Hard”. Correction be carried out in
the said order, by replacing the same with the words “Part-Heard”.
2. On 17th March, 2025, we had passed the following order : -
“1. Having perused the F.I.R. No.0051, registered on
02.02.2024 before the Gandhi Chowk Police Station,
Latur, we are not inclined to entertain this Application
under Section 482 of the Code of Criminal Procedure,
1973.
2. The learned Advocate for the Applicant submits that
since the charge-sheet has been filed, he may given one
opportunity to read the chargesheet and if there is any
material against him, he would take a decision to
withdraw this Application.
3. In view of the said request, list this Application on
20.03.2025. By consent, treated as Part-Heard.”

3. The learned Advocate for the Applicant submits, on
instructions, that the Applicant desires to withdraw this Application and
prefer a discharge application.
4. In view of the above, this Application is disposed off as
withdrawn on instructions. If the Applicant prefers a Discharge
Application, since the Charge-sheet has been filed, all contentions are
kept open, and the withdrawal of this Application would not be an
impediment.
