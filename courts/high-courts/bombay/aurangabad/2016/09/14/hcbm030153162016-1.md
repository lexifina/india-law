PER COURT :
When the application (Cri. Application No.
2150/2016) is called out for hearing, none appeared for
the applicant. Respondent No. 2 has filed the affidavit-in-reply. It is stated in paragraph No. 3 of the reply
that in Crime No. 98/2016, which is sought to be quashed
by this application, the present applicant is not added
as an accused at present. In that view of the matter,

2 criapln2150-2016+
there is no reason for the applicant to file this
application. In the circumstances, this application
stands rejected being premature.
2. As regards other two applications (Cri.
Application No. 2085/2016 and 6915/2016), none appeared
for the applicants when these matters are called out.
The interim relief granted in these applications stands
vacated. Since the order granting interim relief in
these two applications is vacated, there is no
impediment to proceed with the further investigation for
filing the chargesheet.
3. List the applications (Cri. Application No.
2085/2016 and 6915/2016) on 18th October, 2016.
