Hon'ble Shri Justice Rajendra Chandra Singh Samant
Order on board
09/08/2021
1. Heard on application under Section 482 CrPC has been preferred
praying for correction of clerical error in the order dated 28.7.2021
passed in MCRC No.4199/2021.
2. It is submitted by counsel for petitioner, that the crime number that is
mentioned in the impugned order is 319/2018, which is incorrect as the
correct Crime Number is 399/2018. In support of this submission, copy
of FIR has been attached for perusal of this Court.
3. Learned State counsel opposes the submissions made by counsel for
the petitioners.
4. Considered on the submissions. As the copy of the FIR shows, that the
Crime No.399/2018, hence, only on this basis, the request made by
the applicant is allowed.

Page No.2
5. Accordingly, the petition is allowed at the motion stage. It is ordered
that the Crime No.319/2018, which is mentioned in the first para of the
order dated 28.07.2021 in MCRC No.4199/2021 shall be now read as
Crime No.399/2018.
6. A copy of this order be made part of MCRC No.4199/2021.
