# Calcutta High Court, CRR/2481/2022, 2023-07-20

D/L35
20.07.2023
Bpg.
 C.R.R.2481 of 2022
In Re: A petition under Section 482 of the Code of Criminal Procedure,
1973;
 Jyoti Chakraborty and another
 Versus
 The State of West Bengal and another
 Mr. Karan Dudhwewala.
 …for the petitioners.

Learned advocate appearing for the petitioners submits
that he has written instructions not to pursue the present revisional
application.
Accordingly, CRR 2481 of 2022 is dismissed as not
pressed.
Let the written instructions be kept with the record.
Petitioners would be at liberty to file afresh, if so advised.
Department is directed to return the certified copy to the
learned advocate-on-record provided the same is replaced by
photostat copy.
Pending application, if any, is consequently dismissed.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
 (Tirthankar Ghosh, J.)
