# High Court of Madhya Pradesh, MCRC/17433/2019, 2019-05-02

(AKHIL KUMAR SRIVASTAVA)
JUDGE
The High Court Of Madhya PradeshThe High Court Of Madhya Pradesh
MCRC-17433-2019
(GOLU MAITHIL @ BRIJESH Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 02-05-2019
Shri Ghanshyam Sharma, learned counsel for the applicant.
Shri Vaibhav Saxena, learned Govt. Advocate for the respondent-State.
This application has been filed seeking correction in Session Trial
number in the details attached with the certified copy of the order dated
12.03.2019 passed in M.Cr.C.No.6586/2019.
It is submitted by learned counsel for the applicant that due to
typographical error Session Trial number was wrongly mentioned in the
application viz M.Cr.C. No.6586/2019 wherein Session Trial number has
been mentioned as Session Trial No.823/2018 and 833/2018 whereas correct
session trial number is 883/2018. It is prayed that the said error being
inadvertent and bonafide be corrected.
On perusal of the application M.Cr.C. No.6586/2019 and the lower
court order as well as other relevant documents, it seems that a typographical
error had crept in the application which deserves to be corrected. In view of
above, Registrar (Judicial) is directed to look into the matter and direct the
concerned officials to make correction in the official record relating to
application M.Cr.C. No.6586/2019.
This order shall be read conjointly with order dated 12.03.2019 passed
in M.Cr.C.No.6586/2019.
Let a copy of this order be kept in the record of M.Cr.C.
No.6586/2019.
Application is disposed of finally in above terms.
