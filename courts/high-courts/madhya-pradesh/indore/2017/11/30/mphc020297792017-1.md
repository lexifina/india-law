# High Court of Madhya Pradesh, MCRC/22833/2017, 2017-11-30

Indore, dated : 30.11.2017
Shri Mukesh Sharma, learned counsel for the
petitioner.
 Shri Amit Singh Sisodia, learned Public
Prosecutor.
 This is an application praying for modification/
correction of order dated 29.8.2017 passed by this Court in
M.Cr.C. No.8565/2017 granting bail to petitioner – Mahesh
Bhai Thakkar in Crime No.226/2017, Police Station Agar,
District Agar.
 It is submitted by the learned counsel for the
petitioner that due to inadvertence, Crime number has
mistakenly been stated as '265/2017' instead of '226/2017'
which requires to be corrected.
 Learned counsel for the respondent does not
dispute that there is a typographical error in order dated
29.8.2017 passed in M.Cr.C. No.8565/2017 which requires to
be rectified.
 Accordingly, this petition is hereby allowed and it
is directed that in the first paragraph of the order, Crime
No.'226/2017' shall be read instead of Crime No.'265/2017.
 Petition stands accordingly disposed of.
( VED PRAKASH SHARMA )
 JUDGE
