1. This application has been filed for correction of typographical error in
the order dated 29.11.2016.
2. We had passed an order on 29.11.2016 in Writ Appeal No.552 of 2016
in which we have imposed exemplary cost of Rs.10,000/- but in the
judgment it has been shown as Rs.10,0000/-.
3. Therefore, in para 8 of the judgment, the amount mentioned as
10,0000/- is rectified and the same be read as Rs.10,000/-.
4. With the aforesaid modification, this MCC is disposed of.
