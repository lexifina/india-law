This appeal is directed against the order dated 21.01.2016 passed by the learned
single Judge in I.A. no. 976/2016 which is an application filed under Order 39 Rule 2A of
the Code of Civil Procedure, 1908 on behalf of the defendants/respondents. The next
date has been fixed by the learned single Judge in that application on 03.03.2016. The
learned counsel for the appellant on instructions states that he would like to withdraw this

appeal in view of the fact that the application is pending before the learned single Judge
and the points raised in this appeal would be advanced before the learned single Judge.
The appeal is dismissed as withdrawn with the aforesaid liberty. The appellant is
permitted to file an early hearing application before the learned single Judge.
