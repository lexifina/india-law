Heard.
This is an application for restoration.
Considering the averments made in the application, supported by an
affidavit, we find sufficient case is made out for restoration of the case. If
there is any delay, the same is also condoned.
Accordingly, the application is allowed.
The original case is directed to be restored to its original number.
The application is disposed of.
