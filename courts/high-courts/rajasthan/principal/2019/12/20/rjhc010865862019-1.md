HON'BLE MR. JUSTICE ARUN BHANSALI
Order
20/12/2019
The present criminal misc. application has been filed for
correction in the order passed today i.e. dated 20/12/2019 by this
Court in S.B.Criminal Bail Application No.15610/2019.
It is indicated in the application that petitioner has been
arrested in Complaint No.7/2019, whereas, inadvertently in the
order it has been mentioned as FIR No.7/2019, which needs to be
corrected.
In view of the submissions made, the present application is
allowed. It is directed that in the order dated 20/12/2019 passed

(2 of 2) [CRLMB-15610/2019]
in S.B.Criminal Misc. Bail Application No. 15610/2019 the words
“FIR No.7/2019” be read as “Complaint No.7/2019”.
It is further directed that in the bail order name of the
petitioner shall be read as ‘Purushottam Verma’ instead of
‘Purushottam Veram’ as indicated in the cause title.
(ARUN BHANSALI),J
