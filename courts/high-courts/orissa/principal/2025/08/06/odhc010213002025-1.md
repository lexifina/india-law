ORDER
 06.08.2025
I.A. NO.708 of 2025
05. 1. This matter is taken up through Hybrid
Arrangement (Virtual/Physical) Mode.
2. Heard learned counsel appearing for the parties.
3. This application has been filed seeking a direction
on the State Education Tribunal to accept the counter
filed by Opp. party No.4 on 02.08.2025.
4. It is contended that pursuant to order
dt.25.07.2025, though Petitioner was ready to file
counter on 28.07.2025, but in absence of the order
dt.25.07.2025, the Tribunal did not accept the same.
On 02.08.2025, when it was offered again, the
Tribunal refused to accept as the time extended for

// 2 //
Page 2 of 2
filing of the same by this Court in its order
dt.25.07.2025 had already expired.
4.1. It is contended that because Respondent No.4
could not get a copy of the order dt.25.07.2025 and
accordingly could not produce the same before the
Tribunal, the Tribunal neither accepted the counter on
28.07.2025 nor on 02.08.2025. It is accordingly
contended that counter to be filed by Respondent No.4
be accepted with necessary direction on the Tribunal.
5. Mr. S.K. Das, learned counsel appearing for the
appellant fairly contended that he has already been
served with a counter affidavit to be filed by
Respondent No.4.
5.1. Considering the submission made, this Court
while disposing the I.A directs the Tribunal to accept
the counter affidavit on the next date which has been
fixed to tomorrow (07.08.2025).
5.2. Time to file the rejoinder affidavit is extended by
ten (10) days from 07.08.2025.
5.3. The I.A accordingly stands disposed of.
(Biraja Prasanna Satapathy)
