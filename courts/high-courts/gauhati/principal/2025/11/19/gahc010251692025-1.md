BEFORE
HONOURABLE MR. JUSTICE PARTHIVJYOTI SAIKIA
ORDER
Date : 19.11.2025
Heard Mr. I. Bhattacharrya, the learned counsel appearing for the applicants. Also
heard Mr. Bhaskar Sarma, the learned Additional Public Prosecutor for the state-respondent.
2. This application has been filed for correction of typographical error in the order dated
27.10.2025 passed in CRP No.27/2025.
3. In the last paragraph of the said order, “Title Execution Case No.06/2025” has been
mentioned.
4. The learned counsel for the applicants has submitted that it should have been “Title
Execution Case No.06/2005” instead of “Title Execution Case No.06/2025” . It is a
typographical error. Therefore, the error stands corrected.
5. Hence-forth, the “Title Execution Case No.06/2025” appearing in the order dated
27.10.2025 passed in CRP No.27/2025 shall be read as “Title Execution Case No.06/2005” in
the order dated 27.10.2025 passed in CRP No.27/2025.
6. This order shall form a part of the order dated 27.10.2025 passed in CRP No.27/2025.
With the aforesaid direction, this IA stands disposed of.
 JUDGE
