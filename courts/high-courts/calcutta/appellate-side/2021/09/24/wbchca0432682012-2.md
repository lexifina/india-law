# Calcutta High Court, CRR/2846/2012, 2021-09-24

73
 24.09.2021
 sb
 CRR 2846 of 2012

 (Via video conference)

 Momina Begum & ors.
 Vs.
 State of West Bengal

Ms. Baisali Basu …for the State
Ms. Baisali Basu, learned advocate appears on behalf of
the State and submits a report. Let the report be kept with the
record.
On perusal of the revisional application which has been
filed before this court, it reveals that the order under challenge
was passed on 24th February, 2012 and date was fixed on 9th
May, 2012 for execution return of warrant of arrest. The same do
not refer to any police station case neither any certified copy has
been enclosed in the revisional application.
Accordingly, CRR 2846 of 2012 is dismissed.
Pending application, if any, is consequently disposed of.
Interim order, if any, is hereby vacated.
All parties shall act on the server copy of this order duly
downloaded from the official website of this court.
 (Tirthankar Ghosh, J.)
