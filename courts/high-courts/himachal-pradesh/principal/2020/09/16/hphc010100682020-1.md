When this petition was taken up for consideration, an
objection has been taken by Mr. Satyen Vaidya, learned Senior
Advocate on the ground that the execution has to be filed in the
appropriate Court at the first instance, the same is not maintainable in
this Court. Learned counsel for the petitioner submits that then this
petition can be ordered to be closed with liberty to the petitioner to
file an appropriate execution petition before the appropriate Court.
The petition is ordered to be closed with liberty to the decree holder(s)
to approach the appropriate Court for execution of the order(s) in
issue.
