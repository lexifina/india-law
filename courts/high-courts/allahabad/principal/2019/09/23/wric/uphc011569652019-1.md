# Allahabad High Court, WRIC/26786/2019, 2019-09-23

Court No. - 7
Case :- WRIT - C No. - 26786 of 2019
Petitioner :- Harsh
Respondent :- Union Of India And Another
Counsel for Petitioner :- Rajendra Kumar
Counsel for Respondent :- A.S.G.I.,Rakesh Kumar Pandey,Surendra
Prasad Sharma
Hon'ble Ajay Bhanot,J.
Sri Surendra Prasad Sharma, learned counsel for the respondent
No.2-Central Board of Secondary Education, Allahabad submits
that the application of the petitioner for correction in the name
of his father as recorded in the Class X certificate issued by the
respondent-Board has been rejected by order dated 06.08.2015.
The order rejecting the application has been provided to the
learned counsel for the petitioner.
Sri Rajendra Kumar, learned counsel for the petitioner submits
that the cause of action on which the writ petition was founded
does not survive any longer.
The writ petition is dismissed.
It is always open to the petitioner to challenge the order
rejecting the application for correction in the name of his father
if so advised.
Order Date :- 23.9.2019
Ashish Tripathi
