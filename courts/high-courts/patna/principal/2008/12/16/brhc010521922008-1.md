# Patna High Court, CR. REV./447/2008, 2008-12-16

IN THE HIGH COURT OF JUDICATURE AT PATNA
 CR. REV. No.447 of 2008
 BHIM KUMAR @ BHIM SINGH @ BHIM KUMAR SINGH
 Versus
 STATE OF BIHAR
 -----------
5 16.12.2008 Heard learned counsel for the parties.
This revision application against the order declaring the
petitioner as juvenile has already been rejected by this Court.
Under the facts and circumstances of the case, provision
bail so granted to the petitioner, named above, vide order dated
2.6.2008 is hereby confirmed.
Accordingly, this revision application is allowed and the
impugned order is hereby set aside.
B.Jha (Ghanshyam Prasad)
