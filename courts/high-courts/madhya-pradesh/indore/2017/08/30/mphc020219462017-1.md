# High Court of Madhya Pradesh, MCRC/9241/2017, 2017-08-30

MCRC-9241-2017
(KALU @ VIJAY Vs THE STATE OF MADHYA PRADESH)
30-08-2017
Shri Nilesh Agrawal, learned counsel for the applicant.
Shri Hemant Sharma, learned counsel for the respondent/State.
This application under Section 482 of Cr.P.C. is filed for
modification of the order passed by this Court in
M.Cr.C.No.7957/2017 dated 16.08.2017.
In the order crime number is mentioned as 220/2017 while
actual crime number is 368/2017.
After due consideration, the application is allowed. In the
aforesaid order, crime number may be read as 368/2017 in
place of 220/2017.
With the aforesaid modification, this application stands disposed
of.
C.C.as per rules.
(ALOK VERMA)
JUDGE
