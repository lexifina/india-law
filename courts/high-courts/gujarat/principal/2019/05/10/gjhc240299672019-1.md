ORAL ORDER
It is submitted by the learned advocate for the
applicant that because of the strike in the District
Court, Vadodara, the present application is filed
directly before this Court. However, the learned
advocate for the applicant seeks permission to
withdraw this application with a view to file an
application under Section 438 of the Code of Criminal
Procedure, 1973, before the concerned Sessions Court.
Permission, as prayed for, is granted. The
application stands disposed of, as withdrawn.
It is clarified that this Court has not examined
the merits of the case.
(VIPUL M. PANCHOLI, J)
