HON'BLE MR. JUSTICE PANKAJ BHANDARI
 Order
04/05/2021
1. The matter comes up on application for correction in the
order dated 07.04.2021 passed in S.B. Criminal Misc. Bail
Application No.3194/2021.
2. It is contended by counsel for the petitioner/applicant that
erroneously in the cause title father's name of petitioner/applicant
has been mentioned as “Satyanarayan” instead of “Roopnarayan”.
It is also contended that now the correction has been made in the
order of lower court and amended cause title to this effect has
already been filed.
3. I have considered the contentions.

(2 of 2) [CRLMA-150/2021]
4. Considering the contentions made by counsel for the
petitioner/applicant, application for correction in the order dated
07.04.2021 is accordingly, allowed.
5. Amended cause title has been filed and the same is taken on
record in the main bail application.
6. It is ordered that in the cause title of order dated 07.04.2021
passed in S.B. Criminal Misc. Bail Application No.3194/2021,
father’s name of petitioner “Satyanarayan” be now read as
“Roopnarayan”.
(PANKAJ BHANDARI),J
HEENA/100
