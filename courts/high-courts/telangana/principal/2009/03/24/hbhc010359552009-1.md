# High Court for the State of Telangana, WA/364/2009, 2009-03-24

THE HONOURABLE MRS. JUSTICE T. MEENA KUMARI
AND
THE HON’BLE MR. JUSTICE VILAS V. AFZULPURKAR
WRIT APPEAL No. 364 of 2009
ORAL ORDER:
(Per T. Meena Kumari, J)
When the matter has come up for hearing, the learned
counsel for the appellants seeks permission of this Court to
withdraw the Writ Appeal with a liberty to file review application
before the learned Single Judge. The learned counsel for the
appelants also made an endorsement on the file to this effect.
Accordingly, the Writ Appeal is dismissed as withdrawn
with a liberty to file review application before the learned Single
Judge, if they so choose.
