 ORDER
Mr.V.Murali, learned counsel on record for writ
petitioner is before this Court. Learned counsel submits
that he has instructions from the writ petitioner to
withdraw this writ petition and learned counsel has made an
endorsement in the case file, which reads as follows:
'Writ Petition 14216/2019 withdrawn as
instructed by petitioner company.
Instructions for withdrawal as per letter
already submitted.
Sd/-

Counsel for petitioner Company'
2. Learned counsel reiterates the aforesaid
endorsement in the hearing.
3. In the light of the aforementioned endorsement in
the case file and reiteration of the same in the hearing,
this writ petition is dismissed as withdrawn. No costs.
Consequently connected miscellaneous petitions are closed.
