A.No.649 of 2021:
This application praying that this Hon'ble court be pleased to set
aside the exparte order dated 22/12/2020 passed in the above civil suit in
C.S.No.447 of 2017 against the Defendants.
This application coming on this day before this Court for hearing
the court made the following order:
The defendants in C.S.No.447 of 2017 has filed this application
under Order XIV Rule 8 of the Original Side Rules read with Order 9 Rule 7
of the Civil Procedure Code, praying to set aside the ex parte order dated
22.12.2020 passed in C.S.No.447 of 2017, pending on the file of this Court.
https://hcservices.ecourts.gov.in/hcservices/

3
2. Heard both sides.
3. On going through the order dated 22.12.2020, this Court has
passed the ex parte order against the applicants / defendants, for non filing
of the written statement.
4. Today, along with the application, the applicants herein being
the defendants had filed their written statement and the same has been
received. In otherwise, the learned counsel for the respondent / plaintiff is
appeared through Video Conferencing and he is not having any objection
for allowing this application.
5. Accordingly, this application stands allowed and the
ex parte order dated 22.12.2020, is set aside.
