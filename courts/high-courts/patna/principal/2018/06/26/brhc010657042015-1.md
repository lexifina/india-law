ORAL ORDER
4/ 26-06-2018 This application under Section 482 of the Code of
Criminal Procedure has been filed for quashing the First
Information Report of Halsi P.S. Case No.02 of 2014 instituted
under Section(s) 379 Indian Penal Code and Section 135 of the
Electricity Act.
A report was called for from the Court below with
regard to present stage of the case, which has been received, from
which it appears that cognizance has already been taken against
the petitioner by order dated 19.12.2016 for the offence under
Section(s) 135 of the Electricity Act.
In view of such, this application has become
infructuous and dismissed as such.
