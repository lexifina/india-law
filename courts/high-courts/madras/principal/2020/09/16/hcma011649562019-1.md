# Madras High Court, A/7058/2019, 2020-09-16

A.No.7058 of 2019
N.SATHISH KUMAR, J.
This application has been filed to
direct the respondents to furnish security for
a sum of Rs.13,62,185/-, failing which, to
order attachment of the immovable property
morefully described in the schedule to the
Judges summons, pending disposal of the
arbitration proceedings.
2. This Court by an Order dated
17.03.2020, directed the respondents to
furnish security for the suit claim on or
before 16.04.2020 and on failing to furnish
security, there shall be Order of attachment.
3. Despite the Order of this Court
directing to furnish security, the
respondents have not furnished any
security and none appeared for the
respondents.
4. In view of the same, there shall be
an Order of attachment of the immovable
property described in the schedule and this
application is closed. The registry is
directed to communicate this Order to the
concerned Registrar.
