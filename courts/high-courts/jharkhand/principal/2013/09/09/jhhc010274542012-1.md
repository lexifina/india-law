# High Court of Jharkhand, Cr.M.P./1609/2012, 2013-09-09

In the High Court of Jharkhand at Ranchi
Cr.M.P. No.1609 of 2012
Sunil Kumar .........................................Petitioner
V E R S U S
 State of Jharkhand and another.....Opposite Parties
 CORAM: HON’BLE MR. JUSTICE R.R.PRASAD
For the Petitioner: Mr.M.P.Sinha
For the State : A.P.P
 5 / 9.9.13. According to learned counsel appearing for the petitioner with
respect to some allegation, an FIR was lodged as Dhanbad P.S case no.398 of
2010 under Section 367 of the Indian Penal Code which was investigated upon
and the police during investigation did find the allegation to be false. Meanwhile,
with respect to same allegation, one complaint case bearing Complaint Case
No.1709 of 2010 was filed in which cognizance of the offence punishable under
Sections 365, 342/34 of the Indian Penal Code has been taken against the
petitioner and that order has been sought tobe quashed as the police did find
the allegation to be false.
The ground on which the order taking cognizance is being sought to be
quashed never appears to be tenable.
Accordingly, this application stands dismissed.
 (R.R. Prasad, J.)
