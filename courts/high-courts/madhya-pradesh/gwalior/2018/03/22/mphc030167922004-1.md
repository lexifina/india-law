# High Court of Madhya Pradesh, CRA/815/2004, 2018-03-22

THE HIGH COURT OF MADHYA PRADESH
CRA-815-2004
(NAVAL KISHORE @ LALLA BATHAM Vs THE STATE OF M.P. )
Gwalior, Dated : 22-03-2018
None for the appellant.
Shri Devendra Choubey, Public Prosecutor for the
respondent/State.
On 8/3/2018, this Court had issued bailable warrant against
appellant Naval Kishore Batham. A report has been received from the
SHO, Police Station Dabra, District Gwalior to the effect that
appellant Naval Kishore Batham has expired. A copy of the death
certificate has also been received along with the report.
Since the police itself has given a report that Naval Kishore
Batham has expired, therefore, this appeals stands abated.
The appeal is accordingly dismissed as abated.
(G.S. AHLUWALIA)
JUDGE
