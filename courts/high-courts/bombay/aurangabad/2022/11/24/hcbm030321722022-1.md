P. C. :
1. Heard rival submissions.
2. The application is fled for setting aside order dated
18/03/2021 by which this court had dismissed the appeal against
respondent No. 1 & 2. However, it appears thereafter that despite
such order another civil application for issuing notice to respondent
No.1 by paper publication was moved. Though the said application
is allowed on 10/11/2022 but at the relevant time the learned
counsel for the applicant did not point out the order dated
18/03/2021 whereby the appeal against respondent No.1 was
dismissed. This is not a fair practice on the part of the learned
counsel for appellants. However, to correct the technical mistake,
the dismissal order dated 18/03/2021 at least against respondent
No.1 needs to be set aside. As such, following order is passed.

 2 907 ca 14955-22
ORDER :
1. The application is partly allowed and the order
dated 18/03/2021 is set aside only to the
extent of respondent No.1.
2. The civil application is accordingly disposed of.
( SANDIPAUMAR C. MORE, J. )
