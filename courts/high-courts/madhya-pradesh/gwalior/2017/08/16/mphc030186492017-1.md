# High Court of Madhya Pradesh, MCRC/8599/2017, 2017-08-16

MCRC-8599-2017
(SADDAM KHAN Vs THE STATE OF MADHYA PRADESH THR)
16-08-2017
Shri DS Tomar, counsel for the applicant.
Shri Girdhari Singh Chauhan, Public Prosecutor for the respondent/State.
Case Diary is available.
This is second application under Section 439 of CrPC for grant of bail. First
application was dismissed as withdrawn by order dated 05/05/2017 passed
in MCRC 4468/2017.
The applicant has been arrested on 13/11/2016 in connection with Crime
No.839/2016 registered at Police Station Kotwali,District Vidisha for the
offence punishable under Sections 302, 294, 147, 148, 149 of IPC.
At the outset, the counsel for the applicant seeks permission of this Court to
withdraw this application with liberty to file a properly constituted bail
application.
With the aforesaid liberty, application is dismissed as withdrawn.
(G.S. AHLUWALIA)
JUDGE
MKB
