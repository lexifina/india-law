# Allahabad High Court, A482/11871/2018, 2018-05-02

Court No. - 44
Case :- APPLICATION U/S 482 No. - 11871 of 2018
Applicant :- Smt Chameli Devi
Opposite Party :- State Of Up And Anoter
Counsel for Applicant :- Shiv Ram Dubey,Uma Nath Pandey
Counsel for Opposite Party :- G.A.
Hon'ble Rajeev Misra,J.
Heard Mr. Shiv Ram Dubey, learned counsel for the applicant
and the learned A.G.A. for the State.
At the very outset, learned counsel for the applicant submits
that the laches in filing the present application have not been
sufficiently explained and therefore, he be permitted to
withdraw the present application with liberty to file a fresh
application.
Prayer made for is allowed.
The application is dismissed as not pressed with the aforesaid
liberty.
Certified copy of the impugned order be returned to the learned
counsel for the applicant after obtaining a photostat copy of the
same to be kept on record.
Order Date :- 2.5.2018
