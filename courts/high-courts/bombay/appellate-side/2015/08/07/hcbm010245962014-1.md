P.C. :
1 The learned counsel for the applicant fairly submits
that there were a number of identical matters between the parties,
and a number of applications for Leave to Appeal came to be filed.
He submits that one such application for Leave to Appeal was
rejected by this Court by an order dated 30th January 2015
(Criminal Application for Leave to Appeal (Pvt) No.244/15). The
learned counsel fairly submits that the same reasoning would
apply to the present application also.
2 I have gone through a copy of the order passed by me
in the said application for Leave to Appeal.
3 For the same reasons, this does not appear to be a fit
case where Leave to Appeal should be granted.

Tilak 2/2 (12)ALP-249-14
4 Leave refused.
5 Application is rejected.
(ABHAY M.THIPSAY, J)
