# High Court of Madhya Pradesh, MCRC/6576/2014, 2014-08-26

1
M.Cr.C. No.6576/2014
26.08.2014
Shri PM Choudhary, learned counsel for the
applicant.
He seeks leave to withdraw this application with
liberty to file an appropriate application before the trial
Court seeking discharge of the applicant.
We are of the view that there is no need to grant such
liberty. It is always open for the applicant to file application
in accordance with law.
The M.Cr.C. is dismissed as withdrawn.
