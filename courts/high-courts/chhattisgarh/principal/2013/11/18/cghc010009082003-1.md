ORAL ORDER
(Passed on l8th November, 20l3)
(1) Learned counsel for the appellant submits that
the default has been removed.
(2) Heard on admission.
(3) This is plaintiff's appeal under Order 43 Rule
1(c) I of the Code of Civil Procedure, 1908
(henceforth 'the Code ' ) by which the
plaintiff/appellant has challenged the order dated
20—2-2003 passed by the trial Court dismissing the
suit for want of prosecution and rejecting the
plaintiff's application under Order 9 Rule 9 of the
Code holding that the application was not supported

by an affidavit .
(4) Shri Bhaskar Payashi, learned counsel appearing
for the appellant/plaintiff would submit that the
suit was dismissed for default on 20—2—2003 and on
the same day the application for restoration under
Order 9 Rule 9 of the Code was filed showing
sufficient cause, but inadvertently an affidavit in/
support of the application could not be filed. He
would further submit that an opportunity to file the
affidavit ought to have been granted t_o the
appellant/plaintiff. He would further submit that
the respondent/defendant was ex parte before the
trial Court on 20-2—2003.
(5) True it is that the application for restoration
of the suit was not supported by an affidavit, but
the fact remains that the appellant/plaintiff has
promptly filed an application for restoration on the
same day, i.e., 20—2-2003 on which the suit was
dismissed in default. This'clearly shows that the
appellant was not negligent and really interested in
prosecuting the suit. The trial Court ought to have
granted opportunity to file an affidavit in support
of the application for restoration of; the suit
especially when the application for restoration was
filed on the same day and that too within the

’9
3
statutory period of limitation prescribed for filing
the restoration application. On account of the
dismissal of the application without giving an
opportunity to file an affidavit, the
appellant/plaintiff has suffered prejudice and the
trial Court has committed illegality.
(6) In the result, the order dated 20-2—2003
rejecting the application under Order 9 Rule 9 of
the Code summarily is set aside and the application
under Order 9 Rule 9 of the Code is restored to its
file. The trial Court is directed to consider and
dispose of the same in accordance with law after
giving an opportunity to the appellant/plaintiff to
file necessary affidavit within the time stipulated
W / by the trial Court. Thus, the appeal is disposed of
reserving liberty to the respondent/defendant to
file an appropriate application, if feels aggrieved.
