# High Court of Madhya Pradesh, MCC/3564/2017, 2017-12-19

1
MCC No.3564/2017.
Jabalpur, dated 19/12/2017.
Shri Sunil Singh, learned counsel for the applicant.
Heard on I.A.No.18079/2017, which is an application
for Condonation of Delay supported by an affidavit of
counsel for the applicant.
On due consideration, the same is hereby allowed. The
delay in filling the application is hereby condoned.
This MCC has been filed for restoration of M.A.
No.927/2016 which was dismissed for non compliance of
peremptory order dated 06.10.2016. Finding the same to be
bonafide, the application is allowed.
Accordingly, M.A. No.927/2016 is restored to its
original number. Let a typed copy of this order be kept in the
file of M.A. No.927/2016.
After restoration, aforesaid M.A. be placed for orders
before appropriate Bench.
MCC stands allowed and disposed of.
Certified copy as per rules.
 (MISS VANDANA KASREKAR)
 JUDGE
