ORAL ORDER
3 02-07-2014 This application has been filed for restoration of
the contempt application bearing M.J.C. No.1997 of 2012 which
stood dismissed for default on 11.12.2013.
Dismissal of a contempt application in default does
not operate as res judicata. If the petitioner is still of the view that
the opposite parties are in contempt, he is at liberty to file a fresh
contempt application.
The application is dismissed.
