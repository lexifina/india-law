Order

(2 of 2) [CRLMA-138/2021]
Heard on the application for modification/correction in the
order dated 09.04.2021 passed by this court in S.B. Criminal Misc.
Bail Application No.2665/2021.
Counsel for the applicant submits that in the order dated
09.04.2021 the name of respondent No.5 has wrongly been
mentioned as ‘Rajdish Prasad Bairwa’ whereas the correct name of
the respondent No.5 is ‘Jagdish Prasad Bairwa’.
I have perused the order dated 09.04.2021 passed by this
court in S.B. Criminal Misc. Bail Application No.2665/2021.
In that view of the matter, the name of the respondent No.5
in the order dated 09.04.2021 be read as ‘Jagdish Prasad Bairwa’
in place of ‘Rajdish Prasad Bairwa’. The order dated 09.04.2021
stands corrected accordingly. This order be treated to be part of
the order dated 09.04.2021.
The application in the above terms stands disposed of.
(INDERJEET SINGH),J
