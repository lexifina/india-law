ALOK SINGH, J (ORAL)
Learned counsel for the decree-holder/petitioner states that
decree-holder has wrongly moved an application for initiating contempt
proceedings against the judgment-debtors instead he ought to have
moved an execution application seeking possession after giving correct
dates of dispossession of the petitioner. Learned counsel for the
petitioner states that present execution application may be allowed to be
withdrawn with liberty to file fresh execution application.
Present execution application is allowed to be withdrawn with
liberty to file fresh execution application seeking issuance of the warrant
of possession against the judgment-debtors. In the event of moving such
an execution application, same shall be decided in accordance with law
without being prejudiced from the order impugned dated 13.9.2008.
(Alok Singh)
