Heard Mr. AMS Mazumder, learned counsel for the petitioner.
By this interlocutory application the petitioner has prayed for correction of
some inadvertent error cropped up in the order dated 28.06.2019 passed in AB
No.584/2019.
In the first paragraph of the said order, the Katlichera PS Case number has
been wrongly written as PS Case No.420/468/471 IPC which ought to have been
Katlichera PS Case No.272/2018.
The above inadvertent error is corrected as Katlichera PS Case No.272/2018.

Page No.# 2/2
This order shall form part of the order dated 28.06.2019 passed in AB
No.584/2019.
The interlocutory application stands disposed of.
