ORDER
Date : 19-03-2021
Heard the learned counsel Mr. S.P. Bhattacharjee appearing for the applicant.
This Interlocutory Application has been filed for making some correction in the Order
dated 17.03.2021. In the third paragraph it is mentioned as “Mr. K.N. Choudhury submits that
in the event of giving time to file reply, the earlier status-quo order should have been
extended. Mr. Sensua has vehemently objected to the submission of Mr. Choudhury.”
Today, Mr. Bhattacharjee has submitted that there should have been the word “not”
between should and have.
I have given my anxious consideration to the matter. I have decided to agree that it
was nothing but typographical error because on an entire reading of the order it appears that
the word “not” shall be there. Accordingly, the matter stands corrected. Henceforth, the
sentence Mr. K.N. Choudhury submits that in the event of given time to file reply, the earlier
status-quo order should have been extended shall be read as Mr. K.N. Choudhury submits
that in the event of giving time to file reply, the earlier status-quo order should not have been
extended.
The typographical mistake stands corrected. This order shall form a part of the order
dated 17.03.2021 passed in I.A.(Civil) 702 of 2021.

The Interlocutory Application stands disposed of.
