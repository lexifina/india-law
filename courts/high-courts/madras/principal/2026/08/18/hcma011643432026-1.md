ORDER
Order dated 15.04.2024 is assailed primarily on the ground that the
petitioner did not avail of or utilize input tax credit (ITC), whereas said order
proceeds on the erroneous assumption that ITC was utilized.
2. Learned counsel for the petitioner has handed over the GSTR 3B return
for January 2018-19. Such return is a ‘nil’ return.
3. Mr.I.Dinesh, learned Additional Government Pleader, appears on
behalf of the respondent.
4. The GSTR 3B return for the relevant month reveals that a ‘nil’ return
was filed. Therefore, the impugned order, which proceeds on the erroneous
misconception that ITC was availed of and utilized, cannot be sustained. Hence,
the impugned order is set aside without any order as to costs. Consequently,
connected miscellaneous petitions are closed. No costs.
