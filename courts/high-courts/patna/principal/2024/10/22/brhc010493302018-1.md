Second Appeal.
3. The stamp reporter has objected that against the
impugned judgment and decree, Miscellaneous Appeal under
Order 43 Rule 1(u) of the Code of Civil Procedure would lie.
4. The impugned judgment has been passed under
Order 41 Rule 25 of the Code of Civil Procedure. There is no
provision in Order 43 Rule 1(u) of the Code of Civil Procedure
to challenge aforesaid impugned Judgment. The proper remedy
against the impugned judgment is by way of filing civil revision
under Section 115 of the Code of Civil Procedure.
