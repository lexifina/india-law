# High Court of Madhya Pradesh, MCRC/9358/2017, 2017-09-01

MCRC-9358-2017
(SHIVKUMAR JAT Vs THE STATE OF MADHYA PRADESH THR)
01-09-2017
Shri Mahavir Pathak, counsel for the applicant.
Shri Prakhar Dhengula, Public Prosecutor for the respondent/ State.
This is first application under Section 439 of CrPC for grant of bail.
The applicant has been arrested on 22/07/2017 in connection with Crime
No.490/2017, registered at Police Station Civil Line, Morena, District
Morena for the offence punishable under Section 307 read with Section 34
of IPC.
The counsel for the applicant seeks permission of this Court to withdraw
this application, with liberty to file to file a fresh application along-with all
necessary documents.
With the aforesaid liberty, the application is dismissed as withdrawn.
(G.S. AHLUWALIA)
