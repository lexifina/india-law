Order On Board
P. Diwaker, J
06/10/2017
1. The applicants have filed this MCC indicating typographical error in the
order dated 28.8.2017 where in Para-2 the number of criminal revision
has been wrongly typed as “864/2014” whereas infact it is “896/2014”.
2. After perusal of the order dated 28.8.2017, it appears that the above
typographical mistake, on the face, have occured and the same need to
be corrected, to which counsel for the respondent has no objection.
3. The error is hereby rectified. Criminal Revision No.864/2014 mentioned in
Para-2 of the order dated 28.8.2017 be read as “Criminal Revision
No.896/2014”.
4. The MCC is accordingly disposed of.
