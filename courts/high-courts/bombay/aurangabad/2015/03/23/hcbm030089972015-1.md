Per Court :-
Heard learned counsel for the Applicant in this Criminal
Application, in extenso.

Applicant, learned counsel for the Applicant seeks permission to
withdraw the present Criminal Application with liberty to file fresh
Application before the trial court, after charge-sheet is filed.
Permission is granted.
[3] Criminal Application is allowed to be withdrawn with liberty to
the Applicant to file Application for bail after charge-sheet is filed
before the trial court. Accordingly, present Criminal Application is
disposed of.
