P.C. :-
Learned Counsel for the Applicant at the outset states
that the Applicant does not press for the relief prayed for in
this Application at this stage. The learned Counsel for the
Applicant, however, prays for liberty to file an Application
afresh in the event the Appeal is not heard within a
reasonable time. A request is made on behalf of the Applicant
for grant of leave to file a private paper-book as the Applicant
is now in Jail since November 2010.
2. We, accordingly, reject the Application as not pressed
with the liberty as prayed for. We grant liberty to the

Applicant to file a private paper-book within 8 weeks from
today. We further grant liberty to the Applicant to request the
Court for a fixed date hearing after the paper-book is filed.
