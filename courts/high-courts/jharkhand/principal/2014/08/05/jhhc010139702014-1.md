CORAM: HON'BLE MR. JUSTICE SHREE CHANDRASHEKHAR
For the Petitioner : Mr. Deepak Kumar, Advocate
For the State : Mr. Arun Kumar Pandey, A.P.P.
-----
02/05.08.2014 The learned counsel appearing for the applicants
seeks permission to withdraw this application.
Permission is granted.
Accordingly, this anticipatory bail application is
dismissed as withdrawn.
However, it is made clear that withdrawal of this
application would not prejudice the case of the applicant if he
moves application for grant of regular bail before the trial court
and if such application is moved with two days' prior notice to
the Investigating Officer/A.P.P. in the trial court, the learned trial
court would decide the application seeking grant of bail on the
same day or as early as possible.
(Shree Chandrashekhar, J.)
