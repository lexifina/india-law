# High Court of Madhya Pradesh, MCC/2735/2015, 2015-09-14

MCC-2735-2015
(ARJUN BAWASKAR Vs THE STATE OF MADHYA PRADESH)
14-09-2015
Shri A. K. Shukla, learned counsel for the applicant.
This application has been filed for restoration of W.A.
No.961/2013, which was dismissed for non compliance of
the common conditional order dated 29.4.2014. There
being some delay in filing of this application for
restoration, I.A. No.11989/2015 has been filed. Reason
for the delay is attributed to some lapse in the office of
the counsel and the application is supported by affidavit
of the counsel himself.
Finding the same to be bonafide, both the applications
are allowed. Condoning the delay in filing the restoration
application, the restoration application itself is allowed.
W.A. No.961/2013 is restored to its original file. It be
placed for orders before an appropriate Bench.
Application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
(S.K. SETH)
