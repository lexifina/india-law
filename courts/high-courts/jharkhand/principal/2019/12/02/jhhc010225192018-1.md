# High Court of Jharkhand, Cr.M.P./2340/2018, 2019-12-02

IN THE HIGH COURT OF JHARKHAND AT RANCHI

----
1. Brindaban Singh
2. Ambuj Singh
3. Sanjay Singh … Petitioner
-versus-1. The State of Jharkhand
2. Sabita Singh … Opposite Parties

CORAM : HON’BLE MR. JUSTICE ANANDA SEN
----
5/ 02.12.2019 This case has been listed today under the heading “For
Orders” for removal of defects.
 This criminal miscellaneous petition was filed way back on
17.07.2018. Today no one appears on behalf of the petitioner.
 I have gone through the criminal miscellaneous petition.
Petitioners, in this criminal miscellaneous petition, have prayed to quash
the order dated 22.12.2017 passed by the Sub Divisional Magistrate,
Ghatsila, by which notices were issued to the petitioner by invoking
provisions of Section 145 of the Code of Criminal Procedure. Petitioners
have challenged the notice whereby they have been directed to appear in
a proceeding under Section 145 of the Code of Criminal Procedure. The
ground taken is that one proceeding under Section 144 of the Code of
Criminal Procedure was already dropped and as such the Court cannot
proceed in terms of Section 145 of the Code of Criminal Procedure. It is
not the case of the petitioner that the Sub Divisional Magistrate, Ghatshila
has got no jurisdiction to issue notice invoking Section 145 of the Code of
Criminal Procedure. Merely the order issuing notice has been challenged
in this case.
 In opinion of this Court, the petitioner should appear before
the Sub Divisional Magistrate, Ghatshila and file a proper reply taking all
the points. At this stage, this application challenging notice, should not be
interfered.
 Thus, this criminal miscellaneous petition is, hereby,
dismissed.

( Ananda Sen, J.)
Kumar/Cp-03
