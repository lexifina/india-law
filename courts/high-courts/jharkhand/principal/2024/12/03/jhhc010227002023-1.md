Order No:-06 Dated:-03-12-2024
I.A. No.3989 of 2024
 Heard the parties.
 Learned counsel for the petitioner submits that this interlocutory
application has been filed with a prayer to amend the instant Cr.M.P. by
incorporating the additional prayer of quashing the order dated 08.01.2024
passed by the learned Judicial Magistrate-1st Class XXVI, Ranchi by which
the learned Judicial Magistrate-1st Class XXVI, Ranchi has rejected the
petition for discharge of the petitioner.
 Learned Spl.P.P. appearing for the State submits that the order dated
08.01.2024 is a revisable order and the same can only be challenged by filing
a Criminal Revision, hence, the addition of the said prayer will change the
nature and character of the instant Cr.M.P. which has been filed invoking
the jurisdiction of this Court under Section 482 of the Code of Criminal
Procedure. Therefore, it is submitted that this interlocutory application,
being without any merit, be dismissed.
 This Court finds force in the submissions made by the learned Spl.P.P.
appearing for the State. Since the order dated 08.01.2024 is a revisable order,
this Court is not inclined to allow the prayer for amendment of the instant
Cr.M.P., as prayed for, in the instant interlocutory application.

 Accordingly, this interlocutory application, being without any merit,
is dismissed.
 (Anil Kumar Choudhary, J.)
Cr.M.P. No.2024 of 2023
 Learned counsel for the petitioner seeks permission of this Court to
withdraw this Cr.M.P.
 Permission is accorded.
 This Cr.M.P. stands dismissed as withdrawn.
