Jabalpur, Dated : 11-01-2021
Heard through Video Conferencing.
Shri C.B. Tiwari, learned counsel for the applicant.
Shri D.D. Bhave, learned Panel Lawyer for the respondent/State.
Learned counsel for the State has pointed out that this repeat bail
application is not maintainable as two repeat applications have been filed by
the present applicant and the other bail application by M.Cr.C.
No.21217/2020 has been rejected on 15.12.2020.
When confronted with this aspect, learned counsel for the applicant
prays for withdrawal of this application.
This application is dismissed as withdrawn.
