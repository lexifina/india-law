# High Court of Madhya Pradesh, CONC/204/2016, 2017-02-17

CONC-204-2016
(M.L. GOUR Vs SHRI AKHILESH CHATURVEDI)
17-02-2017
None for the applicant.
Shri Girish Kekre, learned counsel for the respondents.
Learned counsel for the respondents submits that the order
passed by this Court on 22.7.2015 in WP No.9626/2015 has
been complied with vide order dated 18.5.2016 which is filed
as Annexure-R/1.
Considering the aforesaid report, nothing survives in this
petition to initiate contempt proceedings against the
respondents. If the petitioner is still aggrieved with the order
dated 18.5.2016, he is at liberty to challenge the same in
accordance with law.
With the aforesaid, this petition stands disposed of.
(SMT. ANJULI PALO)
