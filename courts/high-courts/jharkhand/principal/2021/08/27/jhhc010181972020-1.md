10/ 27.08.2021 Instant application has been filed for initiating contempt proceeding against
the opposite parties for non-compliance of order dated 10.07.2019, passed by this Court in
W.P.(S) No. 5512 of 2018.
 Heard the parties.
 Mr. Saurav Arun, learned counsel appearing for the petitioner submits that
reasoned order has been passed by the State but the same is not in accordance with law and
amounts to gross contempt. The order of this Court has not been fully appreciated in its true
letter and spirit and completely ignoring the purports of the order, reasoned order has been
passed.
 Mr. Deepak Dubey, learned counsel appearing for the State submits that
order and direction of this court has already been complied with and reasoned order to that
effect has been passed. The reasoned order is already enclosed with the show-cause.
 In view of the submissions of the learned counsel for the opposite parties,
no case for contempt is made out as the order of this Court has already been complied with.
Accordingly, the contempt proceeding is dropped. However, liberty is reserved with the
petitioner to challenge the reasoned order by way of fresh writ petition if at all aggrieved.

 (Dr. S.N. Pathak, J.)
