ORAL ORDER
Learned APP states at bar that charge sheet is filed.
In view of above, learned advocate for the
applicants seeks permission to withdraw present application
with a liberty to file discharge application and also to file
appropriate proceedings either u/s 397 or 482 of the Code of
Criminal Procedure, 1973 before appropriate competent Court,
after remedy to file discharge application is availed. Permission
is granted. The application stands disposed of as withdrawn
with above liberty.
It is clarified that this Court has not examined the
merits of the present application.
