HON'BLE MR. JUSTICE PANKAJ BHANDARI
Order
06/09/2019
1. Petitioner/complainant has preferred this Criminal Misc.
Petition seeking fair investigation.
2. Learned Public Prosecutor has submitted the report which is
taken on record. As per the report, Police has already submitted
negative final report on 30.08.2019.
3. In view of the same, misc. petition seeking fair investigation
has become infructous and the same is dismissed as having
become infructous.
4. However, petitioner/complainant would be free to file protest
petition, if so advised.
(PANKAJ BHANDARI),J
