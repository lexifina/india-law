JUDGMENT
Thottathil B.Radhakrishnan, J.
The impugned Ext.P7 is an order by which an application to
restore an application to set aside the ex parte order was
dismissed for default. If that were so, the remedy of the
petitioner is to seek restoration of the application which was
dismissed for default, on account of non-appearance. Ext.P8
application seeking condonation of delay is also issued only
because of non-appearance of the petitioner. Hence, without
prejudice to seeking restoration of the proceedings to set aside
the ex parte order, this Original Petition is dismissed.
