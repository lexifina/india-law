ORDER
Petitioner is the accused in C.C.171/2009 on the
file of Judicial First Class Magistrate, Nilambur.
This petition is filed under section 482 of the Code of
Criminal Procedure to quash the complaint contending
that ingredients of an offence under section 420 of
Indian Penal Code is not attracted. When the matter
was heard, it is found that it is not a fit case to
quash the complaint. Learned counsel appearing for the
petitioner then submitted that petitioner may be
permitted to file an application for discharge under
section 245 of Code of Criminal Procedure before the
learned Magistrate. It is also submitted that
petitioner may be permitted to file the application and
to get an order without insisting for the presence of
the petitioner.
Petition is disposed of granting liberty to the
petitioner to move the Magistrate for an order of
discharge under section 245 of Code of Criminal
Procedure. Petitioner is also at liberty to file an

Crl.M.C.2498/2009 2
application to dispense with his presence for the purpose
of hearing the application.
