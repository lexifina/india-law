PC:
 This is an application seeking correction in the middle name of
the applicant in the Application as well as in the order dated 1st February,2023
passed by this Court.
 Mr. Suchak, learned Counsel for the applicant submits that
inadvertently, a typographical error has crept up in the Application itself,
inasmuch as much as the middle name of the applicant is written as Nasibkhan
instead of “Nasirkhan”. Thus, the applicant carries the blame of mistake. Be
that as it may. He submits that the same requires correction in the Application
and consequently in the order dated 1st February, 2023.
 Accordingly the learned counsel for the applicant is directed to
forthwith correct the middle name of the applicant as “Nasirkhan”.
Consequently, the order dated 1st February 2023 be corrected by inserting the
