ORDER
This petition is for review of judgment dated 18.08.2011 in O.P.No.2740 of
2011. Petitioner filed that petition in challenge of Ext.P8, order (in the Original
Petition) allowing amendment of written statement filed by respondents 1 to 4 in
the Original Petition. This Court after hearing learned counsel for petitioner
held that there is no reason to interfere with the order allowing amendment of
written statement and consequently, dismissed the Original Petition.
2. Learned counsel for petitioner contends that in the nature of
amendment made to the written statement, petitioner is entitled to file a
replication answering the amended written statement and petitioner may be
permitted to file replication.
3. Any pleadings subsequent to the written statement except in
answer to a counter, claim or set off can be made only with the leave of the
court concerned, under Order VIII, Rule 9 of the Code of Civil Procedure.
Hence if petitioner requires to file any replication in answer to the amended
written statement, petitioner has to request the learned Sub Judge for
permission to do so. It is not for this Court to decide that question at the first
instance. If any such request is made learned Sub Judge has to consider that
