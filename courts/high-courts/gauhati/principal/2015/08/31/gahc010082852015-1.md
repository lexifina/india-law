# Gauhati High Court, CRP/368/2015, 2015-08-31

CRP 368/2015
BEFORE
HON’BLE MR. JUSTICE N.CHAUDHURY
Mr. R.K. Jain learned counsel for the petitioners prays that he be permitted to
withdraw this revision petition to file it afresh after removing formal defects.
Prayer is allowed.
Learned counsel for the petitioners is permitted to file a petition afresh under
appropriate provision of law making proper averments. He is also permitted to w
ithdraw the certified copy of this impugned order from the Registry, so that he
can file the application immediately.
This petition stands disposed of.
