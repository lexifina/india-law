# High Court for the State of Telangana, CRLP/15670/2014, 2014-12-18

THE HON’BLE SRI JUSTICE T.SUNIL CHOWDARY
CRIMINAL PETITION No.15670 of 2014
ORDER:
This petition is filed under Section 482 Cr.P.C. to quash the
order in Crl.M.P.No.2645 of 2014 in D.V.C.No.39 of 2012 on the file of
the III Metropolitan Magistarte at Visakhapatnam.
The learned counsel for the petitioner has sought permission of
this Court to permit the petitioner to withdraw the criminal petition with
a liberty to file an appeal before the appropriate forum.
Permission is granted.
Hence, the Criminal Petition is dismissed as withdrawn with a
liberty to the petitioner to file an appeal before the appropriate forum.
Registry is directed to return the certified copy of the order under
challenge to the learned counsel for the petitioner.
Consequently, Miscellaneous Petitions, if any, pending in this
Criminal Petition shall stand closed.
________________________
T.SUNIL CHOWDARY, J
