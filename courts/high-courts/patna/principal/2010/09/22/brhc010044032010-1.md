02- 22/9/2010 Heard Mr. Manoj Kumar Jha for the petitioner. None
appears on behalf of the opposite parties. This application has
been filed for correction in the petitioner’s description and the
address in the order dated 29.7.2009, passed in Cr.WJC No.503
of 2009. It appears to us on a perusal of Cr.WJC No.503 of 2009
that the petitioner’s description and the address noted there, have
been reproduced in the order dated 29.7.2009, whereby the same
has been disposed of. In other words, there is no error
attributable to the Court in incorrectly recording the petitioner’s
description or address.
2. We are, therefore, not inclined to allow this
application. It is accordingly rejected.
