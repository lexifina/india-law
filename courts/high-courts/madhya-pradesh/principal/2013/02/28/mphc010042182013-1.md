# High Court of Madhya Pradesh, MCC/129/2013, 2013-02-28

Khuda Bux Vs. State of M.P. & Others
M.C.C. No. 129 / 2013
28.2.2013:
Shri B.K. Shrivastava, learned counsel for the petitioner.
This application has been filed for restoration of W.P.
No.19334/2012, which was dismissed for non-compliance with
the peremptory order passed on 4.12.2012.
Taking note of the reasons given in the application,
which is supported by affidavit of the counsel himself and
finding same to be bonafide, the application is allowed.
W.P. No.19334/2012 is restored to its original file. It be
placed for orders before an Appropriate Bench
Application stands allowed and disposed of.
(Rajendra Menon)
Judge
