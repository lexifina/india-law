# High Court of Madhya Pradesh, MCRC/18495/2017, 2018-01-03

1
THE HIGH COURT OF MADHYA PRADESH
 MCRC No.18495/2017
(Suresh vs. State of M.P.)
Gwalior, Dated : 03.01.2018
Shri Sushil Goswami, Counsel for the applicant.
Shri Ajay Bhargava, Public Prosecutor for the
respondent/State.
Shri A.R. Shivhare, Counsel for the complainant.
Case diary is available.
This is firth application filed under Section 439 of
Cr.P.C. for grant of bail. The first application was dismissed
by order dated 23.2.2015 passed in M.Cr.C.No.1259/2015.
The second application was dismissed by order dated
20.4.2015 passed in M.Cr.C.No.3374/2015. The third
application was dismissed by order dated 7.9.2015 passed
in M.Cr.C.No.8772/2015 and the fourth application was
dismissed by order dated 13.9.2017 passed in
M.Cr.C.No.2698/2017.
The applicant has been arrested on 20.10.2014 in
connection with Crime No.528/2014 registered by Police
Station Karera, District Shivpuri for offence punishable
under Sections 302, 147, 148, 149 of IPC.
The counsel for the applicant seeks permission of this
Court to withdraw this application with liberty to file a
properly constituted application along with all relevant
documents.
With aforesaid liberty, the application is dismissed as
withdrawn.
(G.S. Ahluwalia)
(alok) Judge
