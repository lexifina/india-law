COMMON ORDER
When the matter is taken up today for hearing, it is pointed out
by this Court to the learned counsel for the petitioners that the matter
pertains to Madurai Bench jurisdiction and hence these writ petitions
have to be filed before the Madurai Bench of Madras High Court.
2. On hearing the same, the learned counsel appearing for the
petitioners seek permission of this Court to withdraw these Writ
Petitions with liberty to file the same before the Madurai Bench of this
Court. He has also made an endorsement to that effect.
3. In view of the above, both these writ petitions are dismissed
as withdrawn granting liberty to the petitioners to file the very same
writ petitions before the Madurai Bench of this Court. Office is
directed to return the original papers, if any, filed in these writ

3
petitions to the learned counsel for the petitioners today itself
so as to enable the petitioners to file the same before the
Madurai Bench of Madras High Court. No costs.
