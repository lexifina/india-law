# Bombay High Court, CHS/1093/2007, 2008-04-21

SUMMARY SUIT NO. 1945 OF 2000
Shashikant P. Shah .... ...... ......Plaintiff.
V/s
M/s.Hanjeer Textiles Pvt. Ltd.. ...... ......Defendants.
Ms.Yogini Gada i/by Harakchand & Co., Adv. For the plaintiff to show

Mr.S.I.Menon, Adv. For the defendant No.1 in support of C/S.
CORAM: A.P.DESHPANDE, J.
21/4/08
PC:
This Court had granted unconditional leave to defend the suit
by an order dated 16.11.05. Defendants were granted four weeks
time to file written statement. However the defendants have failed to
file the same within stipulated period. By this chamber summons a
prayer is made for condonation of 567 days in filing written
statement. The reason set out in the application is that counsel was
labouring under the impression that the written statement has been
filed and hence did not take timely steps. Application is opposed by
learned counsel for the plaintiff. For the reasons set out in the
application same is allowed. Delay in filing written statement is
condoned. Written statement is tendered and is taken on record.
Chamber summons is allowed subject to payment of costs quantified
at Rs.1000/- to the plaintiff.
