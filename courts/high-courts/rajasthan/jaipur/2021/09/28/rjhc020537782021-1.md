Order
28/09/2021
Heard on the application for correction in the order dated
26.07.2021 passed in S.B. Civil Writ Petition No. 19435/2018.
Learned counsel for the petitioner submits that due to
typographical error the name of the counsel for the petitioner Mr.
Virendra Prajapat was not shown in the order dated 26.07.2021.
In that view of the matter, this application is allowed. The
name of the counsel for the petitioner Mr. Virendra Prajapat in

(2 of 2) [WMAP-137/2021]
place of Mr. Bharat Saini be read as counsel for the petitioner in
the order dated 26.07.2021.
Order stands corrected accordingly. This order be treated to
be part of the order dated 26.07.2021.
(INDERJEET SINGH),J
