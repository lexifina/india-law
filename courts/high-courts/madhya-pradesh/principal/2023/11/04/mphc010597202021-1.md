This petition coming on for conciliation this day, the Bench passed the
following:
ORDER
T h e present petition has been filed against the transfer order dated
17.12.2021 which has been stayed by this Court on 20.01.2022. Meaning
thereby, the order has not been given effect to so far.
2. Though, no reply has also been filed but taking into account the fact that
the order of transfer has not been given effect to so far in view of the interim
order passed by this Court, we are setting aside the order of transfer dated
17.12.2021.
3. The petition is accordingly allowed giving liberty to the respondents/State
to issue fresh order if occasion so arises and administrative exigency still exists.
