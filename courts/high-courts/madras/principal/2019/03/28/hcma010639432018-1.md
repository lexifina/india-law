O R D E R
This petition has been filed to direct the respondents to
provide police protection to install CCTC Cameras in the common
area of the petitioner's premises.
2. The learned Additional Public Prosecutor would submit
that on receipt of the complaint from One, Jeyasree, the
Assistant Commissioner concerned has conducted enquiry and the
same has been closed.
3. It is seen that the petitioner did not lodge any
complaint or request to provide police protection to install
CCTV camera. Therefore the direction as sought for by the
petitioner cannot be issued in this petition. However, the
petitioner is at liberty to file a fresh complaint on fresh
cause of action, if so advised.
https://hcservices.ecourts.gov.in/hcservices/

4. With the above observation, this criminal Original
Petition stands disposed of.
