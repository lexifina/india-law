PER COURT :
Heard both sides.
2] Mr.S.T.Shelke, learned counsel, files
affidavit-in-reply in Civil Application No.2695 of
2014 on behalf of respondent – acquiring body,
with request to read the same in present all
applications. The request is accepted. The
affidavit-in-reply is accepted on record and
marked as “X” for the purpose of identification.
He submits that Vakilpatra is yet to be received.
He undertakes to file the same lateron.

 7 group.odt
3] Present Civil Revision Applications are
arising of the same land acquisition proceedings.
There is delay of 15 to 20 days in filing the
Civil Revision Applications against the judgment
and order passed by learned Civil Judge Senior
Division in Land Acquisition Reference
Applications, which is sought to be condoned by
the present Civil Applications.
4] Upon hearing both sides and for the reasons
stated in the applications, the delay caused in
filing the Civil Revision Applications, is hereby
condoned in each of the applications.
5] All the applications are accordingly allowed
and disposed of without any order as to costs,.
6] Civil Revision Applications be registered.
