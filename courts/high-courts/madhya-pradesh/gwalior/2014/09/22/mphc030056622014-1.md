# High Court of Madhya Pradesh, MCRC/2342/2014, 2014-09-22

M. Cr. C. No. 2342/2014
 (Vikas Bondriya Vs. State of MP)
22/09/2014
Shri RK Sharma, Advocate for the applicant.
Shri Prabal Solanki, Public Prosecutor for the respondent- State.
Shri Sharma, learned counsel for the applicant submits that
most probably, Khatma report is being filed by the police, therefore, he
wants to withdraw this application filed under Section 438 of CrPC, with
liberty to file afresh if Khatma report is not filed.
Accordingly, the application is dismissed as withdrawn, with the
aforesaid liberty.

 (B. D. Rathi)
