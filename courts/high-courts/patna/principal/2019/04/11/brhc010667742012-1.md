ORAL ORDER
9 11-04-2019 The learned counsel for the petitioner submits that the
respondent has passed another order against the petitioner by
which modified the present impugned order, which he should be
allowed to challenge in a different proceeding. In view of new
development, this application has been rendered infructuous and
accordingly permission is granted to withdraw the writ
application with the liberty, if so like, he may challenge the
impugned order which has been passed against the petitioner.
With the above observation, this application is
dismissed as infructuous.
