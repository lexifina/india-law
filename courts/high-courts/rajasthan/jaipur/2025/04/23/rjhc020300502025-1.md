Order
23/04/2025
After arguing at some length, learned counsel for the
petitioner seeks permission to withdraw this writ petition with
liberty to file appropriate application to press the stay application
pending before the Appellate Tribunal, Jaipur Development
Authority, Jaipur in Reference Application No.415/2024.
Accordingly, this writ petition is dismissed as withdrawn with
liberty, as prayed for.
If any application is filed by the petitioner for pressing the
stay application pending before Appellate Tribunal within a period
of three weeks alongwith certified copy of this order, learned
Tribunal is directed to pass appropriate order in accordance with
law.
