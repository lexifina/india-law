CORAM : R.Y.GANOO, J.
 DATE : 11th JULY, 2011.
P.C. :
1. Learned Counsel appearing on behalf of the petitioner states that
after the filing of the chargesheet the petitioner had filed an
application for discharge and the same came to be rejected. If
this is the position and if the petitioner is aggrieved by the said
order, the petitioner has to file appropriate proceedings
challenging the order by which application for discharge was
rejected. That has not been done in this petition.
2. On hearing this, learned Counsel for the petitioner applied for
withdrawal of this petition with liberty to file appropriate

: 2 : wp-1745-11=.doc
proceedings so as to challenge the order by which revision for
discharge has been rejected.
3. Petition is allowed to be withdrawn. Liberty as prayed for is
granted.
4. No views are expressed on the merits of the matter.
(R.Y.GANOO, J.)
