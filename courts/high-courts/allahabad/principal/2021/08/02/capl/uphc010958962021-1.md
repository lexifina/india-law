# Allahabad High Court, CAPL/2418/2021, 2021-08-02

Court No. - 4
Case :- CONTEMPT APPLICATION (CIVIL) No. - 2418 of
2021
Applicant :- Smt. Poonam Chaudhary
Opposite Party :- Smt. Shanta Arora And 2 Others
Counsel for Applicant :- Virendra Kumar
Hon'ble Prakash Padia,J.
Supplementary affidavit filed today is taken on record.
The present contempt application has been filed against non-compliance and willful disobedience of the order dated
25.03.2015 passed by this Court in Second Appeal No.337 of
2015 (Prem Sagar Arora and others Vs. Raj Kumar Chaudhary
and others).
After some arguments, counsel for the applicant prays for
withdrawal of the present contempt application with liberty to
file appropriated application as provided under Order XXXIX
Rule 2-A of the Code of Civil Procedure in the pending second
appeal.
Prayer is allowed.
Accordingly, the present contempt application is dismissed as
withdrawn with liberty as prayed.
Order Date :- 2.8.2021
