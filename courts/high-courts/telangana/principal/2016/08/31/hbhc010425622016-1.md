# High Court for the State of Telangana, WP/29471/2016, 2016-08-31

THE HONíBLE SRI JUSTICE A.RAMALINGESWARA RAO
WRIT PETITION No.29471 of 2016
ORDER:
 Learned counsel for the petitioner seeks permission of
this Court to withdraw the present writ petition with a liberty
to file fresh writ petition.
 Permission is accorded.
 Accordingly, this Writ Petition is dismissed as
withdrawn giving liberty to the petitioner to file a fresh writ
petition. No order as to costs.
 Miscellaneous Petitions pending, if any, shall stand
closed.
 _______________________________
 A.RAMALINGESWARA RAO, J
31.08.2016
Note: Office is directed to return the original papers, if any,
 to the counsel for petitioner.
