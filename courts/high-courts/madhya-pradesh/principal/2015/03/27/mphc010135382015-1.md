# High Court of Madhya Pradesh, MCC/784/2015, 2015-03-27

MCC-784-2015
(SMT. VEENA AGARWAL Vs DAULAT SINGH)
27-03-2015
 Shri A.P. Shroti for the applicant.
 This application has been filed for restoration of R.P. No. 188/2014, which has
been dismissed for non-compliance with the common conditional order and non-appearance of the respondents.
 The application is supported by affidavit of the counsel himself and the default
is attributed to some lapse on the part of the counsel.
 Keeping in view the aforesaid, the application is allowed. R.P. No.188/2014 is
restored to its original file. It be placed for orders before the Appropriate Bench.
 Application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
(S.K. GANGELE)
JUDGE
