# High Court of Madhya Pradesh, MCRC/11747/2017, 2017-07-19

MCRC-11747-2017
(RAMESHWAR CHATURVEDI Vs THE STATE OF MADHYA PRADESH)
19-07-2017
Smt. Madhubala Chourasia, learned counsel for the
applicant.
Shri Vivek Lakhera, learned Panel Lawyer for respondent-State.
This application has been filed for modification of order
dated 04.07.2017, passed in M.Cr.C. No.9491/2017.
Learned counsel for the applicant submits that in the order
dated 04.07.2017, passed in M.Cr.C. No.9491/2017, Crime
number is mentioned as Crime No.26/2016 while the correct one
is Crime No.26/2017.
Considering the aforesaid, this application is hereby
allowed.
It is ordered that in the order dated 04.07.2017, passed in
M.Cr.C. No.9491/2017, "Crime No.26/2016" be read as "Crime
No.26/2017".
In view of above, M.Cr.C. stands disposed of.
(H.P. SINGH)
JUDGE
