HON'BLE MR. JUSTICE PANKAJ BHANDARI
Order
26/02/2020
1. Petitioner has preferred this Criminal Miscellaneous Petition
seeking fair investigation in F.I.R. No.638/2019.
2. Learned Public Prosecutor has submitted a report that Police
has already submitted negative final report in the Court. Report
submitted by learned Public Prosecutor is taken on record.
3. In view of the same, Criminal Miscellaneous Petition seeking
fair investigation has become infructuous and the same is
accordingly dismissed as having become infructuous. Stay
application stands disposed.
4. However, petitioner would be free to file protest petition, if so
advised.
(PANKAJ BHANDARI),J
