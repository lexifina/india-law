# Allahabad High Court, A482/34564/2019, 2019-09-20

Court No. - 64
Case :- APPLICATION U/S 482 No. - 34564 of 2019
Applicant :- Kanhaiya Lal
Opposite Party :- State Of U.P. And 5 Others
Counsel for Applicant :- Anil Kumar
Counsel for Opposite Party :- G.A.
Hon'ble Karuna Nand Bajpayee,J.
Heard learned counsel for the applicant and learned A.G.A. for
the State.
Submission of counsel for the applicant is that he does not want
to press this application. Instead of that he wants to file a
complaint case and liberty in that regard has been sought.
In the light of the submission made by counsel for the applicant
this application stands dismissed as not pressed.
So far as the liberty to file the complaint is concerned it is the
choice of the applicant. There is no need to issue any direction
in that regard. Applicant can adopt any course permissible
under law as he desires.
Order Date :- 20.9.2019
