# High Court of Madhya Pradesh, MCC/1409/2017, 2017-10-13

THE HIGH COURT OF MADHYA PRADESH
MCC-1409-2017
(PAWAN NAYAK Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 13-10-2017
Smt. Shobhna Sharma, learned counsel for the applicants.
This MCC is listed today for correction of typographical error
occurred in the order dated 08.05.2017 passed by this Court.
Learned counsel for the applicant submits that in the aforesaid
order, 'W.P. No.2195/2017' has wrongly been mentioned as 'W.P.
No.2195/2014' in para no.2, 3 & 4.
Considering the aforesaid and on perusal of the records, this Court
finds that in the order dated 08.05.2017 there is some
typographical error. Hence, it is directed that in the order dated
08.05.2017 be read as 'W.P. No.2195/2017' in place of 'W.P.
No.2195/2014'.
This order shall be read conjointly with the order dated
08.05.2017.
(SMT. ANJULI PALO)
JUDGE
