The petitioner, which is a Zilla Parishad has filed this civil application
seeking running account bills, which this Court has directed to be seized by
respondent no .5-Collector, to be returned for accounting purposes.
2. We have heard both the sides.
3. Considering the issue regarding the allegations and the purpose of
directing the running account bills to be seized by the respondent no. 5-
Collector, we dispose of the application directing respondent no. 5-Collector
to issue certified photo copies of all the running bills, which he has seized, to
the applicant-Zilla Parishad. We further permit the Zilla Parishad to use
these certified copies of the running account bills for the accounting
