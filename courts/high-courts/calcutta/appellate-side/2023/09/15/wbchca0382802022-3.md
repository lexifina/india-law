# Calcutta High Court, CRR/3148/2022, 2023-09-15

D/L7
15.09.2023
Bpg.
 C.R.R.3148 of 2022
In Re: An application under Section 482 of the Code of Criminal
Procedure;
 Sri Sabuj Sen and another
 Versus
 The State of West Bengal and others
 Mr. Soumya nag
 Mr. Abhinav Rakshit.
 …for the petitioners.
Learned advocate appearing for the petitioners submits
that he has instructions not to proceed with the present revisional
application. Learned advocate, however, prays for liberty to file
afresh.
Written instructions submitted by the learned advocate
appearing for the petitioners be kept with the record.
In view of the contentions so advanced, the present
revisional application being CRR 3148 of 2022 is dismissed as not
pressed.
Petitioners are granted liberty to file afresh incorporating
the changed circumstances.
Department is directed to return the certified copy to the
learned advocate on record of the petitioners after the same is
replaced by photostat copy.
All parties shall act on the server copy of this order duly
