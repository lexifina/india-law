# High Court of Orissa, CMP/733/2016, 2017-09-11

C.M.P. No.733 of 2016
 11. 11.09.2017 Heard learned counsel for the petitioners. Nobody appears for the oppo
site party in spite of notice.
 This Civil Miscellaneous Petition involves allowing an application under Order
 6, Rule 17 of the Code of Civil Procedure at the instance of the plaintiff. Challenging the
impugned order, learned counsel appearing for the petitioners submitted that no application un
der Order 6, Rule 17 of the Code of Civil Procedure could have been entertained while keeping
the petition under Oder 7, Rule 11 of the Code of Civil Procedure pending. Sri Behera, learned
 counsel also claimed that entertaining the application under Order 6, Rule 17 of the Code of
Civil Procedure otherwise is an attempt to allowing the application under Order 7, Rule 11 of
the Code of Civil Procedure in this Court ineffective. It is under the above premises, learned
 counsel for the petitioners submitted that the impugned order becomes bad and should be inter
fered and set aside.
 Considering the submission of learned counsel for the petitioners, looking to
the plaint averments and to the proposed amendment, for the nature of proposed amendment, this
 Court finds there is no restriction on the plaintiff to bring such an amendment. Since the de
fendants had a scope for additional written statement, there is no prejudice to the defendants
. As a result, this Court finds no infirmity in the impugned order and as a consequence, this
 Court dismisses the Civil Miscellaneous Petition having no merit.
 Since the petitioners are enjoying the interim order granted by this Court
, this Court permits the petitioners to file additional written statement within a period of t
hree weeks hence.
 Issue urgent certified copy of this order on proper application.

 BISWANATH RATH,J.
