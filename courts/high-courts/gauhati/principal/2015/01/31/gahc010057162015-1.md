# Gauhati High Court, AB/114/2015, 2015-01-31

AB 114/2015
BEFORE
HON’BLE MR JUSTICE P.K.SAIKIA
This application U/s. 438 CrPC is filed by the petitioner, namely, Fakar Uddin M
ajumder @ Fakar Mullah seeking pre-arrest bail in connection with Hailakandi
P.S.Case No. 221/2012 U/s. 304(B)IPC.
Ms. L.Wajeeda, learned counsel for the petitioner and Mr. B.S.S
inha, learned Addl. P.P.Assam, appearing for the State respondent.
It is submitted by the learned Addl. P.P.Assam that the charge
sheet has already been submitted against the accused/petitioner in connection wi
th the aforesaid case.
The learned counsel for the petitioner, therefore, urges th
is Court to allow him to withdraw this bail petition with a view to file applica
tion seeking bail in connection with the aforementioned case before the appropri
ate court.
The prayer is allowed.
Accordingly, this bail application is disposed of on withdrawal.
However, if the petitioner file an application seeking
bail before the learned Court below, the learned Court below would consider an
d disposed of the same in accordance with law.
The bail application is disposed of. Return the case diary.
