ORDER
The petitioner has filed this petition praying to call for the records and
quash the First Information Report pending on the file of the first respondent-Police in Crime No.577 of 2022, dated 06.12.2022.
2. When this petition is taken up for hearing, learned Additional Public
Prosecutor appearing for the first respondent submitted that the charge-sheet
has been filed before the Judicial Magistrate, Arni and the charge-sheet is taken
on file in e-filing No.C202400582, dated 22.08.2024.
3. Hence, this petition is dismissed. Consequently, the miscellaneous
petition is closed.
