O R D E R
The first defendant has applied to condone the delay in filing the
application to set aside ex parte decree dated 30.06.2025. In the affidavit
in support of this application, it is stated that the applicant became aware
of the decree on 25.08.2025 and that all relevant papers could be obtained
only on 02.11.2025.
2. Learned counsel for the plaintiff submits that reasons mentioned
in the affidavit as an explanation for not appearing in the matter are
untenable and that the first defendant participated in interlocutory
proceedings. She also submits that a counter affidavit would be filed in
the application to set aside the decree because the plaintiff has strong
objections to the same.
2/4
https://www.mhc.tn.gov.in/judis

3. Considering the reasons set out in the affidavit and being
satisfied that sufficient cause is shown to condone the delay, the
application to condone the delay is allowed. The Registry is directed to
number and list the application to set aside the ex parte decree, if
otherwise in order.
