ORAL ORDER
Since the applicants have directly approached
this Court by way of filing the present application
under Section 438 of the Code of Criminal Procedure,
1973, this Court is not inclined to entertain this
application on merits.
Mr.D.R. Bhatt, learned advocate for the
applicants, seeks permission to withdraw this
application with a view to file the same before the
Sessions Court.
Permission, as prayed for, is granted. The
application stands disposed of, as withdrawn. As and
when such an application is filed, the same shall be
considered on its own merits. It is clarified that
this Court has not examined the merits of the case.
(VIPUL M. PANCHOLI, J)
