# High Court of Madhya Pradesh, MCC/456/2017, 2017-03-03

MCC-456-2017
(ZAHOOR KHAN Vs ASHISH MEHTA)
03-03-2017
Shri J.L. Soni, learned counsel for the applicant.
Heard on I.A. No.2245/2017, an application for condonation of delay.
For the reasons mentioned in the application, the same (I.A.
No.2245/2017) is allowed. The delay in filing this application is hereby
condoned.
This application has been filed for restoration of M.A. No.1446/2007
which was dismissed for want of prosecution on 06.10.2016.
Looking to the facts mentioned in the application, the same is allowed.
The aforesaid M.A. No.1446/2007 is restored to its original file.
The MCC stands allowed & disposed of.
Let a copy of this order be kept in the file of M.A. No.1446/2007.
(SMT. ANJULI PALO)
JUDGE
