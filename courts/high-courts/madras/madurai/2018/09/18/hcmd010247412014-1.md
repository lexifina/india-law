This petition is filed to change the investigation in crime
No.5 of 2014 on the file of the second respondent to the file of
the 3rd respondent and to file the final report within a time
stipulated by this Court.

the investigation in crime No.No.5 of 2014 on the file of the
second respondent has been completed and the respondent No.2 laid
the charge sheet on 06.10.2015 before the Judicial Magistrate No.2,
Trichy and the same was not taken on file.
