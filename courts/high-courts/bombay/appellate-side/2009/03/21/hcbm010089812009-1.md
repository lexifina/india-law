 Shree Yogi Darshan Makwane

 Karsandas Chaganlal Solanki (deceased)
 By...Respondents Lrs.-Vijayaben K. Solanki & anr.

 1(a).
CORAM : A.M.KHANWILKAR,J.
DATED : MARCH 21, 2009
P.C.
 .This application is filed on 6th March, 2009. It
 was produced on 13th March, 2009 and it was ordered to
 be placed for hearing today i.e. 21st March, 2009.
 When the matter is called out, Counsel for the
 Respondent seeks time to file reply. It is not the case
 of the Respondent that the respondent was unaware of the
 date given on 13th March, 2009. The Respondent has been
 duly served with this application long back and had
 enough time to file reply, if so desired. As of now, no
 reply has been filed. Request for further time to file
 reply in the fact situation of this case cannot be
 countenanced. That request is rejected.

 2
 2.In view of the assertions made in the application
 being sufficient cause and in the interest of justice, I
 am inclined to allow this application in terms of prayer
 clause (b). Ordered accordingly.
[A.M.KHANWILKAR,J.]
