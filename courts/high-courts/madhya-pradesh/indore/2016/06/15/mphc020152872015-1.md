# High Court of Madhya Pradesh, MCC/497/2015, 2016-06-15

MCC-497-2015
(SANTOSH Vs KAILASHCHANDRA)
15-06-2016
Mr. Bhimsen Soni, learned counsel for the applicant.
Mr. Monesh Jindal, learned counsel for the non-applicant
No.3.
Heard learned counsel for the applicant on IA
No.5047/2015 that is an application for condonation of
delay.
There is a delay of 96 days. Sufficient reason has been
assigned in the application for condoning the delay.
Accordingly, application is allowed and delay stands
condoned.
Also heard learned counsel for the applicant on this
M.C.C.
This application has been filed for restoration of M.A.
No.375/2014 which was dismissed vide order dated
16/06/2015 for non-compliance of peremptory order
dated 18/02/2015.
The application has filed on the ground that due to over
sight, the counsel for the applicant could not file the
process-fee within time.
For the reasons stated in the application which is
supported by an affidavit of the applicant. In view of this,
the application is allowed. Consequently, M.A.
No.375/2014 is restored in its original number. Office is
directed to re-register the miscellaneous appeal and list
accordingly.
Application is disposed of. Copy of this order be kept in

the record of M.A. No.375/2014.
C.C. as per rules.
(KUMARI JUSTICE VANDANA
KASREKAR)
JUDGE
