The Court: Both learned counsel, Mr. Soumabho Ghose and Mr.
Jayanta Kumar Mitra, learned senior advocate made extensive arguments. At
the close of such argument, Mr. Ghose seeks leave of this court to withdraw
this appeal and to file an application under Order 9 Rule 13 of the Civil
Procedure Code before the learned trial Judge.
We allow such prayer. In the records of this court the appeal and the
application should be treated as dismissed as withdrawn with liberty to file an
application under Order 9 Rule 13 of the Civil Procedure Code on the self-same grounds before the learned trial Judge.
All points are kept open.
