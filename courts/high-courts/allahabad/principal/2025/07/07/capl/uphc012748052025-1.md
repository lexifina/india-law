Heard learned counsel for the applicant.

does not want to press this application and it may dismissed as
withdrawn with liberty to file fresh application.
Accordingly, the application is dismissed as withdrawn.

petition, there is no need to grant such permission. It is always
open for the petitioner to file contempt petition, if any, order of
Court has not been complied with.
