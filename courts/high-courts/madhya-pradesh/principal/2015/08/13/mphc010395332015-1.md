# High Court of Madhya Pradesh, WP/13346/2015, 2015-08-13

WP-13346-2015
(RAMJAAN KHAN Vs THE STATE OF MADHYA PRADESH)
13-08-2015
Shri R.K. Singh, learned counsel for the petitioner.
Shri P.K. Pandey, learned Govt. Adv. for the State.
Heard.
Learned counsel for the petitioner prays that the petitioner
be permitted to file an application under Section 18 of the
Madhya Pradesh Land Revenue Code 1894 for making reference
before the appropriate Court.
Petition is disposed of with a observation that the petitioner
is at liberty to file an application for making reference in
accordance with the provisions of 18 of the Madhya Pradesh
Land Revenue Code 1894 before the appropriate Forum.
No order as to the costs.
Certified copy as per rules.
(S.K. GANGELE)
JUDGE
