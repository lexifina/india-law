# High Court of Madhya Pradesh, WP/14714/2013, 2016-11-23

WP-14714-2013
(K.S. SULYA Vs THE STATE OF MADHYA PRADESH)
23-11-2016
Shri Vinod Mehta, learned counsel for the petitioner.
Shri G.P. Kekre, learned counsel for the respondents.
Heard finally.
This writ petition has been filed by the petitioner challenging the
order dated 16.8.2013, whereby the petitioner was sent on
deputation to Narmada Valley Development Authority.
The case of the petitioner is that he was transferred by earlier
order dated 18.6.2012 on his own expense from Ratlam to
Nepanagar, Burhanpur Forest Division and within a short time
without his consent he has now been sent on deputation.
Considering the grievance of the petitioner this Court vide order
dated 30.8.2013 had stayed the operation of the impugned order
dated 16.8.2013. The impugned order has not been given effect to
till now.
Learned counsel for the State fairly submits that with the lapse of
time the impugned order has lost its efficacy, therefore, now the
respondents be permitted to pass fresh order if the administrative
exigency so arises.
In the aforesaid circumstances the impugned order dated
16.8.2013 so far as it relates to the petitioner is set aside with
liberty to the respondents to pass fresh order in accordance with
law, if the need so arises.
Writ petition is accordingly disposed of.
C.C. as per rules.

(PRAKASH SHRIVASTAVA)
JUDGE
