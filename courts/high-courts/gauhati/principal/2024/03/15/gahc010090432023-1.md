Both the applications are taken up together for consideration.
2. I have heard Mr. R. Sarma, learned counsel appearing on behalf of the
Applicant and Mr. M. Smith, learned counsel appearing on behalf of the
Respondents.
3. I.A.(Civil) No. 1338/2023 is an application for condoning the delay of 63
days in preferring the application under Order XLI Rule 19 of the Code for
restoration of the accompanying appeal which was dismissed by default vide an
order dated 23.01.2023.
4. This Court has perused the grounds stated in the said application and is
of the opinion that the same constitutes sufficient cause for condoning the delay
63 days.
5. Misc.(J) Case No. 32/2023 is an application under Order XLI Rule 19 for
restoration of the accompanying appeal, which was dismissed for default vide
order dated 23.01.2023. The said ground assigned in the said application have
been duly noted. The learned counsel for the respondents have not objected to
both the applications. Considering the above, the appeal is restored.
6. Accordingly the instant application is allowed thereby restoring the appeal
