3 03-09-2012 This case has been listed under the heading “To be
Mentioned” at the instance of counsel for the petitioner to correct
some typographical error in the order dated 08.08.2012.
 It is pointed out by counsel for the petitioner that in the
order dated 08.08.2012 in the first line of the order instead of
counter affidavit it should be read as writ petition. Further in
paragraph No.2 name of Respondent Nos. 3 and 4 has been
wrongly mentioned which should be read as “Respondent No.3,
The Principal Secretary, Rural Development Department,
Government of Bihar, Patna and Respondent No.4, The District
Collector, Katihar.
 The order dated 08.08.2012 stands modified.
 Registry is directed to issue modified order accordingly.
