ORDER
This criminal miscellaneous case is filed to quash the
proceedings in C.C.No.410/2011 on the file of the Judicial
First Class Magistrate Court-II, Trivandrum. The above case
is charge-sheeted alleging offences punishable under Section
498(A) of the Indian Penal Code.
2. As per the e-courts service website, the case is
transferred to Long Pending List because there was no
appearance for the petitioner. The petitioner submitted that
the matter is settled. If that is the case, the petitioner can
surrender before the jurisdictional court and regularize the
matter and file appropriate application in accordance with law.
With the above observation, this criminal miscellaneous
case is disposed of.
