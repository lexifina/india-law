PER COURT:-
Learned counsel for the petitioner, since this Court has
dismissed Writ Petition No. 9669 of 2018 (Pravinkumar S/o
Shashikant Pathak and Others v. The State of Maharashtra and
others), seeks leave to withdraw this Writ Petition with liberty to
assail the order passed by the Minister if occasion so arises. Leave
granted. The Writ Petition is dismissed as withdrawn with liberty to
the petitioner to challenge, if occasion so arises, the order passed
by the Minister and if it is so challenged, all the points are kept
open.
