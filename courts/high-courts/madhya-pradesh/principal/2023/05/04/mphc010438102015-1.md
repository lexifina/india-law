ORDER

Learned counsel for the Municipal Corporation, Bhopal points out that a
petition involving the same set of facts, raising same grounds, praying for the
same relief bearing W.P.No.14714/2015 has been filed by the same petitioner.
Smt. Menon, learned senior counsel does not dispute the said aspect.
Accordingly, the present petition i.e. W.P.No.14718/2015 which was
filed later is dismissed as superfluous.
