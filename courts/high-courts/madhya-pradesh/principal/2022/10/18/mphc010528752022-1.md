This application coming on for hearing this day, the court passed the
following:
ORDER
Heard on I.A.No.11364/2022 which is an application for modification of
the order dated 24.08.2022 passed in MCC No.2020/2022.
Learned counsel for the applicants contends that on account of
typographical error in last two lines of the said order, instead of
M.A.No.3003/2016, W.P.No.3003/2016 has been mentioned.
Upon consideration of the contents of the application, the same is
allowed.
In the last two lines of the order dated 24.08.2022, description of the
case number be read as "M.A.No.3003/2016" instead of
"W.P.No.3003/2016".
This order be read conjointly with the order dated 24.08.2022 passed in
MCC No.2020/2022.
With the aforesaid, the application for modification stands disposed of.
