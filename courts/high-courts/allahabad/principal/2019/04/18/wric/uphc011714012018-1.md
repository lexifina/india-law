# Allahabad High Court, WRIC/30854/2018, 2019-04-18

Court No. - 39
Case :- WRIT - C No. - 30854 of 2018
Petitioner :- Kamal Kant And 2 Others
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Jitendra Kumar Singh,Braj Mohan Singh
Counsel for Respondent :- C.S.C.
Hon'ble B. Amit Sthalekar,J.
Hon'ble Saurabh Shyam Shamshery,J.
This Misc Withdrawal Application dated 8.4.2019 has been
filed by the learned counsel for the petitioners with the prayer
to dismiss the writ petition as withdrawn with liberty to file a
fresh writ petition.
Heard Sri Pradeep Kumar learned counsel for the petitioners on
this application which is supported by an affidavit.
It is submitted by the learned counsel that the writ petition may
be dismissed as withdrawn with liberty to file a fresh writ
petition challenging the order dated 8.9.2017.
The Application is allowed.
The writ petition is dismissed with the aforsaid liberty.
Order Date :- 18.4.2019
