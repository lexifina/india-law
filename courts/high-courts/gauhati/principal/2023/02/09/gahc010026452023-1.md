Heard Ms. P Borah, learned counsel for the applicant. Also
heard Mr. B Sarma, learned Addl. PP appearing for the State
respondent, Assam.
This I.A is filed by the applicant, namely, Ajit Baruah for
correction of the number of Gohpur PS Case in the order dated

Page No.# 2/2
23.11.2022 in AB No.2635/2022, wherein the number of Gohpur PS
was mentioned as Gohpur PS Case No.188/2022, which ought to have
been recorded as Gohpur PS case No.118/2022.
Having heard the submission of learned Advocates for both
the sides and also perusing the order dated 23.11.2022 in AB
No.2635/2022, it is provided that henceforth Gohpur PS Case
No.188/2022 appearing in the order dated 23.11.2022 shall be read
as Gohpur PS Case No.118/2022 for all purposes.
In terms of the above, this I.A stands disposed of.
 JUDGE
