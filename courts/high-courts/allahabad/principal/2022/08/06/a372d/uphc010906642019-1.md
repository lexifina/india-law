(Criminal Misc. Delay Condonation Application)
This is a defective application filed by informant. There is a
huge delay of 613 days. None has remained present today for
the applicant nor for respondents.
There is no plausible explanation in regard to the fact that as to
why the said application was not filed for a long time. The
delay in filing the application has also not been properly
explained.
We have no other option to dismiss the application as the delay
is unexplained.
In view of the above, the application stand rejected.
(Order on Application)
We have dismissed the application for condoning the delay in
filing the present application, therefore, the present application
is also dismissed.
The application stands dismissed.
