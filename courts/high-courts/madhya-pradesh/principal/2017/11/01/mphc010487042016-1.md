# High Court of Madhya Pradesh, AC/55/2016, 2017-11-01

THE HIGH COURT OF MADHYA PRADESH
AC-55-2016
(KUMARI NIDHI SINGHAI Vs SYED NAVED HASAN)
Jabalpur, Dated : 01-11-2017
None for the applicant.
Shri Vishal Dhagat, learned Government Advocate for the
respondents.
Shri Dhagat pointed out that on 08-08-17, the applicant was
granted four weeks' time to file certified copy of agreement. No
certified copy was filed till next date. On 13-09-2017, Shri Dhagat
raised objection that there exists no arbitration agreement between
the parties,which contains any arbitration clause. Shri Dhagat further
stated that Annexure P/1 is a forged document. Faced with this,
learned counsel for the applicant prayed for fifteen days' time as a
last indulgence to file original agreement. On 04-10-2017 also, Shri
Gupta, learned counsel for the applicant prayed for time. While
granting time, this Court made it clear that no further time will be
granted on the next date of hearing. Applicant has neither filed that
document nor remained present in both the rounds.
For these cumulative reasons, the application is dismissed.
(SUJOY PAUL)
