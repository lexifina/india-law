# Allahabad High Court, CAPL/4849/2021, 2021-10-29

Court No. - 4
Case :- CONTEMPT APPLICATION (CIVIL) No. - 4849 of
2021
Applicant :- Arun Kumar Agarwal
Opposite Party :- Rajesh Gautam
Counsel for Applicant :- Ashish Goyal
Hon'ble Prakash Padia,J.
List of fresh cases has been revised. Nobody is present.
The applicant has preferred the present petition for non-compliance of the order dated 20.09.2006 passed in Second
Appeal No.1496 of 1981 (Maya Ram Gautam Vs. Manmohan
Sharma and another) which is decided under Order 39 Rule 2-A
of the Code of Civil Procedure.
In case any order is passed in the Second Appeal has been
violated, the Court is of the opinion that proper remedy is
available to the applicant to file appropriate application as
provided under Order 39 Rule 2-A of the Code of Civil
Procedure in the pending Second Appeal.
In this view of the matter, the present Contempt Application is
dismissed with liberty as stated above.
Order Date :- 29.10.2021
