# High Court of Rajasthan, CRLMB/10237/2015, 2016-01-13

S.B. CR. MISC. BAIL APPLICATION NO.10237/2015
Jeevanmal Rathi Vs. State of Rajasthan
Date of order : 13.01.2016
HON'BLE MR. JUSTICE VIJAY BISHNOI
Mr. Vineet Jain, for the petitioner.
Mr. Ashok Upadhyay, Public Prosecutor.
The petitioner has filed this bail
application under Section 438 Cr.P.C.
Learned Public Prosecutor has submitted
factual report dated 6.1.2016 wherein it is
mentioned that after thorough investigation, the
police is going to file negative final report
and there is no need to arrest the petitioner.
At this stage, learned counsel for the
petitioner does not want to press this bail
application filed under Section 438 Cr.P.C. The
same is, therefore, dismissed as not pressed.
[VIJAY BISHNOI],J.
Babulal/
