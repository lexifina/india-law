# High Court of Madhya Pradesh, MCC/2245/2006, 2014-02-06

MCC No.2245/2006
6/2/2014 :
Shri D. S. Choudhary, learned counsel for the
applicant.
This application has been filed under Order 44
Rule 1 CPC seeking permission to sue as an
indegent person. The application is pending since
2006 and report from the office of the Collector with
regard to financial status of the applicant is not
available.
The matter is pending since 2006, there is no
rebuttal to the allegations made in the application
and considering the fact that the applicant was
permitted to sue as an indegent person before the
Trial Court, this application is allowed. Applicant is
permitted to file the First Appeal as an indegent
person. Necessary steps be taken for registration of
First Appeal and listing it for orders before the
appropriate Bench.
Application under Order 44 Rule 1 CPC stands
allowed and disposed of.
( Rajendra Menon) ( Anil Sharma )
