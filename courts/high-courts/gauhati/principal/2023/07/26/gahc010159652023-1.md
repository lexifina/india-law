The present Interlocutory Application has been filed for correction of the
case number appearing in the order of this Court dated 20.07.2023 passed in
AB/2502/2022.
In the aforesaid order, the Kokrajhar P.S. Case number has been mentioned
as 499/2023 whereas it should have been “Kokrajhar P.S. Case No.499/2016”.
The error stands corrected accordingly.
Henceforth, the Kokrajhar P.S. Case No.499/2023 appearing in the order
dated 20.07.2023 passed by this Court in AB/2502/2022 shall be read as “Kokrajhar
P.S. Case No.499/2016”. This order shall form a part of the order dated 20.07.2023
passed in AB/2502/2023.
With the aforesaid direction, the Interlocutory Application (Crl.) stands
disposed of.
