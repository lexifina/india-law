03
This matter is taken up through hybrid mode.
 2. This application has been filed by the petitioner to
recall the order dated 02.09.2021, by which this Court
dismissed the writ petition permitting the petitioner to
withdraw the writ petition due to non-joinder of party.
 3. Now the petitioner has filed this application for
recalling of the order dated 02.09.2021 with liberty to file
a better petition with better particulars, to which learned
State Counsel has no objection.
 4. Considering the grounds stated in the application,
the order dated 02.09.2021 is hereby recalled. The
petitioner is permitted to withdraw the writ petition with
liberty to file a better petition with better particulars.
 5. I.A. stands disposed of.

Alok DR. B.R. SARANGI, J.
