ORDER
This application is filed to set aside the exparte order made in TOS No.23
of 2021 dated 12.03.2025.
2.The learned counsel for the respondent has no serious objection in
allowing this application.
3. The first defendant is said to have filed written statement already. In
order to give one more opportunity to the applicant / first defendant to cross-examine the plaintiff side witness and proceed with the trial, I feel this
application should be allowed.
4. Accordingly, this application is allowed and the ex parte order made in
TOS No.23/2021 dated 12.03.2025 is hereby set aside.
