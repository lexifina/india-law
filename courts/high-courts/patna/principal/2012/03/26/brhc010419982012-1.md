Learned counsel for the petitioner submits that he has not
been able to file supplementary affidavit in the light of order ofthis
Court dated 12.1.2012. It is submitted that within two weeks, he
would file supplementary affidavit.
Learned counsel for the State submits that one more
indulgence be granted to take instruction and file counter affidavit.

two weeks failing which the application shall stand rejected
without further reference to a Bench. In the event of compliance
of the order, the matter shall come up after six weeks in the same
head. Time, in the meanwhile, shall be utilized by the respondents
to file counter affidavit.
