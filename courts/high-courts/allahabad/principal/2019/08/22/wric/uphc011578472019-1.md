# Allahabad High Court, WRIC/27434/2019, 2019-08-22

Court No. - 49
Case :- WRIT - C No. - 27434 of 2019
Petitioner :- Narendra Kumar
Respondent :- State Of U.P. And 5 Others
Counsel for Petitioner :- Dharmendra Kumar Tripathi
Counsel for Respondent :- C.S.C.
Hon'ble Siddhartha Varma,J.
The petitioner has filed the instant writ petition against the
order dated 12.07.2019 by which the Stay Application of the
petitioner has been rejected. The petitioner has challneged the
order dated 12.07.2019 along with the order dated 11.06.2019
passed by the Sub-Divisional Magistrate, Bareilly.
Learned Standing Counsel submits that as per the order dated
11.06.2019 which has been appealed against arrangement for
distribution must have been made therefore no interference be
done with the order dated 12.07.2019.
Under such circumstances, since distribution must be getting
done from the attached shop, it is being directed that the Appeal
itself be decided within a period of one month from the
presentation of a certified copy of this order.
The writ petition is accordingly, disposed of.
Order Date :- 22.8.2019
