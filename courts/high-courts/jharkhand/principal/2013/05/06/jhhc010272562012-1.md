3/ 6.5.13. Heard learned counsel appearing for the petitioners and learned
counsel appearing for the State.
The order dated 24.8.2012 passed in C.P. Case no.294 of 2009
under which cognizance of the offence punishable under Sections 341, 323,
337/34 of the Indian Penal Code is being sought to be quashed on the ground that
earlier to lodgment of the case upon which cognizance has been taken against the
petitioners, the petitioners had also lodged a case which was registered under
Sections 341, 323,506, 379/34 of the Indian Penal Code. There appears to be a
case and counter case wherein both sides have leveled allegations against each
other.
In that view of the matter, the instant prosecution can never be said to
be a case of malicious prosecution.
 Accordingly, the order taking cognizance never warrants to be
quashed. Hence, this application stands dismissed.
 (R.R.Prasad, J.)
