# High Court of Madhya Pradesh, MCC/675/2017, 2017-03-06

MCC-675-2017
(MAJOR CHANDRAKANT SINGH ( RETD. ) Vs THE STATE OF MADHYA PRADESH)
06-03-2017
Shri A.P. Singh, learned counsel for the applicant.
Shri Ramesh Kushwaha, learned counsel for the respondents-State.
Heard on I.A. No.3310/2017, an application for condonation of delay.
For the reasons mentioned in the application, the same (I.A.
No.3310/2017) is allowed. The delay in filing this application is hereby
condoned.
This application has been filed for restoration of W.P. No.6835/2011
which was dismissed for want of prosecution on 20.12.2016. The
application is supported by an affidavit.
Looking to the facts mentioned in the application, the same is allowed.
The aforesaid W.P. No.6835/2011 is restored to its original file. The MCC
stands allowed & disposed of.
Let a copy of this order be kept in the file of W.P. No.6835/2011.
(SMT. ANJULI PALO)
JUDGE
