This Criminal Petition is filed under Section 482 of the
Code of Criminal Procedure, 1973, praying to set aside the
order dated 02.09.2011 taking cognizance in

filed an application seeking to adduce additional grounds.
2. It would be appropriate if the petitioner withdraws this
petition and files a fresh petition.
3. Reserving liberty to the petitioner to file a fresh
petition adducing additional grounds, the present petition is
disposed of. I.A.1/2016 is disposed of.
