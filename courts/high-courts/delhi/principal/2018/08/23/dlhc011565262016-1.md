the State submits that though the petitioner has not been arrayed as an
accused in the main charge sheet nor kept in Column No.12, however, a
supplementary charge sheet has been filed before the learned Trial Court

has not received the summons. In view of the changed circumstances,
learned counsel for the petitioner seeks leave to withdraw the present
petition with liberty to file a fresh petition if need arises and if so advised
