ORDER
 The writ petition has been filed for a direction to first respondent to issue
a passport to petitioner by renewing the same in file No.MA2074629517122, on
the request made by petitioner within a time frame to be fixed by this Court.
2. At the outset, it is submitted by learned Central Government Standing
Counsel for first respondent 3that earlier application of petitioner cannot be
processed any longer and he would submit that it is always open to petitioner to
take out a fresh online application. If any such online application is filed, the
same would considered and appropriate orders would be passed, in accordance
with law, within a time frame to be fixed by this Court, which was agreed to by
the learned counsel for petitioner.
3. In view thereof, it is open to petitioner to file a fresh online application
and if any such online application is filed, the first respondent shall consider the
same on its own merits and renew the passport, in accordance with law, within a
period of four (4) weeks from the date on which the online application is filed
by petitioner. It is made clear that this Court has not expressed any views with
regard to the merits of the case.
