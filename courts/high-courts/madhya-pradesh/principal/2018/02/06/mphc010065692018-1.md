# High Court of Madhya Pradesh, MCRC/5059/2018, 2018-02-06

THE HIGH COURT OF MADHYA PRADESH
MCRC-5059-2018
(HANNU @ HARNAM DANGI Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 06-02-2018
Shri Ajay Kumar Mishra, learned counsel for the applicant.
Shri Amit Sharma, learned Govt. Advocate, for the
respondent/State.
Heard.
This is an application for modification of the bail order dated
18.1.2018 passed in M.Cr.C.No.28577/2017.
Learned counsel for the applicant submits that in the order
passed by this Court dated 18.1.2018 in M.Cr.C.No.28577/2017,
P.O.R.No.1291/12 has wrongly been mentioned, whereas, the correct
one is, 'P.O.R.No.1791/21'.
Considering the aforesaid, this application is allowed. Let
P.O.R. No.1291/12, registered at Forest Range, Range Office
Gaurjhamar, District Sagar, mentioned in the order dated 18.1.2018 in
M.Cr.C.No.28577/2017 be read as P.O.R.No.1791/21. This order
shall be read conjointly with the order dated 18.1.2018.
Let a copy of this order be kept in the record of
M.Cr.C.No.28577/2017.
Certified copy as per rules.
(H.P. SINGH)
JUDGE
