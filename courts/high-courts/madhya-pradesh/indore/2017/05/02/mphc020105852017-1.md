# High Court of Madhya Pradesh, MCRC/4402/2017, 2017-05-02

--- 1 ---
M. CR. C. No. 4402 / 2017
02/05/2017
Petitioner through counsel.
The present application has been filed u/S. 482 of the
Code of Criminal Procedure, 1973 for review / recall of the
order dated 6/4/2017 passed in M.CR.C.No. 619/2017.
The aforesaid order has been passed on an application
preferred u/S. 378(3) of the Code of Criminal Procedure,
1973 against the judgment of acquittal dt. 3/11/2016.
This Court has passed a detailed and exhaustive order.
There is no provision of review / recall under the Code of
Criminal Procedure, 1973.
Accordingly, admission is declined.
