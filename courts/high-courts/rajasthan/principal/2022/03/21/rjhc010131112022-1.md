Order
21/03/2022
The case comes up on an application for correction in the
name of the police station as mentioned in the order dated
14.01.2022.
Learned counsel for the applicant submits that by mistake,
the name of the police station in the order dated 14.01.2022 has
been mentioned as Pratap Nagar whereas it should have been
Boranada.
For the reasons mentioned in the application, the same is
allowed and it is ordered that in the order dated 14.01.2022, the
name of the police station in the FIR No. 267/2021 be read as
police station Boranada instead of police station Pratap Nagar.
