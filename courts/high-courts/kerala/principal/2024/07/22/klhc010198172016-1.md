O R D E R
This Criminal Miscellaneous Case is filed to quash
the proceedings in C.C.No.29/2010 on the file of the
Chief Judicial Magistrate Court, Ernakulam.
2. The petitioner is the 2nd accused in the above
case. The 8th accused earlier approached this Court to
quash the proceedings, and this Court as per order
dated 14.11.2023 in Crl.M.C.No.2271/15 disposed of
the same, allowing the 8th accused to file a discharge
petition if charge is not framed. In such circumstances,
I think this Court need not entertain this Crl.M.C on
merit. A similar order can be passed in this case also.
The petitioner can be allowed to file a discharge petition
if the charge is not framed.

Crl.M.C. No.5005 of 2016
3
Therefore, this Criminal Miscellaneous Case is
disposed of allowing the petitioner to file a discharge
petition before the trial court, if the charge is not
framed. All the contentions raised by the petitioner in
this Criminal Miscellaneous Case are left open.
