# High Court of Madhya Pradesh, MCRC/18424/2015, 2016-02-09

MCRC-18424-2015
(KAMLESH PATEL Vs THE STATE OF MADHYA PRADESH)
09-02-2016
Shri Anshuman Singh, learned counsel for the applicant.
Shri Pradeep Singh, learned GA for the respondent/State.
After arguing for some time, learned counsel for the applicant seeks
leave to withdraw this application filed under Section 438 of Cr.P.C. with
liberty to the applicant to file an application before the trial Court under
Section 439 of Cr.P.C.
The prayer is accepted.
With the aforesaid liberty, the M.Cr.C. is dismissed as withdrawn. In case
the applicant files the application as aforesaid, the same be considered
by the trial court as expeditiously as possible, if possible on the very
same day.
C.C. as per rules.
(SHANTANU KEMKAR)
JUDGE
