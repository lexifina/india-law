HON'BLE MR. JUSTICE RAMESHWAR VYAS
Order
23/02/2021
Learned counsel for the petitioner submits that after
investigation police has already filed FR. The dispute between the
parties is of civil nature.
Learned Public Prosecutor submits that this bail application
has been rendered infructous.
Since, there is no apprehension of arrest, this bail application
has been rendered infructous. The same is therefore, dismissed as
having become infructous. However, if Court of competent
jurisdiction takes cognizance of the matter, then accused should
be release on bail.
The factual report produced by the learned Public Prosecutor
is taken on record.
(RAMESHWAR VYAS),J
