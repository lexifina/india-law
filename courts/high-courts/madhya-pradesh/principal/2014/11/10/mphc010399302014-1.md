# High Court of Madhya Pradesh, MCC/1817/2014, 2014-11-10

1
MCC No.1817/2014
10/11/2014.
Shri Atualanand Awasthy, learned
counsel for the applicant.
This application has been filed for
restoration of F.A. No.438/2014, which was
dismissed for non compliance with the Common
Conditional order passed by this Court on 4.8.2014.
There being delay of about 30 days, I.A.
No.13248/2014 has been filed.
Keeping in view the reasons given the
application which is supported by the affidavit of
counsel himself and finding the same to be
bonafide, both the applications are allowed.
Condoning the delay in filing the restoration
application, the restoration application itself is
allowed. F.A. No.438/2014 is restored to its original
file. It be placed for orders before an appropriate
Bench.
Application stands allowed and disposed
of.
(Rajendra Menon) (Sanjay Yadav)
