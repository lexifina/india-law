# Bombay High Court, APPP/694/2007, 2008-06-03

( 1 )
 IN THE HIGH COURT OF JUDICATURE AT BOMBAY
 CRIMINAL APPELLATE JURISDICTION
 CRIMINAL APPLICATION NO.694 OF 2007
 IN
 CRIMINAL APPLICATION NO.610 OF 2007
 IN
 BAIL APPLICATION NO.3105 OF 2004
 Smt.Sayalee Sanjeev Joshi .. Applicant.
 Versus
 The State of Maharashtra .. Respondent.
 Mr.Rahul Dhumal i/b.Mr.Dinesh Tiwari for the
 applicant.
 Mr.K.V.Saste, A.P.P. for the respondent.
 CORAM : R.Y. GANOO, J.
 DATED : 3rd June, 2008.
 P.C.:
 1. Mr.Rahul Dhumal for the applicant and
 Mr.Saste, learned A.P.P. for the State.
 2. Criminal Application No.610 of 2007 filed by
 the applicant so as to seek modification of the bail
 order came to be dismissed for want of prosecution on
 27.11.2007. Present Criminal Application No.694 of
 2007 is filed to have that order set aside and have
 that application No.610 of 2007 restored to the file
 of this Court.
 3. I have heard the learned Advocates on both the
 sides. Paragraph No.2 of the application indicates as
 to how the learned Advocate for the applicant could
 not appear in the matter and as to how the applicant

 ( 2 )
 also could not appear in the matter on the relevant
 date. Considering the text of the application, I am
 inclined to take a liberal view and grant this
 application. Accordingly, this application is
 granted. Application No.610 of 2007 is restored to
 the file of this Court.
 4. Application for restoration stands disposed
 off accordingly.
 (R.Y. GANOO, J.)
