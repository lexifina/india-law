# Madras High Court, A/253/2021, 2021-06-15

A.No.253 of 2021
N.SATHISH KUMAR, J.
This application has been filed
for a direction to the respondent to
furnish security to the tune of
Rs.6,85,179.11 within the time fixed
by this Court, failing which the Order
of attachment of the properties more
fully described in the Judge's
summons.
2. This Court by an Order
dated 17.03.2021 directed the
respondent to furnish security for the
suit claim.
3. Despite the Order of this
Court directing the respondent to
furnish security has been
communicated to the respondent, the
respondent has not furnished security
and none appeared for the respondent.
4. In view of the same, there
shall be an Order of attachment of the
immovable properties described in the
schedule and this application is
closed. The registry is directed to
communicate this Order to the
concerned Registrar.
