% 07.07.2026
1. The present Writ Petition has been filed against an order passed
by the Central Administrative Tribunal [‘CAT’], condoning the delay
of 63 days in filing original application.
2. Learned counsel representing the Petitioners submits that delay
was not 63 days, but more than four years.
3. If that be so, the Petitioners may, if so advised, file an
application before the CAT in this regard, which will be considered
and decided expeditiously.
4. With these observations, the present Writ Petition, along with
the pending application, is disposed of.
ANIL KSHETARPAL, J.
