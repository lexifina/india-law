# High Court of Andhra Pradesh, CRLP/6458/2019, 2019-11-13

HONOURABLE SRI JUSTICE D.V.S.S. SOMAYAJULU
CRIMINAL PETITION No.6458 of 2019
ORDER:

This Criminal Petition is filed by the petitioner under Section
482 of the Code of Criminal Procedure to direct the Special Mobile
Court, Guntur, to number the CFR No.9705 of 2015, on the file of
the Special Mobile Court, Guntur.
Heard Smt. Marella Radha, learned counsel for the petitioner
and the learned Public Prosecutor appearing for the respondent-State.
The protest petition which has been filed in the year 2015 is
still not numbered because the respondent/police has not filed the
original closure report/final report. Only an attested copy was filed.
The Judicial Magistrate of First Class, Special Magistrate Court,
Guntur also addressed a letter to the Station House Officer,
Nallapadu Police Station to file the original report on or before
23.02.2017 but the police did not show any response.
In that view of the matter, this Court is of the opinion that it is
a fit case that this Court should entertain this application and issue
a direction to the Station House Officer, Nallapadu Police Station,
Guntur District to file original final report in the above Crime No.445
of 2013, within three weeks from the date of receipt of copy of this
order. Learned Public Prosecutor is also directed to issue
appropriate instructions to the police to ensure that these type of
issues do not recur again.
With these observations, this criminal petition is disposed of.

 2
As a sequel, miscellaneous petitions, if any, pending in this
criminal petition shall stand closed.
