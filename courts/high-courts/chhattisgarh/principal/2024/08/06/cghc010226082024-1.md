1. This contempt petition has been filed against non-compliance of the stay
order dated 03.06.2024 passed by this Court in WPS No. 2882 of 2024
(Nimesh Koushik Vs. State of Chhattisgarh & others) wherein following
order has been passed:-
“At the outset, learned counsel for petitioner would submit that for
the similar cause an enquiry has already been conducted and the
order has been passed by the Collector, Korba. So at this juncture,
this Court finds it appropriate that the petitioner file its reply in the
show-cause notice within 14 days of this order to the competent
authority and thereafter the concerned authority has to pass order(s)
within an outer limit of 45 days considering all the aspects and if any
adverse order is passed till such date, no action is to be taken
against the petitioner until an order is passed by this Court. If any
adverse order is passed, the State will be at liberty to file an
appropriate application for vacating the order of this Court.”
2. Learned counsel for the applicant would submit that after stay order
passed by this Court on 03.06.2024, the applicant has been suspended
