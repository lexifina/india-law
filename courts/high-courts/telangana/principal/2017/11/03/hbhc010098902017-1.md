# High Court for the State of Telangana, CC/1613/2017, 2017-11-03

HONíBLE SRI JUSTICE A.RAJASHEKER REDDY
CC No.1613 of 2017
ORDER:
This contempt case is filed alleging violation of the
order dated 27-04-2017 passed in WP No.15197 of 2017
by this Court.
2. After issuance of notices, respondent filed counter
affidavit stating that the order of this Court has been
complied with and appropriate orders are passed vide
endorsement dated 7-7-2016.
3. In the light of the order dated 7-7-2016 passed by the
respondent, no further steps need to be taken in this
contempt case. The contempt case is accordingly closed.
However, if the petitioner is aggrieved by the order dated
7-7-2016, it is open for the petitioner to challenge the
same in separate proceedings, if so advised. Miscellaneous
petitions, if any pending shall also stand closed. No order
as to costs.

 _____________________________
 A.RAJASHEKER REDDY, J
