Rajasthan Housing Board & Anr.
Date of Order :: 11th September 2008.
HON'BLE MR. JUSTICE DINESH MAHESHWARI
Mr. Narpat Singh Rajpurohit for

BY THE COURT:
The petitioner has moved an application (IA
No.10782/2008) seeking permission to withdraw this writ
petition with liberty to file afresh, if occasion so arise with
reference to the communication dated 17.07.2008 as received
from the respondent Housing Board. The application is not
opposed and for the reasons stated, the same is allowed.
The petitioner is permitted to withdraw; and this writ
petition is dismissed as withdrawn with liberty as prayed.
(DINESH MAHESHWARI), J.
