O R D E R
This Criminal Original petition has been filed to transfer
the investigation in Crime No.435 of 2019 from the file of the
second respondent to the file of the third respondent and
consequently direct the third respondent to conduct proper
investigation in an expeditious manner.
2. Though the petitioner seeks transfer of investigation, at
the time of arguments, the learned Counsel appearing for the
petitioner would submit that it would be suffice if a direction is
given to the second respondent police to complete the investigation
https://hcservices.ecourts.gov.in/hcservices/

2
in Cr.No. 435 of 2019 and file a final report within a stipulated
time as fixed by this Court.
3. In view of the submission made by the learned Counsel
appearing for the petitioner, this Court directs the second
respondent police to complete the investigation in Crime No. 435 of
2019 pending on his file and file a final report as expeditiously as
possible.
4. With the above direction, this Criminal Original Petition
is disposed of.
