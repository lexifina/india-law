ORDER
24.02.2026
Heard Mr. B. Taipodia, learned counsel for the petitioner. Also heard Ms. L.
Hage, learned Additional Public Prosecutor for the State respondent.
2. Ms. L. Hage, learned Additional Public Prosecutor, submits that the case has
already been charge-sheeted, vide C.S. No. 05/2026 dated 06.02.2026 and
submitted on 17.02.2026; thus, she submits that a scanned copy of the Trial
Court Record would be necessary.
3. At this stage, Mr. Taipodia, learned counsel for the petitioner, submits that
since the case has already been charge-sheeted, he seeks to withdraw this
petition and prays for liberty to file a fresh bail application before the learned
Trial Court.
4. The prayer is allowed.
5. In view of the above, the petition stands dismissed as withdrawn, with
liberty granted to the petitioner to file a fresh bail application before the learned
Trial Court, if so advised.
