ORAL ORDER
Learned advocate Ms. Nisha Parikh for the petitioners seeks
permission to withdraw the petition stating further that the petitioners
would file Civil Revision Application under section 115 of the Code of
Civil Procedure, 1908, to challenge the very order which is impugned in
this petitioner.
The permission, as prayed for, is granted. The petition stands
disposed of accordingly.
It will be open for the petitioners to apply to the Registry for
getting back the certified copy of the order below Exhibit 27 to enable the
petitioners to produce the same in the Revision Application which may be
filed. If such an application is made, the Registry shall retain the xerox
copy of the order in the present compilation while returning the original
copy.
(N.V.ANJARIA, J)
