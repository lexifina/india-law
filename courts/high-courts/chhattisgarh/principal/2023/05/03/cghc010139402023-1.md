Order on Board
03.05.2023
1. After arguing for some time, learned counsel for the petitioner seeks
permission to withdraw this petition with liberty to file representation
against his transfer order before the concerned authority.
2. The same prayer is not opposed by State counsel.
3. In view of the above, the petitioner is permitted to withdraw this
petition, however, liberty is reserved to petitioner to file representation
before the concerned authority which shall be decided within a
reasonable period of time.
4. With this observation, the instant petition is disposed of.
5. Consequently, all pending applications stand disposed of.
