02 /01.10.2012. This application is directed against the order passed in C.P. Case
No.1461 of 2009, whereby, the prayer of the petitioner for discharge was
rejected. That order is revisable still this application has been filed under
Section 482 of the Code of Criminal Procedure, against the order whereby,
the prayer for discharge has been rejected and hence, this application is
not maintainable.
Accordingly, this application stands dismissed, as not
maintainable.
