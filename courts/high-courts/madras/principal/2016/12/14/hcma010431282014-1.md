ORDER
The first defendant in a suit for partition, has filed this revision
challenging the amendment of the plaint being allowed by the trial
Court.
2. The amendment is with respect to mortgage value of the
property, which was omitted to be mentioned earlier. Therefore, the
amendment is sought for, which is now allowed.
3. The objection of the revision petitioner is that the learned
trial Judge has come to the conclusion that the market value and the
guideline value of the property need not be same, which is erroneous.
The learned counsel for the petitioner would state that he would be
satisfied, if the issue with respect to valuation of the property, is
framed for trial.
4. Accordingly, the learned Subordinate Judge, Tirupattur,
Vellore District is directed to frame the following issue:
"Whether the suit properties are properly valued?"

3
5. After framing the issue, the parties are directed to go for
trial. Hence, the amendment is confirmed and only an additional issue
is framed as above, which can be agitated at the time of trial.
6. With the above direction, this Civil Revision Petition is
disposed of. No costs. Consequently, connected miscellaneous
petition is closed.
