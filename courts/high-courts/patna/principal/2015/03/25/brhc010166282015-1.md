ORAL ORDER
02/ 25-03-2015 The present application has been filed for
modification of order dated 12.03.2015 passed in Cr. Misc. No.
47079 of 2014 for adding alias name of the petitioner.
Initially the bail application was filed in the
name of Md. Mumtaz Ansari and now the petitioner wants to add
alias name as Md. Mumtaz Ansari @ Md. Mumtaz @ Shahin. In
the complaint petition petitioner made accused with the alias
name.
Considering the above facts, the order dated
12.03.2015 passed in Cr. Misc. No. 47079 of 2014 is modified to
add the alias name of the petitioner.
The petitioner is permitted to make addition
in the name of the petitioner in the main petition also.
Accordingly, this modification application is
disposed of.
