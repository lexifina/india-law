RAM CHAND GUPTA, J.(Oral)
The present revision petition has been filed against order dated
02.08.2011 passed by learned Judicial Magistrate First Class, Amritsar
dismissing complaint filed by the present petitioner without approaching
court of Sessions.
Learned counsel for the petitioner requests for withdrawal of
this petition on the plea that he would file the same before court of Sessions.
Dismissed as withdrawn with the aforesaid liberty.
However, if any application for condonation of delay is filed, the
period spent by the petitioner in pursuing this petition in this Court be taken
into consideration.
( RAM CHAND GUPTA )
