# High Court of Madhya Pradesh, WP/3422/2011, 2017-01-02

WP-3422-2011
(PUSHPA DEVI RATHI Vs ZONAL MANAGER STATE BANK OF INDIA AND ORS.)
02-01-2017
Parties through counsel.
Heard on IA No.7077/2016, an application for withdrawal
of this writ petition.
For the reasons assigned in the application, the same is
allowed. This writ petition is dismissed as withdrawn with
the permission to the petitioner to revive the prayer, in
case occasion so arises.
With the aforesaid liberty, petition stands dismissed as
withdrawn.
(P.K. JAISWAL)
JUDGE
(VIRENDER SINGH)
