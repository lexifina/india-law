# High Court of Madhya Pradesh, MCC/2912/2015, 2016-01-08

MCC-2912-2015
(JITENDRA SINGH Vs THE STATE OF MADHYA PRADESH)
08-01-2016
Shri Kamlesh Mishra, learned counsel for the applicant.
Shri Atul Choudhary, learned counsel for the respondents.
This application has been filed for restoration of S.A. No.
432/2007, which was dismissed for want of prosecution
vide order dated 23.4.2015. There being some delay in
filing the application for restoration, I.A. No. 12850/2015
has been filed seeking condonation of delay. Both these
applications are supported by affidavit of Jitendra Singh.
There is no reason to disbelieve the same. Finding the
same to be bonafide, both the applications are allowed.
Condoning the delay in filing the application, restoration
application itself is allowed.
S.A. No. 432/2007 is restored to its original number.
Application stands allowed and disposed of.
(MISS VANDANA KASREKAR)
JUDGE
