# High Court of Tripura, IA./100/2017, 2017-01-27

Case No :IA. 0000100/2017
Party Name : UNION OF INDIA & ANR Vs BISWAJIT SAHA
THE HONBLE THE CHIEF JUSTICE T. VAIPHEI THE HONBLE MR. JUSTICE S.TALAPATRA
27.01.2017.

Heard Mr. A. K. Deb, the learned counsel for the applicant.
The application is for amending the application for condonation of delay relating to the number of
days delay. Instead of 370 days, in the application the number of days delay was stated to be 350
days. This is sought to be amended by this application.
Application is allowed.
The applicant will file the recast application for condonation of delay within seven days.
Application is disposed of.
