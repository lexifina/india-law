# Calcutta High Court, CO/1559/2011, 2023-08-24

24.8.2023
ct. 236
sk,sl.7
 C.O. 1559 of 2011
 Sekhar Mukherjee
 -vs-
 Rashbehari Banerjee
 Ms. Manali Biswas
 …for the petitioner.
 Heard Ms. Biswas, learned counsel for the
petitioner.
 While passing the order of 17th August, 2023 the
application being CAN 7726 of 2019 inadvertently was
not taken into consideration. The pre-emptor during
pendency of this revisional application on 17th April,
2019 transferred the property in question to one Pampa
Mishra and Somnath Ghatak. Thus he lost his right to
prempt the transfer earlier done by his co-sharer. This
subsequent event is sufficient to set aside the order
impugned. But inadvertently the revisional application
was disposed of being infructuous without taking note of
this subsequent development.
 This is an error apparent on the face of record and
I am inclined to set it right by holding that with the
subsequent development, the order impugned cannot be
allowed to remain in force and should be set aside.
Consequently, this revisinal application is allowed
however without cost. The impugned judgment dated

 2
23.3.2011 passed in Misc. Appeal No. 17 of 2010 is set
aside. The order dated 17th August, 2023 is modified.
 (Siddhartha Roy Chowdhury, J)
