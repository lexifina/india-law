1. This Interim Application is filed praying for restoration of the Petition
which came to be dismissed for want of prosecution by an Order dated 14th
December 2023, passed by the Co-ordinate Bench of this Court. There is a gross
delay in filing this Application. There are no averments whatsoever to explain the
delay in filing this Application for restoration.
2. Considering this position learned Counsel for the Petitioner seeks leave to
withdraw this Application with liberty to file proper application explaining the
delay.
3. Application allowed to be withdrawn. All contentions of all the parties are
kept open.
