# Allahabad High Court, TACR/357/2019, 2019-08-26

Court No. - 79
Case :- TRANSFER APPLICATION (CRIMINAL) No. - 357
of 2019
Applicant :- Jagdish Prasad @ Nanhey
Opposite Party :- State Of U.P. And Another
Counsel for Applicant :- Kailash Prasad Pandey,Rajesh
Pandey
Counsel for Opposite Party :- G.A.,Akhilesh Kumar Mishra
Hon'ble Ram Krishna Gautam,J.
Learned counsel for applicant, Sri Sabhajeet Yadav, learned
counsel for opposite party no. 2 and learned A.G.A. for State
are present.
This transfer application has been filed without preferring a
transfer application before Court of District and Sessions Judge,
Pilibhit, whereas request has been made for transferring this
criminal proceeding intra-district, for which firstly transfer
application is to be moved before District and Sessions Judge,
Pilibhit. Hence, this application is being not pressed.
The transfer application is accordingly dismissed as not pressed
with liberty to file transfer application before District and
Sessions Judge, Pilibhit.
Order Date :- 26.8.2019
