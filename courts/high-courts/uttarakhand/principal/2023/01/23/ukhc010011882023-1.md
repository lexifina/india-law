# High Court of Uttarakhand, C482/101/2023, 2023-01-23

C-482 No.101 of 2023
Hon’ble Ravindra Maithani, J.
Mr. M.K. Ray, Advocate for the
petitioner.
Mr. Lalit Miglani, A.G.A. with Ms.
Sonika Khuble, Brief Holder for the State.
Mr. D.S. Mehta, Advocate for the
private respondent.
Learned counsel for the petitioner
appeared through video conferencing.
As the matter is taken up, it is
revealed that, in fact, earlier, the
petitioner had filed an application under
Section 311 of the Code of Criminal
Procedure, 1973 (“the Code”), which was
rejected. Thereafter, another application
under Section 311 of the Code was
subsequently rejected by the impugned
order dated 05.9.2022. This order dated
05.09.2022 was unsuccessfully
challenged in the revision, which was
dismissed on 11.01.2023. It is also
impugned.
At the time of hearing, learned
counsel for the private respondent would
submit that, in fact, the earlier
application, filed by the petitioner was
rejected on 15.01.2020, which was
challenged on 06.01.2022 in the revisional
court. It is submitted on behalf of the
private respondents that, in fact, the
revision filed by the petitioner against the
earlier order of rejection application under
Section 311 of the Code has been delayed
and is still pending.
Learned counsel for the petitioner
would submit that he would like to
withdraw this petition with the direction
to the court below to decide the revision,

preferred by the petitioner, as
expeditiously as possible.
Undoubtedly, a revision, or any other
proceeding, for that matter, are to be
decided expeditiously. This Court has no
detail as to when did the petitioner file the
revision, which is still pending. Therefore,
no direction, as such, is required.
Since the petitioner seeks permission
to withdraw this petition, it stands
dismissed as withdrawn.
Urgency Application IA No.1 of 2023
stands disposed of, accordingly.
 (Ravindra Maithani J.)
 Vacation Judge
 23.01.2023
