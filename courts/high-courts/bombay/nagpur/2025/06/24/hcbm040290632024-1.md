Heard.
2. Present application seeking condonation of
delay in filing this application to set aside the
abatement. Respondent No.1, in the aforesaid appeal,
has expired on 18.03.2024 and after his death, his
wife namely Pruthwika Shravan Ade also expired. The
learned Advocate for respondent No.1 filed a pursis
dated 25.07.2024, which the learned Counsel for the
Applicant received later on. In the meanwhile, the
Appeal got abated. Therefore, and considering the
submissions by the learned Advocate for applicant, the
application is allowed.
3. The 90 days delay in filing this application for
setting aside abatement and to set aside the
abatement, is allowed.
4. Abatement is set aside.
5. The application stands disposed of,
accordingly.
