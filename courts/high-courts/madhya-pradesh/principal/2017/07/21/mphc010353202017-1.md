# High Court of Madhya Pradesh, MCRC/12081/2017, 2017-07-21

MCRC-12081-2017
(PIYUSH PATHAK Vs THE STATE OF MADHYA PRADESH)
21-07-2017
Shri P.S. Gaharwar, learned counsel for the applicant.
Shri Vivek Lakhera, learned Panel Lawyer for respondent-State.
This application has been filed for modification of order dated
14.07.2017, passed in M.Cr.C. No.11361/2017.
Learned counsel for the applicant submits that in the order dated
14.07.2017, passed in M.Cr.C. No.11361/2017, Crime number is
mentioned as Crime No.268/2017 while the correct one is Crime
No.211/2017.
Considering the aforesaid, this application is hereby allowed.
It is ordered that in the order dated 14.07.2017, passed in
M.Cr.C. No.11361/2017, "Crime No.268/2017" be read as "Crime
No.211/2017".
In view of above, M.Cr.C. stands disposed of.
(H.P. SINGH)
JUDGE
