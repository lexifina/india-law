1 This is an application for restoration of Criminal
Application bearing No.209 of 2017 by condoning the delay of
four days.
2 Heard both sides.
Gaikwad RD 1/2

(23)APPPNo.6622018
3 The learned Advocate appearing for the respondent
No.1 vehemently opposed the application by contending that as
none appeared for the applicant when the application was called
out for hearing, the same was rightly rejected.
4 It is seen that on 3rd May 2018, the subject Criminal
Application bearing No.209 of 2017 came to be rejected for want
of prosecution. The duly sworn application shows that on that
day, the matter was mentioned at 3.00 p.m. itself for restoration.
It is thus seen that the applicant was vigilant in prosecuting the
application. The delay caused in filing the application is also
explained. Therefore, the Order :
ORDER
(i) The application is allowed.
(ii) The delay in filing the application for restoration is
condoned.
(iii) The Order dated 3rd May 2018 passed by this Court in
Criminal Application No.209 of 2017 is recalled and the
said application is restored to the file of this Court.
(iv) The instant application is disposed of accordingly.
