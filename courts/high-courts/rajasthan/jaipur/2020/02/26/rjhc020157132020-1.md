Order
26/02/2020
1. Petitioner has preferred this Criminal Miscellaneous Petition
seeking fair investigation in F.I.R. No.154/2016.
2. Learned Public Prosecutor has submitted a report to the
effect that Police has filed negative final report. Report submitted
by learned Public Prosecutor is taken on record.
3. In view of the same, Criminal Miscellaneous Petition seeking
fair investigation is disposed.
4. However, petitioner would be free to file protest petition, if so
advised.
