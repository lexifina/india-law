# High Court of Madhya Pradesh, MCC/911/2016, 2017-07-21

28
MCC No.911/2016
21.07.2017
None for the petitioner(s).
Shri Sunil Jain, learned AAG with Shri Milind
Phadke, learned Govt. Advocate for the
respondent/State.
Perused the report dated 28/12/2016.
This application under order 44 Rule 1 of CPC is
for permission to file present appeal as an indigent
person in a matter arising out of claim of compensation
for acquisition of the land of the petitioner(s).
This Court in M.C.C. No.962/2016 has allowed the
similar application in respect of another land-owner
whose land was acquired for the same project. For the
reasons mentioned therein, we allow the application
and permit the petitioner(s) to file the present appeal as
an indigent person.
Office to register regular First Appeal.
(P.K. Jaiswal) (Ved Prakash Sharma)
