# High Court of Madhya Pradesh, CONC/1843/2016, 2017-09-08

CONC-1843-2016
(RAJKUMARI PATEL Vs THE STATE OF MADHYA PRADESH)
08-09-2017
None for the petitioner.
Shri Bramha Datt Singh, learned counsel for respondents.
As the order passed in Writ Petition No. 10866/2016 has
been complied with as is evident from order dated 28.9.2016,
brought on record vide reply filed on 30.11.2016, no further
action is warranted.
Consequently proceedings are dropped. Rule NISI
discharged. The petitioner if has any grievance, is set at liberty to
file appropriate proceedings against the same before appropriate
forum.
C.c. as per rules.
