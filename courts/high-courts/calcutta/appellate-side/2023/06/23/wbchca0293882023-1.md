# Calcutta High Court, CRR/2250/2023, 2023-06-23

June 23, 2023
AD –21
 Ct. 34
 SG
 CRR 2250 of 2023
 Satya Ranjan Sil @ Sona Ali
 -versus-
 The State of West Bengal and another
Mr. Anjan Ray
Mr. Subhajit Chowdhury
 … for the petitioner
Mr. Madhusudan Sur
Mr. Dipankar Paramanick
 … for the State

Learned advocate for the petitioner orally submits
that he wants to visit Bangladesh for a limited time and
purpose. However, the application before the learned
magistrate was not for visiting a foreign country for a
limited purpose and it was for return of passport.
The report submitted by State be kept with the record.
In view of prayer advanced before this Court, I find
that such prayer was not advanced before the Chief
Judicial Magistrate, Hooghly who is in seisin of the matter.
So far as the order dated 20.05.2023 regarding return of
passport is rejected. The reason so assigned in the said
order is justified.
 However, if the petitioner approaches the court with
a prayer to travel abroad for a limited period on specific

conditions, learned magistrate would consider such prayer
in accordance with law.
With the aforesaid observations, CRR 2250 of 2023 is
disposed of.
Pending application, if any, is consequently disposed
of.
 All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
 Urgent certified copy of this order, if applied for, be
supplied to the parties upon compliance of such requisite
formalities.
 ( Tirthankar Ghosh, J. )
