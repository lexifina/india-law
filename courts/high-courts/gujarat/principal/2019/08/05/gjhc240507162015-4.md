ORAL ORDER
Learned Additional Public Prosecutor Ms.Bhatt has tendered a
report of the Investigating Officer dated 05.08.2019. She has
submitted that 'B' Summary Report is already filed before the
concerned Court on 21.12.2016, however, the same is pending and
the next date is reported to be on 07.08.2019.
It appears that the notice to the applicant has not yet received
back.
In view of the report dated 05.08.2019, the prayers made in
the application would not survive since 'B' Summary Report is
already filed before the concerned Court. However, if any grievance
of the complainant remains, he can file a protest application before
the concerned Court where 'B' Summary Report is filed. The writ
petition stands disposed in the aforesaid terms.
(A. S. SUPEHIA, J)
