# Calcutta High Court, CRR/3059/2012, 2021-11-08

Sr. 39
 08-11-2021
 Subha.
 Court no. 34
 IN THE HIGH COURT AT CALCUTTA
 CRIMINAL REVISIONAL JURISDICTION
 APPELLATE SIDE
 ( Via Video Conference )
 CRR 3059 of 2012
 In the matter of : Biswajit Das ….petitioner.
In Re : An application under Section 482 of the Code of
Criminal Procedure.
 Mr. Arijit Ganguly
 Ms. Manisha Sharma
 …..for the petitioner.
 As none appears on behalf of the petitioner, who has
been enjoying the interim order until further orders, I am of
the view that no purpose would be served if the petitioner is
not interested in pursuing the litigation before this court.
 Accordingly, the present revisional application being
CRR 3059 of 2012 is dismissed for default.
 All pending applications, if any, in connection with
revisional application, are consequently disposed of.
 Interim order, if any, is hereby vacated.
 The jurisdictional is directed to proceed with the trial
of the case.
 All parties are to act on the server copy of this order
duly downloaded from the official website of this court.
 ( Tirthankar Ghosh, J. )
