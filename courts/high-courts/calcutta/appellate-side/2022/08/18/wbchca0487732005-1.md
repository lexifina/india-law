# Calcutta High Court, CRR/3590/2005, 2022-08-18

18.08.2022 IN THE HIGH COURT AT CALCUTTA
 Item No.68 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
C.R.R. 3590 of 2005

 Sanarul Islam
 versus
 The State of West Bengal & Anr.
In Re: An Application under Section 482 of the Code of
Criminal Procedure.
Mr. Arijit Ganguly,
Ms. Debjani Sahu … For the State.
Mr. Aniket Mitra … For the WBSEDCL.
Report dated 18.08.2022 submitted by Mr. Arijit
Ganguly, learned advocate appearing for the State be kept on
record.
The said report reflects that the accused person viz.
Sanarul Islam was acquitted of the charges by the learned
trial court on 26.09.2012.
Mr. Aniket Mitra, learned advocate appears for the
WBSEDCL.
In view of the report so submitted, the revisional
application has become infructuous.
Accordingly, the revisional application being CRR 3590
of 2005 is dismissed as infructuous.
Interim order, if any, is hereby vacated.
All pending connected applications, if any, are
consequently disposed of.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.

Urgent photostat certified copy of this order, if applied

requisite formalities.
 (Tirthankar Ghosh, J.)
