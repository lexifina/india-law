ORDER
Per P. Diwaker, J
14/06/2016
1. Learned counsel for the applicants seeks permission to withdraw this
MCC with liberty to file a duly constituted MCC narrating all the facts therein.
She further submits that Registry be directed to return the certified copy of order
dated 31.3.2016 passed in MCC No. 206/2016.
2. Learned counsel for the State has no objection to the proposition as put
forth by learned counsel for the applicants.
3. Permission granted.
4. Accordingly, the MCC is dismissed as withdrawn with the aforesaid liberty.
5. Registry is directed to return the certified copy of order dated 31.3.2016 to
the counsel for the applicants after retaining the xerox copy of the same.
