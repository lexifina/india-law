# Allahabad High Court, WRIC/4212/2018, 2018-02-01

Court No. - 5
Case :- WRIT - C No. - 4212 of 2018
Petitioner :- Vedram
Respondent :- State Of U.P. And 4ors
Counsel for Petitioner :- Santosh Kumar Yadav
Counsel for Respondent :- C.S.C.
Hon'ble Pankaj Naqvi,J.
Heard learned counsel for the parties.
This is a second writ petition for the same cause of action,
as the petitioner already has an interim order dated
17.5.2017 in Writ-C No. 17877 of 2017.
Grievance of the petitioner now is that despite the interim
order dated 17.5.2017, the respondents are not letting
him catch fish.
Assuming it to be so, remedy lies elsewhere. The second
writ petition for the same cause of action is not
maintainable.
The writ petition is dismissed as not maintainable.
Order Date :- 1.2.2018
