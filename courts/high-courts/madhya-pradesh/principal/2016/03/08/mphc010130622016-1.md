# High Court of Madhya Pradesh, MCRC/4317/2016, 2016-03-08

MCRC-4317-2016
(RAJESH TEMBHRE Vs THE STATE OF MADHYA PRADESH)
08-03-2016
Shri Rahul Sharma, learned counsel for the applicant.
Shri P.K. Chourasiya, learned PL for respondent -State.
This application has been filed for correction of the
typographical error in the order dated 29.02.2016 passed in
M.Cr.C. No. 1980 of 2016.
It is contended that in the aforesaid order the name of the
applicant has been mentioned as Gandhu Singh (G.S. ) Dhurve.
However, the correct name of the applicant is Rajesh Tembhre.
After perusal of the record the contention of the applicant's
counsel is found correct, hence the application is allowed where
in the order dated 29.02.2016 passed in M.Cr.C. No. 1980 of
2016, it has been mentioned "applicant Gandhu Singh (G.S.)
Dhurve be released on bail" be read as "applicant Rajesh
Tembhre be released on bail"
The application stands disposed of.
C c as per rules.
(S.K. GANGELE)
