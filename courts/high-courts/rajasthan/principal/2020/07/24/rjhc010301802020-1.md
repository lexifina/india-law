Order
24/07/2020
The matter comes upon an application seeking correction of
the name of the petitioner No.3 Sukhraj in the order dated
20/07/2020.
Learned counsel for the petitioner submits that inadvertently
the name of the petitioner No.3 Sukhram has been shown as
“Sukhraj” in the cause title of the bail application, whereas it
should have been “Sukhram”
Accordingly, the application is allowed. The name of the
petitioner No.3 as reflected in the order dated 20/07/2020 passed
by this Court in S.B. Criminal Misc. Bail application No.7001/2020
be now read as “Sukhram” instead of “Sukhraj”,
(VINIT KUMAR MATHUR),J
