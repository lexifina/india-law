HON'BLE MR. JUSTICE SATISH KUMAR SHARMA
Order
18/09/2021
Learned counsel for the petitioner has filed this application
for clarification of order dated 3.9.2021, whereby, the petition was
dismissed with liberty to file appropriate application in the
proceedings to be filed before the competent Court.
Learned counsel for the petitioner submits that the petitioner
intends to file an appeal against the impugned order therefore,
above order should be clarified accordingly.
In view of order passed on 3.9.2021, the petitioner is free to
file an appeal before the competent Court to be dealt with in
accordance with law.
Accordingly, the Misc. application stands disposed of.
