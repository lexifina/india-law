written statement before the trial Court, on any such date,

2. Record reveals that petitioners had filed an
application under Order 7 Rule 11 of the Code of Civil
Procedure and perhaps it is for this reason, written
statement never came to be filed, pursuant to various
orders passed by the trial Court. Also at some stage,
petitioners were proceeded ex-parte, which order,
subsequently came to be set aside. No doubt, opportunities
were afforded to the petitioners to file written statement
and failure, resulted into their defence being struck-off, but
however, considering the overall facts and circumstances,
more so, for the reason that petitioners’ application under
Order 7 Rule 11 CPC came to be filed and orders passed
therein came to be assailed before this Court, impugned
order dated 08.04.2015 (Annexure P-5), passed by Civil
Judge (Junior Division), Dalhousie, District Chamba, H.P., in
Civil Suit No.180 of 2013, titled as Kiran Kapoor Versus
Ashok Lal, is quashed and set aside with the following
directions:-
(i) Parties shall appear before the trial Court on
16.05.2017, on which date petitioners shall
positively file their written statement;

 3
(ii) Failure to do so would only amount to their
defence being struck off;
(iii) Trial is expedited;
(iv) Parties undertake to fully cooperate; and
(v) Save and except official witnesses, parties
undertake to produce their respective witnesses,
at their own costs and responsibility.
3. With the aforesaid observations, present petition
stands disposed of, so also pending application(s), if any.
