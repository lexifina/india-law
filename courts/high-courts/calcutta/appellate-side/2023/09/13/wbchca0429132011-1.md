# Calcutta High Court, CRR/3414/2011, 2023-09-13

13.09.2023
 Sl.No. 111
 Ct. 33
 Amalranjan

CRR 3414 of 2011
Re. Sonali Bibi
None appears for the parties.
Perused the contentions of the instant revisional
application along with the order impugned which is reasoned
and the denial of maintenance allowance has been vividly
described.
This court is not inclined to interfere with the
impugned order and accordingly, the instant revisional
application is dismissed.
Department is directed to communicate this order to
the learned trial court immediately for information.
( Ananya Bandyopadhyay,J. )
