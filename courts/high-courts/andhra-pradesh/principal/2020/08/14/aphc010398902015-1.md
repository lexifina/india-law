ORAL ORDER
Dt: 14.08.2020
 This Criminal Petition has been filed seeking to quash or set
aside the proceedings in C.C.No.611 of 2014 on the file of the
learned V Additional Judicial First Class Magistrate, Kakinada, East
Godavari District.
As per the information available on Case Information
System (CIS), the aforesaid case has already been settled before
Lok Adalat on 26.04.2016. Therefore, this petition has now
rendered infructuous.
Accordingly, this Criminal Petition is dismissed as
infructuous. As a sequel, all the pending miscellaneous
applications shall stand closed.
