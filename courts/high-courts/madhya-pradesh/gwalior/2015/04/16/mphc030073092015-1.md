# High Court of Madhya Pradesh, MCRC/3238/2015, 2015-04-16

MCRC.3238/2015. 1
16.04.2015.
Shri V.S.Bhadoria learned counsel for the petitioner.
Shri J.M.Sahni, learned panel lawyer for the
respondent/state.
Heard finally.
This application has been filed seeking modification in the
order dated 6.4.2015 passed by this Court in M.Cr.C.No.2472 of
2015.
It is submitted that due to some mistake name of the
petitioner has been wrongly mentioned as “Raghvendra Singh
Tomar alias Ramu S/o Shri Rambabu Yadav” in the order dated
6.4.2015 and in the memo of application whereas, the correct
name of the petitioner is “Raghvenda Singh alias Ramu S/o Shri
Shyambabu Yadav”.
Keeping in view the aforesaid, this application is allowed.
Wherein in the order dated 6.4.2015 passed in M.Cr.C.No.2472
of 2015 and in the memo of application, name of the petitioner
mentioned as “Raghvendra Singh Tomar alias Ramu S/o Shri
Rambabu Yadav”, is hereby corrected and it shall be read as
“Raghvenda Singh alias Ramu S/o Shri Shyambabu Yadav”.
The order dated 6.4.2015 passed in M.Cr.C.No.2472 of
2015 shall be read conjointly with this order along with the
aforesaid modification.
Certified copy as per rules.
 (SUBHASH KAKADE)
 JUDGE
