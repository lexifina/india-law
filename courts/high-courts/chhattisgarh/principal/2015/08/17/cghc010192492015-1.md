Order On Board
17/08/2015

Heard on I.A. No. 01, application for condonation of delay in filing the
M.C.C.
This is not opposed by counsel for the State.
For the reasons mentioned in the application the same is allowed. The
delay in filing the M.C.C. is condoned.
Also heard on M.C.C. No.673/2015 which is an application for
restoration of W.P.(C) No. 224/2015 which was dismissed by this Court vide
order dated 27.03.2015 for want of prosecution.
This is also not opposed by counsel for the State.
Accordingly, the application is allowed and W.P.(C) No. 224/2015 is
restored to its original number.
