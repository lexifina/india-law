CORAM : V.M. DESHPANDE, J.
DATED : SEPTEMBER 8, 2017
This is an application for speaking to the
minutes.
According to the learned counsel for the
applicant, this Court has passed an order on 21.08.2017
in Criminal Application No.792/2017. In the said order,
name of the applicant is mentioned as “Pundlik
Balkrushna Fiske.” He submits that though name of the
applicant is “Pundlik Amrutrao Fiske”, in the application
itself he has wrongly mentioned the name as Pundlik
Balkrushan Fiske. He prays for making necessary
corrections in the order.
I have perused the charge-sheet. In the
charge-sheet, name of the applicant is mentioned as
“Pundlik Amrutrao Fiske.” The mistake which had
occurred on the part of the learned counsel for the
applicant appears to be bona fide and unintentional.
Hence, following order is passed.

2 appp1475.17.odt
ORDER
(i) Criminal Application No.1475/2017 is
allowed.
(ii) In the order dated 21.08.2107 in Criminal
Application (BA) No.792/2017, the name of the accused
be corrected as “Pundlik Amrutrao Fiske” instead of
Pundlik Balkrushna Fiske.
Necessary corrections be carried out
accordingly.
