# High Court of Madhya Pradesh, WP/7632/2015, 2016-12-07

WP-7632-2015
(B.L. AHIRWAR Vs THE M.P. RAJYA SAHKARI ANUSUCHIT JATI VITT AVAM VIKAS NIGAM)
07-12-2016
Shri Rajendra Mishra, learned counsel for the petitioner.
Shri Pushpendra Yadav, learned Government Advocate for
the State.
Heard.
Learned counsel for the parties submits that transfer order
dated 14.5.2015 was stayed by this court on 21.5.2015. This
interim order is still in operation. Thus, the administrative
exigency which was prevailing at the time of issuance of transfer
order must be over by now. Hence, said transfer order may be set
aside by reserving liberty to the employer to issue a fresh order if
administrative exigency so required.
In view of aforesaid consensus arrived at, the impugned
transfer order dated 14.5.2015 is set aside. Liberty as prayed for
is given to the respondents.
Petition is disposed of.
(SUJOY PAUL)
