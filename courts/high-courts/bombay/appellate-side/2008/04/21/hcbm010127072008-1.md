# Bombay High Court, APPP/229/2008, 2008-04-21

IN THE HIGH COURT OF JUDICATURE AT BOMBAY
 CRIMINAL APPELLATE JURISDICTION
 CRIMINAL APPLICATION NO.229 OF 2008
 IN
 CRIMINAL APPLICATION NO.4213 OF 2007
 Rajbir Raghuvir Chauhan .. Applicant.
 Versus
 The State of Maharashtra .. Respondent.
 Mr.Sandesh More i/b.Mr.Naveen Chomal for applicant.
 Mr.H.J.Dedhia, A.P.P. for respondent.
 CORAM : R.Y. GANOO, J.
 DATED : 21st April, 2008.
 P.C.:
 1. Mr.Sandesh More appearing for the applicant
 Mr.Dedhia, A.P.P. for the State.
 2. By this application, the applicant wants that
 anticipatory bail application No.4213 of 2008 be
 restored to file on merits.
 3. In my view, rather than restoring the
 anticipatory bail application No.4213 of 2008, it
 would be proper if the applicant files a fresh
 application for anticipatory bail placing before the
 Court all the facts and circumstances which are taken

 place upto today. Hence, the following order :-
 a) The applicant is permitted to file a
 fresh application for anticipatory bail, which
 would be considered by the learned Sessions
 Judge on its own merits without going into the
 past.
 4. In view of the above, this application stands
 disposed off as not pressed.
 (R.Y. GANOO, J.)
