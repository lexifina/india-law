# High Court of Orissa, WP(C)/1325/2006, 2018-12-13

10. 13.12.2018 Learned counsel for the petitioner seeks
permission to withdraw the writ petition with liberty to file
the same before the appropriate Court afresh if any cause
of action still survives. A memo filed to that effect is taken
on record.
 The writ petition is accordingly dismissed as
withdrawn.
 However, it is open for the petitioner to file the
petition afresh before the appropriate forum if any cause of
action still survives.
 All pending misc. cases/I.As. are accordingly
disposed of.
