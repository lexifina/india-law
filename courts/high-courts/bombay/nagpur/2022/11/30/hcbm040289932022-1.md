Heard.
2. By this application, the learned Counsel for
the applicants is seeking correction in the judgment
passed on 14/11/2022.
3. The Criminal Application (APL) No.16/2021
was decided on 14/11/2022 by which the First
Information Report vide Crime No.381/2020 registered at
police station Old City, Akola is quashed and set aside.
However, inadvertently the name of Shri A.A. Gupta,
Senior Advocate instead of Shri S.P. Dharmadhikari, Senior
Advocate assisted by Shri A.R. Deshpande, Advocate for
the applicants, was mentioned.
4. It is further contended that by the said order
this Court has quashed and set aside the First Information
Report registered vide Crime No.381/2020 but

11.APPP.1869.22inAPL.16.21.odt 2
inadvertently Sections 342 and 365 of the Indian Penal
Code are remained to be mentioned, and therefore, it is to
be corrected in paragraph Nos.2, 7 and 9(ii) of the
judgment dated 14/11/2022.
5. The charge-sheet bearing No.15/2021 filed by
respondent No.1 before the District and Sessions Judge-2,
Akola is also quashed and set aside and inadvertently it is
remained to be mentioned in the judgment.
6. All the above errors are typographical error
and, therefore, it can be corrected. Hence application is
allowed.
7. The portion regarding the name of the
Advocate is to be corrected and Sections 342 and 365 of
the Indian Penal Code be added in paragraph Nos.2, 7 and
9(ii) of the judgment dated 14/11/2022.
8. The paragraph No. 9(ii) is to be corrected as
follows :
“(ii) The First Information Report vide
Crime No.381/2020 registered at police
station Old City, Akola for the offences
punishable under Sections 323, 324, 504,
342, 365 and 506 read with Section 34 of the
Indian Penal Code and Section 3(1)(r)(s),
3(2)(va) of the Scheduled Castes and the
Scheduled Tribes (Prevention of Atrocities)
Act, 1989 and the charge-sheet bearing
No.15/2021, are quashed and set aside.”

9. The corrected copy of the judgment is to be
uploaded accordingly.
10. The civil application is disposed of.
