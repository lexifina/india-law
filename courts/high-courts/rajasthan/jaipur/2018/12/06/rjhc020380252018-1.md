Order
06/12/2018
This miscellaneous application has been filed to seek liberty to file
review petition instead of a fresh appeal. The prayer is to modify the
order dated 27.04.2018.
As prayed, the order dated 27.04.2018 is modified thus would be
read as under:-
“After arguing the case to some length, learned
counsel for the appellant prays for withdrawal of this
special appeal with liberty to file a review petition."
 With the aforesaid substitution in the order, application is
allowed.
