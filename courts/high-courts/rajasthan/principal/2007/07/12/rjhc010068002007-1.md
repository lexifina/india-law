# High Court of Rajasthan, CRLMB/708/2007, 2007-07-12

D.B. CRIMINAL BAIL APPLICATION NO. 708/07
Date : 12.07.2007
HON'BLE MR. BHAGWATI PRASAD, J
HON'BLE MR. RAGHUVENDRA S. RATHORE, J.
By Post
= = = = =
The matter has already been adjourned for six months. It
could not have been listed ordinarily. But an application has been received
by this Court for parole. It is advisable that the convict should first
approach the appropriate authorities for parole.
The bail application is not entertained and is hereby
dismissed.
(RAGHUVENDRA S. RATHORE), J. (BHAGWATI PRASAD), J.
