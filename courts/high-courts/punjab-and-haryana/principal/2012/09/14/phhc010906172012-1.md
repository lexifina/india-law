# High Court of Punjab and Haryana, CWP/868/2012, 2012-09-14

RANJIT SINGH, J.
Appropriate action has already been taken. Two writ
petitions earlier filed for the same cause by some other petitioners
have already been dismissed on this ground. It is not understood as
to how many persons would approach the Court for same cause. The
petitioner approaching the Court should not resort to such tactics
which only leads to wasting the time of the Court but nothing else.
One petition for the same cause is filed that should be enough.
Dismissed.
September 14, 2012 ( RANJIT SINGH )
rts JUDGE
