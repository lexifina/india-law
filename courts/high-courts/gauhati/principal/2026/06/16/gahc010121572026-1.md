Heard Mr. P J Saikia, the learned counsel appearing for the applicants. Also heard Mr.B
Sarma, learned Additional Public Prosecutor for the State of Assam.
2. This application has been filed praying for correction of inadvertent typographical error
appearing in the order dated 08.06.2026 passed by this Court in Crl. Pet./804/2026.
3. In the aforesaid order, “Sessions Case No.04/2017” has been mentioned, whereas it
should have been “Sessions Case No.30/2026”.

Page No.# 3/3
4. The typographical error stands corrected.
5. Henceforth, the case No. i.e. “Sessions Case No.04/2017” shall be read as Sessions
Case No.30/2026”.
6. This order shall form a part of the order dated 08.06.2026 passed by this Court in Crl.
Pet./804/2026.
With the aforesaid direction, the IA stands disposed of accordingly.
