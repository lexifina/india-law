ORDER
Date : 01-06-2023
Heard Mr. A Mobaraque, learned counsel for the applicant.
This application has been filed for correction/modification of the order
dated 25.05.2023 passed in I.A.(Crl.) 403/2023.
In para 3 of the order dated 25.05.2023 it has been mentioned as “an
appeal under Section 378 of the Code of Criminal Procedure, 1973 praying to
file an appeal against acquittal”, whereas it should have been “an appeal under
Section 372 of the Code of Criminal Procedure, 1973 praying to file an appeal

Page No.# 3/3
against acquittal”.
Further, the learned counsel for the applicant further submits that in the
said order dated 25.05.2023 passed in I.A.(Crl.) 3230/2023, in para 6 it has
been mentioned as “the Registry shall register the connected revision and list it
accordingly” whereas it should have been “the Registry shall register the
connected appeal and list it accordingly”.
The prayers, as sought for are allowed.
The interlocutory application stands disposed of.
The name of Mr. UK Das, learned counsel for the respondent Nos. 2 to 13
be reflected in the cause-list when the connected criminal appeal is listed next.
 JUDGE
