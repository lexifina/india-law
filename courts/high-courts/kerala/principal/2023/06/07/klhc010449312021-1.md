ORDER
This Bail Application filed under Section 438 of Criminal
Procedure Code (Cr.P.C.)
2. When this bail application came up for
consideration, the Public Prosecutor submitted that the final
report in Crime No.1148/2021 of Angamaly Police Station is
already filed before the jurisdictional court.
3. When this bail application came up for
consideration on 07.09.2021, this Court directed the Police
not to arrest the petitioner and that interim order is in force.
Now the final report is already filed. If that be the case, this
bail application need not be retained.
The petitioner shall appear before the jurisdictional
court if not appeared, and file an application for bail. If such
an application is filed, the jurisdictional court will consider the
fact that there was an interim order from this Court not to
arrest the petitioner during the period of investigation.

B.A.No.6458/2021
3
With the above observation, this bail application is
disposed of.
