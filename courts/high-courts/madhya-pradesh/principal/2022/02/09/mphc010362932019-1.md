This petition coming on for admission this day, the court passed the
following:
ORDER
By this petition, petitioner is challenging the order dated 05/07/2019
(Annexure P/1) whereby he has been directed to be transferred.
Learned counsel for the petitioner submits that this Court vide order
dated 26/07/2019 stayed the operation of the impugned order and, therefore,
the impugned order of transfer has not been implemented so far.
Reply has not been filed by the respondents.
Considering the aforesaid, it can be gathered that still no administrative
exigency exists, therefore, the impugned order dated 05/07/2019 (Annexure
P/1), so far as it relates to the petitioner, is set aside. However, liberty is
granted to the respondents that if they so require or any administrative
exigency still exists, they may issue fresh order of transfer.
With the aforesaid, this petition is allowed and disposed of.
