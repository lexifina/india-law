COMMON ORDER
These petitions have been filed challenging the order passed
in I.A.No.377 of 2014 and I.A.No.378 of 2014 in O.S.No.188 of 2012,
by District Munsif-cum-Judicial Magistrate, Vedasandhur, dated
12.12.2014.
2.The learned counsel appearing for the petitioner would
submit that the main case in O.S.No.188 of 2012 itself was dismissed
for default and also he seeks liberty to file a petition to restore
the Civil Revision Petitions, if the main suit is restored.
3.Recording the said submission, this Civil Revision
Petitions are dismissed with liberty to file a petition to restore
the Civil Revision Petitions, if the main suit is restored. No
costs. Consequently, connected miscellaneous petition is closed.
