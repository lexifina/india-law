# High Court of Madhya Pradesh, MCC/466/2014, 2014-05-08

M.C.C. No.466/2014
08/05/2014

Shri Sanjay Lal, learned counsel for the applicant.
Keeping in view the provisions of High Court Rules, as
this is an application for restoration of an appeal, which has
been dismissed, the office objection is overruled.
This application has been filed for restoration of I.T.A.
No.139/2010, which has been dismissed for non compliance
with the peremptory order passed by this Court on 23.8.2010.
Keeping in view the reasons given in the application for
restoration, which is supported by affidavit of the competent
officer, the same is found to be bonafide and is, therefore,
allowed. I.T.A. No.139/2010 is restored to its original file. It be
placed for orders before the appropriate Bench.
Application stands allowed and disposed of.
(Rajendra Menon) (A.K. Sharma)
Judge Judge
