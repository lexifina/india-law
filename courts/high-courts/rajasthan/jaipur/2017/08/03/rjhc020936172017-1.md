HON'BLE MRS. JUSTICE SABINA
Order
03/08/2017
Petitioner has filed this petition under Section 482
Code of Criminal Procedure, 1973 challenging the order dated
22.03.2017, whereby, application moved by the petitioner under
Section 70(2) Code of Criminal Procedure, 1973 was dismissed.
Heard.
Petitioner had jumped bail and absconded during trial
for ten years. In these circumstances, the learned trial court had
rightly dismissed the application moved by the petitioner under
Section 70(2) Code of Criminal Procedure, 1973.
No ground for interference is made out.
Dismissed.
 (SABINA)J.
