# High Court of Madhya Pradesh, MCC/1400/2014, 2014-08-08

M.C.C.No.1400/2014
Rajendra Shrivastava & Anr. Vs. State of MP
08/08/2014
Shri Dharmendra Patel, learned counsel for the applicants.
Shri Uttam Maheshwari, learned counsel for the respondent
No.2.
This application has been filed for restoration of
W.A.No.1426/2012, which has been dismissed for non-compliance with a peremptory order passed. There is some delay
in filing of the application, therefore, I.A.No.10878/2014 has been
filed seeking condonation of delay in filing of the application.
Keeping in view the reasons given in the application and
finding them to be bona-fide, both the applications are allowed.
Condoning the delay in filing of this application, the restoration
application is itself allowed. W.A.No.1426/2012 is restored to it's
original file. It be placed for orders before the appropriate Bench.
Application stands allowed and disposed of.
(Rajendra Menon) (Alok Verma)
