2 05/01/2011 This Court is not convinced from the oral
submissions made by the learned counsel for the
petitioner that he had made all the submissions before the
Bench which heard the contempt matter and when the
order was passed in annexure-2. The observation of the
Court is there in black and white and mere oral
submission that the Court did not consider all his
submissions will not do. If the Court concerned
did not consider all the submissions of the learned
counsel for the petitioner, then the only option for the
petitioner is to file a review application if he has any
grievance. This Court is not going to allow the petitioner
to file a new writ application raising the whole issue

- 2 -
afresh.
This writ application is thus dismissed.
AMIN/ (Ajay Kumar Tripathi, J.)
