# Allahabad High Court, WRIC/19137/2019, 2019-11-22

Court No. - 10
Case :- WRIT - C No. - 19137 of 2019
Petitioner :- Pramod Kumar
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Indra Kumar Singh,Beerendra Pratap
Singh
Counsel for Respondent :- C.S.C.
Hon'ble Vivek Varma,J.
In Ref- Civil Misc. Withdrawal Application No.2 of 2019
Heard Sri Beerendra Pratap Singh, learned counsel for the
petitioner and learned standing counsel for the State.
This is an application for withdrawal of the writ petition, which
is supported with an affidavit.
It has been stated in Paragraph No.6 of the affidavit in support
of this application that the petitioner does not want to press the
writ petition..
In view of the averments made above, this application is
allowed. The writ petition is dismissed as withdrawn.
Interim order, if any, stands vacated.
Order Date :- 22.11.2019
