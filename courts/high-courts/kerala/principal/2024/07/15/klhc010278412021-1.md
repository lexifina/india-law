JUDGMENT
This is an appeal filed invoking the provisions of
Section 378(4) of the Code of Criminal Procedure, 1973.
2. An order of the Magistrate dismissing a complaint
under Section 203 of the Code is impugned in the appeal. Such
an order is not made appealable under any of the provisions of
the Code. Section 372 of the Code bars appeal from any
judgment or order except as provided by the Code or any
other law for the time being in force. Since an order dismissing
a complaint under the provisions of Section 203 of the Code is
not made appealable, this appeal is not maintainable. The
appeal is therefore dismissed as not maintainable, but without
prejudice to the right of the appellant to challenge the
impugned order in an appropriate proceedings.
3. Needless to say that, the appellant may claim
