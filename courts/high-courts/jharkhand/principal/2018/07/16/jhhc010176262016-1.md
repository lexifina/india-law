07/16.07.2018 The petitioner is aggrieved of order dated 25.02.2014 by
which his application under Order IX Rule 13 CPC has been
dismissed.
Under Order XLIII Rule 1(d) CPC an appeal shall lie
against the order rejecting the application under Order IX Rule 13
CPC and while so, this writ petition is held not maintainable.
Granting liberty to the petitioner to file an appeal under
Section 104 CPC read with Order XLIII Rule 1(d) CPC, if so
advised, the writ petition is dismissed as not maintainable.
 (Shree Chandrashekhar, J.)
