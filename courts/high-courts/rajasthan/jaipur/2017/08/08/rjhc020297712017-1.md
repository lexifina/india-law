Order
08/08/2017
 This application has been filed seeking correction in the
order dated 29th May, 2017.
It is stated that inadvertently, in the order dated 29th
May, 2017, the date of application has been mentioned as 05th
January, 2017 instead of 08th July, 2016.
In view of the above, the application is allowed. The
date of application in the order dated 29th May, 2017 be read as
08th July, 2016 instead of 05th January, 2017.
This order be treated as part and parcel of the order
dated 29th May, 2017.
