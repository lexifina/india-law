1. Learned counsel for the applicant seeks permission of this Court to
withdraw this anticipatory bail application with liberty to file repeat
application, for the reasons, that the Police has prepared closure report
of the applicant, and liberty is sought on the ground that if the closure
report is not accepted by the trial Court and if there is apprehension of
arrest, then the applicant may be allowed to file repeat application.
2. Considering the statement so made by the counsel for the applicant, this
bail application is dismissed as withdrawn, with the aforesaid liberty.
