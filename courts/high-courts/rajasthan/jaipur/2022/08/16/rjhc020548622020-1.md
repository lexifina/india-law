HON'BLE MR. JUSTICE UMA SHANKER VYAS
Order
16/08/2022
Heard learned counsel for the parties on an application
No.3/2022 filed for converting this criminal revision petition into
criminal miscellaneous petition.
For the reasons stated in the application No.3/2022, the
same is allowed.
Registry is directed to register this criminal revision petition
as criminal miscellaneous petition and the same be listed before
the Regular Bench having roster of criminal miscellaneous
petitions.
Learned counsel for the petitioner is directed to file amended
cause title.
For statistical purpose, this criminal revision petition is
disposed of.
(UMA SHANKER VYAS),J
