# Calcutta High Court, CRR/766/2023, 2024-03-04

M/L74
04.03.2024
Bpg.
 C.R.R.766 of 2023
In Re: An application under Section 482 of the Code of Criminal
Procedure;
 Chandrajit Shit
 Versus
 Sukanya Shit
The revisional application was called on 19th September,
2023 when none represented on behalf of the petitioner. The
revisional application appeared again on 1st March, 2024 when the
petitioner was not represented. Today, when the revisional
application has been called on, none represented the petitioner.
The subject matter of the revisional application relates to
process issued in connection with Misc. Case No.86 of 2019 which
relates to a proceeding under Section 125 of the Code of Criminal
Procedure.
Having regard to the prayers so advanced in the
revisional application for quashing the said proceedings, I am of the
view that the prayers so advanced in respect of a process issued in
a case of 2019 cannot be interfered.
Accordingly, CRR 766 of 2023 is dismissed.
Pending connected application, if any, is consequently
dismissed.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
