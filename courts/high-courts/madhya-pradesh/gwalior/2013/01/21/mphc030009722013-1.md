# High Court of Madhya Pradesh, MCRC/345/2013, 2013-01-21

Mis. Cr. Case No.345/13
 (Prabal Pratap Singh Vs. State of M.P.,)

21-01-2013
Petitioner by Shri D.S.Tomar, Advocate.
Respondent/State by Shri R.K.Shrivatava, Panel Lawyer.
 With the consent of learned counsel for the parties, the
matter is heard finally.
This petition under Section 482 of Cr. P.C., has been filed by
the petitioner/accused, Prabal Pratap Singh seeking correction in the
order dated 21/11/12 passed in Mis. Cr. Case No.8459/12 by this
Court.
Learned counsel for the petitioner submits that mistakenly
crime number of the case has been mentioned in the impugned
order as 232/2009 while the correct crime number is 233/12.
Considering the submissions made by learned counsel for the
petitioner and the averments made in the petition, the same is
hereby is allowed. The crime number be read as 233/12 in place of
crime number 232/2009 in Mis. Cr. Case No.8459/12 (supra).
This order be read conjointly with the order dated 21/11/12
passed in Mis. Cr. Case No.8459/12 by this Court.
Certified copy as per rules.
 (Brij Kishore Dube)
