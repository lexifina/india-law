Order
21/08/2017
The matter comes up on a misc. application No. 427/2017, with a
prayer for correction of the ‘year’ of the case Number in para No.2, at
page No.1, in line No.3 of the order dated 19th September, 2017, to be
read as 'SBCWP No.15098/2012', instead of 'SBCWP No.15098/2013'.
For the reasons assigned in the misc. application and upon
hearing the counsel for the applicants/petitioners; the typographical
error needs to be corrected.
Ordered accordingly.
But for the correction aforesaid, rest of the order dated 19th
September, 2017, shall be maintained as such.
Misc. Application No.427/2017, stands disposed off.
(VEERENDR SINGH SIRADHANA)J.
