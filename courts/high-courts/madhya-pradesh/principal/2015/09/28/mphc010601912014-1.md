# High Court of Madhya Pradesh, MCC/2968/2014, 2015-09-28

MCC NO.2968/2014
28-09-2015
 Shri Neeraj Pathak, learned counsel for the applicant.
 Shri Ashok Chourasia, learned counsel for the respondents.
 This application has been filed for restoration of Conc No.93/2009,
which was dismissed for non compliance with the peremptory order passed
by this court. There is delay in filing of this application, therefore,
I.A.No.17896/2014 has been filed for condoning the delay.
 Delay in filing the application as well as default itself is attributed to
some lapses on the part of the counsel and applications are supported by
the affidavit of the applicant itself and there is no reason to disbelieve its
bonafide.
 Considering the same both the applications, i.e. application for
condonation of delay and restoration application itself, are allowed. Delay is
condoned and Conc No.93/2009 is restored to its original file. It be placed
for orders before an Appropriate Bench.
 Application stands allowed and disposed of.

 (RAJENDRA MENON)
 JUDGE
