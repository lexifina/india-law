# High Court of Madhya Pradesh, MCC/217/2015, 2015-01-27

1
MCC No.217/2015
27/1/2015.
Shri Atul Anand Awasthi, learned
counsel for the petitioner.
The applicant has filed this application
for restoration of W.P. No.14345/2014 which is
dismissed in common conditional order vide
order dated 26.9.2014. The application is
supported by an affidavit of the Advocate.
Looking to the grounds mentioned in
the application as well as affidavit, the
application is allowed.
W.P. No.14345/2014 is restored to its
original number.
