# High Court of Jharkhand, Cr.M.P./458/2013, 2013-05-14

IN THE HIGH COURT OF JHARKHAND AT RANCHI

Versus
The State of Jharkhand … … Opp. Party
-----
CORAM: HON’BLE MR. JUSTICE R.R. PRASAD
-----
For the Petitioner : Mr. A.K. Das, Advocate
For the Opp. Party : APP
-----
02/14.05.2013: Mr. A.K. Das, learned counsel appearing for the petitioner
submits that initially a case was lodged against this petitioner, which was
registered as Doranda P.S. Case No.119 of 2009 (G.R. No.1338 of 2009)
under Sections 419/420/467/468/406/506 and 120B of the Indian Penal Code.
During investigation, the allegations were never found to be true so far
offences under Sections 419/420/467/468/406 of the Indian Penal Code are
concerned. However, allegation with respect to offences under Sections 448
and 506 of the Indian Penal Code were found to be true. Accordingly, charge
sheet was submitted upon which cognizance was taken vide order dated
20.04.2011, which is under challenge.
Mr. Das, learned counsel appearing for the petitioner further
submits that accepting the entire allegation levelled against the petitioner to be
true, no offence is made out either under Sections 448 or 506 of the Indian
Penal Code and, therefore, order taking cognizance be quashed.
In the fitness of things, I am not inclined to interfere with the order
taking cognizance dated 20.04.2011. However, the petitioner would be at
liberty to raise the issue which has been raised in this application at the time of
discharge upon which order be passed in accordance with law, without being
prejudiced by the order of this Court.
Accordingly, this application stands disposed of.
 (R.R. Prasad, J.)
