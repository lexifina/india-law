HON'BLE MR. JUSTICE UMA SHANKER VYAS
Order
25/11/2022
Heard learned counsel for the parties on an application
No.IA1/2022 filed for converting this criminal miscellaneous
petition into criminal writ petition.
For the reasons stated in the application No.IA1/2022, the
same is allowed.
Registry is directed to register this criminal miscellaneous
petition as criminal writ petition and the same be listed on
29.11.2022 before this Court.
Learned counsel for the petitioner is directed to file amended
cause title.
For statistical purpose, this criminal miscellaneous petition is
disposed of.
(UMA SHANKER VYAS),J
