Heard on I.A. No. 01, which is an application for condonation of delay
in filing the M.C.C.
This is not opposed by the State counsel.
For the reasons mentioned in the application, the same is allowed. The
delay in filing the application is condoned.
Also heard on M.C.C. No. 467/2016 which is an application for
restoration of W.P.S. No. 4819/2005 which was dismissed by this Court vide
order dated 25.04.2012 for want of prosecution.
This is not opposed by the State counsel.
For the reasons mentioned in the application, the same is allowed and
W.P.S. No. 4819/2005 is restored to its original number.
