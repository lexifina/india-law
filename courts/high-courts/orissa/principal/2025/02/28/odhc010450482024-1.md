01. 1. This matter is taken up through Hybrid mode.
2. Referring to the postal receipt under Annexure-2, learned
counsel for the Petitioner submitted that the order dated
11.12.2023 passed by this Court in W.P.(C) No.38842 of 2023
has been duly communicated to the Opposite Party-Contemnor,
however, they have not implemented the order.
3. Learned counsel for the Contemnor sought for some time
to implement the order of this Court in the event the same attains
finality.
4. Considering such submission, as a last chance, six weeks’

petition is disposed of.
