# High Court for the State of Telangana, CC/577/2017, 2017-03-24

THE HONOURABLE SRI JUSTICE CHALLA KODANDA RAM
CONTEMPT CASE No.577 OF 2017
JUDGMENT:
Learned counsel for the petitioner seeks permission of this Court
to withdraw the contempt case with liberty to file fresh contempt case.
Permission is accorded.
Accordingly, the Contempt Case is dismissed as withdrawn giving
liberty to the petitioner to file fresh contempt case. No order as to
costs. Misecllanesous petitions pending if any, shall stand closed.

CHALLA KODANDA RAM, J
