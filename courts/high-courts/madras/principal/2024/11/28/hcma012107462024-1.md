ORDER
The writ petitioner had earlier filed writ petition in W.P.No.25839 of 2023 which
came up for consideration before a learned Single Judge and by an order dated
04.09.2023, the learned Single Judge had dismissed the writ petition. That particular
writ petition had been filed seeking interference with an order of the 5
th
 respondent
therein/4
th
 respondent herein, the Joint Director, Medical and Rural Health Service,
Coimbatore, whereby, the request of the petitioner for extension of license was rejected.
The learned Single Judge had refused to interfere with that order and dismissed the writ
petition. The petitioner had no right to continue to run the tea shop there. The request for
extension had not been granted.
https://www.mhc.tn.gov.in/judis

3
2.Now the writ petition has been filed seeking permission to continue to run the
tea shop till an auction is conducted. If such permission is granted it would run contrary
to the earlier order of the learned Single Judge, dated 04.09.2023 in W.P.No.25839 of
2023. Therefore, with respect to the relief sought, to permit the petitioner to run the tea
shop, the writ petition stands dismissed and that relief is not granted. Needless to point
out, nor even to observe, the petitioner if he is eligible and satisfies the eligibility
conditions of the respondents can always participate in the auction. No Costs.
Consequently, connected miscellaneous petition is closed.
