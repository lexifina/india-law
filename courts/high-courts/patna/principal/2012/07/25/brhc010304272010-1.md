ORAL ORDER
5 25-07-2012 Heard learned counsel for the petitioner and the
University.
It is submitted on behalf of the University that the final
order has been passed and communicated to the petitioner and as
such, since the order of this Court has been complied with, the
contempt application deserves to be dismissed.
Learned counsel for the petitioner, on the other hand,
submits that since the order is not correct, the petitioner proposes
to assail the same before an appropriate forum.
 Be that as it may, since the order has been complied
with, the contempt application need not proceed further. The same
stands disposed of.
 PNM
(Shailesh Kumar Sinha, J)
