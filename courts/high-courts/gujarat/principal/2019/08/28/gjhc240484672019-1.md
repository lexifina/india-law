ORAL ORDER
Learned advocate for the petitioner seeks
permission to withdraw this petition with a view
to file appeal before the Deputy Collector
against the order dated 09.07.2019 passed by the
Mamlatdar, Bhavnagar (Rural).
Permission as prayed for is granted. Petition
stands disposed of as withdrawn.
At this stage, it is submitted by learned
advocate for the petitioner that petitioner will
immediately file appeal before the Deputy
Collector along with an application for stay as
the petitioner is apprehending that the land in
question would be allotted to some other person.
If such an application for stay is filed, the
