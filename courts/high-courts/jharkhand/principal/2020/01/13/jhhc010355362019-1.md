# High Court of Jharkhand, Cr.M.P./3626/2019, 2020-01-13

IN THE HIGH COURT OF JHARKHAND AT RANCHI
Cr. M.P. No.3626 of 2019
----
Tarak Das @ Tarak Harijan … Petitioner
-versus-The State of Jharkhand … Opposite Party
---
CORAM : HON’BLE MR. JUSTICE ANANDA SEN
----
For the Petitioner : Mr. Deepak Kumar, Advocate
 Mr. Sachin Mahato, Advocate
For the State : Mr. Vinay Kumar Tiwary, APP
----
2/ 13.01.2020 Heard learned counsel for the petitioner and the learned
A.P.P. appearing for the State.
 Petitioner has challenged the part of the order dated
24.09.2019 passed by the Additional Chief Judicial Magistrate, Ramgarh in
Mandu (Kuju) Police Station Case No.151 of 2007, by which process under
Section 82 of the Code of Criminal Procedure has been issued.
 Counsel for the petitioner submits that the order issuing
process under Section 82 of the Code of Criminal Procedure is absolutely
cryptic and does not reflect any satisfaction as to why processes under
Section 82 of the Code of Criminal Procedure is to be issued.
 Learned A.P.P. appearing for the State opposes the prayer
and submits that the impugned order has been passed on the application
made by the police.
 After going through the impugned order, I find that only on
application made by the police, Court has issued processes under Section
82 of the Code of Criminal Procedure. This is not mandate of law. What
are the materials to proceed and issue processes under Section 82 of the
Code of Criminal Procedure must be reflected in the order. This subjective
satisfaction is missing in the order impugned issuing process under
Section 82 of the Code of Criminal Procedure. Thus the impugned order is
absolutely cryptic and without any application of mind.
 Accordingly, the order impugned dated 24.09.2019 passed by
the Additional Chief Judicial Magistrate, Ramgarh in Mandu (Kuju) Police
Station Case No.151 of 2007, issuing process under Section 82 of the
Code of Criminal Procedure is hereby quashed and set aside. The matter
is remanded to the Court below to proceed further and pass fresh order in
accordance with law.
 This criminal miscellaneous petition is, thus, allowed.

( Ananda Sen, J.)
