# Allahabad High Court, WRIC/41240/2018, 2018-12-14

Court No. - 38
Case :- WRIT - C No. - 41240 of 2018
Petitioner :- Niranjan Prasad Sharma
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Pankaj Kumar Shukla
Counsel for Respondent :- C.S.C.
Hon'ble Abhinava Upadhya,J.
Hon'ble Vivek Varma,J.
Heard Sri Pankaj Kumar Shukla, learned counsel for the
petitioner and learned Standing Counsel for the State
respondents.
The petitioner claims himself to be a care taker of the trust
property by the name of the 'Jangid Sewa Sansthan',
particularly a large number of property belongs at district
Mathura. The petitioner has applied for security before the
District Level Security Committee for providing gunner, which
application is still pending and not decided.
The writ petition is disposed of with the observation that in
case such an application is pending, the same be considered and
decided in accordance with law, without unnecessarily delay.
Order Date :- 14.12.2018
