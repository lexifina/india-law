# Allahabad High Court, WRIC/15159/2019, 2019-05-27

Court No. - 49
Case :- WRIT - C No. - 15159 of 2019
Petitioner :- Vidyotma
Respondent :- State Of U P And Another
Counsel for Petitioner :- Rakesh Prasad,Daya Shanker Yadav
Counsel for Respondent :- C.S.C.
Hon'ble Ajit Kumar,J.
Pursuant to the order of this Court, the instructions are placed
before this Court by learned Standing Counsel which are taken
on record.
As per the instructions, the District Panchayat Raj Officer, Etah
has already cancelled the order dated 21.01.2019 vide order
dated 25.05.2019. Since the petitioner had challenged the order
dated 21.01.2019, which has been recalled, no more any cause
of action survives in the writ petition.
Accordingly, the writ petition is dismissed and consigned to
record.
Order Date :- 27.5.2019
