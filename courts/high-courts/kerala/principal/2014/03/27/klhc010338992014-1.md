J U D G M E N T
Heard the counsel for the petitioners and the
counsel for the Caveator.
2. The petitioners assert that they are sought
to be dispossessed in execution of a decree to which
they are not parties. E.A.No.45/2014 put in by the
petitioners in this regard under Order XXI Rule 97 of
the Code of Civil Procedure stands dismissed by order
dated 10.3.2014. The petitioners contend that such
execution application has been disposed of without
determining the questions contemplated under Order XXI
Rule 101 of Code of Civil Procedure.
3. Any order passed on such an execution
application under Order XXI Rule 103 of Code of Civil
Procedure is to be treated as a decree against which an
appeal would lie under Order XXI Rule 104 of Code of
Civil Procedure. All questions now urged by the
petitioners in this original petition can very well be
urged in the Execution First Appeal if any filed. It
will be inequitable to test the legality of the order
in an original petition of this nature when an

O.P (C) No.851 of 2014
2
effective statutory remedy by way of appeal exists.
4. I however defer the proceedings for
effecting delivery in E.P.No.32/2011 in O.S.No.69/1986
on the file of the court of the Subordinate Judge of
Sulthan Bathery for one month. This is to enable the
petitioners to invoke the statutory remedy as indicated
above and apply for interim orders.
The Original Petition is disposed of.
