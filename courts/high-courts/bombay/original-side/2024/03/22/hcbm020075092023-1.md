P.C. :
. The learned counsel for the plaintiff submits that in this
administrative suit, the advocates for the plaintiff have changed. The
advocates, now representing the plaintiff, find that certain facts need to be
brought on record for which the plaint would have to be amended
extensively. It is submitted that certain events also need to be brought on
record for the comprehensive consideration of the grievances of the
plaintiff. It is also submitted that if an attempt is made to amend the plaint,
it would require extensive amendments, and that therefore, it would be
more appropriate that the plaintiff withdraws the suit with liberty to file a
fresh suit for the same cause of action.
2. The learned counsel for the defendants has left it to this Court to
pass an appropriate order.
