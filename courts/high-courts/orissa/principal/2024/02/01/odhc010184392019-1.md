12. 1. This matter is taken up through Hybrid
Arrangement (Virtual/Physical) Mode.
2. Heard learned counsel for the parties.
3. The present appeal by the State seeks to challenge
order dated 07.02.2019 passed by the State Education
Tribunal (SET), Odisha, Bhubaneswar in Execution
Case No.163 of 2014 corresponding to GIA Case No.686
of 2012.
4. By the impugned order, the SET had directed the
Appellants to furnish property details along with the
details of the vehicle with registration numbers and had
simply adjourned the matter awaiting the property
details.
5. This appeal is not even maintainable since
against the main order dated 16.02.2013 passed by the
SET in GIA Case No.686 of 2012, the State had already
preferred FAO No.343 of 2013 which was dismissed by
this Court on 11.04.2018. It is stated that a review
petition has been filed for recalling of the said order,
which is stated to be still pending.

// 2 //
Page 2 of 2
6. Nevertheless, it is added that in the said review
petition no order has been passed staying the operation
of either the original order of the SET or of this Court.
7. The net result is that there is no impediment in the
way of the Appellants implementing the order of the
SET. It is highly doubtful that the present FAO against
the interim order of the SET passed in Execution Case
No.163 of 2014 is even maintainable.
 8. For all of the aforesaid reasons, this Court is not
inclined to entertain the present appeal. It is
accordingly dismissed.
 (Biraja Prasanna Satapathy)
