# High Court of Madhya Pradesh, MCC/3493/2015, 2015-12-02

MCC-3493-2015
(SMT. PRADEEP KAUR Vs THE STATE OF MADHYA PRADESH)
02-12-2015
Shri Sanjeev Mishra, learned counsel for the applicant.
This application has been filed for restoration of W.P.
No.12342/2009, which was dismissed for want of
prosecution vide order dated 19.6.2015. There being
some delay in filing of this application for restoration,
I.A. No.15567/2015 has been filed. Reason for the delay
is attributed to some lapse in the office of the counsel
and the application is supported by affidavit of the
applicant.
Finding the same to be bonafide, both the applications
are allowed. Condoning the delay in filing the restoration
application, the restoration application itself is allowed.
W.P.12342/2009 is restored to its original file. It be
placed for orders before an appropriate Bench.
Application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
