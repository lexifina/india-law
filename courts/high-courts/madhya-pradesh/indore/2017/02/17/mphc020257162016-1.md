# High Court of Madhya Pradesh, CR/183/2016, 2017-02-17

CR-183-2016
(SALITABAI Vs VILASRAO)
17-02-2017
Shri R.S. Yadav, learned counsel for the petitioner.
Shri Mukesh Tare, learned counsel for the respondent.
Counsel for the respondent has raised the objection
about maintainability of the petition. The plaintiff filed
the suit which was dismissed in default by order dated
26.09.2014.
Being aggrieved by the same, the petitioner preferred
Miscellaneous Appeal, which was also dismissed on
11.08.2016. Thereafter, the petitioner has preferred this
revision.

Shri R.S. Yadav, learned counsel for the petitioner, at
this stage, prays for withdrawal of the petition, with
liberty to file a writ petition against the order dated

Revision petition is dismissed as withdrawn, with the
aforesaid liberty.
