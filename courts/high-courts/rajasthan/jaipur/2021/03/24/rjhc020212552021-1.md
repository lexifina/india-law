HON'BLE MR. JUSTICE SANJEEV PRAKASH SHARMA
Order
24/03/2021
Application has been moved for correction of the order
passed by the Court dated 17.02.2021.
Learned counsel appearing for the petitioner submits that the
petitioner had prayed for liberty to file early listing application
before CGIT-Cum-Labour Court, Jaipur, however, erroneously it
has been mentioned in the order that he seeks liberty to file
application for listing of the case for final arguments. Accordingly,
the correction which is required to be made in the order dated
17.2.2021 shall be read as “granting liberty to the petitioner to
move application for early listing of the case pending before the
CGIT-Cum-Labour Court”. The remaining part of the order shall be
read as it is.
The present order shall be treated as part and parcel of the
order dated 17.02.2021.
The application stands disposed of.
(SANJEEV PRAKASH SHARMA),J
