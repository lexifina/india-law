Order
22/07/2024
1. This misc. application is filed seeking correction in the order
dated 08.04.2024 passed in SBCWP No.5191/2024.
2. Learned counsel submits that two petitions were disposed of
by a common order. One petition was listed for correction of
mother’s name and other for correction of father’s name. Learned
counsel submits that in the order dated 08.04.2024 only father’s
name has been typed in para 3.
3. For the reasons mentioned therein, the application is
allowed. In para 3 of the order dated 08.04.2024,
father’s/mother’s name be read instead of father’s name.

[2024:RJ-JP:30696] (2 of 2) [WMAP-231/2024]
4. This order shall be part of the order dated 08.04.2024.
5. The misc. application stands allowed accordingly.
