# Allahabad High Court, ABAIL/4531/2020, 2020-08-05

Court No. - 3
Case :- CRIMINAL MISC ANTICIPATORY BAIL APPLICATION U/S
438 CR.P.C. No. - 4531 of 2020
Applicant :- Shafaiz Saifi @ Haidar
Opposite Party :- State of U.P.
Counsel for Applicant :- Malay Kumar Sharma,Praveen Kumar Tripathi
Counsel for Opposite Party :- G.A.
Hon'ble Samit Gopal,J.
Heard Sri Praveen Kumar Tripathi, learned counsel for the
applicant, Sri Rakesh Dubey, learned counsel for the first
informant and Sri Ashwini Prakash Tripathi, learned A.G.A. for
the State and perused the record.
Sri Rakesh Dubey, learned counsel is directed to file his
Vakalatnama in the office within two days.
If any such Vakalatnama is filed, the office shall restore the
same in the file and note the same in the order sheet.
A preliminary objection has been raised by Sri Rakesh Dubey
and Sri Ashwini Prakash Tripathi regarding maintainability of
the present application under Section 438 of the Code of
Criminal Procedure, 1973. It is argued that the same has been
filed in a case for offences under Sections 147, 148, 149, 302,
34, 120-B of the Indian Penal Code, 1860 and Section 7 of the
Criminal Law Amendment Act, 1992 and the same is not
maintainable as per the restrictions of Section 438 (6)(b) of the
Code of Criminal Procedure (Uttar Pradesh Amendment) Act,
2018, which specifically provides that the provisions of Section
438 of the Code of Criminal Procedure, 1973 shall not be
applicable in the offences in which Death sentence can be
awarded and the present case as is under Section 302 of the
Indian Penal Code alongwith other offences, is punishable with
Imprisonment for Life or Death.
Learned counsel for the applicant has stated that the applicant
has been falsely implicated and the applicant claims alibi in the
present matter.
On the question of maintainability, there is no address by the
learned counsel for the applicant.
Looking to the question of maintainability, the present
application is not maintainable as is moved for an offence under
Section 302 of the Indian Penal Code alongwith other offences
and there is a specific bar in the Code of Criminal Procedure
(Uttar Pradesh Amendment) Act, 2018, for invoking the

provisions of Section 438 of the Code of Criminal Procedure,
1973 in the cases which are punishable with Death.
The present application is thus not maintainable and is rejected
as such.
 (Samit Gopal, J.)
