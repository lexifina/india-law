2. It is stated that order dated 07.09.2021 passed in
C.W.J.C. No. 14934 of 2021 is complied on 27.06.2023. No
reasons have been assigned in delaying the process so also there
is no application for extension of time in original C.W.J.C. No.

within a period of four weeks from today.

reserving liberty to the petitioner to file afresh writ petition, if
he is still aggrieved with the order dated 27.06.2023.
4. Learned counsel for the State is hereby directed to
furnish copy of the order dated 27.06.2023, during the course of
the day to the petitioner, failing which adverse order would be
passed in the event of making any Interlocutory Application to
revive the present order.
5. Registry is hereby directed to de-link the C.W.J.C.
