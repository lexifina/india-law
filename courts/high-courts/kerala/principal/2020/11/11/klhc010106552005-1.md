JUDGMENT
Dated this the 11th day of November 2020
 ...
This is an appeal against the acquittal
order dated 12.5.2000 in C.C.No.113 of 1998
on the file of the Judicial First Class
(Munsiff) Magistrate Court-II, Harippad.
2. When this case came up for
consideration, there is no representation.
Therefore, this Court issued notice to the
appellant as per order dated 1.10.2020. The
notice was served to the appellant. Even
then, there is no representation.
3. This is an appeal filed under Section
378(4) Cr.P.C. against an acquittal order.
This appeal is not even admitted. Only notice
on admission is ordered. If an appeal is not
even admitted, the same can be dismissed for

CRL.APPEAL NO.103 OF 2005 3
default. If an appeal is admitted, it cannot
be dismissed for default. In this case, the
appeal is not admitted. There is no
representation for the appellant also. Hence,
this Criminal Appeal is dismissed for
default.
