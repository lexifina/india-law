P.C. :
Heard Shri Vaze, petitioner in person as also learned counsel
Shri Salvi for the respondent.
2. The arguments are heard in the light of earlier order dated
16th October 2012.
3. Shri Vaze submits that on an application filed at Exh.56, an
order to proceed without written statement was passed. Though an
application was filed to have it set aside, it did not specify any provision.
According to him, the application cannot be considered as application

 2/2 11.11rpa
under section 151 of C.P.C. and hence it must be treated as one for review.
The order impugned in A.O.No.458/2011 was, therefore, one by which
review was allowed and, therefore, appeal from order was maintainable
under order 43 rule (1) (w) of C.P.C. Shri Salvi fairly states that no
express provision has been quoted in the application seeking leave to file
W.S. and, therefore, application may be treated as one under section 151
of C.P.C. or then in the alternative as one for review.
4. The exact provision under which the application was filed is a
disputed question which need not detain this Court in present jurisdiction.
Without deciding that question, appeal from order could not have been
held to be not maintainable.
5. In this situation, Review Petition No.11/2011 is granted and
order dated 8th October 2011 is recalled. Appeal from order is restored
back to file. List that appeal from order for further consideration on 26th
November 2012.
(B.P. DHARMADHIKARI, J.)
Sanjay Nanoskar, P.S.
