# High Court of Andhra Pradesh, WP/9596/2019, 2019-07-30

HON'BLE SRI JUSTICE U. DURGA PRASAD RAO
WRIT PETITION No.9596 OF 2019
ORDER:
 When the matter taken up for hearing, learned counsel for the
petitioner seeks permission of this Court to withdraw the present Writ
Petition with a request to give liberty to the petitioner to file a private
complaint as per the requirement.
2. Permission, as sought for, is accorded.
3. Accordingly, this Writ Petition is dismissed as withdrawn
giving liberty to the petitioner to file private complaint as per the
requirement. No costs.
 As a sequel, Interlocutory Applications pending, if any, shall
stand closed.
 _________________________
