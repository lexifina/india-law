ORAL ORDER
This application is listed pursuant to a note
filed by the learned advocate for the applicant.
When the matter is called out, learned
advocate for the applicant submits that now the
charge-sheet is filed during the pendency of this
application. Therefore, he has received
instructions to withdraw this application with a
view to file fresh application before the
appropriate Court. He, therefore, seeks
permission to withdraw this application.
Permission as prayed for is granted.
Application stands disposed of as withdrawn. Rule
is discharged. Liberty is reserved to file fresh
application before the appropriate Court. It is
clarified that this Court has not examined the
merits of the matter.
(VIPUL M. PANCHOLI, J)
