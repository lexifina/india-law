ORAL ORDER
2 03-04-2013 This is most ridiculous application never seen in my
carrier. There is a typographical error in the cause title for the case
that was disposed of. Typographical error was that the petitioner’s
name ought to have started with the Alphabet ‘J’ instead it has
been typed with Alphabet ‘G’. For that clerical correction a
modification application has been filed which has taken two years
time to be listed wasting every body’s time.
However, considering the facts and circumstances, let
the name of the petitioner be read as ‘Jagdish Ray starting with ‘J’
instead of Gagdish Ray starting with ‘G’.

Abhay/-
(Navaniti Prasad Singh, J)
