 Order
05/08/2021
The matter comes up on an application for correction in the
order dt.30.7.2021.
Learned counsel for the petitioner submits that due to
typographical error in the order dt. 30.7.2021, in the para No.2
and in last para no.3 has been mentioned as registered owner of
the vehicle whereas petitioner is Power of Attorney Holder.
For the reasons mentioned in the application, the same is
allowed. In the order dt. 30.7.2021 in para No.2 and last para
no.3 has been mentioned as “petitioner is a registered owner” be
read as “petitioner is Power of Attorney Holder”.
