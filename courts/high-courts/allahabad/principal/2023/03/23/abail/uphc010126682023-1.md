# Allahabad High Court, ABAIL/895/2023, 2023-03-23

Court No. - 82
Case :- CRIMINAL MISC ANTICIPATORY BAIL
APPLICATION U/S 438 CR.P.C. No. - 895 of 2023
Applicant :- Niraj Shukla And 2 Others
Opposite Party :- State Of U.P. And 2 Others
Counsel for Applicant :- Ram Sajiwan Mishra,Dheeraj Kumar
Dwivedi
Counsel for Opposite Party :- G.A.,Rakesh Dubey
Hon'ble Subhash Chandra Sharma,J.
Learned counsel for the applicant, Mr. Rakesh Dubey, learned
counsel for the opposite party as well as learned A.G.A. for the
State are present.
It is submitted that in this case N.B.W. was issued against all the
accused persons out of which the N.B.W. issued against co-accused Vijay Kumar Shukla @ Tinku has already been recalled
by the learned court concerned by order dated 13.12.2022,
therefore, he wants to move recall application before the learned
court and he wants to withdraw this application with liberty to file
afresh if occasion so arises and prays that the same may be
dismissed as withdrawn.
Accordingly, this anticipatory bail application is dismissed as
withdrawn with liberty as aforesaid.
