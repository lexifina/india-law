HON'BLE MR. JUSTICE INDERJEET SINGH
Order
26/03/2019
Heard on criminal misc. application under Section 482 Cr.P.C
seeking correction in the order dated 15.03.2019.
Counsel for the petitioner submits that in para No.2 of the
order, it has been mentioned that the challan has been filed,
whereas the challan has not been filed as yet.
In that view of the matter, para No.2 of the order dated
15.03.2019 be read as under:-
“Counsel for the petitioner submits that the offence alleged
against the petitioner is triable by Magistrate and the petitioner is
in custody since 17.02.2019.”
This order be treated to be part of the order dated
15.03.2019.
Accordingly, the application seeking correction in the order
dated 15.03.2019 stands disposed of.
