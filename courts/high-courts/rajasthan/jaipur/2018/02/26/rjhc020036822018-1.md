HON'BLE MR. JUSTICE ALOK SHARMA
Order
26/02/2018
The matter comes up on application to allow to agitate
the review petition in which the applicant was not party.
Heard the counsel for the petitioner.
I find no ground to allow the application to agitate the
review whom the applicant was not a party in SBCWP
No.20428/2017. In any event the applicant is a complete stranger
to the issue in SBCWP No.20428/2017.
The application is dismissed. So is the review petition.
(ALOK SHARMA) J.
