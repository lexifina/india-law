ORAL ORDER
Learned counsel for the petitioner submits that he
has no instruction. But, it would be necessary to file
rejoinder.
Since the petitioner has not instructed to his counsel
for to file rejoinder, this Court has no other option but to
dismiss the petition for non-prosecution.
Hence, the petition stands DISMISSED for NON-PROSECUTION. However, liberty is reserved to make an
application for restoration, if so advised.
Rule is discharged.
