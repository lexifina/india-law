# Allahabad High Court, WRIC/24096/2018, 2018-07-24

Court No. - 32
Case :- WRIT - C No. - 24096 of 2018
Petitioner :- Shambhu Singh
Respondent :- State Of U.P. And 4 Others
Counsel for Petitioner :- Sandeep Kumar
Srivastava, Sushil Kumar Srivastava
Counsel for Respondent :- Sharwan Kumar
Tripathi, Baleshwar Chaturvedi
Hon'ble Shashi Kant Gupta,J.
Hon'ble Rajiv Gupta,J.
Today, learned Standing Counsel has placed the
copy of the order dated 21.03.2018 passed by
Regional Officer, Uttar Pradesh Pollution Control
Board, Mathura before this Court and the same
has also been served on the learned counsel for
the petitioner.
Learned counsel for the petitioner has submitted
that in order to challenge the aforesaid order
dated 21.03.2018 passed by Regional Officer,
Uttar Pradesh Pollution Control Board, Mathura, he
may be permitted to file a fresh writ petition.
Considering the facts and circumstances of the
case, this writ petition is dismissed as not pressed
at this stage. However liberty is granted to the
learned counsel for the petitioner to file a fresh
petition.
This order has been passed in the presence of Sri
Sharwan Kumar Tripathi, learned counsel for the
respondent nos. 3 and 4.
Order Date :- 24.7.2018
Arun
