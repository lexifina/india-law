Order
01/03/2021
Heard on the application for correction in the order dated
07.08.2020 passed by this Court.
Counsel for the petitioner submits that due to typographical
error the name of the counsel for the petitioner has wrongly been
shown in the order dated 07.08.2020 passed by this Court as “Mr.
G.S. Rathore Adv” instead of “Mr. Ramavtar Bochalya” and prayed
that the name of the counsel for the petitioner be corrected.
In that view of the matter, the name of the counsel for the
petitioner “Mr. Ramavtar Bochalya, Adv” be read in place of “Mr.
G.S. Rathore, Adv” in the order dated 07.08.2020 passed by this
Court. The order dated 07.08.2020 is accordingly corrected and
this order be treated as part of the order dated 07.08.2020.
The application stands disposed of.
