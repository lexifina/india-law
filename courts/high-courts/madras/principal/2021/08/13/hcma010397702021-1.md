# Madras High Court, A/2536/2021, 2021-08-13

A.No.2536 of 2021
in
 C.S.No.368 of 2020
V.PARTHIBAN,J.
This application has been
filed to set aside the exparte order
passed in C.S.No.368 of 2020 dated
09.03.2021.
2. Heard the learned counsel
for the applicant and the learned
counsel for the respondents.
3. This Court has gone
through the averments contained in the
affidavit filed in support of the
application. This Court, being
convinced with the reasons set forth in
the affidavit filed in support of the
application, set aside the exparte order
dated 09.03.2021. Accordingly, the
application is allowed.
