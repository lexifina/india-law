prayed for pre-arrest bail, apprehending arrest in connection with Abhayapuri P.S. Case No.
589/2018 under Section 120(B)/448/326/506 IPC.

Additional Public Prosecutor for the state respondent.
Case diary along with the injury report called for is received and perused.

Page No.# 2/2

nature.

the interim pre-arrest bail granted vide order dated 05.02.2019 is hereby made absolute on the
same terms and conditions.
The bail application stands disposed of.
Return the case diary.
