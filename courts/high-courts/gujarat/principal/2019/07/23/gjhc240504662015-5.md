ORAL ORDER
Learned advocate Mr.Popat appearing for the applicant
requests for withdrawal of the application in order to file appropriate
application before the trial court taking all the contentions raised in
the writ application as well as the making of exemption application
for her presence with regard to the execution of non-bailable
warrant in connection with Criminal Case No.121 of 2009.
The present application stands disposed of as withdrawn. It
will be open for the applicant to take all the available contentions
before the trial court. Rule discharged. Interim relief, if any, stands
vacated.
