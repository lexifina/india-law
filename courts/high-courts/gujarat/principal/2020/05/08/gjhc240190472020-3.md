ORAL ORDER
The matter is heard through video conference. The file of the
above mentioned application is not produced before this Court but
a request letter has been produced and, therefore, learned
advocate for the applicant was called. Mr.Prajapati, learned
advocate for the applicant is heard on telephone and he has
submitted that he wants to withdraw the present application with a
liberty to file fresh application before the trial Court.
Permission as prayed for is granted. The present application
is disposed of as withdraw with the liberty to file fresh application
before the trial Court.
