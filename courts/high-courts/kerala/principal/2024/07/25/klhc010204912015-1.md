O R D E R
This Criminal Miscellaneous Case is filed to quash
the proceedings against the petitioner in C.C.
No.4586/2013 on the file of Judicial First Class Magistrate
Court-I, Chalakkudy.
The main grievance of the petitioner is that, based
on the same set of facts, another case is pending. As per
the e-court service website, it is recorded that, this case
is clubbed with the other case. Moreover, there is no
interim order passed in this Crl.MC. Probably, the case
itself might have been disposed of. No further direction is
necessary in this case. Hence, this Crl.MC can be closed.
Therefore, this Criminal Miscellaneous Case is
closed. Sd/-
P.V.KUNHIKRISHNAN
