Order No.
 ORDER
 28.07.2023
 03. 1. This matter is taken up through Hybrid
Arrangement (Virtual/Physical Mode).
2. Mr. A.K.Mohanty, learned counsel for the
Petitioner by filing a memo to withdraw the present
bail application prays to grant liberty to the Petitioner
to file a better application. The memo be kept on
record.
 3. Mr. B.B. Routray, learned counsel for the
Informant, however, prays not to give liberty to the
Petitioner to file a better application, but such a
blanket stipulation cannot be ordered in this case.
 4. In view of the aforesaid submission, the
present bail application stands disposed of as
withdrawn with liberty to the Petitioner to file a better
application.
