CORAM : A.P. Lavande,J
DATE : 14th August, 2006
Mr. Kasat, Advocate for the applicant seeks leave
to withdraw revision application with liberty to file appeal
from order or any other proceedings against impugned
judgment and decree in terms of Order 43 Rule 1 (u) of Code
of Civil Procedure. The applicant is granted leave to withdraw
revision application. The applicant is at liberty to file appeal
from the order or any other proceeding, if the same is
maintainable in law. The revision application stands
dismissed as withdrawn.
C.A. no.7767/2005
Mr. Kasat, Advocate for the applicant does not
press this application. Hence, the application is dismissed as
not pressed.
