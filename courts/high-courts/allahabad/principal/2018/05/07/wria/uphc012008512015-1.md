# Allahabad High Court, WRIA/8564/2015, 2018-05-07

Court No. - 6
Case :- WRIT - A No. - 8564 of 2015
Petitioner :- Vachspati Tripathi And 6 Others
Respondent :- State Of U.P. & 4 Others
Counsel for Petitioner :- Sujeet Kumar Rai
Counsel for Respondent :- C.S.C.,A.K. Yadav
Hon'ble B. Amit Sthalekar,J.
Civil Misc. Withdrawal Application dated 23.02.2018 supported by an
affidavit is taken up.
Heard Shri Sujeet Kumar Rai, learned counsel for the petitioners on the
application.
This application has been filed with the prayer to dismiss the writ petition
as withdrawn with liberty to file a fresh writ petition if any dues or interest
remains unpaid.
Application is allowed.
The writ petition is dismissed as withdrawn with the aforesaid liberty.
Interim order, if any, stands vacated.
Order Date :- 7.5.2018
N Tiwari
