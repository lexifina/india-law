Orders’ at the instance of office.
Learned counsel for the petitioners submits that the
present application was kept before the counter of this Court for
generating token number but no token number was generated
and at the same time, the file went missing. In the
circumstances, the petitioners obtained a fresh certified copy
and filed another bail application. Later on, in the missing file, a
token number was generated regarding which the petitioners

once missing, in which a token number was generated.
Under the aforesaid circumstances, learned counsel
for the petitioners seeks permission of the Court to withdraw the
present application.
Permission is accorded.
The application is dismissed as withdrawn.
