N.SATHISH KUMAR,J
Instant application has been filed to grant leave to file the suit.
2. Learned counsel appearing for the applicants would submit
that except item No.12 of the property morefully set out in the plaint is
situated in Alapakkam Village Uthramerur Taluk, all the properties
(Item Nos.1 to 11) are situated within the jurisdiction of this Court.
3. Considering the fact that cause of action arose within the
jurisdiction of this Court and item Nos.1 to 11 are situate within
Chennai, this Court is inclined to grant leave to file the suit.
4. Accordingly, leave is granted to file the Suit.
