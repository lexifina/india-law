Order On Board
18/05/18
1. Learned counsel appearing for the petitioners would submit that the
order passed by the Collector, District Surajpur dated 27.04.2018 (Annexure
– P/1) is unsustainable and without authority of law and the same is liable to
be set aside.
2. Learned State counsel would submit that order of Collector is
revisable before the Commissioner, Surguja Division.
3. I have heard learned counsel for the parties.
4. Since, the order passed by the Collector is revisable under the

3
Chhattisgarh Panchayats (Appeal and Revision) Rules, 1995, this Court is
not inclined to entertain this writ petition. It is accordingly dismissed.
However, petitioners would be at liberty to file revision before the
jurisdictional revisional authority in accordance with law.
5. With the aforesaid observation, the writ petition stands finally disposed
of. No order as to cost(s).
