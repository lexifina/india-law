Judgment / Order
26/09/2019
The instant misc. application has been filed by the petitioners for
seeking correction in the order dated 20.09.2019 passed by this Court
in SB Cr. Misc. Petition No.2208/2019.
For the reasons stated in the application, the application is
allowed. The order dated 20.09.2019 passed in SB Cr. Misc. Petition
NO.2208/2019 be read as under :
“Counsel for the petitioner seeks permission to withdraw
this misc. petition with liberty to file afresh, if the occasion
so arises.
Hence, the misc. petition is dismissed as withdrawn
with liberty as prayed for. Stay application is also
dismissed.”
(MANOJ KUMAR GARG),J
