MCC-360-2018
(SUKHNANDAN DANGI Vs MANAGER AGRICUTRAL FARM BAMHOURI)
Jabalpur, Dated : 13-07-2019
There is a delay in filing this petition, hence, I.A. No.1503/2018, has
been filed for condonation of delay.
On due consideration, this application is allowed. Delay stands
condoned.
The present application has been filed for restoration of MCC No.
725/2017, which has been dismissed for non-compliance of common
conditional order dated 21.07.2017.
Considering the averments made in the application, which is duly
supported by an affidavit, we find that sufficient cause is shown for
restoration of the case.
Accordingly, the application is allowed. MCC No.725/2017, is restored
to its original number.
A copy of this order be kept in the record of MCC No.725/2017.
