# Madras High Court, A/6055/2024, 2024-12-02

A.No.6055 of 20243
in C.S.No.272 of 2022
Dr.G.JAYACHANDRAN, J.
Application has been filed to set
aside the exparte order passed by this
Court on 14.12.2023, due to the
applicants'/defendants' failure to file
their Written Statement within the time.
2. The learned counsel
appearing for the applicants/defendants
submits that the Written Statement been
presented along with a condone delay
application. The exparte order has
caused grave prejudice to the
applicants/defendants' right to defend
the case.
3. Taking note of the reasons
stated and the fact that the applicants
have come out with an application to
condone the delay in filing the Written
Statement, to give a fair opportunity to
the applicants /defendants, the order of
this Court dated 14.12.2023 is hereby
set aside. Accordingly, this application
is allowed.
02.12.2024
rpl
Note: The Registry is directed to list the
application to condone the delay in filing
the Written Statement, if it is in order.
