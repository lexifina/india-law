# High Court of Orissa, CONTC/1710/2020, 2020-06-29

04. 29.06.2020 This matter is taken up through video conferencing.
 Heard Mr. Ramakanta Sahoo, learned counsel for
the petitioner and Mr. D.K. Mohanty, learned Standing
Counsel for the State.
 The petitioner has filed this application alleging non-compliance of order dated 24.12.2019 passed in W.P.(C)
No. 28060 of 2019.
 Mr. Ramakanta Sahoo, learned counsel for the
petitioner contended that since the order of this Court has
not been complied, he has approached this Court by filing
contempt application.
 Mr. D.K. Mohanty, learned Standing Counsel for the
State vehemently contended that no time limit has been
fixed with regard to consideration of the case of the
petitioner. If the petitioner is so aggrieved he should have
file application before the appropriate Court seeking time
limit.
 Considering the contention raised by learned counsel
for the parties and after going though the record, it
appears that in order dated 24.12.2019, no time limit has
been fixed. However, liberty is granted to the petitioner to
file proper application before the appropriate Court fixing
time limit.
 With liberty aforesaid, the contempt proceeding is
dropped.
Ajaya

 (DR. B.R. SARANGI, J)
