# High Court of Orissa, WP(C)/21279/2019, 2019-11-16

2.
Ayas
16.11.2019 Heard Shri S.K. Das, learned
counsel for the petitioner.
 For the pendency of an
Original Application on the selfsame
issue, present Writ Petition is not
maintainable. It is, at this stage of
the matter, Shri S.K. Das, learned
counsel for the petitioner requests
for withdrawal of the Writ Petition
with liberty to file a better
application. This Court accordingly
permits the petitioner to withdraw
Writ Petition with liberty to file a
better application.
 Accordingly this Writ Petition
stands dismissed as withdrawn, but
however with liberty as prayed for.

(Biswanath Rath, J.)
