ORAL ORDER
3 26-03-2014 This application is for restoration of MJC No.3042 of
2012 which stood dismissed for default on account of non-appearance of learned counsel for the petitioner on two dates.
Dismissal of a contempt application in default does not
operate as res judicata.
Petitioner is at liberty to file a fresh contempt
application if he is still aggrieved by the action of the opposite
parties.
This application is dismissed.
