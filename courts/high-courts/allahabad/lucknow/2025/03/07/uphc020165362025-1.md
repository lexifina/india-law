Opposite Party :- State Of U.P. Thru. Addl. Chief Secy. Home
Lko. And Another
Counsel for Applicant :- Pal Singh Yadav,Ashish Kumar
Singh,Prathama Singh
Counsel for Opposite Party :- G.A.
Hon'ble Om Prakash Shukla,J.
1. Heard Shri Pal Singh Yadav, learned Counsel for the
applicant, learned A.G.A. for the State-opposite party and
perused the material placed on record.
2. At the outset, learned Counsel for the applicant submits that
the he does not want to press this application on merits and
wants withdraw the same with liberty to file a fresh application
with correct description of opposite party No.2.
3. Learned A.G.A. for the State-opposite party has no objection
to the prayer made by learned Counsel for the applicant.
4. In view thereof, the present application is dismissed as
withdrawn with liberty as prayed by learned Counsel for the
applicant.
5. Office is directed to return certified copies, if any, annexed
with this application to learned Counsel for the applicant.
(Om Prakash Shukla, J.)
