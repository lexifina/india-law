1. Heard learned Counsel for the applicant.
2. By this application, the applicant seeks condonation of delay of
66 days caused in filing the aforesaid application seeking leave to file
appeal.
SQ Pathan 1/2

appln.338.16.11.doc
3. Learned Counsel for the applicant states that the applicant had
filed a Revision Application in this Court being Revision Application No.
10 of 2016. He submits that the said application was disposed of as
withdrawn and liberty was granted to file a substantive appeal, as the
remedy was by way of an appeal against the order of acquittal.
4. Learned Counsel for the respondent No. 2 opposed the
application. However, for the reasons set out in the application, the
applicant has made out sufficient cause for condoning the delay of 66 days
caused in filing the aforesaid application seeking leave to file appeal.
Application is allowed and the dealy is condoned.
5. Application disposed of accordingly.
6. Registry to number the application seeking leave to file appeal
and place the same for admission on 3rd April, 2017.
 REVATI MOHITE DERE, J.
