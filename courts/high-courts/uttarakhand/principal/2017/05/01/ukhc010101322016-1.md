# High Court of Uttarakhand, WPSS/573/2016, 2017-05-01

WPSS No.573 of 2016
Honíble Rajiv Sharma, J.
 Mr. Ravi Babulkar, Advocate for the
petitioner.
 Mr. Pankaj Purohit, Advocate for the
respondent Nos.1 & 2.
 Mr. N.P. Sah, Standing Counsel for the
State.
Heard.
 Petitioner participated in the selection
process. He sat in the written examination.
Petitioner has secured 45.50 marks in the
written examination. However, later on, it
transpires that key answer was wrong.
Petitioner had given option ëDí. However, the
correct answer was ëCí. Thereafter, 1.25
marks have been deducted from 45.50
marks. There is no dispute about it.
 The next submission of the petitioner
is that no separate minimum marks were
required in both the papers.
 There is no illegality whereby
minimum 45 marks were to be secured by
the candidate in each paper.
 Accordingly, there is no merit in the
writ petition and the same is hereby
dismissed.
 Pending application, if any, stands
disposed of.
 (Rajiv Sharma, J.)
