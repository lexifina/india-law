# High Court of Madhya Pradesh, MCRC/21623/2015, 2016-02-23

MCRC-21623-2015
(RAKESH KUMAR Vs THE STATE OF MADHYA PRADESH)
23-02-2016
Shri K.K.Gautam, counsel for petitioner.
This application has been filed for restoration of
M.Cr.C.No.18353/2015, which has been dismissed for want of
prosecution on 27.11.2015.
The application is supported by the affidavit of counsel
himself and the default has been attributed because of some
lapse on the part of counsel and there is no reason to
disbelieve the same.
Keeping in view aforesaid, this application is allowed.
M.Cr.C.No.18353/2015 be restored to its original file and be
listed for hearing before the appropriate Bench.
This M.Cr.C., stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
(SUSHIL KUMAR PALO)
JUDGE
