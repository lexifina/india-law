# Attention of actual users is invited to remark (b)appearing on page 75 of the Import Trade Control Policy Book for the periodJanuary-June 1956 under which applications had been invited for import ofA.C. 3 phase, 50 cycles,

MINISTRY OF COMMERCE AND INDUSTRY PUBLIC NOTICE IMPORT TRADE CONTROL New Delhi, the 5th May 1956 SUBJECT.-Import of A.C. 3 phase, 50 cycles, squirrel cage motors 3 to 10 H.P., 1500 RPN (syn) by actual users with starters and switches against licences granted for S.No. 32(b)/II for the period January—June 1956.

No. 19-I.T.C.(P.N.)/56.—Attention of actual users is invited to remark (b) appearing on page 75 of the Import Trade Control Policy Book for the period January—June 1956 under which applications had been invited for import of A.C. 3 phase, 50 cycles, squirrel cage motors 3 to 10 H.P., 1500 RPM (syn).

Licences have been granted against such applications for the import of the motors in question.

2. It has been represented that actual users may find it difficult to obtain starters and switches from indigenous sources and that the import of this equipment with the motors may be permitted. It has, therefore, been decided to allow actual users holding actual user licences for the said motors for the period January—June 1966 to import one starter and one switch for each such motor imported by them against licences mentioned above.

3. Since the face value of licences will cover only the c.i.f. value of the motors, the face value may be considered to be ipso facto enhanced to an extent mot exceeding 20 per cent, thereof to cover the c.i.f. value of one startar and one switch for each motor.

S. N. BILGRAMI, J t Secy.
