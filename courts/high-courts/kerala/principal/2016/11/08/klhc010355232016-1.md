JUDGMENT
When the petition came up for hearing today, the counsel for the
respondent submitted that ex-parte decree passed in O.S.521/2013
has been set aside and so the respondent cannot proceeded with the
execution. The report of the Sub Judge, Ernakulam also shows that
I.A.3742/2016 and I.A.3741/2016 in O.S.521/2013 filed by the
petitioner to set aside the ex-parte decree along with delay
condonation application have been allowed and the ex-parte decree
has been set aside and the case was posted to 07.11.2016. The prayer
in the petition is that, without disposing the application to set aside the
ex-parte decree, the execution cannot be proceeded with. Since the
ex-parte decree has already been set aside and in view of the setting
aside of the ex-parte decree, the plaintiff cannot proceed with the
execution proceedings, so the prayer in the petition has become
infructuous, in view of the fact that the ex-parte decree put for
execution has already been set aside. So the petition is dismissed as
infructuous.
(K. Ramakrishnan, Judge)
