2 25-09-2013 Learned counsel for the petitioner seeks permission
to withdraw this application with a liberty to prefer appeal against
the impugned order which is an order appealable in view of
Order XLIII Rule 1( r ) of the Code of Civil Procedure.
This application is dismissed as withdrawn with the
liberty aforesaid.
If the petitioner prefers an appeal, he will certainly
have the liberty to take the plea that he had been pursuing this case
against the impugned order; for the purpose of seeking
condonation of delay.
