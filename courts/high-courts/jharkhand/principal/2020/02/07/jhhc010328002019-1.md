7/ 07.02.2020 I.A. No.1091 of 2020
 This interlocutory application has been filed to include
challenge in the main criminal miscellaneous petition to the order dated
20.11.2018 passed by the Sub Divisional Judicial Magistrate, Deoghar in
Mohanpur Police Station Case No.302 of 2017 (G.R. No.1744 of 2017)
whereby process under Section 82 of the Code of Criminal Procedure has
been issued against the petitioners.
 This interlocutory application is allowed. Let the order dated
20.11.2018 passed in Mohanpur Police Station Case No.302 of 2017 (G.R.
No.1744 of 2017) be treated to be an impugned order.
 Cr. M.P. No.3334 of 2019
 Heard learned counsel for the petitioner and the learned
A.P.P. for the State.
 Petitioners in this criminal miscellaneous petition have
challenged the order dated 20.11.2018 passed by the Sub Divisional
Judicial Magistrate, Deoghar in Mohanpur Police Station Case No.302 of
2017 (G.R. No.1744 of 2017), whereby process under Section 82 of the
Code of Criminal Procedure has been issued against the petitioners.
 Counsel for the petitioners submits that the order issuing

 -: 2 :-
process under Section 82 of the Code of Criminal Procedure is absolutely
cryptic and does not reflect any satisfaction as to why processes under
Section 82 of the Code of Criminal Procedure has to be issued. He
submits that without any subjective satisfaction, the impugned order has
been passed only on the basis of the petition filed by the investigating
officer.
 After going through the impugned order, I find that the same is
absolutely cryptic and no satisfaction has been recorded as to why process
under Section 82 of the Code of Criminal Procedure is necessitated. Only
on the basis of the petition filed by the investigating officer, impugned order
has been passed.
 Accordingly, the order impugned dated 20.11.2018 passed by
the Sub Divisional Judicial Magistrate, Deoghar in Mohanpur Police Station
Case No.302 of 2017 (G.R. No.1744 of 2017), issuing process under
Section 82 of the Code of Criminal Procedure as against the petitioners is
hereby quashed and set aside. The order dated 28.06.2019 passed in Cr.
Rev. No.98 of 2019 is also hereby set aside. The matter is remitted to the
Court of Sub Divisional Judicial Magistrate, Deoghar to proceed further
and pass fresh order in accordance with law.
 This criminal miscellaneous petition is, thus, allowed.
