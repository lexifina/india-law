01. 1. This matter is taken up through Hybrid Arrangement (Virtual
/Physical Mode).
2. This Contempt Petition is filed alleging violation of the
Court’s order dated 13.03.2023 passed in W.P.(C) No.5925 of 2023.
3. Mr. P.K. Parhi, learned DSGI submits that the CONTC has
been filed for implementation of order dated 13.03.2023 passed in
W.P.(C) No.5925 of 2023 and he seeks some time to file affidavit in
the matter. However, he submits that the order passed by this Court
has already been implemented by the Opposite Parties/Contemnors.
4. In such view of the submission, the Contempt Petition stands
dropped.
5. Further this Court grants four weeks time to the petitioner to
implement the order, if the same has not been already implemented
by the Opposite Parties/Contemnors. Liberty it granted to the
