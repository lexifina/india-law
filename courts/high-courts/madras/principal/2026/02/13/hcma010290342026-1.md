ORDER
It is seen from the typed set of papers that the first petitioner is not
represented by the second petitioner, namely Vijayalakshmi before the Trial
Court. Therefore, if the first petitioner wants to file the civil revision petition
through his power agent, the second petitioner herein, he has to file an
appropriate application seeking to recognise the power of attorney. Hence, this
petition to accept the cause title is not maintainable.
2. Accordingly, this petition is dismissed with liberty to file an
appropriate application to recognise the power of attorney.
