A.N. JINDAL, J. (Oral)
Heard learned counsel for the parties.
Both the parties have no objection to the setting aside of the
impugned order with a direction to the trial court to pass a fresh speaking
order on the application filed under Order 6 Rule 17 of the Code of Civil
Procedure because the impugned order contains some part of the proposed
amendment and it is not clear from the order as to what extent the
amendment has been allowed.
Consequently, the impugned impugned order is set aside, the
trial court is directed to pass a fresh speaking order on the application filed
under Order 6 Rule 17 of the Code of Civil Procedure.
November 8, 2012 (A.N. JINDAL)
