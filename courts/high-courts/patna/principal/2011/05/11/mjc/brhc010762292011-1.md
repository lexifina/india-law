2. 11.05.2011 Heard learned counsel for the petitioner.
No one appears on behalf of the State.
Present application has been filed seeking restoration
of CWJC No. 2014 of 2005 which was dismissed for non-prosecution on 15.03.2011. It appears that aforesaid writ
application earlier stood dismissed for non-prosecution by order
dated 22.02.2006. Subsequently, it was restored by order dated
14.02.2011. This Court granted three weeks time to file affidavit
bringing on record relevant pleadings supported by documents
failing which the application was to be rejected without further
reference to a Bench. The matter was again taken up on
15.03.2011 when this Court noticed the previous order and that
the marginal notes disclosing non filing of the supplementary
affidavit as per order dated 14.02.2011.
Accordingly, this Court held that in view of the
aforesaid position no fresh order was required to be passed as
present application already stood rejected for non-compliance of
order dated 14.02.2011. The petitioner has not been able to
satisfy the court about the circumstances which prevented him

2
from filing supplementary affidavit within time granted under
order dated 14.02.2011.
This Court, thus, finds no merit in this writ
application which is accordingly, dismissed.
The petitioner, if so advised, may file fresh
application.
 Devendra/ ( K.K. Mandal, J.)
