ORAL ORDER
3 28-03-2017 Heard the learned counsel for the petitioner and the
learned counsel for the respondents.
This review application has been filed by the petitioner
for review of the order dated 02.02.2017 passed in civil
miscellaneous whereby this court while dismissing the civil
miscellaneous application imposed cost of Rs.10,000/- to the
petitioner.
So far the review application is concerned, no ground for
interference in review jurisdiction is made out as the quantity of
the cost imposed cannot be interfered with in review application.
Thus, this review application is dismissed.
Saurabh/-
