# High Court of Madhya Pradesh, MCRC/6041/2015, 2015-08-26

MCRC No.6041/2015
26.08.2015
Shri Himanshu Thakur, counsel for the applicant.
Shri Yogesh Mittal, counsel for the
respondent/State.
This is second application under section 439 of
Cr.P.C filed by the present applicant. His first application
was dismissed on merit in MCRC No.2923/2015 vide
order dated 22.04.2015.
This second application is filed on the ground that
present applicant is in jail for the last four and half
months. He is a student and the alleged forged I.D.
created by present applicant was not misused for any
illegal purpose. Counsel for the applicant submits that
charge-sheet has been filed.
Counsel for the State opposes the application.
After going through the case diary, it is apparent
that no subsequent event has taken place and the earlier

application was dismissed on merit.
Accordingly, there is no ground for considering this
second application. The application is hereby, dismissed.
C.c. as per rules.
(Alok Verma)
 Judge
