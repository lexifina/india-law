2. Learned APP submits that the petitioner has an alternative
efficacious remedy to file a discharge application before the trial
Court. Learned APP, on instructions, fairly submits that as far as
SC/ST Act is concerned, in the chargesheet, there is no material to
show that the aforesaid petitioner uttered any abuses in the name of
complainant’s caste.
3. In view of the objection raised by the learned APP with
respect to an alternative remedy, learned Counsel for the petitioner
seeks leave to withdraw with liberty to file a discharge application.
4. Since there is an alternative remedy, available to the
petitioner, we deem it appropriate to relegate the petitioner to the
trial Court. It is open for the petitioner to file a discharge application
before the trial Court. The petition is accordingly disposed of as
withdrawn with liberty as prayed.
5. If an application for discharge is filed, the learned Judge,
to decide the same on its own merits, in accordance with law,
