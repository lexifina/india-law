Criminal Application No.642/2011, which was
dismissed for default on 30/1/2013.

served on the Counsel for respondent no.2 as stated
by learned Counsel for applicant and

the application for restoration, namely, reasons for
non filing of second set of criminal application due
to fault of Advocate, we are inclined to allow this
criminal application. Accordingly, criminal
application is allowed and disposed of. Criminal
Application No.642/2011 is restored.
The learned Counsel for the applicant
states that second set of criminal application has
already been filed. Office to proceed.
