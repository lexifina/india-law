# High Court of Madhya Pradesh, WP/18282/2017, 2017-11-03

THE HIGH COURT OF MADHYA PRADESH
WP-18282-2017
(RAMASHANKAR DWIVEDI Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 03-11-2017
Shri Rajendra Yadav, learned counsel for the
petitioner.
Shri Vikram Johri, learned Panel Lawyer for the
respondents/ State.
After arguing for some time and unable to convince
this Court as it is apparent that the petitioner had
participated in the said election which he has sought to
challenge, petitioner's counsel prays for withdrawal of
this petition with liberty to file Election Petition, if it is so
permissible.
Accordingly, this petition is dismissed as withdrawn
with the aforesaid liberty.
(VIVEK AGARWAL)
JUDGE
@PK
