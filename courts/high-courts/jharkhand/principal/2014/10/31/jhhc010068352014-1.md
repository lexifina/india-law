Rasool Mian @ Md Rahul @ Rahul Amin .... Petitioner(s)
Versus
State of Jharkhand ... Opposite Party
Coram : HON’BLE MR. JUSTICE RAVI NATH VERMA
For the petitioner (s): Mr. Ashraf Ansari
For the opposite party : Addl.P.P.
For the informant : Mr. Afaque Ahmad
31.10.2014 After some arguments, learned counsel
appearing on behalf of the State submitted that process under
section 82 of the Code of Criminal Procedure has already been
issued against this petitioner and this application is not maintainable.
Learned counsel for the informant is present.
In the aforesaid facts and circumstances of the
case, the counsel for the petitioner seeks permission to withdraw
this application.
This application is, accordingly, dismissed as
withdrawn, as prayed for.
Ambastha/- ( R.N.Verma, J. )
