# Madras High Court, COMP.A/351/2024, 2024-10-28

Comp.A.No.351 of 2024
K.KUMARESH BABU,J.
The present application has been
filed seekng to condone the delay of 171 days in
filing the application to set aside the order
passed in C.P.No.254 of 2012 dated 08.03.2024
2. Mr.A.K.Myilsamy & Associates,
learned counsel appearing on behalf of the
respondent would vehemently oppose the
application contending that the same is without
any merits.
3. Heard both sides.
4. Considering the averments made in
the accompanying affidavit filed in support of
this application and having been satisfied with
the reasons stated therein, the delay of 171 days
in filing the application to set aside the order
passed in C.P.No.254 of 2012 dated 08.03.2024
is condoned and the application is ordered as
prayed for.
Gba 28.10.2024
Note: Registry is directed to number the
application application to set aside the order
passed in C.P.No.254 of 2012 dated 08.03.2024
and list the same next week.
