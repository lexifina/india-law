# High Court of Madhya Pradesh, MCC/1256/2015, 2015-07-16

MCC-1256-2015
(JABALPUR DIVISION BALLAST ASSOCIATION Vs UNION OF INDIA)
16-07-2015
Shri T.S. Ruprah, learned Senior Advocate with Shri
Sourabh Sundar, learned counsel for the applicant.
Shri Atul Choudhury, learned counsel for the
respondents.
This application has been filed for restoration of Writ
Petition No.1479/2015, which has been dismissed for
want of prosecution on 21.4.2015.
The application has been filed indicating various
reasons for the default on the part of the counsel.
The application is supported by an affidavit of the
Advocate representing for the applicant and finding
of the same to be bona fide. The application is
allowed. Writ Petition No.1479/2015 is restored to
its original file.
Accordingly, MCC is allowed and disposed of.
(RAJENDRA MENON)
JUDGE
(SUSHIL KUMAR GUPTA)
JUDGE
