This application has been filed to set aside the order dated
30.08.2019, in A.No.6133 of 2019.
2. When the matter came before the Court on last hearing,
the learned counsel for the respondent stated that he has no objection.
But, today there is no representation for the said counsel. Since the
application is filed to set aside the order dated 30.08.2019 in
A.No.6133 of 2019 for not filing the condone delay application was
dismissed. Since the written statement filed within 45 days, the order
is set aside.
3. Registry is directed to take written statement on record
and list the matter on 18.10.2019 for admission and denial of
documents.
