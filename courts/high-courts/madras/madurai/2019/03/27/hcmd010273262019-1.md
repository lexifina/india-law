ORDER
The petitioner wants this Court to direct the first respondent
to issue passport to him. The petitioner submitted an application
in the year 2017. Since the petitioner did not appear for the
interview, the file got closed on 01.11.2017. The petitioner is
given liberty to submit a fresh application for issuance of
passport.
2. It is stated that a criminal case is pending against the
petitioner at the FIR stage. It is made clear that mere pendency
of a criminal case at the FIR stage, is not a bar for issuing
passport. If the petitioner fulfils all the other formalities, the
first respondent shall process the petitioner's application and
issue passport to him as expeditiously as possible.
https://hcservices.ecourts.gov.in/hcservices/

2
3. Therefore, the order impugned in this writ petition dated
01.11.2017 issued by the first respondent is set aside and this
Writ Petition stands allowed. No costs.
