# Allahabad High Court, /7068/2016, 2023-08-10

Neutral Citation No. - 2023:AHC-LKO:53488
Court No. - 28
Case :- APPLICATION U/S 482 No. - 7068 of 2016
Applicant :- Dhirendra Singh Rawat
Opposite Party :- State Of U.P. And Anr.
Counsel for Applicant :- Apoorva Tewari,Atul Verma,Hari Krishna
Verma,Rajat Singh
Counsel for Opposite Party :- Govt. Advocate
Hon'ble Shree Prakash Singh,J.
Heard learned counsel for the applicant, Sri Aniruddh Kumar
Singh, learned A.G.A.-I for the State and perused the material
placed on record.
Instant application has been filed with the prayer to set aside the
order dated 7.10.2016 passed by the Additional Chief Judicial
Magistrate (1st), Court No.25, Lucknow in Complaint Case
No.1131/151991/15 whereby non-bailable warrant has been
issued against the applicant and also to set aside summoning
order dated 8.6.2016 and criminal proceedings in the
aforementioned complaint.
Learned counsel for the applicant submits that this Court has
been pleased to pass the order dated 31.7.2023 in Application
U/S 482 No.7322 of 2023 wherein the order dated 8.6.2016 has
been set aside. He submits that present applicant is co-accused
in Complaint Case No.1131/151991/15 and thus, the identical
relief may be granted to the present applicant in the instant
application.
Learned counsel for the State submits that since this Court has
already passed the order dated 31.7.2023 whereby the order
dated 8.6.2016 has already been set aside, therefore, now, there
is no question at all to again set aside the said order, which has
already been set aside by this Court.
Having heard learned counsel for the parties, it transpires that
order dated 8.6.2016 which is impugned in this application, has
already been set aside, in Application U/S No. 7322 of 2023,
thus, it is not required to further set aside the same order.
In view of the aforesaid, instant application is also decided in
terms of the order dated 31.7.2023 passed in Application U/S
482 No.7322 of 2023.
Instant application is disposed of accordingly.
