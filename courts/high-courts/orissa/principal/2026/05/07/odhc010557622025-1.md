 ORDER
 07.05.2026
This Intra-Court appeal seeks to call in question the order
dated 27.08.2024, whereby the Appellant’s W.P.C(OA) No.151
of 2017 was dismissed as withdrawn. Subsequently, an
application was moved seeking recall of the said order so that the
petition was restored to the board and heard on merits. That
application came to be rejected vide order dated 15.07.2025 by a
learned Single Judge of this Court. That order is also put in
challenge before us.
2. Both the sides standing tall at the Bar very fairly submit
and we agree that the orders in question should be invalidated so
that application for recall is favoured and main matter itself is
heard by learned Single Judge on merits, keeping open all
contentions of the parties.
Ordered accordingly and Writ Appeal is allowed.
Impugned orders are set at naught. Appellant’s application in I.A.
