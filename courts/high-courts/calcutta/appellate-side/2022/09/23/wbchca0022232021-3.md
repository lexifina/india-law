# Calcutta High Court, CRR/105/2021, 2022-09-23

23.09.2022
S/L No.24
KS
 C.R.R. 105 of 2021
 Rambilas Gupta @ Shaw
 -Vs.-
 The State of West Bengal & Anr.
Mr. Mahendra Prasad Gupta
Ms. Antara Panja
 ….. For the Petitioner
The subject-matter of the revisional application relates to an order
dated 14th December, 2020 passed in M.P. Case No.1017 of 2020 by the Learned
Executive Magistrate, 1st Court at Howrah under Section 144(2) of the Code of
Criminal Procedure.
Records of this revisional application reflect that the prayer which was
before the Learned Executive Magistrate related to a shop room.
Having regard to the issues which can be considered under Section 144
of the Code of Criminal Procedure, I am of the opinion that the dispute
referred to is purely private and personal in nature and there is no
involvement of public law and order calling for an order under Section 144 of
the Code of Criminal Procedure. The application and the order is of
December, 2020. By efflux of time, the same has become infructuous.
Accordingly, M.P. Case No.1017 of 2020 before the Learned Executive
Magistrate is deemed to be infructuous.
Thus, the revisional application being, CRR 105 of 2021 is dismissed as
infructuous.
Pending applications, if any, are consequently disposed of.
All parties are directed to act on the server copy of this order
downloaded from the official website of this Hon’ble Court.
