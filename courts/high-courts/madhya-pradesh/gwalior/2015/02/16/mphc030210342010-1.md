# High Court of Madhya Pradesh, WP/6883/2010, 2015-02-16

WP No. 6883/2010 [Rajendra Singh Vs. State of MP]
16/02/2015
 None for the petitioner.
 Shri Praveen Niwaskar, Government Advocate for
the respondents/ State.
Heard.
In this petition, the petitioner has challenged the
order dated 10-11-2010( Annexure P/1).
This Court on 24/11/2010, stayed the effect and
operation of the said order. The said interim order is
still prevailing.
Considering the aforesaid, I deem it proper to set
aside the order and give liberty to the respondents to
pass a fresh order if administrative exigency so
requires. I do so because the administrative exigency
which was prevailing in 2010, must be over by now.
Consequently, the impugned order Annexure P-1
is set aside by reserving the aforesaid liberty.
With the aforesaid, petition stands disposed of.
 (Sujoy Paul)
Judge
