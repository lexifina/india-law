Order No:-05 Dated:-31-07-2024
I.A. No.9763 of 2023
 Heard the parties.
 Learned counsel for the petitioner submits that this interlocutory
application has been filed with a prayer to withdraw this Criminal
Miscellaneous Petition with liberty to file a fresh application under Section 482
if required in later stage. Hence, the petitioner does not want to proceed with
the Criminal Miscellaneous Petition at this stage.
 Considering the aforesaid facts, this Criminal Miscellaneous Petition is
dismissed as withdrawn with liberty to file a fresh application in the later stage,
if necessary.
 Accordingly, this interlocutory application is disposed of.
