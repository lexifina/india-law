Heard Shri S.V. Sirpurkar, Advocate for the
applicant, Shri H.R. Dhumale, Additional Public
Prosecutor for the non-applicant and Shri H.P. Lingayat,
Advocate for the complainant (intervenor).
The learned Advocate for the applicant has
submitted that the applicant has filed an application
under Section 482 of the Code of Criminal Procedure
praying that the First Information Report registered
against the applicant be quashed. It is submitted that the
Division Bench of this Court has granted an interim order
restraining the non-applicant from taking coercive action
against the applicant. It is submitted that the application
filed by him under Section 482 of the Code of Criminal
Procedure is pending.
In view of the above, in my view, the present
application need not be entertained. It is disposed with
liberty to the applicant to move fresh application, if so
advised and if occasion arises.
