# High Court for the State of Telangana, CRLP/16022/2016, 2016-11-16

HONOURABLE SRI JUSTICE M.SATYANARAYANA MURTHY
CRIMINAL PETITION No.16022 OF 2016
ORDER:
 Today, when this matter has come up for hearing, learned
counsel for the petitioners sought permission of this court to
withdraw this Criminal Petition with a liberty to file appropriate
application before the competent court as per law.
 Permission is accorded.
 Accordingly, this Criminal Petition is dismissed as withdrawn
granting liberty to file appropriate application before the competent
court as per law.
 As a sequel to the disposal of this petition, the Miscellaneous
Petitions, if any, pending, shall stand dismissed.
__________________________________
 JUSTICE M.SATYANARAYANA MURTHY
Dated 16-11-2016.
