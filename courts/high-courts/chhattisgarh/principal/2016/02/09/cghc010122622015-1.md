# High Court of Chhattisgarh, MCC/32/2016, 2016-02-09

HIGH COURT OF CHHATTISGARH, BILASPUR
Order Sheet
MCC No. 32 of 2016
State Of Chhattisgarh Versus Iqbal Ahmed
09/02/2016
Ashu
Shri Shashank Thakur, GA for the State/applicants.
Heard.
After hearing learned counsel for the applicants, the
default No.1 is overruled. The default No.2 is about filing of
application for condonation of delay although no limitation
is provided for moving an application for extension of time.
For this default learned State counsel would submit that an
application seeking withdrawal of I.A. No.1/2016 has
already been preferred.
On due consideration I.A. No.2/16 for withdrawal of
I.A. No.1/16 is allowed. Consequently, default No.2 also
stands removed.
After hearing learned State counsel, the MCC is
heard finally.
Order passed separately.
Sd/-
Judge
Prashant Kumar Mishra
