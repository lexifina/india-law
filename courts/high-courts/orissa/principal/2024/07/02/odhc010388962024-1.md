1. This matter is taken up through Hybrid
Arrangement(Virtual/Physical) Mode.
2. Heard learned counsel for the parties.
3. Since for the self-same relief, Petitioner had earlier
approached this Court in W.P.(C ) No.35915 of 2023 and this

Writ Petition with similar prayer is not entertainable.
4. However, it is open for the Petitioner to file appropriate
application in the disposed of Writ Petition.
5. With the aforesaid liberty, the Writ petition is disposed
of.
