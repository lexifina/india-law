JUDGMENT
Ext.P5 is an order by which the application for condonation
of delay in filing the application for restoration of the suit was
dismissed. Consequently, Ext.P6 order was passed dismissing the
application for restoration of the suit.
2. The suit was dismissed for default. If so, the application
for restoration should be filed under Order IX Rule 9 of the Code
of Civil Procedure. Dismissal of the application under Order IX
Rule 9 of the the Code of Civil Procedure is appealable under
Order 43 Rule 1(c) of the Code of Civil Procedure. Since an
appeal is maintainable, the Original Petition is not maintainable.
Accordingly, the Original Petition is dismissed with liberty to the
petitioner to file appeal against the order impugned.
K.T.SANKARAN,
 JUDGE.
