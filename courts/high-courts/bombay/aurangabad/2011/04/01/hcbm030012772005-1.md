PER COURT:
This is an application for recalling the order passed by this
Court on 17.12.2004 dismissing the Civil Revision Application in default
and for condonation of delay, if any, in presenting the Civil Application.
Heard learned Counsel for the applicant. None appears for
Respondent No.2, though served. For the reasons stated in the
application, application deserves to be allowed and same is accordingly
allowed. The order dated 17.12.2004, passed by this Court, dismissing
the Civil Revision Application in default, is recalled and Civil Revision
Application is restored to its original number. Delay, if any, stands
condoned.
