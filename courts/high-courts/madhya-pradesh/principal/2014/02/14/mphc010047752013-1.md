# High Court of Madhya Pradesh, MCC/141/2013, 2014-02-14

M.C.C. No. 141/2013.
1
(Lekhan Singh Shivvedi Vs. State of M.P. & others.)
14/02/2014.
None for the applicant.
Shri Rahul Jain, Deputy Advocate General for
the respondents/State.
This application has been filed for restoration
of W.P. No.16368/2007, which has been dismissed in
view of the peremptory order passed on 06/08/2012.
Keeping in view reasons indicated in the
application supported by affidavit of the applicant
himself finding the same to be bona fide, the application
is allowed. W.P. No.16368/2007 is restored to its
original file and list before the appropriate Bench.
A copy of this order be kept in the original
file of W.P. No.16368/2007.
With the aforesaid observation, this
application stands allowed and disposed of
.
(Rajendra Menon)
 Judge
