 4. Smt. Nanditapur Haldipur, learned counsel
appearing for the respondent – authorities submits that,

Foundation having held at para No.83A as
unconstitutional, the impugned orders levying damages
and interest, which are determined on the PF contributions

which needs to be set aside and this Court pass the
