 After making his submissions for some time,
learned Counsel for the petitioner submits that it appears
that subsequent application filed by the petitioner under
Order 7, Rule 14 of the Code of Civil Procedure was
erroneously filed as such an application filed by the
petitioner, praying for the same relief, stood allowed by the
learned Trial Court vide order dated 15.11.2013.
 In view of the submissions so made by learned
Counsel for the petitioner, this petition is disposed of by
permitting the petitioner to withdraw the application which
was filed by him before the learned Trial Court under Order 7,
Rule 14 of the Code of Civil Procedure. As a result thereof, the
