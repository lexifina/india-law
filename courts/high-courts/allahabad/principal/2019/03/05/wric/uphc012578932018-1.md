# Allahabad High Court, WRIC/43583/2018, 2019-03-05

Chief Justice's Court
Case :- WRIT - C No. - 43583 of 2018
Petitioner :- Abbhan Singh
Respondent :- State Of U P And 4 Others
Counsel for Petitioner :- Shobh Nath Pandey,Shrawan Kumar
Pandey
Counsel for Respondent :- C.S.C.
Hon'ble Govind Mathur,Chief Justice
Hon'ble Saurabh Shyam Shamshery,J.
For the same cause of action, the petitioner preferred a Public
Interest Litigation No.1747 of 2018. The Public Interest
Litigation aforesaid came to be dismissed as not pressed on
12.1.2018, without having any liberty to file a fresh. For the
same cause of action, the instant petition for writ has been
filed.
Looking to the fact that for the same cause, the petitioner has
approached this Court earlier, we are not inclined to entertain
this petition for writ.
The writ petition is dismissed.
Order Date :- 5.3.2019
SB
(Saurabh Shyam Shamshery,J) (Govind Mathur,C.J)
