ORDER
 This review petition is filed seeking review of the
order dated 20.01.2022 passed in W.P.No.8043/2021.
 2. Sri A.V.Gangadharappa, learned counsel
appearing for the petitioner has contended that in para 3
of the order, he has not made a submission that ‘in future,
if there is any site available, the petitioner’s application for
allotment of site will be considered in accordance with law’,
but he has only made a submission that ‘in future, if there
is any notification calling for applications for allotment of
sites from the general public, the petitioner’s application

3
will be considered in accordance with law’. He further
submits that pursuant to the directions of this Court, his
application has been considered and an endorsement has
been issued.
3. In view of the above, the order dated 20.01.2022
is clarified only in respect of para 3 where the submission
of Sri A.V.Gangadharappa, learned counsel for the
petitioner has been considered as ‘ in future, if there is any
notification calling for applications for allotment of sites
from the general public, the petitioner’s application will be
considered in accordance with law’.
Accordingly, review petition is disposed of.
