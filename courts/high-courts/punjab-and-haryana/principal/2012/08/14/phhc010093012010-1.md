A.N. JINDAL, J. (Oral)
Vide order dated 14.3.2009, the applicants mentioned in the
application dated 16.2.2008 were ordered to be impleaded as plaintiffs in
place of Parbhjot Kaur and except this order, there is no order on record
which may allow the plaintiffs to implead Gurpartap Singh as defendant
No.6. Therefore, vide impugned order dated 31.5.2010, the name of
defendant No. 6 Gurpartap Singh was struck off.
This revision is not maintainable, as such, the same is
dismissed with liberty to the plaintiffs, if they want to implead Gurpartap
Singh as party defendant they would be at liberty to file an application
afresh before the trial court.
August 14, 2012 (A.N. JINDAL)
