impugned directed the amounts in fixed deposits to be
released to the depositor/first respondent. The judgment
inter alia states as follows:
“6. x x x x x x x x x x x x x x x x x

petitioner would submit that that
petitioner has no objection in this Court
granting a reasonable time to the 1st
respondent Bank for repayment of the

2. The period of nine months requested for

expired. We do not wish to interfere with the judgment of
