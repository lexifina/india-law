# High Court of Madhya Pradesh, MCC/1718/2015, 2015-07-09

M.C.C.NO.1718/2015

09-07-2015.
 Shri Amit Kumar Singh, learned counsel for the applicants.
 This application has been filed for restoration of
W.P.No.7585/2015, which has been dismissed for want of
prosecution.
 Keeping in view the reasons given in the application which
is supported by an affidavit of the counsel himself and finding
the same to be bonafide, this application is allowed.
W.P.No.7585/2015 is restored to its original file and the same be
listed for hearing before an appropriate Bench.
 Accordingly, this application stands allowed and disposed
of.
 (RAJENDRA MENON) (SUSHIL KUMAR GUPTA)
 JUDGE JUDGE
