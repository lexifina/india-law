# High Court of Madhya Pradesh, MCRC/9425/2017, 2017-08-30

MCRC-9425-2017
(RAHUL Vs THE STATE OF MADHYA PRADESH)
30-08-2017
Shri Vinod Thakur, learned counsel for the applicant.
Shri Hemant Sharma, learned counsel for the
respondent/State.
This application under Section 482 of Cr.P.C. is filed for
modification of the order passed by this Court in
Cr.A.No.783/2017 dated 23.08.2017.
In the order crime number is mentioned as 323/2016 while
actual crime number is 332/2016.
After due consideration, the application is allowed. In the
aforesaid order, crime number may be read as 332/2016 in
place of 323/2016.
With the aforesaid modification, this application stands
disposed of.
C.C.as per rules.
(ALOK VERMA)
JUDGE
