The applicant is an accused in Crime No.20/2019 before the Anti-Narcotic Cell Police Station, Panaji, Goa. On 23.01.2020, this Court
granted the applicant a conditional bail. Now, the applicant has come up
with this modification application. As the learned counsel for the
applicant puts it, this Court directed the applicant to execute the bail
bond for Rs.1,00,000/- and one local surety for the same amount to the
satisfaction of the learned Additional Sessions Judge, Mapusa. But it
ought to be, according to him, to the satisfaction of the learned Sessions
Judge, Panaji, because that is the jurisdictional Court.

 2 CRMA95-20dt.23.04.2020
2. Though the learned Addl. Public Prosecutor has not objected to
this modification, he has nevertheless drawn my attention to the
application filed for correction. He has insisted that it contains many
contentious issues which need not be gone into at this stage.
3. I reckon it is an application for having the name of the
jurisdictional court changed. And to that extent, the prosecution has no
objection. So the application is allowed to that extent.
4. At any rate, as insisted by the learned Addl. Public Prosecutor, I
clarify that this order is simply confined to the correction the applicant
has sought as to the jurisdictional Court, and nothing else.
The application stands disposed of.
