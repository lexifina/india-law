# High Court of Madhya Pradesh, MCRC/5124/2012, 2012-07-20

-1-
M.Cr.C.NO.5124/12
20.07.2012:
Shri J.Bajpai, learned counsel for the applicant.
Shri M.Kumawat, learned Panel Advocate for the
respondent/State.
Heard.
This is a repeat application for bail. The earlier
application for bail of the same applicant was considered and
rejected by this Court on 22.06.2011. After the said order,
there has been no change in the circumstances so as to take a
different view. Trial is still pending. I find no ground to
entertain the subsequent application and release the applicant
on bail. Accordingly, the application stands rejected and
closed.
 (S.K.SETH)
 JUDGE
