The Court made the following:
ORAL ORDER:
 Heard Ms. Yogita Prakash, learned Counsel appearing online on behalf
of Sri T.S. Praveen Kumar, learned Counsel for the Writ Petitioners and Ms.
Ch. Naga Jyothi, learned Counsel appearing on behalf of Sri M. Krishna Rao,
learned Standing Counsel for Municipal Corporation.
2. When this Writ Petition was listed on 30.03.2026, this Court had granted
time to the learned Counsel for the Writ Petitioners to obtain clear instructions
whether the cause survives or not. Learned Counsel appearing online for the
Writ Petitioners would submit that the Writ Petitioners are unable to render
any instruction and therefore, makes a request to close this Writ Petition due
to ‘no instruction from the Writ Petitioners’.
3. Having recorded the same, this Court deems it appropriate to dismiss
this Writ Petition for Non-prosecution/no instructions. However, liberty is
granted to the Writ Petitioners to file a Restoration Application within a period
of four (4) weeks from today for restoring this Writ Petition if there is any
cause of action in this Writ Petition. It is clearly indicated that if the Writ
Petitioners does not file an Application to this effect within the time granted, it
shall be deemed that the cause of action does not survive in this Writ Petition.
4. Registry is directed to retain the record for a period of four weeks. If
Restoration Application is not filed within the time granted, Registry is given
liberty to destroy the record as per the existing rules.
5. With the above observations, this Writ Petition is dismissed for
Non-prosecution. No order as to costs.
