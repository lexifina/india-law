Dharam Chand Chaudhary, J.(Oral):

 The complaint is that the defence of the
petitioner-defendant has abruptly been struck off vide order
Annexure P-5. An application under Section 151 of the
Code of Civil Procedure filed thereafter for seeking
permission to file the written statement is also disposed of
vide order Annexure P-8. Without entering upon the merits,
this Court feels that in case the petitioner-defendant is not
allowed to file written statement, he may be condemned

appropriate to allow only one opportunity to the petitioner-defendant to file written statement on the next date, i.e., 3rd

On his failure to file the written statement on the date so
fixed also, his defence will stand struck off.

applications, if any, shall also stand disposed of.
