CORAM : T.V. NALAWADE, J.
DATED : 4th March, 2016.
ORDER :
1. The application is filed for setting aside the the order
made by the Registrar and restoration of the matter. Heard the
learned counsel Shri. D.A. Mandake h/f. Mr. M.S. Mulkarni for
original claimant. In view of the contents of the application,
submissions made and as the counsel is taking blame to himself,
this Court holds that the order needs to be set aside. The
application is filed in time. So, the application is allowed. The
order of dismissal is set aside. Appeal is restored.
2. Objections are to be removed prior to 23.3.2016. If
the objections are not removed prior to 23.3.2016, matter shall
stand dismissed automatically without back reference to the
Court.
 [ T.V. NALAWADE, J. ]
