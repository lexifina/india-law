ORAL ORDER
3 06-03-2018 Heard.
After some argument, learned counsel for the petitioner
seeks permission to withdraw this application in order to file
appeal before the State Appellate Authority as the State Appellate
Authority is now functional since the petitioner wants to avail the
remedy of appeal as the writ petition was filed on 11-01-2016 and
the same remained pending in this court for more than two years.
In the event, the petitioner files appeal before the State
Appellate Authority within one month from today along with copy
of this order, the State Appellate Authority will examine the
appeal on its own merit in accordance with law after condoning
the delay if any in filing of appeal in view of the fact that the writ

With the aforesaid observation, this writ application is
