# High Court of Himachal Pradesh, CMPMO/307/2017, 2019-07-05

CMPMO No. 307 of 2017
05.07.2019 Present: None.
In the previous order, there is a reference of order dated
28.1.2018, whereas it should have been 28.12.2018. This typographical
mistake is ordered to be corrected with observation that date mentioned
as 28.1.2018 be read as 28.12.2018 and therefore, it is clarified that
petition stands dismissed for non-prosecution in view of order dated
28.12.2018.
July 05, 2019 (Vivek Singh Thakur)
 (ms) Judge
