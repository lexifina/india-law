 CORAM : M.T. JOSHI, J.
 DATE : 24/03/2015
ORAL ORDER :
1. None appears for the applicant.
2. Vide order dated 17/12/2014, the application is
already dismissed as regards respondent no.1-original
accused in a proceeding under section 138 of the
Negotiable Instruments Act.
3. Aggrieved by the dismissal of the private
complaint, application for leave to file appeal is
filed, in which the present application seeking
condonation of delay in filing the aforesaid application
is preferred.

 2 Cr. Appln. 1204/2014
4. In absence of the original accused, the present
application cannot proceed. In the circumstances, the
Criminal Application no. 1204 of 2014 seeking delay
condonation is dismissed. Consequently, Criminal
Application no. 1203 of 2014 seeking leave to file
appeal does not survive and the same is also disposed
of.
[M.T. JOSHI]
 JUDGE
