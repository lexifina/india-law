# High Court of Rajasthan, CRLR/514/2014, 2014-04-28

S.B. Criminal Revision Petition No.514/2014
S.B. Cr. Misc. Stay Application No.1547/2014
(Ram Lal Versus The State of Rajasthan)
Date of Order :: 28th April, 2014
 HON'BLE MR. JUSTICE MAHESH CHANDRA SHARMA
Mr. Ali Mohd. Khan, counsel for the petitioner
Mr. R.R. Baisla, PP for the State
This petition has been filed against the judgment dated
22.3.2014 passed by Sessions Judge, Baran in Cr. Appeal No.
93/2013.
I have heard learned counsel for the petitioner as well as
learned PP for the State and carefully perused the relevant material
on record including the impugned judgment.
The only request which has been made by learned
counsel for the petitioner is that Rs. 5000/-, which has been
imposed upon the petitioner by the court below and deposited by
him, should be refunded back to the petitioner.
Learned PP appearing for the State has opposed the
same.
The prayer of the learned counsel for the petitioner
seems to be genuine, hence the court below is directed that if the
petitioner has deposited Rs. 5000/- with him, the same should be
refunded to him upon an application being moved by him in this
regard.
The Cr. Revision Petition as also the stay application,
both stand disposed of with the aforesaid direction.
 (Mahesh Chandra Sharma)J.
