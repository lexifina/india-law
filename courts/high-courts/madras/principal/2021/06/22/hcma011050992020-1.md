# Madras High Court, A/2592/2020, 2021-06-22

1
Application No.2592 of 2020
N.SATHISH KUMAR,J. ,
 This application has been filed to
direct the respondents to furnish
security for a sum of Rs.13.71,373.83
within the time fixed by this Court,
failing which pass an Order of
attachment of the immovable property
mentioned in the Judges summons.
2. It is submitted by the learned
counsel appearing for the applicant that
the arbitration proceedings has already
been initiated and the same is pending.
3. In such view of the matter, this
Court is not inclined to pass any order
in this application and the applicant is
at liberty to seek the interim relief
before the learned arbitrator.
Accordingly, this application is closed.
