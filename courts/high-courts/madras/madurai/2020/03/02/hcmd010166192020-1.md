 ORDER
This Criminal Original petition has been filed against FIR.
2.When the matter was taken up for admission, the learned
Government Advocate (Crl.side) pointed out that final report has
been filed and the same has been taken on file as P.R.C.No.56 of
2019 on the file of the Mahila court/Fast Track Court, Sivagangai.
The next hearing date is 13.03.2020. It is for the petitioner to
challenge the final report that has been taken on file. I make it
clear that I have not gone into the merits of the matter. With
liberty to file a fresh petition, this Criminal Original Petition
stands dismissed. Consequently, connected miscellaneous petition
is closed.
