THE HONOURABLE SRI JUSTICE RAJA ELANGO
CRIMINAL REVISION CASE No.1706 OF 2012
ORDER:
Petitioner preferred the present Criminal Revision Case under
Sections 397 and 401 of the Code of Criminal Procedure challenging
the order dated 06.08.2012 passed in Calendar Case No.593 of 2006
whereby the learned Judicial First Class Magistrate, Kovvuru, while
dismissing the complaint filed by the petitioner herein acquitted A.1
and A.2 who are respondent Nos.1 and 2 herein.
Heard.
Evidently, the impugned order is passed acquitting the accused
persons as against which the remedy available to the petitioner-de
facto complainant is only to file an appeal but not a revision. Thus, the
petitioner erroneously preferred the present revision instead of an
appeal.
Hence, the present Criminal Revision case is dismissed with
liberty to the petitioner to prefer an appeal.
Registry is directed to return the material papers to the learned
counsel for the petitioner, if he so desires.
