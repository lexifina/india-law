# High Court of Madhya Pradesh, MCRC/9543/2015, 2015-08-31

MCRC-9543-2015
(LAKHAN SINGH Vs THE STATE OF MADHYA PRADESH)
31-08-2015
Shri S.D. Gupta, learned counsel for the applicant.
Shri A.N.Gupta, learned Panel Lawyer for the State.
Heard. This is an application for correction of the name
of Police Station in the array of the petition to previous order
dated 22.4.2015 passed in M.Cr.C. No.4863/2015.
Considering the averment made in the application, the
same is allowed.
Committal Court/Trial Court concerned is directed to
read name of Police Station Siddiqganj in place of Police
Station Ashta in order dated 22.4.2015 passed in M.Cr.C. No.
4863/2015.
Accordingly, the application is disposed of with the
aforesaid direction.
C.C. as per rules.
(G.S. SOLANKI)
JUDGE
