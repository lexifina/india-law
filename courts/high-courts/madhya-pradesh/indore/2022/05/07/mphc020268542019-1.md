This petition coming on for admission this day, the court passed the
following:
ORDER
This petition has been filed alleging non-compliance of order dated
03.04.2019 passed in W.P. No.14923/2018.
Learned counsel for the respondent has brought to the notice of this Court
the order dated 11.04.2022 passed in W.A. No.1710/2019 whereby the said appeal
has been allowed and the order dated 03.04.2019 has been set aside.
Since the order of which non-compliance has been alleged has itself been set
aside nothing further survives for determination in this petition which is accordingly
disposed off.
