# High Court of Madhya Pradesh, RP/891/2019, 2019-08-13

THE HIGH COURT OF MADHYA PRADESH
R.P. No.891/2019
(EZZAD MOHAMMAD Versus THE STATE OF MADHYA PRADESH)
Jabalpur, Dated: 13.8.2019
Shri Kabeer Paul, learned counsel for the petitioner.
Shri Saurabh Sunder, learned Government Advocate for the
respondent/State.
Heard on I.A. No.7947/2019.
This is an application for condonation of delay in filing the present
petition, which is barred by 36 days.
On due consideration, the same is allowed. The delay stands
condoned.
Heard.
This review petition has been filed for review/modification of the
order dated 24.4.2019 passed by this Court in W.P. No.14050/2017.
It is pointed out by the learned counsel for the petitioner that though
this Court has allowed the writ petition, however, has not mentioned that
the impugned order is set aside.
On perusal of the order dated 24.4.2019, this mistake is apparent.
Hence, it is directed that in the last para it should be read as “the impugned
order dated 29.7.2017 passed in Execution Case No.22/2016 is set aside
and the writ petition stands allowed in terms of the order passed in
Lakhan Lal (supra)”.
This order shall be read in conjunction with the order dated
24.4.2019.
In view of the aforesaid, this petition stands disposed of.

 (NANDITA DUBEY)
 JUDGE
