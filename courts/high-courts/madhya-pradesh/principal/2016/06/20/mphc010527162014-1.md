# High Court of Madhya Pradesh, WP/17797/2014, 2016-06-20

WP-17797-2014
(SURESH DAHIYA Vs THE STATE OF MADHYA PRADESH)
20-06-2016
Shri Shreyas Pandit learned counsel for the petitioner.
Ms. M.S. Chuckal, learned panel lawyer for the
respondent/State.
Shri Vinod Kumar Dubey, learned counsel for the caveator.
This petition has been filed arising out of the order of
transfer passed by the Commissioner, Directorate of
Panchayat Raj, Bhopal vide order Annexure P/3, dated
30.10.2014.
This Court vide order dated 19.11.2014 stayed the said order
which is still in operation and the reply has not yet been
filed.
After hearing learned counsel for both the parties, as the
stay order is in operation since last more than 1 ÃÂ½ years
and the reply has not been filed, therefore, keeping this
matter pending awaiting reply, do not appear to be
justifiable. However, in my opinion the order of transfer
deserves to be quashed with liberty to the State Government
to pass a fresh order if administrative exigency so arise.
With the aforesaid observation, this petition stands allowed
and disposed of quashing the order Annexure P/3.
The respondent/State is at liberty to pass a fresh order if
administrative exigency so arise.
Certified copy as per rules.
(J.K. MAHESHWARI)
