# Allahabad High Court, CRLA/2038/1979, 2018-05-24

Court No. - 27
Case :- CRIMINAL APPEAL No. - 2038 of 1979
Appellant :- Ram Chandra Mishra
Respondent :- State Of U.P.
Hon'ble Ifaqat Ali Khan,J.
Called in revise. None is present for appellant whereas learned
A.G.A., Sri Pankaj Saxena is present.
Perusal of record shows that vide order dated 02.03.1994 this
Criminal Appeal No. 2038 of 1979 (Ram Chandra Mishra vs.
State of U.P.) was dismissed for non prosecution. Recall
application is moved by applicant to recall the order dated
02.03.1994. This recall application is moved on 26.04.1996,
applicant has also moved the application to condone the delay
in filing of recall application but nobody is their to press the
Delay Condonation Application. There is no sufficient reason to
condone the delay.
Hence, Delay Condonation Application as well as recall
application dated 26.04.1996 are dismissed in default of
appellant. File be consigned.
Order Date :- 24.5.2018
Swati
