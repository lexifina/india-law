 CORAM : M.T. JOSHI, J.
 DATE : 23/02/2015
ORAL ORDER :
1. Heard both sides.
2. Learned counsel for the applicant submits that
under section 10 of the Contempt of Courts Act, this
Court can take suo-motu action and, therefore, seeks
recall of the order dated 21/01/2015 passed by this
Court.
3. It should be noted that there is a specific
provision for dealing with the grievance of the present
applicant. Order 39 Rule 2-A of the Code of Civil
Procedure is a complete Code in itself.

 2 CA-1380-2015
4. In the circumstances, there is no need to
recall the order dated 21/01/2015.
5. The civil application is therefore dismissed.
[M.T. JOSHI]
 JUDGE
