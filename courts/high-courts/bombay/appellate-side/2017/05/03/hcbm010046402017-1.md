FINAL ORDER :
1 The learned counsel for the respective sides submit on
instructions that the Aurangabad Bench of this Court has considered
an identical issue and has passed an order dated 25.08.2015 in Writ
Petition No.9958 of 2014 along with identical group of Petitions.
The impugned orders were accordingly set aside.

quashed and set aside.

representations alongwith the documents, if any,
within four weeks.
4. The Respondent to consider the same in
accordance with law, twelve weeks thereafter
and pass an appropriate order in accordance with
law.
