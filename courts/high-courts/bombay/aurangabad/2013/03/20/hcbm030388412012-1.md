ORAL JUDGMENT :
1. Rule. Rule made returnable forthwith. With the
consent of the parties, taken up for final hearing.

 2 W.P.10026.12
2. Application to add sisters as party in a suit for
partition and separate possession is rejected.
3. Shri Dhage, learned counsel for respondents
supports the order and submits that earlier
application filed by sisters to add them as party has
been rejected. As such, again request on behalf of
the plaintiff cannot be considered. According to the
learned counsel, the objection was raised by the
defendants in the written statement itself which is
filed in October, 2007. Still no steps were taken to
add the sisters as party. Provisions of Rule 17 of
Order VI of the Code of Civil Procedure permits to
amend the pleadings in the suit.
4. Provisions of Order 1 Rule 10 of the Code of
Civil Procedure provides for addition of necessary
party. It is suit for partition and separate
possession. It is trite that in a suit for partition
co-sharers are necessary parties. The parties who are
sought to be added as parties are the sisters.
Relationship is not disputed. In a suit for partition
every party is in position of plaintiff.

 3 W.P.10026.12
5. In light of the aforesaid facts, impugned order
is quashed and set aside. Application Exhibit 96 is
allowed.
6. Rule is made absolute accordingly. No costs.
