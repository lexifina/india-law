# High Court of Madhya Pradesh, MCC/1347/2017, 2017-05-08

MCC-1347-2017
(SMT. GINIYA BAI Vs THE STATE OF MADHYA PRADESH)
08-05-2017
Shri M.B. Shrivastava, learned counsel for the applicant.
This application has been filed for restoration of W.P.
No.5388/2017 which has been dismissed for want of prosecution
on 21.04.2017. The application is supported by an affidavit of
Advocate-M.B. Shrivastava.
Keeping in view the reasons indicated in the application, the MCC
is allowed and it is directed that W.P. No.5388/2017 be restored to
its original number and list this case before the appropriate Bench.
Let a copy of this order be kept in the file of W.P. No.5388/2017.
(SMT. ANJULI PALO)
JUDGE
