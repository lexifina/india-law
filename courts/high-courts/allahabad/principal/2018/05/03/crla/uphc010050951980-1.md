# Allahabad High Court, CRLA/2074/1980, 2018-05-03

Court No. - 48
Case :- CRIMINAL APPEAL No. - 2074 of 1980
Appellant :- Braham Singh
Respondent :- Janardan Swaroop
Hon'ble Ifaqat Ali Khan,J.
Called in revise.
This Crl. Misc. Application No. 2074 of 1980 was moved by
the applicant Braham Singh for the leave to file appeal against
the opposite party and the leave was granted to file appeal vide
order dated 13.2.1981. Thus this application has already been
finally disposed of on 13.2.1981 but it is wrongly showing as
pending. Hence this Crl. Misc. Application No. 2074 of 1980 is
disposed of accordingly. File be consigned.
Order Date :- 3.5.2018
