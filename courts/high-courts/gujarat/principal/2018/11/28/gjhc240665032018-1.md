ORAL ORDER
1. This is an application under Section 482 of the Code of Criminal
Procedure, 1973, the applicant is seeking quashment of First
Information Report being I-C.R. No.31 of 2016 registered with
Varnama Police Station, Dist. Vadodara, for the offences punishable
under Sections 143, 147, 148, 149, 307, 323, 504, 506(2) of the
Indian Penal Code read with Sections 25 (1-B) (a) and 27 of the Arms
Act.
2. Learned advocate Mr. Chirag B. Patel, appearing for the
applicant seeks permission to withdraw the present application with a
direction to the Court of learned Chief Judicial Magistrate First Class
to commit the matter under Section 209 of the Code to the Court of
Sessions within one week. Permission, as prayed for, is granted. This
application stands disposed of, as withdrawn with above liberty.
3. Once case is committed, let the applicant make a request to the
