Heard.
This is an application seeking condonation
of 133 days delay caused in filing application for
restoration of the First Appeal No.59/2014 which
was dismissed in default vide order dated
27/11/2018 passed by this Court.
For the reasons recorded in the aforesaid
application and finding them to be satisfactory, the
same is allowed. Delay of 133 days caused in filing
application for restoration of the First Appeal
No.59/2014 stands condoned.
The instant Civil Application accordingly
stands disposed of.
