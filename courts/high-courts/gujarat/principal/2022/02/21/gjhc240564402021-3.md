 Date : 21/02/2022
 ORAL ORDER
1. On 18.01.2022, this Court had passed the following order.
“This Court had, on 14.12.2021, directed the petitioner to
file additional affidavit for the reason mentioned therein.
Learned advocate Ms.Yogini Upadhyay, requests for
further time.
At her request, the matter is adjourned to 21.02.2022. If
no affidavit is filed, as directed by this Court in the order
dated 14.12.2021, the matter stands dismissed for non-prosecution.”
2. Today also, the said order remains uncomplied and
learned advocate Ms.Yogini Upadhyay, requests for some
more time in order to comply the order dated 18.01.2022.
In the order dated 18.01.2022, it was already clarified that
if no affidavit is filed as directed by this Court, in the order
dated 14.12.2021, the matter stands dismissed for non-prosecution. Hence, the matter stands dismissed for non-prosecution.
3. It is clarified that it will be open for the petitioner to
file restoration application producing such affidavit on
record.
(A. S. SUPEHIA, J)
