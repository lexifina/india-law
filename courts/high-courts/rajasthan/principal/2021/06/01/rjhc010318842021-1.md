HON'BLE MR. JUSTICE MANOJ KUMAR GARG
Order
01/06/2021
The instant misc. application has been moved for correction
of FIR number mentioned in order dated 28.05.2021 passed in
S.B. Crl. Misc Bail Application No. 6882/2021 wherein,
inadvertently, the FIR number was wrongly mentioned as
173/2020 whereas, the correct FIR number is 172/2020 P.S.
Talwara, District Hanumangarh.
For the reasons mentioned in the application, the misc.
application is allowed and it is directed that in the order dated
28.05.2021, the FIR number be read as “FIR No. 172/2020 P.S.
Talwara, District Hanumangarh” instead of “173/2020 P.S. Talwara,
District Hanumangarh”.
 The application stands disposed of.
(MANOJ KUMAR GARG)J.
