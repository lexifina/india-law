 (2) ca11398-11-group
2. By these applications, the delay caused in
filing the First Appeals is sought to be condoned by
the applicants/appellants. According to the
applicants/appellants, since the Executive Engineer
had no authority to file any appeal against the Award
of the Reference Court, the matter was processed at
the higher level and it took some time. The learned
counsel appearing for Respondent No. 3 opposes these
applications.
3. Considering the fact that the applicant is a
Public Sector Undertaking wherein the hierarchy is
involved which takes some time for considering as to
whether the Appeal against the Award of the Reference
Court is to be filed or not. Sufficient cause is
made out for condoning the delay. The delay is
condoned. The applications are, therefore, allowed
without any order as to costs.
