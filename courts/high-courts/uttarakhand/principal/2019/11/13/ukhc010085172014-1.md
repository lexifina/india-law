# High Court of Uttarakhand, WPMS/1844/2014, 2019-11-13

MCC 1099 of 2019
CLMA 15137 of 2019
In
WPMS No. 1844 of 2014
Honíble Lok Pal Singh, J.
Mr. Siddhartha Singh, Advocate for the
petitioners.
 Mr. B.S. Adhikari, Advocate for the
respondents.
 Heard.
 Restoration application alongwith delay
condonation application has been moved by
the petitioner to recall the order dated
18.09.2019, whereby the writ petition was
dismissed in default.
 Cause shown is found sufficient. Delay
in filing the restoration application is
condoned. Delay condonation application is
allowed.
 The grounds taken in the restoration
application is sufficient. Restoration
application is allowed. Order dated
18.09.2019 is hereby recalled. The writ
petition is restored to its original number
alongwith interim order.
 List this matter after four weeks.

(Lok Pal Singh, J.)
 13.11.2019
Mamta
