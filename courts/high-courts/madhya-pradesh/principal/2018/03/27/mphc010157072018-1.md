# High Court of Madhya Pradesh, MCRC/12172/2018, 2018-03-27

THE HIGH COURT OF MADHYA PRADESH
MCRC-12172-2018
(NANAK YADAV Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 27-03-2018
Shri R.P. Mishra, learned counsel for the applicant.
Shri Akhilendra Singh, learned GA for respondent-State.
Heard.
This application has been filed for modification in the order
dated 20.03.2018, passed in M.Cr.C. No.8749/2018.
Learned counsel for the applicant submits that in the order dated
20.03.2018, passed in M.Cr.C. No.8749/2018 due to some
typographical error, Crime number has been mentioned as Crime
No.07/2017, but the correct Crime number is Crime No.07/2018 and
due to this, bail could not be furnished.
On due consideration, application is allowed.
It is ordered that in the order dated 20.03.2018, passed in
M.Cr.C. No.8749/2018, Crime No.07/2017 be read as "Crime
No.07/2018".
Let a copy of this order be kept in the record of M.Cr.C.
No.8749/2018 and this order be read conjointly with the order dated
20.03.2018, passed in M.Cr.C. No.8749/2018.
With the above observation, this M.Cr.C. stands disposed of.
Certified copy as per rules.
(H.P. SINGH)
