# High Court of Madhya Pradesh, MCRC/3748/2016, 2016-04-26

MCRC-3748-2016
(HIMA Vs THE STATE OF MADHYA PRADESH)
26-04-2016
Mr. Ashish Gupta, learned counsel for the applicant.
Mr. A.S. Sisodiya, G.A. for the respondent / State.
Learned counsel for the applicant prays for withdrawal
of this first bail application filed under section 438 of
Cr.P.C with a liberty to file a bail application under
section 439 of Cr.P.C.
With the aforesaid liberty, present application is
dismissed as withdrawn. However, it is made clear that if
such an application is filed by the applicant, the same
shall be considered by the court on the same day.
C c as per rules.
