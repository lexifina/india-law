# High Court of Madhya Pradesh, MCC/1210/2014, 2014-09-19

MCC. No.1210 / 2014
19.09.2014.
Shri R.S. Saini, learned counsel for the applicants.
This application has been filed for restoration of
F.A. No.777/12, which has been dismissed in view of the
common conditional order dated 31.01.2014. There being
some delay in filing the application, IA No.9366/14, has
been filed seeking condonation of delay in filing the
application for restoration.
 The applications are supported by an affidavit of
the appellants himself and finding the same to be
bonafide, both the applications are allowed. Delay in filing
the application for restoration is condoned.
 The restoration application itself is allowed and the
First Appeal is restored to its original number. It be placed
for orders before the appropriate Bench.
Application stands allowed and disposed of.
 (Rajendra Menon) (A.K.Sharma)
