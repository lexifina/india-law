# High Court of Jammu and Kashmir and Ladakh, CRAA/19/2012, 2019-05-07

HIGH COURT OF JAMMU & KASHMIR
AT JAMMU
CRAA No.19/2012
 Date of order: 07.05.2019
State vs. Mohd Hanief & anr.
Coram:
Hon’ble Mr. Justice Sanjay Kumar Gupta, Judge

Appearing counsel:
For petitioner (s) : Mr. A.M.Malik,Dy AG
For respondent(s) :
i) Whether approved for reporting in Law Journals etc.: Yes/No
ii) Whether approved for publication in Press: Yes/No
 State has preferred this petition for condoning the delay of 26 days
in filing the Criminal Acquittal Appeal against the judgment dated
21.10.2011 passed by the learned Additional Sessions Judge Rajouri.
 As is evident from the record, the application for leave to file
appeal was not filed, so this court on 22.10.2018 directed the State to file
a formal application in this regard. Thereafter, despite availing so many
opportunities, the State has failed to file the application for leave to file
appeal. On 09.04.2019, last and final opportunity of two weeks’ was
granted but again the State has failed to file the same.
 In view of above, this appeal is required to be dismissed and it is
dismissed.
(Sanjay Kumar Gupta)
