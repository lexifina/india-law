# High Court for the State of Telangana, CRLP/7228/2017, 2017-08-30

THE HONíBLE SRI JUSTICE M.SATYANARAYANA MURTHY
CRIMINAL PETITION NO.7228 OF 2017
ORDER:

 Learned counsel for the petitioner seeks permission of this
Court to withdraw the criminal petition with liberty to file
appropriate application before the Trial Court.
 Permission is accorded with liberty as sought for.
 Criminal petition is dismissed as withdrawn. Registry is
directed to return the certified copies of the documents filed along
with this criminal petition, so as to enable the petitioner to file
appropriate application before the Trial Court.
 Consequently, miscellaneous applications pending if any,
shall stand dismissed. No costs.
