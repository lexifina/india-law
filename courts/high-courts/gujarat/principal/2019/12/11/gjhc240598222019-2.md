ORAL ORDER
Learned advocate Ms. Dharitri Pancholi for learned
advocate Mr. Hardik Raval for respondent no.2 states at bar
that charge sheet is filed before the issuance of order by this
Court.
Learned advocate Mr.Keval Barot is present for
learned advocate Mr. Pravin Gondaliya for the applicants.
It appears that charge sheet is filed. In light of this
position, the applicants are at liberty to file discharge
application and also to file appropriate proceedings either u/s
397 or 482 of the Code of Criminal Procedure, 1973 before
appropriate competent Court, after remedy to file discharge
application is availed. The present application stands disposed
of with above liberty.
It is clarified that this Court has not examined the
merits of the present application.
