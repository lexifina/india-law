# High Court of Madhya Pradesh, MCRC/8929/2019, 2019-07-08

-: 1 :- Misc. Criminal Case No.8929 of 2019.
HIGH COURT OF MADHYA PRADESH; BENCH AT INDORE
Misc. Criminal Case No.8929 of 2019.
(Hanuman Industries v/s Buldhana Urbaan Cooperative Bank Ltd Sahakar Setu)
Indore, Dated : 08.07.2019 :-
Shri A.K.Sethi, learned Senior Counsel with Shri
Kartik Mandloi, learned counsel for the petitioner.
Shri Arpit Kumar Oswal, learned counsel for the
Respondent.
Submissions were made on petition filed under
Section 482 of the Code of Criminal Procedure {in brief “the
Code”].
The Trial Court is ceased with complaint filed under
Section 138 of the Negotiable Instruments Act and when the
complainant's evidence was completed, an application was filed
by the complainant under Section 91 of the Code to bring on
record the reply submitted by the Respondent to the notice
issued against him by the complainant. This document was
allowed to be taken on record.
This order was earlier challenged in a revision. The
revisional Court considering it to be an interlocutory order,
rejected the same revision as not maintainable. Consequently
this petition under Section 482 of the Code has been filed.
Learned Senior Counsel for the petitioner has
submitted before this Court that the provisions of Section 91 of
the Code are not applicable in such cases. He submits that under
Section 91 of the Code, the Court has to pass an order on its
discretion and no application can be allowed to be filed under
Section 91 of the Code.
Learned counsel for the Respondent has submitted
that for ends of justice these facts needed to be brought on
record, that no impropriety has been committed by the learned
lower Court.
Submissions were heard. Documents were perused.

-: 2 :- Misc. Criminal Case No.8929 of 2019.
Section 91 of the Code is worded as under :-
No doubt Section 91 of the Code is couched in such
a manner that it is made to appear that Court's prerogative and
discretion to pass an order regarding production of a document.
However, it does not mean that such discretion can be exercised
by the Court only on its own volition and that no application can
be filed invoking Court's jurisdiction under Section 91 of the
Code. The Court can definitely exercised its jurisdiction when
an application is filed. One can see the similarity between
Section 91 of the Code and Section 311 of the Code as well.
Section 311 of the Code also prescribes for summoning any
person as a witness when his evidence appears to it to be
essential to the just decision of the case. No where it is
prescribed under Section 311 of the Code that the Court shall
pass an order under Section 311 of the Code only its own
volition and no application can be filed. Such provisions in
which the Courts have been given the power to act in the interest
of justice and for just decision of the case, the Court's
prerogative can be invoked on the basis of the application by
either of the parties because it is ultimately for just decision of
the case.
Thus, the submission that an application could not
have been filed under Section 91 of the Code is negatived.
There is no impropriety in the impugned order passed by the
learned Trial Court.
This petition under Section 482 of the Code stands
dismissed.
 [ Shailendra Shukla ]
