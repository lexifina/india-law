# High Court of Madhya Pradesh, MCRC/21853/2020, 2020-07-06

1
THE HIGH COURT OF MADHYA PRADESH
M.Cr.C. No.21853/2020
(Satnam Singh Vs. State of M.P.)
Indore, Dated: 06/07/2020
Shri Nitin Vyas, learned counsel for the applicant.
Shri Saransh Jain, learned counsel for the
Respondent/State.
Heard through video conferencing.
This M.Cr.C. has been filed for correction of the
typographical error in the order dated 29/06/2020 passed in
M.Cr.C. No.17745/2020.
Learned counsel for the applicant submits that by mistake
the crime number has been mentioned in the said order as Crime
No.682/2020 whereas the correct crime number is 682/2019.
He has referred to the order of the trial Court to point out the
said mistake.
Learned counsel for the State has not disputed this.
Hence, the M.Cr.C. is allowed by directing that in the order
dated 29/06/2020 passed in M.Cr.C. No.17745/2020 wherever
the crime number 682/2020 has been mentioned, the same will
be read as “Crime No.682/2019”.
Certified copy as per rules.
 (Prakash Shrivastava)
