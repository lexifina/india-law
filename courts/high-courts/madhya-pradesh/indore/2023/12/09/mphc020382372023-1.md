This application coming on for conciliation this day, the Bench passed
the following:
ORDER
1. This application has been filed for restoration of M.A. No.995/2023,
which has been dismissed for non-compliance of common conditional order
dated 12.04.2023.
2. Since the same is barred by 154 days an application under Section 5
of the Limitation Act bearing IA No.9347/2023 has been filed for condonation
of delay in filing the restoration application.
3. For the reasons stated in the application, the same is allowed and the
delay in filing the restoration application is condoned.
4. Considered the main application as well.
5 . For the reasons stated in the application, the same is allowed
and M.A. No.995/2023, which was dismissed for non-compliance of common
conditional order dated 12.04.2023, is restored to its original number.
6. Let the order dated 12.04.2023 passed in M.A. No.995/2023 be
complied with within a period of four weeks.
7. Let a copy of this order be kept in the record of M.A. No.995/2023.
8. MCC is accordingly allowed and disposed off.
