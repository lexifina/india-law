Dev Darshan Sud, J (Oral).

 Prayer of the learned Additional Advocate General to file
reply to the petition is rejected since two opportunities were afforded to
the respondents to file reply to the petition. This is a telling case. The
petitioner is widow, who has been transferred to a place which is 80 kilo
meters away. From the order it seems that she is working as Class-IV
employee (Peon). We do not find any justification decipherable for
passing this order. In these circumstances, we quash and set aside
impugned order Annexure P-2 so far as it affects the petitioner. Petition
stands disposed of.
2. All pending miscellaneous applications also stand disposed
