O R D E R
After arguing for sometime, the learned counsel for the
petitioner sought permission to withdraw this petition with
liberty to file a petition later, if final report is filed after
investigation, when this Court expressed an opinion that it is
preliminary stage to exercise the power under section 482 of
the Code of Criminal Procedure. So permission is granted and
the petition is dismissed as withdrawn with the above liberty.
Interim order of stay granted as per Crl.M.A.No.5921/2013 is
vacated and the application is dismissed. The learned Public
Prosecutor is directed to communicate this order to the
concerned Station House Officer so that he can proceed with
the investigation.
