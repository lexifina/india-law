PER COURT :-
1. In this case, FIR was registered in the year 2023 and charge
sheet itself was filed in January, 2024. The instant application has
been filed recently in June, 2025.
2. In light of the fact that the charge sheet has been already
placed on record before the competent court, we are of the opinion that
the applicant can file application for discharge before the competent
court. Therefore, we are not inclined to exercise our inherent powers
under section 482 of the Criminal Procedure Code to entertain the
present application.
3. Hence, the application is dismissed. However, the applicant is
granted liberty to file an application for discharge before the competent
court. If such an application is filed, the same shall be decided in
accordance with law, expeditiously.
( Y. G. KHOBRAGADE, J. ) ( MANISH PITALE, J. )
