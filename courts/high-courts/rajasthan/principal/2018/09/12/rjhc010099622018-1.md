Judgment / Order
12/09/2018
This second bail application is pending since May, 2018.
Today also, the Counsel for the petitioner prays for an
adjournment stating that some witnesses have been examined
during pendency of the bail application. If this is so, a fresh bail
application has to be filed before Sessions Judge concerned.
Thus, while giving liberty to the petitioner to file fresh bail
application before the Sessions Judge, Pratapgarh in changed
circumstances, the instant second bail application is dismissed at
this stage. If bail application is dismissed by the Sessions Judge,
Pratapgarh, the petitioner will be at liberty to file fresh bail
application in this Court.
(SANDEEP MEHTA),J
