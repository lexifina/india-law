Order
10/03/2017
Learned counsel for the applicant submits that this
application has been erroneously filed during pendency of the
earlier application [D.B. Criminal Misc. Bail (suspension of
Sentence) Application No.1030/2016], which has been dismissed
today only on merits, therefore, he does not want to press the
instant application.
The application is dismissed in view of the statement
given by learned counsel for the applicant. The dismissal of this
application will not adversely affect any right of the applicant, if he
prefers any subsequent application seeking suspension of
sentence.
