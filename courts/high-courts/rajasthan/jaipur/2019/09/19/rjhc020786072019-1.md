1. Mater comes up on application filed by the petitioner.
2. It is contended by counsel for the applicant that in the order
dated 19.07.2019 in Para No.7 in last line Case No.593/2012 is
mentioned whereas it should be Case No.573/2012.
3. I have considered the contentions.

(2 of 2) [CRLMA-471/2019]
4. In view of the typographically error, in Para No.7 in last line
Case No.593/2012 be now read as Case No.573/2012.
5. Accordingly, the application is allowed.
