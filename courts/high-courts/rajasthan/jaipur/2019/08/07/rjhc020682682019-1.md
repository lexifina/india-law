HON'BLE MR. JUSTICE INDERJEET SINGH
Order
07/08/2019
Counsel for the petitioner submits that due to inadvertence
in the causetitle of the bail application No.9647/2019 filed by the
petitioner, the FIR number has wrongly been mentioned as
315/2017 whereas the correct number of the FIR is 315/2018.
Counsel further submits that in the order dated 24.07.2019, the
FIR number mentioned as 315/2017 be ordered to be corrected as
315/2018.
For the reasons mentioned in the application, the same is
allowed. The FIR No.315/2018 be read in place of FIR
No.315/2017 in the order dated 24.07.2019 passed in S.B.
Criminal Misc. Bail Application No.9647/2019. Amended causetitle
is taken on record. This order be treated to be part of the order
dated 24.07.2019.
(INDERJEET SINGH),J
