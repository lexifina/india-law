ORDER
Date : 16-10-2020
Heard the learned counsel for the petitioner.
By way of this Interlocutory Application, prayer has been made for necessary correction of the
typographical error in the order dated 05.10.2020 passed by this Court in Tr.P.(C) 23/2020. It has been
pointed out that in the aforesaid order Misc (G) Case No. 12/2016 has been wrongly mentioned whereas it
should be Misc (G) Case No. 12/2019.
Having heard the submission of the learned counsel for the petitioner and also on verification of
the record it is seen that the case number has been wrongly mentioned in the aforesaid order.
Let the case number be now read as “Misc(G) Case No. 12/2019”.

Page No.# 2/2
Let this order be part of the main record.
Accordingly, this Interlocutory Application stands disposed of.
