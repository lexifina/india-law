2 04/02/2010 Heard learned Counsel for the petitioners and
the A.P.P. appearing on behalf of the State.
This application has been filed challenging the
order dated 26.11.2008 passed in Chanpatia Police
Station Case No. 82 of 2008 by which the Chief Judicial
Magistrate, West Champaran, Bettiah has taken
cognizance for the offences under Sections 147, 341,
323, 504/320 of the Indian Penal Code.
Initially, the petitioners were accused in a case
under Sections 147, 371, 323, 504 of the Indian Penal
Code but later on Section 302 of the Indian Penal Code
was also added.
Learned Counsel for the petitioners submits
that there is no allegation in the First Information Report

2
which would indicate that a case is made out under
Section 302 of the Indian Penal Code.
All these aspects of the matter will be
considered at the appropriate stage. At this stage, this
Court finds no illegality in the impugned order.
This application is accordingly dismissed.
Anand ( Sheema Ali Khan, J.)
