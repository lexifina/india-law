# Gauhati High Court, AB/502/2014, 2014-04-23

AB 502/2014
BEFORE
THE HON’BLE MR JUSTICE C R SARMA
Heard Mr. J.H. Saikia, learned counsel appearing for the petitioner. Also heard
Mr. B.B. Gogoi, learned addl. P.P., Assam, appearing for the State respondent.
Perused the C.D.
By this application filed under Section 438 Cr.P.C. the petitioner, namely, Md.
Saiful Ali has prayed for pre-arrest bail in connection with Basistha P.S. Ca
se No. 31/2014 under Section 498(A) IPC.
Having heard the learned counsel appearing for both the parties and considering
the evidence so far collected by the investigating officer, I find no sufficient
reason for custodial interrogation of the petitioner.
Accordingly, the interim order dated 07.02.2014 is made absolute subject to con
dition that the petitioner shall appear before the Investigating Officer as and
when so required for the purpose of investigation.
Return the C.D.
The bail application is disposed of.
