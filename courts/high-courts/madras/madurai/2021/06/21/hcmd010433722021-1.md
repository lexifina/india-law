PRAYER: Criminal Original Petition is filed under Section 482 of
the Code of Criminal Procedure, to direct the third respondent to
complete investigation and to file the final report in connection
with the case in Crime No.343 of 2018, on the file of the third
respondent police, dated 29.10.2018, within a time frame fixed by
this Court.
For Petitioner : Mr.K.Malaimaran
For Respondents : Mr.R.M.Anbunithi,
 Additional Public Prosecutor
 (Criminal side)
O R D E R
This Criminal Original Petition has been filed seeking for a
direction to the third respondent herein to complete the
investigation and file a final report in Crime No.343 of 2018 dated
29.10.2018 on the file of the third respondent herein.
2. Today, when the matter came up for hearing, the learned
Additional Public Prosecutor (Criminal side) submitted that the
investigation of the case has been completed and a final report was
also filed as early as on 27.11.2018 before the learned Judicial
Magistrate, Thiruppuvanam and it is also informed that the final
report has not been taken on file so far.

3. Since the final report was filed on 27.11.2018 itself, a

report must be submitted before the Registry.
4. With the above directions, this Criminal Original Petition
is disposed of.
