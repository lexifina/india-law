2. The order which is sought to be set aside has
been complied with. The learned counsel for the
applicant, however, submits that this order needs to be
set aside because the non-applicant is making repeated
applications and delaying the proceedings before the
Family Court. To my mind, the order impugned cannot
be set aside on such fictitious grounds. If the order has
been complied with, there is no reason why should it be
set aside.
3. At this stage, learned counsel for the applicant
submits that the Family Court be directed to decide the
application of interim maintenance in a time bound
manner.
