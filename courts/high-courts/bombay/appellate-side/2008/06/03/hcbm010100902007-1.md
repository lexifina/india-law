# Bombay High Court, APPLN/1129/2007, 2008-06-03

( 1 )
 IN THE HIGH COURT OF JUDICATURE AT BOMBAY
 CRIMINAL APPELLATE JURISDICTION
 CRIMINAL APPLICATION NO.1129 OF 2007
 The State of Maharashtra .. Applicant.
 Versus
 Tanaji Kondiba Shelar & Anr. .. Respondents.
 Mr.H.J.Dedhia, A.P.P. for the applicant.
 None for the respondents.
 CORAM : R.Y. GANOO, J.
DATED : 3rd June, 2008.
 P.C.:
 1. Heard Mr.H.J.Dedhia, learned A.P.P. for the
 State. None for the respondents.
 2. The State wanted order dated 20.12.2006 passed
 by the learned Additional Sessions Judge, Satara to be
 vacated and hence the State has filed this
 application. It is pertinent to note that this order
 dated 20.12.2006 was to remain in force for 90 days as
 set out in Item No.3 of the operative part of the
 order. In view of this nothing survives in this
 application and is accordingly dismissed.
 (R.Y. GANOO, J.)
