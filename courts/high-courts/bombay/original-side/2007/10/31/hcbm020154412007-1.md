CORAM: SWATANTER KUMAR, C.J. &
 DR. D.Y. CHANDRACHUD, J.
 31st October, 2007.
P.C. :
The contention raised before us is that the order dated
21st June, 2007 was passed without providing adequate opportunity
to the Petitioners to place certain documents on record. Counsel
appearing for the State submits that the State would have no
objection if the said order is set aside with liberty to the State to
pass a fresh order after furnishing to the Petitioners an opportunity
to file requisite documents. In view of the statement made, the
order dated 21st June, 2007 is set aside with liberty to the
Petitioners to file the requisite documents within two weeks from

2
today and the Respondents as per their statement will pass an
order within six weeks thereafter. Parties will abide by their
statement and if the Petitioners do not file the requisite documents
within two weeks from today, they will not have the benefit of this
order and the order which is set aside by this order would
automatically stand revived.
The Petition is accordingly disposed of.
CHIEF JUSTICE
 DR. D.Y. CHANDRACHUD, J.
