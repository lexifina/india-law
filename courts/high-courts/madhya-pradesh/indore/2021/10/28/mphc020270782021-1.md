# High Court of Madhya Pradesh, MCRC/53465/2021, 2021-10-28

1
HIGH COURT OF MADHYA PRADESH : BENCH AT INDORE
M.Cr.C. No.53465/2021
Lateef @ Gama S/o Mohd. Shah Vs. State of M.P.
Indore, Dated:- 28 /10/2021
Shri G.P.Singh, Counsel for the applicant – Lateef @ Gama
S/o Mohd. Shah.
Shri Sanjay Karanjewala, Govt. Advocate for the
respondent/State.
1. This application has been filed for correction of crime number
as has been mentioned in order dated 23.10.2021 passed in M.Cr.C.
No.49753/2021.
2. Learned counsel for the applicant submits that the correct crime
number is 213/2021 whereas the same has been inadvertently
mentioned as 199/2021 hence prays for correction of the same.
3. The said prayer is not opposed by the learned counsel for the
respondent/State
4. Consequently this application is allowed and the “Crime
No.199/2021” as mentioned in order dated 23.10.2021 shall stand
substituted by “Crime No.213/21”. This order shall be read conjointly
with order dated 23.10.2021 passed in M.Cr.C. No.49753/2021.
5. The present application is accordingly disposed of.
C.c. as per rules.
 (PRANAY VERMA)
 JUDGE
