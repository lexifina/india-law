ORAL ORDER
2 23-03-2023 Heard the learned counsels for the parties.
 This application has been filed for quashing the order
dated 02.04.2019 passed by the learned S.D.J.M. Hilsa, Nalanda
after differing with the order of learned Additional Sessions
Judge-1st at Hilsa, Nalanda by which set aside the cognizance
order dated 07.09.2018 under Section 7 of the Essential
Commodities Act 1955 against the petitioner in Cr. Rev. No. 119
of 2018 vide order dated 14.12.2018.
There is no merit in this application.
Accordingly, this application is dismissed with
liberty to the petitioner to raise all the grounds at an appropriate
stage.
