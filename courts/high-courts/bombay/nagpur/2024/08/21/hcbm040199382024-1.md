1. This is an application for condonation of delay
of 207 days caused in filing restoration application.
2. Perused the application.
3. Heard learned Advocates of both sides.
4. For the reasons stated in the application, the
application is allowed in the interest of justice.
5. The delay of 207 days caused in filing
restoration application is condoned.
6. The application is disposed of.
MISC. CIVIL APPLICATION ST. No.14045 OF 2024.
1. This is an application for restoration of the first
appeal, which is dismissed in default for non-filing of
private paper-book.
2. Perused the application.
3. Heard learned Advocates of both sides.

cao977.24.odt 2/2
4. Learned Advocate for the applicant submits
that paper-book is ready.
5. Considering the reasons stated in the
application and the submission of learned Advocate for the
appellant that now paper-book is ready it will file within a
week, the application deserves to be allowed.
6. The application is allowed.
7. The appeal is restored on its original number,
subject to filing of paper-book within a week.
8. It is clarified that if the paper-book is filed
within a week, this application shall be deemed to be
rejected without further order.
9. The application is disposed of.
