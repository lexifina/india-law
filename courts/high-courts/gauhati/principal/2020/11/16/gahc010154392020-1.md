ORDER
Date : 16.11.2020
Heard Mr. D. Banik, learned counsel for the applicants. None appears on call for the
State.
This is an application for correction of order dated 04.09.2020 passed by this Court in

Page No.# 3/3
AB 3307/2019.
It is seen that the case relates to Manikpur P.S. Case No.174/2019, which has been
inadvertently mentioned in the said order as Manikpur P.S. Case No. 174/2016. Accordingly,
this application for correction stands allowed.
The order dated 04.09.2020 in AB 3307/2019 would now be read as if interim pre-arrest bail granted to the applicants herein namely, (1) Ibrahim Ali, (2) Sanjib Das, (3) Amjad
Ali and (4) Foyez Uddin Bhuyan @ Foyes Uddin Shekh Buyan by order dated 25.09.2019 has
been made absolute in connection with Manikpur P.S. Case No.174/2019 on same conditions.
Accordingly, the applicants are now directed to appear before the I/O of Manikpur P.S. Case
No.174/2019 within a period of 2 (two) weeks from today.
Accordingly, this application stands disposed of and this order shall be read conjointly
with the order dated 04.09.2020 in AB 3307/2019.
