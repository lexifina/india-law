O R D E R
Petitioner-wife seeks transfer of O.P. No.1081 of 2012
from the Family Court, Malappuram to the Family Court,
Kottarakkara. That is a petition filed by the respondent for
divorce.
2. When the matter came up for hearing before this
Court, an interim order of stay of the proceeding was granted on
5.12.2012. Learned counsel for respondent submitted that the
Family Court, Malappuram has passed an ex parte decree in O.P.
No.1081 of 2012 since the order of stay was not communicated to
that court.
3. Learned counsel for petitioner submitted that an
application to set aside the ex parte decree is already filed but it is
not even numbered.
4. If there is an ex parte decree and an application to set
aside that ex parte decree is pending, that application has to be
disposed of by the Family Court, Malappuram. Question of
considering request for transfer would arise only if the ex parte

decree is is set aside. Hence request for transfer cannot be
entertained at the stage.
5. If the Family Court, Malappuram has not so far
numbered the application to set aside the ex parte decree, that
court has to number the application and after serving notice to
the respondent, dispose of the same as provided under law as
early as possible.
With the above observation and leaving it open to the
petitioner to file fresh application for transfer in case the ex parte
decree in O.P. No.1081 of 2012 is set aside, this Petition is
closed.
