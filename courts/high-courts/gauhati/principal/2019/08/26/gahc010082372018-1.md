BEFORE
HONOURABLE MRS. JUSTICE RUMI KUMARI PHUKAN
ORDER
Date : 26-08-2019
Heard the learned counsel for the applicant and also the learned Additional
Public Prosecutor for the State respondent.
The present application was filed during the pendency of the Bail Application
No.395/2018 to bring on record certain documents with certain prayers etc. but the
said Bail Application was disposed of along with BA No.391/2018 on 03.05.2018 but
inadvertently no order was passed in the present Application.
Learned counsel for the applicant has fairly submitted that the application has
become infructuous as the main case has already been disposed of.
On the verification of the main case it is found that the Interlocutory Application was
filed in connection with the aforesaid BA No.395/2018 which has already been
disposed of.
Accordingly, the present application being infructuous is also hereby dismissed.
 JUDGE
