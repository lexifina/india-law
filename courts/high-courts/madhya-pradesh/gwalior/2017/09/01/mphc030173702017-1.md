# High Court of Madhya Pradesh, MCRC/8044/2017, 2017-09-01

MCRC-8044-2017
(ARVIND SINGH THAKUR Vs THE STATE OF MADHYA PRADESH THR)
01-09-2017
Shri Anshu Gupta, counsel for the applicant.
Shri Prakhar Dhengula, Public Prosecutor for the respondent/ State.
Case Diary is available.
This is second application under Section 439 of CrPC for grant of bail. The
first application was dismissed as withdrawn by order dated 08/06/2017
passed in MCRC 5447/2017.
The applicant has been arrested on 06/09/2016 in connection with Crime
No.226/2015 registered at Police Station Dehat, Ganjbasoda, District
Vidisha for the offence punishable under Sections 395 and 120-B of IPC.
The counsel for the applicant seeks permission of this Court to withdraw
this application with liberty to the applicant to revive the same if there is
any undue delay in trial.
With the aforesaid liberty, the application is dismissed as withdrawn.
(G.S. AHLUWALIA)
JUDGE
MKB
