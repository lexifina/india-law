in

ABDUL QUDDHOSE.J.,
This application has been filed, seeking to set aside the ex-parte order
dated 22.11.2024 passed in C.S.No.505 of 2008. The learned counsel for the
first respondent / plaintiff has not raised any serious objection for allowing
this application. This Court is satisfied with the reasons stated in the
affidavit filed in support of this application. Accordingly, this application is
allowed as prayed for.
2. Registry is directed to number the application filed by the second
defendant seeking to condone the delay in filing the written statement, if it is
otherwise in order and list the same for hearing on 07.02.2025.
