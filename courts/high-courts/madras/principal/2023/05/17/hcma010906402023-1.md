# Madras High Court, WMP/15031/2023, 2023-05-17

W.M.P.No.15031 of 2023
in W.P.No.13922 of 2022
C.V.KARTHIKEYAN, J.
and
SENTHILKUMAR RAMAMOORTHY, J.
Learned counsel for the
petitioner states that in
W.P.No.13922 of 2023, by an order
dated 28.4.2023, ten days' time was
granted to the petitioner to file an
application before the Debts
Recovery Tribunal. By this
miscellaneous petition, the petitioner
seeks a further two weeks' time to
file such application.
Satisfied with the reasons
stated in the affidavit filed in support
of this petition, time granted to file
an application before the Debts
Recovery Tribunal vide order dated
28.4.2023 is extended till 13.6.2023.
This miscellaneous petition is
ordered accordingly.
