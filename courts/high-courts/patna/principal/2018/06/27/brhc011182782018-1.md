ORAL ORDER
2 27-06-2018 This application has been filed for modification of the
order dated 15.5.2018 passed by this Court in Cr.Misc.No. 27994
of 2018 to the extent that before father’s name of petitioner No.1
‘Late’ should be added and in resident of village the word
‘Manora’ should be added prior to ‘Ratanpur’ and for that this
petition has been filed on affidavit.
 In such view of the matter, in the order dated 15.5.2018
before father’s name of petitioner No.1 ‘Late’ should correctly be
read and in resident of village the word ‘Manora’ should correctly
be read prior to Ratanpur.
With the above observation, this application is allowed.
Let this order be communicated to the court concerned
forthwith.
spal/-
(Vinod Kumar Sinha, J)
