Secretary ..PETITIONER

Mr A.B. Tele, Advocate for petitioner;

 DATE : 28th April, 2014
PER COURT:
Mr Tele, the learned Counsel submits that respondent no.3 has
been granted permission to run secondary school. The petitioner is not
granted the permission.
2. A different yardstick is applied to the petitioner. According to the
learned Counsel, only because the petitioner trust is not having any
political patronage, the permission is not granted. Respondent no.3 has a
political patronage, so it has been granted permission.

 (2)
W.P. No.494/02
3. The learned Counsel for respondent no.3 and the learned A.G.P.
support the order passed.
4. Respondent no.3 is running the school for almost 14 years. Even
the strength of the students has been given in the affidavit in reply filed by
the State. The respondent – State has filed the affidavit stating that the
respondent society is running the school smoothly and as per the norms.
5. In the light of above, the writ petition is disposed of. Rule
discharged. No costs. Needless to state, the petitioner, if so desires, may
file a fresh application, which application should be considered as per the
present day policy.
 (N.W. SAMBRE, J.) (S.V. GANGAPURWALA, J.)
