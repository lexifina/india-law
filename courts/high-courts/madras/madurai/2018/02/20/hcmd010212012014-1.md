ORDER
This Criminal Original Petition has been filed by the accused,
to quash the First Information Report in Crime No.39 of 2010, on
the file of the first respondent.
2.The learned Government Advocate (Crl. Side) has submitted
that already charge sheet has been filed on 07.02.2018, before the
learned Judicial Magistrate No.I, Tirunelveli, but so far, the
case was not taken on file.
3.Considering the aforesaid submissions, this Criminal
Original Petition is disposed of. The learned Judicial Magistrate
No.I, Tirunelveli, is directed to verify and if charge sheet is
filed, then he has to take the case on file without any further
delay. Consequently, connected Miscellaneous Petition is closed.
