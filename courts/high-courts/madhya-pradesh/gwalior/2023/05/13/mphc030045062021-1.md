ORDER
This petition under Article 226 of the Constitution of India has been
preferred against the order dated 5.2.2021 passed by respondent No.5, whereby
the petitioner has been transferred from Gram Panchayat Chituyan to Gram
Panchayat Kararikhurda.
By order dated 22.2.2021 passed by this Court, the order dated 5.2.2021
was stayed, therefore, learned counsel for the State submits that the said order
can be set aside with a liberty to pass fresh transfer order, if occasion so arises.
Accordingly, the transfer order dated 5.2.2021 is set aside with liberty to
the State to pass a fresh order, if occasion so arises.
Resultantly, this petition is disposed of.
