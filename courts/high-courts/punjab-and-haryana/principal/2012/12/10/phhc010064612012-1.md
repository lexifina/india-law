A.N.Jindal, J. (Oral)
Challenge in this petition is the order dated 03.04.2012 passed
by the trial Court declining the request of the petitioner/defendant No.1 for
filing the additional written statement to the amended replication.
Since there is no provision in the Code for filing additional
written statement to the replication, if it is so done, then there would be no
end to the pleadings. As such, this petition is declined however, any
additional plea if give rise to triable issues, would be decided on evidence.
 ( A.N.Jindal)
