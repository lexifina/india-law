# Allahabad High Court, BAIL/45872/2020, 2021-12-03

Court No. - 38
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 45872
of 2020
Applicant :- Jasveer @ Jasbeer
Opposite Party :- State of U.P. and Another
Counsel for Applicant :- Sharad Kumar Srivastava,Ajay
Kumar Srivastava
Counsel for Opposite Party :- G.A.
Hon'ble Jayant Banerji,J.
Sri Atul Kumar Srivatava (Advocate Roll No. A/A/2631/14)
holding brief of Sri Sharad Kumar Srivastava, learned counsel
for the applicant made a request for an adjournment to enable
him to file supplementary affidavit bringing on record the order
sheet of the trial court. The order in the first bail was passed on
22.1.2020, and in view of the statement made by the learned
counsel for the appellant, it is apparent that thereafter, trial of
the applicant is going on. As such it would be appropriate for
the petitioner to file a bail application before the trial court
concerned rather than press this application here.
This application is, accordingly, rejected.
Order Date :- 3.12.2021
S.K.S.
(Jayant Banerji,J)
