# Allahabad High Court, CAPL/3184/2018, 2018-08-07

Court No. - 19
Case :- CONTEMPT APPLICATION (CIVIL) No. - 3184 of
2018
Applicant :- Sharad Kumar
Opposite Party :- Manoj Singh, Secretary
Counsel for Applicant :- Kamal Kumar Singh
Hon'ble Irshad Ali,J.
Heard learned counsel for the applicant.
The present contempt application has been filed alleging
disobedience of the order passed by this Court on 16.5.2017 in
Writ-A No. 20895 of 2017 inasmuch as order dated 16.11.2017
passed in Contempt Application (Civil) No. 5234 of 22017.
While entertaining the present contempt application this Court
vide orders dated 31.5.2018 and 18.7.2018 directed to the
learned Additional Chief Standing counsel to obtain instructions
in the mater.
In compliance of the order passed by this Court, Sri K.R. Singh,
learned Additional Chief Standing Counsel has produced the
instructions today before this Court wherein it has been
informed that vide order dated 6.8.2018, the revision pending
before the competent authority, has been decided finally.
In view of the above, no cause of action survives. The contempt
application is finally disposed of.
Order Date :- 7.8.2018
Manoj
