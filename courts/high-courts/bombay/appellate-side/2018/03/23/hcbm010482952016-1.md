in preferring an application for leave to file an appeal.
2. Heard learned counsel for the applicant, learned counsel
for the Respondent No.1 and learned APP.

opposed the application.
However, for the reasons stated in the application, delay is
condoned.
4. Application is allowed in terms of prayer clause (a).
