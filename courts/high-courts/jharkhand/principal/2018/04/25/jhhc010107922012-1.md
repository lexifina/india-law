Order No. 05 Dated 25th April, 2018

 No one appears for the petitioner. Minor defect has been pointed out,
but the same has not been removed for almost six years.
 This application has been filed for restoration of A.B.A. 4305 of 2011
which was dismissed for non-prosecution on 17.02.2012. Much water has
flown since the order dated 17.02.2012. No one appears to apprise this Court
about the actual state of affairs.
 This application seems to have become infructuous and the
same is accordingly dismissed.
 (Rongon Mukhopadhyay, J)
