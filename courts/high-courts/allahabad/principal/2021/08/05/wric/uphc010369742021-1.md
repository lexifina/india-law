# Allahabad High Court, WRIC/10152/2021, 2021-08-05

Court No. - 2
Case :- WRIT - C No. - 10152 of 2021
Petitioner :- Satyawan Singh
Respondent :- State Of U P And 3 Others
Counsel for Petitioner :- Om Prakash Singh
Counsel for Respondent :- C.S.C.,Habib Ahmad
Hon'ble Suneet Kumar,J.
Learned counsel for the respondent-Bank submits that there are factual
errors including the branch name from where the petitioner has obtained
loan.
It is urged that the petitioner has obtained loan from Branch Kotwa
Jalalpur, Azamgarh.
On being confronted with the objection, learned counsel for the petitioner
submits that petition be dismissed as withdrawn with liberty to the
petitioner to file a fresh petition with all correct facts.
The writ petition is, accordingly, dismissed as withdrawn with the
aforesaid liberty.
Order Date :- 5.8.2021
S.Prakash
