# High Court of Orissa, WP(C)/5696/2013, 2019-11-16

03. 16.11.2019 Learned counsel for the petitioner seeks permission to
withdraw the writ petition with a liberty to file afresh, if any
cause of action will arise.
 Prayer for withdrawal is allowed.
 The writ petition is accordingly dismissed as withdrawn
with a liberty to the petitioner to file a fresh petition, if any
cause of action survives.
