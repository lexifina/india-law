Criminal Original Petition under Section 482 of the Criminal
Procedure Code praying to direct the respondent police to file final
report in Crime No.297 of 2017 on the file of the respondent police
within the time frame fixed by this Court.
For Petitioner : Mr.J.Titus Enock
For Respondent : Mr.A.Damodaran, APP
ORDER
This Criminal Original Petition has been filed seeking to direct the
respondent police to file final report in Crime No.297 of 2017 within a
time frame.
2. Heard the learned counsel appearing for the petitioner and the

3. The learned counsel appearing for the petitioner would submit
that though the respondent has registered a case in the above said
crime number on 17.7.2017, no final report is filed till date.
4. The learned Additional Public Prosecutor appearing for the
respondent would submit that the respondent police may be permitted
to file a final report within a period of four months.
5. In view of the above, the respondent police is directed to file
either a final report or closure report, as the case may be, within a
period of four months from the date of receipt of a copy of this order
under due intimation to the defacto complainant.
6. With the above direction, this Criminal Original Petition is
disposed of.
