 Learned counsel for the applicant has filed this
application with the following prayer:-

(2 of 2)

seems to be genuine, therefore, one month’s time is granted to
the applicant to submit the documents before the IO concerned,
pursuant to the order dated 11.3.2016 passed by this Court. It is
made clear that one month’s time will be counted from today.
The application stands disposed of accordingly.
