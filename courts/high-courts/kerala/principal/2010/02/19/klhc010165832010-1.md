ORDER
Petitioner filed C.M.P.No.102/2006 in C.C.No.
7/2004 under Section 205 of Code of Criminal
Procedure to grant exemption from appearance. By
order dated 28.2.2006, exemption was granted. This
petition is filed under Section 482 of Code of
Criminal Procedure for a direction to the
respondent to issue certified copy of the said
order contending that when certified copy was
applied for, Annexure-A1 order was furnished, which
is not an independent order, but a photocopy of the
petition containing the orders written by the
learned Magistrate in his own handwriting.
2. Learned counsel appearing for the petitioner
submitted that as the order is to be produced
before the Passport Authorities, an independent
order should have furnished. When petitioner has
applied only for a certified copy of the order in

CRMC 591/10 2
C.M.P.No.102/2006, learned Magistrate issued the
certified photocopy of the petition containing the
order. If the petitioner files an application
before the Magistrate praying for issue of a
certified copy of the order independently, learned
Magistrate to issue a separate typed copy of the
order dated 28.2.2006 in C.M.P. No.102/2006.
Petition is disposed.
19th February, 2010 (M.Sasidharan Nambiar, Judge)
