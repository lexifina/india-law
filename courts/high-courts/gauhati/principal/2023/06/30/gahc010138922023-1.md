30.06.2023
Heard Mr. P. Choudhury, learned counsel appearing for the
applicant.
This application has been filed for correcting typographical error
appearing in the order dated 19.06.2023 passed by this Court in
Crl.Pet./578/2023.
In the said order, the “further proceeding of D.V. Case No.212/2023
pending in the court of learned SDJM, Cachar, Silchar” was directed to
be stayed.
Mr. Choudhury submits that the case number has been erroneously
shown in that order because the correct case number is “D.V. Case
No.212/2022” and not D.V. Case No.212/2023.
The typographical error stands corrected. Henceforth, the case
number D.V. Case No.212/2023 appearing the order dated 19.06.2023
shall be read as “DV Case No.212/2022”.
This order shall form a part of the order dated 19.06.2023 passed by

Page No.# 3/3
this Court in Crl.Pet/578/2023.
The Interlocutory Application stands disposed of.
