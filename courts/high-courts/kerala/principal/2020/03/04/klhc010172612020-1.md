JUDGMENT
Dated this the 4th day of March 2020
The petitioner filed an application under Sec.28A of the Kerala
Land Acquisition Act. This was rejected stating that the petitioner relied
on a judgment which has no application. Thereafter, the petitioner
submitted an application placing reliance on judgment which has bearing
the matter. This was rejected stating that earlier application has been
rejected.
2. There is no embargo in filing a 2nd application, if first
application was rejected on technical reason. This application has to be
considered based on the parameters under Sec.28A of the Land
Acquisition Act. Therefore, the impugned order is set aside. The
application shall be considered on merit, in accordance with law.
This writ petition is disposed of as above.
