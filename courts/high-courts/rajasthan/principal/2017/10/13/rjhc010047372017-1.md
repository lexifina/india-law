HON'BLE MR. JUSTICE PANKAJ BHANDARI
Judgment / Order
13/10/2017
1. Counsel for the petitioner has moved an application for
modification of order dated 09.10.2017 passed by this Court.
2. It is contended that in the impugned order in para 2 and
para 7, F.I.R. No.115/2017 has been mentioned, whereas the
F.I.R. Number is 118/2017.
3. I have considered the contentions and have perused the
order passed by Sessions Judge, Chittorgarh, wherein F.I.R.
No.118/2017 was mentioned erroneously due to typographical
error. In the bail application, F.I.R. No.115/2017 has been
mentioned, whereas it should be 118/2017, as a result of which
an error occurred in the order dated 09.10.2017.
4. Considering the above, application for modification is

(2 of 2)
[CRLMB-8110/2017]
allowed. In the impugned order dated 09.10.2017 in para 2 and
para 7, F.I.R. No.118/2017 be read in place of F.I.R. No.115/2017.
(PANKAJ BHANDARI)J.
