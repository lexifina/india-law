# High Court of Orissa, CONTC/1651/2019, 2019-09-23

3. 23.09.2019 Heard Mr. D. Nayak, learned counsel for the
petitioner.
 The petitioner has filed this application in view of
order dated 06.12.2019 passed by this Court in CONTC No.
632 of 2018, by which this Court permitted the petitioner
to withdraw that contempt application with liberty to file
better application with better particulars. But fact remains
the petitioner had approached this Court by filing CONTC
No. 632 of 2018 alleging non-compliance of order dated
05.01.2015 passed by this Court in W.P.(C) No. 11640,
which was filed beyond the limitation period prescribed
under the law. If the CONTC No. 632 of 2018 was not
maintainable, therefore, on the request made by learned
counsel for the petitioner he was permitted to withdraw
that contempt application and by suppressing the fact, this
contempt application has been filed. Thereby, this Court is
not inclined to entertain this application. Accordingly, the
contempt proceeding is dropped with cost of Rs.10,000/-,
which to be realized from the counsel for the petitioner.
