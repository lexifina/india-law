# High Court of Madhya Pradesh, MCC/489/2012, 2012-04-16

MCC No.489/2012
16.04.2012
Shri V. Bhide learned counsel for the applicant.
Shri Himanshu Shrivastava, learned counsel for
the respondent.
This is an application for restoration of W.P
No.6474/2006 which was dismissed in default by order
dated 15.3.2012.
It is stated in the application that since
Vakalatnama was not filed, the counsel for the applicant
could not appear on the date when the case was called
on for hearing.
The learned counsel for the respondent also has
no objection on the application being allowed.
In view of the aforesaid, the application is allowed
and W.P No.6474/2006 is directed to be restored to its
original number.
( AJIT SINGH ) ( R. S. JHA )
