K. KANNAN J. (ORAL)
1. In a suit which was dismissed for default, an application was
filed for restoration. That application was also dismissed for default.
The revision petition is filed against the order dismissing the application
filed for restoration of an application which was dismissed for default.
Section 141 CPC allows for the procedure prescribed under the Code in
regard to suit to be applied also with reference to the miscellaneous
proceedings. If under Order 43 Rule 1 CPC, there is a provision for an
appeal against dismissal of an application for restoration of the suit
under Order 43 Rule 1 (c), by virtue of Section 141 CPC, an application
in such an application which is dismissed for default is also appealable.
2. The revision petition is not competent and disposed of as
such with liberty to approach the Appellate Court for appropriate
orders.
