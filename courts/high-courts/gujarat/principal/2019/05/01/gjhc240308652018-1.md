ORAL ORDER
1. This is an application seeking to lodge the First Information Report
in connection with the written complaint dated 29.03.2018 and
31.03.2018.
2. This Court has heard learned advocate Mr. Baghel appearing for
the applicant and learned APP Mr. Soni appearing for the respondent –
State.
3. It appears that earlier between the same parties another FIR came
to be registered being I-CR No. 51 of 2018 for the offences punishable
under Sections 406, 420, 465, 467, 468 and 471 of the Indian Penal Code.
4. It appears that the event which has been narrated is subsequent to

into if more provisions could be added.
5. If the earlier complaint is a part of the present transaction, the
