05/27.08.2021 At the request of the learned counsel for the
petitioner defects as pointed out by the registry is hereby
ignored.
2. A show-cause has been filed in the instant
contempt petition, which transpires that the order dated
11.09.2020 has been complied with by passing a reasoned
and speaking order.
3. Mr. Shadab Bin Haque, learned counsel for the
petitioner fairly submits that the order has not been
complied in true letter and spirit, inasmuch as, the order

-02-
which has been quashed by this Court has again been
passed.
4. Mr. Nipun Bakshi, learned counsel for the
opposite party-Bank submits that the order has been
complied in true letter and spirit, inasmuch as, the matter
was remanded to the appellate authority to pass a fresh
order and the same has been done, which is annexed as
Annexure-A to the show-cause.
5. After going through the appellate order dated
20.03.2021, it appears that the order passed by this Court
has been complied in true letter and spirit, however if the
petitioner is not satisfied with the appellate order he would
be at liberty to approach the appropriate forum, if so
advised.
6. With the aforesaid observation, the instant
contempt petition is hereby dismissed.
