 O R D E R
 [Order of the Court was made by K.K.SASIDHARAN, J.]
The order passed by the first respondent directing removal
of encroachment is challenged in this writ petition.
2. We have heard the learned counsel appearing for the
petitioner and the learned Additional Government Pleader appearing
for the respondents.
3. The order passed by the first respondent indicates that
it is a tank poramboke. The first respondent has no authority to
https://hcservices.ecourts.gov.in/hcservices/

2
initiate action for removal of encroachment in case the property
is tank poramboke. We are therefore of the view that the impugned
order is liable to be set aside.
4. In the result, the order dated 25.06.2013 on the file of
the first respondent is set aside. It is open to the concerned
statutory authority to initiate appropriate action in case there
is a cause of action for taking action against the petitioner.
5. The writ petition is allowed as indicated above. No
costs. Consequently, the connected Miscellaneous Petitions are
closed.
