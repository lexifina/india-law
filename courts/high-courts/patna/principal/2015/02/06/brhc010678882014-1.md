ORAL ORDER
2 06-02-2015 Having regard to the fact that either the dismissal order
or the appellate order removing the petitioner from service was not
passed from any place within the territorial jurisdiction of this
Court, this writ application must be held to be not maintainable
before this Court.
When such an observation has been made, learned
counsel for the petitioner seeks permission to withdraw this
application in order to enable the petitioner to move competent
forum/court for redressal of the grievance raised herein.

Patna High Court CWJC No.6721 of 2014 (2) dt.06-02-2015 2
This application is, accordingly, permitted to be
withdrawn with the aforementioned liberty.
