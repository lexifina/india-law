CORAM: HONOURABLE MR. JUSTICE AHSANUDDIN AMANULLAH
 ORAL JUDGMENT
Date: 16-01-2017
Heard learned counsel for the parties.
The present writ application has been filed for a
direction to the authorities not to build a road from Shakurabad- to
village Galimpur via Saraia, as the same was not as per the approved
plan.
Learned counsel for the State, on the basis of
averments made in the counter affidavit, submitted that there was
never any proposal to build the said road via Saraia and the
authorities have not taken any steps in that direction. However, only
the existing road from Shakurabad-Ghejan Path towards Galimpur,

on which there was encroachment, the same has been removed. It is
the categorical stand that only Shakurabad-Ghejan Path towards
village Galimpur, as proposed, is being built.
Having regard to the categorical stand in the counter
affidavit, nothing survives in the present writ application and,
accordingly, the same stands disposed off.
