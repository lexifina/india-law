HON'BLE MR. JUSTICE PANKAJ BHANDARI
 Order
07/12/2020
1. The matter comes up on application for correction in the
order dated 20.11.2020.
2. It is contended by counsel for the petitioner that in the
impugned order in Para 1, it is mentioned as second bail
application whereas it was first bail application.
3. I have considered the contentions.
4. Considering the contentions made by counsel for the
petitioner, application for correction in the order dated 20.11.2020
is accordingly, allowed.
5. Looking to the typographical error, in Para 1 of order dated
20.11.2020, “second bail application” be now read as “first
bail application”.
(PANKAJ BHANDARI),J
