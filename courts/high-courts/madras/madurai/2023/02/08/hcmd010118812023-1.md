ORDER
This Criminal Original Petition has been filed, invoking Section
482 Cr.P.C., seeking orders to call for the records pertaining to First
Information Report in Crime No.24 of 2021 dated 16.12.2021 on the file
of the first respondent and quash the same as against the petitioner alone.
2.Today, when the matter is taken up for hearing, the learned
counsel appearing for the petitioner would submit that it would be suffice
if a direction is issued to the first respondent to complete the
investigation and file a final report within a stipulated time.
3.The learned Government Advocate(Crl.side) appearing for the
first respondent would submit that the investigation in this case is almost
completed.
4.Recording the above said submission and considering the limited
prayer sought for by the learned counsel appearing for the petitioner, the
first respondent is directed to complete the investigation and file a final
report before the concerned jurisdictional Court within a period of one
month from the date of receipt of a copy of this order.
