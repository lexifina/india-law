# High Court for the State of Telangana, WA/232/2018, 2018-02-19

THE HONíBLE THE ACTING CHIEF JUSTICE RAMESH RANGANATHAN
AND
THE HONíBLE SMT JUSTICE KONGARA VIJAYA LAKSHMI
Writ Appeal No.232 of 2018
JUDGMENT: (Per the Honíble The Acting Chief Justice Ramesh Ranganathan)
Both the Learned Government Pleader for Revenue
(Assignment) appearing for the appellants, and Sri V.V.N.
Narayana Rao, Learned Counsel for the respondent-writ petitioner,
would agree that, instead of keeping the appeal pending on the file
of this Court, it would suffice if the order under appeal is set aside,
the Writ Petition is restored to file and the appellants are directed
to file their counter-affidavit, in the Writ Petition, within a specified
time frame.
As Learned Counsel on either side are in agreement, we set
aside the order under appeal and restore the Writ Petition to file.
The appellants shall file their counter-affidavit in the Writ Petition
within four weeks from today. It is open to Sri V.V.N.Narayana
Rao, Learned Counsel for the respondent-writ petitioner, to request
the Learned Single Judge to take up the WPMP for hearing any day
after four weeks.
The Writ Appeal is, accordingly, disposed of. The
miscellaneous petitions pending, if any, shall stand closed. There
shall be no order as to costs.
