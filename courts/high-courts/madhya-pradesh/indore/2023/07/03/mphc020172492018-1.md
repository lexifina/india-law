ORDER
None for the parties.
Record perused.
This application has been filed for restoration of M.A. No. 1003/2009
which stands dismissed for want of prosecution by order dated 27.06.2012.
2. Since the same is barred by time, an application bearing I.A.
No.4677/2018 has been filed under Section 5 of the Limitation Act for
condonation of delay in filing the restoration application.
3. For the reasons stated in the application, the same is allowed and the
delay in filing the restoration application is condoned.
4. Considered the main application as well.
5. For the reasons stated in the application, the same is allowed and M.A.
No.1003/2009 dismissed for want of prosecution by order dated 27.06.2012 is
restored to its original number for hearing on merits.
6. Let a copy of this order be kept in the record of M.A. No.1003 of
2009.
7. This MCC is accordingly allowed and disposed off.
