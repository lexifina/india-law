This application coming on this day before this court for hearing,
the Court made the following order:-
This application has been filed for a direction to the respondent to
furnish security to the tune of Rs.3,12,894.28 within the time fixed by this
Court and failing which the Order of attachment of the immovable
properties more fully described in the Judge's summons.
2. This Court by an Order dated 21.06.2021 directed the
respondent to furnish security for the claim amount.
3. Despite the Order of this Court directing to furnish security,
the respondent has not furnished any security and none appeared for the
respondent.
4. In view of the same, there shall be an Order of attachment of
the immovable properties described in the schedule to the judges summons.
