ORDER
This writ petition has been filed challenging the order
passed by the first respondent / Special Tahsildar granting patta
in favour of the second respondent.
2.Earlier, this Court ordered notice, and also granted on
order of interim stay. Now, the respondents filed petitions for
vacating the interim stay. By consent of both parties, the main
writ petition is taken up for final hearing, today.
3.Admittedly, against the order passed by the first
respondent / Special Tahsildar, an appeal is provided before the
https://hcservices.ecourts.gov.in/hcservices/

2
Revenue Divisional Officer, thereafter, a revision is also
provided before the District Revenue Officer. Without availing
such remedies, the petitioner cannot file this writ petition,
challenging the order passed by the Special Tahsildar. Hence,
this writ petition is not maintainable.
4.Accordingly, this writ petition is dismissed. However,
it is always open to the petitioner to file an appeal before the
Revenue Divisional Officer, if he so advised. No costs.
Consequently, connected miscellaneous petitions are closed.
