# High Court of Madhya Pradesh, WP/8636/2017, 2017-07-11

WP-8636-2017
(GUDDU PRASAD BASORE Vs THE STATE OF MADHYA PRADESH)
11-07-2017
Mr. Mahendra Pateriya, learned counsel for the petitioner.
Mr. Swapnil Ganguly, learned G.A. for the State.
Learned counsel for the petitioner after arguing for some
time seeks permission to withdraw this petition with the liberty to
file an appeal against the order dated 09th June, 2017.
The other side has no objection.
Accordingly, permission is granted.
Petition is dismissed as withdrawn with the liberty prayed
for.
It is expected that if any such appeal is preferred and
appellant authority will consider and decide the same
expeditiously.
(SUJOY PAUL)
