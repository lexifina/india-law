# High Court of Madhya Pradesh, MA/1049/2014, 2015-09-11

MA-1049-2014
(RIKHAI Vs HIRAMANI)
11-09-2015
Shri A.P. Shah, learned counsel for the appellant.
By this petition, the appellant wants to review the
order passed by the trial Court by which the
application filed under Order 40 Rule 1 of C.P.C. was
rejected by the trial Court.
Liberty is granted to file an application before the
trial Court to file additional documents, if any, for
the purpose of seeking order as desired in
accordance with law.
With this observation, this petition is disposed of.
(MOOL CHAND GARG)
JUDGE
