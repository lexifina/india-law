CORAM: HONOURABLE JUSTICE SMT. ANJANA PRAKASH
ORAL ORDER
3. 16-03-2012 Heard learned counsel for the petitioners and the Opposite
parties.
The present application has been filed for disobedience of
this Court’s order dated 6.7.1998 passed in C.W.J.C. No. 6975 of 1996 by
which this Court had issued notices in the main Writ application and
directed status quo as existing between the parties with respect to the land
detailed in Annexures 1 and 4. The present application was tagged to be
heard along with main Writ application. The main Writ application was
dismissed on 2.9.2011 as having become infructuous.
In view of such, I am not inclined to proceed with the matter
any further. This application is also dismissed on the same terms.
 S.Ali
 (Anjana Prakash, J.)
