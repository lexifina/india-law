CORAM: HONOURABLE MR.JUSTICE S.H.VORA
Date : 16/12/2019
ORAL ORDER
Learned advocate Mr.Vinod Maru appearing for learned
advocate Mr.Chudasama seeks time to produce additional
documents.
Request is declined.
It appears that the chargesheet is filed in the matter.
In view of the above, no case is made out to entertain the
present application and, therefore, the same is hereby rejected.
However, the applicants are at liberty to file discharge application
and also to file appropriate proceedings either u/s 397 or 482 of the
Code of Criminal Procedure, 1973 before appropriate competent
Court, after remedy to file discharge application is availed.
It is clarified that this Court has not examined the merits of
the present application.
(S.H.VORA, J)
