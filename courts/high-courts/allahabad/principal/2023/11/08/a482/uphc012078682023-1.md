# Allahabad High Court, A482/37045/2023, 2023-11-08

Neutral Citation No. - 2023:AHC:214640
Court No. - 87
Case :- APPLICATION U/S 482 No. - 37045 of 2023
Applicant :- Suresh Kumar Sonkar @ Ajay Kumar Sonkar
Opposite Party :- State Of U.P. And 2 Others
Counsel for Applicant :- Monarch Tripathi
Counsel for Opposite Party :- G.A.
Hon'ble Neeraj Tiwari,J.
1. Heard learned counsel for the applicant and learned A.G.A. for
the State.
2. At the very outset, Sri Monarch Tripathi, learned counsel for the
applicant submitted that name of applicant has incorrectly been
typed, therefore, this application may be dismissed as withdrawn
with liberty to file fresh application with correct description of
applicant.
3. Learned A.G.A. informed the Court that earlier, arising out of
same case crime number, another application u/S 482 Cr.P.C. has
been filed, upon which learned counsel for the applicant submitted
that applicant was not party in that matter and he is withdrawing
present application only to file fresh application with correct
description of applicant.
4. Under such facts and circumstance of the case, present
application is dismissed as withdrawn with liberty to file fresh
application
Order Date :- 8.11.2023
