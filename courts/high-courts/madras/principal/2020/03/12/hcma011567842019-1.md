This Application coming on this day before this court for hearing the
court made the following order:
This application is filed to appoint an Advocate Commissioner to
take possession of the property morefully described in the schedule
hereunder and handover the same to the applicant.
2. I heard the leaned counsel for the applicant.
3. Since the award has already been passed, the delivery of
possession cannot be granted as an interim measure. It can be ordered only
in the execution proceedings and if such an order is passed in this
application, it would attract third party interest, if any.
4. In such view of the matter, this application is dismissed.
