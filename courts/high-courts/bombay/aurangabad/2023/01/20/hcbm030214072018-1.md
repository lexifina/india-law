ORDER:-
1. The learned Counsel for the applicant submits that
this Court has granted interim relief which is continued from
time to time in respect of the matter which is sought to be
transferred in this application. However, the status report
obtained from the official website of the concerned Court
indicates that the matter which is sought to be transferred in
this application, is already disposed of on 19th November 2022.
2. The learned Counsel for the applicant seeks time to
take instructions if any application is made by the applicant
for restoration of this application.
3. However, even if such application is made, then also
the present application has become infructuous till the

restoration of the said matter. Moreover, the parties are also at
liberty to file fresh application on restoration of such matter.
There is no point in keeping this matter as it is before this

4. In view of the above, the present application stands
disposed of being infructuous. The interim relief granted if
any, also stands vacated. The applicant is always at liberty to
file fresh application for transfer, if the original petition which
is sought to be transferred in this application, is restored.
