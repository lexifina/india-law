# High Court of Uttarakhand, WPMS/1466/2010, 2014-09-01

MCC No. 611 of 2014 (Review application)
In
WPMS No. 1466 of 2010
Honíble Sudhanshu Dhulia, J.
Mr. Harendra Belwal, Advocate present
for the petitioner.
 Mr. Ashish Joshi, Advocate present for
the respondent no.4.
 Delay condonation application (CLMA
No. 9632 of 2014) is allowed.
 Heard learned counsel for the petitioner
as well as respondents.
 This writ petition was dismissed vide
order dated 03.03.2014. Now a review
application has been filed by the petitioner.
 There is no error apparent on the face of
order nor is there anything which could not be
stated earlier are placed before this Court
which may call interference by this Court.
Moreover there are extremely limited grounds
for interference on the review application
under Order 47 Rule 1 of Code of Civil
Procedure.
 In view thereof, review application is
dismissed.
 (Sudhanshu Dhulia, J.)
