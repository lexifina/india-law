ORDER
Petitioner is the accused in C.C.No.239/2002 on
the file of Judicial First Class Magistrate's
Court, Adoor, which is now pending as L.P.No.
119/2008. This petition is filed under Section 482
of Code of Criminal Procedure for a direction to
the Magistrate to consider the petition to be filed
by the petitioner under Section 205 of Code of
Criminal Procedure. Petitioner is not entitled to
get any anticipatory order on an application to be
filed before the Magistrate. It is up to the
petitioner to file an application and if the
Magistrate refuses to receive the application or
passes any order adverse to him, petitioner can
approach this Court.
Petition is disposed.
27th July, 2009 (M.Sasidharan Nambiar, Judge)
