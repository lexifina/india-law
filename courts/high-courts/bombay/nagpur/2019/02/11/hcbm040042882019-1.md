CORAM : V.M. DESHPANDE, J.
DATED : FEBRUARY 11, 2019
This is an application for condonation of
delay in filing application for restoration of appeal under
Section 378(4) of the Code of Criminal Procedure.
Application for leave to file appeal was rejected for want
of prosecution.
When application for grant of leave to file
appeal was rejected, that time, notices to accused
persons were not issued.
Heard Mr. Band, learned counsel for the
applicant and learned A.P.P. for the State.
For the reasons stated in the application, the
application is allowed. Delay is condoned. Similarly, the
application for restoration of Criminal Application No.
910/2018 is allowed.
The applications are disposed of accordingly.
Criminal Application No. 910/2018 be listed for hearing
on 25.02.2019.
