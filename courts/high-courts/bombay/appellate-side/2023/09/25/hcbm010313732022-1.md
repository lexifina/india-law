1. Heard.
2. While admitting the appeal on 23rd July, 2019, the appellant
was directed to file private paper book with a copy to the other side
within one year, failing which, it was directed that appeal would
stand dismissed.
3. Since the said direction has not been complied with, the
appeal came to be dismissed by the aforesaid self operative order.

4. Learned Counsel for the respondents objects the prayer.
5. After considering the reasons set out in the application,
application is allowed. Order of dismissal of the appeal is set aside.
Appeal is restored to it’s original file and the period for filing
private paper book stands extended for a period of four weeks.
6. If the appellant fails to file private paper book within the
extended period of four weeks, order dated 23rd July, 2019 would
stand revived automatically.
7. Application stands disposed of.
