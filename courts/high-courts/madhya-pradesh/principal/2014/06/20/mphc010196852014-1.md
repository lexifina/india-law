# High Court of Madhya Pradesh, RP/296/2014, 2014-06-20

R.P.No.296/2014
1
Ravi Shankar Tiwari & Ors. Vs. State of MP & Ors.
20/06/2014
Shri Ashok Kumar Gupta, learned counsel for the
petitioners.
Petitioner wants correction in the cause title of a decided
writ petition. The same amounts to amending the writ petition,
which cannot be permitted. There is no error in the order passed
by this Court. The error is in describing the name of one of the
petitioners.
If that be so, the concerned petitioner has to file a separate
petition after making correction in the cause title.
Accordingly, permitting the petitioner to file a fresh writ
petition, this review petition stands disposed of.
(Rajendra Menon)
Judge
