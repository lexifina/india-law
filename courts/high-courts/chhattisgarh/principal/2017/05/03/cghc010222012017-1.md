1. Heard.

2. This case is delinked from WP(C) No. 1092 of 2016.
3. Though, number of grounds urged in earlier round of litigatio, in which
the order dated 13/01/2017 has been passed by this Court, learned
counsel for the petitioner could not dispute that there is an efficacious
and statutory remedy available to file an appeal.
4. In that view of the matter, this petition is dismissed with liberty to file an
appeal. Certified copy of the impugned order Annexure P/4 be returned
to the petitioner, after retaining photocopy of the same.
