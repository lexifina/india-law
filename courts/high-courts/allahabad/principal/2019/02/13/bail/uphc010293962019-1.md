# Allahabad High Court, BAIL/6120/2019, 2019-02-13

Court No. - 66
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 6120
of 2019
Applicant :- Rampravesh Kumar Nishad
Opposite Party :- State Of U.P.
Counsel for Applicant :- Riyajuddin Ansari
Counsel for Opposite Party :- G.A.
Hon'ble Rajiv Gupta,J.
Amendment application filed today is taken on record.
Learned counsel for the applicant has submitted that after
concluding the investigation, the charge-sheet has been
filed against the applicant only under Sections 147, 148,
149, 308, 323, 352 IPC and other sections 307, 354-B,
452 IPC has been dropped.
Learned counsel for the applicant has next submitted that
the present bail application be dismissed as withdrawn in
order to enable the learned counsel for the applicant to
file fresh bail application before the court below under the
amended sections.
In view of above, this bail application is dismissed as
withdrawn in order to enable the learned counsel for the
application to file fresh bail application before the court
below under the amended sections.
Order Date :- 13.2.2019
KU
