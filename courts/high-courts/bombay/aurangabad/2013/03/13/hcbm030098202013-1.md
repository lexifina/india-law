 CORAM : SHRIHARI P. DAVARE, J.

COURT'S ORDER :

1. Heard learned Counsel for the applicant, and learned APP for the
respondent.
2. This is an application preferred by the applicant seeking
extension of time to surrender before learned Judicial Magistrate (F.C.),
Dhule, as per undertaking given by the applicant before this Court in
Criminal Application No. 1236 of 2013.
3. However, learned Counsel for the applicant, on instructions,
stated that the applicant has surrendered before learned Judicial
Magistrate (F.C.), Dhule, today i.e. 13th March 2013, and therefore,

 ( 2 )
present Application has become infructuous, and hence, requested to
dispose it of.
4. In view of the said submission, since the applicant has already
surrendered before learned Judicial Magistrate (First Class), Dhule, on
13th March 2013, as stated by the learned Counsel for the applicant,
Criminal Application has become infructuous and, therefore, same
stands disposed of.

 ( SHRIHARI P. DAVARE )
