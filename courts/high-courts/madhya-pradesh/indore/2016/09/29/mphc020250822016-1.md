# High Court of Madhya Pradesh, MCRC/9905/2016, 2016-09-29

-: 1 :-
Misc. Criminal Case No.9905 of 2016.
29.09.2016:-
Shri Anupam Chouhan, learned counsel for the
applicant.
Shri Pankaj Wadhwani, learned Govt. Advocate for the
Non-applicant/State, on advance copy.
With the consent of parties, heard finally.
O R D E R
THIS application under Section 482 of the Code
of Criminal Procedure has been filed for modification of
crime number in the order dated 26.09.2016 passed in Misc.
Criminal Case No.9011 of 2016.
2. Learned counsel for the applicant submits that
inadvertently in the application crime number has been
mentioned as Crima No.348/2016 instead of “Crime
No.350/2016”. This fact was disclosed when the applicant
wish to furnish the bail-bond before the Trial Court in
compliance of the aforesaid order. It is submitted that the
mistake is bona-fide, therefore, it be corrected. In support,
the applicant has filed the copy of FIR.
3. Learned Govt. Advocate has no objection in

-: 2 :-
allowing the application.
4. After due consideration, the application is
allowed. It is directed that in order dated 26.09.2016 passed
in Misc. Criminal Case No.9011 of 2016 the crime number
be read as “Crime No.350/2016” instead of Crime
No.348/2016. This order be read conjointly with the earlier
order.
5. Thus, the application is disposed of.
Copy of this order be sent immediately to the Trial
Court.
Certified copy as per rules.
 [ Jarat Kumar Jain ]
 JUDGE
(AKS)
