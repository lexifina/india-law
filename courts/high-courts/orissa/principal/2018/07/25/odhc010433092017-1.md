# High Court of Orissa, WP(C)/13581/2017, 2018-07-25

04. 25.07.2018 None appears for the petitioner. On 11.7.2018
also none appeared for the petitioner.
 The writ petition has been filed without
annexures. By order dated 11.7.2018, this Court directed
the petitioner to file copies of the annexures. The same have
not been filed.
 Accordingly, the writ petition is dismissed.
 It is open for the petitioner to file fresh writ
petition, if cause of action still survives.
