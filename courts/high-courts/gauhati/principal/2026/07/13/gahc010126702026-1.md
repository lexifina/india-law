2. The instant application has been filed for correcting a small error that has occurred
in the order dated 26.05.2026, due to the inadvertent error committed by the counsel
appearing for the applicant. The learned counsel appearing for the applicant submits that
the learned counsel while appearing on 26.05.2026, in WP(C) No. 6477/2022, failed to
seek liberty from this Court for filing the case afresh while withdrawing the aforesaid
WP(C) No. 6477/2022. Therefore, he prays that the order should be accordingly
corrected by giving liberty to the petitioner to file a writ petition again, if so advised.
3. Mr J Handique, the learned Standing Counsel for the Revenue Department, does
not have any objection to such prayer.
4. Accordingly, it is directed that in the order dated 26.05.226, in the last line, the
words-“with liberty to file afresh, if so advised”, should be added. Therefore, the last
line of the order dated 26.05.2026, is modified to the following extent:- Accordingly, the
matter is dismissed on withdrawal, with a liberty to file afresh, if so advised.
5. In terms of the above directions, the IA is disposed of.
