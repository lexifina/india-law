# High Court of Orissa, CONTC/441/2012, 2017-11-23

CONTC No.441 of 2012
08. 23.11.2017 The instant contempt application has been filed for no
n-compliance of the order dated 26.4.2011 passed by this Court in W.P.(CRL) No.337 of 2011, bu
t neither the copy of the same has been annexed to the contempt application nor it has been qu
oted with the contempt application.
 In very absence of the copy of the aforesaid order, it will not be app
ropriate to pass any order in the contempt application.
 Accordingly, the contempt application is dismissed.
