This application coming on for admission this day, the court passed the
following:
ORDER
Heard on I.A.No.327/2023 which is an application under Section 5 of the
Limitation Act for condonation of delay. The MCC is time barred by 113 days.
For the reasons stated in the application the same is allowed. The delay in
filing the MCC is hereby condoned.
T he present MCC is filed seeking restoration of W.P.No.7093/2022
which was dismissed in default for non-compliance of common conditional
order vide order dated 24.08.2022.
 The appeal was filed in default and the default was not cured within the
stipulated time. The application is allowed. W.P.No.7093/2022 is restored to its
original number.
A copy of this order be retained in the file of W.P.No.7093/2022.
