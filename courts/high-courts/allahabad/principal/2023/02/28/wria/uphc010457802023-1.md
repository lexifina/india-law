# Allahabad High Court, WRIA/3789/2023, 2023-02-28

Court No. - 36
Case :- WRIT - A No. - 3789 of 2023
Petitioner :- Pravesh Kumar
Respondent :- The State Of U.P. And 5 Others
Counsel for Petitioner :- Rajesh Kumar Mishra,Giriraj Pandey
Counsel for Respondent :- C.S.C.,Shanti Dhar Dwivedi
Hon'ble Neeraj Tiwari,J.
Heard learned counsel for the petitioner, learned standing counsel
for State-respondents and Sri Shanti Dhar Dwivedi, learned
counsel for the respondent Nos. 3 & 4.
Learned counsel for the petitioner submitted that he does not want
to press this petition and the same may be dismissed as not
pressed, for which learned counsel for the respondents has no
objection.
Accordingly, writ petition is dismissed as not pressed.
No liberty is granted to the petitioner to file such petition for the
same cause of action.
Order Date :- 28.2.2023
ADY
