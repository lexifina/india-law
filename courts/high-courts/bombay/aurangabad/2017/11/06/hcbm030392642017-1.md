PER COURT :-
There is no substance in this writ petition.
Petitioner-original defendant has not filed any written
statement. However, the petitioner-defendant has filed
an application for filing the written statement to the
amended plaint. Learned Civil Judge S.D. Jafrabad by
impugned order dated 19.7.2017 has rightly rejected the
said application since “NO W.S.” order has already been
passed against the present petitioner/original defendant
in the suit. I do not find any fault in the impugned
order. Writ Petition accordingly disposed of. No costs.
 ( V.K. JADHAV, J. )
