ORDER
This application has been filed by the plaintiff seeking leave of this Court
to file a reply statement to the written statement filed by the first defendant in
the above suit.
2. Heard the learned counsel appearing for the applicant.
3. The learned counsel appearing for the first respondent/first defendant
has no serious objection in allowing this application.
4. Considering the reasons stated in the affidavit filed in support of the
application, this Court is inclined to grant leave to the applicant/plaintiff to file
a reply statement.
5. Accordingly, this application is allowed. Consequently, the Registry is
directed to receive the reply statement.
