 1.The State of Jharkhand

 ------- Opposite Parties

 03/22.4.2016
Heard both sides.
Learned Counsel for the Opposite Party- JSEB submitted that show-cause has been filed on 13.4.2016 wherein a reasoned order has been
attached as Annexure- C.A.-1 (Memo no. 237 dated 10.3.2016). Therefore,
order has been complied with.
Learned counsel for opposite party has however raised an issue that
after the order dated 17.7.2012 passed in W.P.(C) No. 1834 of 2012,
technical sanction for Rs. 10,99,907/ was made for installation of
transformer. In Annexure-4 it is specifically stated that “All amount
chargeable to the Board under ADP head 2013-2014”. Then an estimate
for installation with the various heads coming from Serial no. 1 to 38 has
been indicated. Thereafter, also a general and technical report dated
8.7.2013 was made in which it has been mentioned “Hence this estimate
may kindly be sanctioned”. There is also a letter no. 30512 which is a
format for application of work order and it has been addressed to the
ESE,Ranchi to issue work orders for the relevant work in which the
amount of Rs. 10,99,907/- is indicated. Therefore, it appears that there
was some technical sanction done, the amount chargeable to the Board
under ADP Head 2013-14, a general technical report was there in which it
was indicated that estimate may kindly be sanctioned and accordingly a
letter for issuing work order was also there. So it appears that all these
have already taken place earlier and pursuant to the order passed by the
learned Single Judge dated 17.7.2012 the work was already in progress.
Subsequently an order dated 10.3.2016 memo no. 237 has
been issued wherein it has been stated that whether the transformer will
be installed in this portion or that portion of the applicant's land and she

 2
has to bear the cost of the transformer which appears to be in
contradiction to the earlier processes that have taken place.
Therefore, Opposite party no.2 is directed to file show cause
making it clear that as to how order dated 10.3.2016 has come up which
is in contradiction to the earlier order.
Put up on 13th May, 2016.
 (Ratnaker Bhengra, J.)
