ORDER
All these civil revision petitions are preferred against the
order of the Land Acquisition court in Sec.144 proceedings. It is
submitted that execution first appeals are filed in connected cases. It
appears that the proper remedy is to file execution first appeal and
not civil revision petitions. Therefore all these civil revision petitions
are closed as not maintainable with liberty to the revision petitioners
herein to file execution first appeals before this court.
2. In order to enable the revision petitioners to file execution
first appeals, the registry is directed to return the copy of the orders
produced in these cases. It has also to be stated that these civil
revision petitions were preferred under the mistaken impression that
it can be filed here and if any delay is occasioned, that may have to
be considered sympathetically.
The civil revision petitions are disposed of as closed in view
of the above discussion.
M.N.KRISHNAN, JUDGE
