 DATED : 12th SEPT., 2014
Learned Additional Public Prosecutor submits that
the State has decided to file an application for cancellation of
the bail before the learned Sessions Judge, who has granted the
anticipatory bail to the respondent and, therefore, prays for
grant of permission to withdraw this application with liberty to
file such application before the learned Sessions Judge.
Similar request was also made by the State in
Criminal Application No. 68 of 2013 and it was granted by the
learned Single Judge of this Court on 19/11/2013. There is no
reason for me why the prayer so made should not be granted.
Accordingly, the State is allowed to withdraw this
application with liberty to file application for cancellation of the
anticipatory bail granted to the respondent-accused before the
learned Sessions Judge, Wardha.
