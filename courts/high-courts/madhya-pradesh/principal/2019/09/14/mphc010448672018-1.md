(PRADEEP KUMAR SINGH Vs SHRI RAJIV RANJAN)
Jabalpur, Dated : 14-09-2019
Shri Rakesh Dwivedi, counsel for the petitioner.
Heard on I.A. No.11153/2018, an application for condonation of delay
in filing this M.C.C.
For the reasons stated in the application which is supported by an
affidavit, the same is allowed and the delay in filing the present M.C.C. is
hereby condoned.
Present M.C.C. has been filed for restoration of CONC No.1769/2013
which stood dismissed for non-compliance of common conditional order
dated 28.2.2014.
For the reasons mentioned in the application for restoration, the same
is allowed. The aforesaid CONC No.1769/2013 is restored to its original
number.
This M.C.C. stands allowed in above terms.
