HON'BLE MR. JUSTICE PANKAJ BHANDARI
 Order
03/03/2021
1. The matter comes up on application for correction in the
father’s name of the petitioner.
2. It is contended by counsel for the petitioner that in the
Lower Court order, father’s name was wrongly mentioned. Now
petitioner has filed the corrected order before the Lower Court.
Copy of the corrected order has also been filed before this Court.
4. I have considered the contentions.
5. Considering the contentions made by counsel for the
petitioner, application for correction in the father’s name of
petitioner is accordingly, allowed.
6. Amended cause title as well as copy of corrected order is
taken on record in the main bail application.

(2 of 2) [CRLMA-69/2021]
7. In the impugned order, father’s name of petitioner be now
read as “Ramveer” instead of “Mahaveer”.
(PANKAJ BHANDARI),J
