# High Court of Rajasthan, CRLMB/3897/2013, 2013-09-19

IN THE HIGH COURT OF JUDICATURE FOR RAJASTHAN
BENCH AT JAIPUR
ORDER
IN
S.B. Cr. Misc. 2nd Bail Application No.3897/2013
Banwari Lal @ Gattya Vs. State of
Rajasthan through Public Prosecutor
Date of Order ::: 19.09.2013
Hon'ble Mr. Justice Mohammad Rafiq
Shri Ritesh Jain, counsel for petitioner
Shri Sanjeev Kumar Mahala, Public Prosecutor
####
By the Court:-
This is second application for bail filed by the
petitioner. The first application of the petitioner for
bail, being Bail Application No.9530/2012, was
dismissed by this court vide order dated 20.09.2012
with liberty to the petitioner to again apply for bail
before the court below itself if the trial is not
concluded within one year. The petitioner has directly
filed this application for bail without applying first
before the trail court.
Learned counsel for the petitioner wants to
withdraw this application with liberty to file the
application before the trail court.
This second bail application is accordingly
dismissed as withdrawn with liberty as prayed for.
(Mohammad Rafiq) J.
