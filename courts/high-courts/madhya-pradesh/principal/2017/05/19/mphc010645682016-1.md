# High Court of Madhya Pradesh, MCC/3427/2016, 2017-05-19

MCC-3427-2016
(MR. CARNET ELIAS FERNANDES Vs SUPERINTENDENT OF POLICE)
19-05-2017
hri S.D. Mishra, learned counsel for the applicants.
Shri Ramesh Kushwaha, learned Panel Lawyer for the respondents no.1
and 2/State.
Heard on I.A. No.17280/2016, which is an application for condonation
of delay.
There is a delay of 32 days in filing the MCC.
For the reasons stated in the application, which is duly supported by
affidavit, I.A. No.17280/2016 stands allowed. Delay in filing the
application is hereby condoned.
This application has been filed for restoration of Writ Petition
No.11671/2015 which has been dismissed for want of prosecution on
10.10.2016. The application is supported by an affidavit of applicant
no.1 Carnet Elias Fernandes.
Keeping in view the reasons indicated in the application, the MCC is
allowed and it is directed that Writ Petition No.11671/2015 be restored
to its original number and list this case before the appropriate Bench.
Let a copy of this order be kept in the file of Writ Petition
No.11671/2015.
(SMT. ANJULI PALO)
JUDGE
