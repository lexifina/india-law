P.C. :
This is an Application filed by the Applicant / original complainant
seeking leave to file appeal against acquittal. Counsel for the Applicant
very fairly states that the present Application is completely misconceived
as an appeal under Section 372 of the Criminal Procedure Code is
maintainable and inadvertently the present Application has been filed. Counsel
for the Applicant therefore seeks to withdraw this Application with liberty to file an
appeal under Section 372 of the Criminal Procedure Code.
Accordingly this Application is dismissed as withdrawn with liberty as
prayed for.
 (P. V. Hardas, J.)
 (A.S. Gadkari, J.)
