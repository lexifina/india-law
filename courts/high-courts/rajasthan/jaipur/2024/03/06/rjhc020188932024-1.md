 S.B. Civil Misc. Application No. 92/2024 has been filed for
the rectification and/or modification of the order dated
16.02.2024.
For the reasons mentioned therein, the same is allowed.
Accordingly, it is made clear that the order dated 16.02.2024
be read in a manner so as to include within its ambit the liberty
granted to the petitioner to file a petition afresh, if the need so
arises in the future.
In terms of the above, S.B. Civil Misc. Application No.
92/2024 stands disposed of.
