# High Court of Uttarakhand, SPA/631/2014, 2014-11-21

SPA No. 631 of 2014
Honíble Sudhanshu Dhulia, J.
Honíble U.C. Dhyani, J.
Mr. Parikshit Saini, Advocate,
present for the appellants.
Mr. P.C. Bisht, learned
Standing Counsel, present for the
State/respondent nos. 1 and 2.
Mr. Shobhit Saharia, Advocate,
present for the respondent no. 4.
This is a Special Appeal
against the order of the learned
Single Judge of this Court dated
18.11.2014 by which it was directed
that in election to Cooperative Society
two votes should not be counted but
should be kept in a sealed cover.
This order has been challenged
in the present Special Appeal. Today
a statement has been given by the
learned counsel for both the parties
that since the elections have already
taken place and the result is declared
and his candidate has won the
election by an overwhelming nine
votes, so in any case the validity of
these two votes is immaterial for the
result of the election.
In view thereof, the Special
Appeal has become infructuous and
the same is hereby dismissed as
infructuous.
 (U.C. Dhyani, J.) (Sudhanshu Dhulia, J.)
