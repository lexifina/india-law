# High Court of Madhya Pradesh, MA/1733/2013, 2014-05-09

M.A. No.1733/2013
9.5.2014
Heard learned counsel for the appellant on
I.A. No.2527/2014.
A Bench of this Court vide order dated
12.7.2013 had granted four weeks' time to deposit
the deficit court fee. Thereafter again vide order
dated 29.1.2014 this Court had granted time to
make good the default. The aforesaid order is
peremptory in nature. However, till today the
deficit court fee has not been deposited. In case,
the aforesaid interlocutory application is allowed,
the same would tantamount to modification of the
order dated 29.1.2014.
For the aforementioned reasons, I.A. No.
2527/2014 is dismissed.
In the result, the appeal is also dismissed.
(Alok Aradhe)
