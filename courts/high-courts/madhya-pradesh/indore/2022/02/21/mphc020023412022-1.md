# High Court of Madhya Pradesh, MCRC/4190/2022, 2022-02-21

-1-
The High Court of Madhya Pradesh : Bench At Indore
M.Cr.C. No.4190/2022
Sanjay Thakur v/s The State of Madhya Pradesh
Indore, dated 21.02.2022
Shri Deepak Sharma, learned counsel for the applicant.
Shri Sudhanshu Vyas, learned Panel Lawyer for the
respondent / State.
This is the repeat (fourth) application filed by the
applicant under Section 439 of the Code of Criminal Procedure,
1973 for grant of bail.
The first bail application was dismissed as withdrawn
vide order dated 11.09.2020 passed in M.Cr.C. No.25209/2020,
second bail application was dismissed on merit vide order dated
11.05.2021 passed in M.Cr.C. No.7956/2021 and third
application was also dismissed vide order dated 21.09.2021
passed in M.Cr.C. No.33524/2021.
After examination of only one seizure witness, this bail
application has been filed. This type of practice is deprecated. No
case for grant of bail is made out in the matter.
Accordingly, this bail application is rejected.
