# High Court of Madhya Pradesh, MCC/1204/2015, 2015-06-17

MCC-1204-2015
(THE CHEIF EXECUTIVE OFFICER Vs M/S SANEE INFRASTRUCTURE PVT.LTD)
17-06-2015
Shri Pankaj Dubey, learned counsel for the applicant.
This application has been filed for restoration of
Arbitration Revision No.13/2014 which has been
dismissed in view of the peremptory order passed on
08/12/2014.
There being some delay in filing the application for
restoration, I.A. No.5678/2015 has been filed seeking
condonation of delay. Both the applications are supported
by affidavit of the counsel himself and there is no reason
to disbelieve the same. Finding the same to be bonafide,
both the applications are allowed. Condoning the delay in
filing the application, restoration application itself is
allowed.
Arbitration Revision is restored to its original
number. It be placed for orders before appropriate Bench.
Application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
(VANDANA KASREKAR)
JUDGE
