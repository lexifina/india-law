Admittedly when the matter came up on
22.3.2016, then in sequel to the order dated 8.3.2016, the

It is represented by learned counsel for

sentence having been vacated, no follow-up action has
been taken by respondent-State.
If that be so, this indeed is a serious matter. In
such circumstances, the State is directed to file an affidavit
specifying what follow-up action it has taken pursuant to the
order passed by this Court on 9.8.2016.

petitioner Sobha Ram has infact died on 25.11.2016.
