ORDER
This Civil Revision Petition has been filed to set aside the
order dated 05.03.2021 made in I.A.No.4 of 2021 in O.S.No.84 of 2018
on the file of the Principal District cum Judicial Magistrate,
Eraniel.
2.O.S.No.84 of 2018 was filed for suit for declaration and for
permanent injunction and an exparte order was passed on 18.11.2020,
as the petitioner/D1 was set exparte for both filing of written
statement and evidence, against which, the petitioner/D1 filed a set
aside petition to set aside the exparte order dated 18.11.2020. The
defendants have also filed written statement along with the set
aside petition. The petitioner also filed a petition in I.A.No.4 of
2021 on 17.12.2020.

3.Set aside petition was filed well within the time limit ie.,
on 17.12.2020 and the defendants have right to file written
submission along with set aside petition. The Principal District
Munsif cum Judicial Magistrate, Eraniel allowed I.A.No.4 of 2021 on
costs. However, it is to be pointed out that when set aside
petition was filed and pending, the Principal District Munsif cum
Judicial Magistrate, Eraniel ought not to have reserved the matter
for judgment. Both the parties are directed to co-operate for the
disposal of the trial in O.S.No.84 of 2018.
4.With these observations, this Civil Revision Petition is
dismissed. No costs. Consequently, connected Miscellaneous
Petition is closed.
