# Madras High Court, A/5514/2022, 2022-12-02

A.No.5514 of 2022
in C.S.No.633 of 2019
C.V.KARTHIKEYAN , J.
The application has been filed seeking to
set aside the exparte decree dated 15.06.2021
passed in the Civil Suit.
2. On an earlier occasion, the applicant
had filed Application No.2933/2022 seeking to
condone the delay of 27 days in filing
application to set aside the exparte decree.
3. That application was allowed by an
order dated 23.09.2022, but a condition was
imposed that the applicant herein should
deposit a sum of Rs.25/- lakhs to the credit of
the suit.
4. It is now informed that the said
condition had been satisfied and an amount of
Rs.25/- lakhs had been so deposited to the
credit of the suit.
5. The present application has been filed
as consequential in nature to set aside the
exparte decree.
6. Since the applicant has shown
bonafide by complying with the directions, the
exparte decree dated 15.06.2021 is set aside.
7. The application stands allowed.
