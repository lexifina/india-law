ORAL ORDER
2 07-12-2015 Learned counsel, Mr. V.R.P.Singh, appearing on behalf
of the petitioner seeks permission to withdraw this application on
the ground that, in fact, the impugned order by which the
injunction application filed under Order 39, Rules 1 and 2 of the
Code of Civil Procedure has been allowed, which is appealable
under Order 43,Rule 1 CPC. Therefore, he shall file the appeal, if
so advised, before an appropriate forum.
In view of the above submission, the petitioner is
permitted to withdraw this application with the liberty to file
appeal before an appropriate forum.
Accordingly, this writ application is dismissed.
