# Madras High Court, A/2002/2022, 2022-07-05

A.No.2002 of 2022
in C.S.No.7 of 2022
KRISHNAN RAMASAMY.J.,
This Application is filed to set aside the ex parte order dated
22.04.2022 against the applicant/defendant No.4 and accept the written
statement filed by the applicant/defendant No.4.
2. The learned counsel appearing for the applicant/defendant No.4
would submit that this Court has extended the time limit till 13.04.2022 for
filing written statements and the same was also filed within the said time.
However, this Court vide order dated 22.04.2022 set the
applicant/defendant No.4 ex parte. Therefore, the learned counsel seeks to
set aside the ex parte order dated 22.04.2022.
3. The learned counsel appearing for the respondents has also not
raised any objections to this application.
4. This Court is satisfied with the reasons stated in the affidavit filed
in support of the Application. Accordingly, this Application stands allowed.
