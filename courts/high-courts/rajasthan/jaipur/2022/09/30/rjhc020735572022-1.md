HON'BLE MR. JUSTICE SUDESH BANSAL
Order
30/09/2022
1. Matter has come up on misc. application seeking correction
of father’s name of respondent No.3/1 Sita Ram in the order dated
3.3.2022.
2. It has been stated that father’s name of Sita Ram is
‘Manohar Lal Gupta’ but inadvertently in the amended cause title
as also in the title page of judgment dated 3.3.2022, his father’s

(2 of 2) [CMAP-136/2022]
name has been mentioned as ‘Ram Chandra’. In support of such
contention, copy of Driving License of Sita Ram has been enclosed
with the application.
3. With consent of counsel for both parties, the error in
mentioning the wrong father’s name of respondent No.3/1 Sita
Ram is allowed to be corrected in the title page, counsel for
applicant is permitted to mention the correct father’s name of
respondent No.3/1 as ‘Manohar Lal Gupta’.
4. In view of above, in the order dated 3.3.2022, father’s name
of respondent No.3/1 Sita Ram S/o Ram Chandra be corrected in
red ink as Sita Ram S/o Manohar Lal Gupta, the correction made
in the original order be upload online showing asterisk (*) mark in
the order that father’s name of respondent No.3/1 Sita Ram S/o
Manohar Lal Gupta have been corrected subsequently. Rest part of
the order shall remain as such.
5. Accordingly, the application stands disposed of.
(SUDESH BANSAL),J
