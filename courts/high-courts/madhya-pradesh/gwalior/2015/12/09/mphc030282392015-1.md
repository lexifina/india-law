# High Court of Madhya Pradesh, MCRC/13381/2015, 2015-12-09

M. Cr. C. No.13381/2015
09/12/2015
Parties through their counsel.
The present application has been filed for correction of
typographical error in order dated 02/12/2015 passed by this
Court in M.Cr.C.No.11986/2015.
It has been stated that crime number has wrongly been
mentioned as Crime No.181/2015 where as the correct crime
number is 180/2015 and the same is under Sec.34(2) of M. P.
Excise Act.
Learned Government Advocate has not objected the
aforesaid prayer.
Therefore, the application stands allowed and in place of
Crime No.181/2015, Crime No.180/2015 is hereby substituted.
The present order shall be read conjointly with the order
dated 02/12/2015. Let a copy of this order be kept in the file of
M.Cr.C.No.11986/2015.
With the aforesaid, M.Cr.C. stands disposed of.
Certified copy as per rules.
