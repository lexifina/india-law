O R D E R
This revision petition is preferred against an order
made under Order XXXVIII Rule 8 C.P.C. When an application
under Order XXXVIII Rule 8 is filed it has to be decided as
per the procedure laid down under Order XXI Rule 58 CPC.
Order XXI Rule 58 makes it clear that the question of title
has to be gone into if it arises and it will have all the
trappings of a decree. So the said order passed will
become an appealable decree and the court which is
competent to entertain the appeal will be able to entertain
it. C.R.P is not maintainable. Therefore C.R.P is
permitted to be withdrawn with liberty to the revision
petitioner to file the appeal in the appropriate forum. Di
