# Allahabad High Court, WRIC/5746/2018, 2018-02-12

Court No. - 2
Case :- WRIT - C No. - 5746 of 2018
Petitioner :- Sandeep Singh
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Surendra Pal
Counsel for Respondent :- C.S.C.
Hon'ble Ram Surat Ram (Maurya),J.
Heard Sri Surendra Pal for the petitioner and Sri Pradeep Kumar for the
respondent-bank.
The petitioner has already challenged the recovery proceeding in Writ - C
No. 55660 of 2015, which was disposed of by order dated 30.9.2015.
Admittedly, the petitioner could not deposit the amount of installment, as
fixed in the order dated 30.9.2015. Now, the petitioner wants that some
time be granted. He could file an application before that Bench itself.
Fresh writ petition is not maintainable.
The writ petition is dismissed with liberty to the petitioner to file an
application before that Bench itself.
Order Date :- 12.2.2018
