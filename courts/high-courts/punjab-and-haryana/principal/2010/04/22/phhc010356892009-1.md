RAM CHAND GUPTA, J.(Oral)
The present petition has been filed under Section 482 of Code of
Criminal Procedure seeking direction to the respondents to provide adequate
security to the petitioners.
It has been stated by learned State counsel that respondent –
State has already provided adequate security to petitioner No.1 as petitioner
No.2 has already expired. He has further stated that respondent – State will
continue to provide adequate security to petitioner No.1.
Hence, in view of this statement of learned counsel for
respondent – State, no further order is required to be passed by this Court in
this petition.
Disposed of accordingly.

( RAM CHAND GUPTA )
