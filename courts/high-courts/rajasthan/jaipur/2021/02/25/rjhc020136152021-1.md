HON'BLE MR. JUSTICE SANJEEV PRAKASH SHARMA
 Order
25/02/2021
An application has been moved for modification of the order
passed by this court.
 Learned counsel for the applicant submits that while he had
prayed for withdrawing an appeal before the Tribunal, he should
be given liberty to file fresh appeal. The Tribunal had passed an
order in 2019 and allowed the appeal of the petitioner against
which the State filed the present writ petition.
At this stage, learned counsel for the applicant on
instructions from the applicant had prayed for allowing him to
withdraw his original appeal itself accordingly an order was
passed. There is no occasion to again give liberty to the
petitioner to file an appeal.
No case for modification is made out.

(2 of 2) [WMAP-31/2021]
The application is dismissed.
(SANJEEV PRAKASH SHARMA),J
