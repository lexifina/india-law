ORDER
The learned Public Prosecutor submits that proper
investigation has been conducted and the final report has
already been filed on 25/12/2006 before the Judicial First
Class Magistrate's Court-I, Paravoor. There is merit in the
submission of the learned Public Prosecutor that proper
investigation has been conducted.
2. In the light of the representation that the final report
has already been filed against all the accused, the petitioner
does not seek any further relief.
3. This Crl.M.C. is, in these circumstances, dismissed as
agreed.
