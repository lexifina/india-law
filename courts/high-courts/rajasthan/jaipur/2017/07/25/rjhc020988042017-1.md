Order
25/07/2017
 1. Nobody appeared for the petitioner before the Tribunal when
impugned order dated April,18 2017 was passed. The Tribunal has
only looked into one aspect of a prayer made in the original
application. The grievance is that other reliefs prayed were not
considered. If this be so, the petitioner should file an application
before the Tribunal pointing out to the Tribunal as aforesaid.
2. If such an application is filed the Tribunal shall decide the
same as per law.

(2 of 2)
[CW-7195/2017]
3. Observing as above the writ petition is dismissed.
