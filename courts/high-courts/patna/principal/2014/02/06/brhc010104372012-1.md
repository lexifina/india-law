ORAL ORDER
2 06-02-2014 Learned counsel for the parties are present.
This criminal revision application is directed against
a notice of show cause issued under section 110 of the Code of
Criminal Procedure (hereinafter referred to as ‘the Code’).
Section 397(2) of the Code does not permit revision against an
interlocutory order.
As prayed, learned counsel for the petitioner is
permitted to convert this criminal revision application into an
application under section 482 of the Code within four weeks
from today, failing which this criminal revision application shall
stand rejected without further reference to the Bench.

(Jyoti Saran, J)
