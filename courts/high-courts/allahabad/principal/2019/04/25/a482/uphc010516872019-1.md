# Allahabad High Court, A482/9793/2019, 2019-04-25

Court No. - 70
Case :- APPLICATION U/S 482 No. - 9793 of 2019
Applicant :- Phool Chandra
Opposite Party :- State Of U.P. And Another
Counsel for Applicant :- Ravindra Sharma
Counsel for Opposite Party :- G.A.
Hon'ble Sanjay Kumar Singh,J.
At the very outset, learned counsel for the applicant submitted
that on account of some defects, he does not want to press this
application and the same may be rejected as withdrawn with
liberty to file a fresh application.
The prayer so made is allowed.
The application is rejected as withdrawn with liberty to file a
fresh application with better particulars.
Office is directed to return the certified copy of the impugned
order to the learned counsel for the applicant after retaining the
photocopies of the same on record.
