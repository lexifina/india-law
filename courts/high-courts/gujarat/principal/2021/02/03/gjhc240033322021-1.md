ORAL ORDER
1. Heard Mr. Malav Mulani, learned advocate appearing for the
petitioners.
2. Mr. Mulani, learned advocate for the petitioners fairly states that a
similar issue arising between the same parties has already been decided
by this court vide order dated 28.01.2021 rendered in Civil Revision
Application No. 32 of 2021 which reads as under:
“1.
Heard Mr.Malav M. Mulani, learned advocate for the
applicants through Video Conferencing.
2.Perusal of the impugned order herein indicates that
the defendants / applicants herein had made an
application under Order 7 Rule 11 of the Code of
Civil Procedure that the suit be rejected on the
ground that it does not disclose the cause of action
