# High Court of Madhya Pradesh, MCC/700/2017, 2017-03-08

MCC-700-2017
(LAXMI SINGH Vs THE STATE OF MADHYA PRADESH)
08-03-2017
Shri Aniruddha P. Singh, learned counsel for the applicant.
Shri Swapnil Ganguly, learned Government Advocate for the
respondent-State.
Heard on I.A. No.3434/2017, an application for condonation of delay.
For the reasons mentioned in the application, the same (I.A.
No.3434/2017) is allowed. The delay in filing this application is hereby
condoned.
This application has been filed for restoration of Writ Appeal
No.720/2015 which has been dismissed on account of the common
conditional order passed on 16.11.2015. The application is supported by
an affidavit of Advocate, Shri Aniruddha P. Singh.
Keeping in view the reasons indicated in the application, the MCC is
allowed and it is directed that Writ Appeal No.720/2015 be restored to
its original number and list this case before the appropriate Bench.
Let a copy of this order be kept in the file of Writ Appeal No.720/2015.
(RAJENDRA MENON)
ACTING CHIEF JUSTICE
(SMT. ANJULI PALO)
JUDGE
