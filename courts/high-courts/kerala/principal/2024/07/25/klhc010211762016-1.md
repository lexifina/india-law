O R D E R
When this Criminal Miscellaneous Case came up for
consideration on 12.07.2024, this Court directed the
Registry to get a report from the Sessions Court,
Kasaragod and find out whether the case arising from
C.P.No.55/2016 on the file of the Judicial First Class
Magistrate Court – I, Kasaragod is still pending. The
Sessions Judge submitted a report in which it is stated that
the case is already disposed of acquitting the accused on
31.07.2018. If that be the case, nothing survives in this
case.
Therefore, this Criminal Miscellaneous Case is closed.
