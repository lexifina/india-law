# Bombay High Court, APPP/230/2007, 2007-04-13

[1]
 IN THE HIGH COURT OF JUDICATURE AT BOMBAY
 APPELLATE JURISDICTION
 CRIMINAL APPLICATION NO. 230 OF 2007.
 CRIMINAL APPLICATION NO. 511 OF 2007
 Husnain Amir Rahmat Qureshi q..Applicant
 V/s
 The State of Maharashtra ..Respondent.
 Mr.R.D. Suryawanshi, Advocate for the applicant.
 Mr. D.P. Adsule, APP for the State.
 CORAM : J.H. BHATIA, J.
 DATE : 13TH APRIL, 2007.
 P.C.
 . By order dated 9th March, 2007 in Criminal
 Application NO. 511 of 2007, bail was granted to the
 applicant. As in the application name of the applicant
 was shown as Husnain Amin Ahmed Qureshi the same name
 was typed and carried in the order. However, Mr. R.D.
 Suryawanshi, learned Counsel for the applicant, states
 that mistake was committed in the name of the father of
 the applicant in the application itself and it should
 have been Husnain Amir Rahmat Qureshi. He has produced
 a copy of the charge-sheet, which shows the name as
 Husnain Amir Rahmat Qureshi. Therefore, the application
 is allowed and in the order dated 9th March, 2007 in

 [2]
 Criminal Application NO. 511/2007, the name of the
 application be corrected and order be issued
 accordingly. This application stands disposed of.
 (J.H. BHATIA, J.)
