BEFORE
HONOURABLE MR. JUSTICE KALYAN RAI SURANA
ORDER
Date : 29-07-2019
Heard Mr. G. Choudhury, learned counsel for the applicant as well as Ms. J.
Rongpipi, learned Standing counsel, APDCL.
This is an application for restoration of the connected WP(C)7039/2013 which was
dismissed for default by order dated 04.04.2019. The learned counsel for the applicant has
submitted that due to inadvertence the counsel had missed the listing of the matter in the
part-II list and therefore, there was no one to represent the petitioner when the connected
writ petition was heard.
Although the learned counsel for the opposite party has objected to this application but
considering the causes shown this Court is inclined to accept the same to be as good and
sufficient cause which has prevented the applicant from being represented when the matter
was taken up on 04.04.2019. Accordingly, this application stand allowed and WP(C) 7039/13
is restored to file. Accordingly, this application stands allowed.
 JUDGE
