# Madras High Court, CRL OP(MD)/10545/2019, 2021-11-19

THE HON'BLE MR JUSTICE G.ILANGOVAN

and

vs.
1.Sabeera Begum
2.Rraffiathul Batchiriya ... Respondents/Respondents/
 Petitioners
PRAYER: Criminal Original Petition filed under Section 482 of the
Code of Criminal Procedure, to set aside the order in Crl.R.C.No.22
of 2019 on the file of the Additional District Judges Court (Fast
Track Court), Kumbakonam, dated 09.04.2019, in confirming the order
in Crl.M.P.No.85 of 2015 in M.C.No.17 of 2002, on the file of Chief
Judicial Magistrate Court, (Thanjavur) at Kumbakonam, dated
15.12.2015.
For Petitioner : No Appearance
O R D E R
This petition is filed to set aside the order, in Crl.R.C.No.22
of 2019 on the file of the Additional District Judges Court (Fast
Track Court), Kumbakonam, dated 09.04.2019.
2.On the earlier occasion ie., on 30.07.2019, notice was
ordered to the respondents. But, that was not effected. So, it was
listed on 09.11.2021. On the date also, there was no representation
for the petitioner. So, it has been posted today, under the caption
'for dismissal'. Even today, there is no representation, for the
petitioner.
3.In view of the above, this Criminal Original Petition is
dismissed for default. Consequently, the connected miscellaneous
petition is closed.
Sd/-
