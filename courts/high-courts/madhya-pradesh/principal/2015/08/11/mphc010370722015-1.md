# High Court of Madhya Pradesh, MCC/2145/2015, 2015-08-11

MCC-2145-2015
(SATISH CHAND GUPTA Vs THE STATE OF MADHYA PRADESH)
11-08-2015
Shri Ravi Dwivedi, learned counsel for the petitioner.
Heard.
This application has been filed for correction of typographical
error in the order dated 13.07.2015 passed in W.P. No.10877/15.
It is submitted by the counsel that in the aforesaid order, the
date of transfer has been mentioned 16.06.2015, however, the
correct date is 5.6.2015.
In this view of the matter, the application is allowed, where in
the order dated 13.7.2015 passed in W.P. No.10877/15, it is
mentioned the order dated 16.06.2015, it be read as 05.06.2015.
MCC is allowed as indicated above.
No order as to the costs.
Certified copy as per rules.
(S.K. GANGELE)
JUDGE
