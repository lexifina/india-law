# High Court of Madhya Pradesh, MCC/2361/2015, 2015-08-18

MCC-2361-2015
(BIHARI LAL SAHU Vs THE STATE OF MADHYA PRADESH)
18-08-2015
Shri Ashok Kumar Pandey, learned Counsel for the applicant.
Ms. Vandana Shrivastava, learned Panel Lawyer for the
respondent/State.
This application has been filed for restoration of Writ Petition
No.10995/2014, which was dismissed for want of prosecution on
14/05/2015. There being some delay in filing the application for
restoration, therefore, I.A. No.10308/2015 has been filed seeking
condonation of delay. Both the applications are supported by an
affidavit and there is no reason to disbelieve the same. Finding the
same to be bona fide, both the applications are allowed.
Condoning the delay in filing the application, restoration
application is itself allowed.
Writ Petition No.10995/2014 is restored to its original
number.
After restoration, Writ Petition No.10995/2014 be placed for
orders before appropriate Bench.
Application stands allowed and disposed of.
Certified copy as per rules.
(VANDANA KASREKAR)
JUDGE
