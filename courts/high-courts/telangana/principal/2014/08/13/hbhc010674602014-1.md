# High Court for the State of Telangana, CRLP/8888/2014, 2014-08-13

THE HON’BLE SRI JUSTICE C. PRAVEEN KUMAR
CRIMINAL PETITION No.8888 of 2014
ORDER:
The petitioners, who are accused Nos.1 to 6, filed the present
application under Section 482 of the Code of Criminal Procedure, 1973,
seeking quashing of all further proceedings in C.C.No.30 of 2013 on the
file of the Additional Judicial First Class Magistrate, Thadepalligudem.
When the matter is taken up for hearing, the learned counsel for
the petitioners seeks permission to withdraw the petition, with a liberty
to file an application for discharge, in case the charges have not
already framed in C.C.No.30 of 2013 on the file of the Additional
Judicial First Class Magistrate, Thadepalligudem.
Permission as sought for is accorded.
Accordingly, the Criminal Petition is dismissed as withdrawn with
a liberty to file an application for discharge before the Court concerned
in case the charges are not already framed. As a sequel thereto,
Miscellaneous Petitions, if any, pending in this Criminal Petition, shall
stand dismissed.
