BEFORE
HON'BLE MR JUSTICE SONGKHUPCHUNG SERTO
ORDER
Date : 24-09-2019
Heard Mr. Arenlong, learned counsel appearing for the petitioner
and Mr. A. Zho, learned counsel appearing for the State respondents.
Mr. Arenlong, learned counsel for the petitioner submits that there is a
proposal for settlement of the issues involved in this writ petition outside the
Court therefore, he has been instructed to withdraw the petition with a
prayer to grant liberty to file afresh if need arise.
Mr. A. Zho, l earned counsel appearing for the State respondents
submitted that he has no objection in allowing the prayer for withdrawal but
regarding liberty to file afresh he has objection because pleadings are already
complete.
Considering the submissions of both the learned counsels, the
petitioner is allowed to withdraw the petition with liberty to file afresh if need
arises.
Accordingly, the writ petition is disposed of on withdrawal.
