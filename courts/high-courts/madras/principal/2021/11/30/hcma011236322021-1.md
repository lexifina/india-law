# Madras High Court, A/3932/2021, 2021-11-30

A.No.3932 of 2021
and
C.S.No.416 of 2019
N.ANAND VENKATESH.,J
This application has been filed by the applicant / plaintiff
seeking for leave of this Court to file additional document, which is a sale
notice dated 22.03.2016, which was issued under the SARFAESI Act.
 2. This applicationhas been opposed by the
respondents/defendants by filing a counter affidavit. The main ground on
which the respondents have opposed this application is that the
additional document pertains to the notice issued to the sister concern
namely M/s.Rarefield Engineers P Ltd., which is a separate legal entity.
Therefore if at all the applicant wants to reply upon this document, the
sister concern must be made as a party in this suit failing which the
applicant cannot rely upon this document.
3. Heard Mr.T.V.Badrinarayanan, learned counsel for the
applicant and M/s.Aiyar and Dolia, learned counsel for the respondents.
4. In the considered view of this Court, this Court is only in the
process of dealing with this application to permit the applicant to file
additional document. The relevancy of this document and the extent to
which it can be relied upon by the applicant, are matters for
consideration when the said document is marked and is relies upon by
