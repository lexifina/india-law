# High Court of Orissa, CONTC/1309/2017, 2018-12-18

02. 18.12.2018 Heard learned counsel for the petitioner.
On perusal of the record, it reveals that the
order dated 10.04.2017 passed by this Court OJC No.
16158 of 1997 is neither quoted nor the same has been
indicated in the contempt application. Therefore, this
Court is not inclined to entertain this application.
However, liberty is granted to the petitioner to file a
fresh application along with the copy of the order, if he
is so advised.
