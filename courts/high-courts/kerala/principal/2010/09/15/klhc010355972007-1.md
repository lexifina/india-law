ORDER
Petitioner the accused in S.T.851/2006 on
the file of Judicial First Class Magistrate's
Court-III, Thrissur filed this petition to
transfer the case to Judicial First Class
Magistrate's Court-II, Sulthan Bathery
contending that entire transaction has taken
place within the jurisdiction of Judicial First
Class Magistrate's Court, Sulthan Bathery and
not within the jurisdiction of Judicial First
Class Magistrate's Court,Thrissur. It is also
contended that petitioner is not in a position
to defend the case by travelling 300 kms. away
from his place and for the convenience of the
parties and the witnesses, the case is to be
transferred to Sulthan Bathery. It is also
contended that C.C.44/2007 is pending before

Tr.P(Crl)52/2010 2
the Judicial First Class Magistrate's Court-II,Sulthan Bathery in respect of the autorikshaw
which was hypothecated and taken away by the first
respondent and it is necessary to try both the
cases together. First respondent opposed the
application for transfer contending that Judicial
First Class Magistrate's Court, Thrissur has
jurisdiction to try the case and part of cause of
action has arisen within the jurisdiction of
Judicial First Class Magistrate's Court, Thrissur.
2. Learned counsel appearing for the
petitioner and learned counsel appearing for first
respondent were heard.
3. The question whether Judicial First Class
Magistrate's Court, Thrissur has jurisdiction to
try the case or not canvassed by the petitioner is
not to be decided in an application for transfer
on the facts of the case. That is a matter to be
decided by the concerned Magistrate while trying
the case. Therefore on the ground of want of
jurisdiction, the case cannot be transferred as

Tr.P(Crl)52/2010 3
sought for.
4. But it is admitted case that the first
respondent has a Branch Office at Kalpetta
Annexure B the details of the hypothecation
statement in respect of the transaction entered
into by the petitioner with the first respondent
was issued from Kalpetta Branch office of the first
respondent Company. Petitioner is a resident of
Pulpally within the jurisdiction of Judicial First
Class Magistrate's Court, Sulthan Bathery. If
petitioner is to defend the case at Judicial First
Class Magistrate's Court, Thrissur there is force
in the submission of the petitioner that he has to
travel a distance of more than 300 kms. It would
cause only difficulty to the petitioner. At the
same time as first respondent, a Private Limited
Company is having a Branch office at Kalpetta.
Hence even if the case is transferred to Sulthan
Bathery, it will not cause any difficulty to the
first respondent. It would only help the witnesses
as the witnesses need not travel to Thrissur. In

Tr.P(Crl)52/2010 4
such circumstances, in the interest of justice,
S.T.851/2006 on the file of Judicial First Class
Magistrate's Court-III, Thrissur is transferred to
Judicial First Class Magistrate's Court-II, Sulthan
Bathery. But the case cannot be tried jointly with
C.C.44/2007 as sought for.
Petition is disposed.
