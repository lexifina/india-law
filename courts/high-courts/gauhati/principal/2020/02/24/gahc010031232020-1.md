24.02.2020
Heard learned counsel for the petitioners and learned counsel for the prosecution.
2. Sri Ram Nanda Kumar and Sri Dwipen Das @ Dipen Das have filed this application for bail under
Section 439 of Code of Criminal Procedure in Azara PS Case No.78/2020 under Section 20(b) of the
Narcotic Drugs and Psychotropic Substances Act, 1985.
3. I find that the same Dwipen Das filed another application for bail through a different counsel
bearing Bail Appln No.368/2020 in context of the same crime.
4. Having gone through the contents of the application, I find that the factum of filing earlier
application for bail in the same FIR, which is pending adjudication, which is a material fact, has been
suppressed. Second application for bail has been filed by Dwipen Das vide Bail Appln 428/2020 while
earlier Bail Appln 368/2020 is pending adjudication. In the second application for bail it has not been
disclosed that earlier application is pending adjudication.
5. Both the applications are dismissed.
CHIEF JUSTICE
