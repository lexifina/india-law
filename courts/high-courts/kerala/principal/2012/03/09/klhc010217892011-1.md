O R D E R
In this petition under Section 482 of the Code of Criminal Procedure,
petitioner, who is the accused in S.T. 840 of 2011 on the file of the Judicial
Magistrate of the First Class, Nedumkandam, seeks an order to quash
Annexure A2 Final Report accusing offences under Sections 447 and 427
r/w Section 34 of the Indian Penal Code with a plea that the matter has been
settled between the parties. Since the offences alleged are compoundable, if
settled, the parties can very well file a petition under Section 320 of the
Code of Criminal Procedure before the trial court. No ground exists for
invoking jurisdiction of this Court under Section 482 Cr.P.C.
In the result, this petition is dismissed with liberty to the petitioner to
file a petition under Section 320 of the Code of Criminal Procedure.
