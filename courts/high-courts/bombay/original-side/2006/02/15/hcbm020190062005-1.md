 CORAM : H.L. GOKHALE &
 ABHAY S. OKA, JJ.
 DATED : 15th February 2006
 P.C. :
 1. Heard Mr.Rammurthy in support of this
 Petition. On being pointed out that there is no
 resolution of the 1st petitioner-Society
 authorising to file this Petition nor have the
 other petitioners sought any leave under Order I
 Rule 8 of the Code of Civil Procedure, 1908,
 Mr.Rammurthy seeks leave to withdraw the Petition.
 2. Petition is allowed to be withdrawn with
 liberty to file a fresh Petition if any such
 resolution is passed by the Society and if any
 leave is sought. Since the Petition is
 withdrawn, the order of status quo stands vacated.
 (H.L. GOKHALE, J.)
