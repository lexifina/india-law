# High Court of Madhya Pradesh, CR/253/2012, 2014-09-08

1
C.R. No. 253/2012
8.9.2014
Shri Praveen Chaturvedi, learned counsel for the
applicant.
It is submitted by learned counsel for the
applicant that on appellant having succeeded on an
application under Order 9 Rule 13, Code of Civil
Procedure, 1908 and ex parte judgment and decree
having been set aside, the present civil revision, which
was directed against the order passed in execution
proceedings has rendered infructuous.
Consequently, the revision stands dismissed as
rendered infructuous.
(SANJAY YADAV)
JUDGE
Vivek Tripathi
