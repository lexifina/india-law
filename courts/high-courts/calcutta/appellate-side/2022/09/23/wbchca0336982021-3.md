# Calcutta High Court, CRR/2249/2021, 2022-09-23

23.09.2022 IN THE HIGH COURT AT CALCUTTA
 Item No.58 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
 C.R.R. 2249 of 2021

 Sudipta Pakhira
 versus
 The State of West Bengal & Anr.
In Re: An Application under Section 482 of the Code of
Criminal Procedure, 1973.
Mr. Amarta Ghose,
Mr. Siddhartha Paul … For the Petitioner.
Mr. Santanu Chatterjee … For the State.
 Mr. Ghose, learned advocate appearing for the
petitioner challenges the continuance of the proceedings.
Mr. Chatterjee, learned advocate appearing for the
State produces the case diary.
I find that the report under Section 173 of the Code of
Criminal Procedure has been filed before the jurisdictional
court. The police officer/investigating officer of the case, on
completion of investigation, exonerated all the accused
persons from the charge-sheet. As such, subject-matter of
challenge before this Court has become infructuous.
Accordingly, no order need be passed in this revisional
application.
The revisional application being CRR 2249 of 2021 is,
thus, disposed of.
All pending connected applications, if any, are
consequently disposed of.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.

requisite formalities.
 (Tirthankar Ghosh, J.)
