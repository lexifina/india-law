ORAL ORDER
17 03-05-2012 Perused the office note dated 03.05.2012 and the
report of the process server at Flag D.
The report is dated 19.5.2011. The process server is
reported that the sole appellant has died. No substitution
application has been filed within the prescribed period. Therefore,
the appeal has already abated against the legal representatives of
the sole deceased appellant in view of the provision as contained
in Order 22 Rule 4 Sub Rule 3 C.P.C. Accordingly, this first
appeal is now incompetent and, therefore, the same is dismissed as
a whole.
S.S.
