It is submitted by the counsel for the petitioner that by
registered post, an application under Section 250 of MPLR Code has
been sent to Tahsildar, Tahsil Bhind, District Bhind, but no action has
been taken.
Heard the learned counsel for the petitioner.
It is not the case of the petitioner that he has filed an
application under Section 250 of MPLR Code as per the procedure
prescribed. The Tahsildar has no jurisdiction to entertain the
application under Section 250 of MPLR Code sent by registered post.

2
THE HIGH COURT OF MADHYA PRADESH
WP-1519-2021
Prashant Sharma Vs. State of MP and others
Accordingly, this petition is dismissed.
If so advised, the petitioner may file an appropriate application
in an appropriate manner before the Tahsildar, District Bhind.
Liberty so granted to the petitioner should not be construed as
a direction to entertain and allow the application filed under Section
250 of MPLR Code. If such application is filed, then the same shall
be decided strictly in accordance with law.
