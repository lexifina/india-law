# Madras High Court, A/5627/2011, 2022-03-02

A.No.5627 of 2011 in
O.P.No.51 of 1998
P.VELMURUGAN, J.
This application has been filed
to set aside the order dated 16.07.2009
passed in O.P.No.51 of 1998 and to
restore the O.P.No.51 of 1998 which was
dismissed for default.
The learned counsel for the
applicant has been repeatedly seeking
adjournments in this matter. The
application is pending from the year
2011. It can be inferred that the applicant
is not interested in prosecuting this
application. Accordingly, this
application is dismissed for default.
