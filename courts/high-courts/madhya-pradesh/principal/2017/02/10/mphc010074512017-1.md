# High Court of Madhya Pradesh, MCC/434/2017, 2017-02-10

MCC-434-2017
(N.P. TRADINGH COMLPANY Vs THE STATE OF MADHYA PRADESH)
10-02-2017
Shri D.D. Bhargava, learned counsel for the applicants.
Shri Swapnil Ganguly, learned Government Advocate for the
respondent/State.
This application has been filed for restoration of W.P.
No.13850/2016, which has been dismissed in view of non-compliance of the common conditional order passed on
17.10.2016.
There has been some delay in filing of the application.
I.A. No.2137/2017 has been filed seeking condonation of delay, the
application is supported by affidavit of the counsel himself and
finding the reasons indicated in the application to be bonafide,
both the applications are allowed condoning the delay in filing the
application for restoration. The restoration application itself is
allowed. W.P. No. 13850/2016 is restored to its original file and list
for order before the appropriate Bench.
(RAJENDRA MENON)
ACTING CHIEF JUSTICE
(SMT. ANJULI PALO)
