% 01.09.2026
1. It is fairly stated by the learned Counsel for the Decree Holder that the
Award sought to be executed, which was set aside by this Court in
OMP(COMM) 340/2021 vide judgment dated 08.04.2024, has been affirmed
as having been set aside by the Division Bench of this Court in an appeal
under Section 37 of the Arbitration and Conciliation Act, 1996, being
FAO(OS)(COMM) 132/2024 and FAO(OS)(COMM) 136/2024, vide
judgment dated 14.08.2026.
2. In view of the above, the present Petition has been rendered
infructuous.
3. Needless to state that if the Order passed by the Division Bench is set
aside, it is always open for the Decree Holder to either file a fresh petition or
an application in accordance with the law.
SUBRAMONIUM PRASAD, J
