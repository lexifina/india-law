Order on Board
09/05/2022
1. Learned counsel for petitioner submits that by virtue of order dated
22.11.2017 Co-ordinate Bench of this Court has granted four weeks' time
to the respondents to file return, but till date return has not been filed.
2. Heard counsel for petitioner, perused order dated 22.11.2017 (Annexure
C-1).
3. Though there was an order granting four weeks' time to the respondents
to file return, but in the same order it has been mentioned that the case to
be listed for final hearing alongwith WPS/3204/2016.
4. Considering facts of the case, nature of order dated 22.11.2017,
submission of counsel for petitioner, and the facts that since 2017 case
was not listed, I do not find any substance in this contempt petition.
5. Accordingly, contempt petition is dismissed.
