ORAL ORDER

proceedings in C.C.No.763 of 2016 on the file of the Judicial First
Class Magistrate, Special Mobile Court, Eluru.

System (CIS), the aforesaid case has already been disposed of on
11.02.2020. Therefore, this petition has now rendered
infructuous.

infructuous. As a sequel, all the pending miscellaneous
applications shall stand closed.
