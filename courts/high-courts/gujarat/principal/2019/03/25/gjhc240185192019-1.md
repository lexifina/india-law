ORAL ORDER
Learned counsel appearing for the applicant,
at the outset, without going into the merits of
the case, submits that the applicant has
challenged the order passed by 12th Additional
Chief Judicial Magistrate by which the present
private respondents are released on bail, for
which remedy is available with the applicant to
file an application under Section 439(2) of the
Code of Criminal Procedure, 1973 before the
concerned Sessions Court. He, therefore, seeks
permission to withdraw this application with a
view to file an application before the concerned
Sessions Court.
Permission as prayed for is granted.
Application stands disposed of as withdrawn. It
