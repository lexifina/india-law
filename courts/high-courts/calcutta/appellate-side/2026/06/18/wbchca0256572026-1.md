1. Learned advocate representing the petitioner submits
that after filing of this writ petition trouble started as
a result thereof present writ petition is devoid of
necessary averments and prayer in connection with
incident which took place post filing of this writ
petition.
2. State respondents and respondent nos.4 to 7 are
represented by learned advocates.
3. Since new issue cropped up after filing of the writ
petition, as prayed for leave is granted to the
petitioner to withdraw the writ petition with liberty to
file afresh.
4. The writ petition stands dismissed as withdrawn.
5. However, this order shall not preclude the petitioner
to file a writ petition with necessary particulars.
6. Parties to act on the server copy of this order duly
downloaded from the official website of this Court.
 (Saugata Bhattacharyya, J.)
