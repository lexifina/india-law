1. It is contended by counsel for the petitioner that erroneously
bail application has been filed.
2. It is contended that the bail application be treated as S.B.
Criminal Appeal
3. Application heard. Application for treating the bail application
as criminal appeal filed by the petitioner is allowed. For the
purpose of statistics, the bail application is dismissed.
4. Registry is directed to register the bail application as S.B.
Criminal Appeal.
5. Office to proceed.
