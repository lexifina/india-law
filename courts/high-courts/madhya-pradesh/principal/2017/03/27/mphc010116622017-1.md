# High Court of Madhya Pradesh, MCC/686/2017, 2017-03-27

MCC-686-2017
(INDRA BUS SERVICE Vs THE IFCO TOKIYO INSURANCE COMPANY LIMITED)
27-03-2017
Shri B.K. Dubey, learned counsel for the applicants.
Heard on I.A. No.3788/2017, an application for condonation of delay.
For the reasons mentioned in the application, which is duly supported by
an affidavit of Suresh Kumar Mehta, the same (I.A. No.3887/2017) is
allowed. The delay in filing this application is hereby condoned.
This application has been filed for restoration of M.A. No.2341/2016
which has been dismissed for non compliance of the peremptory order
dated 16.11.2016. The application is supported by an affidavit of
Advocate-Shri B.K. Dubey.
Keeping in view the reasons indicated in the application, the M.C.C. is
allowed and it is directed that M.A. No.2341/2016 be restored to its
original number and list this case before the appropriate Bench.
Let a copy of this order be kept in the file of M.A. No.2341/2016 .
(SMT. ANJULI PALO)
JUDGE
