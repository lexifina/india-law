This petition coming on for conciliation this day, the Bench passed the
following:
ORDER
By this petition, petitioner has assailed the transfer order dated
24.11.2022.
According to the petitioner vide order dated 05.12.2022, operation of
impugned transfer order has been stayed by this Court. According to him, the
transfer order has not been given effect so far.
In view of the above, this writ petition is disposed of setting aside the
impugned order dated 24.11.2022 so far as it relates to the present petitioner.
However, the respondent/ State is at liberty to pass a fresh order if any
administrative exigency still exists or occasion so arises.
This order will not effect the posting of respondent No.6 and he be
allowed to continue unless any fresh order is passed.
