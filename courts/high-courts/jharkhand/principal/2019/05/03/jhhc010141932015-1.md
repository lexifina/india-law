07/03.05.2019 After some argument, learned counsel for the petitioner seeks permission to
withdraw this application on the ground that earlier this petitioner has preferred

Considering the submission made by learned counsel for the petitioner that the
same issue has already been decided by a co-ordinate Bench of this Court, the present
application is dismissed as withdrawn.
