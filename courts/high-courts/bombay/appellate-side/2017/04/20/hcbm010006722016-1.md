P.C. :
1. The learned counsel for the Petitioner Mr.Kanetkar on
instructions states that since Execution Proceeding has been disposed
of, the above petition challenging an interlocutory order passed
therein does not survive.
2. The petition is accordingly disposed as having turned
infructuous. Needless to state that it would be open for the Petitioner
to adopt appropriate remedy against the final order passed for the
Executing Proceeding, if so advised, which may also include a
challenge to the instant order.
