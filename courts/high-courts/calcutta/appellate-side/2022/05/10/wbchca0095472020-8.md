# Calcutta High Court, CRR/707/2020, 2022-05-10

10.05.2022 IN THE HIGH COURT AT CALCUTTA
 Item No.26 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
 C.R.R. 707 of 2020

 Smt. Sumana Ghosh
 versus
 The State of West Bengal & Anr.
In Re: An Application under Sections 397/401 read with
Section 482 of the Code of Criminal Procedure, 1973.
Mr. Ayan Bhattacherjee,
Mr. Pawan Kumar Gupta,
Mr. Kaushik Chowdhury,
Ms. Sofia Nesar,
Mr. Santanu Sett,
Mr. Ishan Bhattacharya … For the Petitioner.
Mr. Madhusudan Sur,
Mr. Manoranjan Mahata … For the State.
Report dated 04.05.2022 submitted by Mr. Sur, learned
advocate appearing for the State be kept on record.
The said report reflects that the present petitioner viz.,
Sumana Ghosh has been discharged from the case.
In view of the fact that the State is not intending to
pursue the litigation against the present petitioner, this
revisional application has become infructuous.
Mr. Bhattacherjee, learned advocate appearing for the
petitioner submits that the petitioner would follow up
regarding the prayer for discharge advanced by the
investigating agency before the jurisdictional court.
In view of the present position, this revisional
application before this Court has become infructuous.
Accordingly, the revisional application being CRR 707
of 2020 is disposed of as infructuous.

2
Interim order, if any, is hereby vacated.
All pending connected applications, if any, are
consequently disposed of.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance with all
requisite formalities.
 (Tirthankar Ghosh, J.)
