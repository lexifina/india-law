ORDER
This is a proceedings instituted under Section 482 of
the Code of Criminal Procedure seeking orders quashing
Anneuxre A4 First Information Report and all further
proceedings thereto.
2. When this matter was taken up, the learned
Public Prosecutor submitted that on investigation, it was found
that the case is one to be referred and the investigating officer
is unable to file a refer report in the matter in the light of the
interim order passed by this Court interdicting the
investigation.
In the circumstances, the Crl.M.C. is closed
recording the submission made by the learned Public
Prosecutor, so as to enable the investigating officer to file the
refer report.
