By this application the applicant prays that the delay in
filing the review application be condoned. In the application it has
been stated that against the judgment passed in Second Appeal No.
371/2014 the applicant had preferred Special Leave Petition (SLP)
before the Hon’ble Supreme Court. On 17.07.2017 that SLP was
dismissed by observing that it was open for the applicant to move this
Court for clarification, if it found so necessary. The present review
application has been filed on 07.08.2017.
In that view of the matter, the delay in filing the review
application stands condoned. The civil application is disposed of.
