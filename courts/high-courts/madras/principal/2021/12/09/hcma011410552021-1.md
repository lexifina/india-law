# Madras High Court, A/4519/2021, 2021-12-09

A.No.4519 of 2021
in C.S.No.272 of 2015
N.SESHASAYEE, J.
This application is filed to set aside the
exparte order dated 26.03.2021 in the
above suit.
2.The learned counsel for the applicant
submitted that the defendant is suffering
with serious lung infection and the suit
is laid for partition.
3.Taking overall consideration, this
Court deems it fit to allow this
application.
4.Mrs.Sridevi, the learned counsel for
the plaintiff / respondent put her best
effort to resist this application, this
Court overrules the same, as there is a
cry for substantial justice in the suit for
partition.
5.In conclusion, this Court allows this
application.
09.12.2021
