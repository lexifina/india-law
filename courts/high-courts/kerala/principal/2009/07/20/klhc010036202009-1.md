O R D E R
This is an application for anticipatory bail under Section 438
of the Code of Criminal Procedure. The petitioners had filed an
application for anticipatory bail as B.A. No.2718/2009. That Bail
Application was dismissed by order dated 28/05/2009. The same
petitioners have filed this second Bail Application.
No change of circumstances is made out in the case and
there is no reason to entertain the second application particularly
when the first application was dismissed after considering all the
relevant facts.
The Bail Application is accordingly dismissed.
 K.T. SANKARAN, JUDGE
