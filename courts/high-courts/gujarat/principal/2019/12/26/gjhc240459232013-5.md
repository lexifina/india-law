 ORAL ORDER
Shri Mahesh Pujara, learned advocate for Shri
Ashish Dagli, learned advocate for the applicant, states that
since charge-sheet is filed, applicant would like to avail the
remedies available under the Code before appropriate Court.
Shri Mahesh Pujara, learned advocate seeks permission to
withdraw the present application to move appropriate Court for
the purpose.
Permission, as prayed for, is granted.
The present application stands disposed of as
withdrawn. Notice is discharged. Ad-interim relief granted
earlier, if any, stands vacated. The appropriate Court is
directed to decide the application in accordance with law, if
any made before it, and if not decided by that time. It is made
clear the this Court has not gone into the merits of the case.
(UMESH A. TRIVEDI, J.)
