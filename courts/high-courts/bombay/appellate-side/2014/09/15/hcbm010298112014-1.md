P.C. :
Heard Mr.Patil, the learned counsel for the applicant.
The previous application for bail filed by the applicant was allowed to
be withdrawn with liberty to apply afresh for bail after receipt of the
C.A's report, if so advised. The application was thus withdrawn on 4th
July, 2014. Admittedly, the C.A's report has not yet been received.
Inspite of this the present application has been filed on 24th July, 2014.
The learned counsel for the applicant submits that since the C.A's
report has not been filed, he has filed the present application without
waiting for the C.A's report. In my opinion, when the previous
application was withdrawn and liberty was sought to file another only
