# High Court of Madhya Pradesh, MCRC/5567/2012, 2012-07-19

M.Cr.C. No.5567/2012
19/07/2012
Shri B.R. Vishwakarma, learned Counsel for the
applicant.
Shri R.S. Parmar, learned Counsel for the
respondent/State.
Counsel for the applicant prays for withdrawal of
the application. He, however, prays for liberty of this Court
to file fresh application after some material witnesses have
been examined. Prayer is allowed.
The application is, therefore, dismissed as
withdrawn. However, liberty as prayed for is granted to the
applicant.
Cc as per rules.
(MRS. S.R. WAGHMARE)
 JUDGE
Later on:
On examination of the record, it is found that power has
not been filed by Shri B.R. Vishwakarma on behalf of the
applicant. In view of the above, it would be difficult to dismiss
the application as not pressed. The application is, however,
dismissed for want of prosecution.
A copy of this order be sent to the Trial Court for
information.
(MRS. S.R. WAGHMARE)
 JUDGE
soumya
