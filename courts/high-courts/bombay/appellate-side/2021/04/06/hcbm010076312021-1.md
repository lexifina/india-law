Mohd. Taufiq Mohd. Salim Memon ...Applicant
Versus
The State of Maharashtra ...Respondent
…..
Mr. Bhola S. Rai, Advocate for the Applicant.
Mr. Y. M. Nakhwa, APP for the Respondent – State.
…..
CORAM : PRAKASH D. NAIK, J.
DATE : 6th APRIL, 2021.
PC :
1. This is an application for bail. Pending this application,
charge-sheet has been filed against the applicant. It is submitted that
while this application is pending, the applicant had moved an
application before learned Magistrate, after the charge-sheet, which
has been rejected on 19th March, 2021. In view of change in
circumstances, the applicant intends to prefer an application for bail
before the Sessions Court. It is submitted that this application be
allowed to be withdrawn, with liberty to prefer application for bail
before Sessions Court.
2. In view of submission, application is allowed to be
withdrawn with liberty to prefer application for bail before Sessions
Court. Application stands disposed of accordingly.
(PRAKASH D. NAIK, J.)
