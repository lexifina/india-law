# Allahabad High Court, CAPL/4156/2018, 2018-08-10

Court No. - 29
Case :- CONTEMPT APPLICATION (CIVIL) No. - 4156 of
2018
Applicant :- Hemant Kumar And Another
Opposite Party :- Ratan Singh And 4 Others
Counsel for Applicant :- Archana Singh
Hon'ble Saral Srivastava,J.
The present contempt application has been filed alleging
violations of the order of this Court dated 05.07.2017. The
contempt application discloses that the applicants have
already preferred Contempt Application No.-637 of 2018
before this Court for the violation of the aforesaid order
and this Court vide order dated 08.02.2018 dismissed the
contempt application holding that the contempt petition
was misconceived.
Since the earlier contempt application has been
dismissed in which the non-compliance of the same order
was alleged, therefore, the second contempt application
is not maintainable, and is accordingly dismissed.
Order Date :- 10.8.2018
Israr
