# Calcutta High Court, CRR/520/2024, 2024-02-13

D/L65
13.02.2024
Bpg.
 C.R.R.520 of 2024
In Re: An application under Sections 397/401 read with Section 482 of
the Code of Criminal Procedure, 1973;
 Md. Shahed Khan and another
 Versus
 Fortune Integrated Assets Finance Ltd.
 Ms. Minal Palana
 Ms. Meera Agarwal.
 ...for the petitioners.
Learned advocate appearing for the petitioners intends to
withdraw the present revisional application as there are some
technical defects.
Accordingly, CRR 520 of 2024 is dismissed as not
pressed.
Petitioners are granted liberty to file afresh.
Department is directed to return the certified copy to the
advocate on record of the petitioners on the same being replaced by
photostat copies.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
 (Tirthankar Ghosh, J.)
