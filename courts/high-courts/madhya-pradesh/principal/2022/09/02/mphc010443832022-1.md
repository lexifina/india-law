This application coming on for admission this day, the court passed the
following:
ORDER
This is a third repeat bail application under Section 439 of the Code of
Criminal Procedure. The second application was dismissed as withdrawn with
liberty to repeat the same alongwith outcome of criminal antecedents as the
State counsel has pointed out that the applicant is having 28 criminal cases.
No order-sheet has been filed alongwith this application to point the
outcome of criminal antecedents of the aforesaid 28 criminal cases. In such
circumstances, this Court is not inclined to entertain this application at this
stage.
