Code of Criminal Procedure, 1973 as he is in custody since
14/12/2020 in connection with Crime No. 897/2020 registered at
Police Station Durg Kotwali, District Durg (C.G.) for the offence

application with liberty to file afresh application as and when
occasion arises.
3) Accordingly, the application is dismissed as withdrawn with the
liberty as stated above.
