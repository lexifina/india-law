# High Court of Madhya Pradesh, MCRC/2493/2015, 2016-03-21

1
M.Cr.C.No.2493/2015
21/03/2016
None for the parties.
Even on 11.3.2016 nobody gave appearance on behalf of
the applicant.
This application for transferring cases which are pending
at Bina Court, which is within the territorial jurisdiction of
main Seat Jabalpur, has been filed. The applicant should have
filed this application before the main Seat of High Court.
The application has wrongly been filed before this Court.
Thus, the application is dismissed as not maintainable
before this Court as well as in non-prosecution of the
applicant.
(JARAT KUMAR JAIN)
JUDGE

M.Jilla.
