ORDER
The learned counsel for the petitioner submitted that there
are mistakes in the Bail Application as regards the crime number
and the offences and that the petitioner intends to file a fresh Bail
Application showing the correct details. The counsel prayed for
permission to withdraw the Bail Application with liberty to file
another Bail Application. Permission is granted and the Bail
Application is dismissed as withdrawn with liberty to file a fresh
Bail Application showing the correct details.
K.T.SANKARAN,
 JUDGE.
