# Madras High Court, A/3232/2022, 2022-08-08

A.No.3232 of 2022
Appl.No.3232 of 2022
in
C.S.No.233 of 2020
KRISHNAN RAMASAMY, J.
This Application is filed to set aside the ex-parte order passed by this
Court on 11.04.2022 in C.S.No.233 of 2020 on the ground that the written
statement was not filed.
2. This Court had already condoned the delay in filing the written
statement. This is a consequential application.
3. Learned counsel appearing for the respondents has no objection for
allowing this application.
4. This Court is satisfied with the reasons stated in the affidavit filed
in support of this Application. Accordingly, this Application stands allowed.
5. Learned counsels appearing on both sides are directed to file draft
issues.
6. List the matter on 01.09.2022.
