Easwari ... Petitioner
Vs.
State by
Inspector of Police
T4 - Maduravoyal Police Station,
Chennai
(Crime No.1175/2014) ... Respondent
Prayer :
Criminal Original Petition filed under Section 482 of the Code of
Criminal Procedure, praying to direct the respondent herein namely
the Inspector of Police, T-4 Maduravoyal Police Station, Chennai to
file a final report concerned in Crime No.1175 of 2014 before the
concerned court within time stipulated by this Hon'ble Court.
For Petitioner : No Appearance
For Respondents: Mr.M.Maharaja
 Additional Public Prosecutor
ORDER
This petition is filed praying for a direction to the respondent
police to file final report in Crime No.1175 of 2014 within the time
frame stipulated by this Hon'ble court.
2.No representation for the petitioner. Heard the learned
Additional Public Prosecutor.
3.Considering the facts and circumstances of this case, this
Court deems it appropriate to direct the respondent police to file
final report in connection with the case in Crime No. 1175 of 2014,
as expeditiously as possible.
4.With the above observation, this criminal original petition is
disposed of.
