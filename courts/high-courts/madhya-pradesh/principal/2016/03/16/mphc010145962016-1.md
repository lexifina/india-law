# High Court of Madhya Pradesh, MCRC/4811/2016, 2016-03-16

MCRC-4811-2016
(UMESH Vs THE STATE OF MADHYA PRADESH)
16-03-2016
Smt.Indu Pandey, learned counsel for the applicant.
Shri S.K.Shrivastava, learned PL for the State.
Learned counsel for the applicant does not wish to press the
bail application and seeks liberty to apply before the trial Court
under Section 437(6) of the Cr.P.C., if occasion so arises.
If any such application is filed then the trial Court shall
consider the application independently as per provision of section
437(6) of the Cr.P.C. without influencing with the rejection order
of this Court.
With the aforesaid observations, the application is disposed
of.
C.C. as per rules.
(J.K. MAHESHWARI)
