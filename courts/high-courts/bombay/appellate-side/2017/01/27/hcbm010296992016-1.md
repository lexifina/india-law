In view of the earlier order dated 21.1.2016 the
learned counsel for the applicant seeks leave to withdraw
the present application with a view to avail the liberty
which was already granted to the applicant by the said
order dated 21.1.2016. It is to be noted that in the present
application i.e. Bail Application No.1439/2016 this Court
has not considered any merits of the application and the
present application is allowed to be withdrawn only with a
view to permit the applicant to avail the liberty earlier
granted. Application is disposed off.
