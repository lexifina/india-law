# Allahabad High Court, CMRA/580/2022, 2023-02-02

Court No. - 34
Case :- CIVIL MISC REVIEW APPLICATION No. - 580 of 2022
Applicant :- State of U.P.
Opposite Party :- Bhagwan Prasad
Counsel for Applicant :- Tej Bhanu Pandey
Hon'ble Saurabh Shyam Shamshery,J.
Order on Delay Condonation Application
1. This is a review application filed on behalf of State of U.P. with a delay of
almost more than three years to review the judgment and order dated
08.07.2019.
2. An application is filed for condonation of delay. In para 8 thereof it is
mentioned that permission to file review application was granted on 22.11.2021,
however, thereafter State took almost one year to file this review application
with only explanation that it was pending at the end of District Magistrate.
3. Supreme Court in the case of Esha Bhattacharya Vs. Managing Committee
of Raghunathpur Nafar Academy and Others, (2013) 12 SCC 649 has held
that though normally while considering application for condonation of delay
Court ought to have taken a lenient view instead of taking a pragmatic and hyper
technical view, however, when there is an inordinate delay of more than three
years and there is no explanation whatsoever, the same cannot be condoned as
doctrine of prejudice is attracted which warrants strict approach.
4. The application for condonation of delay is accordingly rejected.
Order on Review Application
The application seeking condonation of delay in filing review application
beyond time having been rejected vide order of date, this review application
being barred by limitation, is accordingly dismissed.
