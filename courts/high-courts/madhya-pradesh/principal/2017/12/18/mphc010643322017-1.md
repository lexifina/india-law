# High Court of Madhya Pradesh, MCC/3711/2017, 2017-12-18

1
MCC No.3711/2017.
Jabalpur, dated 18/12/2017.
Shri Ajeet Singh, learned counsel for the petitioner.
This application has been filed for restoration of Writ
Petition No.20546/2017 which was dismissed for non-compliance of peremptory order dated 04.12.2017. The
application is within limitation and the application is duly
supported by an affidavit by the counsel for the petitioner.
Finding the same to be bonafide, the application is allowed.
Writ Petition No.20546/2017 is restored to its original
number. Let a typed copy of this order be kept in the original
file of Writ Petition No.20546/2017.
After restoration, Writ Petition be placed for orders
before appropriate Bench.
MCC stands allowed and disposed of.
Certified copy as per rules.
 (MISS VANDANA KASREKAR)
 JUDGE
Devashish
