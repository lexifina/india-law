(ANIL KUMAR DIXIT Vs THE STATE OF MADHYA PRADESH)
2
Jabalpur, Dated : 08-09-2018
Shri V.D.S.Chouhan, counsel for the petitioner.
This petition has been filed by the petitioner against the order of
hi s transfer dated 16.07.2017 (Annexure P/1), whereby he has been
transferred from Gram Panchayat Katariya Block Dhimarkheda to Gram
Panchayat Pipariya (Bakal) Block Bahoriband.
With the consent of the parties, this order is set aside.
However, liberty is granted to the respondents to pass any fresh order, if
the occasion so arises.
Accordingly, this petition is disposed of.
