# High Court of Madhya Pradesh, MCC/1904/2015, 2015-07-21

MCC-1904-2015
(VARSHA PATEL Vs THE STATE OF MADHYA PRADESH)
21-07-2015
Shri Dhruv Verma, learned counsel for the applicant.
This application has been filed for restoration of W.P.
No.5947/2015 which was dismissed for want of
prosecution on 15.6.2015. Application is supported by an
affidavit of applicant and there is no reason to disbelieve
the same. Finding the same to be bonafide, the
application for restoration is allowed. Writ Petition is
restored to its original file. It be placed for orders before
the appropriate Bench. List the original writ petition
along with W.P.4295/2015.
Application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
(SUSHIL KUMAR GUPTA)
JUDGE
