# High Court for the State of Telangana, CRLP/8765/2013, 2013-08-22

THE HON’BLE SRI JUSTICE C. PRAVEEN KUMAR
CRIMINAL PETITION NO. 8765 OF 2013
ORDER:
1. This is a Criminal Petition filed by the petitioners under Section 482 of
Code of Criminal Procedure, 1973 to quash the proceedings in C.C.No.402
of 2011 on the file of the Judicial First Class Magistrate, Sullurpet.
2. After arguing the matter for some time, the learned counsel for the
petitioners seeks permission of this Court to withdraw the Criminal Petition
with a liberty to file application for discharge.
3. The permission is accorded.
4. Accordingly, the Criminal Petition is dismissed as withdrawn giving
liberty to the petitioners to file an application for discharge before the lower
Court. Miscellaneous petitions, if any, pending shall stand closed.
