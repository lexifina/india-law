# High Court of Madhya Pradesh, CONC/768/2014, 2016-09-23

CONC No.768/2014
23.09.2016
None for the petitioner.
Ms. Kirti Patwardhan, learned counsel for the respondent.
Learned counsel for the respondent has drawn my attention to
the letter dated 14/09/2016 and Cheque of Rs.43,550/- dated
6/08/2016 and submitted that order dated 12/07/2010, passed in
W.P. No.7529/2010(S) has been complied with. The claim of the
petitioner has been examined and amount has been paid to him
along with interest.
If that be so, we dispose of this contempt petition.
In case, if it is found that the order has not been complied with
the petitioner is at liberty to file a fresh contempt petition.
With the aforesaid, the contempt petition stands disposed of.
Rule Nisi, if any, stands discharged.
 (P.K. Jaiswal)
 Judge
