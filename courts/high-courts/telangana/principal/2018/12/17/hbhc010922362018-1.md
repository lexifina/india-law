# High Court for the State of Telangana, CRLP/13154/2018, 2018-12-17

THE HONíBLE DR.JUSTICE SHAMEEM AKTHER
CRIMINAL PETITION No.13154 OF 2018
ORDER:
This Criminal Petition, under Section 439(2) of the Code of
Criminal Procedure, 1973, is filed by the petitioner/de facto
complainant, seeking to cancel the bail granted to A-1 to A-3 on
19.06.2018 in Crl.M.P.No.897 of 2018 in Crime No.676 of 2018 on
the file of the learned II Metropolitan Magistrate, Cyberabad, L.B.
Nagar.
2. Heard the learned counsel for the petitioner/de facto
complainant. This application is filed to cancel the bail granted to
A-1 to A-3. A-1 to A-3 are not made parties to this application.
Therefore, the Criminal Petition is liable to be dismissed.
3. Accordingly, the Criminal Petition is dismissed giving liberty
to the petitioner to file an application afresh.
4. Miscellaneous petitions pending, if any, in this Criminal
Petition shall stand closed.
