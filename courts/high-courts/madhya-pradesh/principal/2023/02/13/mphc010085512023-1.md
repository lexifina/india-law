This application coming on for orders this day, the Court passed the following:
ORDER
Heard on I.A. No.3353/2023.
This is an application for correcting the name of father of the applicant in the cause
title.
It is pointed out that instead of Rehmat Ali in the cause title, it has been mistakenly
typed Ahmad Ali. It is prayed that such mistake be corrected.
Prima facie it appears to be an inadvertent mistake, hence the same is corrected.
Instead of Ahmad Ali it should be read as Rehmat Ali in the cause title.
Accordingly, I.A. No.3353/2023 is allowed and this M.Cr.C. is disposed of.
