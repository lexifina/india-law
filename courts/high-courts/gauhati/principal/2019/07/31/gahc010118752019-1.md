BEFORE
HONOURABLE MRS. JUSTICE RUMI KUMARI PHUKAN
ORDER
Date : 31-07-2019
Heard learned counsel for both the parties.
The petitioner herein has come forward with the grievance that both the cases which are
pending before the learned Sessions Court being Sessions Case No.362/2014 and Sessions Case
No.91/2016 should be tried together being the cross cases filed by both the parties against each
other. Although on earlier occasion, the petitioner challenged the impugned order dated 09.04.2019
passed in Sessions Case No.362/2014 which indicates that the case will run separately, but, it is now
submitted that both the cases have reached the stage of evidence and pending before the same
court. That being so, learned Sessions Judge, Kamrup, Amingaon is in a position to run both the cases
simultaneously to avoid conflict of judgments.
In view of the aforesaid submission and considering the materials on record, the challenge
made before this Court has now come to an end and accordingly, the present petition stands disposed
of with a direction to the learned Sessions Judge, Kamrup, Amingaon to proceed with both the cases
simultaneously so as to reach in a conclusion at the same time.
With the above observation and direction, the present petition stands disposed of.
