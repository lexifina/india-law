 CORAM: RAVI K. DESHPANDE, J.

 DATE : 11 JULY 2013.
P.C.:
1 Heard the learned Counsel for the petitioner.
2 The order impugned in this petition is passed by the Trial
Court on 11.2.2009 granting permission to the defendants to file written
statement.
3 Undisputedly, the written statement was not filed within a
period of 30 days, as prescribed under Order 8 Rule 1 of the Code of Civil
Procedure. There was delay of about one year in filing an Application for
permission to file written statement. The petitioner filed an Application for

2
wp.8622-2009.sxw
review of this order and the said Application was rejected by an order dated
9.7.2009 holding that alongwith written statement, an Application for
condonation of delay was also filed.
4 There is no reason assigned to condone the delay caused in
filing the written statement. Neither explanation is given nor it is
considered in the order dated 11.2.2009 passed by the Trial Court. The
order is virtually unreasoned order and hence it cannot be sustained.
5 In the result, the writ petition is allowed. Order dated
11.2.2009 passed below Exhibit 17 and order dated 9.7.2009 below
Exhibit 17 rejecting the Application are hereby quashed and set aside. The
matter is remitted back to the Trial Court to decide the Application below
Exhibit-17 afresh in accordance with law. No order as to costs.
 RAVI K. DESHPANDE, J.
