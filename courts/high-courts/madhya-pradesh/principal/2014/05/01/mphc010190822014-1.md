# High Court of Madhya Pradesh, MCRC/6142/2014, 2014-05-01

M.Cr.C.No.6142/2014
01.05.2014
Shri Bhupendra Tiwari, learned counsel for the
applicant.
Shri Manoj Kushwaha, learned Panel Lawyer for the
respondent.
Learned counsel for the applicant submits that in the
order dated 17/4/2014 passed in M.Cr.C. No.5269/2014 the
name of applicant has wrongly been mentioned as
'Dharmendra Banskar' whereas the name of applicant is
“Jitendra Banskar”.
Accordingly, it is directed that in the order dated
17/4/2014 the name of applicant shall be read as “Jitendra
Banskar, S/o Shri Bedilal Banskar”. This order shall be read
conjointly with order dated 17/4/2014 passed in M.Cr.C.
No.5269/2014.
Accordingly, the application is allowed.
Certified copy as per rules.
(Alok Aradhe)
