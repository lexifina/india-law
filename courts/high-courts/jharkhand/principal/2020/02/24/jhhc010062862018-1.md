07/24.02.2020 This petition has been filed for the following relief:
“For setting aside the order dated 9.1.2018 passed in Misc. Cr.
Application No.15/17 in connection with RC 05 (A)/2010-AHD – R
by learned Special Judge, CBI, Ranchi by which discharge application
of the petitioner has been rejected and the present case is pending in the
court of Special Judge, CBI, Ranchi.”
2. Mr. Sameer Saurabh, learned counsel appearing on behalf
of the petitioner seeks permission to withdraw this revision
application.
3. Considering the submissions made, this revision
application is dismissed as withdrawn. It is made clear that
withdrawal of this revision application will not prejudice the
case of either parties in any manner whatsoever.
4. Interim order, if any, stands vacated.
5. Pending interlocutory applications, if any, are dismissed as
not pressed.
6. Let this order be communicated to the learned court below
through ‘FAX’.

 (Anubha Rawat Choudhary, J.)
