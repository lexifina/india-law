# Madras High Court, A/5994/2022, 2023-02-06

A.No.5994 of 2022
A.No.5994 of 2022
in
C.S.No.31 of 2010
C.SARAVANAN, J.
This application has been filed to set aside the ex-parte order dated
11.01.2017 passed against the third defendant in C.S.No.31 of 2010.
2. Being satisfied with the reasons given in the affidavit filed in
support of this application, I am inclined to allow this application for setting
aside the ex-parte order passed on 11.01.2017 setting the applicant/third
defendant as ex-parte. Accordingly, this Application is allowed.
3. Considering the fact that this application is being allowed now, the
first respondent/plaintiff is permitted to file a Reply Statement to the Written
Statement of the applicant/third defendant, within a period of four weeks
from today.
