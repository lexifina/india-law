02. 1. This matter is taken up through Hybrid Arrangement
(Virtual/Physical) Mode.
2. Heard learned counsel appearing for the Parties.
3. Mr. R.N. Mishra, learned Addl. Govt. Advocate contended that
the order in question has been complied with passing of an order on
28.06.2023 vide Annexure-A to the compliance affidavit.
4. Mr. M.K. Mohanty, learned counsel for the Petitioner however
contended that the said order is not in compliance to the direction of
this Court.
5. All these things cannot be decided in a Contempt Petition.
However, if the Petitioner is aggrieved vide order dtd.28.06.2023,
he may file appropriate application challenging the same.
6. With the aforesaid liberty, the Contempt Petition is disposed of.
