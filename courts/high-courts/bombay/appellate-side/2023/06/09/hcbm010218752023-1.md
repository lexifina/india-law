CORAM : AMIT BORKAR, J.
DATED : JUNE 9, 2023
P.C.:
1. This is a second application filed under Section 438 of the
Code of Criminal Procedure,1973, in relation to crime No.138 of
2018 registered at Azad Nagar police station, Nashik, for the
offences punishable under Sections 406, 409, 420 r/w. 34 and
120-B of the Indian Penal Code and Section 3 of Maharashtra
Protection of Depositors Act.
2. This Court by an order dated 10th February, 2023 rejected the
earlier application under Section 438 of the Code of Criminal
Procedure,1973.
3. According to learned Advocate for the Applicant, technically
there is no change in circumstances, however in a related
proceedings pending before the Apex Court, the main accused has
deposited amount of Rs.6 crores to be distributed for depositors in
the State of Maharashtra, and the informant has received amount

4. Having considered the application in my opinion, once this

Bail Application is, therefore, rejected.
