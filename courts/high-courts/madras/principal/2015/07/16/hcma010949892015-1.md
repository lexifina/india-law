O R D E R
It is seen that the petitioner is facing trial in S.C.No.127 of
2013, on the file of the Principal Assistant Sessions Judge, Salem.
The petitioner has filed a Transfer Application before the learned
Sessions Judge, Salem, for transferring the above case from the file
of the Principal Assistant Sessions Judge, Salem, to any other
Court, for certain reasons, mentioned in the transfer application.
The said transfer application was presented before the Principal
District Sessions Judge, Salem, on 03.11.2014 and it was returned on
21.11.2014, with the following endorsement,
“How this Court is having jurisdiction to entertain
this petition. To be explained. Returned.”
Challenging this return, the petitioner has approached this Court.
2. When a Court returns a paper, asking for an explanation, it
is the duty of the litigant to comply with the returns and re-submit
https://hcservices.ecourts.gov.in/hcservices/

the same. If the High Court is approached, on this ground, this Court
will get relegated to the status of a passing clerk, which practice
this Court loaths.
3. Therefore, this petition is closed, with a direction to the
petitioner to file a fresh application, before the learned Sessions
Judge, Salem and if any query is raised by the Sessions Judge, it
should be explained and only if an order, refusing to take the
petition on file, is made, can that be subjected to judicial review.
No costs. Consequently, connected Miscellaneous Petition is also
closed.
