HON'BLE MR. JUSTICE PANKAJ BHANDARI
Order
04/07/2019
1. Petitioner has preferred this misc. petition seeking fair
investigation in FIR No.10/2016, registered at Police Station
Neemrana, District Alwar.
2. It is informed by learned public prosecutor that Police has
already submitted negative final report on 19.08.2017.
3. Since Police has already submitted negative final report, the
misc. petition has become infructuous and the same is dismissed
as having become infructuous.
4. However, petitioner may file protest petition, if so advised.
(PANKAJ BHANDARI),J
