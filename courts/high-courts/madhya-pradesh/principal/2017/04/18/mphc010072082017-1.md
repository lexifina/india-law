# High Court of Madhya Pradesh, MCC/413/2017, 2017-04-18

MCC-413-2017
(CHUNNILAL Vs RAMNATH SINGH)
18-04-2017
Shri B.P. Yadav, learned counsel for the applicant.
Heard on I.A. No.2462/2017, an application for condonation of delay.
For the reasons mentioned in the application, the same (I.A.
No.2462/2017) is allowed. The delay in filing this application is hereby
condoned.
This application has been filed for restoration of S.A. No.671/2001 which
has been dismissed for non-compliance of peremptory order dated
03.11.2016. The application is supported by an affidavit of Advocate-B.P. Yadav.
Keeping in view the reasons indicated in the application, the MCC is
allowed and it is directed that S.A. No.671/2001 be restored to its
original number and list this case before the appropriate Bench.
Let a copy of this order be kept in the file of S.A. No.671/2001.
(SMT. ANJULI PALO)
JUDGE
