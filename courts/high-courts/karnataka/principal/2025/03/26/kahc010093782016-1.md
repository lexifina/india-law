WP No. 42280 of 2016
ORAL ORDER
1. This writ petition is filed challenging the order by
which the interim order was vacated and which has
been passed by the Assistant Commissioner.
2. The learned counsel for respondent No.3 submits
that the main matter, which was pending before the
Assistant Commissioner has itself been disposed of
on 19.07.2017.
3. Since the main matter itself is disposed of, the
prayers in this writ petition relating to interim order
would not survive for consideration.
4. The writ petition is therefore dismissed as having
become infructuous.
5. In view of the disposal of the petition, all pending
interlocutory applications, if any, stand disposed of.
Sd/-
