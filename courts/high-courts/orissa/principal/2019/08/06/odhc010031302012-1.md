# High Court of Orissa, WP(C)/22769/2012, 2019-08-06

I.A. No.8625 of 2019
 9. 06.08.2019 This Interlocutory Application has been filed
for extension of time for filing of representation, as has
been directed vide order dated 30.04.2019 that the
petitioner may file representation before the competent
authority within four weeks, while disposing of the writ
petition.
 Considering the grounds taken in the
application, prayer for extension of time to file
representation before the competent authority is
extended by another four weeks hence.
 Accordingly, the Interlocutory Application is
disposed of. It is made clear that except extension of
time to file representation, the order dated 30.04.2019
remains unaltered.
