Order
22/03/2023
The matter comes up on an interim application No.38/2023
filed by the counsel for the petitioner for showing the name of the
counsel for the petitioner as Lokendra Singh Kachhawa in place of
Mahendra Singh Kachhawa.
Learned counsel submits that he argued the matter when
these bunch of petitions were decided by this Court on
16.02.2023, but due to inadvertent error, name of Mr. Mahendra
Singh Kachhawa has been shown as counsel for the petitioner in
the order dated 16.02.2023.
Learned counsel submits that for necessary correction in the
order dated 16.02.2023, this application has been filed.

[2023/RJJP/004682] (2 of 2) [WMAP-38/2023]
Learned counsel for the respondent has no objection if the
name of counsel for the petitioner is corrected.
For the reasons stated in the application, the same is
allowed.
It is ordered that name of counsel for the petitioner
“Mr. Lokendra Singh Kachhawa” be read in place of “Mr. Mahendra
Singh Kachhawa” in the order dated 16.02.2023.
This order be treated as part and parcel of the order dated
16.02.2023.
(ANOOP KUMAR DHAND),J
