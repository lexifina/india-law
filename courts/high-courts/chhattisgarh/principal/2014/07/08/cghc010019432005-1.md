Act, 1985 theapplicant has prayed for execution of the order dated
3.4.1998. passed by the State Administrative Tribunal, Jabalpur in

been executed or complied uvith.

liberty to the applicant to file afresh if the order has not been
executed.
4. No order as to costs.
