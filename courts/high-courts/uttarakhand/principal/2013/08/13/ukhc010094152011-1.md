# High Court of Uttarakhand, WPSS/2014/2011, 2013-08-13

WPSS-2014-11
Hon’ble Sudhanshu Dhulia, J.
Mr. Kishore Kumar, Advocate present
for the petitioner.
Mr. N. P. Sah, Standing Counsel
present for the State of Uttarakhand.
Vide order dated 19.06.2012 this
Court had dismissed the present writ petition
on the ground of alternative remedy, as the
petitioner has a remedy of filing a claim
before the Public Service Tribunal.
Now, a Review Application (M.C.C.
No.478/2013) has been filed by the
petitioner. There is a delay in filing the
review application. Cause shown for the
delay in filing the review application is
sufficient. The Delay Condonation
Application No.Nil/2013 is allowed. The
delay in filing the review application is
condoned.
It has been alleged in the present
Review Application that before filing the
claim before the Public Service Tribunal, the
petitioner has to file a review application
before the State Government. M.C.C.
No.478/2013 is disposed of with a direction
that the petitioner is at liberty to file a
review petition before the State
Government.
 (Sudhanshu Dhulia, J.)
Dated 13.08.2013
Rawat
