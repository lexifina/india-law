This application coming on for hearing this day, the court passed the
following:
ORDER
At the outset, leaned Panel Lawyer for the respondent/State submits that
the seized material containing blood stains have been sent for FSL and the
report is still awaited.
Faced with this, leaned counsel for the applicant seeks withdrawal of this
application with liberty to file afresh after receiving the FSL report.
State counsel is directed to write the concerning office for sending the
FSL report expeditiously looking to the urgency in the matter.
Accordingly, this application is dismissed as withdrawn with the
aforesaid liberty.
