# High Court of Rajasthan, CRLMA/58/2012, 2012-02-07

IN THE HIGH COURT OF JUDICATURE FOR RAJASTHAN
BENCH AT JAIPUR
ORDER
IN
S.B. Cr. Miscellaneous Application No.58/2012
In
S.B. Cr. Misc. Bail Application No.11974/2011
Vishnu Sharma Vs. The State of Rajasthan
through Public Prosecutor
Date of Order ::: 07.02.2012
Hon'ble Mr. Justice Mohammad Rafiq
Shri Nagesh Soral, counsel for petitioner
Shri G.S. Fauzdar, Public Prosecutor
####
By the Court:-
Learned counsel for petitioner submits that despite
grant of bail by this court vide order dated 23.01.2012, the
trial court did not release accused-petitioner Vishnu Sharma
because Wife of the Petitioner made a statement before this
court that only one criminal case was pending against
petitioner, whereas, according to assertion of the
prosecution before the court below, there are actually four
cases pending against him.
Learned counsel for petitioner submits that there is
confusion about identity of accused-petitioner Vishnu
Sharma. It is a coincidence that another person has similar
name and his father's name also happens to be Shankar Lal.
However, that Vishnu Sharma is a property dealer and cases
pending against him are pertaining to property disputes and
the petitioner is different person.
Application is disposed of with direction to the
trial court to make an enquiry in this respect and if this
is found to be correct then release the petitioner on bail
under Section 439 Cr.P.C. as per terms and condition
enumerated in the order dated 23.01.2012 or if it is found
that false statement has been made before this court, the
petitioner may not be released.
(Mohammad Rafiq) J.
