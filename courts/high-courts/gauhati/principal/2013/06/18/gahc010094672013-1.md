# Gauhati High Court, CRP/96/2013, 2013-06-18

CRP 96/2013
BEFORE
THE HON’BLE MR. JUSTICE B.P. KATAKEY

to withdraw the revision petition with liberty to file appeal.

certified copy of the order dated 21.1.2013.
Prayer is allowed.
The revision petition stands dismissed with liberty to file appeal.
The Registry is directed to return the certified copy of the order by keeping th
e photocopy of the same on record.
