ORDER
This MCC has been filed for return of the original sale deed dated
23.11.1953, which was produced before this Court in pursuance to the Court order
dated 24.2.2020 passed in MP No.3029/1990. This Misc. Petition has been
allowed by this Court on 25.2.2022. It is prayed that as the original sale deed is no
longer required in the case, therefore, the same may be returned to the petitioners.
Since the Misc. Petition No.3029/1990 has already been allowed vide order
dated 25.2.2022, the original sale deed is no longer required, under the
circumstances this MCC is allowed. It is directed that the original sale deed be
returned to the petitioners after keeping a photocopy of the same on record.
With the aforesaid direction, this MCC stands finally disposed of.
