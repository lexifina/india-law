# High Court of Madhya Pradesh, MCRC/6722/2018, 2018-03-19

THE HIGH COURT OF MADHYA PRADESH
MCRC-6722-2018
(VIMAL @ CHHOTU Vs THE STATE OF MADHYA PRADESH THR)
Gwalior, Dated : 19-03-2018
Shri S.K.Mishra, learned counsel for the applicant.
Shri A.K.Nirankari, learned Public Prosecutor for the State.
This is third bail application preferred at the instance of the
applicant. Another application vide M.Cr.C.No.5594/2018 which
appears to be second bail application has already been filed and is
pending for consideration today itself.
Learned counsel for the applicant apologies for the mistake and
submits that he intends to withdraw this application so that
M.Cr.C.No.5594/2018 can be pressed into service.
Prayer is accepted.
Petition is dismissed as withdrawn.
(ANAND PATHAK)
JUDGE
