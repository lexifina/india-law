# Madras High Court, A/5832/2019, 2019-11-22

1
Application No.5832 of 2019
PUSHPA SATHYANARAYANA, J.
This Court, upon hearing the learned counsel for the applicant, vide
order dated 25.10.2019, directed the respondent to furnish security to the
extent of the claim made in the application, being an amount of Rs.6,21,527/-,
on or before 22.11.2019, failing which, an order of attachment order would be
passed.
2. When the matter is taken up for hearing today, learned counsel
for the applicant would submit that no security has been furnished as directed
by this Court. He would further submit that arbitration proceedings have been
initiated and a reference letter has also been sent.
3. Heard the learned counsel appearing for the applicant.
4. Notice sent to the respondents with regard to furnish security
ordered by this Court has been duly served and an affidavit of service is also
filed to that effect enclosing the acknowledgement card. Though the name of
the respondents are also printed in the cause list, there is no representation
