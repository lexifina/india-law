# Allahabad High Court, ABAIL/7441/2021, 2023-02-06

Court No. - 77
Case :- CRIMINAL MISC ANTICIPATORY BAIL
APPLICATION U/S 438 CR.P.C. No. - 7441 of 2021
Applicant :- Munsaf Ali
Opposite Party :- State of U.P. and Another
Counsel for Applicant :- Bhuvnesh Kumar Singh
Counsel for Opposite Party :- G.A.
Hon'ble Mrs. Manju Rani Chauhan,J.
Heard Sri Bhuvnesh Kumar Singh, learned counsel appearing
for the applicant submits that he has to file entire order-sheet in
order to show that the applicant is facing trial without seeking
any unnecessary adjournment by filing a fresh anticipatory bail
application.
Learned counsel for the applicant prays to not-press the present
anticipatory bail application with liberty to file a fresh
application.
The anticipatory bail application is dismissed as withdrawn
with the liberty as prayed. Interim order, if any, stands
discharged.
Office to return the certified copy of the order of court below to
learned counsel for the applicant.
Order Date :- 6.2.2023

DIGAMBER SINGH
