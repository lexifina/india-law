 vrd 2 WP3378/11
2. Heard Mr Upadhyay extensively appearing
for the petitioner, a Notary. Earlier, identical
efforts were made by filing writ petition Nos.2603
to 2605 of 2009, which were permitted to be
withdrawn by order dated 16th June 2010 by this
Court. The order reads as under :-
“1. The learned counsel for the petitioner
seeks to withdraw these petitions with
liberty to file revision applications
before the Sessions Court. Petitions stand
disposed off as withdrawn with liberty to
file revision applications before the
appropriate Court. If such revision
applications are filed, the period, during
which these petitions were pending before
this Court, will be excluded for the
purpose of limitation. All the questions
are left open.”

Instead of following the directions, the
petitioner has again approached this Court with
identical prayers in writ jurisdiction which is not
permissible. Writ petitions are disposed off as the
directions dated 16th June 2010 are eloquent to be
scrupulously adhered to.
( K.U. CHANDIWAL J. )
