JUDGMENT
K. Vinod Chandran, J.
The learned Single Judge, whose order is
impugned herein, had considered an application
filed by the petitioner and confined the order to
one of the reliefs prayed for. An appeal from that
order seeking there be an order passed as for the
other relief prayed is not maintainable. The
petitioner would have to seek it before the learned
Single Judge in the same I.A. or file a review from
that order.
The writ appeal is dismissed in limine.
