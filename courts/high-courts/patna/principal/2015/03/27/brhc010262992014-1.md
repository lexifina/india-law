ORAL ORDER
2 27-03-2015 Heard learned counsel for the petitioners and learned
counsel for the State.
 The petitioners seek anticipatory bail in a case instituted
for the offences under Sections 341, 323, 504, 506, 379,
354(B)/34 of the Indian Penal Code and Section and section
3(1)(x) of the SC/Sc Act.
 Learned counsel for the petitioner seeks permission to
withdraw this application against petitioner no.1 Bhagya
Narain Bhagat as the same has become infructuous.
 Permission is accorded. Accordingly this application as
against petitioner no.1, Bhagya Narain Bhagat, is dismissed as
having become infructuous.
