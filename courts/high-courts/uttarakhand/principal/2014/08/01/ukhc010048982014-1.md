# High Court of Uttarakhand, WPMS/1787/2014, 2014-08-01

WPMS No. 1787 of 2014
Honíble Sudhanshu Dhulia, J.
Mr. Ajay Veer Pundir, Advocate, present
for the petitioner.
Mr. Anil Kumar Joshi, Additional
C.S.C., present for the State of Uttarakhand.
Learned counsel for the petitioner wants
to withdraw the present writ petition, as it
would be proper for him to file Public Interest
Litigation, since the prayer which is actually
falls within the purview of Public Interest
Litigation.
In view thereof, the present writ petition
is dismissed as withdrawn with liberty to the
petitioner to file Public Interest Litigation, if
so advised.
