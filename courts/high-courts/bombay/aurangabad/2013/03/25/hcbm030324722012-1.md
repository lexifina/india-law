ORAL JUDGMENT :
1. Rule. Rule made returnable forthwith. With the consent of
the learned counsel for the respective parties, taken up for final hearing.
2. The application to file Written Statement after the Suit is
converted from Small Cause Suit to the Special Civil Suit is rejected.
3. Heard the learned counsel for the respective parties.
4. Earlier the Suit was Small Cause Suit. It appears that the
petitioner had filed his written Say in the said Small Cause Suit.
Thereafter, on an application filed by the plaintiff, the Suit was converted
into Special Civil Suit. The petitioner had filed an application for
allowing him to file Written Statement.
5. The procedure to try the Small Cause Suit is different and
distinct from the procedure to try the Special Civil Suit. The petitioner
would certainly get right to file fresh Written Statement. The jurisdiction
of the Court had changed.

 3 W.P. 1038.2013 - [ J ]
6. While trying Small Cause Suit, the provisions of the Small
Cause Courts Act would apply whereas for trying Special Civil Suit, the
regular provisions would apply. None the less, the petitioner would get
right to file Written Statement.
7. In light of the above, the impugned order is quashed and set
aside. The petitioner is allowed to file the Written Statement considering
the fact that much time is lost. The petitioner shall file the Written
Statement on 03/04/2013.
8. Rule is made absolute in above terms. No costs.
