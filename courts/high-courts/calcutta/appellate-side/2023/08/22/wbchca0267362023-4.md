Learned advocate for the State has submitted that a
report under Section 173 of Cr.P.C. has been filed before
the jurisdictional court and the present petitioner viz
Danish Ali has been discharged from the case for want of
evidence.
 Certified copy of the same has been submitted before
this Court by the learned advocate for the petitioner. Let
the same be kept with the record.
In view of the report so submitted under Section 173
Cr.P.C., CRR 2081 of 2023 is dismissed as infructuous.
Pending application, if any, is consequently disposed
of.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
