# High Court for the State of Telangana, CRLP/3391/2012, 2012-04-04

THE HON'BLE SRI JUSTICE K.C.BHANU
CRIMINAL PETITION NO.3391 OF 2012
ORDER:
Learned counsel for the petitioner requests this Court to dismiss
the Criminal Petition with liberty to the petitioner to file application
under Section 70(2) of the Code of Criminal Procedure, 1973 (Cr.P.C.),
before the trial Court to recall the warrant.
The Criminal Petition is dismissed with liberty to the petitioner
to file application under Section 70(2) Cr.P.C. before the trial Court to
recall the warrant.

(K.C.BHANU, J)
