 CORAM : A.P.Lavande & P.D.Kode,JJ
 DATE : 05.03.2009
Ms Kalpana Pathak, learned counsel for the
appellant seeks leave to withdraw the appeal with liberty to file
review application before the learned Single Judge on the
ground that when the impugned order was passed by the
learned Single Judge, the order passed by the Industrial Court
was already implemented and till date the appellant is
occupying the promotional post.
Mr. Badar, the learned counsel for the respondents
has no objection if the leave is granted to withdraw the appeal
with liberty to file appropriate application before the learned
Single Judge.
In view of the above, the appeal is allowed to be
withdrawn with liberty to file appropriate application before
the learned Single Judge.
