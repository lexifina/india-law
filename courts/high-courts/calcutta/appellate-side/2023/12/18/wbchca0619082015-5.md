1. This revisional application has been filed challenging
the order dated 09.09.2015 passed by the learned
Additional Principal Judge, Family Court No.2,
Calcutta in connection with Miscellaneous Case No. 26
of 2015 under Section 125 of the Code of Criminal
Procedure.
2. Learned counsels appearing on behalf of both parties
have submitted that this revisional application was
filed challenging an interim order of maintenance
passed on 09.09.2015 but thereafter original
application under Section 125 of the Code of Criminal
Procedure had already been dispose of on 25th October,
2016.
3. In the aforesaid view of the matter, the instant
revisional application stands dismissed being

infructuous
4. All parties to this revisional application shall act on the
server copy of this order downloaded from the official
website of this Court.
(Bibhas Ranjan De, J.)
