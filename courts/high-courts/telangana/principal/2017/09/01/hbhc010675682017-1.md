# High Court for the State of Telangana, CRLRC/163/2017, 2017-09-01

THE HONíBLE SRI JUSTICE M.SATYANARAYANA MURTHY
CRIMINAL REVISION CASE NO.163 OF 2017
ORDER:

 Learned counsel for the petitioner seeks permission of this
Court to withdraw the criminal revision case with liberty to file
application under Section 482 Cr.P.C questioning the order under
challenge.
 Permission is accorded with liberty as sought for.
 Criminal revision case is dismissed as withdrawn. Registry is
directed to return the certified copies of the documents filed along
with this criminal revision case with proper acknowledgment, so as
to enable the petitioner to file appropriate application before the
Trial Court.
 Consequently, miscellaneous applications pending if any,
shall stand dismissed. No costs.

JUSTICE M. SATYANARAYANA MURTHY
