21/10.12.2021 Counsel for the petitioner submits that charge sheet has already
been filed in this case and cognizance has been taken and the petitioner
has been summoned. He prays to withdraw this application with a liberty
to the petitioner to challenge the order taking cognizance and the order
issuing summon as there are no materials so that summon can be issued
to him.
 Prayer is allowed.
 The petitioner, if so advised, may file a separate application
praying therein to quash the order taking cognizance and order issuing
summon and may take all the grounds, which has been taken in this
application, in the proposed application which the petitioner wants to file.
 Thus, this application is dismissed as withdrawn with the liberty
aforesaid.
