Item No.9
Re; CRAN/1/2022 ( Condonation of Delay).
Having heard learned counsel for the parties, the delay
in filing the application for leave is condoned.
CRAN/1/2022 is accordingly disposed of.
Re: CRMSPL/2/2022 (Leave)
Heard Mr. Tulsi Lal, learned counsel for the State and
Mr.KMB Jayapal, learned counsel for the responden/OP.
This is an application for grant of leave to the State to
file appeal.
On perusal of the impugned order, we find that learned
Trial Judge, while passing the impunged order, has not
conducted any trial as required to be done in split up case.
Learned Trial Judge, on the basis of the application by the
learned Public Prosecutor, has simply adopted the evidence
recorded in the main trial in the split up trial and passed the

2
judgment on the basis of the evidence recorded in the main
trial.
This being the fundamental defect so far as conduct of
trial is concerned, we feel persuaded to grant leave to the
State to file appeal. Accordingly, CRMSPL/2/2022 is
disposed of.
The appeal be accordingly registered and in numbered
and the same be placed before the appropriate Bench for
disposal.
( Chitta Ranjan Dash, J.)
( Md. Nizamuddin, J. )
