ORAL ORDER
(PER: THE HON'BLE MR JUSTICE ANANT RAMANATH HEGDE)
Heard the learned counsel appearing for the petitioner
and the learned counsel appearing for the respondents.
2. This petition is filed assailing the order dated
27.04.2018 passed on I.A.No.VII in O.S.No.54/2012 on the
file of III Additional Civil Judge, Athani1
.
3. The Trial Court rejected the said application filed by
the petitioner/defendant No.7 under Order VIII Rule 9 read
with Section 151 of the Code of Civil Procedure, 19082
,
seeking permission of the Court to file written statement.
4. The suit was filed in the year 2012. The petitioner
remained ex-parte before the Trial Court. In 2018, the
petitioner filed an application under Order IX Rule 7 read
with Section 151 of the Code. The same came to be
allowed, and the order placing defendant No.7/peititoner

ex-parte was set aside. However, the petitioner did not file
written statement along with that application.
5. Subsequently, in the year 2018, he filed another
application seeking permission of the Court to file written
statement. It is stated that the petitioner is a purchaser
from one of the defendants in the suit. It is noticed that the
petitioner was placed ex-parte in the year 2013. Though the
application was filed under Order IX Rule 7 of the Code, no
application was filed seeking permission to file written
statement. Under these circumstances, the Trial Court has
rejected the application.
6. Learned counsel for the respondents would submit
that the mandate of the Code of Civil Procedure, 1908, to
file written statement within 90 days is not complied, and
the Trial Court is justified in rejecting the application.
7. The Court has considered the contentions raised at
the Bar and perused the records.

8. Since it is contented that the present petitioner has
purchased the property during the pendency of the suit, it is
quite possible that the vendor may not contest the suit
effectively, in which event the petitioner will be put to
hardship.
9. Under these circumstances, the impugned order is
set aside, in order to do complete justice to the parties,
subject to the condition that the petitioner shall pay a sum
of ¹25,000/- as costs to the plaintiffs on the next date of
hearing.
10. Hence, the following:
ORDER
a) The writ petition is allowed.
b) The order dated 27.04.2018 passed on
I.A.No.VII in O.S.No.54/2012 on the file
of III Additional Civil Judge, Athani, is
set aside.
