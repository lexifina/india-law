P.C.:
1. Prayer in petition is to direct Respondent no.2 to decide Petitioner’s
application dated 21st January 2013. The petition itself has been verified
on or about 17th February 2020.
2. Ms.Solunke states that it is possible that application might have been
already decided. Mr.Kulkarni is justified in saying that if it is so,
Respondent no.2 would have communicated the order to Petitioner.
Therefore, we dispose the petition with the following directions:
a. If Petitioner’s application dated 21st January 2013 is still
pending before Respondent no.2 or any Respondent / State
authority, Respondent no.2 or any such Respondent or authority
shall dispose the application within 8 weeks from today.
