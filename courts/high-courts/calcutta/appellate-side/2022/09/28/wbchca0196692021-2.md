# Calcutta High Court, CRR/1368/2021, 2022-09-28

28.09.2022 IN THE HIGH COURT AT CALCUTTA
 Item No.13 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
 C.R.R. 1368 of 2021

 Santu Rajak
 versus
 Anupam Dey Kabiraj & Anr.
In Re: An Application under Section 482 of the Code of
Criminal Procedure.
Mr. Bhagbat Chaudhuri,
Mr. Monojit Chatterjee … For the Petitioner.
Learned advocate appearing for the petitioner submits
that the petitioner is not inclined to proceed with the instant
revisional application. To that effect, written instruction
received from the petitioner has been submitted before this
Court. Let the same be kept on record.
Accordingly, the revisional application being CRR 1368
of 2021 is dismissed as not pressed.
All pending connected applications, if any, are
consequently disposed of.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance with all
requisite formalities.
 (Tirthankar Ghosh, J.)
