Order No.
ORDER
23.09.2024
08. 1. This matter is taken up through Hybrid
Arrangement (Virtual/Physical) Mode.
 2. Heard learned counsel for the parties.
 3. Since the impugned order is an appealable one,
this Court is not inclined to entertain the Writ Petition.
It is open for the petitioner to file an appeal against the
order in question. It is observed that if any such appeal
is filed within a period of 3 (three) weeks hence,
Appellate Authority shall entertain the appeal and
decide the same on merit without insisting on any
delay.
 4. With the aforesaid liberty, the Writ Petition is
disposed of.
