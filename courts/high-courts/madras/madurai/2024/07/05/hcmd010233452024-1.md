ORDER
Heard both sides.
2.The petitioner was having crackers shop license. She was granted
license in the first instance in the year 2016. The first respondent declined to
renew the same on 27.10.2023 by pointing out certain defects. Challenging the
rejection order, this writ petition came to be filed.
3.I made it clear that the defects pointed out in the rejection order will
have to be set right. For instance, the petitioner cannot be allowed to sell
crackers next to cloth shop. The petitioner now states that all the defects
pointed out in the impugned rejection order have been set right. The learned
counsel would further make a grievance that the petitioner was not put on
notice before rejecting the petitioner's request for renewal.

4.In this view of the matter, the petitioner is permitted to go before the
first respondent once again by submitting an application for renewal. The first
respondent will verify if all the defects earlier pointed out have been set right.
If the first respondent is satisfied that there is compliance with the statutory
rules, renewal can be granted. This is left to the discretion of the first
respondent. The learned counsel for the petitioner states that a fresh renewal
application will be submitted within a period of two weeks from the date of
receipt of a copy of this order. The first respondent will entertain the same and
pass final order on merits and in accordance with law within a period of eight
weeks thereafter.
5.With this liberty to the petitioner and direction to the first respondent,
the writ petition is disposed of. No costs. Consequently, connected
miscellaneous petition is closed.
