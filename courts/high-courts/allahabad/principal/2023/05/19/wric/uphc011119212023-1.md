# Allahabad High Court, WRIC/16959/2023, 2023-05-19

Neutral Citation No. - 2023:AHC:109629-DB
Court No. - 47
Case :- WRIT - C No. - 16959 of 2023
Petitioner :- M/S Assotech Limite
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Anuj Srivastava,Birendra Singh
Counsel for Respondent :- C.S.C.,Sandeep Kumar Srivastava
Hon'ble Ashwani Kumar Mishra,J.
Hon'ble Vinod Diwakar,J.
Sri Sandeep Kumar Srivastava has appeared for the respondent
nos.2 and 3.
This writ petition has been filed challenging an order dated
16.6.2022 passed by respondent no.2.
At the time when the matter is taken up the Court is informed
that U.P. Pollution Control Board has since passed a subsequent
order against the petitioner on 10.2.2023 and a notice has also
been issued on 2.5.2023. Copy of these orders have been
furnished to the counsel for the petitioner today in Court.
Faced with the above circumstance, learned counsel for the
petitioner comes up with the prayer to withdraw the writ
petition with liberty to file afresh, challenging the subsequent
orders.
Order Date :- 19.5.2023
Anil
