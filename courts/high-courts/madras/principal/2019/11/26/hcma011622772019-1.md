# Madras High Court, A/6889/2019, 2019-11-26

A. No.6889 of 2019
Application No.6889 of 2019
PUSHPA SATHYANARAYANA, J.
This Court, upon hearing the learned counsel for the
applicant, vide order dated 23.9.2019, directed the respondent to
furnish security to the extent of the claim made in the application
being an amount of Rs.1,18,270/-, on or before 31.10.2019, failing
which, an order of attachment order would be passed.
2. When the matter is taken up for hearing today, learned
counsel for the applicant would submit that no security has been
furnished as directed by this Court. He would further submit that an
award in arbitration between the applicant and the respondent has
been passed on 23.4.2019.
3. Heard the learned counsel appearing for the applicant.
4. Notice sent to the respondent regarding furnishing of
security has been returned with an endorsement 'party denied to
take' and an affidavit of service is also filed to that effect. Though
the name of the respondent is also printed in the cause list, there is
