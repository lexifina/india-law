3 to be transposed as the appellants instead of KandasamyGounder in the
main appeal in A.S.SR.No.37039 of 2017 on the file of this Court.
 2. Heard Dr.P.Vasudevan, representing Mr.V.Chinnasamy, learned

either side, this Court is inclined to allow this petition. Accordingly, this
petition is allowed without costs.
