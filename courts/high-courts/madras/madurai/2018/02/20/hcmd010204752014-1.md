ORDER
This Criminal Original Petition has been filed by the Accused
No.1, to quash the First Information Report in Crime No.280 of 2013,
on the file of the first respondent.
2.The learned Government Advocate (Crl. Side) has submitted
that already charge sheet has been filed and the case was taken on
file in C.C.No.54 of 2016, on the file of the learned Judicial
Magistrate No.I, Kumbokonam.
3.The learned counsel appearing for the petitioner by way reply
has submitted that already this Court has granted stay for filing of
the final report and in such a case, the first respondent should not
have filed final report.
4.Considering the aforesaid submissions, this Criminal Original
Petition dismissed as infructuous. If the petitioner feels that the
