# High Court of Madhya Pradesh, MCC/3395/2015, 2015-12-02

MCC-3395-2015
(NAND BAI Vs SMT. NATBAI)
02-12-2015
Shri Rajesh Dubey, learned counsel for the applicant.
This application has been filed for restoration of CR
No.389/2015, which was dismissed for want of
prosecution vide order dated 16.10.2015. There being
some delay in filing of this application for restoration,
I.A. No.15415/2015 has been filed. Reason for the delay
is attributed to some lapse in the office of the counsel
and the application is supported by affidavit of the
applicant.
Finding the same to be bonafide, both the applications
are allowed. Condoning the delay in filing the restoration
application, the restoration application itself is allowed.
CR No.389/2015 is restored to its original file. It be
placed for orders before an appropriate Bench.
Application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
