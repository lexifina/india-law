RANJIT SINGH, J.
In an additional response filed to the writ petition, the
respondents have disclosed that earlier impugned order has been
withdrawn and a fresh order has been passed by the competent
authority, a copy of which is annexed with the additional reply as
Annexure R-1. The counsel for the petitioner would have to impugn
this order.
Faced with this situation, counsel for the petitioner prays
for time to amend the writ petition. In my considered opinion, it would
be appropriate for the petitioner to file a fresh petition as this is not
only a fresh cause, but the impugned order would have to be
challenged entirely on different grounds.
The writ petition is, therefore, disposed of with liberty to
the petitioner to challenge the fresh impugned order, copy of which is
already on record.
