 ORDER
This Criminal Miscellaneous Case is filed to quash the
proceedings in C.C.No.63/2006 on the file of the Judicial First Class
Magistrate Court, Chittur which is re-numbered as C.C.No.338/2008
on the file of the Judicial First Class Magistrate Court, Palakkad.
2. It is submitted that a discharge petition was filed before
the trial court and the same is dismissed, against which a revision as
Crl.R.P.No.40/2011 is pending before the Sessions Court, Palakkad.
3. If that is the case, this Crl.M.C need not be retained. All
the contentions raised by the petitioner in this Crl.M.C are left open
and the petitioner is free to agitate the same before the revisional
court in accordance with law.
With the above observation, this Crl.M.C is disposed of.
