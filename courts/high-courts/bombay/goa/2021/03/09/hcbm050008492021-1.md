In this First Appeal, there are seven appellants. Accordingly, the
appellants' counsel submits that though the seventh appellant has died, his
name was shown in the array of parties by oversight. Now, he has filed
this application to have the name of the seventh appellant deleted.
2. For the reasons mentioned in the application, this Court allows it.
The seventh appellant's name stands deleted. The appellants will file the
amended copy in one week's time.
3. Post the matter on 23.03.2021.
