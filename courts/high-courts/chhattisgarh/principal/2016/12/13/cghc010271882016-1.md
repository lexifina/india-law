Hon'ble Shri Justice Manindra Mohan Shrivastava
Order On Board
13/12/2016
Heard.
1. After hearing, learned counsel for the petitioner, I am not inclined to
interfere with the order impugned as it does not suffer from any
jurisdictional illegality. The Court below has rightly rejected the
application as found vague and lacking specific details.
2. However, learned counsel for the petitioner prays for grant of liberty
to file application with specific details which were found to be lacking.
3. It would be in the interest of justice to allow the petitioner to file
appropriate application giving the specific details with regard to the
witnesses, which he intend to examine, showing the relevancy.
4. With the aforesaid liberty, the petition is dismissed.
