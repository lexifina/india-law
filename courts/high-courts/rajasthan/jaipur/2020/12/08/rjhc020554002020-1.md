# High Court of Rajasthan, CRLMB/11012/2020, 2020-12-08

S. B. Criminal Miscellaneous Bail Application No. 110 12/2020
~rishan. Murari S/o Sitaram, R/o Chatarpura Ps Indragarh Dist.
Bundi Raj.
Versus
State Of Rajasthan, Through Pp
For Petitioner(s) : Mr. Deepak Khandelwal through VC
For Respondent(s) : Mr. Riyasat Ali, PP
HON'BLE MR. JUSTICE NARENDRA SINGH DHADDHA
Order
Learned counsel for the petitioner submits that inadvertently,
he had filed criminal bail application u/s 438 Cr.P.C., there is a
requirement to file criminal appeal (Section 14-A). Therefore, he
wants to withdraw this bail application with liberty to file criminal
appeal- (Section 14-A).
Prayer is allowed.
~herkfore, the bail application is dismissed as withdrawn with
liberty aforesaid.
Office is directed to return the certified copies of the
documents attached with the bail application to the learned
counsel for the petitioner after retaining photocopies of the same
in the bail application.
(NARENDRA SINGH DHADDHA),
Brijesh 81.
