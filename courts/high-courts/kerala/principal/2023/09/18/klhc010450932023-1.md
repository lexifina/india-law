ORDER
This Criminal Miscellaneous Case is filed with
the following prayer:
“to direct the second respondent to renew
the petitioner’s passport. ”
2. This Court can not issue such a direction
invoking the powers under Section 482 Cr.P.C. The
petitioner is free to file a Writ petition in
accordance with law with the same prayer.
Granting liberty to the petitioner to file a writ
petition, this Criminal Miscellaneous Case is closed.
