# Calcutta High Court, CRR/843/2012, 2021-09-01

11 01.09.2021
 jb.
 C.R.R. 843 of 2012
 In re: Dhirendranath Hembram
Re: An application under Section 401/482 of the Code of
Criminal Procedcure, 1973;
 Mr. Abhra Mukherjee
 Mr. Sauradeep Dutta
 ….For the Petitioner
Mr. Mukherjee learned advocate appearing for the
petitioner submits that trial of the case is over and as such
there is no purpose in pursuing with the revisional
application.
Having regard to the same, I am of the view that the
revisional application should be disposed of.
Thus C.R.R. 843 of 2012 is disposed of.
Pending application, if any is consequently disposed of.
Interim order, if any is hereby vacated.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
 (Tirthankar Ghosh, J.)
