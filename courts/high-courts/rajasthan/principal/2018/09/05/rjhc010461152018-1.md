# High Court of Rajasthan, CW/9947/2018, 2018-09-05

Rajmati Gandhi

----Respondent
For Petitioner(s) : Mr. Sanjay Mathur
JUSTICE DINESH MEHTA
Order
05/09/2018
Mr. Sanjay Mathur, learned counsel appearing for the
petitioner seeks permission to withdraw the present writ petition,
with a liberty to file a revision petition under Section 151 of the
Code of Civil Procedure, laying challenge to the order impugned
dated 04.07.2018.
Permission to withdraw the present writ petition with the
aforesaid liberty is granted.
The writ petition is dismissed as withdrawn.
The Registry is directed to handover the original certified
copy of the order dated 04.07.2018 filed with the present writ
petition to Mr. Sanjay Mathur, who shall file a duly initialed photo-stat copy of the order dated 04.07.2018 for the purpose of record
of this case.
(DINESH MEHTA),J
Upendra/4
