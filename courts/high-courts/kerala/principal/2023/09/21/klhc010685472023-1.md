JUDGMENT
This contempt case is filed alleging non-compliance
of interim order dated 24.07.2023 in W.P.(C.) No. 23774/2023.
It is submitted that the above order is violated. The petitioner
is free to file an appropriate application in a writ court bringing
notice to the court about the violation and in such event a
better order can be passed in the writ petition. Therefore, this
contempt case need not be entertained. All the contentions of
the petitioner in the contempt case are left open. The petitioner
is free to agitate the same before the writ court with
appropriate application.
With the above observation, this contempt case is closed.
