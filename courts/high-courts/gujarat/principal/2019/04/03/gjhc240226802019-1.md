ORAL ORDER
Since the cause shown in parole leave about ailment,
the convict-prisoner is being treated through jail itself
and all the facilities even if a need for an operation
arises is available with the Government hospital through
jail, this application for parole leave on that ground
more particularly, his jail conduct is not reported to be
good, this application cannot be entertained. Hence, the
same is rejected.
(UMESH A. TRIVEDI, J)
