PSR,J.
C.R.P.No. 5696 of 2009
O r d e r:
Heard the learned counsel for the petitioner and the learned
counsel for the respondents.
2. Admittedly, there is no positive finding by this court that the
first respondent herein – Pattan Rahmath Khan is in possession of the
property. What all the order passed by this court is only status quo,
without any finding as to possession of the property, by any of the
parties. Such being the order passed by this court, it is not a case for
granting any police aid. Hence, the impugned order is liable to be set
aside.
3. In the result, the civil revision petition is allowed. The order
impugned herein is set aside. There shall be no order as to costs.
