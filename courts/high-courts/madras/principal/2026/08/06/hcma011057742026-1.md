ORDER
The present writ petition has been filed praying for a writ of Mandamus
to direct the 1st respondent to reissue the passport pursuant to the application
dated 09.01.2026, pending in File No. MA1076215470026 before the 1st
respondent.
2. At the outset, the learned counsel appearing for the respondents would
submit that the application dated 09.01.2026 itself is defective. He would thus
submit that it is always open to petitioner to submit a fresh application and the
same would be considered and appropriate orders would be passed, within a
time period to be stipulated by this Court. Agreed to by the learned counsel for
petitioner.
3. In view of the above submission, it is open to petitioner to file a fresh
representation before the first respondent, along with requisite documents. If
