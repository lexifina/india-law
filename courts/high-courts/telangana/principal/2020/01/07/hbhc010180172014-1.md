# High Court for the State of Telangana, ARBAPPL/129/2014, 2020-01-07

HONíBLE SRI JUSTICE A. RAJASHEKER REDDY
ARBITRATION APPLICATION Nos 129, 130, 131 and
ARBITRATION APPLICATION No.139 of 2014
COMMON ORDER :
 Learned counsel for the applicants as well as learned
counsel for respondent in all these applications submits that
the cause in the Arbitration Applications does not survive and
the same have become infructuous.
 Recording the same, all these Arbitration Applications
are disposed of. No order as to costs.
As a sequel, miscellaneous applications pending, if any,
shall stand closed.
