Order on Board
22/09/2015
1. Learned counsel for the petitioner would submit that the correct
Crime number is 230/2015, whereas, it has been wrongly typed as Crime No.
214/2015 in M.Cr.C. No. 4598/2015 vide order dated 07/09/2015.
2. Learned State counsel after verifying the case diary would submit
that petitioner/accused has been arrested in connection with Crime No.
230/2015.
3. Accordingly, it is directed that in the order dated 07/09/2015 passed
in M.Cr.C. No. 4598/2015, the Crime number be read as 230/2015 in place of
214/2015.
4. With the above direction, petition is disposed of.
5. Certified copy today.
