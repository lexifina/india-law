First Information Report in Crime No.120 of 2015 on the file of the first
respondent police.

2. Heard learned counsel for petitioner and learned Additional
Public Prosecutor appearing for first respondent.
3. It is brought to the notice of this Court that investigation has
been completed and a closure report has been filed as 'mistake of fact'.
The same is also reflected in the website maintained by the Tamil Nadu
Police. Learned Additional Public Prosecutor also confirmed this fact.
4. In view of the above, the First Information Report in Crime
No.120 of 2015 on the file of the first respondent police is no more in
force.
Accordingly, this Criminal Original Petition is disposed of.
Consequently, connected miscellaneous petition is closed.
