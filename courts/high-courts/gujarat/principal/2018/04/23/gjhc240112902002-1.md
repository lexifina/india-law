ORAL ORDER
Learned advocate for the petitioner wants to file further
affidavit. Pursuant to some disclosure in affidavit dated
06.04.2015 Nazir Ahmed Usman Gani Digmar. Learned
advocate Mr.Harsheel Shukla for the respondent has objected
to allow such filing of affidavit at such belated stage and
submitted that this is a oldest matter, no further time can be
granted to file affidavit, more particularly, when matter is
adjourned for the same issue for last couple of days.
However, in the interest of justice, since, the matter is
pending for couple of years, let petitioner be permitted to file
additional affidavit so as to disclose his case.
List on 30.04.2018.
(S.G. SHAH, J)
