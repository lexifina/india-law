2 24-02-2012 It is an ill advised and misdirected writ application
relying on annexure-14 when the petitioner had already
approached and withdrawn the earlier writ application without any
specific direction/observation. A second writ application for the
same relief is not maintainable if not barred by the principles of
resjudicata.
This writ application is dismissed.
