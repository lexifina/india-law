ORAL ORDER
2 29-03-2012 Heard learned counsel for the petitioner and learned counsel
for the State.
This application has been filed for quashing the order dated
18.12.2010 passed by the Judicial Magistrate, Ist Class, Hilsa (Nalanda)
in Complaint Case No.391-C of 2008 by which he has rejected the
petition filed on behalf of the petitioner for discharging him under
section 245 of the Code of Criminal Procedure.
Learned counsel for the petitioner submits that trial has
commenced and some witnesses have been examined.
 In this view of the matter, this application does not survive. It
is accordingly dismissed.
Vinay/- (Shivaji Pandey, J)
