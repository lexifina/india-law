# Madras High Court, A/6587/2023, 2024-01-19

A.No.6587 of 2023 in Tr. C.S. No.378 of 2021
ABDUL QUDDHOSE,J.
This application has been filed to restore the suit, which was
dismissed for non prosecution on 09.11.2023. When this application was
listed for hearing on 22.12.2023, the learned counsel for the respondents/
defendants sought time to file counter. At his request, the matter was posted
for counter and disposal for today's date. Once again, the learned counsel for
the respondents/defendants seeks time to file counter. Sufficient time has
already been granted to the respondents/defendants to file counter as the last
hearing date was on 22.12.2023 and in between there were two Court
vacations as well.
2.This Court has perused the contents of the affidavit filed in support
of this application.
3.Since sufficient cause has been shown by the applicant/plaintiff, this
Court is inclined to allow this application. Accordingly, this application is
allowed as prayed for and the suit is restored to file.
ABDUL QUDDHOSE,J.
