ORAL ORDER
1. This third successive bail application is filed by the
applicant u/s.439 of the Code of Criminal Procedure to release
him on regular bail in connection with an offence being
C.R.No.I-40 of 2015 registered with Ranavav Police Station,
Porbandar for the offences punishable under Sections 302, 34,
120(B), etc. of the Indian Penal Code and Section 135(1) of
the G.P. Act.
2. Having heard learned advocates appearing for the
respective parties and considering the fact that the trial is
going on, this application is not entertained at this stage. I do
not find any reason to entertain this application. Hence, this
application is rejected.
