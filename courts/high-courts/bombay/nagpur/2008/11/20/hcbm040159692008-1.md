# Bombay High Court, APPLN/2783/2008, 2008-11-20

IN THE HIGH COURT OF JUDICATURE AT BOMBAY:
NAGPUR BENCH: NAGPUR
CRIMINAL APPLICATION NO.2783/2008
[Ramkrishna Mehenge ..vs.. State ]
= = = = = = = = = = = = = = = = = = = = = = = = = =
Mr. Kashid, Advocate for applicant
Mr. Mirza, A.P. P for state.
= = = = = = = = = = = = = = = = = = = = = = = = = =
CORAM:R.C. CHAVAN, J.
DATE: 20.11.2008
Heard counsel for parties.
This is an application for anticipatory bail the applicant
who along with others, alleged to have cheated one Rameshwar to
the tune of Rs.46,000/- by conveying the land which did not belong
to him & other co-accused. In view of this, the investigation would
be warranted, which may necessitate the police to take applicant in
custody. No case for anticipatory bail is made out. Application is
rejected.
JUDGE
