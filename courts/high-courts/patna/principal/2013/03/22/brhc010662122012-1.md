ORAL ORDER
2 22-03-2013 Heard learned counsel for the petitioner and the
State.
The petitioner is aggrieved by the order dated
17.2.2012 cancelling his Public Distribution System Licence
No.2/92 passed by the Sub-Divisional Officer, Katihar in Case
No.3/2012, as contained in Annexure 8.
It is submitted on behalf of the petitioner that the
order cancelling the licence is not correct and as such, the same
deserves to be set aside.
Learned counsel for the State, on the other hand,
submits that the order cancelling the licence is a speaking one and
need not be set aside, as prayed for. Moreover, the petitioner has

At this stage, learned counsel for the petitioner
submits that the petitioner proposes to file an appeal against the
impugned order before the Collector of the concerned district. In
case such application is filed within a period of five weeks along
with an application for condoning the delay in filing the appeal,
the same be considered in accordance with law expeditiously
considering the pendency of this writ application.
The writ application stands disposed of.
