# High Court of Jharkhand, Cr.M.P./3666/2019, 2020-01-13

IN THE HIGH COURT OF JHARKHAND AT RANCHI
Cr. M.P. No.3666 of 2019
----
1. Sudhir Singh
2. Chakodi Yadav
3. Yugal Kishore Singh @ Yugal Singh … Petitioners
-versus-The State of Jharkhand … Opposite Party
---
CORAM : HON’BLE MR. JUSTICE ANANDA SEN
----
For the Petitioner : Mr. Rajesh Kumar, Advocate
For the State : Mr. Suraj Verma, APP
----
2/ 13.01.2020 Heard learned counsel for the petitioner and the learned
A.P.P. appearing for the State.
 Petitioners have challenged the order dated 07.01.2019
passed by the Judicial Magistrate 1st Class, Hazaribag in G(F) Case
No.396 of 2013, by which processes under Section 82 of the Code of
Criminal Procedure have been issued against the petitioners. They have
also challenged the subsequent order by which processes under Section
83 of the Code of Criminal Procedure have been issued against the
petitioners.
 While going through the order dated 07.01.2019, I find that the
same does not reflect the subjective satisfaction of the Court. Provisions of
the law as laid down in Section 82(3) of the Code of Criminal Procedure
have also not been complied with. Thus, the order dated 07.01.2019
passed in G(F) Case No.396 of 2013 is held to be bad in law. The same is,
hereby quashed and set aside. Since the order dated 07.01.2019 is set
aside, the subsequent order by which process under Section 83 of the
Code of Criminal Procedure has been issued is also hereby quashed and
set aside. The matter is remanded to the Court below to proceed further
and pass fresh order in accordance with law.
 This criminal miscellaneous petition is, thus, allowed.

( Ananda Sen, J.)
