ORAL ORDER
3 06-11-2019 Referring to the FIR, it is submitted by counsel for
the petitioners that petitioner no.5 has been described in the FIR
as wife of Sunil Sah. It is submitted that same has wrongly been
typed as Late Nawal Sah.
Such typographical error is manifest in the order dated
13.12.2018 passed in Cr. Misc. no. 65635/2018.Error is apparent
as per copy of FIR which is annexure 1 to the instant
modification application.
 The order dated 13.12.2018 is therefore, corrected so

Patna High Court CR. MISC. No.55160 of 2019(3) dt.06-11-2019
2/2
as to read as wife of Sunil Sah in the description of petitioner
no.5 instead of wife of Late Nawal Sah.
The order is modified as above.
 The modification application stands disposed of.
s.hassan/-
