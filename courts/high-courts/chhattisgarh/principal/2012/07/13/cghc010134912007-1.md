Per Abhay Manohar Sapre, J.
1. This M. C. C. isa restoration application and it arise
out of the order passed in W.P. No. 332/1994, which was
dismissed on 06.09.2005.
2. Learned counsel appearing for the applicant submits
that the W.P.No. 332/94 has already been restored by order
dated 13.10.2008, passed in M.C'.C. No. 207/2005 and as it
appears the instant M.C.C. has been filed by the applicant
inadvertently.
3. In the light of the order passed in M.C.C. No.
207/2005, dated 13.10.2008, which has already resulted in
restoring the W.P.No. 332/94, no order is now required to
be passed in the instant restoration application (M.C.C.).
Indeed, it is not necessary to pass another order of
restoration once already passed in another restoration
application (supra).
4. For the above reason we dismiss this M.C.C. as
having rendered infructuous.
5. No order as to costs.
