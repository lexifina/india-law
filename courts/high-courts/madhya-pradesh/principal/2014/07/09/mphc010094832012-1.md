# High Court of Madhya Pradesh, WP/3433/2012, 2014-07-09

1
W.P. No.3433/2012
9/7/2014
Shri P.N. Dubey, learned counsel for the petitioner.
Shri Rahul Jain, learned counsel for the respondent.
Counsel for the petitioner has fairly stated before this
Court that since the impugned suspension order dated
20.1.2012 has subsequently been revoked, therefore, the writ
petition has become infructuous. He has sought liberty to file
a fresh petition if any fresh cause of action arises.
The writ petition is dismissed as infructuous with the
above liberty.
C.C. as per rules.

(Prakash Shrivastava)
