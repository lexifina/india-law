# High Court of Rajasthan, CRLMB/7304/2015, 2015-07-13

1
IN THE HIGH COURT OF JUDICATURE FOR RAJASTHAN
 JAIPUR BENCH, JAIPUR
ORDER
SB Cr Misc IInd Bail Application No.7304/2015
Ashok @ Maman versus State of Rajasthan
13.7.2015
HON'BLE MR. JUSTICE MN BHANDARI
Mr Shyam Bihari Gautam - for the petitioner
Mr Virendra Godara, PP – for the State
BY THE COURT:
The first bail application was dismissed as withdrawn
with liberty to the petitioner to file fresh bail application before
the court below on filing of the challan. Without filing fresh bail
application before the court below, this court has been approached
by filing second bail application. Hence, it is dismissed, however,
with liberty to the petitioner to file fresh bail application before
the court below.
(MN BHANDARI), J.
