ORAL ORDER
2 26-07-2023 Heard learned counsel for the petitioner and learned
Additional Public Prosecutor for the State.
2. The petitioner is in custody since 23.03.2021 in
connection with Muzaffarpur Sadar P.S. Case No. 86/2021
registered for the offence punishable under Sections 392 of the
Indian Penal Code.
3. This application is held to be not maintainable in
view of the fact that the petitioner has not been remanded in the
present case. As and when the petitioner is remanded in
connection with the present case, he will file a bail application
directly in this Court.
4. In view of the above, this application is dismissed.
