O R D E R
~~~~~~~
Petitioners are accused in S.C.No.848/2009 on the file of
the Additional Sessions Court, Alappuzha. This petition is filed
under Section 482 of the Code of Criminal Procedure for a
direction to the Judicial First Class Magistrate-I, Cherthala,
where C.C.250/2010 is pending, to commit the case to the
Sessions Court as it is the counter case to S.C.No.848/2009
tried by him. .
2. Learned counsel appearing for the petitioner and the
learned Public Prosecutor were heard.
3. When there is a main case and a counter case, both
cases are to be tried by the same court. As is clear from
Annexure-II final report taken cognizance by the learned
Magistrate, C.C.No.250/2010 is a counter case of
S.C.No.848/2009. Even though the offences involved are not
exclusively triable by a sessions court, as the main case and the

Crl.M.C.No.3645/2010 2
counter case are tried by the same court, though not jointly,
learned Magistrate has to commit the case to Sessions Court as
provided under Section 323 of Code of Criminal Procedure to
enable trial of both cases by the same court.
Crl.M.C. is allowed. Judicial First Class Magistrate-I
Cherthala is directed to commit C.C.No.250/2010 to Sessions
Court, so that, the case should be tried by the same court which
is trying S.C.No.848/2009.
(M.SASIDHARAN NAMBIAR, JUDGE)
