# Allahabad High Court, WRIA/9961/2019, 2019-07-08

Court No. - 38
Case :- WRIT - A No. - 9961 of 2019
Petitioner :- Suleman
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Ravindra Pal Singh Kashyap
Counsel for Respondent :- C.S.C.
Hon'ble Ashwani Kumar Mishra,J.
The order dated 27.8.2018, which is impugned in this petition is
in essence communication of an order passed by Director
(Administration) on 25.6.2018. The order dated 25.6.2018 has
not been challenged nor its copy has been annexed. Law is
settled that a writ would not lie against a consequential order
when the main order itself is not under challenge.
Faced with the aforesaid, learned counsel for the petitioner
comes up with the prayer to withdraw this petition with liberty
to file a fresh challenging the order dated 25.6.2018.
Writ petition is accordingly dismissed as withdrawn with
liberty, as prayed.
Order Date :- 8.7.2019
Ashok Kr.
