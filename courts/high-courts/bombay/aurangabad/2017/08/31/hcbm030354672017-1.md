# Bombay High Court, WP/10714/2017, 2017-08-31

Versus

S.M.GAVHANE,JJ.
DATED : 31.08.2017
P.C. :-
1. Heard. It is apparent that the petitioner has
tendered application for inclusion of name in the voters’
list after the cut-off date prescribed by the State Election
Commission. The cut-off date prescribed for inclusion of
name was 01.07.2017; whereas the application has been
tendered by the petitioner on 17.07.2017, which falls beyond
the date prescribed by the State Election Commission. Since
the application has been tendered beyond the cut-off date,
the application is rightly not considered by the State
Election Commission. Hence, the petition being devoid of
substance, stands dismissed.
[S.M.GAVHANE,J.] [R.M.BORDE,J.]
