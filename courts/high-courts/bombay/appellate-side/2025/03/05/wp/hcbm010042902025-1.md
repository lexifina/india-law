1. Heard the learned Counsel for the petitioner.
2. The challenge in this petition is to an order dated 15th
October, 2024 passed by the learned Civil Judge, Sangli,
whereby an application preferred by the petitioner to club
both the suits i.e. RCS/33/2020 and RCS/243/2021, which
are pending before the one and the same Court and record
common evidence, came to be rejected.
3. No fault can be found with the impugned order
declining to club the suit.
4. Mr. Dalvi, the learned Counsel for the petitioner, on
instructions, submits that the purpose of the application
would be served if both the suits are tried by the same Court,
