03/11.03.2019. The father of this petitioner died on 13.01.2015. This petitioner applied for
grant of compassionate appointment in the month of July, 2015. Petitioner submits
that till date in spite of the depositing all the papers and documents, no final order
has been passed on the application of the petitioner.
 Counsel for the petitioner submits that suffice it would be if a direction is
given to the respondents to dispose of the claim of the petitioner and pass an
appropriate order on the application of compassionate appointment within a
stipulated time.
 Counsel for the State submits that a reasoned order on the application of
the petitioner will be passed at the earliest, if it is still pending.
 Considering the submission of the parties, I direct the petitioner to file a
representation along with a copy of this order before respondent 4. The respondent
no. 4 will pass an appropriate order on the application for grant of compassionate
appointment filed by the petitioner if necessary, the application will be placed
before the Committee, if any, for appropriate decision. The decision should be
communicated to the petitioner within eight weeks from the date of receipt of the
copy of this order.
 With the aforesaid direction and observation, this writ application stand
disposed of.
 (AnandaSen, J)
