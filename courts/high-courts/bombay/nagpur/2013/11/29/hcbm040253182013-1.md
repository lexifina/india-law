Shri M.P. Kariya, counsel for the petitioner.
CORAM : SMT. VASANTI A. NAIK, J.
 DATE : 29 th November, 2013.
 The impugned order is challenged by the
petitioner with the only apprehension that he would be
prevented from filing an appropriate application under the
Code of Civil Procedure in view of the rejection of the
application filed by the petitioner under Order 21 Rule 97 of
the Code of Civil Procedure.
The apprehension expressed by the learned
counsel is not well founded. The application filed by the
petitioner under Order 21 Rule 97 of the Code of Civil
Procedure was not dismissed by the Executing Court on
merit and was dismissed only because the petitioner had no
locus to file the application under Order 21 Rule 97 of the
Code of Civil Procedure. Since the application filed by the
petitioner is not decided on merit, the order passed thereon
would not come in the way of the petitioner if an appropriate
application is filed.
The writ petition is disposed of with no order as
to costs.
 JUDGE
Hirekhan
