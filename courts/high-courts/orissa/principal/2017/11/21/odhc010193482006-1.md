# High Court of Orissa, WP(C)/5522/2006, 2017-11-21

W.P.(C) No. 5522 of 2006
03. 21.11.2017 Heard learned counsel for the parties.
 Considering the fact that the matter has been pending for more than a decade a
nd the issue involved is only with regard to non-filing of revised return within the specified
 time and also taking into consideration that it is stated that the tax has already been paid
by the petitioner and the notice had been stayed, we dispose of this writ petition with the di
rection that in case the tax has already been paid, late filing of return would be condoned an
d the petitioner shall not be compelled to file revised return. However, it shall be open to t
he petitioner to file revised return if so advised.
 With the aforesaid observation, the writ petition stands disposed of.
