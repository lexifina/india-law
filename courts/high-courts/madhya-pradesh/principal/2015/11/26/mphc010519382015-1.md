# High Court of Madhya Pradesh, MCC/3033/2015, 2015-11-26

MCC-3033-2015
(RAI SINGH THAKRE Vs THE STATE OF MADHYA PRADESH)
26-11-2015
Shri S. Tiwari, learned counsel for the applicant.
This application has been filed for restoration of W.P.
No.7995/2013, which was dismissed for non-compliance
of peremptory order on 10.05.2013.
Keeping in view the reasons given in the application and
finding the same to be bonafide, the application is
allowed.
The restoration application itself is allowed, W.P.
No.7995/2013 is restored to its original file. It be placed
for orders before an appropriate Bench.
Application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
