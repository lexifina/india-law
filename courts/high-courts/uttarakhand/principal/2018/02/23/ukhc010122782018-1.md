# High Court of Uttarakhand, BA1/342/2018, 2018-02-23

BA1 No. 342 of 2018
Hon’ble V.K. Bist, J.
Mr. D.K. Sharma, Senior
Advocate assisted by Mr. Rajesh
Sharma, Advocate for the applicant.
Mr. J.S. Virk, Assistant
Government Advocate for the State of
Uttarakhand.
Heard learned counsel for the
parties.
Learned Senior Advocate for the
applicant seeks permission of this
Court to withdraw this bail application
with liberty to file Criminal Revision.
The bail application is dismissed
as withdrawn with liberty to file
Criminal Revision.
Officer is directed to return back
the certified copies of the orders
annexed with this bail application to
the learned counsel for the applicant
today itself, after keeping the
photocopies of the same in this file.
Let a certified copy of this order
be issued today itself.
 (V.K. Bist, J.)
Arpan 23.02.2018
