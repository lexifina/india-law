48.5 marks as against the cut off 49.5 which is made for the Backward
Class Candidates. Therefore, this Court is not able to see any infirmity
in the impugned order for interference. Hence, this Writ Petition is
dismissed. No costs. Consequently, connected Miscellaneous Petition is
closed.
