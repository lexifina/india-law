Judgment / Order
26/03/2021
1. Matter comes up on an application filed by the applicant for
correction in the name of the counsel mentioned in the order
dated 03.03.2021.
2. It is contended by counsel for the applicant that in the order
dated 03.03.2021, counsel for the applicant was Deepak Soni
whereas, name of counsel Kapil Gupta has been wrongly typed.
3. I have considered the contentions.
4. Considering the application filed by counsel for the applicant,
application is allowed. In the order dated 03.03.2021, name of
counsel be now read as ‘Deepak Soni’ in place of ‘Kapil Gupta’.
(PANKAJ BHANDARI),J
