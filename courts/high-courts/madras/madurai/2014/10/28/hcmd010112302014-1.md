PRAYER: Petition is filed under Section 482 of the Code of Criminal
Procedure praying to direct the respondent police to investigate the
case in Crime No.24/2014 on the file of the second respondent police and
to file a final report within a stipulated period.
For Petitioner : Mr.R.Sundar
For Respondents : Mr.A.P.Balasubramani
 Govt. Advocate (Crl. Side)
O R D E R
This petition has been filed seeking a direction to direct the
respondent police to investigate the case in Crime No.24/2014 on the
file of the second respondent police and to file a final report within a
stipulated period
2. Heard the learned Counsel for the petitioner and the learned
Government Advocate (Crl.Side) appearing for the respondents.
3. The petitioner has given a complaint which has been registered
in Cr.No.24 of 2014 against the accused and so far no final report has
been filed. Hence, the petitioner is before this Court.
4. In view of the above, the respondent police is directed to
complete the investigation and file final report as expeditiously as
possible.
5. Accordingly, the Criminal Original Petition is disposed of.
Sd/-
