ORAL ORDER
3 12-02-2014 In view of the fact that the writ application has been
restored today by an order passed in M.J.C. No. 3389 of 2013, learned
counsel for the parties have also been on merit of this case.
After some arguments, learned counsel for the petitioners
however seeks permission to withdraw this writ application in order to
enable the petitioners to avail departmental remedy, if any.
This writ application is, accordingly, permitted to be
withdrawn with the aforementioned liberty.
