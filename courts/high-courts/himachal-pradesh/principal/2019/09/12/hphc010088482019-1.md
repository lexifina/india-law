Ajay Mohan Goel, Judge (Oral)
 By way of this petition, the petitioner has
challenged the order passed by the Court of learned Rent
Controller, Una, dated 07.03.2019, vide which, an application
filed by the respondent-landlord under Order 1, Rule 10 of
the Code of Civil Procedure, wherein a prayer was made by
the landlord for addition of name of one Smt. Raj Rani, wife of
late Shri Ram Asra as respondent in the eviction petition inter
alia on the ground that after the death of the original tenant,
 --
-

	-

tenancy rights have inter alia devolved upon Smt. Raj Rani
also, as allowed.
2. Learned Counsel for the petitioner has argued that
a perusal of the application so filed under Order 1, Rule 10 of
the Code of Civil Procedure (hereinafter referred to as ‘the
Code’ for short) would demonstrate that the averments made
therein by the landlord were to the effect that name of Smt.
Raj Rani be arrayed as one of the respondents after deleting
the name of the present petitioner. As per learned Counsel,
perversity in the impugned order is that whereas the request
of the landlord for impleading Raj Rani as respondent has
been allowed by the Rent Controller, however, name of
petitioner has not been deleted and findings stand returned
that he is a necessary party, by referring to the response filed
by the present petitioner to the application wherein it was
mentioned that petitioner was a tenant. Learned Counsel has
argued that when the landlord himself was not admitting the
petitioner to be a tenant, then the observation made by
learned Rent Controller in the impugned order that the
petitioner was a tenant, was completely uncalled for because

now it will come in the way of present petitioner if he wants to
file an application for deletion of his name.
3. In my considered view, this apprehension of the
petitioner is completely mis-conceived. The observations
which are contained in the order impugned have to be
construed only for the purpose of adjudication of the
application so filed under Order 1, Rule 10 of the Code before
the said Court. In case, petitioner intends to file any
application under Order 1, Rule 10 of the Code, for deletion
etc. of his name from the array of respondents, then, but
obvious, learned Rent Controller has to decide the same, in
accordance with law, in view of averments therein, after giving
an opportunity to the other party(s) to put forth their
response to the same, uninfluenced by observations made by
it in the order which was passed on an application filed for
addition of the name of Raj Rani under Order 1, Rule 10 of
the Code.
4. Accordingly, this petition, as prayed for, is
disposed of with the observation that in case any application
is filed by the petitioner under Order 1, Rule 10 of the Code
for deletion etc. of his name from the array of respondents,

then, learned Rent Controller shall adjudicate upon it on
merit after giving an opportunity to all the parties to respond
to the same, uninfluenced by any observation made by it in
the impugned order.
The petition stands disposed of in above terms, so
also pending miscellaneous application(s), if any.
