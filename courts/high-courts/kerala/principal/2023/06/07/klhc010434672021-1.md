ORDER
This Bail Application is filed under Section 438 of Criminal
Procedure Code (Cr.P.C.)
2. When this bail application came up for
consideration, the Public Prosecutor submitted that, after
investigation, the final report is filed in Crime No.266/2021 of
Ernakulam Town Police Station. When this bail application
came up for consideration on 11.08.2021, this Court passed an
order “not to arrest the petitioner”. That order is in force
even now.
3. Since the final report is already filed, no further
orders are necessary. The petitioner can surrender before the
jurisdictional court and if any bail application is filed before
the the jurisdictional court, the jurisdictional court will
consider the same in the light of the fact that there was an

B.A.No.6229/2021
3
interim order from this Court during the period of
investigation.
With the above observation, this bail application is disposed
of.
