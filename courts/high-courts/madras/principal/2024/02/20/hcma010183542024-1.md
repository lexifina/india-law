ABDUL QUDDHOSE, J.
The learned counsel for the respondent / defendant would submit that this
application can be allowed, provided that the respondent / defendant is granted
liberty to raise all objections with regard to the contents of the affidavit filed in
support of this application in the main suit or in any other interlocutory
applications to be filed by the applicants / plaintiffs in the near future.

in support of this application, which has been filed to combine the cause of
action. Accordingly, this application is allowed as prayed for.
3. Registry is directed to number the suit, if it is otherwise in order.
