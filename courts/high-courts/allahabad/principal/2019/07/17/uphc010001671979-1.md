# Allahabad High Court, SAPL/1889/1979, 2019-07-17

Counsel for Appellant :-

which was sent by registered post on 25.02.2005. Perused
report dated 15.07.2019. Notices have been received back with
postal endorsement that both the appellants have died and there

3. Interim order, if any, stands vacated.
