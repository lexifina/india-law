...
 CORAM : S.G. MEHARE, J.

 DATED : FEBRUARY 22, 2023
PER COURT:-
1. Learned counsel for the respondent raised an objection
that instead of approaching the Sessions Court, the applicant had
directly approached this Court. This approach is against the
precedent. The remedy is available to him before the Sessions Court.
2. Learned counsel for the applicant seeks leave to
withdraw the application with liberty to file a revision before the
Sessions Court.
3. Leave granted. The period spent before this Court shall
not be counted for limitation.
4. With the above observations, the application stands
disposed of.
 (S.G. MEHARE, J.)
