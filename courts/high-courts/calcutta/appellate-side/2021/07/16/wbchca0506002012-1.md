# Calcutta High Court, CRR/3356/2012, 2021-07-16

Sr. 26
 16-07-2021
 Subha.
 Court no. 34
 IN THE HIGH COURT AT CALCUTTA
 CRIMINAL REVISIONAL JURISDICTION
 APPELLATE SIDE
 ( Via Video Conference )
 CRR 3356 of 2012
In Re : Mathur Santra.
 ……..Petitioner.
 In the matter of : An application under Section 482 read with
Section 401 of the Code of Criminal Procedure.
 The present revisional application has been
preferred against the judgement and order dated 17th August,
2012 passed by the learned Additional Chief Judicial
Magistrate-in-Charge, Uluberia in Misc. Case No. 35 of 2012.
 The impugned order reflects that the learned Magistrate
was pleased to issue distress warrant for issuing Execution
Return on 18.09.2012.
 Records of the revisional application reflects that the
revisional application is yet to be admitted before this court.
 Having regard to the fact that the petitioner has failed
to apprise this court regarding the present stage of the
proceedings which were registered only in respect of execution,
I am of the view that no interference is called for at this
belated stage.

2
 Accordingly, the present revisional application
being CRR 3356 of 2012 is dismissed.
 All pending applications, if any, are consequently
disposed of.
 All parties are to act on the server copy of this order
duly downloaded from the official website of this court.
 ( Tirthankar Ghosh, J. )
