# High Court of Madhya Pradesh, WP/961/2015, 2017-07-11

Writ Petition No.961 of 2015.
11.07.2017:-
Shri Mohd. Iqbal Khan, learned counsel for the
petitioner.
Shri Kamal Airen, learned counsel for the
Respondents.
Heard on I.A.No.3752/2017, an application for
withdrawal of writ petition.
The State Government has issued Circular dated
07.10.2016 by which the direction has been issued to grant
minimum pay scale to the daily wagers.
The petition is dismissed as withdrawn. However,
liberty is granted to the petitioner to approach again if
occasion so arises.
Cc as per rules.
 [ VIVEK RUSIA ]
 JUDGE
(AKS)
