Heard Mr. F. Lalengliana, learned Senior Counsel appearing
for the petitioner. Also heard Ms. Vanneihsiami, learned Additional
Public Prosecutor appearing for the State respondent.
The learned Senior Counsel for the petitioner on instructions
received from the client through his junior counsel, submits that the
petitioner wishes to withdraw the present bail application with liberty
to file an appropriate application before this Court.

The prayer is allowed.
Accordingly, the bail application stands dismissed on being
withdrawn with liberty to file afresh.
Since the petitioner is in custody, in the event the learned
counsel for the petitioner approaches the Registry, the original copy of
the vakalatnama be returned to the learned counsel for the petitioner
for doing the needful.
