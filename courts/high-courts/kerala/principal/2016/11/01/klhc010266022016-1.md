J U D G M E N T
Chitambaresh, J.
There is a procedural irregularity in the
court below in first dismissing the application to set
aside the ex parte decree and then considering the
application for impleading in the said application.
I.A.Nos.3399/2015 and 3400/2015 were filed for
impleading in I.A.No.782/2014 filed to set aside the
ex parte decree. I.A.No.781/2014 was also filed to
condone the delay in filing the application to set
aside the ex parte decree.
2. We do feel that the court below should
have condoned the delay as well as allowed the
impleadment. The application for setting aside the ex
parte decree should have been dealt with thereafter.
We are also satisfied about the reasons stated for
condoning the delay in filing the application to set
aside the ex parte decree.
3. We allow I.A.Nos.3399/2015 and 3400/2015
and I.A.No.781/2014 in O.S.No.922/2010. This is of
course subject to the following conditions:-
