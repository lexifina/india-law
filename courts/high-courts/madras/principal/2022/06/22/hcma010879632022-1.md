https://hcservices.ecourts.gov.in/hcservices/

2. The primary ground argued by Mr.Sri Harini, learned
counsel for the petitioner, is that the impugned order of
revision dated 18.03.2022 which itself revises an earlier order
dated 28.02.2022 has not been preceded by a show cause notice.
3. This is an admitted fact and for this reason, the
impugned order is unsustainable and is hence set aside.
4. This writ petition is allowed. Connected writ
miscellaneous petitions are closed. No costs.
