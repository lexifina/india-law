# Allahabad High Court, A482/21432/2019, 2019-05-28

Court No. - 53
Case :- APPLICATION U/S 482 No. - 21432 of 2019
Applicant :- Rajendra Singh
Opposite Party :- State Of U.P. And 2 Others
Counsel for Applicant :- Vishnu Dutt Ojha,Sushil Jaiswal
Counsel for Opposite Party :- G.A.
Hon'ble Pankaj Naqvi,J.
On being confronted with an objection as to the
maintainability of this application, in view of the decision
of the Full Bench in Jagannath Verma vs. State of U.P
and another, AIR 2014 All 2014, which held that against
the order impugned, i.e., dismissing an application under
Section 156(3) Cr.P.C, a criminal revision is maintainable,
learned counsel for the applicant has come with a request
that this application be dismissed, but with liberty to file an
appropriate proceeding.
The application is dismissed, but with the aforesaid liberty.
Office is directed to return the certified copy of the order
impugned, after retaining a xerox copy thereof on record.
Order Date :- 28.5.2019
Chandra
