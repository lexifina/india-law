# High Court of Madhya Pradesh, MCC/876/2014, 2017-05-22

MCC-876-2014
(THE STATE OF MADHYA PRADESH Vs GYANCHAND)
22-05-2017
Smt. Janhvi Pandit, learned Government Advocate for the
applicant/State.
Heard on I.A. No. 9660/2016, which is an application for
correction in the description of respondnet no. 1 in the cause title.
Considering the nature of the amendment, the application is
allowed. Learned counsel for the applicant is permitted to carry
out the necessary amendment in the cause title today itself.
Also heard on admission.
This is an application for restoration of the writ petition
which has suffered dismissal on account of common conditional
order.
Considering the ground mentioned in the application which
is supported by an affidavit, the application is allowed. W.P. No.
1690/2014 be restored to its original number.
(VIJAY KUMAR SHUKLA)
