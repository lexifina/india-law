 Heard the learned counsel for petitioner as
well as the learned counsel for respondents.
2. The present application is filed for speaking to
the minutes in the order dated 07.07.2025. The learned
counsel appearing for petitioner submits that there is
typographical error in line No.2 of para No. 2 that instead
of ‘petitioner’ it should be ‘applicant’. Further in line No.3
of para 2 instead of ‘petitioner’ it should be ‘respondent’
and in the same line instead of ‘unsuitable’, it should be
‘eligible’.

3. The learned counsel appearing for
respondents has no objection so far as this part is
concerned. Accordingly, the application is allowed.
4. The office is directed to replace in line No.2 of
para 2 instead of ‘petitioner’ it should be replaced by
‘applicant’ and in the third line of second para instead of
‘petitioner’ the same should be replaced by ‘respondent’
and in the same line instead of ‘unsuitable’ it should be
replaced by ‘eligible’. The motion is accordingly allowed.
Hence, the application is disposed of.
5. Necessary corrections be made, and corrected
order be uploaded accordingly.
