ORDER
This Criminal Original Petition has been filed to quash the First
Information Report registered in Cr.No.1 of 2025, on the file of first respondent
as against the petitioner.
2. The petitioner is A3 in this case. It is the contention of the petitioner
that there is no allegation against the petitioner. However, he has been included
in the First Information Report. The crux of the allegation indicates that
spurious jewels had been pledged with the bank with the connivance of the
appraiser, huge loan has been obtained by the accused persons.
https://www.mhc.tn.gov.in/judis

3. The First Information Report has been registered on the complaint
made by the Bank Manager. The petitioner appears to be the Assistant Manager
of the bank. According to the petitioner, there is no allegations against him. Be
that as it may, if there is no allegation made out, it is for the investigating
officer to file necessary report in this regard. Therefore, as there are serious
allegations against the other accused, the First Information Report cannot be
quashed at this stage. If the investigating officer finds that there is no
cognizable offence made out against the petitioner, the investigating Officer can
proceed as per law. Hence, this Court is not inclined to quash the charges
against the petitioner at this stage.
4. Accordingly, this Criminal Original Petition is dismissed.
Consequently, connected miscellaneous petition is closed.
