ORDER
The petitioner/applicant has moved this application under Section 482 of the
Code of Criminal Procedure for modification in the order dated 30.01.2022 passed
in M.Cr.C. No.2220/2022.
Learned counsel for the applicant submits that vide order dated 31.01.2022
passed in M.Cr.C. No.2220/2022 this Court directed the applicant to appear
before the Investigating officer in respect of Crime No.1391/2021 and also Istgasa
No.5/2021 because this Court on earlier occasion taking note of both the crimes
had granted bail under Section 438 of the Code of Criminal Procedure to the
applicant vide order dated 01.12.2021 passed in M.Cr.C. No.39440/2021.
However, the order passed by this Court in M.Cr.C. No.2220/2022 is
nothing but in furtherance to the order passed by the Court in M.Cr.C.
No.39440/2021, therefore, there is no reason to mention the amount of bail bond
because that amount had already been mentioned in earlier order passed by this
Court in M.Cr.C. No.39440/2021. Thus, it is clarified that if the order passed by
