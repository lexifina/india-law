Order No.
ORDER
15.12.2023
01. 1. This matter is taken up through Hybrid Arrangement (Virtual
/Physical Mode).
2. Heard learned counsel for the petitioner.
3. Alleging violation of this Court’s order the present contempt
application has been filed. Learned counsel for the petitioner
submitted that after the writ application was disposed of vide order
dated 18.07.2023, the Opposite Parties have deliberately and
willfully violated this Court’s order. In the process, they have also
shown disrespect to order dated 18.07.2023 as they had relieved the
members of Petitioner’s association without cost imposing.
4. Considering such submissions made by learned counsel for the
Petitioner and keeping in view the allegations made in the contempt

 // 2 //
application which appears to be very serious in nature. The Opposite
Parties are further four weeks time to implement the order dated
18.07.2023 in W.P.(C) No.21912 of 2023, if the same has not been
complied with in the meantime, provided the operation of
order/judgment has not been stayed by higher forum and file
compliance report before the Registry of this Court within one week
thereafter. It is made clear that in the event the order of the Court is
not given effect to within the time stipulated hereinabove, it will be
construed to be deliberate violation of this Court’s order.
5. The CONTC is accordingly disposed of.
 Urgent certified copy of this order be granted on proper
application.
