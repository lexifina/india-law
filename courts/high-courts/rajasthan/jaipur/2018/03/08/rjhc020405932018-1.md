HON'BLE MR. JUSTICE PANKAJ BHANDARI
Order
08/03/2018
1. Counsel for the petitioner has moved an application for
correction in the order dated 05.03.2018.
2. It is contended by counsel for the petitioner that in the order
dated 05.03.2018, in the cause title “Manoj Kumar S/o Sohan Lal”
has been wrongly mentioned, whereas it should be “Manoj Kumar
S/o Mohan Lal.” It is also contended that correction has been
made in the order of the Court below on 06.03.2018.
3. It is requested by counsel for the petitioner that amended
cause title be taken on record and in the impugned order dated

(2 of 2) [CRLMA-136/2018]
05.03.2018, “Manoj Kumar S/o Sohan Lal” be read as “Manoj
Kumar S/o Mohan Lal.”
4. Application for correction is accordingly allowed. In the
impugned order dated 05.03.2018, in the cause title “Manoj
Kumar S/o Sohan Lal” be read as “Manoj Kumar S/o Mohan Lal.”

(PANKAJ BHANDARI),J
