# Calcutta High Court, CRR/3009/2016, 2022-02-25

25.02.2022 IN THE HIGH COURT AT CALCUTTA
 Item No.7 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
 C.R.R. 3009 of 2016
 (Via Video Conference)
 Pradip Kumar Kar & Ors.
 versus
 The State of West Bengal
In Re: An Application under Sections 397/401 read with
Section 482 of the Code of Criminal Procedure filed in
connection with Burdwan Police Station Case No. 776 of 2009
dated 25.11.2009 under Sections 384/511/506/120B of the
Indian Penal Code.
Mr. Jayanta Narayan Chatterjee,
Mr. Debojit Samanta,
Mr. S. Koley … For the Petitioners.
Mr. Saibal Bapuli,
Mr. Bibaswan Bhattacharya … For the State.
A report dated 23.02.2022 submitted by Mr. Bibaswan
Bhattacharya, learned advocate appearing for the State which
has been prepared by the Inspector-in-Charge, Burdwan
Police Station be kept on record.
The report reflects that last date was fixed on
21.02.2022 and the next date has been fixed on 28.02.2022.
Learned advocate for the State submits that the case
diary along with all the documents which were misplaced has
already been traced out and the prosecution is ready to
proceed with the case.
The report also reflects that the prosecution is ready
with the documents under Section 207 of the Code of
Criminal Procedure. Let the same be complied with on the
next date as the accused persons are yet to receive the copies.

2
The learned Magistrate is directed to complete the
process of consideration of charge within a period of 60 (sixty)
days from the date of communication of this order.
Learned advocate for the State is directed to
communicate this order and request his counterpart to place
the same on the next date fixed in the learned trial court.
With the aforesaid observations, the revisional
application being CRR 3009 of 2016 is disposed of.
Interim order, if any, is hereby vacated.
All pending connected applications, if any, are
consequently disposed of.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance with all
requisite formalities.
 (Tirthankar Ghosh, J.)
