 Learned counsel for appellant absent.

(Judicial), as the value does not exceed Rs.10 lakhs.
 3. In view of the above, the proper forum to file
appeal is before the District Judge.
 4. Accordingly, the appeal is dismissed as not
maintainable, with liberty to the appellant to file the same
before the District Judge.
 Office is directed to return the documents to the
appellant.
