# Allahabad High Court, A482/4385/2020, 2020-02-04

Court No. - 52
Case :- APPLICATION U/S 482 No. - 4385 of 2020
Applicant :- Rehman
Opposite Party :- State Of U.P. And 4 Ors
Counsel for Applicant :- Krishna Kumar Shukla
Counsel for Opposite Party :- G.A.
Hon'ble Neeraj Tiwari,J.
Heard learned counsel for the applicant and learned AGA.
Learned AGA has raised preliminary objection and submits that
the applicant has alternative remedy to file revision under
Section 397 Cr.P.C., which is not disputed by learned counsel
for the applicant.
The application is dismissed with liberty to the applicant to file
revision under Section 397 Cr.P.C. in accordance with law, if so
advised.
Office is directed to return the certified copies of the document
annexed with the application after retaining the photocopy of
the same on record.
Order Date :- 4.2.2020
Arvind
