ORDER
Date : 01.06.2023
Ms. S. K. Achumi, learned counsel for the petitioner wants to
withdraw this writ petition with liberty to file afresh.
On the other hand, Mr. K. Angami, learned Government
Advocate for the respondents opposes the prayer for allowing the
withdrawal with liberty to file afresh.
Learned counsel for the petitioner has submitted that the
petitioner was in fact under a mistaken belief that this case has
already been withdrawn and, therefore, she had filed WP(C) No.
93/2023 along with seven others petitioners in respect of the same
matter. It is also pointed out to this Court, that today WP(C) No.
93/2023 was allowed to be withdrawn by the petitioner due to some
technical defect with a liberty to file afresh. As the subject-matter of
both the cases are same and as liberty to file a fresh case has
already been granted in WP(C) No. 93/2023, this Court allows the
petitioner to withdraw the present petition also with liberty to file
afresh.
This case is accordingly dismissed on withdrawal with liberty to
file afresh.
