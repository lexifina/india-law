2/ 22.04.2009 This is an application for restoration of Cr. Misc. No.52515
of 2008, which was dismissed for non-compliance of the order dated
10.2.2009 within the specified time.
Heard.
On the grounds mentioned in the application, this
restoration application is allowed and Cr. Misc. No.52515 of 2008 is
restored to its original file as the requisites etc. have already been filed.
Learned counsel for the petitioner is permitted to comply
with the order dated 10.2.2009 and add the informant as opposite party
no.2 in the main application in course of the day.
JA/- (Sheema Ali Khan, J.)
