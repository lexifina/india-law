# Madras High Court, A/2258/2017, 2017-06-15

A.No.2258 of 2017
in C.S.No.319 of 2009
P.KALAIYARASAN, J.
This application has been filed by
the applicant/plaintiff seeking permission to
file reply statement.
2. It is averred in the application
that in the written statement, the
defendant has stated some new facts
regarding the alleged dealership agreement
entered in the year 1992 which are
necessary to be dealt with by way of a
reply statement. Therefore, the applicant/
plaintiff wants to file a reply statement.
3. Learned counsel for the
respondent/defendant opposes this
application contending that no new facts
has been brought in the written statement.
4. In the written statement, the
respondent/defendant has stated certain
new facts regarding the alleged dealership
entered in the year 1992.
5. Therefore, this Court is of the
view that the applicant/plaintiff has to be
given an opportunity to put forth his case
by filing a reply statement. Accordingly,
this application is allowed and the reply
statement is ordered to be received.
15.06.2017
