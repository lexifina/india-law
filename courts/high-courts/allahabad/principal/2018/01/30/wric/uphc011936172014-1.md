# Allahabad High Court, WRIC/43175/2014, 2018-01-30

Court No. - 25
Case :- WRIT - C No. - 43175 of 2014
Petitioner :- Satish Kumar Maurya
Respondent :- State Of U.P. & 2 Others
Counsel for Petitioner :- Gopal Krishna Pandey
Counsel for Respondent :- C.S.C.,R.P. Yadav,Ram Kishun Mishra
Hon'ble Siddhartha Varma,J.
This writ petition arises out of the order dated
03.07.2014 by which the Appellate Court had
entertained the appeal against the order dated
31.01.2008, which was passed on an application
filed by the respondent No.2 under Order 9, Rule
13 of Code of Civil Procedure. Since the
respondent No.2 has filed a regular First Appeal
against the ex-parte decree, it shall not be proper
for him to pursuance the proceedings, which arise
from the filing of the application under Order 9,
Rule 13 of Code of Civil Procedure.
Under such circumstances, the order dated
03.07.2014 is quashed. All proceedings, which
have arisen from the filing of the application
under Order 9, Rule 13 of Code of Civil
Procedure are quashed. However, the grounds,
which the respondent No.2 had taken in the
application under Order 9, Rule 13 of Code of
Civil Procedure, may be taken by him while
pursuing the First Appeal.
Accordingly, the writ petition is allowed.
Order Date :- 30.1.2018
