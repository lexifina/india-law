Order

Matter comes up on an application (IA No. 9435/2018), with
a prayer for withdrawal of the writ application with liberty reserved
to the petitioner to file fresh.
 For the reasons detailed out in the memo of the interim
application and upon hearing the learned counsel for the parties
as well as having regard to the nature of the controversy involved;
the application merits acceptance.
Consequently, the application is hereby allowed.
In the result, the writ application is dismissed with liberty
reserved to the petitioner to file fresh, if so advised.
