# Allahabad High Court, WRIC/13406/2019, 2019-04-18

Court No. - 34
Case :- WRIT - C No. - 13406 of 2019
Petitioner :- M/S Humza Brick Works And Another
Respondent :- State Of U.P. And 4 Others
Counsel for Petitioner :- Arvind Kumar Trivedi,Mohd. Ashraf Abbasi
Counsel for Respondent :- C.S.C.,Hari Nath Tripathi
Hon'ble Sudhir Agarwal,J.
Hon'ble Rajendra Kumar-IV,J.
1. Heard Sri Arvind Kumar Trivedi, learned counsel for
petitioner, learned Standing Counsel for State of U.P. and its
authorities, Dr. H.N.Tripathi, learned counsel for respondent 4
and perused the record.
2. Admittedly, petitioner was not granted any consent/No
Objection Certificate to run brick-kiln by Pollution Control
Board. He has only made an application and thereafter started
running brick-kiln. Therefore, it was directed to be closed by
authority concerned. It also appear that earlier respondent 5
approached this Court in a Public Interest Litigation No.55745
of 2016 wherein a statement was made by respondents that
brick-kiln has been directed to be closed and thereafter said PIL
was disposed for vide judgment dated 29.11.2016. There is no
order passed by this Court for closing the brick-kiln but brick-kiln has been closed by authorities concerned for the reason that
it was being run without having consent/No Objection
Certificate from Pollution Control Board and without such
consent/NOC, brick-kiln could not have been run.
3. As petitioner has not obtained consent/No Objection
Certificate from Pollution Control Board, he has no right to run
the brick-kiln. In view thereof, we find no illegality in the order
passed by Sub Divisional Magistrate, Tanda, District Rampur.
4. Writ petition, therefore, lacks merit. Dismissed.
Order Date :- 18.4.2019
