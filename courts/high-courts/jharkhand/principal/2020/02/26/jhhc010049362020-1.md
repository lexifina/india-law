# High Court of Jharkhand, Cr.M.P./449/2020, 2020-02-26

IN THE HIGH COURT OF JHARKHAND AT RANCHI
Cr. M.P. No. 449 of 2020
----
Shambhu Jha … Petitioner
-versus-The State of Jharkhand … Opposite Party
----
CORAM : HON’BLE MR. JUSTICE ANANDA SEN
----
For the Petitioner : Mr. Vikash Kumar, Advocate
For the State : Mr. Sardhu Mahto, A.P.P.
----
3/ 26.02.2020 Heard learned counsel for the petitioner and the learned
A.P.P. for the State.
 2. Petitioner has challenged the order dated 22.01.2020 passed
by the Chief Judicial Magistrate, Seraikella in Adityapur Police Station
Case No.312 of 2018, by which processes under Section 82 of the Code of
Criminal Procedure has been issued.
3. Counsel for the petitioner submits that the order issuing
process under Section 82 of the Code of Criminal Procedure is absolutely
cryptic and does not reflect any satisfaction as to why processes under
Section 82 of the Code of Criminal Procedure has to be issued. He
submits that merely on the application made by the police, the Court below
has passed the order issuing process under Section 82 of the Code of
Criminal Procedure.
4. After going through the impugned order, I find that the same is
absolutely cryptic and no satisfaction has been recorded as to why process
under Section 82 of the Code of Criminal Procedure is necessitated. The
order has been passed only on the petition filed by the investigating officer.
5. Accordingly, the order impugned dated 22.01.2020 passed by
the Chief Judicial Magistrate, Seraikella in Adityapur Police Station Case
No.312 of 2018, issuing process under Section 82 of the Code of Criminal
Procedure is hereby quashed and set aside. The matter is remitted to the
Court below to proceed afresh and pass an order in accordance with law.
6. This criminal miscellaneous petition is, thus, allowed.

( Ananda Sen, J.)
