Application praying that this Hon'ble Court be pleased to set aside the
order of dismissal dt.08.02.2017 in C.S.No.94/2009 and restore the above
suit.
 This Application coming on this day before this Court for hearing, the
Court made the following order:
This application has been filed to set aside the order of dismissal dated
08.02.2017 in C.S.No.94 of 2009 and restore the above suit.
2.The plaintiff is a purchaser of a share in the suit property from one of the
co-sharers. He has now laid a suit for partition. The counter filed by the 4
th
defendant states that it is an unnecessary party to the litigation.
3.The suit is dismissed for default and this application is filed to restore the
same along with the application to condone the delay in taking out this
application.
4.The 2
nd
 defendant has not filed any counter, whereas, the 4
th
 defendant has
filed its counter, which has already been noted and now it has only taken an
appeal that it is not a necessary party to the litigation.
