Hon'ble Rajeev Misra,J.
1. Heard Mr. Chandra Prakash Singh, the learned counsel for
applicants and the learned A.G.A. for State.

applicants do not wish to press this applicant. Accordingly,
present application be dismissed as not pressed with liberty to file
fresh.

learned counsel for applicants.
4. In view of above, present application is dismissed as not pressed
with liberty to file fresh.

learned counsel for applicants after obtaining a photostat copy of
the same to be kept on record
