439 Code of Criminal Procedure 1973 seeking regular
bail in F.I.R. No.108/2016 registered at Police Station
Raini, District Alwar, for offence under Section 302,
201 Indian Penal Code 1860.

11.11.2016. There is no change in circumstances
warranting interference by this court.
Dismissed.
