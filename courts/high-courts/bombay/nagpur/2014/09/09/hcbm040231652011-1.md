The applicant/appellant has not stated the provisions under
which the application is made. The learned advocate for the
applicant/appellant submits that the application has to be treated as
under Order 41 Rule 5 of the Code of Civil Procedure. The prayer as
made in the application is not in consonance with the provisions of
Order 41 Rule 5 of the Code of Civil Procedure. While considering the
application under Order 41 Rule 5 of the Code of Civil Procedure, there
cannot be stay to the judgment and decree passed by the District
Court and execution of the decree can be stayed. Shri Shrivastava,
the learned advocate for the applicant/appellant, seeks oral leave to
amend the prayer clause to bring it in consonance with the provisions
of Order 41 Rule 5 of the Code of Civil Procedure. Leave granted

amount is deposited, there shall be stay to the execution of the
impugned decree until further orders. Civil application is allowed in the
above terms.
