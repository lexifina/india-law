WRIT PETITION No.1566 of 2014
ORDER: (per Hon’ble the Chief Justice Sri Kalyan Jyoti Sengupta )
Learned Counsel for the petitioner wants to withdraw this
writ petition with liberty to file a fresh one.
Accordingly, we dismiss this Writ petition as being
withdrawn with liberty to file a fresh one, in accordance with law, if
so advised. However, leave granted by this Court should not
remain for indefinite period. This leave operated, provided any
fresh action is taken within 15 days from date, failing which this
leave will stand revoked. Miscellaneous Petitions pending, if any,
shall also stand closed. No order as to costs.
