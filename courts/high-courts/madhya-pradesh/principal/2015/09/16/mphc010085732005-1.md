# High Court of Madhya Pradesh, CR/177/2005, 2015-09-16

C.R.No.177/2005
16.09.2015
Shri Adil Usmani, learned counsel for the applicant.
In fact, the revision should have been treated as
dismissed in reference to order dated 16.7.2015, as a
peremptory order was issued by this Court for compliance of
order dated 9.4.2015, failing which the revision was to be
treated as dismissed without even reference to the Bench. It
appears that the Registry has not looked into this order and
has wrongly listed this matter on 3.8.2015, whereas since
the order dated 9.4.2015 was not complied with the revision
was to be treated as dismissed automatically.
Learned counsel appearing for the applicant prayed for
time to make an appropriate application.
Whatever the circumstances, the restoration
application is required to be filed with prayer for recall of the
peremptory order aforesaid.
This revision is treated as disposed of
accordingly.
(K.K.Trivedi)
 Judge
A.Praj.
