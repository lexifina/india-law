P.C. :
1. Rule. Rule is made returnable forthwith. By consent, heard finally.
2. The application dated 2nd December, 2011 filed by the respondents
herein for condonation of delay to file written statement and say to
application below Exh.5 was before the learned Civil Judge, Senior
Division, Panvel in S.C. Suit No.503 of 2011. On the said
application, the learned Civil Judge, Senior Division, Panvel passed
order “other side to file their say and posted the matter for further
hearing on 7th January, 2012”.
3. It appears that some application was moved on 8th December, 2012

2 677-12-wp-Urgent=.sxw
and ultimately the impugned order dated 22nd December, 2011 was
passed thereby granting the application filed by the respondents
without their being a proper hearing in regard to this application
below Exh.23/D. In my view, if the application below Exh.23/D
was posted for hearing on 7th January, 2012 as per the Roznama
dated 2nd December, 2011, the learned trial Judge could not have
attended to this application below Exh.23/D prior to 7th January,
2012. He has passed the impugned order on 22nd December, 2011
thereby disposing of the application below Exh.23/D. The principles
of natural justice have not been followed. Hence, on this limited
ground, I am inclined to set aside the order dated 22nd December,
2011 and allow the petitioners to file their reply to the said
application below Exh.23/D and thereafter decide the matter on
merits.
4. After the aforesaid order is passed, learned advocate for the
respondents submitted that affidavit-in-reply to Exh.23/D is already
filed. Learned advocate for the petitioners is unable to confirm the
said fact. The Court is informed that the next date in the suit is on
13th March, 2012. Hence, petitioners can be permitted to file a
reply if not already filed on 13th March, 2012 and the learned Judge

3 677-12-wp-Urgent=.sxw
can be directed to dispose of application below Exh.23/D by 16th
April, 2012. Hence, following order is passed.
ORDER
(i) Order dated 22nd December, 2011 below Exh.23/D is set aside. The
petitioners can file their reply to Exh.23/D on 13th March, 2012, if
not already filed. The petitioners to serve a copy of the same to the
other side.
(ii) The Learned Civil Judge, Senior Division, Panvel before whom S.C.
Suit No.503 of 2011 is pending shall hear and dispose of application
below Exh.23/D as expeditiously as possible and preferably before
16th April, 2012. There shall be no order as to costs.
(iii)Since lawyers on both the sides are present before this Court,
petitioners need not wait for authenticated copy of this order. They
will file the affidavit in reply on the basis of a forwarding application
made by advocate for the petitioners. Office to issue authenticated
copy of this order to both the sides.
[R.Y.GANOO, J.]
