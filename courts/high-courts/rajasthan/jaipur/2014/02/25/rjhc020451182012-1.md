# High Court of Rajasthan, CRLMP/4116/2012, 2014-02-25

S.B. Criminal Misc. Petition No.4116/2012
S.B. Criminal Misc. Stay Application No.3480/2012
(Karniram Versus State of Rajasthan)
Date of Order :: 25th February, 2014
 HON'BLE MR. JUSTICE MAHESH CHANDRA SHARMA
Mr. Avdhesh Purohit, counsel for the petitioner
Mr. Virendra Godara, PP for the State
Learned counsel for the petitioner wants that this petition
should be disposed of with direction to the Investigating Officer to
investigate the matter fairly, properly and impartially, if report has
not been filed in this case.
Learned PP appearing for the State has opposed the
same.
The prayer of the counsel of the petitioner seems to be
genuine, hence ordered accordingly. The Cr. Misc. petition as also
the stay application both stand disposed of.
 (Mahesh Chandra Sharma)J.
