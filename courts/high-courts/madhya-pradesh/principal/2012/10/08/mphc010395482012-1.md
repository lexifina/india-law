# High Court of Madhya Pradesh, MCC/1063/2012, 2012-10-08

Ram Krishna Shrivastava Vs. The State of M.P. & Ors.
1
M.C.C. No. 1063 / 2012
8.10.2012:
Shri Vishal Dhagat, learned counsel for the petitioner.
Shri Sanjeev Kumar Singh, learned Panel Lawyer for
respondents.
By this application petitioner is seeking correction of cause-title of a decided writ petition.
The same requires amendment of the writ petition and as writ
petition is already decided, amendment of the cause-title in the
manner done cannot be permitted. Petitioner should file a separate
writ petition indicating the correct facts and, therefore, finding this
petition to be unsustainable, the application is disposed of with
liberty to the petitioner to file a separate petition seeking the
aforesaid benefit.
The application is dismissed with the aforesaid.
 (Rajendra Menon)
