 ORDER
This Criminal Original Petition has been filed to quash the FIR
in Crime No.138 of 2015 on the file of the first respondent police.
2.The learned Additional Public Prosecutor would submit that
the respondent police have already filed a final report on
12.10.2015 before the learned Judicial Magistrate, Tirunelveli and
the same is yet to be taken on file.
3.In view of the above, nothing survives in this criminal
original petition and the same is closed. Consequently, the
connected miscellaneous petition is closed.
