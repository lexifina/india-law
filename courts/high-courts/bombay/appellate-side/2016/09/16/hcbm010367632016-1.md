CORAM : A.S.OKA, &
 A. K. MENON, JJ.

P.C.:
The application discloses that chargesheet has
already been filed for the offences punishable under
Sections 406, 409, 467, 468 and 471 of the Indian
Penal Code. The applicant has a remedy to apply for
discharge. Hence, we decline to entertain this
application under Section 482 of the Code of
Criminal Procedure, 1973 for quashing the First
Information Report.
2. The application is disposed of. However, the
remedy of the applicant is kept open. All the
contentions raised in this Application are kept
open.
 (A.K.MENON,J.) (A.S.OKA,J.)
