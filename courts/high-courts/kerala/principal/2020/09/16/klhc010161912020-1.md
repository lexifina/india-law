This Bail Application filed under Section 438 of
Criminal Procedure Code was heard through Video
Conference.
2. This bail application is filed by the accused in
crime No.03/2020 of Cheruthuruthy Police Station,
Thrissur District. The above case is registered against the
petitioner alleging offences punishable under Sections
450, 324, 302, 176 and 212 of the Indian Penal Code
(IPC).
3. The petitioner was arrested on 03.01.2020.
This bail application was filed on 28.02.2020. Even now
this petition filed under Section 438 of Cr.P.C. is pending
before this Court. When this bail application came up for

B.A.No. 1636 of 2020
3
consideration on 06.07.2020, there was no
representation. Thereafter this bail application came for
consideration before this Court through Video Conference.
There is no representation when the bail application was
called. Thereafter I passed over this bail application and
called it again. Even now there is no representation. In
such circumstances, this bail application is dismissed for
default.
