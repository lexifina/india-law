# High Court of Uttarakhand, WPMS/477/2011, 2014-03-13

MCC No. 80 of 2014
CLMA No. 2069 of 2014
In
WPMS No. 477 of 2011
Hon’ble B.S. Verma, J.
Ms. Seema Sah, Advocate for the petitioner.
Mr. Sharad Sharma, Senior Advocate assisted
by Mr. Pradeep Chamiyal, Advocate for the
respondents.
Learned Senior Counsel, appearing for the
respondents had made prayer that clarification
application be treated as modification application.
In view of the prayer made by learned Senior
Counsel for the respondents, clarification
application is treated as clarification / modification
application.
I have perused the order dated 24.09.2013, in
the body of the order, this Court has considered the
application 42-C/2 as impleadment application.
Learned Senior Counsel has contended that since
the application 42-C/2 has been allowed in toto,
therefore, the trial court has interpreted the order
that the amendment is also allowed, therefore, it
need clarification.
I have perused my order, in the body of the
Judgment and Order, only impleadment application
was discussed and the same was allowed. So far as,
amendment part, which has been sought in the
application was not allowed. Therefore, operative
portion of the judgment is clarified that the
application 42-C/2 amendment / impleadment is
partly allowed only in respect of impleadment of the
purchaser / petitioner. The order is modified to the
extent mentioned above.
Modification application stands allowed to
the above extent.
 (B.S. Verma, J.)
