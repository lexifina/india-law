# High Court of Madhya Pradesh, MCC/1804/2016, 2017-09-12

MCC-1804-2016
(MOHD. WAHEED KHAN Vs THE STATE OF MADHYA PRADESH)
12-09-2017
Shri Jitesh Shrivastava, learned counsel for the applicant.
Heard on I.A. No.9678/2016, an application for condonation of
delay.
For the reasons mentioned in the application, the same (I.A.
No.9678/2016) is allowed. The delay in filing this application is
hereby condoned.
This application has been filed for restoration of W.P.
No.20785/2015 which has been dismissed for want of prosecution
on 24.02.2016. The application is supported by an affidavit of
counsel for the applicant.
Keeping in view the reasons indicated in the application, the MCC
is allowed and it is directed that W.P. No. 20785/2015 be restored
to its original number and list this case before the appropriate
Bench.
Let a copy of this order be kept in the file of W.P. No.20785/2015.
(SMT. ANJULI PALO)
JUDGE
