# High Court for the State of Telangana, CRLP/7951/2015, 2015-08-21

HONOURABLE Dr. JUSTICE B.SIVA SANKARA RAO
CRIMINAL PETITION No.7951 of 2015
ORDER:

Learned counsel for the petitioners seeks permission to
withdraw the criminal petition with liberty to file better application
afresh.
Permission as sought for is accorded.
Accordingly, the Criminal Petition is dismissed as withdrawn
with liberty to file better application afresh. Consequently, the
miscellaneous petitions pending if any shall also stand dismissed.
