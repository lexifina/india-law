 CORAM : A.I.S. CHEEMA, J.
 DATED : 25th FEBRUARY, 2015
Order :-
1. Heard learned counsel for applicant - Sharmila -
original complainant.
2. Learned counsel for applicant-original complainant
submits that she was expecting that State to file appeal
against acquittal but State did not take steps and so
applicant has filed present application along with appeal and
because of this there was delay.
3. Learned counsel for respondents No. 1 to 6 original
accused opposes the application and submits that the delay
is not properly explained.

2 Cri.A.1701.13
4. In this matter the State has also filed Criminal
Application No. 1804 of 2013 for leave. It appears that
State had also moved an application for condonation of
delay. The delay in the application for State has been
condoned.
5. For the reasons stated in the present application for
condonation of delay, in the interest of justice, the same is
allowed. Delay stands condoned.
6. Present Criminal Application stands disposed of.
Sd/-
 ( A.I.S. CHEEMA, J. )
