ORDER
The Civil Revision Petition is filed challenging the order passed by the
Executing Court, dismissing the application filed by the petitioner to set aside
the sale that had taken place on 29.03.2012.
2. The petitioner had filed an application under the Order XXI Rule 90
Code of Civil Procedure seeking to set aside the sale, which was adjudicated
under Rule 92 and dismissed. Therefore, the impugned order is appealable one
under Order 43 Rule 1(j) of the Code of Civil Procedure. Consequently, a
revision is not maintainable and accordingly, this Civil Revision Petition is
dismissed with liberty granted to the petitioner to file an appeal before the First
Appellate Court.
 3. The Registry is directed to issue a copy of this order on 26.10.2026.
The Registry is further directed to return the original order copy either on
26.10.2026 or 27.10.2026.
4. It seems the revision was filed within 30 days from the date of the
impugned order (After exclusion of the time taken for obtaining the certified
copy). The petitioner is directed to file an appeal before the Appellate Court
within two weeks from the date of receipt of a copy of this order. If the appeal is
