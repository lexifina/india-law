Order
12/06/2020
Heard learned counsel for the petitioner and learned counsel
for the complainant through Jitsi Meet. It has been submitted on
behalf of the petitioner that the S.B. Criminal Misc. Bail Application
No.6268/2020 Bhupesh @ Bhola S/o Buddharam was allowed on
10.06.2020 by this Court. Counsel for the petitioner have come to
know about the mistake of the petitioner father Buddharam in
place of Rakesh which is typographically bona fide mistake which
can be cured by the Hon’ble Court and required to be corrected as
Bhupesh @ Bhola S/o Rakesh. The mistake is bona fide and
father’s name of the petitioner is required to be corrected as
Rakesh in place of Buddharam which has wrongly been typed in
the application. The amended cause-title has been submitted
along with application.

(2 of 2) [CRLMA-141/2020]
Learned counsel for the complainant has opposed the
application and submitted that as name of the father of the
petitioner was wrongly mentioned in the application, he could not
file his power in the bail application when bail application was
heard on merits.
Perused the order dated 10.06.2020 passed in S.B. Criminal
Misc. Bail Application No.6268/2020. The name of the petitioner
father appears as Rakesh in the order of the learned Court below
but application was filed name of Bhupesh @ Bhola S/o
Buddharam which appears to be a bona fide mistake. Hence,
application for correction of this mistake is accepted. Amended
cause-title is taken on record. In the order dated 10.06.2020
passed in S.B. Criminal Misc. Bail Application No.6268/2020.
Name of the petitioner be read as Bhupesh @ Bhola S/o Rakesh in
place of Bhupesh @ Bhola S/o Buddharam. Application is accepted
as above.
