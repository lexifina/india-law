ORDER
The contempt petition is filed for disobedience of the order of this Court
dated 17.10.2023.
2. The learned counsel for the petitioner sought time.
3. The learned counsel for the contemnors on the other hand submitted that
the order passed by this Court has been complied with. The learned counsel
produced the copy of the order dated 06.01.2025, granting permanent status to the
petitioner.
4. In view of the order of the respondents dated 06.01.2025, this Court is of
the view that the contempt petition deserves to be closed. Accordingly, this
contempt petition is closed. The learned counsel for the petitioner is given liberty
to challenge the order dated 06.01.2025, if so advised.
