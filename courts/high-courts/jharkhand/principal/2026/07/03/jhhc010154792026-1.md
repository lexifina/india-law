03/ 03rd July, 2026
1. Heard the parties.
2. After some arguments, the learned counsel for the
petitioner admits that the order of confiscation passed by the
Confiscating Authority, is appealable before the Appellate Authority.
He submits that he may be given permission to file an appeal.
3. For availing a statutory remedy, no permission is
necessary from any Court or any authority. It is the right of a litigant
to file an appeal under any statute if the same provides for,
considering the limitations. Thus, the petitioner should file an
appropriate appeal before the Appellate Authority.
4. With the aforesaid observations, this writ petition stands
disposed of.
