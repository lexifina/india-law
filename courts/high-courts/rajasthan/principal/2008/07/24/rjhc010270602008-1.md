# High Court of Rajasthan, CRLMP/967/2008, 2008-07-24

S.B.CR.MISC. PETITION NO. 967/2008
 IN
S.B. CR. MISC. BAIL APPLICATION NO.2985/2008
(Anop Singh Vs. State of Rajasthan)
DATE OF ORDER : 24/7/2008
HON'BLE MR.BHANWAROO KHAN, J.
Mr. H.S. Bahlot, for the petitioner.
Mr. S.K. Vyas, PP.
This Misc. Petition under Section
482, Cr.P.C. is filed for seeking correction
in the bail order dated 21.07.2008 passed by
this Court in which by typographical error
name of accused-petitioner's father Bheek
Singh has wrongly been mentioned, it should
has been Bheem Singh and number of misc. bail
application i.e. 2985/2007 has also wrongly
been mentioned whereas it should has been
2985/2008.
 The corrections are made and number of
Misc. Bail Application No. 2985/2008 and
father's name of the petitioner Bheem Singh
are inserted and the word “Misc. Bail
Application No.2985/2007” and “father's name
of the petitioner Bheek Singh” are deleted.
With these modification, the misc.
application stands allowed.
 (BHANWAROO KHAN)J.
