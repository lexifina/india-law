28/01/2026
1. After arguing for some time by petitioner, this Court on
perusal of the file observed that there was no application under
Order 41 Rule 5 CPC for staying the execution of the decree.
2. In response to this learned counsel for the petitioner submits
that inadvertently he had not filed an application under Order 41
Rule 5 CPC.
3. At this stage, learned counsel for the petitioner seeks
permission to withdraw the present petition with liberty to file an
application under Order 41 Rule 5 CPC praying for stay of the
execution of the decree.
4. Accordingly, the present writ petition is dismissed with
aforesaid liberty.
5. It is made clear that if any such application is filed under
Order 41 Rule 5 CPC, it is expected from the learned Appellate
Court to decide it as expeditiously as possible, without being
influenced by the order dated 07.01.2026.
6. Pending application(s), if any, also stand disposed of.
(BIPIN GUPTA),J
