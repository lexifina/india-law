# Allahabad High Court, BAIL/19203/2020, 2020-07-29

Court No. - 48
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 19203
of 2020
Applicant :- Chandan And Another
Opposite Party :- State of U.P.
Counsel for Applicant :- Alkesh Singh
Counsel for Opposite Party :- G.A.
Hon'ble Pradeep Kumar Srivastava,J.
This bail application has been directly filed before this Court as
the concerned district court was closed due to COVID-19
pandemic.
Learned counsel for the applicants has submitted that he wants
to withdraw this bail application with liberty to file the same
before the district court concerned.
In view of above, the present bail application is rejected as
withdrawn with liberty to file the same before the learned court
below.
