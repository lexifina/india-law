# Madras High Court, A/2745/2019, 2019-04-08

1
Appl.No.2745 of 2019
 in
E.P.SR.No.32592 of 2019
R.SURESH KUMAR, J.
This application has been filed seeking to grant an order
permitting the applicant, to file the current Execution Petition
simultaneously with E.P.No.40 of 2019, to execute the Foreign Awards dated
9
th April 2017 and 6th
 August 2017.
2. Learned counsel for the applicant submits that, already a
Execution Petition in E.P.No.40 of 2019 has been filed and the same is
posted for hearing on 11.04.2019. Hence, in order to take this Execution
Petition as an simultaneous Execution Petition, this application has been
filed. Since, this Execution Petition is filed to execute the Foreign Award
dated 09.04.2017 and 06.08.2017 and already an Execution Petition has
been filed in E.P.No.40 of 2017 and the same is pending before this Court,
this petition became necessary, to permit the petitioner to file this
Execution Petition as simultaneous Execution Petition, with the earlier
Execution Petition filed before this Court.
3. In view of the above, this application is allowed. Post the
main Execution Petition, if it is otherwise in order, along with the E.P.No.40
of 2019 on 11.04.2019.
