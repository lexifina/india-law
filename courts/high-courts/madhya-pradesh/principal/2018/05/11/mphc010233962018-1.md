# High Court of Madhya Pradesh, MCC/1300/2018, 2018-05-11

THE HIGH COURT OF MADHYA PRADESH
MCC-1300-2018
(KAILASH NARAYAN TIWARI Vs CHANDRA PRAKASH)
Jabalpur, Dated : 11-05-2018
Shri Ajay Mishra, learned counsel for the applicant.
This is an application for restoration of M.A. No.5657/2008
which has suffered dismissal on account of non compliance of the
peremptory order dated 29.1.2018.
Considering the averments made in the application supported by
an affidavit of the counsel himself, the application is allowed. The
original case is directed to be restored to its original number.
The delay in filing the present application for restoration, is also
condoned for the same reasons as mentioned herein above.
With the aforesaid, this applications stands allowed and disposed
of.
(VIJAY KUMAR SHUKLA)
JUDGE
