# High Court of Orissa, WP(C)/5601/2018, 2019-04-09

03. 09.04.2019 It appears that a memo has been filed by the
learned counsel for the petitioner seeking permission for
withdrawal of this writ petition with a liberty to the
petitioner to file fresh application, if any cause of action
arises.
 Permission for withdrawal is granted.
 Accordingly, the writ petition stands dismissed as
withdrawn with liberty to the petitioner to file a fresh
application, if any cause of action arises.
 Misc. Cases/I.As. connected to this writ petition, if
any, are dismissed accordingly.
 Interim order dated 12.04.2018 passed in this case
stands vacated.
