# High Court of Madhya Pradesh, MCC/2610/2014, 2015-02-06

M.C.C.No.2610/2014
Anil Kumar Namdev Vs. State of MP & Ors.
06/02/2015
Shri Sharad Verma, learned counsel for the applicant.
This application has been filed for restoration of a Writ Petition
No.9051/2014, which has been dismissed due to peremptory order
passed by this Court. There being some delay in filing of this
application for restoration, I.A.No.16418/2014 is filed seeking
condonation of the delay, which is supported by affidavit of the
counsel.
Keeping in view the reasons indicated in the application and
finding the same to be bona-fide, I.A.No.16418/2014 is allowed.
Condoning the delay in filing of this application for restoration, the
restoration application is itself allowed. W.P.No.9051/2014 be restored
to it's original file. It be placed for orders before an appropriate bench.
With the aforesaid, this application stands allowed and
disposed of.
 (Rajendra Menon) (C.`V.Sirpurkar)
