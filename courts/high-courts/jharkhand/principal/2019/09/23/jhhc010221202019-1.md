# High Court of Jharkhand, Cr.M.P./2159/2019, 2019-09-23

IN THE HIGH COURT OF JHARKHAND AT RANCHI
Cr. M.P. No. 2159 of 2019
----
Bindeshwar Mahto … Petitioner
-versus-The State of Jharkhand … Opposite Party
---
CORAM : HON’BLE MR. JUSTICE ANANDA SEN
----
For the Petitioner : Ms. Jyoti Nayan, Advocate
For the State : A.P.P.
For the Informant : Mr. Nilesh Kumar, Advocate
----
2/ 23.09.2019 Heard learned counsel for the parties.
 Petitioner has challenged the order dated 02.07.2019 passed
by the Judicial Magistrate 1st Class, Ranchi in Bariatu Police Station Case
No.128 of 2018 corresponding to G.R. No.2553 of 2018, by which
processes both under Section 82 and Section 83 of the Code of Criminal
Procedure have been issued on the very same day.
 Learned counsel for the petitioner submits that the entire order
is illegal as the impugned order issuing process both under Sections 82
and 83 of the Code of Criminal Procedure could not have been passed on
the same day. He further submits that no reasons have been recorded as
to why processes have been issued. He submits that non-furnishing of the
reasons vitiates the entire order.
 Learned A.P.P. appearing for the State opposes the prayer
and submits that since the petitioner did not appear, the aforesaid order
was passed.
 I have gone through the impugned order dated 02.07.2019.
The impugned order is a composite order issuing process under Sections
82 and 83 of the Code of Criminal Procedure.
 From perusal of first proviso to Section 83 sub section (1), it is
clear that order can be passed issuing proclamation under Section 82 of
the Code of Criminal Procedure and Section 83 of the Code of Criminal
Procedure. Thus, there is no bar in issuing process under Sections 82 and
83 of the Code of Criminal Procedure simultaneously.
 Question then arises as to what should be the nature of the
order passed. There should be cogent, valid and strong reasons for issuing
proclamation and process under Sections 82 and 83 of the Code of
Criminal Procedure simultaneously. There should be sufficient materials
before the Court to pass such composite order. While passing such order,

satisfaction should be recorded and recording of such satisfaction should
not be mechanical. In this case, from the impugned order, I find that the
investigating officer had filed affidavit stating that accused will try and
trying to remove the moveable properties and also may tamper with the
evidence of this case. On what basis the same has been mentioned, is not
there. Mere recording such statement is not sufficient to issue composite
order. Further, the satisfaction of the Court has not been recorded as to
how the Court is satisfied that it is necessary to issue both processes
simultaneously. Impugned order lacks such satisfaction. Accordingly, the
impugned order dated 02.07.2019 passed by the Judicial Magistrate 1st
Class, Ranchi in Bariatu Police Station Case No.128 of 2018
corresponding to G.R. No.2553 of 2018, by which processes both under
Section 82 and Section 83 of the Code of Criminal Procedure have been
issued, is, hereby, quashed.
 The matter is remanded to the Trial Court for proceeding and
passing appropriate order as per law.
 This application is, thus, allowed.
 Let a copy of this order be communicated through FAX to the
Court concerned at the cost to be deposited by the petitioner.
( Ananda Sen, J.)
