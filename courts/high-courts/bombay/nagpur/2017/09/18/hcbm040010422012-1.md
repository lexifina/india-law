 CORAM : P.N. DESHMUKH, J.
 DATED : SEPTEMBER 18, 2017
Heard Shri Sohoni, learned Counsel for
petitioner. Perused the pursis filed on record vide which
petitioner seeks permission to withdraw the petition
contending that dispute is settled between the parties.
Shri Sohoni, learned Counsel for petitioner
submits that issue involved in the petition pertains to
filing of complaint by petitioner against respondents for
the offences punishable under Sections 500, 501, 502,
295(A) and 298 read with Section 34 of Indian Penal
Code vide which process is issued against respondents,
which order is also stated to be set aside.
As per pursis, since matter is stated to be
settled, leave to withdraw the petition is granted. The
petition is disposed of as withdrawn.
