# Allahabad High Court, WRIA/9947/2020, 2020-11-23

Court No. - 72
Case :- WRIT - A No. - 9947 of 2020
Petitioner :- Dharmendra Kumar Singh
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Sadhu Sharan
Counsel for Respondent :- C.S.C.
Hon'ble Neeraj Tiwari,J.
Learned counsel for the petitioner submitted that after
service of notice, impugned order dated 3.2.2020 passed
by respondent no. 3 was recalled vide order dated
17.11.2020, therefore, this writ petition may be dismissed
as withdrawn with liberty to file fresh writ petition for any
other consequential benefit, if requires.
Accordingly, this writ petition is dismissed as withdrawn.
The petitioner is given liberty to file fresh writ petition if
any other consequential benefit has not been given to him.
Order Date :- 23.11.2020
