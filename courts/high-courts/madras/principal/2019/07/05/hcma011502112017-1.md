ORDER
This Criminal Original Petition has been filed seeking to
direct the first respondent to transfer the investigation in FIR
No.600 of 2015, dated 05.08.2015 to the file of the General
Bureau of Crime Investigation Department for further
investigation and file a final report within time frame fixed by
this Court
2. The learned Additional Public Prosecutor, on
instructions, would submit that the respondent police have
already filed a final report and the same has been taken on file
in C.C.No.225 of 2016, on the file of the Judicial Magistrate
No.V, Coimbatore.
3.In view of the above, no further orders can be passed by
this Court. Accordingly, the Criminal Original petition is
closed. Consequently, connected miscellaneous petition is
closed.
