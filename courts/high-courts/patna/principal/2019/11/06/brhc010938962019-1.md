ORAL ORDER
2 06-11-2019 This application has been filed for grant of anticipatory
bail to the petitioner in connection with Bhorey P.S. Case No. 205 of
2019 registered for offence under Sections 302, 404, 120(B)/34 of
the Indian Penal Code and Section 27 of the Arms Act.
This is the second attempt for grant of anticipatory bail.
Earlier, the petitioner had moved before this Court for anticipatory
bail in Cr. Misc. No. 45899 of 2019 which was rejected vide order
dated 24.7.2019.
This Court does not find any merit in the present
anticipatory bail application.
Accordingly, this application is dismissed.
