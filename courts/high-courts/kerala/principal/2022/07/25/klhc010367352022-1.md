JUDGMENT
The above writ petition is filed with the following
prayers:
“(a) Issue a writ of mandamus, such other
writ order or direction compelling the respondents 1
to 3 to implement Ext.P4 Order within such time limit
as this Hon'ble Court shall deem just.
(b) pass such other order as this Hon'ble
Court shall deem just.”[SIC]
2. When this writ petition came up for
consideration on 23.06.2022, this Court passed the
following order:
“The 1st and 2nd respondents will see that
Ext.P4 order is implemented in its letter and spirit if
the same is not varied or modified by any competent
authority. After implementing the order, a report will
be filed before this Court within two weeks.”
3. Thereafter, when the matter again came up

WP(C) NO. 17994 OF 2022
3
for consideration on 12.07.2022, this Court passed the
following order:
“This Court directed to implement Ext.P4
order, if it is not varied or modified. The order was
passed on 23/06/2022 and the case is posted today.
It is submitted by the counsel for the petitioner that
the order is not complied.
Therefore, the Secretary to the 1st respondent
Corporation will appear in person before this Court
on 25.07.2022.
In the meanwhile, if Ext.P4 is varied or
modified, the personal appearance is dispensed with
and if the order is complied, then also the personal
appearance is dispensed with.”
4. Now both sides submitted that, Ext.P4 order
is now stayed by the Mayor and therefore the same can
not be implemented. In the light of the same, this writ
petition itself can be closed with liberty to the
petitioner to approach this Court again, if there is any
fresh cause of action. All other contentions raised in
this writ petition are left open and the petitioner is free
to file a fresh writ petition, if there is any fresh cause
of action.

Therefore, this writ petition is closed with liberty
to the petitioner to file a fresh writ petition, if there is
any fresh cause of action.
