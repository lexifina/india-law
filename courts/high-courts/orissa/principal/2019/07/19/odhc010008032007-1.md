# High Court of Orissa, WP(C)/16257/2007, 2019-07-19

04. 19.07.2019 Learned counsel for the petitioner seeks
permission to withdraw the writ petition with liberty to the
petitioner to file fresh application, if any cause of action
arises. A memo filed to that effect is taken on record.
 Permission for withdrawal is granted.
 The writ petition stands dismissed as withdrawn
with liberty to the petitioner to file fresh application, if any
cause of action arises.
 Misc. Cases/I.As. connected to this writ petition, if
any, are dismissed accordingly.
