# High Court of Orissa, WP(C)/11703/2018, 2019-11-21

05. 21.11.2019 Learned counsel for the petitioner prays for withdrawal
of the writ petition with a permission to file afresh if any cause
of action survives.
 Permission for withdrawal is granted.
 The writ petition is accordingly dismissed as withdrawn
with a liberty to the petitioner to file afresh, if any cause of
action still survives.
