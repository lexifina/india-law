Heard for some time. At this stage, learned Counsel for
respondent No. 1 submits that he may be permitted to withdraw
the application, which was filed under Order 21, Rule 37 of the
Code of Civil Procedure before the learned Executing Court with
liberty to file appropriate application for execution of the award in
issue. The prayer so made by learned Counsel for respondent No. 1
is allowed and the application filed under Order 21, Rule 37 of the
Code of Civil procedure before the Executing Court is permitted to
be withdrawn, with liberty as prayed for. As a result thereof, order

liberty as prayed for, so also pending miscellaneous application(s),
