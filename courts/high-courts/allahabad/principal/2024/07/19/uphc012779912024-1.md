Hon'ble Mahesh Chandra Tripathi,J.

Order on Delay Condonation Application
1. Heard Sri Anuj Srivastava, learned counsel for the applicant.
2. Cause shown in the affidavit accompanying the delay
condonation application is sufficient.
3. The delay in filing the review/clarification application is
condoned.
4. The delay condonation application is allowed.
Order on Review Application
1. Heard Sri Anuj Srivastava learned counsel for the applicant.
2. This application has been filed for reviewing the judgement and
order dated 29.2.2024 by which the writ petition was disposed of
with detailed observations.
3. Perused the grounds taken in the review application in question
and the order dated 29.2.2024 passed by this Court. It is clearly
reflected from the order that has been so passed by this Court that
each and every facet of the matter that has been raised, has been
examined by this Court and in the garb of review application,
rehearing cannot be permitted.
4. Consequently, in the facts of the case the review application has
no merit and the same is dismissed, accordingly.
