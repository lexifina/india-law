ORDER
This Bail Application is filed under Section 438 of
Criminal Procedure Code (Cr.P.C.)
2. When this bail application came up for
consideration, the Public Prosecutor submitted that the final
report in Crime No.406/2022 of Palarivattom Police Station is
already filed before the Jurisdictional Court. If that be the
case, no further orders are necessary. The petitioner can
approach the Jurisdictional Court with appropriate application
for bail, if not appeared so far. If any bail application is filed,
the court below will consider the same, keeping in mind the
fact that there was an interim order from this Court to the
effect that the petitioner shall not be arrested.
With the above observation, the bail application is
closed.
