ORAL ORDER
(Per: HONOURABLE MR. JUSTICE AJAY KUMAR TRIPATHI)
12 08-09-2017 Both the contempt applications are required to be
dismissed.
The entitlement of the petitioners will flow from
Rule 103 of the Bihar Service Code which has been taken note of
in the order of the Division Bench.
It goes without saying that obligation of the
respondents to comply with the order in true letter and spirit of
Rule 103 would be required to be made, if not already made.
Counsel for the respondents, however, submits that
they have implemented the order, to the extent Rule 103 permits.
