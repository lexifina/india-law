JUDGMENT
The above Contempt case is filed alleging
that there is violation of Annexure A1 judgment.
Admittedly, Annexure A3 order is passed
subsequent to Annexure A1 judgment. According
to the petitioner, Annexure A3 order is not an
order as directed by this Court. If that is the
case, the petitioner can challenge Annexure A3
order by filing a separate writ petition. I
think there is no contempt in this case.
Therefore, the contempt case is closed.
