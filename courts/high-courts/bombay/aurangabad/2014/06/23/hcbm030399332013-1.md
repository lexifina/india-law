PER COURT :-
1. Since the original accused have filed Criminal Appeal No.144/2013, the
subsequent appeal filed by appointed Counsel Mr. M.A.Tandale should be
kept along with the earlier appeal.
2. Since the original accused have engaged Advocate Mr. Tushar M.Tandale
and he has already filed appeal, which is already admitted, the appearance of
Advocate Mr. M.A.Tandale ( appointed ) stands discharged.
3. Criminal Application No.6052/2013 is filed for condonation of delay in filing
the appeal. Since Criminal Appeal No.144/2013 is already admitted, this
application stands disposed of.
4. Since the application filed by the appellants for bail is already rejected, we
are not inclined to entertain second application (No.6053/2013) for bail as
there is no change in circumstances. Hence, Application No.6053/2013
stands rejected.
( P.R. BORA, J. ) ( S.S. SHINDE, J. )
