 O R D E R
This Criminal Original Petition has been filed praying
this Court to direct the second respondent to investigate and
to file a final report in Crime No.9/2012, dated 09.01.2012 on the
file of the second respondent within the time stipulated by this
Court.
2.Heard the learned counsel for the Petitioner and the
learned Government Advocate(Crl.side) appearing for the
respondents and perused the materials placed before this Court.
3.When the matter was taken up for hearing, the learned
Government Advocate(Crl.side) would submit that the charge sheet
was filed as early as on 28.1.2015. Since it was returned for
some defects, the same was resubmitted on 21.2.2017. However, the
same is yet to be taken on file.
4.However,the respondents are directed to take steps to see
that the charge-sheet is taken up on file within a short span of
time. With the above direction, this petition is closed.
