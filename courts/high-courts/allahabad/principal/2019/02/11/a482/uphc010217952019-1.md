# Allahabad High Court, A482/4167/2019, 2019-02-11

Court No. - 48
Case :- APPLICATION U/S 482 No. - 4167 of 2019
Applicant :- Chandrabhan Niranjan @ Lalla
Opposite Party :- State Of U.P. And Another
Counsel for Applicant :- Ajay Sengar
Counsel for Opposite Party :- G.A.
Hon'ble Om Prakash-VII,J.
Since Application U/S 482 No. 12982 of 2009 has already
been decided for the same cause of action on 19.8.2014,
if applicant is aggrieved by the aforesaid order he ought
to have moved restoration application in the aforesaid
Application. Therefore, present Application U/S 482
Cr.PC. is not entertainable.
During the course of argument, learned counsel for the
applicant requested to withdraw the petition with the
liberty to move restoration application in the aforesaid
application.
Application is dismissed as withdrawn with the liberty as
prayed.
Order Date :- 11.2.2019
