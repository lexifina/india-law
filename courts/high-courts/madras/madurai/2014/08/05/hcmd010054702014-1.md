# Madras High Court, CRL OP(MD)/13973/2014, 2014-08-05

CORAM
THE HONOURABLE MR.JUSTICE N.KIRUBAKARAN
Crl.O.P.(MD).No.13973 of 2014
Kaisar Nihara : Petitioner
-Vs-The State represented by
The Inspector of Police,
Sencottah Police Station,
Tirunevel District.
(Crime No.179 of 2013) : Respondent
PRAYER: Petition is filed under Section 482 of the Code of
Criminal Procedure praying to direct the respondent to file a
final report before the learned Judicial Magistrate, Shencottah in
Crime No.179 of 2013 pending on the file of the respondent police
with a time limit.
For Petitioner : Mr.P.Rajkumar
For Respondent : Mr.P.Kandasamy,
 Govt. Advocate (Crl. Side)
ORDER
This petition has been filed seeking a direction to direct the
respondent to file a final report before the learned Judicial
Magistrate, Shencottah in Crime No.179 of 2013 pending on the file
of the respondent police with the time limit.
2. Heard the learned Counsel for the petitioner and the
learned Government Advocate (Crl.Side) appearing for the
respondent.
3. Based on the petitioner's complaint, F.I.R. was registered
in Cr.No.179 of 2013, however, the final report has not been
filed. Taking into consideration the fact that the F.I.R. was
registered in the year 2013, the respondent police is directed to
file a final report at the earliest.
4. The Criminal Original Petition is ordered accordingly.
