ORDER
It is submitted that Ext.P3 order is already challenged
before this Court and there is an interim order in favour of the
review petitioner. If that be so, no review is necessary because
in direction No.i this Court only directed the 2nd and 3rd
respondents to implement Ext.P3, if it is not varied or modified
by any competent authority. Since the order is already stayed by
this Court, further action will be subject to the result of the other
writ petition.
With the above observation, this review petition is closed.
