JUDGMENT
Koshy, J.
This is a petition for police protection. If the loading and unloading
is carried out by mechanical process, the police to see that no obstruction is
caused. However, if there is any manual loading and unloading work, that
should be entrusted to the registered workers. But if the unloading work is
carried out mechanically, no wages can be demanded by the workers.
With the above observation, the writ petition is disposed of.
