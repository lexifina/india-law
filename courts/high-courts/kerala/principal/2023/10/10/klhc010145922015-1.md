ORDER
This Criminal Miscellaneous Case is filed with following
prayers:
1. Set aside Anx. A order of the learned JFCM I
Varkala dated 12.11.2014 in CMP.
No.8501/2014 & CMP No.8504/2014 in Crime
No.1055/2014 of the Varkala Police Station and
allow the Crl.MC.
2. Grand such other relief deemed fit to this
Hon'ble Court. (SIC)
2. The impugned order is an order passed under
Section 451 of the Code of Criminal Procedure. The Public
Prosecutor now submitted that the trial of the case is already
started and CW-1 is already examined. The Public Prosecutor
further submitted that the case is now posted to 05.12.2023
for the examination of CW-2.

3. In such circumstances, this Court need not
interfere with the order passed under Section 451 of the Code
of Criminal Procedure. The petitioner and the contesting
respondents can raise all the contentions before the trial
court.
Granting liberty to the petitioner and the contesting
respondents to raise all the contentions before the trial court,
this Criminal Miscellaneous Case is closed.
