ORAL ORDER
1. The petitioner is challenging the order of the Deputy
Commissioner by which the Deputy Commissioner
had directed the entries standing in the name of the
users to be cancelled and the name of the
Government to be entered.
2. Learned counsel for the petitioner submits that this
very order was set aside by this Court in
W.P.No.27084/2014 and also W.P.No.27581/2014.
However, insofar as the petitioners were concerned,
it is contended by the petitioners that the purchasers
of the land were unaware of the order passed by the
Deputy Commissioner.

3. In my view, since the order passed by the Deputy
Commissioner has already been set aside by two
decisions rendered by two co-ordinate Benches of
this Court, no prejudice would be caused if this order
is also set aside and the matter is remanded to
respondent No.2 –The Special Deputy Commissioner
for a fresh adjudication as ordered in the
aforementioned writ petitions.
4. This writ petition is accordingly allowed.
5. Since the parties are represented before this Court,
they are directed to appear before respondent No.2
on 26.05.2025.
6. In view of the disposal of the petition, all pending
interlocutory applications, if any, stand disposed of.
