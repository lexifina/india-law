ORDER
This Crl.M.C is filed challenging Annexure A6 order by which
the vehicle is released to the 2nd respondent. Annexure A6 order
was passed on 30/7/2016. Even though, an interim order was
passed, the interim order was not extended after 2018. Now,
probably the main case itself might have been disposed of. There
is no representation for the petitioner. Therefore, granting liberty
to the petitioner to raise all the contentions in the case, if any,
before the Lower Court, if any proceedings is pending, this Crl.M.C
is closed.
