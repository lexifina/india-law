# Allahabad High Court, BAIL/20785/2020, 2020-09-08

Court No. - 70
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 20785 of 2020
Applicant :- Raju Raghav Alias Jaiveer Alias Jai Prakash And Another
Opposite Party :- State of U.P.
Counsel for Applicant :- Arun Kumar Vishvakarma
Counsel for Opposite Party :- G.A.
Hon'ble Siddharth,J.
Learned counsel for the applicant states that he
has filed this bail application when the court below
was not functioning, however court below
reopened and bail application was filed and same
has been rejected.He prays that this application
should be heard.
When this bail application was filed on 28.7.2020
rejection order was not in existence and has been
subsequently passed over on 5.9.2020.
Hence this bail application is dismissed with liberty
to the applicant to file fresh bail application
alongwith rejection order.
Order Date :- 8.9.2020
Atul kr. sri.
