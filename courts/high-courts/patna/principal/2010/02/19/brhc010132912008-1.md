2 19/02/2010 This application has been filed for setting aside
the order dated 04.08.2007 by which the application for
discharge of the petitioner has been rejected.
The Court below while considering the petition
for discharge has passed a reasoned order as all the
witnesses have supported the prosecution case.
In view of the aforesaid fact, I do not think that
there is no illegality in the impugned order.
This application is accordingly dismissed.
Anand ( Sheema Ali Khan, J.)
