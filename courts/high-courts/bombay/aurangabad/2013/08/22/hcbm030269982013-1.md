# Bombay High Court, REVN/130/2013, 2013-08-22

1
IN THE HIGH COURT OF JUDICATURE AT BOMBAY,
BENCH AT AURANGABAD
CRIMINAL REVISION APPLICATION NO.130 OF 2013
The State of Maharashtra .. Applicant
Versus
Santosh Narayan Bhamre and ors. .. Respondents
Mr B.J.Sonawane, A.P.P. for applicant
 CORAM : A.R. JOSHI, J.

 DATE : 22nd August 2013
PER COURT
1. Learned A.P.P. is unable to explain and also to show to this
Court as to which order is challenged in the present criminal
revision application. Much time is given to learned A.P.P. to
enlighten the Court, but in vain. Even, the order which is
supposed to have been challenged, is not forming part of the
present papers.
2. In the result, there is nothing in the present criminal revision
application in which any relief can be granted. State is at liberty
to file any other application challenging any order of the earlier
Court, if feeling aggrieved by any such order.
3. Present criminal revision application is dismissed.
 ( A.R. JOSHI, J.)
