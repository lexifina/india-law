# High Court of Rajasthan, CRLMB/3713/2001, 2007-07-13

S.B. CRIMINAL MISC.BAIL APPL.NO.3713/2007.
Ramjeewan @ Nathu Vs. State
Date of Order : 13/7/2007.
HON'BLE MR.JUSTICE MOHAMMAD RAFIQ
Mr. N.S. Shekhawat for the applicant-petitioner.
Mr. Harshvardhan Nandwana PP for the State.
******
Heard learned counsel for the
applicant-petitioner as well as learned
Public Prosecutor for the State and
perused the the application for correction
in the number of first information report
as indicated in the order of this Court
dated 20/6/2007.
It is contended that the genesis of
the mistake lies in the incorrect number
being mentioned in the bail application
moved before the Court of Sessions itself
therefore petitioner had first moved
application for correction before that
Court which vide its order dated 4/7/2007
allowed the desired correction to be made
in the rejection order dated 22/5/2007.
Copy of the order dated 4/7/2007 has been
placed on record.

S.B.CR.MISC.BAIL APPL.NO.3713/2007
For all these reasons, the
application is allowed.
Accordingly, F.I.R. No.357/1992
P.S. Bani Park, Jaipur as indicated in the
order dated 20/6/2007 of this Court is
ordered to be corrected and it shall now
be read as “F.I.R. No.351/1992 P.S. Bani
Park, Jaipur“.
 (MOHAMMAD RAFIQ), J.
