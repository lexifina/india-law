ORDER
Heard both sides.
2.By the impugned order dated 29.09.2025, the petitioner has been
called upon to remove the encroachment in question. This order has to
be set aside for the following two reasons. (a) Though the impugned
order is issued under Section 128 of the Tamil Nadu Urban Local Bodies
Act, 1998, no show cause has been given as statutory mandated. (b) The
impugned order has been issued in the name of a dead person. Therefore,
it should be construed as nullity.
3.In this view of the matter, the impugned order is set aside and the
matter is remitted to the file of the respondent. The respondent is
directed to adhere to the directions given in W.P.(MD)No.16765 of 2020.
The respondent will issue show cause notice not in the name of
Chandran, who is no more but in the name of the writ petitioner and
thereafter, pass an appropriate order as per law.
