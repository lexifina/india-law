# Allahabad High Court, WRIB/4490/2018, 2018-07-19

Court No. - 22
Case :- WRIT - B No. - 4490 of 2018
Petitioner :- Pramod Kumar
Respondent :- Deputy Director Of Consolidation And 3 Others
Counsel for Petitioner :- Upendra Kumar Pandey
Counsel for Respondent :- C.S.C.,Ashish Kumar Srivastava
Hon'ble Rajiv Joshi,J.
Heard learned counsel for the petitioner and Sri Ashish
Kumar, learned counsel for the respondent No. 5.
This writ petition has been filed for quashing the order
dated 12.6.2018 passed by the Consolidation Officer
Mainpuri, whereby the application filed under Rule 109-A
for implementation of the same order has been
dismissed.
The record reflects that the reference made under Section
48 (3) of the U.P. Consolidation of Holdings Act was
accepted by the Deputy Director of Consolidation vide
order 13.1.2016. Against that order restoration was filed
by the respondent No. 4, the said restoration application
was allowed vide order dated 17.2.2016 whereby the
order dated 13.1.2016 was recalled.
The petitioner challenges the said order before this Court
in Writ- B No. 11467 of 2016, the operation of the order
dated 17.2.2016 was stayed till the next of listing vide
order dated 20.7.2016. During the pendency of the
aforesaid writ petition, petitioner moved an application
under Rule 109-A for the implementation of the order
dated 13.1.2016. The said order had already been set
aside vide order 17.2.2016 and the writ petition is still
pending, in which the said order has not been quashed
the petitioner cannot implement the order date 13.1.2016
which has already been recalled.
In these circumstances, the Consolidation Officer has
rightly rejected the application of the petitioner under Rule
109-A of the U.P. Consolidation of Holdings Rules. There
is no illegality or infirmity in the order impugned.
The writ petition is devoid of any merits and is accordingly
dismissed.
Order Date :- 19.7.2018
Akbar
