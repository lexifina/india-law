# Calcutta High Court, WPA/3712/2022, 2022-04-21

21.04.2022
 Item No.220
 Ct. No.17
 S.A.
W.P.A. 3712 of 2022
Basan Mondal
-vs-State of West Bengal & Ors.
Mr. Subhrangsu Panda
Ms. Mithu Singha Mahapatra
…for the petitioner
The petitioner has submitted that he made the
first application which was rejected. Subsequent
application he made on 21.01.2022, has been rejected
as defective. The petitioner has every liberty to file
the third application.
Hence, I do not find any merit in the writ
application and the same is dismissed.
However, dismissal of this writ application will
not create any impediment for the petitioner to file the
third application or other consecutive applications for
transfer.
 (Abhijit Gangopadhyay, J.)
