Case :- CRIMINAL MISC. BAIL APPLICATION No. - 46414 of 2023
Applicant :- Kanha @ Jayprakash Singh
Opposite Party :- State of U.P.
Counsel for Applicant :- Atul Kumar Singh
Counsel for Opposite Party :- G.A.,Anita Singh,Prem Babu Verma
Hon'ble Samit Gopal,J.
1. List revised.
2. Heard Sri Atul Kumar Singh, learned counsel for the applicant,
Ms. Anita Singh, learned counsel for the first informant and Sri
Bade Lal Bind, learned counsel for the State.
3. Learned counsel for the applicant submits that there are some
typographical error in the bail application with regards to the
provision in which it has been moved and also the date from which
the applicant is in jail and as such present bail application be
dismissed as not pressed as he intends to file a proper and better
bail application.
4. Prayer is allowed.
5. The present bail application is, accordingly, dismissed as not
pressed.
