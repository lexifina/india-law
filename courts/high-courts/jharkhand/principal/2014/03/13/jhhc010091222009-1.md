# High Court of Jharkhand, Cr.M.P./1189/2009, 2014-03-13

 Geeta Agarwal @ Geeta Agarwala.........Petitioner

 CORAM: HON’BLE MR. JUSTICE R.R.PRASAD
 For the Petitioner :Mr.Rajesh Kumar
 For the State : A.P.P
04/ 13.03.14. I.A.(Cr.)No.8648 of 2013
Heard learned counsel appearing for the petitioner and learned
counsel appearing for the State on the interlocutory application bearing
no.8648 of 2013 wherein prayer has been made to quash the order
dated 5.1.2013 whereby and whereunder the court having rejected the
application filed under Section 317 of the Code of Criminal Procedure
has passed the order for issuance of warrant of arrest non-bailable. The
prayer made in the interlocutory application be allowed to be
incorporated in the main application.
The prayer is allowed.
Let the interlocutory application form part of the main application.
 Cr.M.P. No.1189 of 2009
 Learned counsel appearing for the petitioner submits that initially
this case was filed for quashing of the FIR of Giridih (M) P.S. Case
no.215 of 2009 registered under Section 379 of the Indian Penal Code
and also under Section 135 of the Indian Electricity Act. Subsequently,
the petitioner challenged the order dated 5.1.2013 by way of
interlocutory application. Presently, the petitioner would be confining
the prayer made in the interlocutory application. So far the main
prayer is concerned for quashing of the FIR, he would not be pressing
that prayer but liberty be reserved to raise the point which has been
raised in this application, relating to quashing of the FIR.

Cr.M.P.No.1189 of 2009
 -2-
In view of the submission, this application remains confined
to the prayer made in the interlocutory application wherein prayer
has been made to quash the order dated 5.1.2013 wherein
application filed under Section 317 of the Code of Criminal
Procedure was rejected and consequently, warrant of arrest non-bailable has been ordered to be issued.
Having heard learned counsel appearing for the parties and
on perusal of the record, I do not find any illegality with the order
dated 5.1.2013 passed in Giridih (M) P.S. Case no.215 of 2009
(G.R.No.1504 of 2009) as before that day, the petitioner had been
directed to appear physically. In spite of that he did not appear
rather filed an application under Section 317 of the Code of
Criminal Procedure which was rejected as the petitioner in spite of
direction did not appear physically. I do not find any illegality with
the said order.
However, the plea which has been taken is that
subsequently the court on 15.3.2013 did allow the prayer made in
the application filed under Section 317 of the Code of Criminal
Procedure . Even if the application has been allowed, that will not
 make the order dated 5.1.2013 illegal.
Accordingly, I do not find any merit in this application.
Hence, it is dismissed. However, if the petitioner surrenders and
prays for bail, the same be decided after taking into account the
submission including the submission made hereinabove without
being prejudice by the order of this Court.

 (R.R.Prasad, J.
