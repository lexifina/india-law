# High Court of Madhya Pradesh, WP/6818/2017, 2017-05-19

WP-6818-2017
(RAKESH KANDYA Vs THE STATE OF MADHYA PRADESH)
19-05-2017
Shri Tapan Kumar Bathre, learned counsel for the
petitioner.
Smt. Vandana Shrivastava, learned panel lawyer for the
respondents/State.
The issue raised in the present petition is squarely
covered by a decision rendered by this Court in W.P.
No.2445/2012, Smt. Pushpa Kandya vs. State of
Madhya Pradesh & others, decided on 24th July, 2013.
Following the same, other writ petition against the very
same order was allowed vide order dated 30.07.2013. It
is found by this Court that the order was issued in gross
violation of Section 115 of the M.P. Land Revenue Code
and, therefore, the same cannot be allowed to stand.
Since common order was passed on 03.01.2012, which
has already been set aside by this Court, this writ
petition is required to be allowed.
Keeping in view the aforesaid, the writ petition is
allowed. Impugned order dated 03.01.2012 (Annexure
P-3) is hereby quashed. However, the competent
authority of the State would be free to initiate the
proceedings individually in respect of violation of the
lease conditions, if there is any complaint, in accordance
to the provisions of the M.P. Land Revenue Code. This
order will not come in the way in the said proceedings.
The writ petition is allowed to the extent indicated herein

above.
Certified copy as per rules.
(MISS VANDANA KASREKAR)
