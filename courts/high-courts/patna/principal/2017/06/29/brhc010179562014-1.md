ORAL ORDER
3 29-06-2017 Learned counsel for the petitioners submits that earlier
the so called husband had preferred quashing petition vide Cr. Misc.
No.14440 of 2014 wherein by order dated 16.10.2014, entire
proceeding including order of cognizance dated 27.08.2013 was set
aside.
The petitioners are father-in-law, mother-in-law,
grandfather-in-law and grandmother-in-law of the complainant. Since
the entire proceeding relating to Haveli Kharagpur P.S. Case No.194 of
2012 has already been set aside including the order of cognizance dated
27.08.2013 so this matter has become infructuous.
Accordingly, this quashing petition is dismissed as
infructuous.
