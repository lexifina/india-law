RAKESH KUMAR JAIN, J (ORAL)
This revision petition is directed against order dated 22.4.2011 passed
by the Rent Controller, Gurgaon by which an application filed by the landlord for
appointment of Local Commissioner for the purpose of assessing the condition of
the demised premises which is allegedly in a dilapidated condition has been
dismissed.
Learned counsel for the petitioner has very fairly stated that this
application has been filed at the stage of admission and denial. The issues have
not been framed and the evidence is yet to come.
In view thereof, the petitioner may, if so advised, file the application
at an appropriate stage but at this stage this kind of application can not be accepted
as has been rightly done by the Rent Controller. Hence, the revision petition is
dismissed.
(RAKESH KUMAR JAIN)
