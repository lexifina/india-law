5. This notice is preferred by the
Claimant under Order XXI Rule 22 of the Code of
Civil Procedure, 1908 for permission to file
Execution Application for executing the Award
dated 21st March, 2012 in Arbitration Proceedings,
as there was delay of more than two years.
6. Considering the submission made by
the learned Counsel for Claimant and the
averments made in Affidavit in support of
Execution Application, I am satisfied that Applicant
has made out the case for allowing this Notice.
Hence, the following order.
ORDER
(A) Notice preferred by the Claimant
under Order XXI Rule 22 of the Code of Civil
Procedure for permission to file Execution
Application to execute Award dated 21st March,
2012 is allowed.
(B) Applicant can proceed with the
Execution Application according to law.
(C) Notice stands disposed of accordingly.
(K.K.TATED, J.)
