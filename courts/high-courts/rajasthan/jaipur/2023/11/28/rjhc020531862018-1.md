HON'BLE MR. JUSTICE AVNEESH JHINGAN
Order
28/11/2023
1. This petition was filed seeking quashing of order dated
27.03.2018, whereby application of the petitioner under Order 21
Rule 34(2) read with Section 151 CPC has been decided in which
the order was passed for deposit of security for costs. During
pendency of the petition, the judgment and decree against the
petitioner has been executed.
2. An application for amendment has been made to challenge
the final order since there is a fresh cause of action arising and
the amendment would only create complication.
3. Prayer for amendment of the petition is rejected.
4. The petition is disposed of with liberty to file petition afresh.
(AVNEESH JHINGAN),J
