1. Proceedings of this matter have been taken through video conferencing.
2. This is the first bail application filed under Section 483 of Bharatiya
Nagrik Suraksha Sanhita, 2023 for grant of regular bail to the applicant who
has been arrested in connection with Crime No. 33/2024, Police Station
Divisional Excise Flying Scot, Division- Surguja (C.G.), for the offence
punishable under Sections 20(B((ii)(b) of the N.D.P.S. Act.
PREETI

2
3. Learned counsel for the applicant submits that the first bail application of
the applicant has already been rejected by this Court vide order dated
18.10.2024 passed in MCRC No. 7222/2024, thereafter the applicant has filed
the present bail application terming it to be first bail application and on a pointed
query being made by learned counsel for the applicant as to why his bail
application has been filed as first bail application, though the first bail
application of the applicant has already been rejected, he states that the Police
Station has been wrongly mentioned in the first bail application. Hence, this bail
application.
4. The explanation advanced by learned counsel for the applicant that the
present bail application has been turned into the first bail application as the
police station was wrongly mentioned in the earlier bail application which was
rejected by this Court appears to be misleading one and the counsel for the
applicant is put to strict caution, failing which, adverse inference would be
drawn against him.
5. In view of the same, learned counsel for the applicant prays to withdraw
the present bail application with liberty to file afresh.
6. Accordingly, this bail application is dismissed as withdrawn.
