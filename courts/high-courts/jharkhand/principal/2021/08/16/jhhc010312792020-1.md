04/16.08.2021 Ms. Lavanya Gadodia, JC to Mr. Sumeet Gadodia, submits that
amount claimed by the petitioner has already been sanctioned but actual
payments have not been released. Learned counsel produces a copy of the
letter dated 14.06.2021 to this effect. Learned counsel further submits that
since grievance of the petitioner has already been redressed, the writ
petition has now become infructuous. Learned counsel however submits
that petitioner may be given liberty to move before this Court if so
aggrieved.
 Mr. Manoj Kumar, learned GP-II does not object.
 Since grievance of the petitioner has already been redressed, this
writ petition stands disposed of. However, liberty is given to the petitioner
to file fresh writ petition, if so required in case of fresh cause of action
arises.
