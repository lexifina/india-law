P.C. :
. In Suit No.76/2021, various applications are pending. It is brought to
the notice of this Court that Interim Application No.1636/2021 was already
disposed of by City Civil Court, before the matter was transferred to this
Court and an Appeal from Order bearing No.122/2021 is pending against
the said order before this Court. In that light, Interim Application
No.1636/2021 is disposed of.
2. Learned counsel for the parties jointly submit that in view of
subsequent development of the defendants having handed over possession of
the flats and all the buildings having been demolished, Interim Application
No.1635/2021 and Interim Application (Lodging) No.41333/2022 are
rendered infructuous. Hence, the said two applications are disposed of as
infructuous.
3. In Interim Application No.3349/2021 and Interim Application
No.972/2023, the defendants are granted time of three weeks to file reply
affidavit.
4. List Interim Application No.3349/2021, Interim Application
No.1634/2021, Interim Application No.3350/2021, Interim Application
No.1637/2021, Interim Application No.2400/2021 and Interim Application
No.972/2023 for further consideration on 18.07.2023.

5. Similarly, there are various applications pending in Suit
No.1190/2019. Interim Application (Lodging) No. 25477/2022 is disposed
of, as it stood withdrawn, as recorded in order dated 10.08.2022.
6. Interim Application (Lodging) No.25993/2022 was dismissed by an
order dated 06.10.2022, yet it is being shown in the cause list. Office to take
note of this fact and to ensure that this application is no longer shown in the
cause list for hearing.
7. The plaintiffs are granted time of three weeks to file reply affidavit in
Interim Application No.964/2023 and Interim Application (Lodging)
No.31796/2022 as also rejoinder affidavit in Interim Application (Lodging)
No.36778/2022.
8. List Notice of Motion No.2179/2019 alongwith Interim Application
No.964/2023, Interim Application (Lodging) No.31976/2022 and Interim
Application (Lodging) No.36778/2022 for further consideration on
18.07.2023.
9. It appears that Suit No.181/2011 has been wrongly tagged alongwith
these two suits. Hence, Suit No.181/2011 is de-tagged, to be listed
separately before the appropriate Court.
10. Learned counsel appearing for the plaintiffs in Suit No.76/2021
submits that by an administrative order, an Appeal from Order No.122/2021
has been directed to be listed alongwith these two suits. Office to verify and
take steps accordingly.
