HON'BLE DR. JUSTICE PUSHPENDRA SINGH BHATI
 Order
12/07/2017
1. Petitioner has preferred this misc. petition under
Section 482 of Cr.P.C. for quashing the order dated 29.04.2017
passed in civil suit No.9/2016 (42/2015) by learned ADJ No.1, Sri
Ganganagar, whereby the original agreement to sale has been
refused to hand over the police authority for sending the same to
the handwriting expert in connection with the FIR No.62/2016 PS
Kotwali, District Sri Ganganagar (Raj.)
2. This Court has taken note of the fact that counsel for
the petitioner has sought for the FSL which has already been
conducted and once the FSL for the same document has been
conducted and is on record, no second FSL for the same document
needs to be conducted.

(2 of 2)
[CRLMP-1635/2017]
3. Counsel for the petitioner however pointed out that
since there was a registered sale deed, therefore, new FSL should
have been conducted as i.e. authenticate document from which
the comparison need to be made was now available.
4. Counsel for the respondent, however opposed the same
and stated that once the original documents has been put through
the FSL and proper report has been obtained then there is no
requirement for second FSL and this could be proved counter-productive as it would not only delay the proceedings but also
open the doors for multiplicity of proceedings.
5. After hearing counsel for the parties, this Court is of
the opinion that no right of second FSL accrues to the present
petitioner as first FSL is already on record for the same document,
therefore, the present petition does not need any intervention,
hence, the misc. petition is dismissed.
(DR. PUSHPENDRA SINGH BHATI)J.
