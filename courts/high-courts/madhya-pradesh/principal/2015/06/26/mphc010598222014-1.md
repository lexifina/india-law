# High Court of Madhya Pradesh, MCC/2921/2014, 2015-06-26

MCC-2921-2014
(HARIOM TIWARI Vs THE STATE OF MADHYA PRADESH)
26-06-2015
Shri Narendra Sharma, learned counsel for the
applicant.
Shri Swapnil Ganguly, learned Govt. Adv. for the State.
This application has been filed for restoration of W. A.
No. 1284/13 which has been dismissed in view of the
non-compliance with a peremptory order passed on
9.12.13.
The application is supported by an affidavit of the clerk
of the counsel.
There being some delay in filing the application for
restoration, I. A. No. 6668/15 has been filed for
condonation of delay.
Keeping in view the reasons given in the application for
condonation of delay and finding the same to be
bonafide, the application is allowed.
Condoning the delay in filing the application for
restoration, the restoration application itself is allowed.
W. A. No. 1284/13 be restored to its original file.
It be placed for orders before the appropriate Bench.
Application stands allowed and disposed of with the
aforesaid.
(RAJENDRA MENON)
JUDGE
(VANDANA KASREKAR)
JUDGE
