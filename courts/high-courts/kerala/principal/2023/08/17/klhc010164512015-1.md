ORDER
The above criminal miscellaneous case is filed to quash the
proceedings in C.C.No.96/2012 on the file of the Judicial 1st Class
Magistrate Court-I, Aluva. This Crl.M.C came up for consideration
on 07.04.2015 and thereafter this Crl.M.C is not listed. Learned
Public Prosecutor submitted that as per the e-court website, the case
is seen as disposed. Moreover, there is no interim order also passed
by this Court. If that is the case, probably the prayers in this Crl.M.C
might have been infructuous.
Hence this Crl.M.C is dismissed as infructuous.
