HON'BLE MR. JUSTICE PANKAJ BHANDARI
Order
03/03/2020
1. The matter comes up on application filed by the applicant-petitioner seeking correction in the order dated 06.02.2020.
2. It is contended by counsel for the applicant that in Paragraph
No.8 District Magistrate, Jaipur has been printed whereas, the
order should have mentioned District Magistrate, Baran as the
impugned order by which parole application was rejected, was
passed by District Magistrate, Baran.
3. I have considered the contentions.

(2 of 2) [CRLMA-73/2020]
4. Due to typographical error District Magistrate, Jaipur has
been typed in Para No.8 of the impugned order, the same needs to
be corrected.
5. Accordingly, the application is allowed. Now, in place of
“District Magistrate, Jaipur”, the same be read as “District
Magistrate, Baran” in Para No.8 of the impugned order dated
06.02.2020.
(PANKAJ BHANDARI),J
