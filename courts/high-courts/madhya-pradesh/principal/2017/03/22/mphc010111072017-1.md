# High Court of Madhya Pradesh, MCC/640/2017, 2017-03-22

MCC-640-2017
(MAN MOHAN DAS RAI Vs THE TRANSPORT APPELLATE TRIBUNLA)
22-03-2017
Shri Pramesh Jain, learned counsel for the applicant.
Heard on I.A. No.3887/2017, an application for condonation of delay.
For the reasons mentioned in the application, which is duly supported by
an affidavit of Advocate-Shri Pramesh Jain, the same (I.A. No.3887/2017)
is allowed. The delay in filing this application is hereby condoned.
This application has been filed for restoration of M.C.C. No.2682/2015
which has been dismissed on account of common conditional order
passed on 24.11.2016. The application is supported by an affidavit of
Advocate-Shri Pramesh Jain.
Keeping in view the reasons indicated in the application, the M.C.C. is
allowed and it is directed that M.C.C. No.2682/2015 be restored to its
original number and list this case before the appropriate Bench.
Let a copy of this order be kept in the file of M.C.C. No.2682/2015.
(SMT. ANJULI PALO)
JUDGE
