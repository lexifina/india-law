Per Mohammad Yaqoob Mir, ‘CJ’: (ORAL)
1. Meghalaya Electricity Duty Act is under challenge but now same
has been amended which position is supported by Notification bearing
No.LL(B) 170/84/57 dated 18.12.2018 along with the copy of the
Ordinance dated 18.12.2018. Confronted with the same position, learned
counsel for the petitioner would submit that he may be permitted to
withdraw the petition with liberty to file a fresh one.
2. In view of the later development, prayer made by the learned
counsel for the petitioner is not opposed therefore allowed. Petition is
dismissed as withdrawn with liberty to the petitioner to file a fresh one,
if so chooses.
3. Disposed of as above.
