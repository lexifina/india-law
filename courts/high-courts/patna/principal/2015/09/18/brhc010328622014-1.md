ORAL ORDER
2 18-09-2015 Heard learned counsel for the petitioner, learned counsel
for Veer Kunwar Singh University and learned counsel for the State.
The counsel for the University has produced the order
dated 03/09/2015 by which the case of the petitioner has been rejected.
In such view of the matter, this Court does not want to
proceed with the matter any more. Accordingly, this application is
dismissed with the liberty if so advised, the petitioner may challenge
the order dated 03/09/2015 in an appropriate proceeding.
Photo copy of the aforesaid order is being kept on record.
