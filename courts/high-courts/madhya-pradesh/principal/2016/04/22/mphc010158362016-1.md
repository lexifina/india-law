# High Court of Madhya Pradesh, WP/5512/2016, 2016-04-22

WP-5512-2016
(PANNALAL Vs THE STATE OF MADHYA PRADESH)
22-04-2016
Shri Rakesh Singh, learned counsel for the petitioners.
Shri Anubhav Jain, learned panel lawyer for the
respondents/State.
After arguing some time the learned counsel for the
petitioners seeks to withdraw this petition with a liberty
to file an appeal before the Collector.
Prayer is allowed.
Accordingly, petition is dismissed as withdrawn with the
aforesaid liberty, as prayed for.
If such an appeal is filed along with the application for
stay, the the same will be considered by the Collector as
expeditiously as possible.
(MISS VANDANA KASREKAR)
JUDGE
