ORDER
The petitioner/an accused in S.C.No.155 of 2023 on the file of the
Assistant Sessions Court, Valliyoor has moved this application to quash
the proceedings.
2. When this application is taken up for hearing, the learned counsel
for the petitioner submits that the complaint has been amicably settled
between the parties. However, there is no material placed before this Court
that there was an amicable settlement arrived between the parties.
3. In the absence of any material that the matter has been amicably
settled between the parties, this Court is not inclined to entertain this
application.
2/4
https://www.mhc.tn.gov.in/judis

Crl.O.P.(MD)No.13022 of 2025
4. Accordingly, this petition is dismissed with liberty to the
petitioner to file a fresh application along with the compromise memo.
