05/06.01.2021
This application has been filed by the State opposing release of
the coal. Only ground taken by the petitioner is that coal is required for
the purpose of investigation and Investigating officer had objected
against the release of the seized coal. State relies on the aforesaid
ground, which is absolutely not tenable. There cannot be a vague
ground as such, relied by the State. On this vague ground, the order of
release passed by the court below cannot be objected. This type of
frivolous petition should not be filed. The State is directed to be
cautious in future, before filing such application with vague grounds
before this Court.
Since no cogent ground is put forth by the petitioner, I am not
inclined to allow this application and therefore the impugned order
needs no interference.
Accordingly, the instant application stands dismissed as
withdrawn.
