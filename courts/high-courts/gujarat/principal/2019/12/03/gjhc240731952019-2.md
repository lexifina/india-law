ORAL ORDER
1. The Civil Application is made for vacation of the order dated
19.11.2019 which was based upon the submission of the learned
Counsel for the petitioner that on a simple application the court
insisted for execution of the mandatory order without there being
any execution petition from the opponent.
2. During the course of hearing, the learned Counsel for the Applicant
stated that an Application for execution of the order dated
25.10.2019 passed below exh.5 granting mandatory injunction in
favour of the Applicant will be filed and he would not press for the
Application already filed (Exh.55).
3. Learned Counsel for the petitioner in the main petition states that if
Exh.55 is not pressed, this petition raising a limited issue can be

disposed of.
4. In above view of the matter, the Application Exh.55 is disposed of
with a liberty to the Applicant to file the execution petition
wherein if the case for urgency is made out, the trial court would
consider the same. Petition along with Civil Application is
disposed of. Interim order vacated.
