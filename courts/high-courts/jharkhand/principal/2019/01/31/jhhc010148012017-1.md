05/31.01.2019
After some arguments, counsel for the petitioner submits that he wants to
challenge the punishment order before the appropriate authority and thereafter
seeks liberty to file an application for the same relief which has been sought for
in the writ application.
After going through the record, I find that since the petitioner was punished,
the said order needs to be challenged in appeal. Petitioner has to first challenge
the punishment order then only he can pray for the relief which has been prayed
in the writ petition.
Considering the submission of the petitioner, I allow the petitioner to
withdraw the instant writ application for the present, to approach the appellate
authority challenging the order of punishment.
With the aforesaid observation and direction, the instant writ application
stands dismissed as withdrawn.
