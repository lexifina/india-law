# High Court for the State of Telangana, CC/232/2017, 2023-02-07

THE HONíBLE SRI JUSTICE C.V.BHASKAR REDDY
Contempt Case No.232 of 2017
ORDER:
Learned counsel for respondent No.3 submitted that on
08.08.2019 after filing the contempt case the compound wall which
was demolished has been reconstructed to the satisfaction of the
petitioner and he has no grievance so far as the implementation of the
orders which are subject matter of the contempt case.
Recording the said submission, this contempt case is closed.
However, liberty is granted to the petitioner, if any cause survives, to
file fresh application seeking revival of the contempt case in
accordance with law.
 Miscellaneous petitions, if any pending in this contempt case
shall stand closed.
