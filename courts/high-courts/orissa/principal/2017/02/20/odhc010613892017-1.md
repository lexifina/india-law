# High Court of Orissa, WP(C)/1348/2017, 2017-02-20

W.P.(C) No.1348 of 2017
20.02.2017 Heard Mr. S. Ray, learned counsel for the petitioner and Mr. Beura, learned Standing C
ounsel for the Revenue.
 In this writ application, the petitioner has sought to challenge the Provisional Asses
sment Order notice thereof.
 Learned counsel for the petitioner submits that in the meantime, the petitioner has pr
ocured the necessary declaration forms for being produced before the Assessing Officer for rev
ision of the Provisional Assessment Order.
 Accordingly, without expressing any views on the issued raised in the matter, we dispo
se of the writ application by granting liberty to the petitioner to file an appropriate applic
ation before the Assessing Officer seeking modification of the Provisional Assessment Order on
 production of necessary declaration forms obtain by him. If such an application is filed, it
shall be opened for the Assessing Officer to deal with the same in accordance with law forthwi
th and if necessary, orders and demand be passed afresh.
 The petitioner undertakes to appear before the Assessing Officer and also file necessa
ry application along with the declaration form as well as certified copy of this order on 16.3
.2017.
 Issue urgent certified copy on proper application.
 A free copy of this order be handed over to learned Standing Counsel for the Revenue.
