# Madras High Court, TR CMP(MD)/61/2018, 2018-04-09

BEFORE THE MADURAI BENCH OF MADRAS HIGH COURT
 DATED: 09.04.2018
CORAM:
 THE HONOURABLE MR.JUSTICE M.V.MURALIDARAN
 Tr.C.M.P.(MD) No.61 of 2018
N.Nisha ... Petitioner
 Vs.
T.Lakshmi Sundaran ... Respondent
PRAYER: Petition filed under Section 24 of the Civil Procedure Code
to withdraw the H.M.O.P.No.146 of 2017 on the file of the Principal
Sub-Court, Nagercoil and transfer the same to the file of Sub-Court,
Pattukottai to try along with H.M.O.P.No.21 of 2018 on the file of
Sub-Court, Pattukottai.
For Petitioner : Mr.M.P.Senthil
For Respondent : Mr.S.J.Chakkaravarthy
ORDER
The petitioner has filed the Transfer application seeking
transfer of H.M.O.P.No.146 of 2017 on the file of the Principal Sub-Court, Nagercoil to the Learned Sub-Court, Pattukottai to try along
with H.M.O.P.No.21 of 2018 on the file of Learned Sub-Court,
Pattukottai.
 2. The learned counsel for the respondent reported that the
said H.M.O.P.No.146 of 2017 was disposed of on 30.01.2018 itself on
the file of the Principal Sub Court, Nagercoil. Therefore this
transfer petition becomes infructuous.

 3. In view of the submission made by the learned counsel for
the respondent, this petition is dismissed as infructuous. However,
liberty is granted to the petitioner to approach this Court to file
an application for transfer, if the said H.M.O.P.No.146 of 2017 is
restored. No costs.
