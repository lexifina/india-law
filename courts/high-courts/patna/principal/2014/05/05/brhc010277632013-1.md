CORAM: HONOURABLE MR. JUSTICE ASHWANI KUMAR SINGH
ORAL ORDER
2 05-05-2014 Heard learned counsel for the petitioner and learned
counsel for the State.
By invoking the extraordinary jurisdiction of this Court
under Section 482 of the Code of Criminal Procedure, the
petitioner has prayed for quashing the first information report of
Rajpur P.S. Case No. 51 of 2011 registered for the offences
punishable under Sections 452, 341, 323, 307, 380, 504 read with
34 of the Indian Penal Code as well as Section 27 of the Arms
Act.
From bare perusal of the FIR, it would appear that the
allegations made in the first information report do constitute
cognizable offence.
Accordingly, the application is dismissed.
Jagdish/- (Ashwani Kumar Singh, J)
