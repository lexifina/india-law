# High Court of Madhya Pradesh, RP/150/2016, 2016-08-10

R.P. No. 150/2016
Mukesh Dayal Sharma Vs. State of M.P. & Others
10.08.2016
Shri B.B. Shukla, learned counsel for the petitioner.
Shri Prakhar Dhengula, learned Panel Lawyer for the
respondents/State.
This review petition has been filed for seeking
correction in the order dated 12.04.2016 passed in R.P.
No. 110/2016.
Learned counsel for the petitioner submits that a
typographical error has been crept in the order dated
12.04.2016 passed in R.P. No. 110/2016. In the last para
of the order it is mentioned that “a copy of this order be
kept with the record of W.P. No. 8105/2016” whereas it
should have been “a copy of this order be kept with the
record of W.P. No. 8105/2015”.
In view of the submissions, it is directed that instead
of “W.P. No. 8105/2016” the same be read as “W.P.
No.8105/2015”. The remaining order shall remain intact.
A copy of this order be kept with the record of R.P.
No. 110/2016.
With these observations, this review petition is
disposed of.
 (S.A. Dharmadhikari)
 Judge
Aman
