Order
04/01/2024
1. Instant miscellaneous application has been filed by petitioner-applicant, seeking correction in the order dated 14.12.2023 passed
in SB Criminal Miscellaneous (Petition) No.5897/2023 by this
Court, wherein in Para No.1, reference of FIR number has been
mentioned as “202/2022” instead of “212/2022”.
2. Heard learned counsel for both parties.
3. It appears that in subject matter of the petition, reference of
FIR number was mentioned as “202/2022”, due to which, in Para
No.1 of the order dated 14.12.2023, the FIR number has been
mentioned as “202/2022”, while in fact it should be “212/2022”,
which error occurred inadvertently.
4. Counsel for petitioner is directed to file amended cause title.

[2024:RJ-JP:539] (2 of 2) [CRLMA-732/2023]
5. In view of above, in the order dated 14.12.2023, FIR number
as mentioned in Para No.1 that is “202/2022” be corrected in red
ink as “212/2022” and the correction made in the original order be
upload online showing asterisk (*) mark in the order that
reference of FIR number has been corrected subsequently. Rest
part of the order shall remain unchanged.
6. Accordingly, the misc. application stands disposed of.
(SUDESH BANSAL),J
