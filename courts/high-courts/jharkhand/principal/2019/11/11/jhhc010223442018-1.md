6/11.11.2019 Heard the parties.
 The petitioner is aggrieved by the part of the order dated
02.05.2018, by which the process under Section 82 of the Code of
Criminal Procedure was issued against him.
 Learned counsel appearing for the petitioner submits that the
order is absolutely cryptic and does not reflect the reasons as to why the
same has been passed. He submits that it is the mandate of the law that
subjective satisfaction has to be recorded while issuing process under
Section 82 of the Code of Criminal Procedure, but the same is missing in
this case. Accordingly, he prays to quash the same.
 Mr. Ashok Kumar, learned A.P.P. after going through the
impugned order through tries to support the order but could not give any
ground in support of the same.
 After going through the impugned order, I find that the order is
absolutely cryptic as the same does not reflects any reason. Even
subjective satisfaction has not been recorded while issuing process under
Section 82 of the Code of Criminal Procedure. It is mandate of the law that
while issuing process under Section 82 of the Code of Criminal Procedure,
the Court below has to record subjective satisfaction.
 Since, the subjective satisfaction is missing, I am inclined to allow
this criminal miscellaneous petition. Accordingly, the same is hereby
allowed. The impugned order dated 02.05.2018, by which processes under
Section 82 of the Code of Criminal Procedure has been issued, is hereby
set aside. The court below is directed to proceed afresh accordingly as per
law.
 This criminal miscellaneous petition stands allowed.

 (Ananda Sen, J)
