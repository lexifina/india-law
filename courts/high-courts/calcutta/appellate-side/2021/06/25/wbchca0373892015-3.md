 Mr. Suman De, learned advocate appearing for the
State submits a report before this court prepared by the
Officer-in-Charge, Shibpur Police Station.
 The report dated 24th June, 2021 so submitted by
the learned advocate for the State be kept with the record.

2
 The report reflects that the opposite party no. 1
namely, one Jaba Samaddar has expired on 2nd February,
2021.
 As the revisional application was against an order
passed in connection with a proceeding under Section 125 of
the Code of Criminal Procedure wherein the opposite party no.
1 was the affected party, I am of the view that so far as the
present revisional application before this court is concerned,
the same has become infructuous.
 Accordingly, the revisional application being CRR
2411 of 2015 is dismissed as infructuous.
 All connected applications, if any, consequently are
disposed of.
 Interim orders, if any, are hereby vacated.
 All parties are to act on the server copy of this order
duly downloaded from the official website of this court.
