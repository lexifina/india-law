# Allahabad High Court, WRIA/2616/2025, 2025-03-03

Neutral Citation No. - 2025:AHC:29233
Court No. - 10
Case :- WRIT - A No. - 2616 of 2025
Petitioner :- C/M Shiksha Sadan Kanya Inter College Muzaffar
Nagar And Another
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Sumit Shukla,Suresh Chandra Shukla
Counsel for Respondent :- C.S.C.
Hon'ble Saurabh Shyam Shamshery,J.
1. Heard Sri Sumit Shukla, learned counsel for the petitioners
and Sri Dhirendra Pratap, learned Standing Counsel.
2. This is the second round of litigation.
3. Petitioner has earlier approached this Court by way of filing a
Writ Petition No.4332 of 2024, Neutral Citation
No.2024:AHC:49942, which was disposed of vide order dated
20.3.2024.
4. Now the petitioner has again approached this Court that
aforesaid order has not been complied with despite proper
application was filed. However, proper application as directed
by this Court vide order dated 20.3.2024 is not on record. A
reference is made by learned counsel for the petitioner in
respect of Annexure-5 to the writ petition, which does not
appear to be a proper application as required by this Court,
therefore, petitioner has unnecessary rushed to this Court
without complying with earlier order of this Court, therefore,
this writ petition is disposed of with liberty to the petitioner to
file a proper application as directed by this Court in the above
referred order dated 20.3.2024.
Order Date :- 3.3.2025
