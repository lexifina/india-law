# Allahabad High Court, /7509/2023, 2023-09-21

Hon'ble Vivek Chaudhary,J.
Hon'ble Manish Kumar,J.
Heard learned counsel for the petitioner and Sri
Shikhar Anand, learned counsel for the respondent
no.1/U.P. State Information Commission.
Petitioner by the present writ petition has
challenged the order dated 26.05.2023 whereby
the recall application of petitioner is rejected. The
recall application was filed to recall the order
dated 09.11.2021. The order dated 09.11.2021
itself notes that in case the petitioner has not
received any information or she is not satisfied
with the information she can further file a recall
application along with the objections/documents.
The petitioner filed a recall application on the
ground that on four different occasions, different
information which provided to the petitioner were
in itself contradictory and hence her appeal should
be heard.
The application for recall is rejected on the ground
that even if on four different occasions different
information are provided to the petitioner, it is
open to the petitioner to approach the competent
forum/Court on the basis of the said information
and seek relief. It is not clear as to from where the
petitioner can seek relief in case contradictory
information are being provided to the petitioner. It
was duty of the appellate authority more so when
it has already been said in the order dated
09.11.2021 that in case the petitioner is not

satisfied she may file a recall application to hear
the matter on merits and deal with the issue
involved. Without dealing with the issue involved,
the recall application could not have been
rejected. Hence, the order dated 26.05.2023
cannot sustain and is set aside.
The State Information Commissioner is expected
to hear the petitioner on merits as expeditiously as
possible.
The writ petition is allowed.
(Manish Kumar, J.) (Vivek Chaudhary, J.)
