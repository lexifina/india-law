the learned counsel for the parties, taken up for final hearing.
2. The present petitioner had filed an application under Order
XLI Rule 27 of the Code of Civil Procedure [ For short, ‘ the Code ’ ] for
additional evidence. The same is rejected. Aggrieved thereby the present
Writ Petition is filed.

3. Though Mr. Nandode, learned counsel for the petitioner and
Mr. C.R. Deshpande, learned counsel for the respondent have canvassed
the arguments on merits, I am not inclined to consider the said arguments
on merits.
4. The Apex Court in the case of State of Rajastan V/s
T.N.Sahani and others reported in 2001 ( 10 ) - SCC - 619 and in the
case of Mallyalam Plantation Ltd. V/s State of Kerala and another
reported in 2011 AIR SCW – 264 have held that the application for
additional evidence has to be decided along with the Appeal.
5. In light of the above, the impugned order is quashed and set
aside. The Court shall decide the said application filed under Order XLI
Rule 27 of the Code [ Exh. 32 ] along with Appeal.
