HON'BLE MR. JUSTICE PANKAJ BHANDARI
Order
03/09/2019
1. Petitioner has preferred this Criminal Writ Petition seeking
fair investigation in FIR No.336/2017.
2. Learned Public Prosecutor has submitted the report which is
taken on record. As per the report, Police has submitted negative
final report on 06.03.2019.
3. In view of the same, Criminal Writ Petition has become
infructous and the same is dismissed as having become
infructous. Stay applications stands disposed.
4. However, petitioner would be free to file protest petition, if so
advised.
