ORDER
This Criminal Original Petition has been filed by the
Petitioner/accused No.1 to quash the First Information Report in
Crime No.292 of 2016, on the file of the first respondent police.
2.The learned Government Advocate (Crl.Side) has submitted
that already the investigation has been completed and a charge
sheet was filed on 12.08.2016 itself before the learned Judicial
Magistrate, Tiruchendur, but sofar, the case was not taken on
file.
3.Considering the aforesaid Submissions, the learned Judicial
Magistrate, Tiruchendur is directed to verify whether the charge
sheet was already filed, if already charge sheet was filed then,

he should take the case on file without further delay. The learned
Chief Judicial Magistrate, Tuticorin is also directed to verify,
if charge sheet was already filed, he has to give proper

further delay. In future, the Magistrate should take the case on
file within reasonable time.
4.With the aforesaid directions, this Criminal Original
Petition is disposed of. Consequently, connected miscellaneous
petition is closed.
