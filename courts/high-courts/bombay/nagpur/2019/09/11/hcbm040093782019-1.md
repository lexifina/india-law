 DATED : SEPTEMBER 11, 2019
Heard learned Counsel for the parties.
This application is for condonation of delay
of 90 days in filing application for restoration of Criminal
Application No.987/2018, which came to be dismissed
by conditional order dated 30/1/2019.
For the grounds mentioned in the application
and considering the subject matter, which is an appeal
by victim against acquittal of accused, delay is condoned.
The application is allowed.
