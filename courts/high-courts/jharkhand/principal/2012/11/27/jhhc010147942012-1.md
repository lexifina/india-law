02/27.11.2012 The learned counsel for the petitioner seeks permission to amend
the present C.M.P.
2. Permission is granted.
3. Necessary modification be carried out in the application
accordingly.
4. The present application is filed for extension of the time limit,
which was prescribed in the previous order dated 09th November, 2012.
5. Heard the learned counsel for the petitioner and the learned counsel
for the Opposite Parties.
6. Perused the application.
7. Learned counsel for the Opposite Parties has strongly opposed the
application.
8. In view of the reasons stated in the application, the time limit,
which was prescribed in the earlier order dated 09th November, 2012,
which was up to 30th November, 2012, is extended upto 15th December,
2012 so as to enable the petitioner to file an Appeal before the appellate
forum. This extension is given by way of last chance.
9. C.M.P. stands disposed of, accordingly.
(P.P. Bhatt, J.)
