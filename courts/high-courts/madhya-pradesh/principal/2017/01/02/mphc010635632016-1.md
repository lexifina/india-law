# High Court of Madhya Pradesh, MCC/3360/2016, 2017-01-02

MCC-3360-2016
(SMT. SEEMA MISHRA Vs THE STATE OF MADHYA PRADESH)
02-01-2017
Shri Rajesh Dubey, Advocate for the applicant.
Shri Puneet Shroti, Advocate for the respondents/State on
advance copy.
Heard.
This application has been filed for restoration of
W.P.No.6798/2016 (S), which had suffered dismissal on account
of peremptory order for non-payment of process fee.
The application for restoration is within limitation.
Considering the ground mentioned in the restoration application,
which is duly supported by affidavit, this application is allowed.
Accordingly, W.P.No.6798/2016 (S) is restored to its
original number.
(VIJAY KUMAR SHUKLA)
JUDGE
S/
