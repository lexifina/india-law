HON'BLE MR. JUSTICE MANOJ KUMAR GARG
Order
26/05/2021
The instant misc. application has been moved for correction
in order dated 25.05.2021 passed in S.B. Crl. Misc Bail Application
No. 6716/2021 wherein, inadvertently, the name of petitioner was
wrongly mentioned as Roopa Ram S/o Teza Ram whereas, the
name of petitioner is Baljeet Singh S/o Gurdev Singh.
For the reasons mentioned in the application, the misc.
application is allowed and it is directed that in the operative
portion of order dated 25.05.2021, the name of petitioner be read
as “Baljeet Singh S/o Gurdev Singh” instead of “Roopa Ram s/o
Teza Ram”.
 The application stands disposed of.
(MANOJ KUMAR GARG)J.
