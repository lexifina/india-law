Heard.
(1) This is an application for modification of the order dated
18.04.2016.
(2) Learned counsel for the applicant submits that in para 1 of
the order dated 18.04.2016, Crime No.124/2016 has been
mentioned whereas it should be Crime No.95/2016, therefore, the
order deserves to be modified accordingly.
(3) The prayer is not opposed by counsel for the applicant.
(4) The prayer is accepted and it is directed that in paragraph 1
of the order dated 18.04.2016 the words- Crime No.124/2016 be
read as Crime No.95/2016. Rest of conditions mentioned in the
order shall remain intact.

2
(5) The order dated 18.04.2016 stands modified accordingly
and be read along with this order.
(6) Accordingly, the Cr.M.P stands disposed of.
(7) A copy of this order be placed on the file of M.Cr.C.
