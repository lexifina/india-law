CORAM: HONOURABLE MR. JUSTICE V.N. SINHA
ORAL ORDER
3 05-12-2012 Heard learned counsel for the petitioner and the State
Election Commission.
2. This writ petition is directed against the order
dated 6.11.2012 passed in Election Petition No.08/2011
Annexure-3. Perusal of order dated 6.11.2012, however, does not
indicate that thereunder petitioner has suffered any injury as his
election as Mukhiya of Andauli Darbespura Gram Panchayat
within Belchhi block of Patna district has not been set aside so far.
3. In such view of the matter, the writ petition is
disposed of granting liberty to the petitioner to challenge any
subsequent order by which her election is set aside.
