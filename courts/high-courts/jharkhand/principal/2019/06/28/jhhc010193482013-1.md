02/28.06.2019 None appears on behalf of the petitioner.
The prayer in this writ application is for setting aside the
order dated 19.07.2013 passed in T.S. No. 66/2008 by which
the evidence of the plaintiffs have been closed. The petitioner
also prayed to set aside the order dated 23.07.2013 by which
the application preferred by the petitioner for recall of the order
dated 19.07.2013 has been rejected.
It appears from the impugned order dated 19.07.2013 that
the petitioner-plaintiff was given several opportunities to appear
but save and except filing applications for adjournment the
petitioner-plaintiff did not appear which ultimately resulted in
closure of their evidence on 19.07.2013. Subsequent an
application was preferred by the petitioner-plaintiff to recall the
order dated 19.07.2013. However, considering the clear lack of
interest on the part of the petitioner-plaintiff in pursuing T.S.
No. 66/2008 the same was also rejected.
There being no reason to conclude otherwise with respect
to the findings recorded in the order dated 19.07.2013 and
23.07.2013, I am not inclined to entertain this writ application
which accordingly stands disposed of.

(R. Mukhopadhyay, J.)
