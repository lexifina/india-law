ORAL ORDER
6 01-05-2013 The petitioners submit that some clerical error has been
erupted in order dated 7.3.2013 & 16.4.2013.
Order dated 16.4.2013 is recalled.
A part of second last paragraph (page 17) of order
dated 7.3.2013 reads as follows:-
“The impugned order of the Block Development
Officer, Siswan cancelling the appointments were found genuine
by the Appellate Tribunal is set aside. It is expected that the
Appellate Authority would decide the matter within four months
from the date of filing of the representation.”
The petitioners submit that the aforesaid order is being
misinterpreted to read that even the order of the Appellate
Tribunal has been set aside. Order is quite clear which states that
only the impugned order of Block Development Officer, Siswan
cancelling the appointment of Prakhand Teachers has been set
aside. Order dated 7.3.2013 is clarified to the extent that the
impugned order of the Block Development Officer, Siswan based
on the repot of the Selection Committee is set aside.
The impugned order is modified only to the extent
mentioned above.
