ORAL ORDER
3 04-11-2020 Heard the counsel for the parties.
This is an application seeking quashing of the First
Information Report of Korha P.S. Case No. 175 of 2015,
dated 12.09.2015, which has been registered under Sections
364, 302, 201 and 120(B)/34 of the Indian Penal Code.
On 04.09.2020, this Court had called for a report
from the Court below about the stage of the case.
The report has since been received, which indicates
that in this case final report as mistake of fact has already
been filed.
In this view of the matter, there is no necessity of
adjudicating the present application.
The application stands disposed off accordingly.

Praveen-II/-
