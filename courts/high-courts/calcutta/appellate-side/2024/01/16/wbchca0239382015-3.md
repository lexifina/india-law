1. This revisional application has been filed with a prayer for
quashing the proceeding in connection with Watgunge Police Station
Case No.344 of 2014 dated 8th September, 2014 under Sections
120B/420/406/409 of the Indian Penal Code which was initiated by
an application under Section 156(3) of the Code of Criminal
Procedure.
2. Both the learned advocates appearing on behalf of the petitioner
and the State are present.
3. In compliance with the order dated 8th December, 2023, learned
advocate on behalf of the State has submitted a report of Watgunge
Police Station wherefrom it is seen that all the accused, including the
petitioner, were discharged from the case following a final report
submitted by the Investigating Officer before the learned Chief
Judicial Magistrate, Alipore, South 24-Parganas.
4. This being the position, the instant revisional application, being
CRR 1435 of 2015, stands dismissed as infructuous.
5. Criminal Section is directed to supply certified copy of this order,
if applied for, upon compliance of necessary formalities.
(Bibhas Ranjan De, J.)
