# High Court of Madhya Pradesh, MCC/161/2021, 2021-02-04

The High Court Of Madhya PradeshThe High Court Of Madhya Pradesh
MCC-161-2021
(DISTRICT MAGISTRATE/COLLECTOR JABALPUR Vs SATISH KUMAR VERMA)
Jabalpur, Dated : 04-02-2021
Heard through Video Conferencing.
Shri A.P. Singh, learned Dy. Advocate General for the State.
None for the respondent.
Heard.
In this MCC, it is prayed that "this Hon'ble Court may kindly be
pleased to allow the instant application and further be pleased to allow the
applicant to use the Ravi Shankar Shukla Stadium, Wright Town, Jabalpur
for organizing the aforesaid event".
The same situation arose when M.C.C. No.303/2020 was decided by
this Court vide order dated 03.02.2020, which reads as under:
"Jabalpur, Dated : 03-02-2020
Shri Shashank Shekhar, learned Advocate General for the applicant.
Respondent in person.
This is an application seeking appropriate directions to allow the applicant
to issue permission for use of Ravi Shankar Shukla Stadium, Wright Town, Jabalpur
for holding a function organized by the State Government to felicitate Hon'ble the
President, Hon'ble the Chief Justice of India, Hon'ble the Governor and other
dignitaries/State Guest on 21.03.2020.
Notice of this application. Respondent accepts notice.
We have heard learned counsel for the parties. The Advocate General has
made a statement that the changes which are required to be made for the security
of the dignitaries would be restored after the function is over.
In view of the above, we permit the State Government to take steps for
carrying out the changes which are required to be made for the security of the
aforesaid dignitaries in the Ravi Shankar Shukla Stadium, Wright Town, Jabalpur
and in the vicinity thereof for the function scheduled on 21.03.2020. The applicant
shall restore the changes made to the previous status after the function is
concluded.

For the same reason, this Court passed the order dated 03.02.2020, we
deem it proper to entertain this MCC and grant permission.
Accordingly, we permit the State Government to take steps for
carrying out the changes which are required to be made for the security of
dignitaries in the Ravi Shankar Shukla Stadium, Wright Town, Jabalpur and in
the vicinity thereof for the functions scheduled to be held on 06.03.2021. It
shall be the duty of the applicant to restore the changes made to the previous
status after the function is concluded.
This order is passed in view of exceptional circumstances and after
considering the security measures required to be made for the dignitaries.
M.C.C. is disposed of.
