# High Court of Madhya Pradesh, WP/9605/2020, 2020-07-23

(SUJOY PAUL)
JUDGE
The High Court Of Madhya PradeshThe High Court Of Madhya Pradesh
WP-9605-2020
(RAJENDRA KUMAR BANSAL Vs THE STATE OF MADHYA PRADESH AND OTHERS)
Jabalpur, Dated : 23-07-2020
Heard through Video Conferencing.
Shri Akhil Singh, counsel for the petitioner.
Shri Ashish Barnard, Dy. A.G. for respondents/State.
With the consent, finally heard.
Learned counsel for the petitioner submits that against the transfer
order dated 10.7.2017 (Annx.P/2), petitioner filed W.P.No.10303/17.
Initially, an interim order was granted on 21.7.2017 against the said transfer
order. Subsequently, Lok Adalat by order dated 09.03.2019 (Annx.P/4) set
aside the order of transfer dated 10.07.2017 by reserving liberty to the
respondents to pass fresh order in accordance with law. Surprisingly, by
impugned order dated 2.7.2020 (Annx.P/1), the petitioner's representation has
been rejected and respondents now intend to implement the transfer order
dated 10.7.2017 which has already been set aside by the Lok Adalat.
Shri Barnard did not dispute the aforesaid argument of learned counsel
for the petitioner. He urged that respondents may be given liberty to pass a
fresh transfer order, if administrative exigency so requires.
I find force in the argument of Shri Akhil Singh. An order of transfer
which stood quashed, cannot be enforced by rejecting the representation.
Resultantly, the order dated 2.7.2020 (Annx.P/1) is set aside. Liberty is
reserved to the respondents to pass a fresh order of transfer if administrative
exigency so requires.
Petition is allowed.
