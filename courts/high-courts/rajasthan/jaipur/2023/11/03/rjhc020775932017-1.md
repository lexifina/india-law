Judgment / Order

Matter comes up on a letter dated 13.03.2018 received from
the Rent Tribunal, Jaipur Metropolitan for extension of time for
disposal of the Original Application No.370/2013 (493/2011).
On 11.08.2023, this Court called for the status report from
the Rent Tribunal about the status of the original application.
In compliance of direction of this Court, the status report has
been sent vide letter dated 31.08.2023. As per the status report
received, the original application has already been disposed of
vide letter dated 02.01.2020.
In view of the status report, no further order is required to
be passed in this matter.
(GANESH RAM MEENA),J
