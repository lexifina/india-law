HON'BLE MR. JUSTICE PANKAJ BHANDARI
 Order
02/02/2021
1. The matter comes up on application for correction in the
order dated 18.01.2021 passed in S.B. Criminal Misc. Bail
Application No.493/2021.
2. It is contended by counsel for the applicant/petitioner that
erroneously in the subject matter of bail application Police Station
“Sadar Karauli” has been mentioned in place of Police Station
“Kotwali Karauli”.
3. I have considered the contentions.
4. Considering the contentions made by counsel for the
applicant/petitioner, application for correction in the order dated
18.01.2021 is accordingly, allowed.

(2 of 2) [CRLMA-26/2021]
5. Amended cause titled has been filed and the same is taken
on record in the main bail application.
6. It is ordered that in Para 2 of order dated 18.01.2021 passed
in S.B. Criminal Misc. Bail Application No.493/2021, Police Station
“Sadar Karauli” be now read as Police Station “Kotwali Karauli”.
(PANKAJ BHANDARI),J
