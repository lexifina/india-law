Order
02/07/2020
Heard on the misc. application.
Counsel for the petitioner submits that due to typographical
error in para No.4 (c) of the order dated 29.06.2020 the amount of
personal security has wrongly been typed as Rs.10 lacs in place of
Rs.1 Lac.
Learned Public Prosecutor has not disputed this fact.
In that view of the matter, this misc. application is allowed and
in para No.4 (c) of the order dated 29.06.2020 the amount of
personal security be read as Rs.1 lac instead of Rs.10 lacs and the
order dated 29.06.2020 stands corrected accordingly.
This order be treated to be part of the order dated 29.06.2020.
(INDERJEET SINGH),J
