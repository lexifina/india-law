# High Court for the State of Telangana, CRLP/8562/2017, 2018-10-25

HONíBLE Dr. JUSTICE B.SIVA SANKARA RAO
CRIMINAL PETITION No.8562 of 2017
ORDER:
As per instructions of the learned Public Prosecutor, the
police filed the final report referring as false.
Hence, this Criminal Petition is closed as the relief became
infructuous. If at all any protest filed and any cognizance
taken, the remedy is left open.
Miscellaneous petitions, if any, shall stand closed.
