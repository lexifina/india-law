ORDER
Mr.A.P.Srinivas, learned Senior Standing Counsel takes notice for the
Respondent.
2.This Writ Petition is disposed of at the admission stage itself with the
consent of the learned counsel for the Petitioner and the learned Senior Standing
Counsel for the Respondent.
3. The Petitioner is before this court against the impugned order passed
on 20.11.2023 whereby Petitioner’s GST Registration has been cancelled with
effect from 02.02.2023 viz.,being the date of Show Cause Notice in Form GST
Reg- 17/31 that preceded the impugned order.
4. The allegation against the Petitioner is that petition had failed to file
returns for the last six months prior to the said Show Cause Notice in Form GST
Reg-17 which has now culminated in the impugned order. There is an embargo
under the Scheme for the Petitioner to file return for the subsequent tax period
within the prescribed time.
5. Considering the same, there is no merits in the challenge to the
