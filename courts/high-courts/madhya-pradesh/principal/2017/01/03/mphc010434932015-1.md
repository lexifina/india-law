# High Court of Madhya Pradesh, WP/14589/2015, 2017-01-03

WP-14589-2015
(SMT. SAIDEEN BEE Vs THE STATE OF MADHYA PRADESH)
03-01-2017
Shri Rajesh Pancholi, learned counsel for the petitioner.
Mr. Manoj Kushwaha, learned Panel Lawyer for the
respondents/State.
This Court vide order dated 03.11.2016 has directed the
State to file the khasra entries before this Court after deleting
remark made in column No.12 in pursuance of Annexure P/7.
Learned Panel Lawyer has filed a copy of Khasra entry, in which
the remark made in column No.12 of the Khasra entries has
been deleted in pursuance of the order dated 03.11.2016 by the
Naib Tahsildar.
In view of aforesaid nothing survives for adjudication in
the present petition. However, if petitioner has any grievance, she
can file representation before the Competent authority.
With the aforesaid observations, the petition stands
disposed of.
Certified copy as per rules.
(MISS VANDANA KASREKAR)
JUDGE
