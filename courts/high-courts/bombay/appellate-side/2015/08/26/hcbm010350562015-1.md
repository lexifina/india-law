IN THE HIGH COURT OF JUDICATURE AT BOMBAY
CRIMINAL APPELLATE JURISDICTION
ANTICIPATORY BAIL APPLICATION NO. 1263 OF 2015
Jangal Mahadu Walke & Anr. ...Applicants
 Versus
The State of Maharashtra ...Respondent
Mr. Balwant Salunkhe I/b Mr. Subhash Hulyalkar for the Applicants
Ms. Veera Shinde, A.P.P for the Respondent-State
Mr. Sachin Pawar for the Original Complainant
 CORAM : REVATI MOHITE DERE, J.
 WEDNESDAY, 26TH AUGUST, 2015
P.C. :
1. It appears that the anticipatory bail application preferred by the
applicants was dismissed for default by the learned Sessions Judge vide
order dated 18th August, 2015, by passing the following order :
“Dismissed for Default.”
2. Learned A.P.P states that the applicants ought to file an
application for restoration of the application, which was dismissed for
default.
SQ Pathan 1/2

aba.1263.15.doc
3. Learned Counsel for the applicants seeks leave to withdraw
this application with liberty to file an appropriate application seeking
restoration of the application which was dismissed for default vide order
dated 18th August, 2015.
4. If such an application is filed, the learned Judge shall decide
the same on its own merits, uninfluenced by the withdrawal of this
application.
5. Accordingly, application is disposed of as withdrawn with
liberty as prayed.
6. All concerned to act on the authenticated copy of this order.
 REVATI MOHITE DERE, J.
