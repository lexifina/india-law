# Allahabad High Court, A482/18710/2019, 2019-07-04

Court No. - 73
Case :- APPLICATION U/S 482 No. - 18710 of 2019
Applicant :- Ram Dulari
Opposite Party :- State Of Up And Another
Counsel for Applicant :- Raj Kumar Kesari
Counsel for Opposite Party :- G.A.
Hon'ble Pradeep Kumar Srivastava,J.
Sri Raj Kumar Kesari, learned counsel for the applicant submits
that applicant may be permitted to withdraw this application so
that he can file a criminal revision against the impugned order.
In view of above submission, without entering into the merits of
the case, applicant is permitted to withdraw this application
with liberty to file criminal revision against the impugned order.
Accordingly, application is dismissed as withdrawn with liberty
to file criminal revision.
Certified copy of impugned order be returned to the counsel for
the applicant.
Order Date :- 4.7.2019
