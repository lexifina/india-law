 ORDER
When this bail application came up for consideration, learned
Public Prosecutor submitted that the final report in Crime
No.23/2022 of Malayinkeezhu Police Station, Thiruvananthapuram
Rural is already submitted before the jurisdictional court. If that is
the case, the petitioners can approach the jurisdictional court, on
getting summons, if not already appeared. If the petitioners
surrender before the jurisdictional court with bail application,
jurisdictional court will consider the same in the light of the fact that,
there was interim order from this court.
With the above observation, this bail application is closed.
