This is an application for rectification of the order dated 20.12.2019.
It is stated in the application that there is a typographical error in the
order dated 20.12.2019 as the FIR No. 329/2019 has been wrongly typed.

FIR no.329/2019 mentioned in the order dated 20.12.2019 be read as
329/2017.
The application stands disposed of accordingly.
