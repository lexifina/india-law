 ORDER
This Criminal Miscellaneous Case is filed to quash the
proceedings in C.C.No.957/2014 on the file of the Judicial First Class
Magistrate Court-I, Perambra. This Crl.M.C is pending from 2016
onwards. No interim order is passed in this case. Probably, the main
case itself might have been disposed by the trial court. Moreover, this
petition to quash the proceedings cannot be entertained because the
Public Prosecutor submitted that, there is criminal antecedents to the
petitioner.
Therefore, this Crl.M.C is closed.
