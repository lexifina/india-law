(DAYARAM AND OTHERS Vs NARESH RAJAK)
Jabalpur, Dated : 25-02-2020
Shri Gopal Shriwas, learned counsel for the appellant.
I.A.No.4081/2020, an application for conversion of present Criminal
Appeal under Section 372 of the Code of Criminal Procedure, 1973 (for short
'the Code of 1973') to that of an application for Leave to Appeal under
Section 378(4) of the Code of 1973.
Taking into consideration that the criminal machinery has been set on
motion on the basis of private complaint, we deem it appropriate to allow the
application and permit the present Appeal to be converted into application
under Section 378(4) of the Code of 1973.
Office to register the present Appeal into MCrC under Section 378(4)
of the Code of 1973.
Meanwhile correction to that effect be carried out in the memo of
Appeal.
I.A.No.4081/2020 stands disposed of finally in above terms.
