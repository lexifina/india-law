Order on Board
Per Ramesh Sinha, Chief Justice
26/07/2023
1) Heard Mr. Sumesh Bajaj, learned Counsel for the appellants.
Also heard Mr. Chandresh Shrivastava, learned Additional
Advocate General, for the State and Mr. Malay Shrivastava,
learned Counsel for the respondent No. 3.
2) After arguing at length, learned Counsel for the appellants
seeks to withdraw this appeal with liberty to file the review
petition before the learned single Judge for reviewing the
impugned order dated 03/12/2022.
3) Accordingly, the instant appeal is dismissed as withdrawn
with the aforesaid liberty. As there would be an issue of
limitation in the review petition which would be filed by the
appellants, liberty is also granted to the appellants to file an
appropriate application for condonation of such delay along
with review petition, if so advised.
