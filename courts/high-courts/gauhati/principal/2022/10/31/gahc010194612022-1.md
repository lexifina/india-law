BEFORE
HONOURABLE MR. JUSTICE ARUN DEV CHOUDHURY
ORDER
31.10.2022
Heard Mr. M. Khan, learned counsel for the applicant. Also heard Ms. R. D.
Mozumdar, learned counsel for the opposite party.
This is an application under Section 151 of the Code of Civil Procedure, 1908
for a direction to the Registry from this Court to release 50% of the awarded
amount, which has already been deposited as per order dated 29.06.2022
passed in I.A.(C) No. 1890/2022 arising out of MAC Appeal No. 335/2022.
As the connected appeal has already been admitted, the applicant may file
necessary application for withdrawal of the same from the Registry and in the
event such application is filed, the same be allowed after proper verification and
identification as per laid down procedure.
Accordingly, this Interlocutory Application is disposed of.
 JUDGE
