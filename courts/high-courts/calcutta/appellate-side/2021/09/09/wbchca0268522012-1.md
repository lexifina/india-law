# Calcutta High Court, CRR/1946/2012, 2021-09-09

Sr.44
 09-09-2021
 Subha.
 Court no. 34
 IN THE HIGH COURT AT CALCUTTA
 CRIMINAL REVISIONAL JURISDICTION
 APPELLATE SIDE
 ( Via Video Conference )
 CRR 1946 of 2012
 In the matter of : Shri Raju Sen
 . …..petitioner.
In Re : An application under Section 482 read with Section
401 of the Code of Criminal Procedure.
 The revisional application was preferred in respect of
Misc. Execution Case No. 29 of 2012 under Section 125(3) of
the Code of Criminal Procedure pending before the learned
Additional Chief Judicial Magistrate, Ghatal wherein the
learned Magistrate was pleased to direct the present petitioner
to dilute the arrears which accrued on different periods.
 Having regard to the fact that the revisional
application is simply pending for the last 8 years and there is
no interim order, I do not think that it would be fit and proper
to interfere with the proceedings pending before the learned
Magistrate at this belated stage.
 Further, from the records, I find that there has been
no dispute regarding the main order of maintenance awarded
by the learned Magistrate.

2
 In view of the aforesaid, no interference is called for
by this court. Accordingly, the present revisional application
being CRR 1946 of 2012 is dismissed.
 All pending applications, if any, in connection with
revisional application, are consequently disposed of.
 All parties are to act on the server copy of this order
duly downloaded from the official website of this court.
 ( Tirthankar Ghosh, J. )
