ORAL ORDER
2 03-12-2020 This application has been filed for modification of the
order dated 29.05.2020 passed by this Court in Criminal
Miscellaneous No.3843 of 2020.
On perusal of order dated 29.05.2020, it appears that
when the aforesaid case was come up for hearing, learned counsel
for the petitioner requested this Court to list this case as and when
normal Court would start functioning as he has no system to argue
this case, so on the request of learned counsel for the petitioner, it
was ordered for listing this case as and when normal Court would
start functioning. Now, by filing this application, the petitioner
seeking relief for modification of the aforesaid order.
In such view of the matter, there is no need to pass
any order in this modification application. However, the petitioner,
