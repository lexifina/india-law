JUDGMENT
Ramachandran Nair, J.
Heard both sides. Writ Appeal is filed against judgment of the
learned Single Judge declining to interfere with the refusal of the
Panchayat to grant licence to start and run the shop. The appellant is a
retail outlet run as chain stores in the country as a whole. It is reported
that subsequently Panchayat granted licence and the shop is being run
now based on periodical renewals obtained. We do not think appeal
has any significance as of now because it is for the Panchayat to
consider and grant renewal, if appellant is eligible. Writ Appeal is
closed with the above observation.
