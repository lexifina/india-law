ORDER
This Crl.MC is filed with the following prayers:-
“In the above circumstances, it is humbly prayed that
this Hon'ble Court may be pleased to set aside the
order passed in CMP No.134/14 pending before the
Hon'ble Judicial First Class Magistrate Court No.III,
Kollam and allow the CMP No.134/14 in S.T.123/2010 or
direct the court below to consider the petition afresh
and also set aside the order passed on 12.3.2015
closed the defence evidence and direct the court below
to re-open the defence evidence and examine the
balance defence witnesses pass such other appropriate
orders in the interest of justice.”
2. The order passed in CMP No.134/2014 is an order
by which the application of the petitioner to send the cheque
for expert opinion is rejected. The second prayer is to set
aside the order passed on 12.03.2015 by which the defence
evidence is closed. This Crl.MC is pending before this Court
from 2015 onwards. No interim order is passed in this case.
Probably, the main case itself might have been disposed of.

Therefore, this Crl.MC need not be retained. Therefore, this
Crl.MC is closed living open all the contentions of the
petitioner.
