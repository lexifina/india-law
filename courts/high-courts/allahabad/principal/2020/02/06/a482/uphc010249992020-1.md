# Allahabad High Court, A482/4951/2020, 2020-02-06

Court No. - 82
Case :- APPLICATION U/S 482 No. - 4951 of 2020
Applicant :- Atik Ahamad
Opposite Party :- State Of Up And 3 Ors
Counsel for Applicant :- Fakhruzzaman
Counsel for Opposite Party :- G.A.
Hon'ble Bachchoo Lal,J.
Learned counsel for the applicant pointed out that prior to this
application, the applicant has done a notice of Cr. Revision but
in the order dated 10.4.2019 have some correction so the
applicant did not file the criminal revision and after correction
the applicant has filed this application u/s 482 Cr.P.C. He
further states that he wants to file a criminal revision against the
impugned order therefore, he does not want to press this
application u/s 482 Cr.P.C. and it may be dismissed as not
pressed with liberty to file a fresh revision.
Accordingly, this application u/s 482 Cr.P.C. is dismissed as not
pressed with liberty to file a fresh revision.
Let the certified copy of impugned order be returned to the
learned counsel for the applicant as per Rules.
Order Date :- 6.2.2020
