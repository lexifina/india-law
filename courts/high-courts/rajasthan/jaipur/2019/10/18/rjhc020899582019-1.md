Judgment / Order
18/10/2019
1. Petitioner has filed this Petition seeking fair investigation.
2. Learned Public Prosecutor has submitted a report which is
taken on record. As per which Police has proposed negative final
report.
3. In view of the same, Criminal Miscellaneous Petition seeking
fair investigation has become infructuous and the same is
accordingly dismissed as having become infructuous.
4. However, petitioner would be free to file Protest Petition, if so
advised.
