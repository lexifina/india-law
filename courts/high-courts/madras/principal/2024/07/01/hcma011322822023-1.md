KRISHNAN RAMASAMY, J.
These applications have been filed
to set aside the orders dated 13.07.2023
passed by the learned Master in the above
condone delay applications.
2. The learned counsel appearing
for the respondent submitted that he has
no objection in allowing these
applications.
3. Being satisfied with the reasons
assigned by the petitioner, this Court is
inclined to allow these petitions.
4. Accordingly, these Applications
are allowed. The orders dated
13.07.2023, passed by the learned Master
in the above condone delay applications,
are set aside and the delay in filing the
above petitions is hereby condoned.
