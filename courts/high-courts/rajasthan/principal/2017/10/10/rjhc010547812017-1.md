HON'BLE THE CHIEF JUSTICE
HON'BLE MR. JUSTICE RAMCHANDRA SINGH JHALA
Order
10/10/2017
1. The main order passed by the Tribunal on 06.09.2016 was
set aside by a Division Bench of this Court on 15.05.2017 and
thus there was no occasion for the review applications of said
order to have been filed before the Tribunal.
2. Learned counsel for the petitioners states that the review
application was filed prior to the writ petition being decided by this
Court. If this be so the petitioners should have withdrawn the
review application.
3. Be that as it may, since the order review whereof was sought
before the Tribunal has already been set aside by a Division Bench

(2 of 2)
[CW-7764/2017]
of this Court, we dispose of the writ petition declaring that the
impugned order dated 23.03.2017 passed by the Tribunal is null
and void.
