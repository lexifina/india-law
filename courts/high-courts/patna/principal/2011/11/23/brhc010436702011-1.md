2 23.11.2011 This application has been filed for modification of the
order dated 21.7.2011.
Learned counsel for the petitioners submits that the name
of the petitioner’s father has been wrongly typed in the main quashing
application.
Counsel for the petitioners is permitted to correct the
name in the main quashing application in course of the day.
The order dated 21.7.2011 is modified and should be read
as Manager Ram, Son of Moti Ram instead of Son of Bhogi Ram.
The time to produce a copy of this order is accordingly extended by a
period of one month.
This modification application is allowed to the aforesaid
extent.
 Sanjay (Sheema Ali Khan, J.)
