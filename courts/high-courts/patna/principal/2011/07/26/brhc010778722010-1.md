---Respondents.
 -----------
06. 26.07.2011 Heard Mr. Ram Shankar Das, learned counsel for the
petitioner and Ms. Nilu Agrawal, learned counsel for the respondent Bihar
State Electricity Board.
On hearing both sides, this Court, based on pleadings on
record, is satisfied that no relief can be granted to the petitioner since
neither the Jharkhand Electricity nor the State Advisory Committee of the
Board has been made party to the proceeding.
Petitioner, however, is granted liberty to approach the
concerned authority of the Bihar State Electricity Board as well as the
Jharkhand State Electricity Board for his mutual transfer on satisfying
requirements therefor. If any such application is filed before the
respondent Secretary, Bihar State Electricity Board, I am sure, the same
shall receive due consideration in accordance with law.

 Sym
 ( Kishore K. Mandal, J. )
