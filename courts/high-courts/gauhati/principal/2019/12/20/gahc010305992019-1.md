(Manojit Bhuyan, J)
Heard Mr. H.K. Baruah, learned counsel for the applicant as well as Ms. G. Hazarika, learned
counsel representing respondent no.1. Also heard Mr. J. Payeng, learned counsel for respondent
nos.2, 3 and 4; Ms. B. Das, learned counsel for respondent no.5 and Ms. U. Das, learned counsel for
respondent no.6.
Applicant seeks correction in the order dated 29.11.2019 to the extent that the description of
the case number, which is recorded as “FT (1st) Case No.2653/2011” should read as “FT (1st) Case
No.2563/2011”.
We have perused the available materials on record and find that the prayer so made is bona
fide. Accordingly, the order dated 29.11.2019 stands corrected and modified to the extent that the
description “FT (1st) Case No.2653/2011” shall now read as “FT (1st) Case No.2563/2011”.
With the above modification the present Interlocution Application stands disposed of.
