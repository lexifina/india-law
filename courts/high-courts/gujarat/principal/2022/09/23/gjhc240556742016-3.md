ORAL ORDER
Learned advocate for the applicant seeks
permission to withdraw this application with a request
to file an application before the concerned trial court
for expeditious hearing of the trial. Permission, as
prayed for, is granted. The present application stands
disposed of as withdrawn. Rule is discharged. It is
open for learned advocate for the applicant – original
complainant to file an application before the concerned
trial court for expeditious hearing of the trial. As
and when such application is filed, the concerned trial
court shall examine the same on its own merits.
