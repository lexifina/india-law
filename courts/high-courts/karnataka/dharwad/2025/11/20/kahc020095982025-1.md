ORAL ORDER
(PER: THE HON'BLE MR JUSTICE ANANT RAMANATH HEGDE)
Learned counsel for the petitioner submits that there is an
error in the application of compromise petition filed before the
Trial Court and consequently, the same error has occurred in the
compromise decree.
2. It is submitted that application was sought to be
moved for correction of the decree after the disposal of the case
and same is not accepted by the Trial Court.
3. It is made clear that for correction of the
typographical error, the application is maintainable even after
the disposal of the suit.
4. Hence, the following:
ORDER
i. The petition is disposed of.
ii. Liberty is reserved to the petitioner to file an
application before the Trial Court.
