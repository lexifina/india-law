# High Court of Madhya Pradesh, WP/11649/2012, 2012-08-08

W.P. No. 11649/2012
08.08.2012
 Shri Dinesh Upadhyay, Advocate for the petitioners.
 The impugned order dated 28.2.2012 (annexure P/1)
passed by Additional Commissioner, Sagar Division, Sagar in
Revision Case No. 667-A/19/2006-2007 has been challenged
in this petition.
 Learned counsel for the petitioners submits that he
would like to withdraw this petition and would like to assail the
impugned order dated 28.2.2012 (annexure P/1) by filing
revision application before the Board of Revenue.
This prayer is accepted and this petition is dismissed as
withdrawn with liberty to file revision application before the
Board of Revenue.
Let revision application be filed on or before 31.8.2012. If
the same is filed within this period the same be decided on its
own merit without entering into the question of limitation.
Let certified copy of the impugned order dated 28.2.2012
be returned to learned counsel for the petitioners so as to
enable him to file revision application before the Board of
Revenue and a photocopy thereof be retained in the file.
With the aforesaid observations, this petition is dismissed
as withdrawn with the aforesaid liberty.
 (A.K. Shrivastava)
