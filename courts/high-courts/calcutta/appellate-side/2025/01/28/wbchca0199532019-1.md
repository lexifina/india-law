# Calcutta High Court, WPA/8745/2019, 2025-01-28

28.01.2025

 Court No.30
 BM
WPA 8745 of 2019
 Usha Devi Prajapati
 Vs.
The State of West Bengal & Ors.
Mr. Susanta Pal
Mr. Prabir Kumar Ray
... for the State
The present writ application of the year 2019
has been preferred praying for direction upon the
respondents to enquire into the grievance of the
petitioner regarding vacating of the premises with the
help of local Police authorities.
None appear for the petitioner on call.
Learned counsels for the State are present.
The writ petition is thus dismissed for default.
There will be no order as to costs.
All connected applications, if any, stand
disposed of.
Interim order, if any, stands vacated.
( Shampa Dutt (Paul), J. )
