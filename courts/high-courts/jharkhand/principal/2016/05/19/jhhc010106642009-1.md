06 /19.05.2016: In this writ application the petitioner has prayed for quashing the
order dated 14.10.2008, by which the petitioner has been suspended in
contemplation of the departmental enquiry. The petitioner has also
challenged Annexure-1/A, i.e. order dated 24.11.2008, by which he has
been relieved from the post and he has also prayed for quashing the charge
sheet as contained in Memo No. 2748 dated 17.10.2008, which is
Annexure-2 to this writ petition.
Counsel for the State relying upon the counter affidavit submits that
after a proper departmental proceeding, the petitioner has been awarded
punishment of Censure, vide Annexure-A to the counter affidavit i.e. order
contained in memo 875 dated 19.03.2010.
Since the order of punishment has already been passed, this writ
application challenging the order of suspension and issuance of charge
sheet, has become infructuous. The petitioner, if so advised, may challenge
the punishment order in a separate proceeding before the appropriate
Forum.
This application is dismissed as infructuous.
