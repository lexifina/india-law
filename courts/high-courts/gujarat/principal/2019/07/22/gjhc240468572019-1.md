1. This is an application preferred by the applicant under
Section 378(4) of the Code of Criminal Procedure, 1973 for
leave to appeal against the judgment and order of acquittal
dated 31.05.2019 passed in Criminal Case No.70 of 2011 by
learned Chief Judicial Magistrate, Bhuj, District Kutchh.

rule for the respondent-State.
3. Heard learned advocate for the applicant and learned
APP for the respondent-State.
4. Considering the averments made in the application
supported by affidavit as well as arguments advanced by Mrs.
R.P. Lakhani, learned advocate for the applicant that the
meager amount came to be advanced and cheque in question
bounced, the return memo which came to be received from
