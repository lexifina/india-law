# High Court of Himachal Pradesh, CMP/5030/2019, 2019-07-04

CMP No. 5030 of 2019 in LPA No. 22 of
2018
04-07-2019 Present: Mr. J.S.Bhogal, Senior Advocate with Mr.
Satish Sharma, Advocate, for the
appellant/non-applicant.
Mr. Vikas Chauhan, Advocate for the
respondent-applicant.
 This is an application seeking the release of
accrued interest on the amount already ordered to be
released.
 Heard the learned Senior Counsel, appearing
for the State Electricity Board and the learned
counsel, appearing for the applicant in this
application, who is respondent in the main appeal.
 There is no dispute about the fact that the
amount deposited by the appellant to the tune of Rs.
78,28,107/-, was already ordered to be released.
Since that amount was kept in Fixed Deposit, it has
earned interest. Hence, this application for the
release of the amount.
 Since the deposited amount has already been
ordered to be released, there cannot be any objection
to the release of the interest. Hence, application is
allowed and disposed of.
 (V. Ramasubramanian)
 Chief Justice
 (Anoop Chitkara)
 Judge
