# Allahabad High Court, CRLP/19843/2018, 2018-07-25

Court No. - 1
Case :- CRIMINAL MISC. WRIT PETITION No. - 19843 of 2018
Petitioner :- Smt. Nanhki Devi
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Babu Lal Ram
Counsel for Respondent :- G.A.
Hon'ble Ramesh Sinha,J.
Hon'ble Dinesh Kumar Singh-I,J.
Heard Sri Babu Lal Ram, learned counsel for the petitioner and Sri
Deepak Mishra, learned AGA for the State.
Learned AGA has pointed out that the post mortem report of the deceased
has not been annexed with the writ petition, to which learned counsel for
the petitioner prays that the present petition be dismissed as not pressed
with liberty to file fresh.
Accordingly, the present petition is dismissed as not pressed with liberty to
file fresh.
Office is directed to return the certified copy of the F.I.R. to learned
counsel for the petitioner after retaining a copy of the same.
(Dinesh Kumar Singh-I, J.) (Ramesh Sinha, J.)
Order Date :- 25.7.2018
