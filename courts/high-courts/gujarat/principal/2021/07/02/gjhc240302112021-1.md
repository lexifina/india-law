ORAL ORDER
Learned advocate for the petitioner has rightly
pointed out that earlier the petitioner had filed a
petition before this Court which was withdrawn on
08.07.2019. While permitting the withdrawal, a
liberty was granted to the petitioner to file an
application before the concerned trial Court. Learned
advocate for the petitioner has fairly submitted that
thereafter, the petitioner has not approached the
concerned trial Court.
Learned advocate for the petitioner, therefore,
seeks permission to withdraw this petition with a
view to file an appropriate application before the
concerned trial Court.
Permission, as prayed for, is granted. The
petition stands disposed of, as withdrawn. Liberty is
granted to the petitioner to file an appropriate
