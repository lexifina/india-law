ORDER
16.12.2024
Heard learned counsel for the parties.
This is an Interlocutory Application praying for amendment of the writ
petition in respect of the changes sought to be withdrawn which are narrated in
para III of the Interlocutory Application.
It is submitted that this small changes are necessary to be recalled in the
writ petition which by oversight could not be done at the time of filing writ
petition.
Ms. P.R. Mahanta, as well as Mr. J. Handique, learned counsel
representing the respondents do not object to the prayer made accordingly, this
Interlocutory Application stands allowed and the petitioner is permitted to make
necessary changes as described in Para III of the Interlocutory Application:
“That, the applicant wants to make the following amendments-That in para-2 after the words “Wajedul Islam” the word ‘daughter’ may be amended as ‘son’. Aforesaid
typographical mistake is need to be corrected by amending the writ petition in the interest of justice”.
The petitioner will file amended writ petition and serve copies thereof to
the learned counsels for the respondents after making necessary changes as
prayed for. Interlocutory Application is accordingly allowed and disposed of.
