ORAL ORDER
2 21-02-2022 Learned counsel for the petitioner undertakes to remove all the
defects pointed out by the Stamp Reporter within four weeks after start of
normal functioning of the Court.
Mr. Chakrapaani, learned counsel for the petitioner has
informed this Court that in paragraph ‘3’ of the petition, only one criminal
antecedent has been mentioned whereas the impugned order itself shows
that the petitioner has got two more criminal cases.
Learned counsel prays to withdraw this application with liberty
to file fresh application giving complete antecedents i.e. cases which are
pending against the petitioner and those in which the petitioner has been
acquitted so far.
This application stands dismissed with liberty as prayed for.

SUSHMA2/-
