Heard Mr. M. Ahmed, learned counsel for the applicant as well as Mr. A. Kalita,
learned counsel representing respondent nos.2, 3 and 4. Mr. A.I. Ali, learned counsel
appears for respondent no.5 whereas Ms. U. Das, learned counsel appears for respondent
no.6.
This is an application seeking correction in the order dated 11.03.2019 passed in the
related writ petition i.e. WP(C) 1516/2019.
Applicant submits that the case before the Foreigners Tribunal is registered and
numbered as FT Case No.128/17. However, in the order of this Court dated 11.03.2019,
the same finds recorded as “FT (8) Case No.1281 of 2017”. Perhaps, this is on account of
the fact that in the Cause Title of the writ petition, the case has been described as “F.T.
Case No.1281/2017”.
Be that as it may, the description of the case number “FT (8) Case No.1281 of 2017”
appearing in the order dated 11.03.2019, shall now read as “FT Case No.128/17”.

Page No.# 3/3
With the above correction, the present Interlocutory Application stands allowed.
