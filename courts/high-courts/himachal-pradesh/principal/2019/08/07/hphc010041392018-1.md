Ajay Mohan Goel, Judge (Oral):
Learned counsel for the petitioner submits that he has
instructions to state that he may be permitted to withdraw the
application, which was filed under Order 6, Rule 17 of the Code of Civil
Procedure, in which the impugned order has been passed, which stands
assailed by way of present petition, with liberty to file an appropriate
application before the learned Trial Court, if so advised. The prayer of
learned counsel for the petitioner is allowed. The application filed by the
petitioner under Order 6, 17 of the Code of Civil Procedure, in which the
impugned order was passed by the learned Trial Court is permitted to be
withdrawn, meaning thereby that the impugned order dated 19.01.2018,
which has been assailed by way of this petition has been rendered
