PRAYER: Criminal Original Petition filed under Section 482 of
the Criminal Procedure Code, to call for the records pertaining to
the First Information Report in Crime No.207 of 2017, on the file of
the first respondent Police dated 13.05.2017 for the offences under
Sections 294(b), 323 and 506 (i) of the Indian Penal Code and quash
the same as illegal and un-sustainable.
For Petitioner : Mr.S.Balamurugan
For R-1 : Mr.M.Chandrasekaran
 Additional Public Prosecutor
O R D E R
This Criminal Original Petition has been filed to quash the
First Information Report in Crime No.207 of 2017, dated 13.05.2017
on the file of the first respondent Police.
2.Today, when the matter is taken up for hearing, the learned
Additional Public Prosecutor, appearing for the first respondent, on
instructions, submitted that the investigation has been completed
and final report has already been filed before the learned Judicial
Magistrate No.II, Virudhunagar and the same is yet to be taken on
file.
3.In view of the above development, this Court is not
inclined to interfere with the First Information Report at this
stage.

4.This Criminal Original Petition stands disposed of with a
direction to the learned Judicial Magistrate No.II, Virudhunagar, to
immediately take the final report on file and proceed further, in
accordance with law. It is left open to the petitioner, to
challenge the final report, if so advised. Consequently, the
connected miscellaneous petition is closed.
