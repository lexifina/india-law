PRAYER: Criminal Original Petition is filed under Section 482 of
the Code of Criminal Procedure, to pass an order directing the
learned Judicial Magistrate No.I, Tuticorin, to expedite the trial

For Petitioner : No Appearance
For R1 : Mr.A.Robinson
 Government Advocate(Crl. side)
For R2 : No Appearance
ORDER
This Criminal Original Petition has been filed to pass an order
directing the learned Judicial Magistrate No.I, Tuticorin, to
expedite the trial in C.C.No.224 of 2005, within a time frame to be
fixed by this Court.
2.Today, when the matter is taken up for hearing, the learned
Government Advocate (Criminal side) appearing for the first
respondent submitted that the trial in C.C.No.224 of 2005, on the
file of the Judicial Magistrate Court No.I, Tuticorin, has been
completed and the same has ended in acquittal.
3.In view of the above subsequent developments, the relief
sought for in this Criminal Original Petition has become
infructuous. Hence, this Criminal Original Petition is dismissed as
infructuous.
