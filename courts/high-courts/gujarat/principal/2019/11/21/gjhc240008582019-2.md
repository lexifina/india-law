ORAL ORDER
Learned advocate for the respondent No.2 places on
record copy of charge sheet filed before the competent Court
in respect of offence in question, which is ordered to be taken
on record. In light of this position, learned advocate for the
applicants seeks permission to withdraw present application
with a liberty to file discharge application and also to file
appropriate proceedings either u/s 397 or 482 of the Code of
Criminal Procedure, 1973 before appropriate competent
Court, after remedy to file discharge application is availed.
Permission is granted. The application stands disposed of as
withdrawn with above liberty. Notice discharged.
It is clarified that this Court has not examined the merits
of the present application.
(S.H.VORA, J)
