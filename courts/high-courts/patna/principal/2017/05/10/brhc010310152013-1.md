ORAL ORDER
2/ 10-05-2017 This application has been filed for quashing of
charge-sheet of Bahera P.S. Case No.391 of 2012.
Heard counsel for the petitioner and the State.
It has been submitted that charge-sheet has been
submitted in the case for the offence under Section(s) 302 Indian
Penal Code on 30.09.2013 and thereafter cognizance has also been
taken by the learned Magistrate vide order dated 10.03.2014.
Since cognizance has already been taken in the case,
this quashing application has become infructuous.
Accordingly, this application is dismissed as having
become infructuous.
