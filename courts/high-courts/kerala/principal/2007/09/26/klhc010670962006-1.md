JUDGMENT
This writ petition is filed challenging the order passed in E.A.No.288
of 2006 in E.A.No.18/2006 in E.P.No.691/2006 in O.S.No.375/2000. The
petitioner herein preferred an application to set aside the sale under Order
XXI Rule 90 C.P.C. It is admitted that the said application was posted for
hearing under Order XXI Rule 105. For the default, the said petition was
dismissed. Then the remedy provided is under Order XXI Rule 106. An
application to restore a matter dismissed for default will squarely come
within Order XXI Rule 106 and when an order is passed under Order XXI
Rule 106, Order 43 Rule 1(ja) provides an appellate remedy. Therefore the
writ petition as filed cannot be entertained and it is dismissed with liberty
to the petitioner to move the appellate court, if the law so permits.
