# Madras High Court, A/6137/2018, 2019-12-10

 A.No.6137 of 2018

C.S.No.123 of 2018
Dr.G.Jayachandran, J.
Heard the learned counsel for the applicant/defendant.
2. The applicant has received a suit summon on 09.04.2018 under the
amended Civil Procedure Code r/w Commercial Courts Act. The defendant
ought to have filed written statement within 30 days. However, the defendant
has failed to file written statement within the time prescribed. There is 76
days delay in filing the written statement, which is well within the prescribed
upper time limit of 120 days to file written statement. Hence the delay is
condoned. The written statement is taken on file.
