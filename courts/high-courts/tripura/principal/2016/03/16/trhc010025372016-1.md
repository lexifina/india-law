# High Court of Tripura, IA./342/2016, 2016-03-16

Case No :IA. 0000342/2016
Party Name : NEW INDIA ASSURANCE COMP;ANY Vs RANJIT DEBBARMA
HONBLE THE CHIEF JUSTICE DEEPAK GUPTA
This is a pending matter in which in which the insurance company has deposited the
awarded amount.
 This is an application filed by one of the claimant Sri Ranjit Debbarma for release of
the amount.
 The application is totally misconceived. The award has been apportioned amongst
various claimants and this application has been filed without disclosing any facts with
regard to the apportionment of the amount. Sri Ranjit Debbarma does not hold any power of
attorney for the other claimants.
 Therefore, the application is dismissed.
