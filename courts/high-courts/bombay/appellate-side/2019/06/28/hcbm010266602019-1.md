IN THE HIGH COURT OF JUDICATURE AT BOMBAY
CRIMINAL APPELLATE JURISDICTION
CRIMINAL APPLICATION NO.859 OF 2019
(FOR RESTORATION)
IN
CRIMINAL BAIL APPLICATION NO.969 OF 2019
Laxman Dhondaji Pattebahadur ...Applicant
 Versus
The State of Maharashtra ...Respondent
Mr.S.B.Chandan, for the Applicant.
Mr.P.H.Gaikwad, A.P.P for the Respondent - State.
 CORAM : REVATI MOHITE DERE, J.
DATE : 28th JUNE, 2019
P.C. :
1. Heard the learned counsel for the Applicant.
2. By this application, the applicant seeks recall of the order dated
18th April, 2019, and prays for restoration of Criminal Bail Application
No.969 of 2019, which came to be dismissed for non- prosecution, as
none was present on behalf of the applicant.

2/2 923-appp.859.2019.doc
3. For the reasons set out in the application, the application is
allowed. The order dated 18th April, 2019, is recalled and Criminal Bail
Application No.969 of 2019, is restored to file.
4. The Application is accordingly disposed of.

5. Criminal Bail Application No.969 of 2019, be listed for
'admission' on 12th July, 2019.
 REVATI MOHITE DERE, J.
