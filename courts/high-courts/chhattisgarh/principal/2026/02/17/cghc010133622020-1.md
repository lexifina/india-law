 Order on Board
17.02.2026
1. By this petition, the petitioner is challenging the impugned order
dated 03.06.2020 by which Rs. 1,18,752/- has been directed to be
recovered from the petitioner.
2. Mr. Aman Upadhyay, learned counsel for the petitioner would
submit that the impugned order is unsustainable and bad in law,
therefore, the same is liable to be set aside.
3. Mr. Sharad Mishra, learned State counsel would support the
impugned order passed by the respondent authorities.
4. I have heard learned counsel appearing for the parties and perused
the documents meticulously.
5. A careful perusal of the impugned order would show that for the
period from 13.10.2008 to 30.06.2017, excess amount was paid to

3
the petitioner, therefore, it was sought to be recovered in 16
installments, which has already been paid by the petitioner. In that
view of the matter, I do not find any merit in this petition, the same
is liable to be and hereby dismissed.
