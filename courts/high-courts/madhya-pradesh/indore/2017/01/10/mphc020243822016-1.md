# High Court of Madhya Pradesh, WP/6552/2016, 2017-01-10

WP-6552-2016
(JAGMOHAN Vs ANIS FATMA BEE)
10-01-2017
Shri Anil Jain, learned counsel for the petitioner.
Shri Romesh Dave, learned counsel for the
respondent.
Petitioner has filed the present petition being
aggrieved by the order dated 04.08.2016, by which
application under Order 8 Rule 1(2) read with
Section 151 has been rejected and written statement
filed along with the said application has not been
taken on record.
The contention of the petitioner/defendant is that
since the Presiding Officer was not available,
therefore, the defendant was under impresssion that
he is not required to file the written statement. When
the Presiding Officer joined, immediately on the next
day he filed a written statement along with an
application for permission to file the written
statement. Since 90 days time was over, therefore,
the civil Court has mechanically rejected the
application without assigning reasons.
That suit is filed on 25.01.2016 and still at the stage
of service of notice to defendant No.6. There is not
much progress in the suit. Reasons given by the
petitioner appears to be bona-fide and there is no
intention to delay the trial.
Since, the written statement has already been filed

with the application, therefore, the delay is
condoned. The trial Court is directed to take the
written statement on record.
Impugned order dated 04.08.2016 is set aside so far
it relates to rejection of application for permission to
file the written statement.
With the aforesaid petition is allowed with the cost
of Rs.1,000/- payable to hte plaintiff.
(VIVEK RUSIA)
JUDGE
