# High Court of Madhya Pradesh, MCC/9/2017, 2017-08-02

M.C.C. No.09/2017
02/08/2017
Shri Sapnesh Jain, learned counsel for the applicant.
Ms. Kiran Pal, learned counsel for the respondent.
Heard on application under Order 44 Rule 1 of the
C.P.C., seeking permission to file an appeal as indigent
person.
As per report dated 04/07/2017 received from
Tehsildar and Sub-Divisional Officer, Tarana (in ref. of
Letter No. 7630/AG/17 Indore, dated 21/06/2017),
applicant has no means to pay the court fees, therefore, we
allow the prayer and permit the present applicant to file
appeal as an indigent person.
With the aforesaid, M.C.C. No.09/2017 stands
allowed and disposed of.
(P. K. Jaiswal) (Ved Prakash Sharma)
