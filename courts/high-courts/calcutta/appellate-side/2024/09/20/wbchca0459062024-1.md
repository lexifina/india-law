Mr. Subrata Karmakar …For the petitioners.
The order impugned is appellable under Order XLIII
Rule (1)(r) of the Code of Civil Procedure, the revisional
application assailing the said order is not maintainable, as
such C.O. 3321 of 2024 is dismissed as not maintainable
without any order as to costs.
The learned advocate-on-record for the petitioners is at
liberty to take back the certified copy of the order
impugned upon furnishing photocopy thereof.
Parties to act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent Photostat certified copy of this order, if applied
for, be supplied to the parties subject to compliance with
all requisite formalities.
