Pius C.Kuriakose,J.
Under challenge in this F.A.O. is an order passed
by the Subordinate Judge, Kollam dismissing an application
filed by the second defendant for setting aside the exparte
decree. It is submitted by Mr.Vinoy Varghese Kallummoottil,
learned counsel for appellant and Mr. C. Rajendran, learned
counsel for respondent that subsequent to the filing of this
appeal all the issues between the parties have been settled
between them. Both sides request that the impugned order
be set aside and that the exparte decree passed in
O.S.49/2000 be set aside. This is necessary according to
them so that compromise petition can be filed and one half of
the court fee remitted can be refunded to the plaintiff.
Accepting the submissions made by both parties we set aside
the order under appeal without examining the merits and
allow I.A.2915/2005. It is made clear that it is for the

are passing the present order.
