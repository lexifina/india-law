05/11.12.2019 Heard learned counsel for the petitioner and learned counsel for the
respondents.
 It is submitted on behalf of the petitioner that in view of the Memo
No.629 dated 5th July, 2012 which has been attached as Annexure-A to the
counter affidavit by which Letter No. 1656 dated 26th December, 2011, which has
been attached as Annexure-2 to this writ application has been cancelled,
therefore, instant application has become infructuous.
 Learned counsel for the respondents submitted that grievance of the
petitioner has already been settled.
 In view of above submission, instant application is dismissed as
infructuous.
