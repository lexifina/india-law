P. C. :
1 Learned Counsel for the respondent has submitted that in
fact, the application seeking leave to appeal would not be maintainable
under section 378 of the Code of Criminal Procedure, 1973 and would
have to be filed under section 372 of the Code of Criminal Procedure,
1973 before the District Court. The learned Counsel for the applicant has
fairly admitted the provisions of law and submitted that he would
withdraw the present application with liberty to file appeal before the
appropriate forum as contemplated under section 372 of the Code of
Criminal Procedure, 1973. Liberty as prayed for is granted in the interest
of justice. The application stands dismissed as withdrawn.
