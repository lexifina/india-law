# High Court of Madhya Pradesh, RP/316/2014, 2014-11-10

1
R.P. No.316/2014
10/11/2014
Shri G.S. Patwardhan, learned counsel for the
petitioner.
Ms. Pritha Moitra, learned counsel for the respondent.
Heard.
This is second review application for reviewing the
order dated 27/06/2013, passed in W.P. No.11514/2012(S).
Similar review application has been dismissed by order dated
1/11/2013, passed in R.P. No.500/2013.
Learned counsel for the petitioner submits that in view
of interim order passed on 13/10/2014 in W.P.
No.1368/2013, the petitioner is not in a position to comply
with the order passed on 27/06/2013.
Considering the fact that after 27/06/2013 to
13/10/2014, there was no stay of any kind and, therefore, no
case for reviewing the order 27/06/2013 when once similar
review application is dismissed, as prayed by the learned
counsel for the petitioner is made out.
Accordingly, this second review application is
dismissed.
 (P.K. Jaiswal) (D.K. Paliwal)
 Judge Judge
