# High Court of Madhya Pradesh, MCRC/5475/2017, 2017-07-03

1
MCRC.5475/2017
Raj Kumari Ken
v.
State of M.P.
03/07/2017
Shri R.P.Singh, counsel for the applicant.
Shri Prakhar Dhengula, Panel Lawyer for the
respondent/State.
This application under Section 482 of CrPC has been
filed seeking restoration of MCRC No.2573/2017, an
application for grant of anticipatory bail which was dismissed
for want of prosecution on 15/03/2017.
As there is no impediment in filing the second
application for grant of anticipatory bail, therefore, the
counsel for the applicant seeks permission of this Court to
withdraw this application with liberty to file second application
for grant of anticipatory bail.
With the aforesaid liberty, the application is dismissed
as withdrawn.
 (G.S.Ahluwalia)
AKS Judge
