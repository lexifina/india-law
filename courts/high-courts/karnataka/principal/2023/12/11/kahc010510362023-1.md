 THIS PETITION, COMING ON FOR PRELIMINARY
HEARING, THIS DAY, THE COURT MADE THE FOLLOWING:
ORDER
 The petitioner/judgment debtor in Execution No.8/2022
on the file of Prl. Civil Judge and JMFC, Hunsur, is before this
Court praying to set aside the execution proceedings in
Execution No.8/2022.
 2. Heard learned counsel, Sri.Mohammad Tahir for the
petitioner/judgment debtor and perused the writ petition
papers.
 3. Learned counsel for the petitioner/judgment debtor
would submit that suit was filed in representative capacity and
said suit was decreed. The legal representatives of plaintiffs
filed execution petition. Learned counsel for the petitioner
would submit that execution petition by legal representatives of
plaintiffs in a representative suit, would not be maintainable.
Hence, he prays for setting aside the execution proceedings
itself.
 4. Section 47 of Code of Civil Procedure provides
opportunity to the parties in execution proceedings to file

 With the above, writ petition stands rejected.
