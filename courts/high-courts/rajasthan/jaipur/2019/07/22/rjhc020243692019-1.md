HON'BLE MR. JUSTICE PANKAJ BHANDARI
Judgment / Order
22/07/2019
1. Petitioner has preferred this Criminal Misc. Petition under
Section 482 Cr.P.C. seeking fair investigation.
2. Report is submitted by learned Public Prosecutor. As per
which Police has submitted negative final report on 02.05.2019.
Report is taken on record.
3. In view of the same, the present Petition has become
infructuous and the same is accordingly dismissed as having
become infructuous.
4. However, petitioner would be free to approach the Magistrate
concerned to file protest petition, if so advised.
(PANKAJ BHANDARI),J
