ORAL ORDER
2 03-04-2014 After some arguments, learned counsel for the
petitioner seeks permission to withdraw this application
in order to enable the petitioner to file statutory appeal
against the impugned order of suspension dated
06.02.2014 (Annexure-16) to this writ application.
That being so, this application is permitted to be
withdrawn with the aforementioned liberty.
It goes without saying that if the petitioner would
file his appeal, the matter being one relating to
suspension, the same should be disposed of
expeditiously.
