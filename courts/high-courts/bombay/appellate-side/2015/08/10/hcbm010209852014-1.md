P.C. :-
1. Heard rival submissions on this application for condonation
of delay of 241 days in preferring the application for leave to file
appeal challenging the acquittal of the respondent in the matter of
offence punishable under Section 138 of Negotiable Instruments
Act.
2. For the reasons mentioned in the application, delay is
condoned. Application is allowed.
3. Learned Counsel Mr. Tapan Thatte for respondent No.1
waives service of the application for leave to file appeal. The
applicant to file notes of evidence by next date on which date the
application for leave to file appeal shall be heard. Application for
leave to file appeal is stand over to 31st August, 2015.
