P.C.:-
1. Learned Advocate for petitioner submitted that, the petitioner had
preferred an application for discharge before the trial Court which has been
rejected vide order dated 12th July 2023.
2. In these circumstances, we are not entertaining this petition
challenging charge-sheet as the petitioner has remedy of challenging order
rejecting the application for discharge before the appropriate Court.
3. This petition is disposed off with liberty to the petitioner to challenge
the order rejecting the application for discharge before appropriate Court.
4. Petition stands disposed off.
