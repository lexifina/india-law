# Patna High Court, MJC/2555/2007, 2011-08-11

IN THE HIGH COURT OF JUDICATURE AT PATNA
Miscellaneous Jurisdiction Case No.2555 of 2007
Kameshwar Ram & Anr
Versus
State Of Bihar & Ors
----------------------------------
11 11.08.2011 Heard learned counsels for the petitioner
and the State.
A show cause has been filed on behalf of
the State stating therein that the order of the Court
has been complied with and necessary order has
been passed which has been annexed with the show
cause.
Learned counsel for the petitioner
submits that order passed is not correct as the same
has been passed without due consideration of the
relevant materials.
Be that as it may, since the order of the
Court has been complied with, this contempt
application need not proceed further. However, it will
be open for the petitioner to assail the aforesaid
order, if so advised, in an appropriate forum.
The application accordingly stands
disposed of.
 Manish ( Shailesh Kumar Sinha, J.)
