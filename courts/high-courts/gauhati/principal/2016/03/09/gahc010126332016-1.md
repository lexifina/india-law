# Gauhati High Court, I.A./928/2016, 2016-03-09

I.A. 928/2016
BEFORE
HON’BLE MR. JUSTICE T. VAIPHEI
Heard Mr.M.H. Choudhury, the learned counsel for the applicant and Mr.S
Chakraborty, the learned Standing Counsel for Secondary Education Department.
The application is for amending the connected writ petition as proposed
in paragraph-3 of the application. By this amendment, a new paragraph, namely, 3
1(a) is being added while the prayer in the writ petition is being refreshed as
proposed therein.
As there is no objection, the application is allowed.
The petitioner shall file a re-cast writ petition within one week from t
oday.
The Interlocutory Application stands disposed of.
