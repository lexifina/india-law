 SANDIPKUMAR C. MORE, JJ.
 DATE : 7th DECEMBER, 2021
ORDER :
1. We heard learned counsel Shri Kulkarni and learned
counsel Shri Ladda for the applicants for some time. Learned
counsel for the applicants, on instructions, seek leave to
withdraw both these applications with liberty to the applicants to
file applications for discharge in the trial Court.
2. Leave granted. Both the Applications are dismissed as
withdrawn, with liberty to each of the applicants to file
application for discharge before the trial Court in pending case.
3. We have not considered the merits and on filing such
application for discharge, it is for the trial Court to consider the
same on its own merits, in accordance with law.
