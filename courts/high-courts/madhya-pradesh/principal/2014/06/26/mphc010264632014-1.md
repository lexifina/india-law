# High Court of Madhya Pradesh, CONC/944/2014, 2014-06-26

..... 1

 Con.C. No. 944 of 2014
26.06.2014
Shri Mukesh Agrawal, Counsel for the petitioner.
Considering the fact that the main case W.P.
No.5091/14 is still pending and if the petitioner has any
grievance with regard to the subsequent action taken
inspite of the order dated 26.3.2014 in the said writ
petition, petitioner may file appropriate application
seeking further relief in W.P. No.5091/14.
For the present, in the facts and circumstances, we
are of the opinion that it is not an appropriate case to
initiate any action for contempt. As the petitioner can
always seek further relief and interim benefit in the order
passed in W.P.5091/14. Accordingly, granting liberty to
the petitioner to file an appropriate application and seek
consequential stay of the impugned action passed in W.P.
No. 5091/14, this contempt application is disposed of.
 (Rajendra Menon) [Sushil Kumar Gupta]
vj JUDGE JUDGE
