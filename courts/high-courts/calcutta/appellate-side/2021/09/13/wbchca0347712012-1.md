# Calcutta High Court, CRR/2389/2012, 2021-09-13

D/L40.
September
13, 2021
Bpg.
C.R.R. No. 2389 of 2012
(Via Video Conference)
In Re: An application under Section 482 of the Code of Criminal
Procedure read with Sec.397 and 401 of the Code.
 Sri Srimanta Kumar Pramanik
 Versus
 State of West Bengal & Ors.
The revisional application was preferred in respect of a
proceeding under Section 144(2) of the Code of Criminal Procedure.
Having regard to the time period provided under Section
144 of the Code of Criminal Procedure, I am of the view that the
main application being M.F. Case No.166 of 2012 and the orders
passed therein have become infructuous.
Accordingly, the revisional application being CRR 2389 of
2012 is dismissed.
Pending application, if any, is consequently disposed of.
Interim order, if any, is hereby vacated.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
 (Tirthankar Ghosh, J.)
