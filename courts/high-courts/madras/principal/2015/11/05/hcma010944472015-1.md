O R D E R
With the consent of the learned counsel for the petitioner
and Mr.P.V.Selvakumar, learned counsel appearing for the first
and second respondents, the writ petition is taken up for final
disposal.
2. This writ petition is filed praying to direct the
second respondent to implement the order passed by the first
respondent dated 24/8/2009, so as to demolish building situated
at No.11 Hanumar Koil Street, West Mambalam, Chennai 33 by
considering the petitioner's representation dated 28/9/2015.
3. When the matter is taken up for hearing,
Mr.P.V.Selvakumar, learned counsel appearing for the first and
second respondents filed an inspection report stating that he
inspected the site in question on 2
nd November 2015 and found
that the building in question has already been demolished.
4. The learned counsel appearing for the petitioner
produced a photograph to show that there is a temporary
structure built in the corner of building in question, which is
yet to be removed .
5. In view of the above, a direction is issued to the
first and second respondents to the effect that if there is any
unauthorised construction, the same is to be removed.
6. This writ petition is disposed of with the above
direction. No costs. Consequently, the connected Miscellaneous
Petition is closed.
