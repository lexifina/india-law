# Allahabad High Court, WRIC/15163/2019, 2019-05-02

Court No. - 9
Case :- WRIT - C No. - 15163 of 2019
Petitioner :- Kazim Hasan
Respondent :- State Of U P And 14 Others
Counsel for Petitioner :- Pradeep Kumar Mishra
Counsel for Respondent :- C.S.C.,Gaurav Kumar Chaturvedi
Hon'ble Anjani Kumar Mishra,J.
The writ petition has been file seeking direction for expeditious
disposal of proceedings. However, the order sheet of the
proceedings sought to be expedited has not been filed.
The writ petition is therefore dismissed granting liberty to the
petitioner to file a fresh writ petition annexing thereto the entire
order sheet of the proceedings sought to be expedited.
