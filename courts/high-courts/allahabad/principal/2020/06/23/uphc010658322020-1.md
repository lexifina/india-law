# Allahabad High Court, BAIL/16251/2020, 2020-06-23

Court No. - 76
Case :- CRIMINAL MISC. BAIL APPLICATION No. -
16251 of 2020
Applicant :- Sushila Devi @ Hausila Devi And
Another
Opposite Party :- State of U.P.
Counsel for Applicant :- Devottam Pandey
Counsel for Opposite Party :- G.A.
Hon'ble Ravi Nath Tilhari,J.
Heard Sri Pramod Kumar Singh, Advocate holding
brief of Sri Devottam Pandey, learned counsel for
the applicants.
This bail application has been titled as first bail
application. As per stamp reporter, report, defect
no. 4 reads "It appears like a second bail."
A supplementary affidavit has been filed stating
that the present is second bail application.
Learned counsel for the applicants submits that
the first bail application of the same applicants in
the same Case Crime No. 196 of 2016 was
rejected by this Court on 10.7.2019 in Criminal
Misc. Bail Application No. 28911 of 2017. A copy of
this order has been brought on record along with
supplementary affidavit, at page no. 7 thereof.
It is very sorry state of affairs that the present bail
application has been titled as first bail application
and filing of the earlier bail application by the
same accused-applicants and its rejection by this
Court, was not disclosed in the bail application.
Considering the report of the stamp reporter and
the copy of the order dated 10.7.2019 annexed
with supplementary affidavit as Annexure- SA1
thereof, by which first bail application of applicants
was rejected, the present bail application cannot
be the first bail application. Criminal Misc. Bail
application, titled as first bail application no.
16251 of 2020, is hereby rejected.
Order Date :- 23.6.2020
A. Singh
