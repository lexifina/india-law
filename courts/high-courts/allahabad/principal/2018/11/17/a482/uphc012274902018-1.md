# Allahabad High Court, A482/41419/2018, 2018-11-17

Court No. - 55
Case :- APPLICATION U/S 482 No. - 41419 of 2018
Applicant :- Vinod Kumar Sharma
Opposite Party :- State Of U.P. And 2 Ors
Counsel for Applicant :- Vijai Shanker Tripathi,Vinod Shankar Tripathi
Counsel for Opposite Party :- G.A.
Hon'ble Vivek Kumar Singh,J.
Heard learned counsel for the applicant and the learned AGA for the State.
The present application under Section 482 has been moved by the
applicant for a direction to the Opposite Party No.2 for complying with the
order dated 30.08.2018 by which the learned Magistrate has issued non-bailable warrant against the opposite party No.3 Pankaj Kumar.
The applicant has filed this application for getting the order of the learned
Magistrate to be complied with.
There seems to be no occasion for the applicant to move the application
before this Court as the issue has ready been ceased with the competent
Magistrate.
Accordingly, the application stands rejected.
Order Date :- 17.11.2018
