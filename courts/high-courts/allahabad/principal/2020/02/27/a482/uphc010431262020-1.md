# Allahabad High Court, A482/8282/2020, 2020-02-27

Court No. - 77
Case :- APPLICATION U/S 482 No. - 8282 of 2020
Applicant :- Rahul Kumar
Opposite Party :- State Of U.P. And 8 Others
Counsel for Applicant :- Ronak Chaturvedi
Counsel for Opposite Party :- G.A.
Hon'ble Sanjay Kumar Singh,J.
At the very outset, learned counsel for the
applicant submitted that on account of some
defects, he does not want to press this application
and the same may be dismissed as withdrawn with
liberty to file a fresh application.
In view of the statement made by Mr. Ronak
Chaturvedi, learned counsel for the applicant at
the bar, the application is rejected as withdrawn
with liberty to file a fresh application with better
particulars.
Office is directed to return the certified copy of the
order sheet/other docuement, if any, to the
learned counsel for the applicant after retaining
the photocopy of the same on record.
Order Date :-27.2.2020
