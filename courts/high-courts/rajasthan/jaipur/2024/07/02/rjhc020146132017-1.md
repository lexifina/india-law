Order
02/07/2024
The present restoration application has been filed under
Order 41 Rule 19 r/w Section 151 of Civil Procedure Code for
restoration of S.B. Civil Restoration Application No.381/2015(d)
which has been dismissed in non-compliance of order dated
10.11.2016 passed by a Co-ordinate Bench of this Court.
For the reasons stated & grounds mentioned in the
application, this Court is inclined to restore the original
proceedings in S.B. Civil Restoration Application No.381/2015(d).
Accordingly, the restoration application is allowed and the
original proceedings in S.B. Civil Restoration Application
No.381/2015(d) is restored.
The application stands disposed of accordingly.
