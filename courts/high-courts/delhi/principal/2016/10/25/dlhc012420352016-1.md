LPA 560/2016
1. By the order under appeal dated 17.08.2016, W.P.(C) No.8402/2015
was dismissed in default for non-prosecution.
2. We are, therefore, of the view that the proper course would be to file
an application before the learned Single Judge for recalling the order dated
17.08.2016.
3. Accordingly, granting leave and liberty to the appellant to move an
appropriate application in the writ petition, the appeal is disposed of.
4. If any such application is filed, we request the learned Single Judge to
consider and decide the same in accordance with law.
