# High Court of Rajasthan, CRLMA/178/2016, 2016-07-26

S.B. CRIL. MISC. APPLICATION NO.178/2016
IN
S.B. CRIMINAL BAIL APPLICATION NO.14541/2015
Date of Order : 26th July, 2016
HON'BLE MR. JUSTICE M.N.BHANDARI
Mr.Abhimanyu Singh for Mr.PS Sirohi, for the applicant(s).
Mr.Sudesh Saini, Public Prosecutor – for the State.
An application has been filed for correction in the
order dated 05th May, 2016.
It is stated that due to typographical error, in the
order dated 05th May, 2016, name of the accused-applicant has
been mentioned as Bharalal @ Bhartya instead of Bharatlal @
Bhartya. Accordingly, necessary correction may be permitted.
In view of the above, the application for seeking
correction in the order dated 05th May, 2016 is allowed. In the
order dated 05
th May, 2016, name of the accused-applicant be read
Bharatlal @ Bhartya instead of Bharalal @ Bhartya.
This order be treated as part and parcel of the order
dated 05th May, 2016.
(M.N.BHANDARI), J.
S/No.41
Preeti, P.A.
