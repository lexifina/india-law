ORDER:
1) The application is filed to set aside the order
made by learned Registrar (Judicial) by which the
Registration is refused. In view of the contentions made in
the application and the submissions made the application
is allowed. The order of the learned Registrar (Judicial) is
set aside. The condonation of delay of 37 days caused in
filing proceeding is condoned.

is not removed prior to that date the matter will stand
dismissed automatically without back reference to this
