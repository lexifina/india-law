# High Court of Madhya Pradesh, MCC/223/2014, 2014-02-24

1
MCC No.223/2014
24/2/2014
 Shri Sharad Pandey, learned counsel for the
applicants.
This application has been filed for restoration of
W.P. No.20478/2013 which was dismissed for want of
prosecution on 20.1.2014.
Keeping in view the reasons indicated in the
application, the restoration application is allowed. Writ
petition be restored in its original file and it be placed for
orders before the appropriate Bench.
Accordingly, this application stands allowed and
disposed of.
