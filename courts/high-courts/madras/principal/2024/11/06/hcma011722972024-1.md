# Madras High Court, A/4765/2024, 2024-11-06

A.No.4765 of 2024 in C.S. (Comm.Div.) No.63 of 2024
ABDUL QUDDHOSE,J.
This application has been filed by the plaintiff seeking leave of this Court to
file reply statement to the written statement filed by the first defendant.
2.Learned counsel for the first respondent/first defendant has also not raised
any serious objection for allowing this application.
3.This Court is satisfied with the reasons contained in the affidavit filed in
support of this application as sufficient cause has been shown.
4.Accordingly, this application is allowed as prayed for and the reply
statement filed by the plaintiff to the written statement filed by the first defendant
is taken on record.
5.Since the learned counsel for the first respondent/first defendant is not
ready to argue the Interlocutory Applications, at the request of learned counsel for
the first respondent/first defendant, post the matter for arguments in Interlocutory
Applications on 13.11.2024.
