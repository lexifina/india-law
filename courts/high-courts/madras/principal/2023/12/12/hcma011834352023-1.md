# Madras High Court, A/5980/2023, 2023-12-12

Application No.5980 of 2023
in
C.S.(Comm.Div.)No.113 of 2021
ABDUL QUDDHOSE,J.
This application has been filed to
restore the suit, which was dismissed for
default by order of this Court dated
20.09.2023 in C.S.(Comm.Div.)No.113 of
2021.
The learned counsel for the
respondent/defendant has not raised
serious objection for allowing this
application.
This Court is also satisfied with the
reasons contained in the affidavit filed in
support of this application as sufficient
cause has been shown. Accordingly, this
application is allowed as prayed for and the
suit in C.S.(Comm.Div.)No.113 of 2021 is
restored to the file of this Court.
Post the matter for Case
Management Hearing on 22.12.2023.
