On the earlier occasions this Court had made it known to the
learned Counsel for the Petitioner that the Petitioner would have to file a
separate Petitions for each of the Applications under section 14 of the
SARFAESI Act listed in Exh.A to the Petition.
2. Learned Counsel for the Petitioner fairly states that no instructions
are forthcoming from the Petitioner.
3. In the circumstances, we dismiss the Petition. It will be open for the
Petitioner to file separate Petitions for each of the Applications, if so
advised.
