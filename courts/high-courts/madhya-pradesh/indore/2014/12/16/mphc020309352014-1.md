# High Court of Madhya Pradesh, MCRC/10269/2014, 2014-12-16

M.Cr.C. No.10269/2014
16.12.2014
Shri Sanjay Sharma, learned counsel for the applicant.
Shri R. S. Parmar, learned Panel Lawyer for the non-applicant/State.
Heard.
This is an application under Section 482 of the Cr.P.C.
for correction of crime number.
It is submitted that inadvertently, wrong crime number
has been typed in M.Cr.C. No.5607/2014 whereas, the
correct number is Crime No.374/2014.
On due consideration of the aforesaid, prayer for
correction is allowed. Accordingly, in the order dated
04.12.2014 in place of “Crime No.377/2012”, it should be
read as “Crime No.374/2014”. This order shall be read
conjointly with the order dated 04.12.2014 passed in M.Cr.C.
No.5607/2014.
With the aforesaid observation, this petition is disposed
of.
(P. K. Jaiswal)
 Judge
