ORAL ORDER
Learned APP states at bar that charge sheet is filed
on 23.07.2019 before the competent Court. In light of this
position, the applicant is at liberty to file discharge application
and also to file appropriate proceedings either u/s 397 or 482
of the Code of Criminal Procedure, 1973 before appropriate
competent Court, after remedy to file discharge application is
availed. The present application stands disposed of with above
liberty.
It is clarified that this Court has not examined the
merits of the present application.
