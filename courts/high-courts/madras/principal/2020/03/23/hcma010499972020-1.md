# Madras High Court, CRL OP/6710/2020, 2020-03-23

IN THE HIGH COURT OF JUDICATURE AT MADRAS
DATED: 23.03.2020
CORAM
THE HONOURABLE MR. JUSTICE G.K.ILANTHIRAIYAN
Crl.O.P.No.6710 of 2020
M.Sankar .. Petitioner/Defacto complainant
Vs.
The Inspector of Police,
W-27, All Women Police Station,
Vadapalani,
Chennai.(Crime No.19/19).. Respondent
Prayer : Criminal Original Petition is filed under Section 482
of the Code of Criminal Procedure, to direct the respondent
police to complete the investigation and to file a final
report within a time frame in a case in Crime No.19 of 2019
pending on the file of the respondent police.
For Petitioner : Mr.P.Nagaraju
For Respondent : Mr.M.Mohamed Riyaz,
 Additional Public Prosecutor
ORDER
This criminal original petition has been filed to direct
the respondent police to complete the investigation and to
file a final report in Crime No.19 of 2019 pending on the file
of the respondent police within the time frame as fixed by
this Court.
2. Considering the limited request made by the
petitioner, this Court directs the respondent Police to
complete the investigation and file final report in Crime
No.19 of 2019 pending on the file of the respondent police
within a period of three months from the date of receipt of
copy of this order.
3. With the above direction, this Criminal Original
Petition is disposed of.
