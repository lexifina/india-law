# High Court of Madhya Pradesh, RP/403/2014, 2014-12-18

1
R.P. No.403/2014
18.12.2014
Shri Sanzay Zamindar, learned counsel for the petitioners.
Ms. Vinita Phaye, learned counsel for the
respondent/State.
Heard.
This review petition has been filed by the petitioners for
correction of the typographical error in the description of the
parties in the cause title in the order dated 3.12.2014 passed in
W.P. No.8738/2014(s).
Learned counsel appearing for the petitioner submits that
due to the typographical error, the description of the respondent
No.3 is shown as “Chief Executive Officer” whereas the correct
description is “Chief Municipal Officer”.
Counsel for the respondents has no objection to the said
typographical correction.
Keeping in view the aforesaid, review petition is allowed
and it is directed that in the order dated 3.12.2014 in W.P.
No.8738/2014(s), in the description of the respondent No.3
instead of “Chief Executive Officer” the proper description will be
read as “Chief Municipal Officer”.
The review petition is accordingly disposed of.
C.C. as per rules.

 (Prakash Shrivastava)
