Mr. M. Alam, learned counsel for the applicants/ writ petitioners. Also heard Mr. H.K.
Sharma, learned Standing Counsel for the APDCL.
This application has been filed for correction the name of the counsel which has been
wrongly recorded in the first line of the order dated 12.12.2018 in WP(C) No.8482/2018,
which reads as follows:
“Heard learned counsel for the petitioners. Also heard Mr. A. Alam, learned
counsel for the APDCL.”
It has been submitted that the correct names of the counsel for the parties would be as
follows:
“Heard Mr. M. Alam, learned counsel for the applicants/ writ petitioners. Also
heard Mr. H.K. Sharma, learned Standing Counsel for the APDCL.”
This application is allowed as not objected to and as it does not touch upon the merit of
the case.
 JUDGE
Comparing Assistant
