ORDER
02.06.2025
Heard learned counsel for the parties.
This Interlocutory Application has been filed seeking correction of the
order dated by order dated 05.03.2025 passed in Interlocutory Application
(Civil) no.317/2025. By order dated 05.03.2025 while allowing the prayer for
correction of the address of the respondent no.9, the Court had directed the
applicant to file the amended cause title reflecting the correct address of the
respondent no.9, namely, Smt. Misran Bibi. Learned counsel for the applicant
submits that respondent no.9 is not Smt. Misran Bibi but Smt. Jamila Bibi and it
is only to that extent the Interlocutory Application has been filed seeking
correction in the order dated 05.03.2025 passed in Interlocutory Application
(Civil) no.317/2025.
Prayer made is not objected to by the learned counsel for the
respondents.
Accordingly, after hearing the learned counsel for the parties and also
upon perusal of the pleadings available before this Court, it is seen that the
respondent no.9 ought to have been Smt. Jamila Bibi instead of Smt. Misran Bibi
in the order dated 05.03.2025 passed Interlocutory Application (Civil)
no.317/2025.
Accordingly, this Interlocutory Application stands allowed.
The respondent no.9 will be read as Smt. Jamila Bibi instead of Smt.
Misran Bibi as reflected in the order dated 05.03.2025 passed in Interlocutory

Page No.# 4/4
Application (Civil) no.317/2025.
The present Interlocutory Application stands disposed of in terms of the
above. The order passed today in this Interlocutory Application shall be read
together with the order dated 05.03.2025 passed in Interlocutory Application
(Civil) no.317/2025.
The amended cause title shall be filed by the applicant/writ petitioner
within 1 (one) week from today.
