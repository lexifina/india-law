HON'BLE MR. JUSTICE KULDEEP MATHUR
Order
24/01/2023
The present application has been filed seeking correction in
the order dated 23.01.2023, passed by this Court in S.B. Criminal
Misc. Bail Application No.557/2023 stating therein that due to
inadvertence, in the last para of the order aforesaid, name of the
petitioner and his father’s name have wrongly been mentioned as
“Laxman @ Lachha S/o Shri Mangi Lal”, whereas the same should
is “Laxman S/o Shri Nanda”.
For the reasons stated in the application, the same is allowed
and it is ordered that in the last para of the order dated
23.01.2023, passed in S.B. Criminal Misc. Bail Application, name
of petitioner be read as “Laxman S/o Shri Nanda” in place of
“Laxman @ Lachha S/o Shri Mangi Lal”.
(KULDEEP MATHUR),J
