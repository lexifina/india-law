# Allahabad High Court, A482/10649/2018, 2018-04-02

Court No. - 44
Case :- APPLICATION U/S 482 No. - 10649 of 2018
Applicant :- Sabir Ali And 4 Others
Opposite Party :- State Of U.P. And Another
Counsel for Applicant :- Rajesh Yadav
Counsel for Opposite Party :- G.A.
Hon'ble Rajeev Misra,J.
Heard Mr. Rajesh Yadav, learned counsel for the applicants and
the learned A.G.A. for the State.
This application has been filed challenging the summoning
order dated 15.1.2016 in the year 2016.
The laches in filing the present application have not been
explained in the affidavit accompanying the application.
Accordingly, the learned counsel for the applicants requests to
dismiss this application as not pressed with liberty to file a fresh
application giving better particulars and details. Prayer made
for is allowed. This application is dismissed as not pressed with
liberty to file a fresh application with better particulars and
details.
Certified copy of the impugned order be returned to the learned
counsel for the applicants after obtaining a photo copy of the
same, which may be kept on record.
Order Date :- 2.4.2018
HSM
