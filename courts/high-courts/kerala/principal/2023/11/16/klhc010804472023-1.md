ORDER
This is an application for anticipatory bail.
2. When this matter is taken up for consideration
today, learned Public Prosecutor, on instructions, would
submit that, as on date, no crime has been registered against
the petitioner at the Perumpadappu police station
[Malappuram District]. Therefore, this application for
anticipatory bail is only to be closed.
Taking into consideration the submission of the learned
Public Prosecutor, the bail application is closed. It is made
clear that if the petitioner’s presence is required in
connection with any complaint filed before the Perumpadappu
police station, the Station House Officer, Perumpadappu
police station [Malappuram district] shall issue a notice under
Section 41A of the Code of Criminal Procedure to the
petitioner.
