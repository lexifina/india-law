# High Court of Madhya Pradesh, WP/8176/2016, 2017-01-09

1
Writ Petition No.8176/2016
09.01.2017
Shri Akash Sharma, learned counsel for the
petitioners.
Heard on the question of admission.
O R D E R
By this writ petition, the petitioners are
challenging order dated 09.09.2016 (Annexure P/4),
whereby an application under Order 1 Rule 10 (2) read
with Section 151 of the Code of Civil Procedure, 1908
has been rejected.
2. It is not in dispute that in election petitions, the
provisions of Code of Civil Procedure, 1908 will not be
applicable.
3. Considering the aforesaid, learned Court below
has rightly rejected the application. No case to interfere
with the aforesaid order, as prayed for, is made out.
4. Writ Petition No.8176/2016 has no merit and is
accordingly dismissed.
 (P.K. Jaiswal)
 Judge
Pithawe RC
