# Allahabad High Court, WRIA/15337/2019, 2019-11-14

Court No. - 55
Case :- WRIT - A No. - 15337 of 2019
Petitioner :- C/M, Uchchattar Madhyamik Vidyalaya Barauli
Etah And Another
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Hritudhwaj Pratap Sahi,Samarath
Singh,Sankalp Narain
Counsel for Respondent :- C.S.C.,Sanjay Kumar Srivastava
Hon'ble Neeraj Tiwari,J.
Sri H.P. Sahi, learned counsel for the petitioners submitted that
State Government has issued order dated 31.10.2019 stopping
the recruitment process in all aided private schools which
required to be challenged, therefore, petition may be dismissed
with liberty to file fresh petition challenging the order dated
31.10.2019 along with other reliefs prayed in this petition, for
which Sri S.K. Srivastava, learned counsel for respondent No. 2
as well as learned standing counsel has no objection.
Accordingly, writ petition is dismissed as withdrawn with the
aforesaid liberty.
Order Date :- 14.11.2019
Sartaj
