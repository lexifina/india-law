 This application coming on this day before this court
for hearing the court made the following order:
Despite the respondents having been served with notice
in February 2017, the respondents have not filed any
counter.
2. This application has been filed seeking to set aside
the order dated 06.02.2017 dismissing the application in
A.No.6206 of 2016 for non-prosecution.
3. Considering the averments made in the affidavit
filed in support of the application, and the fact that the
counsel for the applicants was indisposed on 06.02.2017,
this application is allowed. The order of dismissal dated
06.02.2017 is set aside. The Application in A.No.6706 of
2016 is restored.
4. Post the Application in A.No.6706 of 2016 on
08.08.2019 for arguments.
