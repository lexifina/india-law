IA No. 24814/2015 (condonation of delay)
 Learned counsel for the plaintiff has submitted that he has no
objection if the application for condonation of delay is allowed.
 In view of the reasons stated in the application and no
objection, the application is allowed and the delay is condoned.
 The applications stands disposed of.
O.A. 471/2015 (against order dt. 11.08.2015)
After some hearing, parties have agreed that the order of Joint
Registrar dated 11.08.2015 on IA No. 12074/2015 to be set aside and
the application be put up before the District Court, where the suit has
been transferred for fresh hearing. Accordingly, order dated
11.08.2015, which is an ex parte order is hereby set aside. The
defendant is at liberty to file reply to this application within two
weeks and rejoinder thereto, if any, be filed within two weeks

thereafter.
 The matter be listed before District & Sessions Judge, Saket
Courts for assigning the same to the Court having jurisdiction for
09.03.2017.

 DEEPA SHARMA, J
