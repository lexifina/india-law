1. Heard learned counsel for both the sides.
2. Although this application is styled as an application
under Section 482 of the Code of Criminal Procedure read with
Article 215 of the Constitution of India, the learned counsel for the
applicant clarified that this is an application for review of the
order passed by this Court on 14.11.2011 in Criminal Application
No. 337/2011.
3. The review is sought on four grounds mentioned in
para nos. (A), (B), (C), (D) of the application. In fact all these
grounds were considered while dealing with the previous
application filed under Section 438 of the Code of Criminal
Procedure. The ground of illness of the applicant was also
considered. The case was considered on merits and it was held
that this is a case where custodial interrogation is necessary.
4. In that view of the matter, there is no substance in this
application. The application is, therefore, rejected.

2
At this stage, learned counsel for the applicant makes
oral request seeking time to surrender before Police.
Time to surrender before the Police is granted till
07.12.2011.
