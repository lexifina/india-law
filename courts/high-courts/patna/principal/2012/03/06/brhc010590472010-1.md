 ORAL ORDER

2. 06-03-2012 Learned counsel for the petitioner and learned
A.P.P. for the State are present.
In view of the proviso added to Section 372 of
the Code of Criminal Procedure, 1973 (hereinafter referred to
as the “Code”) by which appeal has been provided against an
order of acquittal, learned counsel for the petitioner prays for
and is granted six weeks time to convert the present revision
application into appeal under Section 372 of the code.
If the present application is converted into
appeal under Section 372 of the Code within six weeks from
today, the same shall be deemed to have been filed within
time.
Anand Kr.
