ORDER
This Criminal Miscellaneous Case is filed with following
prayers:
i. This Hon’ble Court may be pleased to quash
Annexure E order to the extent it did not
order release of gold ornaments specified in T-281/2021 and T-291/2021.
ii. To allow Annexure B petition as prayed for by
passing order of release of gold ornaments
specified in T-281/2021 and T-291/2021.
iii. To grant such other reliefs as this Hon’ble
Court deems fit in the peculiar facts and
circumstances of this case.
2. Petitioner filed an application under Section 451 of
the Code of Criminal Procedure to release certain gold articles
before the Judicial First Class Magistrate Court, Njarakkal. As
per Annexure-E order, except the items specified as
T.No.281/21 and T.No.291/21, all other gold articles were
released by the learned Magistrate. The reason for not

CrlM.C..No.1966/2022
3
releasing T.No.281/21 and T.No.291/21 was that the same is
not identified by the customers. Now the Public Prosecutor
submitted that as far as these items are also concerned, the
customers already identified the items.
3. If that be the case, the petitioner can file a fresh
petition to release the gold articles specified as T.No.281/21
and T.No.291/21, and if such an application is filed, the
learned Magistrate can be directed to consider the same in
the light of the above submission of the Public Prosecutor.
Therefore, this Criminal Miscellaneous Case is disposed
of in the following manner:
1. The petitioner is free to submit a fresh
application under Section 451 of the Code of
Criminal Procedure to release the gold
articles specified as T.No.281/21 and
T.No.291/21, before the Judicial First Class
Magistrate Court, Njarakkal, with prior notice
to the Prosecutor concerned, within two
weeks from the date of receipt of a copy of
this order.
2. If such an application is filed, the learned

of the observations in this order, as
