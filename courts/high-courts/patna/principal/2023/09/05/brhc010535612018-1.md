This application is dismissed as withdrawn with
liberty as prayed for, in case, any question of mediation arises
for consideration before the District Teacher Appellate Tribunal,
the same will be considered keeping in view that the petitioners
have filed this writ application as back as on 29.08.2018 which
has remained pending with this Court for all this time.
This application stands disposed of.
