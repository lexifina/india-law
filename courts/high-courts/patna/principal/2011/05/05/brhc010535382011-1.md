# Patna High Court, CWJC/3913/2011, 2011-05-05

IN THE HIGH COURT OF JUDICATURE AT PATNA
 CWJC No.3913 of 2011
 SITARAM MEHTA
 Versus
 THE STATE OF BIHAR & ORS
 -----------
03. 05.05.2011 Heard learned counsels for both the parties.
The order impugned has been passed on
misconceived reading of the application moved by the
petitioner for adoption of the written statement already
on record. Therefore, the order dated 01.09.2009 is set
aside. The application of the petitioner is allowed to
adopt the W.S. of defendant No.2.
 Mkr. ( Prakash Chandra Verma, J. )
