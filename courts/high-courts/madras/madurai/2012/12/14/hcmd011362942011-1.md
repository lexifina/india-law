and

Merline Selva Sundari : Respondent/Petitioner
 Criminal Original Petition filed under section 482 of the Code of

on the file of the Judicial Magistrate No.I, Thoothukudi.
For Petitioner : No appearance
For respondent : Mr.G.R.Edmand
ORDER
The petitioner has filed this petition, seeking to quash the
proceedings in W.C.No.10 of 2011 on the file of the Judicial Magistrate
No.I, Tuticorin.
2. This petition is pending before this Court from the year 2011. So
far this petition has not been admitted. There is no representation on
behalf of the petitioner. Learned Counsel for the respondent is present.
This Court perused the grounds raised in the quash petition. No valid
ground is raised to quash the proceedings. Hence, this petition is
dismissed. Consequently, connected miscellaneous petition is also
dismissed.
