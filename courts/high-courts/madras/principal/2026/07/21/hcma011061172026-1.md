ORDER
This application has been filed to condone the delay of 890 days in filing
application to set aside exparte order made against the D1 in C.S.No.638 of 2018
dated 20/11/2020.
2. It is submitted by the learned counsel for the applicant that since he was
set exparte, there has been a considerable delay in filing the petition to set aside the
exparte decree and the delay is neither wilful nor wanton and sought for allowing
this application.
3.On the other hand, learned counsel for the respondents have strongly
opposed for allowing this application.
