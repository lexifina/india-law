JUDGMENT
Ext. P2 application put in for permission for private sale
was dismissed by the execution court by Ext. P3 order. But Ext.
P3 order was set aside by Ext. P4 judgment in O.P.(C). No.
200/2013 observing as follows:-
“But, permission for private sale could be granted under Rule
83 of Order XXI of the Code only after an order for sale of
immovable property is made. Here, no such order is passed by
the learned Sub Judge. Therefore, Ext. P2, application was
premature. Ext. P2, application ought to have been kept
pending to be considered after an order for sale of the property
was passed.”
2. Now the execution court has ordered the property to
be sold after settling the proclamation and fixing the upset price.
This has been done by order dated 26.02.2014 in E.P. No.
46/2012 in O.S. No. 17/2010. It is time now for the execution
court to consider Ext. P2 application since order for sale has
already been passed as stated above.
3. I direct the Court of the Subordinate Judge of
Perumbavoor to consider Ext. P2 application (E.A. No. 150/2012)

O.P.(C) No. 869 of 2014 2
in E.P. No. 46/2012 on or before 31.05.2014. The property shall
be proclaimed for sale only after orders are passed in E.A. No.
150/2012 as directed in Ext. P4 judgment.
The Original Petition is disposed of.
V.CHITAMBARESH
