1. Heard the learned Counsel for the Applicant and
the learned Counsel for the Respondents.
2. This is an application for restoration which was
dismissed for default on 15.12.2008. There is delay in
filing the application. The said application has
vehemently opposed by the learned Counsel for the
Respondents.

1
3. For the reasons stated in paragraph No.6, the
delay caused in filing the applciation is condoned.
On the same ground, the reasons given by the Applicant
for not remaining present before this Court is also
accepted. The order dated 15.12.2008 is recalled and
application is restored to the file.
4. Application is allowed and disposed of.
