HARNARESH SINGH GILL, J.(Oral)
Challenge is to the order dated 27.02.2023 passed by the
learned trial Court, vide which the application filed by the petitioner
seeking default bail under Section 167(2) Cr.P.C. was dismissed.
On 24.04.2023, a Coordinate Bench of this Court, has passed
the following order:-
'After arguing for sometime, learned counsel for
the petitioner prays for an adjournment to prepare on
the aspect as to whether the prayer made in the
instant revision petition with regard to the quashing of
order dated 10.02.2023, vide which extension of time
was granted by the Court below is maintainable along
with the revision petition, wherein default bail under
Section 167(2) has been sought.
Adjourned to 03.05.2023'.
Learned counsel for the petitioner submits that the order
under challenge is an interlocutory one and thus, revision petition qua the
same is maintainable. He further submits that on 02.02.2023, an

I have heard the learned counsel for the parties.
As noticed above, the FSL report was to be filed by
12.02.2023. However, on 02.02.2023, an application for extension of
time to file the FSL report was moved by the learned Public Prosecutor
along with the report of the Public Prosecutor. The said application was
allowed on 10.02.2023 enabling the prosecution to file the FSL report
within extended period of three months starting from 12.02.2023.
The petitioner moved the application seeking default bail on
24.02.2023 i.e. after the date on which the period for filing the FSL report
was extended.
In view of the above, no ground is made out to set aside the
order impugned herein.
Dismissed.
