# Allahabad High Court, FAFOD/498/2003, 2018-02-28

Court No. - 38
Case :- FIRST APPEAL FROM ORDER DEFECTIVE No. - 498 of 2003
Appellant :- Mohammad Suleman
Respondent :- U.P.State Road Transport Corporation Lucknow & Others
Counsel for Appellant :- Tripurari Sharan Shukla
Hon'ble Ran Vijai Singh,J.
Hon'ble Mukhtar Ahmad,J.
Delay Condonation Application No. 95842 of 2003 is
taken up for orders:
We have seen the Office report dated 27.02.2018.
This application was rejected on 28.08.2003 with a liberty
to the learned counsel for the appellant to file a fresh
application. From the perusal of the record, it transpires
that no fresh application has been filed along with
supporting affidavit to condone the delay in filing the
appeal.
In view of the fact that the delay condonation application
has already been rejected, the appeal is dismissed as
barred by time.
Order Date :- 28.2.2018
Amit Mishra
