# Allahabad High Court, WRIC/6323/2020, 2020-02-27

Court No. - 33
Case :- WRIT - C No. - 6323 of 2020
Petitioner :- Anil Kumar
Respondent :- State Of U.P. And 4 Others
Counsel for Petitioner :- Shiv Shankar Pd Gupta
Counsel for Respondent :- C.S.C.,Amaresh Yadava
Hon'ble Dr. Kaushal Jayendra Thaker,J.

Learned counsel for the petitioner very frankly states that order
which is impugned was reviewed thereafter similar order was
passed. The State wants to file a reply. The petitioner may file a
fresh petition challenging the same with this liberty this writ

withdrawn at this stage with liberty to challenge the new order.
