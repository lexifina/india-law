As per affidavit-in-reply of State investigation is complete.
However, no chargesheet could be filed as per order of this court
dated 15.2.2018 by which prosecution is directed to not to file the
chargesheet. As such, it is found that the investigation is complete.
In that view of the matter, learned counsel for the applicants
seeks leave to withdraw the application with liberty to file discharge
application before the trial court.
In view of above statement, we recall order dated
15.2.2018. Prosecution is thus to file chargesheet before the
competent court.
Application stands disposed of as allowed to be withdrawn
with liberty to file application for discharge as aforesaid.
