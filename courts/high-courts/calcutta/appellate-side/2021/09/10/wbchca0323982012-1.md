# Calcutta High Court, CRR/2276/2012, 2021-09-10

90
 10-09-2021
 ct. no.34
 debajyoti
 CRR 2276 of 2012
In re: An application under Section 482 read with Section
401 of the Code of Criminal Procedure.
 - And -
 In the matter of: Mr. Dinesh Gupta
 … Petitioner.
The present revisional application was preferred
challenging the proceedings pending before the learned
Metropolitan Magistrate, 16th Court, Kolkata in Complaint
Case No.1974 of 2012 under Section 138 of the Negotiable
Instruments Act. Records of the present revisional
application reflect that the impugned order, which was
granted, was extended till 07th June, 2013. No information
has been furnished before this Court regarding the present
stage of the proceedings. Further, the contentions advanced
in the revisional application are based on foundation of facts
which are to be agitated in course of the trial. As such, no
interference is called for.
Accordingly, CRR 2276 of 2012 is dismissed. Pending
application, if any, is consequently disposed of. Interim
order, if any, stands vacated.
All parties shall act on the server copies of this order
duly downloaded from the official website of this Court.
 ( Tirthankar Ghosh, J. )
