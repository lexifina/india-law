1] Learned counsel for the petitioners seeks liberty to
withdraw this petition with further liberty to file
application for discharge before the trial Court.
2] The petition is dismissed as withdrawn with liberty
as prayed for. However, we make it clear that in case
charge is framed, there is no question of liberty to file
the application for discharge. In case, charge is not
yet framed, if the petitioners file application for
