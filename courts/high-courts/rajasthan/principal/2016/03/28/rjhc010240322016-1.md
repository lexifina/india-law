# High Court of Rajasthan, CRLMB/1826/2016, 2016-03-28

S.B. CR. MISC. BAIL APPLICATION NO.1826/2016
Bhagchand V/S State of Rajasthan
Date of order : 28.03.2016
HON'BLE MR. JUSTICE VIJAY BISHNOI
Ms Deepika Choudhary, for petitioner.
Mr Deepak Choudhary, Public Prosecutor.
Mr Narpat Singh, for the complainant.
Learned counsel for the petitioner, without
arguing on merits, has submitted that he does
not want to press this criminal misc.
anticipatory bail application, however, seeks
liberty for the petitioner to file fresh
anticipatory bail application before the
Sessions Court.
Accordingly, this criminal misc.
anticipatory bail application preferred by the
petitioner under Section 438 Cr.P.C. is
dismissed as not pressed with the liberty as
prayed for.
[VIJAY BISHNOI],J.
