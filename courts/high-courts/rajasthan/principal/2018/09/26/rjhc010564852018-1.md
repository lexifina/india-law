Order
26/09/2018
Matter comes up on an application for re-constituting file of
Civil First Appeal No.345/2013, which is not traceable in office.
A search slip was also issued for tracing out the file but in
vain. Since issuance of the search slip, three months have passed
and so far despite making efforts the file has not been traced out.
In this view of the matter, application is allowed and file of
Civil First Appeal No.345/2013 is ordered to be reconstituted.
