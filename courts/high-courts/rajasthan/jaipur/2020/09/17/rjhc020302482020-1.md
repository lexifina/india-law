Judgment / Order
17/09/2020
1. Matter comes upon an application filed by the applicant for
correction in order dated 02.06.2020.
2. It is contended by counsel for the applicant that in order
dated 02.06.2020 in para 5, it is mentioned that no charge-sheet
has been filed, whereas in fact charge-sheet has been filed and
the same was available on record at the time of passing of the
order dated 02.06.2020. It is also contended that in para 5 in last
line, it is mentioned that Polygraph and Narco test was not
conducted, whereas, Polygraph test has been conducted and only
Narco test has not been conducted.
3. I have considered the contentions.

(2 of 2) [CRLMA-137/2020]
4. Considering the contentions of counsel for the applicant,
application is allowed.
5. In para 5 in first line word ‘no’ stands deleted. Similarly in
para 5 in last line word ‘Polygraph and’ also stands deleted. Order
dated 02.06.2020 stands modified, accordingly.
(PANKAJ BHANDARI),J
