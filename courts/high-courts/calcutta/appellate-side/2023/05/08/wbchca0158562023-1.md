# Calcutta High Court, CO/1049/2023, 2023-05-08

08.05.2023
 712
 Naren
 Ct.237
 C.O. 1049 of 2023

 Sajal Kumar Guha.
Vs.
 Dayanand Arya.
 Mr. Tarak Nath Halder … for the petitioner.
This revisional application has been filed with a
prayer for early disposal of an application under Order VI
Rule 17 of the Code of Civil Procedure, 1908, which is
pending since 2nd June, 2022.
No notice is required to be served upon the
opposite party. Thus, service of notice is dispensed with.
Learned Civil Judge (Junior Division), 2nd
Court, Sealdah is requested to dispose of the application
under Order VI Rule 17 of the Code of Civil Procedure,
1908 within a period of four weeks from the date of
communication of this order and to proceed with the suit
thereafter without giving any unnecessary adjournment to
either of the parties.
Learned Advocate appearing for the petitioner is
at liberty to communicate the order to the learned Trial
Judge.

With the aforesaid observation, this revisional
application stands disposed of.
All parties shall act on the server copies of this
order duly downloaded from the official website of this
Hon’ble Court.

 (Bibhas Ranjan De, J.)
