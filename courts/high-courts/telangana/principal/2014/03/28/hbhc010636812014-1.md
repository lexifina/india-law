# High Court for the State of Telangana, CRP/469/2014, 2014-03-28

THE HON’BLE SRI JUSTICE K.C.BHANU
CIVIL REVISION PETITION No.469 OF 2014
ORDER:
Learned counsel for the petitioner seeks permission to withdraw the Civil Revision
Petition with liberty to file appeal as the impugned order is appeable order.
Permission is accorded.
Accordingly, the Civil Revision Petition is dismissed as withdrawn. Registry is
directed to return the original documents to the counsel for the petitioner to enable
him to file appeal. There shall be no order as to costs. Miscellaneous petitions, if
any, pending in this Civil Revision Petition shall stand closed.

K.C.BHANU, J
