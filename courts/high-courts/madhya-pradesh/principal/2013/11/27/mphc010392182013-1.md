# High Court of Madhya Pradesh, MCC/1060/2013, 2013-11-27

MCC. No.1060/2013
27/11/2013 :
Shri S. K. Singh Singh, learned counsel for the applicant.
This application has been filed for restoration of W.P.
No.20026/2011 which was dismissed due to non compliance of the
peremptory order on 17.1.2012. There being some delay in filing the
application I.A. No.9813/2013 has been filed seeking condonation of
delay. Application is supported by an affidavit of applicant himself and
there is no reason to disbelieve the same. Finding the same to be
bonafide, both the applications are allowed. Condoning the application
in filing the application, the restoration application itself is allowed. Writ
Petition is restored to its original number. It be placed for orders before
the appropriate Bench.
Application stands allowed and disposed of.
 (RAJENDRA MENON)
