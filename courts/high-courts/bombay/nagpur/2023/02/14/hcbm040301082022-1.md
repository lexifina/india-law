 Heard.
2. The petitioner a convict seeks to quash and set
aside the order dated 16.11.2022 passed by the Divisional
Commissioner, Nagpur rejecting regular parole for 30 days
for medical treatment. It emerges that earlier the
petitioner has applied for regular parole which was
granted by the Authority on 29.08.2022. However, later
on rejected on 16.11.2022 which is impugned herein.
3. The State has brought to the notice that already
on 26.08.2022, the petitioner was released on furlough
leave from which he returned on 24.09.2022. Thus, it is
apparent that when the petitioner’s parole application was
allowed on 29.08.2022, already he was on furlough leave,
therefore, if still subsequent cause arose or any emergent
medical situation, the petitioner has to apply fresh.
4. In view of above, petition stands disposed of with
liberty to the petitioner to file fresh application, if
