# High Court of Madhya Pradesh, MCC/1018/2017, 2017-05-02

MCC-1018-2017
(BIHARI SINGH Vs THE STATE OF MADHYA PRADESH)
02-05-2017
Shri V.D.S. Chauhan, learned counsel for the applicant.
This application has been filed for restoration of W.P. No.15814/2010
which has been dismissed for want of prosecution on 09.03.2017. The
application is supported by an affidavit of Advocate-Shri V.D.S.
Chauhan.
Keeping in view the reasons indicated in the application, the MCC is
allowed and it is directed that W.P. No.15814/2010 be restored to its
original number and list this case before the appropriate Bench.
Let a copy of this order be kept in the file of W.P. No.15814/2010.
(SMT. ANJULI PALO)
JUDGE
