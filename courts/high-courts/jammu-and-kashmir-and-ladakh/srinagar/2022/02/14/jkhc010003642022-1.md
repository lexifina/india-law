 Learned counsel for the petitioner seeks withdrawal of the instant
writ petition with liberty to file fresh one if cause survives.
 This petition is, accordingly, dismissed as withdrawn with liberty
to file the fresh one, provided the genesis or the cause of action is not
already a subject-matter of consideration before this Court in any other
petition. The petitioner would be at liberty to amend the previous petitions if
there is any subsequent development in regard to a cause of action, which
already has arisen.
