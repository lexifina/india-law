# Gauhati High Court, I.A./1319/2016, 2017-03-21

I.A. 1319/2016
BEFORE
HON’BLE MR. JUSTICE KALYAN RAI SURANA
Heard Mr. K. Kalita, learned counsel for the applicant.
By filing this application, the applicant has prayed for restoration of CRP 325/
2010, which was dismissed for default by order dated 18.12.2015.
This Court by an order passed today in connection with I.A. 1320/2016 has condon
ed the delay in filing the application for restoration.
On the same grounds, this Court is inclined to restore the connected CRP 325/201
0 to file.
The I.A. stands disposed of.
