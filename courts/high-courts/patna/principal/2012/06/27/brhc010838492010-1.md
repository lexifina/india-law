CORAM: HONOURABLE MR. JUSTICE SHAILESH KUMAR SINHA
ORAL ORDER
3 27-06-2012 Heard learned counsel for the petitioner and the opposite
parties.
Learned counsel appearing for the State submits that a
show cause has been filed annexing a copy of the reasoned order vide
Memo No.259 dated 24th of February, 2012, as contained in Annexure
G to the show cause and as such, since the order of this Court has been
complied with by passing a reasoned order on the representation filed
by the petitioner, the contempt application need not proceed.
Learned counsel for the petitioner submits that the
aforesaid order is not correct and as such, the petitioner proposes to
assail the same before an appropriate forum.
Considering the submissions of the learned counsel for
the parties, this contempt application need not proceed further. The
same stands disposed of.
 PNM
(Shailesh Kumar Sinha, J)
