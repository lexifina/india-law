This petition coming on for conciliation this day, the Bench passed the
following:
ORDER
This petition is filed challenging the order of dated 27.11.2022.
Indeed, the impugned order was stayed by this Court on 06.12.2022.
Meaning thereby, the impugned order has not been given effect to, although
reply of the State has been filed.
Under such circumstances, rather to keep the matter pending, we dispose
of this petition. Accordingly, the impugned order is set aside. The respondents
are set at liberty to fresh order, if occasion so arises.
Petition stands disposed of.
