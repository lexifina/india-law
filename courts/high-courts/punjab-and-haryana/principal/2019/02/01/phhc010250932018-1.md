RAMENDRA JAIN, J. (ORAL)
Proxy counsel for the petitioner prays for adjournment on the
ground that arguing counsel is in some personal difficulty. However, the
same is not justified, considering the earlier interlocutory orders which
are detailed herein.
This petition for the first time was taken on Board on
03.04.2018. Thereafter, the same is taken on Board for six times,
excluding the said date. Meaning thereby, this case has been taken up on
Board for seven times. Every time a request for adjournment has been
made for the reasons best known to learned counsel for the petitioners.
Such type of repeated requests for adjournment have flooded this Court
with lakhs of cases for no rhyme or reason, whatsoever.
Therefore, finding no genuineness in the request for
adjournment, the instant petition is dismissed.
