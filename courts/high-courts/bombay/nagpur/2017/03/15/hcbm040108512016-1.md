ORAL ORDER
By the present petition, the petitioner challenges the order dated 4th
October, 2014, passed by Judicial Magistrate First Class, Umrer, thereby
rejecting applications Exh.38 and 44, in Regular Criminal Case No.101 of
2010.
2. So far as application Exh.38 for re-calling of P.W. Nos.4, 10, 12 and
13 for re-examination is concerned, in my opinion, the learned Magistrate
has rightly rejected the same, as the contention of the respondents is
accepted that the said witnesses were summoned only for the purpose of

 criwp304.16
(2)
filling in the lacunae.
3. So far as application Exh.44 is concerned, in my opinion, the same
should have been allowed, which is for the purpose of re-calling P.W.5 for
his re-examination, particularly in the backdrop of the document viz. the
written statement which is sought to be proved in the present proceedings
which was filed in Regular Civil Suit No.33 of 2012.
4. In view thereof, in my opinion, the present petition needs to be
allowed only to the extent of application Exh.44. Thus, the following order :-
The order dated 4th October, 2014, passed by Judicial Magistrate
First Class, Umrer, rejecting application Exh. 44, in Regular Criminal Case
No.101 of 2010, is hereby quashed and set aside.
 Application Exh.44 stands allowed.
The order dated 4th October, 2014, passed by Judicial Magistrate
First Class, Umrer, rejecting application Exh.38 stands confirmed.
Criminal Writ Petition stands disposed of accordingly.
 (N.W. SAMBRE, J.)
