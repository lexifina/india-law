# High Court of Madhya Pradesh, MCRC/18180/2016, 2016-10-21

MCRC-18180-2016
(GHANSU Vs THE STATE OF MADHYA PRADESH)
21-10-2016
Km. Savita Choudhary, learned counsel for the applicant.
Shri Vivek Lakhera, learned PL for the respondent/State.
Heard.
This application has been filed for modification of
typographical error in the order dated 23.09.2016 passed in
Criminal Appeal No.1208/2005.
In the aforesaid order CJM Satna has been mentioned,
however, the competent Court is CJM, Chhindwara.
In this view of the matter, the application is allowed. Where
in the order dated 23.09.2016 it has been mentioned 'CJM Satna'
it be read as 'CJM Chhindwara'.
C.C. as per rules.
(S.K. GANGELE)
JUDGE
(H.P. SINGH)
