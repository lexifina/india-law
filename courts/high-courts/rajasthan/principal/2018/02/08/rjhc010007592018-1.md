Judgment / Order
08/02/2018
1. Application for correction in the order dated 10.10.2017
passed by this Court has been moved.
2. It is contended by counsel for the petitioner that in the
second last line of para 10 of order dated 10.10.2017,
“respondent No.2” has been erroneously mentioned, whereas it
should have been “petitioner”.
3. I have considered the contentions of counsel for the
petitioner and taking note of the typographical error, in the second
last line of para 10 of order dated 10.10.2017 passed by this
Court “respondent No.2” be read as “petitioner”.
4. Application for correction is, accordingly, allowed.
(PANKAJ BHANDARI), J.
