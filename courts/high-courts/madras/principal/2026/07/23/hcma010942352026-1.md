ORDER
This Criminal Original Petition is filed to set aside the docket order dated
15.04.2026 against the petitioner.
2. It can be seen that the petitioners are accused in S.T.C.No.109 of 2026
on the file of the learned Judicial Magistrate, Fast Track Magisterial Court
No.1, Erode. Since the petitioners even after service did not appear, the Trial
Court issued a bailable warrant. Therefore, no Criminal Original Petition can be
entertained as against the said order. The Trial Court is fully justified in issuing
the bailable warrant. However, considering the age of the petitioners, let them
appear on the next hearing date, which is stated to be 06.08.2026 and file a
recall application before the same Court. The same shall be considered on the
same day by the Trial Court based on the web copy of this order. Accordingly,
this Criminal Original Petition is disposed of. Consequently, connected
miscellaneous petition is closed.
