O R D E R
Annexure-3 order is being challenged by the petitioner
seeking intervention of this Court invoking the power under
Section 482 of the Code of Criminal Procedure.
2. Petitioner is the accused in C.C.No.1913/2011 pending
before the Judicial First Class Magistrate Court-II, Kochi. He
was charge sheeted by the 1
st respondent alleging the offences
under Sections 419,468,471 of the Indian penal Code and
Section 12(1)(b) and (d) of the Passport Act. He filed an
application for discharge as C.M.P.No.3055/13 and that was
dismissed by the learned Magistrate by Annexure-3 order,
which is being challenged by the petitioner under Section 482
of the Code of Criminal procedure.
3. When this petition comes up for admission, the
learned Public Prosecutor submitted that only revision will lie
against an order of discharge. If that be the case, no application
under Section 482 of the Code of Criminal procedure can be
entertained. The dismissal of application for discharge is a

Crl.M.C.No.1441 of 2014 2
revisable order as it cannot be said that it is an interlocutory
order against which no revision will lie. It is settled law that it is
an intermediary order affecting the right of the accused and so
revision will lie against such order. So if statutory remedy of
revision is available, then this Court cannot invoke the power
under Section 482 of the Code of Criminal Procedure to quash
the order and the remedy of the petitioner is to file revision
against that order and the application is liable to be dismissed.
So the application is dismissed with liberty for the petitioner to
file revision before the appropriate forum.
