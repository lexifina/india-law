JUDGMENT
This original petition is filed aggrieved by an order in
dismissing the application to set aside an ex-parte award against the
petitioner in OP(MV)No.147/2006 on the file of Motor Accidents
Claims Tribunal, Neyyattinkara. The award was passed on
10.01.2013. Petitioner claims that he came to know about award
only when recovery proceeding were initiated. Thereafter, he filed
an application I.A.No.4322/2015 to set aside the ex-parte award.
This application was dismissed on 8.07.2018. Challenging this
order petitioner approached this Court. Petitioner's case is that he
was never served with a notice. The Tribunal observed from the
record that notice addressed to the petitioner was returned as
'unclaimed'. Accordingly, he was set ex-parte and an ex-parte award
was passed.
It is to be noted that the petitioner was an accused in criminal
case. He was found not guilty. The address in the criminal case as
