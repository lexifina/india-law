JUDGMENT
After arguing for sometime, the learned counsel
appearing for the petitioner submitted that the
petitioner seeks permission to withdraw this writ
petition with liberty to file it again because another
candidate already approached the Apex Court with an
SLP. The permission is granted. If that be the case, if
there is any fresh cause of action, the petitioner is free
to file a fresh writ petition.
Therefore, this Writ Petition is dismissed as
withdrawn by granting liberty to the petitioner to file a
fresh writ petition.
