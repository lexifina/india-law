# Madras High Court, A/445/2021, 2021-07-20

A.No.445 of 2021
N.SATHISH KUMAR, J.
This application has been filed for a direction to the respondents to
furnish security to the tune of Rs.3,64,095/- within the time fixed by this
Court and failing which the Order of attachment of the immovable
properties more fully described in the Judge's summons.
2. This Court by an Order dated 17.06.2021 directed the respondents
to furnish security for the claim amount.
3. Despite the Order of this Court directing to furnish security, the
respondents have not furnished any security and none appeared for the
respondents.
4. In view of the same, there shall be an Order of interim attachment
against the respondents. In the meanwhile, the applicant shall initiate
arbitration proceedings within three months, failing which, the interim
Order granted by this Court stands automatically vacated. The registry is
directed to communicate the Order of attachment to the concerned
Registrar.
5. With the above observation, this application is closed
