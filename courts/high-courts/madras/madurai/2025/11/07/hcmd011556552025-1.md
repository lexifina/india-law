 ORDER
 Heard both sides.
 2.The case on hand pertains to the assessment year 2022-2023.
The petitioner suffered the impugned assessment order which was passed
on 16.08.2023. The petitioner failed to file an appeal against the same.
In the meanwhile, for the same defect but for enhanced quantum, another
assessment order came to be passed on 29.08.2025. It is well settled that
for a defect occurring in a certain assessment year, only one assessment
order can be passed. There cannot be passing of a second assessment
order for the same defect.
 3.I therefore mold the relief and quash the second assessment
order passed on 29.08.2025. As regards, the order impugned in the writ
