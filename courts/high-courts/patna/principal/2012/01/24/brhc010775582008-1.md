3 24-01-2012 Heard learned counsel for the parties.
After some arguments, Mr. Uma Kant Shukla,
learned counsel for the petitioner, seeks permission to withdraw
this application in order to enable the petitioner to file an
appeal.
This application is, accordingly, permitted to be
withdrawn with the aforementioned liberty and it is made clear
that if the petitioner will file the appeal within a period of one
month from today, the same shall be disposed of on merit
instead of non-suiting the petitioner on the ground of
delay/limitation, if any.
