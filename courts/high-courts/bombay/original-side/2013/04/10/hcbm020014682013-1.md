1. A Judge's Order is taken out for refund of the amount
deposited by defendants 2 and 4 in compliance of the order dated
12th October, 2011 passed by this Court as modified by the Appeal
Court which has been set aside by the Supreme Court.
2. The application of the plaintiff that the order has not been set
aside by the Supreme Court has been dismissed. The order of the
Appeal Court is, therefore, set aside by the Supreme Court.
3. The order of this Court was two fold:
 (a) An order of the usual injunctions.
(b) An order of deposit per month.

4. The order of the Appeal Court which was by way of
modification, was also two fold.
(a) An order of the usual injunctions expecting the creation
of licence.
(b) An order of the deposit per month less taxes.
5. This Court's order merged in the Appeal Court order. The
Appeal Court order was set aside. Hence upon the doctrine of
merger this Court's order also would stand set aside.
6. It was contended by the plaintiff that it was not. That was
because the plaintiff contended that merely because the Appeal
Court order was set aside this Court's order cannot be deemed to be
set aside. The analogy given by the Counsel on behalf of the
plaintiff is that if this Court decrees the suit, the Appeal Court sets
aside the decree and the Supreme Court sets aside the appeal order,
the decree would not stand set aside. It would stand confirmed.
That is absolutely correct, but that does not call in the doctrine of
merger because the initial order has been reversed and the
reversing order is again reversed. When an initial order is not
reversed, but modified or confirmed the doctrine of merger would
certainly apply.
7. It is in view of this contention of the plaintiff that the plaintiff

was directed to get clarified from the Supreme Court whether the
ad-interim order of this Court dated 12th October, 2011 was
continued until the Notice of Motion was heard. That application
has also been dismissed. The plaintiff's contention that it was
continued, the Appeal Court order having been set aside
notwithstanding, has been dismissed. It is, therefore, not possible
to continue the ad-interim order. Consequently it is not possible to
call upon the defendants to continue to deposit each month and it
follows as a matter of corollary, therefore, that the amount
deposited must be allowed to be withdrawn as per the Judge's
Order which was the seminal application upon which this
contention has been raised.
8. In view thereof the Judge's Order is signed.
9. Upon the application of the plaintiff the Prothonotary and
Senior Master of this Court is directed not to refund the amounts
for two weeks.
