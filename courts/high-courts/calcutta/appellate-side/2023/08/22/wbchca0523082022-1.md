In Re: An application under Section 482 of the Code of Criminal

 Versus

 Mr. Indranuj Dutta.
 …for the petitioner.

Learned advocate appearing for the petitioner submits
that he has instructions not to proceed with the present revisional
application.
Written instructions submitted by the learned advocate
appearing for the petitioner be kept with the record.
Accordingly, CRR 4308 of 2022 is dismissed as not
pressed.
Pending application, if any, is consequently disposed of.
Petitioner would be at liberty to file afresh in case there
are change of circumstances.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
