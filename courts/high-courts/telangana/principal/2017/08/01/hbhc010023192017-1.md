# High Court for the State of Telangana, CRLP/6509/2017, 2017-08-01

HON’ BLE DR. JUSTICE B. SIVA SANKARA RAO
CRIMINAL PETITION No.6509 of 2017
ORDER:
 Learned counsel for the petitioner sought permission to
withdraw the case with any liberty with regard to the N.B.W.
pending against the petitioner/ A.5 in C.C.No.56 of 2014 on the
file of the Judicial First Class Magistrate at Chevella.
 Permission is accorded.
 The Criminal Petition is dismissed as withdrawn. It is left
open to the petitioner, so far as the N.B.W. pending, to appear
and file recall application for the learned Magistrate in such an
event to consider on the same day.
 Consequently, miscellaneous petitions, if any, pending in
this Criminal Petition, shall stand closed.
___________________________
JUSTICE Dr. B.SIVA SANKARA RAO
Date: 01.08.2017
