ORDER
This Criminal Revision is directed against the order passed in Crl.M.P.No.
617 of 2023 dated 27.03.2023 on the file of the Judicial Magistrate No.II,
Kodaikkanal, dismissing the petition filed under Section 451 Cr.P.C.
2. Admittedly, the petitioner has not filed any application before the
Sessions Court for return of the vehicle.
3. When the same was questioned, the learned counsel appearing for the
petitioner would submit that liberty may be given to the petitioner to file an
application for return of vehicle before the Sessions Court.
4. In view of the above, this Criminal Revision Petition is dismissed and
the petitioner is at liberty to file an application for return of vehicle in dispute
before the Sessions Court.
