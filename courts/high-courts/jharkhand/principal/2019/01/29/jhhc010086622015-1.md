04/29.01.2019. Heard learned counsel appearing for the petitioner and learned
Additional Public Prosecutor appearing for the State.
Learned counsel for the State has placed the order dated 11.05.2016
passed in G.R. No.282 of 2012 by the learned Chief Judicial Magistrate,
Lohardaga.
Vide order dated 02.03.2016 the State was directed to file counter-affidavit in this regard, but the same has not been done so far.
In view of the order dated 11.05.2016, the petitioner is ready to
withdraw this application so as to file an application before the court below.
Learned State counsel has no objection.
Considering the said submission, this application is dismissed, as
withdrawn.
However, the petitioner is at liberty to file an application before the
court below and the court below shall consider the same on its own merits
without being prejudiced by this order.
(Kailash Prasad Deo, J.)
