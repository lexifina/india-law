Judgment / Order
01/09/2021
1. Counsel for the applicant has moved this application under
Section 482 Cr.P.C. for correction in the order dated 06.07.2020.
2. It is contended by counsel for the applicant that in the
impugned order dated 06.07.2020 F.I.R. number is mentioned as
F.I.R. No.281/2020, whereas in fact it is F.I.R. No.281/2019.
3. Amended cause-title has been filed.
4. I have considered the contentions.
5. Considering the contentions of counsel for the applicant,
application for correction in the order dated 06.07.2020 is allowed
and in the impugned order dated 06.07.2020, “F.I.R. No.
281/2020” now be read as “F.I.R. No.281/2019”.

(2 of 2) [CRLMA-259/2021]
6. Amended cause-title is taken on record in the main bail
application.
