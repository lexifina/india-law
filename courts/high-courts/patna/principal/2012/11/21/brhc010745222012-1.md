CORAM: HONOURABLE MR. JUSTICE AKHILESH CHANDRA
ORAL ORDER
2 21-11-2012 Heard.
This is an application seeking restoration of
Cr. Misc. No. 30593 of 2010, an application under
Section 438 of the Code of Criminal Procedure, which
was dismissed for non-prosecution vide order dated
15.03.2012, in connection with Complaint Case No.
2324/2009, Tr. No. 2970/2010 pending before Sub-Divisional Judicial Magistrate, Vaishali at Hajipur.
Finding no reasonable ground to restore
this application to its original file, this application
stands dismissed. However, petitioner, if so wishes, is
at liberty to file fresh application under section 438 of
the Code of Criminal Procedure, in case, mandatory
requirement for the same is still available to him.
Rajeev/- (Akhilesh Chandra, J)
