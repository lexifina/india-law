ORDER
R. DEVDAS J., (ORAL):
 Sri.Jai.M.Patil, learned counsel undertakes to file vakalath
for respondent-Bank.
 The petitioner-partnership firm is aggrieved of the
impugned order dated 14.03.2022 passed by the Debts
Recovery Tribunal, Bengaluru, (DRT-2). Learned counsel for the
petitioner submits that by order dated 01.04.2021, the Tribunal
had permitted the petitioner to file written statement subject to
the petitioner depositing Rs.20,000/-. However, since the time
granted for compliance of the said order had expired, the
petitioner made one more application on 06.08.2021 to recall
the order dated 01.04.2021 and enable the petitioner to file

written statement. However, the Tribunal, by the impugned
order dated 14.03.2022 rejected the application stating that it
does not merit consideration. Learned counsel submits that in
the interest of justice, the petitioner should be permitted to file
a written statement and proceed with the matter.
 2. Learned counsel for the respondent-Bank submits
that in spite of sufficient opportunity being given to the
petitioner, the petitioner did not deposit the amount as directed
by the Tribunal and consequently, the impugned order has
been passed.
 3. Having heard the learned counsel for the petitioner
as well as learned counsel for the respondent-Bank, this Court
is of the considered opinion that in the interest of justice, the
petitioner should be permitted to file a written statement and
proceed with the matter. Learned counsel for the petitioner
submits that written statement has already been filed by the
petitioner, however, since the petitioner did not deposit
Rs.20,000/- as was directed earlier, the written statement is
not taken on record.
