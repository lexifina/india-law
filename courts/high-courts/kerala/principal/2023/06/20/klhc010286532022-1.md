 O R D E R
When this bail application came up for consideration, the
learned Public Prosecutor submitted that the final report in
Crime No. 199/2022 of Pothanikadu Police Station is already
submitted before the competent court. If that is the case, this
bail application need not be retained here. The petitioner is
free to approach the competent court to get bail, if not already
appeared. If such an application is filed, the court concerned
will consider the fact that there was an interim order in this
bail application.
With the above observation, this bail application is closed.
