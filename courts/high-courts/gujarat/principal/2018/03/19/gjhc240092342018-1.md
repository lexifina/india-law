 ORAL ORDER BELOW NOTE FOR SPEAKING TO MINUTES
By this note for speaking to minutes, it has been pointed
out that inadvertently a wrong number of the criminal case has
been stated in the order passed by this Court dated 20th
February 2018.
In the order passed by this Court, there is a reference of
the Criminal Case No.6275 of 2017, which is not the correct
number. The correct number of the Criminal Case is 6349 of
2017.
The registry shall effect the necessary correction in this
regard and issue a fresh writ of the order. Direct service is
permitted.
(J.B.PARDIWALA, J.)
