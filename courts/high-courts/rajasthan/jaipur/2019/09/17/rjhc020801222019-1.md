Order
17/09/2019
1. The matter comes up on application filed by counsel for the
petitioner.
2. It is contended that petitioner’s counsel name in the bail
application order has been mentioned as “Vikram Singh Jain”
whereas petitioner’s counsel name is “Vikram Singh Nain”.
3. Application is allowed.
4. In the order dated 02.09.2019, petitioner’s counsel name be
read as “Vikram Singh Nain” in place of “Vikram Singh Jain”.
