# High Court of Uttarakhand, WPSB/129/2009, 2011-06-28

WPSB No.129/09
Hon’ble Barin Ghosh, C.J.
Hon’ble Servesh Kumar Gupta, J.
(Review Appln. No.431/2011)
(Delay Condonation Application No.5965/11)
 Mr. H.S. Sharma, Advocate for the
petitioner/review applicant.
 Mr. I.P. Kohli, Advocate for the respondents.
 Considering the averments made in the application
for condonation of delay in filing the review application
and finding the same to be somewhat reasonable, we
allow the same.
 Considered the review application where it has
been stated/insinuated that the judgment under review
is an erroneous judgment. That may be so but that is
no ground for review. The review application is
thoroughly misconceived and the same is dismissed.

 (Servesh Kumar Gupta, J.) (Barin Ghosh, C.J.)
