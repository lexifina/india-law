2
This application is filed to set aside the exparte
judgment and decree dated 30.09.2019 in C.S.No.890 of 2015.
2. I heard the learned counsel for the
applicant/defendant and the learned counsel for the
respondent/plaintiff.
3. By earlier order dated 30.01.2020, the delay in
filing the application to set aside the ex parte judgment
and decree and to condone the delay in filing the written
statement were allowed. This application is consequential.
4. The learned counsel for the respondent submits that
she has no objection if this application is allowed.
5.Accordingly, this application is allowed and the ex
parte judgment and decree dated 30.09.2020 in C.S.No.890 of
2015 is set aside.
6. List C.S.Nos.890 of 2015 and 153 of 2015 on
26.02.2020 under the caption 'for framing issues'.
