Jabalpur, Dated : 13-07-2019
Shri Arpan Shrivasatava, learned counsel for the applicants.
I.A. No.4123/2019 has been filed for correction the name of
respondent No.1.
On due consideration, application (I.A. No.4123/2019) is
allowed.
Learned necessary corrections be carried out.
Present application is filed for restoration of First Appeal
No.91/2011 which has been dismissed by virtue of common
conditional order dated 10.08.2018.
For the reasons mentioned in the application, present
application is allowed. Consequently, F.A. No.91/2011, is restored to
its original number.
Learned counsel for the applicant is now directed to cure the
default, if any, in First Appeal No.91/2011 within a period of one
month failing which the dismissal order shall revive.
Accordingly, present MCC stands disposed of.
