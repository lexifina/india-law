2. The Rules of this Court require writ record to be filed along with a
Letters Patent Appeal and if the appellant feels that complete writ record
need not be filed application has to be filed seeking exemption.
3. In both appeals false certificates have been filed that complete writ
record has been filed along with the appeals.
4. Learned counsel for the appellant concedes that complete writ record
has not been filed with the appeals.
5. Since false certificates have been filed in the appeals we dismiss the
appeals granting liberty to the appellants to file fresh appeals challenging the
impugned order but enclosing complete writ record and if some record is not
intended to be filed, on the opinion of the appellants that the same is not
relevant, exemption can be prayed for.
6. No costs.
