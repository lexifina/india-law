# High Court of Orissa, ABLAPL/1664/2021, 2021-03-08

02. 08.03.2021 The matter is taken up through hybrid arrangement
(virtual/physical) mode.
 In view of the submission of the learned counsel for the
State, the name of the Petitioner No.3 has been omitted from
the arena of the case has not charge-sheeted, learned counsel
for the Petitioners does not want to press this application for
the Petitioner No. 3.
 In view of the submission of the learned counsel for the
State that the Petitioners having received the notice under
section 41A of the Code of Criminal Procedure have been
cooperating with the investigation; learned counsel for the
Petitioners for the present does not press this application. He
therefore, prays for withdrawal of this bail application seeking
liberty for the Petitioners to approach this Court afresh in case
cause of action so arises in future.
 Granting the liberty as aforesaid, this application stands
disposed of as withdrawn.
 Issue urgent certified copy as per rules.

 D. Dash, J.
