HON’BLE MR. JUSTICE PRASANTA KUMAR DEKA
-O R D E R-27.02.2019
Heard Mr. PK Roy, learned counsel for the appellant. Also heard Ms. M Roy, learned counsel
for the respondent no. 1 and Mr. CKS Baruah, learned counsel for the respondent nos. 3 to
6.
The appeal value as per suit value is Rs. 2,63,127.20 and the same is against an order
passed under Order XXI Rule 58 of the CPC by the Executing court of the learned Civil
Judge, Karimganj. The order under Order XXI Rule 58 of the CPC has the same force and
subject to the same conditions as to appeal as if it was a decree. As the appeal value is
below Rs. 5,00,000/-, the appeal lies before the learned District Judge, Karimganj. As such,
the appeal memo along with the enclosures is returned with a liberty to file it in the
appropriate court. This appeal is disposed of as the appeal memo is returned to file it in
the appropriate appellate court with appropriate pecuniary jurisdiction.
Registry to take necessary steps as required under the provision of the Code of Civil
Procedure.
