04/16.03.2018: This is an application filed by the petitioner seeking modification of
order dated 5.1.2018 passed in B.A. No. 9100 of 2017.
There cannot be any review of an order passed in a bail application,
by filing an application. The petitioner always has liberty to file a fresh bail
application.
Thus, this petition is dismissed with a liberty to file a fresh bail
application.
