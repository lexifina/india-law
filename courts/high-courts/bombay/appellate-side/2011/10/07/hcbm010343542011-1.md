2. Rule. By consent Rule made returnable forthwith and taken up for
final hearing.
3. Heard.

2
mss WP7780
4. By the impugned order, learned Judge of Small Causes Court at Pune
has condoned the delay in filing an application under Order 9 Rule 13 of the
Code within one day without issuing notice to the present petitioner. In
this situation, the advocate for respondents has consented for setting aside
this order and remitting the application to the trial court for consideration on
merits afresh.
5. Hence by consent, the writ petition is allowed and Rule is partly made
absolute. Impugned order dated 21/4/2011 is set aside and Misc.
Application No. 30/2011 is restored to file. The petitioner will be at liberty
to file reply and thereafter the trial court will decide the application on its
own merits without being influenced by the earlier order dated 21/4/2011
which is being set aside by consent. No order as to costs.
(G. S. GODBOLE, J.)
