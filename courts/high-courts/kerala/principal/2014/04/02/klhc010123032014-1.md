Dated this the 2nd April, 2014.
JUDGMENT
This contempt case has been filed alleging that the
respondent is guilty of wilful disobedience of the directions of
this Court. An affidavit has been filed by the respondent
producing Annexure G, copy of an order dated 30.1.2014
issued in compliance with the direction of this Court. The
contention of the counsel for the petitioner is that, the said
order is more or less on the same terms as Annexure B order
that has been set aside by the judgment of this Court.
Therefore, it is contended that the present order Annexure G
is not in compliance with the direction of this Court.
2. Heard. Since an order has been passed by the first
respondent in compliance with the direction of this Court,
which is Annexure G, I am not satisfied that any further action
need be initiated against the respondent in this contempt

Cont.Case 234/2014 2
case. This is for the reason that no deliberate intention to
disobey the directions of this Court can be spelt out in view of
the fact that an order Annexure G has been passed. If the
petitioner is aggrieved by the same he is at liberty to challenge
the same in appropriate proceedings. In view of the above this
contempt case is closed.
