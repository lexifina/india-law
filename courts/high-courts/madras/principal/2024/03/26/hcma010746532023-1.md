# Madras High Court, A/4015/2023, 2024-03-26

A.No.4015 of 2023 in
E.P.No.105 of 2018
N.SATHISH KUMAR, J.
This petition has been filed to
restore the Execution Petition
No.105/2018 on the file of this Court.
2. Publication effected against the
first respondent, however, none
appeared on behalf of him.
3. Considering the fact that this
application has been filed to restore the
execution proceedings, which was
dismissed for default and also being
satisfied with the reasons assigned in the
affidavit filed along with the petition,
this court is inclined to allow the
petition.
4. Accordingly, this application is
allowed and the Registry is directed to
proceed with the execution proceedings.
It is also stated that proclamation was
already issued and hence, the same shall
continue for further proceedings. The
proceedings shall be done expeditiously
in this matter.
 26.03.2024
