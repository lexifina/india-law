# High Court for the State of Telangana, WP/23761/2012, 2012-08-27

THE HON’BLE SRI JUSTICE K.C.BHANU
WRIT PETITION NO.23761 OF 2012
ORDER:
The learned counsel for the petitioners seeks permission of this
Court to withdraw the writ petition giving liberty to the petitioner to file
a revision before the Government against the impugned proceedings.
2. Permission is accorded.
3. Accordingly, the writ petition is dismissed as withdrawn giving
liberty to the petitioner to file a revision before the Government
against the impugned proceedings. No order as to costs.
4. Miscellaneous petitions, if any, pending in this writ petition shall
stand closed.
---------------------
K.C.BHANU, J
