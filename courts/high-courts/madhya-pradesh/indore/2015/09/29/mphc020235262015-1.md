# High Court of Madhya Pradesh, MCRC/8671/2015, 2015-09-29

M.Cr.C.No.8671/2015
29.09.2015
Shri Jagdish Dangi, learned counsel for the applicant.
Shri Romesh Dave, learned counsel for the
respondent/State.
Heard on I.A.No.7430/2015 which is an application for
dispensing with filing of Vakalatnama as the applicant is in
jail.
After due consideration, the application is allowed.
Filing of Vakalatnama is dispensed with.
Heard on main application under Section 482 Cr.P.C.
This is an application for review of order passed by this
Court in M.Cr.C.No.8118/2015 dated 22.09.2015. It is stated
in the application that crime number has been wrongly
mentioned as 939/2015 which should be 934/2015.
After due consideration, the application is allowed. In
the order passed in M.Cr.C.No.8118/2015 dated 22.09.2015
crime number be read as 934/2015 in place of 939/2015.
With the aforesaid correction, this application stands
disposed of.
C.C.as per rules.
( ALOK VERMA)
 JUDGE
