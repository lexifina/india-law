# Calcutta High Court, CRR/599/2015, 2022-06-16

16.06.2022
S/L No.6
 KS

 C.R.R. 599 of 2015
 Meherunnessa Bibi alias Meherunnessa
 -Vs.-
 State of West Bengal & Anr.

The revisional application is listed today for hearing.
On call none appears for the petitioner and for opposite parties.
In compliance with order dated 30.03.2022 Administrative Notice
was issued upon the petitioner and opposite party no.2. Report
received from the Department reveals that notice had been served upon
the petitioner as well as opposite party no.2.
Petitioner filed this revisional application under Section 482 of
the Code of Criminal Procedure praying for quashing of the charge-sheet in B.G.R. Case No.2324 of 2012 under Sections 420/ 468/ 471/ 34 of
the Indian Penal Code pending before Learned A.C.J.M., Basirhat. Since
the petitioner is not diligent in proceeding with this revisional
application, the revisional application is dismissed for default.
Interim order, if any, stands vacated.
Let a copy of this order be communicated to the Learned
A.C.J.M., Basirhat for information.
All parties shall act on the server copy of this order downloaded
from the official website of this Court.

2

 (Ananda Kumar Mukherjee, J.)
