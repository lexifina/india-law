# Patna High Court, CR. REV./1181/2007, 2008-08-06

IN THE HIGH COURT OF JUDICATURE AT PATNA
CR. REV. No.1181 of 2007
SAFIQUE ALAM
Versus
THE STATE OF BIHAR & ORS
-----------
2. 6.8.2008 No one appears for the petitioner.
This revision application has been filed for adding section
436 of the Indian Penal Code instead of section 435 of the Indian Penal
Code under which cognizance has been taken besides sections 147 and
447 of the Indian Penal Code by the impugned order.
As cognizance of the offence has already been taken, this
revision is not maintainable for change of section. This matter can be
raised and decided only at the stage of framing of charge.
Accordingly, the revision application is rejected.
Md.S. (Ghanshyam Prasad,J.)
