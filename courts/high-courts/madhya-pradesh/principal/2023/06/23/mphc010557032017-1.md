2. It is submitted by the counsel for the petitioner that the petitioner had
applied for maternity leave but the same was rejected by order dated
23.11.2017. It is fairly conceded by the counsel for the petitioner that now no
substantive relief can be granted to the petitioner.
3. Heard the learned counsel for the petitioner.
4. When this Court is not in a position to give substantive relief to the
petitioner, then it would not be appropriate for this Court to decide this petition
only for academic purposes.
5. Accordingly, this petition is dismissed as having rendered infructuous by
efflux of time.
