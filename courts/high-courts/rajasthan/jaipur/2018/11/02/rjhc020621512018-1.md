 Order
02/11/2018
1. Learned Counsel for the applicant states that there is a
confusion in the order dated 17.05.2018. On the one hand, while
discharging notice of contempt, the Division Bench has observed
that the petitioner can challenge the order dated 17.05.2017 by
taking resort to appropriate proceedings. In the same breath,
liberty is granted to revive so as to challenge the order.
2. Needless to state the last line is surplus. Meaningfully
read the order dated 17.05.2018 requires the applicant to
challenge the communication dated 17.05.2017 by way of a
substantive proceedings, which means a writ petition.

(2 of 2) [CRW-84/2018]
3. So clarifying the application is disposed of.
