1. This is an application for condonation of delay
of 379 days caused for filing application for restoration of
appeal.
2. Heard learned advocates for both sides.
3. Perused the application.
4. The learned advocate for the appellant
submitted that record and proceeding was called but not yet
received. The appellant is ready to file private paper book as
per the directions of this Court. It is lastly prayed to allow
the application.
5. On perusal of application and the argument of
learned advocate for the appellant, delay is not deliberately
caused. The application deserves to be allowed in the
interest of justice. The application is allowed. Delay of 379
days is condoned.
6. Application is disposed.
