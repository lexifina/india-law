A.N. JINDAL, J. (Oral)
The case was adjourned for 14.6.2011 for filing written
statement by defendant No.1/petitioner. Since he could not file the reply, as
such, his defence was struck off, vide impugned order dated 14.6.2011,
which has been challenged in the present petition.
The suit was filed in February, 2011. Certainly some time must
have been taken for summoning the defendants. Therefore, it cannot be said
that there was intentional delay on the part of the defendant No.1/petitioner
in filing the written statement. Rather, it appears that one copy of the
written statement, which the petitioner wanted to file, is already on record.
In the circumstances, this petition is accepted, impugned order
dated 14.6.2011 is set aside. The petitioner/defendant No.1 would file the
written statement, subject to payment of Rs, 2,000/- as costs.
August 3, 2012 (A.N. JINDAL)
