1. This is an application for condonation of delay
of 728 days caused for filing application for restoration of
the appeal.
2. Perused the application.
3. Heard learned Advocates of both sides.
4. For the reasons stated in the application, the
application deserves to be allowed in the interest of
justice.
5. The application is allowed
6. The delay of 728 days caused in filing
restoration application is condoned, as the delay is not
deliberately caused.
7. The application is disposed of.

cao473.24.odt 2/2
MISC. CIVIL APPLICATION ST. No.5469 OF 2024.
1. This is an application for restoration of the first
appeal.
2. Perused the application.
3. Heard learned Advocates of both sides.
4. Learned Advocate for the applicant submits
that he will file the paper-book within two weeks.
5. For the reasons stated in the application and
the submission of learned Advocate for the applicant, the
application is allowed.
6. The appeal is restored on its original number
on the condition that appellant shall file paper-book
within two weeks.
7. It is clarified that if the paper-book is not filed
within two weeks, this application shall be deemed to be
rejected without reference to the Court.
8. The application is disposed of.
 (SANJAY A. DESHMUKH, J.)
