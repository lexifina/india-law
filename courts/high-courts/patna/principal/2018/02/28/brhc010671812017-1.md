ORAL ORDER
2 28-02-2018 Heard learned counsel for the petitioner and the State.
This application has been filed for restoration of Cr.
Misc. 4991 of 2017 to its original file and number which was
dismissed as not pressed vide order dated 8.8.2017 passed by this
Court.
From the order sheets of Cr. Misc. 4991 of 2017 it
appears that anticipatory bail application of the petitioner was
pending since 15.02.2017.
Therefore, this Court does not find any reason to
restore Cr. Misc. 4991 of 2017.
This application stands dismissed with liberty to the
petitioner to file fresh anticipatory bail application.
