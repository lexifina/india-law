3. Learned State counsel submits that a bare perusal of

always has the liberty to file petition alongwith requisite fee for
getting the land measured, if he is dissatisfied.
4. The Court is fully satisfied with the contention put
forward by the learned State counsel. If the petitioner has any
doubt about the earlier measurement can always prefer a proper
petition alongwith requisite fee to get it remeasured in presence
