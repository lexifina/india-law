# High Court of Madhya Pradesh, MCRC/13419/2017, 2017-08-22

MCRC-13419-2017
(LALLA @ AMIT SINGH Vs THE STATE OF MADHYA PRADESH)
22-08-2017
Shri D.S. Baghel, learned counsel for the applicant.
Shri Piyush Jain, learned Panel Lawyer for the respondent/State.
Learned counsel for the applicant prays for withdrawal of this bail
application filed under Section 439 of the Code of Criminal Procedure
with liberty to file a fresh bail application after the material witnesses
are examined before the trial Court.
Accordingly, the bail application under Section 439 of the Code of
Criminal Procedure stands dismissed as withdrawn with the liberty as
aforesaid.
