CORAM: HONOURABLE DR. JUSTICE RAVI RANJAN
ORAL ORDER
5 18-07-2012 It has been submitted on behalf of the State that the cost
imposed by this Court has already been deposited and copy of
receipt evidencing the same has been filed. Let the same be kept
on record.
After some argument, learned counsel for the petitioner
seeks leave to withdraw this writ application to pursue this matter
before the authorities concerned itself.
There is no objection on behalf of the State.
Leave is granted.
Accordingly, this writ application is dismissed as
withdrawn with the aforesaid liberty granted to the petitioner.
Sanjay-II/-
(Dr. Ravi Ranjan, J)
