# High Court of Madhya Pradesh, MCC/1321/2014, 2014-07-31

MCC No.1321/2014
31/07/2014
Shri Pradeep Dubey, learned counsel for the applicant.
This application has been filed for restoration of Writ
Appeal No.1547/2013, which has been dismissed for want of
prosecution. There being some delay in filing the application
for restoration, I.A.No.9898/2014 has been filed for seeking
condonation of delay.
Keeping in view the reasons given in the application for
restoration, which is supported by affidavit of clerk of the
counsel himself and finding the same to be bonafide, both the
applications are allowed.
Writ Appeal No.1547/2013 is restored to its original
file. It be placed for orders before an appropriate Bench.
MCC stands allowed and disposed of.
(Rajendra Menon) (Alok Verma)
