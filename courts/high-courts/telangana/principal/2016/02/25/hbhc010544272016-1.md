# High Court for the State of Telangana, CRLP/2258/2016, 2016-02-25

THE HONOURABLE SRI JUSTICE RAJA ELANGO
CRIMINAL PETITION No.2258 OF 2016
ORDER:
Learned counsel for the petitioners seeks permission to
withdraw this Criminal Petition with a liberty to the petitioners to file a
fresh petition if charge sheet is filed against them.
2. Permission is accorded.
3. Accordingly, the Criminal Petition is dismissed as withdrawn
with a liberty to the petitioners to file a fresh petition if charge sheet is
filed against them.
4. Miscellaneous petitions pending, if any, in this Criminal Petition
shall stand closed.
 _________________________
