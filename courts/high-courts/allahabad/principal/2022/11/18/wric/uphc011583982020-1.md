# Allahabad High Court, WRIC/23208/2020, 2022-11-18

Court No. - 21
Case :- WRIT - C No. - 23208 of 2020
Petitioner :- M/S Kabeer Suppliers And Engineers
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Prakhar Saran Srivastava
Counsel for Respondent :- C.S.C.,Shyam Mani Shukla
Hon'ble Manoj Kumar Gupta,J.
Hon'ble Jayant Banerji,J.
(Order on Withdrawal Application.)
An application has been filed praying for withdrawal of the writ
petition with liberty to file a fresh petition. It is supported by an
affidavit of sole proprietor.
Shri Prakhar Saran Srivastava, learned counsel for the petitioner
prays that the application be allowed.
There is no opposition to the withdrawal application.
The application is allowed.
The writ petition is accordingly dismissed as withdrawn with
liberty to file afresh.
