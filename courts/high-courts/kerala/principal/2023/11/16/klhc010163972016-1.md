ORDER
This Crl.M.C is filed to set aside Annexure A5 final report
against the petitioners which is pending as CC 666/2014 on the
file of the Judicial First Class Magistrate Court-I Kozhikode. This
Crl.M.C is pending before this Court from 2016 onwards. No
interim order is passed in this case. Probably the case might
have been disposed of by the trial court. If the case is not
disposed of, the petitioners are free to agitate all the contentions
before the trial court at the appropriate stage.
With the above observations, this Criminal Miscellaneous
Case is closed.
