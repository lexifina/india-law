JUDGMENT
Perused the writ petition. This writ petition is preferred to
set aside Ext.P5 order. It was an application to set aside the
Commissioner's plan and report. The Commissioner was examined.
The court did not find any ground to set aside Commissioner's report
but nevertheless held that there are mistakes, which requires to be
corrected. Therefore, the court ordered to remit back the
Commissioner's report to file a modified report considering the
objections raised by the petitioners in the petition.
2. The court has given a direction to the Commissioner to
consider the objections raised by the petitioners in the petition and
then to file a report. If there is any grievance for the writ petitioner
certainly, she can file objections to that report including the
objections which she had already raised in the present petition.
With these observations, the writ petition is dismissed.
M.N.KRISHNAN, JUDGE
