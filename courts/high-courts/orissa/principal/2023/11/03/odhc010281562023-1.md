Order No.
ORDER
03.11.2023
07. 1. This matter is taken up through Hybrid
Arrangement (Virtual/Physical) Mode.
2. Heard learned counsel appearing for the Parties.
3. This Contempt Petition has been filed seeking
compliance of the order dtd.17.08.2022 so passed in
WPC(OAC) No.3264 of 2017 and subsequent order passed
on 21.02.2023 in CONTC No.941 of 2023.
4. It is contended that the order in question was not
complied with only on the ground that against the order
passed by this Court on 17.08.2022, the State has filed
W.A. No.1798 of 2023. But it is fairly admitted by the
learned counsel for the State that W.A. No.1798 of 2023
has been dismissed by this Court vide order
dtd.17.10.2023. Copy of the said order produced in Court
be kept in record.

// 2 //

5. Since the Writ Appeal in question has already been
dismissed on 17.10.2023, this Court while disposing the
Contempt Petition directs Opposite Parties-Contemnors to
comply with the order dtd.17.08.2022 by 31.12.2023,
otherwise adverse inference will be taken.
6. Accordingly, the Contempt Petition stands disposed
of.
