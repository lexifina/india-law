O R D E R
In this petition under Section 482 of the Code of
Criminal Procedure, the accused in C.C.No.876/2010 for offence under
Section 420 IPC on the file of the Judicial Magistrate of the First Class,
Nadapuram seeks an order to quash Annexure B final report with a plea
that the matter has been settled between the parties.
2. Offence under Section 420 IPC being compoundable,
the petitioner can very well file a petition before the trial court under
Section 320 of the Code of Criminal Procedure and get an order of
acquittal thereon, without the intervention of this court under Section
482 of the Code of Criminal Procedure. No reason to invoke
jurisdiction under Section 482 of the Code of Criminal Procedure.
In the result, this petition is dismissed with liberty to the
petitioner to file a petition under Section 320 of the Code of Criminal
Procedure before the trial court.
 P.S.GOPINATHAN,
