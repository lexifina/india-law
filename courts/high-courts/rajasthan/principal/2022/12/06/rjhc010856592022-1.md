----Respondents
For Petitioner(s) : Mr. Kaushal Gautam
JUSTICE DINESH MEHTA
Order
06/12/2022
1. Present application has been filed by the applicant, seeking
correction in the order dated 05.12.2022 passed by this Court in
SB Criminal Misc. Bail Application No.15519/2022.
2. Upon perusal of the memo of petition, it is clear that the
petitioner himself has furnished incorrect details in the cause-title
of the bail application, which requires to be amended.
3. Hence, the present application seeking correction in the
order dated 05.12.2022 is rejected.
4. The petitioner shall, however, be free to file application for
amendment in the cause-title of the bail application and then
apply for correction in the order.
(DINESH MEHTA),J
