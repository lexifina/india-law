CORAM : MRS. SWAPNA JOSHI, J.

Heard.
This is an application for condonation of delay in filing the restoration
application.
Perused the application and the contents thereof. On perusal of the
application, I am satisfied that the ground is made out for condoning the delay.
Hence, criminal application is allowed and the delay of six days is hereby
condoned.
CRIMINAL APPLICATION [APPP] NO.830/2018
Heard.
This is an application for restoration of application seeking leave to file
appeal which was dismissed in default on 21.3.2018. The respondent
remained absent though served.
For the reasons mentioned in the application, the application is hereby
allowed. The application seeking leave to file appeal is restored to file. With
this order, criminal application stands disposed of.
