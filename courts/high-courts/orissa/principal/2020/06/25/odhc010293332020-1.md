# High Court of Orissa, WP(C)/13162/2020, 2020-06-25

02. 25.06.2020 Learned counsel appearing for the petitioner by Video
Conferencing mode seeks permission to withdraw the writ
petition with liberty to the petitioner to file fresh application
if any necessity arises.
 Permission for withdrawal of the writ petition is
granted.
 Accordingly, the writ petition stands disposed of
being withdrawn with liberty to the petitioner to file fresh
application if any necessity arises.
