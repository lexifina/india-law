# Madras High Court, CMP/11811/2024, 2024-06-25

C.M.P. No.11811 of 2024
in
C.M.A. No.1586 of 2020
ABDUL QUDDHOSE, J.
The learned counsel for the petitioner
is not pressing this petition, since this
petition is not maintainable before this
Court. The said petition / application will
have to be filed before the Original Side of
this Court dealing with the Arbitration
matters.
2. The application has been filed
under Section 29A of the Arbitration and
Conciliation Act.
3. Necessarily, the said application has
to be filed only before the Original Side of
this Court. Accordingly, this petition is
dismissed as not pressed. Liberty is granted
to the applicant to file an appropriate
application under Section 29A of the
Arbitration and Conciliation Act before the
Original Side of this Court dealing with the
arbitration matters.
4. Registry is directed to number the
said application, once the same is filed and if
it is otherwise in order.
