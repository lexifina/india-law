# High Court of Orissa, WP(C)/18712/2019, 2019-11-26

02. 26.11.2019 Heard learned counsel for the petitioner.
 By way of this writ petition, the petitioner has
prayed for a direction to the opposite parties to comply with
the order dated 04.04.2019 (Annexure-1), passed by the
Odisha Administrative Tribunal, Principal Bench,
Bhubaneswar, in O.A. No.1270 of 2019.
 Considering the prayer made, it will not be
appropriate to pass any order in this writ petition.
 However, it will be open for the petitioner to file
contempt petition before the learned Single Judge.
 Accordingly, the writ petition stands disposed of.
 All the connected Misc. Cases/I.As, if any is/are
accordingly disposed of.
