Order
24/08/2023
1. The instant application has been preferred seeking correction
in the order dated 19.08.2023 passed in S.B. Criminal Misc. Bail
Application No.8386/2023. It is averred in the application that the
in cause title of the aforesaid bail application, the name of the
petitioner's father has been mentioned as Shiva, whereas the
petitioner's father's name is Basantilal and the same error has
crept in the order granting bail, therefore, the same may be
ordered to be corrected. An amended cause title has also been
filed with the application.
2. On a perusal of the file and the challan papers, it is revealing
that the petitioner's father's name is Basantilal. Therefore, the
correction sought for in the order dated 19.08.2023 is essential.
3. Accordingly, the instant application seeking correction is
allowed and it is ordered that the name of the father of the
petitioner, wherever appearing in the order dated 19.08.2023

[2023:RJ-JD:26971] (2 of 2) [CRLMA-307/2023]
passed in S.B. Criminal Misc. Bail Application No.8386/2023 shall
be read as "Basantilal" instead of "Shiva", which is actually alias
name of the petitioner. The amended cause title is taken on
record and the same be placed appropriately in the file. This
order shall be treated as part and parcel of the order dated
19.08.2023.
(FARJAND ALI),J
