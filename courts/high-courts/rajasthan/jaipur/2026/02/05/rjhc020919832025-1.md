JUSTICE ANOOP KUMAR DHAND
Order
05/02/2026
1. The matter comes up on misc. application No.449/2025
seeking correction/modification of the order dated 19.09.2025
passed by this Court while deciding S.B. Civil Writ Petition
No.1482/2025.
2. Learned counsel for the respondents-applicants submits that
in last line of Para 5 (1) of the order dated 19.09.2025, the date
25.10.2026 has been inadvertently typed out as 25.10.2016.
Learned counsel submits that for the aforesaid correction, the
instant application has been preferred.
3. After perusing the application and going through the order
dated 19.09.2025, this Court is satisfied that the date 25.10.2026
has been wrongly typed out as 25.10.2016. Accordingly, the misc.
application stands allowed and it is ordered that the date
“25.10.2016” appearing in the last line of the Para 5(1) of the
order dated 19.09.2025 be read as “25.10.2026”.
4. This order shall be treated as part and parcel of the order
dated 19.09.2025.
(ANOOP KUMAR DHAND),J
