# High Court for the State of Telangana, WP/40553/2016, 2017-02-07

THE HON’BLE SRI JUSTICE A.RAJASHEKER REDDY
WP No.40553 of 2016
ORDER:

Learned counsel for the petitioner seeks permission to withdraw this writ
petition with liberty to file fresh writ petition, as the petitioner earlier could not file
certain documents with this writ petition, relevant to the case.
2. Permission is hereby accorded and the writ petition is dismissed as
withdraw. Petitioner is at liberty to file fresh writ petition, if so advised.
Miscellaneous petitions, if any pending in this case are also dismissed. There shall
be no order as to costs.
