# Madras High Court, A/6947/2019, 2020-03-23

A.No.6947 of 2019
A.No.6947 of 2019
N.SATHISH KUMAR, J.
This application has been filed by the applicant, seeking a direction to the
respondent to furnish security to the tune of Rs.11,22,519/- failing which to order
attachment of the immovable properties morefully described in the judges summons.
2. This Court by an Order dated 23.09.2019, directed the respondent to furnish
security for the suit claim on or before 31.10.2019, and on failing to furnish security,
there shall be Order of attachment.
3. Despite the Order of this Court directing to furnish security, the respondent
has not furnished any security and none appeared for the respondents.
4. In view of the same, there shall be an Order of attachment of the immovable
property described in the schedule and this application is closed. The Registry is
directed to communicate this Order to the Registrar concerned.
