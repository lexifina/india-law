# High Court of Madhya Pradesh, MCC/2489/2015, 2015-08-24

MCC-2489-2015
(D.K. SHARMA Vs THE STATE OF MADHYA PRADESH)
24-08-2015
Shri A.K.Singh, learned counsel for the applicant.
This application has been filed for restoration of Writ Petition
No.26381/2003, which was dismissed for want of prosecution.
There being some delay in filing the application for restoration,
therefore, I.A. No.10912/2015 has been filed seeking condonation
of delay. Both the applications are supported by an affidavit of
Advocate himself and there is no reason to disbelieve the same.
Finding the same to be bona fide, both the applications are
allowed.
Condoning the delay in filing the application, restoration
application is itself allowed.
Writ Petition No.26381/2003 is restored to its original
number.
After restoration, Writ Petition No.26381/2003 be placed for
orders before appropriate Bench.
Application stands allowed and disposed of.
Certified copy as per rules.
(VANDANA KASREKAR)
JUDGE
