Applications praying that this Hon'ble court be pleased to allow the
Applicant/Plaintiff to file a single suit for joinder of cause of action and
reliefs against the Respondents/Defendants.
This application coming on this day before this court for hearing the
court made the following order:-
This Application is filed to allow the Applicants/Plaintiffs to file a single
suit for joinder of cause of action and reliefs against the Respondents/Defendants.
2.In this case, not only the written statement has been filed but, a counter
claim too has been filed. Indeed, a third party to the suit is also made a party to the
counter claim.
3. In a scenario such as this, where the parties have done things believing
that the leave has been granted, it is absolutely necessary for the Court to allow
this Application.
4.This Application is accordingly allowed.
5.Post the matter on 22.11.2021.
