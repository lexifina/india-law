This petition coming on for admission this day, the court passed the
following:
ORDER
Learned counsel for petitioner contends that vide order dated 11.03.2023
(Annexure P/2), the right to file written statement of defendant No.5/ petitioner
has been closed.
2. It is contended by the counsel for petitioner that the written statement
was under preparation and therefore, a time was sought to file the same but the
trial Court has declined to grant time to defendant No.5 to file written statement.
It is contended by the counsel that the written statement is almost prepared and
the defendant No.5 is ready to file the same before the next date of listing
before the trial Court i.e. 02.05.2023.
3. In view of the statement made by counsel for the petitioner, the order
dated 11.03.2023 stands quashed. The defendant No.5/ petitioner be permitted
to file written statement on 02.05.2023 subject to payment of cost of Rs.2500/-
(Two Thousand Five Hundred) to the plaintiff.
4. It is made clear that if no written statement is filed by the 2nd May,
2023 and the cost in terms of this order is not paid by 2nd May, 2023, the trial
