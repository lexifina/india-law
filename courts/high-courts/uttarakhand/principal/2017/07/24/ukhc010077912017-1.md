# High Court of Uttarakhand, WPMS/296/2017, 2017-07-24

WPSS No.296 of 2017
Honíble Rajiv Sharma, J.
Mr. Mohd. Umar, Advocate for the
petitioner.
Mr. P.C. Bisht, Standing Counsel, for
the State/review applicant.
Delay of 55 days in moving the review
application is condoned in view of the
reasons stated therein. Delay condonation
application (CLMA 7999/17) stands
allowed accordingly.
On 23.2.2017, the State was granted
three weeksí time to file the counter
affidavit. Thereafter, the matter was taken
up on 27.3.17 and 28.3.17. Then on
29.3.17, the State was again granted two
weekís time to file the counter affidavit but
no such affidavit was filed. Thereafter, the
matter was ordered to be taken up on
12.4.2017. However, no counter affidavit
was filed in the meantime.
Respondents have been granted
ample opportunities to file the counter
affidavit which they have not availed.
Accordingly, there is no merit in the
review application (MCC 640/17) and the
same is hereby dismissed.

(Rajiv Sharma, J.)
 24.07.2017
Rdang
