# Calcutta High Court, CRR/371/2012, 2021-11-08

D/L7
November
8, 2021
Bpg.
C.R.R. No.371 of 2012
(Via Video Conference)
In Re: An application under Section 482 of the Code of Criminal
Procedure, 1973.
 Ranjit Barman & Ors.
 Versus
 State of West Bengal & Anr.
Mr. Arijit Ganguly,
 Mr. Ashok Das.
 …for the State.

Report submitted by learned advocate appearing for the
State be kept with the record. The report was prepared by the
Inspector-in-Charge, Sitai Police Station, Cooch Behar.
Report reflects that all the three accused persons were
acquitted by the learned Additional District and Sessions Judge,
Dinhata.
In view of the report so submitted, nothing survives so
far as the subject-matter of the present revisional application is
concerned which relates to quashing of the FIR.
Accordingly, CRR 371 of 2012 is disposed of.
Pending application, if any, is consequently disposed of.
Interim order, if any, is hereby vacated.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
 (Tirthankar Ghosh, J.)
