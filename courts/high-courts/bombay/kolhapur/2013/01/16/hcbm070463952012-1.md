1. Heard learned counsel appearing for the petitioners and
learned AGP appearing for the Respondents.   Considering the limited
prayer in this petition, the same need not be kept pending.
2. The petition is disposed of by passing the following order:
ORDER
(i) If applications dated 3rd November, 2012 (Exhibit A, B and C to
the petition) are not yet disposed of, we direct that the  concerned
authority shall dispose of the same as expeditiously as possible  within a
period of 3 months from today.
(ii) We make it clear that we have made no adjudication of merits
and all contentions are kept open.
Parties to act upon an authenticated copy of this order.
 (A.P. BHANGALE, J ) ( A.S. OKA, J )
