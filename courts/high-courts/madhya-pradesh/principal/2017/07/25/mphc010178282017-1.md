# High Court of Madhya Pradesh, MCC/1114/2017, 2017-07-25

MCC-1114-2017
(PRAMOD Vs LAKKHU)
25-07-2017
Shri Pushpendra Dubey, learned counsel for the applicant.
Heard on I.A. No. 5324/2017, which is an application for
condonation of delay.
Considering the averments made in the application which is
duly supported by an affidavit, the application (I.A. No.
5324/2017) is allowed. Delay in filing the application for
restoration is hereby condoned.
Also heard on admission.
This is an application for restoration of Second Appeal
which was dismissed on account of peremptory order.
Considering the avermenent made in para 3, 4 & 5 of the
application which are supported by an affidavit of the counsel
himself, I deem it proper to allow the application and restore the
appeal.
Accordingly, S.A. No. 1270/2015 be restored to its original
number. A copy of this order be also attached with the main file
of S.A. No. 1270/2015.
(VIJAY KUMAR SHUKLA)
