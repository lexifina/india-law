# High Court of Madhya Pradesh, MCC/994/2014, 2014-06-23

MCC. No.994/2014
23/6/2014
Shri A. K. Singh, learned counsel for the applicants.
This application has been filed for restoration of W.P.
No.1479/2014 which was dismissed due to non compliance of the
peremptory order. There being some delay in filing the application I.A.
No.8327/2014 has been filed seeking condonation of delay.
Application is supported by an affidavit of counsel and there is no
reason to disbelieve the same. Finding the same to be bonafide, both
the applications are allowed. Condoning the application in filing the
application, the restoration application itself is allowed. Writ Petition is
restored to its original number. It be placed for orders before the
appropriate Bench.
Application stands allowed and disposed of.
(Rajendra Menon) (Sushil Kumar Gupta)
