ORAL ORDER
1. On 22.09.2022, this Court had passed the following order:-
“Learned advocate Ms.Jayswal requests for some time in
order to file appropriate application.
The matter is kept on 10.10.2022.”
2. Thereafter, on 10.10.2022, the following order was passed:-
“On 22.09.2022, this Court had adjourned the matter on
the request of learned advocate Ms.Jayswal, appearing for the
appellants for filling appropriate application.
Today also, the same request is made. The matter is kept
on 19.10.2022. If no application is made, the matter stands
dismissed for non-prosecution.”
3. It was clarified in the order that if no application is made, the
matter stands dismissed for non-prosecution.
4. Today, learned advocate Ms.Vidita Jayswal has submitted that
despite her best efforts, the applicant has not turned up and did not
cooperate.
5. Hence, the matter stands dismissed for non prosecution with a
liberty to file application for restoring the matter in case, the applicant
cooperate with the learned advocate Ms.Jayswal.
(A. S. SUPEHIA, J)
