# High Court of Madhya Pradesh, MCC/1650/2011, 2011-12-02

M.C.C.No.1650/2011
2.12.2011
Shri Pushpendra Kumar Verma, for the applicant.
Shri Umesh Pandey, Government Advocate, for the State.
This is an application for making correction in the order
dated 20.10.2011 passed in Writ Petition No.16558/2005 in so
far as it relates to registration number of the truck seized.
It is stated in the application that the registration
number of the seized truck is URG 1525 but by mistake the
same has been mentioned as URG 1575.
Having regard to the aforesaid submission, I deem it
proper to correct the mistake.
The registration number of the truck be read as URG
1525 instead of URG 1575 in the order dated 20.10.2011.
 The application is allowed.
Certified copy as per rules.
JUDGE
