# Madras High Court, CRL OP(MD)/13706/2014, 2014-07-23

1
BEFORE THE MADURAI BENCH OF MADRAS HIGH COURT
DATED : 23.07.2014
CORAM
THE HONOURABLE MR.JUSTICE N.KIRUBAKARAN
Crl.O.P.(MD).No.13706 of 2014
K.Ezhamurugudevadoss : Petitioner
-Vs-The Inspector of Police,
Traffic Investigation Wing,
Madurai Town. : Respondent
PRAYER: Petition is filed under Section 482 of the Code of
Criminal Procedure praying to direct the respondent to expedite
the investigation in Crime NO.52 of 2014 on the file of the
respondent and file final report within a time stipulated by
this Court.
For Petitioner : Mr.S.Elangovan
For Respondents : Mr.P.Kandasamy,
 Govt. Advocate (Crl. Side)
ORDER
This petition has been filed seeking a direction to the
respondent to expedite the investigation in Crime NO.52 of 2014 on
the file of the respondent and file final report within a
stipulated time.
2. Heard the learned Counsel for the petitioner and the
learned Government Advocate (Crl.Side) appearing for the
respondent.
3. The learned Counsel for the petitioner would contend that
even though the F.I.R. has been registered on 27.05.2014, since
then final report has not been filed by the respondent police and
hence, the petitioner has approached this Court seeking a
direction to file a final report.
4. Taking into consideration the fact that the F.I.R. has
been registered on 27.05.2014, the respondent police is directed
to file a final report as expeditiously as possible.
5. The Criminal Original Petition is ordered accordingly.
