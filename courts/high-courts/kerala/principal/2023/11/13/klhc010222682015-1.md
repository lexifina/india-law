ORDER
This Criminal Miscellaneous Case is filed to quash the
proceedings in L.P.No.29/2015 in C.C.No.920/2013 on the file
of the Judicial First Class Magistrate Court-I, Mavelikkara,
arising from Crime No.282/2010 of Kurathikkad Police Station.
2. When this matter came up for consideration, this
Court directed the Registry to get a report from the trial
court. A perusal of the report would show that the trial is
already started and the case is now posted to 16.11.2023 for
Section 313 (1)(b) Cr.P.C. examination of the accused.
If that be the case, this criminal miscellaneous case need
not be retained here. The trial court will try to dispose the
case as expeditiously as possible.
With the above observation, this Criminal Miscellaneous
Case is disposed of.
