# Calcutta High Court, CRR/1214/2024, 2024-03-28

D/L18
28.03.2024
Bpg.
 C.R.R.1214 of 2024
In Re: An application under Section 482 with 401 of the Code of
Criminal Procedure, 1973;
 Arnab Mukherjee
 Versus
 State of West Bengal and another
 Mr. Dibasish Basu
 Mr. Chandrachur Lahiri.
 ...for the petitioner.
Learned advocate appearing for the petitioner intends to
withdraw the present revisional application as the same suffers
from technical deficiencies.
Petitioner is granted liberty to file afresh.
Accordingly, CRR 1214 of 2024 is dismissed as not
pressed.
Department is directed to return the certified copy to the
advocate on record of the petitioner on the same being replaced by
photostat copies.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
 (Tirthankar Ghosh, J.)
