1. The petitioners challenged the auction sale already made by filing an
application under order 21 Rule 92 of the Code of Civil Procedure, which
has been rejected by the impugned order, which is appealable under order
43 Rule 1(j) of Code of Civil Procedure.
2. In view of that the petitioners seeks to withdraw this Writ Petition with liberty
to file appeal in accordance with law.
3. Accordingly, the writ petition is dismissed as withdrawn with aforesaid
liberty in favor of the petitioners.
4. Certified copy of the impugned order be returned to the counsel for the
petitioners after furnishing attested copy thereof.
