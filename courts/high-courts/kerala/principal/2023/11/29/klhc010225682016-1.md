ORDER
This Criminal Miscellaneous Case is filed to quash the
proceedings in C.C.No.442/2011 on the file of the Judicial First
Class Magistrate Court, Ottappalam.
2. This case is pending before this Court from 2016
onwards. No interim order is passed in this case. There is no
representation for the petitioner also. Probably the main case
itself might have been disposed of by the trial court.
Therefore, this Crl.M.C is closed. If the main case is still
pending, all the contentions raised by the petitioner in this
Crl.M.C are left open and the petitioner is free to agitate the
same before the trial court.
