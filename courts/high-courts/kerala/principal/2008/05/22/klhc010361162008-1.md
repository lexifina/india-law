ORDER
This petition is filed under Order XLVII Rule 1
of Code of Civil Procedure to review the judgment
passed on 3.8.2007 whereunder the second appeal was
dismissed in limine. The case of the petitioner is
that the appeal happened to be dismissed as this
court took the view that appellant did not file a
written statement when infact a written statement
was filed. A copy of the petition filed to set
aside the ex parte order as against him as well as
copy of written statement produced along with that
petition were produced in support of the
submission. Annexure B, certified copy of the
order in I.A.1793/2003 itself shows that petitioner
was set ex parte as early as 29.9.2000 and that
application was filed to set aside the ex parte
order only on 13.6.2003 and that petition was
dismissed as per separate order dated 16.6.2003.

R.P.511/08 in R.S.A.656/06 2
Therefore eventhough petitioner had appeared
earlier in the suit, she did not file a written
statement and was set ex parte. Though three years
after setting her ex parte, a petition to set aside
the ex parte order was filed along with the written
statement neither the petition was allowed nor the
written statement was received. In such
circumstance, it cannot be said that there is any
apparent error in the judgment warranting review.
The second appeal was dismissed for valid reasons.
I find no substantial question of law involved in
the appeal warranting any interference.
In the absence of any apparent error or other
sufficient reason, the review petition is
dismissed.
Review Petition is dismissed.
