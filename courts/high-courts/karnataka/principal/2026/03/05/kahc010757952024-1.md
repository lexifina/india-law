ORAL JUDGMENT
This appeal is filed against the order dated 02.12.2024
passed in M.A. No.25/2022 on the file of Senior Civil Judge,
Belur.
2. Aforementioned appeal in M.A.No.25/2022 was
against the order in I.A.No.II in O.S.No.91/2022 on the file
of Civil Judge, Belur. The said application at I.A.No.II was an
application under Order XXXIX Rules 1 and 2 of Code of Civil
Procedure. The first appeal filed by the present appellants is
also dismissed.
3. Under these circumstances, Miscellaneous Second
Appeal does not arise, as there is no such provision in the
Code of Civil Procedure which enable the appellants to file
Miscellaneous Second Appeal.
4. Accordingly, Miscellaneous Second Appeal is
dismissed.
5. Liberty is reserved to the appellants to avail such
remedy as advised in law.
