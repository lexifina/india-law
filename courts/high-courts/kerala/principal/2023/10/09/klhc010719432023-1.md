 ORDER
This Criminal Miscellaneous Case is filed challenging
Annexure-2 order passed by the Judicial First Class Magistrate
Court-XI, Thiruvananthapuram in Crl.M.P.No.3228/2023 in
C.C.No.10/2015 mainly for the reason that Crl.M.C.No.711/2015 is
pending before this Court. Now, Crl.M.C.No.711/2015 is already
allowed and the proceedings in C.C.No.10/2015 pending before the
Judicial First Class Magistrate Court-XI, Thiruvananthapuram is
already quashed. In such circumstances, Annexure-2 order need not
be retained. No permission is necessary to travel abroad in the light
of the fact that, C.C.No.10/2015 pending before the Judicial First
Class Magistrate Court-XI, Thiruvananthapuram is already quashed,
if the petitioner is otherwise eligible.
Therefore, this Crl.M.C is allowed quashing Annexure-2 order.
