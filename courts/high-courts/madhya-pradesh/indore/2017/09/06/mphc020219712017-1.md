# High Court of Madhya Pradesh, RP/354/2017, 2017-09-06

- 1 -
Review Petition No.354/2017
06/09/2017
Shri Vikas Rathi, learned counsel for the petitioner.
Shri J. B. Mehta, learned counsel for the respondents.
The present review petition has been filed against order dated
02/08/2017 by which two writ petitions i.e. Writ Petition
Nos.3249/2017 and 3270/2017 have been disposed of. The same
reveals that defendant has been permitted to file written statement.
Learned counsel has informed this Court that in fact a prayer
was made for filing of counter claim and the same line has been
omitted in order dated 02/08/2017.
The review petition stands disposed of with a liberty to file
counter claim also. In case the same has been filed, it may be taken
on record in accordance with law.
Certified Copy as per rules.
(S. C. SHARMA)
