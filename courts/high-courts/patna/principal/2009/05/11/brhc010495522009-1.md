2 11/5/2009 Heard counsel for the petitioners.
In view of the fact that the main order on which the
present impugned order filed in this writ application is based has
not been filed, this writ application must be held to be not
maintainable.
It has to be noted that the petitioner has assailed the
order of the Collector of Katihar district dated 12th January, 2009
which is based on the Government direction contained in Letter
No. 4655 dated 29.5.2008, but then that order is not on the record
and consequently even if the writ petition with the present prayer
is allowed such order will still survive.
That being so, this application is permitted to be
withdrawn with a liberty to the petitioner to file a fresh writ
application after getting the main order.
Abhay Kumar (Mihir Kumar Jha, J.)
