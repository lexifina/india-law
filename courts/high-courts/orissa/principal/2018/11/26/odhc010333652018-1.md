# High Court of Orissa, ABLAPL/9440/2018, 2018-11-26

04. 26.11.2018 In view of the submission of the learned counsel
for the State that no case has yet been registered at the
concerned police station, learned counsel for the
petitioner prays for withdrawal of the bail application
with liberty to file it afresh in case cause of action for the
same arises in future. Granting such liberty, the ABLAPL
is disposed of as withdrawn.
 Issue urgent certified copy of this order on proper
application.
 The earlier interim order passed by this Court
stands vacated.
