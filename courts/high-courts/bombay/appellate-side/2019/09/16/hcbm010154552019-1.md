 CORAM :- SARANG V. KOTWAL, J.

P. C. :-
Ld. Counsel for the applicant at the outset tenders an order
dated 21/02/2019 passed in Criminal Bail Application No.175/2019.
Vide that order, the applicant’s application for bail was allowed to be
withdrawn. The application was dismissed as withdrawn. This fact is
not mentioned in the present application neither this order is
annexed. Ld. Counsel for the applicant therefore prays for
unconditional withdrawal of the present application as well. The
prayer is accepted. The application is allowed to be withdrawn and is
disposed of accordingly.
