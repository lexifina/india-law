# High Court of Madhya Pradesh, MCC/947/2016, 2017-05-02

MCC-947-2016
(SITARAM JADHAM Vs THE STATE OF MADHYA PRADESH)
02-05-2017
Smt. Vibha Pathak, learned counsel for the applicants.
Heard on I.A. No.6417/2016, an application for condonation of delay.
For the reasons mentioned in the application, the same (I.A.
No.6417/2016) is allowed. The delay in filing this application is hereby
condoned.
This application has been filed for restoration of Conc. No.1309/2015
which has been dismissed by virtue of common conditional order dated
28.09.2015. The application is supported by an affidavit of V.P. Nema.
Keeping in view the reasons indicated in the application, the MCC is
allowed and it is directed that Conc. No.1309/2015 be restored to its
original number and list this case before the appropriate Bench.
Let a copy of this order be kept in the file of Conc. No.1309/2015.
(SMT. ANJULI PALO)
JUDGE
