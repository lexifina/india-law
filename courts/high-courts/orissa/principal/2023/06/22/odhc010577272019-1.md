CORAM:
THE CHIEF JUSTICE

Order No.
ORDER
22.06.2023
 03. 1. The present appeal by the State seeks to challenge an order dated
4
th September, 2019 passed by the State Education Tribunal (SET),
Odisha, Bhubaneswar in Execution Case No.123 of 2013
corresponding to GIA Case No.572 of 2011.
 2. By the impugned order, the SET had directed the Appellants to
furnish property details along with the details of the vehicle with
registration numbers and had simply adjourned to 3rd October, 2019
awaiting the property details.
 3. This appeal is not even maintainable since against the main order
dated 27th September, 2012 passed by the SET in GIA Case No.569
of 2011, the State had already preferred FAO No.379 of 2017
which was dismissed by this Court on 16th March, 2018. It is stated
that a review petition has been filed for recalling of the said order,
which is stated to be still pending.

 4. Nevertheless, it is added that in the said review petition no order
has been passed staying the operation of either the original order of
the SET or of this Court.
5. The net result is that there is no impediment in the way of the
Appellants implementing the order of the SET. It is highly doubtful
that the present FAO against the interim order of the SET passed in
Execution Case No.123 of 2013 is even maintainable.
 6. For all of the aforesaid reasons, the Court is not inclined to
entertain the present appeal. It is accordingly dismissed.
 (Dr. S. Muralidhar)
