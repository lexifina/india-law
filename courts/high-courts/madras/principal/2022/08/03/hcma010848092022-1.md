# Madras High Court, A/3151/2022, 2022-08-03

A.No.3151 of 2022
 in
TOS.No.16 of 2006
A.A.NAKKIRAN.,J.
This petition has been filed to set aside the order dated 14.11.2018
passed in TOS.No.16 of 2016, dismissing the TOS.No.16/2016 for non-prosecution and to restore the same on the file of this court.
2. Heard both sides.
3. The learned counsel for the respondents has no objection in
allowing this application.
4. Considering the facts and circumstances of the case and that the
learned counsel for the respondents has no objection in allowing this
application, this Court is inclined to allow this application, on payment of
cost of Rs.1,000/-(Rupees One Thousand only) payable to the respondents.
A.A.NAKKIRAN.,J.
https://www.mhc.tn.gov.in/judis

5. The learned counsel for the applicants has paid a cost of
Rs.1,000/-(Rupees One Thousand only) directly to the learned counsel for
the respondents and the learned counsel for the respondents has also made
an endorsement to that effect.
6. Accordingly, this application is allowed.
7. Post the main case before this court on 02.09.2022 for arguments.
