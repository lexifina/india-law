ORDER
This petition is filed praying for a direction to the second
respondent to file charge sheet for the FIR No.660 of 2014 before the
learned Magistrate Court.– 2, Chengelpattu.
2.Heard the learned counsel appearing for the petitioner and the
learned Additional Public Prosecutor.
3.Considering the facts and circumstances of this case, this
Court deems it appropriate to direct the second respondent police to
file final report in connection with the case in Crime No.660 of
2014, on or before 31.08.2015.
4.With the above observation, this criminal original petition is
disposed of.
