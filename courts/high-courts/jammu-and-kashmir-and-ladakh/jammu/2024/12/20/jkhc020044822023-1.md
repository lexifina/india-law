Crl LP (D) No. 58/2023
1. This is an application seeking leave to file appeal against the
judgment of acquittal dated 28.03.2023 passed in File No. 56/Spl.
Challan titled UT of J & K Vs. Balkar Singh Masieh. This Court
vide order dated 25.08.2023 has already condoned the delay of 59
days in filing the present appeal. The respondent was given time to
file response to leave application on 09.02.2024. We are in
December, 2024 and so far, no response to the leave application has
been filed.
2. We have gone through the application seeking leave to file appeal
and are convinced that there is a prima facie material on record
which calls for the examination of the appeal on merits. As such,
application is allowed and leave to file the instant appeal is
granted.
3. Registry to diarize the main appeal.
