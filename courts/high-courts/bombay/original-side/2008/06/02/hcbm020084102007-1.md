CORAM : SMT.ROSHAN DALVI, J.
Dated : 2nd June, 2008
P.C. :
1.An ex-parte decree has been passed. An application to set it
aside has been rejected. An Appeal filed therefrom has been
rejected. The decree has to be executed. This application is
taken out under the provisions of Order XXI Rule 34 of the
Code of Civil Procedure, 1908. It is to call upon the
defendants to execute a Deed of Conveyance annexed to this
application. This application has been taken out in April
2007. The service of this application made in April 2007 has
also been admitted. The remark of the Bailiff on the reverse

2
of the application shows that the service is made on
13.4.2007. No affidavit in reply has been filed to this
application. For want of affidavit in reply, this application
deserves to be made absolute as prayed. Order accordingly.
2.The defendants shall execute the Deed of Conveyance within
two weeks from today.
 [SMT.ROSHAN DALVI, J.]
