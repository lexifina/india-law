# Bombay High Court, WP/3466/2011, 2012-11-21

CIVIL APPELLATE JURISDICTION

Shri Sameer Yasin Shaikh .... Petitioner
Vs.
Shri Iqbal Abdul Latif Shaikh .... Respondents
& Ors.

Mr. S.G. Deshmukh i/by Mr. G.T. Kanchanpurkar, Advocate for the

Coram : Smt. R.P. SondurBaldota, J.
Date : 21st November, 2012
P.C.
1. This petition challenges the order dated 15th April 2011, by
which the trial Court dismissed the application filed by the
petitioner for condonation of delay in filing the application for
setting aside exparte decree. The instant suit was filed in the
year 2004. It was decreed exparte on 20th February 2007. More
than two years thereafter i.e. on 1st August 2009, the petitioner
filed the application for setting aside exparte decree alongwith

Dusane 2/2 WP3466.2011
the application for condonation of delay. The trial Court
dismissed the application on the ground that there is no cause
whatsoever set out in the application to explain the delay and
also observing that there is a reasonable ground to think that
the delay was occasioned by the petitioner deliberately to gain
time.
2. Perusal of the application for condonation of delay
confirms the finding of the trial Court that it is completely
devoid of explanation. Infact at paragraph 2 of the affidavit,
the petitioner claims that there is no delay whatsoever in filing
the application for setting aside exparte decree and that the
application for condonation has been filed only for the purpose
of ensuring that there is no technical difficulty in the way of
the petitioner in getting the exparte decree set aside. Since
there is no cause whatsoever set out in the application, there
can be no interference with the impugned order. Hence, the
petiton is dismissed in limine.
(Smt.R.P. SondurBaldota, J.)
