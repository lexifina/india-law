ORDER:
1. This is an application for condonation of delay
of 21 days caused for filing Civil Revision
Application.
2. Heard learned counsels appearing for the
respective parties. Learned counsel for the respondents
oppose the application on the ground that the delay is
not reasonably explained.
3. For the reasons stated in the application the
delay caused for filing Civil Revision Application
seems to be properly explained. Therefore, delay needs
to be condoned. Accordingly it is condoned.
4. Civil Application is disposed of.
