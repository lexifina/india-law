Order On Board
01/07/2020
This application for anticipatory bail has been filed by the applicant
apprehending his arrest in connection with some case in which, some Magistrate
has taken cognizance under Section 138-A of the Negotiable Instruments Act, 1881
on the basis of complaint filed by some applicant.
The application is blissfully vague. Neither the application of the complainant
nor the name of the Magistrate nor order taking cognizance has been disclosed in
the application much less any application filed. Therefore, the application for
anticipatory bail is rejected with liberty to file proper application.
