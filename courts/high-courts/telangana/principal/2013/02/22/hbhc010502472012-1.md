# High Court for the State of Telangana, WP/9589/2012, 2013-02-22

THE HON’BLE SRI JUSTICE NOOTY RAMAMOHANA RAO
WRIT PETITION NO.9589 OF 2012
ORDER:
This writ petition is originally instituted by four persons and
accordingly the pleadings were set up, but however, the learned
counsel for the petitioner has been instructed by petitioners
1,2 and 3 to withdraw the writ petition. Therefore, it becomes
necessary to set up the pleadings properly with regard to the fourth
petitioner. Hence, Sri C.M.R. Velu requests permission of this Court to
dismiss this writ petition as withdrawn with a liberty to the fourth
petitioner to institute a properly constituted writ petition, in case he still
feels the necessity to do so.
According the liberty as prayed for to the fourth respondent, this
Writ petition is dismissed as withdrawn. Miscellaneous applications if
any, shall stand dismissed. No costs.

NOOTY RAMAMOHANA RAO, J
