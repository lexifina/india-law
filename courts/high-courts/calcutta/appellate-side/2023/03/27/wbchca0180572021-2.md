# Calcutta High Court, CRR/1231/2021, 2023-03-27

D/L45
27.03.2023
Bpg.
 C.R.R.1231 of 2021
In Re: An application under Section 482 of the Code of Criminal
Procedure, 1973;
 Swati Biswas
 Versus
 The State of West Bengal and another
Ms. Baisali Basu.
 …for the State.
 Report submitted by Ms. Baisali Basu, learned advocate
appearing for the State reflects that the report under Section 173 of
the Code of Criminal Procedure which was filed in connection with
New Town Police Station Case No.38 of 2021 dated 10.02.2021 was
with the findings of mistake of fact. As such, the present revisional
application do not survive.
In view of the report so submitted before the
jurisdictional court, CRR 1231 of 2021 is dismissed.
Let the report be kept with the record. r
Pending application, if any, is consequently disposed of.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
 (Tirthankar Ghosh, J.)
