The petition challenges the order dated
21-03-2023 below Exh 48 and application for grant of
permission to file documents tendered by the
petitioner/plaintiff, during the course of cross examination of
respondent/defendant. The application has been rejected by
the impugned order which holds that the document is not
admissible or relevant. It is a settled position of law that
while considering the application for permission to file
document, the admissibility or relevance of the document is
not required to be taken into consideration and what is
required to be taken into consideration is the need for the
document to be permitted to be filed on record considering
the nature of the lis. It this matter, this is not even the case,
for the reason that the document was being sought to be
produced for the purpose of confronting the respondent
during the course of cross examination, which is a course of
action which is permissible under Order 13, Rule 3 (a) of the
Code of Civil Procedure.
2023:BHC-NAG:14555

wp 2792.23. 2/2 4
2. In that view of the matter, the impugned order
cannot be sustained and the same is hereby quashed and set
aside. The application for production of document is allowed.
