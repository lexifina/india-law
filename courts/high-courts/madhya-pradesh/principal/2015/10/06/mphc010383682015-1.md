# High Court of Madhya Pradesh, MCC/2265/2015, 2015-10-06

MCC-2265-2015
(SHRI GURU TEG BAHADUR KHALSA COLLEGE Vs THE STATE OF MADHYA PRADESH)
06-10-2015
Shri Akash Choudhary, learned counsel for the
petitioner.
Shri Manas Verma, learned counsel for the respondent
no.2.
This application has been filed for restoration of
W.A.No.105/2007, which was dismissed for want of
prosecution on 16.07.2015.
Keeping in view the reasons given in the application
which is supported by the affidavit of counsel himself and
finding the same to be bonafide, the application is
allowed.
The restoration application itself is allowed,
W.A.No.105/2007 is restored to its original file. It be
placed for orders before an appropriate Bench.
Application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
(C V SIRPURKAR)
