 P.N. DESHMUKH, JJ.
DATE : MARCH 25, 2015.
Heard.
It is not in dispute that the other prisoners,
related to the present prisoner who were co-accused
in the trial with the present prisoner, were ordered to
be released by the State Government. It is
appropriate, particularly in the light of the serious
objection raised by the police machinery, to relegate
the petitioner to file appeal before the State
Government. Hence, we make the following order :
ORDER
Criminal Writ Petition No.772 of 2014 is
allowed to be withdrawn with liberty to file the
appeal before the State Government.
