4/03.02.2021 After some arguments, learned counsel appearing for the
petitioner seeks permission to withdraw this criminal miscellaneous
petition with a liberty to raise all the points, which have been raised in this
petition, at an appropriate stage by filing a application for discharge.
 Prayer is allowed.
 Let this criminal miscellaneous petition be dismissed as
withdrawn with the liberty aforesaid.
 If any discharge application is filed by the petitioner, the same
should be considered on its own merit and a reasoned order should be
passed on the discharge application, without being prejudiced by this
order of withdrawal passed by this Court.
