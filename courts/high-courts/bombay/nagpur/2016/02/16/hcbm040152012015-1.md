This is Misc. Civil Application to restore Second Appeal No.
271 of 2012 which automatically stood dismissed on 8th June, 2015 as
per the order dated 26th March, 2015 on failure to file a private paper-book.
Accepting the reasons given in the application explaining the
situation which led to dismissal of the Second Appeal to be
satisfactory, Misc. Civil Application is allowed. Second Appeal No. 271
of 2012 is restored to its file.
