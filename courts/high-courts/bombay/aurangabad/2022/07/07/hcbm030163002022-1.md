PER COURT :-
. This is an application for permitting the Applicant
no.4-Anand Pimpalgaonkar in this case to be added as the
Applicant no.4 in the Criminal Application no.725 of 2020.
This course is not available to the applicant. He will have to
file fresh application on separate grounds. Therefore, this
application is rejected. However, we are granting liberty to
the Applicant no.4 in this application to prefer a separate
application for the reliefs claimed by other Applicants in
Criminal Application No.725 of 2020. With these directions,
the application is disposed off.
(BHARAT P. DESHPANDE, J.) (SARANG V. KOTWAL, J.)
