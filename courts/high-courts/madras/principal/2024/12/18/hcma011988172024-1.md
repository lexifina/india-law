COMMON ORDER
These applications have been filed by the applicant/plaintiff
seeking to amend the name of the fourth defendant.
2. Learned counsel for the respondents/defendants have not
raised any serious objection for allowing these applications.
3. This Court is satisfied with the reasons contained in the
affidavits filed in support of these applications since sufficient cause has
been shown.
4. Accordingly, these applications are allowed as prayed for.
5. Learned counsel for the applicant/plaintiff is directed to
carry out the amendment in terms of the order passed by this Court.
Post the matter for filing amended copy of the plaint on
22.01.2025.
