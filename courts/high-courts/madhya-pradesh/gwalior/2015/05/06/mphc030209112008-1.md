# High Court of Madhya Pradesh, WP/5845/2008, 2015-05-06

Writ Petition No.5845/2008
Prakash Chandra Shrivastava
vs.
State of MP & others
 1
06.05.2015
Shri C.P.Singh, Advocate for the petitioner.
Smt. Nidhi Patankar, Govt. Advocate for the
respondent/State.
With the consent, matter is heard.
The petitioner is aggrieved by order dated
11.10.2007, whereby the respondents have decided to
inflict recovery. It is mentioned that if the petitioner fails to
deposit the amount, a recovery shall be made from him.
The singular ground to assail this order is that no
opportunity is provided to the petitioner in this regard.
The State has not chosen to file reply till date. An
ex parte interim order is continuing since 9.1.2009.
Considering the aforesaid, I deem it proper to set aside
the order dated 11.10.2007 (Annexure P/1) because the
same is passed without following principle of nature
justice. The impugned order is set aside. Liberty is
reserved to the respondents to proceed against the
petitioner in accordance with law.
Since the impugned order is passed in 2007, the
