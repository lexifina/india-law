# High Court of Jharkhand, Cr.M.P./270/2018, 2019-01-02

IN THE HIGH COURT OF JHARKHAND AT RANCHI
 Cr. M.P. No. 270 of 2018
 Parmeshwar Sahu .... Petitioner
 Versus
 The State of Jharkhand … Opposite Party
 ---
 CORAM: HON’BLE MR. JUSTICE RONGON MUKHOPADHYAY
 ---
 For the Petitioner : Ms. Sunita Kumari, Advocate
 For the State : Mr. Ram Prakash Singh, APP
 Order No. 07 Dated 02nd January, 2019
 I.A. No. 10672 of 2018
 Heard Ms. Sunita Kumari, learned counsel for the petitioner and Mr.
Ram Prakash Singh, learned A.P.P. for the State.
 In this application the petitioner has sought for amendment in the
main application in view of the order dated 24.01.2018/01.02.2018 due to
inadvertence by which process u/s 83 Cr.P.C. has been ordered to be issued
was never mentioned in the main application therefore necessitating the
present amendment application.
 Considering the averment made in the instant application and in
order to avoid multiplicity of proceeding, this amendment application stands
allowed.
 Let I.A. No. 10672 of 2018 be treated as part of the main application.
Cr.M.P. No. 270 of 2018
 In this application the petitioner has prayed for quashing of the
requisition dated 09.12.2017 as well as the subsequent order dated 23.12.2017
passed by learned Judicial Magistrate, Gumla in connection with Sisai P.S.
Case No. 71 of 2017 (G.R. No. 620 of 2017) by which proclamation u/s 82
Cr.P.C. has been ordered to be issued. A supplementary affidavit has been
filed by the petiotner in which the order dated by which proclamation has been
directed to be issued has been brought on record, which is the order dated
12.12.2017/23.12.2017. By virtue of I.A. No. 10672 of 2018 having been allowed
by this Court, the petitioner also has challenged the order dated
24.01.2018/01.02.2018 by which process u/s 83 Cr.P.C. has been ordered to be
issued.

 2.
 None of the orders dated 12.12.2017/23.12.2017 as well as
24.01.2018/01.02.2018 indicates subjective satisfaction on the part of the
learned Magistrate necessitating taking of coercive steps against the petitioner
and same are hereby quashed and set aside
 This application is allowed.
 However, the learned court below is at liberty to proceed further in
accordance with law.
 Pending I.A. stands disposed of.

 (Rongon Mukhopadhyay, J)
