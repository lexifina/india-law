# Allahabad High Court, WRIC/18753/2019, 2019-05-29

Court No. - 38
Case :- WRIT - C No. - 18753 of 2019
Petitioner :- Suraj Rai
Respondent :- State Of U.P And 3 Others
Counsel for Petitioner :- Sudist Kumar
Counsel for Respondent :- C.S.C.
Hon'ble Abhinava Upadhya,J.
Hon'ble Saurabh Shyam Shamshery,J.
Learned counsel for the petitioner submits that a committee has
been constituted for providing security which assesses the threat
perception on the person claiming security from the State
Government which has not been impleaded as a party . Learned
counsel for the petitioner submits that the writ petition may be
dismissed with the liberty to file a fresh petition arraying
necessary party.
With the aforesaid liberty, the writ petition is dismissed.
Order Date :- 29.5.2019
VPC
(Saurabh Shyam Shamshery,J) (Abhinava Upadhya,J)
