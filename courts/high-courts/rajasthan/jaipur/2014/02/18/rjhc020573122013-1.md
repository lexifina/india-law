# High Court of Rajasthan, WMAP/337/2013, 2014-02-18

IN THE HIGH COURT OF JUDICATURE FOR RAJASTHAN
AT JAIPUR BENCH JAIPUR
S.B. Civil Misc. Application No.337/2013
Prabodh Kumar Singh & Anr.
Versus
State of Rajasthan & Ors.
DATE OF ORDER : 18/02/2014
HON'BLE MR. JUSTICE M.N. BHANDARI
Mr. Rajendra Prasad, AAG, for applicants
Mr. Shobhit Tiwari, for non-applicants
***
 This application has been moved for correction of
typographical mistake in the order dated 18.07.2013. All the
counsel agreed that wherever year 1996-97 has been
mentioned, it should be read as 1997-98.
 As agreed by the parties, application for correction is
allowed with the direction that wherever year 1996-97 has been
mentioned in the order dated 18.07.2013, it would be read as
1997-98. This order would be treated as part of the order dated
18.07.2013.
 The respondents would be expected to now comply with
the direction of this court if they have not challenged it before
the Division Bench.
 [M.N.BHANDARI], J.
