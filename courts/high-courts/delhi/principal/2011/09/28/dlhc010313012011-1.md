Vide impugned order dated t9.I.2OIL, the learned Single
Judge has dismissed the Review Application filed by the appellant herein
and stayed another application. The main grievance of the appellant in
this appeal is that in the order passed by the learned Single Judge in
Review Application as well as the application, i.e., CA No.75O0l2010 vide
which the appellant has sought to withdraw his consent given earlier, no
appeal lies against such order. Order 47 Rule VII of the Code of Civil
Procedure specifically bars the appeal against the order passed in the
review application. Likewise, Order 43 Rule III of the Code of Civil
Procedure lists certain orders against which appeal can be filed and order
passed in such an application seeking consent, which application was filed
under Section 151 of Code of Civil Procedure, no appeal is filed.
This appeal as well as application is dismissed as not
maintainable.
