P.C. :
1. Learned counsel for the applicant states that,
inadvertently the applicant has filed two bail applications in the
same case and, therefore, he has instructions to withdraw this
application i.e. Criminal Bail Application No.491 of 2020.
2. Considering these circumstances, this application is
allowed to be withdrawn.
3. Liberty is granted to the applicant to file a praecipe for
fresh circulation of other bail application filed by him.
4. Criminal Bail Application No.491 of 2020 stands
disposed of in these circumstances.
