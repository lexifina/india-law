ORDER :
1. The application is filed for setting aside the order
made by the learned Registrar Judicial by which registration of
the second appeal is refused. The learned counsel for the
applicants is taking blame to himself. In view of the submissions
made and contentions made in the application, the application is
allowed. Delay, if any, is condoned. The order of learned
Registrar judicial is set aside. Matter is restored. If office
objections are not removed prior to 12.8.2016, it is to be
presumed that the present application is dismissed.
