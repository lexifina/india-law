Code of Criminal Procedure, 1973 for grant of bail. The First Bail
Application i.e. MCRC No. 531/2021 was dismissed as withdrawn

(C.G.) for the offence under Section 394 of Indian Penal Code.

application with liberty to file afresh as and when occasion arises.
5) Accordingly, the Second Bail Application is dismissed as
withdrawn with the liberty as stated above.
