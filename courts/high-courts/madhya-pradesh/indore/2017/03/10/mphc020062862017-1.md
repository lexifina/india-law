# High Court of Madhya Pradesh, MCRC/2621/2017, 2017-03-10

MCRC-2621-2017
(RAVI Vs THE STATE OF MADHYA PRADESH)
10-03-2017
Ms. Shraddha Dixit, learned counsel for the applicant.
Shri Mukesh Kumawat, learned counsel for the
respondent/State.
Case diary is available.
This is fifth bail application under Section 439 of the Code of
Criminal Procedure for grant of bail. His fourth bail application
was considered and dismissed in M.Cr.C.No.11884/2016 vide
order dated 02.01.2017.
Now this fifth application is filed claiming parity with co-accused-Mohanlal who was granted bail by the common order,
while the bail application of the present applicant was
dismissed.
Arguments heard, case diary perused.
Learned counsel for the State opposes the bail application.
The case of the present applicant was considered while
dismissing his fourth application and, therefore, no ground is
made out for consideration of this 5th application.
Accordingly, this application is dismissed.
Certified copy as per rules.
(ALOK VERMA)
JUDGE
