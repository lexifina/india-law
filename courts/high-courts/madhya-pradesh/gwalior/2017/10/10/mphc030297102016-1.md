# High Court of Madhya Pradesh, MCRC/13835/2016, 2017-10-10

MCRC 13835/2016
National Fertilizers Ltd. Vijaipur & Anr. Vs. State of MP
10/10/2017
Shri Devendra Sharma, counsel for the applicants.
Shri BPS Chauhan, Public Prosecutor for the
respondent/ State.
This Court by order dated 13/02/2017 had granted
time to the applicants to file an application for converting
the petition under Section 482 of CrPC for restoration of
Criminal Revision No.364/2011 instead of recalling the
order dated 27/10/2016. Thereafter, the case was taken
up on 07/07/2017 and none appeared for the applicants.
Till today, though the application has not been filed but
the counsel for the applicant seeks permission of this
Court to withdraw this application with liberty to the
applicants to file a properly constituted application for
restoration of Criminal Revision No.364/2011.
The prayer appears to be bona fide. Accordingly, it
is accepted.
The present application is dismissed as withdrawn
with liberty to the applicants to file a properly
constituted application.
 (G.S. Ahluwalia)
 Judge
MKB
