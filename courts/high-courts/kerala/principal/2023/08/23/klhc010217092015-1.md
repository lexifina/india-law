ORDER
When this Criminal Miscellaneous Case came up for
consideration, this Court directed the Registry to get a
report as to whether S.C.No.41/2011 is still pending. The
First Additional Sub Judge, Nedumangadu forwarded a
letter in which it is stated that the proceedings in
S.C.No.41/2011 is quashed by this Court as per order
dated 08.11.2018 in Crl.M.C. No.4687/2014. Therefore,
no further order is necessary in this case.
Accordingly, this Crl.M.C. is closed.
