# High Court for the State of Telangana, CC/1117/2017, 2017-06-30

THE HONíBLE SRI JUSTICE CHALLA KODANDA RAM
CONTEMPT CASE No.1117 of 2017
ORDER:
 This Contempt Case is filed alleging willful disobedience of
order dated 01.04.2016, passed by this Court in W.P.No.14453 of
2017.
 Today, when the matter is taken up for hearing, the learned
counsel for the petitioner submits that the respondents have
complied with order dated 01.04.2016, passed by this Court in
W.P.No.14453 of 2017, on 14.06.2017.
 In that view of the matter, though there is a slight delay in
complying with the order of this Court, inasmuch as the
respondents have complied with the order of this Court on
14.06.2017, the contempt case is liable to be closed.
 Accordingly, the Contempt Case is closed. No order as to
costs.
 Miscellaneous Petitions, if any, pending in this contempt
case shall also stand closed.
_____________________________
CHALLA KODANDA RAM, J.
