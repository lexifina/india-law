2. In view of Rule 103 of Order XXI of the Code of Civil Procedure,
orders passed in applications filed under order XXI Rule 97 to 100 of the
Code of Civil Procedure for determination of the question under Rule 98
and 101 are deemed to be decrees and are appealable as if it were a decree.
3. Hence, this Revision is not maintainable. The Revision is
therefore dismissed with liberty to the petitioner to file appropriate appeal
before the concerned appellate Court. No costs. Consequently, the
connected miscellaneous petition is closed. The certified copy of the fair
and decreetal order filed in this Revision are directed to be returned to the
counsel to enable him to file an appeal.
