# Allahabad High Court, A482/11579/2019, 2019-03-29

Court No. - 73
Case :- APPLICATION U/S 482 No. - 11579 of 2019
Applicant :- Shakir
Opposite Party :- State Of U.P. And 3 Others
Counsel for Applicant :- Anurag Shrivastava
Counsel for Opposite Party :- G.A.
Hon'ble Neeraj Tiwari,J.
Learned AGA has raised preliminary objection and submitted
that this application is not maintainable as against the order
impugned, applicant has alternative remedy to file revision
under sections 397/401 Cr.P.C.
Learned counsel for the applicant could not dispute the
aforesaid fact.
The application is dismissed with liberty to the applicant to
approach competent court, if so advised.
Certified copy of the order be returned to learned counsel for
the applicant after keeping the photocopy of the same in the
record.
Order Date :- 29.3.2019
