P.C. :
1. This is a successive application for bail. The earlier Application
preferred by the Applicant for Bail was rejected by this Court by an Order
dated 14th December, 2018.
2. After hearing learned counsel appearing for the Applicant at
length, when this Court was not inclined to grant any relief, the learned
counsel, on instructions, seeks leave to withdraw present Application.
3. Leave granted.
4. Application is dismissed, as withdrawn.
5. Record indicates that, the Applicant is in Jail since 1st March
2018. In present case i.e. Session Case No.61/2018 pending on the file of
learned Session Judge, Raigad, Alibaugh charge is not yet framed.
