# Allahabad High Court, A482/6246/2023, 2023-04-04

Court No. - 68
Case :- APPLICATION U/S 482 No. - 6246 of 2023
Applicant :- Smt Gudiya @ Ruksar
Opposite Party :- State Of U.P. And 2 Others
Counsel for Applicant :- Pawan Kumar
Counsel for Opposite Party :- G.A.
Hon'ble Mrs. Manju Rani Chauhan,J.
The present application u/s 482 has been filed challenging the
order dated 02.02.2023 vide which the victim has been sent in
Rajkiya Bal Grah, Nidhariya, District- Ballia.
Learned A.G.A. has pointed out that the order is revisable.
Accordingly, the application u/s 482 Cr.P.C. is dismissed with
liberty to file revision.
Certified copy of the impugned order, if any, be returned to the
learned counsel for the applicant after retaining the photo copy of
the same.
Order Date :- 4.4.2023
Rahul.
