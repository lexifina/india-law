This court has perused the order impugned and has found that the
petitioner has been debarred from filing written statement vide order dated
04.08.2012 as contained in Annexure-2 to the writ petition and thereafter
written statement has been filed, the same has been rejected on the
ground that vide order 04.08.2012 since petitioner has been debarred
hence, there is no question of accepting written statement so long the
order dated 04.08.2012 is in existence.
Learned counsel for the petitioner after making some arguments
seeks permission to withdraw this written petition.
In view thereof, the writ petition is dismissed as withdrawn.
