JUDGMENT
The petitioner is concerned with the building, constructed
with two shop rooms which, the petitioner contends, is built in 2002.
The petitioner contends that the petitioner had not approached the
Panchayat for any numbering of the building for long years after that,
since the petitioner was employed in the Middle-East. The petitioner
made an application in 2014, which was rejected as per order
No.A2-9710/15 dated 08.01.2016, which reads as under:

The said order is produced across the Bar, which the petitioner is

2. As of now, the petitioner in the above writ petition
seeks issuance of a building number on the basis of the present set
back provided under the Panchayat Building Rules, 2011. The same
cannot be permitted, since there is nothing to prove the petitioner's
submission that the building was constructed in 2002. Admittedly the

set back to be provided would depend upon the time when the
building was constructed. Though there was no Building Rules
applicable to the Panchayat, the Kerala Municipality Building
Rules, 1999 were made applicable by Circular No.24136(1)/
R.A.1/07/LSGD dated 25.07.2007 and later the Kerala Panchayat
Building Rules, 2011 also came into force. The petitioner's
application for numbering itself is in 2014. In such circumstance,
there can be no reliance placed on the Building Rules to claim that
the set back provided is in consonance with the set back now
provided in the Rules. The petitioner's remedy would be to
approach the appropriate authority for regularisation of the
construction, which has to be done by the petitioner in accordance
with the Kerala Panchayat Building Rules, 2011.
Leaving liberty to such remedy, the writ petition is
dismissed. No costs.
