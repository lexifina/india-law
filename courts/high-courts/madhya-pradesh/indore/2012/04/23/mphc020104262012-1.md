# High Court of Madhya Pradesh, MCC/543/2012, 2012-04-23

18
MCC No.543/2012
23/4/2012
Ms. Seema Sharma, counsel for petitioner.
This is a petition for correction in the order dated
29/3/2012 passed in W.P.No.2788/2012.
Learned counsel for petitioner submits that there is a
typographical error. In first para of the order, the date is
mentioned as 10/4/2008 which ought to have been
1/4/2010 and in last para of order the date of retirement is
shown as 31st July 2912 which ought to have been 31st July
2012 and also, no time limit has been given for deciding the
representation.
From perusal of order, it transpires that there are
typographical errors. Accordingly, in first para of order the
date mentioned as 10/4/2008 be read as 1/4/2010 and date
of retirement as shown as 31th July 2912 be read as 31st
July, 2012 and competent authority is directed to decide the
representation within two months from the date of receipt of
copy of the order.
Let a copy of this order be placed in the record of
W.P.No.2788/2012.
(N.K.MODY)
 JUDGE
MK
