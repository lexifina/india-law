# High Court for the State of Telangana, WP/18160/2017, 2017-06-07

HONíBLE SRI JUSTICE SURESH KUMAR KAIT
AND
HONíBLE Dr. JUSTICE SHAMEEM AKTHER
WRIT PETITION No.18160 of 2017
ORDER : (ORAL)
 (per Honíble Sri Justice Suresh Kumar Kait)
 Ms. K. Jyothi Prasad, learned counsel for the petitioner,
seeks permission of this Court to withdraw the instant writ
petition with a liberty to the petitioner to file a fresh writ
petition seeking appropriate relief.
2. Permission is accorded. Accordingly, granting the liberty
as prayed for, this writ petition is dismissed as withdrawn.
No order as to costs.
3. As a sequel, miscellaneous petitions pending, if any,
shall stand closed.
4. Registry is directed to return the original documents to
the learned counsel for petitioner.
