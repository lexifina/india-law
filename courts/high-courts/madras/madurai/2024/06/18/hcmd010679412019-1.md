 JUDGMENT
This Second Appeal is filed to set aside the judgment and decree
dated 05.02.2019 in A.S.No.52 of 2018 on the file of the learned Sub
Judge, Aranthangi, concurrent the judgment and decree dated 31.07.2013
passed in O.S.No.135 of 2005 on the file of the learned District Munsif,
Aranthangi.
2. There was no representation for the appellant on 30.04.2024.
Today also none appeared for the appellant. But the learned counsel for
the respondent present.
3. Therefore, this Court is of the view that no purpose is going to
be served in keeping this Appeal, pending. Accordingly, this Second
Appeal is dismissed for default. No costs. Consequently, connected
miscellaneous petitions are closed.
