3. The scope of special appeal is ordinarily confined to those facts
and grounds, which are pleaded, argued, and are discussed in the
judgm ent. No new point can be taken up, unless it was argued before
learned Single Judge, and if the point was taken and has not been
discussed, the petitioner may file a review petition, if he is so advised.
4. The Special Appeal is dismissed, with liberty to the petitioner to
file an appropriate review petition before learned Single Judge.
