# Allahabad High Court, A482/31077/2019, 2019-09-11

Court No. - 64
Case :- APPLICATION U/S 482 No. - 31077 of 2019
Applicant :- Parashuram
Opposite Party :- State Of U.P. And Another
Counsel for Applicant :- Pradeep Kumar Tiwari
Counsel for Opposite Party :- G.A.
Hon'ble Karuna Nand Bajpayee,J.
Shri Sami Ullah Khan has filed his Vakalatnama on behalf of
opposite party No.2, which is taken on record.
Heard learned counsel for the applicant, opposite party No.2 as
well as learned A.G.A. Perused the record.
It appears that by way of passing order dated 18.12.2018 this
Court had already given the direction to the applicant to appear
before the court below and obtain bail but the protective
direction issued by this Court has not been availed so far. Now
the applicant again approaches with the same prayer and wants
the same relief. It is a clear misuse of court's proceedings.
Application stands dismissed with no liberty to file any petition
in this regard.
Order Date :- 11.9.2019
P.S.Parihar
