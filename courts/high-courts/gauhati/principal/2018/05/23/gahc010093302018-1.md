ORDER
Date : 23-05-2018
Heard Mr. I.H. Khan, learned counsel for the applicant. Also heard Mr. B. Gogoi, learned
counsel for the opposite parties.
This application has been filed seeking correction of an alleged typographical error
wherein the name of the petitioner no. 2 has been mentioned in the cause title as “Md. Yasir Ali”.
According to Mr. Khan, his name ought to have been reflected as “Md. Yaasin Ali” but I find from
the record that the name of the petitioner no. 2 has been mentioned as “Md. Yasir Ali” and that is.
how it has been projected in the order.
In view of the above, there is no typographical error in the order which calls for correction.
IA stands dismissed.
 JUDGE
Sukhamay
Comparing Assistant
