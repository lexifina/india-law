# High Court of Madhya Pradesh, MCRC/11599/2014, 2014-12-08

1 M.Cr.C. No. 11599/2014
08/12/2014
Shri Rishikesh Bohare, Advocate for the applicants, wants
to withdraw the application with liberty that if the applicants file
regular bail application before the concerned Trial Court, the same
may be directed to be decided on the same day.
Considered.
It is directed that if the applicants surrender before the learned
trial court within seven days and file an application for regular bail,
the same may be decided as expeditiously as possible.
This M.Cr.C. is dismissed as withdrawn with the aforesaid
liberty.
 (S.K. Palo)
 Judge
