# High Court for the State of Telangana, TRCMP/683/2017, 2017-11-28

THE HONíBLE DR. JUSTICE B.SIVA SANKARA RAO
Tr.CMP.No.683 OF 2017
ORDER:
 Heard.
 Undisputedly, there is an ex parte decree and an
application to set aside the same filed is still pending and
unless the same is decided and O.P. restored, if any, the
question of considering the petitionerís request to transfer
does not arise.
 Having regard to the above, the transfer civil
miscellaneous petition is closed, giving liberty any such
contingency in future to make fresh application.
Miscellaneous petitions pending consideration, if any, in this
case shall stand closed in consequence. No order as to costs.
