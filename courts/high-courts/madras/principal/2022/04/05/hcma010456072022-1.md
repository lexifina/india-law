ORDER

The present petition has been filed seeking a direction
to the 1
st respondent to make necessary arrangements to provide
the pathway to the petitioner's land within the time stipulated
by this Court.
 2. The petitioner's property is situated in Tirunelveli
District, however, instead of approaching Madurai Bench of this
Court, the petitioner has filed this Writ Petition before this
Court, which cannot be entertained. Therefore, this Writ
Petition is rejected. Consequently, the connected Miscellaneous
Petitions are closed.
 3. Registry is directed to return the impugned order back
to the petitioner to enable the petitioner to file an
appropriate application before the Madurai Bench of this Court,
if so advised.
