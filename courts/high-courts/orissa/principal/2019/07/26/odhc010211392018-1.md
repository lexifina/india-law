# High Court of Orissa, ABLAPL/5634/2018, 2019-07-26

05. 26.07.2019 Heard learned counsel for the parties.
 Learned counsel for the State on instruction
submits that no F.I.R. has been registered against the
petitioners for commission of any cognizable offences.
 In view of the fact that no F.I.R. has been lodged
against the petitioners, this application for anticipatory bail
is premature.
 ABLAPL is accordingly dismissed as not
maintainable.
 It is open for the petitioners to file fresh
application as and when any formal F.I.R. is registered
against them for commission of any cognizable offences.
