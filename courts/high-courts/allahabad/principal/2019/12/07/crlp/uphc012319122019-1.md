# Allahabad High Court, CRLP/25054/2019, 2019-12-07

Court No. - 51
Case :- CRIMINAL MISC. WRIT PETITION No. - 25054 of 2019
Petitioner :- Shoukeen Ahmad Ahmad @ Shoukeen
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Manoj Kumar Srivastava
Counsel for Respondent :- G.A.
Hon'ble Vipin Sinha,J.
Hon'ble Raj Beer Singh,J.
Learned counsel for the petitioner has very fairly informed the Court that
earlier the petitioner had filed a writ petition being no. 17824 of 2019
which was got dismissed as withdrawn vide order dated 4.7.2019 with
liberty to the petitioner to file anticipatory bail application. It has further
been informed that in pursuance of the said order, an anticipatory bail
application was filed before another Bench of this Court, which however
has been rejected on 18.9.2019, copy of the order is annexed with the writ
petition.
In this view of the matter, the present writ petition being second writ
petition for the same cause of action is not maintainable and the same is
dismissed as such.
Order Date :- 7.12.2019
