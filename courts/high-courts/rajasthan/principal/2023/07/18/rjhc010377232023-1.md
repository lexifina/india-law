Order
18/07/2023
The instant misc. application has been filed seeking
correction in the order dated 18.04.2023 passed by this Court in
S.B. Criminal Misc. Bail Application No.2378/2023 as far as the
amount in the second last para of the order has been mentioned
as ‘Rs.2,00,000/-’, instead of ‘2,50,000/-’.
For the reasons contained in the application, the same is
allowed and it is ordered that in the second last para of the order
dated 18.04.2023, amount ‘2,00,000/-’ be read as ‘2,50,000/-’.
This order shall be treated as part and parcel of the order
dated 18.04.2023.
