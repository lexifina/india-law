JUDGMENT
The dismissal of an application filed under Order 21 Rule 90
of the Code of Civil Procedure seeking to set aside an execution
sale, is impugned in this Original Petition. The order is appealable
in nature under Order 43 Rule 1(j) of the Code of Civil Procedure.
Without prejudice to the right of the petitioner to challenge
the impugned order in appeal, this Original Petition is closed.
