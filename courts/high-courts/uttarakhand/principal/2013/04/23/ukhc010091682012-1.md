# High Court of Uttarakhand, SPA/270/2012, 2013-04-23

MCC Review Application No. 90 of 2013
CLMA Delay Condonation Application No. 2441 of 2013
In
SPA No. 270 of 2012
Hon’ble Barin Ghosh, C.J.
Hon’ble V.K. Bist, J.
Mr. S.C. Bhatt, Advocate for the review applicant.
Mr. Chetan Joshi, Brief Holder for the State of
Uttarakhand / appellants.
There is some delay in filing the present Review
Application. Accordingly, an Application for
condonation of delay has been filed, which is not being
seriously objected to by the learned counsel for the State.
We have also independently considered the averments
made in the Application for condonation of delay and,
being satisfied with the sufficiency of the reasons for the
delay, allow the Application and, thereby, condone the
delay.
The Application for review has been filed in order
to reargue the case on new principles. The same is not
permissible. Review Application fails and the same is
dismissed.
 (V.K. Bist, J.) (Barin Ghosh, C.J.)
23.04.2013
Rathour
