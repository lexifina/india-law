# Allahabad High Court, A482/10933/2022, 2022-05-13

Court No. - 43
Case :- APPLICATION U/S 482 No. - 10933 of 2022
Applicant :- Sunil Babu And 2 Others
Opposite Party :- State Of U.P. And Another
Counsel for Applicant :- Vinay Kumar,Kumar Beenu Singh
Counsel for Opposite Party :- G.A.
Hon'ble Shamim Ahmed,J.
List has been revised. None appears for the applicants.
Heard learned AGA for the State and perused the record.
Learned AGA has pointed out that this is the second application
u/s 482 CrPC as earlier for the same relief the applicants have
filed an application u/s 482 CrPC No.41582 0f 2018 which was
disposed of by this Court vide order dated 11.12.2018.
Accordingly, the present application u/s 482 CrPC is not
maintainable for the same relief and the same is dismissed.
