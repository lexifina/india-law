# High Court of Madhya Pradesh, MCC/316/2017, 2017-02-03

MCC-316-2017
(COMMISSIONER Vs M/S THE CLIQUE )PERSONALITY DEVELOPMENT INSTITUTE))
03-02-2017
Shri Gautam Prasad, learned counsel for the application.
This application has been filed for restoration of C.E.A. No.15/2015
which has been dismissed on account of peremptory order dated
02.09.2016 (Annexure A-1).
There is some delay in filing the application (I.A. No.1645/2017)
has been filed seeking condonation of delay.
Keeping in view the reasons indicated in the application and
finding the same to be bonafide, delay in filing the restoration
application is condoned and the application for restoration of
C.E.A. No.15/2015 is allowed. C.E.A. No.15/2015 is restored to its
original number.
List for order before the appropriate Bench.
(RAJENDRA MENON)
ACTING CHIEF JUSTICE
(SMT. ANJULI PALO)
