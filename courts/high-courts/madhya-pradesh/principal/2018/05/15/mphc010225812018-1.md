# High Court of Madhya Pradesh, CONC/1353/2018, 2018-05-15

THE HIGH COURT OF MADHYA PRADESH
CONC-1353-2018
(SMT. LAXMI GARG Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 15-05-2018
Shri Shyam Yadav, counsel for the petitioner submits that interim
order dated 31.7.2013 passed in W.P.No.3036/11 has not been
honoured by the respondents.
In the opinion of this court, petitioner can file interlocutory application
in the pending writ petition and there is no need to file separate
contempt petition.
With aforesaid observation, this contempt petition is dismissed.
(SUJOY PAUL)
JUDGE
