# High Court for the State of Telangana, WP/22304/2017, 2017-07-20

THE HONOURABLE Dr.JUSTICE B.SIVA SANKARA RAO
WRIT PETITION No.22304 of 2017
ORDER :
Learned counsel for the petitioners seeks permission to
withdraw the Writ Petition with liberty to file a fresh writ
petition.
Permission is accorded, as sought for.
Accordingly, the Writ Petition is dismissed as withdrawn.
The Registry is directed to return the original papers to the
learned counsel for the petitioner.
Consequently, miscellaneous petitions, if any, pending shall
stand closed. No costs.
