-----------------
CORAM: HON'BLE MR. JUSTICE SHREE CHANDRASHEKHAR
For the Petitioner : Mr. N. N. Mishra, Advocate
For the State : Mr. R. Vardhan, APP
------------------
04/28.06.2017 The learned counsel for the petitioner submits that
inadvertently, against the order dated 16.05.2017 in G.R. Case
No. 874 of 2016 the instant bail application has been filed,
whereas the petitioner is required to file appeal. He seeks liberty
to file a fresh petition and he prays for a liberty to obtain the
certified copy of the impugned order dated 16.05.2017 which
has been filed along with the instant bail application.
Prayer is granted.
Registry is directed to give certified copy of the
impugned order dated 16.05.2017 to the learned counsel for the
petitioner, while keeping a xerox copy of the same on record.
The petitioner shall be at liberty to file a fresh petition.
With the aforesaid liberty, the instant bail application
is disposed of.
 (Shree Chandrashekhar, J.)
