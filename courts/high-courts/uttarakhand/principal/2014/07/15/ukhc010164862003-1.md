# High Court of Uttarakhand, WPMS/738/2002, 2014-07-15

Review Application (MCC) No.478 of 2014
In
WPMS No.738 of 2002
Honíble Sudhanshu Dhulia, J.
Mr. C.K. Sharma, Advocate,
present for the petitioner/review
applicant.
Mr. B.P.S. Mer, learned Brief
Holder, present for the State of
Uttarakhand.
This is an application (CLMA
No.7464 of 2014) for condonation of
delay in filing review application.
On the grounds urged and in the
interest of justice, the application is
allowed. Delay is condoned.
This court had earlier dismissed
the writ petition on the ground that the
land in question now vests with the
State. Now a review application has
been filed.
There is no error apparent on the
face of record, which may call for any
interference with the order. In any case,
under Order 47 Rule 1 of the Code of
Civil Procedure, the scope for review is
very limited.
In view thereof, the review
application is dismissed.

 (Sudhanshu Dhulia, J.)
