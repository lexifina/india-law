 Learned counsel for the applicant, on instructions,
seeks permission to withdraw this application. It is stated that
applicant is in custody from 29th April, 2018. Applicant seeks
liberty to file fresh application for bail in the event trial does not
commence within a period of six months. Hence, Bail application
is allowed to be withdrawn with liberty to prefer an application
for bail, if trial does not commence within a period of six months.
Criminal Bail Application is disposed of, as withdrawn.
