Order
15/05/2023
The present misc. application has been filed by learned
counsel for the petitioner seeking modification / correction in the
order dated 03.02.2023 passed in S.B. Criminal Misc. Bail
Application No.15821/2022, stating therein that the bail
application was dismissed as not pressed with the liberty to file a
fresh bail application. However, inadvertently, it was typed as
‘after the statement of the injured is recorded’ in place of ‘after
the statement of the Investigating Officer - Kishan Lal
Bishnoi is recorded’.
For the reasons mentioned in the present misc. application,
the same is allowed.
It is ordered that the order dated 03.02.2023 passed in S.B.
CRLMB No.15821/2022 be read as under:-

(2 of 2) [CRLMA-149/2023]
“Learned counsel for the petitioner does not want to
press this bail application at this stage. He, however,
prays for liberty to file fresh bail application after the
statement of the Investigating Officer Kishan Lal
Bishnoi is recorded.
The present bail application is, therefore, dismissed
as not pressed with the liberty aforesaid.”
To the above extent, the order dated 03.02.2023 stands
corrected/modified.
This order shall be treated as part and parcel of the order
dated 03.02.2023.
(KULDEEP MATHUR),J
