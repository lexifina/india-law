Short reply filed on behalf of the State be taken on record.
Learned counsel for the petitioner has contended that this
revision petition has become infructuous, since the main suit in which the
order was passed which had been set aside in appeal by learned Addl.

default.
Learned State counsel affirms this fact.
It being so, the revision petition does not survive and is
dismissed as infructuous.
