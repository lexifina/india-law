RMT.TEEKAA RAMAN, J.
This Application has been filed to amend the Plaint as follows:
a.In Plaint para 5, after the words 'at Chennai on', date is mentioned as 7.7.2018,
but he correct date is 17.7.2018. Therefore, the date 7.7.2018 in para 5 has to be
amended as 17.7.2018.
b.In para No.9 of the Plaint, 4
th
 row in the Tabular column, Cheque Number has
been mentioned as 527438, but the correct number is 537438. Therefore the
cheque number 527438 has to be amended as 537438.
c.In para No.13 of the Plaint, in column No.6 of the 1
st
 row, in the Tabular
column, it has been mentioned as “a)on 11.6.2020, paid Rs.15,00,000/- by
RTGS vide UTR No.”, instead of “RTGS vide UTR No” to be mentioned as
FT-CR-01241000034639”
d.In Para No.15 of the Plaint, in column No.6 in the 2
nd
 row, in the tabular
column, it has been mentioned as “a)on 11.6.20, Rs.15,00,000/- by RTGS vide
CR-01241000034639”, instead of RTGS, to be mentioned “Fund Transfer”.
2.Heard the learned counsel for the Applicant.
3.Having been satisfied with the submission made by the learned counsel
for the Applicant, in the interest of justice, this Application is ordered as prayed
for.
