JUDGMENT
This original petition is filed challenging an order passed in
application to set aside the ex-parte order. The petitioner was the 1st
respondent in OP(MV)No.151/2017 on the filed of the Motor
Accident Claims Tribunal, Kasaragod. Petitioner was set ex-parte.
Thereafter, petitioner filed an application to set ex-parte order. This
application was filed on 3.07.2018. This application was dismissed
on 26.07.2018, by Ext.P7 order. Thereafter, an award was passed
26.07.2018.
2. By the award petitioner was directed to deposit the
compensation amount.
3. The reason for dismissal was on the ground that
application was belated. It is to be noted that the award was passed
only on 26.07.2018. The petitioner submitted the application for
setting aside on 03.07.2018. The Tribunal could have given an
opportunity to the petitioner to contest the matter. No other reason

OP (MAC).No.131 OF 2018
..4..
has been stated in that order for declining the application to set aside
the ex-parte order.
4. In such view of the matter, the impugned order is set
aside. Consequently, the award passed in the matter is also set
aside. The application filed by the petitioner for setting aside the
ex-parte award along with the delay condonation petition are
allowed. Parties are directed to appear before the Tribunal on
22.11.2019.
The OP(MAC) is disposed as above.
