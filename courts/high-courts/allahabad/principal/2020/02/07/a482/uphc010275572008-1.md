# Allahabad High Court, A482/25835/2008, 2020-02-07

Court No. - 92
Case :- APPLICATION U/S 482 No. - 25835 of 2008
Applicant :- Mohd. Anam Alias Guddu
Opposite Party :- State Of U.P.And Others
Counsel for Applicant :- Madan Mohan Srivastava
Counsel for Opposite Party :- Govt. Advocate
Hon'ble Pradeep Kumar Srivastava,J.
List has been revised. None is present to press this application
on behalf of the applicant.
It appears that after filing of this application on none of the date
when the case has been listed, anyone has present for the
applicant.
Learned A.G.A. for the State is present.
It appears that this application under Section 482 Cr.P.C. has
been given with the request for quashing the order dated
26.5.2008 passed by the Judicial Magistrate 1st, Court No.25,
Azamgarh, by which the application no.17 of 2008, under
Section 156(3) Cr.P.C. has been rejected.
Since, none is present to press this application and moreover, if
the application under Section 156(3) Cr.P.C. was rejected, the
applicant had every right to file a complaint case in the matter.
Considering from both the angle, I do not find any force in the
application and the application is dismissed.
Order Date :- 7.2.2020
