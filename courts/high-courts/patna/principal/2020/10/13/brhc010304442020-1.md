ORAL ORDER
2 13-10-2020 Learned counsel for the petitioner has informed that due to
some mistake in the Registry/Office, for the same filing two Token
Numbers were generated. The first Token Number was later on
registered as Cr. Misc. No. 20909/2020 in which this petitioner has
already been granted bail vide order dated 25.06.2020 passed by
learned coordinate Bench of this Court. It is submitted that the
present case arises out of a subsequent Token Number generated for
the same e-filing, therefore, this may be permitted to be withdrawn.
Mr. Akhileshwar Dayal, learned APP Incharge appears on
behalf of the State.
In the aforesaid circumstances, this application is
dismissed as withdrawn.

Rajeev/-
