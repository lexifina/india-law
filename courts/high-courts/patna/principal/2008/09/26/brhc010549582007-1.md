# Patna High Court, C.R./1738/2007, 2008-09-26

IN THE HIGH COURT OF JUDICATURE AT PATNA
C.R. No.1738 of 2007
SOM DUTT
Versus
NEETI SUBHRAM
 -----------
2 26/9/2008 Heard counsel for the petitioner.
This Court would not find any
reason to interfere with the impugned
order which has only done justice to the
wife. The exparte decree therefore was
rightly set aside and this Court would not
find any reason to interfere with the same
in exercise of power under section 115 of
the C.P.C.
In that view of the matter, there
is no merit in this application and the
same is accordingly dismissed.
 ( Mihir Kumar Jha,J.)
