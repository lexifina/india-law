# Allahabad High Court, A482/7065/2020, 2020-02-18

Court No. - 77
Case :- APPLICATION U/S 482 No. - 7065 of 2020
Applicant :- Ramnarayan
Opposite Party :- State Of U.P. And 3 Others
Counsel for Applicant :- Hari Shankar,Ajay Tripathi,Gautam Dubey
Counsel for Opposite Party :- G.A.
Hon'ble Sanjay Kumar Singh,J.
At the very outset, learned counsel for the applicant submitted that on
account of some defects, he does not want to press this application at this
stage and the same may be dismissed as withdrawn with liberty to file a
fresh application.
The request so made is allowed.
The application is dismissed as withdrawn at this stage with liberty to file
a fresh application with better particulars.
Office is directed to return the certified copy of the order sheet or other
document, if any, to the learned counsel for the applicant after retaining
the photocopy of the same on record.
