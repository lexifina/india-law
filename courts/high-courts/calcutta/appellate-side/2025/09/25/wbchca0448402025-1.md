Learned counsel for the petitioner submits that there are some
incurable defects in the revisional application. As such, the
petitioner would not like to press this application with liberty to file
proper application afresh on the selfsame grounds.
Accordingly, the revisional application is dismissed as not
pressed.
This order shall not preclude the petitioner from filing proper
application afresh on the selfsame grounds.
On the prayer of the learned counsel for the petitioner, the
office is directed to return certified copy of the order sheet upon
supplying copy of the same for the record and upon compliance of
necessary formalities.
Parties shall act on a server copy of this order duly downloaded
from the official website of this Court.
