Order
16/04/2025
After arguing at some length, learned counsel for the
petitioner seeks permission to withdraw this writ petition with
liberty to file fresh application with better particulars before the
learned tribunal for pre-mature release of the amount which has
been kept in the fixed deposits.

[2025:RJ-JP:16205] (2 of 2) [CW-2930/2025]
Permission sought for is granted.
Accordingly, this writ petition is dismissed as withdrawn with
liberty as prayed for. However, petitioner would be at liberty to file
fresh application with better particulars before the learned
tribunal. If any such application is filed by the petitioner, learned
tribunal is directed to pass a reasoned and speaking order in
accordance with law.
Stay application as well as pending application(s), if any, also
stand disposed of.
