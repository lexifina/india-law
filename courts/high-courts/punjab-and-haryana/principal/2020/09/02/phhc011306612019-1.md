CRM-21167-2020
This application has been filed seeking permission to withdraw
the main case, which is presently fixed for 15.10.2020 on the ground that the
applicant/petitioner has since been released on bail by the Trial Court while
invoking provisions of Section 437(6) Cr.P.C.
In view of the reasons mentioned in the application, the same is
allowed and the main case which is fixed for 15.10.2020 is preponed. The
same is taken on board today.
CRM-M-45940-2019 (O&M)
In view of the specific prayer made in the application for
withdrawal of the main case i.e. CRM-M-45940-2019, the main case itself is
dismissed as withdrawn.
