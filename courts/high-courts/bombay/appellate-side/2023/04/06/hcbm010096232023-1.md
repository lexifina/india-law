1. Today in the morning session, I have passed the following
order :
“1. None present for the Applicant.
2. This is an application under Section 439 of Code of
Criminal Procedure for bail.
3. The learned APP submits that during pendency of the
present application, the prosecution has filed charge-sheet. In
that view of the matter, the applicant is permitted to file fresh
application for bail before the Trial Court/Sessions Court.
4. Application is disposed of.”
2. The learned Counsel for the applicant submits that in the
morning session he could not appear due to unavoidable circumstances.
On instructions he seeks leave to withdraw the present Application with
liberty to file a fresh application for bail before the trial Court. The
Application is disposed of with liberty as sought for.
