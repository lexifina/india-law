# High Court of Madhya Pradesh, MCRC/19408/2018, 2018-05-17

THE HIGH COURT OF MADHYA PRADESH
MCRC-19408-2018
(ASHISH KUMAR SINGH @ GOLU Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 17-05-2018
Shri P.K. Verma, learned counsel for the applicant.
Shri Ramji Pandey, learned P.L. for the respondent-State.
Heard.
This is an application for modification in the name of applicant
No.2 Anu Singh @ Shalu in the bail order dated 08.05.2018 passed in
M.Cr.C.No.16453/2018.
Learned counsel for the applicant submits that in the order dated
08.05.2018 passed by this Court in M.Cr.C.No.16453/2018, name of
applicant No.2 has wrongly been mentioned as Anu Singh @ Shalu,
whereas, the correct one is Anupam Singh @ Shalu S/o Shri Bharat
Singh.
Considering the aforesaid, this application is allowed. Let the
name of applicant No.2 mentioned in the order dated 08.05.2018
passed in M.Cr.C.No.16453/2018, be read as Anupam Singh @ Shalu
S/o Shri Bharat Singh in place of Anu Singh @ Shalu. This order shall
be read conjointly with the order dated 08.05.2018.
Let a copy of this order be kept in the record of
M.Cr.C.No.16453/2018.
With the aforesaid observations and modifications, this M.Cr.C.
stands disposed of.
Certified copy today.
(H.P. SINGH)
