# Allahabad High Court, SAPL/242/2010, 2021-09-29

Court No. - 38
Case :- SECOND APPEAL No. - 242 of 2010
Appellant :- Sri Maharaj Singh Tyagi
Respondent :- Sri Virendra Singh
Counsel for Appellant :- S. O. P. Agrawal
Counsel for Respondent :- A. P. Srivastava
Hon'ble Siddharth,J.
Order on Civil Misc. Delay Condonation Application
No. 7248 of 2018
This is an application seeking condonation of delay in
filing the restoration application.
Cause shown for delay in filing the restoration application
is sufficient.
The delay condonation application is allowed and the
delay in filing the restoration application is condoned.
Order on Civil Misc. Restoration Application No. 7249
of 2018
This is an application for recalling the order dated
30.11.2017 passed by this Court and for restoration of the
appeal.
Cause shown in the affidavit accompanying the
restoration application for non-appearance is sufficient.
The restoration application is allowed.
The order dated 30.11.2017 is recalled and the appeal is
restored to its original number.
Order on Civil Misc. Withdrawal Application No. 08 of
2021
This application has been filed by the appellant duly
supported by an affidavit of the sole appellant- Sri
Maharaj Singh Tyagi.
The withdrawal application is allowed.
The second appeal is dismissed as withdrawn.
Sri Ram Jatan Yadav, learned counsel for the respondent
has no objection to the withdrawal of the second appeal.
Order Date :- 29.9.2021/Rameez
