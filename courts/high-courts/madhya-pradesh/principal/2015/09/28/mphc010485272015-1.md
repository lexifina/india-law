# High Court of Madhya Pradesh, MCC/2856/2015, 2015-09-28

MCC-2856-2015
(CHAITRAM Vs MANJU DEVI)
28-09-2015
Shri K.S.Thakur, learned counsel for the applicants.
This application has been filed for restoration of Second Appeal
No.403/2001, which was dismissed for want of prosecution vide
order dated 12/03/2015. There being some delay in filing the
application for restoration, therefore, I.A. No.12588/2015 has been
filed seeking condonation of delay. Finding the same to be bona
fide, both the applications are allowed.
Condoning the delay in filing the application, restoration
application is itself allowed.
Second Appeal No.403/2001 is restored to its original
number.
After restoration, Second Appeal No.403/2001 be placed for
orders before appropriate Bench.
Application stands allowed and disposed of.
Certified copy as per rules.
(VANDANA KASREKAR)
JUDGE
