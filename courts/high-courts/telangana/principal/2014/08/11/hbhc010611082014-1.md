# High Court for the State of Telangana, CRLP/9166/2014, 2014-08-11

THE HONOURABLE Dr.JUSTICE B.SIVA SANKARA RAO
CRIMINAL PETITION No.9166 of 2014
ORDER:
Sri C. Pratap Reddy, learned counsel for the
petitioners seeks permission of this Court to withdraw the
criminal petition with liberty to file a fresh application from
any changed circumstances.
Permission is accorded.
Accordingly, this criminal petition is dismissed as
withdrawn with liberty as prayed for. As a sequel, the
miscellaneous petitions, pending if any, shall stand
closed.
