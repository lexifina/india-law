# Allahabad High Court, A482/17484/2019, 2019-04-30

Court No. - 64
Case :- APPLICATION U/S 482 No. - 17484 of 2019
Applicant :- Badam Singh And 4 Others
Opposite Party :- State Of Up And Another
Counsel for Applicant :- Anil Kumar Bind
Counsel for Opposite Party :- G.A.
Hon'ble Arvind Kumar Mishra-I,J.
Heard learned counsel for the applicants and learned A.G.A. for
the State.
In this case, as per computer data/stamp reporter, previously
Application U/S 482 No.41363 of 2013 has been filed before
this Court, regarding which a query was made to the learned
counsel for the applicant whereupon he submitted that though
the aforesaid application was not decided on merit but was
dismissed in default vide order dated 18.09.2017.
In view of above, this subsequent application in the wake of the
aforesaid order dated 18.09.2017 is not maintainable at this
juncture.
At this stage, learned counsel for the applicants has submitted
that the instant application may be dismissed as withdrawn so
as to move recall application in Application U/S 482 No.41363
of 2013.
The instant application is dismissed as withdrawn.
Let the certified copy of the impugned order be returned to the
learned counsel for the applicant after getting it xeroxed and
kept on record.
Order Date :- 30.4.2019
