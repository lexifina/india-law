# High Court of Madhya Pradesh, MCC/854/2014, 2014-06-16

M.C.C.No.854/14
16.6.2014.
Shri Ashutosh Tiwari, Counsel for the petitioner.
Shri S.M.Lal, Panel Lawyer on advance notice for the
respondents.
This application has been filed for restoration of
W.P. No.15023/13 which has been dismissed for want of
prosecution on 2.5.2014.
The application is supported by an affidavit of the
counsel himself and considering the reasons given in the
application to be bonafide, the same is allowed. Writ
petition is restored to its original file. It be placed before
the appropriate Bench.
Application stands allowed and disposed of.
