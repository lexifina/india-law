# High Court of Madhya Pradesh, MCC/1294/2014, 2014-08-01

MCC No.1294/2014
01/08/2014
Shri Pratyush Tripathi, learned counsel for the
applicant.
This application has been filed for restoration of Writ
Petition No.1862/2010, which was dismissed for want of
prosecution by this Court on 27/06/2014.
Keeping in view the reasons given in the application for
restoration, which is supported by an affidavit, the same is
found to be bonafide and is, therefore, allowed. Writ Petition
No.1862/2010 is restored to its original file. It be placed for
orders before an appropriate Bench.
Application stands allowed and disposed of.
(Rajendra Menon) (Alok Verma)
