ORDER
Petitioner filed C.M.P.No.319/2010 in S.T.No.
158/2009 before Judicial First Class Magistrate's
Court-III, Kollam under Section 205 of Code of Criminal
Procedure. Learned Magistrate, by Annexure-A3 order,
dismissed the petition on 30.9.2010, as there was no
representation for the petitioner and also for the
reason that no copy was served. This petition is filed
under Section 482 of Code of Criminal Procedure to
quash Annexure-A3 order and to allow the petition filed
under Section 205 of Code of Criminal Procedure.
2. Annexure-A3 order shows that the said petition
was dismissed as there was no representation. Learned
Magistrate did not consider the application on merits.
In such circumstances, petitioner is granted permission
to file a proper petition under Section 205 of Code of
Criminal Procedure. If such a petition is filed,
learned Magistrate to consider the same on merits and
pass appropriate order in accordance with law.
Petition is disposed.
23rd December, 2010 (M.Sasidharan Nambiar, Judge)
