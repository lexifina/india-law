# Allahabad High Court, A482/6758/2019, 2019-02-22

Court No. - 41
Case :- APPLICATION U/S 482 No. - 6758 of 2019
Applicant :- Akhilesh Kumar And 4 Others
Opposite Party :- State Of U.P. And Another
Counsel for Applicant :- Som Veer
Counsel for Opposite Party :- G.A.
Hon'ble Vivek Chaudhary,J.
Learned counsel for the applicants, after arguing at some
length prays that he may be permitted to file a discharge
application. This Court need not grant any liberty to file a
discharge application as it is open for any party to file a
discharge application as per the provisions of Cr.P.C. In
case, such an application is filed by the applicants, the
Court concerned is expected to decide the same
expeditiously, as per law.
With the aforesaid observations, the application is
consigned to record.
Order Date :- 22.2.2019
P Kesari
