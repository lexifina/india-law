# High Court of Orissa, WP(C)/4543/2013, 2019-02-18

03. 18.02.2019 Heard learned counsel for the petitioner.

in the writ petition has become infructuous.

infructuous, granting liberty to the petitioner to file fresh
petition if any cause of action still survives.
 All connected Misc. Cases/I.As, if any stand
disposed of accordingly.
