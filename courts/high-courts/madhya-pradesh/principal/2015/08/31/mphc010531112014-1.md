# High Court of Madhya Pradesh, MCRC/18146/2014, 2015-08-31

MCRC-18146-2014
(LALLA SINGH Vs THE STATE OF MADHYA PRADESH)
31-08-2015
Shri Teerath Prasad Jaiswal, learned counsel for the
applicant.
Shri A.N.Gupta, learned Panel Lawyer for the State.
Heard. This is an application for extension of outer limit of
the order dated 26.2.2013 passed in M.Cr.C. No.1000/2013.
Considering the averment made in the application, the same
is allowed.
The applicant is permitted to comply with the order dated
26.2.2013 passed in M.Cr.C. No. 1000/2013 within one month
from today and fully cooperate in the investigation.
Accordingly, the application is disposed of with the
aforesaid observation.
C.C. as per rules.
(G.S. SOLANKI)
JUDGE
