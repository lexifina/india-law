# High Court of Himachal Pradesh, CMP/8546/2021, 2021-09-20

CMP(M) No. 732 of 2020
20.09.2021 Present: Mr. Lovneesh Thakur, Advocate, for the applicant.
 Mr. Tara Chauhan, Advocate, for non-applicants/respondents
 No.1 and 2.
 Dr. Lalit Kumar Sharma, Advocate, for non-
 applicant/respondent No.3.
 CMP No. 8546 of 2021

 By way of this application filed under Section 173 of Code of
Civil Procedure, a prayer has been made to treat the appeal filed alongwith an
application for condonation of appeal under Section 173 of MACT Act as an
appeal under Order 43 Rule 1(d) of Civil Procedure Code challenged order
dated 5.9.2020, passed in C.M.A. No. 532 of 2018, by the learned Motor
Accident Claims Tribunal,(I) Una, District Una, vide which an application filed
by the present applicant under Order 9 Rule 13 of the Code of Civil Procedure
for setting aside the ex parte award has been dismissed.
 There is no serious objections to the application, so filed,
accordingly, this application is allowed, as prayed for, however with the
direction to the Registry that the application which has been filed under Section
5 of condonation of delay be treated an application filed for condonation of
delay in an appeal filed under Order 43 Rule 1(d) of the Code of Civil
Procedure assailing order dated 5.9.2020 passed in CMA No. 532 of 2018 vide
which application filed under Order 9 Rule 13 of the Code of Civil Procedure
by the present applicant for setting aside ex parte award has been set aside.
Application stands disposed of. Appropriate memo of parties in consonance
with the order so passed by the Court today be filed by the applicant within one
week. List thereafter.
 (Ajay Mohan Goel)
 Judge
