# Bombay High Court, APPA/425/2008, 2008-05-02

(-1-)
MGN
 IN THE HIGH COURT OF JUDICATURE AT BOMBAY
 APPELLATE SIDE, CRIMINAL JURISDICTION
 CRIMINAL APPLICATION NO.425 OF 2008
 IN
 CRIMINAL APPEAL NO.1109 OF 2007
 Jamirmirza Yasin Shaikh ..Applicant
 Vs.
 The State of Maharashtara..Respondent
 Mr. V.V. Purwant, for the Applicant
 Mrs. V.R. Bhosale, APP for State.
 CORAM: F.I. CORAM: F.I. REBELLO REBELLO &
 K.U.CHANDIWAL, JJ.
 DATED: 2ND MAY 2008
 P.C.:
 . We find that the Appeal was filed by lawyer.
 Application for bail is filed by lawyer, but only
 one copy of the application has been filed. We have
 perused the record. There is no undertaking also
 taken to file the second copy.
 2. We fail to understand as to how the office
 accepted the application for hearing before the
 Division Bench when only one copy is filed. We can
 understand as an exception an application moved
 through Jail. The application was filed through
 legal Counsel. Hence application for bail rejected.
 3. The rejection of the application will not
 stand in the way of the applicant applying afresh.

 (-2-)
 4. The Deputy Registrar Shri P.B. Ghag to file
 explanation as to how the bail application was
 entertained. The explanation to be filed on or
 before 6th June, 2008. Criminal Application
 disposed of accordingly.
 (K.U.CHANDIWAL, J.) (K.U.CHANDIWAL, J.) (F.I.REBELLO, J.)
