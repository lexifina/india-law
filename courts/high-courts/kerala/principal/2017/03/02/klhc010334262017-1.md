JUDGMENT
1. Petitioners are the plaintiffs in a suit for partition. Petitioners filed
an application to send registered Will for expert opinion stating that
it was fabricated. The application has been dismissed by the court
below.
2. Considering the facts and circumstances, this court is of the view that
the application ought to have been allowed by the court below.
Therefore, the impugned order is set aside. The application to send
registered Will for expert opinion is allowed.
The original petition is disposed of accordingly.
A.Muhamed Mustaque, Judge.
