# High Court of Madhya Pradesh, MCC/540/2017, 2017-03-20

MCC-540-2017
(MOSER BAER POWER LTD. Vs THE STATE OF MADHYA PRADESH)
20-03-2017
Shri Pranay Verma, learned counsel for the applicant.
Heard on I.A. No.2746/2017, an application for condonation of delay.
For the reasons mentioned in the application, which is duly supported by
an affidavit of Advocate-Shri Pranay Verma, the same (I.A.
No.2746/2017) is allowed. The delay in filing this application is hereby
condoned.
This application has been filed for restoration of F.A. No.554/2016 which
has been dismissed on account of the common conditional order passed
on 26.09.2016. The application is supported by an affidavit of Advocate
-Shri Pranay Verma.
Keeping in view the reasons indicated in the application, the M.C.C. is
allowed and it is directed that F.A. No.554/2016 be restored to its
original number and list this case before the appropriate Bench.
Let a copy of this order be kept in the file of F.A. No.554/2016.
(SMT. ANJULI PALO)
JUDGE
