O R D E R
This Criminal Original Petition has been filed to
direct the respondents to return the documents in Crime / FIR
No.145 of 2011 on the file of the respondent to file a final
report before this Hon'ble Court within a time as stipulated by
this Hon'ble Court.
2.The learned counsel for the petitioner would submit that
originally the petitioner was arrayed as first accused in Crime
No.145 of 2011 registered for the offences under Sections 406,
465, 469, 471, 420 of IPC r/w Section 34 of IPC as against the
petitioner and another. In which the petitioner was arrayed as
first accused. After completion of investigation, the second
respondent file the final report only as against the second
accused and discharged the petitioner. Even that, the
respondent did not return the documents which were seized while
https://hcservices.ecourts.gov.in/hcservices/

investigation. Therefore, he sought for direction, directing
the second respondent to return the documents.
3.Considering the above facts and circumstances of the case,
the second respondent is directed to file a final report and
also deposit all the documents which were seized during the
investigation before the Jurisdictional Court namely the
Judicial Magistrate No.II, Chengalpattu, the Judicial Magistrate
No.II, Chengalpattu is also directed to receive the same in
accordance with law. Therefore, the petitioner is at liberty
to file a appropriate petition for return of documents before
the Court concerned in the manner known to law.
4.With the above directions, this Criminal Original Petition
is disposed of.
