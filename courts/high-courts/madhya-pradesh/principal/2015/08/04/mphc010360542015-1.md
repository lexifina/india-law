# High Court of Madhya Pradesh, MCC/2070/2015, 2015-08-04

MCC-2070-2015
(MADANLAL Vs KARAN SINGH)
04-08-2015
Ms. Kalpna Khare, learned counsel for the applicant.
This application has been filed for restoration of
Miscellaneous Appeal No. 647/2015,
which was dismissed for want of
prosecution by this Court on 5.05.2015.
There being some delay in filing the
application for restoration I.A. No.9721/15
has been filed seeking condonation of
delay. Both the applications are supported
by affidavit of Shri Priyesh and there is no
reason to disbelieve the same. Finding the
same to be bonafide, both the
applications are allowed.
Condoning the delay in filing the application,
restoration application itself is allowed.
Miscellaneous Appeal No. 647/2015 is restored to its
original number. It be placed for orders
before appropriate Bench.
Application stands allowed and disposed of.
(VANDANA KASREKAR)
JUDGE
