HON'BLE MR. JUSTICE SANGEET LODHA
Order
14/11/2017
This misc. application has been filed by the petitioner
seeking correction in the cause title of Civil Writ Petition
No.9586/17 which already stands disposed of vide order dated
14.9.17.

(2 of 2)
[WMAP-267/2017]
It is submitted that the name of the petitioner’s husband is
“Nathmal Verma”, however, inadvertently, the same has been
mentioned in the cause title as “Nathmal Sharma”.
The correction sought for deserves to be permitted.
Accordingly, the application is allowed. A copy of this order
and amended cause title already filed be placed in the file of Civil
Writ Petition No.9586/17.
