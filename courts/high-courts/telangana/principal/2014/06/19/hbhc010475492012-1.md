# High Court for the State of Telangana, CRLP/2930/2012, 2014-06-19

HON’BLE SRI JUSTICE S. RAVI KUMAR
CRIMINAL PETITION No. 2930 of 2012
ORDER:
This petition is filed to quash F.I.R. the order dated
12.01.2012 in Crl.M.P.No.1282 of 2011 in C.C.No.1349 of
2009, which is filed under Rule 219 of Cr.P.C. for return of
document i.e., original passport.
2. None appeared for the petitioner.
3. Learned Public Prosecutor submitted that main
C.C.No.1349 of 2009 has ended in acquittal, as per
judgment dated 20.06.2013.
4. In view of the disposal of the main C.C., this criminal
petition is dismissed with liberty to the petitioner to
approach the Court below for return of the document, if not
taken return till date.
5. As a sequel, miscellaneous petitions, if any, filed in
this criminal petition, shall stand dismissed.
__________________
S. RAVI KUMAR, J

th June 2014.
