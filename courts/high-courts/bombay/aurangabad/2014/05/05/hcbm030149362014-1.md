Mr. S.G. Chapalgaonkar, Advocate for applicant.
CORAM : T.V. NALAWADE, J.
DATED : 5th May, 2014.
PER COURT :
1. The application is filed against the order made by
the learned Registrar (Judicial) of this Court by which the
Registrar has refused to register the appeal. It appears
that the objection was that there were few documents
which were not readable. The learned counsel
undertakes to supply the readable copies.
2. In view of this statement, the application is
allowed. The delay, if any, is condoned. The order of
dismissal is set aside.
3. The objections are to be removed on or before
30.6.2014.
