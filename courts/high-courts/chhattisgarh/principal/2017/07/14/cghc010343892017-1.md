Order on Board
14-07-2017
1. Heard the matter finally.
2. It is prayed on behalf of the petitioner that on account of clerical error
learned counsel while filing the MCRC No.2823 of 2017 mentioned the name
of petitioner as Set Prakash Thuriya and as the actual name of the petitioner is
Set Prasad Thuriya, hence the order passed in MCRC No.3823 of 2017 dated
05-07-2017 in the name of petitioner the word 'Prakash' may be corrected as
'Prasad'.
3. On due consideration, the instant CRMP is hereby allowed. It is directed
that name of the applicant as in MCRC No.3823 of 2017 dated 05-07-2017 be
read as Set Prasad Thuriya instead Set Prakash Thuriya.
4. The Cr.M.P. disposed of.
 Sd/-
(Chandra Bhushan Bajpai)
