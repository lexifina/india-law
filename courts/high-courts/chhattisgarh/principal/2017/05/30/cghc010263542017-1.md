Heard.
1. It is submitted by learned counsel for the applicant that he wishes to
withdraw the bail application with liberty to file fresh application.
2. It is pointed out by the State counsel that the present bail application has
been filed representing that is first bail application whereas, in reality, it is second
bail application and the first bail application was rejected by the Single Bench of
Hon'ble Justice Shri Sanjay K. Agrawal on 30.03.2015 in MCRC No.1321 of 2015.
3. On the request of the counsel for the applicant, this bail application is
dismissed as withdrawn with liberty as prayed for is granted with condition to file
appropriate application mentioning all the true facts with respectively rejection of
first bail application and also mentioning the Court rejecting the same.
