PRAYER: Petition filed under Section 482 Code of Criminal Procedure,
to call for the entire relevant records connected to the First
Information Report in Crime No.556 of 2021 dated 20.11.2021 pending
on the file of the first respondent police and quash the same as
illegal as against the petitioner.
For Petitioner : Mr.R.Senthilkumar
For R1 : Mr.E.Antony Sahaya Prabahar
 Additional Public Prosecutor
 ORDER
Heard the learned counsel for the petitioner and the learned
Additional Public Prosecutor for the first respondent.
2. Though this petition has been filed for quashing the FIR,
when the matter was taken up for hearing, the learned counsel for
the petitioner submitted that he would be satisfied, if the first
respondent is directed to file final report at the earliest.
3. In response to the said request, the learned Additional
Public Prosecutor, on instructions, submitted that the first
respondent would file the final report within a period of two weeks
from the date of receipt of a copy of this order.
4. Recording the said submission, this Criminal Original
Petition is disposed of. Consequently, connected miscellaneous
petition is closed.
Sd/-
