# High Court of Madhya Pradesh, MCC/2310/2017, 2017-08-28

MCC-2310-2017
(V.M.SINGH Vs THE STATE OF MADHYA PRADESH)
28-08-2017
Shri Samresh Katare, learned counsel for the applicant.
Shri Anunay Singhai, learned panel lawyer for the
respondents.
This is an application for restoration of the writ petition
which has been suffered dismissal on account of non-compliance
of common conditional order.
considering the averments made in the application which is
supported by an affidavit, I find sufficient cause has been made
out for restoration of the case.
According the application is allowed.
Office is directed to restore the W.P. No. 93/2017 to its
original number.
A copy of this order be also attached with the file of W.P.
No. 93/2017.
(VIJAY KUMAR SHUKLA)
JUDGE
Amitabh
