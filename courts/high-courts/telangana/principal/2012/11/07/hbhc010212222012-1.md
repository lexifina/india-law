# High Court for the State of Telangana, CRLP/7740/2012, 2012-11-07

HONOURABLE SRI JUSTICE SAMUDRALA
GOVINDARAJULU
CRIMINAL PETITION No. 7740 of 2012
ORDER:
The petitioner approached this Court straight away on return
endorsement of anticipatory bail application made by the Sessions
Judge. This application cannot be entertained straight away in this
Court. The petitioner should have replied to the return
endorsement and should have re-presented the same before the
Sessions Judge and should have obtained a judicial order thereon.
In the result, this petition is dismissed as not maintainable
before this Court at this stage.

SAMUDRALA GOVINDARAJULU, J.
