CORAM : A.S.CHANDURKAR, J.
DATED : DECEMBER 02, 2019.
As the petitioner’s application under Order XLI Rule 19 of the
Code of Civil Procedure, 1908 (for short, ‘the Code’) for restoration of the
appeal that was dismissed for want of prosecution has been rejected, an
appeal under the provisions of Order XLIII Rule 1(t) of the Code is
available to the petitioner.
Hence the writ petition is permitted to be withdrawn with
liberty to file an appeal. No costs.
All points raised in the petition are kept open.
