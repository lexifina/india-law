# Gauhati High Court, WP(C)/1304/2015, 2015-03-27

WP(C) 1304/2015
BEFORE
HON’BLE MR. JUSTICE MICHAEL ZOTHANKHUMA
Mr Z Rahman, counsel for the petitioner submits that he has not been able to col
lect the appointment order of the respondent No.8 till date and that he has file
d a fresh RTI application for procurement of the same.
The counsel for the petitioner accordingly prays that he may be allowed
to withdraw this writ petition with liberty to file afresh as and when he receiv
es the appointment order of the respondent No.8.
The prayer is allowed.
The writ petition is accordingly dismissed as withdrawn with liberty to
file afresh, if so advised.
