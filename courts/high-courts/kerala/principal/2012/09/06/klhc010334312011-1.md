 J U D G M E N T
The execution application purporting to be under Order XXI
Rule 58 of the Code of Civil Procedure was dismissed for default
for the reason that the claim petitioners did not take proper
steps in time. The remedy, if any, to restore the execution
application dismissed for default is to make a motion under
Order XXI Rule 106 of the Code of Civil Procedure . The Original
Petition challenging the order in E.A No.1088/2004 in E.P
No.61/2004 in O.S No.1911/1988 on the file of the Court of the
Second Additional Munsiff of Thiruvananthapuram is
misconceived.
The Original Petition is dismissed without prejudice to the
right of the petitioner to move the execution court itself as
aforesaid.
 V.CHITAMBARESH.
