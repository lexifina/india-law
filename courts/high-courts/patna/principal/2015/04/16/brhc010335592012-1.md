ORAL ORDER
2 16-04-2015 Heard learned counsel for the petitioners and learned
counsel for the State.
This application has been filed for quashing First
Information Report vide Motihari SC/ST P.S. Case No.70 of
2012 for the offences under Sections 341, 323, 379/34 of the
Indian Penal Code read with Sections 3(i)(x) of the SC/ST
Act.
Allegations made in the FIR prima-facie constitute
offence against the petitioners. There is no material fact on the
record for the purposes of entertaining this application. This
Court under Section 482 of the Code of Criminal Procedure
will interfere only in the exceptional circumstances and
present case does not fall in the category of exceptional
circumstances. This Court does not find any merit in this
application.

Patna High Court Cr.Misc. No.45510 of 2012 (2) dt.16-04-2015

Accordingly this application is dismissed.
