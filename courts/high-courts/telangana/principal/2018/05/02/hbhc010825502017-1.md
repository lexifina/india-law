# High Court for the State of Telangana, CRLRC/2627/2017, 2018-05-02

HON'BLE Dr. JUSTICE SHAMEEM AKTHER
CRIMINAL REVISION CASE No.2627 OF 2017
ORDER:
 This Criminal Revision Case, under Sections 397 and 401 of the
Code of Criminal Procedure, 1973, is filed by the petitioner aggrieved by
the judgment dated 14.07.2017 in Crl.A. No.110 of 2016 on the file of the
III Additional District and Sessions Judge, Gadwal, where the learned
Sessions Judge confirmed the order dated 20.05.2016 passed in D.V.C.
No.2 of 2014 on the file of the Judicial Magistrate of First Class at
Atmakur.
2. Learned counsel for the petitioner seeks permission of the
Court to withdraw the Criminal Revision Case.
3. Accordingly, this Criminal Revision Case is dismissed as
withdrawn. Miscellaneous petitions, if any pending in this case, shall
stand closed.
_______________________
Dr. SHAMEEM AKTHER, J
