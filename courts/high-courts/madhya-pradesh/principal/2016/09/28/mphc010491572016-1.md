# High Court of Madhya Pradesh, MCRC/17279/2016, 2016-09-28

MCRC-17279-2016
(BABLOO @ RAJESH BHUIYA Vs THE STATE OF MADHYA PRADESH)
28-09-2016
Shri Rakesh Dwivedi, learned counsel for the applicant.
Shri B.P. Pandey, learned G.A. for the State.
This petition has been filed in order to correct the crime number
which has been mentioned in the order dt. 16.09.2016 in M.Cr.C.
No.15176/2016 by which the applicant was granted bail as Crime
No.218/2016.
It is directed that Crime No.218/2016 in the order dt. 16.09.2016
passed in M.Cr.C. No.15176/2016 shall be read as Crime
No.268/2016.
With the aforesaid direction, the instant M.Cr.C. application
stands allowed.
C.C. as per rules.
(ATUL SREEDHARAN)
JUDGE
N.Mohan
