ORAL ORDER;
Sri G. Seena Kumar, Learned Counsel for the Writ
Petitioner would submit that in view of the subsequent
developments, the Writ Petitioner has requested the counsel
by letter dated 19.12.2023 to withdraw this Writ Petition,
with liberty to file afresh Writ Petition. Accordingly, the
Counsel for the Writ Petitioner has also filed a Letter in the
Registry dated 27.12.2023. Both the Letters are taken on
record.
2. Accordingly, this Writ Petition is dismissed as
withdrawn with liberty to file a fresh Writ Petition, if so
advised. No order as to costs.
3. Interlocutory Applications, if any, stand closed in
terms of this order.
