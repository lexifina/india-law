# High Court of Madhya Pradesh, MCRC/27691/2020, 2020-10-06

1 THE HIGH COURT OF MADHYA PRADESH
MCRC No.27691/2020
Jagdish vs. State of M.P.
Gwalior, Dated : 06/10/2020
Shri D.S. Tomar, Counsel for the applicant.
Shri R.S. Dhakad, Panel Lawyer for the respondent/State.
Heard through video conferencing.
Case diary is available.
This third application under Section 439 of Cr.P.C. has been
filed for grant of bail.
By order dated 28.2.2020 the applicant has withdrawn the
application with liberty to file a properly constituted bail application
along with the order sheets of the another case, in which the applicant
was arrested. It appears that this application has been filed without
complying the aforesaid liberty.
Accordingly, the counsel for the applicant seeks permission of
this Court to withdraw this application with liberty to file a properly
constituted application along with the order sheets of the other case
in which he was arrested.
With aforesaid liberty, the application is dismissed as
withdrawn.
 (G.S. Ahluwalia)
