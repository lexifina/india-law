# Allahabad High Court, ARCO/38/2019, 2019-05-24

Court No. - 5
Case :- ARBITRATION AND CONCILI. APPL.U/S11(4) No. - 38 of
2019
Applicant :- Pavan Coal Company Llp And 3 Others
Opposite Party :- U.P Pradeshik Cooperative Federation Ltd.
Counsel for Applicant :- Subhash Chandra Tiwari,Shakti Shanker Tiwari
Counsel for Opposite Party :- Ram Gopal Tripathi,Ram Gopal Tripathi
Hon'ble Ashok Kumar,J.
This is a second application filed under Section 11 of the
Arbitration and Conciliation Act, 1996. Earlier application filed
by the same applicants was dismissed by this Court on
13.4.2018.
Sri Ram Gopal Tripathi, learned counsel for the respondent has
raised the preliminary objection about the maintainability of the
present application and has informed the Court that the earlier
application no. 103 of 2015 was dismissed of this court.
The relief sought by the applicant in the instant application is
similar as of the application, which was dismissed. Admittedly
this is a 2nd application for the same cause, which is not
maintainable.
The application is accordingly, dismissed.
Order Date :- 24.5.2019
S.S.
