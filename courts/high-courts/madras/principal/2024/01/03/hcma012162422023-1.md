A.No.29 of 2024
in
C.S.No.231 of 2019
N.SATHISH KUMAR, J.
This application has been filed to
set aside the expate Order dated
30.10.2023 passed against the
applicant/fourth defendant.
2. The learned counsel appearing
for the applicant submitted that though
they had had filed the written statement
in the 2019 itself, the same has returned
returned and it has been misplaced. As
the written statement has not been filed,
the exparte Order has been passed.
3. Considering the nature of
averments in the affidavit filed along
with the application, this application is
Ordered.
4. The registry is directed to post
the application filed to condone delay in
filing the written statement on
24.01.2024.
