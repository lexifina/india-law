 JUDGMENT
I have heard the learned counsel for the petitioner
and the learned counsel for the respondent.
The learned counsel for the respondent who has
produced the file contains the application submitted by
the petitioner. The respondent has also filed a counter
affidavit.
I have perused the file and it is seen that as per the
petitioner's statement, the construction is a new one
which requires approval of the District Collector
concerned. The respondent Municipality is awaiting
orders from the District Collector in the matter. As there
is no wilful laches on the part of the respondent, there is
no need to proceed with the contempt. Hence this
Contempt Case is closed.
 Sd/- A.V.RAMAKRISHNA PILLAI
