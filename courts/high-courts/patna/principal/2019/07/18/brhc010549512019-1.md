CORAM: HONOURABLE MR. JUSTICE VINOD KUMAR SINHA
ORAL ORDER
2 18-07-2019 It appears that this application has been filed for
transfer of several complaint cases making the complainants as
opposite parties in this case.
In my view, this application is not permissible for
transfer of so many cases in one application. Petitioner should
file separate application for separate complaint case.
Learned counsel for the petitioner is permitted to
withdraw this application with liberty to file separate application
for transfer of particular complaint case.
This application is dismissed as withdrawn.
