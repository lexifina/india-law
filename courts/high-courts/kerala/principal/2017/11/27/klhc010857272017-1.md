Dated this the 27th day of November, 2017
JUDGMENT
The petitioner is aggrieved with Ext.P16 order
passed, wherein the Customs Authority has found that the
machine now produced before the Authority is not the one
imported. The learned Counsel appearing for the petitioner
would submit that the purchase order was for a machine of the
description 77020 AC Doppler System. When the same was
pending, there was a technical upgradation, based on which,
Ext.P1 was issued by the importer and hence the machine with
the additional features with the description 77025A Colour
Doppler (Sonos-500) Echo-Cardiography System was
imported. There are proceedings for confiscation, penalty and
also import duty.

2
W.P.(C) No.37784/2017
2. This Court had by Ext.P9 judgment found that
when there is confiscation and penalty then there can be no
charge of import duty also. The petitioner then produced the
machine for initiating confiscation proceedings, which was
found to be not the one, which was actually imported as per
the bill of entry. Admittedly, there is an Appellate Forum and
the petitioner has not approached the said Appellate Forum.
The petitioner would have to first approach the Appellate
Forum, since the disputes are factual in nature.
The writ petition is closed, leaving open the remedy
of the petitioner to approach the Appellate Forum, subject to
the laws of limitation.
