Order
05/11/2019
This writ petition was filed by the petitioner with the prayer
to set aside the order dated 08.12.2017, by which respondent
No.2 restrained the petitioner from participating in the RJS
Selection Process.
This Court vide order dated 11.07.2019 required respondent
No.3 to accept the application form of the petitioner off-line and
permit him to appear in the written examination.

(2 of 2) [CW-27982/2018]
The respondents have now pursuant to the order of this
Court produced the result of the petitioner according to which he
failed.
Taking into consideration the above, nothing survives in this
petition.
The petition stands dismissed.
However, liberty is granted to the petitioner to file fresh
petition, if occasion arises.
