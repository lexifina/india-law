ORAL ORDER
Heard learned Advocate Shri Harshad K. Patel for the applicant and
learned APP Ms. Moxa Thakkar for the respondent No.1 – State.
Learned Advocate Shri Patel submits that an order dated 07.08.2015
passed in Criminal Misc. Application No.404 of 2012 by the learned
Principal Civil & Judicial Magistrate First Class at Jambusar, had been
challenged before learned Sessions Court in Criminal Revision Application
No.85 of 2015, wherein an order dated 20.09.2016 had been passed by the
learned 4th Additional Sessions Judge, Bharuch, whereas learned Advocate
Shri Patel submits that vide order dated 30.12.2019 granting maintenance to
the respondent wife has been set aside in the proceedings under Section
127(2) of the Code of Criminal Procedure passed learned Additional Chief
Judicial Magistrate, Jambusar
Considering the same, learned Advocate Shri Patel, does not press
this application.
