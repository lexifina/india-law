ORAL ORDER
2/ 19-12-2017 Heard learned counsel for the petitioner and learned
APP for the State.
Petitioner apprehends his arrest in Pipra P.S. Case
No.124 of 2017 instituted for the offence under Section(s) 409,
406, 419, 420, 468, 471, 201, 120-B/34 Indian Penal Code
pending in the Court of the Judicial Magistrate, 1st class, Sheohar.
It is mentioned in para 26 of the bail petition that
Cr.W.J.C. No.887 of 2017 has been filed by this petitioner for
quashing of the present First Information Report in which the
Hon’ble Court vide order dated 01.11.2017 has directed the State
to file Counter Affidavit and also passed an order that no coercive
step shall be taken against the petitioner.

Patna High Court Cr.Misc. No.60307 of 2017 (2) dt.19-12-2017
2/2
In view of such, this anticipatory bail application is
not maintainable for the present.
The application is dismissed as withdrawn.
Liberty is given to the petitioner to file fresh
anticipatory bail application after disposal of Cr.W.J.C. No.887 of
2017, if so required.
