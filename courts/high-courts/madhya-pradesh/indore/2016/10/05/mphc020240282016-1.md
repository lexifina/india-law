# High Court of Madhya Pradesh, MCRC/9485/2016, 2016-10-05

M.Cr.C.No.9485/2016
05.10.2016
Shri Siddharth Jain, learned Counsel for the
applicant Deepchand.
Shri Pankaj Wadhwani, learned Govt. Advocate for
the non-applicant/State.
With the consent of parties, heard finally.
O R D E R
THIS application under Section 482 of the Code of
Criminal Procedure [for short “the Code”] has been filed for
correction of typographical error in regard to date mentioned
in M.Cr.C.No.4005/2011.
[2] Learned Counsel for the applicant pointed out that
in M.Cr.C.No.4005/2011 order has been passed on
26.07.2016, however, due to typographical error year 2015
has been typed , therefore, it be corrected.
[3] Perused the order.
[4] The order has been passed on 26.07.2016; whereas
due to typographical error in the aforesaid order date is
mentioned as "26.07.2015".
[5] Thus, in the aforesaid order date be read as

"26.07.2016". This order be read conjointly with the earlier
order.
[6] Copy of this order be placed in the
M.Cr.C.No.4005/2011.
[7] Thus, the application is disposed of.
Certified copy as per rules.

 [ JARAT KUMAR JAIN ]
 JUDGE
