ORDER
Counsel for the petitioner contends that the petitioner is defendant before
the Court below. Its right to file written statement was closed vide order dated
28.8.2017. Thereafter, petitioner/defendant moved an application under Section
151 Code of Civil Procedure, 1908 seeking extension of time to file written
statement. The said application filed under Section 151 C.P.C was also
dismissed vide order dated 9th March, 2018. Subsequently, another application
of similar nature was dismissed. Thus, the order impugned dated 19.12.2018
(Annexure P-4) is being assailed in the present petition.

JUDGE
2. Counsel contends that the petitioner ought to have been extended
opportunity to file written statement as the same could not be filed
inadvertently.
3. The counsel for the respondent/plaintiff submits that the order
impugned be quashed while imposing cost upon the petitioner, inasmuch as, on
account of interim order passed by this Court, the trial is stayed since 2019.
4. Having heard the submissions as well as considering the consensus,
the impugned order dated 19.12.2018 (Annexure P-4) passed by the Court
below is set aside. The petitioner is extended permission to file written
statement. It is directed that the petitioner/defendant shall file written statement
on a date to be fixed by the Trial Court subject to payment of cost of
Rs.5,000/- to the respondent/plaintiff. It is made clear that if no written
statement is filed on the date so fixed by the trial Court in terms of this order,
the trial Court shall be free to proceed with the matter in accordance with law.
5. With the aforesaid the petition stands disposed of.
