This Execution Petition alongwith these Application diary numbers coming on
this day before this court for hearing, The court made the following order:-
There are five applications in D.Nos22145 to 22149 of 2021 filed before the
Registry for numbering and the same have been placed before this court for its
maintainability.
1) The first application is to recall the order passed in E.P.No.71/2017
dated 16.10.2019. This court being an executing court is empowered to execute the
decree presented for execution only. When an order has been pronounced by this
court, it can be challenged by way of appeal or revision. This court has no authority
to recall or modify the order which has been already passed. The court cannot rewrite

its own order which was already passed.
2) The second application is to pass an order concelling the registered
deed in Doc.No.501 of 2020 executed on 07.01.2020. A Sale Deed is a bilateral deed
which can be cancelled by the consent of both parties that is by the buyer and seller.
If any one of the parties to the document or a 3
rd
party wants to cancel the
registration, they have to approach the competent Civil court for cancellation of deed.
3) The third application is to grant for interim injunction against the
respondent not to encumber the property in any way. Temporary injunctions can be
granted either before Judgment or after Judgment by only the trial courts.
4) The fourth application is to implead the proposed respondents. There
is no proceeding pending before this court and the execution application was already
disposed. Hence this court cannot entertain this application.
5) The fifth and final application is to grant leave to the petitioner to
maintain these applications. The petitioner is not a party to the proceedings and the
proceedings were already completed and execution application was already disposed.
Hence this applicant cannot maintain this application before the executing court.
Further this court has executed the decree as ordered by the trial court

and execution application was disposed of. This court has become functus officio and
no application is maintainable before this court. In fine all the above said five
applications are ordered to be returned.
