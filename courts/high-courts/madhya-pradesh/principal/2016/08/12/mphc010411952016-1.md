# High Court of Madhya Pradesh, MCRC/14617/2016, 2016-08-12

MCRC-14617-2016
(NITIN MOHINDRA Vs CENTRAL BUREAU OF INVESTIGATION)
12-08-2016
Shri Pratyush Tripathi, learned counsel for the applicant.
Shri Rajesh Patel, learned counsel for the respondents.
While allowing M.Cr.C. No.8682/2016 on 4.7.2016 the
Crime Number has been wrongly mentioned as 18/2014
registered by CBI, Bhopal. In fact, Crime number is 20/2013.
Accordingly, this application is allowed. Crime number
mentioned in the order passed on 4.7.2016 in M.Cr.C.
No.8682/2016 be read as Crime No.20/2013 instead of Crime
No.18/2014.
With the aforesaid, this application stands allowed and
disposed of.
(RAJENDRA MENON)
ACTING CHIEF JUSTICE
(ANURAG SHRIVASTAVA)
