Surya Kant, J. (Oral)
In view of the reply-affidavit alongwith the order dated
9.1.2012 (Annexure R-1) whereby the petitioner's claim for pre-mature
release has been rejected, there is no necessity to continue with these
contempt proceedings which are accordingly dropped.
The contempt petition is accordingly disposed of with liberty
to the petitioner to impugn the order dated 9.1.2012 (Annexure R-1) before
an appropriate forum, if so advised.
