Application praying that this Hon'ble Court be pleased
to allow impleadment of the proposed respondent and array
the same as the 5th Respondent in the present proceedings.
This Application coming on this day before this Court
for hearing, the Court made the following order:-
The prayer sought for herein is to allow impleadment
of the proposed respondent and array the same as the fifth
respondent in the present proceedings.
2. The prayer for impleadment of the fifth respondent
as one of the respondents, i.e., fifth respondent in the
main application is sought for.
3. The fifth respondent is the Mercedes Benz (India)
Private Limited which is the manufacture of the vehicles
and the parties herein already in this application, either
the erstwhile agency of the said manufacture or the present
agency and there has been independent dispute between these
two agencies, where some interim arrangement had already
been made in the main application.
4. Only in that circumstances, this application has
been filed to implead this fifth respondent as one of the
respondents in the main application and after hearing the
learned counsel for the parties, this Court is of the view
that, the fifth respondent is a necessary party to be
