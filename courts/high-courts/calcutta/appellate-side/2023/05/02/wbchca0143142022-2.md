1. Counsel for the petitioner seeks extension of
time to file exception to the final report of the
Muchipara Police Station.
2. This Court is of the view that since the
investigation has been completed, the
petitioner may file a formal application before
the Jurisdictional Magistrate under Section
173(8) of the Cr. P.C. and take all and every
exception to the report.
3. The Magistrate may consider the petitioner’s
application in accordance with law.

2
4. In the meantime, the Muchipara Police Station
shall file a final report before the
Jurisdictional Magistrate.
5. With the aforesaid observation, both the writ
petitions shall stand disposed of.
6. There shall be no order as to costs.
7. All parties shall act on the server copy of this
order duly downloaded from the official
website of this Court.
 (Rajasekhar Mantha, J.)
