Hon'ble Shri Justice Goutam Bhaduri
Order on Board
01-08-2016
1. Learned counsel appearing for the applicant would submit that
proceeding has been stayed in a complaint case i.e., Cri.
M.P.No. 575 of 2016 by order dated 30-5-2016 passed by this
Court and consequently at this stage there is no apprehesion
of arrest. He would further submit that if any finding is given
by ths Court, it will affect the the finding of the Cr.M.P.
2. In view of the above, learned counsel for the applicant seeks
permission of this court to withdraw the instant bail application
with liberty to file afresh, if eventuality so arises in future.

3. Permission is granted.
4. Considering the fact that proceeding has been stayed by
order dated 30-5-2016 passed by this court in Cr.M.P.No.
575 of 2016 which is pending considertion and, therefore, at
this stage since there is no apprehesion of arrest, the instant
bail application is dismissed as withdrawn with the aforesaid
liberty.
