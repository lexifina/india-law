CORAM: HON'BLE MR.JUSTICE RAKESH KUMAR JAIN
Present : Mr.G.S.Sidhu, Advocate for the petitioners.

RAKESH KUMAR JAIN, J. (Oral)
This is an application for restoration of the bail application
which was dismissed for non prosecution on 10.7.2009.
Counsel for the petitioners/applicants submits that he would
rather file a fresh petition. Therefore, he prays for withdrawal of the present
application with liberty to file fresh bail application on the same cause of
action.
After hearing the learned counsel for the petitioners, this
application is allowed to be withdrawn with liberty to file fresh bail
application.
 (Rakesh Kumar Jain)
