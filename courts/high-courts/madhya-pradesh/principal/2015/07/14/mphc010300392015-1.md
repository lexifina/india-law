# High Court of Madhya Pradesh, MCC/1717/2015, 2015-07-14

MCC NO.1717/2015

14-07-2015.
 Shri Naveen Kumar Agrawal, learned counsel for the
applicant.
 This application has been filed for restoration of
R.P.No.216/15, which has been dismissed for want of
prosecution.
 Keeping in view the reasons indicated in the application,
which is supported by an affidavit of the counsel himself and
finding the same to be bonafide, this application is allowed.
R.P.No.216/15 is restored to its original file and it be listed for
hearing before an Appropriate Bench.
 Accordingly, this application stands allowed and disposed
of.

 (RAJENDRA MENON) (SUSHIL KUMAR GUPTA)
 JUDGE JUDGE
