Learned Additional Public Prosecutor submits that
charge-sheet is already filed before the competent Court.

2. On the earlier date, having considering the
involvement of applicant in the crime of which
quashment is prayed for, we had granted time to make a
statement if application for discharge would be preferred
or to proceed with the present application.
3. Learned Counsel for the applicant seeks leave to
withdraw the application with liberty to file discharge
application as charge-sheet is filed.
4. In the circumstances, leave as prayed is allowed.
5. Application stands disposed of as allowed to be
withdrawn with liberty as prayed for.
