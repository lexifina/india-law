O R D E R
Dated this the 4th day of August 2020
This Bail Application was filed on 10.12.2019. When this
Bail Application came up for consideration on 9.1.2020, this
Court passed an order 'post when moved again'. Thereafter,
this Bail Application was not posted.
Now this Bail Application again came up for
consideration. There is no representation for the petitioner.
Therefore, I passed over this matter. After completing my
work, this Bail Application was again called. Even now there is
no representation. Probably there may not be any
apprehension of arrest to the petitioner. Therefore, I close this
Writ Petition with liberty to the petitioner to file it again if there
is any apprehension of arrest in connection with Crime No.154
of 2019 of Manjeswar Police Station.
