# High Court of Rajasthan, WRES/214/2008, 2008-08-01

D.B.Civil Misc.Restoration Application No.214/2008
Lt.Col.Ranveer Singh Rathore
V/s
Chief of Army Staff & ors.
1.8.2008
Hon'ble the Chief Justice Mr.Narayan Roy
Hon'ble Mr.Justice Mohammad Rafiq
Mr.Indrajeet Singh for the petitioner.
Mr.Sanjay Pareek for the respondents.
This restoration application has been filed to
restore PIL application no.5155/07 which was
dismissed for non-prosecution.
The matter was on the board on 5.5.2008.
Repeatedly it was called out, but none appeared on
behalf of the petitioner to press it. Counsel
submits that cause list was not supplied to him.
Be that as it may, since PIL application was
dismissed for non-prosecution, there would be no
use to restore the same as the writ petitioner
would be at liberty to file a fresh PIL application
if there would be such requirement.
This restoration application accordingly is
dismissed.
(Mohammad Rafiq)J. (Narayan Roy)C.J.
Parmar
