 O R D E R
This Crl.M.C. is filed to quash the proceedings in CC
No. 1891/2014 on the file of the Judicial First Class
Magistrate Court-I, Aluva. This Court perused the final
report produced along with the Crl.M.C. After going through
the final report, I am of the considered opinion that this is
not a case which is to be quashed invoking the provisions
under Sec. 482 Cr.P.C. If the charge is not framed, the
petitioner can file a discharge petition raising all the
contentions raised in this Crl.M.C.
Therefore, granting liberty to the petitioner to file a
discharge petition before the trial court, if charge is not
framed, this Crl.M.C. is disposed of. All the contentions
