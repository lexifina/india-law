ORDER
This criminal original petition has been filed to expedite
the investigation in connection with the crime No.33 of 2020 and
to file a final report within a stipulated time pending on the
file of the 1st Respondent.
2.The learned Government Advocate (Crl.side) submits that
the case is one of impersonations, created forged document and
using the forged document, the defacto complainant said to have
been cheated. Further, in this case, since supporting documents
have been secured, forensic report has to be obtained and
handwritten report has to be recorded, which would take some
time and sought 6 months time.
https://hcservices.ecourts.gov.in/hcservices/

3.This Court, finding the submission of the learned
Government Advocate (Crl.side) reasonable, grants six months
time. Accordingly, the criminal original petition is disposed of.
