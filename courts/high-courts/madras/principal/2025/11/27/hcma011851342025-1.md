This application has been filed by the applicants/petitioners to grant
leave to amend the original O.P.No.518 of 2024.
2. According to the applicants/petitioners, this is the second
application in this original petition, and the second petitioner in the original
petition has already filed the main suit seeking grant of Letters of
Administration. At that time of filing the main petition, the description of the
property was wrongly mentioned. Therefore, the applicants have filed this
application to rectify the same.
3. I have heard the learned counsel appearing for the
applicants/petitioners. There is no respondent in the application/petition.

4. Considering the reasons stated in the affidavit, and since the
details of the property were wrongly mentioned in the main petition, and the
property description in the petition does not tally with the original petition, it
would be appropriate to permit the amendment by incorporating the correct
description of the property.
5. Accordingly, this application is allowed. Leave is granted.
6. The Registry is directed to carry out the necessary amendments
wherever required and list the matter on 08.12.2025.
