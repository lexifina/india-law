# High Court for the State of Telangana, CRP/5120/2016, 2016-10-28

THE HONíBLE SRI JUSTICE A.RAJASHEKER REDDY
Civil Revision Petition No.5120 OF 2016
ORDER :
The grievance of the petitioner in this Civil Revision is that
when he has filed Interlocutory Application for return of the
documents, the Office has returned the same with some
objections. Even after comply with the objections, the said
application was returned stating that this Court stayed all further
proceedings.
Learned counsel for the petitioner submits that this Court
has stayed all further proceedings but application for return of
documents from the file can be disposed of.
In this case, it is to be seen that it is not for the Office to
raise such objection. It is for the Court below to take into
consideration the aspect of stay granted by this Court while
disposing interlocutory application.
 In view of the same, this Civil Revision Petition is disposed of
directing the Court below to number the Interlocutory Application
of the petitioner and deal with the same according to law. As a
sequel thereto, miscellaneous petitions, if any, pending shall
stands closed.
