# Allahabad High Court, WRIC/53164/2014, 2018-02-23

Court No. - 38
Case :- WRIT - C No. - 53164 of 2014

Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Udayan Nandan,Shashi Nandan
Counsel for Respondent :- C.S.C.,Pankaj Kr. Shukla
Hon'ble Ran Vijai Singh,J.
Hon'ble Mukhtar Ahmad,J.
In Re.: Civil Misc. Withdrawal Application.
This is an application to dismiss the writ petition as withdrawn. In this
application, it is stated that petitioner does not want to pursue the writ
petition and it may be dismissed as withdrawn, to which learned counsel
appearing for the respondents has no objection.
The application is allowed.
The writ petition is dismissed as withdrawn.
Interim order, if any, stands vacated.
Order Date :- 23.2.2018
