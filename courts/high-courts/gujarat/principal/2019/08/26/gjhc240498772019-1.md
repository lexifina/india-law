ORAL ORDER
The learned advocate for the applicant does not invite
reasoned order and seeks permission to withdraw this
application but, states at bar that he would like to file
discharge application after filing of the chargesheet.
In light of the statement made at bar and since the
applicant has alternative remedy to file discharge application
and also to file appropriate proceedings either u/s 397 or 482
of the Code of Criminal Procedure, 1973 before appropriate
competent Court, after remedy to file discharge application is
availed, present application stands disposed of as withdrawn.
However, the applicant is at liberty to file discharge
application before the competent Court, as aforesaid.
It is clarified that this Court has not examined the merits
of the present application.
(S.H.VORA, J)
