ORAL ORDER
23 01-08-2012 Heard learned counsel for the petitioner and learned
counsels for the State and for the Patna University.
It is admitted by learned counsel for the petitioner that all
the post retiral dues of the petitioner have already been paid,
except certain arrears of salary which remain to be paid.
In the above circumstances, the writ application is
dismissed as infructuous. However, the petitioner shall have
liberty to file a fresh writ petition, if so advised, for payment of
arrears of salary.
