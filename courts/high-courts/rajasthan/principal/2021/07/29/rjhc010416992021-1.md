Judgment / Order
29/07/2021
The application has been moved for correction in the order
dated 13.07.2021 on the ground that name of witness “Sonu
Patwa” has been used instead of “Sunny Patwa”.
Taking into consideration the list of witnesses along with the
charge sheet, the name of witness mentioned in the order dated
13.07.2021 for Appeal No.480/2021: Varun Vs State is corrected
as “Sunny Patwa” instead of “Sonu Patwa”.
The application is allowed accordingly.
The present order shall be treated as part of the order dated
13.07.2021 passed in Criminal Appeal No.480/2021.
