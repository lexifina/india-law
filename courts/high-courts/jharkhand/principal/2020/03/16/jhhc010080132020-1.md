# High Court of Jharkhand, Cr.M.P./807/2020, 2020-03-16

IN THE HIGH COURT OF JHARKHAND AT RANCHI
Cr. M.P. No. 807 of 2020
----
Indradeo Prasad @ Indradeo Yadav … Petitioner
-versus-The State of Jharkhand … Opposite Party
---
CORAM : HON’BLE MR. JUSTICE ANANDA SEN
----
For the Petitioner : Mr. Prateek Sen, Advocate
For the State : Ms. Nehala Sharmin, A.P.P.
----
2/ 16.03.2020 Heard learned counsel for the petitioner and the learned
A.P.P. for the State.
 2. Petitioner challenges the orders dated 07.05.2018 and
10.10.2018 passed by the Chief Judicial Magistrate, Hazaribagh in Sadar
(Korrah) Police Station Case No.44 of 2016 (G.R. No.124 of 2016), by
which process under Section 82 of the Code of Criminal Procedure and
attachment order under Section 83 of the Code of Criminal Procedure
have been issued.
3. Counsel for the petitioner submits that the order issuing
process under Section 82 of the Code of Criminal Procedure is absolutely
cryptic and no subjective satisfaction has been recorded by the Court
below. He submits that without complying with the provisions of Section
82(3) of the Code of Criminal Procedure, order of attachment under
Section 83 of the Code of Criminal Procedure has been passed. Thus, he
submits that both the impugned orders, being absolutely bad in law and
unsustainable, are liable to be set aside by this Hon’ble Court.
4. I have heard learned counsel for the parties and have gone
through the impugned orders. I find that the order dated 07.05.2018, by
which processes under Section 82 of the Code of Criminal Procedure has
been issued, is absolutely cryptic and does not reflect any subjective
satisfaction. The order dated 10.10.2018, by which attachment in terms of
Section 83 of the Code of Criminal Procedure has been issued is also bad
and cryptic as the same has been passed without complying with the
provisions of Section 82(3) of the Code of Criminal procedure. Both these
orders, i.e., order dated 07.05.2018 and 10.10.2018 are, accordingly,

 -: 2 :-
quashed and set aside. The matter is remanded to the Court below to
proceed afresh and pass orders in accordance with law.
5. This criminal miscellaneous petition is, accordingly, allowed.

(Ananda Sen, J.)
