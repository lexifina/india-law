# Allahabad High Court, A482/13888/2019, 2019-04-11

Court No. - 67
Case :- APPLICATION U/S 482 No. - 13888 of 2019
Applicant :- Vinod
Opposite Party :- State Of U.P. And Another
Counsel for Applicant :- Mohd. Aqueel Khan
Counsel for Opposite Party :- G.A.
Hon'ble Rahul Chaturvedi,J.
The instant application has been filed by the applicant assailing
the order dated 05.04.2018 whereby the discharge application
of the applicant was rejected.
Submission of learned counsel for the applicant is that in the
present case charge has already been framed and matter is to be
for the trial.
This application U/s 482 Cr.P.C. is rendered as infructuous in
the light of charge which has already been framed.
Accordingly, this application is dismissed.
Order Date :- 11.4.2019
