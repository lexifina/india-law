PER COURT :
1. Learned advocates for the respective sides submit
that in view of the amendment dated 26/06/2018, by which,
Section 9A of the Code of Civil Procedure (Maharashtra
Amendment) has been deleted, this petition can be disposed
off by modifying the impugned order.
2. In view of the above, this petition is disposed off.
The impugned order dated 19/10/2016 stands set aside and
application Exhibit 26 stands disposed off.
