ORDER:
1) The application is filed for stay to the execution
of the judgment and order delivered by the Reference
Court. It is contended that when this Court has granted
stay, as per the order made by this Court, the amount has
been deposited by the acquiring body in the execution
proceeding. The claimant contended before the executing
Court that entire amount which is due is not deposited.

 2 CA 7672/2014
Learned counsel for the claimant is present. He disputes
the calculation which is done by the acquiring body. If
there is some dispute over calculation the dispute can be
settled in this Court. The SLAO is to make calculation and
submit the same in this proceeding before 22nd August
2014. Similarly the claimant also to make calculation and
submit the table in this Court and the dispute can be
resolved.
2) When this Court has granted stay the executing
Court cannot go ahead with the execution proceeding.
Inform the executing Court accordingly. Authenticated
copy be provided both the sides. The application is
disposed of.
