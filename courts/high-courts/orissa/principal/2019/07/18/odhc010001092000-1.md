# High Court of Orissa, OJC/10098/2000, 2019-07-18

05. 18.07.2019 Learned counsel for the petitioners states that he
has no instruction in the matter. As such, he seeks
permission to withdraw the writ petition with a liberty to the
petitioners to file fresh application, if any cause of action
arises. A memo filed to that effect is taken on record.
 Permission for withdrawal is granted.
 Accordingly, the writ petition stands dismissed as
withdrawn with a liberty to the petitioners to file fresh
application before the appropriate forum, if any cause of
action arises.
 Misc. Cases/I.As. connected to the writ petition, if
any, are dismissed accordingly.
