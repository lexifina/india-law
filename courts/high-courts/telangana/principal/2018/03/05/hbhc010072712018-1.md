# High Court for the State of Telangana, CC/266/2018, 2018-03-05

HONOURABLE SRI JUSTICE A.RAJASHEKER REDDY
C.C. No. 266 of 2018
ORDER :
 This Contempt Case is filed against respondents alleging
willful disobedience in compliance of order dated 23.11.2017
in W.P. No.39682 of 2017.
 Learned counsel for the petitioner as well as Sri
Chintapalli Srinivas, learned Standing Counsel for the
respondents submits that the aforesaid order of this Court has
been complied with.
 Recording the submission of the learned counsel for the
petitioner, this Contempt Case closed. As a sequel thereto,
miscellaneous petitions, if any, pending in this Contempt
Case, shall stands closed.
 ____________________________
A.RAJASHEKER REDDY, J
