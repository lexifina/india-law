# High Court of Madhya Pradesh, MCC/1443/2014, 2014-08-14

MCC NO.1443/2014
14/08//2014

This application has been filed for restoration of
W.P.No.806/2013, which has been dismissed in view of the
common conditional order passed on 03-04-2014.
In the writ petition, respondents were not noticed and
represented, therefore, no notices to the respondents are
necessary.
Keeping in view the reasons given in the application
and finding the same to be bonafide, this application is
allowed. W.P.No.806/13 is restored to its original file. It be
placed for orders before an appropriate Bench.
Accordingly this application stands allowed and
disposed of.

(RAJENDRA MENON) (ALOK VERMA)
 JUDGE JUDGE
