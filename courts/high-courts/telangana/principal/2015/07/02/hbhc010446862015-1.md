# High Court for the State of Telangana, WP/19809/2015, 2015-07-02

THE HON’BLE SRI JUSTICE A.V.SESHA SAI
W.P.No.19809 of 2015
ORDER:
Learned counsel appearing for the petitioners seeks
permission of this Court to withdraw this Writ Petition with a liberty
to file another writ petition.
Permission is accorded.
Accordingly, the Writ Petition is dismissed as withdrawn
with a liberty to file another writ petition. No order as to costs.
Miscellaneous petitions, if any, pending in this writ petition
shall stand closed.
