By the Court:
The petitioner was alloted Fair Price Shop. His
authorization was suspended, which was then challenged by the
petitioner in the Revision Petition. The Revisional Authority found
suspension to be bad and set aside the same with the remand of
case to the competent authority for causing enquiry in regard to
the allegation made against the petitioner but till the enquiry is
completed, the suspension order was kept alive.
I find the order of Revisional Authority to be
contradictory, inasmuch as, it had set aside the suspension order
and at the same time, maintained it till completion of enquiry,
which cannot be permitted.
Accordingly, this writ petition is allowed in part. The
order of suspension is set aside, however, remaining order of
