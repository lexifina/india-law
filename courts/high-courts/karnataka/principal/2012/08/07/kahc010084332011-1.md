This Writ Appeal is filed under Section 4 of the High Courts
Act, 1961, prays that this Hon'ble Court be pleased to set aside the
order dated 03.08.2011 passed in Writ Petition No. 10484/2008 on
the file of the learned Single Judge and be pleased to allow the writ
petition by allowing this writ appeal.
This Writ Appeal coming on for Preliminary Hearing this day,
K.L.MANJUNATH. J., delivered the following :
JUDGMENT
The learned Counsel for the appellant submits that the
appellant is intending to file a Review. Therefore, he may be
permitted to withdraw this writ appeal with liberty to file a Review.
2. Accordingly, this writ appeal is dismissed as withdrawn
with liberty to the appellant to file a Review.
