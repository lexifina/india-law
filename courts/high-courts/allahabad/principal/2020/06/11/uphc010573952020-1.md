# Allahabad High Court, ABAIL/2755/2020, 2020-06-11

Court No. - 78
Case :- CRIMINAL MISC ANTICIPATORY BAIL APPLICATION U/S
438 CR.P.C. No. - 2755 of 2020
Applicant :- Taslima
Opposite Party :- State of U.P.
Counsel for Applicant :- Jagdish Prasad Mishra
Counsel for Opposite Party :- G.A.
Hon'ble Ajit Kumar,J.
Heard Sri Jagdish Prasad Mishra, learned counsel for the
applicant and learned AGA for the State.
Learned counsel for the applicant states that while during
lock-down period the present anticipatory bail application
was not traceable as the same was kept somewhere else in
the registry and he did not receive any message from the
High Court and so applicant happened to file another
anticipatory bail application through E-filing bearing no.
2635 of 2020, which has been allowed vide order dated
27.05.2020 by this Court, hence the present bail
application is rendered infructuous and same may be
dismissed as such.
The computerized cause list shows disposal of the said
application and the order is also available on official
website which has been duly perused by this Court.
Learned AGA does not have any objection to the above
request made by learned counsel for the applicant.
The application is accordingly dismissed as infructuous.
Order Date :- 11.6.2020
