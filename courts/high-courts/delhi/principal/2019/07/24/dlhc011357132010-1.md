I.A. 9896/2019 (application for correction under Section 151 CPC)
1. This is a joint application on behalf of Petitioner and Respondents
seeking correction of the mistake in para-1 of the application under Order
23 Rule 3 CPC (I.A. 5928/2016) which was allowed vide order dated 2nd
May, 2016.
2. Learned counsel for the applicants states that though there is no mistake
in the order, however, for the sake of keeping the record correct, he prays
that it be noted that the date mentioned in para-1 of the of the application
under Order 23 Rule 3 CPC (I.A. 5928/2016) which should be read as
“16th February, 1995” instead of “16th February, 1985.” The application is
duly supported by affidavit by both the parties accordingly, same is
allowed.
3. It is clarified that the date mentioned in para -1 of the application under
Order 23 Rule 3 CPC (I.A. 5928/2016) shall now be read as “16th

February, 1995” instead of “16th February, 1985.”
