# Allahabad High Court, WRIC/24614/2019, 2019-11-18

Court No. - 10
Case :- WRIT - C No. - 24614 of 2019
Petitioner :- Nand Kishor
Respondent :- State Of U P And 5 Others
Counsel for Petitioner :- Deepak Gaur
Counsel for Respondent :- C.S.C.,Ajay Sengar,Brij Kumar
Yadav,Devesh Kumar Verma
Hon'ble Vivek Kumar Birla,J.
Ref: Civil Misc. Withdrawal Application No. 2 of 2019
Heard Sri Deepak Gaur, learned counsel for the petitioner,
learned Standing Counsel for the State and Sri Ram Gobind,
Advocate holding brief of Sri Ajay Sengar, learned counsel for
respondent no. 6.
Learned counsel for respondent states that he wants to file
counter affidavit.
Since the withdrawal application has already been filed, there is
no reason to grant time to file counter affidavit in the writ
petition.
The withdrawal application stands allowed. Whatever ground
that are being taken on mala-fide that are being taken by
learned counsel for the respondent. It is open for him to take the
same before the appropriate authority at appropriate stage.
Prayer is granted.
Interim order, if nay, stands vacated.
This writ petition is accordingly dismissed as not pressed. No
order as to costs.
Order Date :- 18.11.2019
