ORDER
In relation to assessment order dated 20.11.2025, the petitioner had
lodged an application for rectification on 03.02.2026. Meanwhile, the
assessment order was challenged in W.P.No.18907 of 2026. By order dated
08.06.2026, the assessment order was set aside and the matter was remanded for
consideration. Because the rectification application was rejected by order dated
05.05.2026, this writ petition has been filed.
2. Mr. R. Sethu Prabakaran, learned Government Counsel (Tax), accepts
notice for the respondent.
3. In view of the assessment order being set aside by order dated
08.06.2026 in W.P.No.18907 of 2026, the rectification proceedings have been
rendered infructuous. Recording the same, this writ petition is disposed of
without any order as to costs. Consequently, connected miscellaneous petition is
closed.
