# High Court of Rajasthan, CRLMA/270/2007, 2007-05-07

S/2
S.B. CRIMINAL MISC APPLN. 270/2007.
IN
S..B. CRIMINAL APPEAL NO.284/2007.
DATED : 07.05.2007
HON'BLE MR. CHATRA RAM JAT, J.
Mr.H.S.Shrimali for the appellant
Mr.J.P.S.Choudhary, P.P.
*****
 The case comes upon an application for making correction in
the order dated 04.05.2007 and for filing amended cause title.
 Perused the application. The order dated 04.05.2007 is
modified to the extent that name of accused appellant No.1 is read
as Ajay Singh Meghwal @ Ajay Kumar Meghwal S/o Khumba Ram
Meghwal instead of Ajay Singh @ Ajay Kumar S/o Khumba Ram
Rajput and accused appellant No.3 Bhanwar Singh @ Bhanwar Lal
S/o Khumba Ram Meghwal instead of Bhanwar Singh S/o Khumba
Ram Rajput.
Accordingly, the application for correction in the order dated
04.05.2007 and for filing of amended cause title is allowed.

[CHATRA RAM JAT]J.
