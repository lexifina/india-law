HON'BLE MR. JUSTICE M.N. BHANDARI
Order
18/04/2017
 An application has been filed for correction in the order
dated 08th February, 2017.

(2 of 2)
[WMAP-104/2017]
It is stated that inadvertently, in the order dated 08th
February, 2017, at page No.2, number of the writ petition has
wrongly been mentioned as 280/2003 whereas it should be
281/2003. Accordingly, necessary correction may be permitted.
In view of the above, the application is allowed. The
number of the writ petition at page No.2 in the order dated 08th
February, 2017 be read as 281/2003 instead of 280/2003.
This order be treated as part and parcel of the order
dated 08th February, 2017.
(M.N. BHANDARI)J.
