# Allahabad High Court, WRIC/32158/1995, 2019-04-12

Court No. - 34
Case :- WRIT - C No. - 32158 of 1995
Petitioner :- Sabha Narain
Respondent :- State Of U.P. And Others
Counsel for Petitioner :- M.N. Singh,V.K. Singh
Counsel for Respondent :- C.S.C.,S.C.,Yogendra.Pati.Tripathi
Hon'ble Sudhir Agarwal,J.
1. In this writ petition, allotment of land to beneficiaries
(respondents) declared surplus vide order dated 24.07.1995 is
under challenge.
2. In connected Writ Petition No. 2966 of 1995, surplus land
declared by Prescribed Authority vide order dated 16.09.1974
has been set aside by this Court vide order of date and once the
order impugned is set aside, all subsequent proceedings for
allotment of land are wholly illegal and without jurisdiction.
3. In the result, this writ petition is also allowed. Impugned
order dated 24.07.1995 is hereby set aside.
Order Date :- 12.4.2019
Siddhant Sahu
