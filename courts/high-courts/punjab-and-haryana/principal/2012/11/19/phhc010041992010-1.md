AJAY TEWARI, J (Oral)
In this petition, head note as well as the prayer clause read as
under :-
“Civil Revision Petition under Article 227 of the
Constitution of India for setting aside the order dated
22.5.2008 passed by Commissioner under Workmen's
Compensation Act vide which the application of the
petitioner for setting aside the ex-parte award was
dismissed without any reason.”
“It is, therefore, prayed that revision petition be accepted
and the order/award dated 22.5.2008 and the order
dismissing the application for setting aside the award be
set aside.”

 C.R No. 2062 of 2010 (O&M) ::2::
On 22.5.2008, the main award was passed. Thereafter, the
petitioner filed an application for setting aside the ex-parte award which
came to be dismissed on 11.6.2009. It is not disputed that the main award is
appealable under Section 30 of the Workmen's Compensation Act, and it is
the order refusing to set aside the ex-parte Award which is revisable. A
perusal of the head note of the petition tends to give an impression that only
the order refusing to set aside the ex-parte award has been challenged even
though the date mentioned is that of the main award. Of-course, in the
prayer clause, prayer has been made to set aside not only the order refusing
to set aside the ex-parte award but the main award as well.
In my considered opinion, both the orders could not have been
challenged by one omnibus petition. The main award had to be challenged
under Section 30 of the said Act by way of an appeal which has not been
filed. Consequently, this petition is restricted to challenge the order
refusing to set aside the ex-parte award.
Counsel for the petitioner has argued that summons were never
served upon the petitioner.
A perusal of the impugned order reveals that the learned
Commissioner has found that the petitioner had admitted before him that he
had notice of the claim. Apart from that, registered notice had been duly
served at the residential address of the petitioner. Consequently, no fault
can be found with the impugned order. Resultantly, this petition is
dismissed with no order as to costs.
