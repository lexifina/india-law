This petition coming on for conciliation this day, the Bench passed the
following:
ORDER
This petition is filed against the transfer order dated 11.10.2022. This
order was stayed by the High Court vide order dated 23.11.2022. The stay has
continued for more than six months.
Accordingly, the impugned transfer order dated 11.10.2022 is quashed.
The stay is made absolute. The State is given liberty to pass fresh order in
accordance with law, if administrative exigency so arises.
In above terms, this writ petition is disposed of.
