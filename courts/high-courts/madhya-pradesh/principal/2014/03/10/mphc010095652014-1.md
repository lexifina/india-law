# High Court of Madhya Pradesh, MCRC/3001/2014, 2014-03-10

MCRC No. 3001/2014
10.03.2014
Shri Sumit Raghuwanshi, Advocate for the applicant.
Shri Vijay Kumar Pandey, Deputy Advocate General for
the respondent/State.
The previous application filed by this applicant being
MCRC No.1158/2014 has been dismissed by this Court on 10th
February, 2014. No changed circumstance has been brought on
record nor the counsel appearing for the applicant is able to
demonstrate, which would warrant consideration of this
application.
The argument of the applicant that some of the aspects
were not considered while passing the earlier order dated 10th
February, 2014 cannot be the basis to entertain successive bail
application.
The applicant is free to pursue other remedy, if so
advised, but having failed to point out any changed
circumstance, we decline to entertain this successive bail
application.
Rejected.
(A. M. Khanwilkar) (K.K. Trivedi)
 Chief Justice Judge
