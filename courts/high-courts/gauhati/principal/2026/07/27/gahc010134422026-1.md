2. By this application, the petitioner has sought for correction of clerical/typographical
error in the order dated 11.06.2026 passed in AB 1074/2026.
3. The learned counsel submits that in the said order, the registration number of
Golakganj Police Station Case Number was wrongly reflected as Golakganj P.S Case
No.24/2026, whereas, it should be Golakganj P.S. Case No.94/2026.
4. The learned counsel has also pointed out that the penal provision related to the said
case was written as Section 303(3), but it should have been Section 303(2) of the BNS,
2023. He also submits that the father’s name of the petitioner No.2 was written as Abu
Kashem and the same should have been Abul Kashem.
5. It is seen that in the second paragraph of the order dated 11.06.2026, the case
number was written as Golakganj P.S. Case No.24/2026, however, the same should be
Golakganj P.S. Case No.94/2026, so far as the penal provision mentioned in the said FIR
was 303(2) and in the same paragraph, the penal provision was written as Section 303(3)
BNS, 2023.
6. Further, the name of the father of the petitioner No.2 was written as Abu Kashem
whereas, by seeing the cause title, it should have been Abul Kashem.
7. As such, in the order dated 11.06.2026 in paragraph-2, the case number should be
read as Golakganj P.S. Case No.94/2026 and the penal provision should be read as Section
303(2) and the name of the father of the petitioner No.2 should be read as Abul Kashem.
8. Necessary corrections are made. The present order will become a part of the order
dated 11.06.2026.
I.A. stands disposed of.
