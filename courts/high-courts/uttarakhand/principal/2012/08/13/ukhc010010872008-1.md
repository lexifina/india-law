# High Court of Uttarakhand, FA/76/2008, 2012-08-13

Review Application No. 630 of 2012
Delay Condonation Application No. 8244 of 2012
In
FA No. 76 of 2008
Hon’ble Barin Ghosh, C.J.
Hon’ble U.C. Dhyani, J.
Mr. Anurag Bisaria, Advocate for the appellant /
applicant.
Mr. Sudhir Kumar, Advocate for the respondent.
Considered the averments made in the Application for
condonation of delay in filing the Review Application and,
being satisfied with the reasons furnished therein, we allow
the same.
The Application for Review seeks to re-argue the
matter. The same is not permissible. Accordingly, the
Review Application fails and the same is dismissed.

 (U.C. Dhyani, J.) (Barin Ghosh, C.J.)
