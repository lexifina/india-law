ORDER
This Criminal Miscellaneous Case is filed under
Section 482 of the Code of Criminal Procedure, 1973 (“the
Code” for the sake of brevity).
2. This criminal miscellaneous case is filed
challenging Annexure-A3 by which the prayer of the
petitioner to release a mobile phone is rejected. The Public
Prosecutor, after getting instructions, submitted that the
mobile phone is already sent for examination to RFSL,
Kottayam. If that be the case, there is no question of
releasing the same at this stage. Once the report came
from RFSL along with the mobile phone, the petitioner is
free to approach the court below with a fresh petition and if
such a petition is filed, the court below will consider the
same in accordance with law.

CrlM.C..No.9126/2023
3
With the above observation, this criminal
miscellaneous case is disposed of.
