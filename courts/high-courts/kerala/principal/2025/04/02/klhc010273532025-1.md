O R D E R
When this bail application came up for consideration,
the learned Public Prosecutor submitted that the
investigating agency is proposed to file a custody application
before the jurisdictional court. If that is the case, this bail
application need not be entertained now. The petitioner can
file a fresh bail application before the jurisdictional court,
once the custody application is filed and the custody period is
over.
With the above observation, this bail application is
disposed of.
