# Allahabad High Court, CRLP/13162/2019, 2019-05-16

Court No. - 51
Case :- CRIMINAL MISC. WRIT PETITION No. - 13162 of 2019
Petitioner :- Shah Hussain
Respondent :- State Of U.P. And 4 Others
Counsel for Petitioner :- Sumit Jaiswal,Irfan Hasan
Counsel for Respondent :- G.A.
Hon'ble Vipin Sinha,J.
Hon'ble Ifaqat Ali Khan,J.
This is the second writ petition. The petitioner has earlier approached this
Court by filing Criminal Misc. Writ Petition No.4532 of 2019 which was
disposed of finally vide order dated 18.2.2019 passed by another Bench of
this Court. The said order has been perused by this Court.
It is not being disputed that the said order was not complied with and now
a second writ petition has been filed virtually for the same cause of action.
The second writ petition for the same cause of action is not maintainable
and accordingly, the same is dismissed.
Order Date :- 16.5.2019
