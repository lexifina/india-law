ORDER
 28.03.2023
 Vide order dated 14th March 2023 learned counsel for the respondents had
sought time to file response to the application seeking leave to file the appeal against
the judgment of acquittal. In the said order it was observed that in the event
objections are not filed, the said application seeking leave shall be considered on
merits.
 Neither the reply has been filed till date nor there is representation on behalf
of the respondent today.
 The issues raised can be considered only if the leave to file the appeal is
granted.
 Hence, in view of above, for the reasons stated in the application, same is
allowed. Leave is granted to file the appeal against the judgment of acquittal.
 Registry to diarize the appeal and list for consideration on 11th April 2023.
