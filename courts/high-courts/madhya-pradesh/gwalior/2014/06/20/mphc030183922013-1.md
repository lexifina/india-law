# High Court of Madhya Pradesh, WP/6262/2013, 2014-06-20

WP No.6262/2013
20.06.2014
Shri Vishal Mishra, Advocate for the petitioner.
Shri S.P. Jain, Advocate for the respondents No. 2 & 3.
Learned counsel for the parties submit that an interim
order is prevailing in this matter since September, 2013 and
therefore, administrative exigency which was prevailing when
the order Annexure P/1 was passed must be over. Thus, said
order may be set aside but liberty be reserved to the other
side to pass fresh order if administrative exigency so requires.
Prayer is reasonable.
In view of consensus of the parties aforesaid, impugned
order dated 31.08.2013 (Annexure P/1) is set aside. Liberty is
reserved to the employer to pass fresh order if required.
Petition is allowed to the extent indicated above.
 (Sujoy Paul)
