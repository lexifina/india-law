02/ 11th September, 2026
1. Heard the parties.
2. The petitioner has filed an application before the Project
Director, NHAI which is not the Competent Authority under the Act.
3. The Project Director, has returned the application with a
request to file before the Competent Authority. Thus, no contempt is
made out at this stage, accordingly, this contempt application is
dropped.
4. It will be open to the petitioner to file an appropriate
application before the Competent Authority in terms of the order
dated 30.03.2026 passed by this writ Court in W.P.(C) No.1960 of
2026.
