# High Court of Madhya Pradesh, MCC/266/2015, 2015-07-23

MCC-266-2015
(L.I.C. OF INDIA Vs SHRI MAHENDRA SINGH CHHABRA)
23-07-2015
Shri R.K.Upadhyay, learned counsel for the applicant.
This application has been filed for restoration of First Appeal
No.27/2005 which was dismissed for non-compliance of the
peremptory order passed on 14.2.2007. There being some delay,
I.A.No.1301/2015 has been filed.
Keeping in view the reasons indicated in the application for
condonation of delay in filing the application for restoration, which
is supported by the affidavit and finding the same to be bonafide,
I.A.No.1301/2015 is allowed. Condoning the delay in filing the
restoration application, the restoration application itself is allowed.
First Appeal No.27/2005 is restored to its original file. It be placed
before an appropriate Bench.
The MCC stands allowed and disposed off.
(RAJENDRA MENON)
JUDGE
(SUSHIL KUMAR GUPTA)
JUDGE
