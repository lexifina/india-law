2 16-06-2015 Heard learned counsel for the parties.
 Having regard to the fact that earlier an application for
anticipatory bail of the petitioner was dismissed for default on
01.08.2014 in Cr. Misc. No. 4542 of 2014, this application definitely is
not maintainable inasmuch as it was for the petitioner to file an
application for restoration of that application.
That being so, this application is wholly misconceived and
is, accordingly, dismissed.
