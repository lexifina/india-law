PRAYER: Criminal Original Petition filed under Section 482 of the
Criminal Procedure Code, to call for the records relating to the
criminal case in Crime No.368 of 2017, pending on the file of the
first respondent, Puthukadai Police Station and quash the same.
For Petitioner : Mr.N.Dilip Kumar
For R-1 : Mr.M.Chandrasekaran
 Additional Public Prosecutor
O R D E R
This Criminal Original Petition has been filed to quash the
First Information Report in Crime No.368 of 2017, pending
investigation on the file of the first respondent Police.
2.Today, when the matter was taken up for hearing, the
learned Additional Public Prosecutor, appearing for the first
respondent, on instructions, submitted that the investigation has
been completed and final report has already been filed before the
Judicial Magistrate No.II, Kuzhithurai and the same has been taken
on file in C.C.No.219 of 2019.
3.In view of the above development, this Court is not
inclined to interfere with the First Information Report at this
stage. Liberty is granted to the petitioner to challenge the final
report, if so advised.
