# High Court for the State of Telangana, CRP/1036/2015, 2015-06-23

THE HONOURABLE SRI JUSTICE M.S.RAMACHANDRA RAO
CRP.No.1036 of 2015
ORDER :
The counsel for petitioners seeks with withdraw this
Revision with liberty to file an appeal against the
impugned order.
2. Granting permission as sought for, the Civil
Revision Petition is dismissed as withdrawn. No order as
to costs.
3. The Registry is directed to return the certified copy
of the impugned order to the learned counsel for petitioner
immediately.
4. As a sequel, miscellaneous petitions pending, if
any, in this Revision shall stand closed.

JUSTICE M.S.RAMACHANDRA RAO
