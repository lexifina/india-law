# Allahabad High Court, BAIL/17142/2018, 2018-07-19

Court No. - 55
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 17142 of 2018
Applicant :- Suresh And Another
Opposite Party :- State Of U.P.
Counsel for Applicant :- Shashank Kumar,Shilpa Ahuja,Vinod Kumar
Yadav
Counsel for Opposite Party :- G.A.
Hon'ble Vivek Kumar Singh,J.
Heard learned counsel for the applicant and learned AGA
appearing for the State.
Applicant no. 2, Jai Singh has been granted bail by this Court
on 31.5.2018.
This bail application has been moved on behalf of applicant
no.1, Suresh. In this bail application a prayer has been made to
permit the counsel for the applicant to delete the name of
applicant no2 in the memo of bail application and the same
may be dismissed as withdrawn with liberty to file fresh bail
application only on behalf of the applicant Suresh.
Learned counsel for the applicant is permitted to withdraw the
bail application with liberty to file fresh bail application on
behalf of applicant Suresh.
Certified copy of the F.I.R. filed with the rejection order
datd4.4.2018 be returned back to the learned counsel for the
applicant so that he may file fresh bail application.
This bail application is accordingly dismissed as withdrawn.
Order Date :- 19.7.2018
