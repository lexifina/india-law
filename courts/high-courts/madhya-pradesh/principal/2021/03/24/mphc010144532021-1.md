# High Court of Madhya Pradesh, MCRC/15783/2021, 2021-03-24

(SANJAY DWIVEDI)
The High Court Of Madhya PradeshThe High Court Of Madhya Pradesh
MCRC-15783-2021
(SANTOSH SINGH GOND Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 24-03-2021
Shri Yagyavalk Shukla, learned counsel for the petitioner.
Shri Palash Upadhyay, learned Panel Lawyer for the
respondent/State.
Learned counsel for the petitioner submits that by the instant
application filed under Section 482 of the Code of Criminal
Procedure, the petitioner is seeking modification in the order dated
15.03.2021 passed in M.Cr.C. No.8698/2021, whereby wrong Crime
Number i.e. 229/2019 has been mentioned in the order whereas the
correct crime number is 290/2019. He further submits that in the bail
application, which was entertained by this Court, the Crime Number
was wrongly mentioned for the reason that in the order which was
under challenge before this Court, the Court below has mentioned the
incorrect crime number and under the misconception, the said number
was reproduced in the bail application submitted on behalf of the
petitioner, upon which the order dated 15.03.2021 has been passed.
Considering the request made by learned counsel for the
petitioner and on the basis of the statement that the actual Crime
Number is 290/2019, the order dated 15.03.2021 passed in M.Cr.C.
No.8698/2021 is modified to the extent that the crime number be
read as 290/2019 instead of 229/2019.
With the aforesaid modification, this application stands
allowed.
