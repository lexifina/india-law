PER COURT :
1. An application of the petitioner under Order XVIII Rule
17 of the Code of Civil Procedure [ For short, ‘ the Code ’ ] is
rejected. Aggrieved thereby the present Writ Petition is filed.
2. Mr. More, learned counsel submits that due to
inadvertence, some questions were to be put in cross
examination. Order XVIII Rule 17 of the Code permits recall of
the witness for the said purpose. According to the learned
counsel, the Court has erroneously rejected the said
application.
3. From the perusal of the application, it is manifest that the
application does not depict the questions to be put to the

 2 W.P. 8645.2011
witness, who is sought to be recalled. Order XVIII Rule 17 of
the Code permits the Court to recall the witness and put the
question to him. The parties have to give the list of questions,
which are remained to be asked to the Court.
4. In light of the above, no error is committed by the Court
in rejecting the said application. However, the petitioner is at
liberty to file fresh application, which the Court would consider
on its own merits. No costs.
