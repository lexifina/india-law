# Gauhati High Court, AB/1711/2014, 2014-09-11

AB 1711/2014
BEFORE
HON’BLE MR JUSTICE C R SARMA
Heard Mr. S.C. Biswas, learned counsel appearing for the petitioner. Also heard
Mr. B.S. Sinha, learned Addl. P.P., Assam, appearing for the State respondent.
By this application filed under Section 438 Cr.P.C. the petitioner, namely, Md.
Jiaul Haque has prayed for pre-arrest bail in connection with Bijni P.S. Case
No. 290/2013 under Sections 347/381/384/406/420/506 IPC.
The learned Addl. P.P. has submitted that police has already submitted final rep
ort in this case.
In view of above, this bail application is closed.
