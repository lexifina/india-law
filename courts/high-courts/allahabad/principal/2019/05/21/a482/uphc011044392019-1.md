# Allahabad High Court, A482/20200/2019, 2019-05-21

Court No. - 70
Case :- APPLICATION U/S 482 No. - 20200 of 2019
Applicant :- Ashok Kumar
Opposite Party :- State Of U.P. And Anr
Counsel for Applicant :- Sanjeev Kumar Khare
Counsel for Opposite Party :- G.A.
Hon'ble Sanjay Kumar Singh,J.
At the very outset, learned counsel for the applicant prays for
and is permitted to withdraw this application on account of
some defect in the petition with liberty to file a fresh
application.
The prayer so made is allowed. The present application is
dismissed as withdrawn with liberty to file a fresh application
with better particulars.
Certified copy of the charge-sheet dated 15.8.2017 as well as
cognizance order dated 15.12.2018 appended as Annexure No.8
to the application be returned to the counsel for the applicant
after obtaining the xerox copy of the same.
