Heard Mr. S. Sarma, learned counsel for the petitioner as well as Mr. B. Sarma, learned Addl.
P.P. for the State.
By filing this I.A., the learned counsel for the petitioner has projected that bail was granted to
the applicant by order dated 25.10.2018 in AB No. 3405/2018, but due to some error a
different order was given to him on obtaining certified copy.
Having seen the order dated 25.10.2018 in AB No. 3405/2018, this Court is inclined to direct
the Registry to issue the correct certified copy of the order to the applicant.

Page No.# 2/2
Let this I.A. along with the file of AB No. 3405/2018 be placed before the learned Registrar
(Judicial) so as to enable him to issue necessary direction to give the certified copy of the
correct order to the applicant.
Accordingly, as this is not a case requiring any correction of any Judicial order, hence, this
Court is inclined to allow this application on terms as indicated above.
