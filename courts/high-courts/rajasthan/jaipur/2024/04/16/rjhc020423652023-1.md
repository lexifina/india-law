Order
16/04/2024
At the outset, learned counsel for the petitioner submitted
that the present misc. application is filed seeking
rectification/correction in the order dated 09.03.2023.
In pursuance to the order dated 04.12.2023, letter dated
22.12.2023 was communicated by Additional District and Session
Judge, Mahwa, District Dausa, wherein it has been submitted that
the correct number of the case is 06/2018 and there is no case as
number 66/2017.
Considering the prayer so made in the present Misc.
Application, the same is allowed.
It is ordered that in the order dated 09.03.2023, the case
number be read as “06/2018” instead of “66/2017”.
Rest of the order dated 09.03.2023 be maintained as same.
(SAMEER JAIN),J
