# Allahabad High Court, A482/32561/2023, 2023-11-03

Neutral Citation No. - 2023:AHC:210889
Court No. - 87
Case :- APPLICATION U/S 482 No. - 32561 of 2023
Applicant :- Devesh Kumar
Opposite Party :- State Of U.P. And 5 Others
Counsel for Applicant :- Manoj Pandey
Counsel for Opposite Party :- G.A.,Karunesh Narayan Tripathi
Hon'ble Neeraj Tiwari,J.
1. Heard learned counsel for the applicant, learned AGA for the
State and Sri Karunesh Narayan Tripathi, learned counsel for the
opposite party no.2.
2. After some argument, learned counsel for the applicant
submitted that he does not want to press the present application
and it may be dismissed as withdrawn for which Sri Karunesh
Narayan Tripathi, learned counsel for the opposite party no.2 has
no objection.
3. Accordingly, the application is dismissed as withdrawn.
4. However, no liberty is given to applicant to file fresh application
for the same cause of action.
