Judgement / Order
17/11/2016

2
The instant application has been filed seeking
correction in the order dated 15.11.2016.
Learned counsel for the petitioner states that
due to inadvertence, in the order dated 15.11.2016
passed in Writ Petition No.8461/2016, instead of Class
VI in which the petitioner craves admission has been
mentioned as Class IV. He thus prays that necessary
correction be made.
The prayer thus made is justified.
Accordingly, it is ordered that Class IVth
mentioned in the order dated 15.11.2016 shall be
read as Class VIth.
The application is thus disposed of.
 (SANDEEP MEHTA)J.
