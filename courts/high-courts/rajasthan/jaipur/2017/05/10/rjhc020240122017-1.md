HON'BLE MR. JUSTICE M.N. BHANDARI
Order
10/05/2017
By this writ petition, a challenge is made to the budget
announcement of the State Government dated 8.3.2017 and also
order dated 10.4.2017 by which Nodal Officer has been appointed
for Government College at Begu, District – Chittorgarh.
It is a case where as per the policy of the State
Government, petitioners’ institution was recognised. The
respondents thereupon de-recognised the institution. The order
was challenged by maintaining CW 10767/2014, which was
allowed vide order dated 8.11.2016. The impugned order dated
26.9.2014 was set aside by applying the directions given in the
case of “Meera Shiksha Samiti, Sangaria versus State of
Rajasthan”, SB Civil Writ Petition No.9409/2014, decided on
17.10.2016 at Principal Seat, Jodhpur. Therein order of de-recognition was set aside with consequential benefits.
If the order of this court was not complied, the
petitioners could have preferred a contempt petition but instead of
that, petitioners have filed this petition. In pursuance of the order
of this court, when de-recognition goes, consequence has to be
followed thus I do not find any reason to interfere in the impugned

order but this writ petition is disposed of with liberty to the
petitioners to file a contempt petition if compliance of the order
has not been made.
