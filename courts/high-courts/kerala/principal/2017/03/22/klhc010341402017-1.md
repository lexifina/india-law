JUDGMENT
The petitioners were set ex parte in O.S.No.48/2014 on the file
of the Munsiff Court, Harippad. The petitioners filed application to set
aside ex parte decree with a petition for condoning the delay of 119
days in filing application to set aside the ex parte decree. The
petitioners also filed application for staying the operation and
implementation of ex parte decree passed against them.
Having considered the facts and circumstances, there shall be a
direction to the Munsiff Court, Harippad to dispose the application to
set aside ex parte decree along with delay condonation petition before
summer holidays. Till the disposal of applications as above, operation
and implementation of ex parte decree is stayed.
The original petition is disposed of as above.
