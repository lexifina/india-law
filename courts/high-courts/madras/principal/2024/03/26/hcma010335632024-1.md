# Madras High Court, A/1657/2024, 2024-03-26

A.No.1657 of 2024
in OP.No.525 of 2014
C.SARAVANAN, J.
This application is filed to set aside
the dismissal order dated 05.09.2023 and to
restore the OP.No.525 of 2014.
2. Already, this Court has passed an
order dated 12.03.2024 to condone the delay
in filing the application for restoration of
the above OP.
3. Being satisfied with the reasons
stated in the affidavit filed in support of this
application, this application deserves to be
allowed. Accordingly, OP.No.525 of 2014
stands restored on the file of this Court.
4. List after four weeks, both the
parties are directed to be ready with the
case.
