# High Court of Orissa, WP(C)/19836/2010, 2019-02-14

06. 14.02.2019 Learned counsel for the petitioner submits that the
petitioner may be permitted to withdraw this writ petition
with liberty to file a fresh application if any cause of action
survives.
 A memo has also been filed with the same prayer,
which is taken on record.
 Accordingly, the writ petition stands dismissed as
withdrawn with liberty aforesaid.
