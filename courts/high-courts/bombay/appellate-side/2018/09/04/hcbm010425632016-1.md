P.C. :-
1. Learned Trial Court has framed the issue under section 9-A
of the Code of Civil Procedure, 1908 by an order dated 19th June,
2013 “whether the suit filed is within limitation or not”.
2. The petitioners (original plaintiffs) have applied for review
of the said order which application has rejected by an order dated 22nd
July, 2015.
3. In view of deletion of section 9-A of the Code of Civil
Procedure, 1908, the issue of limitation can be tried as one of the
issue along with other issues under Order XIV Rule 2 of the Code of
Civil Procedure, 1908.
4. Hearing of RCS No.234 of 2011 is expedited. The writ
petition stands abated in view of deletion of section 9-A of the Code of
