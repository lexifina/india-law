JUDGMENT
There is no representation on the side of the appellant. Till date,
the appellant has not taken steps to file an application seeking to restore
the appeal, which was dismissed as against the first respondent. On the
last hearing date, the learned counsel for the appellant sought further time
to file an application to restore the appeal, which was dismissed as
against the first respondent.
Since there is no representation on the side of the appellant and till
date, steps have not been taken to file an application to restore the appeal,
which was dismissed as against the first respondent, it can now be
inferred that the appellant is not interested in prosecuting the appeal.
Accordingly, the Civil Miscellaneous Appeal is dismissed for non-prosecution. No Costs.
