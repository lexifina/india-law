ORDER
Date : 11-05-2026
By an Order dated 04.05.2026, passed in FA/3/2024, the appellant
was given the liberty to file appropriate application for deletion of the
provisions relating to civil rules, i.e., Section 115 of the Code of Civil
Procedure from the cause title, while filing the first appeal. This
interlocutory application is accordingly filed.
2. The learned counsel for the applicant has been heard. The learned
counsel for the respondent had not objected to the deletion of the
provisions of Section 115 of the Code of Civil Procedure. Accordingly, this
interlocutory application is allowed.
3. The provisions of Section 115 of the Code of Civil Procedure
appearing in the Cause Title of FA/3/2024 shall stand deleted.
4. I.A.(Civil)/80/2026 is allowed and disposed of.
