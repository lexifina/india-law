PRAYER: This Criminal Original Petition has been filed under Section 482
of the Code of Criminal Procedure, to call for the FIR on the file of the
respondent police in Cr.No.334 of 2012 and quash them as illegal.
For Petitioner : M/s.V.Sankaranarayanan
 For R1 : Mr.P.Kandasamy Govt. Advocate(Crl. Side)
ORDER
 Heard the submissions of the learned counsel appearing for the
petitioners and the learned Government Advocate (Crl.side) on instruction
would submit that the case in Crime No.334 of 2012 registered by the
first respondent, after investigation, has culminated in a final report
which has been taken on file in C.C.No.108 of 2013, on the file of the
Judicial Magistrate, Andipatti.
2.In view of the same, nothing survives for adjudication. Therefore,
this Criminal Original Petition is dismissed as infructuous.
Consequently, connected Miscellaneous petitions is closed.
