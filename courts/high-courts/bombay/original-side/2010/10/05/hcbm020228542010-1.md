P.C. :
1. By this chamber summons, the defendant wants that decree
passed against him be set aside. If a person wants to have a decree
set aside, he should take out the notice of motion. Unless the decree is
set aside, execution application cannot be set aside. Hence, this
chamber summons is dismissed as not maintainable. There shall be no
order as to costs.
