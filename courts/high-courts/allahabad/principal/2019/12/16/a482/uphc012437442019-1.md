# Allahabad High Court, A482/46408/2019, 2019-12-16

Court No. - 75
Case :- APPLICATION U/S 482 No. - 46408 of 2019
Applicant :- Suhail Siddiqui
Opposite Party :- State of U.P. and Another
Counsel for Applicant :- Ved Prakash Mishra
Counsel for Opposite Party :- G.A.
Hon'ble Rajiv Gupta,J.
After some arguments, learned counsel for the applicant
submits that he does not want to press this applicant and
the same may be dismissed as with drawn with liberty to
file fresh application with better particulars.
In view of above, the application filed u/s 482 Cr.P.C. is
dismissed as withdrawn with liberty to file fresh application
with better particulars.
Certified copy, if any, be returned back to learned counsel
for the applicant as per the Rules.
Order Date :- 16.12.2019
