HON'BLE MRS. JUSTICE SABINA
Order
25/7/2017
Petitioner has filed this petition under Section 482
Code of Criminal Procedure, 1973 challenging the order dated
11.1.2017, whereby, application moved by the petitioner under
Section 70(2) Code of Criminal Procedure, 1973 was dismissed.
Heard.
Petitioner had jumped bail on 6.1.2000. In these
circumstances, the learned trial court had rightly dismissed the
application moved by the petitioner under Section 70(2) Code of
Criminal Procedure, 1973.
No ground for interference is made out.
Dismissed.
