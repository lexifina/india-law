# High Court of Uttarakhand, WPMS/1773/2013, 2014-03-31

WPMS No. 1773 of 2013
Hon’ble Alok Singh, J.
Mr. N.S. Pundir, Advocate for the
petitioner.
Mr. A.K. Joshi, Addl. C.S.C. for the
respondents/State.
Learned counsel for the petitioner
submits that contract period is over. Earlier
black listing order dated 30.04.2013 has
already been withdrawn vide order dated
20.05.2013, therefore, as on day, there is no
black listing order against the petitioner.
In view of the above, learned counsel for
the petitioner seeks permission to withdraw
this petition with liberty to file fresh if
respondents do not permit the petitioner to
participate in the next tender process.
Permitted to be withdrawn with the
aforesaid liberty.
 (Alok Singh, J.)
Dated 31.03.2014
