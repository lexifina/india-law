ORDER
This writ petition has been filed to direct the first to
fifth respondents to implement the order dated 12.04.2016
passed by the second respondent.
2. It seems that the second respondent has passed the order
dated 12.04.2016 in Na.Ka.181/2016/A-5 under Section 145 Cr.P.C
and the petitioner has filed this petition seeking direction to
the first to fifth respondents to implement the same. As such
the third respondent is directed to implement the said order
dated 12.04.2016, if not implemented so far.
3. With the above direction, this writ petition stands
disposed of. No costs.
