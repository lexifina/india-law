# High Court of Madhya Pradesh, MCC/1465/2014, 2014-08-14

MCC NO.1465/2014
14/08//2014

This application has been filed for restoration of
W.P.No.9049/2014, which has been dismissed in view of the
common conditional order passed.
Keeping in view the reasons given in the application
and finding the same to be bonafide, this application is
allowed. W.P.No.9049/2014, is restored to its original file. It
be placed for orders before an appropriate Bench.
Accordingly this application stands allowed and
disposed of.
