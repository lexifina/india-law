APPLICATION U/S 438 CR.P.C. No. - 608 of 2020
Applicant :- Ram Prakash Alias Chhunnapal
Opposite Party :- State of U.P.
Counsel for Applicant :- Ram Surat Patel
Counsel for Opposite Party :- G.A.
Hon'ble Dinesh Kumar Singh-I,J.
1. Sri Ram Surat Patel, learned counsel appearing for the
applicant, has prayed that he does not want to press this
application and the same may be rejected with liberty to file
afresh before the Sessions Judge.

not pressed, with liberty to file afresh before the Sessions
Judge, as prayed.
3. Certified copy of the document(s) annexed in the affidavit
appended to the application be returned forthwith, provided that
a photostat copy of the same is retained on record.
