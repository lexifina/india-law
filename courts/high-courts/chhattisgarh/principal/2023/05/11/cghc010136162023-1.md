1. Heard Mr. Suresh Tandon, learned counsel for the petitioner. Also
heard Mr. Avinash Singh, learned Panel Lawyer, appearing for the
respondents/State.

2
2. There is various defects pointed out by the Stamp Reporter and the
petitioner has prayed for some time to cure the same.
3. This practice is not appreciable as it is the duty of the counsel for
the petitioner to file a petition in a proper manner following all the
requisite conditions for filing of an appeal.
4. The learned counsel for the petitioner seeks permission of this
Court to withdraw this petition with liberty to file afresh.
5. Learned State counsel has no objection.
6. Permission is granted.
7. Accordingly, the appeal is dismissed as withdrawn with liberty to file
afresh.
8. Certified copy of the impugned order be returned to the learned
counsel for the appellant after furnishing duly photostat copy of the same.
