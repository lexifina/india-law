# High Court of Orissa, WP(C)/1816/2017, 2019-03-11

09. 11.03.2019 On 26.11.2018, the following order was passed:
“Copy of the counter affidavit is served on learned
counsel for the petitioners.
 In view of the counter affidavit, learned counsel
for the petitioner requests for time.
 The matter to come up on 10.12.2018.”
 On 10.12.2018, the following order was passed:
“Learned counsel for the petitioners requests for time
to file rejoinder.
 This matter to come up on 07.01.2019.”
 On 07.01.2019, the following order was passed:
“In view of the rejoinder affidavit filed by the
petitioners in Court today. The same be kept on record.
 List this matter on 21.01.2019.”
 On 21.01.2019, the following order was passed:
“In view of the rejoinder filed, learned counsel for the
State requests for time.
 This matter to come up on 18.02.2019.”
 Today, learned counsel for the petitioners is not
present.
 Hence, the writ petition stands dismissed for non-prosecution.
All connected Misc. Cases/I.As. if any, are
accordingly disposed of.
