2. There is no doubt that legally, there is provision for
effecting a change of name in the certificates though by
way of a proper process. In the present matters, the
petitioners' parents claim to have changed their name in
the Passport as well as in Aadhar card. Let the
applications filed for effecting such change before the
Passport authorities and Aadhar authorities be produced
on the enxt next date of hearing.
3. The question to be answered is as to whether the entire
name (both the first name as well as second name) can be
changed without effecting a name change through the
official gazette. Supporting documents be filed as
aforesaid.
4. The petitioner will also file a tabulation of the various
statutory authorities before which the name of the
petitioners' mother has been changed.
5. List on 08.12.2023. Counters by then in all writ
petitions with an advance copy served upon the
petitioners.”
2. Today, learned counsel for the petitioner would state that, in fact, the
name of the mother has been changed by way of official application in the
Gazette and a copy of the same is produced before the Court.
3. Learned counsel for Corporation would state that there is no difficulty
in such circumstances to change the birth certificate of the petitioners'
incorporating the amended name of mother and father. Let the needful be done
within a week from today.
4. List on 29.01.2024 at the end of admission list.
