# High Court of Madhya Pradesh, MCRC/43607/2020, 2020-11-06

(ANAND PATHAK)
JUDGE
The High Court Of Madhya PradeshThe High Court Of Madhya Pradesh
MCRC-43607-2020
(BITTU SHARMA Vs STATE OF MADHYA PRADESH)
Gwalior, Dated : 06-11-2020
Shri Rajiv Sharma, learned counsel for the applicant.
Shri Nitin Goyal, learned PL for the respondent/State.
Heard through Video Conferencing.
Heard on document No.8326/2020 by which applicant wants to
replace the cause title as according to him, this is second bail application
while due to inadvertence, first bail application has been mentioned in cause
title. Same needs to be corrected.
On due consideration, document is allowed. The present application is
directed to be treated as second bail application.
Heard on bail application.
When learned counsel for the respondent/State referred suicide note
and act of the applicant, then learned counsel for the applicant seeks
withdrawal of this bail application.
Prayer accepted.
Application is dismissed as withdrawn.
Anil*
