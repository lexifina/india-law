# High Court of Madhya Pradesh, MCC/3464/2015, 2016-08-31

MCC-3464-2015
(NRIPAT Vs MAHILA MALDI)
31-08-2016
The case is listed for correction of typographical error in the order
dated 09.12.2015, wherein S.A. No.167/2007 has been wrongly
mentioned instead of S.A. No.167/2009.
Vide order dated 09.12.2015, S.A. No.167/2007 has been restored
instead of S.A. No.167/2009. The above typographical error needs
to be corrected. It is therefore made clear that in the aforesaid
order wherever S.A. No.167/2007 is mentioned be read as S.A.
No.167/2009.
This order shall be read in conjunction with the order dated
09.12.2015.
Certified copy as per rules.
(MISS VANDANA KASREKAR)
JUDGE
