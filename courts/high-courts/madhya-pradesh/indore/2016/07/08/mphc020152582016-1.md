# High Court of Madhya Pradesh, MCRC/5849/2016, 2016-07-08

M.Cr.C. No.5849/2016
08.07.2016
Shri Gaurav Verma, learned counsel for the
applicant.
He submits that inadvertently, the applicant has
filed this application u/s. 439(2) of the Cr.P.C. Before this
Court whereas it should have been filed before the Sessions
Court as the Sessions Court has granted the bail. He,
therefore, seeks permission to withdraw this M.Cr.C. With
liberty to file the said application before the appropriate
forum.
Permission granted. This M.Cr.C. stands
dismissed as withdrawn with the aforesaid liberty.
( JARAT KUMAR JAIN )
 JUDGE.
