# Allahabad High Court, A482/18184/2019, 2019-05-07

Court No. - 70
Case :- APPLICATION U/S 482 No. - 18184 of 2019
Applicant :- Anil
Opposite Party :- State Of U.P. And Anr
Counsel for Applicant :- Mool Chandra Maurya
Counsel for Opposite Party :- G.A.
Hon'ble Sanjay Kumar Singh,J.
At the very outset, learned counsel for the applicant submitted
that on account of some defects, he does not want to press this
application and the same may be dismissed as withdrawn with
liberty to file a fresh application.
The request so made is allowed.
The application is dismissed as withdrawn with liberty to file a
fresh application with better particulars.
Office is directed to return the certified copy of the impugned
charge sheet to the learned counsel for the applicant after
retaining the photocopy of the same on record.
Order Date :- 7.5.2019
