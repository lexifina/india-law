 CORAM : A. K. MENON, J.

P.C.:
This is a notice of motion for restoration of an execution
Application which came to be rejected by self-operative order dated 16th
December, 2015 under Rule 986 of the Original Side Rules. Perused the
affidavit in support of the notice of motion. I am satisfied with the
reasons set out therein. Accordingly the order dated 16th December, 2015
passed by the Prothonotary and Senior Master is set aside and the
Execution Application is restored to file on condition that all the
objections be removed within two weeks, failing which, this order will
stand vacated.
 (A. K. MENON, J.)
