Heard Mr. K. Lollen, learned counsel for the petitioner.
This bail application has been filed under Section 439 of the Code of
Criminal Procedure, 1973, for grant of bail to the petitioner in connection with G.R.
Case No. 532/19 under Sections 448/365/326/34 of the Indian Penal Code read
with Section 25(1B) (a) of the Arms Act pending before the learned Court of
Judicial Magistrate, First Class-Cum-Civil Judge (Junior Division), Changlang
District, Arunachal Pradesh.
Although this bail application has been filed for release of the petitioner, it is

found from the record as well as from the submission of the learned counsel for
the petitioner that the petitioner is not the accused and has not been arrested in
connection with the aforesaid G.R. Case No. 532/19 under Sections
448/365/326/34 of the Indian Penal Code read with Section 25(1B) (a) of the
Arms Act pending before the learned Court of Judicial Magistrate, First Class-Cum-Civil Judge (Junior Division), Changlang District, Arunachal Pradesh.
In that view of the matter, this bail application cannot be adjudicated in the
present form.
The bail application stands dismissed.
