# High Court for the State of Telangana, WP/26071/2012, 2012-09-11

HON’BLE SRI JUSTICE K.C. BHANU
WRIT PETITION No.26071 OF 2012
ORDER:
The learned counsel for the petitioners seeks permission of this
Court to withdraw the writ petition giving liberty to file an application
under Section 482 Cr.P.C.
Permission is accorded.
Accordingly, the writ petition is dismissed as withdrawn giving
liberty to the petitioner to file an application under Section 482 Cr.P.C.
No order as to costs.
Miscellaneous petitions, if any, filed in this writ petition shall stand
closed.
