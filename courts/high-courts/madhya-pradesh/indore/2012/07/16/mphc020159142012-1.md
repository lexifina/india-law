# High Court of Madhya Pradesh, MCRC/5021/2012, 2012-07-16

M.Cr.C. no. 5021/2012
16/07/2012
Mr. Yogesh Gupta, Advocate for the petitioner.
Mr S. D. Bohra, G. A for the respondent / State.
Petitioner has come to this Court for seeking anticipatory
bail. It is submitted that the first application was not pressed because
the prosecution informed about involvement of the petitioner in some
other case. Today, the petitioner has been able to procure the order
regarding acquittal of the petitioner in other case. Petitioner's counsel
however, does not press this application. Consequently, the same is
dismissed as not pressed.
C c as per rules.
 (M.C. GARG)
 JUDGE
