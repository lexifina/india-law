# High Court of Madhya Pradesh, MCRC/19741/2015, 2015-11-30

MCRC-19741-2015
(ABHINAY SINGH Vs THE STATE OF MADHYA PRADESH)
30-11-2015
Shri Himanshu Mishra, learned counsel for the
applicant/accused.
Shri Vaibhav Tiwari, learned P.L. for the respondent/State.
This is the repeat bail application filed by the applicant/accused
under Section 439 of the Code of Criminal Procedure for grant
of bail in connection with Crime No.148/2015 registered at
Police Station Waidhan, District Singrauli for the offences
punishable under Sections 457 and 380 of the IPC.
The first application was dismissed by this Court vide order
dated 16/06/2015 passed in M.Cr.C. No. 6552/2015 with a
direction that if the trial is not concluded within three months,
the applicant /accused would file an application again for bail.
Learned counsel for the applicant/accused seeks permission to
withdraw this application with a liberty to file a bail application
before the trial Court under section 437 (6) of Cr.P.C as the trial
has not been concluded within 60 days from the first date of
recording the evidence fixed by the trial Court.
The prayer is accepted.
Hence, the petition is dismissed as withdrawn with the liberty as
stated earlier.
(M.K. MUDGAL)
JUDGE
