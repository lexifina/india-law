# High Court of Jharkhand, Cr.M.P./2065/2019, 2019-09-23

IN THE HIGH COURT OF JHARKHAND AT RANCHI
Cr. M.P. No. 2065 of 2019
----
Israil Ansari … Petitioner
-versus-The State of Jharkhand … Opposite Party
---
CORAM : HON’BLE MR. JUSTICE ANANDA SEN
----
For the Petitioner : Mr. Syed Tafazzul Sajid, Advocate
For the State : Mr. Navin Kumar Singh, A.P.P.
----
2/ 23.09.2019 Heard learned counsel for the parties.
 Learned counsel for the petitioner confines this application
only with respect to the order dated 02.02.2019 passed by the Judicial
Magistrate 1st Class, Palamau at Daltonganj in connection with Ramgarh
Police Station Case No.47 of 2014 corresponding to G.R. No.2407 of
2014, by which process under Section 82 of the Code of Criminal
Procedure has been issued.
 A perusal of the impugned order dated 02.02.2019 does not
reveal any appropriate reason necessitating issuance process under
Section 82 of the Code of Criminal Procedure and accordingly, the said
order is hereby quashed and set aside.
 This application is allowed.
 However, the learned Magistrate is at liberty to proceed
further in accordance with law.
 Let a copy of this order be communicated through FAX to the
Court concerned at the cost to be deposited by the petitioner.
( Ananda Sen, J.)
Kumar/Cp-03
