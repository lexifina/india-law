# Calcutta High Court, CRR/2722/2012, 2021-09-16

Mr. Arijit Ganguly
Mr. Sandip Chakraborty
…..For the State
This revisional application was preferred challenging the
order dated 18.06.2012 passed by the learned Sub-Divisional
Executive Magistrate, Contai in Misc. Case No.407 of 2012 under
Section 144 of the Code of Criminal Procedure.
Having regard to the time constraints under the provisions
of Section 144 of the Code of Criminal Procedure, I am of the view
that the main proceedings before the Executive Magistrate has
become infructuos.
Accordingly, CRR 2722 of 2012 is dismissed.
Interim order, if any, stands vacated.
All pending connected applications, if any, are
consequently disposed of.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Hon’ble Court.
( Tirthankar Ghosh, J.)
