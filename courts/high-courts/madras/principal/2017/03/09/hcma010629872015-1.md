ORDER
The learned Senior Counsel appearing for the petitioner would fairly
submit that this Criminal Revision Petition may be dismissed with liberty to file
an appropriate application to raise the attachment order under Order 21, Rule
58 CPC before the Executing Court.

2
D.KRISHNAKUMAR, J.
gms/asi
In view of the above submission made by the learned Senior Counsel, this
Criminal Revision Petition is dismissed with liberty to the petitioner to file an
application, if any, as permitted under law. No costs. Connected M.P. is
closed.
