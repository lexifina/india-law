# High Court of Madhya Pradesh, MCC/1484/2017, 2017-05-15

MCC-1484-2017
(NOOR MOHAMMAD Vs THE STATE OF MADHYA PRADESH)
15-05-2017
Shri S.P. Dubey, learned counsel for the applicant.
This application has been filed for restoration of W.P. No.16196/2016
which has been dismissed for want of prosecution on 17.04.2017. The
application is supported by an affidavit of Advocate-Mohd. Imran.
Keeping in view the reasons indicated in the application, the MCC is
allowed and it is directed that W.P. No.16196/2016 be restored to its
original number and list this case before the appropriate Bench.
Let a copy of this order be kept in the file of W.P. No.16196/2016.
(SMT. ANJULI PALO)
JUDGE
