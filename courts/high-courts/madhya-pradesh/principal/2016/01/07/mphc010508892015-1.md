# High Court of Madhya Pradesh, WP/17183/2015, 2016-01-07

WP-17183-2015
(UTTAM PAL Vs THE STATE OF MADHYA PRADESH)
07-01-2016
Shri S.D.Gupta, learned counsel for the petitioner.
Shri Vaibhav Tiwari, learned Panel Lawyer for the respondents.
In view of the fact that charge-sheet has already been filed,
learned counsel for the petitioner submits that the petitioner be
granted liberty to file an application under Section 301 (2) of
the Code of Criminal Procedure to assist the prosecution.
In view of the aforesaid submission, the writ petition is disposed
of with the liberty as aforesaid.
