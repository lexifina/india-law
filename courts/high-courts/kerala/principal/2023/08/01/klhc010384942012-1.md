JUDGMENT
A letter has been received from the District Judge,
Thalassery stating that the judgment in A.S.No.183/2007 which
has been challenged in this regular second appeal, has already
been recalled owing to the fact that the judgment was passed
against a dead person. A request is made for return of the
documents for hearing the appeal, which has been reopened.
In the above circumstances, there is no necessity for the
second appeal since the impugned judgment is no longer there.
The second appeal is hence closed and the Registry is directed
to return files, which have been already received.
