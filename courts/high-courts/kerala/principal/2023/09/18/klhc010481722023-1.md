 O R D E R
This transfer petition is filed to file transfer MC No.
20/2023 on the file of the Family Court, Thalassery to Family
Court, Alappuzha. Admittedly, the above case is set ex-parte. If
that is the case, this transfer petition is not maintainable at
this stage. It is submitted that the petition is filed to set aside
the ex-parte order. If the ex-parte order is set aside, the
petitioner is free to file a fresh transfer petition.
Granting liberty to the petitioner to file a fresh transfer
petition, this transfer petition is closed.
