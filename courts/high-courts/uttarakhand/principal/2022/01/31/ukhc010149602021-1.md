# High Court of Uttarakhand, C482/1723/2021, 2022-01-31

C-482 No. 1723 of 2021
Hon’ble Alok Kumar Verma, J.
Heard Mr. Anoop Jaiswal, learned
counsel for the applicant and Mr. Lalit
Miglani, A.G.A. for the State through
video conferencing.
Mr. Anoop Jaiswal, learned
counsel for the applicant submitted that
there are some formal defects in the
application, filed under Section 482 of
the Code of Criminal Procedure, 1973
and requested to permit the applicant
to withdraw this application with liberty
to file afresh.
Learned counsel for the State has
no objection.
This application, filed under
Section 482 of the Code of Criminal
Procedure, 1973 is dismissed as
withdrawn with liberty to file afresh, in
accordance with law.
 (Alok Kumar Verma, J.)
 (Vacation Judge)
