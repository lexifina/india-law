Criminal Original Petition filed under Section 482 of the Code of

For Respondent : Mr.M.Maharaja
 Additional Public Prosecutor
ORDER
This petition is filed praying for a direction to the respondent
police to investigate the case and to file a final report in Crime
No.109 of 2014 on the file of respondent within stipulated period as
granted by this Hon'ble Court.
2.Heard the learned counsel appearing for the petitioner and the
learned Additional Public Prosecutor.
3.Considering the facts and circumstances of this case, this
Court deems it appropriate to direct the respondent police to file
final report in connection with the case in Crime No.109 of 2014, on
or before 31.07.2014.
https://hcservices.ecourts.gov.in/hcservices/

4.With the above observation, this criminal original petition is
disposed of.
