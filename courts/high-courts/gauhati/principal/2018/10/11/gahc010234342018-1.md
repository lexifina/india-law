Date : 11.10.2018
Heard the learned counsel for the petitioner.
By this application, the petitioner has prayed correction of the session case number in
the order dated 28.09.2018, passed in I.A.(Crl.) 244/2018.
The case number mentioned in the aforesaid order as 23/2007, which should be
Sessions Case No. 23/2017.
Having regard to the submission so made and after clarification of the record
pertaining to the main case being Crl. App. No. 84/2018, the prayer is allowed.

Page No.# 2/2
Accordingly, the case number mentioned in I.A.(Crl.) 244/2018 as Sessions Case No.
23/2007 now be read as Sessions Case No. 23/2017 for all purpose.
Let a copy of this order be kept as a part of the said record.
With the aforesaid observation, this I.A. stands disposed of.
 JUDGE
