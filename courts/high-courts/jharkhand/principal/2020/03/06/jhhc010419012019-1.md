6/06.03.2020 Heard the parties.
 In this application, the petitioner has challenged the order dated
30.09.2019, by which final form has been accepted by the court below and
the petitioner-informant has been directed to file protest-cum-complaint
petition if there is any grievance.
 Learned counsel for the petitioner submits that protest-cum-complaint petition has already been filed by the petitioner.
 Since, the relief has already been given to the petitioner by the
court below, this quashing application is misconceived. Thus, I am not
inclined to entertain the same. Accordingly, the same is hereby dismissed.

 (Ananda Sen, J)
