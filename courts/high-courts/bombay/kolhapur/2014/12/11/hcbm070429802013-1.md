2. This is an application challenging issuance of process.  The order
in question can be challenged before the Sessions Court under Section 397 of
the Cr.P.C.   This Application was entertained in October 2013 because the
Advocates were on strike in Kolhapur Sessions Court.  That issue is now over.
3. The   learned   Senior   Advocate   for   the   applicant   is   allowed   to
withdraw the Application with liberty to file Revision Application before the
