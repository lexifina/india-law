# High Court of Orissa, RVWPET/226/2019, 2019-11-19

03. 19.11.2019 Learned counsel for the petitioners-Department
seeks permission to withdraw this writ petition.
 However, we see that this petition is not filed with
bona fide.
 However, since learned counsel for the petitioners-Department requests for not to pass any order imposing
costs, we are not passing any order imposing costs and we
dispose of this RVWPET as withdrawn.
 Misc. Case(s)/I.A.(s) connected to this petition, if
any, is/are disposed of.
