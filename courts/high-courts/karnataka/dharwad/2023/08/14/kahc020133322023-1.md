ORDER
 The captioned writ petition is filed by the defendant
feeling aggrieved by the order passed by the learned
Judge on I.A.No.II filed under Section 151 of Code of Civil
Procedure, wherein application filed by defendant seeking
permission to file written statement in a partition suit, is
rejected.
 2. The respondent/plaintiff has instituted a suit for
partition and separate possession in O.S.No.37/2022, on
the file of Civil Judge and JMFC, Kundagol. The present
petitioner failed to contest the proceedings and he was
placed exparte. An application was filed by petitioner to
recall the exparte order by filing an application under
Order IX rule 7 of Code of Civil Procedure. The said
application was allowed and petitioner was permitted to
contest the proceedings. After recalling of an exparte
order, though petitioner was afforded several
opportunities, he did not choose to file written statement.

Learned Judge has rejected the application on the ground
that matter is posted for judgment.
 3. Heard learned counsel for the petitioner and
perused the order under challenge.
 4. Learned counsel for the petitioner would submit
before this Court that since the petitioner/defendant was
hoping that his brother would settle the matter, he did not
choose to file written statement. She would further fairly
admit that plaintiff has legitimate share in the properties.
If the present petitioner/defendant is not seriously
disputing the plaintiff’s legitimate share, I am not inclined
to interfere with the order passed by the learned Judge.
This application is filed when the matter is posted for
judgment.
 5. The materials on record clearly demonstrate
that the application filed by defendant in I.A.No.II totally
lacks bona-fides and the same is tainted with mala-fides.
