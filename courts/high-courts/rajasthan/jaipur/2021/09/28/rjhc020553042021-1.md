Order
28/09/2021
Heard on the application for correction in the order dated
17.08.2021.
Counsel for the petitioner submits that the petitioner has
withdrawn the writ petition on 17.08.2021 with liberty to file fresh,
if need so arises, however, in the order dated 17.08.2021 the
liberty to file fresh writ petition was not mentioned.

(2 of 2) [WMAP-144/2021]
In that view of the matter, the application is allowed. The last
part of the order dated 17.08.2021 be read as under:-
“The writ petition is dismissed as
withdrawn with liberty to file fresh writ petition,
if need so arises.”
This order be treated as part of the order dated 17.08.2021.
(INDERJEET SINGH),J
