ORAL ORDER
(16.08.2012)
The following order of the Court was passed by
Abhay Manohar Sapre, J.
Heard.
2. This application has been filed under Order 44 Rule 1 of
Code of Civil Procedure (hereinafter for short 'the Code),
challenging judgment and decree dated 02.01.2009 passed in
Civil Suit No. 1 B/2008, whereby, the appellants' (applicants)
suit was dismissed.
3. " Admittedly, this application has been filed by a lawyer
(Mr. S.P. Kale) and not by the applicants in person, whereas
Order 44 Rule 1 read with Order 33 Rule 3 of the Code
mandates that it is necessary for the applicant himself/herself
to make its presentation in person. The presentation in this
case itself is invalid as being not done in confomiity with the

requirements of Order 44 Rule 1 read with Order 33 Rule 3 of
the C.P.C., and, fherefore, such presentation being invalid, the
application cannot be entertained for its hearing on merits, and
has to be dismissedas being not maintainable per se.
4. We find that this application is pending since 2010 and
no application for either amendment or re-presentation has
been filed within the time and therefore, it is not possible for
thisCourt to entertain this application except to dismiss it.
5. For the foregoing discussion, the application filed by the
applicants fails and is hereby dismissed as not maintainable.
6. No cost.
