Thereafter, the same respondent No.2 has filed application (M.Cr.C.
No.13071/2021) for correction of crime number in order dated 27.02.2021
passed in M.Cr.C. No.6308/2021. The same Co-ordinate Bench vide
order dated 14.07.2021 has held that it is not simply a typographical error
o f mentioning different crime number. Therefore, it is not a fit case, in
which, the crime number be modified. After considering all the facts and
circumstances of the case, the application for modification was dismissed
and it is also directed that a separate order sheet be opened to the
applicant for cancellation of order dated 27.02.2021 passed in M.Cr.C.
No.6308/2021.
Thereafter, same respondent No.2 again filed a fresh application
(M.Cr.C. No.39683/2021) for correction of crime number in order dated
27.02.2021 passed in M.Cr.C. No.6308/2021. The same was allowed vide
order dated 22.12.2021 and it was directed that in the order dated
27.02.2021 passed in M.Cr.C. No.6308/2021, the crime number be read as
"119/2018" in place of "119/2021".
It is important to note that material facts have again been suppressed
by the applicant before this Court in M.Cr.C. No.39683/2021. He has not
intimated that earlier on 14.07.2021, the same prayer was dismissed by the
Co-ordinate Bench of this Court by detailed order dated 14.07.2021
