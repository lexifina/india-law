 Order
20/10/2023
1. Instant petition has been filed against the impugned order
dated 29.09.2019 by which the petitioner has been transferred.
2. Vide order dated 16.12.2019 the effect and operation of the
transfer order 29.09.2019, qua the petitioner has been stayed.
3. Since the interim order is still in currency and sufficient time
has been passed thereafter, the transfer order dated 29.09.2019
stands quashed and set aside, qua the petitioner.
4. The petition stands allowed. However, the respondents would
be at liberty to pass fresh order, if administrative exigency, so
arises.
