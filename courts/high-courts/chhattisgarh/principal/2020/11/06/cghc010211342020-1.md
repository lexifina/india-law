Heard.
1. This is repeat bail application. Earlier bail application was withdrawn with
liberty to revive in case trial does not proceed early. This application has been
repeated too frequently.
2. As the trial is likely to commence very soon, at this stage, this bail application
is rejected. If there is no progress in trial and the applicant completes one year
of pre-trial detention, it would be open for the applicant to revive the bail
application.
