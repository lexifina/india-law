# High Court of Orissa, OJC/10533/2000, 2019-01-03

06. 03.01.2019 Learned counsel for the petitioner seeks permission to
withdraw the writ petition with liberty to file fresh application
within thirty days if any cause of action survives.
 Permission is granted.
 Accordingly, the writ petition stands dismissed as
withdrawn with liberty to the petitioner to file afresh within thirty
days if any cause of action survives.
