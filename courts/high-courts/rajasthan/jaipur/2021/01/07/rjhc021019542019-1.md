Learned counsel for the petitioner submits that he has
instructions to withdraw the writ petition with liberty to file afresh,
if need so arises. In the view of this Court, if a writ petition is
withdrawn, it can only be filed if fresh cause of action arises.
Granting liberty aforesaid, the writ petition is dismissed as
withdrawn.
