Learned counsel for the petitioner submits that by an
inadvertent mistake, name of Peera Ram has been mentioned as
petitioner No.2 in the cause title whereas Peera Ram has already
been enlarged on bail by the trial court.
Hence, the present bail application qua Peera Ram is
dismissed as infructuous.
The present bail application survives only for petitioner No.1
Mukesh Kumar.

(2 of 2) [CRLMB-3138/2020]
Learned counsel for the petitioner submits that he does not
want to press the present bail application at this stage with liberty
to file fresh bail application after filing of the charge-sheet.
Accordingly, the bail application is dismissed as not pressed
with liberty as prayed for.
