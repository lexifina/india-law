# Madras High Court, A/2120/2019, 2020-03-23

A.No.2120 of 2019
N.SATHISH KUMAR, J.
This application is filed by the applicant, seeking a direction to the
respondents to furnish security to the tune of Rs.5,94,253/- failing which to
order attachment of the immovable properties morefully described in the Judges
Summons.
2. This Court, by an order dated 20.03.2019, directed the respondents to
furnish security for the claim on or before 20.04.2019 and on failing to furnish
security, there shall be Order of attachment.
3. Despite the order of this Court directing to furnish security, the
respondents have not furnished any security and none appeared for the
respondents.
4. In view of the above, there shall be an order of attachment of the
immovable property described in the schedule and this application is closed.
The Registry is directed to communicate this order to the Registrar Office
concerned.
