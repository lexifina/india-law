HON'BLE MR. JUSTICE INDERJEET SINGH
Order
24/02/2020
On 08.02.2020, this court passed the following order:-
“Counsel for the petitioner wants to
withdraw this writ petition with liberty to
file fresh, if need so arises.
In that view of the matter, this writ
petition is dismissed with liberty, as prayed
for.”

(2 of 2) [WMAP-34/2020]
Counsel for the petitioner submitted that the petitioner has
simply withdraw the writ petition and he does not want to file
fresh writ petition.
In that view of the matter, the order dated 08.02.2020 is
corrected as under:-
“Counsel for the petitioner wants to
withdraw this writ petition.
In that view of the matter, the writ
petition is dismissed, as prayed for.”
The application is accordingly disposed of. It may be treated
to be part of the order dated 08.02.2020.
