This is an application for condonation of delay of 42
days in seeking leave to file appeal against dismissal of
complaint. Respondent is duly served, but has not cared to
appear. It is, therefore, presumed that respondent has no
objection to make the application. Application is allowed. Delay is
condoned. List the application for leave to file appeal on
11.7.2012.
