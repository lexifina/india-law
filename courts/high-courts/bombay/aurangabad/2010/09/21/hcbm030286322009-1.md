 Heard.
It is not in dispute that the contempt
petition is already dismissed. This application
is filed for condonation of delay caused in filing
civil application for restoration of contempt
petition. When counsel appearing for the
applicant confronted with the query that which
provision is available for the applicant to file
review application, he fairly states that there is
no provision as such.
In this view of the matter, application for
condonation of delay as well as civil application
for review stand rejected.

(S. S. SHINDE. J.)
