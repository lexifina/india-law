ORDER
This Criminal Miscellaneous Case is filed challenging the
order dated 06.09.2016 in Crl.M.P.No.2152/2016 by which an
application to delete the condition in a Bail order is rejected.
2. This Criminal Miscellaneous Case is pending before this
Court from 2016 onwards. Probably, the case is itself might have
been disposed of. There is no representation also for the
petitioner.
3. I am of the considered opinion that this Criminal
Miscellaneous Case need not be retained here.
With the above observation, this Criminal Miscellaneous
Case is closed.
