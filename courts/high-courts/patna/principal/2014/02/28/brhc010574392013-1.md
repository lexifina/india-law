ORAL ORDER
2 28-02-2014 After some arguments, learned counsel for the
petitioner seeks permission to withdraw this application in order to
satisfy the Authority that he was entitled to get Matric Trained
Pay-Scale.
This application is, accordingly, permitted to be
withdrawn with the aforementioned liberty.
It is, however, made clear that the petitioner can move
this Court again only if he can demonstrate that he had actually
passed the Teachers Training Examination so as to get the benefit
of Matric Trained Pay-Scale.
