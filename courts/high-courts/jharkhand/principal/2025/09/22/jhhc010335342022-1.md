 10/ 22.09.2025: Heard, learned counsel for the parties.
2. This writ petition has been filed without any Annexures. Annexures
to a writ petition is an evidence in support of the pleadings. If there is any
pleading on fact the same has to be supported by an evidence i.e. the
document. Now the petitioner has filed supplementary affidavit bringing
on record the Annexures. The statement made in the supplementary
affidavit cannot be said to be pleadings in the main case. He has also not
sought for any amendment of the pleadings.
3. Since there is no pleading in the main case in support of the
Annexures (evidence), the Annexures cannot be taken note of as without a
pleading an evidence cannot be accepted.
4. Further, no relief was sought for to file any supplementary affidavit
bring on record the aforesaid material. By filing a supplementary affidavit,
neither the pleadings can be added or amended nor the evidence can be
brought on record. It is only by way of amendment application the same can
be done. Thus, the supplementary affidavit is rejected.
5. Consequently, since there is no evidence is support of the pleadings,
this writ petition is dismissed, with a liberty to the petitioner to file a fresh
and proper writ petition on the same cause of action.
