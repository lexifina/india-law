1. This application under section 482 of the Code of Criminal
Procedure has been filed by the petitioners, challenging the order
dated 19.07.2023 passed by the learned J.M.F.C., Basta in 1.C.C.
Case No. 417 of 2014.
2. Mr. D. Sahoo, learned counsel for the petitioners submits
that the petitioners want to withdraw this application in order to
file a fresh application with better particulars.
3. Considering the submission of the learned counsel for the
petitioners, the CRLMC is disposed of as withdrawn granting the
liberty prayed for.
4. The Registry is directed to return the certified copy of the
order dated 19.07.2023 (Annexure-1) to the learned counsel for
the petitioners on it being substituted by an attested photostat
copy.
