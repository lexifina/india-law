Per D.N.Patel,J.
1. Having heard counsel for both sides and looking to the facts and
circumstances of the case, it appears that name of some candidates does
not figure in the list of Above Poverty Line category candidates prepared
by the State Government. This is the main grievance as per counsel for
the petitioner.
2. It has been assured by counsel appearing for the respondents that if
there is any error on the part of the said authorities, the same will be
rectified after following the necessary procedure.
3. Taking into consideration the submission made by the learned
counsel for both sides and the main allegation levelled by this petitioner
that names of the 162 candidates does not figure in the list of Above
Poverty Line candidates and names of 55 candidates have not found
place in the list of Below Poverty Line candidates, it appears that this
petition does not involve any matter of public interest at all
3. In this situation, suffice it will be to give a direction to the State that if
the concerned candidates approach the concerned respondent authorities,
after proper verification, if there is any need to alter or amend the list of
Above Poverty Line candidates or the list of Below Poverty Line
candidates, the same will be amended or altered.

-2-
4. Error similar to the one in hand is a very common occurrence when
Government works on matters involving large volume of data with respect
to a large population base and for this no public interest litigation is tenable
at law.
5. In view of the above direction, this public interest litigation is, hereby,
dismissed.
 (D.N.Patel, J.)
 (Pramath Patnaik, J.)
