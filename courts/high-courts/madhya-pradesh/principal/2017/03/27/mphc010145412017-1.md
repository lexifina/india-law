# High Court of Madhya Pradesh, MCC/843/2017, 2017-03-27

MCC-843-2017
(CHITRALEKHA NETAM Vs THE STATE OF MADHYA PRADESH)
27-03-2017
Shri P.K. Sharma, learned counsel for the applicant.
Smt. D.K. Bohre, learned Government Advocate for the
respondents.
This is an application for restoration of W.P. No. 110/2013
which has been dismissed for want of prosecution by order dated
22.02.2017.
It is stated that the with the personal difficulty the counsel
could not attend the hearing of the said case. This fact is
supported by an affidavit.
Considering the aforesaid averments, the application is
allowed. W.P. No. 110/2013 is restored to its original number.
A copy of this order be attached with the main file of
W.P.No. 110/2013.
(VIJAY KUMAR SHUKLA)
JUDGE
