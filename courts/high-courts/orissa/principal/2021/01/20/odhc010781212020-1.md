# High Court of Orissa, WP(C)/36852/2020, 2021-01-20

ORDER
 03. 20.01.2021 In the wake of the pandemic Covid-19, the
case is taken up through V.C.
 Heard.
 Learned counsel for the petitioner wants to
withdraw this writ petition with a liberty to file a
better application.
 Accordingly, this writ petition stands
disposed of as withdraw. Liberty is given to the
petitioner to file a better application, if he so
desired.
 The parties may utilize the copy of this
order as per the High Court’s Notice No.4587 dated
25.03.2020.
