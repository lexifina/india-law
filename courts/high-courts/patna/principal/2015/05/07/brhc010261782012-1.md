CORAM: HONOURABLE MR. JUSTICE SHIVAJI PANDEY
ORAL ORDER
2 07-05-2015 Heard learned counsel for the petitioner and learned
counsel for the State.
This application has been filed for quashing the order
dated 22.11.2012 passed by the A.D.J. II, Hilsa by which
application of the petitioner under Section 228 of the Code
of Criminal Procedure has been rejected.
From the impugned order it appears that the victim
was assaulted by the cricket bat on the vital part of the body.
In such view of the matter, this Court is not inclined
to interfere with the impugned order.
Accordingly this application is dismissed.
Vinay/-
(Shivaji Pandey, J)
