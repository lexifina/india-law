ORAL ORDER
2. 12-12-2014 The present petition has been filed for initiating
contempt proceeding on allegation of wilful disobedience to an
interim order passed in C.W.J.C. No. 7456 of 2013.
It was admitted by learned counsel for the petitioner
that main writ petition is still pending.
Keeping in view the fact that main writ petition is still
pending, I do not find any ground for passing any positive order in
the petition.

Patna High Court MJC No.3734 of 2014 (2) dt.12-12-2014
2/2
The petition stands dismissed.
The petitioner, if so advised, may file
petition/affidavit in the main writ petition.
Anay/-
