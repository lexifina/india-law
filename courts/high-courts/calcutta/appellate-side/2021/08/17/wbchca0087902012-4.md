The petitioners approached this Court challenging the First
Information Report which was filed in connection with Kolaghat
Police Station Case No.327 dated 29.11.2011.
Earlier the report was called for.
Mr. Imran Ali, learned advocate appearing for the State
submits a report which has been forwarded by the Officer-in-Charge, Kolaghat Police Station.
Report reflects that there has been change of circumstances
which has rendered the revisional application infructuous.

Let the report be kept with the record.
In view of the aforesaid, C.R.R.551 of 2012 is dismissed.
Pending application, if any, is consequently disposed of.
Interim order, if any, is hereby vacated.
All parties shall act in terms of copy of this order downloaded
from the official website of this Court.
 (Tirthankar Ghosh, J.)
