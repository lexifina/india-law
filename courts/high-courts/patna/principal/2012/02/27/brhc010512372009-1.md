ORAL ORDER
3 27-02-2012 After some argument Mr. Chakrapani, learned
counsel for the petitioner, seeks permission to withdraw this
application in order to enable the petitioner to highlight the plea of
discrimination in the matter of giving him a Class IV post though
similarly situated persons according to him have been given Class
III post.
This application is, accordingly, permitted to be
withdrawn with the aforementioned liberty and an observation that
if such a representation is filed the authorities will dispose it of
expeditiously.
surendra/-
