ORDER
The writ petition is filed challenging the impugned refusal check slip
dated 20.02.2026.
In view of section 34C of the Act, since the original parent document
is not available, the same is refused. So long as the statutory requirement is
there no exception that can be taken with reference to these refusal check
slip. However, even as per the provision, if the parent document is not
available, non traceable certificate has to be produced by the person if the
document is not traceable.
3.Let the petitioner approach the jurisdictional police and lodge a
complaint. The jurisdictional police by following the directions given in the
circulars in that regard shall make an endeavor and if the document is not
traceable, the non traceable certificate shall be given. As and when the
petitioner approaches, the same shall be done by the jurisdictional police as
expeditiously as possible thereafter by getting the non-traceable certificate,
it will be open for the petitioner to re-present the document. Upon which, if
