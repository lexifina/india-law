# High Court for the State of Telangana, WP/34382/2014, 2019-02-08

THE HONOURABLE SRI JUSTICE SANJAY KUMAR
WRIT PETITION NO.34382 OF 2014
O R D E R
Sri M.Chalapathi, learned counsel for the petitioner, seeks leave to
withdraw this writ petition reserving liberty to the petitioner to file a Public
Interest Litigation, if so advised.
Leave granted.
The writ petition is dismissed as withdrawn with the liberty
aforestated. Pending miscellaneous petitions, if any, shall also stand
dismissed. No order as to costs.
