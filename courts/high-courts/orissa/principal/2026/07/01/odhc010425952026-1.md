ORDER
01.07.2026
Order No. 02
1. This matter is taken up through hybrid mode.
2. Heard learned counsel appearing for the Parties.
3. Since it is fairly contended that against the impugned order,
Petitioner has already moved the State Cooperative Tribunal in filing
Revision Petition in TRN No. 12/2026, this Court is not inclined to
entertain the writ petition with the prayer as made.
4. However, it is open for the Petitioner to file an I.A., if any
subsequent order has been passed subsequent to filing of the revision
before the Tribunal.
5. The writ petition accordingly stands disposed of.
 (BIRAJA PRASANNA SATAPATHY)
