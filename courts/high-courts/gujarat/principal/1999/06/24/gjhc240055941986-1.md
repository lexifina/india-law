ORAL JUDGEMENT
 In this case, the petitioner is appearing in-person.
 From the remarks in the Board it turns out that
 intimation which has been sent to him, has returned back
 with the postal authorities' endorsement `left'. If any
 fresh notice is given of the date of hearing to be fixed
 in this case, it will meet with the same fate and it will
 be only an attempt in futility. The Special Civil
 Application is dismissed for non-prosecution. Rule
 discharged. Interim relief, if any, granted by this
 Court stands vacated. No order as to costs.
