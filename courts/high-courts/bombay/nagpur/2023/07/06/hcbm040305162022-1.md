 CORAM : URMILA JOSHI-PHALKE, J.
DATED : 06/07/2023
1. The application is for grant of bail under
Section 439 of the Code of Criminal Procedure in
connection with Crime No.194/2022, registered with
Police Station, Mana, District Akola, for the offence
punishable under Sections 302 and 504 of the Indian
Penal Code.
2. After hearing the learned Counsel for the
applicant to some extent, this Court has shown
disinclination to grant bail. The learned Counsel for the
applicant seeks permission to withdraw the application
with liberty to file afresh, if there is no progress in the
trial within six months.
3. Considering the statement made by the
learned Counsel, if there is no progress in the trial within
eight months, liberty is granted to the applicant to move
afresh application before this Court.

(2) 41.ba.1435.2022
4. The application is disposed of, as withdrawn.
