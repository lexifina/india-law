1. Admittedly, the order which is challenged in this writ petition is
appealable and this fact has already been admitted by the learned
counsel for the petitioner.
2. Considering the fact that the order is appealable, I direct the
petitioner to file an appeal before the Appellate Authority taking all
the points available to the petitioner.
3. Once an appeal is filed, it is expected that the same should be
decided on merits dealing with the points raised by the petitioner.
4. Accordingly, this writ petition stands disposed of.
