Page No.# 3/3
As per the Data Collection Format, the DISE Code issued in favour of the Chenibari B.A.
Girls’ M.E.M. is 0307312, which is reflected from the annexure-F, page-25 of the writ petition.
As per the list of recognized M.E./M.E.S. for the year 2009-10, the Chenibari B.A. Girls’ M.E.M.
is shown to have been provided the DISE Code No. 037312, but in the format for report of
the District Scrutiny Committee of Darrang district the DISE Code of 2009-10 in respect of
Chenibari Bher Bheri Anchalik Girls’ M.E.M., Madrassa is shown as 18080305105. Even if the
figure 1808 is understood to be district code, still the subsequent figure 305105 is at a
variance with the DISE Code 0307312, which was issued to the petitioner’s School. Because
of such mistake in the DISE Code further process of provincialisation of the teaching and non-teaching staff of the Chenibari B.A. Girls’ M.E.M. has not been carried forward.
In the circumstances, the Director of Elementary Education Department, Assam to find
out from the record as to what is the correct DISE Code issued to the Chenibari B.A. Girls’
M.E.M. and if the DISE Code issued is a valid code under the law, the further process for
provincialisation be undertaken by correcting the DISE Code issued to the school concerned.
If the Director is of the view that the DISE Code recorded in the format of the District
Scrutiny committee is the correct code, appropriate order be passed and the petitioner be
communicated about the same.
In terms of the above, this petition stands disposed of.
