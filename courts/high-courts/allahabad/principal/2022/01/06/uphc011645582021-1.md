# Allahabad High Court, ABAIL/18099/2021, 2022-01-06

Court No. - 71
Case :- CRIMINAL MISC ANTICIPATORY BAIL
APPLICATION U/S 438 CR.P.C. No. - 18099 of 2021
Applicant :- Mohammad Shoyab Khan
Opposite Party :- State of U.P.
Counsel for Applicant :- Fakhruzzaman
Counsel for Opposite Party :- G.A.
Hon'ble Samit Gopal,J.
Heard Sri Samsuzzman, Advocate holding brief of Sri
Fakhruzzaman, learned counsel for the applicant and Sri
Ankit Srivastava, learned State counsel.
Learned State counsel has served a counter affidavit to
learned counsel for the applicant today in Court. He states
that he will file the same in the office within by tomorrow.
Office is directed to trace out the same and place it on
record and make a note about it in the order sheet.
Learned State counsel points out that charge sheet in the
matter has already been submitted on 13.6.2021.
After arguments at some length, learned counsel for the
applicant prays that the present application be dismissed as
withdrawn as he intends to file a better petition with all the
documents as of now.
As prayed by learned counsel for the applicant, the present
anticipatory bail application is dismissed as withdrawn.
(Samit Gopal,J.)
Order Date :- 6.1.2022
