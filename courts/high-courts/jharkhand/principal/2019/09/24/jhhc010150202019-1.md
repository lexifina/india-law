# High Court of Jharkhand, Cr.M.P./1467/2019, 2019-09-24

IN THE HIGH COURT OF JHARKHAND AT RANCHI
Cr. M.P. No. 1467 of 2019
----
Gopeshwar Singh … Petitioner
-versus-1. The State of Jharkhand
2. Ram Prasad Sen Gupta … Opposite Parties
---
CORAM : HON’BLE MR. JUSTICE ANANDA SEN
----
For the Petitioner : Mr. Asit Baran Mahata, Advocate
For the State : A.P.P.

3/ 24.09.2019 Heard learned counsel for the parties.
 Petitioner in this application has prayed for quashing the
orders dated 02.11.2017 and 12.12.2017 passed by the Sub Divisional
Judicial Magistrate, Lohardaga in complaint case being C-172 of 2016, by
which process under Sections 82 and 83 of the Code of Criminal
Procedure have been ordered to be issued against the petitioner.
 I have gone through both the orders. On perusal of order
dated 02.11.2017, by which process under Section 82 of the Code of
Criminal Procedure has been issued, it is evident that execution report of
warrant of arrest was awaiting. The Court below on that date awaiting the
execution report, has passed the order by which just to expedite the case,
O/C was directed to issue process under Section 82 of the Code of
Criminal Procedure. Similar is the order on 12.12.2017 when execution
report of 82 of the Code of Criminal Procedure was awaited, but, only to
expedite the case, process under Section 83 of the Code of Criminal
Procedure was issued.
 This is not the mandate of law. Process under Section 82 of
the Code of Criminal Procedure has to be issued if the Court has reason to
believe that person against whom warrant of arrest has been issued, is
absconding or concealing himself so that the warrant cannot be executed.
Similarly, while issuing process under Section 83 of the Code of Criminal
Procedure, the Court must record reasons as to why he is issuing process
under Section 83 of the Code of Criminal Procedure. “To expedite the
case” cannot be a ground for issuing process under Sections 82 and 83 of
the Code of Criminal Procedure. Thus, the Court below, absolutely on a
wrong legal notion, has issued both the process under Sections 82 and 83

of the Code of Criminal Procedure. Thus, the order dated 02.11.2017 and
12.12.2017 are, hereby, quashed and set aside.
 As a consequence to quashing of the orders dated 02.11.2017
and 12.12.2017, the order dated 07.02.2018 passed by the Sub Divisional
Judicial Magistrate, Lohardaga, by which the petitioner has been declared
as permanent absconder, is also, hereby, quashed.
 This application, thus, stands allowed.
 The Court below is at liberty to proceed further in accordance
with law.
 Let a copy of this order be communicated through FAX to the
Court concerned at the cost to be deposited by the petitioner.
