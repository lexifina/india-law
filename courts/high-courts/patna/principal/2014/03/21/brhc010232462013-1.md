ORAL ORDER
2 21-03-2014 This application was filed by the petitioners
apprehending arrest in Hathauri Police Station Case No 125 of
2011 registered under Sections 302/34 of Indian Penal Code
(IPC).
Learned counsel for the petitioners submits that police
had filed final report. Differing from that, the learned Chief
Judicial Magistrate, Muzaffarpur took cognizance of an offence
under Sections 302/34 of IPC but the same has been set aside by
this Court and the matter has been remanded. As such, there is no
apprehension for the time being. It is further submitted that the
only allegation is that various children had gone to take a bath in
the river. The informant’s grandson drowned which is being

been set aside, learned counsel for the petitioners does not press
