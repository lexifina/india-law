# Allahabad High Court, A482/3470/2021, 2021-02-22

Court No. - 69
Case :- APPLICATION U/S 482 No. - 3470 of 2021
Applicant :- Virendra Kumar Rai
Opposite Party :- State Of U.P. And 2 Others
Counsel for Applicant :- Om Prakash Tripathi,Amrendra
Nath Singh (Senior Adv.)
Counsel for Opposite Party :- G.A.
Hon'ble Neeraj Tiwari,J.
Heard learned counsel for the applicant and Sri Sanjay
Sharma, learned A.G.A. for the State
At the very outset, learned A.G.A. has raised preliminary
objection and submitted that this application is not
maintainable as against the order impugned, applicant has
alternative remedy to file revision under 397/401 Cr.P.C.,
which was not disputed by learned counsel for the
applicant.
Accordingly, the application is dismissed as withdrawn
with liberty to approach the revisional Court, if so advised.
Office is directed to return the certified copy of impugned
order after keeping the photocopy of the same on record.
Order Date :- 22.2.2021
