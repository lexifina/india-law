# High Court for the State of Telangana, WP/2040/2012, 2012-08-13

THE HON’BLE SRI JUSTICE K.C.BHANU
WRIT PETITION No.2040 OF 2012
ORDER:
Learned counsel for the petitioner seeks permission to
withdraw the Writ Petition with liberty to the petitioner to file a Review
Petition before the competent authority.
Permission is accorded.
Accordingly, the Writ Petition is dismissed as withdrawn with
liberty to the petitioner to file a Review Petition before the competent
authority. There shall be no order as to costs.
Miscellaneous Petitions, if any, pending in this Writ Petition shall
stand closed.
