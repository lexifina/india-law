# Madras High Court, A/4996/2019, 2021-04-16

1
Application No.4996 of 2019
N.SATHISH KUMAR,J. ,
 This application has been filed
for an interim Order for appointment of
a receiver to seize the vehicle mentioned
in the Judges summons.
2. It is submitted by the learned
counsel appearing for the applicant that
award has already been passed in this
matter.
3. In such view of the matter, this
Court is not inclined to pass any order
in this application and the applicant has
to work out the remedy to execute the
award. Accordingly, this application
is closed.
