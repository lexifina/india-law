Hon'ble Shri Justice Sanjay K. Agrawal
Order On Board
 07/11/17
Heard.
2. By the impugned order dated 03.10.2017, the trial Court has rejected
the application filed by the petitioners / plaintiffs under Order 23 Rule 3 of the
CPC only on the ground that the suit property is the government land and,
therefore, the State has to be heard.
3. Learned counsel appearing on behalf of the petitioners would submit
that the impugned order is unsustainable and bad in law and is liable to be
set aside.
4. I have heard learned counsel for the petitioners.
5. The trial Court ought to have heard the State as the State is already a
party defendant in the suit and thereafter could have decided the petitioner's
application under Order 23 Rule 3 of the CPC. Accordingly, the impugned
order is set aside and the application is restored and the Civil Judge Class-I,
Dhamtari is directed to hear the petitioners' application under Order 23 Rule
3 afresh after hearing the parties including State of Chhattisgarh.
6. Accordingly, the writ petition is allowed to the extent indicated herein
above. No order as to cost(s).
