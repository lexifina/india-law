# Allahabad High Court, WRIC/35342/2019, 2019-11-05

Court No. - 34
Case :- WRIT - C No. - 35342 of 2019
Petitioner :- Bhagelu Triveni Goswami
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Jyoti Giri,Rang Raj Giri
Counsel for Respondent :- C.S.C.
Hon'ble Sudhir Agarwal,J.
Hon'ble Rajeev Misra,J.
1. Heard Ms. Jyoti Giri learned counsel for petitioner and
learned Standing Counsel for State.
2. Grievance of petitioner is that he has made an application
dated 18.06.2019 before respondent no.3, Station House
Officer, P.S. Machhali Shahar, District-Jaunpur for registration
of Missing Person Report but the same has not been registered.
3. If that be so, remedy lies to petitioner to file Criminal Misc.
Writ Petition.
4. It is accordingly dismissed with liberty to petitioner to filer
fresh Criminal Misc. Writ Petition.
Order Date :- 5.11.2019
