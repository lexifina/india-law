ALKA SARIN, J. (Oral)
1. Limited prayer in the present petition is that the application for
Police help be decided in a time-bound manner.
2. Learned counsel for the petitioner would contend that a status
quo order was issued in favour of the petitioner herein on 16.11.2023.
However, despite the status quo order the respondents have been carrying
out construction on the premises and an application under Order XXXIX
Rule 2-A of the Code of Civil Procedure, 1908 was filed in which notice has
been issued. Thereafter, an application for Police help was filed for
implementation of order dated 16.11.2023, however, the same has been
adjourned on two separate dates for awaiting the report of the SHO as well
as for the reply. Learned counsel for the petitioner would further contend
that in the interregnum the construction has been carried out in full speed by
the respondents.
