Dated this the 6th day of July, 2018
J U D G M E N T
When the petition came up for hearing, learned counsel
for the petitioner submitted before this Court that this original
petition is filed to set aside Ext.P8. I perused Ext.P8,which reads
as follows:-
“No objection filed so far. Depute Amin for executing the
order. For report 24.3.2018.”
2. After hearing the counsel for the respondents, who
submitted before this Court that it is evident that so far no
objection is filed. It appears that only on subsequent date, it was
filed. Thus, the impugned order hereby is set aside and if any
objection is filed subsequently, but before pronouncing this
order, that shall be considered and appropriate orders in
accordance with law shall be passed.
This Original Petition is disposed of as above.
