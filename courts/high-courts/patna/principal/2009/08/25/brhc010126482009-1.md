# Patna High Court, CR. WJC/234/2009, 2009-08-25

IN THE HIGH COURT OF JUDICATURE AT PATNA
CR. WJC No.234 of 2009
SUGANTI DEVI
Versus
STATE OF BIHAR & ORS
-----------
4. 25.08.2009 Learned counsel for the petitioner seeks permission
to withdraw this application saying that he will file another
application after ascertaining the exact case number and the
sessions trial number with respect of which prayer for
expeditious trial and conclusion thereof is prayed.
He is permitted to withdraw the application with
liberty to file again when he gets the correct P.S.Case number
and Sessions Trial Number.
This application is, accordingly, disposed of.
 Jay/ ( C.M.Prasad,J )
