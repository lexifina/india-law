Judgment / Order

1. Application has been moved for modification of the order
dated 23.10.2017.
2. It is contended that in the order dated 23.10.2017 in line
two of para No.3 name of co-accused, Prince has been mentioned,
whereas, it should be Pawan.
3. Considering the contentions application is allowed. In order
dated 23.10.2017 in line two of para No.3, “Prince’’ be read as
“Pawan”.
4. Application is, accordingly, allowed.
