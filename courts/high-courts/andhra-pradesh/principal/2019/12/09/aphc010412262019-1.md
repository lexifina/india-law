# High Court of Andhra Pradesh, WP/19803/2019, 2019-12-09

THE HON’BLE SRI JUSTICE M.SATYANARAYANA MURTHY
WRIT PETITION NO.19803 OF 2019
ORDER:

 Learned counsel for the petitioners seeks permission of this
Court to withdraw the writ petition, with a liberty to file
appropriate application before the competent Court which is
dealing with Agri Gold matters.
 Permission is accorded as sought for.
 Writ petition is dismissed as withdrawn, with a liberty to file
appropriate application before the competent Court which is
dealing with Agri Gold matters. No costs.
 Registry is directed to return the original papers filed along
with this petition, so as to enable these petitioners to file
appropriate application before competent court, under due
acknowledgment within two days from today.
 Consequently, miscellaneous applications pending if any,
shall also stand dismissed.
_________________________________________
JUSTICE M. SATYANARAYANA MURTHY
