# Allahabad High Court, /691/2023, 2023-03-21

Court No. - 8
Case :- CONTEMPT APPLICATION (CIVIL) No. - 691 of 2023
Applicant :- Pramod Kumar
Opposite Party :- Shri Daddan Singh, S.H.O., Ps, Kaiserganj, Bahraich
Counsel for Applicant :- Rama Nand Yadav,Arjun Singh Yadav,Santosh
Kr. Yadav Warsi
Hon'ble Abdul Moin,J.
Heard.
The contention of learned counsel for the applicant is that this Court vide
order dated 19.09.2022 passed in an application filed under Section 482
No. 4468 of 2022 Inre; Mohammad Sharif Vs. State of U.P and Ors, a
copy of which is annexure 1 to the contempt application had allowed the
application with liberty to the complainant to file an application before the
concerned police station to lodge the report.
It is contended that despite an application having been filed by the
applicant, the report has not been lodged and hence the contempt.
The Court is of the view that once this Court itself through the order dated
19.09.2022 did not issue any specific direction to the authorities to lodge
First Information Report consequently, it cannot be said that because the
First Information Report has not been lodged as such, contempt has been
committed by the authority concerned.
Keeping in view the aforesaid, no case for contempt is made out.
Accordingly, the contempt application is rejected.
At this stage, learned counsel for the applicant argues that it is implicit in
the order passed by the Court that the First Information Report has to be
lodged.
Needless to mention that a contempt can only arise if specific direction has
been issued violated. However, in the order as passed by this Court, this
Court does not find any explicit order has been issued requiring the
authorities to lodge First Information Report and hence the said argument
is rejected.
