# High Court of Rajasthan, CW/4587/2007, 2008-02-07

1
S.B. CIVIL WRIT PETITION NO.4587/2007
(M/s. Hema Construction Vs. State of Rajasthan & Ors.)
Date of order :: 07.02.2008
HON'BLE MR. JUSTICE GOPAL KRISHAN VYAS
Mr.Chaitanya Gehlot, for the petitioner.
Mr.Rameshwar Dave, for the State.
Learned counsel for the petitioner wants
to withdraw the present writ petition with liberty
to file fresh writ petition if occasion arises.
Accordingly, the writ petition is
dismissed as withdrawn. However, the petitioner is
at liberty to file fresh writ petition if occasion
arises. It is made clear that in this case stay
has already been vacated.

(GOPAL KRISHAN VYAS), J.
