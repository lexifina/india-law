# High Court of Uttarakhand, WPSS/950/2005, 2013-07-04

WPSS No.950-2005
Hon’ble Sudhanshu Dhulia, J.
Mr. Kishore Kumar, Advocate present
for petitioner.
Mr. Subhash Upadhayay, Standing
Counsel present for the State.
A Review Application No.374/2013
has been filed by the petitioners. Perused
the review application.
The ground urged for the review of
the order dated 07.05.2013 does not satisfy
the parameters laid down under Order
XLVII Rule 1 of the Code of Civil
Procedure. Moreover, the grounds to review
an order are in any case extremely limited.
There is no good ground presently to review
the order dated 07.05.2013. The review
application is dismissed accordingly.
 (Sudhanshu Dhulia, J.)
Dated 04.07.2013
Rawat
