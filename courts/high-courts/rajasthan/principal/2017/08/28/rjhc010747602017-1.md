JUSTICE DINESH MEHTA
Order
28/08/2017
 After arguing for some time, Mr. Dron Kaushik, learned
counsel appearing for the petitioners seeks permission to withdraw
the present writ petition with the liberty to move appropriate
application under Order XIV Rule 5 of the Code of Civil Procedure
for proposing any other issues, which according to him still
requires to be framed.
Permission granted.
The writ petition is dismissed as withdrawn with the liberty
aforesaid.
If any such application is filed by the petitioners, the learned
Trial Court shall decide the same in accordance with law.
DINESH MEHTA), J.
