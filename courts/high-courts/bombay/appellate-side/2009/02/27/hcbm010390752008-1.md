 The petitioner/wife has
 challenged the impugned order dated
 12.08.2008 whereby the her interim
 application for interim maintenance
 as well as application to produce
 documents are kept pending by
 observing that both the applications
 to be decided along with the main
 petition. The fact that there is an
 interim application filed for
 maintenance and an application to
 produce documents for deciding the
 said interim maintenance application

 2
 just cannot be tagged like this along
 with main petition. It is desirable
 that such application should be
 disposed of as early as possible.
 The other side has no objection if
 these applications are disposed of
 first.
 In view of this, both these
 petitions are allowed. The impugned
 order dated 12.08.2008 in both the
 petitions are quashed and set aside.
(ANOOP V. MOHTA,J.)
