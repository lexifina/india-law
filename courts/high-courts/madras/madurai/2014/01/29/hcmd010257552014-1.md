ORDER
The first defendant is the petitioner before this Court challenging
the order of dismissal of his application to file objection to the
Advocate Commissioner's Report.
2. Heard Mr.S.C.Herold Singh, learned counsel appearing for the
petitioner.
3. After inspection, the Advocate Commissioner filed a report on
01.10.2012. Thereafter only the petitioner filed the objection
belatedly. The said petition was dismissed. Admittedly, there is a
default on the part of the petitioner to file objection in time.
Secondly, merely because there is no objection filed by the petitioner to

the Advocate Commissioner's Report, it will not prohibit the petitioner
from cross-examining the Advocate Commissioner at the time of trial, if
he is so advised. The reasoning given by the Trial Court for dismissing
the application to receive objection cannot be found fault with.
Therefore, the Civil Revision Petition fails and the same is dismissed.
No costs. Consequently, connected Miscellaneous Petition is also
dismissed.
