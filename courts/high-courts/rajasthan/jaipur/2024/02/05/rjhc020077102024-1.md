 Order
05/02/2024
Matter comes up on an application filed by the applicant for
correction in the order dated 08.08.2023 passed by this Court.
Learned counsel for the applicant submits that due to
typographical error in order dated 08.08.2023, the word ‘suit’ has
been typed instead of ‘appeal’.
For the reasons mentioned in the application, the same is
allowed. In the order dated 08.08.2023, the word ‘suit’ be read as
‘appeal’ wherever occurring in the order dated 08.08.2023.
Rest part of the order dated 08.08.2023 shall remain
unchanged and this order shall be treated as an integral part of
the order dated 08.08.2023.
(NARENDRA SINGH DHADDHA),J
