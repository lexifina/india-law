ORAL ORDER
 The petitioner, who has successfully participated in
the subject tender, has offered Security Deposit on
09.05.2024 with the fourth respondent. The petitioner
has offered the Security Deposit along with his Letter, and
the fourth respondent has returned the Instruments
endorsing the receipt of the letter stating that
Instruments are returned because the Code of Conduct
for elections is in place. The petitioner has therefore
sought directions to the fourth respondent to accept the
Security Deposit offered and issue Work Order in terms of
the Letter of Acceptance [Annexure-A].
 Sri R.Nagendra Naik, the learned counsel for the
petitioner, submits that the petitioner has offered the
Security Deposit and is even now willing to offer the
Security Deposit within a week and that this Court must
issue directions as sought for because it cannot be
disputed that even if the petitioner had to offer Security
Deposit within 20 days as stipulated in the tender
contract, it could not have been received because the

Code of Conduct of elections was notified on 16.03.2025.
This is an assertion which Sri Shamanth Naik, the
learned High Court Government Pleader, is unable to
contest even on instructions.
This Court must opine that if the petitioner was
prevented within the time to offer the Security Deposit
because of the notification of the Code of Conduct for the
scheduled elections, and the Security Deposit is not
accepted on the same ground especially with the interim
orders in the present petition, the petition must be allowed
calling upon the respondents to issue Work Order to the
petitioner provided he offers the Security Deposit within a
week from today without seeking for a certified copy of
this order. It is needless to observe that if the petitioner
defaults in offering the Security Deposit as now permitted,
the respondents will be at liberty to notify fresh tender.
 The petition is allowed accordingly.

ORAL ORDER ON 'FOR BEING SPOKEN TO'
This Court has disposed of this petition on
28.07.2025 after hearing the learned counsels for the
parties but the petition was directed to be listed today

Mr. Shamanth Naik, the learned High Court

making a mention was that the tender was pulled out
of the portal and there has to be a specific direction
by this Court to issue Work Order manually for due
compliance.
However, with the presence of certain Officers,
the learned counsel proposes to canvass reasons
which touch upon the merits and those cannot be
considered on the petition being listed on a memo.
