# Calcutta High Court, CRR/419/2012, 2021-09-06

Sr.19
 06-09-2021
 Subha.
 Court no. 34
 IN THE HIGH COURT AT CALCUTTA
 CRIMINAL REVISIONAL JURISDICTION
 APPELLATE SIDE
 ( Via Video Conference )
 CRR 419 of 2012
In the matter of : Shri Rabindra Nath Pradhan …..petitioner.
In Re : An application under Section 482 of the Code of
Criminal Procedure.

 The revisional application has been preferred in
connection with Egra P. S. Case No. 146 of 2010 under
Section 406 of the Indian Penal Code.
 The issues so canvassed are mixed question of facts
and law which cannot be adjudicated at this stage.
 Accordingly, the revisional application being CRR
419 of 2012 is dismissed.
 All pending applications, if any, are consequently
disposed of.
 Interim order, if any, is hereby vacated.
 All parties are to act on the server copy of this order
duly downloaded from the official website of this court.
 ( Tirthankar Ghosh, J. )
