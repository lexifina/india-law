I.A. No. 4520 of 2019
6/14.05.2019 By filing this interlocutory application, petitioner prays to
withdraw this writ application with a liberty to file a fresh writ application.
The ground taken by the petitioner is that there are number of defects in
this writ application and the some of them relates to illegible documents,
which cannot be cured. He submits that on the same cause of action he
wants to file a fresh writ application after procuring all the documents.
 Considering the prayer made by the petitioner, I am inclined to
allow this interlocutory application. Accordingly, this interlocutory
application is allowed.
W.P.S. No. 4702 of 2018
 In view of the order passed in the aforesaid interlocutory
application, this writ application is allowed to be withdrawn with a liberty
to file a fresh writ application.
I.A. No. 2287 of 2019
 This interlocutory application has been filed for reconstructing
the main writ application.
 In view of the order passed in the main writ application, this
interlocutory application has become infructuous. Accordingly, the same is
hereby dismissed as such.
