Heard.
Since there was error in mentioning the name
of the applicant/appellant in the appeal memo as well as
application and the same was permitted to be corrected
vide order 17.3.2011 passed upon application for said
purpose made by the applicant/appellant, the present
application will be required to be allowed for making
consequential correction. As such the application is
allowed. The name “Dinesh Dadarao Sawade” in the
order dated 15.3.2011 be now read as “Dinesh Deorao
Sawale”. The application stands disposed of.
