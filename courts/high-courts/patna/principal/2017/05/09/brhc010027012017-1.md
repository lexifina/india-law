CORAM: HONOURABLE MR. JUSTICE SHIVAJI PANDEY
ORAL JUDGMENT
Date: 09-05-2017
Heard learned counsel for the parties.
Earlier the petitioner had moved before this Court in
C.W.J.C. No. 3696 of 2011 which was disposed of with a liberty to
file an appeal within a period of four weeks before the appellate
authority but, till date, the petitioner has not filed the same and, After
five years, the present writ application has been filed for extension of
time.
This Court is not inclined to extend the time. However,
liberty is given to the petitioner to file an appeal and the appellate
authority, if so advised, will pass an order in accordance with law.
With the aforementioned observation, this application is

Patna High Court CWJC No.2195 of 2017 dt.09-05-2017 2
disposed of.
