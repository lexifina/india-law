# Bombay High Court, APPLN/132/2012, 2012-06-22

IN THE HIGH COURT OF JUDICATURE AT BOMBAY
CRIMINAL APPELLATE JURISDICTION
CRIMINAL APPLICATION NO.132 OF 2012
Prakash Nemgonda Patil .. Applicant.
 V/s.
Rafiq Ramjan Mahat and ors .. Respondents
Mr. Sandeep Koregave, for the Applicant
Mrs. U. V. Kerjariwal, APP for the Respondent – State
Mr. Akil Kupade, for Respondent No.1.
CORAM : R.C.CHAVAN, J.
DATE : 22nd June, 2012
P.C.
This is an application for condonation of delay of 7
days caused in filing application for leave to file appeal against
acquittal of the respondent for the offence punishable under
Section 138 of the Negotiable Instruments Act. Though the
learned counsel for the respondent has objection, for the reasons
mentioned in the application, application is allowed. The delay is
condoned. List the application for leave to file appeal after three
weeks.
 (R.C.CHAVAN, J.)
