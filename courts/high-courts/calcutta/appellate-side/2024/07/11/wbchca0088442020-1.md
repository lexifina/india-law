1. None appears on call on behalf of the petitioner.
2. This revisional application is pending since 2020,
and moreover running in the list for a considerable
period.
3. It appears that petitioner is not at all interested to
proceed with this revisional application further.
4. Thus, the revisional application stands dismissed
for default.
5. Connected applications, if any, stand disposed of.
6. Department is directed to communicate this order
to the learned Trial Court.
