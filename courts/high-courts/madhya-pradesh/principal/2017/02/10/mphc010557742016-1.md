# High Court of Madhya Pradesh, MCC/2857/2016, 2017-02-10

MCC-2857-2016
(RAMHIT Vs DHARMU)
10-02-2017
Shri Rajmani Singroul, learned counsel for the applicant.
Shri Abhishek Arjariya, learned counsel for the respondent.
Heard on I.A. No. 15321/2016 which is an application for
condonation of delay.
Considering the grounds mentioned in the application (I.A.
No. 15321/2016), the application is allowed. Delay in filing the MCC
is condoned.
Also heard on admission.
This MCC is filed for for restoration of S.A. No. 474/2007
which was dismissed for want of prosecution on 09.04.2015.
Learned counsel for the applicant submits that for amicable
settlement the process is going on between the parties.
In view of the aforesaid and considering the grounds
mentioned in the application which have been duly supported by
an affidavit of the counsel, the application is allowed.
S.A. No. 474/2007 is directed to be restored to its original
number.
A copy of this order be placed on the file of S.A. No.
474/2007.
(VIJAY KUMAR SHUKLA)
JUDGE
