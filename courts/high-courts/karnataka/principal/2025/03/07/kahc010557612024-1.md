ORAL ORDER
1. As against the impugned order, which is an order by
which the request of the petitioner for conversion has
been rejected, the statute provides an appeal.
2. In the light of the above, the petitioner is relegated
to the remedy of availing the remedy provided to file
an appeal.
3. Learned counsel for the petitioner however submits
that, while the Deputy Commissioner refused the
permission requested by the petitioner, he had in
fact granted permission in respect of similar lands.
4. In my view, this is a ground which can be urged by
the petitioner in the appeal and if such a ground is
urged, the Appellate Court shall take the same into

5. The petitioner is permitted to file an appeal within a

6. This petition is accordingly disposed of.
7. In view of the disposal of the petition, all pending
interlocutory applications, if any, stand disposed of.
