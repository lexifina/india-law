Mr. Ghate, Advocate for applicant.
Mr. Yengal, A.P.P. for non applicant no.1.
None for non applicant no.2.
CORAM:- R. Y. GANOO, J.
 DATED:- 12th AUGUST, 2009.
1. As the matter was called out, learned Advocate
for the applicant applied for withdrawal of this application
with liberty to file application for discharge before the
competent Court. He made grievance against non applicant
no.2 saying that the first information report filed by
Mr. Shyam Turke is totally at the instance of non applicant
no.2 and, therefore, the applicant wants to file complaint
against non applicant no. 2 to his superiors. He sought
liberty of this Court to file such a complaint.
2. I have heard learned Advocates for both the
sides. The request for withdrawal of the application as
sought can be granted but there is no need for this Court to
grant liberty to the applicant to file complaint against non

2
applicant no. 2. The applicant is free to do so if he so
desires. Hence, the order.
The application is allowed to be withdrawn with
liberty to file discharge application before appropriate
Court. No liberty is required to be granted to the applicant
to file complaint against non applicant no.2. The applicant
is free to attend the matter as he may be advised.
JUDGE
