CORAM : AVINASH G. GHAROTE, J.
DATE : 23RD FEBRUARY, 2024
Heard Mr.Tejas Deshpande, learned counsel for the
applicant. It is contended that the order dated 12/12/2023
needs to be reviewed on the ground that there is no
provision in the Civil Procedure Code for granting liberty to
file an appropriate application. If the Court notices an error
in the application, it would always be open to the Court in
it’s inherent powers under Section 151 of Civil Procedure
Code to pass appropriate orders, considering which I do not
see any ground for review being made out. The application
is therefore rejected. No costs.
