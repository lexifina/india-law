ORDER
1. Considered IA No.2985/2023, which is an application for
modification/clarification of order dated 27.04.2023 passed in W.P.
No.81/2022.
2. It is submitted that due to typographical mistake, in para No.6 line
No.2 of the order the date shown is “03.04.1990” whereas the same should be
“30.04.1990” and in para No.8 in the last line the date shown is “09.01.2021”

whereas the same should be “19.01.2021”.
3. The said mistake is apparent on the face of record hence the
application is allowed and it is directed that the date shown as “03.04.1990” in
para No.6 line No.2 and date shown as “09.01.2021” in para No.8 in the last line
of the order dated 27.04.2023 passed in W.P. No.81/2022 shall be read as
“30.04.1990” in para No.6 line No.2 of the order and “19.01.2021” in para
No.8 in the last line of the order dated 27.04.2023 passed in W.P. No.81/2022.
4. This order shall be read conjointly with the order dated 27.04.2023
passed in W.P. No.81/2022.
5. IA No.2985/2023 is accordingly disposed off.
