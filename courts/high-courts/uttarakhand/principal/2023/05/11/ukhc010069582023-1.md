3. Learned State counsel opposed this
anticipatory bail application and would
submit that this application is not
maintainable as per provisions of Section 6 of
the Code of Criminal Procedure (Uttarakhand
Amendment) Act, 2019.
4. In view of the above, learned counsel
for the applicants seeks permission to
withdraw the anticipatory bail application
with liberty to take appropriate legal remedy
at appropriate forum.
5. The request is not opposed by the
counsel for the State counsel.
6. Request is allowed.
7. Accordingly, the anticipatory bail
application is dismissed as withdrawn with
aforesaid liberty.
