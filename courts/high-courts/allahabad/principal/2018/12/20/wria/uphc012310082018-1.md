# Allahabad High Court, WRIA/25899/2018, 2018-12-20

Court No. - 58
Case :- WRIT - A No. - 25899 of 2018
Petitioner :- Vishnu Dev Tripathi
Respondent :- State Of U.P. And 7 Others
Counsel for Petitioner :- Ran Vijay Singh
Counsel for Respondent :- C.S.C.
Hon'ble Ashwani Kumar Mishra,J.
This petition has been filed for a direction upon the
respondents to release petitioner's salary
henceforth.
While entertaining the writ petition, learned
Standing Counsel was permitted to obtain
instructions. Alongwith the instructions received,
the learned Standing Counsel has produced an
order of the Director of Education, dated
2.12.2016 which also contains an office report in
which petitioner's appointment has been found to
have been made beyond sanctioned strength.
A copy of this order alongwith the note has been
handed over to the learned counsel for the
petitioner in Court.
Leaving it open for the petitioner to challenge the
order dated 2nd December, 2016, in appropriate
proceedings, this writ petition is permitted to be
withdrawn.
Order Date :- 20.12.2018
Ranjeet Sahu
