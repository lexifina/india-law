02.
This matter is taken up through hybrid mode.
2. This interlocutory application has been filed in Court today.
The same be registered.
3. This application has been filed by the State-Opposite parties
seeking four weeks time to file counter affidavit. But in
paragraph-4 of the application it has been stated that since it is
single tender, the same has been cancelled and, as such steps have
been taken for publishing of fresh tender call notice for the
aforesaid work.
4. In view of the above statement made in paragraph-4 of the
interlocutory application, the writ petition has become infructuous.
5. Accordingly, the writ petition as well as the I.A. stand
disposed of.
