 O R D E R
The counsel for the petitioner submitted that some of the
documents produced by the petitioner ought not have been
produced in the bail applications. He wants to withdraw these
bail applications along with the documents produced in these
bail applications. Therefore, these bail applications are allowed
to withdraw with liberty to file it again. The Registry will return
the documents produced by the petitioner in these bail
applications. Therefore, these bail applications are dismissed as
withdrawn with liberty to file it again.
