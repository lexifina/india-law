JUDGMENT
Since the learned Government Pleader submitted that request for
appointment of Special Public Prosecutor has already been rejected and
the same was communicated to the petitioner through post on
01.06.2020, learned Counsel for the petitioner seeks permission to
withdraw this writ petition with liberty to file a fresh writ petition.
If any orders rejecting the request for appointment of a Special
Public Prosecutor have been issued, the same gives rise to a fresh cause
of action. Therefore, permission from this Court to file a fresh writ petition
is not required.
This writ petition is dismissed as withdrawn.
