ORAL ORDER
4 02-08-2017 Heard learned counsel for the petitioners as well as
learned A.P.P.
Learned counsel for the petitioners submits that already
cognizance has been taken in his case by order dated 13.10.2014,
however, today he has filed interlocutory application challenging
the order of cognizance.
This application has been filed for quashing F.I.R. but
as per submission after filing of charge sheet cognizance has been
taken by the court, therefore, this application has become
infructuous.
So, this application is dismissed as such.
