3 20-06-2018 Learned counsel for the petitioner submits that in first
paragraph at page 2 of the order dated 03.05.2018 inadvertently
the description of the vehicle has been recorded as ‘vehicle
(Truck)’ whereas the correct description would be ‘vehicle
(Tractor)’.
In view of the above, let the order dated 03.05.2018
be read in connection with the vehicle (Tractor). The other part of
the order shall remain intact.
