ORDER
This is an application filed by the applicants seeking extension of
three months’ time to implement the judgment dated 28th October, 2013
passed in SWP No.2142/2011. The application was filed on 28.01.2014.
 Learned counsel for the applicants submits that with the afflux of
time this application has been rendered infructuous.
 Accordingly, this application is dismissed as having been rendered
infructuous.
