JUDGMENT
It is trite law that an application for delivery of property
in occupancy of the judgment debtor under Order XXI Rule 95
of the Code of Civil Procedure has to be made within one year
when the sale becomes absolute. The following decisions are
apposite to the context.
(i) Pattam Khader Khan Vs. Pattam Sardar Khan
[(1996) 5 SCC 48].
(ii) Balakrishnan Vs. Malayandi Konar [(2006) 3
SCC 49].
2. The execution sale in the instant case was
confirmed on 17.09.2008 and the execution application under
Order XXI Rule 95 of the Code of Civil Procedure was filed in
time on 15.09.2009 (within one year). But then the execution
application was returned for being accompanied by the sale
certificate issued by the court. It took some time for the court
to issue the sale certificate. The execution application under
Order XXI Rule 95 of the Code of Civil Procedure was re-

presented along with the sale certificate on 28.06.2011.
3. The petitioner/decree holder cannot be faulted with
for the delay on the part of the court below in issuing the sale
certificate. The execution application under Order XXI Rule 95
of the Code of Civil Procedure was filed within one year after the
sale was confirmed. It was re-presented with the original of the
sale certificate when the execution application was returned to
cure defects. The order of the court below directing delivery of
the property in the execution application under Order XXI Rule
95 of the Code of Civil Procedure is legal. No grounds exist to
interfere with the order directing delivery under the
circumstances.
The Original Petition fails and is dismissed.
