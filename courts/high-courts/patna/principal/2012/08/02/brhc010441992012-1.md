CORAM: HONOURABLE JUSTICE SMT. ANJANA PRAKASH
ORAL ORDER
2/ 02-08-2012 Heard the parties.
The Petitioners seek quashing of the order dated
19.06.2009 passed in Sessions Trial No.444 of 2009 by which the
Sessions Judge, Munger, has framed charge under section 307/34
Indian Penal Code.
It has been submitted that injury report does not
substantiate the charge of section 307 Indian Penal Code and,
therefore, charge under section 307 Indian Penal Code is bad.
Since no prejudice would be caused to the Petitioners
even if charge under section 307 Indian Penal Code is framed, I
am not inclined to entertain the application.
The application is dismissed.
