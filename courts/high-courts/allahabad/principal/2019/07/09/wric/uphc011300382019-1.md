# Allahabad High Court, WRIC/21867/2019, 2019-07-09

Court No. - 6
Case :- WRIT - C No. - 21867 of 2019
Petitioner :- Vikram Singh
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Jaysingh Yadav
Counsel for Respondent :- C.S.C.
Hon'ble Yashwant Varma,J.
Heard learned counsel for the petitioner and the learned
Standing Counsel for the State-respondents.
This petition challenges an order passed by the Appellate
Authority rejecting an application for stay made in a statutory
appeal directed against an order cancelling an arms licence.
Undisputedly, any interlocutory order would have clearly
amounted to grant of final relief. In view thereof, the Court
finds no ground warranting interference with the order
impugned.
The petition is dismissed.
Order Date :- 9.7.2019
Arun K. Singh
(Yashwant Varma, J.)
