Order
23/07/2020
No case for contempt is made out as admittedly, the
petitioner’s online application has been considered. However, if the
petitioner has not been given appointment and if he has any
grievance that a person lesser in merit has been given
appointment, he is always free to file a writ petition.
In view thereof, the contempt petition is dismissed.
