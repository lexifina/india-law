JUDGMENT
H.L.Dattu,C.J.
Sri.Jawahar Jose, learned counsel appearing for the appellant,
seeks leave of this Court to withdraw the Writ Appeal with liberty to file an
appropriate Review Petition before the learned Single Judge.
2. In our view, the request of the learned counsel is reasonable
and if it is granted, it will not prejudice the respondents in any manner
whatsoever. Therefore, we permit the appellant's learned counsel to withdraw
the Writ Appeal and also reserve liberty to the appellant, if it so desires, to file an
appropriate Review Petition before the learned Single Judge.
Ordered accordingly.
