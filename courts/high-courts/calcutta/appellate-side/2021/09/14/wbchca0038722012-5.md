# Calcutta High Court, CRR/125/2012, 2021-09-14

14.09.2021 IN THE HIGH COURT AT CALCUTTA
 Item No.8 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
 C.R.R. 125 of 2012
 (Via Video Conference)
 Nirod Baran Mondal
 versus
 State of West Bengal
In Re: An Application under Section 482 read with Sections
397/401 of the Code of Criminal Procedure.
Mr. Arijit Ganguly,
Mr. Sandip Chakraborty … For the State.
Mr. Arijit Ganguly, learned advocate appearing for the
State has submitted a report of the concerned police station.
The said report dated 08.09.2021 be kept with the record.
The report reflects that by a judgment and order dated
20.03.2018, the learned Additional Sessions Judge, 2nd
Court, Bankura was pleased to acquit the accused persons of
the charges under Sections 413/414 of the Indian Penal
Code. In view of the report so submitted, this revisional
application has become infructuous.
The revisional application being CRR 125 of 2012 is,
thus, dismissed.
Interim order, if any, is hereby vacated.
All pending connected applications, if any, are
consequently disposed of.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
 (Tirthankar Ghosh, J.)
