# Allahabad High Court, /2094/2022, 2023-11-23

Neutral Citation No. - 2023:AHC-LKO:77269
Court No. - 14
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 2094
of 2022
Applicant :- Ram Sagar
Opposite Party :- State Of U.P Thru. Prin. Secy. Home
Counsel for Applicant :- Rakesh Pratap Singh
Counsel for Opposite Party :- G.A.
Hon'ble Mohd. Faiz Alam Khan,J.
1. No one is present for the applicant when this case is taken up
for hearing. Learned AGA for the State is available. No
request has been received from the learned counsel for the
applicant to adjourn the case.
2. Perusal of the record would reveal that on 21.8.2023 when
this case was last listed learned counsel for the applicant was
not available and in this background it was clearly observed that
if learned counsel for the applicant will choose to remain
absence on the next date of listing, the instant bail application
will be dismissed for want of prosecution.
3. Thus, this bail application is dismissed for want of
prosecution.
Order Date :- 23.11.2023
