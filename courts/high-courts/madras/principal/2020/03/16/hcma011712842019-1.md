# Madras High Court, A/7716/2019, 2020-03-16

A.No.7716 of 2019
N.SATHISH KUMAR, J.
This application has been filed to
direct the respondent furnish security for a
sum of Rs.2,70,331.69 failing which to
attach the immovable property of the
respondent morefully described in the
schedule, till the enforcement of the Award
that may be ultimately passed in the
arbitration proceedings.
2. This Court by an Order dated
directed the respondent to furnish security
for the suit claim on or before 07.01.2020
and on failing to furnish security, there shall
be Order of attachment.
3. Despite the Order of this Court
directing to furnish security, the respondent
has not furnished any security and none
appeared for the respondent.
4. In view of the same, there shall be
an Order of attachment of the immovable
property described in the schedule and this
application is closed. The registry is
directed to communicate this Order to the
concerned Registrar.

 16.03.2020
