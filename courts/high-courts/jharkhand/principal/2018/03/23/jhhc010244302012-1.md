06/23.03.2018 In these writ petitions, orders passed on the Original
applications which were numbered as P.L.A cases have not
been brought on record. The applications on which the
impugned order dated 23.03.2012 has been passed have
also not been brought on record.
Previously hearing of these writ petitions has been
adjourned on as many as four occasions. The plea raised in
these writ petitions in absence of these two documents
cannot be decided and, accordingly, these writ petitions are
dismissed in default, with liberty to the petitioner(s) to file
fresh writ petitions with proper pleadings, supported by
necessary documents.

 (Shree Chandrashekhar, J.)
