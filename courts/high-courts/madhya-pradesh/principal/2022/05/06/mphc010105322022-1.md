ORDER
Heard on I.A. No.3191/2022, an application for converting/treating this
petition as miscellaneous petition.
For the reasons mentioned in the application, the same is allowed.
However, looking to the petition, it is seen that the petitioner has already
incorporated the amendment as per the order dated 24.3.2022, but there is no such
order of amendment passed by this Court.
Learned counsel for the petitioner submits that it is an inadvertent mistake. It
is submitted that there is a bunch of petitions in which such an application was
filed and by mistake, the amendment was made in the present petition also.
Considering that learned counsel for the petitioner has made a bonafide
mistake, this mistake is overlooked. However, since the amendment has already
been made, office is directed to re-register this writ petition as miscellaneous
