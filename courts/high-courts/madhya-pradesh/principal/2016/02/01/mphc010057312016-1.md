# High Court of Madhya Pradesh, MCRC/1943/2016, 2016-02-01

MCRC-1943-2016
(AJAY @ ARJUN @ LULLI Vs THE STATE OF MADHYA PRADESH)
01-02-2016
Shri T.P. Jaiswal, learned counsel for the applicant.
This application has been filed for correction of the typographical
error in the order dated 25.01.2016 passed in M.Cr.C. No. 12/2016.
It is mentioned that the applicant is in jail since 11.10.10, however
the correct date is 11.08.2015.
Looking to the aforesaid facts of the case, the application is
allowed wherein an order dated 25.01.2016 passed in M.Cr.C. No.
12/2016, ''the applicant is in jail since 21.10.10, it be read as
applicant is in jail since 11.08.2015.''
Application is disposed of.
(S.K. GANGELE)
JUDGE
