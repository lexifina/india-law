PER COURT :
1. Mr. Halkude, the learned counsel for the petitioners
submits that the objection raised by them under Order XXI Rule
58 of the Code of Civil Procedure [ For short, ‘ the Code ’ ] of
the attachment of property is rejected.
2. If an objection under Order XXI Rule 58 of the Code is
decided, then it amounts to a decree and Appeal lies under
Order XXI Rule 58 ( 4 ) of the Code.
3. The learned counsel for the petitioners seeks leave to
withdraw the Writ Petition and file Appeal before the
appropriate forum.

 2 WP 8981.2011
4. The forum where the Appeal is filed, shall take into
consideration the time spent in prosecuting the present Writ
Petition.
5. The Writ Petition is disposed of as withdrawn with the
liberty as aforesaid. No costs.
