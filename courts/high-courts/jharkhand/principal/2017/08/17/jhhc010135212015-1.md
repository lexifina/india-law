06/17.08.2017 Heard learned counsel appearing for the petitioner as well as
learned Addl.P.P. for the State.
Learned counsel for the petitioner submits that since no coercive
order has been passed in Cr.M.P. No.2266 of 2015 hence, he does not want
to proceed with this anticipatory bail application and seeks permission of
this Court to withdraw this anticipatory bail application with a liberty to
file in future date, if necessary.
Accordingly, this anticipatory bail application stands dismissed as
withdrawn with the aforesaid liberty.
Animesh (Anil Kumar Choudhary, J.)
