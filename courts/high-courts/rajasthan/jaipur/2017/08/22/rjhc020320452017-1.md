HON'BLE MR. JUSTICE VEERENDR SINGH SIRADHANA
Order
22/08/2017
The matter comes up on an application No. 435/2017, with a
prayer for correction of the writ number as reflected on page No. 2 of
the order dated 10th August, 2017, to be read as “[CW-12751/2017]”,
instead of “[CW-4762/2016]”.
For the reasons detailed out in the memo of application and upon
hearing the learned counsel for the petitioner/applicant, the
typographical error needs to be corrected.
Ordered accordingly.
The description of the writ application number at page 2 of the
order dated 10th August, 2017 be read as “[CW-12751/2017]” instead
of “[CW-4762/2016]”.
But for the correction as indicated above, rest of the order dated
10th August, 2017, shall be maintained as such.
The application (IA No. 435/2017), stands disposed off.
The time schedule to file representation and for its determination
would be reckoned from today.
(VEERENDR SINGH SIRADHANA)J.
