# High Court of Orissa, WP(C)/8065/2015, 2018-12-05

10. 05.12.2018 Learned counsel for the petitioner seeks permission to
withdraw the writ petition. A memo to that effect has been filed
indicating therein that the petitioner may be permitted to
withdraw the writ petition with liberty to file fresh application if
any cause of action survives. The memo is taken on record.
 Permission is granted.
 Learned counsel for the opposite parties does not
object to the same.
 Accordingly, the writ petition stands dismissed as
withdrawn with liberty to the petitioner to file afresh if any
cause of action survives.
 The interim order stands vacated.
