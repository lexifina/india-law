Date : 04-09-2019
Heard learned counsel for the applicant.
By way of this Interlocutory Application, the applicant has sought for correction of the order
dated 15.07.2019 passed in Crl.Pet. 780/2019 wherein in the first paragraph of the order
vehicle number has been wrongly written as AS-01-K-3161 whereas it should be NL-01-K-3161.
It has been submitted that although in rest of the order the vehicle number has been written

Page No.# 2/2
properly but in the first paragraph of the order vehicle number has not been written correctly.
Having heard the submission of the learned counsel for the petitioner and the materials on
record it appears that only in the initial paragraph of the order the number has been wrongly
written which should be read as “NL-01-K-3161”.
With this correction and modification, this Interlocutory Application stands disposed of.
 JUDGE
