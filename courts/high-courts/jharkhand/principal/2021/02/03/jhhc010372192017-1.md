3/ 03.02.2021 Petitioner has prayed for quashing the entire First Information
Report in relation to Gawan Police Station Case No.49 of 2017.
 Now cognizance has already been taken, which is apparent from
the report of the Additional Chief Judicial Magistrate, Giridih.
 In view of the above, counsel for the petitioner seeks permission
to withdraw this writ petition with a liberty to file a fresh application, challenging
the order taking cognizance and order issuing summons.
 Permission, as sought for is granted. This writ petition is,
accordingly, dismissed as withdraw with the liberty to file an appropriate
application to challenge the order taking cognizance and order issuing
summons.

(Ananda Sen, J.)
