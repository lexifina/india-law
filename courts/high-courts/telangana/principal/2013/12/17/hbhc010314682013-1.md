# High Court for the State of Telangana, CRP/4781/2013, 2013-12-17

HON'BLE SRI JUSTICE M.S. RAMACHANDRA RAO
Civil Revision Petition No.4781 of 2013
ORDER:
Heard Sri S.Niranjan Reddy, learned counsel for
petitioner and Sri Shyam S.Agarwal, learned counsel for
respondent.
2. As the order impugned in this Revision is an order
passed under Order 38 Rule 5 of the Code of Civil
Procedure, 1908 (for short “the Code”) which is
appealable under Order 43 Rule 1(q) of the Code by way
of a Civil Miscellaneous Appeal, I am not inclined to
entertain this Civil Revision Petition.
3. Granting liberty to the petitioner to avail the remedy
under Order 43 Rule 1(q) of the Code, this Civil Revision
Petition is dismissed. No costs.
4. Miscellaneous applications if any, pending in this
Civil Revision Petition shall stand closed.

JUSTICE M.S. RAMACHANDRA RAO
