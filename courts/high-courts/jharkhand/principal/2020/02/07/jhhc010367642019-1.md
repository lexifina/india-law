# High Court of Jharkhand, Cr.M.P./3751/2019, 2020-02-07

IN THE HIGH COURT OF JHARKHAND AT RANCHI
Cr. M.P. No.3751 of 2019
----
Mosomma Khatoon @ Mosama Parween … Petitioner
-versus-The State of Jharkhand … Opposite Party
---
CORAM : HON’BLE MR. JUSTICE ANANDA SEN
----
For the Petitioner : Md. Imtiaz Khan, Advocate
For the State : Ms. Priya Shrestha, A.P.P.
----
3/ 07.02.2020 Heard learned counsel for the petitioner and the learned
A.P.P. for the State.
 Petitioner in this criminal miscellaneous petition has
challenged the order dated 27.08.2019 passed by the Judicial Magistrate,
Daltonganj in Complaint Case No.2770 of 2017, whereby process under
Section 82 of the Code of Criminal Procedure has been issued against the
petitioner.
 Counsel for the petitioner submits that the order issuing
process under Section 82 of the Code of Criminal Procedure is absolutely
cryptic and does not reflect any satisfaction as to why processes under
Section 82 of the Code of Criminal Procedure has to be issued. He
submits that without any subjective satisfaction, the impugned order has
been passed.
 After going through the impugned order, I find that the same is
absolutely cryptic and no satisfaction has been recorded as to why process
under Section 82 of the Code of Criminal Procedure is necessitated.
 Accordingly, the order impugned dated 27.08.2019 passed by
the Judicial Magistrate, Daltonganj in Complaint Case No.2770 of 2017,
issuing process under Section 82 of the Code of Criminal Procedure is
hereby quashed and set aside. The matter is remitted to the Court below to
proceed further and pass fresh order in accordance with law.
 This criminal miscellaneous petition is, thus, allowed.

( Ananda Sen, J.)
