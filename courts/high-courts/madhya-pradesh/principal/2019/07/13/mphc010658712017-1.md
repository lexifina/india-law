(KAILASH BELIA Vs SMT. DEEPTI GOUR MUKHARJEE)
Jabalpur, Dated : 13-07-2019
None for the petitioner.
Shri Sunil Kumar Mishra, learned counsel for the respondents.
Learned counsel appearing for the respondents submits that the
order dated 16.11.2017 passed by this Court in W.P.
No.18155/2017, has been complied with and in this regard, the
respondents have filed the compliance report i.e. Annexure-R/1.
I n view of the reply/compliance report submitted by the
respondents, as the order passed by this Court has been complied
with, therefore, nothing further remains to be adjudicated in this
petition.
However, liberty is granted to the petitioner that if he is still
aggrieved with the order so passed by the respondents, then he may
challenge the same before the appropriate forum.
With the aforesaid liberty, the contempt petition is disposed of.
Rule nisi, if any issued, stands discharged.
