Mr. V.V. Gangurde, APP for State.
CORAM : A.S.GADKARI, J.
DATE : 25th APRIL 2018.
P.C.:
1] This is an application for restoration of Criminal Application No.
362 of 2012 which was dismissed for want of prosecution by an Order
dated 31st August 2017.
2] The record indicates that, the present application was filed on
1.3.2012. As the applicant did not peruse the said application diligently, the
same was earlier dismissed by an Order dated 23.9.2014 which was
restored by an Order dated 19th July 2016. As the applicant did not remain
present on several occasions, on 31st August 2017 this Court was
 1/2

constrained to again dismiss the application for want of prosecution. It
appears from the conduct of the applicant that, the applicant is not serious
enough in persuing with the Criminal Application No.362 of 2012 which
was filed on 1.3.2012.
3] After perusing the record, this Court finds no merit in the
present application for restoration of Criminal Application No.362 of 2012.
The application is accordingly rejected.
