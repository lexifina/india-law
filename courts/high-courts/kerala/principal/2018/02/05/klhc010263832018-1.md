JUDGMENT
~ ~ ~ ~ ~ ~
Petitioner challenging an order passed by the
Motor Accidents Claims Tribunal, Alappuzha has
approached this Court. The petitioner was set ex parte in a
claim petition. An award was passed on 19.12.2016.
Thereafter the petitioner filed an application to set aside
the ex parte award. This application was filed only on
03.8.2017. Noting that no application was filed to condone
the delay, the tribunal rejected the application to set aside
the ex parte award. It is challenging the said order this
Original Petition is filed.
2. The tribunal is justified in rejecting the
application in the absence of any application filed to
condone the delay. It is only after condonation of delay,
that tribunal can take up the application to set aside the
award. The petitioner's case is that he had knowledge

O.P.(Mac).12/18 :2:
about the award only when he arrived in India and
therefore he had filed the application immediately after
knowing about the award. That can be a reason for
condonation of delay. But, that cannot be a reason for not
filing an application for condonation of delay. However,
taking note of the fervent plea made by the learned counsel
for the petitioner an opportunity is given to the petitioner
to file an application to condone delay.
3. Accordingly, impugned order is set aside. The
petitioner shall file an application for condonation of delay
within two weeks from the receipt of a copy of this
judgment. Since respondents 1 and 2 are ex parte before
the tribunal, no notice was issued to them.
This original petition is disposed of as above.
