# Calcutta High Court, CRR/918/2012, 2021-09-14

14.09.2021 IN THE HIGH COURT AT CALCUTTA
 Item No.3 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
 C.R.R. 918 of 2012
(Via Video Conference)
 Dwijadas Banerjee
 versus
 The State of West Bengal
In Re: An Application under Section 401 read with Section
482 of the Code of Criminal Procedure, 1973.
Mr. Subhasish Roy … For the Petitioner.
Mr. Arijit Ganguly,
Mr. Sanjib Kumar Dan … For the State.
A report has been submitted by Additional Officer-in-Charge, Jadavpur Police Station which states that the present
petitioner viz., Dwijadas Banerjee expired on 03.10.2020. A
photostat copy of the death certificate has been enclosed
along with the report. Let the said report dated 14.09.2021 be
kept with the record.
This revisional application was preferred challenging
the order dated 06.02.2012 passed by learned Chief Judicial
Magistrate, Alipore in connection with Jadavpur Police
Station Case No. 176 dated 12.05.2004.
Having regard to the report so submitted, this
revisional application has become infructuous.
Accordingly, the revisional application being CRR 918
of 2012 is dismissed.
Interim order, if any, is hereby vacated.
All pending connected applications, if any, are
consequently disposed of.

2
Department is directed to transmit a photostat copy of
the report along with the death certificate to the jurisdictional
court within a period of seven days from date.
The learned court will thereafter conduct an enquiry
and decide regarding the fate of the present petitioner.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
 (Tirthankar Ghosh, J.)
