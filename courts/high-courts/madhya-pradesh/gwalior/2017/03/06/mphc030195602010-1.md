# High Court of Madhya Pradesh, MCRC/7072/2010, 2017-03-06

1
MCRC.7072/2010
State of M.P.
v.
Mahendra Kumar Jain & Ors.
06/03/2017
Shri Rajendra Singh Yadav, Public Prosecutor for the
applicant/State.
Shri R.K.Sharma, counsel for the respondents.
It appears that by order dated 09/02/2017, this
Court had directed that instead of a petition under
Section 482 of CrPC, the State should have filed a
criminal revision and, accordingly, a permission was
sought by the State counsel to file an application for
converting this petition into a criminal revision. Again on
17/02/2017, a last opportunity was sought by the State
counsel to file an application for converting this MCRC
into a criminal revision. Today again, a prayer has been
made that a letter has been written to the Collector for
appointing the OIC so that an application may be filed for
converting this petition under Section 482 of CrPC into a
criminal revision.
For filing an application for conversion of this
petition into a criminal revision, the affidavit of the OIC is
not required. This could have been done by the AG Office
on its own. However, it appears that for the reasons best
known to the applicant, they are not interested in filing
the application for converting this petition into a criminal
revision.
As it was already mentioned by this Court in its
order dated 17/02/2017 that a last opportunity is being
granted for converting this petition into a criminal
revision and since the applicant has failed to file the

2
MCRC.7072/2010
necessary application, no further opportunity can be
granted.
Under the facts and circumstances of the case, the
application is accordingly dismissed for non-compliance
of the order dated 09/02/2017.
 (G.S.Ahluwalia)
AKS Judge
