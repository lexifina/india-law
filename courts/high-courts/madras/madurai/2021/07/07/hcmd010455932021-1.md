ORDER
This petition has been filed to direct the fourth
respondent herein to file charge sheet in Crime No.349 of 2018,
within a period stipulated by this Court.
2.By order dated, 01.07.2021, a copy of the closure report
was directed to be circulated upon this Court. In pursuant to the
same, notice has been circulated to this Court and it is seen that
on 19.07.2019, RCS Notice has been issued to the petitioner. Since
the closure report will not have any impact upon the further
investigation, the fourth respondent is directed to keep the file
pending, for reopening the same at any time, if new clues are
available.
