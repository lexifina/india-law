following:
ORDER
After arguing for some time, the learned counsel for the petitioner prays
for withdrawal of this review petition. It is submitted that liberty be extended to
file an application for recalling the orders passed by the learned trial Court in
view of the subsequent developments.
If such an application is filed, it is expected that the same will be decided
expeditiously.
Accordingly, this review petitoin stands dismissed as withdrawn with the
aforesaid liberty.
