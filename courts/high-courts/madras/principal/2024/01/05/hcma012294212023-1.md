Criminal Original Petition under Section 482 of the Criminal
Procedure Code praying to direct the second respondent police to
expedite the investigation in Crime No.2 of 2023 dated 20.2.2023 on
the file of the second respondent police in fair manner and file a final
report within a time stipulated by this Court.
For Petitioner : Mr.S.Raj Kumar
For Respondents : Mr.A.Damodaran, APP
ORDER
This Criminal Original Petition has been filed seeking to direct
the second respondent to investigate the case in Crime No.2 of 2023
and to file final report within the time fixed by this Court.

2. Heard the learned counsel for the petitioner and the learned
Additional Public Prosecutor appearing for the respondents.
3. The learned counsel appearing for the petitioner would
submit that though the second respondent registered a case in the
above said crime number on 20.2.2023, no final report is filed till
date.
4. The learned Additional Public Prosecutor appearing for the
respondents would submit that the second respondent may be
permitted to file a final report as expeditiously as possible.
5. In view of the above, the second respondent is directed to
file either a final report or closure report, as the case may be, as
expeditiously as possible under due intimation to the defacto
complainant.
6. With the above direction, this Criminal Original Petition is
disposed of.
