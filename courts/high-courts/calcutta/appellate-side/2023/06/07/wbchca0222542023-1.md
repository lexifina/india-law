# Calcutta High Court, CRR/1680/2023, 2023-06-07

D/L29
07.06.2023
Bpg.
 C.R.R. No.1680 of 2023
In Re: An application under Section 483 of the Code of Criminal
Procedure, 1973;
 Afsana Bibi Khatun
 Versus
 State of West Bengal and another
Ms. Aiswarjya Gupta.
 …for the petitioner.
Petitioner is aggrieved by the fact that Misc. Case No.28
of 2018 is an application under Section 127 of the Code of Criminal
Procedure which was filed almost five years ago and till date the
same is pending before the learned Judicial Magistrate, 1st Court,
Alipore, South 24 Parganas.
Learned Judicial Magistrate, 1st Court, Alipore, South 24
Parganas is directed to dispose of the application under Section 127
of the Code of Criminal Procedure by 31st August, 2023. If there is
non-cooperation from the side of the opposite party, learned
Magistrate would proceed ex parte and dispose of the application.
With the aforesaid observations, CRR 1680 of 2023 is
disposed of.
Pending application, if any, is consequently disposed of.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
 (Tirthankar Ghosh, J.)
