6. 24.03.2011 Having heard learned counsel for the parties we
would find it difficult to continue with this contempt
application inasmuch as the order of this Court dated
31.7.2003 had already been implemented and if there is
subsequent and temporary encroachment which is not
the subject matter of the present contempt application
and if the petitioner is aggrieved, he can avail the
remedy before the appropriate forum in accordance with
law.
 With the aforementioned observation, this MJC
application is disposed of.
