# High Court of Madhya Pradesh, MP/509/2018, 2018-02-21

1
HIGH COURT OF MADHYA PRADESH
MP No.509/2018
(Smt. Vimla v. Anand Tomar & Another)
Gwalior, Dated : 21.02.2018
Shri K.K. Chaturvedi, learned counsel for the petitioner.
Heard.
Petitioner has filed this writ petition being aggrieved by
order dated 07.11.2017 Annexure P/7, order dated
04.12.2017 Annexure P/8 and order dated 10.01.2018
Annexure P/13. The application under Order 26 Rule 10, CPC
has been rejected vide order Annexure P/7. Thereafter, vide
order dated 04.12.2017, the applications under Section 151
CPC and another application under Order 19 Rules 1 and 2
CPC both claiming the same reliefs have been decided and
rejected. Petitioner then again filed an application under
Order 26 Rule 9, CPC, which has been decided vide order
dated 10.01.2018.
2. As per the provisions contained in Rule 7 in Chapter X
of the High Court of M.P. Rules, 2008, this writ petition
against the three different orders is not maintainable.
3. Learned counsel for the petitioner submits that he
would like to restrict his claim only to order dated 07.11.2017
Annexure P/7, whereby the petitioner's application under
Order 26 Rule 10, CPC has been rejected.
4. Petitioner had moved an application alleging that the
local Commissioner, Revenue Inspector had prepared a
fabricated report on 02.05.2017 in connivance with
defendant no.1 and made several allegations against the
Commissioner, which the Court did not find substantiated in
the matter and, therefore, rejected the application by the
impugned order.
5. Provisions contained in Order 26 Rule 10, CPC deal
