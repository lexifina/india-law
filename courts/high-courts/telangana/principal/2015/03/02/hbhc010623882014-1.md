# High Court for the State of Telangana, WP/40288/2014, 2015-03-02

HON’BLE SRI JUSTICE CHALLA KODANDA RAM
WRIT PETITION No.40288 OF 2014
ORDER:
Sri Bajrang Singh Thakur, learned counsel for the petitioners, by letter
dated 25.02.2015 addressed to the Registry, seeks permission of the Court to
withdraw the writ petition giving liberty to the petitioners to file a fresh writ
petition.
Permission is granted.
Accordingly, the writ petition is dismissed as withdrawn giving liberty
to the petitioners to file a fresh writ petition, if so advised. No order as to costs.
Miscellaneous petitions, if any pending in this writ petition, shall stand
closed.
