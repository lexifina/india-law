# High Court of Madhya Pradesh, MCRC/19067/2014, 2015-01-21

M.Cr.C.No.19067 of 2014

1
Syed Javed Akhtar vs State of M.P.
21/01 / 2015
Shri Saleem Rehman, Advocate for the applicant.
Shri Arvind Singh, Panel Lawyer for the respondent/
State.
Heard on I.A.No.23268/2014, which is an
application for condonation of delay.
The application is allowed. Delay in filing this
petition is hereby condoned.
Heard finally.
This petition has been filed for restoration of
M.Cr.C.No.12336/2012, which was dismissed in default
on 04/08 /2014.
It is submitted by due to inadvertence mistake of
junior counsel, the default had not been removed and the
petition was dismissed in default.
It is settled law that for the fault of a counsel, a
litigant cannot make to be sufferer.
Hence, this petition is allowed.
M.Cr.C.No.12336/2012 is restored to its original number.
A copy of this order be placed in the file of
M.Cr.C.No.12336/2012.
 (SUBHASH KAKADE)
SJ JUDGE
