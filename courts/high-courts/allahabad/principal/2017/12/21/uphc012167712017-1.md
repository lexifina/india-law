# Allahabad High Court, CRLP/27258/2017, 2017-12-21

Court No. - 42
Case :- CRIMINAL MISC. WRIT PETITION No. - 27258 of 2017
Petitioner :- Mohd. Akmal
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Jamal Ahmad Khan
Counsel for Respondent :- G.A.
Hon'ble Ramesh Sinha,J.
Hon'ble Vivek Kumar Singh,J.
Criminal Misc. Amendment Application No.421793 of 2017:-
Heard Sri J.A.Khan, learned counsel for petitioner, Sri Ashish Pandey,
learned AGA for State and perused the record.
Though, the amendment application of the petitioner was allowed, but
when the order came for the signature of the Court then it was found from
the record that the correction which has been carried out by the learned
counsel for the petitioner had been done wrongly for which he was been
again summoned in the Court and apologize for the same and further there
has been wrong description of the respondent nos.2 to 4 in the array of the
respondents in the writ petition to which the learned counsel for the
petitioner prayed that the present amendment application alongwith the
petition be dismissed as not pressed with a liberty to file fresh writ petition
with proper prayer and array of respondents.
The present amendment application as well as the writ petition is
dismissed as not pressed with liberty to the petitioner to file fresh petition,
if so advised.
Certified copy of the order impugned passed by the Commissioner be
returned to the learned counsel for the petitioner as the Rules of the Court.
.
(Vivek Kumar Singh, J.) (Ramesh Sinha, J.)
