# High Court of Orissa, CONTC/1179/2018, 2019-04-05

15. 05.04.2019 Heard learned counsel for the parties.
 This contempt proceeding has been initiated for alleged
non-compliance of the order dated 04.05.2018 passed in W.P.(C)
No.5387 of 2018.
 Learned counsel for the petitioners submits that in the
meantime the Original Application bearing O.A. No.2757 (C) of
2017 and batch of cases filed by the petitioners before the
Odisha Administrative Tribunal, Cuttack Bench, Cuttack have
already been dismissed.
 Since the Original Applications are dismissed and this
is a contempt against the interim order of the Tribunal, it will be
open for the petitioners to file appropriate application before the
Tribunal.
 The contempt proceeding is dropped.
 The CONTC is accordingly disposed of.
