2. It is pointed out by Mr. S. S. Kantak, learned Senior Counsel
appearing for the applicant that there is a direction to the learned
Judge to dispose of an application which has to be read as an
application to vacate the interim order at para 5 of the order dated
13.07.2015. In fact, this court meant to direct the learned Judge to
decide the application which means the application to be filed by the
applicant to vacate the interim order within one month in the light of

2 MCA/449/2015
the observations made therein.
3. With the aforesaid clarification, the application stands
disposed of.
