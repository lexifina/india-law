# High Court of Madhya Pradesh, MCC/972/2012, 2014-01-21

1
MCC No.972/2012
21/1/2014.
Shri Mahesh Shukla, learned counsel
for the applicant.
This application has been filed for
restoration of W.P. No.389/2006 which was
dismissed for want of prosecution on 28.11.2011.
There being some delay I.A. No.9570/2012 has
been filed seeking condonation of delay. The
applications are supported by the affidavit of the
counsel himself and the reasons given in the
application seems to be bonafide. Considering
the same, both the applications are allowed.
Condoning the delay in filing the application for
restoration, the restoration application itself is
allowed. Writ petition is restored to its original
file. It be placed for orders before the
appropriate Bench.
With the aforesaid, this application
stands allowed and disposed of.
(Rajendra Menon)
 Judge
