1. Petitioner has preferred this Criminal Miscellaneous Petition
seeking fair investigation.
2. Learned Public Prosecutor contends that negative final report
has already been filed.
3. In view of the same, the present Petition has become
infructuous and the same is accordingly dismissed as having
become infructuous. Stay application stands disposed.
4. Petitioner would be free to file protest petition, if so advised.
