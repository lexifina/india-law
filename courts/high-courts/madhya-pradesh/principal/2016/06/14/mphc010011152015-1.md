# High Court of Madhya Pradesh, WP/342/2015, 2016-06-14

WP-342-2015
(MOTISHARAN SAKET Vs THE STATE OF MADHYA PRADESH)
14-06-2016
None for the petitioner.
Shri Pushpendra Yadav, learned Government Advocate for the
respondent/State.
Heard.
In this petition the petitioner has challenged the transfer order
dated 12-12-2014 (Annexure P/1). This Court on 20-12-2014 passed
an interim order directing the respondents to continue the petitioner
at present place of posting. The said interim order is still prevailing.
Thus, in my view, the administrative exigency which was prevailing in
December, 2014 must be over by now. Thus, the impugned order is
set aside to the extent it relates to the petitioner. Liberty is reserved
to the respondents to pass an appropriate order if administrative
exigency so required.
The petition is allowed.
(SUJOY PAUL)
JUDGE
