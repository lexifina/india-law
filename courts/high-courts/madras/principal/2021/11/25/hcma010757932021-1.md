This application praying that this Hon'ble Court be pleased to set
aside the exparty order passed against petitioner/Respondent on 31/03/2021
for non filing of counter affidavit.
This application coming on this day before this court for hearing
the court made the following order:
This application has been filed to set aside the exparte order
dated 31.03.2021 passed in O.P.No.1079 of 2019 against the
applicant/respondent. On that date, the applicant/respondent was set
exparte in the main Original Petition namely O.P.No.1079 of 2019.
https://hcservices.ecourts.gov.in/hcservices/

/ 3 /
2. In the affidavit filed in support of this application, the
applicant/respondent has stated that due to Covid Pandemic situation, she
was unable to come over to Chennai from Dubai and that is the reason for
not entering appearance in O.P.No.1079 of 2019.
3. This Court is satisfied with the reasons contained in the affidavit
filed in support of this application seeking to set aside the exparte order.
4. The learned counsel for the respondent has also not raised any
serious objection for allowing this application.
5. A memo has been filed by the counsel for the Applicant/respondent
giving details of the applicant's Dubai address as well as the present
address in Chennai.
6. A counter statement has also been filed by the applicant/respondent
in the main original petition.
7. The only apprehension raised by the learned counsel for the
respondent/petitioner on the earlier hearing date was that whereabouts of the

address of the applicant/respondent has been furnished by way of memo

stated in the affidavit filed in support of this application is satisfactory.
Accordingly, this application is allowed as prayed for.
