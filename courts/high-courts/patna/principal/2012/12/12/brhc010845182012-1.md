CORAM: HONOURABLE MR. JUSTICE AKHILESH CHANDRA
ORAL ORDER
2 12-12-2012 Heard learned counsel for the petitioner and learned
Additional Public Prosecutor for the State.
This is an application seeking restoration of Cr. Misc. No.
26293 of 2011 under Section 438 of the Code of Criminal Procedure, which
stands dismissed for non-prosecution vide order dated 15.11.2011 in
connection with Supaul P.S. Case No. 02 of 2009 (G.R. No. 27 of 2009),
pending before Chief Judicial Magistrate, Supaul.
Finding no reason, this restoration application is dismissed.
However, petitioner is at liberty to file fresh application if mandatory
requirement under Section 438 of the Code of Criminal Procedure is still
available to him.
Praveen-II/-
(Akhilesh Chandra, J)
