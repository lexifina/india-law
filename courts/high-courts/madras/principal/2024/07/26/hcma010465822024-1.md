P.B.BALAJI, J.,
This Application has been taken out by the 2
nd
 defendant to set aside the
exparte order passed on 10.10.2018 in the above C.S. No.709 of 2013.
2. Heard Mr.M.Sriram, learned counsel for the Applicants,
Mr.K.Chandrasekaran, learned counsel for the first respondent and
Mr.K.Soundararajan, learned counsel for the fifth respondent.
3. The learned counsel for the respondents have no serious objection in
allowing this Application provided that the written statement has also brought on
record.
4. Mr.Sriram, learned counsel submits that alongwith condone delay
Application, the written statement has already been filed. The said Application
will be brought on record shortly.
5. I have gone through the affidavit filed in support of the above
Application and it is just and proper to allow this Application. Accordingly, this
Application is allowed and Registry is directed to number the condone delay
Application in filing the written statement, if it is otherwise in order.
