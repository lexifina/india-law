ORDER
Revision petition is filed challenging the order passed by
Judicial First Class Magistrate-II, Thiruvananthapuram in
CMP.2651 of 2008 in C.C.24 of 2002 under Section 452 of Code
of Criminal Procedure, disposing the property at the conclusion
of trial. Section 454 provides for an appeal against an order
under Section 452 of Code of Criminal Procedure. Under sub-section ()1) of Section 454 of Code of Criminal Procedure, any
person aggrieved by an order made by a court under Section
452 of Code of Criminal Procedure can file an appeal to the
court, to which appeals ordinarily lie from conviction by that
court. Therefore remedy of petitioner is to file an appeal.
Revision petition is dismissed with liberty to file an appeal
as provided under Section 454 of Code of Criminal Procedure.
M.SASIDHARAN NAMBIAR, JUDGE
