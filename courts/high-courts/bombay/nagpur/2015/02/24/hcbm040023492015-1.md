Shri P.B. Patil, Advocate for the applicant.
Shri Ghodeswar, APP for the respondent.
 CORAM : PRASANNA B.VARALE, J.

After arguing the matter for some time, the learned counsel
Shri Patil, on instructions, prays for withdrawal of the application
with liberty to file the successive application. The application is
allowed to be withdrawn.
Needless to state that the applicant can file successive
application provided, the applicant is in a position to show change in
circumstance or any other reasonable ground.
The application is allowed to be withdrawn with liberty as
prayed for.
