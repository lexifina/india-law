Date : 31-05-2018
By this application 438 CrPC, accused petitioners namely 1. Arup Saha, alias Bappa
2. Apurba Saha, alias Bappi 3. Satya Gopal Saha, alias Mani Saha 4. Manojit Saha, alias
Bapan and 5. Subhajit Saha, alias Chutan have prayed for granting of pre-arrest bail in
connection with Kharupetia PS Case No. 45/2018 under sections
147/148/149/448/325/323/307/380 of IPC ( GR Case No. 274/18)
Heard the submissions of learned counsels for both the parties.
It is to be noted that on the same facts a cross FIR has been filed by the petitioner side also
with the similar sort of allegation regarding assault with iron, rod etc. So far as regarding the
present case is concerned medical report reveals that injury was simple caused by blunt object.

Page No.# 3/3
That apart, there is no any supporting evidence as regards the theft of ornament and money. It
can be assumed that only for enmity between the parties, the present case has been filed.
Taking into account all above, it appears that custodial detention of the accused
petitioners are not warranted. Interim bail so granted earlier to the accused petitioners are
hereby made absolute.
Return the case diary.
