# High Court of Jharkhand, Cr.M.P./193/2020, 2020-02-26

IN THE HIGH COURT OF JHARKHAND AT RANCHI
Cr. M.P. No. 193 of 2020
----
Shamshad Ansari … Petitioner
-versus-The State of Jharkhand … Opposite Party
----
CORAM : HON’BLE MR. JUSTICE ANANDA SEN
----
For the Petitioner : Mr. Avishek Prasad, Advocate
For the State : Mr. Bhola Nath Rajak, A.P.P.
----
4/ 26.02.2020 Heard learned counsel for the petitioner and the learned
A.P.P. for the State.
 Petitioner has challenged the order dated 14.01.2020 passed
by the Additional Chief Judicial Magistrate, Ranchi in Sadar Mesra Police
Station Case No.260 of 2016 (G.R. No.3534 of 2016), by which processes
under Section 82 of the Code of Criminal Procedure has been issued.
 Counsel for the petitioner submits that the order issuing
process under Section 82 of the Code of Criminal Procedure is absolutely
cryptic and does not reflect any subjective satisfaction as. He submits that
the order impugned is bad and is liable to be set aside.
 After going through the record, I find that on earlier occasion
also, the Court below had issued processes under Section 82 of the Code
of Criminal Procedure, which was quashed by a Coordinate Bench of this
Court. Thereafter the petitioner did not chose to appear before the Court
below, which clearly suggests that the petitioner had knowledge of the
proceedings. This is a very good ground to issue process under Section 82
of the Code of Criminal Procedure. I find no illegality in the impugned order
dated 14.01.2020. Thus, there being no merit, I am not inclined to entertain
this criminal miscellaneous petition. This criminal miscellaneous petition is,
accordingly, dismissed.

( Ananda Sen, J.)
Kumar/Cp-03
