ORDER
This application has been filed to transfer the execution
petition to Commercial Division of this Court.
2. Considering the fact that the Execution petition has been
filed for the execution of an award, the Execution petition can be
heard only by the Commercial Division. That apart, the respondent
has no objection in the Execution petition being transferred to the file
of this Court.
3. In view of the above, this application is allowed.
