# High Court of Madhya Pradesh, MCC/241/2016, 2016-07-05

- 1 -
M. C. C. No.241/2016
05/07/2016
Shri M. I. Khan, learned counsel for the applicant.
Shri Bhuwan Deshmukh, learned counsel for the
respondent/State.
The present application has been filed for correction of
typographical error in order dated 18/02/2016 passed in Writ Petition
No.1317/2016.
Learned counsel for the applicant has fairly stated before this
Court that on account of some mistake committed by him, father's
name of the petitioner Sumersingh has been mentioned as
'Ambaram', whereas the correct name is 'Ramsingh'.
Learned Government Advocate has not objected to the
aforesaid statement.
Resultantly, in the cause title 'Ramsingh' in place of 'Ambaram'
is hereby substituted.
The present order shall be read conjointly with the order dated
18/02/2016 passed in W. P. No.1317/2016.
A copy of this order be kept in the file of W. P. No.1317/2016.
MCC stands allowed.
Certified Copy as per rules.
(S. C. SHARMA)
