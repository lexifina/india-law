ORAL ORDER
4 18-06-2014 Heard learned counsel for the petitioners and learned
counsel for the State.
The counsel for the petitioners submits that as the
grievance raised by petitioners in this application has been redressed,
accordingly, this petition has been rendered infructuous and wants to
withdraw this application.
As this petition has become infructuous, there is no need
to proceed with.
The counsel for the State has not raised objection.
In this view of the matter, this petition is dismissed as
infructuous.
