P.C.:
 1.Heard Advocate for the Petitioner. By this
 Writ Petition under Article 227 of the Constitution
 of India, the Petitioner has challenged the order
 dated 02nd November, 2006 passed by the trial Court
 by which the trial Court has directed that police
 aid be granted for implementation of the order
 passed below Exhibit 5 on 30th April, 2005 by which
 temporary injunction has been granted against the
 Petitioner. It is not in dispute that the order
 dated 30th April, 2005 is still in force. So long
 as the order is in force, the same has to be
 implemented and therefore, no fault can be found
 with the impugned order. No case is made out for
 interference. Petition is rejected.
