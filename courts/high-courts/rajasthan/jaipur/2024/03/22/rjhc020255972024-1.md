Order
22/03/2024
Present application is filed for typographical correction in the
order dated 18.03.2024, wherein in para 14 of the page 5, the
year “2009” has been wrongly mentioned instead of year “2019”.
For the reasons mentioned in the application, same is
allowed and typographical error needs to be corrected.
It is directed that in the order dated 18.03.2024, the year
“2009” be read as “2019”.
Rest of the order dated 18.03.2024 be maintained as such.
