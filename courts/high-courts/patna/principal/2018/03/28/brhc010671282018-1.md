ORAL ORDER
3 28-03-2018 Heard learned counsel for the parties.
This application is for modification in the order dated
22.09.2017 passed in Cr.W.J.C. No.1584 of 2017 to the extent that
besides the Bank Guarantee security of title deed of immovable
property of equal value in the name of the petitioner be permitted
to be given as security for release of the vehicle.
Prayer for modification is allowed.
The order dated 22.09.2017 stands modified to the
aforesaid extent.
The application stands disposed of.
