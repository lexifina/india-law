This application praying that this Hon'ble court be
pleased to set aside and restore the order dated 07/06/2019
in O.P.No.736 of 2017 which was dismissed for default vide
order dated 07/06/2019.
This application coming on this day before this court
for hearing the court made the following order:
The above application is filed by the applicant for
setting aside and restoring the O.P.No.736 of 2017, which
was dismissed for default by orders of this Court dated
07.06.2019.
2. The note sheet would show that the respondent has
not been appearing before this Court. Today, the learned
counsel for the applicant has made his submissions. The
reasons for the dismissal for default is narrated in
paragraph 3 of the affidavit filed in support of the Judges
Summons. The same contentions have also been argued by
the learned counsel for the applicant.
3. This Court finds considerable force in the said
arguments and accordingly, this application is allowed and
the O.P.No.736 of 2017 is restored to file. The O.P is
posted for final disposal on 09.03.2020.
