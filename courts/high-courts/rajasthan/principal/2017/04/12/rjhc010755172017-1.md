HON'BLE MR. JUSTICE ARUN BHANSALI
Order
12/04/2017
This writ petition has been filed by the petitioner aggrieved
against the order dated 04.03.2017 passed by the Rent Tribunal,
Jodhpur Metro (‘the Tribunal’), whereby though the application
filed by one Mahant Shridhar Giri for being impleaded in place of
the original applicant Mahant Shiv Ratan Giri, has been rejected, a
direction has been given to the Trust to file appropriate application
for continuing with the petition.
It is submitted by learned counsel for the petitioner that the
Tribunal could not have given a direction to the Trust for filing
application for continuing with the petition. It is upto the Trust to
file such an application, if it wants to continue with the
proceedings and, therefore, the order impugned passed by the
Tribunal to the extent the said direction has been given to the
Trust deserves to be set aside.

(2 of 2)
[CW-4042/2017]
I have considered the submissions made by learned counsel
for the petitioner and have perused the material available on
record.
This petition has been filed on the apprehension that the
Tribunal has preempted filing of the application and has already
passed the order that the petition would be continued by a duly
appointed person.
The apprehension is misplaced, inasmuch as, as and when
such an application, if filed, the petitioner would get an
opportunity to contest the same and the said application would
have to be determined by the Tribunal on its own merits
irrespective of the observations made by it in the order dated
04.03.2017 passed by it.
In view of the above discussion, no interference is called for
in the order impugned, the writ petition is, therefore, dismissed.

(ARUN BHANSALI)J.
