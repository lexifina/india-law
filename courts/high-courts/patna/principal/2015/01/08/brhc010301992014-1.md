ORAL ORDER
2 08-01-2015 Heard learned counsel for the parties.
This is an application seeking restoration of Cr.
Misc. No. 2570/2014 dismissed for non-prosecution on
09.12.2014 in connection with Bihpur (Bhawanipur) P.S. Case
No. 297/2012 pending before learned Additional Sessions Judge
– IV, Bhagalpur.
It is stated that earlier case diary was called for
vide order dated 20th March 2014, on receipt of the same call for
hearing, but nothing could be done except dismissing the
application for non-prosecution on 23rd June 2014. On the
prayer, it could be restored vide order dated 12th August 2014
passed in Cr. Misc. No. 32171/2014, but again the application
made same fate. None turned up on behalf of the petitioner on
repeated calls on two consecutive dates, consequently,
application was dismissed on 9th December 2014.
Finding no reason to entertain this application,
accordingly, this application stands dismissed.
Rajeev/- (Akhilesh Chandra, J.)
