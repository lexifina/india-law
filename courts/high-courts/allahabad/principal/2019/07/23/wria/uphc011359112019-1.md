# Allahabad High Court, WRIA/10624/2019, 2019-07-23

Court No. - 39
Case :- WRIT - A No. - 10624 of 2019
Petitioner :- Umesh Prasad
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Ram Sumer Chaudhary
Counsel for Respondent :- C.S.C.,Mohd Shere Ali
Hon'ble Neeraj Tiwari,J.
Heard learned counsel for the petitioner, learned Standing
Counsel for the respondent nos. 1 & 2 and Mohd Shere Ali,
learned counsel for the respondent no.3.
Learned counsel for the petitioner submitted that earlier an
order dated 4.11.2017 was passed against the petitioner, which
was challenged by the petitioner by filing Writ Petition
No.54004 of 2017 in which counter and rejoinder affidavits
have been exchanged and now consequential order dated
29.06.2019 has been passed, which is under challenge in the
present petition.
Learned Standing Counsel as well as Mohd Shere Ali, learned
counsel for the respondent no.3 has vehemently opposed and
submitted that present petition is not maintainable as it is
required to the petitioner to challenge the said order by filing
amendment application in the pending petition.
Accordingly, the writ petition is dismissed with liberty to the
petitioner to file amendment application challenging the order
dated 29.06.2019.
Order Date :- 23.7.2019
Junaid
