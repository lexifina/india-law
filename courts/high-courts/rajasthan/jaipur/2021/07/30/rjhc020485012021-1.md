Order

(2 of 2) [WMAP-113/2021]
30/07/2021
This misc. application has been filed for correction in the
order dated 26.07.2021 passed by this Court, whereby the writ
petition filed against the order passed by the Central
Administrative Tribunal in Original Application, has been disposed
of.
Contention of learned counsel for the applicant is that due to
inadvertence, the number of Original Application came to be
mentioned as 0291/151/2021 in the memo of writ petition and
consequently it reflected so in the order aforesaid too. It is prayed
that the number of Original Application be corrected as
291/159/2021 instead of the former.
Learned counsel for the non-applicants does not dispute the
aforesaid fact.
 Considering the submissions and the mistake being
bonafide, the correction prayed for is allowed. On the second page
of the order dated 26.07.2021, instead of “Original Application
No.0291/151/2021”, the same be read as Original Application
No.291/159/2021.”
The misc. application is accordingly allowed. This order shall
be treated as part and parcel of the order dated 26.07.2021.
(MAHENDAR KUMAR GOYAL),J (SANGEET LODHA),J
