ORDER
An order refusing to set aside the ex-parte decree after
condoning the delay is challenged in this Original Petition. An
order so passed under Order IX Rule 13 of the Code of Civil
Procedure is very much appealable. The appeal lies under
Order XLIII Rule 1 (d) of the Code of Civil Procedure.
2. The grounds relating to condonation of delay can
also be urged in the Civil Miscellaneous Appeal if any filed.
The Civil Revision Petition under the circumstances is wholly
misconceived.
The Civil Revision Petition is dismissed without prejudice
to the right of the petitioner to file an appeal as directed.
Registry to return the original order to the counsel.
V. CHITAMBARESH
 JUDGE
