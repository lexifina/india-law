 DATED : 24th February, 2010.
 This civil application is for restoration of the writ
petition No.957 of 1999, which was dismissed for default on
13th November, 2009. The application has been signed and
verified by the learned counsel for the petitioners. The
application for restoration has to be filed by the concerned
parties. The least that is required in the application is
verification of the application by one of the petitioners. In
the circumstances, the application as filed is not
maintainable. The same is dismissed. The petitioners are at
liberty to file a proper application for restoration of the
petition.
 JUDGE.
