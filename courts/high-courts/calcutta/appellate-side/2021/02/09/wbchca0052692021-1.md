# Calcutta High Court, CO/212/2021, 2021-02-09

09.02.2021
 Sl. No. 6
 srm
C.O. No. 212 of 2021
Ataur Rahman
Vs.
Md. Shahnawaz Alam & Ors.
Mr. Abdul Hadi
…for the Petitioner.
This revisional application has been filed against an
order rejecting an application under Order 39 Rule 4 of the
Code of Civil Procedure. The said order is an appealable order
under Order 43 Rule 1(r) of the Code of Civil Procedure.
This revisional application is dismissed as not
maintainable.
The petitioner is at liberty to approach the appropriate
forum in accordance with law upon taking back the certified
copy of the order impugned upon furnishing a photocopy
thereof
There will be, however, no order as to costs.
 (Shampa Sarkar, J.)
