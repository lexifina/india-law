# Calcutta High Court, CRR/1788/2012, 2021-09-23

23.09.2021
 item No.16
 n.b.
 ct. no. 34
CRR 1788 of 2012
(via video conference)
 Samit Saha & Ors
-Vs-State of West Bengal
Mr. Arijit Ganguly
Mr. Sandip Chakraborty
…..For the State
Mr. Sandip Chakraborty, learned Advocate appearing for
the State has submitted the report which is prepared by Inspector
In-charge, Ranaghat Police Station.
The report reflects that there are two cases one being
Case no.84 of 2012 dated 3.3.2012 under Sections 498(A)/34 of
the Indian Penal Code and another being Complaint Case No.1403
of 2011 under Sections 498(A)/406 IPC. The report be kept with
the record.
The report reflects so far as the case is concerned the
charge was framed and date has been fixed for examination of the
accused on 27.9.2021.
The settled position of law being that and the self-same
cause of action if there is police case and complaint case, the
provisions of Section 210 of the Code of Criminal Procedure is to be
invoked.

Accordingly, no interference is called for in this revisional
application. The revisional application being CRR 1788 of 2012 is,
thus, dismissed.
Interim order, if any, stands vacated.
All pending connected applications, if any, are
consequently disposed of.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Hon’ble Court.
( Tirthankar Ghosh, J.)
