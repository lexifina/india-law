This appeal is directed against the order dated 08.07.2024
by which ex parte interim order has been granted by the learned
Single Judge.

[2024:RJ-JP:31662-DB] (2 of 2) [SAW-471/2024]
Though, number of arguments are raised by learned counsel
for the appellants to challenge the order, we are not inclined to
entertain this appeal because the appellants have a remedy to file
an application for vacating the stay order.
We give the appellants liberty to file an application for
vacating the stay order and make a mention before the learned
Single Judge for consideration of application for vacating the stay
order within a period of one week.
This appeal is dismissed with the liberty aforesaid.
