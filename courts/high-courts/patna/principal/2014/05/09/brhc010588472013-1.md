CORAM: HONOURABLE MR. JUSTICE ASHWANI KUMAR SINGH
ORAL ORDER
3 09-05-2014 The present application under Section 482 of Code
of Criminal Procedure has been filed for setting aside the final
report no.113 of 2011 submitted by the police in connection with
Nawada Sadar Muffasil P.S. Case No.66 of 2011 in which
prosecution under Sections 182 and 211 of the Indian Penal Code
has been proposed to be taken against the petitioner.
This application is thoroughly misconceived.
At this stage, learned counsel for the petitioner
seeks leave to withdraw this application.
The application is dismissed as withdrawn.
Sunil/-
(Ashwani Kumar Singh, J)
