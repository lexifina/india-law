(RAZA HUSSAIN Vs NASREEN B)
Jabalpur, Dated : 01-07-2019
Shri Aditya Singh Kunwar, Advocate for the petitioner.
Heard on I.A. No. 3357/2019, which is an application to convert this
petition into first appeal.
There is no specific provision of conversion of misc. petition into first
appeal, therefore, this application is rejected.
At this stage, learned counsel for the applicant seeks permission to
withdraw this petition with liberty to file first appeal.
Prayer seems to be reasonable, therefore, allowed.
Accordingly, this petition is dismissed as withdrawn with the liberty as
prayed.
Certified copy of the impugned judgment be returned back to the
counsel for the petitioner on filing photocopy thereof.
