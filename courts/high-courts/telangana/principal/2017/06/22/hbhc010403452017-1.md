# High Court for the State of Telangana, WP/20478/2017, 2017-06-22

THE HONOURABLE SRI JUSTICE RAJA ELANGO
WRIT PETITION No.20478 of 2017
ORDER:
Learned counsel for the petitioner seeks permission to
withdraw this writ petition with liberty to file a fresh application.
2. Permission is granted.
3. Hence, the Writ Petition is dismissed as withdrawn
giving liberty to the petitioner to file a fresh application. There
shall be no order as to costs. Miscellaneous petitions, if any,
pending in this writ petition shall stand closed.
