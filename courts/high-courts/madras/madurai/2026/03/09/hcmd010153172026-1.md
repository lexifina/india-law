of 2023, dated 07.11.2025 and thereby dismissing the application filed by
the petitioner under Order XXI Rule 97 of the Code of Civil Procedure.
2. Though the learned counsel for the petitioner urges on the merits
of the application, I have to point out, in terms of Order XXI Rule 103 of
the Code of Civil Procedure, any order passed under Order XXI Rule 98
or 100 is subject to an appeal, as if it were a decree.
3. The learned counsel for the petitioner states that the application
has been filed under Order XXI Rule 97 and not under Order XXI Rule
98. While the submission might look interesting, an application filed
under Order XXI Rule 97 is adjudicated under Order XXI Rule 98.
Similarly, an application filed under Order XXI Rule 99, is adjudicated
under Order XXI Rule 100.
4. The petitioner has the right of appeal to challenge the order
passed by the learned District Munsif, Oddanchatram. When an appeal
lies, a revision is not maintainable. Hence, the Civil Revision Petition is
dismissed with a liberty to the petitioner to file an appeal against the
