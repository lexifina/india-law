# High Court of Andhra Pradesh, WP/3932/2021, 2021-02-18

THE HONOURABLE SRI JUSTICE D. RAMESH
W.P. No.3932 OF 2021
ORDER:-
 Learned counsel for the petitioner requested to
withdraw the writ petition with a liberty to file an application
before the learned Magistrate.
2. Permission for withdrawal is accorded.
3. Accordingly, this Writ Petition is dismissed as
withdrawn with a liberty to file an application before the
learned Magistrate for release of vehicle and in such an event,
learned Magistrate shall consider the same and pass
appropriate orders within three days thereafter.
 Miscellaneous applications pending, if any, in this case
stands closed. Interim orders granted if any, stands vacated.
No costs.
