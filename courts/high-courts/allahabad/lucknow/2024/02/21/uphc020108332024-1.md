Hon'ble Abdul Moin,J.
(I.A. No.1 of 2024)
This is an application for condonation of delay in filing the
review application.
Heard.
On due consideration, the application is allowed and the delay
in filing the review application is hereby condoned.
Order on review application
1. Heard learned counsel for the applicant.
2. Instant review application has been filed contending that of
the various grounds on which the writ petition filed by the
petitioner had been dismissed by this Court vide judgment and
order dated 29.03.2022 one of the grounds was that keeping in
view the Government Order dated 14.07.2020 the institution
cannot be taken in grant in aid.
3. The argument while filing the instant review application is
that a coordinate bench of this Court has taken a different view
while considering the Government Order dated 14.07.2020 and
as such it is prayed that keeping in view the subsequent
judgment of this Court interpreting the said Government Order
differently the order of this Court be reviewed.
4. Once admittedly even as per the grounds raised by the
learned counsel for applicant in the review application a
different view of the Government Order dated 14.07.2020 has
been taken vis-a-vis some other judgment which has been
passed by this Court wherein another view has been taken of
the same Government Order the same would not fall within the

purview of there being an error apparent on the face of record.
5. Considering the aforesaid, no case for review is made out.
Accordingly, the review application is dismissed.
