 COMMON JUDGEMENT
Though the challenge is to the order dated 17.09.2021, the
records would indicate that thereafter orders have been passed
on 06.10.2021 and 08.10.2021 which reads as follows
respectively;
https://hcservices.ecourts.gov.in/hcservices/

"For furnishing security L/C memo filed by the
Respondent to furnish security and valuation report.
Memo received. Petitioner counsel submitted that
valuation not correct for the property to be attached.
If any objection to be considered regarding valuation
if petition chosen to have separate valuation they can
form their own recourse for production of the original
sale deed and objection if any Call on 08.10.2021.
Undertaking filed and recorded Call on 08.10.2021"
"For production of Original Sale deed and
objection if any Memo filed in Original Sale deed dated
14.08.1958 Memo received. Objection filed regarding
valuation. Security furnished. Objected by plaintiff
that value is highly stated. All this things can be
seen during trial. Original Document filed. Main suit
only Hence petition stands closed. With liberty to
Plaintiff to value if necessary and security allowed
and in accordance with law."
2. Following the order dated 06.10.2021, the appellants
before this Court had produced the report of their valuer along
with their objections dated 08.10.2021 which the learned Judge
has not taken note of and stated that all of it would be
considered during the trial.
3. The appellants are particularly aggrieved by the above
facts, since according to them the property which has been
offered as security which is 62.21 Cents in Survey No.25/1B1B1
would not be equivalent to the suit claim. The said fact is
refuted by the learned counsel appearing for the respondent who
would submit that the said extent is about 3 Crores in value.
4. The learned I Additional District Judge, Coimbatore
ought to have decided the value of the security that had been
furnished particularly when documents have been filed by the
appellant to show that the value of the property is not what has
been projected. While, the respondent would submit that it is
worth about 3 Crores.
5. In these circumstance, without traversing into the
merits of the appeals the matters are remanded back to the I
Additional District Judge, Coimbatore with the direction to the
I Additional District Judge, Coimbatore shall first test the
value of the property offered as security. Both parties are at
liberty to furnish the documents to show the true value of the
property which has been offered as security.
https://hcservices.ecourts.gov.in/hcservices/

6. With these directions, the appeals are disposed of. It
is needless to state that the property which has been offered
now as a security has not been alienated. No costs.
Consequently, the connected Miscellaneous Petitions are closed.
