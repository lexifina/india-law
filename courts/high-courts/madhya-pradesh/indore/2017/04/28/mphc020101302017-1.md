# High Court of Madhya Pradesh, MCRC/4195/2017, 2017-04-28

.Cr.C. No.4195/2017
28.04.2017
Shri Akhilesh Choudhary, learned counsel for the applicant.
Ms. Mamta Shandilya, learned Public Prosecutor for the non-applicant – State.
Heard.
This is an application under Section 482 of the Cr.P.C. for
amendment in the name of father of the applicant in cause title in the
order dated 12.04.2017 passed in M.Cr.C. No.2687/2017.
It is submitted that due to typographical error in the cause title,
in order dated 12.04.2017, name of father of the applicant has been
mentioned as Aruji Vasunia Bhil whereas, the correct name is Udda
Vasunia and prays that the application be allowed.
On due consideration of the aforesaid, we allow the
application.
Accordingly, in the order dated 12.04.2017, in place of “Aruji
Vasunai Bhil”, it should be read as “Udda Vasunia”. This order
shall be read conjointly with the order dated 12.04.2017 passed in
M.Cr.C. No.2687/2017.
With pthe aforesaid, M.Cr.C. No.4195/2017 is allowed and
stands disposed of.
(P. K. Jaiswal)
 Judge
