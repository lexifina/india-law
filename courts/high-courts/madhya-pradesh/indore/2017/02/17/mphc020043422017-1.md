# High Court of Madhya Pradesh, MCRC/1839/2017, 2017-02-17

M.Cr.C. No. 1839/2017
17.02.2017
Shri Rizwan Nizam, learned counsel for the
petitioner.
Smt. Mamta Shandilya, learned Public Prosecutor.
This is a petition u/s. 482 of the Code of Criminal
Procedure, 1973 (hereinafter, for short, ‘the Code’) for
correction/modification in order dated 10.2.2017 passed by
this Court in M.Cr.C. No.910/2017.
It is submitted that this Court vide order dated
10.2.2017 in M.Cr.C. No.910/2017 was pleased to grant bail
to petitioner-Mohan in connection with Crime No.870/2016,
however, due to typographical error, the “Crime
No.870/2016” has been mentioned instead of “Crime
No.860/2017”. Hence, the same deserves to be corrected.
Learned Public Prosecutor has not disputed the
aforesaid factual position, therefore, this petition is allowed.
The order dated 10.2.2017 is modified to the extent that, in
the first Para of the order “Crime No.870/2016” shall stand
substituted by “Crime No.860/2017”.
Petition stands disposed of accordingly.
( VED PRAKASH SHARMA )
 JUDGE
