# Allahabad High Court, A482/1988/2009, 2023-07-20

Court No. - 86
Case :- APPLICATION U/S 482 No. - 1988 of 2009
Applicant :- Babu Ram
Opposite Party :- State Of U.P.And Another
Counsel for Applicant :- M.B. Mathur,Tripurari Pal
Counsel for Opposite Party :- Govt. Advocate
Hon'ble Rajiv Gupta,J.
Order on Restoration Application No. 1 of 2022:-
1. Heard learned counsel for the applicant, learned AGA
for the State and perused the record.
2. The instant application u/s 482 Cr.P.C. has already
been dismissed in default vide order dated 22.11.2021,
however subsequently, the present restoration application
has been filed.
3. Learned counsel for the applicant has informed this
Court that the sole applicant, Babu Ram has already
expired on 10.07.2023, as such, the instant restoration
application has become infructuous.
4. In view of the above, the present restoration application
is dismissed as having become infructuous.
Order Date :- 20.7.2023
