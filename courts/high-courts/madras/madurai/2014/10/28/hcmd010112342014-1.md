Dindigul District. : Respondent
PRAYER: Petition is filed under Section 482 of the Code of
Criminal Procedure praying to direct the respondent to file final
report in Crime No.70 of 2014 pending on the file of the
respondent within a time frame.
For Petitioner : Mr.D.Venkatesh
For Respondent : Mr.A.P.Balasubramani
 Govt. Advocate (Crl. Side)
O R D E R
This petition has been filed seeking a direction to direct the
respondent to file final report in Crime No.70 of 2014 pending on
the file of the respondent within a time frame.
2. Heard the learned Counsel for the petitioner and the
learned Government Advocate (Crl.Side) appearing for the
respondent.
3. The petitioner has given a complaint which has been
registered in Cr.No.70 of 2014 against the accused and so far no
final report has been filed. Hence, the petitioner is before this
Court.
4. In view of the above, the respondent police is directed to
complete the investigation and file final report within a period
of six months from the date of receipt of a copy of this order.
5. Accordingly, the Criminal Original Petition is disposed of.
