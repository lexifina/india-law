The learned Counsel appearing for the petitioner
submits that so far as the prayer clause-1 in the application is
concerned, the application to that extent is not pressed. So far as
the relief in terms of prayer clause-2 is concerned, he submits
that talks are going on in between the parties and hence, the
application be disposed of granting liberty to the petitioner in the
event if the settlement is not materialized.
In view of this, the application stands disposed of as
infructuous, so far as the prayer clause-1 is concerned. So far as
the prayer clause-2 is concerned, the petitioner is granted liberty
to file fresh application if such occasion arises in future.
