 ORDER
When this bail application came up for consideration, learned
Public Prosecutor submitted that the final report in Crime
No.240/2022 of Vanchiyoor Police Station, Thiruvananthapuram is
already submitted. If that is the case, this bail application need not
be retained.
2. The petitioner can appear before the jurisdictional court,
if any summons is received from the court. If any such summons is
received, the petitioner can surrender before the court below and file
bail application. If such an application is filed, the court below will
consider that bail application in the light of the fact that there was an
interim order from this Court not to arrest the petitioner during the
pendency of bail.
With the above observation, this bail application is closed.
