# High Court of Orissa, WP(C)/3871/2007, 2019-11-07

07. 07.11.2019 Learned counsel for the petitioner seeks
permission to withdraw the writ petition with liberty to file
fresh application if any cause of action still survives.
A memo filed to that effect is taken on record.
 Permission for withdrawal is granted.
 The writ petition stands dismissed as withdrawn.
 All connected Misc.Cases/I.As, if any, are
accordingly disposed of.
 It is open for the petitioner to revive this petition
within 30 days if any cause of action still survives.
