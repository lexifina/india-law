# High Court of Madhya Pradesh, WP/14123/2014, 2015-03-19

WP-14123-2014
(DR. RAMABHILASH DUBE Vs THE STATE OF MADHYA PRADESH)
19-03-2015
Shri R.N. Tiwari, learned counsel for the petitioner.
Shri Vaibhav Tiwari, learned Panel Lawyer for the respondents.
It is contended by learned counsel for the petitioner that by a common order the subsequent order
of the repatriation of the petitioner has been withdrawn, and the present writ petition has
rendered infructuous but only the order of the repatriation, the impugned order is required to be
quashed.
Keeping in view the order dated 12.12.2014, passed by the State Government, the writ petition
stands allowed. The impugned order dated 04.09.2014 stands quashed.
The writ petition stands disposed of.
 (K.K.TRIVEDI)
