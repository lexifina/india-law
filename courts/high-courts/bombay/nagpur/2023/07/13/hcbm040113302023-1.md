1. Heard.
2. The present application is for grant of bail under
Section 439 of the Code of Criminal Procedure, 1973.
3. After hearing the learned counsel for the
applicant to some extent and on perusal of the
investigation papers, this Court has shown
disinclination to allow the present application.
4. Mr A.S. Band, learned counsel for the applicant
seeks permission to withdraw the same with liberty to
file a fresh if the trial is not commenced, and if there is
no substantial progress within one year in the trial.
5. The applicant is permitted to withdraw the
present application with the liberty to file a fresh.
Criminal application is disposed of as
withdrawn.
