# High Court of Madhya Pradesh, MCC/277/2017, 2017-02-17

MCC-277-2017
(NAGAR PALIKA PARISHAD MANDLA Vs THE STATE OF MADHYA PRADESH)
17-02-2017
Shri Mohan Sausarkar, counsel for the applicant.
Shri Ramesh Kushwaha, P.L. for the State.
Heard on I.A. No.1483/2017, an application for condonation of delay.
There is a delay of five days in filing this application.
Looking to the reasons mentioned in the application, I.A. No.1483/2017
is allowed. Delay is condoned.
The present application has been filed for restoration of W.P.
No.12393/2011, which was dismissed on 20.12.2016 for want of
prosecution.
For the reasons mentioned in the application, which is supported by an
affidavit of Mohan Sausarka, the present application is allowed.
W.P. No.12393/2011 is restored to its original number.
Let a copy of this order be kept in the file of W.P. No.12393/2011.
(SMT. ANJULI PALO)
JUDGE
