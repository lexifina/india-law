ORAL ORDER
2 10-05-2012 In this writ application petitioner has challenged the order
dated 03.01.1999, by which his application for compassionate
appointment has been rejected.
Learned Senior Counsel for the petitioner has made an
effort to explain the delay in approaching this Court. However,
this Court is not convinced with the explanation and finds the writ
application suffering from gross delay and laches.
In the circumstances, this writ application is dismissed.
