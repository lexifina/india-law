ORDER
The revision petitioners filed an obstruction petition in the
execution proceedings. The same was dismissed. Questioning the same,
this civil revision petition has been filed.
2. Since an order passed in an application filed under Order 21
Rule 97 of the Code of Civil Procedure is a decree, only an appeal
would lie and not a civil revision petition. The learned Counsel for
the respondents also brought to the notice of this Court that the
execution petition itself has been terminated and the property has
been handed over the the decree holders.
https://hcservices.ecourts.gov.in/hcservices/

2
3. Therefore, this civil revision petition is dismissed as not
maintainable. The only course open to the petitioners is to file an
appeal. No costs. Consequently, connected miscellaneous petition is
closed.
