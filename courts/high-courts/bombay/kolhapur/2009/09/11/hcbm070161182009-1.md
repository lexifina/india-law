. Not on board. Taken on board.
2. On the oral prayer made by the learned counsel appearing for the
applicant, the application is restored.
3. Heard the learned counsel for the applicant. An application for leave to
prefer appeal under sub-section 4 of Section 378 of the Code of Criminal
Procedure, 1973 has been dismissed on merits by this Court by order dated
30th January 2009. The applicant by this application has invoked section 482 of
the Code of Criminal Procedure, 1973 praying for recalling of the judgment and

2
order dated 30th January 2009 on the ground that two specific points which
were raised in the application for leave have not been dealt with by this Court
while passing the order dated 30th January 2009.
4. It is not the case of the applicant that the said points were argued before
this Court and have not been dealt with. The submissions which were made
before the Court have been dealt with. This is not a case where power under
section 482 of the said Code can be invoked for recalling the order dated 30th
January 2009. Hence, application is rejected.
 (A.S.OKA,J)
