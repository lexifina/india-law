HON'BLE MR. JUSTICE PANKAJ BHANDARI
Order
28/05/2021
1. Counsel for the applicant has moved an application under
Section 482 Cr.P.C. seeking correction in the order dated
21.05.2021 passed in S.B. Criminal Miscellaneous Bail Application
No.7690/2021.
2. It is contended by counsel for the applicant that in the order
dated 21.05.2021, in place of “F.I.R. No.43/2018”, “F.I.R.
No.43/2016” has been wrongly typed.
3. I have considered the contentions.
4. Considering the contentions of counsel for the applicant,
application seeking correction in the order dated 21.05.2021, is
allowed.

(2 of 2) [CRLMA-164/2021]
5. In Para No.2 of the order dated 21.05.2021, in place of
“F.I.R. No.43/2016” the same be now read as “F.I.R. No.43/2018.”
6. Counsel for the applicant is directed to file amended cause
title today itself.
7. Office is directed to take the same on record in the main bail
application.
(PANKAJ BHANDARI),J
