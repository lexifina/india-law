1. We have heard learned counsel for the parties.
2. Learned APP, on instructions from the Investigating Officer,
submits that offence punishable under section 307 of the Indian
Penal Code has now been added in connection with the crime.
3. Learned counsel for the petitioner submits that though
offence punishable under section 307 is added, however, offence
punishable under section 452 of the Indian Penal Code is
remained to be added.
4. Learned counsel for the petitioner, however submits that if
