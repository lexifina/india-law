2. Learned counsel for the State prays for time to file reply to the
application for restoration as well as condonation of delay.
3. A perusal of order-sheet reflects that on 13/04/2023, last opportunity
was granted to the respondent to file reply to condonation of delay. Thereafter,
vide order dated 23/06/2023 again time was granted to the respondent to file
reply to the application for condonation of delay with stipulation that if reply is
not filed by the next date of hearing, right to file would stand forfeited. As of
now, no reply has been filed, therefore, as the right to file has already been
forfeited, the prayer is rejected.
4. Learned counsel for the applicant contends that there was defect
which could not be rectified and the said factum was not brought to the notice
to the applicant by his counsel. It is further stated in the application that earlier
also, an application for restoration was filed vide MCC No.543/2015 but the
same was also dismissed and later on restored. It is contended by the counsel
that subsequent MCC No.17/2012 already dismissed as in writ petition an order
dated 20/07/2012 had already been passed and therefore, the MCC had
rendered infructuous. Thus, the knowledge of dismissal of WP No.9262/2008
could only be gathered on 27/09/2016 by the counsel and accordingly, the delay
occasioned in filing of the application is bonafide.
5. Per contra, learned counsel for the State submits that there is no day
to day explanation of delay for condonation of delay.
6. The said application for condonation of delay which has not been
controverted by the respondents by filing any reply during last seven years, the
same is allowed.
