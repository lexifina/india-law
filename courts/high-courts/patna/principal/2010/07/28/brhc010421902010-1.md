# Patna High Court, CR. MISC./27525/2010, 2010-07-28

IN THE HIGH COURT OF JUDICATURE AT PATNA
 Cr.Misc. No.27525 of 2010
 SURESH RAM SON OF LATE HARICHARAN RAM
 Versus
 THE STATE OF BIHAR
 -----------
2. 28.7.2010 By an order dated 5.7.2010 vide
Cr.Misc.No.15357 of 2010 the petitioner was granted bail but
the wrong Presiding Officer’s name was given on account of
the fact that it was wrongly typed in the petition.
This application has been filed by the Counsel
for the petitioner stating therein that correct name of the
Presiding Officer is Sri Namendra Prasad, IInd A.D.J., Buxar.
The order is modified to the extent that the name
of the Presiding Officer be read as “Namendra Prasad, IInd
A.D.J., Buxar”.
Application stands allowed.
Let this order be communicated to the court
concerned through fax at the cost of the petitioner.
Narendra/
( Anjana Prakash, J. )
