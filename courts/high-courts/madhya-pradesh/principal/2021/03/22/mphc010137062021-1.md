# High Court of Madhya Pradesh, MCRC/14995/2021, 2021-03-22

1
HIGH COURT OF MADHYA PRADESH
M.Cr.C. No. 14995/2021
(Satya @ Satyendra Vs. State of Madhya Pradesh)
JABALPUR; Dated: 22.03.2021
Shri Alok Kumar Sharma, learned counsel for the petitioner.
Shri Anand Shukla, learned Panel Lawyer for the State.
This petition under Section 482 of the Code of Criminal Procedure,
1973 has been filed for modification of order dated 1.2.2021 passed in
M.Cr.C No. 53461/2020 to the effect that Crime Number mentioned as
2709/2020 be read as Crime Number 270/2020.
2. On perusal of record it appears that learned counsel for the
petitioner has himself mentioned the Crime Number as 2709/2020 in
M.Cr.C No. 53461/2020.
3. Faced with this situation, learned counsel for the petitioner prays
for withdrawal of the petition with liberty to file a fresh petition with
correct details.
4. Consequently, the petition is dismissed as withdrawn with the said
liberty.
 (Virender Singh)
