# Madras High Court, CRL OP/5093/2015, 2015-03-04

IN THE HIGH COURT OF JUDICATURE AT MADRAS
DATED: 04.03.2015
CORAM:
THE HON'BLE MR.JUSTICE R.S.RAMANATHAN
Crl.O.P.No.5093 of 2015
S.Munusamy ... Petitioner
Vs.
The State of Tamil Nadu,
rep. by the Inspector of Police,
CCB, Chennai-8. ... Respondent
Prayer : Criminal Original Petition filed under Section 482 of the
Code of Criminal Procedure, praying to direct the respondent police
to complete investigate and file the final report in Crime
No.113/2012 on the file of the respondent police within a stipulated
period.
For Petitioner : Mr.D.Senthil Kumar
For Respondent : Mr.M.Maharaja
 Additional Public Prosecutor
ORDER
This petition is filed praying for a direction to the respondent
police to complete investigate and to file a final report in Crime
No.113/2012 on the file of the respondent police, within a stipulated
period.
2.Heard the learned counsel appearing for the petitioner and the
learned Additional Public Prosecutor.
3.Considering the facts and circumstances of this case, this
Court deems it appropriate to direct the respondent police to file
final report in connection with the case in Crime No.113 of 2012 on
or before 31.08.2015.
4.With the above direction, this criminal original petition is
disposed of.
Sd/-
Assistant Registrar
