JUDGMENT
What is impugned in this Original Petition is a
supplementary preliminary judgment in a suit for partition. The
assignee is allotted a share, the propriety of which is impugned
in this Original Petition. The remedy, if any, of the petitioner is
only to file an appeal against the supplementary preliminary
judgment referred to above.
The Original Petition is dismissed without prejudice to the
right of the petitioner to file an appeal, if so advised.
