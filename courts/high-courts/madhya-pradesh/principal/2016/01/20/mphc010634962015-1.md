# High Court of Madhya Pradesh, MCC/3657/2015, 2016-01-20

MCC-3657-2015
(SANJAY CHOUBEY Vs STATE OF MADHYA PRADESH)
20-01-2016
Shri M. Saursarkar, learned counsel for the petitioner.
This application has been filed for restoration of W.A.
No.526/2015 which was dismissed for non-compliance of
the peremptory order on 26.11.2015. There being some
delay, I.A. No.657/2016 has been filed.
Keeping in view the reasons given the application which
is supported by the affidavit of counsel himself and
finding the same to be bonafide, both the applications
are allowed.
Condoning the delay in filing the restoration application,
the restoration application itself is allowed, W.A.
No.526/2015 is restored to its original file. It be placed
for orders before an appropriate Bench.
Both the applications stand allowed and disposed of.
(RAJENDRA MENON)
JUDGE
(SUSHIL KUMAR PALO)
JUDGE
