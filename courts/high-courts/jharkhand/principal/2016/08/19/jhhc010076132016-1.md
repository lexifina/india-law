3/16.6.2016 Show cause has been served on counsel for the petitioner today.
Learned A.A.G for the State seeks permission to file it today. Permission is
allowed.
Learned Advocate General assisted by learned Additional Advocate
General for the State submits that there was some need for clarification in
the interim order passed due to developments which had taken place such
as taking over possession of the leasehold property by the State Authorities
and the Gazette Notification.
However, no Interlocutory Application for clarification of the interim
orders have been filed on behalf of the State. Therefore, there is no need of
any clarification in respect of the interim order passed in the writ petition.
However, on the request of the learned counsel for the State one
more indulgence is granted to file supplementary show cause in the matter
of compliance of the order.
List this case on 5th July, 2016.
(Aparesh Kumar Singh,J)
