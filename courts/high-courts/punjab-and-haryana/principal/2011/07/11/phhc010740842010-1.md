...Respondents

RANJIT SINGH, J.
When this case came up for hearing on 29.11.2010, the
counsel had prayed for time to file an affidavit disclosing the date of
death of Kulwant Kaur duly supported by the death certificate. Ever
since that date, number of requests for adjournment have been
made, but the requirement has not been complied with. The counsel
for the petitioner prays for some more time to comply with the order.
Let him withdraw this writ petition to file a fresh one after
placing on record the death certificate as well as the date of death of
Kulwant Kaur.
Dismissed as withdrawn with liberty to file a fresh one for
the same cause after complying with the directions.
July 11, 2011 ( RANJIT SINGH )
ramesh JUDGE
