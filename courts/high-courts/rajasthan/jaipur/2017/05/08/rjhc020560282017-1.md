HON'BLE MR. JUSTICE MAHESH CHANDRA SHARMA
Order
08/05/2017
 Vide order dated 29.9.2016, the IInd bail application
filed on behalf of the petitioner was dismissed as withdrawn, with
liberty to the petitioner to file a fresh bail application before the
trial court at the appropriate stage of the trial, but instead of filing
the bail application before the trial court, the petitioner has
directly filed this IIIrd bail application before this Court.
At this stage, learned counsel for the petitioner wants
to withdraw this IIIrd bail application with liberty to the petitioner
to file a fresh bail application before the trial court, as ordered
previously by this Court vide order dated 29.9.2016.
In view of above, the IIIrd bail application filed on
behalf of the petitioner stands dismissed as withdrawn, with the
aforesaid liberty.
(MAHESH CHANDRA SHARMA) J.
