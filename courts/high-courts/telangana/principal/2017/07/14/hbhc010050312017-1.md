# High Court for the State of Telangana, CRP/3398/2017, 2017-07-14

HON’BLE SRI JUSTICE V. RAMASUBRAMANIAN
Civil Revision Petition No.3398 of 2017
ORDER:
 Aggrieved by the dismissal of an application filed under Order
XXI Rule 58 of the Code of Civil Procedure, the judgment debtor has
come up with the above revision.
 2. Heard the learned counsel for the petitioner.
 3. It is seen from the impugned order that the application filed
by the petitioner has been dismissed for non-prosecution. Therefore,
the appropriate remedy for the petitioner is first to file an application
for restoration.
 With the above liberty, the Civil Revision Petition is dismissed.
As a sequel thereto, miscellaneous petitions, if any, pending shall
stand closed.

V. RAMASUBRAMANIAN, J
