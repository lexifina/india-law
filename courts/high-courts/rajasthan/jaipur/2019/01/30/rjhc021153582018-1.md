HON'BLE MR. JUSTICE SANJEEV PRAKASH SHARMA
Order
30/01/2019
1. Application has been moved by the petitioner for correction
and modification in the order dated 2.11.2018 passed by this
court in S.B.Civil Writ Petition No.21459/2017.
2. Counsel submits that the petitioner was allowed to withdraw
the writ petition with permission to file fresh but the fact of
permission to file fresh has not been mentioned in the order
dated 2.11.2018 due to inadvertence.
3. Having gone through the application and writ petition, I
deem it appropriate to allow the petitioner to withdraw this writ
petition with liberty to file fresh if needs so arises.
4. Application is accordingly. allowed.
5. The order dated 2.11.2018 stands modified accordingly.
(SANJEEV PRAKASH SHARMA),J
