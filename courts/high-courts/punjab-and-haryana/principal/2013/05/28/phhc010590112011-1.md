RAM CHAND GUPTA, J.(Oral)
The present revision petition has been filed against the order
dated 29.01.2011 vide which charge was framed against petitioner-accused.
None appeared for the petitioner despite second/third call.
It has also been stated by learned counsel for the complainant
that petitioner has only challenged order framing charges against the
petitioner-accused and however, he has not challenged the order vide
which petitioner was ordered to be charged. He has filed certified copy
of the order dated 29.01.2011 which is taken on record.
Dismissed for non-prosecution.
( RAM CHAND GUPTA)
