% 24.04.2025
1. The petitioner has filed the present petition, inter alia, impugning an
order dated 13.01.2025 passed pursuant to the order dated 03.07.2024 passed
by this court in ITA No.721/2023.
2. Since the said order dated 03.07.2024 has been recalled, the impugned
order is required to be set aside.
3. In view of the above, the impugned order dated 13.01.2025 is set aside.
4. The petition is disposed of in the aforesaid terms. The pending
application is also disposed of.
