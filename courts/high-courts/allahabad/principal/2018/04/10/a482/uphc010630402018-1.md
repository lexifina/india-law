# Allahabad High Court, A482/10798/2018, 2018-04-10

Court No. - 63
Case :- APPLICATION U/S 482 No. - 10798 of 2018
Applicant :- Abdullah
Opposite Party :- State Of U.P. And 2 Ors
Counsel for Applicant :- Manoj Kumar Mishra
Counsel for Opposite Party :- G.A.
Hon'ble Amar Singh Chauhan,J.
Learned counsel for the applicant made a request for withdrawal of the
application with liberty to file a revision. It is submitted by learned
counsel for the applicant that the impugned order is revisable as per ratio
laid down by the Full Bench of this Court in the case of Jagannath
Verma Vs. State of U.P., A.I.R. 2014 All 214.
Prayer made is allowed.
Hence, the application stands dismissed as withdrawn with the aforesaid
liberty.
Office is directed to return the Certified copy of the impugned order to the
learned counsel for the applicant after retaining the photo copy of the same
on record.
Order Date :- 10.4.2018
