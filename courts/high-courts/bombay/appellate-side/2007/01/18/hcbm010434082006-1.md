 Mr Denzil D’Mello, for the petitioner.
 CORAM: D.B.BHOSALE,J.
 DATED: 18.01.2007.
 P.C.:
 Heard the learned counsel for the
 petitioner.
 Mr. D’Mello, learned counsel for the
 petitioner, prays for withdrawal of this
 petition with liberty to the petitioner to
 file a fresh application with similar prayer
 as made in the application dated 4.11.2006
 if he cannot find the address of the
 respondent-tenant. The writ petition is
 allowed to be withdrawn with liberty as
 prayed for. If an occasion arises for the
 petitioner to file a fresh application with
 a similar prayer, he should mention in the
 application in detail as to what efforts he
 made to find the address of the
 respondent-tenant. The court below, after
 having satisfied, may consider to pass an
 order of the substitute service. With this
 observation, this writ petition is disposed
 of.
 (D.B.BHOSALE,J.)
