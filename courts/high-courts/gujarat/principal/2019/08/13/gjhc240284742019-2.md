ORAL ORDER
Considering the fact that charge-sheet is already
filed, the applicant is directed to avail remedy of filing
discharge application. The applicant is also at liberty to file
appropriate proceedings either u/s 397 or 482 of the Code of
Criminal Procedure, 1973 before appropriate competent Court,
after remedy to file discharge application is availed.
In view of above, present application stands
disposed of. It is clarified that this Court has not examined the
merits of the present application.
(S.H.VORA, J)
