HON'BLE MR. JUSTICE P.K. LOHRA
Order
08/02/2018
 Matter comes up on an application for reconstitution of the
file of S.B. Criminal Misc. Petition No.4081/2017, which is reported
to be misplaced in the Office on 01.02.2018.
On 01.02.2018, Registry was directed to furnish detailed
report in the matter.
As per report, despite issuance of search-slip and making
extensive search, the file has not been traced out. Probably, the
file has not returned back to the Section and lost while in transit.
In this view of the matter, the application for reconstitution
of file for the aforesaid case is allowed.
Office to proceed.
(P.K. LOHRA)J.
