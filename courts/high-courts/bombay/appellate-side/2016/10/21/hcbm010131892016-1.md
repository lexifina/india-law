P.C. :
1. Heard Mr.J.M. Chitale, learned Counsel for applicant
and Mr.Sapkal, learned Counsel for respondents.
2. This is an application for recalling order dated
28/03/2016 passed by this Court. Mr.Chitale submitted that by
order dated 28/03/2016, Civil Revision Application No.262/07
was dismissed for default as none appeared for the parties.
3. Mr.Chitale submitted that Civil Application No.627/16
was filed on 17/02/2016 which was in time. In view thereof, the

Nesarikar 2 / 2 1-CA-506-16-IN-CRA-262-07.odt
Registry should have allowed that application without placing it
before the Court. Instead of doing that, the Registry placed it
before the Court and in the process the Civil Revision Application
was dismissed in default.
4. On 28/03/2016, none appeared for the applicant. It is
material to note that even none appeared for respondents as well
on 28/03/2016. For the reasons stated in application, Civil
Application is allowed in terms of prayer clause (a) with no order
as to costs. Civil Revision Application is restored to the its original
position.
(R. G. KETKAR, J.)
