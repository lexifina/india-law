5. 16.9.2011 Heard learned counsel for the petitioners and the
State.
A show cause has been filed on behalf of the State
stating therein that the order of this Court has been complied with and
necessary payments have been made. With respect to petitioner no.4, it
is stated that for want of any detail, no claim could be entertained.
Learned counsel appearing for the petitioners prays
for time to file reply.
This Court is not inclined to grant time and as such,
prayer is rejected.
Considering the show cause, since the order of this
Court has been complied with, this contempt application need not
proceed further. The same stands disposed of.
 PNM (Shailesh Kumar Sinha,J.)
