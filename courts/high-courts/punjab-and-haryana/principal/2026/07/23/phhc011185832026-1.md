1. By this common order, 18 appeals, the details of which have
been given in the heading, are being disposed of as all these appeals involve
the same question of law on similar facts.
2. Learned counsel for the appellants-State submits that without
there being any prayer for setting aside the policy dated 07.10.2010, the
same has been set aside which is beyond the jurisdiction of the learned
Single Judge hence, the present appeals may kindly be disposed of having
been not pressed any further with liberty to file a review application before
the learned Single Judge and in case need arises to file fresh appeal.
3. Ordered accordingly.
4. Civil miscellaneous application pending if any, also stands
disposed of.
