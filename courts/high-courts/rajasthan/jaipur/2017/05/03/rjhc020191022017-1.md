HON'BLE MR. JUSTICE MOHAMMAD RAFIQ
Order
03/05/2017
 This application has been filed for modification of order dated
01.10.2014 passed in Writ Petition No.8499/2014 and seeking further time to
file representation before the authorities. The application itself has been filed
after two-and-a-half-year of the order, whereas representation was ordered to
be decided within six weeks. At this, learned counsel prayed for permission to
file a fresh writ petition by not pressing the present application.
The application is disposed off with that liberty subject to law.
(MOHAMMAD RAFIQ) J.
