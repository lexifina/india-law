CORAM: HON’BLE MR. JUSTICE SANJEEV KUMAR, JUDGE
ORDER
This is an application filed by the applicant for condoning the delay in
filing application for restoration seeking restoration of CIMA No.222/2008
along with Condl(C) No.152/2008, which was dismissed in default of
appearance and for non-prosecution by this Court on 18.12.2012.
 Admittedly, there is delay of 879 days in filing the application seeking
restoration of the appeal alongwith application for condonation of delay in
filing the appeal.
 Learned counsel for respondent No.1 submits that he has no serious
objections in condoning the delay, if the main appeal, which is pending in
this Court since 2008, itself is taken up for consideration.
 Accordingly, this application is allowed. Delay in filing the
application seeking restoration of the appeal along with condonation of
delay application is condoned.
 Registry to diarize the restoration application and list the same today
itself.

 (Sanjeev Kumar)
