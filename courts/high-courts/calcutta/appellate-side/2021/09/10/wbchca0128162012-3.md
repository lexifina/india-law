# Calcutta High Court, CRR/848/2012, 2021-09-10

45
 10-09-2021
 ct. no.34
 debajyoti
 CRR 848 of 2012
In re: An application under Section 401 read with Section
482 of the Code of Criminal Procedure.
 - And -
 In the matter of: Kartick Sarkar
 … Petitioner.
Mr. Sudip Ghosh Chowdhury
 … For the Petitioner.
Mr. Anwar Hossain
 … For the State.
The present revisional application was preferred at a
stage when the investigation of the case is under progress.
Mr. Anwar Hossain, learned advocate for the State, has
submitted a status report which reflect that charge-sheet
no.532 of 2020 dated 31-10-2020 under Sections 420/406 of
the Indian Penal Code has been submitted in connection with
Titagarh Police Station Case No.459 of 2011 dated 29-08-
2011.
Let the report be kept with the record.
Having regard to the change of circumstances, I am of
the view that CRR 848 of 2012 is not maintainable any
further and as such, the same is dismissed. Pending
application, if any, is consequently disposed of. Interim
order, if any, stands vacated.
All parties shall act on the server copies of this order
duly downloaded from the official website of this Court.
 ( Tirthankar Ghosh, J. )
