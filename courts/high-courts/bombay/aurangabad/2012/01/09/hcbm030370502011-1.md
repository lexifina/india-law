. Rule. Rule returnable forthwith. With the consent of

3. The present respondents have filed suit for declaration
regarding mutation entries. The present petitioner was served
with suit summons on 25th April, 2011 and filed an application
seeking time to file written statement. The said application was
allowed. Thereafter, on 04.07.2011 the petitioner filed an
application seeking time to file written statement. Said
application is rejected and the Trial Court passed an order of no
written statement against the present petitioner. Thereafter, on
28.07.2011 the petitioner did not file any application and on
25.08.2011 the petitioner filed an application for setting aside no
written statement order along with written statement. The said
application is rejected. Aggrieved thereby present petition is
filed.
4. Shri Rudrawar, the learned counsel for respondents
opposes the petition and submits that on two occasions different

3 wp 9117.11
reasons were given by the petitioner and on 28.07.2011 no
application was filed. Reason mentioned in an application for
setting aside no written statement order is altogether different
than the earlier applications. This shows the petitioner has not
approached with clean hands. The petitioner is misleading the
Court. The petitioner is supposed to file the written statement
within a period of 30 days as per Order VIII Rule 1 of the Code of
Civil Procedure. The Trial Court has rightly rejected the
application.
5. It would appear that after the appearance within four
months the petitioner has filed written statement. The delay is
not abnormal one. The petitioner is an authority under the
statute. The reason given by the petitioner is that because of the
meetings he could not file the written statement. I am inclined
to afford one opportunity to the petitioner. At the same time, the
petitioner deserves to be mulct with the cost. In the result I pass
the following order.
O R D E R
A. The writ petition is allowed.
B. The impugned order is quashed and set aside and the
