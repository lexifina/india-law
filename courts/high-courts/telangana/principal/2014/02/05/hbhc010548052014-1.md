# High Court for the State of Telangana, CRLP/1035/2014, 2014-02-05

THE HON’BLE SRI JUSTICE C.PRAVEEN KUMAR
Crl.P.No.1035/2014
ORAL ORDER:
The learned counsel for the petitioners seeks permission of the
court to withdraw the criminal petition with liberty to file an application for
quashment of the proceedings in case police file a charge sheet.
Permission is accorded.
The Criminal Petition is accordingly dismissed giving liberty to file
an application for quashment of the proceedings in case police file a charge
sheet against the petitioners. Miscellaneous petitions, if any, shall stand closed.
-----------------------------------
C. PRAVEEN KUMAR, J.
