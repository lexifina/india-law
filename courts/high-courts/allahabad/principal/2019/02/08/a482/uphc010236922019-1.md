# Allahabad High Court, A482/4482/2019, 2019-02-08

Court No. - 72
Case :- APPLICATION U/S 482 No. - 4482 of 2019
Applicant :- Lalman Singh
Opposite Party :- State Of Up And Another
Counsel for Applicant :- Pramod Kumar Srivastava,Manoj
Kumar Srivastava
Counsel for Opposite Party :- G.A.
Hon'ble Ajit Kumar,J.
Learned counsel for the applicant at the very outset submits that
the order dated 18.10.2018 which is impugned in this petition is
not cognizable by this Bench as it is an administrative order
against which their lies a remedy of a writ petition. He,
therefore, prays for dismissal of present application as
withdrawn with liberty to file an appropriate writ petition.
This 482 Cr.P.C. petition is accordingly dismissed as
withdrawn with aforesaid liberty.
Order Date :- 8.2.2019
