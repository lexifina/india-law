# Allahabad High Court, WRIC/37896/2018, 2018-11-27

Court No. - 7
Case :- WRIT - C No. - 37896 of 2018
Petitioner :- Manoj Kumar Yadav
Respondent :- State Of U.P. And 03 Others
Counsel for Petitioner :- Bhola Nath Yadav
Counsel for Respondent :- C.S.C.
Hon'ble Saumitra Dayal Singh,J.
1. Supplementary affidavit filed today is taken on record.
2. Present writ petition has been filed against the order dated
18.12.2013 passed by the District Magistrate, Allahabad, by
which the petitioner's application for grant of firm arm licence
has been rejected.
3. Though, it has been stated that the petitioner did not file any
appeal against that order, however, in view of the fact that
almost 5 years have passed since the impugned order came into
existence, no interference is warranted in the present writ
petition.
4. At the same time, it is left open to the petitioner to file a fresh
application for grant of arms licence in accordance with law,
which application may be decided on its own merits without
being influenced by the fact that the petitioner's earlier
application had been rejected or that the petitioner had not
challenged that order within time.
5. Petition is accordingly disposed of.
Order Date :- 27.11.2018
