# High Court of Orissa, CMP/1673/2015, 2018-02-07

C.M.P. No.1673 of 2015
07.02.2018
 Heard Shri N.K. Sahu, learned counsel appearing for the petitioners.
 The order impugned herein is an order pursuant to entertaining an application
under Order-39, Rule-2(A) of the Code of Civil Procedure. Since the impugned order is appellab
le, this Court finds, the Civil Miscellaneous Petition is not maintainable at this stage. Howe
ver, considering the request of Shri Sahu, learned counsel appearing for the petitioners that
there has been several applications pending with the trial court including an application unde
r Order-39, Rule-2(A) of C.P.C. which may be directed to be disposed of within a stipulated pe
riod, this Court directs, in the event the applications are ready for hearing and the objectio
ns to the applications are already filed, the pending applications should be disposed of withi
n a period of three weeks from the date of communication / production of the certified copy of
 this order.
 The Civil Miscellaneous petition stands disposed of with the aforesaid directi
on only.

 ..
 Biswanath Rath, J.
