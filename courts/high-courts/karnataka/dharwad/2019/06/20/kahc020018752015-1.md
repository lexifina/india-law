ORDER
The impugned order dated 07.03.2015 at
Annexure-H passed in E.P.No.10/2004 is one under Order
XXI Rule 97 CPC which is an appealable order. Hence,
without expressing any opinion on merits, this petition
stands dismissed as not maintainable.
2. It is also made clear that petitioner would be at
liberty to file an appeal, if so advised and the issue
regarding limitation is kept open. The fact that petitioner
(decree holder) was pursuing his grievance before this
Court would be taken note of while considering the
application filed for condonation of delay in the appeal as
also objections, if any, filed by the judgment debtor to
such application.
