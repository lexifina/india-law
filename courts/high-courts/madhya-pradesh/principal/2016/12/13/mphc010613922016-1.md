# High Court of Madhya Pradesh, WA/897/2016, 2016-12-13

WA-897-2016
(J.P. KALHEKAR Vs PRINCIPAL SECRETARY GOVT OF MP HORTICULTURE AND
FOODPROCESSING DEPTT.)
13-12-2016
Shri Shekhar Sharma for the appellant.
Shri Amit Seth, Government Advocate, for the State on
advance notice.
Learned counsel raises a ground which does not find place
in the order passed by the learned writ Court. Therefore,when this
Court confronted learned counsel for the appellant with a querry
as to whether such a ground was canvassed before the learned
writ Court, learned counsel states that it was canvassed.
If that be so, appellant/petitioner should file an application
for review and reconsideration before the learned writ Court.
Shri Shekhar Sharma, learned counsel for the appellant,
seeks permission to withdraw this writ appeal with liberty to file
a review application.
Permission granted.
Accordingly, with the aforesaid liberty, the writ appeal
stands dismissed as withdrawn.
CC as per rules.
(RAJENDRA MENON)
ACTING CHIEF JUSTICE
