Order

Present restoration application No.144/2023 has been filed
for recalling of the order dated 15.11.2022 wherein restoration
application No.830/2015 was dismissed.
For the reasons mentioned in the application for restoration
and upon hearing the learned counsel for the petitioner, the
application for restoration is hereby allowed. Order dated
15.11.2022 is hereby recalled.
 The restoration application No.830/2015 be restored to its
original number.
 Registry to proceed.
