 ORDER
 (27.05.2019)

This petition has been filed by the petitioner for seeking
quashment of order dated 01.10.2015 passed by JMFC in Criminal
Case No. 1580/2015, whereby the learned Magistrate ordered to
register the case against the petitioner for the offence punishable
under Section 120 B of IPC.
2. Since, this Court has already passed a common order in
connected M.Cr.C. No. 167/16 while considering the facts of this and
also arguments of the learned counsel for the petitioner. This Court
has given the findings that the order dated 01.10.2015 is not
sustainable and same is set aside, therefore, there is no need to pass
any separate order in this case.

 2
 M.Cr.C. No. 2471/2016
3. Accordingly, this petition is allowed in terms of common
order passed in connected M.Cr.C. No. 167/16.
4. Office is directed to keep the copy of order passed in
M.Cr.C. No. 167/16 in this file also.
