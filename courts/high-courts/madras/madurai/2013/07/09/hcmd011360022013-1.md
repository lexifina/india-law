the file pending in Cr.No.477 of 2012 from the file of the second
respondent and transfer the same to the file of the third respondent
for further investigation.

filed and whether it has been taken on file.

Magistrate, D10880evakottai, shows that already charge sheet has been

https://hcservices.ecourts.gov.in/hcservices/
