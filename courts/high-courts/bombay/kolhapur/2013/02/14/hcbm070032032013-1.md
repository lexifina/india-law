P.C.:-
1. Notice for final disposal was issued on 31st January, 2013.
The prayer is for quashing the offence registered under Section
420 r/w. Section 34 of the Indian Penal Code. The learned
counsel appearing for the applicants states that there is a
settlement between the applicants and the second respondent.
The second respondent has confirmed that there is a settlement.
Infact, in the Court a Demand Draft in the sum of Rs. 7 lacs has
been handed over by the Advocate for the petitioner to the
Advocate for the second respondent which has been drawn in
the name of the second respondent. In the affidavit tendered
today, the second respondent has reiterated that there is a

2/2 41-APL.88.2013.doc
settlement and the second respondent has no objection for
quashing the offence.
2. Perusal of the First Information Report shows that the
dispute is about the transfer of immovable property. Moreover,
the offence is registered only under Section 420 of the Code of
Criminal Procedure, 1973. The dispute appears to be
predominately a civil dispute. Moreover, there is a complete
settlement, which is reflected from the affidavit tendered by the
second respondent. The second respondent is personally
present in the Court.
3. Therefore, this is a fit case where the power under Section
482 of the Code of Criminal Procedure, 1973 for quashing the
offence should be exercised. Accordingly, we pass the following
order :
ORDER
i) Rule is made absolute by directing that C.R. No.
200/2012 registered with the Karveer Police Station,
Kolhapur stands quashed and set aside ;
ii) All concerned to act upon an authenticated copy of
this order.
 (A.P. BHANGALE, J.) (A.S.OKA, J.)
