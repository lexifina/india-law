# Calcutta High Court, CRR/1643/2021, 2023-05-03

D/L47
03.05.2023
Bpg.
C.R.R. No.1643 of 2021
In Re: An application under Section 407 read with Section 482 of the
Code of Criminal Procedure, 1973 (as amended);
 Smt. Shreyashee Basu Roy Chowdhury (Mandal)
 Versus
 Sri Kinjal Basu Roy Chowdhury and another
Ms. Rituparna Ghosh.
 …for the petitioner.
Mr. Arijit Ganguly,
 Ms. Sujata Das.
 …for the State.

Status report filed by the State be kept with the record.
Report reflects that a show cause has been issued by the
jurisdictional court.
I find that the revisional application was preferred by the
petitioner for transferring the case from the court of learned ACJM,
Haldia, Purba Medinipur to any court within the jurisdiction of the
learned District Judge, Alipore. As the present case is not pursued
before the learned ACJM, Haldia, Purba Medinipur, show cause has
been issued.
Petitioner is granted liberty if she intends to file afresh
before the court at Alipore to withdraw Misc. Case No.115 of 2020
from the court of learned ACJM, Haldia, Purba Medinipur and file
afresh before any court within the jurisdiction of the learned
District Judge, Alipore.
With the aforesaid observations, CRR 1643 of 2021 is
disposed of.

2
Pending application, if any, is consequently disposed of.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
 (Tirthankar Ghosh, J.)
