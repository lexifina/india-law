# Allahabad High Court, A482/9173/2019, 2019-03-11

Court No. - 73
Case :- APPLICATION U/S 482 No. - 9173 of 2019
Applicant :- Babu Ram Kushwaha
Opposite Party :- State Of U.P. And 2 Others
Counsel for Applicant :- Gaurav Singh Tomar,Subhash Gosain
Counsel for Opposite Party :- G.A.
Hon'ble Neeraj Tiwari,J.
Heard learned counsel for the applicant and learned A.G.A. for
the State.
Learned A.G.A. raised preliminary objection that the present
application is not maintainable against ex-parte order as
applicant have remedy to file recall application under 126(2)
Cr.P.C.
At this stage, learned counsel for the applicant submitted that he
does not want to press this application and the same may be
dismissed as not pressed with liberty to file an application under
Section 126 (2) Cr.P.C. and direction may be issued to decide
the same within a fix time.
Accordingly, the application is dismissed as not pressed with
the observation that, if any, application is filed under Section
126 (2) Cr.P.C. the court below shall decide the same
expeditiously, strictly in accordance with law.
Order Date :- 11.3.2019
