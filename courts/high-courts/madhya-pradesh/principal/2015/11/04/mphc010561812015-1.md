# High Court of Madhya Pradesh, MCC/3259/2015, 2015-11-04

MCC NO.3259/2015
04-11-2015
Shri Vijay Shrivastava, learned counsel for the applicant.
This application has been filed for restoration of W.A.No.570/2015,
which has been dismissed for want of prosecution.
Keeping in view the reasons indicated in this application for
restoration and finding the same to be bonafide, the application for
restoration is allowed. W.A.No.570/2015 is restored to its original file. It be
placed for orders before an appropriate Bench.
Application stands allowed and disposed of.

 (RAJENDRA MENON) (K.K.TRIVEDI)
 JUDGE JUDGE
