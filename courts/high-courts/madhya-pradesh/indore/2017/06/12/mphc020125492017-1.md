# High Court of Madhya Pradesh, MCRC/5258/2017, 2017-06-12

MCRC-5258-2017
(FAISAL MASAUD Vs THE STATE OF MADHYA PRADESH)
12-06-2017
Shri A.R. Khan, learned counsel for the applicant.
Shri Rohit Mangal, learned counsel for the
respondent/State.
This is repeat (second) bail application filed by the
applicant under Section 439 of the Code of Criminal
Procedure for grant of bail.
First application was dismissed on merit. This second
application is filed on the ground that the parties have
entered into compromise.
After hearing both the sides, I find that there is no change
in the circumstances and no case is made out for
consideration of this second bail application. This second
application (M.Cr.C. No.5258/2017) is accordingly
dismissed.
Certified copy as per rules.
(ALOK VERMA)
JUDGE
