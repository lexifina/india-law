# High Court of Orissa, WP(C)/13761/2018, 2019-01-08

05. 08.01.2019 Heard learned counsel for the petitioners.
 It is stated by learned counsel for the petitioners that
the relief sought for in the writ application has already been
granted to the petitioner. Hence, nothing remains to be
adjudicated in this writ application and the same has
become infructuous.
 Accordingly the writ application is dismissed as
infructuous.
 All connected Misc. Cases/I.As, if any are
accordingly disposed of.
