1. Learned Counsel for the Applicant seeks permission to withdraw the
Bail Application as he has already got the Interim Bail from the learned
Trial Court.
2. Learned Prosecutor submits that there is material concealment by the
Applicant while the present Bail Application was pending without disclosing
about the Interim Bail Application which was filed before the learned Trial
Court in August, 2025, which got allowed despite the pendency of the
present Bail Application.
3. Moreover, further extensions have also been taken vide Order dated
31.10.2025, again without disclosing the pendency of the present Bail
Application.
4. Be at it may, the present Bail Application alongwith pending
Application, is permitted to be withdrawn.
