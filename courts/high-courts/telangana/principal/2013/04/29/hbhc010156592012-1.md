# High Court for the State of Telangana, TRCRLP/153/2012, 2013-04-29

HON'BLE SRI JUSTICE B.SESHASAYANA REDDY
Transfer Criminal Petition No.153 of 2012
ORDER:-
This petition has been taken out under Section 407 of Cr.P.C. by
the de facto complainant in C.C.No.43 of 2011 on the file of the
Additional Judicial First Class Magistrate, Anantapur to transfer the
said Calender Case to the file of the Judicial First Class Magistrate,
Dhone.
Both the parties consented for transfer of C.C.No.43 of 2011 on
the file of the Additional Judicial First Class Magistrate, Anantapur to
the file of the Judicial First Class Magistrate, Gooty.
In that view of the matter, the Tr.Crl.P. is allowed transferring
C.C.No.43 of 2011 on the file of the Additional Judicial First Class
Magistrate, Anantapur to the file of the Judicial First Class Magistrate,
Gooty. As sequel to it, Miscellaneous Petitions, if any pending, shall
stand dismissed.
