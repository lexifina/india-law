2. 19.11.08. Vide order dated 30. 4. 2008, prayer for anticipatory bail of the
petitioner was rejected by this Court. The petitioner has filed yet another
anticipatory bail application submitting that no case is made out against the
petitioner. If that is so, the petitioner may file a quashing application or
Criminal Writ, B if so advised.
The Court is not inclined to entertain second anticipatory bail
application in view of earlier rejection.
Accordingly this anticipatory bail application is dismissed.
 m.p. (Ajay Kumar Tripathi, J)
