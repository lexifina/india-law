Heard.
2] Vide order dated 27th August, 2013, four weeks’
time was given for taking steps and it was directed
that, in case of failure, the application shall stand
dismissed. The steps were not taken within time and
the application stood dismissed. Subsequently, steps
were sought to be taken, but, in the meantime, the
application was already disposed of.
3] In view of the reasons mentioned in the
application, the order 27th August, 2013 deserves to be
set aside. The same is, accordingly, set aside. Civil
Application No.2182 of 2013 is restored to file.
Delay stands condoned, as prayed for.

 2
4] Issue notice to the proposed respondents (legal
representatives of respondent nos.1/2 and 2),
returnable 28th March, 2014.
