 DATE : 23rd November 2009
PER COURT
1. This is an application filed by the State seeking condonation
of delay of 25 days in filing an application seeking leave to file appeal.
The Division Bench of this Court by its order dated 6.10.2009 issued Rule
in this criminal application making it returnable on 23.11.2009. This is
how this application seeking condonation of delay is listed before us.
2. We have heard learned Additional Public Prosecutor for the
applicant and Shri C.K.Shinde, learned Counsel for the respondents and
for the reasons stated in the application, application is allowed and delay
is condoned. Since Rule has been issued in this application, we make
Rule absolute.
