J U D G M E N T
Defendants are the petitioners. The suit was tried
and adjourned for judgment 08.07.2015. On 04.07.2015
the learned Munsiff suo motu set aside the commission
report, and the plan attached to it and directed that the
plaintiff may file a fresh commission application he is so
advised. Mainly this order is challenged in this O.P.
2. Heard the learned counsel for the petitioners.
3. A copy of the proceedings sheet was called for.
I have perused the proceedings sheet. The case was
posted for judgment to 08.07.2015. Without giving any
notice to any of the parties the learned Munsiff advanced
the posting of the case to 04.07.2015 and passed the
following order:-
“On going through the case file I strongly feel that
the commission report and plan marked in this
case is not good for deciding the present suit. The
plaintiff already filed a petition. I.A.1926/14 on
27.06.2014 to set aside the report and plan. The
commission report and plan are set aside. The
plaintiff if he want, can file a fresh Commission
Application for ascertaining the necessary facts
with the help of surveyor. Since the present case

O.P.(C)NO.1728 of 2015 2
is a very old one, he shall file such application if
any within 3 days. Call on 8.7.15”.
4. It was not proper for the learned Munsiff to
take up the case on 04.07.2015 without issuing notice to
any of the parties and to pass the order. It is seen from
the impugned order that it is the 'feeling' of the learned
Munsiff that the commission report will not help the court
to take a proper decision that is the basis for passing the
impugned order. In fact, he has not mentioned the
reasons for setting aside the commission report and the
plan. He should have passed a speaking order. A report
and the plan cannot be set aside at his sweet will. The
impugned order is liable to be set aside.
In the result, this O.P is allowed. The order passed
by the learned Munsiff on 04.07.2015 setting aside the
report and the plan is set aside. The learned Munsiff is
directed to pass a speaking order after hearing both sides.
