O R D E R
This criminal original petition has been filed to quash the
F.I.R. in Crime No.38 of 2017 on the file of the first respondent
police.
2. When the matter was taken up for hearing today, the learned
Additional Public Prosecutor on instructions would submit that
already investigation over and the final report is also ready and in
view of the interim order passed by this Court, the first respondent
is not in a position to file a final report.
3. The learned counsel appearing for the petitioner seeks

already over, the first respondent is directed to file a final

copy of this order. Consequently, the connected Miscellaneous
Petitions are closed.
