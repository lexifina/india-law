Heard the learned counsel appearing for the parties. This
application is pending from March 2000 and till today there is no
ad-interim relief granted on this application. The learned counsel
appearing for the applicant states that the applicant is still in
possession. Thus, it is obvious that there is no apprehension as of
today that the applicant will be dispossessed. Hence, this
application is not entertained and the same is rejected. If cause of
