Order
03/05/2019
This Court vide order dated 09.01.2019 admitted the
appeal but did not pass any interim order on stay application,
therefore, stay application has been listed today for appropriate
orders.
According to learned counsel for the appellant-applicant
total demand would be approximately Rs. 23,00,000/-.
In the facts of the case, we see no reason to pass any
interim order staying such demand. However, it is observed that the
recovery if any made, would be subject to final outcome of the
appeal.
Stay application stands disposed of with the aforesaid
observation.
Name of Mr. Anurag Kalawatia, learned counsel be shown
in the Cause List as counsel for the respondent.
