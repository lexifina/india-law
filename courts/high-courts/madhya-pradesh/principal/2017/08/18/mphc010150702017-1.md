# High Court of Madhya Pradesh, WP/4581/2017, 2017-08-18

WP-4581-2017
(RAM PRASAD PRAJAPATI Vs THE STATE OF MADHYA PRADESH)
18-08-2017
Shri G.S. Baghel, learned counsel for the petitioners.
Shri G.P. Singh, learned Government Advocate for the
respondents/State.
Heard.
This Court has already decided the petition finally on
27.03.2017 itself. So far as the petition is concerned, the
same is kept alive for the reason as already observed in the
order dated 27.03.2017.
Since the Government has already complied with the
order passed by this Court, nothing survives to be decided in
this petition.
Accordingly, the petition stands disposed of.
C.C. as per rules.
