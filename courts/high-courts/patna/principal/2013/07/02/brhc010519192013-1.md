ORAL ORDER
2 02-07-2013 Heard learned counsel for the petitioner and learned
counsel for the State.
 This application has been filed for quashing the
order dated 3.4.2013 passed by the District and Sessions
Judge, Siwan in Criminal Revision No.76 of 2013 by which
the court below has affirmed the order dated 21.2.2013 passed
by the Sub Divisional Magistrate, Siwan in Misc. Case
No.3552 of 2012 by which he has converted the proceeding
under section 144 of the Code of Criminal
Procedure(hereinafter referred to as ‘the Code’) to 145 of the
Code.
 Learned counsel for the petitioner submits that
earlier there was proceeding under Section 144 of the Code

Patna High Court Cr.Misc. No.18727 of 2013 (2) dt.02-07-2013
 2
and the Sub Divisional Magistrate, Siwan vide order dated
19.9.2012 has passed the order in favour of petitioner and
there is no occasion for the Magistrate to again initiate
proceeding under section 144 of the Code and convert the
same into 145 of the Code. Section 144 of the Code primarily
meant to maintain peace whereas Section 145 of the Code
decides the possession of the party. There is no res-judicata in
re-initiating proceeding under Section 144 of the Code as
apprehension of breach of peace can erupt subsequent to
closure of first proceeding.
 In this case on the basis of the police report proceeding
under section 144 of the Code was initiated and the same has
been converted into 145 of the Code as it was found that there
was bonafide land dispute and there was apprehension of
breach of peace and which has been affirmed by the District
Judge.
 This Court does not find any merit in this application.
It is accordingly dismissed.
Vinay/- (Shivaji Pandey, J)
