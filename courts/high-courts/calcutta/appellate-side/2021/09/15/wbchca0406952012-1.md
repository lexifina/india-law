# Calcutta High Court, CRR/2693/2012, 2021-09-15

15.09.2021
 item No.47
 n.b.
 ct. no. 34
CRR 2693 of 2012
(via video conference)
Partha Sarathi Kusmete
-Vs-
 The State of West Bengal
The revisional application was preferred challenging the
order dated 22.6.2012 passed by the Learned Executive Magistrate
Katwa in connection with M.P. Case No.443 of 2012 under Section
144(2) of the Code of Criminal Procedure.
In view of the time constraints provided under the
provisions relating to section 144(2) of the Code of Criminal
Procedure, I am of the view, that the main proceedings have
become infructuous.
Accordingly, CRR 2693 of 2012 is dismissed
Interim order, if any, is hereby vacated.
All pending connected applications, if any, are
consequently disposed of.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Hon’ble Court.
( Tirthankar Ghosh, J.)
