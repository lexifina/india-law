# Madras High Court, A/5763/2023, 2023-11-27

A.No.5763 of 2023
in
CS.No.808 of 2013
A.A.NAKKIRAN, J.
This application has been filed to condone the delay of 3485 days in
filing the written statement.
2. Heard both sides.
3. Though the learned counsel for the respondents has strongly opposed to allow
this application, being satisfied with the reasons stated in the affidavit filed in support
of this application, this court is inclined to allow this application on payment of cost of
Rs.4,000/- (Rupees Four Thousand Only) to the learned counsel for the respondents on
or before 07.12.2023.
4. Accordingly, this application is allowed.
5. Post the main case before this court on 08.12.2023.
