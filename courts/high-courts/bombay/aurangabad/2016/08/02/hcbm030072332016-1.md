CORAM : T.V. NALAWADE, J.
DATED : 2nd August, 2016.
ORDER :
1. The application is filed for setting aside the order
made by the learned Registrar Judicial by which registration is
refused for non compliance of office objections. The learned
counsel for applicant is taking blame to himself. In view of the
submissions made and contentions of the application, this Court
holds that application needs to be allowed and the delay, if any,
needs to be condoned.
2. So, the application is allowed. Delay, if any, is
condoned. The order of learned Registrar Judicial is hereby set
aside. If office objections are not removed prior to 12.8.2016, it
is to be presumed that the present application is dismissed.
 [ T.V. NALAWADE, J. ]
