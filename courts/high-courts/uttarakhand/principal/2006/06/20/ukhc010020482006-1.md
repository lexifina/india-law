# High Court of Uttarakhand, BA1/511/2006, 2006-06-20

BA 511/06
(Recall Appl. No. 958/06)
Hon’ble J.C.S. Rawat, J.
Recall Application No. 958/06 has
been filed by Sri Vinod Sharma learned
counsel for the applicant with the prayer
to recall the order dt. 16-06-06. by which
the bail application No-511/06 was
dismissed in default.
Since the recall application has
been filed against the order dt 16.06.06
by which bail was dismissed in default,
hence the recall application is
misconceived. Therefore, the recall
application is rejected as misconceived.
 (J.C.S. Rawat, J.)
Dt. 20-06-2006
