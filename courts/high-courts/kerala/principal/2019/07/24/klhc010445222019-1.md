JUDGMENT
V.Chitambaresh, J
It appears that the petitioners attempted a review of the
order in O.A.No.2212 of 2017 impugned herein. RA.No.23/19
so filed was dismissed by order dated 03.07.2019, it reads
thus:
“The connected Review Applications against the common
order stand dismissed by order dated 8
th
 November, 2018.
The above order will govern these Review Applications as
well. The Review Application are accordingly dismissed.”
2. However, the order dismissing the review
application is not seen impugned.
3. Connected review applications against the common
order was also dismissed by the Tribunal by order dated
08.11.2018. The challenge to the same in separate Original
Petitions was also negatived by this Court. There is no point
in entertaining this Original Petition when the common order

OP(KAT).No.286 of 2019
3
impugned stands affirmed by this Court.
The Original Petition is dismissed.
