# High Court for the State of Telangana, CRLRC/2250/2016, 2017-01-17

HONOURABLE Dr. JUSTICE B.SIVA SANKARA RAO
CRIMINAL REVISION CASE No.2250 of 2016
ORDER :
Learned counsel for the petitioner seeks permission to
withdraw the Criminal Revision Case.
2. Permission is accorded.
3. Accordingly, the Criminal Revision Case is dismissed as
withdrawn with liberty to file application under Section 482
Cr.P.C. to exercise any inherent power, for compounding
pursuant to the docket order of the Court dated 05.12.2007. The
Registry is directed to return the original papers on proper
acknowledgement.
4. Miscellaneous petitions, pending if any, shall stand closed.

 Dr. B. SIVA SANKARA RAO, J
