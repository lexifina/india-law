Report so submitted by the State be kept with the record.
The subject-matter of challenge in this revisinal application
before this Court related to an order dated 03.03.2021 wherein the
petitioner’s prayer for discharge was refused by the learned Special
Court. The report so submitted by the State shows that Supplementary
charge-sheet was filed by the Investigating Agency in the month of
March, 2023. Consequently, the petitioner should get an opportunity
after receiving the documents under Section 207 of the Code of Criminal
Procedure to prefer a fresh application under Section 227 of the Code of
Criminal Procedure. That being the present position the merits of the
case need not be gone into at this stage. Learned Special Court would
dispose of such an application under Section 227 of the Code of
Criminal Procedure, if so advised and filed before the learned Trial

2
Court without being influenced by the earlier order dated 03.03.2021 so
passed.
With this aforesaid observation, C.R.R. 841 of 2021 is disposed of.
Pending applications, if any, are consequently disposed of.
All parties are directed to act on the server copy of this order
downloaded from the official website of this Hon’ble Court.

 (Tirthankar Ghosh, J.)
