PER COURT :
1. Heard. The challenge in this writ petition is to the order dated
14th July, 2020 passed by the Sub-Divisional Officer (Assistant Collector),
Kinwat in File No.2019/BND-56/Wayphani (Mahur)/CR-26, whereby the
order passed by the Mamlatdar on 10th July, 2019 in the rasta case has been
set aside.
2. The petitioner/revision applicant was not a party to the
proceeding before the Mamlatdar. The Sub-Divisional Officer was, therefore,
right in allowing the revision application. He has however, not remanded the
matter back to the Mamlatdar for giving the petitioner/revision applicant an
1 / 2

opportunity of hearing. Since same has not been done and the file before the
Mamlatdar has been closed which would be prejudicial to the interest of the
petitioner, the order impugned in this writ petition deserves to be set aside.
Same is, therefore, set aside. The matter is remanded back to the Mamlatdar
to decide afresh after giving the parties an opportunity of hearing.
3. Writ petition is disposed of accordingly.
