# Allahabad High Court, A482/8144/2019, 2019-03-05

Court No. - 70
Case :- APPLICATION U/S 482 No. - 8144 of 2019
Applicant :- Sarfaraj Husain And 6 Others
Opposite Party :- State Of Up And Another
Counsel for Applicant :- Rakesh Kumar Verma
Counsel for Opposite Party :- G.A.
Hon'ble Sanjay Kumar Singh,J.
It is submitted by learned counsel for the applicants that dispute
between the parties concerned has been amicably settled outside
the Court but the compromise application has not yet been filed
before the trial court.
In view of the above, a request has been made to permit the
applicants not to press this application with liberty to file fresh
application after filing the aforesaid compromise application
before the trial court.
The prayer so made is allowed.
The present application is dismissed as not pressed with liberty
to file fresh application after filing the compromise application
before the trial court.
Order Date :- 5.3.2019
