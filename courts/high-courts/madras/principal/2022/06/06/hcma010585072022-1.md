This application is filed to grant leave / permission to file a Reply /
Rejoinder statement in the above T.O.S. No.9 of 2015.
2. Learned counsel for the applicant submits that the applicant may be
permitted to file a reply / rejoinder statement in the above T.O.S. No.9 of
2015.
3. Learned counsel for the first respondent submits that there is no
averment in the application and hence vehemently objected to allow this
application.

statement in this case is unnecessary and unwarranted and hence objected to
allow this application.
5. Heard both sides.
