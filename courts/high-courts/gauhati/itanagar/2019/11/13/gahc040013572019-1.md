Heard Mr. K. Lollen, learned counsel for the petitioner.
This bail application has been filed under Section 439 of the Code of
Criminal Procedure, 1973, for grant of bail to the petitioner in connection with
Changlang P.S. Case No. 37/2019 registered under Sections 302/120(b) of the
Indian Penal Code read with Section 25 (1A) of the Arms Act.
Although this bail application has been filed for release of the petitioner, it is
found from the record as well as from the submission of the learned counsel for
the petitioner that the petitioner is not the accused and has not been arrested in
connection with the aforesaid Changlang P.S. Case No. 37/2019 registered under

Page No.# 2/2
Sections 302/120(b) of the Indian Penal Code read with Section 25 (1A) of the
Arms Act.
In that view of the matter, this bail application cannot be adjudicated in the
present form.
The bail application stands dismissed.
