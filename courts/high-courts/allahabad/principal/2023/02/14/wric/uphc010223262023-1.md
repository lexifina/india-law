# Allahabad High Court, WRIC/3604/2023, 2023-02-14

Court No. - 34
Case :- WRIT - C No. - 3604 of 2023
Petitioner :- Govind Narayan Dwivedi
Respondent :- State Of U P And 2 Others
Counsel for Petitioner :- Rakesh Kumar
Counsel for Respondent :- C.S.C
Hon'ble Saurabh Shyam Shamshery,J.
Petitioner is aggrieved that an application filed by him for arms
license for Virasatan is pending for the last more than one year.
However, learned counsel for petitioner fairly submits that he has
no instructions whether any number has been provided or not in
the application.
Learned Standing Counsel submits that in case any application of
petitioner is still pending, same will be decided expeditiously.
Considering above submission, this writ petition is disposed of
with observation that licensing authority shall decide the
application of petitioner if still pending, in accordance with law
expeditiously.
Order Date :- 14.2.2023
