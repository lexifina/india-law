(2 of 2) [WRES-370/2018]
Heard.
A glance of the order dated 21st April, 2017, would reflect
that the writ application was dismissed, taking note of the fact
that none appeared in the first as well as second round, for the
petitioner. Further, the order against which the writ application is
directed, was not enclosed with the writ application.
Thus, the order was made considering the fact that the
impugned order itself was not placed on record against which the
writ application was instituted.
The restoration application is, therefore, misconceived and is
hereby dismissed.
