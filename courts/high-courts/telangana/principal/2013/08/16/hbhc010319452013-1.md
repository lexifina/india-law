# High Court for the State of Telangana, CRP/3243/2013, 2013-08-16

THE HON’BLE SRI JUSTICE RAMESH RANGANATHAN
CIVIL REVISION PETITION NO.3243 of 2013
ORDER:
Sri P.Satyanarayana, Learned Counsel for the petitioner, would
submit that, instead of an adjudication on merits, it would suffice if this
Court were to grant liberty to the petitioner to approach the trial Court and
file an application to set aside the ex parte order.
Granting liberty as sought for, the Civil Revision Petition is
dismissed as not pressed. No order as to costs.
_______________________________
(RAMESH RANGANATHAN, J)
Date: 16.08.2013.

Issue C.C. by 20.08.2013.
