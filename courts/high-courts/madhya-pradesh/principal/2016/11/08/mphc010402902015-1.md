# High Court of Madhya Pradesh, MCC/2403/2015, 2016-11-08

MCC-2403-2015
(MAHENDRA KUMAR SONI Vs THE STATE OF MADHYA PRADESH)
08-11-2016
Shri Parag Chaturvedi, learned counsel for the applicant.
Shri Pradeep Singh, learned G.A. for the respondents/State.
Heard.
The case is listed for correction of typographical error in the
order dated 17.08.2015 passed in M.C.C. No.2403/2015.
The aforesaid M.C.C. was filed for restoration of W.P.
No.1604/2014, however, in the order dated 17.08.2015, the number of
W.P. has been mentioned as W.P. No.16048/2015.
It is a typographical error. Hence, the application is allowed.
Where in the order dated 17.08.2015 passed in M.C.C. No.2403/2015,
it is mentioned 'W.P. No.16048/2015' it be read as 'W.P.
No.16048/2014.'
C.C. as per rules.
(S.K. GANGELE)
