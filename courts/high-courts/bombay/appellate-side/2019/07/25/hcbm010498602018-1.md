 CORAM : REVATI MOHITE DERE, J.
DATE : 25th JULY, 2019
P.C. :
1. Heard the learned counsel for the Applicant.
2. By this application, the applicant seeks recall of the order dated
4
th June, 2018, by which the applicant’s bail application being Criminal
Bail Application No.2200 of 2017, came to be dismissed for non-prosecution.

2/2 30-appp.1364.2018.doc
3. For the reasons set out in the application, the application is
allowed and delay is condoned. The order dated 4th June, 2018, is recalled
and Criminal Bail Application No.2200 of 2017, is restored to file.
4. The Application is accordingly disposed of.
5. Criminal Bail Application No.2200 of 2017, be placed for
‘admission’ on the Supplementary Board on 31st July, 2019.
 REVATI MOHITE DERE, J.
