# High Court of Orissa, BLAPL/5625/2018, 2019-04-19

I.A. No. 302 of 2019
03. 19.04.2019 This is an application for modification of the
order dated 16.08.2018.
While releasing on bail by this Court imposed a
condition to the petitioners to furnish the property
security of Rs.2,00,000/- each with two solvent local
sureties each for the like amount.
Learned counsel for the petitioners submitted
that the petitioners are unable to furnish such property
security to the tune of Rs.2,00,000/- for which they are
still languishing in jail custody and the same may be
reduced to property security of Rs.50,000/- (rupees fifty
thousand only).
Learned counsel for the State has no serious
objection to such prayer.
Considering the submissions made by the
learned counsel for the respective parties, the property
security amount of Rs.2,00,000/- (rupees two lakhs) is
reduced to Rs.50,000/- (rupees fifty thousand only).
The rest part of the order remains unaltered.
I.A. is accordingly disposed of.
Issue urgent certified copy as per Rules.
