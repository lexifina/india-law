ORAL ORDER :
1. This is an application for recalling the order of dismissal in
default dated 13.07.2009. It is stated that, immediately after the
impugned order came to be passed, it was orally mentioned for
recalling the order and when directed to file separate application
this application has been filed on 17.07.2009. Perused the
application. After considering the grounds stated in the
application, the impugned order is recalled and set aside. The

2
application is allowed in terms of prayer clause ‘B’. The appeal is
restored to its original position. The civil application is disposed
of accordingly.
