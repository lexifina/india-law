Order
26/09/2023
The instant misc. application has been filed seeking
correction in the order dated 21.09.2023 passed by this Court in
S.B. Crminal Misc. Bail Application No.10931/2023 as in the first
and last para of the said order, name of the police station
‘Dhambola, District Bhilwara’ has been mentioned.
The prayer for correction is accepted.
Thus, the instant misc. application is allowed and it is
ordered that in the first and last para of the order dated
21.09.2023, name of police station be read as ‘Dhambola,
District Dungarpur’ in place of ‘Dhambola, District-Bhilwara’.
This order shall be treated as part and parcel of the order
dated 21.09.2023.
