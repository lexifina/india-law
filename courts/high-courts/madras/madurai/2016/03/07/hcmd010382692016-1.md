PRAYER: Criminal Original Petition is filed under Section 482 Cr.P.C., to
direct the respondent to file a final report before the learned Judicial
Magistrate No.2, Dindigul in Crime No.238 of 2015 pending on the file of
the respondent police within the time limit fixed by this Court.

For Petitioner : Mr.D.Selvaraj
For Respondent : Mr.K.V.Rajarajan
 Government Advocate (Crl.Side)
 ORDER
This petition has been filed for a direction to the respondent to
file a final report before the learned Judicial Magistrate No.2, Dindigul
in Crime No.238 of 2015 pending on the file of the respondent police.
2. When the case was taken up for hearing, the learned Government
Advocate (Crl. Side) submits that the investigation in Crime No.238 of
2015 is pending on the file of the respondent police and it will take
some time to complete the investigation and file a final report.
3. Under such circumstances, taking into consideration the nature of
the allegations, no time bound direction can be issued. However, the
respondent is directed to complete the investigation and file final
report expeditiously.
With the above direction, this petition is disposed of.
