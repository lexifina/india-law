ORAL ORDER
2 22-12-2021 By order dated 08.12.2021, bail was granted to the
petitioner but in the description of the party it was typed as P.S.
Muffasil, in accordance with description of the party as given in the
main bail petition, learned counsel submits that in the main bail
petition it was inadvertently typed as Muffasil P.S. instead of Alauli
P.S., hence this modification petition.
In view of the statement made in the modification petition,
let name of P.S. be read as Alaluli instead of Muffasil in the
description of the party, the order dated 08.12.2021 is modified to the
extent indicated above.
The modification petition stands disposed of.
