# High Court of Madhya Pradesh, MCC/611/2014, 2014-04-21

MCC No.611/2014
21/4/2014 :
Shri Anurag Tiwari, learned counsel for the
applicant.
This application has been filed for restoration of
MCC No.1298/2013 which has been dismissed for non
compliance with the peremptory order passed on
13.1.2014.
Keeping in view the reasons indicated in the
application, the same is allowed. MCC No.1298/2013 is
restored to its original file and default pointed out in
MCC No.1298/2013 be rectified within two days.
With the aforesaid, this application stands allowed
and disposed of.
( Rajendra Menon) ( A. K. Sharma )
