2. 10.12.2010 Heard the parties.
This is an application for quashing
the order dated 9.12.2009 passed by Addl. Session
Judge, F.T.C. No. 2, Supaul, by which he has set
aside the order of the S.D.M., Birpur dated
15.5.2007 in Misc. Case No. 6/2007, by which he
had initiated the proceeding under Section 144
Cr.P.C. Since the final order was passed on
15.5.2007 and set aside on 9.12.2007 much
beyond the stipulated period, I am not inclined to
interfere in the matter.
The application stands dismissed.
Fahad. ( Anjana Prakash, J. )
