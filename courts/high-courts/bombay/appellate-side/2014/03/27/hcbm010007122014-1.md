1. This is an application for restoration of the
earlier disposed of bail application. Today, none
present for the applicant.
2. Earlier Criminal Bail Application No.1699/2013
was dismissed by this Court vide order dated
26.11.2013. That time, it was observed by this Court
that earlier bail application of the applicant was
rejected on merits and it was Bail Application
No.1175/2012 and it was so rejected on 24.8.2012.
That time, directions were given to the Additional
