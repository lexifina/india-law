Heard.
By this petition, the petitioner impugns an order
passed by the first appellate Court on 18.10.2011 rejecting an
application filed by the petitioner under Order 41 Rule 27 of the
Code of Civil Procedure for permission to file documents on record.
On hearing the learned counsel for the parties and on
a perusal of the impugned order as also the application filed by the
petitioner, it appears that though several reasons are stated by the
petitioner in the application for permission to place the documents
on record, the impugned order does not record a single reason for
rejecting the application. The order is sans reasons and cannot be
sustained.
Hence, for the reasons aforesaid, the writ petition is
allowed. The impugned order is quashed and set aside. The first
appellate Court is directed to decide the application filed by the
petitioner in accordance with law.
Order accordingly. No order as to costs.
