court made the following order:
Heard the learned counsel for the plaintiff who stated that there
are a few typographical errors in the present application which is an
application seeking leave to institute the suit. Officially the suit has not yet
been instituted. Intended copy of the plaint alone has been filed.
2. Learned counsel stated that in view of the errors which has crept
inadvertently, necessary permission should be granted to withdraw the
present application and file an application with the correct details and also
incorporating the correct details in the intended plaint. Permission is
granted.
3. Application is dismissed as withdrawn with liberty to file fresh
application along with the corrected intended plaint.
