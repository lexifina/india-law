HON'BLE MR. JUSTICE GANESH RAM MEENA
Judgment / Order
03/08/2023
1. The present writ misc. application has been filed by the
applicant-petitioner for correction in the order dated 20.07.2023
passed by this Court.
2. Counsel appearing for the applicant submits that as per the
order dated 20.07.2023, the writ petition has been disposed,
however, in the second last line of the last para word ‘dismissed’
has been mentioned instead of word ‘disposed’.
3. On submissions made by counsel for the petitioner and
perusal of the order dated 20.07.2023 and for the reasons
mentioned application, the present writ misc. application for
correction in order dated 20.07.2023 is allowed and the word
‘disposed’ be read in place of word ‘dismissed’ in the second line
of the last para of the order dated 20.07.2023.
4. This order will be part and partial of order dated 20.07.2023.
(GANESH RAM MEENA),J
