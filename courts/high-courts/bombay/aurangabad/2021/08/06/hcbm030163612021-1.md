PER COURT :
1. We have heard learned Counsel for the petitioners for some time.
2. The learned Counsel for the petitioners, on instructions seeks leave to
withdraw the Writ Petitions with liberty to the petitioners to file an application
for discharge.
3. Leave granted.
4. The Criminal Writ Petitions are dismissed as withdrawn with liberty to
file an application for discharge, if so desired and upon filing of such
application, it is for the Special Court to consider the same on its own merits.
