This petition coming on for admission this day, the court passed the
following:
ORDER
Petitioners/schools have filed this writ petition under Article 226 of
Constitution of India making a prayer for quashing of order dated 02.11.2021
contained in Annexure-P/5, by which, Respondent No.2 has allotted a wrong
code to petitioners.
2. It is submitted by learned counsel for petitioners that petitioners are
Govt. Schools and, therefore, code which is to be allotted to Govt. Schools is
to be given to petitioners/schools. However, due to some mistake, Respondent
No.2 had allotted a different code to petitioners-schools. Counsel for
petitioners made a prayer that order dated 02.11.2021 be quashed and
respondents be directed to allot correct code to petitioners-schools.
3. Counsel appearing for Respondent No.2 prays for short time to file
reply.
4. Heard learned counsel for petitioners.
5. On going through the pleadings and documents, which have been filed
b y petitioners, it is clear that petitioners-schools were earlier run by society.
Said schools have been taken over by State Govt. along with all the assets,
teachers and other staff of schools. Staff is paid by Government. Notification is
also pointed out, by which, said order was passed. This shows that the
petitioners are Govt. Schools.

(VISHAL DHAGAT)
JUDGE
6. Considering the same, writ petition is allowed directing Respondent
No.3 for re-examining the issue and pass a fresh order allotting correct code to
petitioners-schools. Fresh order, which will be passed by said respondent will
supersede order dated 02.11.2021 contained in Annexure-P/5 so far as it relates
to petitioners.
7. With aforesaid direction, writ petition is disposed off.
