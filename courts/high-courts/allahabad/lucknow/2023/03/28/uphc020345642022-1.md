# Allahabad High Court, /992/2022, 2023-03-28

Court No. - 12
Case :- CRIMINAL MISC ANTICIPATORY BAIL
APPLICATION U/S 438 CR.P.C. No. - 992 of 2022
Applicant :- Ravi Shankar Kori
Opposite Party :- State Of U.P. Thru. Its Prin. Secy. Home
Counsel for Applicant :- Vijay Kumar Verma,Vinod Kumar
Tiwari
Counsel for Opposite Party :- G.A.
Hon'ble Mohd. Faiz Alam Khan,J.
No one is present for the applicant when the case is taken up for
hearing nor any request has been made on behalf of the
applicant to adjourn the case. Learned A.G.A. is available for
the State.
Perusal of the record would reveal that it is on 29.06.2022 when
this application was placed for the very first time before this
Court, learned A.G.A. was granted two weeks' time to file
objections. However, thereafter the matter could not be taken up
for hearing. Today, neither learned counsel for the applicant is
present nor any request has been made to adjourn the case on
behalf of the applicant.
In the above-mentioned scenario, it appears that perhaps the
applicant has lost interest in prosecuting the instant application.
Thus, the instant anticipatory bail application is dismissed for
want of prosecution.
