Judgment
17/07/2017
 Since the main Writ Petition No.4747/2016, M/S. Meena Gas
Agency, Kotputali Vs. State of Rajasthan & Ors. has already been
decided by this court today, whereby, the impugned order dated
9
th August, 2014 so as consequential order dated 15th April, 2014
have been set aside thus the impugned orders challenged herein
are also set aside with the same reasoning as given in the Writ
Petition No.4747/2016.
The present writ petition is also allowed with the aforesaid.
