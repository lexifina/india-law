# High Court of Madhya Pradesh, MCRC/16542/2015, 2015-11-17

M.Cr.C. No.16542/2015
17.11.2015
Shri K.K. Kushwaha, counsel for the applicants-accused.
Shri R.S. Shukla, Panel Lawyer for the respondent/State.
Case diary is available.
This is the repeat bail application filed by the applicants-accused under Section 439 of the Code of Criminal Procedure.
The first bail application filed by the applicants-accused was
dismissed by this court vide order dated 2.9.2015 passed in M.Cr.C.
No.14134/2015 as withdrawn with the liberty to the applicants-accused to file the bail application again after recording the
statements of the alleged eye-witnesses as referred in the earlier
order.
Indisputably, the statements of the aforesaid eye-witnesses
have not been recorded so far. Hence, this application filed by the
applicants-accused is not maintainable. It is hereby dismissed.
 (M.K.Mudgal )
 Judge
