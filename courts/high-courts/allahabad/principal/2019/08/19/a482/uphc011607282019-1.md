# Allahabad High Court, A482/31559/2019, 2019-08-19

Court No. - 72
Case :- APPLICATION U/S 482 No. - 31559 of 2019
Applicant :- Smt Sarjit Kaur
Opposite Party :- State Of Up And Another
Counsel for Applicant :- Omvir Singh Rajpoot
Counsel for Opposite Party :- G.A.
Hon'ble Rajiv Joshi,J.
Heard Shri Omvir Singh Rajpoot, learned counsel for the
applicant and learned A.G.A. for the State.
From the perusal of the documents annexed with the
application, it is apparent that incomplete documents have been
filed.
Under these circumstances, learned counsel for the applicant
prays that the present application be dismissed as withdrawn
with liberty to file fresh application.
Accordingly, application is dismissed as withdrawn with liberty
to file a fresh application after filing the proper documents.
Certified copy of the order annexed along with the application
be returned to the learned counsel for the applicant within a
week after retaining photostat copy of the same on record.
Order Date :- 19.8.2019
T. Sinha
