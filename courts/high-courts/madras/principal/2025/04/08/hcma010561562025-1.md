ORDER
This application has been filed seeking to modify the order dated
27.02.2025 in O.A. No.181 of 2025.
2.Since the parties are exploring the possibility of settlement, there is no
necessity to keep this application pending. To protect the interest of the applicant,
this Court can grant liberty to the applicant to revive this application if the need
arises in the near future and if the settlement talks fail. Accordingly, this
application is closed. Liberty is granted to file a similar application if the need
arises for the applicant in the near future.
