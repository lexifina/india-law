# High Court of Orissa, ABLAPL/14120/2018, 2019-01-15

03. 15.01.2019 In view of the submission of the learned counsel for
the State that as yet, no prima facie evidence has surfaced
against the petitioner in so far as C.I.D. (CB), Odisha,
Cuttack P.S. Case No.23 of 2018 corresponding to G.R.
Case No.1266 of 2018 pending on the file of learned
S.D.J.M., Dhenkanal is concerned, learned counsel for the
petitioner prays for withdrawal of this application with
liberty to file the same afresh in case cause of action for
the same arises in future.
 In view of the above, granting such liberty, the
ABLAPL is disposed of.
 The interim order dated 17.12.2018 does no more
survive.
 Issue urgent certified copy of this order as per rules.
 A free copy of this order be supplied to the learned
counsel for the State.
