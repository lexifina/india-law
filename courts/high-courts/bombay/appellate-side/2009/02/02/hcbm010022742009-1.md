the charge-sheet has now been filed by the police. No application has
been preferred by the applicant in the Sessions Court after filing of the
charge-sheet. Counsel for the applicant, therefore, seeks permission
to withdraw this application with liberty to file an application in the
Sessions Court.
2. Since charge-sheet is filed, application is allowed to be
withdrawn with liberty as prayed.
3. Application is disposed of.
