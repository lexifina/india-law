JUDGE
Heard on I.A.No. 4736/2023 which is an application for
modification/correction of the order dated 27.6.2023 passed in W.P.no.
13653/2023.
2. Counsel for the petitioner submits that due to inadvertance and
typographical mistake, the description of respondent Nos.4 and 5 has been
mentioned as Indore instead of Dewas.
3. Considering the aforesaid application which is supported by an
affidavit, the same is allowed and the order dated 27.6.2023 passed in W.P.No.
13653/2023 is modified to the extent that so far as description of respondent
Nos.4 and 5 is concerned, in place of 'Indore', it shall be read as 'Dewas'.
C.c. as per rules.
