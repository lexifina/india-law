# High Court of Madhya Pradesh, MCC/733/2012, 2014-02-26

M.C.C. No. 733/2012.
1
26.02.2014.
None for the applicant.
This application has been filed for restoration of W.P.
No. 5038/2012 which has been dismissed due to non
compliance with the peremptory order dated 16/04/2012.
Keeping in view the reasons as indicated in the
application for restoration which is supported by an affidavit
of counsel himself, application is allowed, W.P. No.
5038/2012 is restored to its original number and list for
order before appropriate Bench.
Copy of this order be kept in the original file of W.P.
No. 5038/2012.
With the aforesaid, application is allowed and disposed
of.
(RAJENDRA MENON)
