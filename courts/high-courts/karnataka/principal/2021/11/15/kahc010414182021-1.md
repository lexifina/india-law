O R D E R

 The first defendant in O.S.No.119/2019 on the file of
the Principal Senior Civil judge, Chitradurga (for short, 'the
civil Court'), has impugned the civil Court's order dated

 3
08.10.2021. The civil Court by this impugned order has
rejected the petitioner’s application to amend the written
statement.
2. The learned counsel for the petitioner submits
that the first to third respondents have filed O.S.
No.119/2019 for partition. These respondents are the
petitioner’s brothers and sisters. The respondents have
deliberately left out one of the properties which will have to
be partitioned and therefore, the petitioner has filed the
present application for amendment, but it is actually
intended as a counter claim.

3. This Court is of the considered view that if the
petitioner proposes to make a counter claim, the same
must be tested as against the parameters necessary to
allow a counter claim and as such, notwithstanding the
disposal of the present application, the petitioner must
have the liberty to file an application for a counter claim,

 4
and if such application is filed the same must be
considered in accordance with law.
 The petition stands disposed of with the aforesaid
observations.
