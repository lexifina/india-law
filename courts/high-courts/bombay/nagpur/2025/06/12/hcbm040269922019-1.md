 Heard.
2. By this application, the State has sought
permission to file charge-sheet in view of the order dated
25.09.2019 whereby it was ordered not to file the charge-sheet
without seeking leave of this Court.
3. The present petition is pending since last six
years. Now the charge-sheet is ready. Considering the
allegations and nature of the offence we are of the opinion
that permission needs to be granted.
4. Accordingly, the application is allowed.
5. Permission is granted to the State to file the
Charge-sheet.
