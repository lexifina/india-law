ORDER
This criminal original petition has been filed to quash the
First Information Report in Crime No.1117 of 2020 on the file of
the first respondent police.
2.Today, when the matter is taken up for hearing, the learned
counsel appearing for the petitioner would fairly submit that
though the petitioner came up with the larger prayer, it would be
suffice, if the respondent police is directed to complete the
investigation and file the final report, within a time frame.
3.In view of the above submission, this Court, without going
