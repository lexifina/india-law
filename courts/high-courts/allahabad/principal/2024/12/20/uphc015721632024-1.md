# Allahabad High Court, A482/37576/2024, 2024-12-20

Neutral Citation No. - 2024:AHC:199668
Court No. - 52
Case :- APPLICATION U/S 482 No. - 37576 of 2024
Applicant :- Raheesh Khan And 3 Others
Opposite Party :- State of U.P. and Another
Counsel for Applicant :- Rajendra Prasad Tiwari,Vinay Kumar
Tiwari,Vineet Tiwari
Counsel for Opposite Party :- G.A.
Hon'ble Mrs. Manju Rani Chauhan,J.
Heard learned counsel for the applicants as well as learned A.G.A
for the State.
Learned A.G.A. for the State points out that earlier an Application
U/S 482 No.41204 of 2011 (Ramzan Khan and Others vs. State of
U.P. and Another) was filed and the same was rejected vide order
dated 22.02.2022. The present application has been filed with the
same prayer. This is second application filed under Section 482
Cr.P.C., hence is not maintainable and liable to be dismissed.
Accordingly, the present application is dismissed.
Order Date :- 20.12.2024
Kalp Nath Singh
