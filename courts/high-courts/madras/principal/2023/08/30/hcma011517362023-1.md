# Madras High Court, A/4487/2023, 2023-08-30

A.No.4487 of 2023
in O.P.No.812 of 2022
R.N.MANJULA, J.
This application has been filed
seeking for an order of transfer of
G.W.O.P.No.1243 of 2022 pending on
the file of VI Additional Family Court,
Chennai to the file of this Court to be
tried along with O.P.No.812 of 2022.
2. When the matter is taken up
today, the learned counsel for the
applicant sought permission of this
Court to withdraw this application with
a liberty to file a petition before this
Court.
3. Recording the submission of
the learned counsel for the applicant this
application is dismissed as withdrawn
with the liberty to the applicant to file
an appropriate petition before this
Court.
