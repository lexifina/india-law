I.A. 6909/2025
1. This is an application filed under section 152 of CPC seeking
correction of error in recording Counsel’s name in the order dated
06.02.2025.
2. The name of the counsel for the respondent has wrongly been
recorded as Ms. Sai P. whereas the correct name is Ms. Ranu Purohit.
3. For the said reasons, the present application is allowed and the order
dated 06.02.2025 is rectified and the name of the learned counsel for
the respondent is to be read as “Ms. Ranu Purohit.”
4. The application is disposed of in aforesaid terms.
