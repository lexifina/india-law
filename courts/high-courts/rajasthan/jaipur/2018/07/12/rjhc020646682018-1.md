Judgment / Order
12/07/2018
1. Application has been moved by the counsel for the petitioner
that in order dated 10.7.2018 in the subject matter of cause title
and in Para 2 of the main order Police Station Madanganj, District
Bundi has been mentioned whereas it should be police station
Madanganj, District Ajmer.
2. It is contended by counsel for the petitioner that there was
typographical error at the time of filing the bail application.
3. Considering the prayer, application is allowed. In the subject
matter of cause title and in Para 2 of the main order in place of

(2 of 2) [CRLMA-389/2018]
Police Station Madanganj, District Bundi the same be read as
Police Station Madanganj, District Ajmer.
4. Amended cause title to this effect has already been filed, the
same is taken on record in S.B.Criminal Misc.Bail Application
No.8302/2018.
5. The application accordingly allowed.
(PANKAJ BHANDARI),J
