ORAL ORDER
2 14-12-2016 Order impugned dated 31.05.2016 has been passed by
the learned Subordinate Judge-I, Arwal in Partition Suit No.141 of
2001 disposing of the application under Order 39 Rule 1 and 2 of
the Code of Civil Procedure which is appealable under Order 43
Rule 1(r) of the Code of Civil Procedure. Therefore, the
petitioners seek permission to withdraw this civil miscellaneous
application with liberty to file appeal according to law.
In view of the submission, the petitioners are permitted
to withdraw this civil miscellaneous application with liberty to file
an appeal. Accordingly, this civil miscellaneous application is
dismissed as withdrawn with the aforesaid liberty.
