ORAL ORDER
4 22-05-2018 Heard learned counsel for the petitioner and the APP
for the State.
Petitioner seeks bail in a case originally registered
under Sections 364/34 of Indian Penal Code but subsequently
added with Sections 302/201 of Indian Penal Code.
Learned counsel for the petitioner submits that delay
in lodging the first information report suggests that this case is of
false implication. Apart from that, it is suggested that deceased
was having criminal antecedent.
Since the allegation, based on circumstantial
evidence, is that the deceased had accompanied the petitioner and,
