# High Court of Rajasthan, CRLMB/8837/2015, 2015-08-14

IN THE HIGH COURT OF JUDICATURE FOR RAJASTHAN
 JAIPUR BENCH, JAIPUR
ORDER
SB Cr Misc Second Bail Application No.8837/2015
Rajkiran Yogi versus State of Rajasthan
14.8.2015
HON'BLE MR. JUSTICE MN BHANDARI
Mr Yunus Khan - for the petitioner
Mr Virendra Godara, PP – for the State
BY THE COURT:
This second bail application has been filed without
approaching the court below as per the liberty granted to the
petitioner while dismissing the first bail application. In view of
aforesaid, this bail application is dismissed while maintaining the
liberty granted to the petitioner while dismissing the first bail
application.
