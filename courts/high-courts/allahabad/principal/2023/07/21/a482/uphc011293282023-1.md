# Allahabad High Court, A482/21887/2023, 2023-07-21

Neutral Citation No. - 2023:AHC:145928
Court No. - 87
Case :- APPLICATION U/S 482 No. - 21887 of 2023
Applicant :- Manish Agnihotri
Opposite Party :- State Of U.P. And 2 Others
Counsel for Applicant :- Dev Raj Singh,Sunita Chauhan
Counsel for Opposite Party :- G.A.
Hon'ble Neeraj Tiwari,J.
1. Supplementary affidavit filed today, is taken on record.
2. Heard learned counsel for the applicant and learned AGA.
3. After some argument, learned counsel for the applicant
submitted that she does not want to press this application,
therefore, the same may be dismissed as not pressed for which
learned AGA has no objection.
4. Accordingly, application is dismissed as withdrawn.
5. No further liberty is given to the applicant to file fresh
application for the same cause of action.
