# High Court of Madhya Pradesh, MCC/915/2013, 2013-09-30

M.C.C.No.915/2013
Savita Bairagi Vs. State of M.P. & Ors.
30/09/2013
Shri Arun K. Soni, learned counsel for the applicant.
This application has been filed for restoration of
W.P.No.10999/2013, which was dismissed on 10.7.2013 for want
of prosecution.
Keeping in view the reasons given in the application and
finding the same to be bonafide, the application is allowed.
W.P.No.10999/2013 is restored to it's original file. It be placed for
orders before the appropriate bench.
With the aforesaid, the application is allowed and disposed
of.
(Rajendra Menon) (Smt.Vimla Jain)
