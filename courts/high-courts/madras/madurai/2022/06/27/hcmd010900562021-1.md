ORDER
Heard the learned counsel on either side.
2.The petitioners had been selected as dealer by Indian Oil
Corporation Limited. The petitioners have to obtain NOC from the
second respondent. The second respondent can grant NOC only if the
third respondent issues NOC. The third respondent has rejected the
petitioners' request by citing IRC guidelines. Challenging the
same, the writ petition has been filed.
3.The learned counsel for the petitioners draws my attention to
a catena of decisions in which it has been held that IRC guidelines
are only directory and not mandatory. In this case, the third
respondent has denied the petitioners' request for issuance of NOC
only by citing the IRC guidelines. Since the petitioners' case
stood rejected only by citing the IRC guidelines, the impugned
communication deserves to be set aside and a positive direction can
be issued. In this view of the matter, the impugned order of the
third respondent is set aside and the third respondent is directed
to issue NOC as sought for by the writ petitioners forthwith and
without any delay.
4.The writ petition is allowed accordingly. No costs.
Consequently, connected miscellaneous petitions are closed.
