**********
2 18/07/2011 Heard Counsel for the petitioner and the A.P.P.
appearing on behalf of the State.
This application has been filed against the
order dated 15.01.2007 passed by the Additional Chief
Judicial Magistrate, Jehanabad.
The petitioner has challenged the order by
which cognizance has been taken under Sections 182,
211, 193, 194 & 384 of the Indian Penal Code after
investigation of the case, which is found to be untrue.
There is no illegality in the order impugned. The
Court below is well within power to take cognizance in
case it finds that the case has been falsely lodged.
This application is accordingly dismissed.
Anand ( Sheema Ali Khan, J. )
