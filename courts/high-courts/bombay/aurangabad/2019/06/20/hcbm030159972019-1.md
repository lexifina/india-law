P.C. :-
Mr. Adkine the learned advocate submits that the petitioner has
filed an application for rental compensation, the same is not decided. The
learned A.G.P. accepts notice for respondent nos.1 and 2 and submits that the
petitioner has not filed any application for rental compensation before the
Competent Authority.
2. The application filed by the petitioner for rental compensation is
to the acquiring body. In fact to adjudicate the said application the same is
required to be filed before the S.LA.O. / Competent Authority.
3. The petitioner may file an application seeking rental
compensation before the Competent Authority. The Competent Authority
shall after receipt of the application decide the said application on its own
