This appeal has been listed for consideration of the
restoration application. From the order-sheet, we
find that the appeal was dismissed on merits by
order dated 21.08.2009. Thereafter, there is
neither any application for recalling the order
dated 21.08.2009 nor is there any order recalling
the same. However, on account of some wrong
reporting, the Office has been continuously listing
this application and various orders have been
passed.
Apparently, the Court was never apprised of the
fact that the appeal had been dismissed on merits
by order dated 21.08.2009 which has attained
finality.
In that view of the matter, pending applications of
this appeal does not require any consideration.
The file be consigned, accordingly.
