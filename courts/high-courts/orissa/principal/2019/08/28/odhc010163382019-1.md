# High Court of Orissa, ABLAPL/3877/2019, 2019-08-28

03. 28.08.2019 Accepting the submission of the learned counsel
for the State that in course of investigation, the
allegations leveled in the complaint petition have been
found to be false, learned counsel for the petitioners
prays for withdrawal of this bail application with liberty
to move afresh in case cause of action for the same arises
in future.
 Granting the liberty, as aforesaid, the ABLAPL is
disposed of accordingly.
 Issue urgent certified copy of this application on
proper application.
