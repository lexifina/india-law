 CORAM : M.L.TAHALIYANI,J.
 DATE : 05 SEPTEMEBR, 2014
P.C. :
1 By this Application the Applicant challenges the
impugned order dated 17 February 2014 passed by Judicial
Magistrate, First Class, directing issuance of process against the
Applicant for the offences punishable under sections 406, 420,
206, 421, 424 of the Indian Penal Code. However, the order
under challenge can be taken to the Sessions Court by filing a
Revision Application. When there is a statutory provision for
challenging such an impugned order, this court will not
entertain the application under section 482 of the Code of
Criminal Procedure.
2 Hence, the present Application is dismissed.
