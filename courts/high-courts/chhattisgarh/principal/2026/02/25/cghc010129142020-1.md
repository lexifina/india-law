1. By this petition, the petitioner has challenged the transfer order
dated 23.04.2020, by which the attachment of the petitioner has
been revoked and he has been transferred and posted at Mungeli.
2. Mr. Arvind Shrivastava, learned counsel for the petitioner, would
submit that the impugned transfer order is not sustainable and bad in
law, therefore, the same is liable to be set aside.
3. Mr. Anmol Sharma, learned State counsel, would support the
impugned order and submit that the petition is liable to be
dismissed.
4. I have heard learned counsel appearing for the parties and perused
the documents meticulously.
5. Since the impugned order dated 23.04.2020 has been stayed by this
Court on 22.06.2020 and it is continued in operation in favour of the
petitioner for the period of more than five years, therefore, the
impugned order dated 23.04.2020 is hereby set aside. However,
liberty is reserved to the respondent authorities to pass a fresh
transfer order, if any administrative exigency arises in future.
6. Accordingly, this writ petition is allowed to the above extent. No
cost.
