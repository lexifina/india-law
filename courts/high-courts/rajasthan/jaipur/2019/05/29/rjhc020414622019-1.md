HON'BLE MR. JUSTICE SANJEEV PRAKASH SHARMA
Judgment / Order
29/05/2019
1. By way of this writ petition, the petitioner assails the order
dated 12/04/2019 whereby the application moved for allowing the
petitioner to file her written statement has been rejected.
2. It is noticed that firstly on 05/06/2007 ex-parte proceedings
were initiated against the petitioner, however, on 28/06/2007, the
same was recalled. Thereafter, on 16/07/2007, 02/08/2007,
13/08/2007 and 31/08/2007 opportunity to file written statement

(2 of 2) [CW-9386/2019]
was granted whereafter on 26/09/2007, the said opportunity was
closed. The application has been moved after eleven years for
seeking permission to file written statement which has been
rejected by the impugned order dated 12/04/2019.
3. This Court does not find any error in the order impugned
passed by the learned trial court.
4. The writ petition is misconceived and the same is accordingly
dismissed.
(SANJEEV PRAKASH SHARMA),J
