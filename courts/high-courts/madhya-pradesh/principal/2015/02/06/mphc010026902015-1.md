# High Court of Madhya Pradesh, RP/47/2015, 2015-02-06

1
R.P. No.47/2015
6/2/2015.
Shri Udyan Tiwari, learned counsel for
the applicant.
While restoring W.P. No.845/2014 vide
order dated 6.1.2015 passed in MCC
No.2941/2014, the number of the case has been
written as W.P. No.9627/2014 instead of
W.P.845/2014.
Keeping in view the aforesaid, this
application is allowed. It is clarified and ordered
that what was restored on 6.1.2015 in MCC
No.2941/2014 was W.P. No.845/2014 and not
W.P. No.9627/2014 as indicated therein.
The aforesaid correction be made.
With the aforesaid, this application
stands allowed and disposed of.
(Rajendra Menon) (S. K. Gangele)
