# High Court of Orissa, CONTC/1835/2018, 2019-01-22

02. 22.01.2019 Heard learned counsel for the petitioner.
The petitioner has filed this application alleging
non-compliance of the order dated 09.11.2017 passed
by this Court in W.P.(C) No.23281 of 2017. But neither
the said order has been quoted nor the order copy has
been annexed to the contempt application. Therefore,
this Court is not inclined to entertain this application.
However, in course of hearing, learned counsel for the
petitioner wants to withdraw the contempt application
with liberty to file a better application with better
particulars.
In such view of the matter, the contempt
application stands disposed of with the liberty
aforesaid.
