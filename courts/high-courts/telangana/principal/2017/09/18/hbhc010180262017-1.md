# High Court for the State of Telangana, CRLRC/1313/2017, 2017-09-18

THE HON’ BLE SRI JUSTICE M.SATYANARAYANA MURTHY
CRIMINAL REVISION CASE No.1313 OF 2017
ORDER:
Sri Chandra Sekhar Ilapakurti, learned counsel for petitioner
seeks permission of this Court to withdraw the Criminal Revision
Case with liberty to file appropriate application.
Permission is accorded.
Accordingly, this Criminal Revision Case is dismissed as
withdrawn with liberty to file appropriate application. Registry is
directed to return all the documents to the concerned counsel with
proper acknowledgement.
As a sequel, miscellaneous petitions if any pending shall
stand closed.
