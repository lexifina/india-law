JUDGMENT
It is indubitable that this Original
Petition is not maintainable because, what is
sought for is that Ext.P3 Execution Petition be
stayed.
2. This is because, the Execution Petition
has been filed against the order in RCP
No.14/2022, admittedly confirmed in Appeal,
against which a Revision is stated to be pending
before this Court. Obviously, the petitioner
should have moved the Bench before which the
Revision is pending for orders against the
execution, which he admittedly has not done.
3. This is more so because, this Original
Petition has not been filed challenging any order
of the learned Munsiff, but merely saying that he
is likely to effect eviction.

OP(C) NO. 2233 OF 2023
3
In the afore circumstances, this Original
petition is dismissed.
