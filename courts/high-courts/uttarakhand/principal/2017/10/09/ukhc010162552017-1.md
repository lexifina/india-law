# High Court of Uttarakhand, BA1/865/2017, 2017-10-09

MCRC No.398 of 2017 (Application for Correction/Amendment)
In
BA1 No. 865 of 2017
Hon’ble V.K. Bist, J.
Mr. Ghanshyam Joshi, Advocate for
the applicant.
Mrs. Preeta Bhatt, Brief Holder for
the State of Uttarkhand.
Heard learned counsel for the
parties.
It is submitted by the learned
counsel for the applicant that correction
application has been moved in bail
application no. 1078 of 2017; but,
inadvertently, in the index portion of the
correction application, same has wrongly
been shown as bail application no. 865 of
2017. He prayed that he may be permitted
to withdraw the correction application
with liberty to file fresh in appropriate bail
application.
Permission is granted.
The application for correction/
amendment is dismissed as withdrawn
with the liberty as above.
Learned counsel for the applicant
then prayed that certified copies of the
orders annexed with the correction
application may be returned back to him
so that he may file appropriate
application.
Prayer, being innocuous, is allowed.
Office is directed to return the
certified copies of the orders annexed with
the correction application to the learned
counsel for the applicant today itself, after
keeping the photocopies of the same in
this file.
 (V.K. Bist, J.)
Arpan 09.10.2017
