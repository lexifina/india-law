# High Court for the State of Telangana, SA/402/1998, 2012-04-26

HONOURABLE SRI JUSTICE B.N. RAO NALLA
SECOND APPEAL Nos.400 AND 402 OF 1998
COMMON JUDGMENT:
Sri D. Hanumantha Rao, learned counsel for the appellant in
both the appeals, sought permission of the Court to withdraw these
appeals with liberty to file fresh appeals, if necessary, and to that effect
he made an endorsement on the case files.
Permission is accorded.
Accordingly, these Second Appeals are dismissed as withdrawn
with liberty to file fresh appeals, if necessary. No order as to costs.
