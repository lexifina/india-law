HON'BLE MR. JUSTICE M.N.BHANDARI
Order
23/08/2017
 This application has been filed to seek correction in the
order dated 23rd September, 2015.
It is stated that inadvertently, in the order dated 23rd
September, 2015, the date of suspension order has been
mentioned as 11th May, 2013 instead of 14th May, 2015.
Accordingly, necessary correction may be permitted.
In view of the above, the application is allowed. In the
order dated 23rd September, 2015, the date of suspension order
be read as 14th May, 2015 instead of 11th May, 2015.
This order be treated as part and parcel of the order
dated 23rd September, 2015.
(MN BHANDARI) J.
