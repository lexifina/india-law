# High Court of Orissa, WP(C)/26991/2017, 2019-09-09

4.
Ayas
9.09.2019 Heard learned counsel for the
parties.
 Considering the request of
Shri R. Prusty, learned counsel for
the petitioner, this Court permits the
petitioner to withdraw this writ
petition with liberty to file an
application for settlement of the
disputed land. However, it is made
clear that this Court has not
expressed any opinion on the merit
involving the request for settlement of
the disputed land in question.
 Accordingly, the Writ Petition
stands dismissed as withdrawn but
with liberty, as prayed for.

(Biswanath Rath, J.)
