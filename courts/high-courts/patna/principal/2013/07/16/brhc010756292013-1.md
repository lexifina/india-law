ORAL ORDER
3 16-07-2013 Heard learned counsel for the petitioner and learned
counsel for the State.
 This application has been filed for quashing the First
Information Report of Koilwar P.S. Case No.41 of 2004
registered under Sections 324, 307, 333, 353, 504/34 of the
Indian Penal Code and 27 of the Arms Act.
 After some argument, learned counsel for the petitioner
seeks permission to withdraw this application with a liberty to
raise all points before the court below at the appropriate stage.
 Permission is accorded. Accordingly this application is
dismissed as withdrawn with the aforesaid liberty.
Vinay/- (Shivaji Pandey, J)
