ORDER
This Criminal Miscellaneous Case is filed to quash
Annexure-1 final report in ST.No.3039/2017 on the file of the
Judicial First Class Magistrate Court-I, Thodupuzha,
2. When this matter came up for consideration on
07.09.2023, this Court passed the following order:
“The Registry will get a report from the Judicial First
Class Magistarate Court-I, Thodupuzha why final
orders are not passed in Anx. 3 petition, even though
it was filed on 22/01/2018.
Post along with the report on 13/09/2023.”
3. Now a report is submitted by the Judicial First
Class Magistrate Court-I, Thodupuzha, in which it is stated
that there is some delay in disposing the matter and the case
was taken on 26.08.2023 and now it stands posted for further
