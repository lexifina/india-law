# High Court of Tripura, CMAppl(FA)/660/2013, 2014-01-06

Case No :CMAppl(FA) 0000660/2013
Party Name : Uttam Kr. Saha Vs Sujit Nandi And Another
THE HONBLE MR JUSTICE U. B. SAHA
The instant application is filed under Order XLI Rule 27 read with Section 151 of the Civil
Procedure Code for allowing the applicant-appellant to produce some documents as
additional evidence. When the matter is taken up for order, Mr. PK Dhar, learned counsel
for the applicant-appellant wants to withdraw the instant application with a liberty to file
afresh as there is some mistake in the instant petition. In view of the above, the instant CM
application is disposed of as withdrawn with liberty to file afresh, if so advised.
