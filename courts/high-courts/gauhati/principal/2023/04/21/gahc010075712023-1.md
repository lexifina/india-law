BEFORE
HONOURABLE MR. JUSTICE ARUN DEV CHOUDHURY
ORDER
21.04.2023
Heard the learned counsel for the applicant.
This is an application filed under Section 152 of the Code of Civil Procedure,
1908 praying for correction of typographical error in the order dated 22.03.2023
passed in RSA/29/2023.
The number of the Title Suit as shown in paragraph 2 of the said order
dated 22.03.2023, ought to have been “21/2011” instead of “21/2021”.
Accordingly, the said typographical error is corrected. The order dated
22.03.2023 be read with the order passed today, and shall form a part of the
order dated 22.03.2023 in RSA/29/2023.
Accordingly, this application stands allowed.
 JUDGE
Comparing Assistant
