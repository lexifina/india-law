# High Court of Madhya Pradesh, MCC/2676/2014, 2015-02-06

M.C.C.No.2676/2014
Hotel Aamer Palace Vs. Naval Kishore & Anr.
06/02/2015
Shri Abhijeet A. Awasthi, learned counsel for the applicant.
This application has been filed for restoration of a Review
Petition No.157/2013, which has been dismissed because of a
common conditional order passed before notice to the respondents.
There being some delay in filing of this application for restoration,
I.A.No.16731/2014 is filed seeking condonation of the delay, which is
supported by affidavit of the counsel.
Keeping in view the reasons indicated in the application and
finding the same to be bona-fide, I.A.No.16731/2014 is allowed.
Condoning the delay in filing of this application for restoration, the
restoration application is itself allowed. R.P.No.157/2013 be restored
to it's original file. It be placed for orders before an appropriate bench.
With the aforesaid, this application stands allowed and
disposed of.
 (Rajendra Menon) (C.V.Sirpurkar)
