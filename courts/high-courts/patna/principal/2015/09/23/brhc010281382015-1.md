CORAM: HONOURABLE JUSTICE SMT. ANJANA MISHRA
ORAL ORDER
3 23-09-2015 The present application has been filed for adding alias
name of the petitioner Sachin Ojha whose alias name is also
Suchin Ojha alias Sachin Kumar. Since, in the petitioner’s
anticipatory bail application, only the name Sachin Ojha @ Sachin
Kumar appeared and the alias name Suchin Ojha has been left out,
though bail has been granted by this Court, the court below
refused to accept the bail bonds as the alias name Suchin Ojha
does not appears in the column, and as such the petitioner has filed
the modification application.
Let alias name of the petitioner i.e. Suchin Ojha be also
added in the order dated 01.07.2015 in addition to the names of
Sachin Ojha @ Sachin Kumar.
The modification is allowed to the extent as indicated
above. The date of surrender shall now run as of today.
Saif/-
 (Anjana Mishra, J)
