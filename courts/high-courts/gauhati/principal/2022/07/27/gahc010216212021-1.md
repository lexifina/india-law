ORDER
Date : 27-07-2022
Mr. S. Choudhury, learned counsel for the petitioner seeks not to press
with this writ petition in the present form, inasmuch as during the pendency of
the writ petition, an appellate order had been provided to the petitioner which
also requires to be assailed along with the order which have already been
assailed in the writ petition.
Considering the said statement, the writ petition is allowed to be
withdrawn with liberty to the petitioner to file appropriate application, if so
advised.
