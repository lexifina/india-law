# Allahabad High Court, WRIA/2565/2023, 2023-02-09

Court No. - 36
Case :- WRIT - A No. - 2565 of 2023
Petitioner :- Rammurti Saxena
Respondent :- State Of U.P. And 4 Others
Counsel for Petitioner :- Nand Kishor Mishra,Shilpa Ahuja
Counsel for Respondent :- C.S.C.
Hon'ble Neeraj Tiwari,J.
Heard learned counsel for the petitioner and learned Standing
Counsel for the State-respondents.
Learned Standing Counsel has raised preliminary objection and
submitted that this is second petition for the same cause of action,
which is not maintainable and liable to be dismissed.
Learned counsel for the petitioner submitted that he may be
permitted to withdraw this petition with liberty to file contempt
petition for which learned Standing Counsel has no objection.
Accordingly, the writ petition is dismissed as withdrawn with the
aforesaid liberty.
Order Date :- 9.2.2023
Junaid
