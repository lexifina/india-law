1. The present application is for grant of bail
under Section 439 of the Code of Criminal Procedure.
2. After hearing the learned Counsel for the
applicant to some extent, this Court has shown
disinclination to grant bail, the learned Counsel for the
applicant seeks permission to withdraw the application.
3. The learned Counsel for the applicant is
permitted to withdraw the application with liberty to
move an application for bail before this Court after one
year, if the trial is not commenced.
4. The application is disposed of, as withdrawn.
