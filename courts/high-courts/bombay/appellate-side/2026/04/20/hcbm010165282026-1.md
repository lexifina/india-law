P.C.
1. This Interim Application is filed by the applicant/petitioner praying for
restoration of Writ Petition, which came to be dismissed by an order dated 29
November, 2024 for want of prosecution as also for condonation of delay in
filing this Application.
2. We have perused the averments as made in the Interim application. Delay
caused in filing this application has been appropriately and sufficiently explained,
hence the same is condoned. It is in the interest of justice that the Writ Petition is
restored to the file of this Court.
3. Accordingly, Interim Application is allowed. The Writ Petition is restored
to the file of this Court.
4. Interim Application is disposed of.
(AARTI SATHE, J.) (G. S. KULKARNI, J.)
