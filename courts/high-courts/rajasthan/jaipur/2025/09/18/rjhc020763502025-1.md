Order
18/09/2025
1. The application has been filed for seeking correction of
clerical/typographical errors crept in order dated 04.07.2025
passed in S.B. Criminal Miscellaneous Petition No.3232/2025.
2. It has been stated in the application that on account of
bona fide errors in the order dated 04.07.2025, date of impugned
order, vehicle number, FIR number and application number have
wrongly been mentioned therein.
3. On examination of application as well as order dated
04.07.2025, it is apparent that some typographical errors are
there in order dated 04.07.2025, which are required to be
rectified.

[2025:RJ-JP:38136] (2 of 2) [CRLMA-434/2025]
4. Accordingly, the application filed by the petitioner is
allowed.
5. In para 1 & 2 of order dated 04.07.2025, instead of
impugned order dated 10.10.2023, date of impugned order may
be read as 03.08.2023; vehicle No.RJ-45-CL-8798 be read as
Vehicle No.RJ-14-CD-7374; FIR No.1070/2023 be read as FIR
No.519/2023 and application number before the learned trial court
be read as 309/2023 instead of 449/2023. This order may be
treated as a part of order dated 04.07.2025. Necessary
corrections in this regard have also been carried out with red ink
in original order dated 04.07.2025.
(ANAND SHARMA),J
