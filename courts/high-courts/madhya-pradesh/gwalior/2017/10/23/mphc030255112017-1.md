# High Court of Madhya Pradesh, MCRC/17896/2017, 2017-10-23

MCRC 17896/2017
 Rajesh Sharma vs. State of MP
23/10/2017
Shri Abhishek Parashar, counsel for the applicant.
Shri RVS Ghuraiya, Public Prosecutor for the respondent/
State.
This application has been filed on the ground of ill-health
of the applicant. However, nothing has been mentioned in the
application with regard to the disease from which the applicant is
suffering nor any document has been filed in support of health
condition. Therefore, counsel for the applicant seeks permission
of this Court to withdraw this application with liberty to the
applicant to file a properly constituted application.
Accordingly, the application is dismissed as withdrawn.
 (G.S. Ahluwalia)
 Judge
MKB
