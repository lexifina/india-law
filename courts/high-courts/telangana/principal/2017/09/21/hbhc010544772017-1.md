# High Court for the State of Telangana, WP/32376/2017, 2017-09-21

HONOURABLE SRI JUSTICE A.RAJASHEKER REDDY
WRIT PETITION No.32376 OF 2017
O R D E R :
Learned counsel for the petitioners seeks permission of this
Court to withdraw the writ petition with liberty to file fresh writ
petition.
Permission is accorded.
Accordingly, the writ petition is dismissed as withdrawn
granting liberty to file fresh writ petition. Interim Order, if any,
granted earlier by this Court stands vacated. No costs.
As a sequel thereto, miscellaneous petitions, if any, pending
in the writ petition, shall stand closed.
