P.C. :
1 The learned Advocate for the applicant/accused
submits that the co-ordinate Bench of this court (Coram : Sadhana
S. Jadhav, J.) has already directed for return of gold jewellery but
the respondents are not returning the same, and therefore, the
instant application for return of gold jewellery is again moved.
avk 1/2

21-APPA-290-2018.doc
2 As even according to the learned Advocate for the
applicant/accused the order directing return of gold jewellery has
already been passed by the co-ordinate Bench of this court, second
application for the same relief cannot be entertained. If the
authorities are not complying with the said order, then the remedy
lies elsewhere.
With this observation, Criminal Application No.290 of
2018 stands disposed of.
(A. M. BADAR, J.)
