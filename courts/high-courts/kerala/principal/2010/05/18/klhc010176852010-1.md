ORDER
Heard both sides. Condition No.1 imposed in
Annexure - 3 order dated 22.10.2009 in Criminal
R.P.No.9/2009 on the file of the Sessions Court,
Thodupuzha is modified. Instead of depositing cash
security of Rs.50,000/-, the petitioner need only execute
a bond for Rs.1,00,000/- with two solvent sureties each
for like sum amount to the satisfaction of the Judicial
First Class Magistrate Court-II, Peermade. In all other
respects, Annexure -3 order is confirmed. This Criminal
M.C is allowed to the above extend.
