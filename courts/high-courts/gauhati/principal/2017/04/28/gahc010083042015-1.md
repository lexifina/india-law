# Gauhati High Court, CRP/485/2015, 2017-04-28

CRP 485/2015
BEFORE
HON’BLE MR JUSTICE KALYAN RAI SURANA
Both sides are duly represented by their learned counsel.
Mr. B.J. Ghosh, learned counsel for the petitioner submits that there are some f
ormal defects in this revision application and therefore, prays to permit him to
withdraw the same with liberty to file a fresh.
The prayer is allowed.
The revision is dismissed on withdrawal with liberty as prayed for.
The registry may return back the certified copy of impugned order to the learned
counsel for the petitioner to enable him to file a fresh revision application.
However, photo copy of the same order may be retained in the file.
