ORAL ORDER
02. 08.02.2012. The learned counsel for the petitioner submitted that he will
simply delete the property mentioned in detail in Schedule II of the
plaint and will not pray to delete the property on the ground that
there has already been settlement between the parties regarding
Schedule II property before the Gram Panchayat Katchari. On this
ground, the learned counsel for the petitioner seeks permission to
withdraw this writ application with liberty to file a fresh application
simply praying for deleting Schedule II property from the plaint.
In view of the above submission, this writ application is
permitted to be withdrawn. The petitioner may, if so advised, file
application before the Court below making prayer and if such
application is filed, the Court below shall dispose of the said
application according to law without being influenced by the
impugned order and also this order of this Court. Accordingly, this
writ application is dismissed as withdrawn with the aforesaid liberty.
Sanjeev/- (Mungeshwar Sahoo,J.)
