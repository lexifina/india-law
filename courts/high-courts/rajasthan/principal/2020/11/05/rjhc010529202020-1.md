The matter comes up on an application for correction in the
order dated 3.11.2020.
Counsel for the petitioner submits that the bail application
qua petitioner No.2 Lalu Ram has become infructuous as he was
arrested.
For the reasons mentioned in the application, the same is
allowed. The order dated 3.11.2020 is modified accordingly and
the bail application qua petitioner Lalu Ram is dismissed as having
become infructuous.
