# High Court of Madhya Pradesh, MCC/258/2013, 2013-10-31

1
MCC No.258/2013
31/10/2013
 Shri Manoj Sharma, learned counsel for the
applicant.
This application has been filed for restoration of
W.P. No.12536/2003 which was dismissed for want of
prosecution on 19.5.2013. There being some delay in
filing the application, I.A. No.2361/2013 has been filed
seeking condonation of delay.
Having heard learned counsel for the applicant and
on perusal of the reasons given in the application and
finding the same to be bonafide, both the applications are
allowed. Condoning the delay in filing the restoration
application, the restoration application itself is allowed.
Writ petition be restored in its original file and it be placed
for orders before the appropriate Bench.
Accordingly, this application stands allowed and
disposed of.
 (RAJENDRA MENON)
