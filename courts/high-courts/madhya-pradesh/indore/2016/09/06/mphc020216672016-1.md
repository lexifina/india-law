# High Court of Madhya Pradesh, WP/5782/2016, 2016-09-06

W.P. No. 5782 Of 2016
06.09.2016
Shri L.C.Patne, learned counsel for the petitioner.
Shri S.H.Karanjewala, learned counsel for
respondents/State.
Heard.
This writ petition has been filed by the petitioner challenging
the order of termination dated 26/11/15 as also the appellate order
dated 29/03/16.
Learned counsel appearing for the petitioner has submitted
that Appeal has been dismissed by the Collector vide order dated
29/03/16 on the ground of delay without appreciating that
petitioner could not prefer an appeal because he had suffered an
accident. Counsel for the petitioner has not disputed the fact that
no application for condonation of delay was filed before the
Collector, but he has submitted that an opportunity ought to have
been given to the petitioner to file an application for condoning the
delay in filing the appeal.
Learned counsel for the respondents has no objection if an
opportunity is given to the petitioner to file an application for
condonation of delay before the Collector.
That apart, in the present case, the learned Collector
himself should have given an opportunity to the petitioner to file an
application for condonation of delay when it was found that the
appeal was filed belatedly. The order of the Collector reflects that
petitioner was not granted any opportunity to file an application for
condonation of delay.
In these circumstances, writ petition is disposed of by
setting aside the impugned order of the Collector dated 29/03/16
with a liberty to the petitioner to file an appropriate application for
condonation of delay before the Collector and the Collector is
directed to pass an appropriate order on the application for

condonation of delay and thereafter to decide the appeal in case if
the delay is condoned.
 (Prakash Shrivastava)
