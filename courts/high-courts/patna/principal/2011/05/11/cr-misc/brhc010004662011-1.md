2. 11/05/2011 This application has been filed for
modification of the order dated 21.12.2010
passed in Cr.Misc.No.33699 of 2010, by which
anticipatory bail application of the
petitioner was allowed and he was granted
four weeks time to surrender and apply for
bail.
Petitioner did not surrender within the
stipulated time and now this modification
application has been filed on 21.4.2011 for
extending the time.
This Court does not find any justifiable
reason to extend the time granted by this
Court earlier for surrender. The application
is accordingly dismissed.
 Pradeep/ ( J. N. Singh,J.)
