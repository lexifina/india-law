# High Court of Uttarakhand, WPSB/259/2010, 2012-09-03

Review Application No. 663 of 2012
Delay Condonation Application No. 9018 of 2012
In
WPSB No. 259 of 2010
Hon’ble Barin Ghosh, C.J.
Hon’ble U.C. Dhyani, J.
Mr. Davesh Bishnoi, Advocate for the
petitioners / review applicants.
Mr. Vinay Kumar, Standing Counsel for the
State of Uttarakhand / respondent No. 3.
We have considered the averments made in
the Application for condonation of delay and,
being satisfied with the reasons furnished therein,
allow the same and condone the delay in
preferring the Review Application.
The Review Application is thoroughly
misconceived, since the same seeks to re-agitate
the point decided specifically against the
petitioners while dealing with the writ petition.
The Review Application is dismissed.

 (U.C. Dhyani, J.) (Barin Ghosh, C.J.)
