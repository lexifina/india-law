# High Court for the State of Telangana, CC/67/2013, 2013-07-02

HON'BLE SRI JUSTICE N.R.L. NAGESWARA RAO
CONTEMPT CASE No.67 OF 2013
ORDER:
Heard the learned counsel for the petitioner.
Since the order, dated 14.08.2012, in C.R.P.No.3584 of
2012 passed by this Court is said to have been not implemented,
the petitioner is at liberty to approach the Court below for effective
implementation of the order of this Court, since the order of this
Court merges with the order of the Court below, which can be
effectively implemented by the Court below.
With the above liberty, the Contempt Case is disposed of.
No order as to costs. Miscellaneous petitions, if any, pending in
this Contempt Case shall stand closed.
_______________________________
JUSTICE N.R.L. NAGESWARA RAO
