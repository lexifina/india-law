# Madras High Court, A/2062/2024, 2024-04-16

A.No.2062 of 2024
and CS.No.205 of 2022
C.V.KARTHIKEYAN, J
 This application has been filed to set
aside the exparte order dated 09.10.2023
passed against the defendant. The suit has
been filed seeking recovery of money.
Since the defendant did not appear on
09.10.2023 and also not filed written
statement the defendant has been set
exparte.
 2. It is seen from the records that the
applicant had initially filed an application
to condone the delay of 330 days in filing
the written statement. Taking into
consideration the fact that it can only be
to the an advantage of the plaintiff that
the defendant is a party to the suit, since
that would also facilitate execution, if at
all a decree is passed, exparte order dated
09.10.2023 is set aside.
 3. Registry is directed to number the
consequential application to condone the
delay in filing the written statement and
put up before this Court.
 4. List the matter on 04.06.2024.
