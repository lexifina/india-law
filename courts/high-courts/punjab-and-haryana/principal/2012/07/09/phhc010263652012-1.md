NAWAB SINGH J.(ORAL)
This is an application for pre-arrest bail under Section 438
Code of Criminal Procedure in case bearing First Information Report
No.173 dated May 11, 2012 registered under Sections 307 read with
Sections 34 and 120-B of the Indian Penal Code in Police Station
Narnaund, District Hisar.
2. By order dated June 27, 2012 passed by Rakesh Kumar
Jain, J. interim direction was given that petitioner be released on bail in
the event of his arrest.
3. Learned Assistant Advocate General, Haryana has stated
that petitioner has joined the investigation and he is not required for
custodial interrogation.
4. In this view of the matter, order dated June 27, 2012 passed
by this Court, is made absolute.
5. Petition is allowed accordingly.
July 09, 2012 ( NAWAB SINGH )
