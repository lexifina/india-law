The petitioner had applied for permission to
open the B.Sc. Home Science Course from the Academic
Session 2014-15. The Academic Session for which the
permission was sought has already lapsed. It would,
therefore, be necessary for the petitioner to file an
appropriate application before 31st of October, 2015 for
permission to start the course from the Academic Session
2016-17.
Shri Kulkarni, the learned counsel for the
petitioner, states that the petitioner would file an application
before 31st of October, 2015 so that the same could be
decided by the University and the State Government before
15th of June, 2016.
On the statement made by the learned counsel
for the petitioner, we dispose of the writ petition by keeping
all the points open. No costs.
