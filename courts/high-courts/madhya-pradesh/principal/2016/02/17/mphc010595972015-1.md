# High Court of Madhya Pradesh, MCRC/20672/2015, 2016-02-17

MCRC-20672-2015
(LAXMAN SINGH PARIHAR Vs THE STATE OF MADHYA PRADESH)
17-02-2016
Shri Manish Datt, learned Senior Counsel with Shri T.P. Jaiswal,
learned counsel for the applicant.
Shri Ajay Tamrakar, learned P.L. for the respondent/State.
After arguing for some time learned counsel for the applicant
seeks leave to withdraw this M.Cr.C. with liberty to the
applicant to surrender before the concerned special Judge
and to file an application for regular bail with a further prayer
that in case the application is filed, the concerned Court be
directed to take the same for consideration at the earliest.
With the aforesaid liberty and direction to the concerned Court
that if possible such application if filed be taken up for
consideration on the same day, the M.Cr.C. is dismissed as
withdrawn.
C.c. as per rules.
(SHANTANU KEMKAR)
JUDGE
