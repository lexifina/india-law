ORDER
This Criminal Miscellaneous Case is filed against
Annexure-1 order, by which the Additional Sessions Judge–III,
Manjeri cancelled the bail granted to the petitioner in
S.C.No.1411/2021, arising from Crime No.605/2020 of
Perinthalmanna Police Station. The above case is charge-sheeted against the petitioner alleging offences punishable
under Sections 143, 147, 148, 324, 326, 308, 354 and 395
read with Section 149 of the Indian Penal Code.
2. The Sessions Court granted bail to the petitioner as
per order dated 09.02.2020 in Crl.M.C.No.710/2020 with
certain conditions. It is submitted that the petitioner violated
the conditions and therefore, the bail was cancelled as per
Annexure-1 order. Aggrieved by the same, this criminal
miscellaneous case is filed.

CrlM.C..No.4381/2022
3
3. Heard the learned counsel for the petitioner and
the learned Public Prosecutor.
4. This Court perused Annexure-1 order. Annexure-1
order was stayed by this Court on 06.07.2022 and that order is
in force even now. It is submitted that the sessions case is
now ripe for trial. It is true that the petitioner violated certain
conditions as mentioned in Annexure-1. Since there is an
interim order for the last one year and also because the case is
ripe for trial, I think Annexure-1 order can be set aside in the
peculiar facts and circumstances of the case. I make it clear
that if the petitioner violate any of the conditions in the bail
order dated 09.02.2020 in Crl.M.C. No.710/2020 in future, the
investigating authority is free to file appropriate application
before the jurisdictional court.
With the above observation, Annexure-1 order is set
aside and the criminal miscellaneous case is disposed of.
