1. Heard Shri Kotwal, learned counsel for the
petitioner.
2. The petition challenges the order dated
03/02/2022, by which the application for amendment of the
plaint has been allowed. It is an admitted position that the
issues are yet to be framed, considering which, the proviso to
Order VI Rule 7 of the Code of Civil Procedure would not be
attracted and the plaintiff would be entitled to amend the
plaint. It is not as if that by allowing the amendment, the
averments are held to be proved. The defendant will have an
equal chance to file an additional written statement or amend
