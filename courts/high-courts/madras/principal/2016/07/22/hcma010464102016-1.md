ORDER
This petition has been filed to quash the charge sheet in
CC.No.95 of 2015 on the file of the learned Judicial Magistrate
No.I, Coimbatore.
2. Heard Mr.J.Franklin, learned counsel appearing for the
petitioner; Mr.C.Emalias, learned Additional Public Prosecutor
appearing for the first respondent and Mr.K.Govi Ganesan,
learned counsel appearing for the second respondent.
3. When this court was about to dismiss this petition on
merits, the learned counsel for the petitioner sought permission
to withdraw this petition, with liberty to raise all the points
before the trial Court.
https://hcservices.ecourts.gov.in/hcservices/

4. In view of the above, this Criminal Original Petition is
dismissed as withdrawn to raise all the points before the trial
Court. Consequently, connected miscellaneous petition is
closed.
