ORAL ORDER
 3 28-04-2015 The present application under Section 482 of the
Code of Criminal Procedure has been filed for setting aside the
order dated 09.05.2012 passed by the learned Sessions Judge,
Katihar in Criminal Revision No. 01 of 2011 by which the
prayer of the petitioner to set aside the order dated 22.11.2010
passed by the learned Judicial Magistrate, Katihar whereby he
has directed for framing of charges under Section 406 of the
Indian Penal Code and Section 138 of the Negotiable
Instruments Act, 1881 in Complaint Case No. 2123 of 2004 has
been rejected.

Patna High Court Cr.Misc. No.40508 of 2012 (3) dt.28-04-2015
2 / 2
2
Though the present application has been filed under
Section 482 of the Code of Criminal Procedure but, as a matter
of fact, it is a second revision which is barred under Section
397(3) of the Code of Criminal Procedure.
Accordingly, the application is dismissed as not
maintainable.
