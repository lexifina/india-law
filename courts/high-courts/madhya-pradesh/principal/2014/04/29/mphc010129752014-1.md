# High Court of Madhya Pradesh, WP/4716/2014, 2014-04-29

W.P. No. 4716/2014
29.4.2014
Shri Udayan Tiwari, learned counsel for the
petitioner.
The petition is directed against the order dated
11.2.2014 whereby the trial Court (Additional District
Judge, Maihar) in Civil Suil No. 01A/2013 has rejected the
petitioner's / plaintiff's application under Order 39 Rule 1
and 2 read with Section 151 of the Code of Civil
Procedure.
The order impugned is appealable under Order 43
Rule 1 (r) Code of Civil Procedure.
Faced with such situation, learned counsel for the
petitioner prays for withdrawal of the petition with liberty
to file an appeal under Order 43 Rule 1 (r) Code of Civil
Procedure against the order dated 11.2.2014 (supra).
Petition stands dismissed as withdrawn with the said
liberty.
Let certified copy of impugned order dated
11.2.2014 be returned to the petitioner on his filing true
copy thereof.
C.C. as per rule.
 (SANJAY YADAV)
 JUDGE
