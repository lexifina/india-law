Heard learned APP for the State on this application for condonation of
delay. There is delay of about 28 days in preferring the appeal along with
the application for leave to file appeal, challenging the acquittal of the
respondent. For the reasons mentioned in the application, the delay is
condoned and the application is allowed and accordingly disposed of. The
office to number the application for leave to file appeal.
