# High Court of Madhya Pradesh, WP/9554/2012, 2017-02-13

WP-9554-2012
(DR.B.P.CHOURIA Vs THE STATE OF MADHYA PRADESH)
13-02-2017
Shri Manish Tiwari, Advocate for the petitioner.
Shri Pushpendra Yadav, G.A. for the respondents/State.
With the consent of the parties finally heard.
Learned counsel for the parties during the course of
arguments fairly submit that the impugned order was passed on
28.04.2012. This order was stayed by this Court on 06.07.2012.
Interim order is still surviving. It is agreed that the administrative
exigency which was prevailing at the time of issuance of order
dated 28.04.2012 (Annexure-P/1) must be over by now. Hence,
the said order may be set aside by reserving liberty to the
department to pass fresh order if administrative exigency so
requires.
In view of the consensus arrived at, the impugned order
dated 28.04.2012 (Annexure-P/1) is set aside. Liberty as prayed
for is granted to the respondents.
Petition stands disposed of.
Certified copy as per rules.
(SUJOY PAUL)
JUDGE
