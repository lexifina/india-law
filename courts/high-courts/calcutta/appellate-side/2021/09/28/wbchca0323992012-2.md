# Calcutta High Court, CRR/2277/2012, 2021-09-28

41
g.b.
28.09.2021
Court No.34

 CRR 2277 of 2012
In Re: - An application under Section 482 read with Section 401
of the Code of Criminal Procedure;
 And
In Re: - Sukumar Adhikari & Ors.
 Petitioners
Mr. Arijit Ganguly
Mr. Saryati Datta
 ……..For the State
 The report submitted by the learned advocate for the
State is kept with the record.
 The revisional application was preferred challenging the
FIR registered in connection with Bhatar Police Station case no.
57/2012 dated 26.03.2012.
 Mr. Saryati Datta, learned advocate appears for the State
and submits a report. Report reflects that subsequently charge
sheet has been submitted and dates have been fixed for supply of
copies under Section 207 of the Code of Criminal Procedure.
 Having regard to the stage at which the petitioner
approached this court, I am of the opinion that there has been
changed of circumstances and the revisional application has
become infructuous due to filing of the charge sheet.
 Accordingly, CRR 2277 of 2012 is dismissed.
 Pending applications, if any, consequentially stand
disposed of.
 Interim order, if any, is hereby vacated.
 All parties shall act on the server copy of this order duly

downloaded from the official website of this Court.
-
 (Tirthankar Ghosh, J.)
