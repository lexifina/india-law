ORDER
By this petition, petitioner is challenging the order dated 11/03/2020
(Annexure P/3) whereby he has been directed to be transferred.
Learned counsel for the petitioner submits that this Court vide order
dated 19/03/2020 stayed the operation of the impugned order and, therefore,
the impugned order of transfer has not been implemented so far.
Reply has been filed by the respondents.
Considering the aforesaid, it can be gathered that still no administrative
exigency exists, therefore, the impugned order dated 11/03/2020 (Annexure
