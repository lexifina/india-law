BA.No.1747/2020 2
O R D E R
Dated this the 13th day of August 2020
The learned counsel for the petitioner wants to withdraw
this bail application with liberty to file it again. This Court
observed that the annexures produced along with this bail
application ought not have been the part of the bail application.
There is a chance to misuse such photos in future. Therefore,
Registry will return these original photographs produced along
with the bail application to the learned counsel for the
petitioner. This bail application is dismissed as withdrawn with
liberty to the petitioner to file it again if he is advised so.
