4) Today, we have perused the file of the
Selection Committee for Post Code No.09 and Post Code
No.10 whereupon, we find that the petitioner had never
applied for the Post Code No.09 i.e. Professor (Mass Media)
Specialization in Print Media. The file indicates the singular
application of the petitioner for Post Code No.10 i.e.
Professor (Mass Media)–Specialization in TV Journalism.
This would therefore make it apparent that though the
petitioner had never applied for the Post Code No.09, the
Selection Committee in its own wisdom treated the
candidature of the petitioner for the Post Code No.09 also
and recommended his name for the Post Code No.09. That
the petitioner had not applied for the Post Code No.09, is
further apparent as the file indicates 17 candidates had
applied for Post Code No.09, however, the name of the
petitioner does not figure there, out of those 17 persons 05
persons were held eligible for interview for the Post Code
No.09, in which also the name of the petitioner does not
figure. This would clearly indicate that the Selection
Committee, of its own did not have any jurisdiction to
consider the candidature of the petitioner for the Post Code
No.09 and make a recommendation to that effect, as all
that the Selection Committee is empowered to consider, is
the candidature of the candidate to the post to which
candidate has applied, specifically so, when the application
was in pursuance to an advertisement and was not a walk-in-interview.

5) Mr. Meghe, learned Counsel for the petitioner
has been unable to point out to us any application made by
the petitioner for Post Code No.09, and it is also the case of
the respondents that the petitioner had never applied for
the said post. If that be the case, the Selection Committee
could not have considered the request of the petitioner to
consider his candidature for the Post Code No.09, which is
the position as reflected on perusal of the Selection
Committee report (page 47). Though learned Counsel
Mr.Meghe, places reliance upon the Ordinance 38, all that it
prescribes is the procedure and norms for appointment and
nothing else. Though clause 10 of the said Ordinance
indicates that the Selection Committee may decide its own
method for evaluating the performance of the candidates,
such evaluation necessarily has to be in terms of the
application made by the candidate for a particular post and
not otherwise. The contention of learned Counsel Mr.Meghe,
that similar qualifications were prescribed for the Post Code
Nos.09 and 10 is only to be mentioned to be rejected as
what is necessary to note, is that the specialization
indicated in the last column of the advertisement, clearly
indicated the preference/requirement of specialization in
different fields, which was for the purpose of imparting
teaching in those fields.
6) It is therefore, apparent that since the
petitioner had never applied for the Post Code No.09, his
candidature could not have been considered by the
Selection Committee for the said post and the

recommendation in that regard thus would not be legal.
The appointment order dated 07/07/2009, therefore, has
rightly been refused to be approved by the Executive
Committee of the respondent No.1 and we do not see any
reason made out by the petitioner to interfere in the
impugned order dated 09/01/2023. The petition is
therefore, dismissed. No costs. The original file of the
selection process be returned back to the respondent No.1.
