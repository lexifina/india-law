3 05-02-2014 This application has been filed for restoration of MJC
No.3047 of 2012 which stood dismissed for default on account of
non-appearance of learned counsel for the petitioner on two dates.
Dismissal of a contempt application in default does not
constitute res judicata.
The application is dismissed.
 Petitioner is at liberty to file a fresh contempt
application.
