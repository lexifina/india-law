 ORAL JUDGEMENT

 	Both the counsel for the petitioner and the
 respondents are in agreement that cognate matter arising
 out of same impugned order challenged in this special
 civil application, being special civil application
 No.5508 of 1989 has already been decided by this Court on
 16th February, 1991 and that order has been set aside.
 In view of the fact that the order impugned in this
 special civil application has already been set aside by
 this Court, this petition also deserves acceptance.

 2.	In the result the petition is allowed. The order
 annexure-E dated 31-3-90 is quashed and set aside. Rule
 made absolute accordingly. No order as to costs.
