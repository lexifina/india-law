1. Writ petition is taken up for consideration when Mr.
Bhattacharya, learned advocate representing
petitioner submits that pursuant to order passed by
this Court on this writ petition police protection is
provided and petitioner has been able to run tea estate
with assistance of concerned police authorities.
2. State respondents are represented by learned
advocates.
3. Mr. Chatterjee, learned advocate representing
respondent nos. 5 to 14 submits that tea estate is not
being run following norms and as such, issue needs to
be gone into.
4. Considering the submission made on behalf of
petitioner and taking note of case made out in this writ

petition, no further order need be passed on this writ
petition.
5. Writ petition stands disposed of.
6. Concerned police authorities are directed to provide
protection to petitioner, if occasion so arises.
7. If respondent nos.5 to 14 find that tea estate of
petitioner is not being run following norms, in that
event leave is granted to respondent nos.5 to 14 to take
steps in accordance with law, if so advised.
8. Application, if any pending, also stands disposed of.
9. Parties to act on the server copy of this order duly
downloaded from the official website of this Court.
 (Saugata Bhattacharyya, J.)
