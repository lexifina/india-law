# High Court for the State of Telangana, WP/2711/2017, 2017-02-07

HONíBLE SRI JUSTICE CHALLA KODANDA RAM
WRIT PETITION No.2711 OF 2017
ORDER:
Learned counsel for the petitioner seeks permission of this Court
to withdraw the writ petition giving liberty to the petitioner to file a fresh
writ petition. Learned standing counsel for the respondent-Corporation
does not have any objections.
 Permission is accorded.
Accordingly, the writ petition is dismissed as withdrawn giving
liberty to the petitioner to file a fresh writ petition. No order as to costs.
As a sequel, the miscellaneous applications, if any, shall stand
closed. There shall be no order as to costs.
