O R D E R
Instant application is filed to direct the respondents to furnish
security for a sum of Rs.5,91,121.15, failing which pass an order of
attachment before judgment of the schedule property as morefully
described in the Judges Summons, attachment order transmitted
through Sub-Court, Salem.
2. Learned counsel appearing for the applicant submitted that
so far arbitration proceedings has not been invoked.
3. Though this Court, vide, order, dated 31/7/2019, directed to
report the status of the arbitration proceedings, so far, arbitration
proceedings has not been invoked. In such a view of the matter, this
Court is not inclined to pass any order.
4. Accordingly, instant application is closed. It is for the
applicant to work out his remedy for interim relief before the
Arbitrator.
