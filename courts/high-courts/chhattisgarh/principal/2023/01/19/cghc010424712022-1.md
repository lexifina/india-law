Mr. Aditya Tiwari, on behalf of Mr. Saurabh Kumar Pande,

The present MCC has been filed only so far as defect in the name of the
petitioner No.6 in the order Annexure P-1 dated 29.11.2022 passed in WPC
No.5202/2022.
Learned counsel for the petitioner submits that there is a typographical
error so far as name of the petitioner no.6 is concerned, wherein instead of
Kavita Verma the name has been reflected Kavit Verma.
The petitioner has filed the present MCC only seeking modification to
the aforesaid extent.
The limited prayer is not opposed.
Accordingly, MCC stands allowed.
The name of petitioner no.6 in order dated 29.11.2022 in WPC
No.5202/2022 shall be read as ‘Kavita Verma’ instead of ‘Kavit Verma’.
The present MCC accordingly stands allowed and disposed of.
