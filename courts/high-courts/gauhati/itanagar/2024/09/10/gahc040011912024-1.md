BEFORE
HONOURABLE MR. JUSTICE KARDAK ETE
ORDER
Date : 10.09.2024
Heard Mr. D. Panging, learned counsel for the applicant/respondent No.1
and Mr. A. Tatak, learned counsel for the opposite party/petitioner.
This is an application filed under Order XVII Rule 1 of the Code of Civil
Procedure, 1908, praying for adjournment of the connected election petition for
15(fifteen) days for filing of the written statement.
Mr. Tatak, learned counsel for the opposite party/petitioner has no
objection to the present application seeking time to file the written statement.
Having considered the grounds for seeking time to file the written
statement and the objection not being raised by the opposite party/petitioner, I
deem it appropriate to allow this application. Accordingly, the
applicant/respondent No.1 is granted 15(fifteen) days time to file written
statement.
The I.A. stands allowed and disposed of.
