 … for the petitioners.
Name not supplied by pvt. Respondents.

 … for the CESC
It is submitted on behalf of the petitioner
that they propose to file a fresh application for an
electricity connection at the subject premises.
The respondent-CESC Limited submits that in
case such application is filed, the same would be
considered in accordance with law.
On behalf of private respondent, it is
submitted that the petitioner has no locus to file
any application for a separate electricity
connection since the petitioner is an employee.
In view of the submissions made on behalf
of the petitioner i.e. that they propose to file an
application afresh, WPA 28236 of 2025 stands
dismissed.
It is made clear that there has been no
expression on the merits of the case and if any
proposed application is filed for a new

2
connection, the same would be considered in
accordance with law.
