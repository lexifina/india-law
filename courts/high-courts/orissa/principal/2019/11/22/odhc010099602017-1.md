# High Court of Orissa, CONTC/444/2017, 2019-11-22

21. 22.11.2019 This contempt petition has been filed by the
petitioner for non-compliance of the order of the Court
dated 23.11.2016 passed in W.P.(C) No.2286 of 2016.
 Learned A.G.A. for the State files an affidavit on
behalf of opposite party no.1 in Court today indicating
therein that the orders in question have already been
complied with. The same is taken on record.
 We have gone through such affidavit. In view of the
fact that the orders in question have already been complied
with, no further order is required to be passed in this case.
 Hence, the contempt proceeding is dropped.
Accordingly, the CONTC stands disposed of.
 Misc. Case(s)/I.A.(s) connected to the petition, if
any, is/are also disposed of.
 However, it is open for the petitioner to file an
application within thirty days from today for revival of this
petition in case of any difficulty.
 Issue urgent certified copy of this order as per
Rules.
