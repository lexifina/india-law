IN APPLN/2624/2013
ARUN S/O PANDURANG GARAD & ORS.
VERSUS
THE STATE OF MAHARASHTRA & ORS.

PER COURT :-
The delay in filing this application stands condoned.
2. The learned counsel appearing for the applicants
submits that, already all office objections have been removed. In the
light of the statements made by the learned counsel appearing for
the applicants and the contents of the application, we allow this
application and restore the Criminal Application No. 2624/2013 to
its original file. The application stands disposed of.
3. The learned counsel appearing for the applicants prays
10 days time so as to file appropriate application for amendment in
Criminal Application No.2624/2013 so as to take exception to the
charge-sheet. Such application to be filed on or before 20th March,
2015, failing which the application shall stand dismissed. In case
the application is filed, list on 24th March, 2015.
( A.M. BADAR, J. ) ( S.S. SHINDE, J. )
