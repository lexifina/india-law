# High Court of Orissa, OJC/6655/1999, 2019-11-20

03. 20.11.2019 Learned counsel for the petitioner seeks
permission to withdraw the writ petition with liberty to
revive this petition if any cause of action still survives.
 Permission for withdrawal is granted.
 The writ petition stands dismissed as withdrawn.
 All connected Misc. Case(s)/I.A(s), if any, is/are
accordingly dismissed.
 However, it is open for the petitioner to revive this
petition within 30 days if any cause of action still survives.
