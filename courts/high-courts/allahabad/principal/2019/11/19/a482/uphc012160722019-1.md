# Allahabad High Court, A482/40782/2019, 2019-11-19

Court No. - 76
Case :- APPLICATION U/S 482 No. - 40782 of 2019
Applicant :- Shiv Kumar Singh
Opposite Party :- State of U.P. and Another
Counsel for Applicant :- Ajeet Singh
Counsel for Opposite Party :- G.A.
Hon'ble Mrs. Manju Rani Chauhan,J.
Learned counsel for the applicant states that since the reasons for
delay in filing the present application has not been explained in the
present application, he does not want to press the present
application and therefore, the present application be dismissed as
not pressed with liberty to file fresh.
Prayer made for is bona fide. Accordingly, the same is allowed.
The present application is dismissed as not pressed with liberty to
file fresh.
Certified copies of all the documents enclosed in the present
application shall be given to the learned counsel for the applicant
after retaining the photo copies of the same to be kept on record.
(Manju Rani Chauhan, J.)
Order Date :- 19.11.2019
