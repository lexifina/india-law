# High Court of Orissa, ABLAPL/4482/2019, 2020-08-25

3 25.08.2020 The matter is taken up through video conferencing.
 In view of the submission of the learned counsel
for the State that no case has yet been registered at any
of the Police Station as indicated in the roder dated
09.04.2019; learned counsel for the petitioners prays for
withdrawal of this application with liberty to file the same
in case cause of action so arises in future.
 Granting the liberty as aforesaid, the ABLAPL
stands disposed of. Interim order dated 09.04.2019 does
not more survive.
