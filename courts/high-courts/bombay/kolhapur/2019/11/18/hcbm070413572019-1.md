P. C. :
. The application is filed by original complainant challenging the
acquittal order of some of the accused. The convicted accused have
already preferred Appeals which are admitted. Be that as it may, State
Government has also filed separate Application bearing No. 112 of 2019
for leave to file Appeal in which we have granted leave to file Appeal.
In that view of the matter, we grant leave to file Appeal in this
matter also. Appeal is admitted. Registry is directed to number the
Appeal. Action under section 390 is directed. To be heard along with
Criminal Application No. 112 of 2019.
