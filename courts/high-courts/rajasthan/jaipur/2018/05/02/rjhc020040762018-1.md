Judgment / Order
02/05/2018
Application has been moved for correcting of the order. It is
stated that there is a typographical mistake crept in the order. In
the last line of the order, instead of order dated 26.10.2012, it
should be order dated 6.5.2014.
Having heard learned counsel, this court is satisfied that the
order requires correction, the date 26.10.2012 is deleted from the
order dated 6.4.2018 and instead order dated 6.5.2014 is
directed to be mentioned in para 3. The writ petition is disposed
of by setting aside the orders passed by authority dated
11.1.2017 and 6.5.2014.

(2 of 2) [WMAP-173/2018]
Application is accordingly disposed of.
