# High Court of Madhya Pradesh, CRA/469/2017, 2017-04-25

Cra.469.2017
Chotu Singh Sikarwar @ Hero Vs. State of Madhya Pradesh
25.04.2017
Shri Bhupendra Singh Chouhan and Shri
Ankit Saxena, Advocates for the appellant.
Shri Mohd. Irsahd, Panel Lawyer, for the
respondent/State.
Heard the learned counsel for the parties.
At this stage, as prayed by the learned
counsel for the appellant, the present appeal
filed by appellant, namely, Chotu Singh Sikarwar
@ Hero against the order dated 30.03.2017
passed by the Special Judge [Scheduled Castes
and Scheduled Tribes (Prevention of Atrocities)
Act], Gwalior (M.P.) in Bail Application
No.99/2017, is hereby dismissed being
withdrawn with the liberty that if any repeat
application is filed before the trial court then the
same shall be considered by the trial court. Its
previous order shall not create any bar when
hearing of that application will be started and if
application is not accepted appellant would be
free to file an appeal afresh at that time.
 (N.K. Gupta)
 Judge
