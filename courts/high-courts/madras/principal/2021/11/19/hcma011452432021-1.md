O R D E R
The order challenged in this Revision is the order passed in the
application under Order XXI Rule 97 of the Code of Civil Procedure,
determining the questions under Rule 98 of Order XXI of the Code of Civil
Procedure.
2. In terms of Rule 103 of Order XXI of the Code of Civil Procedure,
such an order is made specifically appealable and is deemed to be a decree
of a civil Court. Therefore, this Revision is not maintainable. It is open to
the petitioner to take back the papers and file an appeal before the
competent Court.
3. The Registry is directed to return certified copies of the order that
has been filed along with this Revision.
4. The Executing Court is required to adjourn the Execution Petition
in E.P.No.9 of 2017 by 15 days to enable the petitioner to move the
appellate Court. No costs. Consequently, the connected miscellaneous
