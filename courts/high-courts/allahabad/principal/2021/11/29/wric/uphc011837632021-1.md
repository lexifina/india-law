# Allahabad High Court, WRIC/30451/2021, 2021-11-29

Court No. - 7
Case :- WRIT - C No. - 30451 of 2021
Petitioner :- Ram Milan (Since Deceased) And 5 Others
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Anil Kumar Yadav
Counsel for Respondent :- C.S.C.,Azad Rai
Hon'ble Dinesh Pathak,J.
Heard Shri Anil Kumar Yadav, learned counsel for the
petitioners, learned counsel for the Gaon Sabha and the learned
Standing Counsel for the State respondents.
After due deliberations at length, learned counsel for the
petitioners prays for to dismiss the present petition as
withdrawn with liberty to file a fresh petition so as to enable
him to file better particulars and details.
Learned Standing Counsel as well as counsel for the Gaon
Sabha have no objection to the prayer so made.
The prayer so made is allowed. The writ petition is dismissed
as withdrawn with liberty to file a fresh petition.
Order Date :- 29.11.2021
