ORAL ORDER
2 06-03-2012 The petitioner has filed this writ application with a
prayer that the enquiry set up by Letter No. 1122, dated 14.6.2011
should be concluded expeditiously. Apparently the enquiry was
ordered with respect to the caste certificate of Jaigun Nisha,
presently elected member of Panchayat Samiti from Panchayat
Raj, Kohila. If any such enquiry has been ordered by the
competent authority then notices should be issued to the party in
question before any order is passed in the matter.
This writ application is accordingly, disposed of.
Sanjay/-
