# High Court of Madhya Pradesh, WP/16107/2014, 2014-12-02

W. P. No.16107/2014
2.12.2014
Shri Ashok Kumar Pali, counsel for the petitioner.
Shri Swapnil Ganguly, Dy. Govt. Advocate General for
respondents/State.
Heard counsel for the parties.
For the reasons mentioned in the reply affidavit, we find
no basis to interfere in this Public Interest Litigation, much less
to issue directions to the State to continue with the Sattidhar
project. The reply affidavit points out that the command area of
the said project is now overlapping with the command area of
“Pench diversion project” (Major). Thus, the villagers would be
getting water for irrigation from Pench diversion project
(Major). As a result, the State has decided not to continue with
the Sattidhar project.
There is no reason to doubt the correctness of this
position stated on affidavit of Executive Engineer, W.R.D.,
Chhindwara.
Hence, this petition should fail and the same is dismissed.
(A. M. Khanwilkar) (Sanjay Yadav)
 Chief Justice Judge
Anchal
