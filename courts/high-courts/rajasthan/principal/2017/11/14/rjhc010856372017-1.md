HON'BLE MR. JUSTICE SANGEET LODHA
Order
14/11/2017
This misc. application has been filed by the petitioner
seeking correction in the cause title of Civil Writ Petition
No.9583/17 which already stands disposed of vide order dated
21.8.17.
It is submitted that the name of the petitioner is “Rama
Kishan Joshi”, however, inadvertently, the same has been
mentioned in the cause title as “Ram Kishan Joshi”.
The bonafide error deserves to be permitted to be rectified.

(2 of 2)
[WMAP-252/2017]
Accordingly, the application is allowed. A copy of this order
and amended cause title already filed be placed in the file of Civil
Writ Petition No.9583/17.
