CORAM: HONOURABLE MR. JUSTICE SANJAY PRIYA
ORAL ORDER
17 01-07-2019 First Appeal was dismissed on 7.3.2007 by learned
Single Judge of this Court as having become incompetent. This
M.J.C. application has been filed to set aside the order dated
7.3.2007.
None appeared on behalf of the petitioner.
This Court finds that since First Appeal has already
been dismissed by order dated 7.3.2007 as having become
incompetent, the instant M.J.C. application filed for setting
aside the order dated 7.3.2007 has no merit.
This Court is of the view that this application is not
maintainable.
This M.J.C. is accordingly dismissed.
