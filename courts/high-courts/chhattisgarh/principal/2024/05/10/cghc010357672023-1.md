Heard.
1. The application has been filed for correction of khasra number
which has been shown as 213 whereas it is stated that the khasra number
is 2/3 which would be evident from the issue and the document Ex.P-2.
2. We went through the issues wherein it shows that the disputed
khasra number is 2/3 not 213. Consequently, it shows that typographical
mistake has occurred at para 24. Accordingly, the same is corrected and
the khasra number be read as 2/3 instead of 213. Decree be modified
accordingly.
3. With such observation, MCC stands disposed of.
