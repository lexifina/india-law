ORAL ORDER
(PER: THE HON'BLE MR JUSTICE ANANT RAMANATH HEGDE)
1. This petition is filed assailing the order dated
16.12.2023 rejecting the application filed under
Order XXI Rule 58 of the Code of Civil Procedure,
1908 (for short ‘Code’) by the pendente lite
purchaser in a suit for specific performance.
2. The suit for specific performance is decreed and the
plaintiff has filed execution petition. The pendente
lite purchaser has filed application under Order XXI
Rule 58 of the Code claiming right over the
property.
3. It is the contention of the learned counsel for the
petitioner that the pendente lite purchaser has filed
an appeal against the decree, which is an ex- parte
decree. It is submitted that appeal is dismissed for
non-prosecution and an application is filed to
restore the appeal and same is pending.

4. Under these circumstances, the Court does not find
any error in the order rejecting the application filed
under Order XXI Rule 58 of the Code.
5. Hence, the following:
ORDER
i. The petition is dismissed.
ii. The Executing Court can proceed with the
execution of the decree.
iii. However, it is made clear that merely because
the decree is executed, it does not render the
miscellaneous petition pending before the
jurisdictional Court infructuous. The
Miscellaneous Petition has to be heard in
accordance with law.
iv. The sale deed to be executed shall be subject
to result of the suit as decree is in a way still
under challenge.
