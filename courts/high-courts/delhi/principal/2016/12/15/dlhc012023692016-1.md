Crl. M.A. 14469/2016 (Delay)
There is a delay of 148 days in filing the appeal. The only plea taken
in this application is that after passing of the impugned judgment the file
moved from one table to another for approval due to which it took time to
file the appeal. It is submitted that delay is neither intentional nor deliberate.
The reasons seeking condonation of delay are totally vague. No
details have been given as to with which authority the file remained pending
and for what period. There is nothing on record to show that prompt action
was taken in taking the approval for filing the appeal. Merely on this bald
plea that file moved from one table to another which took time in taking the
decision to file the appeal will not be sufficient to condone such a long

delay. Neither sufficient nor cogent reasons have been given for this delay.
For the foregoing reasons, application is dismissed, consequently,
appeal is also dismissed being barred by time. Miscellaneous application is
disposed of as infructuous.
A.K. PATHAK, J.
