By way of this Interlocutory Application (Crl.), the applicant has sought for

Page No.# 2/2
correction of the case number in the cause title of Crl.Rev.P./192/2019 (D/O) and
has also submitted that the case number has been wrongly written as “F.C. Misc.
Case No.525/2018”, for which the same has been recorded in the order dated
08.02.2022. Now, prayer has been made to allow the applicant to correct the cause
title by inserting proper case number as “F.C. Misc. Case No.515/2018” instead of
F.C. Misc. Case No.525/2018, which has stated to be cropped up inadvertently.
Having regard to the submission so made and the documents annexed, the
applicant is hereby allowed to correct the case number in the cause title of
Crl.Rev.P./192/2019 (D/O), which is F.C. Misc. Case No.515/2018 pending in the
Principal Judge, Family Court, Dhubri.
Consequently, the order dated 08.02.2022 be also read as F.C. Misc. Case
No.515/2018.
The Interlocutory Application stands disposed.
