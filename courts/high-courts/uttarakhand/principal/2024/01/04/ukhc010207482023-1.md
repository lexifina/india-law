4. In this writ-petition filed in public interest,
petitioner has raised the issue of lack of
infrastructure in educational institutions run by a
Society.
5. It is not in dispute that intermediate college
run by such Society is receiving financial aid from
the State Government. Before granting financial aid,
State Government ensures that all the norms
regarding infrastructure / faculty, etc. are fulfilled.
6. Learned State Counsel submits that petitioner
appears to have some issue with management of the
concerned college. Thus, this PIL is motivated.
7. We find force in the said contention. Be that
as it may. Since the petitioner has raised issue in
respect of institutions run by a particular Society,
therefore, this writ petition does not appear to be
filed in public interest. We, accordingly, dismiss
this writ petition with liberty to the petitioner to
make representation to the concerned authority.
