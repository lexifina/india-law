# High Court of Madhya Pradesh, WA/404/2012, 2012-09-05

W.A. no. 404/2012
05/09/2012
Mr. K.C. Raikwar, learned counsel for the appellant.
Heard on the question of admission.
By this intra-court appeal, the appellant has
challenged the order dated 29/08/2012, by which the learned
Single Judge issued notice to the respondents on payment of
PF within seven days. In case, if there is any urgency, learned
counsel for the appellant could have filed the application for
passing of the interim order prior to 05/09/2012, which has not
been done by the appellant. Therefore, we are of the view that
no case to interfere with the said order as prayed by the
learned counsel for the appellant is made out. Present appeal
has no merit and accordingly, the same is dismissed in limine.
C c as per rules.
( P.K. JAISWAL ) (M.C. GARG)
 JUDGE JUDGE
