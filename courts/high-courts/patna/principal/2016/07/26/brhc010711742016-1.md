ORAL ORDER
2 26-07-2016 Heard learned counsel Mr. Rajive Ranjan Singh for the
petitioners.
By the impugned order dated 04.12.2015 passed in Title
Suit No.535 of 2010 the learned Subordinate Judge-IX,
Kahalgaon, Bhagalpur has rejected the injunction application
under Order 39 Rule 1 and 2 of the Code of Civil Procedure filed
by the plaintiffs-petitioners.
Since the order is appealable under Order 43 Rule 1 (r)
of the Code of Civil Procedure, this writ application is not
maintainable. If so advised, the petitioners may avail the forum of
appeal under the Code.
Accordingly, this writ application is dismissed as not
maintainable.
Harish/-
(Mungeshwar Sahoo, J)
