# Allahabad High Court, SAPL/1103/1995, 2023-03-14

Court No. - 5
Case :- SECOND APPEAL No. - 1103 of 1995
Appellant :- Jafar Uddin
Respondent :- Hari Shanker And Others
Counsel for Appellant :- J.P.Singh,Babita Upadhyay,Haseen
Ahmad,Sanjeev Kumar Gaur,Saurabh Basu,Virendra Pal Varshney
Counsel for Respondent :- M.K. Gupta,Anuj Agrawal,Ravi
Anand Agarwal,Shreya Gupta
Hon'ble Prakash Padia,J.
The appellant has moved a withdrawal application No.10 of 2023
for dismissing the second appeal, substitution application and
restoration application as withdrawn. The withdrawal application
is supported by an affidavit of elder son of appellant namely
Sararuddin Ahmad.
It is stated in paragraph-3 that the deponent does not want to press
present second appeal, substitution application and restoration
application.
Copy of the aforesaid applications have been served upon Shri
Shreya Gupta, learned counsel for the opposite party.
She has no objection if withdrawal applications is allowed.
Withdrawal Application is allowed.
Accordingly, second appeal, restoration application as well as
substitution application are dismissed as withdrawn.
Order Date :- 14.3.2023
