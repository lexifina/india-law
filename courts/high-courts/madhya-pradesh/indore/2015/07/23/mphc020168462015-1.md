# High Court of Madhya Pradesh, MCRC/6245/2015, 2015-07-23

MCRC No.6245/2015
23.07.2015
Shri Sapnesh Jain, counsel for the applicant.
Ms. Mini Ravindran, counsel for the respondent/State.
Heard on application filed under section 482 of Cr.P.C.
This application is filed for review of order passed by this Court
in MCRC No.5657/2015 dated 08.07.2015.
According to the counsel for the applicant, crime number
mentioned in the order was not correct. The actual crime number
is 459/2014, however, by mistake, Crime No.469/2014 was
mentioned in the order of the lower court, therefore, the same was
mentioned in the application and in the order of this Court.
On due consideration, the application is allowed. It is
directed that in order passed in MCRC No.5657/2015 on
08.07.2015 in place of 'Crime No.469/2014, Crime No.459/2014'
be read.
With this direction, the application stands disposed of.
Certified copy as per rules.
(Alok Verma)
 Judge
