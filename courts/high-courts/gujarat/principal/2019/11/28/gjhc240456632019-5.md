 ORAL ORDER
It appears that the chargesheet is already filed in these
matters.
In light of the above, learned advocate for the petitioners
seeks permission to withdraw present petitions with a liberty to
file discharge application and also to file appropriate
proceedings either u/s 397 or 482 of the Code of Criminal
Procedure, 1973 before appropriate competent Court, after
remedy to file discharge application is availed.
Permission is granted. The petitions stand disposed of as
withdrawn with above liberty.
It is clarified that this Court has not examined the merits
of the present petitions.
(S.H.VORA, J)
