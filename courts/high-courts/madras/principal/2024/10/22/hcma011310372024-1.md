# Madras High Court, A/5413/2024, 2024-10-22

A.No.5413 of 2024
in
CS.No.751 of 2010
A.A.NAKKIRAN, J.
This application has been filed to condone the delay of 4846 days in
seeking to file the written statement in the above suit.
2. Heard both sides.
3. Learned counsel for the respondent has strongly opposed to allow this
application.
4. Being satisfied with the reasons stated in the affidavit filed in support of this
application, this court is inclined to allow this application on payment of cost of
Rs.5,000/- (Rupees Five Thousand Only) to the learned counsel for the respondent on or
before 29.10.2024.
5. Accordingly, this application is allowed.
6. Post the main case before this court on 29.10.2024.
