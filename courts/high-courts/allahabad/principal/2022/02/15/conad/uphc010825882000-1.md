Hon'ble Dr. Kaushal Jayendra Thaker,J.
Hon'ble Ajai Tyagi,J.
Order on Civil Misc. Delay Condonation Application
Heard.
This is an application seeking condonation of delay in filing the
appeal.
Cause shown for the delay is sufficient.
Delay is condoned.
This application is, accordingly, allowed.
Order on Appeal
This appeal challenges the order of learned Single Judge dated
13.9.2000 which reads as under :
"...............................The respondents have filed a counter affidavit in
which it has been stated that the order passed by this Court has already
been complied with. There is no wilful disobedience.
There is no necessity to take further action on this contempt application.
Notices are discharged. The contempt application is hereby dismissed."
We are convinced that there are no grounds continuing.
This contempt appeal is, therefore, dismissed.
