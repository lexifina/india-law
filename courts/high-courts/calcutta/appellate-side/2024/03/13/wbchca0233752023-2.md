# Calcutta High Court, CRR/1783/2023, 2024-03-13

D/L47
13.03.2024
Bpg.
 C.R.R.1783 of 2023
 Anup Kumar Jana and others
 Versus
 The State of West Bengal and another

None appears for the petitioners.
No accommodation has been sought for.
Earlier, the revisional application appeared on
14.12.2023 when none represented the petitioners. Today, when the
revisional application has been called, none represented the
petitioners. The revisional application has been called on several
occasions. Petitioners seem to be not interested to pursue the
revisional application.
Accordingly, the revisional application being CRR 1783 of
2023 is dismissed for default.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
 (Tirthankar Ghosh, J.)
