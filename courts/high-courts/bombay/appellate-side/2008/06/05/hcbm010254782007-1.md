 2. By an order dated 20.9.2006, the application
 filed by the State for cancellation of bail was
 rejected by learned Ad-hoc Additional District Judge-2
 & Additional Sessions Judge, Raigad-Alibag. The State
 is aggrieved by the said order dated 20.9.2006.
 Considering the nature of the order passed by the
 learned Additional Sessions Judge, it is clear that a
 Criminal Application as has been filed by the State.

 ( 2 )
 It is not maintainable. In view of this observation,
 learned A.P.P. applies for withdrawal of the Criminal
 Application and seeks liberty to file appropriate
 proceedings so as to challenge the order dated
 20.9.2006. Request is granted. Liberty as prayed is
 granted.
