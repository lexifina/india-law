# Calcutta High Court, CRR/1619/2021, 2023-05-03

D/L38
03.05.2023
Bpg.

 C.R.R.1619 of 2021
In Re: An application under Sections 401 and 482 of the Code of
Criminal Procedure, 1973;
 Chandan Mondal and others
 Versus
 The State of West Bengal and another
Mr. Dipanjan Datta,
 Mrs. Rituparna Saha.
 …for the opposite party no.2.
Mr. Arijit Ganguly,
 Ms. Debjani Sahu.
 …for the State.
None appears for the petitioners.
Mr. Arijit Ganguly, learned advocate appearing for the
State submits a status report.
Let the report be kept with the record.
Learned advocate for the private opposite party no.2 is
present.
I have considered the report so submitted which reflects
that the police authorities after completion of the investigation
submitted charge-sheet before the jurisdictional court. I have
considered the enclosures to the revisional application, which do
not reflect that the copies under Section 207 of the Code of Criminal
Procedure were supplied to the accused persons.
Considering the stage at which the petitioners
approached this Court, I am of the view that the present application
was preferred at a premature stage.

2
Petitioners would be at liberty to canvass such points
after receiving the documents under Section 207 of the Code of
Criminal Procedure before the jurisdictional court under Section
239 of the Code of Criminal Procedure and thereafter approach this
Court.
With the aforesaid observations, CRR 1619 of 2021 is
disposed of.
Pending application, if any, is consequently disposed of.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
 (Tirthankar Ghosh, J.)
