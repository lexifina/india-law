# Patna High Court, CR. WJC/1101/2008, 2008-12-02

IN THE HIGH COURT OF JUDICATURE AT PATNA
 CR. WJC No.1101 of 2008
 BRAJ KISHORE SINGH
 Versus
 STATE OF BIHAR
 -----------
2 2.12.2008 It appears that the petitioner has already moved this
Court against the order dated 24.5.2005 which has been rejected
by a Bench of this Court in Cr. Rev. No.549 of 2005 by order
dated 19.8.2008. In view of the aforesaid fact, this writ application
is not maintainable .
It will be open to the petitioner to file appropriate
application before appropriate forum, if so advised, if there is any
new cause of action.
With the aforesaid observation this writ application is
dismissed.
Anilksinha (Samarendra Pratap Singh,J.)
