ORDER
This Criminal Original petition has been filed to call for
the records relating to the FIR in Crime No.411 of 2016 pending
on the file of the Nagapattinam Town Police Station,
Nagapattinam District and quash the same.
2. The learned Additional Public Prosecutor, on
instructions, would submit that the respondent police have
already filed a final report and the same has been taken on file
in C.C.No.617 of 2018, on the file of the learned Judicial
Magistrate No.I, Nagapattinam.
https://hcservices.ecourts.gov.in/hcservices/

3.In view of the above, no further orders can be passed by
this Court. Accordingly, the Criminal Original petition is
closed. Consequently, connected miscellaneous petition is
closed.
