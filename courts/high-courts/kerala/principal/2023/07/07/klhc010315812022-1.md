ORDER
When this bail application came up for consideration, learned
Public Prosecutor submitted that the final report in Crime
No.212/2022 of Valapattanam Police Station is already filed before
the competent court. If that is the case, this bail application need not
be retained.
2. It is submitted that the second petitioner has already
arrested and released on bail. The first petitioner is free to approach
the competent court with appropriate application for bail and if such
an application is received, the same will be considered by the
competent court in, accordance with law, taking note of the fact that,
there was an interim order from this Court.
With the above observation, the bail application is disposed of.
