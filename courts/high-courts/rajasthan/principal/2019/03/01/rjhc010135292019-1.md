JUSTICE DINESH MEHTA
Order
01/03/2019
The present writ petition is directed against the order dated
16.02.2019, passed by learned Additional District Judge No.4,
Jodhopur Metropolitan whereby the petitioner’s request for ad
interim order has been refused.
According to this Court, under Order XLIII Rule 1(r) of the
Code of Civil Procedure an appeal is required to be filed.
The writ petition is not a proper remedy. Hence, it is
dismissed.
The stay application No.3035/2019 is also dismissed.
