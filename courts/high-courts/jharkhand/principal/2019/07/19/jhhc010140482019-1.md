03/19.07.2019 Heard learned counsel for the parties.
 The present CMP has been filed for modification of the order dated
04.02.2019 passed in W. P. (S) No. 6126 of 2011.
 It has been submitted by the learned counsel for the petitioner that
there is typographical error in the last 2nd para in the 2nd page of the order
dated 04.02.2019 passed in W. P. (S) No. 6126 of 2011, where instead of
‘06.06.2009’, ‘06.06.2003’ has been typed.
 Therefore, it should be read as ‘06.06.2009’ in place of
‘06.06.2003’ in the last 2nd para in the 2nd page of the order dated
04.02.2019 passed in W. P. (S) No. 6126 of 2011.
 The order dated 04.02.2019 is modified to the extent as noted
above.
 Let this order be read along with order dated 04.02.2019.
 With the above modification, the present CMP stands disposed of.

 (Rajesh Kumar, J.)
