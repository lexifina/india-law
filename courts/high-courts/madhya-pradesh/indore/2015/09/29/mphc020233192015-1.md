# High Court of Madhya Pradesh, MCRC/8624/2015, 2015-09-29

M.Cr.C.No.8624/2015
29.09.2015
Shri A.K.Saraswat, learned counsel for the applicant.
Shri Mukesh Parwal, learned Govt.Advocate for the
respondent/State.
Learned counsel for the applicant submits that
inadvertently the application is filed under Section 438 Cr.P.C.
The applicant is in custody and therefore application should
have been filed under Section 439 Cr.P.C. He seeks to
withdraw this application with liberty to file another application
under Section 439 Cr.P.C.
Prayer allowed.
Accordingly, this application is dismissed as withdrawn
with liberty as aforesaid.
C.C.as per rules.
( ALOK VERMA)
 JUDGE
