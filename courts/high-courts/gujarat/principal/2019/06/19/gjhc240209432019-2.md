ORAL ORDER
Learned advocate for the applicant does not
press this application as the trial is already
commenced and more than ten witnesses are examined.
However, it is requested that if the trial is not
concluded within a period of four months, liberty be
reserved to file a fresh application.
In view of the above submission, the application
stands disposed of, as not pressed. However, liberty
is reserved to the applicant to file a fresh
application, if the trial is not concluded within a
period of four months.
