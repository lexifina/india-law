HON'BLE MR. JUSTICE VINIT KUMAR MATHUR
Order
15/05/2023
An application has been filed seeking correction in the order
dated 27.09.2022 passed by this Court in S.B. Civil Writ Petition
No.11108/2022.
Learned counsel for the applicant submits that due to
inadvertent mistake, the name of the Course in Para No.1 of the

[2023/RJJD/015329] (2 of 2) [WMAP-102/2023]
order dated 27.09.2022 is shown as “Post Basic B.Sc. (N)”,
whereas it should have been “B.Sc. (N)”. He, therefore, prays that
the name of Course in the order dated 27.09.2022 may kindly be
corrected.
For the reasons mentioned in the application, the same is
allowed. The name of Course in Para No.1 of the order dated
27.09.2022 be read as “B.Sc. (N)” instead of “Post Basic B.Sc.
(N)”.
