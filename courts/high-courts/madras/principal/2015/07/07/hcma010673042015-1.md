ORDER
The petitioners are the employees of the second respondent
Co-operative Society. They have questioned the impugned order
of the first respondent Deputy Registrar dated 10.06.2015
directing the second respondent to impose same punishment to the
petitioners. It is relevant to extract the following passage in
the impugned order.

"nkYk ; 2 gzpahsh ;fSf ;Fk ; xnu khjphpahd jz ;lid mspj ;J xG' ;F eltof ;if
Kot [ fl ;LkhWk ;. jtwpdhy ; ,jdhy ; Vw ;gLk ; epjpapHg ;g [f ;F r';f jiytUk ;. eph ;thff ;
FGt [k ; bghWg ;ngw ;f nehpLk ; vdt [k ; bjhptpj ;Jf ; bfhs ;fpnwd ;.
2. The concerned disciplinary authority is the second
respondent. In my considered view, the second respondent alone
can decide about the punishment. The first respondent cannot
issue a direction as to what punishment the second respondent
could impose. It is for the second respondent to decide based on
the materials available on record.
3. In these circumstances, the impugned order of the first
respondent dated 10.06.2015 is set aside and the Writ Petition
is allowed. The first respondent is at liberty to pass an order
relating to proceedings under Section 81 of the Tamil Nadu Co-operative Societies Act. This could not preclude the first
respondent to issue fresh order. But the first respondent could
not issue a direction to the second respondent relating to
imposition of punishment in a disciplinary matter. The second
respondent is at liberty to take appropriate action based on the
materials available on record.

4. No costs. The connected Miscellaneous Petitions are
closed.
