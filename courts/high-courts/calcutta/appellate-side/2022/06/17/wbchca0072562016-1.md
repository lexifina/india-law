# Calcutta High Court, CRR/269/2016, 2022-06-17

17.06.2022
S/L No.8
 KS

 C.R.R. 269 of 2016
 Mrs. Tarannum Banu
 -Vs.-
 The State of West Bengal & Anr.

The petitioner filed this revisional application under Sections 482
read with Section 401 of the Code of Criminal Procedure praying for
quashing of the charge-sheet in G.R. Case No.2894 of 2015 corresponding to
Phansidewa Police Station Case No.372 of 2015 under Sections 363/ 364A/
34 of the Indian Penal Code, pending before the Learned Additional Chief
Judicial Magistrate, Siliguri.
On call none appears for the petitioner and opposite party nos.1 and
2.
On a perusal of record, it appears that there is some typographical
errors in page no.2 of the revisional application, wherein it has been
mentioned that the case is pending before the Learned Additional Chief
Judicial Magistrate, Hooghly at Serampore. The petitioner should have
been diligent in filing the application before this Court. The order was
passed for the last time on 04.08.2017. Thereafter, no steps taken by the
petitioner for extension of the interim order.
Accordingly, the revisional application is dismissed for default.
Let a copy of this order be communicated to the Learned Additional
Chief Judicial Magistrate, Siliguri for information.

2
All parties shall act on the server copy of this order downloaded
from the official website of this Court.
 (Ananda Kumar Mukherjee, J.)
