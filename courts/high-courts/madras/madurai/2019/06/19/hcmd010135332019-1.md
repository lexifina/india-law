O R D E R
This Criminal Original Petition has been filed to direct
the respondent to file a final report in Crime No.209 of 2018 on
the file of the respondent Police.
2.When the matter was taken up for hearing, the learned
Government Advocate (Crl.side) submitted that the final report has
already been filed in Crime No.209 of 2018 on the file of the
Solavanthan Police Station. The final report was submitted as
early as on 20.01.2019. The final report has not been returned so
far. It is further submitted that there are no defect in the
final report.
3.In any event, the jurisdictional Magistrate should either
take the final report on file or return it citing appropriate
reason. Keeping the final report pending without taking on file
for more than six months is clearly not acceptable. In any event,
it is only the statement made by the respondent police. If the
final report is still pending without being taken on file, the
jurisdictional Magistrate shall immediately take it on file, if it
is otherwise in order.
4.This Criminal Original Petition is ordered accordingly.
The Registrar(Judicial) of this Court is called upon to find out
