Crl.M.A.13159/2019
1. This is an application for withdrawal of the bail
application.
2. Learned counsel for the petitioner submitted that the
matter is fixed for arguments before the Trial Court on the point
of charge today itself, i.e, 8.7.2019.
3. Learned counsel for the petitioner seeks permission to
withdraw the bail application with liberty to file the same after
framing of charge, if any.
4. Accordingly, the application is allowed and the bail
application is dismissed as withdrawn, with liberty as prayed. It
is clarified that this Court has not expressed any opinion on the
merits of the bail application.
