Application bearing No.CRM-47349-2023 is filed so as to
pre-pone the main case, i.e. CRM-M-49347-2023, which is fixed for
10.01.2024 (wrongly mentioned as 03.11.2024). Further permission is
sought, so as to withdraw the main petition.
As per request, the main case is pre-poned today and is taken
on Board today itself. Application stands allowed accordingly.
In view of the prayer made in the application and in view of
the statement made by learned counsel for the petitioner, main petition,
i.e. CRM-M-49347-2023 is hereby dismissed as withdrawn.
