 The order impugned before this Court is the order dated
16.05.2014 vide which the application filed by the petitioner under
Order XXXIX Rules 1 & 2 of the CPC in a pending suit had been
dismissed. There is a specific provision in the Statute book i.e. the Code
of Civil Procedure which is contained in Order XLIII of the CPC which
provides that for a dismissal of an application under Order XXXIX
Rules 1 & 2 of the CPC, the remedy is to file an appeal.
 Present petition filed under Article 226 of the Constitution of
India which is only an alternate remedy is not maintainable. Dismissed.
 INDERMEET KAUR, J
