1. This is an application for condonation of delay
of 828 days caused for filing restoration application.

application, the application is allowed in the interest of
justice.

restoration application is condoned.
6. The application is disposed of.
MISC. CIVIL APPLICATION ST. No.12865 OF 2024.
1. This is an application for restoration of the
appeal.
2. Perused the application.

cao921.24.odt 2/2
3. Heard learned Advocate of the applicant.
4. Learned Advocate for the appellant-applicant
submits that paper-book is ready and it will be filed within
a week.
5. Considering the reasons stated in the
application and the submission of learned Advocate for the
appellant-application, the application deserves to be
allowed in the interest of justice.
6. The application is allowed.
7. The conditional order of this Court dated
19.6.2021 is set aside and the appeal is restored on its
original number, subject to filing of the paper-book.
8. If the paper-book is not filed within a week,
the application shall be deemed to be rejected without
further order.
9. The application is disposed of.
