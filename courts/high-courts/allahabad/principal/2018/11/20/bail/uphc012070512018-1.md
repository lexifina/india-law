# Allahabad High Court, BAIL/39784/2018, 2018-11-20

Court No. - 28
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 39784 of 2018
Applicant :- Suresh
Opposite Party :- State Of U.P.
Counsel for Applicant :- Qazi Vakil Ahmad
Counsel for Opposite Party :- G.A.
Hon'ble Rajiv Gupta,J.
Heard learned counsel for the applicant and learned A.G.A,.
Learned counsel for the applicant has submitted that after
filing the bail application in the present case certain
sections have been added and as such he wish to withdraw
this bail application so that he may be able to file bail
application before the court below under the changed
sections.
In view of above, learned counsel for the applicant is
permitted to withdraw this bail application.
The bail application is dismissed as withdrawn.
Order Date :- 20.11.2018
