ORDER
1. The above review petition has been filed seeking for the
review of the order dated 25.8.2022 passed in
W.P.No.12715/2022.
2. Sri.B.L.Sanjeev, learned counsel for the review petitioner
would submit that the order which has been passed is a
interim order and is not a final order. A perusal of the
order indicates so. In view thereof, the
W.P.No.12715/2022 is restored to file. The order dated
25.08.2022 is reviewed. The same is held to be interim
order and W.P.No.12715/2022 is restored to file.
3. Re-list this W.P.No.12715/2022 on 21.04.2023.
