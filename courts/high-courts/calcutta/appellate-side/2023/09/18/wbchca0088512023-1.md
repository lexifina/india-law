# Calcutta High Court, CRR/660/2023, 2023-09-18

D/L89
18.09.2023
Bpg.
 C.R.R.660 of 2023
 Sri Harish Maruti Pasalkar and another
 Versus
 The State of West Bengal and another
Mr. Dipanjan Chatterjee
 Mr. Triptimoy Talukdar.
 …for the petitioners.

Learned advocate appearing for the petitioners intends to
withdraw the present revisional application and file afresh with a
vakalatnama which is properly filled up.
Petitioners are granted liberty to file afresh.
Accordingly, CRR 660 of 2023 is dismissed as withdrawn.
Pending application, if any, is consequently dismissed.
Department is directed to return the certified copy to the
advocate-on-record of the petitioner on the same being replaced by
photostat copy.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
 (Tirthankar Ghosh, J.)
