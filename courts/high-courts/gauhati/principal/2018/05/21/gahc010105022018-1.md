Heard the learned counsel for the petitioner and learned counsel for the state.
By this application applicant/petitioner has prayed for correction of order dated
16.05.2018 wherein name of the Court written as CJM, North Salmara instead of SDJM, North
Salmara. On perusal of the matters on record, the same is found to be true. Accordingly the order
dated 16.5.2018 in BA Application No. 727/2018 in the last line of the order be read as to the
satisfaction of Ld. “SDJM” North Salmara.

Page No.# 2/2
With the observations above, petition stands disposed of.
