Order
29/11/2017
The contention which is mainly argued here is not reflected
in the judgment of the Tribunal. It is contended that the argument
was raised but the same is not reflected in the order. Hence, it will
be open for the appellant to file rectification application before the
Tribunal.
It is made clear that we have not expressed any opinion on
merits of the case at this stage. However, it will be open for the
appellant to file appeal after rectification application is decided
wherein even this order can be challenged.
The appeal stands disposed of.
