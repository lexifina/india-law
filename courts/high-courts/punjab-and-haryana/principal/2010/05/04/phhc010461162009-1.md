GURDEV SINGH, J.
Heard.
This petition by Balbir Singh-petitioner has been filed under
Section 482 of the Criminal Procedure Code (hereinafter referred to as 'the
Code'), for quashing the order dated 12.1.2009 passed by Sub Divisional
Judicial Magistrate, Sunam (Annexure P/20). This order was passed on the
application for release of the vehicle on superdari. The same is not an
interlocutory order. Reference in this regard can be made to the judgment in
Babu Lal Jain versus State of Haryana 1997 (4) RCR (Criminal 223. Only
revision was competent. The petitioner could not have filed this petition
under Section 482 of the Code invoking inherent jurisdiction of this Court.

Crl. Misc. No. M-4972 of 2009 2
In the first instance the revision was to be filed before the Sessions Judge.
This petition is dismissed accordingly.
May 4, 2010 (GURDEV SINGH )
