ORAL JUDGMENT

SCR.A/409/2006 2/3 JUDGMENT
1 This application has been moved by the
convict-petitioner by post seeking parole leave
for filing appeal in the Supreme Court. Along
with the application he has annexed order dated
29/10/2005 whereunder I.G. Prisons has rejected
the earlier application on the same ground.
2 Mr.K.T.Dave, learned APP. has placed on
record the report of the jail authority as well
as the copy of order dated 16/3/2006 made by
I.G. Prisons.
3 As can be seen from order dated 16/3/2006 of
I.G. Prisons, the petitioner had also moved an
identical application through jail authority vide
forwarding letter dated 27/1/2006. It is this
application which came to be rejected vide the
aforesaid order dated 16/3/2006.
4 The petitioner has already been informed that

taken by availing of the assistance of the legal
