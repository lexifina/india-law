# Allahabad High Court, BAILC/2969/2013, 2019-07-17

Court No. - 34
Case :- CRIMINAL MISC. BAIL CANCELLATION
APPLICATION No. - 2969 of 2013
Applicant :- Suresh Chandra
Opposite Party :- State Of U.P.And Others
Counsel for Applicant :- Ratan Singh
Counsel for Opposite Party :- Govt.Advocate,Geetam Singh
Hon'ble Sudhir Agarwal,J.
1. This is an application seeking cancellation of bail
granted to respondent-2 pending since 2013. Called in
revise. None appeared to press it.
2. Sri Ratan Singh, learned A.G.A., appearing for State,
however, informs that by efflux of time this application
has rendered infructuous since trial has completed wherein
respondent-2 has been acquitted.
3. Application is accordingly dismissed.
Order Date :- 17.7.2019
