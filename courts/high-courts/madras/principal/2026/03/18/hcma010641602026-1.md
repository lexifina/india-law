ORDER
The applicant/petitioner had filed an application [(PT)A No.2 of
2026] for permission to file three documents. Such application was
allowed by order dated 04.03.2026. As a consequence, the present
application has been filed to recall P.W.1 for purposes of marking said
documents and enabling the cross-examination of P.W.1 in relation
thereto, if deemed necessary by the counter party.
2. Learned counsel for the first respondent opposes this application
on the ground that this application could have been filed along with the
earlier application for permission to file additional documents. He also
points out that the earlier application was filed in October, 2025.

3. For reasons set out while allowing the earlier application, I am
