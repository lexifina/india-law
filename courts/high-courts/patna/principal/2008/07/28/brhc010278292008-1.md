# Patna High Court, C.R./1055/2008, 2008-07-28

IN THE HIGH COURT OF JUDICATURE AT PATNA
 C.R. No.1055 of 2008
 SANGEETA DEVI
 Versus
 MUKUL SHARMA
 -----------
2 28/7/2008 Heard counsel for the petitioner.
In the opinion of this Court the impugned
order refusing to reject the plaint under Order
VII Rule 11 of the Code of Civil Procedure does
not require any interference, in as much as, there
is material finding which discloses clear cause of
action.
That being the position, there is no merit
in this application, the same is accordingly
dismissed.
 ( Mihir Kumar Jha, J. )
