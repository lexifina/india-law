ORDER
The petitioner has filed this Crl.M.C, challenging the
order dated 11.07.2014 in M.P.No.5475/2014 in
C.C.No.1556/2009, on the file of the Judicial First Class
Magistrate Court, Chavakkad.
2. When the case has come up for hearing, the
learned Senior Public Prosecutor submits that
C.C.No.1556/2009 on the file of the Judicial First Class
Magistrate Court, Chavakkad has been disposed of and the
cause of action to pursue the matter does not exists. The
submission is recorded. No representation for the petitioner
as well.
In the result, the Crl.M.C stands dismissed as
infructuous.
