# High Court of Orissa, CMP/471/2020, 2020-08-27

2 27.08.2020 This matter is taken up through Video conferencing.
 Heard Sri Patra, learned counsel for the petitioners.
 This Civil Miscellaneous Petition involves rejection of an
application under Order 39, Rule 3 of the Code of Civil
Procedure. Taking this Court to the grounds involving the Civil
Miscellaneous Petition, Sri Patra, learned counsel for the
petitioners prays for interim protection till the application under
Order 39, Rules 1 and 2 of the Code of Civil Procedure is taken
up and decided. Sri Patra, learned counsel also made an
allegation that taking advantage of COVID-19 situation, the trial
court is not taking up the application under Order 39, Rule 1 and
2 of the Code of Civil Procedure. Hearing the submission of Sri
Patra, learned counsel, this Court observes for there is clear
direction of the High Court to the trial courts, there is no
restriction on the part of the trial court in taking up the urgent
matters. If the trial court is not undertaking such exercise, then it
unfortunate and the District Judge concerned should see to it
 Be that as it may, since the Civil Miscellaneous Petition
involves an order involving Order 39, Rule 3 of the Code of Civil
Procedure, the Civil Miscellaneous Petition is not maintainable
for the statutory remedy of appeal available. Further, for the
settled position of law, pending consideration of an application
under Order 39, Rule 1 and 2 of the Code of Civil Procedure,
High Court gets little scope for interfering in the orders involving
application under Order 39, Rule 3 of the CPC. For the above
reasons, this Court is not inclined to entertain the Civil
Miscellaneous Petition but, however, directs the trial court to
complete the exercise involving Order 39, Rule 1 and 2 CPC
application within a period of fifteen days from the date of
communication of this order by the petitioners. It is observed that
