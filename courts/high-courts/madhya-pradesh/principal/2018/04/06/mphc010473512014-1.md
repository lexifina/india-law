# High Court of Madhya Pradesh, CR/459/2014, 2018-04-06

THE HIGH COURT OF MADHYA PRADESH
CR-459-2014
(RAJENDRA SINGH Vs B.S.I. LIMITED)
Jabalpur, Dated : 06-04-2018
Shri Avinash Zargar, Advocate for the applicants.
Shri Gaurav Tiwari, Advocate for respondent No. 1.
Shri Anubhav Jain, GA for respondent No. 3.
None for respondent Nos. 2 & 4.
This revision under Section 115 of the Code of Civil Procedure
has been filed being aggrieved by the order Annexure P-1 dated
8.8.2014 passed by First Civil Judge Class II, Sehore in Civil Suit No.
2-A/2010.
After hearing learned counsel for both the parties because the
application under Order 22 Rule 4 of the Code of Civil Procedure has
not been decided by passing a reasoned order by the trial Court,
therefore, order Annexure P-1 dated 8.8.2014 passed by First Civil
Judge Class II, Sehore in Civil Suit No. 2-A/2010 stands set aside. The
trial Court is directed to reconsider the application under Order 22
Rule 4 of the Code of Civil Procedure and pass a fresh order in
accordance with law.
This petition stands disposed of with the aforesaid observation.
(J.K. MAHESHWARI)
