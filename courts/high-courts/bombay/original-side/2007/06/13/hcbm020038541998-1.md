 in the draft judgment remained to be corrected before
 signing the same. The corrections which are required to
 be made in the judgment are as under:

 addition to costs Rs.10,000/-
 Should be read as "Costs Rs.1,00,000/-"
 2. Page 5, Para ii) the entire para should be read
 as:
 "The respondents should pay to the appellants a
 sum of Rs.3,59,695/- along with interest at 18%

 [2]
 p.a. from the date of award till realization
 and costs Rs.25,000/-."
 3. Page 4, Para 3, line 14 on 14.01.1997
 Should be read as "24.01.1997"
 4. Page 6, Para 4, 3rd line from the bottom:
 pumping rate of Rs.200/- m.t. per hour
 Should be read as "200 m.t. per hour"
 5. Page 8, point iii) Rs.200/- m.t. per hour
 Should be read as "200 m.t. per hour"
 6. Page 14, Para 13(b) 2nd line: shortage 16.500 mt
 Should be read as "16,500 m.t."
 7. Page 16, 9th line from the top: interim relief
 by an application dated 29.11.1996
 Should be read as "26-11-1996"

 rate Rs.200/- m.t. per hour
 Should be read as "200 m.t. per hour"
 9. Page 25, Para 20, pumping rate Rs.200/- m.t.
 per hour
 Should be read as "200 m.t. per hour"
