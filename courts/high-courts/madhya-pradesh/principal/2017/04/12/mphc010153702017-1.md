# High Court of Madhya Pradesh, MCC/908/2017, 2017-04-12

MCC-908-2017
(GANPATI VERMA Vs THE STATE OF MADHYA PRADESH)
12-04-2017
Shri Aditya Khandekar, learned counsel for the applicant.
Heard on I.A. No.4525/2017, an application for condonation of delay.
For the reasons mentioned in the application, which is duly supported by
an affidavit of Advocate-Aditya Khandekar, the same (I.A.
No.4525/2017) is allowed. The delay in filing this application is hereby
condoned.
This application has been filed for restoration of W.P. No.18205/2016
which has been dismissed for non-compliance of common conditional
order dated 03.01.2017. The application is supported by an affidavit of
Advocate-Aditya Khandekar.
Keeping in view the reasons indicated in the application, the M.C.C. is
allowed and it is directed that W.P. No.18205/2016 be restored to its
original number and list this case before the appropriate Bench.
Let a copy of this order be kept in the file of W.P. No.18205/2016.
(SMT. ANJULI PALO)
JUDGE
