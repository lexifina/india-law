# High Court of Orissa, CONTR/7/2018, 2019-01-25

02. 25.01.2019 Heard Mr. H.K. Mahanta, learned counsel for
the petitioner.
The petitioner has filed this application alleging
violation of the order dated 07.12.2017 passed in
ABLAPL No.19014 of 2017. But neither the order
alleged to have been violated has been filed nor the
same has been quoted in this application. Therefore, in
course of hearing, learned counsel for the petitioner
wants to withdraw this application with liberty to file a
better application with better particulars.
Prayer is allowed.
The CONTR stands disposed of as withdrawn
with the liberty aforesaid.
