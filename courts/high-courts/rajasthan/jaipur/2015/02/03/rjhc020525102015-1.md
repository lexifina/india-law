This is third bail application on behalf of the
petitioner. The third bail application of the petitioner was
dismissed by order of this Court dated 5/9/2014 but without
first approaching the trial court, the petitioner has straightway
filed this third bail application before this Court.
At this stage, learned counsel for the petitioner
wants to withdraw this bail application with the liberty to move
again before the court below.
Hence, this third bail application u/S.439 Cr.P.C. is
dismissed as withdrawn with the liberty aforesaid.
