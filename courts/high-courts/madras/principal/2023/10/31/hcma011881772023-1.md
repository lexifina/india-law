This application has been filed by the applicant/plaintiff seeking permission
of this Court to receive a copy of the full script of the movie 'Thandavam' dated
29.03.2012, filed by the first respondent/first defendant in the above suit.
2.The suit has been filed for infringement of copyright. The applicant/
plaintiff claims that the script for the movie 'Thandavam' was authored by him. He
claims copyright over the said script. However, the same has been disputed by the
respondents/defendants.
3.In O.A. No.790 of 2012, the first respondent/first defendant had filed
counter affidavit along with typed set of documents, which encloses the script of
the first respondent/first defendant. The script of the first respondent/first

4.The applicant in this Application seeks permission of this Court to receive

5.A counter affidavit has also been filed by the first respondent/first

6.Though the respondents/defendants have sought for dismissal of this
application, this Court is of the considered view that no prejudice would be
caused if the application is allowed as prayed for as the first respondent/first
defendant has produced the copy of the same script in the counter affidavit filed in
O.A. No.790 of 2012.
7.Learned counsel for the first respondent/first defendant has not raised any
serious objection when this Court expressed its view that the application will have
to be allowed.
