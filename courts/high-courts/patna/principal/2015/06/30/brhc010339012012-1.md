ORAL ORDER
5 30-06-2015 The present application under section 482 of the
Code of Criminal Procedure has been filed for quashing the order
dated 14.09.2012 passed by the learned Judicial Magistrate 1st
Class, Patna in Complaint Case No. 3162(C) of 2004 by which the
application filed under sections 245 of the Code of Criminal
Procedure for discharge of the petitioners in the aforesaid case has
been rejected.
After some arguments, learned counsel for the
petitioners seeks leave to withdraw this application in order to

Patna High Court Cr.Misc. No.40091 of 2012 (5) dt.30-06-2015
2/2
raise all the points available to the petitioners at appropriate stage
in course of trial.
Leave is granted. The application is disposed of.
