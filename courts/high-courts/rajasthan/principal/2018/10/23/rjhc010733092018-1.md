HON'BLE MR. JUSTICE MANOJ KUMAR GARG
Order
23/10/2018
The instant misc. application has been moved for correction
in order dated 22.10.2018 passed in S.B. Crl. Misc. Bail
Application No.9684/2018, whereby, while allowing the bail
application, the petitioner was ordered to be released on bail.
Learned counsel for the petitioner submits that inadvertently
due to a typographical error in the order dated 22.10.2018, in
header at page 2, the bail application number has wrongly been
mentioned as CRLMB-9682/2018 instead of CRLMB-9684/2018.
Therefore, necessary correction be made in the order dated
22.10.2018.
In view of above submissions made and for reasons stated in

(2 of 2)

the application, the present misc. application is allowed. It is
ordered that in the order dated 22.10.2018, in header at page 2
the bail application number be read as “CRLMB—9684/2018”
instead of “CRLMB—9682/2018”. To that extent, the order dated
22.10.2018 stands corrected.
(MANOJ KUMAR GARG)J.
