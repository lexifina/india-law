PER COURT:
1. This is an application by which the applicant / State
seeks leave to file an appeal challenging the judgment of the
Additional Sessions Judge-7, Aurangabad dated 19.03.2011 in
Sessions Case No.273/2008, acquitting the respondents for an
offence punishable u/s 302, 324, 504, 506 r/w 34 of the Indian
Penal Code.
2. We have heard Shri.Kaldate, learned APP for applicant
and we have perused the record and proceedings. We have also

drp {2} Cri. Application No.2639/2011
examined the findings recorded by the trial court vis-a-vis the
evidence of the prosecution. Upon such examination, according to
us, this is a fit case for granting leave.
3. Accordingly, this criminal application is allowed and
leave, as prayed for, is granted. Appeal stands admitted. Action u/s
390 of the Code of Criminal Procedure be taken by the trial court,
by issuing bailable warrant for Rs.15,000/- each against the
respondents.
 [A.V.POTDAR, J.] [P.V.HARDAS, J.]
