(SANTOSH DWIVEDI Vs PRAMILA DWIVEDI)
Jabalpur, Dated : 01-07-2019
Shri Ramnath Dwivedi, Advocate for the applicant.
Heard on I.A. No. 6440/2019, which is an application to convert this
revision into first appeal.
There is no provision of conversion of civil revision into first appeal,
therefore, this application is rejected.
At this stage, learned counsel for the applicant seeks permission to
withdraw this petition with liberty to file first appeal.
Prayer seems to be reasonable, therefore, allowed.
Accordingly, this revision is dismissed as withdrawn with the liberty as
prayed.
Certified copy of the impugned judgment be returned back to the
counsel for the applicant on filing photocopy thereof.
