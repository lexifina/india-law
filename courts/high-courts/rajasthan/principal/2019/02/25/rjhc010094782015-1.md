Order
25/02/2019
Notices were ordered to be issued on 18.03.2016.
Whereafter, on 10.11.2017, time was granted for filing correct
notices; again on 08.02.2018, one week’s time was granted to file
requisite correct notices, however, the same have not been filed so
far i.e. requisite correct notices have not been filed since
18.03.2016. It appears that the petitioner has lost interest in the
application.
In view thereof, the application is dismissed for non-prosecution.
(ARUN BHANSALI),J
