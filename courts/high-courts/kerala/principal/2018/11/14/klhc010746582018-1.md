JUDGMENT
The learned counsel for the petitioner submits that since
this writ petition has been filed by the father of the borrower, he
does not intend to pursue it, became the borrower and the other
guaranters are now intending to file a fresh writ petition. He,
therefore, prays that this writ petition be allowed to be
withdrawn, so as to allow the borrower/guaranter to file an
appropriate writ petition.
This request is granted. Consequently, this writ petition
stands closed as having been withdrawn.
