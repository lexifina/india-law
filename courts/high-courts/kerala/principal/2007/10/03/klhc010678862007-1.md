JUDGMENT
This writ petition is filed for a direction to the Munsiff's Court,
Punalur to pass an order in the application to set aside the Commission
report before the final hearing of the final decree application in O.S.No.159
of 1982. Learned counsel for the petitioner submits that it is a final decree
application pending and the petition is filed dissatisfied with the
Commissioner's plan and report to set aside the same and she has got very
serious grievance in that matter. When an application to set aside the
Commissioner's plan and report is filed, the court is bound to consider it and
adjudicate it first before proceeding further with the matter.
Therefore the writ petition is disposed of directing the Munsiff's
Court, Punalur to consider and pass appropriate orders in the application
filed for setting aside the Commissioner's plan and report, give a breathing
time to the parties and thereafter proceed with the final decree application in

WP(C) 29217/2007 -:2:-
accordance with law.
Writ petition is disposed of as above.
