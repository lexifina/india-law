3. As per Section 362 of the Code of Criminal Procedure,
there is no provision in criminal law to review the matter
when the same is finally disposed of except to correct
clerical and arithmetical error. Review is a statutory
provision. It is available in Code of Civil Procedure, however,
it is not available in Code of Criminal Procedure. Hence, the
application is rejected.
