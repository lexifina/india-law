ORAL ORDER
The Applicant (Original Accused No.2) has filed this Application under
Section 438 of the Code of Criminal Procedure for Anticipatory Bail in
connection with the offences punishable under Sections 420, 465, 467, 468,
120(b), 34, 504 and 506(1) of the Indian Penal Code for which FIR being I-CR
No. 4/2020 is registered at Mehasana City ‘B’ Division Police Station,
Mehasana.
Heard learned Advocate Mr. Dharmik Barot for learned Advocate Mr.
Samarth S. Amin for the applicant and learned APP Mr. Chintan Dave for the
respondent-State through video conference.
Learned Advocate for the Applicant seeks permission to withdraw the
present Application with a liberty to file a fresh application.
Permission as prayed for is granted. The Application stands disposed of
as withdrawn with liberty to file fresh Application after some time.
Rue is discharged. Interim relief granted earlier stands vacated.
This Court has not opined on merits of the case.
(DR. ASHOKKUMAR C. JOSHI,J)
SURESH SOLANKI / PIYUSH / JNW
