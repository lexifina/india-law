# High Court of Uttarakhand, WPMS/616/2015, 2015-03-19

WPMS No.616 of 2015
Honíble Sudhanshu Dhulia, J.
Mr. G.C. Kandpal, Advocate present for the
petitioners.
Present petitioners before this Court were
defendants in a suit, which filed by the
respondent/plaintiff, which was decreed.
Subsequently, an appeal filed by the
petitioners/defendants before II Addl. District
Judge, Rudrapur (Udham Singh Nagar) which was
also dismissed. Now a Second appeal No.72 of
2013 is pending before this Court.
There is no stay by this Court in the Second
Appeal. Meanwhile, the decree holder has moved
for execution being execution case No.3 of 2009.
The case of the decree holder before the execution
court is that inspite of courtís decree in his favour,
judgement debtors are not letting him to enforce
the decree and they are creating obstacles etc. and
thereafter respondent/ decree holder moved an
application under Order XXI Rule 32 of Code of
Civil Procedure which would include sending the
judgment debtors in civil prison. After recording of
this fact, the execution court has passed an order
under Order XXI Rule 32 of Code of Civil
Procedure directing the judgment debtors to be
sent to civil prison by passing order dated
04.02.2015, which is impugned before this Court.
The only question raised by the petitioners
before this Court is that against the decree of the
trial court which has been upheld in the first
Appeal, against which Second Appeal No.72 of
2013 is still pending before this Court, the
execution court cannot proceed. This argument is
entirely misconceived.
The writ petition is totally devoid of any
merit as there is no illegality in the impugned
order. The writ petition fails and is hereby
dismissed in limine.
 (Sudhanshu Dhulia, J.)
