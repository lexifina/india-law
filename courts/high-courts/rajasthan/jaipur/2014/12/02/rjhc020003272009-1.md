Mr.Aladeen Khan, Public Prosecutor.
By the Court:
By this criminal miscellaneous petition, a challenge is
made to order granting prosecution sanction for offence under
Arms Act.
Learned counsel submits that a cyclostyle order has
been passed, thus prosecution sanction has been given without
application of mind. In view of above, the order dated 18th
September, 2008 deserves to be set aside. The prosecution
sanction should not be given as an empty formality but is to be
granted after due application of mind and, that too, after going
through the fact. If the facts warrant prosecution sanction, it can
be granted otherwise should be refused.
Learned Public Prosecutor has opposed the prayer
made by learned counsel for the petitioner.

2
I have considered the submissions and find that
impugned order granting prosecution sanction is on the form where
blanks have been filled. It could not show application of mind by
the competent authority. The prosecution sanction should not be
taken as an empty formality but the order has to be with
application of mind.
Accordingly, the impugned order dated 18th
September, 2008 is set aside. The competent authority would,
however, be at liberty to pass a fresh order for prosecution
sanction, after applying its mind.
With the aforesaid, this criminal miscellaneous
petition stands disposed of so as the stay application.
(M.N. BHANDARI), J.
