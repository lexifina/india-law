04/02.12.2020 Heard Mr. Sanjay Kumar, learned counsel for the
petitioner and Mr. Santosh Kumar Shukla, learned A.P.P. for
the State.
In this application the petitioner has prayed for
modification of the order dated 31.10.2018 passed in A.B.A. No.
1628 of 2018.
Mr. Sanjay Kumar, learned counsel for the petitioner, at
the outset, seeks permission to withdraw this application with a
liberty to file a fresh anticipatory bail application, if so advised.
Mr. Santosh Kumar Shukla, learned A.P.P. for the State
does not have any objection to the prayer made by the
petitioner.
Permission is accorded.
This application stands dismissed as withdrawn with the
aforesaid liberty.
(Rongon Mukhopadhyay, J.)
