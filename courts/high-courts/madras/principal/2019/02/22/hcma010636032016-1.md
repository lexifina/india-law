ORDER
This petition has been filed to direct the 3rd respondent to
register a Case as against the Respondents 5 to 11 based on the
petitioner's Complaint dated 23.06.2016 and Investigate the same
and to file a Final Report within the stipulated time as fixed.
2. The learned Additional Public Prosecutor would submit
that in the above case enquiry was conducted and the same was
closed.
3. In view of the above, this Court is not inclined to allow
the prayer sought for in this petition. However, the petitioner
is at liberty to file a fresh complaint on fresh cause of action
if so advised.
4.With the above observations this writ petition stands
disposed of. No Costs. Consequently, the connected miscellaneous
petitions are closed.
