# High Court of Madhya Pradesh, MCC/2643/2014, 2015-08-06

MCC-2643-2014
(HARILAL KOL Vs SAKHUA KOL)
06-08-2015
Shri S.K.Singh, learned counsel for the applicants.
Shri P.K.Dubey, learned counsel for the respondents.
This application has been filed for restoration of Misc. Appeal
No.2962/2012, which was dismissed for non-compliance of the
common conditional order dated 20/01/2014. There being some
delay in filing the application for restoration, I.A. No.16739/2014
has been filed seeking condonation of delay. Both the applications
are supported by an affidavit and there is no reason to disbelieve
the same. Finding the same to be bonafide, both the applications
are allowed.
Condoning the delay in filing the application, restoration
application is itself allowed.
Misc. Appeal No.2962/2012 is restored to its original
number. It be placed for orders before appropriate Bench.
Application stands allowed and disposed of.
(VANDANA KASREKAR)
JUDGE
