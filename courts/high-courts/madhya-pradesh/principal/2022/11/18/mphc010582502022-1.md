ORDER
Registry has listed this case on the question of maintainability.
This miscellaneous petition has been preferred challenging the order
dated 01/10/2022, whereby application filed by the petitioner under Order 41
Rule 19 CPC has been dismissed by Court below against which miscellaneous
appeal is provided under Order 43 Rule 1(t) CPC.

JUDGE
As such, this miscellaneous petition is not maintainable and is dismissed.
However, liberty is granted to the petitioner to file miscellaneous appeal against
the order dated 01/10/2022 (Ann.P/1).
With the aforesaid liberty, this miscellaneous petition is dismissed as not
maintainable.
Registry is directed to return the certified copy of the order dated
01/10/2022 to the learned counsel for the petitioner after retaining its photocopy
on record.
