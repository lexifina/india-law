CORAM: HONOURABLE MR.JUSTICE VIPUL M. PANCHOLI

ORAL ORDER
Learned advocate for the applicants fairly
submitted that this Court has granted protection
to the applicants in the application filed under
Section 482 of the Code of Criminal Procedure,
1973, vide order dated 27.01.2020. Copy of the
said order is placed on record. In view of the
said order passed by this Court, at this stage,
learned advocate for the applicants seeks
permission to withdraw this application.
Permission as prayed for is granted.
Application stands disposed of as withdrawn. It
is clarified that this Court has not examined the
merits of the case. In case of any difficulty,
liberty is reserved to file fresh application for
the same subject matter.
(VIPUL M. PANCHOLI, J)
