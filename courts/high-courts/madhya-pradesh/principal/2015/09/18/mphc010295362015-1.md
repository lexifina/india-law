# High Court of Madhya Pradesh, MCRC/10394/2015, 2015-09-18

Misc.Cr.C.No.10394/2015
18-09-2015
 Shri Siddharth Rai, learned counsel for the applicant.
 This application has been filed for restoration of Misc.Cr.Case
No.16499/2013, which has been dismissed for want of prosecution.
 Keeping in view the reasons indicated in this application for
restoration and finding the same to be bonafide, the application for
restoration is allowed.
Misc.Cr.Case No.16499/2013 is restored to its original file. It be
placed for orders before an Appropriate Bench.
Application stands allowed and disposed of.
 (RAJENDRA MENON)
 JUDGE
