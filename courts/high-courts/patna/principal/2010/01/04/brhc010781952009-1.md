02 04-01-2010 Office notes, in my view, appear to be correct. The
petitioner had come to this Court for the identical relief
earlier, in which directions were issued. It is alleged that
those directions are not being obeyed. It would, thus, be
impermissible for the petitioner to file writ application for
the same relief again.
This application is, thus, not maintainable and
disposed of.
