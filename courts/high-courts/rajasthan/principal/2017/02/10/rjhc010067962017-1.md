HON'BLE MR. JUSTICE SANGEET LODHA
Order
10/02/2017
 This application has been preferred by the petitioner for
reconstitution of the file of S.B.Civil Writ Petition No. 6059/14.
It is submitted that the record of the writ petition is not
traceable.
As per the report of the Deputy Registrar (Judicial), the file
of the writ petition could not be traced out even after all possible
efforts made.
In this view of the matter, the application seeking
reconstitution of the file is allowed. The reconstituted file of the
writ petition accompanying the application is taken on record.
 (SANGEET LODHA)J.
