This is an application seeking to set aside order dated
18.12.2017, passed by the Registrar, refusing registration of the petition.

application deserves to be allowed and same is accordingly allowed.
Order dated 18.12.2017, passed by the Registrar, refusing registration of
the petition is set aside. Delay occurred in presenting instant application
stands condoned. Petition is restored to its original number.
Civil Application is disposed of.
