ORAL ORDER
1. By way of the present application, the applicant has
prayed for the following relief:-
“8(B). This Hon'ble Court may be pleased to quash and
set aside the FIR being I-C.R.2 of 2018 registered CID
Crime police station, Rajkot Zone, Rajkot and
consequent proceedings thereon and chargesheet
No.3/18.”
2. The learned A.P.P. states at bar that the chargesheet is
filed in the matter.
3. Having heard submissions made at bar by the learned
advocate for the applicant and considering the averments
made in the present application, no case is made out to
entertain the present application without availing alternate
remedy to file discharge application. Therefore, the present
application is not entertained at this stage. However, the
applicant is at liberty to file discharge application and also to
file appropriate proceedings either u/s 397 or 482 of the Code

Court, after remedy to file discharge application is availed.
4. It is clarified that this Court has not examined the merits

5. Accordingly, present application stands disposed of.
