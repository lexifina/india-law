This is an application for pre-arrest bail in case
bearing FIR No.31 dated March 25th, 2012 under Sections 420 etc.
IPC, Police Station Model Town, District Ludhiana.
Learned State counsel has stated that during
investigation, petitioner has been found innocent. Prosecution has
proposed to file report for cancellation of the case.
In view of this, learned counsel for the petitioner
has stated that this petition be dismissed as withdrawn.
It is ordered accordingly.
