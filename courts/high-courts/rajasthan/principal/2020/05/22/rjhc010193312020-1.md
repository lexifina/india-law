Judgment / Order
22/05/2020
Heard learned counsel for the petitioner Mr. Rakesh Matoria
through Jitsi Meet App. and the learned Public Prosecutor.
Learned counsel for the petitioner has submitted that this
bail application has inadvertently been filed by him as the
petitioner has already been enlarged on bail by a Coordinate
Bench of this Court vide order dated 24.4.2020 passed in S.B.
Criminal Misc. Bail Application No.4139/2020. Learned counsel for
the petitioner, thus, submitted that he wants to withdraw this bail
application.
Accordingly, this bail application is dismissed as withdrawn.
