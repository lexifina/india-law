O R D E R
There is no necessity to issue notice to the second
respondent as he is a co-plaintiff along with the petitioners in
this Civil Revision Petition.
2. The suit for recovery of possession, compensation and
damages was decreed exparte on 31.08.2010. The defendant had
filed I.A.No.5348/2010 on 14.09.2010 to set aside the exparte
decree. The said application was dismissed for default due to
non representation on 31.05.2011.
3. The defendant thereafter again filed I.A.No.7470/2011
to set aside the same exparte decree. This was supported by
I.A.No.7471/2011 to condone the delay in preferring the same.
The court below has by the order impugned allowed both these
applications.
4. It is trite law that principles of resjudicata
apply to different stages of the same litigation. I.A.No.7470/2011
was obviously barred by resjudicata in view of the dismissal of

C.R.P No.167 of 2012 2
I.A.No.5348/2010. The court below erred in entertaining
I.A.7470/2011 filed to set aside the exparte decree along with
7471/2011 for condonation of delay.
5. The impugned order is set aside and
I.A.Nos.7470/2011 and 7471/2011 in O.S.No.28/2010 on the file
of the Court of the II Additional Subordinate Judge
Thiruvananthapuram are dismissed. This however will not
disable the defendant from seeking to restore I.A.No.5348/2010
dismissed for default. I.A.No.5348/2010 can be restored to file
by recourse to Order IX Rule 9 of the Code of Civil Procedure to
be dealt with on merits.
5. The Civil Revision Petition is allowed. No costs.
