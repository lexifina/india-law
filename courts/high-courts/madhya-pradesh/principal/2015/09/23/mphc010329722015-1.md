# High Court of Madhya Pradesh, MCC/1894/2015, 2015-09-23

MCC-1894-2015
(MAHENDRA DWIVEDI Vs THE STATE OF MADHYA PRADESH)
23-09-2015
Shri Priyank Khandelwal, learned counsel for the
applicant.
This application has been filed for restoration of W.P. No.
7494/2007, which was dismissed for want of prosecution
vide order dated 09.4.2015. There being some delay in
filing the application for restoration, I.A. No. 8603/2015
has been filed seeking condonation of delay. Both the
applications are supported by affidavit of Mahendra
Dwivedi. There is no reason to disbelieve the same.
Finding the same to be bonafide, both the applications
are allowed.
Condoning the delay in filing the application, restoration
application itself is allowed. W.P. No. 7494/2007 is
restored to its original number.
Application stands allowed and disposed of.
(VANDANA KASREKAR)
JUDGE
