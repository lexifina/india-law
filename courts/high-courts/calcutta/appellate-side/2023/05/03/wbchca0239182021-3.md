# Calcutta High Court, CRR/1581/2021, 2023-05-03

03.05.2023 IN THE HIGH COURT AT CALCUTTA
 Item No.31 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
C.R.R. 1581 of 2021

 Arka Dutta
 versus
 The State of West Bengal & Anr.
In Re: An Application under Section 482 read with Section
401 of the Code of Criminal Procedure, 1973.
Mr. Swapan Banerjee,
Mr. Md. Kutubuddin … For the State.
Report dated 18.04.2023 submitted by Mr.
Kutubuddin, learned advocate appearing for the State be kept
on record.
The present revisional application was preferred
immediately after charge-sheet was submitted before the
jurisdictional court. None of the copies relating to the
provisions of Section 207 of the Code of Criminal Procedure
are enclosed along with this revisional application. Having
considered that the revisional application was preferred in the
year 2021 and the case commenced in the year 2020 as also
the fact that no documents have been enclosed for this Court
to ascertain regarding the prosecution case, I hold that the
revisional application so preferred is premature.
Accordingly, the revisional application being CRR 1581
of 2021 is dismissed.
Pending connected application, if any, is consequently
disposed of.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.
