# Allahabad High Court, CRLP/8888/2019, 2019-04-09

Court No. - 33
Case :- CRIMINAL MISC. WRIT PETITION No. - 8888 of 2019
Petitioner :- Sunil Rajbhar
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Harendra Yadav
Counsel for Respondent :- G.A.
Hon'ble Manoj Misra,J.
Hon'ble Suresh Kumar Gupta,J.
There is a correction by hand in the petition to change
Case Crime No.from 275 of 2018 to 276 of 2018. In fact,
the main prayer discloses the Case Crime No. as 275 of
2018.
In view of the above, we deem it appropriate to dismiss
the petition with liberty to the petitioner to file fresh
petition with description of correct Case Crime number so
that the office is in a position to report whether the present
petition is first petition or second petition of the same
Case Crime number.
Order Date :- 9.4.2019.
Rks.
