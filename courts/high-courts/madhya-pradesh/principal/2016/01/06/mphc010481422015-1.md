# High Court of Madhya Pradesh, MCC/2834/2015, 2016-01-06

MCC-2834-2015
(SHUBHAM VIKLANG AVAM SAMAJ SEWA SAMITI Vs SHRI V.K. BATHAM)
06-01-2016
Shri A. Usmani, learned counsel for the applicant.
Mrs. S. Pandey, learned counsel for the respondents.
This application has been filed for restoration of Conc.
No.557/2012, which was dismissed on account of peremptory
order dated 08/05/2015. There being some delay in filing the
application for restoration, therefore, I.A. No.15414/2015 has been
filed seeking condonation of delay. Both the applications are
supported by an affidavit of the Advocate himself and there is no
reason to disbelieve the same. Finding the same to be bona fide,
both the applications are allowed.
Condoning the delay in filing the application, restoration
application is itself allowed.
Conc. No.557/2012 is restored to its original number.
After restoration, Conc. No.557/2012 be placed for orders
before appropriate Bench.
Application stands allowed and disposed of.
Certified copy as per rules.
(MISS VANDANA KASREKAR)
JUDGE
