# High Court of Madhya Pradesh, MCRC/21568/2016, 2016-12-13

MCRC-21568-2016
(ANUJ KUMAR Vs THE STATE OF MADHYA PRADESH)
13-12-2016
Shri Jitendra Arya for the applicant.
Shri A. Namdeo, Pl, for the State.
Seeking correction of an order-dated 28.11.2016, passed by
this Court in M.Cr.C.No.20475/2016, this application has been
filed.
However, the correction sought for is not in the order
passed by this Court, but in the description of the applicant's
particulars in the cause title.
This is an error in the cause-title. It cannot be corrected in
the manner as prayed for.
In case applicant is unable to reap the benefits of the order
passed, the applicant should file a separate application afresh
incorporating the correct particulars. The correction in the cause-title in the manner sought for, cannot be permitted.
Accordingly, this application is disposed of with liberty
to the applicant to file a fresh application and seek the relief in
accordance with law.
CC as per rules.
(RAJENDRA MENON)
ACTING CHIEF JUSTICE
(SMT. ANJULI PALO)
