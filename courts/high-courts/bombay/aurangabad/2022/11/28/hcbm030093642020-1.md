PER COURT :
1. Heard the learned advocate for the applicant and learned APP.
2. After the disinclination is shown to grant any relief to the
applicant, the learned advocate for the applicant, on instructions, seeks
withdrawal of the application.
3. The application stands disposed of as withdrawn.
4. Learned advocate for the applicant also prays for liberty to be
granted to the applicant to file discharge application before the trial court.
The applicant would be at liberty, if the law permits, to file such application
which then the trial court would consider on its own merits. No necessity to
give any liberty to that effect.
