The order impugned in this petition is passed below
Exhibit 32 on 20-2-2013 by the Trial Court, allowing the
application for amendment under Order VI, Rule 17 of the Civil
Procedure Code. Undisputedly, the issues are yet to be framed.
The contention of the learned counsel for the petitioners is that
the applications under Order VII, Rule 11 of the Code were filed
at Exhibits 22 and 25 on 18-4-2012 and 23-4-2012 respectively.
The hearing on both these applications was held on 30-4-2012,
2-5-2012 and thereafter on four occasions. It is after hearing of
these applications, the application at Exhibit 32 for amendment
under Order VI, Rule 17 of the Code has been filed. The
contention is that the application under Order VII, Rule 11 of the
Code should have been decided before considering the
application for amendment to the plaint. Undisputedly, the
objection to the amendment was not that it is barred by the law of

Rule 11 of the Code is that the suit itself is barred by limitation.

Rule 11 of the Code can be decided subsequently also.
The petition is dismissed.
