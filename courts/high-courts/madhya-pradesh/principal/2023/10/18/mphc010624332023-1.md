ORDER
It is fairly conceded by Shri Chauhan that his basic contention in the
application form, there was a common column regarding declaration of C and D
certificate is not mentioned in the petition. The representation of petitioner has
been rejected on the ground that he himself had not put tick mark against the
column which was meant for NCC "C" certificate.
2. However, by referring to rule book, it is submitted by counsel for
petitioner that since an erroneous information was sought by respondents
requiring declaration with regard to "C" and "D" NCC certificate, therefore,
petitioner had not put tick mark in front of NCC certificate whereas he is holder
of "C" NCC certificate. It is further submitted that there is no certificate like D
in NCC.
3. Considered the submissions.
4. This Court is not concerned about error in rule book but the basic
thing is whether there was a common block in the application form requiring
information about C and D certificate or there was separate column in the
application form.
5. Since petition is lacking basic averment with regard to error in the
application form, therefore, this petition is permitted to be withdrawn with
liberty to file a fresh petition with specific pleadings alongwith copy of
application form if it is available with petitioner.
