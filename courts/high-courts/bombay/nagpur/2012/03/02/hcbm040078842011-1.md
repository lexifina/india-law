CORAM : R. K.DESHPANDE, J.
DATE : 02. MARCH, 2012.
Shri Jachak, the learned Counsel appearing for the
respondents raises an objection about maintainability of the civil
application on the ground that the suit has been dismissed under
Order VII Rule 11(d) of the Code of Civil Procedure and hence, it
is decree and regular appeal is available.
In view of this, Shri J.M.Shamkuwar, the learned
Counsel appearing for the applicant, seeks permission to
withdraw this civil application with liberty to file regular appeal.
Hence, the applicant is permitted to withdraw this
application with liberty to file appeal in accordance with law.
