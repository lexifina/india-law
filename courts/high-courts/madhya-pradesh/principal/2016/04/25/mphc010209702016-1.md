# High Court of Madhya Pradesh, MCC/1134/2016, 2016-04-25

MCC-1134-2016
(HARCHARAN AHIRWAR Vs THE STATE OF MADHYA PRADESH)
25-04-2016
Shri Subodh Kathar, learned counsel for the applicant.
Shri Swapnil Ganguly, learned Govt. Adv., for the State.
This application has been filed for restoration of W.P.
No.6311/2014 which has been dismissed for want of prosecution
on 31.3.2016.
Keeping in view the reasons indicated in the application which is
supported by affidavit of counsel himself, we allow this application.
Writ petition No.6311/2014 is restored to its original file. It be
listed for orders before the appropriate Bench.
Accordingly, this application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
(ANURAG KUMAR
SHRIVASTAVA)
