This is an application, filed under Section 438 of the Cr.PC. seeking pre-arrest bail of
the accused-petitioner, namely, Bhagawan Nand Jha, in connection with Panbazar P.S.
Case No.620/2020 registered under Sections 341/324/325 of the Indian Penal Code.
Heard Mr. J. Islam, learned counsel for the petitioner. Also heard Ms. S.H. Borah, learned

Page No.# 2/2
Additional Public Prosecutor, Assam appearing for the State Respondent.
The case has been registered under Sections 341/324/325 of the Indian Penal Code.
That being so, the provisions of law under which the case has been registered are all
bailable.
Learned counsel for the petitioner has submitted that Section 324 of the Indian Penal
Code is non-bailable. As per the Schedule in the Code of Criminal Procedure, Section 324 of
the Indian Penal Code is non- bailable, but Section 324 of the I.P.C. is non-bailable only with
effect from the date it will be notified.
Since the said section has not been notified as non-bailable yet, the offence under
Section 324 of the Indian Penal Code still remains bailable.
That being so, in the considered view of this Court, an application under Section 438 of
the Code of Criminal Procedure is not maintainable for bailable offences.
Accordingly, this petition stands disposed of being not maintainable.
