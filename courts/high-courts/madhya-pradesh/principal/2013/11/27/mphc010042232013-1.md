# High Court of Madhya Pradesh, MCC/134/2013, 2013-11-27

MCC. No.134/2013
27/11/2013 :
Shri Priyank Khandelwal, learned counsel for the applicant.
This application has been filed for restoration of W.P.
No.3809/2008 which was dismissed for want of prosecution on
21.11.2012. There being some delay in filing the application I.A.
No.1099/2013 has been filed seeking condonation of delay.
Application is supported by an affidavit of counsel himself and there is
no reason to disbelieve the same. Finding the same to be bonafide,
both the applications are allowed. Condoning the application in filing
the application, the restoration application itself is allowed. Writ Petition
is restored to its original number. It be placed for orders before the
appropriate Bench.
Application stands allowed and disposed of.
 (RAJENDRA MENON)
