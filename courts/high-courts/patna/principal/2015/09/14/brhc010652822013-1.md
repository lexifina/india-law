ORAL ORDER
7 14-09-2015 As per the counsel for the Accountant General and
the State of Bihar, whatever the petitioner is entitled has already
been paid to him.
The counsel for the petitioner does not dispute, but he
submits that if some amount has been left out, he should be given
liberty to file a representation.
The petitioner has not pointedly made out the claim
which is still to be gone into.
As the petitioner has not pointedly made out a case
for raising grievance, it will be futile for this Court to again give a
chance to file a representation. Prayer has been made by the
petitioner has no strength to stand, the same is rejected.
As all the payment has been made, there is no need to

2/2
proceed with the matter. Accordingly, this application is
dismissed.
