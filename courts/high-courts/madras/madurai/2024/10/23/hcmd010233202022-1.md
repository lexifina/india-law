 ORDER
 This Criminal Original Petition is filed to quash the First
Information Report in Crime No.97 of 2021 pending on the file of the
first respondent.
2. The case of the petitioner is that this is the second F.I.R. in
respect of the same cause of action and as such has to be quashed.
However, when the matter came up for hearing, it was brought to the
notice of this Court that already final report has already been filed and
the same has been taken on file as C.C. No. 405 of 2024 on the file of the
Judicial Magistrate No.II, Kumbakonam.
3. In view of thereof, giving liberty for the petitioner to challenge
the final report on the same ground, this petition has become infructuous.
