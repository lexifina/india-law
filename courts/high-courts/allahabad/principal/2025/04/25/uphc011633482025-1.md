# Allahabad High Court, FAFOD/453/2025, 2025-04-25

Court No. - 2
Case :- FIRST APPEAL FROM ORDER DEFECTIVE No. - 453
of 2025
Appellant :- Smt. Kriti Goyal And Another
Respondent :- Shri Mukul Bansal
Counsel for Appellant :- Abhishek Kumar Kushwaha,Sudekchhit
Pandey
Hon'ble Neeraj Tiwari,J.
1. Heard learned counsel for the appellants and Ms. Radhika
Agrawal, Advocate, holding brief of Sri Tarun Agarwal, learned
counsel for the respondent.
2. Learned counsel for the respondent has raised preliminary
objection and submitted that apart from delay, amount in question
is less than 25,00,000/-. Therefore, appeal has to file before
District Judge, which is not objected by learned counsel for the
appellants.
3. Accordingly, appeal is dismissed with liberty to the appellants
to file appeal before District Judge, if so advised.
4. Certified copy of the impugned order be returned to learned
counsel for the appellants after keeping the photocopy of the same
on record.
Order Date :- 25.4.2025
