DATE : 3rd March, 2011
PER COURT :
Mr Ghanekar, learned Counsel for the applicant states on
instructions that the applicant does not press for the relief prayed for in
this application at this stage but seeks leave to file private paper-book
and further requests this Court to set down the appeal for hearing.
Learned Counsel states that in the event his request is acceded to by
this Court, the applicant would not press for the relief at this stage.
2. We see no impediment whatsoever in acceding to the request of
the learned Counsel for the applicant. We accordingly dismiss this

2 Cri.Application No.5164 of 2010
application as not pressed and grant leave to the applicant to file private
paper - book within three weeks from today. We further direct that the
appeal be set down for hearing, in the event the private paper-book is
filed. Application is accordingly dismissed as not pressed with the
aforesaid leave and directions.

(A.V. POTDAR, J.) ( P.V. HARDAS, J.)
