AMIT RAWAL, J. (ORAL)
Prayer in review application under Order 47 Rule 1 read with
Section 151 of the Code of Civil Procedure is for reviewing the order dated
25.09.2019.
Present review application is bereft of final order. Since the
final order is not available, it is not comprehendible that how learned
counsel for the review applicant/petitioner could make out an error apparent
on record.
Faced with the aforesaid situation, learned counsel for the
review applicant/petitioner seeks liberty of this Court for withdrawal of
present review application with liberty to file fresh one as and when the
final order is available.
Ordered accordingly.
