# Allahabad High Court, A482/7318/2019, 2019-03-15

Court No. - 70
Case :- APPLICATION U/S 482 No. - 7318 of 2019
Applicant :- Rajpal Singh
Opposite Party :- State Of U.P.
Counsel for Applicant :- Ajay Kumar Mishra
Counsel for Opposite Party :- G.A.
Hon'ble Sanjay Kumar Singh,J.
Learned counsel for the applicant submitted that since the
prayer has not been properly mentioned in the application,
therefore, the applicant wants to withdraw the present
application with liberty to file a fresh application.
In view of above, the application is rejected as withdrawn with
liberty to file a fresh application with better particulars.
Office is directed to return the certified copy of the impugned
order to the learned counsel for the applicant after retaining the
photocopy of the same on record.
