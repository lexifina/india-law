 O R D E R
This Criminal Original Petition is filed for a direction to the
second respondent to file a final report in connection with Crime No.1
of 2015, dated 07.02.2015 on the file of the second respondent within a
stipulated time.

submit that the second respondent will file a final report within a
period of six months.
3. In view of the same, the second respondent is directed to
complete the investigation and file a final report on or before
31.01.2016.
4. With the above direction, this Criminal Original Petition is
disposed of.
