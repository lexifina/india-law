# Allahabad High Court, A482/28813/2023, 2023-08-08

Neutral Citation No. - 2023:AHC:158878
Court No. - 89
Case :- APPLICATION U/S 482 No. - 28813 of 2023
Applicant :- Sarfaraj
Opposite Party :- State of U.P. and Another
Counsel for Applicant :- Surendra Mohan Mishra,Vishveshwar Mani
Tripathi
Counsel for Opposite Party :- G.A.
Hon'ble Deepak Verma,J.
1. Heard Sri Surendra Mohan Mishra, learned counsel for the
applicant and Sri Vishwa Deepak Mishra, learned AGA for the
State.
2. The present 482 Cr.P.C. application has been filed to quash the
impugned order dated 06.07.2023 passed in Case No.926 of 2023,
Under Sections 125 Cr.P.C., P.S. Siddharth Nagar, District
Siddharth Nagar, passed by Addl. Principal Judge, Family Court,
Siddharth Nagar.
3. Counsel for the applicants submits that applicant has challenged
the impugned order dated 06.07.2023 passed by learned
Additional Principal Judge, Family Court, Siddharth Nagar that
second recall application for set aside the ex parte order is not
maintainable. First recall application of the applicant was rejected
on merit vide order dated 26.04.2023.
4. Per contra, learned A.G.A. submits that the applicant has not
challenged the order dated 26.04.2023 by this application, the
order passed on 06.07.2023 is just and proper.
5. In view of the above, order dated 06.07.2023 is just and proper.
No interference is warranted, at this stage.
6. The present 482 application is dismissed with the aforesaid
observation.
Order Date :- 8.8.2023
