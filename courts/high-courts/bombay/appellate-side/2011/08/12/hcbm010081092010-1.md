This is an application for condonation
of delay of 95 days in seeking leave to file
appeal. The learned counsel for the respondent
has a very strong objection to condonation of
delay. However, for the reasons mentioned in
the application, the application is allowed.
The delay is condoned. List the application for
leave to file appeal for admission on
26-8-2011. The application accordingly stands
disposed of.
