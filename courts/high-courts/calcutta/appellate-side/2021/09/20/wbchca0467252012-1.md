# Calcutta High Court, CRR/3083/2012, 2021-09-20

Sr.45
 20-09-2021
 Subha.
 Court no. 34
 IN THE HIGH COURT AT CALCUTTA
 CRIMINAL REVISIONAL JURISDICTION
 APPELLATE SIDE
 ( Via Video Conference )
 CRR 3083 of 2012
 In the matter of : Remi Bibi ….petitioner.
In Re : An application under Sections 482 of the Code of
Criminal Procedure.
 The revisional application under Section 482 of the
Code of Criminal Procedure was preferred for a direction from
this court for arresting the accused persons.
 Having regard to the prayers so advanced by the
complainant/petitioner, I am of the view that the prayer so
advanced before this court is completely misconceived.
 Accordingly, the present revisional application being
CRR 3083 of 2012 is dismissed.
 All pending applications, if any, in connection with
revisional application, are consequently disposed of.
 Interim order, if any, is hereby vacated.
 All parties are to act on the server copy of this order
duly downloaded from the official website of this court.
 ( Tirthankar Ghosh, J. )
