HON'BLE MR. JUSTICE PANKAJ BHANDARI
Order
19/07/2019
1. Petitioner has filed this misc. petition seeking fair
investigation.
2. Learned Public Prosecutor has submitted the report, which is
taken on record. As per the report, Police has come to the
conclusion that no offence is made out and Police has already file
negative final report before the concerned Court.
3. In view of the same, misc. petition has become infructuous
and the same is dismissed as having become infructuous.
4. However, petitioner would be free to file protest petition, if so
advised.
(PANKAJ BHANDARI),J
