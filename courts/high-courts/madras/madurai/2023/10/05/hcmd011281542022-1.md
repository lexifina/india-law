2. When the matter is taken up for hearing today, the learned
counsel appearing for the petitioner/second respondent would submit that
the second contemnor/first petitioner has filed an application for return
of the property before the jurisdictional Court and the same is pending
and that the petitioner/second respondent has already made no objections
to the application.
3. The learned Government Advocate (Criminal Side) appearing
for the first contemnor/first respondent would submit that they have also
stated no objections for allowing the return of property petition.
4. The learned counsel appearing for the petitioner/second
respondent would further submit that since the application has already
been filed, the present contempt petition may be closed.
