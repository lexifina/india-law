 ORDER
This petition has been filed to direct the second respondent to
register the case on the petitioner's complaint dated 22.04.2015 and
proceed with the same according to law within the time frame as fixed by
this Court.
2. Heard the learned counsel for the petitioner and the learned
Government Advocate(Crl.Side) appearing for the State.
3. Learned Government Advocate (Crl.Side) submits that on the same
set of facts, a case has already been registered and the investigation
has been conducted and the same was closed and a copy of the Closure
Report has been served to the petitioner.
4. Recording the same, this Criminal Original Petition is closed.
