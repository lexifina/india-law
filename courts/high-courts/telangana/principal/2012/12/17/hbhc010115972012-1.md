# High Court for the State of Telangana, TRCRLP/257/2012, 2012-12-17

THE HON'BLE SRI JUSTICE K.C. BHANU
TRANSFER CRIMINAL PETITION NO.257 OF 2012
ORDER:
This Transfer Criminal Petition, under Section 407 of the Code
of Criminal Procedure, 1973 is filed to withdraw and transfer
C.C.No.1425 of 2012 pending on the file of II Additional Chief
Metropolitan Magistrate (Mahila Court), Vijayawada to the file of IV
District Court (Mahila Court), Vijayawada to try along with S.C.No.277
of 2012.
2. Heard.
3. Transfer Criminal Petition is dismissed giving liberty to the
petitioner to file necessary transfer application before the concerned
District Court. Miscellaneous petitions, if any, pending in this Transfer
Criminal Petition shall stand closed.
