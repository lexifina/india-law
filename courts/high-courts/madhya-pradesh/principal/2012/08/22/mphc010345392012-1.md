# High Court of Madhya Pradesh, MCC/924/2012, 2012-08-22

1
MCC No.924/2012
22.8.2012
 None appears for the applicant.
This application has been filed for restoration of
W.P. No.6058/2008 (s) which was dismissed for non
compliance with the peremptory order passed by this
Court.
On perusal of the reasons given in the application
and finding the same to be bonafide, the restoration
application is allowed. Writ petition be restored in its
original file and it be placed for orders before the
appropriate Bench.
Accordingly, this application stands allowed and
disposed of.
 (RAJENDRA MENON)
