1. By this Interim Application, the Applicant has prayed that the petition,
which came to be dismissed for non prosecution by order dated 28th March 2025,
be restored to the file of this Court.

opinion that the petition be restored to the file of this Court. We, accordingly,
allow the Interim Application in terms of prayer clause (a). Interim Application is
disposed off. No costs.
