# High Court of Orissa, WP(C)/4506/2015, 2019-01-15

06. 15.01.2019 Learned counsel for the petitioner seeks
permission to withdraw the writ petition with liberty to file
the same afresh if any cause of action still survives. A
memo filed to that effect is taken on record.
 Granting such liberty, the writ petition is
accordingly dismissed as withdrawn.
 All pending misc. cases/I.As., if any, are
accordingly disposed of.
