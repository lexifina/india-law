# High Court of Madhya Pradesh, MCRC/46295/2020, 2020-12-15

(VISHNU PRATAP SINGH CHAUHAN)
JUDGE
The High Court Of Madhya PradeshThe High Court Of Madhya Pradesh
MCRC-46295-2020
(LALYO @ LALE @ MOIN ANSARI Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 15-12-2020
Heard through Video Conferencing.
Shri Shashank Pandey, learned counsel for the applicant.
Shri Sanjay K. Malvi, learned Panel Lawyer for the respondent/State.
The applicant has filed this application for modification in the order
dated 27.08.2020 passed in M.Cr.C.No.12006/2020.
Having heard learned counsel of both the parties.
The applicant had filed an application for releasing him on bail. This
Court vide order dated 27.01.2020 passed in M.Cr.C.No. 298/2020 allowed
the application and passed a bail order but by way of typographical mistake,
name of the applicant was wrongly mentioned in that order. The applicant
again filed an application for modification in the order dated 27.1.2020 passed
in M.Cr.C.No.298/2020 and this Court vide order dated 27.08.2020 passed in
M.Cr.C. No.12006/2020, allowed the modification in the order dated
27.01.2020 but again there is typographical mistake occurred in the order; in
place of the previous order dated 27.01.2020, the order dated 21.01.2020 was
typed.
In these circumstances, this Court is inclined to allow this modification
application and it is directed that in the order dated 27.08.2020 passed in
M.Cr.C.No.12006/2020 wherever date "21.01.2020" is written, it be read as
"27.01.2020".
This order shall be read as a part of order dated 27.1.2020 passed in
M.Cr.C.No.298/2020 and order dated 27.08.2020 passed in
M.Cr.C.No.12006/2020 by this Court.
With the aforesaid modification, this application stands disposed of.
