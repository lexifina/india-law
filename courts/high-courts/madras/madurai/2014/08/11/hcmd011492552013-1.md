# Madras High Court, TR CMP(MD)/442/2013, 2014-08-11

1
BEFORE THE MADURAI BENCH OF MADRAS HIGH COURT
DATED : 11.08.2014
CORAM
THE HONOURABLE MR.JUSTICE R.KARUPPIAH
Tr.C.M.P.(MD)No.442 of 2013
and
M.P.(MD)No.1 of 2013
Jeya Pon : Petitioner
-Vs-K.Vijayalingam : Respondent
PRAYER: Petition is filed under Section 24 of the Code of Civil Procedure
praying to withdraw the petition in H.M.O.P.No.136 of 2012 from the file
of the Sub-Court, Palani and transfer the same to the file of the Sub-Court, Tuticorin.
For Petitioner : Mr.R.Sundar
For Respondent : Mr.T.A.Ebenezer
O R D E R
This Transfer Civil Miscellaneous Petition has been filed to
withdraw the petition in H.M.O.P.No.136 of 2012 from the file of the Sub-Court, Palani and transfer the same to the file of the Sub-Court,
Tuticorin.
2. Heard the learned Counsel appearing for the petitioner and the
learned Counsel appearing for the respondent and perused the materials
available on records.
3. Both the learned Counsel submitted that H.M.O.P.No.136 of 2012
pending on the file of the Subordinate Court, Palani may be transferred
to the Principal Subordinate Court, Tirunelveli.
4. In view of the submissions made by both the learned Counsel and
considering the convenient of both parties, H.M.O.P. case has to be
transferred as prayed for by both the learned Counsel.
5. In the result, H.M.O.P.No.136 of 2012 pending on the file of the
Subordinate Court, Palani is ordered to be transferred to the file of the
Principal Subordinate Court, Tirunelveli.
6. The Transfer Civil Miscellaneous Petition is ordered accordingly.
Consequently, the connected Miscellaneous Petition is closed. No costs.
