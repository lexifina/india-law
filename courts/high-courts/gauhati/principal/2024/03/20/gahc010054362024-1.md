Heard Mr. A. Hassan, learned counsel for the applicant.
The application has been filed for correcting the name of the sole
respondent.
It is submitted that in the contempt petition the name of the sole
respondent has been mentioned as ‘Mrinal Hazarika’ whereas it should
have been written as ‘Mrinal Saikia’.
The application is disposed with a direction to the applicant to file
amended Causetitle correcting the name of ‘Mrinal Hazarika’ by ‘Mrinal
Saikia’.
