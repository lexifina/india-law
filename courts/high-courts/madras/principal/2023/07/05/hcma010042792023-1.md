# Madras High Court, A/3231/2023, 2023-07-05

A.No.3231 of 2023
in
CS.No.509 of 1999
A.A.NAKKIRAN, J.
This application has been filed to condone the delay of 2435 days in
filing written statement in the above Civil Suit.
2. Heard both sides.
3. The learned counsel for the respondent has no objection in allowing
this application.
4. Being satisfied with the reasons stated in the affidavit filed in support
of this application and in view of no objection submitted by the learned
counsel for the respondent, this Court is inclined to allow this application on
payment of cost of Rs.3000/- (Rupees Three Thousand Only) before the
Mediation Centre attached to this court on or before 12.07.2023.
5. Accordingly, this application is allowed.
6. Post the main case before this court on 13.07.2023.
