# High Court of Madhya Pradesh, MCC/701/2016, 2016-03-01

MCC-701-2016
(A.S. ANSARI Vs THE STATE OF MADHYA PRADESH)
01-03-2016
Shri Mukesh Mishra, learned counsel for the applicant.
Shri A. Ojha, learned counsel for the respondents.
This application has been filed for restoration of Writ Petition
No.6023/2005, which was dismissed for want of prosecution vide order
dated 22/06/2015. There being some delay in filing the application for
restoration, therefore, I.A. No.2951/2016 has been filed seeking
condonation of delay. Both the applications are supported by an
affidavit of the Advocate himself and there is no reason to disbelieve
the same. Finding the same to be bona fide, both the applications are
allowed.
Condoning the delay in filing the application, restoration
application is itself allowed.
Writ Petition No.6023/2005 is restored to its original number. After
restoration, Writ Petition No.6023/2005 be placed for orders before
appropriate Bench.
Application stands allowed and disposed of.
Certified copy as per rules.
(MISS VANDANA KASREKAR)
JUDGE
