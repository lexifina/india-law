# High Court of Madhya Pradesh, MCC/2471/2015, 2018-04-22

THE HIGH COURT OF MADHYA PRADESH
NATIONAL LOK ADALAT
MCC-2471-2015
(SMT. PHOOLMATI VISHWAKARMA Vs SHARADA PRASAD KUSHWAHA)
Jabalpur, Dated : 22-04-2018
Shri A.K. Pandey,, learned counsel for the applicants.
Learned counsel for the petitioners submits that the present
application is restoration application and the application is within
limitation.
Considering the averments made in the application which is duly
supported by an affidavit, we find sufficient cause has been shown in
the application to allow the application. Therefore, the restoration
application is allowed and the F.A No.310/2008 is directed to be
restored to its original number.
M.C.C stands disposed of.
