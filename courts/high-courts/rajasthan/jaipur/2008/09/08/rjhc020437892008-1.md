# High Court of Rajasthan, CW/7762/2008, 2008-09-08

D.B.Civil Writ Petition No.7762/2008
Kuldeep Kapoor V/s The State of Raj. & ors.
8.9.2008
Hon'ble the Chief Justice Mr.Narayan Roy
Hon'ble Mr.Justice Mohammad Rafiq
Mr.Ashish Kishore Saxena for the petitioner.
This matter earlier was adjourned on the request
of counsel for the petitioner to file amendment
application. Till date amendment application has not
been filed.
Learned counsel appearing on behalf of the
petitioner however seeks permission to withdraw this
writ application so as to file a properly constituted
writ application with necessary documents for which
amendment was to be filed.
This writ application accordingly is dismissed,
as withdrawn.
(Mohammad Rafiq)J. (Narayan Roy)C.J.
