# Madras High Court, A/3330/2022, 2022-08-12

A.No.3330 of 2022 in C.S.No.288 of 2020
A.No.3330 of 2022
in C.S.No.288 of 2020
KRISHNAN RAMASAMY.J.,
This application has been filed seeking to set aside the order dated
10.03.2022 setting the applicants/defendants exparte and restore the
defendants to the file of the suit in C.S.No.288 of 2020.
2. It is submitted by the applicants/defendants that since they were
actively pursuing the mediation process and defending suit at the interim
stage, there has been delay of 449 days in filing the written statement.
Therefore, the applicants/defendants would submit that the delay in filing the
written statement is only bonafide and is neither willful nor wanton. Hence,
the applicants/defendants filed this application praying to set aside the
exparte order dated 10.03.2022.
3. The learned counsel appearing for the respondents raised no
objections for the same.
4. This Court is satisfied with the reasons stated in the affidavit filed in
support of this Application. Accordingly, this Application stands allowed as
prayed for.
5. Post the main suit on 08.09.2022.
12.08.2022
