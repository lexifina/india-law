ORAL ORDER
Learned advocate Mr. Chaudhari for the applicant states
at bar that the charge sheet is filed pending hearing of
present Criminal Misc. Application, therefore, he seeks
permission to withdraw present application with a liberty to
file discharge application and also to file appropriate
proceedings either u/s 397 or 482 of the Code of Criminal
Procedure, 1973 before appropriate competent Court, after
remedy to file discharge application is availed. Permission is
granted. The application stands disposed of as withdrawn with
above liberty.
It is clarified that this Court has not examined the merits
of the present application.
(S.H.VORA, J)
