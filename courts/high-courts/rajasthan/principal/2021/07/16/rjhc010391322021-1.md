Judgment / Order
16/07/2021
Learned counsel for the petitoners submits that due to
inadvertence and typographical error in the cause title of the Bail
Application No.8419/2021 instead of writing FIR Number, Case
Number of the bail application filed before the Sessions court was
mentioned as “138/2021” whereas the FIR Number is “119/2020”
and thus, correct FIR number is to be mentioned in the order
dated 08.07.2021 passed by this Court.
Considering the submission, I am satisfied that there is
typographical error, which has crept in the order dated 08.07.2021
passed in Bail Application No.8419/2021.
Accordingly, this application is allowed and it is ordered that
in the order dated 08.07.2021 passed in the S.B. Criminal Misc.

(2 of 2) [CRLMA-198/2021]
Bail Application No.8419 /2021, the correct “FIR No.119/2020” be
read instead of “FIR No.138/2021”.
This order shall be treated as part & parcel of the order
dated 08.07.2021 passed in S.B. Cr. Misc. Bail Application
No.8419/2021.
(SANJEEV PRAKASH SHARMA),J
