ORAL ORDER
6/ 16-02-2012 Heard counsel for the parties.
Counsel for the petitioner seeks
permission to withdraw this application in
order to enable the petitioner to file
representation before the appointing Authority
for demonstrating that the petitioner was
qualified for a class-III post and there was a
vacancy on such class III post in Yatindra
Narayan Astang Ayurveda College, Champanagar,
Nathnagar, Bhagalpur where the father of the
petitioner was working before his death.
If he files such representation showing

will be re-examined and if found necessary be
routed through District Compassionate

That being so, this application is
permitted to be withdrawn with the
