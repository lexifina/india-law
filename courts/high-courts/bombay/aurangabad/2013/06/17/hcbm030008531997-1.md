COURT'S ORDER :
1. Heard learned Counsel for the parties.
2. The order dated 2-7-1997 passed by my learned predecessor,
dismissing the Second Appeal at admission stage, is sought to be reviewed
through this application.
3. On perusal of the application, there appears no reason why
review should be sought. The learned Judge very clearly rejected the
submissions of the learned Counsel for the appellants in unambiguous
words. There appears no ground for review prescribed by Order XLVII
Rule 1 of the Code of Civil Procedure, available to the applicants. There
is no discovery of new and important evidence, neither there is any
mistake or error apparent on the face of record. The applicants probably
placed reliance on the term used in Sub-Rule 1, "for any other sufficient
reason" for filing this application for review. Besides making same
submissions which were made earlier, no new submissions are made today

 (3)
for showing that the review should be allowed. The application for review
does not deserve to be allowed.
4. Hence, Application seeking review is dismissed. Rule
discharged. No costs.
