ORAL ORDER
9 02-11-2023 Heard the parties.
2. The petitioners have sought for the following reliefs:-
i. To set aside the order dated 18.08.2017 passed
by Sub-Judge 7, Gopalganj in T.S. No. 423 of
2013.
ii. To reject the petition dated 18.11.2014 filed by
the intervenors/respondents 1st set to be impleaded
as defendants in the suit.
3. There is no illegality in the impugned order. If the
petitioners have any dispute with regard to the newly added
defendants, they may file amendment application, if so advised,
and if such an amendment application is filed that will be dealt
in accordance with law by the Court below.
4. With the aforesaid observations and directions, this
application is dismissed.
