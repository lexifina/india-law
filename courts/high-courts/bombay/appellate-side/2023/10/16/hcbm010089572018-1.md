1. The order impugned allowed application under Order 7,
Rule 11(d) of the Code of Civil Procedure, 1908 such order has
status of a decree. Remedy of petitioner is to file appeal under
Section 96 of the Code of Civil Procedure, 1908. The writ petition
is, therefore, not maintainable.
2. Writ petition is, therefore dismissed with liberty to file
appeal under Section 96 of the Code of Civil Procedure, 1908.
