# High Court of Madhya Pradesh, MCC/2812/2014, 2015-08-07

MCC-2812-2014
(SMT. SHAKUNTALA AITS Vs THE STATE OF MADHYA PRADESH)
07-08-2015
Shri O.P.Tripathi, learned counsel for the applicant.
Shri R.N.Yadav, learned counsel for respondents/State.
This application has been filed for restoration of Writ Petition
No.10002/2014, which was dismissed on account of common
conditional order dated 16/07/2014. There being some delay in
filing the application for restoration, therefore, I.A. No.17544/2014
has been filed seeking condonation of delay. Both the applications
are supported by an affidavit of the Advocate himself and there is
no reason to disbelieve the same. Finding the same to be
bonafide, both the applications are allowed.
Condoning the delay in filing the application, restoration
application is itself allowed.
Writ Petition No.10002/2014 is restored to its original
number. After restoration, Writ Petition be placed for orders before
appropriate Bench.
Application stands allowed and disposed of.
Certified copy as per rules.
(VANDANA KASREKAR)
JUDGE
