This petition coming on for admission this day, the court passed the
following:
ORDER
The petitioner is assailing the order dated 30-04-2020 ( Annexure P/2).
On the face of it, the same appears to be an offshoot of order dated 11-04-2022
contained in ( Annexure P/1), which is under challenge at the instance of the
petitioner in WP No. 10345/22.
The petitioner submits that the order dated 11-04-2022 ( Annexure P/1)
has been lateron modified vide order dated 24-05-2022. However, the order
dated 24-05-2022 is not dispute in this petition.
In the present petition, the only challenge is to the order of recovery
dated 30-04-2022 ( Annexure P/2). Thus, since the petitioner has already
questioned the order dated 11-04-2022, which is subjudice in WP No.
10345/22, this court is not inclined to entertain the petition however, liberty is
extended to the petitioner to assail the order dated 30-04-2022 ( Annexure P/2)
as well as order dated 24-05-2022 (Annexure P/7) by moving an appropriate
application for amendment in WP No. 10345/22.
With the aforesaid, the petition stands disposed off.
