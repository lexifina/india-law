# High Court of Orissa, WP(C)/17264/2019, 2019-09-27

02. 27.09.2019 Heard learned counsel for the petitioner.
Since for the selfsame relief, the petitioner has
already filed original application before the State
Administrative Tribunal, which is pending for
adjudication, this Court is not inclined to entertain this
application. However, liberty is granted to the petitioner
to approach the appropriate forum in accordance with
law.
With the aforesaid liberty, the writ petition
stands disposed of.
