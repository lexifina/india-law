PC: (per the Hon’ble the Acting Chief Justice Dilip B. Bhosale)
Heard Sri Vedula Venkatarama, learned Senior Counsel for the
appellant and Sri C.V. Mohan Reddy, learned Senior Counsel for
respondent No.1.
This writ appeal is directed against the order dated
21-05-2015 whereby learned single Judge granted interim suspension
of the order impugned in the writ petition, as prayed. This order was
passed in the vacation. It was open for the appellant to file
miscellaneous petition for either seeking vacation of the interim order
or for hearing of the writ petition itself for final disposal. If we interfere
with the order impugned in the present appeal, that will virtually
amount to dismissing the writ petition without hearing and, therefore,
we deem it appropriate to relegate the appellant to file miscellaneous
petition for appropriate relief before learned single Judge.
With these observations, we dispose of the writ appeal.
If any such miscellaneous petition is filed, we request the
learned Judge to consider and decide it expeditiously. All contentions
of the parties on merits are kept open.
Miscellaneous petitions, if any, also stand disposed of.
