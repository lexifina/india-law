 ORAL ORDER
4. 08-02-2012 Learned counsel for the petitioner and learned
A.P.P. for the State are present.
By order dated 4.7.2011 ten days time was given
to the petitioner to surrender before the trial Court and
make prayer for bail which was not complied with and when
the matter was taken up on 24.01.2012, again two weeks
time was given to comply with the direction given in order
dated 4.7.2011.
The directions given in order dated 4.7.2011
have neither been complied with nor any application has
been filed for any modification of the same.
In view of the aforesaid, this application stands
dismissed for non-compliance of the order dated 4.7.2011.
Anand Kr.
