# High Court of Orissa, WP(C)/14458/2011, 2019-11-14

20. 14.11.2019 On 16.05.2019 the following order was passed:
 “Learned counsel for the petitioner is not
present. Earlier he has taken time.
 This matter to come up on 27.06.2019 on which
date if learned counsel for the petitioner has not
appeared, this matter will be deemed to have been
dismissed.”
 Thereafter on 27.6.2019, 01.08.2019 and 22.08.2019,
learned counsel for the petitioner has not appeared.
 Today also none appears for the petitioner.
 Accordingly, the writ petition stands dismissed for
non-prosecution.
