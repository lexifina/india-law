HON'BLE MR. JUSTICE NARENDRA SINGH DHADDHA
Order
31/03/2023
First bail application filed by the petitioner was
withdrawn by learned counsel for the petitioner, which was
accordingly dismissed by this Court vide order dated 25.08.2022
in S. B. Criminal Miscellaneous Bail Application No.4376/2022. By
the said order, no liberty was granted to the petitioner to file a
fresh bail application directly before this Court.
Instead of filing a fresh bail application before the trial
court, the petitioner has directly filed this second bail application
before this court, whereas he should have first approached the
trial court.
The second bail application filed by the petitioner is
disposed of accordingly.
(NARENDRA SINGH DHADDHA),J
