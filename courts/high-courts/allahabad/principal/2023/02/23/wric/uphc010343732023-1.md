# Allahabad High Court, WRIC/5527/2023, 2023-02-23

Court No. - 48
Case :- WRIT - C No. - 5527 of 2023
Petitioner :- Laxmi
Respondent :- State Of U.P. And 30 Others
Counsel for Petitioner :- Mridul Kumar
Counsel for Respondent :- CSC,Bhupendra Kumar Tripathi
Hon'ble Saral Srivastava,J.
Heard learned counsel for the petitioner, learned Standing Counsel
for State-respondents and Sri Bhupendra Kumar Tripathi, learned
counsel for respondent no.3.
In a partition suit i.e. Original Suit No.T202114360203120, final
decree has been passed on 24.08.2022. The petitioner wants
execution of the final decree dated 24.08.2022 passed in Original
Suit No.T202114360203120.
The petitioner in the present writ petition has approached this
Court seeking a direction upon respondent no.2 to execute the final
decree dated 24.08.2022. In this respect, petitioner has submitted a
representation dated 15.09.2022 to the respondent no.2, which is
enclosed as Annexure 1 to the writ petition.
Be that as it may, for execution of final decree, a procedure
contemplated under Section 214 of U.P. Revenue Code has to be
followed and a proper application in this regard has to be
submitted under the provision of U.P. Revenue Code before the
competent authority i.e. respondent no.2 and respondent no.2 will
proceed in accordance with the procedure as contemplated under
the U.P. Revenue Code for execution of the final decree. Petitioner
has not yet filed any application as contemplated under Section
214 of U.P. Revenue Code and has submitted only a
representation, therefore, no direction as sought by the petitioner
can be issued in the present writ petition.
Accordingly, writ petition lacks merit and is hereby, dismissed
with liberty to the petitioner to file an appropriate application as
contemplated under Section 214 of U.P. Revenue Code before the
competent authority.
