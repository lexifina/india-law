# Patna High Court, CR. MISC./35352/2008, 2011-07-13

IN THE HIGH COURT OF JUDICATURE AT PATNA
Cr.Misc. No.35352 of 2008
Nemu Singh, Son of late Goli Singh @ Dulahi Singh, Resident of Village Pithauri, PS Baniapur,
District Saran at Chapra ---- petitioner
Versus
State Of Bihar ---- Opposite Party
-----------
2 13.7.2011 Heard the parties.
This application has been field against the order dated
2.7.2008, by which the Court below has rejected the application
filed under Section 311 of the Code of Criminal Procedure for
examination of witnesses. When the evidence was closed and the
accused examined in this case under Section 313 of the Code of
Criminal Procedure, this application was filed which has been
rejected.
Now, it appears that the judgment has already been
delivered in this case, thus this application has become
infructuous.
This application is dismissed as infructuous.
 Sanjay ( Sheema Ali Khan, J.)
