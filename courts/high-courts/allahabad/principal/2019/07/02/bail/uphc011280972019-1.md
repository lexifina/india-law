# Allahabad High Court, BAIL/25979/2019, 2019-07-02

Court No. - 44
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 25979 of 2019
Applicant :- Ram Dayal
Opposite Party :- State Of U.P.
Counsel for Applicant :- Karuna Nand Tiwari,Amar Bahadur Maurya
Counsel for Opposite Party :- G.A.
Hon'ble Ramesh Sinha,J.
Heard Sri K.N. Tiwari, learned counsel for the applicant and Sri A.R.
Chaurasia, learned A.G.A. for the State.
Learned A.G.A. has pointed out that the applicant is involved in three
cases but the bail orders of the same have not been annexed with the
present bail application to which learned counsel for the applicant submits
that the applicant has been granted bail in one case only and so far as other
two cases are concerned in the said cases the bail application is yet to be
filed. He prays that the present application be dismissed as not pressed
with liberty to file fresh.
Accordingly, the present bail application is dismissed as not pressed with
liberty to file fresh.
Office is directed to return a certified copy of this order to the learned
counsel for the applicant after retaining a photocopy of the same.
It is made clear that the present bail application has not been decided on
merits by this Court, hence it may not be treated as tied up or part heard to
this Bench.
Order Date :- 2.7.2019
Shiraz
