# High Court for the State of Telangana, CRLP/7678/2010, 2013-06-17

THE HON’BLE SRI JUSTICE C. PRAVEEN KUMAR
CRIMINAL PETITION NO. 7678 OF 2010
ORDER:
1. This is a Criminal Petition filed by the petitioner under Section 482 of
Code of Criminal Procedure, 1973 (for short “Cr.P.C.”) to quash the
proceedings in C.C.No.235 of 2007 on the file of the Additional Judicial First
Class Magistrate, Avanigadda, Krishna District.
2. The learned counsel for the petitioner seeks permission of this Court to
withdraw the Criminal Petition giving liberty to file an application for
discharge before the trial Court.
3. The permission is accorded.
4. Accordingly, the Criminal Petition is dismissed as withdrawn with a
liberty to file an application for discharge before the trial Court under Section
239 of Cr.P.C., if the charges are not already framed. Miscellaneous
petitions, if any, pending shall stand closed.
