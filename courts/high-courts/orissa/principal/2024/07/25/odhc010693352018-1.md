25.07.2024
02. 1. This matter is taken up through Hybrid
Arrangement (Virtual/Physical) Mode.
 2. Heard learned counsel appearing for the Parties.
3. Since the present Writ Petition has been filed only
on mere apprehension and no further action has been
taken basing on Annexure-5, this Court is not inclined to
entertain the Writ Petition. However, it is open for the
Petitioner to file appropriate application, if any adverse
order is passed against him while complying the order
under Annexure-5.
4. With the aforesaid observations, the Writ Petition
stands disposed of. Interim order passed earlier stands
vacated.
