CORAM: HONOURABLE MR. JUSTICE VIPUL M. PANCHOLI
 Date : 30/07/2020
 ORAL ORDER
Learned advocate for the applicant submitted that
after filing of the charge-sheet, the applicant has not
filed an application before the Sessions Court. He,
therefore, seeks permission to withdraw this
application with a view to file an application before
the Sessions Court.
Permission, as prayed for, is granted. The
application stands disposed of, as withdrawn. Liberty
is reserved to the applicant to file an application
before the Sessions Court. It is clarified that this
Court has not examined the merits of the case and,
therefore, as and when such an application is filed
before the Sessions Court, the same shall be examined
on its own merits.
(VIPUL M. PANCHOLI, J)
