Order
20/05/2024
The present application has been filed under Section 482 of
Cr.P.C. for correction/modification of the order dated 20.03.2024
passed by this Court.
It has been averred in the application that in order dated
20.03.2024, inadvertently, District Alwar has been mentioned
instead of District Ajmer and the name of the learned counsel for
the petitioner is mentioned as Shri Mahendra Singh instead of Shri
Mahendra Singh Gothwal.
For the reasons mentioned in the application, the same is
disposed of.
The order dated 20.03.2024 passed by this Court is modified
to the extent that District Alwar be read as District Ajmer and

[2024:RJ-JP:23741] (2 of 2) [CRLMA-206/2024]
name of learned counsel for the petitioner be read as Shri
Mahendra Singh Gothwal instead of Shri Mahendra Singh.
This order shall be treated as part and parcel of order dated
20.03.2024 passed by this Court.
(PRAVEER BHATNAGAR),J
