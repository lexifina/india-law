 This Criminal Revision Petition is filed under Section
397 read with 401 of the Code of Criminal Procedure, 1973, by
the advocate for the petitioner praying to set aside the order

ORDER

the petition with liberty to file an appropriate petition.
 The petition is dismissed as withdrawn with liberty to the
petitioner to file any other petition, if the law so permits.
