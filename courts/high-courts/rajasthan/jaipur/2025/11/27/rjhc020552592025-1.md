HON'BLE MR. JUSTICE BIPIN GUPTA
Order
27/11/2025
1. Learned counsel for the respondent submits that the appeal
in which the interlocutory order was passed, against which the
present writ petition is pending, has been finally decided by the
learned First Appellate Court, vide order dated 06.08.2025,
therefore, the present writ petition has rendered infructuous.
2. Learned counsel for the petitioner is not in a position to
refute the above fact. Taking into consideration, fact that Civil
Regular Appeal has been decided vide order dated 06.08.2025,
the present Civil Writ Petition is dismissed as having become
infructuous.
3. However, the petitioner would be at liberty to file recalling
application, if the first appeal has not been decided.
4. All pending application(s), if any, also stand disposed of.
(BIPIN GUPTA),J
