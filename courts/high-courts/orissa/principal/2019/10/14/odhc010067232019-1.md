# High Court of Orissa, WP(C)/2651/2019, 2019-10-14

07. 14.10.2019 Petitioner seeks permission to withdraw the writ
petition with liberty to file fresh writ application if any cause of
action arises. A memo to that effect has been filed in Court
today which is taken on record.
 Permission is granted.
 Accordingly, the writ petition stands dismissed as
withdrawn with liberty to the petitioner to file fresh writ
application if any cause of action arises.
 The interim order passed earlier stands vacated.
