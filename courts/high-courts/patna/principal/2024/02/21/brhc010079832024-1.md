CORAM: HONOURABLE MR. JUSTICE SANDEEP KUMAR
ORAL ORDER
2 21-02-2024 The petitioner has challenged the order dated
03.03.2023 passed in Case No. 137726/2016-17 by the State
Information Commission by which a fine of Rs. 25,000/- as
punishment has been imposed on the petitioner.
2. It has been contended by the learned counsel for
the petitioner that the impugned order is perverse and cannot be
sustained as the show cause filed has not been considered and

Patna High Court CWJC No.2041 of 2024(2) dt.21-02-2024
2/2
the same has been rejected as having been found unsatisfactory.
3. The learned counsel appearing for the State
Information Commission has tried to defend the impugned order
but has not been able to defend the order.
4. These kind of orders are not expected to be
passed by the State Information Commission. The show cause
should have been considered and discussed by the State
Information Commission and thereafter any order prejudicial to
the petitioner would have been passed.
5. In these circumstances, this application is
allowed and the impugned order dated 03.03.2023 passed in
Case No. 137726 of 2016-17 and consequential order dated
10.05.2023 are hereby quashed.
6. This application stands allowed.

Shishir/-
