# High Court of Madhya Pradesh, MCC/1158/2014, 2014-07-31

MCC NO..1158/2014
31/07//2014

Shri Sunil Kumar Yadav, learned counsel for the
applicant.
Shri Naveen Dubey, learned counsel for the
respondents on advance notice.
This application has been filed for restoration of
F.A,No.384/11, which has been dismissed for want of
prosecution..
Keeping in view the reasons indicated in the
application and the explanation given in I.A.No.10281/14,
for condoning the delay, which is supported by an affidavit of
the counsel himself and finding the same to be bonafide,
both applications are allowed.
Condoning the delay in filing of the application for
restoration, the restoration application itself is allowed.
This appeal is restored to its original file and it be
placed for hearing before an Appropriate Bench.
The application stands allowed and disposed of.
 (RAJENDRA MENON) ( ALOK VERMA )
 JUDGE JUDGE
