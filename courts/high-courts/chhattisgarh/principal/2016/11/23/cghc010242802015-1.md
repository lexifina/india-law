Per Deepak Gupta, C.J.
On 07.11.2016, we had passed the following order:
“07.11.2016 Shri B.D.Guru, counsel for the appellants.
Shri Arun Sao, Deputy Advocate General for the
State and its authorities.
Order 47 Rule 1 of the Code of Civil Procedure,
1908 (hereinafter referred to as 'the Code') provides that
any person considering himself aggrieved by a decree or
order from which an appeal is allowed, but from which no
appeal has been preferred, may file a revision petition. It
is obviously meant that if an appeal has been filed, then
a review petition is not maintainable. Though Order 47
Rule 1 of the Code is in strict sense may not apply in this
case but the principles would apply.
We are of the view that a party cannot be

4
permitted to file a review petition as well as any appeal
at the same time. It is for the party to decide which
remedy wants to prosecute.
Shri B.D.Guru, learned counsel for the appellants
states that he will seek instructions in the matter.
List it on 23rd November, 2016.”
2. Shri Rajat Jariwal, learned counsel for the appellant states that in view of
the pendency of the review petitions, the appellant seeks leave of this Court to
withdraw the above appeals reserving liberty to the appellants to pursue the
remedy in review petitions. The appellant also seeks liberty that in case the
review petitions are decided against the appellant, it may seek appropriate remedy
in accordance with law.
3. Liberty, as prayed for, is granted.
4. With the aforesaid liberty, the appeals are dismissed as withdrawn.
