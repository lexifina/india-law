# High Court of Madhya Pradesh, MCC/1025/2017, 2017-04-24

MCC-1025-2017
(SMT. REETA AWADHIYA Vs THE STATE OF MADHYA PRADESH)
24-04-2017
Shri R.B.Gautam, learned counsel for the applicant.
Shri Puneet Shroti, learned panel lawyer for the
respondentson advance copy.
This is an application for restoration of writ petition.
Upon perusal of the order it is clear that the application has
not been dismissed for want of prosecution or in default.
Considering the aforesaid, the application for restoration is
not maintainable.
Learned counsel for the applicant prays for liberty to file
appropriate application.
The application is dismissed with aforesaid liberty.
