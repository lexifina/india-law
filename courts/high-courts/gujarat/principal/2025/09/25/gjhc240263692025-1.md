ORAL ORDER
After arguing the matter for some time, learned
advocate Ms. Sanvida Soni for the applicant seeks
permission to withdraw the present application along with
Criminal Appeal which is in filing stage with a liberty to file
Criminal Revision Application before the appropriate forum,
as the present application is not maintainable.
Permission, as sought for, is granted. The present
application stands disposed of as withdrawn with above
liberty.
In view of the above, the Criminal Appeal which is in
filing stage stands disposed off accordingly.
Registry to return the original papers to the learned
advocate for the applicant after keeping the xerox copy of
the same on record as per rule.
