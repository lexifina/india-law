6.It may not be necessary to delve any further into other
aspects of the matter, as there is no disputation or contestation that the
captioned two HCPs are squarely covered by S.Subashini's case.
Therefore, impugned preventive detention orders in both captioned
HCPs are also set aside on the same point ie., on the same point as in
Subashini's case.

7.Ergo, the sequitur is, captioned I HCP is allowed.
Impugned preventive detention order dated 21.07.2023 bearing
reference No.64/BCDFGISSSV/2023 made by the second respondent is
set aside and the detenu Thiru.Murugan @ Kuttai Murugan, aged 40
years, son of Thiru.Alagu, is directed to be set at liberty forthwith, if not
required in connection with any other case / cases.
8.Apropos, the sequitur is, captioned II HCP is allowed.
Impugned preventive detention order dated 04.08.2023 bearing
reference No.73/BCDFGISSSV/2023 made by the second respondent is
set aside and the detenu Thiru.Rajeshkannan @ Kuppai Kannan, aged
38 years, son of Thiru.Nallan, is directed to be set at liberty forthwith, if
not required in connection with any other case / cases. There shall be no
order as to costs.
