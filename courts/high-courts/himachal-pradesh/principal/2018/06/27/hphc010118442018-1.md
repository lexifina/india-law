Ajay Mohan Goel, Judge (Oral)
 Having heard learned Senior Counsel appearing
for the petitioner and in view of order which is proposed to be
passed, this Court does not deem it necessary to issue notice
to the respondent.
2. Prima facie, taking into consideration the fact that
the application so filed under Order 23, Rule 1 of the Code of
Civil Procedure before the learned trial Court was as cryptic
and vague as it could have been, there is no infirmity with the
order passed by learned Court below dismissing the said
application.
 --
-

	-

3. At this stage, Mr N.K. Thakur, learned Senior
Counsel appearing for the petitioner submits that party
should not be made to suffer for the lapses of the Counsel as
it was the duty of the learned Counsel representing the said
party to have had filed an appropriate application in this
regard. He further submits that interest of justice would be
served in case present petitioner is permitted to withdraw the
application which was filed under Order 23, Rule 1 of the
Code of Civil Procedure before the learned trial Court with
liberty to file an appropriate application under the same
provisions of law afresh.
4. Taking into consideration the prayer so made by
learned Senior Counsel and the fact that what weighed with
the learned trial Court while dismissing the application, was
crypticness in the application, prayer of Mr. N.K. Thakur,
learned Senior Counsel is allowed. Petitioner/plaintiff is
permitted to withdraw application dated 15.11.2017 which
was so filed under Order 23, Rule 1 of the Code of Civil
Procedure before the learned trial Court. As the application so
filed by the plaintiff has been permitted to be withdrawn,
accordingly, impugned order dated 22.01.2018, which was so
passed by the learned trial Court on the same, is rendered

inoperative. Liberty is granted to the petitioner/plaintiff to file
a fresh application under Order 23, Rule 1 of the Code of Civil
Procedure before the learned trial Court, if so advised, subject
to plaintiff paying a cost of 3,000/- before filing any such
application, which cost shall be paid against proper receipt to
the District Legal Service Authority, Una. It is clarified that in
case the cost so directed by the Court is not deposited by the
petitioner/plaintiff, then no fresh application under Order 23,
Rule 1 CPC, shall be entertained by the learned trial Court.
The petition stands disposed of in above terms, so
also pending miscellaneous application(s), if any.
Copy dasti.
 (Ajay Mohan Goel)
