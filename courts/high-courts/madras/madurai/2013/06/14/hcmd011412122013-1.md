 PETITION FOR ANTICIPATORY BAIL Under Sec. 438 Cr.P.C.
ORDER : The Court Made the following order :-
The petitioner herein/accused No.1 in Crime No.504 of 2012 on the
file of the respondent police, by apprehending arrest for the alleged
offences punishable under Section 174 of the Criminal Procedure Code has
approached this Court for an order for his release on anticipatory bail
under Section 438 of the Code of Criminal Procedure.
2. The learned counsel appearing for the petitioner would submit that
there is no dowry demand was made as alleged by the defacto complainant.
3. The learned Government Advocate (Criminal side) appearing for the
State would submit that investigation is going on. As on date, the
petitioner has not been arrayed as accused.
4. In view of the statement made by the learned Government Advocate,
this Criminal Original Petition is dismissed. Liberty is granted to the
petitioner to file an application in future, if necessary.
