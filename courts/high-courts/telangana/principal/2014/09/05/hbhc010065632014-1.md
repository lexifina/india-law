# High Court for the State of Telangana, CRLP/10290/2014, 2014-09-05

HONOURABLE Dr. JUSTICE B.SIVA SANKARA RAO
CRIMINAL PETITION No.10290 of 2014
ORDER :
This Criminal Petition filed under Section 438 Cr.P.C by
petitioner/A-5 in Crime No.168/2014 on the file of Proddatur Rural Police
Station, Kadapa District registered against the petitioners and others for
the offences punishable under Section 302 read with Section 34 IPC.
2. Learned counsel appearing for the petitioner seeks
permission of this Court to withdraw the Criminal Petition with liberty to
file a fresh application from changed circumstances.
3. Permission as sought for is accorded.
4. Accordingly, the Criminal Petition is dismissed as
withdrawn.
5. As sequel to it, miscellaneous petitions pending if any in
this criminal petition, shall stand closed.
___________________________
Dr. B. SIVA SANKARA RAO, J
