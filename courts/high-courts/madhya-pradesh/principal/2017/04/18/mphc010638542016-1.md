# High Court of Madhya Pradesh, MCC/3384/2016, 2017-04-18

MCC-3384-2016
(SMT. SEVANTI SURYAVANSHI Vs THE STATE OF MADHYA PRADESH)
18-04-2017
Shri Rajesh Dubey, learned counsel for the applicant.
Heard on I.A. No.592/2017, an application for condonation of delay.
For the reasons mentioned in the application, the same (I.A.
No.592/2017) is allowed. The delay in filing this application is hereby
condoned.
This application has been filed for restoration of Contempt Petition
No.1073/2016 which has been dismissed for non-compliance of common
conditional orders dated 23.08.2016. The application is supported by an
affidavit of Advocate-Rajesh Dubey.
Keeping in view the reasons indicated in the application, the MCC is
allowed and it is directed that Contempt Petition No.1073/2016 be
restored to its original number and list this case before the appropriate
Bench.
Let a copy of this order be kept in the file of Contempt Petition
No.1073/2016.
(SMT. ANJULI PALO)
JUDGE
