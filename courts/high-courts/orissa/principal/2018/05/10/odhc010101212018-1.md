# High Court of Orissa, WP(C)/5201/2018, 2018-05-10

2. 10.05.2018
Prasant
Heard Mr. P.K. Jena, learned counsel for the petitioner
and Mr. Beura, learned Sr. Standing Counsel for the Revenue.
 It is submitted on behalf of the petitioner that the
petitioner was an existing dealer under VAT regime and made
necessary application to migrate to the GST regime. While
payments made by the petitioner have been accepted;
migration is yet to be completed due to certain technical
reason for which the petitioner is unable to submit its return
online.
 Learned Sr. Standing Counsel submits that he has
already discussed the matter with the Nodal Officer appointed
for the purpose.
 Accordingly, we dispose of this writ application with a
direction to the Nodal Officer to take immediate steps in this
regard so as to complete the migration process in order to
enable the petitioner to file its return online.
 Free copy of this order be handed over to the learned Sr.
Standing Counsel for the Revenue. Urgent certified copy of
this order be granted on proper application.
