O R D E R
This Criminal Original Petition has been filed to quash the
First Information Report in Cr.No.37 of 2014 on the file of the
second respondent.
2.The learned Government Advocate (Crl.side) has submitted that
already charge sheet has been filed and the case was taken on file
in C.C.No.110 of 2017 on the file of the Additional Mahila Court
(Magistrate level), Madurai.
3.The learned counsel for the petitioners has submitted that
since this Court has granted interim stay, the second respondent
should not have filed a charge sheet.
4.considering the fact that since a charge sheet has also been
filed and the case was taken on file in C.C.No.110 of 2014 on the
file of the Additional Mahila Court(Magistrate level), Madurai,
this petition is disposed of. If the petitioners feel that the
second respondent has violated the order passed by this Court, dated
08.09.2014, it is open to them to take appropriate action against
the second respondent. Consequently, connected Miscellaneous
petition is closed.
