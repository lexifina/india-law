# High Court of Madhya Pradesh, MCC/1381/2017, 2017-05-08

MCC-1381-2017
(PAPPU @ RAMESH GANGELE Vs THE STATE OF MADHYA PRADESH)
08-05-2017
Shri A.K. Rawat, learned counsel for the applicant.
This application has been filed for restoration of W.P.
No.1002/2017 which has been dismissed on 27.03.2017 for non-compliance of peremptory order dated 07.03.2017. The application
is supported by an affidavit of applicant.
Keeping in view the reasons indicated in the application, the MCC
is allowed and it is directed that W.P. No.1002/2017 be restored to
its original number and list this case before the appropriate Bench.
Let a copy of this order be kept in the file of W.P. No. 1002/2017.
(SMT. ANJULI PALO)
JUDGE
