# High Court of Madhya Pradesh, RP/179/2017, 2017-03-03

RP-179-2017
(M/S ENGINEER MAHENDRA KUMAR SAHU Vs THE STATE OF MADHYA PRADESH)
03-03-2017
Shri A.K. Singh, learned counsel for the petitioner.
Seeking correction of the cause title of a writ petition which
has been disposed of, i.e. W.P. No.18896/2016 on
22.11.2016.
This review application has been filed, if an error has
occurred in describing one of the respondent in the original
writ petition then the remedy is not for filing an application
for review of the order. The remedy is either to recall the
entire order restore the writ petition its original file or the file
a separate writ petition giving the correct description and
seek disposal of the matter afresh in accordance with law.
Learned counsel for the petitioner on the aforesaid facts
being pointed out prays permission to withdraw this
application with liberty to file a separate writ petition or a
review application as indicated by this Court.
Prayer is allowed.
Application is dismissed as withdrawn with the aforesaid
liberty.
(RAJENDRA MENON)
ACTING CHIEF JUSTICE
(SMT. ANJULI PALO)
JUDGE
