# Allahabad High Court, A482/7036/2023, 2023-02-27

Court No. - 66
Case :- APPLICATION U/S 482 No. - 7036 of 2023
Applicant :- Pankaj Kumar And 4 Others
Opposite Party :- State of U.P. and Another
Counsel for Applicant :- Shashi Kant
Counsel for Opposite Party :- G.A.
Hon'ble Rajeev Misra,J.
Heard Mr. Shashi Kant, the learned counsel for applicants and the
learned A.G.A. for State.
After some arguments, the learned counsel for applicants fairly
submits that since there are inherent mistakes in this application,
which cannot be cured by filing a supplementary affidavit or an
amendment application, therefore, present application be
dismissed as not pressed with liberty to file fresh.
Prayer made by the learned counsel for applicants is not opposed
by the learned A.G.A.
Accordingly, this application is dismissed as not pressed with
liberty to file fresh.
Certified copy of impugned order shall be returned to the learned
counsel for applicants after obtaining a photo copy of the same to
be kept on record.
Order Date :- 27.2.2023
