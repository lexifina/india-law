ORAL ORDER
3 26-09-2012 This contempt application has been filed alleging
non-compliance of the order dated 17.05.2012, which is an
interim order. Subsequently, a final order was passed by this
Court which was challenged in a letters patent appeal.
A show cause has been filed which indicates that the
order passed in the latter patent appeal has been implemented.
In the circumstances, there is no occasion for this
Court to entertain this contempt application.
This contempt application is thus dismissed.
