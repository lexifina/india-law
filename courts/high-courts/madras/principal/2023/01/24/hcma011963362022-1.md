In the main writ petition, this Court by order dated 03.08.2022
directed the petitioner to file an appeal before the Revenue Divisional
Officer concerned within a period of four weeks.
2. Within the said period of four weeks, the petitioner was not able
to file the appeal, as the counsel on record fell sick. Therefore, in order to
extent the time, as the appeal is now ready to file within a shortest
possible time to the Revenue Divisional Officer, the present application
has been filed.
3. Heard Mr.N.R.Anantha Rama Krishnan, learned counsel
appearing for the petitioners and Mr.P.Sathish, learned Additional
Government Pleader appearing for the respondents.
4. Having regard to the aforesaid, this Court is inclined to dispose
of this miscellaneous petition to the following effect:
That a week's time is granted to the petitioner from
