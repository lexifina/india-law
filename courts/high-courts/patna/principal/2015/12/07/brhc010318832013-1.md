ORAL ORDER
6 07-12-2015 Learned counsel for the petitioner seeks some time to
file an interlocutory application for amending the prayer in order
to challenge the order of the Zila Parishad contained in letter no.
814 dated 31.07.2010 requiring the petitioner to return the empty
bags.
2. This Court is of the view that such amendment
would go beyond the scope and very nature of the present writ
petition which has been filed for payment of the dues clamed to be
owing to the petitioner.
3. After some argument, learned counsel for the
petitioner seeks permission to withdraw the writ petition with

Patna High Court CWJC No.462 of 2014 (6) dt.07-12-2015
2/2
liberty to the petitioner to approach this Court afresh in a duly
constituted writ petition to challenge the aforesaid order dated
31.07.2010 and consequential order dated 12.08.2010.
4. As prayed, the writ petition is dismissed as
withdrawn with the aforesaid liberty.
B.T/-
 (Vikash Jain, J)
