O R D E R
This Court had passed an order dated 6.2.2017 in these cases,
which reads as follows:
“When Crl.M.C.Nos.7094/2015 and 7095/2015 were taken up
for consideration on 23.1.2017, the learned counsel for the
complainant was extensively heard by this Court. The learned counsel
for R-2 (complainant) had also made submissions, but had wanted a
short time to file a statement to produce certain documents and also
had requested to list these cases along with connected
Crl.M.C.No.7085/ 2015. Accordingly, all the three cases were later
taken up for consideration on 25.1.2017. This Court on 23.1.2017
had also passed order to revive prospectively the stay order. On
25.1.2017, the learned counsel appearing for the 2
nd
respondent
wanted some more time to file statement so as to produce certain
documents in relation to a bail application filed before this Court and
the interim order in Crl.M.C.No. 7085/2015 was also revived
prospectively for a short period. All the cases were adjourned to
2.2.2017. On 2.2.2017, Sri.K.R.Vinod, learned counsel appearing for
the petitioner submitted that he is relinquishing his appearance, etc.
and this Court had then made it clear that all the cases will be taken
up for final disposal on 6.2.2017 and that it is for the petitioner to
ensure that necessary arrangements may be made for any new
appearance before the next posting date and had posted these cases
to 6.2.2017. On 6.2.2017, when these cases had been taken up for
consideration, there is no appearance for the petitioner. Since these
cases were extensively heard earlier, this matter would be treated as
part-heard.
List these cases on 10.2.2017 and it is made clear that if there
is no appearance for the petitioner on that day, this Court will be
constrained to dismiss these matters for non-prosecution. The
Registry will list these cases on 10.2.2017 with a warning in the list
that it is posted for dismissal due to non prosecution.”

Crl.M.C.7094/15 etc. - : 2 :-
In pursuance to this Court's order dated 6.2.2017, the Registry
had listed these cases today (10.2.2017) with the specific warning in
the list that these cases are posted for dismissal due to non-prosecution. Today when the matter has been taken up for
consideration, today also none has appeared on behalf of the
petitioner in these cases. Therefore, it is only to be inferred that the
petitioner is no longer interested to prosecute this matter any
further. Accordingly, these Crl.M.Cs. will stand dismissed due to
non-prosecution. The 2
nd respondent will be at liberty to produce a
copy of this order before the learned Magistrate for information
about the dismissal of this matter.
