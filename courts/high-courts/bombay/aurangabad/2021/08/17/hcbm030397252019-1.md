PER COURT :-
This application is filed for quashing of the First Information Report
bearing Crime No. 383 of 2018. Learned APP submits that even at the time
of filing present application, i.e. on 2nd February, 2019 the charge-sheet has
been submitted, however, the applicants have mainly requested for quashing
of the FIR without making any reference of the charge-sheet.
2. Learned counsel for the applicants at this stage seeks leave to
withdraw this criminal application with liberty to file an application for
discharge before the trial in the pending case.
3. Leave granted.
4. The Criminal Application is dismissed as withdrawn with liberty as
prayed for.
( SHRIKANT D. KULKARNI ) ( V. K. JADHAV )
