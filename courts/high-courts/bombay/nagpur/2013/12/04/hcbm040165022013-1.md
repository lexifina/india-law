The order impugned dated 04-5-2013 passed on
the application under Order VII Rule 11(d) of the Civil
Procedure Code by the trial Court in Regular Civil Suit
No.04 of 2013 does not call for any interference.
However, it is made clear that the applicants are at
liberty to file an application under Section 9-A of the
Civil Procedure Code raising the issue of jurisdiction.
The application for grant of temporary injunction is
pending. The Court can frame an issue if it so finds and
decide the same in accordance with law. Hence, the
revision application is dismissed with liberty to file an
application under Section 9-A of the Civil Procedure
Code.
