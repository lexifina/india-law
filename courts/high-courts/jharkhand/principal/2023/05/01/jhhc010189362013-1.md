 This petition has been filed for quashing the cognizance order dated
01.03.2013 passed in Complaint Case No. 907 of 2012, pending in the court of
learned A.C.J.M, Hazaribag.
2. Status report is on record which suggests that the case record has
been transferred to Ramgarh Judgeship vide order dated 18.09.2015.
3. Learned counsels for the petitioner as well as State are not in a
position to submit about the status of the case pending before the Ramgarh
Judgeship.
4. In view of above facts, this petition is being disposed of with liberty
to the petitioner to file fresh petition if cause of action still survives.
5. Accordingly, this petition is disposed of. Pending, I.A., if any stands
disposed of. Interim order is vacated.
