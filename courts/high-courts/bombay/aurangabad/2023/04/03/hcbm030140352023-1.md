PER COURT :-
1. Admittedly, election programme has travelled at an
advance stage. Name of the petitioner was not included in the
provisional voters’ list, to which the petitioner has not raised any
objection from 15th February, 2023 to 24th February, 2023.
2. In the aforesaid background, though Mr. Thombre, learned
counsel has urged that inclusion of the name of the petitioner will
not cause any change in the election programme, we refrain
ourselves from causing interference; particularly, when
implementation of the election programme is already
commenced. Petition stands disposed off. The petitioner is at
liberty to file Election Petition, if so desired.
3. Pending Civil application stands disposed off.
