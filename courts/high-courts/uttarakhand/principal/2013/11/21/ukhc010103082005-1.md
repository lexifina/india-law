# High Court of Uttarakhand, WPMS/440/2002, 2013-11-21

CLMA No.12528 of 2013 (Delay Condonation application in
recall) &
MCC No. 737 of 2013 (Recall Application)
In
WPMS No.440 of 2002
Honíble Sudhanshu Dhulia, J.
Mr. Tapan Singh, Advocate, present for the
applicant/petitioners.
Mr. R.C. Arya, learned Standing Counsel
present for the State.
Mr. A.K. Sharma, Advocate, present for the
private respondent.
Delay condonation application is allowed.
Delay in filing recall application is condoned.
A review petition was filed for review of the
order dated 06.07.2012, by which the writ petition
was dismissed on merits. Since the learned counsel
for the petitioner was not present to press the
review application, therefore, review application was
dismissed for default vide order dated 03.10.2012.
Now another application has been filed for recall of
order dated 03.10.2012 by which review application
was dismissed for default.
In the interest of justice, application for recall
of order dated 03.10.2012 is allowed. Order dated
03.10.2012 is hereby recalled. Review application is
restored to its original number.
Review Application (MCC) No. 713 of 2012
Heard learned counsel for the parties on
review application.
There is no ground for interference, much
less that learned counsel for the petitioners has not
been able to show any error at the face of the record
which may call for interference in the order
06.07.2012. Otherwise also there is extremely
limited grounds for review of the order.
No ground for review of the order dated
06.07.2012 has been found. The review application
is hereby dismissed.
 (Sudhanshu Dhulia, J.)
