# High Court of Madhya Pradesh, RP/34/2017, 2017-01-16

R. P. No.34/2017
16.01.2017
Shri Vivek Dalal, learned counsel for the review petitioner.
Shri Peyush Jain, learned GA for the respondents – State,
on advance notice.
Heard.
Learned counsel for the review petitioner has submitted
that writ appeal filed by the State was barred by time (491 days).
The order dated 22.05.2014 passed in Revenue Case
No.4140/B-121/2012-13 has already been set aside much prior to
the date of filing of the writ appeal.
In view of the aforesaid, the review petitioner is free to
take all these objections in review application regarding
limitation and also the order of SDO, which has already been set
aside by the appellate authority, if any filed by the State in
compliance to order dated 21.11.2016.
With the aforesaid, the review petition stands disposed of.
Certified copy, as per rules.
(P. K. Jaiswal) (Virender Singh)
 Judge Judge
