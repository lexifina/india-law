This misc. application has been filed by the petitioner for
reconstitution of file of DBCWP No.651/2013.
It is noticed that file of DBCWP No.651/2013 was traced out
and listed before the Court on 24.07.2018, which already stands
dismissed as withdrawn.
In this view of the matter, the application for reconstitution
of file of DBCWP No.651/2013 has rendered redundant.
Disposed of accordingly.
