ORDER
Petitioners apprehend arrest by the keezhvaipur Police in
Crime No.1069 of 2013.
2. Learned Public Prosecutor submits that Section 326
of the Indian Penal Code having been deleted as per report
dated 13-10-2013 filed before the jurisdictional magistrate,
what remains is only Sections 447 and 324 r/w Section 34 of
the Indian Penal Code which are bailable offences.
3. I have heard the learned counsel for the petitioners
also.
4. Since as it now stands only bailable offences are
alleged, request for anticipatory bail cannot be allowed.
Petitioners can approached the Court concerned and seek
regular bail.
Application is disposed of with the above observation.
THOMAS P. JOSEPH, JUDGE
