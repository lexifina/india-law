 .Heard learned counsel appearing for the
 petitioner.
 .Having heard learned counsel for the
 petitioner, it is not in dispute that the similar
 application being Wealth Tax Application No.14 of

 2000 raising identical question has already been
 dismissed by this Court by a reasoned order. In
 this view of the matter, there is no merit in the
 these applications.
 .However, since the sole respondent in these
 applications has expired and no steps were taken to
 substitute the name of deceased respondent, we have
 no option but to dismiss these applications as
 abated. Accordingly, all these applications are
 dismissed as abated with no order as to costs.
