# High Court of Madhya Pradesh, CRR/881/2016, 2016-04-06

CRR-881-2016
(INDRABHAN GUPTA KESHRI Vs THE STATE OF MADHYA PRADESH)
06-04-2016
 Shri P.K.S. Sengar, learned counsel for the applicant.
 Shri Pankaj Dubey, learned counsel for the respondent.
 Finding justification for recalling the complaint for
asking certain questions, the complaint has been recalled by
alleging that an application filed under Section 311 of Cr.P.C.
Interalia contending that the application has been allowed
illegally, all the questions proposed to be asked have already
been asked and the application has been filed for filling up
the lacuna, this criminal revision was filed.
 We have gone through the order passed by the learned
court below and we find that no error was occurred in the
order warranting reconsideration.
 Accordingly, the application is dismissed.
(RAJENDRA MENON)
JUDGE
(SUSHIL KUMAR PALO)
JUDGE
