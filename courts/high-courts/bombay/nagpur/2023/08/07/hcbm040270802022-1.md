This is an application for grant of bail under Section
439 of the Code of Criminal Procedure.
2. After hearing the learned counsel for the applicant and
after going through the investigation papers, when this Court
shown its disinclination to grant bail, learned counsel seeks
permission to withdraw the same with liberty to file afresh if
there is no substantial progress in the trial within six months.
3. The permission is granted. The application is
dismissed as withdrawn with liberty to the applicant to file
afresh if there is no substantial progress in the trial within
one year.
