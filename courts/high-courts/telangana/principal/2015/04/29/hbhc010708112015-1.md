# High Court for the State of Telangana, WP/13204/2015, 2015-04-29

HON’BLE SRI JUSTICE VILAS V.AFZULPURKAR
W.P.No.13204 of 2015
ORDER:
Since the petitioner is a contractor for more than twenty works, the single writ
petition in this manner cannot be entertained.
Learned counsel appearing for the petitioner seeks permission of this Court to
withdraw this Writ Petition with a liberty to file separate writ petitions relating to each
contract.
Permission is accorded.
Accordingly, the Writ Petition is dismissed as withdrawn giving liberty as prayed for.
No order as to costs.
The miscellaneous petitions, if any, pending in this writ petition shall stand closed.
