IN

M/S. MARK BUILDERS REPRESENTED BY

P.C.:
 Heard learned Counsel for the applicant as well as for the respondents.
 The applicant has filed this application for stay of the execution of the
impugned decree passed by the Trial Court. The learned Counsel for the
applicant states that for the time being, he does not press this application.
 He, therefore, seeks permission to withdraw this application with liberty
to file a fresh application if the circumstances demand.
 Application disposed off accordingly.
