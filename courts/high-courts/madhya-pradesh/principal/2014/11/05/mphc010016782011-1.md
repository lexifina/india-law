# High Court of Madhya Pradesh, MCRC/334/2011, 2014-11-05

M.Cr.C.No.334 of 2011

1
Anil Kumar vs State of M.P.
05/11 / 2014
None present for the applicant.
Shri P.K. Chourasia, Panel Lawyer for the
respondent/State.
This is an application under Section 482 of the Code
of Criminal Procedure being aggrieved by the order dated
26/05 /2010 passed by learned First Additional Sessions
Judge, Chhindwara in S.T.No.198/08 dismissing the
application under Section 311 of Cr.P.C. filed by the
applicant for recalling of the witnesses.
Order under challenge was passed on 26/5 /2010
and there is no stay granted by this Court.
This application is of the year 2011. Since none is
present on behalf of the applicant, it seems that with the
passage of time, the applicant has lost interest in
prosecuting the case. Hence, this application is hereby
dismissed for want of prosecution.
However, the applicant is extended a liberty to file
appropriate application for recalling of this order on
admissible grounds.
 (SUBHASH KAKADE)
 JUDGE
