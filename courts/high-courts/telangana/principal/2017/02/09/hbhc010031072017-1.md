# High Court for the State of Telangana, WP/4576/2017, 2017-02-09

THE HON'BLE SRI JUSTICE A.RAMALINGESWARA RAO
WRIT PETITION No.4576 of 2017
ORDER:
 This Writ Petition is filed seeking release of the Auto
Rickshaw bearing No.TS 05 UA 5262 with Chassis Number
MBX0002GFSF915053, which was produced in C.C.No.985 of
2016 before the learned Judicial First Class Magistrate,
Huzurnagar.
 Since there is a provision in the Code of Criminal
Procedure and the relevant Acts seeking release of the vehicle,
which was involved in any offence, the petitioner is given liberty
to file appropriate application before the competent
Court/authority seeking release of the vehicle.
 The Writ Petition is, accordingly, closed. The
miscellaneous petitions pending in this Writ Petition, if any,
shall also stand closed. There shall be no order as to costs.

 (A.RAMALINGESWARA RAO, J)
