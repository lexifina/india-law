# High Court of Madhya Pradesh, SA/1031/2009, 2015-03-25

SA-1031-2009
( THE STATE OF MADHYA PRADESH Vs MST.LEELAWATI DEVI (D) RAJENDRA
BAHADUR SINGH)
25-03-2015
Shri Ashish Anand Bernard, learned Govt. Advocate for appellant State.
Shri M.K. Saraf, learned counsel for respondent.
Learned counsel for the appellant prays for withdrawal of appeal with liberty to
file an application for setting aside abatement in the Civil Appeal which was
dismissed, by impugned order, as abated.
Prayer allowed.
Petition stands dismissed as withdrawn with the said liberty.
Let the certified copy of order dated 10.3.2004 be returned to the appellant on
appellant furnishing a true copy thereof.
