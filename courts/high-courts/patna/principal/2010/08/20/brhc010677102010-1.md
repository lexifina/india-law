02 20.08.2010 The petitioner was not selected for the post of Primary
Panchayat Teacher instead some others were selected. The Block
Development Officer set aside the order of the selection, which
order was set aside by the Tribunal.
Petitioner challenges both the orders i.e. the Block
Development Officer and the Tribunal. In my view, petitioner not
having been selected should have raised a grievance independently

- 2 -
in the year 2007 itself, which he did not do. This Court would not
exercise its discretion at this late stage.
The writ application is dismissed.
Trivedi (Navaniti Prasad Singh, J.)
