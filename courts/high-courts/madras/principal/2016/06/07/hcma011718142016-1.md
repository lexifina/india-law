 ORDER
This Criminal Original Petition has been filed praying to
quash the case in Crime No.358 of 2014 on the file of the
first respondent-Police.
2. Heard the learned counsel for the petitioner and the
learned Additional Public Prosecutor appearing for the first
respondent.
3. When this court was about to dismiss this petition on
merits, the learned counsel for the petitioner sought
permission to withdraw this petition, with liberty to raise
all the points during trial.
https://hcservices.ecourts.gov.in/hcservices/

4. In view of the above, this Criminal Original Petition
is dismissed as withdrawn to raise all the points during
trial. Consequently, connected miscellaneous petition is
closed.
