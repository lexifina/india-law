# Allahabad High Court, A482/42059/2022, 2023-02-02

Court No. - 72
Case :- APPLICATION U/S 482 No. - 42059 of 2022
Applicant :- Vijay Yadav
Opposite Party :- State of U.P. and Another
Counsel for Applicant :- Sushil Kumar Pal,Sanjay Pandey
Counsel for Opposite Party :- G.A.
Hon'ble Umesh Chandra Sharma,J.
Heard learned counsel for the applicant as well as learned AGA for
the State and perused the record.
Learned counsel for the applicant concedes that the impugned
order is revisable and it cannot be challenged under Section 482
Cr.P.C. He wants withdrawal of the application with liberty to file
revision.
Accordingly, this application is dismissed as withdrawn with
liberty to file a revision.
It is directed to return the certified copy of the impugned order and
after retaining a xerox copy of the same.
Order Date :- 2.2.2023
