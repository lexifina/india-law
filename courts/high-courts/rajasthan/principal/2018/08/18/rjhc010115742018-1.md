 State of Rajasthan & Ors.
----Respondents
For Petitioner(s) : Mr. Birbal Ram, petitioner in person.
HON'BLE MR. JUSTICE SANDEEP MEHTA
Order
18/08/2018
The original file of S.B. Civil Writ Petition No.5133/2014 has
reportedly gone missing. The Dy. Registrar (Judicial) issued a
search slip whereon a report dated 17.11.2017 is made that the
file could not be traced out.
In these circumstances, the instant application moved by
learned counsel Shri V.K. Agarwal for reconstitution of the file is
accepted. Paper book which has been filed alongwith the
reconstitution application is taken on record and the file is directed
to be reconstituted on the basis thereof. Office to proceed.
(SANDEEP MEHTA),J
Tikam/18
