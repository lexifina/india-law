# Allahabad High Court, /1060/2023, 2023-05-02

Court No. - 7
Case :- CONTEMPT APPLICATION (CIVIL) No. - 1060 of 2023
Applicant :- Rajendra Kumar
Opposite Party :- Smt. Savita Yadav, Sub Divisional Magistratae, Tehsil
Musafirkhana, Amethi
Counsel for Applicant :- Tulsi Ram Yadav,Shiv Prasad Chaurasia
Hon'ble Abdul Moin,J.
Supplementary affidavit filed today by learned counsel for the
applicant is taken on record.
Heard.
It is contended that the undertaking which was required to be
given by the Writ Court has only been given on 26.04.2023.
Considering that the Writ Court had required the matter to be
decided within six months and the undertaking has only been
given on 26.04.2023, as such it is apparent that the contempt
application is premature.
Accordingly, the contempt application is rejected at this stage
with liberty to the applicant to file fresh in case any cause of
action subsists.
Order Date :- 2.5.2023
