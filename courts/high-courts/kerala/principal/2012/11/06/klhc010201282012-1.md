 O R D E R
An order refusing to set aside the exparte decree is under
challenge in this Civil Revision Petition. The Civil Revision
Petition even if allowed does not finally terminate the
proceedings. The suit only gets resurrected if the exparte decree
is set aside. Therefore the remedy of the petitioners is to file an
original petition only.
The Civil Revision Petition is dismissed without prejudice to
the right of the petitioners to file an original petition.
 V.CHITAMBARESH.
