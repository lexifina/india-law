ORAL ORDER
2 14-08-2018 Heard the learned counsel for the petitioner.
The petitioner has filed this Civil Misc. petition
against the order dated 23.06.2018 by which the petition of the
respondents filed under Order 21 Rule 97 has been allowed.
In view of the provisions as contained in Order 21
Rule 103 of the Code of Civil Procedure, the order impugned is
appealable.
The learned counsel for the petitioner seeks
permission to convert this Civil Misc. petition into Misc. Appeal
under Order 21 Rule 103 of the Code of Civil Procedure within
ten days.
