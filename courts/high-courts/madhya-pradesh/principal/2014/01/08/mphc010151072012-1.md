# High Court of Madhya Pradesh, MCC/488/2012, 2014-01-08

1
MCC No.488/2012
8/1/2014.
None appears for the applicant.
This application has been filed restoration
of F.A. No.617/2010 which has been dismissed in view
of the peremptory order passed by the Court on
26.4.2011. There is a delay of 278 days in filing the
application for restoration and therefore, notices were
issued to the respondents. Inspite of service, none
appears for the respondents.
Keeping in view the reasons given in I.A.
No.5021/2012 an application for condonation of delay
supported by affidavit of appellant and finding the
same to be bonafide, both the applications are
allowed. Condoning the delay in filing the application
for restoration, the restoration application itself is
allowed. First Appeal be restored to its original file. It
be placed for orders before the appropriate Bench.
With the aforesaid, this application stands
allowed and disposed of.
(Rajendra Menon)
 Judge
