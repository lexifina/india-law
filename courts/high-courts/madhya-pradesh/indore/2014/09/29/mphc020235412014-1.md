# High Court of Madhya Pradesh, MCC/659/2014, 2014-09-29

1
Miscellaneous Civil Case No.659/2014
29.09.2014
Shir V.P. Khare, learned counsel for the applicant.
Heard.
By filing this miscellaneous civil case, the applicant is
seeking return of the documents and certified copy of the
impugned order 04.08.2014 filed in Miscellaneous Civil Case
No.107/2014.
On applicant's furnishing attested true copy of the same, the
documents and the certified copy of the impugned order be
supplied to the applicant.
With the aforesaid, this miscellaneous civil case stands
disposed of.
 (Shantanu Kemkar) (Jarat Kumar Jain)

Pithawe RC
