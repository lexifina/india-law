ORDER: (per Hon’ble the Chief Justice Sri Kalyan Jyoti Sengupta )
In this Writ petition, there is no ground to challenge the
impugned rule. Therefore, the learned Counsel for the petitioners
wants to withdraw this writ petition with liberty to file a fresh writ
petition with appropriate ground.
Accordingly, Writ petition is dismissed as being withdrawn
with liberty to the petitioners to file a fresh writ petition with proper
ground. However, this shall be done within a period of fortnight
from today, failing which the issue would be closed chapter. No
order as to costs.
Miscellaneous Petitions, if any, pending in this writ petition
are closed. There is no order as to costs.
