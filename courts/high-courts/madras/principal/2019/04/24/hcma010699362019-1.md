ORDER
The above Civil Revision Petition is filed for a direction as against the
return made by the learned Additional Subordinate Judge, Myladuthurai, which
was stated as returned on 14.03.2019, but the same was actually returned on
21.03.2019, as per the instructions given to the learned Senior Counsel
Mr.M.Subbiah. Be that as it may.
http://www.judis.nic.in

3
2. It is seen that the return does not specify the number of days within
which the return has to be done. Thus, the revision petitioner shall represent the
above return on or before 29.04.2019
3. The original petition in E.A. SR No.3112 of 2019 Is returned to the
learned counsel for the petitioner and necessary endorsement was obtained to
that effect.
 4. On re-presentation of the papers, the learned Additional
Subordinate Judge, Myladuthurai,shall take up the matter on the very same
day or on latest by 30.04.2019.
 5. With the above directions, the Civil Revision Petition stands
disposed of. No costs. Consequently, connected miscellaneous petition is
closed.
