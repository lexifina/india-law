# High Court for the State of Telangana, CRP/4694/2009, 2013-02-20

THE HON’BLE SRI JUSTICE N.R.L.NAGESWARA RAO
C.R.P.NO.4694 OF 2009
ORDER:-
Heard the learned counsel for the revision petitioners. It is
represented that the Execution Petition, which was filed in the
suit, is no longer pending as it was returned and not presented.
Therefore, the order of the court below to treat the application as
a caveat also does not survive for consideration. Even
otherwise, the petitioners have got every right under Order XXI,
Rule 97 CPC to file an application about the rights in the
property even before actual dispossession.
In view of the above circumstances, while granting liberty to
the petitioners to file an application under Order XXI, Rule 97
CPC, the Civil Revision Petition is dismissed as infructuous. No
costs.
