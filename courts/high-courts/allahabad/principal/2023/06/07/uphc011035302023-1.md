1. Heard learned counsel for the petitioner, learned A.G.A. for the
State and perused the record.
2. Learned counsel for the petitioner submits that instant petition
may be dismissed as withdrawn with liberty to file an application
for anticipatory bail.
3. Accordingly, the petition is dismissed as withdrawn with
aforesaid liberty.
4. Needless to state that in case petitioner moves an application for
anticipatory bail, the same shall be dealt with expeditiously in
accordance with settled law.
