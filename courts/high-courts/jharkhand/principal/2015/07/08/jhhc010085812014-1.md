I.A. No.558 of 2015
6/30.01.2015 This interlocutory application has been filed for grant of one month's
time for filing counter affidavit.
On the last occasion i.e. on 23.1.2015 the respondents have been
directed to file counter affidavit and the case was directed to be listed
today.
As has been informed by learned counsel for the respondents that they
have got instruction but it is to be filed by way of affidavit along with
certain documents.
Since the matter pertains to appointment and as has been submitted
by learned counsel for the petitioner that the appointment letter was
to be issued on 26th January, 2015, so the respondents were directed to
file affidavit vide order dated 23.1.2015, but no affidavit has been filed.
Hence, the respondents are directed to file counter affidavit within two
weeks.
Post the writ petition on 18th February, 2015.
I.A. No. 558 of 2015 stands disposed of.
In the meanwhile, counsel for the respondents is also directed to
file response to the I.A. being I.A. No.465 of 2015.
