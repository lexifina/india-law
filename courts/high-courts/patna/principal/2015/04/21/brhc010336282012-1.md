ORAL ORDER
3 21-04-2015 In my considered opinion, this application under
section 482 of the Code of Criminal Procedure for quashing the order dated
31.10.2012 passed by the learned Sessions Judge, Bhojpur, Ara in A.B.P. No.
602 of 2012 is misconceived. By the aforesaid order the application for
anticipatory bail of the petitioner was rejected by the learned Sessions Judge.
Against the aforesaid order an application under section 438 of the Code of
Criminal Procedure would be maintainable before this Court.
In that view of the matter, this application filed under
section 482 Cr.P.C. is dismissed as not maintainable. However, this order
will not preclude the petitioner from filing another application for grant of
anticipatory bail before this Court in the same subject matter.
