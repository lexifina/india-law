PRAYER: This application is filed under Order XIV Rule 8 of O.S.Rules read
with Section 5 of Limitation Act, 1963, praying to condone the delay of 406
days in filing the application to set aside the order dated 10/11/2023 in
C.S.No.122 of 2019 which was dismissed for non-prosecution and restore the
suit on the file of this Court.
For Applicants: Mr.Darshit B Jain
For Respondents: No appearance
ORDER
This application has been filed praying to condone the delay of 406 days
in filing the application to set aside the order dated 10/11/2023 passed in
C.S.No.122 of 2019 which was dismissed for non-prosecution and restore the
suit on the file of this Court.
2. Heard the learned counsel for the applicants and perused the materials
available on record. Despite service of notice and the learned Counsel had
entered appearance on behalf of the respondents, today, when the matter is
taken up for hearing, there is no representation for the respondents.
3.Considering the reasons stated in the affidavit filed in support of this
application, this application is allowed.
