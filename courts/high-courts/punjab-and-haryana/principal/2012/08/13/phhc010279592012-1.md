SABINA, J.
Petitioner has filed this petition under Section 482
of the Code of Criminal Procedure, 1973 for quashing of the
order dated 23.11.2002 (Annexure P-1) in complaint No. 386
dated 11.9.2000 titled as 'Gurmeet Singh vs. Gurdev Singh and
others'.
Learned counsel for the petitioner has submitted that
the complaint has been dismissed as withdrawn on 8.2.2011. In
these circumstances, the impugned order dated 23.11.2002
(Annexure P-1) whereby the petitioner had been declared
proclaimed offender was liable to be set aside.
Learned counsel for respondent No.2 has admitted
the factum that the complaint in question was dismissed as
withdrawn on 8.2.2011.
Since the complaint in question has been got

Crl. Misc. No. M-19386 of 2012 (O&M) -2 -
dismissed as withdrawn, the order whereby the petitioner was
declared a proclaimed offender is liable to be set aside.
Accordingly, this petition is allowed. The impugned order dated
23.11.2002 (Annexure P-1) is set aside.
