# Patna High Court, MJC/176/2009, 2011-06-21

IN THE HIGH COURT OF JUDICATURE AT PATNA
 MJC No.176 of 2009
 MADAN MOHAN PRASAD
 Versus
 THE STATE OF BIHAR & ORS.
 -----------
4. 21.6.2011 Heard learned counsel for the petitioner and the State.
A show cause has been filed on behalf of the State stating
therein that the order of this Court has been complied with and
necessary order has been passed, as contained in Annexure C.
Learned counsel for the petitioner submits that since the
order (Annexure C) is not correct, the petitioner proposes to assail
the same in an appropriate proceeding.
Be that as it may, since the order of this Court has been
complied with, the contempt application need not proceed further.
The same stands disposed of.
 PNM (Shailesh Kumar Sinha, J.)
