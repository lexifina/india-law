CORAM: HONOURABLE MR. JUSTICE SUDHIR SINGH
ORAL ORDER
4 04-07-2017 Learned counsel for the petitioners seeks permission to
withdraw the aforesaid two writ applications with a liberty to
prefer an appeal before the State Appellate Authority which has
been constituted vide Notification No. 7/B 3-80/2011-513 dated
13.05.2015, challenging the Memo No. 625 dated 23.10.2010
passed in Case No. 49/2010 by the Member, District Teachers’
Employment Appellate Authority, Patna.
 Permission is accorded.
 The petitioners shall file an appeal before the State
Appellate Authority within a period of thirty days from the date of
the order which should be disposed of in accordance with law
within the statutory period.
 The petitioners will be at liberty to file a separate
application before the State Appellate Authority, if so advised, for
any interim relief.
 With the aforesaid observation and direction, the
present writ applications stand disposed of.
U.K./-
(Sudhir Singh, J)
