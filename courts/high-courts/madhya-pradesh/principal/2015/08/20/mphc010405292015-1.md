# High Court of Madhya Pradesh, MCC/2413/2015, 2015-08-20

MCC-2413-2015
(SHANTI BAI Vs POORANLAL)
20-08-2015
Shri S.K.Mishra, learned counsel for the applicants.
This application has been filed for restoration of Writ Petition
No.12058/2014, which was dismissed for non compliance of the
common conditional order dated 19/08/2014. There being some
delay in filing the application for restoration, therefore, I.A.
No.10558/2015 has been filed seeking condonation of delay. Both
the applications are supported by an affidavit and there is no
reason to disbelieve the same. Finding the same to be bona fide,
both the applications are allowed.
Condoning the delay in filing the application, restoration
application is itself allowed.
Writ Petition No.12058/2014 is restored to its original
number.
After restoration, Writ Petition No.12058/2014 be placed for
orders before appropriate Bench in the next week.
Application stands allowed and disposed of.
Certified copy as per rules.
(VANDANA KASREKAR)
JUDGE
