# High Court of Madhya Pradesh, RP/395/2017, 2017-07-21

RP-395-2017
(AJAY SHARMA Vs THE STATE OF MADHYA PRADESH)
21-07-2017
Shri Anil Sharma, learned counsel for petitioner.
Shri Vivek Mishra, learned Panel Lawyer for respondent-State.
Heard.
Learned counsel for the petitioner submits that there is
typographical error in the order dated 03.07.2017 as at the top of
the order, the writ petition number is mentioned as WP
No.9417/2017, whereas it is to be read as 9417/2012. Similarly,
in second para, instead of the year 2013, the year 2010 is to be
substituted. Such prayer is not opposed by Shri Vivek Mishra,
learned Panel Lawyer for respondent-State. Therefore, this
review petition is allowed. It is directed that at the top of the
order instead of WP No.9417/2017, it will be read as WP
No.9417/2012 and in second para of the order, instead of the year
2013, it will be read as year 2010.
Let a copy of this order be kept in WP No.9417/2012 (S) so
as to read cojointly with order dated 03.07.2017.
(VIVEK AGARWAL)
JUDGE
