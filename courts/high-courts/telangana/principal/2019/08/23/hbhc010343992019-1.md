# High Court for the State of Telangana, WP/18355/2019, 2019-08-23

HONOURABLE SRI JUSTICE CHALLA KODANDA RAM
WRIT PETITION No.18355 of 2019
ORDER:
This writ petition is filed seeking implementation of the order
dated 13.11.2017 in W.P.No.37980 of 2017. Since the grievance of
the petitioner was already addressed by this Court while passing
the order dated 13.11.2017, the petitioner is entitled to file a
Contempt Case for non-implementation thereof, but not a fresh
writ petition.
In those circumstances, leaving it open to the petitioner to
file a contempt case against the respondents concerned for not
implementing the order of this Court dated 13.11.2017, which is a
serious issue, this Writ Petition is closed. No costs.
Miscellaneous petitions, if any, shall stand closed.
_____________________________
CHALLA KODANDA RAM, J
