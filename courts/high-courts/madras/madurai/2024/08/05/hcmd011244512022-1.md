ORDER
The Criminal Original Petition is filed to quash the First
Information Report in Crime No.1924 of 2019, dated 25.10.2019 on the
file of the first respondent, in sofar as the petitioner/A3 is concerned.
2.Today, when the matter came up for hearing, the learned
Additional Public Prosecutor submitted that already a charge has been filed
and the same has been taken on file in C.C.No.921 of 2024 on the file of
the learned Judicial Magistrate No.I, Madurai.
3.In view thereof, nothing further survives to be adjudicated in
this petition and as such, this Criminal Original Petition is dismissed as
having infructuous. Consequently, connected miscellaneous petition is
closed.
