 JUDGMENT
The contempt case is filed complaining of non-compliance with
the directions issued by this Court in WP(C) No.29615/2022. It is
submitted that though this Court had directed to trace out the
concerned files and if not possible to reconstruct the file and to issue
duplicate pattas, the same have not been done so far.
2. Pending the contempt case, the petitioner has by
abundant caution submitted application for issuance of a Nijasthithi
Certificate, which can serve the same purpose as a duplicate patta,
in case it is not possible to recreate the patta. It is submitted that
he had preferred such an application as early as in 2023, but
nothing has happened on that application. A fresh application has
been filed on 26.03.2025, copy of which has been produced as
Annexure VI.
In the above circumstances, there will be a direction to the
respondents to consider and pass orders on the application dated
