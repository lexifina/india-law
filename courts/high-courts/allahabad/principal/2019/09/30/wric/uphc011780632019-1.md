# Allahabad High Court, WRIC/31235/2019, 2019-09-30

Court No. - 49
Case :- WRIT - C No. - 31235 of 2019
Petitioner :- Mohd. Ashraf Ansari
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Kailash Prasad Pandey,Rajesh
Pandey
Counsel for Respondent :- C.S.C.
Hon'ble Siddhartha Varma,J.
This writ petition has been filed against the order dated
17.01.2018 passed by the Additional Collector (Finance /
Revenue) Pilibhit.
Learned Standing Counsel submits that if the petitioner's
grievance was that he was not heard then he may file a recall
application.
Under such circumstances, the petitioner may file a recall
application, if he so advised.
With these observations, the writ petition is, accordingly,
dismissed.
Order Date :- 30.9.2019
