ORAL ORDER
2 03-08-2016 The learned counsel, Mr. Ambika Bhagat, for the petitioner
seeks permission to withdraw this Civil Misc. application with
liberty to file appeal as the order rejecting the injunction
application is appealable and the petitioner has filed this
application challenging the order dated 10.02.2015 passed by
Munsif IIIrd Chapra in partition suit No.97 of 2012.
In view of the aforesaid submission, the petitioner is
permitted to withdraw this Civil Misc. application with liberty to
file Misc. Appeal before appropriate Forum.
Accordingly, this Civil Misc. application is dismissed as
withdrawn with aforesaid liberty.
