Prayer: Petition filed under Section 482 of the Code of Criminal

Crime No.167 of 2010 dated 07.08.2010 on the file of the respondent police
and to file a final report within a stipulated time.
For Petitioner : Mr.K.Gokul
 For Respondent : Mr.S.P.Maharajan
Govt. Advocate (Crl.Side)
ORDER
This petition has been filed to direct the the second respondent to
file a charge sheet in the FIR in Crime No.167 of 2010 dated 07.08.2010 on
the file of the respondent police and to file a final report within a
stipulated time.
2. Heard both sides.
3.At the request of the learned Government Advocate (Criminal Side)
the respondent police is directed to investigate the case in Crime No.167
of 2010 on the file of the respondent and file a final report within a
period of eight weeks from the date of receipt of a copy of this order.
4. With the above direction, this petition is disposed of.
