# Allahabad High Court, /144/2023, 2023-01-27

Court No. - 6
Case :- CONTEMPT APPLICATION (CIVIL) No. - 144 of 2023
Applicant :- Nagendra Narayan Mishra
Opposite Party :- Himanshu Kumar, Prin. Secy. Deptt. Of Rural
Development Anubhag-1, Lko.
Counsel for Applicant :- Dinesh Kumar Ojha
Hon'ble Rajnish Kumar,J.
This Court had passed the following order on
20.01.2023:-
"This application has been filed alleging non compliance of the order dated
12.12.2022 passed in Writ-A No.8333 of 2022.
Submission of learned counsel for the applicant is that the order dated
29.11.2022 has been stayed by the writ court but the same has not been
complied with despite sufficient service.
Perusal of the order dated 12.12.2022 bearing no.1144/38-1-2022-537/2022 has
been stayed whereas the applicant has filed the order which is said to be stayed
is numbered as 1141/38-1-2022-537/2022.
In view of above, learned counsel for the applicant prays for adjournment to
enable him to get the order corrected from the writ court.
As prayed, list in the next week."
Learned counsel for the applicant submits that he
has moved an application for correction. However,
once an order is corrected that would require to be
served and in case of non-compliance, the
applicant may file fresh contempt application.
With the aforesaid, the application is dismissed.
Order Date :- 27.1.2023
Akanksha
