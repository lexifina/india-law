ORDER
This Criminal Original Petition is filed to quash the First
Information Report in Crime No.14 of 2023 pending on the file of
the first respondent police.
2.The learned Additional Public Prosecutor submits that in
this case, investigation has been concluded, the final report has been
filed before the learned Judicial Magistrate, Pattukottai and the same
has been taken on file in C.C.No.183 of 2024.
3.Recording the same, this Criminal Original Petition is
dismissed with liberty to the petitioner to challenge the final report,
if he is having any grounds. Consequently, connected miscellaneous
petition is closed.
