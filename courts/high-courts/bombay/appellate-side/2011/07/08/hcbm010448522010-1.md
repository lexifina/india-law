 .........
CORAM : R.Y.GANOO, J.
 DATE : 8th JULY, 2011.
P.C. :
1. After some arguments, learned Counsel for the petitioners states
that if both the cases are taken up by the same Judge that would be
convenient. She further submitted that both the cases be kept on only
one day so that the parties can attend to the matter. She submitted
that if the order is passed in the aforesaid term, she would like to
withdraw the petition.
2. At the request of learned advocate for the petitioners, petition is
allowed to be withdrawn.

: 2 : wp-3521-10=.doc
3. So far as trying both these cases by one Judge, the Court is
informed that both the cases are pending before the learned
Magistrate, C.R. No.3. To that extent, there is no need to pass any
specific order. So far as keeping both these cases on one day it would
not be proper to this Court to pass any directions in that behalf. It
would be proper if the petitioners make an application before the
learned Magistrate, C.R. No.3 for keeping both these cases on one given
day. I am sure that learned Magistrate will consider that application in
the proper perspective and pass appropriate orders.
4. Learned Counsel for the respondent submitted that in the fact
and circumstances of the case, the learned Magistrate, C.R. No.3 be
directed to take up these cases expeditiously. It is not possible for this
Court to pass such order particularly because this Court is not aware of
the pendency before the learned Magistrate, C.R. No.3. Request is
rejected.
5. Petition stands disposed of in the above terms.
(R.Y.GANOO, J.)
