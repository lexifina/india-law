# Madras High Court, A/2067/2022, 2022-07-05

A.No.2067 of 2022
in C.S.No.7 of 2022
KRISHNAN RAMASAMY.J.,
This Application is filed to set aside the ex parte order dated
13.04.2022 against the defendant No.6 and defendant No.7, the Applicants
herein and take the Written Statements on file in C.S.No.7 of 2022.
2. The learned counsel appearing for the applicants would submit that
time to file written statement was given till 05.05.202, but in the meantime,
the applicants were set ex parte on 13.04.2022. Therefore, the learned
counsel for the applicants would urge this Court to set aside the exparte
order passed against the applicants.
3. The learned counsel appearing for the respondents has also not
raised any objections to this application.
4. This Court is satisfied with the reasons stated in the affidavit filed
in support of the Application and the written statement is taken on record.
Accordingly, this Application stands allowed.
