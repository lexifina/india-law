ORDER

Learned Public Prosecutor, on instructions, submits that
final report has been filed on 25.3.2019. The prosecution
does not have an allegation that the vehicles sought to be
released were used for the purpose of committing the crime.
As such, there is no impediment in releasing the vehicles to
the respective petitioners. Consequently, Annexuer-B order
is set side. The Judicial First Class Magistrate Court,
Kunnakulam is directed to release the vehicles to the
petitioners, if the petitioners comply with the requisite legal
formalities.
