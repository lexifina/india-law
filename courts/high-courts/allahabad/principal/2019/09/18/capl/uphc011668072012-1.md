# Allahabad High Court, CAPL/3746/2012, 2019-09-18

Court No. - 50
Case :- CONTEMPT APPLICATION (CIVIL) No. - 3746 of
2012
Applicant :- Ram Shanker Tiwari
Opposite Party :- Ramagya Kumar Dios
Counsel for Applicant :- Rajesh Nath Tripathi
Counsel for Opposite Party :- S.C.,SC
Hon'ble Ashok Kumar,J.
Heard learned counsel for the applicant and learned Standing
Counsel.
Admittedly, this contempt application has been filed and is
based to the judgment dated 27.09.2011, passed in Writ - A No.
50423 of 1999.
It is not disputed that a review application has been filed by the
State / learned Standing Counsel which is still pending and yet
to be decided by the Court.
In view of the aforesaid, this contempt application is dismissed
with liberty to the applicant to file the fresh contempt
application in case the review application filed by the state is
dismissed by the Court.
Order Date :- 18.9.2019
SK Srivastava
