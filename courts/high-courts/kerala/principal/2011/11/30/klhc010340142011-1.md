JUDGMENT
1
st judgment debtor in E.P.No.537 of 2005 in T.S.C.O.S.1177 of 2004 of
the court of learned Principal Sub Judge, Irinjalakuda is the petitioner,
challenging Ext.P4, order dismissing E.A.No.1419 of 2009 for default on
31.05.2010. E.A.No.1419 of 2009 is an application filed under Rule 90 of Order
XXI of the Code of Civil Procedure (for short, “the Code”) to set aside the sale
held on 08.09.2009. E.A.No.1419 of 2009 was dismissed for default on
31.05.2010. As per Rule 106(1) of Order XXI of the Code time available to the
petitioner to seek to set aside the dismissal is 30 days from the date of the
order. No such application was preferred before the executing court. Instead,
this Original Petition is filed on 22.11.2011, much after the time prescribed under
Rule 106(1) of Order XXI of the Code has run out. In such situation, this Court
should not interfere under Article 227 of the Constitution and grant a relief which
is prohibited by the Code which would only mean circumventing provisions of the
Code. In that view of the matter this Original Petition cannot be sustained.
Original Petition is dismissed.
THOMAS P.JOSEPH,
 Judge.
