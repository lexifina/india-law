# Allahabad High Court, A482/21473/2018, 2018-07-16

Court No. - 44
Case :- APPLICATION U/S 482 No. - 21473 of 2018
Applicant :- Ritu Singh And 3 Others
Opposite Party :- State Of U.P. And Another
Counsel for Applicant :- Ashutosh Prasad Shukla
Counsel for Opposite Party :- G.A.
Hon'ble Rajeev Misra,J.
Heard Mr. Ashutosh Prasad Shukla, learned counsel for the
applicants and the learned A.G.A. for the State.
After some arguments, learned counsel for the applicants
submits there are certain inherent mistakes in this application
and therefore, in the interest of justice, this application may be
dismissed as withdrawn with liberty to file a fresh petition.
The prayer made for is bonafide. Accordingly, the same is
allowed.
The application is dismissed as withdrawn with the aforesaid
liberty.
Certified copy of the impugned order be returned to the learned
counsel for the applicants after obtaining a photostat copy of the
same to be kept on record.
Order Date :- 16.7.2018
