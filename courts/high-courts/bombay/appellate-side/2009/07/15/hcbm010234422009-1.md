 R. G. KETKAR JJ.

P.C.
1. The petitioner has preferred this Application through the Jail. His
case is that while convicting him learned Judge has not given him
benefit of set off as provided under Section 428 of the Code of
Criminal Procedure. Operative part of the impugned judgment shows
that learned Sessions Judge has given a specific direction that all the
accused are entitled for set off under Section 428 of the Code of
Criminal Procedure. The relevant sentence run as follows:
“ All these accused are entitled for set off u.s.
428 Cr.P.C. for the period undergone by them in this
offence.”

2
2. In view of this the Application does not survive and is disposed
of as such.
3. The present order be communicated to the Applicant in the Jail.
(R.G. KETKAR, J) (Smt. RANJANA DESAI, J)
