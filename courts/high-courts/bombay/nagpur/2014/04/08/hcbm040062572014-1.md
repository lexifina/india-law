 CORAM : A.B. CHAUDHARI, J.
DATE : 08th April, 2014.
This is an application for setting aside
abatement following the death of appellant no.5.
Heard learned Adv. for the applicants.
Accepting the reasons furnished in the
application to be sufficient and satisfactory,
the application is allowed and abatement is set
aside.
----
Civil Application No. 292 of 2014 :

2
By this application, the applicants
request to condone the delay in bringing on
record the legal representatives of deceased
appellant no.5.
Accepting the reasons offered in the
application explaining the delay to be
satisfactory, Civil Application is allowed and
delay is condoned.
 -----
Civil Application No. 293 of 2014 :
This is an application to bring on record
the legal heirs of deceased appellant no.5.
For the reasons stated in the
application, the application is allowed.
Civil Application No. 454 of 2005 :
This is an application for appointment of
a Receiver.
Application is disposed of.
