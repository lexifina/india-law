1. Status report stands filed.
2. Learned counsel for the petitioner submitted that as certain facts
are missing from the anticipatory bail application, he may be allowed
to withdraw the anticipatory bail application with the liberty to file an
anticipatory bail application afresh. Accordingly, the anticipatory bail
application is dismissed as withdrawn with the liberty to file an
anticipatory bail application afresh, as per law.
3. It is clarified that this Court has not expressed any opinion on
the merits of the anticipatory bail application.
