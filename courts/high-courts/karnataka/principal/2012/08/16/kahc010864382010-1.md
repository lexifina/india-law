FOLLOWING:-
ORDER
The petitioner-plaintiff filed a suit for possession.
During the pendency of the suit he filed an application I.A.3
under Order 26 Rule 9 of CPC seeking appointment of
Commissioner in respect of the suit schedule property by
making an inventory along with damages and place the said

3
report before this Court. The same was allowed with
observations that the same would have to be tried in a
separate proceedings instituted by the plaintiff wherein both
the parties would be at liberty to challenge the same as per
law. Aggrieved by the same, the present Petition is filed.
2. The learned counsel for the petitioner contends
that the trial Court should not have held that the report of
the Court Commissioner requires to be tried in a separate
proceedings and the same is unknown to law and
consequently that portion of the order requires to be set
aside.
3. The learned counsel for respondent is absent.
The trial Court while allowing the application has passed the
order to the following effect:-
“I.A.No.3 filed by the learned counsel for
the plaintiff under Order 25 Rule 9 read with

4
Section 15 Civil Procedure Code is hereby
allowed holding that the Court Commissioner is
ordered to be appointed in order to inspect the
suit schedule property regarding the alleged
damages and to report the same to the court
making it clear that after the Court
Commissioner submits his report, the same has
to be tried in a separate proceedings if instituted
by the plaintiff, wherein both the parties are at
liberty to challenge the same as per law.”
That latter part of the order wherein the trial court has
stated that after the Court Commissioner submits his report
the same has to be tried in a separate proceedings is not
justifiable. There are no reasons as to why separate
proceedings was ordered. Merely stating that the same
would have to be tried in a separate proceedings would
undoubtedly affect the legal rights of the petitioner. Under
these circumstances I’am of the considered view that the
same requires to be deleted

5
For the aforesaid reasons, the impugned order is
sustained except the extent by deleting to the following
portion of the order:-
“……making it clear that after the Court
Commissioner submits his report, the same
has to be tried in a separate proceedings if
instituted by the plaintiff, wherein both the
parties are at liberty to challenge the same as
per law.”
Hence this portion of the order would stand deleted from
the impugned order. The rest of the order sustains.
Writ Petition is disposed off accordingly.
