# High Court of Madhya Pradesh, MCC/3186/2016, 2017-01-02

MCC-3186-2016
(DAMODAR Vs THE STATE OF MADHYA PRADESH)
02-01-2017
Shri Vinod Tiwari, learned counsel for the applicant.
Shri Puneet Shroti, learned panel lawyer for the
respondent/State.
This is an application for restoration of Second Appeal
No.405/2012 which stood dismissed for want of prosecution on
07.11.2016.
Considering the avernments made in the application for
restoration which is duly supported by an affdavit, the present
application is allowed.
The Second Appeal No.405/2012 be restored to its original
number.
(VIJAY KUMAR SHUKLA)
