ORDER
Petitioner is served with Annexure-8, preliminary order dated April 29,
2011 in M.C.No.9 of 2011 purporting to be under Section 107 read with Section
111 of the Code of Criminal Procedure (for short, “the Code”). Petitioner
challenges the said order on the ground that the order does not reflect materials
on which the Sub Divisional Magistrate is said to have formed satisfaction to
issue a preliminary order. I have heard learned Public Prosecutor also.
2. Under Section 111 of the Code, the Sub Divisional Magistrate
while acting under Sections 107 to 110 of the Code if he deems it necessary to
require any person to show cause under the said provisions, he shall make an
order in writing setting forth the substance of the information received and other
matters stipulated in the provisions. Annexure-8, order does not state the
information received by the Sub Divisional Magistrate. In the circumstances, the
order cannot stand and is liable to be set aside. But I make it clear that this order
will not stand in way of the Sub Divisional Magistrate complying with Section 111
of the Code and issuing a fresh order as provided under law.

Crl.MC No.1922/2011
2
Resultantly this Criminal Miscellaneous Case is allowed. Annexure-8,
preliminary order is set aside without prejudice to the Sub Divisional Magistrate
issuing a fresh order as provided under law.
