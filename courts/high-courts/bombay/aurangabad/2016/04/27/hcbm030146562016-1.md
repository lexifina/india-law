DATED : 27th April, 2016.
ORDER :
1. The application is filed for setting aside the order
made by this Court on 4.3.2016 by which the matter was
dismissed for default for not suppling copies for serving notice
on respondents. The learned counsel for applicant has taken
blame to himself.
2. In view of the contentions made in the application
and submissions made, the application is allowed. Delay of 3
days caused in filing application is condoned. The order is set
aside. Original proceeding is restored. Copies are to be supplied
prior to 6.5.2016. If that is not done, the proceeding shall stand
dismissed automatically without back reference to the Court.
 [ T.V. NALAWADE, J. ]
