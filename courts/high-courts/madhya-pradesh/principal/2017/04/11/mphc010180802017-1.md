# High Court of Madhya Pradesh, MCC/1124/2017, 2017-04-11

MCC-1124-2017
(SHEETLA PRASAD Vs THE STATE OF MADHYA PRADESH)
11-04-2017
Shri M.P. Shukla, learned counsel for the applicant.
Shri Puneet Shroti, learned PL for the State on advance
copy.
Counsel for the applicant submits that in the original writ
petition no one was representing the private respondents.
This is an application for restoration of writ petition which
has been dismissed for want of prosecution.
Considering the averments made in para 3 of the application
which is supported by an affidavit of the counsel himself, I
find sufficient cause for restoration of the WP.
The application is allowed. W.P. No. 21316/2015 is restored
to its original number.
Let a copy of this order be placed in the aforesaid WP.
C.C as per rules.
(VIJAY KUMAR SHUKLA)
JUDGE
