# Allahabad High Court, ABAIL/4775/2020, 2023-02-03

Court No. - 77
Case :- CRIMINAL MISC ANTICIPATORY BAIL
APPLICATION U/S 438 CR.P.C. No. - 4775 of 2020
Applicant :- Chhote Lal
Opposite Party :- State of U.P.
Counsel for Applicant :- Satya Prakash Shukla
Counsel for Opposite Party :- G.A.
Hon'ble Mrs. Manju Rani Chauhan,J.
Ref:- Order on Cri. Misc. Withdrawal Application
List revised. No one has appeared on behalf of the applicant to
press this application.
Mr. Rakesh Soni, learned counsel for the State is present.
This application has been filed seeking withdrawal of this
application.
On the basis of telephonic instructions, learned AGA submits
that the applicant has already been arrested on 20.09.2020. The
aforesaid fact has been accepted by learned counsel for the
applicant in para 3 of the withdrawal application.
Accordingly, this withdrawal application is allowed.
Order on anticipatory bail application
Since the withdrawal application has been allowed, this
anticipatory bail application is, accordingly, dismissed as
withdrawn.
Interim order, if any, stands discharged.
