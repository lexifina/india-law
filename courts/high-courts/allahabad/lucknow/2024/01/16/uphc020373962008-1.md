Hon'ble Alok Mathur,J.
1. Cause list has been revised. There is request for adjournment
on behalf of petitioner.
2. Perusal of order sheet indicates that that matter was listed on
12.01.2024, on which date also there was request for
adjournment by learned counsel for the petitioner and the case
was directed to be listed today as peremptorily. Today again
request for adjournment has been made.
3. Considering the fact that the matter was listed peremptorily
for today, the request for adjournment made on behalf of
petitioner is declined.
4. Consequently, present writ petition is dismissed for want of
prosecution.
5. Interim order if any, stands discharged.
