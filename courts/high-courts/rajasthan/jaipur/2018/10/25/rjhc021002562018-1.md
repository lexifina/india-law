Judgment / Order
25/10/2018
The writ petition has been preferred for implementation of
the award passed by Labour Court which have been upheld by this
court.
Counsel for the petitioner submit that he has been moved
application u/s 29 but the same has not been further processed.
I have heard learned counsel for the petitioner.
This court finds that the application moved by the petitioner
was defective and the Additional Labour Commissioner has
conveyed to the petitioner’s counsel for filing of correct application
in the correct format by mentioning name of the person which has
not been done.

(2 of 2) [CW-23537/2018]
In view of the above, with liberty to the petitioner to file
application u/s 29 in the correct format, the writ petition is
dismissed.
(SANJEEV PRAKASH SHARMA),J
