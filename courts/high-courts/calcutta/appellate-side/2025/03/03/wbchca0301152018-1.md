# Calcutta High Court, CRR/2163/2018, 2025-03-03

03.03.2025
Court No.32
Item No.38
Sudipta
CRR 2163 of 2018
Aruna Kothari
Vs.
The State of West Bengal & Anr.
1. None appears on behalf of either of the parties. No
accommodation is sought for. This Revisional Application is
pending since 2018. Several opportunities were given to the
petitioner despite the petitioner is not interested to move the
Revisional Application on several occasions.
2. In view of the facts, it seems the petitioner is no more
interested to proceed with the case.
3. Accordingly CRR 2163 of 2018 is thus, dismissed for default.
4. Interim order, if any, shall stand vacated.
5. Let a copy of this order be communicated to the learned
Court below for information.
6. All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
(Ajay Kumar Gupta, J.)
