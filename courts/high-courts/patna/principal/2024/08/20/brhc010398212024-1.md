ORAL ORDER
2 20-08-2024 Heard learned counsel for the parties.
2. This application has been filed for quashing of
the order dated 28.02.2024 passed by learned 2nd Assistant
Session Judge, Sasaram, Rohtas by which cognizance has been
taken against the petitioners in in S.Tr. No. 227 of 2018, arising
out of Nasariganj P.S. Case No. 65/2015, for the offence 307/34
of the Indian Penal Code.
3. The petitioners have challenged the order dated
28.02.2024 by which charges have been framed. Earlier the
discharge application was filed by the petitioners which was
rejected on 04.11.2023. The order dated 04.11.2023 was
challenged before this Court in Cr. Miscellaneous No. 86118 of

Patna High Court CR. MISC. No.34552 of 2024(2) dt.20-08-2024
2/2
2023 which was permitted to be withdrawn on 01.03.2024.
Once the order rejecting the discharge application has become
final, the present application of the petitioners cannot be
entertained.
4. This application is dismissed with liberty to the
petitioners to pray for alteration of charge, if so advised.
Ranjeet/-
(Sandeep Kumar, J)
