# High Court of Madhya Pradesh, MCC/21/2017, 2017-04-26

M.C.C. No. 21/2017
26.04.2017
Shri Manish Sankhla, counsel for the petitioner.
Shri Umesh Gajankush, Dy. Advocate General
for the respondent State.
The application is for permission to file present
appeal as an indigent person in a matter arising out of claim
of compensation for acquisition of the land of the petitioner.
This Court in M.C.C. No.962/2016 has allowed
the similar application in respect of another land-owner
whose land was acquired for the same project. For the
reasons mentioned therein, we allow the application and
permit the petitioner to file the present appeal as an indigent
person.
Office to register regular First Appeal.
 ( HEMANT GUPTA ) (VED PRAKASH SHARMA)
CHIEF JUSTICE JUDGE
