# Allahabad High Court, WRIC/9562/2018, 2018-03-15

Court No. - 33
Case :- WRIT - C No. - 9562 of 2018
Petitioner :- Raj Narayan Mishra Mahavidyalaya Aror
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Shobha Tripathi,Om Subhash Tripathi
Counsel for Respondent :- C.S.C.
Hon'ble Manoj Misra,J.
The present petition seeks quashing of an order dated 30th May,
2017 passed by the Secretary, Examination Regulatory
Authority, U.P., Allahabad by which application of the
petitioner institution for affiliation to run D.El.Ed. Course with
effect from academic session 2017-2018 has been rejected on
the basis of an inspection report suggesting that the library
room is not as per the norm.
The previous application which has been rejected relates to
academic session 2017-18 which is already over therefore the
appropriate course for the petitioner is to file a fresh application
if the petitioner believes that the earlier application was
wrongly rejected on unsustainable ground.
Accordingly, without interfering with the order dated 30th May,
2017, the petition is disposed of by giving liberty to the
petitioner to apply afresh for affiliation for the ensuing
academic session 2018-19 within the time schedule provided
for such application. If any such fresh application is filed with
relevant documents to suggest that the defect earlier noticed is
either non-existent or has been rectified, then the third
respondent (Secretary, Examination Regulatory Authority, U.P.,
Allahabad) shall accord consideration to the fresh application in
accordance with law, without being prejudiced by the earlier
order and in case the third respondent is of the view that the
application requires consideration of some authority then he
shall transmit the same to that authority with his
report/comments.
Order Date :- 15.3.2018
