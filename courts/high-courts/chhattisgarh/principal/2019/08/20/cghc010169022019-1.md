1. Heard on I.A. No. 01, application for condonation of delay in filing the
application.
2. On due consideration, application is allowed and delay in filing the
application is condoned.
3. Learned counsel appearing for the applicant/ petitioner seeks permission of
this Court to withdraw this MCC application with liberty to file fresh contempt
petition.
4. I have heard learned counsel for the applicant/ petitioner.
5. The prayer is fair and reasonable.
6. Accordingly, the MCC application is dismissed as withdrawn with the
aforesaid liberty, whereas earlier dismissal will not be a bar to file fresh
contempt petition.
