O R D E R
This Criminal Original Petition has been filed to quash the
First Information Report in Crime No. 32 of 2017, dated 26.01.2017,
pending investigation on the file of the first respondent Police.
2.Today, when the matter was taken up for hearing, the
learned Additional Public Prosecutor, appearing for the first
respondent, on instructions, submitted that the investigation has
been completed and final report has already been filed before the
Judicial Magistrate Court, Valliyoor and the same has been taken on
file in C.C.No.64 of 2019.

3.In view of the above development, this Court is not

report, if so advised.
4.The Criminal Original Petition stands closed accordingly.
Consequently, the connected miscellaneous petition is closed.
