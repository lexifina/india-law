ORDER
Date : 14.6.2022
This is an application praying for correction of certain errors in order dated
23.2.2022 passed in WP(C) No. 5391/2020. The petitioner has annexed
downloaded copy of order dated 23.2.2022. The said order and the order
passed in the writ petition is having dissimilarity. In that view of the matter, this
court verified the process and it was learnt that due to some technical error, a
wrong order was uploaded relating to WP(C) No. 5502/2020 passed on the same
day. Subsequently, such technical error was corrected. Now the actual order is
available. The learned counsel for the petitioner Mr. S. Rahman has returned
back the original certified copy (incorrect copy) downloaded.
In view of the aforesaid facts no order needs to be passed correcting the
order as prayed for.
Accordingly this I.A. is disposed of.
 JUDGE
