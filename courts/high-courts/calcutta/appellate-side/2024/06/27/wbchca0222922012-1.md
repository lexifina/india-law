# Calcutta High Court, CO/1424/2012, 2024-06-27

27.06.2024
Item No.10
 BR
CO 1424 of 2012
+
IA No. CAN 2 of 2024
Chief Operating Officer, Apeejay Infra
Logistics Pvt. Ltd.
-vs-
 Ramkrishna Bhakta and others
 Mr. Manoj Malhotra,
 Mr. Partha Pratim Roy
 …. For the petitioner
 Re: CAN 2 of 2024
1. Petitioner is represented by Mr.
Partha Pratim Roy, learned counsel.
2. Affidavit of service filed by the
petitioner be kept with the record.
3. Despite service effected upon the
opposite parties there is no representation
on behalf of the opposite parties.
4. This application is filed seeking for
extention of the time to file written
objection against the application filed by
the plaintiffs under Order 39 Rule 7 of the
Civil Procedure Code before the learned
trial Court.
5. It appears from the order dated
2.4.2024 wherein the revisional application
was disposed of with giving liberty to the

petitioner to file written objection against
the application filed by the plaintiffs
under Order 39 Rule 7 of the Civil
Procedure Code within two weeks from
date.
6. It is submitted by the learned Counsel
on behalf of the petitioner that due to
some unavoidable circumstances it could
not file the said written objection within the
time frame as fixed by this Court by
passing the said order dated 02.04.2024.
7. The ground stated in the petition
appears to be satisfactory and as such time
for filing the written objection against the
application filed under Order 39 Rule 7 of
the Civil Procedure Code is hereby
extended for a further period of two weeks.
8. Liberty is hereby given to the
petitioner to file written objection against
the application filed by the plaintiffs under
Order 39 Rule 7 of the Civil Procedure Code
before the learned trial Court within two
weeks from the date of order.
9. Accordingly, CAN 2 of 2024 is hereby
allowed and disposed of.
 ( Prasenjit Biswas, J. )
