# Calcutta High Court, CRR/1919/2023, 2023-06-08

08.06.2023 IN THE HIGH COURT AT CALCUTTA
 Item No.25 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
 C.R.R. 1919 of 2023

 Aamir Khan alias Amir Khan
 versus
 Directorate of Enforcement, The Assistant
 Director, Kolkata Zonal Office-II
In Re: An Application under Section 482 read with Section
397/401 of the Code of Criminal Procedure, 1973.
Mr. Dwaipayan Banerjee,
Mr. Piyush Chowdhary,
Mr. S. M. Burhanuddin … For the Petitioner.
Learned advocate appearing for the petitioner submits
that the petitioner is not inclined to proceed with the instant
revisional application wherein he prayed for default bail
under Section 167(2) of the Code of Criminal Procedure.
Having considered such prayer, the revisional
application being CRR 1919 of 2023 is dismissed as not
pressed.
The petitioner is not granted any liberty to file afresh in
respect of the same order challenging the same before the
High Court.
Pending connected application, if any, is consequently
disposed of.
All concerned parties shall act on the server copy of
this order duly downloaded from the official website of this
Court.

Urgent photostat certified copy of this order, if applied

requisite formalities.
 (Tirthankar Ghosh, J.)
