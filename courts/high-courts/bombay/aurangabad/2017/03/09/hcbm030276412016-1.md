PER COURT :-
1 Heard learned counsel for the applicant, learned AGP for
respondent Nos.1 to 5 and learned counsel for respondent Nos. 6 & 7.
2 It is submitted by learned counsel for the applicants – original
respondents that the impugned order dated 21.4.2016 has already
been implemented before the order of stay was passed by this Court
on 7.6.2016.
3 I have gone through the copy of the corrected mutation entry
filed along with this application. It discloses that correction as per the
order dated 21.4.2016 has been carried out on 7.5.2016. The stay
order, however, was passed on 7.6.2016. This being the position, the
stay order would be insignificant and now, if any consequential interim
relief is required, the petitioner would have to file suitable application.
4 With this observation, this application is disposed of.
 ( S. B. SHUKRE, J. )
