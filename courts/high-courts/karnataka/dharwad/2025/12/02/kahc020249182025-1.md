ORAL ORDER
(PER: THE HON'BLE MR JUSTICE ANANT RAMANATH HEGDE)
This petition is filed assailing the order dated
05.11.2025 rejecting the petitioner/plaintiff's application to
recall DW1 to cross- examine DW1 further.
2. Learned counsel for DW1/respondent No.18
submits that DW1 has been cross-examined extensively and
there is no need to allow the application as all contentions
available based on the pleadings have been taken care of in
the cross-examination.
3. Learned counsel for the petitioner would submit
there are few important questions to be put to DW1 which
will demolish the case of DW1.
4. Under these circumstances, the Court is of the
view that lenient view has to be taken and the application
has to be allowed by imposing cost of ¹2,500/- payable to
DW1.
