# Calcutta High Court, CRR/2296/2012, 2021-09-28

Sr.43
 28-09-2021
 Subha.
 Court no. 34
 IN THE HIGH COURT AT CALCUTTA
 CRIMINAL REVISIONAL JURISDICTION
 APPELLATE SIDE
 ( Via Video Conference )
 CRR 2296 of 2012
 In the matter of : Sri Jagannath Chandra Adhikary ….petitioner.
In Re : An application under Section 401 read with Section
482 of the Code of Criminal Procedure.
 Md. Anwar Hossain
 Ms. Sreyashee Biswas
 …..for the State.
 The revisional application has been preferred
challenging the First Information Report registered in
connection with Sonarpur Police Station Case No. 64 dated
February 6, 2010.
 Mr. Hossain, learned advocate for the State has
submitted a report prepared by the Sub-Inspector of Police,
Sonarpur P.S., Baruipur Police District. Let the report be kept
with the record.
 Record of this revisional application reflects that the
chargesheet has already been submitted and the next date has
been fixed on 6th October, 2021 for appearance of the accused
persons.

2
 Having regard to the change of circumstances, I am
of the view that the instant revisional application has become
infructuous..
 Accordingly, the present revisional application being
CRR 2296 of 2012 is dismissed.
 All pending applications, if any, in connection with
revisional application, are consequently disposed of.
 Interim order, if any, is hereby vacated.
 All parties are to act on the server copy of this order
duly downloaded from the official website of this court.
 ( Tirthankar Ghosh, J. )
