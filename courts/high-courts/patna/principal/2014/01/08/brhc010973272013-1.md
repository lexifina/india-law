ORAL ORDER
2 08-01-2014 This application has been filed for modification of the
order dated 22.10.2013 passed in CWJC No.20602 of 2012 by
which this Court had granted liberty to the petitioner to file an
application before the concerned District & Sessions Judge
within four weeks from that date.
Learned counsel for the petitioner submits that due to
unavoidable reasons, the application could not be filed within
that time. He submits that petitioner is now ready to file an
application with the concerned District & Sessions Judge

Patna High Court MJC No.5929 of 2013 (2) dt.08-01-2014
 2/2
immediately.
In the circumstances, three weeks’ time is allowed from
today to the petitioner to file an application in terms of the said
order dated 22.10.2013 passed in the writ matter.
This modification application is disposed of.
B.T/-
(Jayanandan Singh, J)
