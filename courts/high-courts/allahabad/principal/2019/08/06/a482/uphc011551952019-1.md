# Allahabad High Court, A482/30566/2019, 2019-08-06

Court No. - 64
Case :- APPLICATION U/S 482 No. - 30566 of 2019
Applicant :- Arjun Pal
Opposite Party :- State Of U.P. And 3 Others
Counsel for Applicant :- Ramesh Kumar Mishra,Gyanendra
Kumar Mishra
Counsel for Opposite Party :- G.A.
Hon'ble Karuna Nand Bajpayee,J.
This application under Section 482 Cr.P.C. has been filed with
the prayer to direct the C.J.M., Allahabad to decide application
dated 28.2.2019 moved by the applicant under Section 156
(3)Cr.P.C. within specified period of time.
Heard learned counsel for the applicant and learned A.G.A. for
the State. Perused the record.
Only submission made by the counsel for the applicant before
the Court is that there is some application dated 28.2.2019
moved before the court below but no order has been passed on
the same so far. Therefore, some direction to get the application
decided may be issued by this Court.
This Court in the absence of complete record is not in a position
to know about the exact status and the reasons why the said
application is still pending. But in any view of the matter, if the
submission made by the counsel is correct and if there is some
application dated 28.2.2019 pending before the court below
awaiting its adjudication, it may be observed that the court
below is required to pass appropriate orders on the same as it
may deem fit in according to law.
With the aforesaid observation, this application stands disposed
off.
Order Date :- 6.8.2019
