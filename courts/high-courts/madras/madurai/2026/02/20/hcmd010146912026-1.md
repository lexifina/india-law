ORDER : The Court made the following order :-
 This petition has been filed to set aside the order
dated 30.01.2024 and restore the criminal original
petition in Crl.O.P(MD) No.357 of 2022 on the file of
this Court.
2.I have gone through the affidavit filed in support
of this petition and I am satisfied with the reasons
stated therein. Therefore, the order in Crl.O.P.(MD).No.
357 of 2022, dated 30.01.2024 is set aside and the same
is restored. This petition is accordingly ordered.
3.Registry is directed to restore the main petition
on file and the interim stay granted is also restored.
