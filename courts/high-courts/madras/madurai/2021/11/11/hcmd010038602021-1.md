ORDER
This criminal original petition has been filed for quashing the
impugned FIR in Crime No.16 of 2020 on the file of the first
respondent.
2.When the matter was taken up for hearing, the learned
Additional Public Prosecutor appearing for the first respondent
submitted that final report has been filed and it was taken on file
in C.C No.41 of 2021 on the file of the Additional Mahila Court,
Ramanathapuram. Hence, the criminal original petition is dismissed
as infructuous. The petitioner is given liberty to file a fresh O.P
on the same cause of action. Connected miscellaneous petition is
also dismissed.
