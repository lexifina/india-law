# Allahabad High Court, WRIC/5045/2017, 2019-01-16

Court No. - 39
Case :- WRIT - C No. - 5045 of 2017
Petitioner :- M/S Vijay Filling Station
Respondent :- B.P.C.L. And 2 Others
Counsel for Petitioner :- Gunjan Jadwani,Anurag Khanna
Counsel for Respondent :- S.C.
Hon'ble B. Amit Sthalekar,J.
Hon'ble Mrs. Manju Rani Chauhan,J.
Civil Misc. Withdrawal Application no. 5 of 2018 dated 17.12.2018 is
taken up.
Heard Ms. Gunjan Jadwani, learned counsel for the petitioner-applicant and Sri Vikas Budhwar, learned counsel for the
respondents.
The prayer in the application is that the writ petition may be
dismissed as withdrawn with liberty to file fresh writ petition.
However, learned counsel for the parties inform that this writ
petition was filed challenging the inspection report as well as
observation report but thereafter, a final termination order has
been passed which has been challenged through a separate writ
petition which is still pending.
In this view of the matter, the present writ petition has become
infructuous and is accordingly dismissed as having become
infructuous.
The withdrawal application is disposed of.
Interim order, if any, stands vacated.
Order Date :- 16.1.2019
Kirti
