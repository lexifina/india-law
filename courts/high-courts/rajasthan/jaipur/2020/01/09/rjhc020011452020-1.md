Order
09/01/2020
Heard on the application for correction in the order dated
10.12.2019 which was passed with consent of both the parties.
Counsel for the petitioner submitted that the number of the
criminal case pending before the learned trial Court has been
mentioned in the order dated 10.12.2019 as 402/2019 whereas
correct number of the criminal case pending before the learned
trial Court is 24/2019 (117/2012).
Counsel for the respondents has not disputed this fact.

(2 of 2) [CRLMA-4/2020]
In that view of the matter, in the last para of the order dated
10.12.2019 the number of criminal case be read as 24/2019
(117/2012) in place of 402/2019 and the order dated 10.12.2019
stands corrected accordingly and it may be treated to be part of
the order dated 10.12.2019.
Accordingly, the application stands disposed of.
