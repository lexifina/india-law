HON'BLE THE CHIEF JUSTICE
HON'BLE MR. JUSTICE DINESH CHANDRA SOMANI
Order
20/09/2017
 1. The appeal was filed with a delay of 32 days. No
application being filed for delay to be condoned the Registry
notified the defects. The same have not been cured till date. The
Registry has placed the file before the Court for appropriate
orders.

(2 of 2)
[SAW-1165/2017]
2. Overlooking the defects i.e. not filing an application
praying that delay in filing the appeal be condoned we find no
ground to interfere with the impugned order for the reason it is
based on a consent.
3. Once having given consent before the learned Single
Judge, the appellants cannot raise any issues concerning the
impugned order.
4. Dismissing the writ appeal as not maintainable because
it lays a challenge to an order passed by consent we simply
observe that if the appellants move an application before the
learned Single Judge concerning the consent recorded and want to
withdraw the same, the same shall be decided by the learned
Single Judge as per law.
(DINESH CHANDRA SOMANI),J. (PRADEEP NANDRAJOG),C.J.
