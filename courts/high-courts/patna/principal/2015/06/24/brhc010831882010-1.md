within the territorial jurisdiction of this Court, this writ application is

for the petitioner seeks permission to withdraw this writ application in
order to enable the petitioner to move before the competent
forum/court.
That being so, this writ application is accordingly permitted
to be withdrawn with the aforementioned liberty.
