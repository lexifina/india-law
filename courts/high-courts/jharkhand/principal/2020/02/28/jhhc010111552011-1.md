04/28.02.2020 This petition has been filed for the following relief:
 “For quashing the order dated 12.08.2009 passed in
Complaint Case No.807 of 2009 by Judicial Magistrate, Jamshedpur
whereby and whereunder cognizance for an offence under Section 418
of the Indian Penal Code has been taken and processes have been issued
against the petitioner and all subsequent proceeding thereto now
pending in the court of Judicial Magistrate, Jamshedpur.”
2. Learned counsel for the petitioner submits that he does
not want to press this petition.
3. Considering the submission made, this criminal
miscellaneous petition is dismissed as not pressed.
4. Interim order, if any, stands vacated.
5. Pending Interlocutory applications, if any, stand
dismissed as not pressed.
6. Let a copy of this order be communicated to the learned
court below through FAX.
