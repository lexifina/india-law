Judgment / Order
01/10/2018
Instant misc. application has been filed for correction in
order dated 24.09.2018 passed in S.B. Crl. Misc. Bail Application
No. 8742/2018, whereby, while allowing the bail application, the
petitioner was ordered to be released on bail.
Learned counsel for the petitioner submits that inadvertently
in the order dated 24.09.2018 the name of police Station has
wrongly been mentioned as “Nikumb, District Chittorgarh” instead
of “Mangalwad, District Chittorgarh”. Therefore, necessary
correction be made in the order dated 24.09.2018.
For the reasons stated in the application and in view of
submissions made, the present misc. application is allowed. It is
ordered that in the order dated 24.09.2018, the name of the
Police Station be read as “Mangalwad, District Chittorgarh” instead
of “Nikumb, District Chittorgarh”. To that extent, the order dated
24.09.2018 stands corrected.
(MANOJ KUMAR GARG),J
