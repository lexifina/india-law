# High Court of Jharkhand, Cr.M.P./150/2014, 2014-02-24

In the High Court of Jharkhand at Ranchi
Cr.M.P.No.150 of 2014
Sanjay Kakkar …........................... Petitioner
V E R S U S
State of Jharkhand …....…….Opposite Party
CORAM: HON’BLE MR. JUSTICE R.R.PRASAD
For the Petitioner: Mr. Shailesh
For the State :A.P.P
03/ 24.02.14. So far defect no.1 is concerned, it is hereby ignored.
So far defect no.2 is concerned, it be removed in
course of the day.
Learned counsel appearing for the petitioner submits
that though the order dated 03.01.2014 passed in C.P. Case
no.315 of 2013 under which cognizance of the offences
punishable under Sections 406, 420 and 120B of the Indian
Penal Code has been taken and also the order dated
03.01.2014 under which process under Section 82 of the Code of
Criminal Procedure has been ordered to be issued have been
challenged but the petitioner would be confining his prayer for
quashing of the order under which process under Section 82 of
the Code of Criminal Procedure has been issued.
Having heard leaned counsel appearing for the parties and
on perusal of the ordersheet which was produced in course of
hearing, which be placed on record, it does appear that the
process under Section 82 of the Code of Criminal Procedure has
been ordered to be issued without there being any report
relating to execution of the warrant of arrest.
In that view of the matter, the order dated 3.1.2014 never
appears to have been passed in accordance with law.
Accordingly, it is set aside.
In the result, this application stands allowed.
ND/ (R.R.Prasad, J.)
