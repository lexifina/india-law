# High Court for the State of Telangana, CRP/2875/2014, 2017-11-03

THE HON’ BLE DR. JUSTICE B.SIVA SANKARA RAO
CIVIL REVISION PETITION No.2875 OF 2014
COMMON ORDER:
As per the note put up by the Registry main case itself was
disposed of on 06.07.2017, hence, there is nothing survives in this C.R.P.
to continue.
 Accordingly, this C.R.P. is dismissed as infructuous. It is made
clear that if at all the petitioner can show that the main case is pending
and the cause in C.R.P. still survives, it can file application within one
week from today with proof for restoration.
 Miscellaneous petitions pending consideration, if any, in this case
shall stand closed in consequence. There shall be no order as to costs.
_________________________
DR.B.SIVA SANKARA RAO, J
