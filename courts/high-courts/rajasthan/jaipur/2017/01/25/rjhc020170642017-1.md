HON'BLE MR. JUSTICE M.N. BHANDARI
Judgment
25/01/2017
 This miscellaneous application has been filed for
mofidication in the order dated 29th September, 2016.
It is stated that inadvertently, in the order dated 29th
September, 2016, name of the post has been mentioned as
Teacher Gr.III Level II to Level I instead of PTI Grade III.
Accordingly, necessary correction may be permitted.
In view of the submissions made above, the application

(2 of 2)
[WMAP-22/2017]
is allowed. In the order dated 29th September, 2016, wherever
name of the post has been mentioned as Teacher Gr.III Level II to
Level I, it should be read as PTI Grade III.
This order be treated as part and parcel of the order
dated 29th September, 2016.
 (M.N. BHANDARI)J.
