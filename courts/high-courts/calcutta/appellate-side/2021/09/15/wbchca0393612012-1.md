# Calcutta High Court, CRR/2635/2012, 2021-09-15

Sr.32
 15-09-2021
 Subha.
 Court no. 34
 IN THE HIGH COURT AT CALCUTTA
 CRIMINAL REVISIONAL JURISDICTION
 APPELLATE SIDE
 ( Via Video Conference )
 CRR 2635 of 2012
 In the matter of : Tanveer Alam Ansari .. …..petitioner.
In Re : An application under Sections 401 and 482 482 of the
Code of Criminal Procedure..
 The revisional application has been preferred in
connection with M. R. Case No. 195 of 2012 dated 19-06.2012
under Section 133 of the Code of Criminal Procedure preferred
before the court learned Executive Magistrate, Coochbehar.
 Having regard to the nature of the order which has
been passed and the period of time which has expired in the
meantime, I am of the view that no interference is called for by
this court at this belated stage.
 Accordingly, the present revisional application being
CRR 2635 of 2012 is dismissed.
 All pending applications, if any, in connection with
revisional application, are consequently disposed of.
 Interim order, if any, is hereby vacated.
 All parties are to act on the server copy of this order
duly downloaded from the official website of this court.
 ( Tirthankar Ghosh, J. )
