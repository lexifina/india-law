# Calcutta High Court, CO/923/2023, 2023-05-01

01.05.2023
rc/ct.no.237
Item No.374
C.O.No. 923 of 2023
Manju Devi Paswan
Vs.
Bablu Mazumdar & Anr.
Mr. Avijit Ghosh …for the petitioner
This revisional application has been filed with a
prayer for expeditious disposal of the application under
Order 39 Rule 7 of the Code of Civil Procedure read with
Rule 151 of the Code of Civil Procedure which was filed on
February 17, 2022.
Learned advocate appearing for the petitioner
submitted that the petitioner is residing in a precarious
condition and the residential portion of the petitioner is
required to be repaired. For the reason one application
under Order 39 Rule 7 of the Code of Civil Procedure read
with Rule 151 of the Code of Civil Procedure was filed
which is pending till date.
No notice is required to be served upon the opposite
party.
Service of notice is dispensed with.
Learned Civil Judge, Junior Division, 2nd Court at
Alipore is requested to dispose of the application under
Order 39 Rule 7 of the Code of Civil Procedure read with
Rule 151 of the Code of Civil Procedure filed on February

2
17, 2023 within two weeks from the date of
communication of this order.
The petitioner is at liberty to communicate this order
to the learned Court.
With the above observations and directions this
revisional application stands disposed of.
There shall be, however, no order as to costs.
Urgent certified website copy of this order, if applied
for, be furnished to the parties upon compliance of
necessary formalities.
(Bibhas Ranjan De,J)
