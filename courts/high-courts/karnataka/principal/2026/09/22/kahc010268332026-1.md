ORAL ORDER
1. This petition is filed impugning the order dated
07.04.2026, whereby the application filed under Order XVI Rule
7A(2) of the Code of Civil Procedure, seeking to issue witness
summons by hand to witness Nos. 4 and 5 of the list of witness
dated 13.02.2026, has been rejected.
2. Learned counsel appearing for the respondents submits
that the respondents have no objection to allow defendant No.3
- petitioner herein to issue witness summons by hand to
witness Nos. 4 and 5.
3. In view of the submission made, the following:
ORDER
 i) The order dated 07.04.2026 passed in
O.S.No.48/2012 is set aside.
 ii) The application filed under Order 26 Rule 7A(2) of
the Code of Civil Procedure is hereby allowed.
 iii) The trial Court is requested to take note of the
direction issued in W.P.No.217/2023 dated 19.11.2024
