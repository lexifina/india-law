# Allahabad High Court, CAPL/151/2014, 2022-03-25

Court No. - 18
Case :- CONTEMPT APPLICATION (CIVIL) No. - 151 of
2014
Applicant :- Hari Singh
Opposite Party :- Mohan Lal
Counsel for Applicant :- Mrs. Vatsala
Counsel for Opposite Party :- S.C.,A.R.Dube
Hon'ble Prakash Padia,J.
Heard Mrs. Vstsala, learned counsel for applicant.
The applicant has preferred this contempt application for non-compliance of the order dated 24.2.2010, passed in Second
Appeal No. 249 of 2010 (Mohan Lal vs. Hari Singh).
After some arguments, a prayer has been made to dismiss the
present with liberty to file an appropriate application as
provided under Order XXXIXRule 2-A of Civil Procedure
Code, 1882.
Prayer is accepted. The present contempt application is
dismissed with liberty to the applicant to file a proper
application as provided under law, if so advised.
