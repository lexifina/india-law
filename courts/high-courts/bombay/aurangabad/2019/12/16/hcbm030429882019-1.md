PER COURT :-
1 We have heard the learned counsel for the petitioners and
Mr. Nawandar learned counsel for respondent No.3.
2 Both the petitioners No.1 and 2 applied from Project
Affected Persons category (PAP category). Petitioner No.2 was
issued with the appointment order on 20.11.2017 in Class IV
cadre. Petitioner No.2 did not join. On 29.11.2018, petitioner
No.1 filed an application stating that he is interested in the post
and petitioner No.2 is not interested. Since Petitioner No.2 did
not join the post, Petitioner No.1 claims appointment from PAP
category in class IV post.
3 It would appear that one person from a family can be
benefited being from PAP category. Petitioner No.2 was already
