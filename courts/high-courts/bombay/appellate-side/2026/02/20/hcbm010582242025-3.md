P.C. :
1. Heard learned counsel for the applicant and learned APP for
respondent -State
2. Learned counsel for the applicant submitted that the applicant
is behind bars for more than three years, yet trial is not concluded.
3. Learned APP submitted that some witnesses have been
examined and only three to four witnesses have remained to be examined.
4. Considering the submission of learned APP, learned counsel for
the applicant, on instructions, seeks leave to withdraw the application with
liberty to file fresh bail application after five months, if trial is not
concluded within five months.
5. Considering the submissions of learned counsel for the
applicant, the application is allowed to be withdrawn with aforesaid
liberty.
6. The bail application stands disposed of.
(SHIVKUMAR DIGE, J.)
