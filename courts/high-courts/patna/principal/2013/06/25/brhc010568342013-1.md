CORAM: HONOURABLE MR. JUSTICE SHIVAJI PANDEY
ORAL ORDER
2 25-06-2013 Heard learned counsel for the petitioners and learned
counsel for the State.
In this case, petitioners are challenging the order
dated 12th December 2012 passed in G.C. Case No. 49/2012 by
which the court below has taken cognizance under section 182 and
211 of the Indian Penal Code.
Counsel for the petitioners submits that another
application was filed vide Complaint Case No. 797C of 2012
(Annexure-3) which is pending before the Additional Chief
Judicial Magistrate, Barh (Patna). He further submits that as the
facts of both the cases are inter-connected relating to the same
person, it will be in the interest of justice, both the cases should be
heard together.
The petitioners, if so advised, will be at liberty to file

Patna High Court Cr.Misc. No.9815 of 2013 (2) dt.25-06-2013
2/2
the application before the appropriate authority. If any such
application is filed, the court below will pass the order in
accordance with law.
This Court is not inclined to interfere with the order
of cognizance. However, liberty is given to raise all points before
the court below at the appropriate stage.
The court below while deciding the case filed by the
petitioner will not be prejudiced by this order.
With this observation, this application is disposed of.
Mahesh/-
(Shivaji Pandey, J)
