ORDER
Heard the learned counsel for the petitioner and the learned
Additional Advocate General appearing for the respondents.
2.The petitioner wants to write the Tamil Nadu State
Eligibility Test for the year of 2018 since that would qualify him
for the post of Assistant Professor. The test is to be conducted on
04.03.2018. The last date for submission of application was
https://hcservices.ecourts.gov.in/hcservices/

2
09.02.2018. According to the petitioner, the server was not
functioning and that therefore he wants this Court to extend the
time for reception of application.
3.The petitioner's request could have been sympathetically
considered by this Court but for the fact that he has approached
this Court after some delay. Even according to the petitioner, last
date for submission of application is 09.02.2018. This writ
petition came to be filed on 26.02.2018. Since there are hardly
three days left for conducting the examination, it will not be
possible for the respondents to receive the application at this
point of time.
4.This Court is of the view that conducting an examination is
tedious process. There are several formalities involved.
Therefore, the relief sought for by the petitioner cannot be granted
at this stage. This writ petition stands dismissed. No costs.
Consequently, connected miscellaneous petition is closed.
