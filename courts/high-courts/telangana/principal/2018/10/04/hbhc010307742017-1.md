# High Court for the State of Telangana, WP/7764/2017, 2018-10-04

THE HONíBLE SRI JUSTICE RAMESH RANGANATHAN
AND
THE HONíBLE SMT JUSTICE KONGARA VIJAYA LAKSHMI
WRIT PETITION NO.7764 OF 2017
ORDER: {Per the Honíble Sri Justice Ramesh Ranganathan}
As a consequence of the order passed today in W.P.No.7656
of 2017, whereby the assessment order was set aside, the
consequential penalty order must be, and is accordingly, set aside.
Needless to state that this order shall not disable the assessing
authority from initiating penalty proceedings afresh after a fresh
assessment order is passed or if the earlier assessment order
revives.
The Writ Petition is disposed of accordingly. There shall be
no order as to costs. Miscellaneous petitions, if any, pending shall
stand closed.
