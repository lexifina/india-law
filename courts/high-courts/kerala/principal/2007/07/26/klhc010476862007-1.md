JUDGMENT
This writ petition is filed to set aside Exts.P5 to P7 orders passed by
the Sub Court, Neyyattinkara. It is seen that there are remedies available
under the Code of Civil Procedure when an application is dismissed for
default, when it is posted for hearing under Order XXI Rule 105.
Application for restoration has to be filed under Order XXI Rule 106 C.P.C.
If such petitions can be filed by the petitioner which is permissible under
law he is at liberty to do so and in order to enable him a breathing time for
settling the matter with the decree holder, if the delivery is not already
effected, the same shall be deferred for a period of two months from today.
Writ petition is disposed of accordingly.
M.N.KRISHNAN, JUDGE
