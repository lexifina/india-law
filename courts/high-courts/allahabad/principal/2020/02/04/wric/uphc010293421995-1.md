# Allahabad High Court, WRIC/34045/1995, 2020-02-04

Court No. - 34
Case :- WRIT - C No. - 34045 of 1995
Petitioner :- Hanumant Singh
Respondent :- State of U.P. and Others
Counsel for Petitioner :- Tarun Varma,Anand Kumar
Counsel for Respondent :- S.C.
Hon'ble Sudhir Agarwal,J.
1. Heard Sri J.S. Pandey, Advocate holding brief of Sri Tarun
Verma, learned counsel for petitioner and learned Standing
Counsel for respondents.
2. Writ petition is directed against orders dated 03.04.1987
passed by Prescribed Authority, Gorakhpur and 28.10.1995
passed by Additional Commissioner (Judicial), Gorakhpur.
3. Learned counsel for petitioner submitted that proceedings
under U.P. Imposition of Ceiling on Land Holdings Act, 1960
(hereinafter referred to as "Act, 1960") were finalized vide
order dated 30.01.1975 and that order attained finality as
observed by Appellate Authority in its order dated 28.10.1995,
still fresh proceedings were initiated which are illegal.
4. However, facts stated in Annexure-5 of writ petition, which is
order dated 03.04.1987 passed by Prescribed Authority shows
that notice was issued to tenure holder on 31.10.1974
whereafter Prescribed Authority passed order dated 30.01.1975
declaring 3.75 acre (irrigated) land as surplus. Thereagainst
appeal was preferred and Appellate Authority vide order dated
23.10.1975 set aside the order of Prescribed Authority.
Thereafter amended notice was issued to tenure holder and
Prescribed Authority passed order on 31.07.1976 declaring
21.94 acre land surplus. Thereagainst appeal preferred by tenure
holder was decided vide order dated 10.12.1977 and matter was
remanded to Prescribed Authority. Third order was passed by
Prescribed Authority on 08.03.1979 declaring 21.94 acre

(irrigated) land surplus, whereagainst again appeal was
preferred in which Appellate Authority vide order dated
13.12.1979 modified Prescribed Authority's order dated
08.03.1979 and declared 9.80 acre (irrigated) land surplus.
Tenure holder carried the matter to this Court in a writ petition
and vide judgment dated 20.07.1981 this Court set aside
appellate order dated 13.12.1979 and Prescribed Authority's
order dated 08.03.1979. There was a review order dated
26.03.1980 also whereby Appellate Authority rejected review
and this Court vide judgment dated 20.07.1981 set aside review
order also. It is pursuant thereto, fresh order ought to have been
passed by Prescribed Authority but instead it passed order dated
03.04.1987 observing that earlier order dated 30.01.1975 has
attained finality though it is already there that order dated
30.01.1975 was set aside in appeal vide appellate order dated
23.10.1975. Appellate Authority has also confirmed Prescribed
Authority's order dated 31.07.1976 but I find that this finding
that order dated dated 30.01.1975 has attained finality is totally
perverse and shows misreading on the part of Appellate
Authority also.
5. In the circumstances, writ petition is allowed. Orders dated
03.04.1987 and 28.10.1995 are hereby set aside. Prescribed
Authority is directed to pass a fresh order in view of the facts
discussed above.
Order Date :- 4.2.2020
