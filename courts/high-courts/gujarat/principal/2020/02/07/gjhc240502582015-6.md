 ORAL ORDER
1. Mr.Shakeel Qureshi, learned advocate for the applicant
submits that the First Information Report being C.R.No.I-199 of 2013
registered with Varachha Police Station, District: Surat has already
been quashed and set aside by this Court (Coram: Hon’ble
Ms.Justice Sonia Gokani) vide order dated 30.04.2019 passed in
Criminal Misc. Application No.5266 of 2019 and, therefore, in view of
the above order, the present application has become infructuous.
2. Mr.Dharmesh Devnani, learned Additional Public Prosecutor
also submits that he has information from the Police Autority that
the FIR has been quashed and set aside.
3. The said order dated 30.04.2019 passed by this Court in
Criminal Misc. Application No.5266 of 2019 is taken on record.

4. In view of the above, the present application stands disposed
