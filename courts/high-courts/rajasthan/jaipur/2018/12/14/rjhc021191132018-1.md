HON'BLE MR. JUSTICE PANKAJ BHANDARI
Order
14/12/2018
Petitioner has moved an application for correction in the
order dated 06.12.2018 that in the impugned order dated
06.12.2018, para No.3, line No.1,5 & 6 and in para No.7, line No.1
erroneously Kailash Sharma has been typed as name of the
petitioner, whereas name of the petitioner is Prahlad Sharma.
Considering the fact that the typographical error has been
committed, in the order dated 06.12.2018 in para No.3, line
No.1,5 & 6 and in para No.7, line No.1, “Kailash Sharma be
read as Prahlad Sharma”.
Application for correction is accordingly allowed.
(PANKAJ BHANDARI),J
