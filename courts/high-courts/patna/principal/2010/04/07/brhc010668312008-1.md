7 07/04/2010 This application has been filed challenging
the order dated 06.12.2006 by which the Court has
found the case First Information Report for charge under
Sections 323, 341 and 542/34 of the Indian Penal Code.
The petitioner has challenged that part of
the order by which the Court has referred to the orders
passed by this Court i.e. the High Court, wherein it was
observed that if the injuries were found either to be
serious or grievous, then the accused persons would
come within the purview of Section 307 of the Indian
Penal Code.
I find no illegality in the order impugned.
This application is thus dismissed.
Anand ( Sheema Ali Khan, J.)
