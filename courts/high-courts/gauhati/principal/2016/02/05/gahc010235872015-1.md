# Gauhati High Court, I.A./2541/2015, 2016-02-05

I.A. 2541/2015
BEFORE
HON’BLE MR. JUSTICE UJJAL BHUYAN
Heard Mr. D. Bhattacharya, learned counsel for the applicant.
It is submitted that though extension of time was sought for compliance
of the Court’s order by filing the Interlocutory Application, in the meanwhile,
Court’s order has already been complied with.
In view thereof, this interlocutory application has become infructuous.
Dismissed as infructuous.
