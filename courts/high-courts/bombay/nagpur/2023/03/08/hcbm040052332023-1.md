 The petition challenges the order dated
15-02-23 (pg 49) by the respondent no. 1, whereby the
application for amendment filed by the applicant has been
rejected. The impugned order which rejects the application
is an unreasoned one which would indicate that it was not
justified by any count whatsoever, considering which, the
same is quashed and set aside and matter is remanded to
the respondent no.1 who decides the application by giving
appropriate reasons after hearing the learned counsel for
the parties.
2. The appeal shall be expedited.
