# Calcutta High Court, CRR/3457/2023, 2024-03-14

D/L139
14.03.2024
Bpg.
 C.R.R.3457 of 2023
 Rajendra Kumar Malu
 Versus
 Sri Kushal Chand Baderia

Earlier, the revisional application was called on
14.09.2023, an accommodation was sought for on behalf of the
petitioner. Today, when the revisional application has been called,
none represented the petitioner. The revisional application is
running in the list for a considerable period of time and called on
several occasions.
Accordingly, the revisional application being CRR 3457 of
2023 is dismissed for default.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
