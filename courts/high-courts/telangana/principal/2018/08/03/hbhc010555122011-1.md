# High Court for the State of Telangana, ARBAPPL/112/2011, 2018-08-03

HON’BLE THE CHIEF JUSTICE
THOTTATHIL B. RADHAKRISHNAN
ARBITRATION APPLICATION No.112 OF 2011
ORDER (ORAL):
 This matter was listed on 27.07.2018. There was no appearance
for the applicant. Hence, the matter was listed today for being
considered for dismissal for default in the event of continued
non-appearance. None appeared for the applicant today as well.
This Arbitration Application, hence, dismissed for default.
No order as to costs.
As a sequel thereto, Miscellaneous Applications, if any, pending
in the Arbitration Application stand dismissed for default.
