# High Court for the State of Telangana, WP/25414/2014, 2014-09-02

THE HON’BLE SRI JUSTICE RAMESH RANGANATHAN
AND
THE HON’BLR SRI JUSTICE M.SATYANARAYANA MURTHY
WRIT PETITION NOs.25414 AND 25415 OF 2014
COMMON ORDER: {Per the Hon’ble Sri Justice Ramesh
Ranganathan}
The proceedings under challenge in both these Writ Petitions
are penalty orders passed as a consequence of the order of
assessment.
Sri Karan Talwar, learned counsel for the petitioner, would
submit that, as the assessment orders were set aside in appeals and
remanded back to the assessing authority to pass orders afresh, the
impugned penalty orders, passed as a consequence of the earlier
assessment orders which have since been set aside, must also be
quashed.
Sri J.Anil Kumar, learned Special Standing Counsel for
Commercial Taxes, on instructions, would fairly submit that the
assessment orders have been set aside in appeal. As the assessing
authority is now required to pass orders afresh, the penalty orders,
passed as a consequence of the earlier assessment orders, are set
aside leaving it open to the first respondent, if need be, to initiate
penalty proceedings after assessment orders are passed afresh.
The impugned orders of penalty are, accordingly, set aside.
Both the Writ Petitions are disposed of. There shall be no order as to
costs. Miscellaneous petitions, if any, pending shall stand closed.
