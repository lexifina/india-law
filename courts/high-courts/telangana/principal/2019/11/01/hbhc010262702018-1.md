# High Court for the State of Telangana, CC/930/2018, 2019-11-01

THE HONOURABLE SRI JUSTICE M.S.RAMACHANDRA RAO
CONTEMPT CASE No.930 of 2018
ORDER :
 Since the order whose contempt is alleged has been complied
with by passing an order dt.08-03-2018 by the respondent, this
Contempt Case is closed granting liberty to the petitioner to challenge
the order dt.08-03-2018 passed in Memo No.JDWA/K/Admn/
U.I/2017-18/307 by the respondent in a separate proceeding. No
costs.
 Therefore, this Contempt Case is closed. No costs.
 As a sequel, the miscellaneous petitions, if any pending, shall
stand closed.

JUSTICE M.S.RAMACHANDRA RAO
