ORDER
Petitioners had previously moved for pre-arrest bail
in the same case, Crime No.31/2012 at Cheemeni Police
Station, in which investigation is going on imputing offences
punishable under Section 143, 147, 148, 341, 324, 326 and
308 read with 149 of the Penal Code. Vide Annexure A1 order
dated 21.03.2012 that discretionary relief canvassed by the
petitioners under Section 438 of the Code of Criminal
Procedure was found meritless and their application was
dismissed. A1 order is passed based on the submissions made
by the State on incorrect materials and as such a fresh
application for the same relief can be canvassed before this
court, is the submission of the learned counsel. In case there
is change of circumstance entitling the party to seek again the

B.A. NO.2603 of 2012 2
discretionary relief of anticipatory bail, if so canvassed for, it
has to be looked into and examined. However the challenge
against previous order that it was based on incorrect
particulars furnished, without any foundation thereof, to
present the second application for the same relief, does not call
for any scrutiny.
Petition is dismissed.
S.S.SATHEESACHANDRAN
 JUDGE.
