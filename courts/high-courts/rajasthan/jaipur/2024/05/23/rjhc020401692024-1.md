1. Matter comes up on Writ Misc. Application filed by applicant
seeking correction/modification in the order dated 30.04.2024
passed by this Court.
2. It is contended by counsel appearing for the applicant that in
Para 7 of the order dated 30.04.2024, certain facts have not been
correctly indicated, hence, the same may be corrected.
3. We have heard counsel for both the parties and have
perused the order dated 30.04.2024.
4. Considering the above, we deem it proper to modify the
order dated 30.04.2024.
5. The following portion in Para 7 of order dated 30.04.2024 i.e.
“We are not inclined to accept the said arguments for the very
reason that this is not a case where the registered person failed to
furnish the return rather, the petitioner has filed the NIL return”
be now replaced by “We are not inclined to accept the said
arguments for the very reason that this is not a case where the
registered person failed to furnish the return rather, the petitioner
has filed the NIL GSTR-3B for the period July 2017 to September
2018, and no return or GSTR-3B for the period October 2018 to
September 2020 were filed by the petitioner.”
6. The present Writ Miscellaneous Application is accordingly,
allowed and the order dated 30.04.2024 is modified to the above
extent.
7. This order shall be treated as part and parcel of the order
dated 30.04.2024 passed by this Court.
