# High Court of Madhya Pradesh, MCC/256/2015, 2015-02-05

M.C.C. NO.256/2015
05/02//2015
 Shri Jitesh Shrivastava, learned counsel for the applicant.
 Shri S.K.Shukla, learned counsel for the respondents.
 This application has been filed for restoration of R.P.No.150/14
which has been dismissed for non compliance of peremptory
order. As there is some delay in filing of the application,
I.A.No.1241/2015 has been filed seeking condonation of delay.
The default in filing of the restoration application is attributed to
some lapses in the office of the counsel for the applicant, which
supported by filing an affidavit of counsel himself and finding the
same to be bonafide, this application is allowed.
 R.P.No.150/2014 is restored to its original file and it be placed
for hearing before an Appropriate Bench.

 (RAJENDRA MENON) (C.V.SIRPURKAR)
 JUDGE JUDGE
