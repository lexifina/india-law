This matter is taken up for hearing through Video-Conferencing.
Despite several adjournments, the counsel for the petitioners is
absent.
2. It is seen from the records that the Revision is filed against an order
dismissing an application filed under Order 21 Rule 97 of the Code of Civil
Procedure. An order deciding an application under Order 21 Rule 97 is an
appealable order, in view of Rule 103 of Order 21 of the Code of Civil
Procedure. Hence the Civil Revision Petition is rejected as not
maintainable. No costs. Consequently, the connected miscellaneous
petitions are closed.
