P.C. :
1. This matter is placed on the board for
correcting two typographical errors in the
order dated 18th February, 2009. Mr.Solkar
points out that the correct number of the
proceeding which was sought to be quashed
was R.C.C.No.63 of 2006. The number
R.C.C.No.143 of 2005 was the old number of
the proceedings.
2. The second correction is with regard

to description of the offences in the
proceedings. The description omits to
mention the offence punishable under
Section 504 IPC. The order dated 18th
February, 2009 be read with the above
corrections as regards the description of
the offence in the proceedings and the
number of the proceedings. With this
Criminal Application No.186 of 2009 stands
disposed off.
