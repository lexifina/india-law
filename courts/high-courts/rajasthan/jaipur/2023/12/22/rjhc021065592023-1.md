HON'BLE MR. JUSTICE SUDESH BANSAL
Order
22/12/2023
1. Matter has come up on an application seeking correction in
the order dated 20.12.2023 wherein in para No.5, the name of
petitioner has wrongly been mentioned as “Rajkumar @ S.p S/o
Shri Kishansingh”, instead of “Nayyum Khan S/o Mainudeen
Kayamkhani”.
2. Heard counsel for the applicant.
3. It appears that in the order dated 20.12.2023, in para No.5,
inadvertently the name of petitioner has been mentioned as
“Rajkumar @ S.p S/o Shri Kishansingh”, whereas it should be
“Nayyum Khan S/o Mainudeen Kayamkhani”, which is a
typographical error.
4. In view of above, in the order dated 20.12.2023, the name
of petitioner “Rajkumar @ S.p S/o Shri Kishansingh”, be corrected
in red ink as “Nayyum Khan S/o Mainudeen Kayamkhani”, the
correction made in the original order be upload online showing
asterisk (*) mark in the order that the name of petitioner has
been corrected subsequently. Rest part of the order shall remain
as such.
5. Accordingly, the application stands disposed of.
(SUDESH BANSAL),J
