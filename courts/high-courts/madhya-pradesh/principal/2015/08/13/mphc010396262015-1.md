# High Court of Madhya Pradesh, MCC/2365/2015, 2015-08-13

MCC-2365-2015
(SUNIL PRAJAPATI Vs THE STATE OF MADHYA PRADESH)
13-08-2015
Shri Kunal Dubey, learned counsel for the applicant.
This application has been filed for restoration of Writ Petition
No.4811/2010, which was dismissed for want of prosecution vide
order dated 29/04/2015. There being some delay in filing the
application for restoration, therefore, I.A. No.10324/2015 has been
filed seeking condonation of delay. Both the applications are
supported by an affidavit of the applicant himself and there is no
reason to disbelieve the same. Finding the same to be bonafide,
both the applications are allowed.
Condoning the delay in filing the application, restoration
application is itself allowed.
Writ Petition No.4811/2010 is restored to its original number.
After restoration, the petition be listed for orders before
appropriate Bench.
Application stands allowed and disposed of.
Certified copy as per rules.
(VANDANA KASREKAR)
JUDGE
