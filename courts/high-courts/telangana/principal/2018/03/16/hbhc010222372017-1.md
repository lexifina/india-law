# High Court for the State of Telangana, CRP/4860/2017, 2018-03-16

THE HON'BLE SRI JUSTICE A.RAMALINGESWARA RAO
CIVIL REVISION PETITION No.4860 of 2017
ORDER:
 Learned counsel for the petitioner seeks permission to
withdraw the Civil Revision Petition with liberty to file
comprehensive suit.
 Permission is accorded.
 Accordingly, the Civil Revision Petition is dismissed as
withdrawn with liberty to file comprehensive suit. Miscellaneous
petitions, if any, pending in this revision petition shall stand
closed. There shall be no order as to costs.
