ORAL ORDER
Learned advocate for the applicant seeks permission to
withdraw present application with a liberty to file fresh
proceeding u/s 482 of the Code of Criminal Procedure, 1973
after explaining reasons/grounds for preferring second
application u/s 482 of the Code of Criminal Procedure, 1973 ,
as earlier, the applicant has filed Criminal Misc. Application
No.4465 of 2019 before this Court, which came to be
withdrawn vide order dated 11.3.2019. Permission is granted.
The application stands disposed of as withdrawn with above
liberty.
It is clarified that this Court has not examined the merits
of the present application.
(S.H.VORA, J)
