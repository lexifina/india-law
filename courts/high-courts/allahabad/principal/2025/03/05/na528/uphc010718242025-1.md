# Allahabad High Court, NA528/7178/2025, 2025-03-05

Neutral Citation No. - 2025:AHC:31346
Court No. - 77
Case :- APPLICATION U/S 528 BNSS No. - 7178 of 2025
Applicant :- Raj Kumar
Opposite Party :- State of U.P. and Another
Counsel for Applicant :- Ashish Kumar Mishra
Counsel for Opposite Party :- G.A.
Hon'ble Arun Kumar Singh Deshwal,J.
1. Heard Sri Ashish Kr. Mishra, learned counsel for the applicant
and Sri Brijesh Kr. Dwivedi, learned A.G.A. for the State.
2. The instant application has been filed to set aside the impugned
order dated 4.5.2024 as well as NBW dated 3.6.2024 passed by
Gram Nyayalay, Pindra, District Varanasi.
3. After some argument, learned counsel for the applicant seeks
permission to withdraw this case to file a better application as
relevant document has not been annexed with the affidavit.
4. In view of the above request, the application is dismissed as
withdrawn with the aforesaid liberty.
5. Certified copy of the impugned order(s), if any, may be returned
to the counsel for the applicant after retaining a photocopy of the
same on record.
Order Date :- 5.3.2025
