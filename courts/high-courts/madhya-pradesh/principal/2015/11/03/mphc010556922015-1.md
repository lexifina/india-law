# High Court of Madhya Pradesh, WP/18776/2015, 2015-11-03

WP-18776-2015
(RAJKUMAR RAI Vs THE STATE OF MADHYA PRADESH)
03-11-2015
Shri Rakesh Kumar Jain, learned counsel for the petitioner.
 Shri A.P. Singh, learned counsel for the respondent/State.
 Learned counsel for the petitioner seeks permission to
withdraw this petition because remedy to file an appeal against the
order passed by SDO is available.
Needful be done by the petitioner within three weeks from
today.
In view of the aforesaid, this petition is permitted to be
withdrawn. Petitioner may file an appeal within the time so
specified and the certified copy of the order passed by the SDO be
returned back to learned counsel for the petitioner on retaining the
photocopy thereof on record.
Disposed of with the aforesaid.
(J.K. MAHESHWARI)
JUDGE
