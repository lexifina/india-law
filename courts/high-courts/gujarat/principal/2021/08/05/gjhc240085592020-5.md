ORAL ORDER
1. Heard learned advocates.
2. The order dated 14.06.2021 is recalled.
3. The petitioner apprehended detention under PASA.
4. In response to the notice of this Court, it is informed to
the Court that not only the FIRs which are mentioned in the
petition, independent of that also, there were FIRs and the
detention order was already passed long back, which is yet to
be executed.
5. Mr. Patel, learned advocate for the petitioner seeks
permission to withdraw this petition, reserving liberty to file
separate petition challenging the detention order which is
stated to have been passed.
