This petition coming on for admission this day, the court passed the
following:
ORDER
Shri Jitendra Shrivastava, Panel Lawyer for the State submits that once
election results have been declared petitioner has a remedy to file an election
petition.
This issue is now well settled by a Division Bench of this High Court in
W.A. No.937/2022 (Smt. Rachna Devi Patel Vs. The State of Madhya
Pradesh and Others).
Therefore, Manoj Kushwaha prays for withdrawal of this petition with
liberty to file Election Petition, if so advised.
With the aforesaid liberty, this petition is dismissed as withdrawn.
