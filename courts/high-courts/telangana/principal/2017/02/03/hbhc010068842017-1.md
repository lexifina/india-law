# High Court for the State of Telangana, CC/99/2017, 2017-02-03

THE HON'BLE SRI JUSTICE A.RAMALINGESWARA RAO
CONTEMPT CASE No.99 OF 2017
ORDER:
 This Court by order dt.29.08.2016 in W.P.No.20007 of
2014 dismissed the Writ Petition confirming the order of the 2nd
respondent.
2. The present Contempt Petition is filed seeking
implementation of the order of the 2nd respondent. But there is
no direction by this Court to implement the orders of the 2nd
respondent and in the absence of the same, no contempt case
arises.
3. Therefore, this Contempt Case is misconceived and it is
accordingly dismissed. No order as to costs.
4. Miscellaneous Petitions, if any, pending in this Writ
Petition shall stand closed.
_______________________________
 A.RAMALINGESWARA RAO, J
03rd February, 2017.
