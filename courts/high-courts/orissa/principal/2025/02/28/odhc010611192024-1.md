Order No.
01. 1. This matter is taken up through Hybrid mode.
2. The Petitioner has filed this contempt application arising out of
non-compliance of order dated 05.02.2024 passed by this Court in
W.P.(C) No.2162 of 2024 which was subsequently modified vide
order dated 18.04.2024.
3. Further referring to the postal receipt, which was filed in Court
today and the same is taken on record, learned counsel for the
Petitioner submitted that the aforesaid order has duly communicated
to the Opposite Party-Contemnor.
4. Learned counsel for the Opposite Party-Contemnor, on the

 Page 2 of 2.
other hand, sought for some time to implement the order of this
Court in the event the same attains finality.
5. Considering such submission and keeping in view the request
made by the learned counsel for the Contemnor, six weeks’ further
time is granted to the Contemnor to implement the order dated
05.02.2024 passed by this Court in W.P.(C) No.2162 of 2024 which
was subsequently modified vide order dated 18.04.2024, if the same
attains finality.
6. It is made clear that in the event the order of the Court is not
given effect to within the time stipulated hereinabove, it will be
construed to be deliberate violation of this Court’s order.
7. With the aforesaid observation and direction, the contempt
application is disposed of.
 ( A.K. Mohapatra )
