Order
 The learned counsel appearing for the petitioner submits that in
view of the order passed by the Hon’ble Division Bench of this Court in
W.P.No.16510 of 2024 dated 21.01.2026, the Impugned Order has to be set
aside, as the Impugned Order is a Rectification Order seeking to rectify the
Order dated 22.03.2024, which has now been set aside by the Hon’ble
Division Bench of this Court by the aforementioned order dated 21.01.2026.

the Order passed by the Hon’ble First Bench of this Court dated 21.01.2026
in W.P.No.16510 of 2024. No costs. Consequently, connected Miscellaneous
Petition is closed.
