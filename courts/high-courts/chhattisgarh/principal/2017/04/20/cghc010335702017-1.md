Order On Board

Heard.
1. This is an application for seeking correction in so far as the name of Janpad
Panchayat is concerned.
2. Learned counsel for the applicant submits that due to typographical mistake, the
name of Janpad Panchayat was wrongly mentioned as “Katghora”. Whereas the
correct description would be “Pali”.
3. Learned State counsel does not oppose the prayer.
4. Accordingly, the MCC application is allowed and in the cause title of order dated
19.01.2017 passed in WPS No.296 of 2017, in the description of respondent
No.3, in place of “Katghora”, it shall be read and understood as “Pali”. The order
has to be read with the aforesaid clarification.
5. The applicant shall submit a copy of this order before the concerned authority for
necessary compliance.
 Sd/-
