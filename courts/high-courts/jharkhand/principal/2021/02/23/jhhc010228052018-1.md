8/23.02.2021 Heard Mr. Rajeeva Sharma, learned senior counsel for the
petitioner at length.
 After some arguments, learned senior counsel for the petitioner
seeks permission to withdraw this criminal miscellaneous petition,
wherein FIR has been challenged, with a liberty to file an appropriate
discharge application before the court below.
 Prayer is allowed.
 Let this criminal miscellaneous petition be dismissed as
withdrawn giving liberty to the petitioner to file discharge application.
 If any discharge application is filed, the same will be considered
on its own merits and as per the materials on record the court below will
pass a reasoned and speaking order on the discharge application without
being prejudiced by this order of withdrawal.
