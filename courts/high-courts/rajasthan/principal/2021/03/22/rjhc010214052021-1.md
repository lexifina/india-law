HON'BLE MR. JUSTICE VINIT KUMAR MATHUR
Order
22/03/2021
The present application has been filed by the applicant
seeking correction in the order dated 17.03.2021 passed in S.B.
Criminal Misc. Second Bail Application No. 3495/2021.
It is submitted by learned counsel for the applicant that due
to typographical mistake, in the order dated 17.03.2021 the FIR
number has wrongly been mentioned as 106/2019 whereas it
should have been 192/2019.
For the reasons mentioned in the application, the same is
allowed. The FIR number in the order dated 17.03.2021 passed in
S.B. Criminal Misc. Second Bail Application No. 3495/2021 be read
as 192/2019 instead of 106/2019.
(VINIT KUMAR MATHUR),J
