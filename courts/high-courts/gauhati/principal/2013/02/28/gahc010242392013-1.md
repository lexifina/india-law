# Gauhati High Court, AB/301/2013, 2013-02-28

AB 301/2013
PRESENT
HON’BLE MR JUSTICE A. C. UPADHYAY
Heard Mr FKR Ahmed, learned counsel for the petitioner and Mr B S Sinha, learned
Additional PP.
Learned counsel for the petitioner submitted that an application was fil
ed on behalf of petitioner u/s 438 of the CrPC in connection with a case registe
red by the Lanka police station, which the petitioner was not aware of .
By order dated 13th February, 2013, report was called from Lanka police
station whether any case was registered by it against the petitioner.
Learned Additional PP submitted, on instructions, that no case has so fa
r been registered by Lanka police station against the petitioner.
In view of above, this application is closed with liberty to file approp
riate application in future, if so advised. Interim order dated 13th February, 2
013 stands vacated.
