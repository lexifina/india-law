P.VELMURUGAN, J
This application has been filed to set aside the ex-parte order dated
11.06.2024 passed against the first defendant in the above suit.
2. Heard the learned counsel for the applicant/first defendant and
the learned counsel for the first respondent/plaintiff and perused the
materials available on record.
3. Though the applicant/first defendant has forfeited his right to file
written statement, however, he is having right to cross examine the
plaintiff's side witnesses.
4. On being satisfied with the reasoning adduced in the affidavit
filed in support of this application, the ex-parte order passed by this
Court dated 11.06.2024 is set aside.
5. Accordingly, the application in A.No.3098 of 2024 is allowed.
