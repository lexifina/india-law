 ORDER
When the matter is taken up today for hearing, it is pointed out
by this Court to the learned counsel for the petitioner that the
matter pertains to Madurai Bench jurisdiction and hence the same has
to be filed before the Madurai Bench of Madras High Court.
2. On hearing the same, the learned counsel appearing for the
petitioner seeks permission of this Court to withdraw the Writ
Petition. He has also made an endorsement to that effect.
3. In view of the above, this writ petition is dismissed as
withdrawn with liberty to the petitioner to file the very same writ
petition before the Madurai Bench of this Court. Office is directed
to return the original papers, if any, filed in this writ petition to
the learned counsel for the petitioner along with the order copy so
as to enable the petitioner to file the same before the Madurai Bench
of Madras High Court. No costs. Consequently, the connected
miscellaneous petitions are closed.
