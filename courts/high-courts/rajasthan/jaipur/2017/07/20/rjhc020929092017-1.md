HON'BLE MR. JUSTICE PANKAJ BHANDARI
Judgment / Order
20/07/2017
1. Heard on application filed filed for modification order dated
25.03.2016.
2. It is contended that in place of Rs.20,000/-, 25,000/- has
been mentioned. The amount deposited by the petitioner was
Rs.20,000/- and petitioner was entitled to refund of only
Rs.20,000/-.
3. I have considered the contentions by counsel for the
petitioner.
4. It appears that a typographical error has been committed in
the impugned order dated 25.03.2017 and the same needs to be
corrected.

(2 of 2)
[CRLMA-338/2017]
5. Application is allowed, the last paragraph of the order in
place of “25,000/-” the same be now read as “20,000/-.”
6. The order dated 25.03.207 stands modified accordingly.
(PANKAJ BHANDARI), J.
