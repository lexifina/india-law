# High Court of Madhya Pradesh, MCC/826/2012, 2012-08-22

MCC. No.826/2012
22/8/2012
None appears for the petitioner.
This application has been filed for restoration of W.P.
No.26494/2003 which was dismissed for want of prosecution on
15.2.2012. There being some delay in filing the application I.A.
No.8075/2012 has been filed seeking condonation of delay. Delay and
default is explained by attributing some lapses on the part of counsel
and his clerk. Application is supported by an affidavit of counsel and
there is no reason to disbelieve the same. Finding the same to be
bonafide, both the applications are allowed. Condoning the application
in filing the application, the restoration application itself is allowed. Writ
Petition is restored to its original number. It be placed for orders before
the appropriate Bench.
Application stands allowed and disposed of.
 (RAJENDRA MENON)
