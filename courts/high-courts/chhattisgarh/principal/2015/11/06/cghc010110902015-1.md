Hon’ble Shri Justice Sanjay K. Agrawal
Order on Board
06/11/2015
1. Learned counsel for the petitioner would submit that correct name
of petitioner's father is Shri Nakul Rathiya, whereas, it has been wrongly
typed as Shri Nakul Kanwar in M.Cr.C. 5441/2015 vide order dated
12/10/2015.
2. Learned State counsel after verifying the case diary would submit
that correct name of petitioner's father is Shri Nakul Rathiya.
3. Accordingly, it is directed that in the order dated 12/10/2015 passed
in M.Cr.C. No. 5441/2015, the name of petitioner's father be read as Shri
Nakul Rathiya in place of Shri Nakul Kanwar.
4. With the above direction, petition is disposed of.
 Sd/-
(Sanjay K. Agrawal)
