C O M M O N O R D E R
The petitioner is seeking for transfer of the First Appeal
pending on the file of the III Additional District Court,
Puducherry to be tried along with the applications in un-numbered First Appeal in A.S.No.Nil of 2020 pending on the file
of the Principal Sub Court, Puducherry.
https://hcservices.ecourts.gov.in/hcservices/

2.The learned counsel seeks permission to withdraw the
petitions with liberty to file appropriate petition for
transferring the pending First Appeal on the file of the III
Additional District Court, Puducherry to the file of the
Principal Sub Court, Puducherry. The learned counsel also made
an endorsement to that effect.
3.In view of the same, the Transfer Civil Miscellaneous
Petitions are dismissed as withdrawn. It is open to the
petitioner to file appropriate petition seeking for transfer
before the Principal District Court, Puducherry for transferring
the pending First Appeal on the file of the III Additional
District Court, Puducherry to the file of the Principal Sub
Court, Puducherry to be tried along with the pending
applications in the A.S.No.Nil of 2020. No costs. Consequently,
the connected miscellaneous petitions are closed.
