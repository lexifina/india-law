# High Court of Madhya Pradesh, CONC/222/2011, 2017-03-03

CONC-222-2011
(RAJENDRA Vs JANGLI)
03-03-2017
Shri A.D. Mishra, Advocate for the applicant.
None appears for the respondent.
This is an application for contempt arising out of interim
order dated 21.05.2009 passed in S.A. No.596/2009. The said
order was passed on an application under Order 39 Rule 1 and 2
C.P.C.
Prima facie, this application for contempt is not
maintainable as the appropriate remedy for appellant is to file an
application for breach of injunction.
In view of the aforesaid, this contempt petition is dismissed
as withdrawn with liberty to file an appropriate application, in
accordance with law.
(VIJAY KUMAR SHUKLA)
JUDGE
