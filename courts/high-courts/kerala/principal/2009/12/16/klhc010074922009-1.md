O R D E R
The learned counsel for the petitioner sought permission to
withdraw the Bail Applications in order to enable the petitioner to
move the learned Magistrate for default bail under Section 167(2)
of the Code of Criminal Procedure.
Permission is granted and the Bail Applications are
dismissed as withdrawn with liberty to the petitioner to file fresh
Bail Application, if it becomes necessary.
Issue copy of this order today itself.
 K.T. SANKARAN, JUDGE
