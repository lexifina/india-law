# High Court of Madhya Pradesh, MCRC/16272/2017, 2018-06-20

THE HIGH COURT OF MADHYA PRADESH
MCRC-16272-2017
(IMRAN UDDIN Vs THE STATE OF MADHYA PRADESH)
Jabalpur, Dated : 20-06-2018
Shri L.P. Singh with Shri Manoj Kushwaha, learned counsel for
the applicant.
Shri Manish Soni, learned G.A. for the respondent/State.
Heard on I.A.No.10087/2018, which is an application for
withdrawal of the petition.
Learned counsel for the applicant submitted that he may be
permitted to withdraw this M.Cr.C. with liberty to file afresh if
occasion so arises.
On due consideration the application is allowed.
Accordingly, M.Cr.C. is dismissed as withdrawn with the
aforesaid liberty.
