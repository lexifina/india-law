JUDGE
Learned counsel for the applicant has submitted that applicant No.-1
Danbihari has already been arrested, therefore, the application in respect to
applicant No.1 has rendered infructuous.
The application in respect to applicant No.1-Danbihari is accordingly
dismissed as having rendered infructuous.
Learned counsel for the applicant seeks for and is granted permission to
withdraw this first anticipatory bail application under Section 438 of CrPC with
liberty to surrender before the trial Court and to file an application for regular
bail. It is further prayed that trial Court may kindly be directed to decide the
regular bail application of the applicant No.2-Ramsharan as expeditiously as
possible, if possible on the same day.
With aforesaid liberty, the application is dismissed as withdrawn.
Trial Court is directed to decide the regular bail application of the
applicant No.2-Ramsharan, if filed, as expeditiously as possible, if possible on
the same day, in accordance with law.
