22. The anusanga principle (or elliptical extension) states
that an expression occurring in one clause is often meant also
for a neighbouring clause, and it is only for economy that it is
only mentioned in the former (see Jaimini 2, 2, 16). The anusanga
principle has a further sub-categorization. If a clause which oc- F
) curs in a subsequent sentence is to be read into a previous
sentence it is a case of Tadapakarsha, but when it is vice-versa
it is a case of Tadutkarsha.
23. The Anusanga principle of Mimansa was used by
Jimutvahana in the Dayabhaga. Jimutvahana found that there G
is a text of Manu which states:
~ ... "Of a woman married according to the Brahma, Daiva,
