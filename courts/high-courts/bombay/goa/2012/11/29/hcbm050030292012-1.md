2. This is an application for condonation of delay of 23 days in
filing the revision application challenging the order dated
07.07.2012. It is not in dispute that the applicant is at present in
custody which prevented him to file the revision application within
time prescribed.
3. For the reasons stated therein which stand uncontroverted,
the application for condonation of delay of 23 days in filing the
revision application is allowed.
4. The application stands disposed of accordingly.
