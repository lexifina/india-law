 This is an application for speaking to the minutes of the order
dated 27.4.2017 passed in the Appeal From Order No.17/2017.
Shri V. Sardessai, learned Advocate for the applicants submits
that there is a typographical error in the number of the Inventory
Proceeding which has occurred in the said order requiring

at line no.2 as Inventory Proceeding No."28/2003" instead of
24/2003".
 Registry to make necessary correction in the order.
 The application stands disposed off accordingly.
