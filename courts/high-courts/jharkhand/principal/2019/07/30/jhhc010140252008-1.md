11/Dated 30th July, 2019
Per Sanjay Kumar Dwivedi, J.
1. Learned counsel appearing for the petitioner submits that grievances of
the petitioner have already been redressed and the only grievance left is that
salary for the period from 01.3.2001 to 31.8.2001 is still to be paid.
2. Said claim of the petitioner has been rejected by order dated 02.9.2017,
which is referred to in Annexure B to the supplementary counter affidavit and
there is no challenge to that order in this writ petition. Accordingly, no relief can
be extended to the petitioner in this writ petition.
3. Accordingly, this writ petition is dismissed.
4. It goes without saying that the petitioner, if so advised, may file a writ
petition challenging the Order dated 02.9.2017.
