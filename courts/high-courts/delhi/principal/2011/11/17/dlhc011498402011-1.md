ORDER
% 17.11.2011
1. Present execution petition has been filed by the decree holder under
Order XXI of the Code of Civil Procedure.
2. Learned counsel for the decree holder submits that assets of the
judgment debtors are situated at NOIDA, Uttar Pradesh. Counsel,
thus, wishes to withdraw present execution petition and the
application with l iberty to file the same in the appropriate Court
having jurisdiction over the matter.
3. Accordingly, petition and application stand dismissed as withdrawn.
Liberty, as prayed for, is granted. Decree holder would be entitled to
file execution petition in the appropriate Court of jurisdiction.
- .C.
