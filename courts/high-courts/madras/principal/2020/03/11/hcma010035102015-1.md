A.No.4402 of 2015
N.SATHISH KUMAR, J.
This application is filed by the applicant, seeking a direction to the
respondents to furnish security to the tune of Rs.1,48,771/- failing which
to order attachment of the immovable properties more fully described in
the Judges summons.
2. Despite an order of this Court, security has not been furnished
from 05.09.2019, hence, order of attachment is passed. Registry is
directed to communicate this order to concerned Registrar office.
In view of the above, this application is closed.
