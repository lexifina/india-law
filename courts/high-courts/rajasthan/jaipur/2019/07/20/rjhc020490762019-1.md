HON'BLE MR. JUSTICE PANKAJ BHANDARI
Judgment / Order
20/07/2019
1. Petitioner has preferred this Criminal Misc. Petition under
Section 482 Cr.P.C. seeking fair investigation.
2. Report is submitted by learned Public Prosecutor. As per
which Police has come to the conclusion that no offence is made
out and Police is going to submit negative final report.
3. In view of the same, the present Petition has become
infructuous and the same is accordingly dismissed as having
become infructuous. Stay application stands disposed.
4. Petitioner would be free to file protest petition, if so advised.
