PER COURT:
This is an application for setting aside Registrar’s order
dated 19.07.2011, dismissing the appeal for want of prosecution.
Heard. For the reasons stated in the application,
application deserves to be allowed and same is accordingly allowed. The
order dated 19.07.2011, passed by the Registrar, dismissing the appeal
for want of prosecution, is set aside. Delay occurred in presenting the
application stands condoned. Appeal be restored to its original number.
