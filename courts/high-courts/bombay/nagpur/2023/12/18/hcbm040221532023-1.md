Heard.
2. Present application is filed by the applicant
for grant of bail under Section 439 of the Code of Criminal
Procedure.
3. After hearing the learned Counsel for the
applicant to some extent, this Court has expressed
disinclination to grant bail to the present applicant.
4. Learned Counsel for the applicant seeks to
withdraw the same with liberty to file afresh after six
months.
5. Permission is granted.
6. In view of that, the application is disposed of
as withdrawn with liberty to file afresh if there is no
substantial progress in the trial within nine months.
