# High Court of Orissa, ABLAPL/1279/2018, 2019-09-04

for the State that no case has yet been registered against
the petitioners at Infocity Police Station; learned counsel
for the petitioners prays for withdrawal of this
application seeking liberty to move afresh in case cause
of action for the same so arises in future.

stands disposed of. The interim order dated 08.03.2018
does no more survive.
