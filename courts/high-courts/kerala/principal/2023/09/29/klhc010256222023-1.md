O R D E R
 This Criminal Miscellaneous Case is filed to quash Annexure-4
order passed in Crl. M.P.No.856/2023 in CC.No.2378/2017 by the
Judicial First Class Magistrate Court, Chavakkad, by which an
application was dismissed, stating that this Court stayed the
proceedings by order dated 10.5.2019 in Crl.MC.1588/2019.
Today, Crl.M.C. No.1588/2019 is allowed and the proceedings
against the petitioner are quashed. In the light of the same,
Annexure-4 order can be set aside. Therefore, this Criminal
Miscellaneous Case is allowed. Annexure-4 order is quashed.
