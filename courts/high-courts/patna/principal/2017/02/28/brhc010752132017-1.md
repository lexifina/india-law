3 28-02-2017 This contempt petition has been filed by the mother of a
convict seeking premature release in terms of Section 432 of the
Code of Criminal Procedure.
2. A counter affidavit has been filed today in which it
has been stated that on 17.02.2017 the State Sentence Remission
Board took a decision to recommend the release of the petitioner’s
son, namely, Shiv Gope.

Patna High Court MJC No.246 of 2017 (3) dt.28-02-2017
2/2
3. Mr. P.K. Verma, learned AAG 3 submits that he has
instruction that the person would be released in about a week’s
time.
4. Be that as it may, in view of the order passed by the
State Sentence Remission Board, this MJC petition for all intents
and purposes has become infructuous and it is accordingly
disposed of.
