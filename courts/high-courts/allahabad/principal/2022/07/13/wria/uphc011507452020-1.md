# Allahabad High Court, WRIA/12300/2020, 2022-07-13

Court No. - 34
Case :- WRIT - A No. - 12300 of 2020
Petitioner :- Smt Ranjana Gond
Respondent :- State Of U.P. And 5 Others
Counsel for Petitioner :- Gopal Das Srivastava
Counsel for Respondent :- C.S.C.,Durga Singh,Mohd Shere Ali,Shailesh
Kumar Shukla
Hon'ble Neeraj Tiwari,J.
Ref:-Civil Misc. Withdrawal Application No. -8 of 2021
Case was called out. Learned counsel for both sides are not
present whereas learned Standing Counsel for the State-respondents is present.
In the present writ petition, withdrawal application was filed by
the petitioner to withdraw the present petition.
Learned counsel for the petitioner requested the Court to
withdraw the withdrawal application by filing appropriate
application, which was accepted by this Court vide order dated
16.03.2022. Again, case was listed on 22.04.2022, petitioner
was granted time to file withdrawal application as directed by
this Court vide order dated 16.03.2022 failing which
withdrawal application shall be allowed and petition be
dismissed, but no such application has been filed.
Accordingly, the withdrawal application is allowed and
consequently, the writ petition is dismissed as withdrawn.
