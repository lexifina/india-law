# Allahabad High Court, WRIC/770/2018, 2018-01-09

Court No. - 5
Case :- WRIT - C No. - 770 of 2018
Petitioner :- Riyasat Ali
Respondent :- State Of U.P. & 7 Others
Counsel for Petitioner :- Narendra Singh
Counsel for Respondent :- C.S.C.
Hon'ble Pankaj Naqvi,J.
It is not disputed by learned counsel for the petitioner that
for the same cause of action, petitioner had approached
this Court by means of Writ C No.2567/2017, which came
to be disposed off on 19.1.2017.
If that be so, a 2nd petition, for the same cause of action,
is liable to be dismissed as not maintainable.
The writ petition is dismissed as not maintainable.
Order Date :- 9.1.2018
