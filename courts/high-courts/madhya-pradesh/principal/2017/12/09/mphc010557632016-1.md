# High Court of Madhya Pradesh, MCC/2846/2016, 2017-12-09

THE HIGH COURT OF MADHYA PRADESH
MCC-2846-2016
(REGIONAL MANAGER U.P. STATE ROAD TRANSPORT CORPORATION Vs SMT. UMA
DWIVEDI)
Jabalpur, Dated : 09-12-2017
Shri Dharmendra Soni, counsel for the applicant.
Heard on I.A.No.15991/2016, an application for
condonation of delay.
For the reasons mentioned in the application I.A.No.
15991/2016, the same is allowed and the delay in filing the
application is hereby condoned.
The present application has been filed for restoration of
M.A.No. 1912/2013 which has been dismissed for non-compliance of order dated 12.05.2015.
Considering the averments made in the application, which
is duly supported by an affidavit, I find that sufficient cause is
shown for restoration of the case.
Accordingly, the MCC is allowed. M.A.No. 1912/2013 is
restored to its original number.
Let a copy of this order be kept in the record of M.A.No.
1912/2013.
(NANDITA DUBEY)
