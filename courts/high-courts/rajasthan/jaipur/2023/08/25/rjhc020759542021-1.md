HON'BLE MR. JUSTICE PANKAJ BHANDARI
Order
25/08/2023
1. The matter comes up on misc. application seeking correction
in the name of counsel for complainant in order dated 10.11.2021
passed in S.B. Criminal Misc. Petition No.6004/2021 titled as
Suresh @ Tinda vs State & Anr.
2. It is mentioned in the application that name of counsel for
complainant is mentioned as ‘Mr. Mohd. Amar Joshi’ instead of
‘Mr. Mohd. Ammar Zaidi’.
3. Looking to the typographical error, name of ‘Mr. Mohd. Amar
Joshi’ be now read as ‘Mr. Mohd. Ammar Zaidi’ in order dated
10.11.2021 passed in S.B. Criminal Misc. Petition No.6004/2021.

(2 of 2) [CRLMA-366/2021]
4. Criminal Misc. Application No.366/2021 is accordingly,
allowed.
(PANKAJ BHANDARI),J
