# High Court of Madhya Pradesh, MCC/617/2014, 2014-06-20

M.C.C.No.617/2014
1
Pawan Industries Vs. The Additional Commissioner
20/06/2014
Shri R.N.Roy, learned counsel for the applicant.
Shri Sanjay Lal, learned counsel for the respondent on
advance notice.
This application has been filed for restoration of
W.P.No.734/2012, which was dismissed for want of prosecution
on 3.3.2014.
Keeping in view the reasons indicated in the application for
restoration, which is supported by the affidavit of the counsel
himself and finding the reasons given in the application to be
bona-fide, this application is allowed. W.P.No.734/2012 is
restored to it's original file. It be placed for orders before the
appropriate bench.
With the aforesaid, this application stands allowed and
disposed of.
(Rajendra Menon) (Sushil Kumar Gupta)
