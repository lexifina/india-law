 ORAL ORDER
Learned advocate for the applicants seeks
permission to withdraw present application with a liberty to file
discharge application, since earlier discharge application was
not decided on its merits and it was withdrawn because the
applicants intended to file present proceedings before this
Court.
Learned APP objects permission for filing discharge
application. The objection is rejected as earlier withdrawal of
discharge application was not decided on its merits.
In view of above, the petitioner is permitted to file
discharge application before the competent Court. It is clarified
that this Court has not examined the merits of the present
application and earlier withdrawal of discharge application will
not come in the way of the applicants at the time of hearing
fresh discharge application, if filed within two weeks from
today. The application stands disposed of as withdrawn with
above liberty. Direct service is permitted.
(S.H.VORA, J)
