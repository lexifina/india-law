5./24.02.2014 Heard the parties.
The order dated 16/07/2009, passed in Sadar P.S. Case No. 61 of
2009, G.R No. 199 of 2009, under which cognizance of the offences
punishable under section 341,323,324,452,380,498/34 of the Indian Penal
Code has been taken against the petitioner is being sought to be quashed on
the ground that earlier to lodgment of this case, petitioners had also lodged
a complaint case and only after lodgment of the case, this case has been
lodged after five months of the alleged occurrence and, therefore, it can be
said that in retaliation this case has been lodged and, thereby, it can be said
to be a case of malicious prosecution.
This is not the stage to determine as to whether actually
occurrence took place or in retaliation this false case has been lodged. This
can be determined only during trial and, therefore, order taking cognizance
never warrants to be quashed. Hence, this application stands dismissed.
 Notwithstanding the fact that this application got dismissed, the
petitioners would be at liberty to raise all the points, which have raised in
this application at an appropriate stage.
(R.R.Prasad, J)
