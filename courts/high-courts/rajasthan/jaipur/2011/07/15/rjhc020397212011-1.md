# High Court of Rajasthan, CRLMA/147/2011, 2011-07-15

1
IN THE HIGH COURT OF JUDICATURE FOR RAJASTHAN
BENCH AT JAIPUR
S.B. CR. MISC. APPLICATION NO.147/2011
IN
S.B. CR. MISC. BAIL APPL. NO.6335/2011
Rohtash & Ors. Vs. State
Date of order : 15/7/2011.
HON'BLE MR.JUSTICE MOHAMMAD RAFIQ
Shri Mohd. Iqbal Khan for the appellant.
Shri Mahendra Meena, PP.
******
Application has been filed seeking correction in the
name of applicant no.2 and consequential correction in
the bail order dated 8.7.2011.
It is contended that due to oversight, the name of
applicant which actually is Bhallu Ram was in the bail
application described as Bhallur and accordingly in the
bail order also, same name was indicated. Owing to that
reason, the applicant could not be released on bail.
The application is not opposed by learned PP.
In the circumstances, the name of applicant no.2 in
bail application is ordered to be corrected as Bhallu Ram
instead of Bhallur Ram and consequently in bail order
also, his name shall be read as Bhallu Ram S/o Shri Ram.
The application is accordingly allowed.
 (MOHAMMAD RAFIQ), J.
RS/
