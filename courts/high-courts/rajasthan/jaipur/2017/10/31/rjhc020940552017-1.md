Judgment / Order
31/10/2017
1. Heard on application filed for modification of order dated
07.09.2017.
2. It is contended that in para four of the order, Delhi High
Court has been mentioned, whereas it should be Delhi family
Court. Typographical error is rectified. In para four instead of High
Court, the same be read as Delhi family Court.
3. It is also contended that in para five, it is mentioned that
respondent No.2 was not given response in the house, instead of

(2 of 2)
[CRLMA-553/2017]
response, word privacy ought to be inserted. Considering the
contentions in para five of the order dated 07.09.2017, word
response is substituted by the word privacy.
4. The application is, accordingly, allowed.
