# High Court of Orissa, WP(C)/9514/2020, 2020-07-03

03. 03.07.2020 This matter is taken up through video
conferencing mode.
 Mr. S.D. Routray, learned counsel for the
petitioner submits that in the meantime several
developments are taken place which are necessary to
be brought to the notice of this Court. In such
background, he wants to withdraw this writ
application with liberty to file a better petition. To that
effect, he files a memo in Court today. The same is
taken on record.
 Considering the submissions made, this writ
application is disposed of as withdrawn with the above
liberty.
