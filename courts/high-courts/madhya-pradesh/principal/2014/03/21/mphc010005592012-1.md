# High Court of Madhya Pradesh, CONC/10/2012, 2014-03-21

Conc. No. 10/2012.
21/03/2014.
Shri Sushil Agrawal, Advocate for the petitioners.
Shri L.S. Singh, Senior Advocate with Shri Lav Kush Mishra,
Advocate for the respondent.
Making a complaint that an interlocutory order passed in First
Appeal No.175/2011 has not been complied with, this application has
been filed for initiating action for contempt. Order dated 31.3.2011 is an
interlocutory order passed in the matter of deciding an application under
Order 39 Rules 1 and 2 of CPC and First Appeal No.175/2011 has
already been decided and it has been dismissed.
In view of the order Annexure-R/3 already passed by this Court on
10.2.2012, no further action is required to be taken, application is,
therefore, dismissed.
 (Rajendra Menon) (Smt. Vimla Jain)
