Order
29/08/2022

(2 of 2) [CCP-25/2022]
This contempt petition has been filed by the petitioner
alleging non-compliance of the order dated 12.01.2021 passed by
this Court.
At the very outset, learned counsel appearing for the
respondents submits that this contempt petition has been filed for
breach of the interim order dated 12.01.2021, but the said interim
order dated 12.01.2021 has been vacated by this Court vide order
dated 17.08.2022. Therefore, this contempt petition has been
rendered infructuous.
On the other hand, learned counsel for the petitioner
submits that the petitioner is going to file a D.B. Special Appeal
against the order dated 17.08.2022 vide which the ex-parte
interim order dated 12.01.2021 has been vacated.
In view of the above, the present contempt petition
stands disposed of. Notices stand discharged.
However, the petitioner will be at liberty to file an
application for revival of this contempt petition if occasion so
arises.
(PRAKASH GUPTA),J
