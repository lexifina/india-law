Order
21/05/2024
1. Instant miscellaneous application has been filed by
petitioners-applicants, seeking correction in the order dated
01.05.2024 passed in S.B. Criminal Miscellaneous (Petition)
No.2775/2022 by this Court, wherein in Para Nos.1 & 7, reference
of FIR number has been mentioned as “51/2021” instead of
“51/2022”.

[2024:RJ-JP:24185] (2 of 2) [CRLMA-225/2024]
2. Heard learned counsel for petitioners.
3. It appears that in subject matter of the petition, reference of
FIR number was mentioned as “51/2021”, due to which in Para
Nos.1 & 7 of the order dated 01.05.2024, FIR number has been
mentioned as “51/2021”, while in fact it should be “51/2022”,
which is error, occurred inadvertently.
4. Amended cause title, filed by the counsel for petitioners, is
taken on record.
5. In view of above, in the order dated 01.05.2024, FIR number
as mentioned in Para Nos.1 & 7 i.e. “51/2021” be corrected in red
ink as “51/2022” and the correction made in the original order be
upload online showing asterisk (*) mark in the order that
reference of FIR number has been corrected subsequently. Rest
part of the order shall remain as such.
6. Accordingly, the misc. application stands disposed of.
(SUDESH BANSAL), J
