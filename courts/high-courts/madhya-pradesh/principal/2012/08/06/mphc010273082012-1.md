# High Court of Madhya Pradesh, WP/9789/2012, 2012-08-06

W.P. No. 9789/2012
06.08.2012
 Shri Anoop Nair, Advocate for the petitioner.
Shri S.M. Lal, Government Advocate for the respondent/
State on advance copy.
Learned counsel for the petitioner submits that he would
like to withdraw the petition and would like to file an appeal
under Section 44 of the M.P. Land Revenue Code before the
Commissioner against the order dated 31.01.2012 passed by
S.D.M. Teekamgarh (annexure P/1) which is impugned in the
writ petition.
This prayer is accepted and this writ petition is dismissed
as withdrawn with liberty to file appeal before the
Commissioner. However, it is made clear that if the appeal is
filed on or before 31.10.2012, the same be decided on its own
merits without entering into the question of limitation.
With the aforesaid observations, this petition is dismissed
as withdrawn with the aforesaid liberty.
 (A.K. Shrivastava)
