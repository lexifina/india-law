ORAL ORDER
4 03-04-2019 Heard learned counsel for the petitioner.
This application has been filed for restoration of
M.A.No. 731of 2012 which stood dismissed for non-compliance
of order dated 16.12.2015.
Counsel for the petitioner submits that in view of the
order dated 24.01.2017 passed in M.A. No.419 of 2013 wherein
the judgment has been treated as Award, there is no need to file
Award in the present case.
Considering the aforesaid submission and the reasons
mentioned in the restoration petition, M.A.No. 731 of 2012 is
restored to its original file and number.
Accordingly, this application stands disposed of.
