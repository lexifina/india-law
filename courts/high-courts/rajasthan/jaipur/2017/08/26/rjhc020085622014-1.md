HON'BLE MR. JUSTICE M.N.BHANDARI
Order
26/08/2017
 This contempt petition has been filed alleging non-compliance of the order of this court dated 30th January, 2006
passed in a civil first appeal. The contempt would not lie in the
regular first appeal if injunction has been granted, rather, it would
be under Order 39 Rule 2A CPC.
Thus while dismissing the contempt petition, a liberty is
given to maintain an application under Order 39 Rule 2A CPC. If
issue of delay is raised, the petitioner would be at liberty to satisfy
it in reference to the pendency of this contempt petition from the
year 2014 but for the period prior to it, it would be independent to
it.
(MN BHANDARI) J.
