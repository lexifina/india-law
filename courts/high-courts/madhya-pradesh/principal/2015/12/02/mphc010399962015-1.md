# High Court of Madhya Pradesh, MCC/2393/2015, 2015-12-02

MCC-2393-2015
(UMA SHANKER YADAV Vs THE STATE OF MADHYA PRADESH)
02-12-2015
Shri Rakesh Singh, learned counsel for the applicant.
This application has been filed for restoration of WPS
5488/2005, which was dismissed for non compliance of
peremptory order passed. There being some delay in
filing of this application for restoration, I.A.
No.10774/2015 has been filed. Reason for the delay is
attributed to some lapse in the office of the counsel and
the application is supported by affidavit of the Clerk of
counsel.
Finding the same to be bonafide, both the applications
are allowed. Condoning the delay in filing the restoration
application, the restoration application itself is allowed.
WPS 5488/2005 is restored to its original file. It be
placed for orders before an appropriate Bench.
Application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
