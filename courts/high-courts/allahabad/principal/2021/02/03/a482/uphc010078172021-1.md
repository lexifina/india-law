# Allahabad High Court, A482/1859/2021, 2021-02-03

Court No. - 89
Case :- APPLICATION U/S 482 No. - 1859 of 2021
Applicant :- Hashin Khan
Opposite Party :- State of U.P. and Another
Counsel for Applicant :- Mushir Khan
Counsel for Opposite Party :- G.A.
Hon'ble Rajeev Misra,J.
Ref: Correction Application
Heard Mr. Mushir Khan, learned counsel for applicant and
learned A.G.A. for State.
This correction application has been filed by applicant seeking
correction in the order dated 25.1.2021. Learned counsel for
applicant contends that in the second paragraph of order dated
25.1.2021, description of court has inadvertently been
transcribed as 'Judicial Magistrate, Bhognipur' whereas the
correct description of court is "Chief Judicial Magistrate,
Farrukhabad". He therefore, contends that aforesaid mistake
occurring in order dated 25.1.2021, be corrected accordingly.
Prayer made is bonafide.
Accordingly, in place of description 'Judicial Magistrate,
Bhognipur' as occurring in second paragraph of order dated
25.1.2021, the description "Chief Judicial Magistrate,
Farrukhabad" shall be read.
This correction shall form part of earlier order dated 25.1.2021.
With the aforesaid direction, present correction application is
finally disposed of.
Order Date :- 3.2.2021
Arshad
