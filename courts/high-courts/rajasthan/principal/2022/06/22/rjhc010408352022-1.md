Order
22/06/2022
The matter comes up on an application for correction of the
order dated 21.06.2022 passed in S.B. Criminal Misc. Bail
Application No.8084/2022.
It has been submitted that the number of the FIR in the
order has been mentioned as 293/2022 whereas the same ought
to have been 293/2020.
In view of the submission made, the application is allowed. It
is clarified that the FIR number in the order dated 21.06.2022
shall be read as FIR No.293/2020.
