2. 17.1.2012 Heard learned counsel for the petitioner and
learned counsel for the State.
This application has been filed for quashing the
order dated 19.11.2011 passed by the Sub Divisional
Magistrate, Kishanganj in connection with Case No. 569M
of 2011 whereby notice has been issued against the
petitioner and other persons under Section 110 of the Code
of Criminal Procedure.
At this stage this Court does not want to
interfere with the impugned order with a direction to the
petitioner to file his show-cause. If the order is passed
against the petitioner, he will be at liberty to challenge the
same before appropriate forum.
With the aforesaid observations and directions
this application is disposed of.
 Vinay/ ( Shivaji Pandey, J.)
