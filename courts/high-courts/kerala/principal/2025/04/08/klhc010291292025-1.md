ORDER
When this bail application came up for consideration, the
Public Prosecutor submitted that, as per the instruction dated
08.04.2025, no case is registered against the petitioner at
Muvattupuzha Police Station in connection with the averments
in this bail application. If that is the case no further order is
necessary.
It is made clear that if any case is registered against the
petitioner in connection with the averments in this bail
application with non-bailable offence, two weeks prior notice
should be given to the petitioner before taking any coercive
steps.
With the above observation, this bail application is
disposed of.
