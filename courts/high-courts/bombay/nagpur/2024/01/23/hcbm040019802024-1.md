2. The order dated 23.10.2023 passed below

Judicial Magistrate First Class (Court No. 2), Digras,

already file a revision application against the order of
granting maintenance to the respondent and also moved
an application for stay on execution of the order of
maintenance. The said revision and stay application are
pending before the learned Additional Sessions Judge,
Darwaha, District Yavatmal. It is contended that in
execution proceeding, the respondent has moved an
