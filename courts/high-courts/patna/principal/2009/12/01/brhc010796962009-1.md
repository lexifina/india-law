# Patna High Court, MJC/3424/2009, 2009-12-01

IN THE HIGH COURT OF JUDICATURE AT PATNA
MJC No.3424 of 2009
THE STATE OF BIHAR & ORS.
Versus
RUCHI KUMARI @ RACHI SINHA @ N
-----------
3/ 01.12.2009 Heard counsel for the State.
This application has been filed by the State for
modification of order dated 03.08.2007. The ground which has
been taken for modification of order dated 03.08.2007 shows
that the state is aggrieved by the said order and the correctness
of order is being challenged. For that, instead of filing
modification application the State can file L.P.A.
This application is dismissed.

 Sanjeet/
 (Mridula Mishra, J.)
