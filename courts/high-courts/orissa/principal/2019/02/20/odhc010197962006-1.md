# High Court of Orissa, WP(C)/15962/2006, 2019-02-20

04. 20.02.2019 Heard learned counsel for the petitioner.
Since the petitioner files this application
assailing the order dated 22.05.2003 passed under
Section 7-A of the EPF and MP Act, 1952, this Court is
not inclined to entertain this application. However,
liberty is granted to the petitioner to challenge the said
order before the appropriate forum in accordance with
law, if it so advised.
With the aforesaid liberty, the writ petition
stands disposed of.
