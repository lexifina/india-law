# High Court of Madhya Pradesh, MCC/173/2014, 2014-02-07

MCC No.173/2014
7.2.2014
Counsel for the parties present.
This application has been filed for restoration of
W.P.No. 10175/2012 which has been dismissed in view of
the peremptory order passed on 1/3/2013.
There being delay in filing the application,
I.A.2016/2014 has been filed seeking condonation of delay.
The applications are supported by affidavit of the counsel
himself and finding the same to be bonafide, Both the
applications are allowed. Condoning the delay in filing the
application for restoration, the restoration application itself
is allowed. W.P.No.10175/2012 is restored to its original file.
It be placed for orders before appropriate bench.
Applications stands allowed and disposed of.
(Rajendra Menon) (A.K.Sharma)
Judge Judge
