ORAL ORDER
2 06-03-2013 Heard.
This is an application seeking restoration of Cr.
Misc. No. 29219/2010 under section 438 of the Code of
Criminal Procedure which was dismissed for improper
compliance of earlier order dated 11.08.2010. in connection
with Complaint Case No. 1045/2009 pending before Chief
Judicial Magistrate, Muzaffarpur.
Finding no reason to restore this application to
its original file. Accordingly, this restoration application stand
dismissed. However, petitioner, if so wishes, and mandatory
requirement for an application under section 438 of Code of
Criminal Procedure are still available, may filed fresh
application.
Rajeev/- (Akhilesh Chandra, J)
