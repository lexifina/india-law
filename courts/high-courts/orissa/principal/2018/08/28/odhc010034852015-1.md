# High Court of Orissa, WP(C)/19254/2015, 2018-08-28

04. 28.08.2018 Learned counsel for the petitioner seeks permission to
withdraw the writ petition. A memo to that effect has been filed
indicating therein that the petitioner may be permitted to
withdraw the same with liberty to file afresh if any cause of
action survives. The memo is taken on record.
 Permission is granted.
 Learned counsel for the opposite parties does not
object to the same.
 Accordingly, the writ petition stands dismissed as
withdrawn with liberty to the petitioner to file afresh if any
cause of action survives.
