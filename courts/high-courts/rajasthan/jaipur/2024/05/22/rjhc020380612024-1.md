Order
22/05/2024
1. This is an application seeking correction in the name of the
counsel for the petitioner in order dated 08.04.2024 passed in
SBCWP No.5191/2024.
2. Due to typographical error in the order dated 08.04.2024
name of counsel for the petitioner ‘Mr. Dheeraj Verma’ was
mentioned instead of ‘Mr. Rahmat Ali‘.
3. For the reasons stated therein, the misc. application stands
allowed. In the order dated 08.04.2024, name of ‘Mr. Rahmat Ali’
be read instead of ‘Mr. Dheeraj Verma’.
4. This order shall be treated as an integral part of the order
dated 08.04.2024.
(AVNEESH JHINGAN), J
