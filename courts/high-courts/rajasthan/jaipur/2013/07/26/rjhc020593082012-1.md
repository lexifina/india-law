# High Court of Rajasthan, CW/4225/2012, 2013-07-26

HON'BLE MR. JUSTICE M.N. BHANDARI
None present for petitioner
Mr. Shantanu Kumawat for Mr. S.N. Kumawat, AAG, for

***
By this petition, a prayer is made to allow the petitioner to
participate in the process of selection for the post of Teacher
Gr.II.
Learned counsel for respondents submits that petitioner
was not not only allowed to appear in the selection test but
result thereupon was also declared. The grievance of the
petitioner is regarding non-declaration of cut-off marks for
physically handicapped persons. It is specifically for the
category of OL/BL i.e. orthopaedic handicapped persons.
It is stated that separate cut-off marks are required to be
declared only when number of candidates desired to fill up
reserve seats are not found while arranging list vertically for the
reason that reservation to the physically handicapped person is
horizontal in nature. Thus, if number of candidates required to

2
be given horizontal reservation are found while drawing vertical
list, reservation gets satisfied. While declaring result for OL/BL,
the aforesaid was clearly mentioned indicating that persons to
the category to which petitioner belongs were available in the
main list. In view of the position aforesaid, when number of
seats reserved for physically handicapped person in OL/BL
category were filled while drawing main list arranging it
vertically then it is not required separate cut-off marks. In fact,
the separate cut-off for horizontal reservation is given only
when number of candidates were not available while drawing
list vertically.
In view of the above, I do not find any merit in the writ
petition, the same is dismissed. Stay application is also
dismissed.
 [M.N.BHANDARI], J.
