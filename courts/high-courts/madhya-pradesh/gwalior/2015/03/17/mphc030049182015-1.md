# High Court of Madhya Pradesh, MCRC/2192/2015, 2015-03-17

1
M.Cr.C.No.2192/2015
(Pran Singh Vs. State of M.P.)
17/03/2015
Shri Deependra Singh Kushwaha, counsel for
applicant-Pran Singh.
Shri A.S.Yadav, Panel Lawyer for the
respondent/State.
Heard on this first application for bail under Section
439 of the Code of Criminal Procedure filed on behalf of
applicant-Pran Singh.
After arguing for some time, in response to some
queries of the Court, learned counsel for the applicant prays
for withdrawal of this application.
Consequently, this first application for bail under
Section 439 of the Code of Criminal Procedure filed on
behalf of applicant-Pran Singh is dismissed as withdrawn.
 (C.V.Sirpurkar)
