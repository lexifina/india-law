# Allahabad High Court, A482/15283/2023, 2023-05-05

Court No. - 66
Case :- APPLICATION U/S 482 No. - 15283 of 2023
Applicant :- Shiv Bachan Pandey
Opposite Party :- State Of U.P. And 8 Others
Counsel for Applicant :- Yogesh Kumar Tripathi
Counsel for Opposite Party :- G.A.
Hon'ble Vivek Varma,J.
At the outset, Sri Rupak Chaubey, learned AGA has raised a
preliminary objection that against the order impugned dated
16.02.2023, the applicant has a remedy to file revision.
At this stage, counsel for the applicant prays for withdrawal of
the instant application with liberty to file a revision.
Accordingly, the instant application is dismissed as withdrawn
with the aforesaid liberty.
Let the certified copy of the documents, if any, be returned to
the counsel for the applicant as per the rules of the Court.
Order Date :- 5.5.2023
Aditya

SACHIN MISHRA
