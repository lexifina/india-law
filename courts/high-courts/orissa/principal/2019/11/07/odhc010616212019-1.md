# High Court of Orissa, WP(C)/21098/2019, 2019-11-07

2.
Ayas
7.11.2019 Heard learned counsel for the petitioners.
 Date of action involving the order vide Annexure-3
having been expired and the review notice vide Annexure-3
having been acted upon, this Court finds no scope for
entertaining the request of the petitioner at this stage. It
appears, being apprehensive of some danger the petitioner has
filed this Writ Petition but having no cause of action presently.
This Writ Petition is not maintainable at this stage, which is
dismissed accordingly. However in the event of any future
cause of action depending upon the result of the action
pursuant to the VHF Message notice vide Annexure-3, the
petitioner will be at liberty to file a fresh writ petition.
