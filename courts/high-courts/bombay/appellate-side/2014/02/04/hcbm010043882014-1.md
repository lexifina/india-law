4. We dispose of the Petition by passing the following order :-
ORDER
(i) We direct the Petitioner to appear before the first
Respondent on Tuesday i.e. 11th February, 2014 at 11.00
am. The Petitioner shall produce a copy of application
dated 28th October, 2013 as well as an authenticated
copy of this order before the first Respondent;
(ii) If application is already disposed of, a copy of the order
be provided to the Petitioner. If application is not
disposed of, the first Respondent shall make an
endeavour to decide the application within a period of
four weeks from 11th February, 2014;
(iii) We make it clear that we have made no adjudication on
the merits of the application made by the Petitioner;
(iv) Petition is disposed of on above terms;
(v) All concerned to act upon the authenticated copy of this
order.
