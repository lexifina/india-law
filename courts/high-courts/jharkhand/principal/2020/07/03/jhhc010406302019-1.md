 08/Dated: 03/07/2020
After some argument, learned counsel for the petitioner, Md.
Asadul Haque seeks permission to withdraw this bail application as
petitioner has renewed the instant regular bail application against the
same impugned order dated 03.04.2019, which has already been
considered by this Court while passing order of rejection on
08.07.2019 in B.A. No. 4430/2019.
Learned counsel for the State, Mr. Suchendra Prasad,
Additional Public Prosecutor has no objection.
After hearing the learned counsel for the parties, learned
counsel for the petitioner is allowed to withdraw this bail
application.
Accordingly, this bail application is dismissed as withdrawn.
 (Kailash Prasad Deo, J.)
