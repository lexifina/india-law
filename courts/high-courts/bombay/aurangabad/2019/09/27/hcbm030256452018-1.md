PER COURT :
1] We find no merit in the Writ Petition for the reason by the
impugned order passed by the Maharashtra Administrative Tribunal, only
direction given is to interview respondent No.1.
2] Suffice it to state there is no direction to the manner in which
the select list has to be prepared. The select list would obviously have
