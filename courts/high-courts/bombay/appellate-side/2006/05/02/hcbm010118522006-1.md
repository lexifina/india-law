# Bombay High Court, APPLN/1400/2006, 2006-05-02

IN THE HIGH COURT OF JUDICATURE AT BOMBAY
 CRIMINAL APPELLATE JURISDICTION
 CRIMINAL APPLICATION NO. 1400 OF 2006
 Mahadev Kandu Gaikwad. ...Applicant
 V/s.
 State Govt.of Maharashtra. ...Respondent
 Shri Vilas Mali for Applicant.
 Shri R.Y. Mirza, APP for the State.
 CORAM : V.M. KANADE, J.
 DATED : MAY 2, 2006
 P.C. :-
 1. This is an application for transferring the
 matter which is pending in the Court of Additional
 District Judge, Nagpur to any competent court in Mumbai.
 2. In my view, I can not entertain this application
 as the application will have to be filed before the
 Nagpur Bench of this Court. Application, therefore, is
 not pressed and is allowed to be withdrawn.
 3. Liberty is granted to the applicant to file this
 application before Nagpur Bench of this Court. Liberty
 to apply in vacation.
 . Certified copy expedited.
 (V.M. Kanade, J.)
