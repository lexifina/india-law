ORAL ORDER
2. 11-10-2017 Heard Sri Dhirendra Nath Jha, learned counsel for the
petitioner and learned Addl. Public Prosecutor.
The present petition has been filed with a prayer to
modify an order dated 01-07-2017 passed in Cr. Misc. No.
21847 of 2017. By the said order, while granting bail to the
petitioner, this Court had imposed certain conditions. The said
order was passed on a petition filed for grant of anticipatory bail
under Section 438 of the Code of Criminal Procedure, 1973 (for
short “Cr.P.C.”).
Once, an order was passed by this Court, there is no
reason to pass any order for altering any condition imposed by
this Court. Had it been a case of clerical error or typographical

of the Cr.P.C., there is no question to pass any order, which
