# High Court of Madhya Pradesh, MCRC/11539/2017, 2017-07-14

MCRC-11539-2017
(MOHD NOORUDDIN Vs THE STATE OF MADHYA PRADESH)
14-07-2017
Shri S.N. Khan, learned counsel for the applicant.
Shri Anubhav Jain, learned PL for the respondent/State.
Seeking correction of the crime number in the order dated
05.07.2017 passed in M.Cr.C.No.6908/2017, this application has
been filed along with FIR.
As per the FIR correct crime number is 312/2013 registered
at Police Station Omti, District Jabalpur.
Considering the aforesaid, crime no.312/2013 be read in
place of crime no.313/2013 in the bail order dated 05.07.2017
passed in M.Cr.C.No.6908/2017.
This order be conjointly read with the order dated
05.07.2017 passed in M.Cr.C.No.6908/2017.
Accordingly, this application is disposed of.
C.C. as per rules.
(J.K. MAHESHWARI)
