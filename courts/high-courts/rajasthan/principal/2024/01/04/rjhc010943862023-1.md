Order
04/01/2024
An application has been filed for correction of the name of
petitioner No.1 in the order dated 13.10.2023 passed in S.B. Civil
Writ Petition No.15732/2023.
Learned counsel for the applicant-petitioner submits that in
the order dated 13.10.2023, because of typographical error, the
name of petitioner No.1 has been shown as ‘Baljeet Singh Butter’,
whereas it should have been ‘Baltej Singh Butter’.
For the reasons stated in the application, the same is allowed
and the name of petitioner No.1 in the order dated 13.10.2023 be
now read as ‘Baltej Singh Butter’ instead of Baljeet Singh Butter’.
(VINIT KUMAR MATHUR),J
