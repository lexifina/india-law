# High Court of Madhya Pradesh, MCC/469/2016, 2016-06-24

1
M.C.C.No.469/2016
24/06/2016
Shri Vaibhav Bhagwat, learned Counsel for the
applicant.
Heard on IA No. 5082/2016 which is an application for
condonation of delay.
The main application is filed for restoration of F.A.
No.366/2005 which was dismissed in compliance of common
conditional order dt. 20.2.2014.
After dismissal of the appeal, the appellant did not know
about the dismissal and, therefore, no action could be taken by
him.
Accordingly, this application is filed by delay of 852
days.
On considering the grounds stated in the application
which is supported by an affidavit, the application is allowed.
The delay of 852 days in filing this application is condoned.
Heard on main application under Order 41 Rule 19 of
CPC.
On considering the grounds stated in this main
application which is also supported by an affidavit, the
application is allowed.
FA No. 366/2005 is restored to its original number.
Office is directed to list before the appropriate Bench.
(ALOK VERMA)
 JUDGE

M.Jilla.
