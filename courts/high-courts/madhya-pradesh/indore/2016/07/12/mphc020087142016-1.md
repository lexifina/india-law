# High Court of Madhya Pradesh, MCRC/3142/2016, 2016-07-12

MCRC-3142-2016
(GHANSHYAM Vs THE STATE OF MADHYA PRADESH)
12-07-2016
Shri Avinash Sirpurkar, learned counsel for the
applicant.
Shri Deepak Rawal, learned public prosecutor for the
respondent-State.
Considering the fact that the respondent-State has
also filed an application for grant of leave to appeal
vide MCRC No.5512/2016. We permit the learned
counsel for the applicant for withdrawal of this
application with liberty to file an application under-Section 301(2) of Code of Criminal Procedure, 1973 in
pending application for grant of leave to appeal filed
by the respondent-State to assist the learned public
prosecutor.
With the aforesaid liberty, the MCRC No.3142/2016 is
permitted to be withdrawn.
Certified copy as per rules.
(P.K. JAISWAL)
