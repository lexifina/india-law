# High Court of Madhya Pradesh, MCRC/18532/2014, 2014-12-08

M.Cr.C. No.18532/2014
08.12.2014
 Shri D.S.Thakur, Advocate for the petitioner.
 Shri Puneet Shroti, Panel Lawyer for the
respondents/State.
 The issue of maintainability has been raised to the effect
that without taking recourse to file an application before the
trial Court the applicant has directly come before this Court.
 After hearing learned counsel for the applicant and
facing such difficulty he seeks withdrawal of the petition with
liberty to apply to the trial Court, if so advised.
 Prayer is not opposed, therefore, the same is allowed.
 Petition is dismissed as withdrawn with the aforesaid
liberty.

 (J.K.Maheshwari)
 JUDGE
