RAJIV NARAIN RAINA, J.(Oral)
The petitioner is defendant No.2 in the suit from where the
present revision petition arises. The petitioner was proceeded ex parte on
October 10, 2012 by the order passed by the Civil Judge (Junior Division)
Jhajjar as none appeared for him. The case was posted for October 23, 2012
for ex parte consideration. The petitioner moved an application for setting
aside the order dated October 10, 2012 proceeding ex parte against him. The
application remained pending. The opposite party did not file reply to the
application. It appears that on October 17, 2013 the case was fixed for filing
reply of non-applicant plaintiff by way of last opportunity. On October 17,
2013 the reply was not filed despite adjournments taken. If the application
for setting aside the ex parte order was not contested by the opposite side it
should have been allowed. But the trial Court by order dated October 17,
2013 dismissed the application itself for the reason that last opportunity was
given to file reply but was not availed. When this order was read out in

The situation is rather funny to wit: Here is my application for
setting aside an ex parte order passed adverse to my interest, you keep
taking time and do not file a reply despite last opportunity granted, the
result is that my application is dismissed summarily for want of reply. This
is truly amazing exercise of jurisdiction. Anyhow, faced with the order, the
defendant No.2 filed an application under Order 9 Rule 13 CPC for setting
aside this order. The trial judge found no worth in it and has rejected the
same by the impugned order dated April 1, 2014 affirming the flawed order.
The certified copy of the order (P-6) records that it was announced in open
Court on April 1, 2013 but the date under the signatures of the trial Judge on
the same page is April 1, 2014. The Judge should have been careful when
signing the order.
Be that as it may, the reasons recorded in declining the application
for setting aside the ex parte order suffer from the tragic flaw noticed in the
order dated October 17, 2013 which dismissed the application for want of
reply. It is very sad that a Judge should have passed an order such as the one
dated October 17, 2013. It may be noted that on October 10, 2012 when the
precursor order was passed, defendant No.1 was ex parte and it was
defendant No.2 (petitioner) who was then proceeded against ex parte
because none appeared for him. But in the order dated October 10, 2012 as
placed before this Court (P-3) counsel's presence for defendant No.2 is
recorded (page 18 of the paper book). I therefore assume that the order
dated October 17, 2013 relates to defendant No.2 whose application was
