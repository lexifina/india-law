O R D E R
 This Criminal Original Petition has been filed to call for
the records relating to the case in Crime No.15 of 2014, on the file
of the first respondent / complainant and quash the same as against
the petitioner / Accused No.3.
2.The learned Government Advocate (Crl. Side) appearing for
the first respondent would submit that insofar as Crime No.15 of
2014 is concerned, investigation has been completed and the charge
sheet laid on 29.12.2016. But the same was not taken on file before
the concerned Court.
3.Recording the submission made by the learned Government
Advocate (Crl. Side), this Criminal Original Petition stands
dismissed. Consequently, connected miscellaneous petition is
closed.
