# High Court of Uttarakhand, WPSS/1587/2007, 2008-10-23

WPSS No. 1587 of 2007
MCC Recall/Restoration Application No. 1225 of 2008
CLMA Delay Condonation Application No. 7033 of 2008
Honíble P.C. Verma, J.
 Mr. I.P. Gairola, learned counsel for
the petitioner/applicant.
 Mr. H.M. Raturi, learned Standing
Counsel for the State of Uttarakhand /
respondents.
 Present applications have been filed
for delay in filing the recall/restoration
application as well as for recalling the
order dated 12.9.2008, whereby the writ
petition has been dismissed on the ground
of alternative remedy.
 Perused both the applications. No
good ground either for delay in filing the
recall application or for recalling the order
dated 12.9.2008 has been made.
 Being unsatisfied with the reasons
given for delay in filing the recall
application and for recalling the aforesaid
order, both the applications are dismissed.

(P.C. Verma, J.)
23.10.2008
Rathour
