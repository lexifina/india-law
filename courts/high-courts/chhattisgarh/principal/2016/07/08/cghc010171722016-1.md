Order On Board
08/07/2016
Counsel for the appellant wants to withdraw this appeal with
liberty to file fresh appeal. He further submits that Registry be directed
to return the the certified copy of the impugned judgment dated
30.11.2015 (Annexure A-1) which has been filed along with this appeal.
State counsel has no objection to the above proposition as put
forth by the counsel for the appellant.

Accordingly, the appeal is dismissed as withdrawn with the
aforesaid liberty. Registry is directed to return the certified copy of the
impugned order to counsel for the petitioner provided he supplies the
xerox copy of the same.
