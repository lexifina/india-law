PER COURT :-
1. Heard learned counsel Shri Ghayal for the petitioners.
2. Learned counsel submits that the petitioner ought to
have filed an application under Order 1 Rule X Sub Rule 2 of Civil
Procedure Code instead of filing an application for amendment under
Order VI Rule XVII of Civil Procedure Code. Learned counsel, thus,
seeks permission to withdraw this petition with liberty to file an
application under Order 1 Rule X of Civil Procedure Code before the
Trial Court.
3. Permission granted. Writ Petition is disposed of as
withdrawn with the liberty as prayed for.
4. In view of disposal of writ petition, pending civil
application also stands disposed of.
 ( V.K. JADHAV, J. )
