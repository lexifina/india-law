HON'BLE MR. JUSTICE KULDEEP MATHUR
 Order
18/12/2023
The instant misc. application has been filed seeking
correction in the order dated 15.12.2023 passed by this Court in
S.B. Criminal Misc. Bail Application No.12636/2023 as in first and
last paras of the said order, inadvertently, number of FIR has been
mentioned as ‘FIR No.166/2023’ instead of ‘FIR No.166/2022’.
The prayer for correction is justified.
Thus, the instant misc. application is allowed and it is
ordered that in the first para of the order dated 15.12.2023, the
number of FIR be read as ‘FIR No.166/2022’ in place of ‘FIR
No.166/2023’.
This order shall be treated as part and parcel of the order
dated 15.12.2023.
(KULDEEP MATHUR),J
