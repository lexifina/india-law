It has been brought to the notice
of this Court by the Government
Advocate, that there is already a pending
C-482 No. 325 of 2018, which has been
preferred by the present applicant for the
same cause of action, as such, the
compounding application should have
been filed in the already pending C-482
application.
In that eventuality, the present C-482 application and compounding
application would not be maintainable.
Thus, the same is, accordingly, dismissed
as withdrawn with a liberty to file a
compounding application in the aforesaid
pending C-482 application.
