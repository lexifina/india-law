# Allahabad High Court, A482/19846/2022, 2022-07-29

Court No. - 84
Case :- APPLICATION U/S 482 No. - 19846 of 2022
Applicant :- Bhuri Devi
Opposite Party :- State Of U.P. And 3 Others
Counsel for Applicant :- Subhash Chander Dwivedi
Counsel for Opposite Party :- G.A.
Hon'ble Syed Aftab Husain Rizvi,J.
Heard learned counsel for the applicant, learned A.G.A. for the
State and perused the record.
This application U/s 482 Cr.P.C. is filed to direct the Additional
Civil Judge (J.D.) Court No. 23, District Etah to decide the
application under section 156(3) Cr.P.C. under section 376D,
363, 504 and 506 IPC, P.S. Raja Ka Rampur, District Etah
expeditiously and if possible within stipulated period fixed by
this court.
Supplementary affidavit has been filed and the copy of the
application U/s 156(3) Cr.P.C. is annexed with it. It is
mentioned that the said application has been filed on 12.7.2022
while this application U/s 482 Cr.P.C. has been filed on
2.7.2022, so this application has been filed before filing of the
application U/s 156(3) Cr.P.C., hence, this application U/s 482
Cr.P.C. is premature and not maintainable.
The application U/s 482 Cr.P.C. is hereby dismissed being
premature. However, it is made clear that at a later stage if the
application U/s 156(3) Cr.P.C. remained un-disposed the
applicant may move fresh application U/s 482 Cr.P.C.
