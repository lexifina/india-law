PER COURT :-
1. Notice. Learned counsel for respondent No.2 waives notice.
Heard both sides.
2. The application is filed for setting aside the dismissal of FA
No.2771/2013 as against respondent No.1 for default. Learned counsel for
the appellant takes blame on himself. It appears that service report was to
the effect that the respondent No.1 owner is not residing on the address
given. Same address was given in the claim petition and in the claim
petition owner had appeared and had contested the matter by appointing
counsel. In view of the circumstance and as the original claimants
prosecuted the appeal on quantum, this Court holds that order of dismissal
needs to be set aside. Application is allowed. Order of dismissal is set aside
and matter as against respondent No.1 is restored to file.
3. Second prayer is made in same application for giving
permission to issue fresh notice in daily newspaper. In view of the report of
the baillif regarding service which is already mentioned.
4. Notice as against respondent No.1, is made returnable on
25.8.2014. Hamdast allowed.
 ( T.V. NALAWADE, J. )
