C ORAM : C.L.PANGARKAR, J.
DATED : 23rd November, 2009.

Heard learned Advocate Shri N.B.Kalwaghe
for petitioner. He has filed present application for
dispensing with the filing of certified copy as well as
translation of the said orders. The certified copies must
be filed. As far as translation is concerned, if it is found
that the translation is necessary for the purpose of
decision of the matter, the petitioner should give an
undertaking that if the Court directs to file such
translation, he will file it. If such an undertaking is
already given, no further undertaking is necessary.
Civil Application is disposed of.
