# Calcutta High Court, CO/1466/2023, 2023-05-08

08.05.2023
 733
 Naren
 Ct.237
 C.O. 1466 of 2023

 M/s. Swan Construction.
Vs.
 Awadhesh Kumar Agnihotri & Ors.
 Mr. Debjit Mukherjee … for the petitioner.
This revisional application has been filed with a
prayer for early disposal of an application under Order
XXXIX Rule 4 of the Code of Civil Procedure, 1908
pending since 16th August, 2019.
No notice is required to be served upon the
opposite party. Thus, service of notice is dispensed with.
Learned Civil Judge (Senior Division), 2nd Court,
Barasat is requested to dispose of the application under
Order XXXIX Rule 4 of the Code of Civil Procedure within
six weeks from the date of communication of this order.
Learned Advocate appearing for the petitioner is
at liberty to communicate the order to the learned Trial
Judge.
With the aforesaid observation, this revisional
application stands disposed of.
All parties shall act on the server copies of this
order duly downloaded from the official website of this
Hon’ble Court.

 (Bibhas Ranjan De, J.)
