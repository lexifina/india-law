 Order
18/12/2023
Learned counsel for respondents submits that the
respondents have reinstated the petitioner back in service. Thus,
the order dated 23.09.2022 of which contempt is alleged has been
complied with.
In view of the above, the contempt petition is disposed of.
Notices stand discharged.
Learned counsel for the petitioner submits that he will file an
application for clarification of the order dated 23.09.2022.
In case, application for clarification being filed and the same
is allowed, the petitioner would be at liberty to file application for
revival of this contempt petition.
