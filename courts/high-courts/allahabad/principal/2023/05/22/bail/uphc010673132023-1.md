# Allahabad High Court, BAIL/15879/2023, 2023-05-22

Neutral Citation No. - 2023:AHC:111837
Court No. - 76
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 15879
of 2023
Applicant :- Manju Singh
Opposite Party :- State of U.P.
Counsel for Applicant :- Kunwar Janmejay Pratap Singh
Counsel for Opposite Party :- G.A.
Hon'ble Saurabh Shyam Shamshery,J.
This is second bail application. The first bail
application was rejected on 18.11.2022.
Sri Kunwar Janmejay Pratap Singh, learned counsel for
applicant submits that subsequently, two co-accused
have been granted bail by coordinate Benches of this
Court vide orders dated 27.02.2023 and 27.03.2023
respectively, however, it appears that it has not been
brought on record before coordinate Bench that bail
application of co-accused (present applicant) has been
rejected. Therefore, it cannot be considered to be a
subsequent event which could be considered by this
Court while considering second bail application.
Learned counsel also submits that number of proposed
prosecution witnesses are 13, however, till date, only
one witness has been examined during trial and
applicant is in jail since 24.04.2022.
In these circumstances, this application is liable to be
rejected, hence, rejected.
Trial Court shall take all endeavour to conclude trial
expeditiously.
Order Date :- 22.5.2023
