CORAM: HONOURABLE MR. JUSTICE NAVIN SINHA
ORAL ORDER
3 07-03-2012 Heard learned Counsel for the petitioner and the State.
The Court is satisfied that the Bench order in 1992 (2) PLJR 336
declining similar relief raises issues of judicial discipline and propriety. If
that order attained finality, any subsequent similar claim should
appropriately have been referred to the Division Bench, even if certain
aspects were allegedly not considered.
The order of a Single Judge binds a Single Judge. The only
option left is to refer it to a Division Bench if not in concurrence as held in
(2009) 5 SCC 634 (Century Textiles Industries Limited v. Deepak Jain);-
“23. …..Time and again it has been emphasised
that judicial propriety and decorum requires that if a
Single Judge, hearing a matter, feels that earlier
decision of a Single Judge needs reconsideration, he
should not embark upon that enquiry, sitting as a Single
Judge, but should refer the matter to a larger Bench.
Regrettably, in the present case, the learned Single
Judge departed from the said healthy principle and
chose to re-examine the same question himself.”

Patna High Court CWJC No.1817 of 2012 (3) dt.07-03-2012
The Court is not satisfied of the need to do so in view of the
judgement in 1992 (2) PJJR 336 which still holds the field.
The writ application is dismissed.

(Navin Sinha, J)
