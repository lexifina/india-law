 The petitioners had earlier approached the H.P.
Administrative Tribunal by way of an application in Original
Application No. 6002/2018, challenging the proceedings dated
17.09.2018 whereby a seniority list was altered. The said
application is still pending.
2. In the meantime for whatever reasons, one of the
petitioners herein seeks to withdraw from the Original Application.
But since the Tribunal is now abolished, the petitioners have come
up with the above writ petition seeking a transfer of the Original
Application to the file of this Court and to permit the 3rd petitioner
herein to withdraw his name from the array of the parties.

1 Whether the reporters of Local Papers may be allowed to see the judgment?

 - 2 -
3. Mr. J.K. Verma, learned Additional Advocate General,
takes notice for the respondents. There cannot be any objection to
the first part of the prayer for the transfer of the Original
Application. It is only after the transfer is effected, the 3rd petitioner
can be permitted to withdraw from the array of the parties.
4. Therefore, for the present, the writ petition is disposed
of directing the transfer of Original Application No. 6002 of 2018
from the file of the H.P. Administrative Tribunal to the file of this
Court. The file may be transferred within a week from the receipt of
a copy of this order.
5. After the file is transferred and it is numbered as a
Writ Petition, the 3rd petitioner may file a memo for deletion of his
name from the array of the parties.
6. Pending application(s), if any, stands disposed of.
 (V. Ramasubramanian)
