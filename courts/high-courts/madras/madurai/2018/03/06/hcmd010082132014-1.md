Petitioner/ accused No.3 to quash the First Information Report in
Crime No.430 of 2014, on the file of the first respondent police.
2.The learned counsel appearing for the petitioner and the
learned Government Advocate (Crl.Side) appearing for the first
respondent are present.

already a charge sheet has been filed and the case has been taken on
file in C.C.No.365 of 2014, on the file of the learned Judicial
Magistrate, Uthamapalayam.
4.Recording the aforesaid submissions, this Criminal Original
Petition is dismissed as infructuous.
