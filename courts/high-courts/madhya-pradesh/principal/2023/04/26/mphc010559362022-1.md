ORDER
Learned counsel for the applicant prays for withdrawal of this bail
application with liberty to file properly constituted application along with all the
relevant documents which applicant wishes to file.

relevant documents. For over a period of five months, no documents have been
filed, therefore, this Court cannot be allowed to be used by keeping an
application pending without advancing arguments on merits.
Accordingly, application is dismissed as withdrawn with the aforesaid
