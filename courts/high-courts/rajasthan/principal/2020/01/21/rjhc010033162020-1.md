Order
21/01/2020
An application has been filed by the appellant for correction in
the order dated 26.11.2019 in S.B. Criminal Misc. Bail Application
No.14407/2019, in which counsel submits that in the headnote of
bail application the Police Station has wrongly been mentioned as
“Bali”, whereas the correct name of Police Station is “Sadri”.
Therefore, it is prayed that necessary correction be made in the
order dated 26.11.2019.
For the reasons mentioned in the application, the application is
allowed. The name of Police Station in S.B. Criminal Misc. Bail
Application No.14407/2019 may be read as “Sadri” instead of “Bali”.
Application allowed accordingly.
