ORDER
This Criminal Miscellaneous Case is filed under
Section 482 of the Code of Criminal Procedure, 1973.
2. It is submitted that the petitioner is not in
India. Petitioner is an accused in L.P. No.102/2003 on
the file of the Judicial First Class Magistrate Court – I,
Manjeri. The petitioner wants to quash the proceedings
based on settlement. The same can be considered only
after regularizing the proceedings before the lower
court. If there is any apprehension of arrest at the time
of his arrival to India, the petitioner is free to file a
separate Crl.M.C. The Registry shall return the original
of the affidavit submitted by the 3rd respondent to the
petitioner.

Crl.M.C..No.8040/2023
3
Granting liberty to the petitioner to file a fresh
Criminal Miscellaneous Case, when he came back to
India, this Crl.M.C is closed.
