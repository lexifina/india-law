ORDER
These bail applications are filed by the accused in
different cases registered by the Keezhvaipur Police Station.
2. When these bail applications came up for
consideration earlier, there was an interim order not to
arrest the petitioner.
3. Today, when the matter came up for
consideration, the learned Public Prosecutor submitted that
the final report in these crime were already submitted
before the jurisdictional court. If that is the case, no further
order is necessary in these bail applications. The petitioner
in these bail applications is free to appear before the
jurisdictional court, if not appeared and if the petitioner

9890/2021, 9933/2021, 9904/2021,
9876/2021, 9919/2021, 9899/2021,
9892/2021, 9882/2021, 9895/2021]

appears with any bail application, the court concerned will
consider the same in the light of the fact that there was an
interim order from this Court.
With these above observations, these bail applications
are closed.
