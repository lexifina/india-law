The Court: In terms of the leave granted to the award-holder vide order
dated August 20, 2024, GA/1/2024 has been filed, seeking leave to return the
execution application with liberty to file afresh before the Commercial Division
of this Court.
Although the said application is not appearing in the list today, the same
be treated to be on the day’s list in view of the innocuous nature of the prayer
and is now taken up for hearing.
GA/1/2024 is allowed, thereby directing the return of the execution
application bearing EC/15/2024 to the award-holder, to be presented afresh
before the Commercial Division of this Court.
 (SABYASACHI BHATTACHARYYAJ.)
