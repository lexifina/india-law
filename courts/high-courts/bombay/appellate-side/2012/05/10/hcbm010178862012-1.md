P.C.
1. Heard.
2. I have gone through the Bail Application and Annexures thereto.
3. According to the case of the Investigating Agency, the Applicant
was found to be using the mobile telephone hand set which was with
the deceased. The circumstance needs explanation, and therefore, it
cannot be said at this stage that there exists no prima facie case against
the Applicant.
4. In view of this observation, the learned counsel for the Applicant
seeks permission to withdraw the Application.

- 2 -
 BA666.12
4. Application is allowed to be withdrawn and is dismissed as such.
