# Allahabad High Court, WRIC/6513/2021, 2021-06-17

Court No. - 36
Case :- WRIT - C No. - 6513 of 2021
Petitioner :- Abdul Aziz And 2 Others
Respondent :- State Of U.P. And 9 Others
Counsel for Petitioner :- Some Narayan Mishra
Counsel for Respondent :- C.S.C.,Pawan Kumar Singh
Hon'ble Dr. Kaushal Jayendra Thaker,J.
Hon'ble Dinesh Pathak,J.
Heard learned counsel for the parties.
This writ petition has been filed with a request that they have filed a
recall application, which is Annexure-11 to this petition, and the
same is pending before the District Magistrate/Collection,
Allahabad.
No useful purpose would be served by keeping this petition pending.
Therefore, we direct that the recall application filed by the
petitioners shall be decided by respondent no.2 as expeditiously as
possible, after hearing all the parties concerned. We make it clear
that we have not gone into the merits of this petition and we have not
decided the dispute between the parties. All that we have done is that
directed the respondent no.2 to decide the recall application of the
petitioners, which is pending since more than two years.
With these observations, this petition stands partly allowed.
As we have not passed any adverse orders, there is no need to issue
notice to rest of the respondents.
Order Date :- 17.6.2021
Manish Himwan
