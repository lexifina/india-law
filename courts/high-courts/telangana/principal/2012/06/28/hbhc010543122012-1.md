# High Court for the State of Telangana, CRLRC/524/2012, 2012-06-28

HONOURABLE SRI JUSTICE RAJA ELANGO
CRIMINAL REVISION CASE No:524 OF 2012
ORDER:
Learned Counsel for the petitioner seeks permission of this
Court to withdraw the revision case, with a liberty to file an appeal.
Permission is accorded and the Criminal Revision Case is
dismissed as withdrawn. Consequently, miscellaneous petitions
pending, if any, stand dismissed. However, the petitioner is at liberty
to file an appeal, if he so desires.
________________
Justice Raja Elango
