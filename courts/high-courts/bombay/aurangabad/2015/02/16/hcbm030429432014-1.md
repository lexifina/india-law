PER COURT :
1. By order dated 19/01/2015, when the present
application filed u/s 439 of the Code of Criminal Procedure
was listed before the Hon'ble Judge [CORAM ;
T.V.NALAWADE, J.], taking the matters pertaining to the
application u/s 439 of the Code of Criminal Procedure, that
day, request was made on behalf of the learned counsel for the
applicants that he wish to amend the application for making

 2 Cr. Apln. 6863.2014
the suitable prayer to invoke the provisions of Section 482 of
the Code of Criminal Procedure. Therefore, on the said date,
the matter was removed from the board.
2. Today when the matter is taken up, from the
Criminal Application it is clear that no amendment is made in
the prayer clause. Further, only the amendment is made in
the first page to the effect that the application is filed u/s 482
of the Code of Criminal Procedure. After hearing the learned
counsel for the applicants, he wish to withdraw the present
Criminal Application. Permission granted.
3. The present Criminal Application is dismissed as
withdrawn.
