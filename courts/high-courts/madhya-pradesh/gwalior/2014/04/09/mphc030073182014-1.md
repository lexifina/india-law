# High Court of Madhya Pradesh, RP/138/2014, 2014-04-09

RP 138/2014
( M/s SKOL Breweries Ltd Vs. state of MP)
09/04/2014.
Shri Sankalp Sharma, Advocate for petitioner.
Heard.
This review petition has been filed for
correction of the typographical error occurring in the
order dated 7/3/2014 passed by this Court in MCC
81/2014. In the aforesaid order, number of the writ
petition has been mentioned as WP 8647/2011,
however, the correct number if WP 8647/2012.
We have perused the record. The contention of
the petitioner is correct.
Hence, the review petition is allowed. Where in
the order dated 7/3/2014 passed by this Court in
MCC 81/2014 it is mentioned as WP 8647/2011, it be
read as WP 8647/2012.
Review petition is disposed of.
(S.K.Gangele) (B.D.Rathi)
