# High Court of Madhya Pradesh, MCRC/10009/2016, 2016-11-02

--- 1 ---
M. CR. C. No. 10009 / 2016
02/11/2016
Mr. Arjun Pathak, learned counsel for the petitioner.
Mr. C.S. Ujjainia, learned counsel for the respondent –
State.
Learned counsel for the petitioner prays for withdrawal
of the present bail petition with liberty to file fresh bail
petition u/S. 439 of the Code of Criminal Procedure, 1973.
prayer allowed.
The present bail petition is dismissed as withdrawn with
aforesaid liberty. It is made clear that in case a bail petition
u/S. 439 of the Code of Criminal Procedure, 1973, the court
below shall make all possible endeavour to hear the same on
the same day.
Certified copy, as per Rules.
(S. C. SHARMA)
