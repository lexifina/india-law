O R D E R
The applicant has filed this application to correct the name of
the applicant/accused as 'Vishnu' instead of 'Jishnu', which is
mistakenly crept in the application as well as in the order, which
was passed by this Court.
2. Heard the learned counsel for the applicant and the
learned Public Prosecutor.
The learned Public Prosecutor admits that there is a mistake in
the name of the applicant/accused and the actual name of he
applicant/accused is 'Vishnu'. Hence, the correction petition is
allowed. Registry is directed to carry out the correction in the
application as also in the consequent order passed by this Court.
