1. This is an application for condonation of delay
of 440 days caused in filing application for restoration of
the appeal.
2. Perused the application.
3. Heard learned Advocate of the applicant.
4. For the reasons stated in the application and
the fact that delay is not deliberately caused, the
application is allowed.
5. The delay of 440 days caused in filing
restoration application is condoned.
6. The application is disposed of.

appeal.

4. Learned Advocate for the applicant submits
that now the paper-book is ready and it can be filed within
a week.
5. Considering this fact, the application deserves
to be allowed.
6. The application is allowed.
7. The appeal is restored on its original number,
subject to the condition that if the paper-book is not filed
within a week, the application shall be deemed to be
rejected without further order.
8. The application is disposed of.
