# High Court of Madhya Pradesh, MCRC/2659/2015, 2015-02-26

M.Cr.C.No.2659 of 2015

1
Tejnarayan vs The State of M.P.
26/02 / 2015
Shri Y.K.Gupta, Advocate for the applicant.
Shri Vijay K. Pandey, Panel Lawyer for the
respondent/State.
Heard finally.
This application has been filed seeking modification
in the order dated 04.02.2015 passed by this Court in
M.Cr.No.249/2015.
It is submitted that due to some inadvertent
mistake, name of Police Station has wrongly been
mentioned as “Kotwali Raisen, District Raisen (M.P.)”,
whereas the correct name of Police Station is “Misrod,
District Bhopal (M.P.)”.
Keeping in view the aforesaid, this application is
allowed. In the order dated 04/02 /2015 passed by this
Court in M.Cr.C.No.249/2015 where “Police Station
Kotwali Raisen, District Raisen (M.P.)” is mentioned, it is
hereby corrected and shall be read as “Police Station
Misrod, District Bhopal (M.P.)”
The order dated 04/02 /2015 passed by this Court
in M.Cr.C.No.249/2015 shall be read conjointly with this
order along with the aforesaid modification.
Certified copy as per rules today itself.
 (SUBHASH KAKADE)
SJ JUDGE
