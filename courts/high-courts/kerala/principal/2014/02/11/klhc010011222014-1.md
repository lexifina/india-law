ORDER
Petitioner apprehends arrest in Crime No.93 of 2014 of
the Konny Police Station for the offences punishable under
Sections 452, 294(b), 323 and 324 r/w Section 34 of the Indian
Penal Code with respect to an incident which allegedly occurred
on 18-01-2014.
2. Learned Public Prosecutor submits on instruction
that Section 452 of the Penal Code is deleted from the section
of offences and report to that effect is filed in the JFMC-II,
Pathanamthitta.
3. Once Section 452 of the Indian Penal Code is
deleted, other offences alleged are bailable and as such the
application for anticipatory bail cannot be entertained.
Petitioner can surrender before the Court concerned and seek
regular bail.
Application is disposed of with the above observation.
