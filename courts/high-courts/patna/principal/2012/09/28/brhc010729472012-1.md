CORAM: HONOURABLE MR. JUSTICE AKHILESH CHANDRA
ORAL ORDER
2 28-09-2012 Heard.
This application has been filed for the grant of regular
bail to the petitioner for offences punishable under sections 414 of the
Indian Penal Code and Section 7 of the Essential Commodities Act, in
connection with Thakurganj (Zia Pokhar) P.S. Case No. 72/2012
pending in the court of Chief Judicial Magistrate, Kishanganj.
Learned counsel for the petitioner seeks permission to
withdraw this application since petitioner has already been released by
the court below under Section 167(2) of the Code of Criminal
Procedure. Permission is granted.
Accordingly, this application stands dismissed as
withdrawn.
Rajeev/- (Akhilesh Chandra, J)
