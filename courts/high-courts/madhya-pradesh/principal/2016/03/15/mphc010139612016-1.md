# High Court of Madhya Pradesh, MCRC/4584/2016, 2016-03-15

MCRC-4584-2016
(SANTOSH Vs THE STATE OF MADHYA PRADESH)
15-03-2016
Shri Ganga Prasad Patel, learned counsel for the
applicant.
He is heard.
The present M.Cr.C has been filed for correction in the
cause title of the order dated 03.03.2016 passed in
M.Cr.C No.2676/2016. The applicant is described in the
said order Santosh S/o Netram Rajpoot. Learned counsel
for the applicant submits that it ought to have Santosh
S/o Netraj Rajpoot.
On due consideration, the application is allowed. The
order be read as Santosh S/o Netraj Rajpoot.
M.Cr.C. Stands disposed of.
Let a copy of this order be retained in the file of M.Cr.C.
No.2676/2016.
(S.K. SETH)
JUDGE
