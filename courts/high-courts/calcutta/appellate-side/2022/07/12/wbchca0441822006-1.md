# Calcutta High Court, CRR/3453/2006, 2022-07-12

12.07.2022 IN THE HIGH COURT AT CALCUTTA
 Item No.26 CRIMINAL REVISIONAL JURISDICTION
 Ct.No.34
 dc.
C.R.R. 3453 of 2006

 Sanjeev Kumar Srivastava
 versus
 The State of West Bengal & Anr.
In Re: An Application under Section 482 of the Code of
Criminal Procedure, 1973.
Mr. Arijit Ganguly,
Mr. Arani Bhattacharyya … For the State.
Pursuant to the order passed by this Court on
06.07.2022, Mr. Arijit Ganguly, learned advocate for the State
submits a report of Officer-in-Charge, Entally Police Station
dated 12.07.2022. Let the said report be kept on record.
The report reflects that on conclusion of investigation,
final report was submitted with an opinion by the
Investigating Officer as ‘Mistake of Fact’.
This revisional application was filed for quashing of
Entally Police Station Case No. 4 dated 04.01.2006. In view of
the report so submitted, there is no scope for interference as
the original case is not existing. As such, the revisional
application has become infructuous.
Accordingly, the revisional application being CRR 3453
of 2006 is dismissed as infructuous.
All pending connected applications, if any, are
consequently disposed of.
All parties shall act on the server copy of this order
duly downloaded from the official website of this Court.

Urgent photostat certified copy of this order, if applied

requisite formalities.
 (Tirthankar Ghosh, J.)
