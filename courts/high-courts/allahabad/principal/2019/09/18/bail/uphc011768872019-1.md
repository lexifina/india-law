# Allahabad High Court, BAIL/37056/2019, 2019-09-18

Court No. - 51
Case :- CRIMINAL MISC. BAIL APPLICATION No. - 37056 of 2019
Applicant :- Harish Kumar
Opposite Party :- State Of U.P.
Counsel for Applicant :- Mohit Singh
Counsel for Opposite Party :- G.A.
Hon'ble Vipin Sinha,J.
Heard Sri Mohit Singh, learned counsel for the applicant, Sri Sandeep
Shukla, learned counsel for the complainant and Sri Pankaj Mishra,
learned AGA appearing for the State and perused the record.

application which has been filed by the co-accused, having identical role
has already been rejected by this Court.
Accordingly, the present anticipatory bail application is hereby rejected.
