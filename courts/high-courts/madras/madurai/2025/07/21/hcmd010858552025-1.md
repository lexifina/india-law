ORDER
This petition has been filed to dispense with the production of the certified
copy of the first information report in Cr.No.185 of 2025 on the file of the first
respondent Police.
2.The petitioners have not assigned any reason to entertain this petition.
Therefore, this Court is not inclined to entertain this petition. Accordingly, this
criminal miscellaneous petition is dismissed with liberty to file main petition along
with certified copy of first information report in Cr.No.185 of 2025 on the file of the
first respondent Police.
