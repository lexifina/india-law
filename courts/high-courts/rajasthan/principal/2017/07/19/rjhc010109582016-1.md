HON'BLE MS. JUSTICE NIRMALJIT KAUR
Order
19/07/2017
 Learned counsel for the respondent has placed on record the
order dated 26/05/2017 in compliance of the order dated
29/10/2015.
Accordingly, the contempt petition has rendered infructuous
and the same is dismissed. Rule is discharged. However, if the
petitioner is still having any grievance with respect to the
compliance report, he will be at liberty to file an application for
revival of the contempt petition by giving the details as to how the
order in question has not been complied with and in what manner.
