ORDER
Date : 04-09-2019
Heard Mr. S. Islam, learned counsel for the applicant/claimants. Also heard Mr. K.K.
Bhatta, learned counsel for the Insurance Company/appellants.
This is an application to allow the applicant/claimant to withdraw the 50% of the
awarded amount, which has been deposited with the Registry of this Court.
As the issue to be decided in this appeal is whether the deceased was a gratuitous
passenger, this Court is not inclined to allow the application at this stage.
I.A is accordingly dismissed.
