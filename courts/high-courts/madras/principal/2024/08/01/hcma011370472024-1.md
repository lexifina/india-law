# Madras High Court, A/3851/2024, 2024-08-01

A.Nos.3851 & 3852 of 2024
in E.P.No.18 of 2024
KRISHNAN RAMASAMY, J.
These applications are filed to
permit the applicant to amend the address
of the respondent in cause title and
schedule in the above Execution Petition
and to file the corrected clean copy of the
above Execution Petition.
2. The learned counsel for the
respondent would submit that he has no
objection in allowing these applications.
3. Being satisfied with the reasons
stated in the affidavit filed in support of
these applications, this Court is inclined
to allow these applications.
4. Accordingly, these applications
are allowed. The applicant is permitted to
make necessary amendments in the cause
title of the above Execution Petition and
file a clean copy of the same.
