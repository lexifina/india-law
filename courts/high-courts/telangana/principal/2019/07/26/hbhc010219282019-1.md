# High Court for the State of Telangana, CC/738/2019, 2019-07-26

THE HON’BLE SRI JUSTI CE SANJAY KUMAR
CONTEMPT CASE No.738 of 2019
ORDER:
The respondent is present in person.
2. This contempt case was instituted alleging wilful disobedience to
the order dated 01.04.2019 passed in W.P.No.5268 of 2019.
3. While so, Sri L.Ravinder, learned counsel representing Sri N.Ravi
Prasad, learned counsel for the petitioners, would inform this Court that
the order has since been complied with.
4. Recording the said statement, the contempt case is closed. No
order as to costs.
