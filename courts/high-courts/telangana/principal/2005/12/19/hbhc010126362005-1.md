ORDER:
The learned counsel for the petitioner seeks to withdraw the writ petition with a
liberty to file an application before the concerned Court, seeking relief to return the
charge sheet so as to enable the authorities to file the same before the appropriate
Court. Permission is accorded.
Accordingly, the Writ Petition is dismissed as withdrawn, giving liberty to the
petitioner to file an application before the concerned Court for redressal. No order as
to costs.
