ORDER
This petition under Article 227 of Constitution of India has been filed
against order dated 23.05.2022 passed by S.D.O. (Revenue) Mada, District
Singrauli in Revenue Case No.0042/A-6-A/2021-22 as well as order dated
28.07.2023 passed by Additional Collector, District Singrauli in Case
No.84/Revision/2022-23 by which application filed by petitioners under Section
115 of M.P.L.R. Code for correction of map has been rejected under Order 7
Rule 11 CPC.
2. It appears that father of petitioners had also filed a similar application
and a spot inspection report was submitted according to which map was
properly prepared. Thereafter, it appears that said record went missing and
application could not be decided finally. Later on, petitioners filed an
application under Section 115 of M.P.L.R. Code for similar relief. Respondents
filed an application under Order 7 Rule 11 CPC which was allowed by S.D.O.
(Revenue) Mada, District Singrauli on the ground that since the first application
is still pending, the petitioners should have made an effort to locate the said
record and should not have filed the second application for similar relief.
3. Being aggrieved by order passed by S.D.O. (Revenue) Mada, District
Singrauli, petitioners preferred a revision which too has been dismissed by
Additional Collector, District Singrauli by impugned order dated 28.07.2023
passed in Revenue No.0084/Revision/2022-23.
4. Challenging the order passed by authorities below, it is submitted by
counsel for petitioners that since record of the first application which was filed
by father of petitioners is missing, therefore, the second application was
maintainable.

JUDGE
5. However, during the course of arguments, it was fairly conceded by
Shri Shah that two parallel applications for similar relief are not maintainable.
6. The fate of first application is not known. If the first application was
already decided, then the said order would apply as res judicata and if the first
application is still pending, then the second application for similar relief is not
maintainable and in fact petitioner should have tried to search out the record of
the first application or could have filed an application for reconstruction of
record.
7. Under these circumstances, this Court is of considered opinion that
authorities below did not commit any mistake by rejecting the application under
Section 115 of M.P.L.R. Code on the ground of its maintainability.
8. However, liberty is granted to petitioners that either they should make
an effort to trace out the missing record of the first application or they may file
an application before competent authority for reconstruction of record.
9. With aforesaid liberty, petition is dismissed.
