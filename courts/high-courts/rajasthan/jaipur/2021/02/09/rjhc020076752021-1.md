HON'BLE MR. JUSTICE PANKAJ BHANDARI
Order
09/02/2021
1. The matter comes upon an application filed by the petitioner
for correction in the name of the petitioner in the cause title.
2. It is contended by counsel for the petitioner that in Criminal
Misc. Bail Application No.644/2021, name of Ram Naresh was
mentioned. Whereas, actually the name of petitioner is Ram
Ganesh. It is contended that order of the Court below has also
been modified.
3. In view of the prayer made by counsel for the petitioner,
application is allowed.
4. In the order dated 18.01.2021 in Criminal Misc. Bail
Application No.644/2021, name of petitioner be now read as
“Ram Ganesh” instead of “Ram Naresh”.

(2 of 2) [CRLMA-28/2021]
5. Amended cause title has been filed in the main bail
application and the same is taken on record.
(PANKAJ BHANDARI),J
