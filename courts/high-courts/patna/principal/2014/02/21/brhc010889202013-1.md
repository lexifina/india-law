ORAL ORDER
 2 21-02-2014 Counsel for the petitioner submits that during the
pendency of this writ application some subsequent events have
taken place wherein the petitioner has already been inflicted
punishment in a departmental proceeding whose memo of charge
was actually assailed by him in this writ application. He has,
accordingly, sought leave of this Court to withdraw this
application in order to enable the petitioner to take appropriate
steps against the order of punishment.
This application is, accordingly, permitted to be
withdrawn with the aforementioned liberty.
