O.P.(C) No.2254 of 2015
============================
Dated this the 1st day of February, 2016
JUDGMENT
Petitioner is the plaintiff in O.S No.810 of 2011 of Munsiff
Court, Alappuzha. A Commissioner was deputed for local
inspection and measurement of the properties. By Ext.P4
judgment this Court directed that the Commissioner shall file his
report within a period of four months. The Commissioner could
not file the report within four months. The learned Munsiff by
Ext.P5 order closed the commission application. This is
challenged.
2. Heard.
3. The order closing the commission application is illegal.
The learned Munsiff should have informed this Court about the
delay in filing the commission report and seek for further time.
The order is liable to be set aside.
In the result, this original petition is allowed. Ext.P5 order
is set aside. The learned Munsiff is directed to instruct the
Commissioner to file the report before 01.06.2016.
