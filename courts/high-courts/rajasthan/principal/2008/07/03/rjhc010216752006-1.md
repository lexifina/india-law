# High Court of Rajasthan, CW/5599/2006, 2008-07-03

Date of Order :: 3rd July 2008.
HON'BLE MR. JUSTICE DINESH MAHESHWARI
Mr.G.R.Goyal, for the petitioner
Mr.J.K.Chanda, for the respondent No.2.
 ....
Learned counsel for the petitioner seeks permission to
withdraw this writ petition with liberty to file afresh, if occasion
