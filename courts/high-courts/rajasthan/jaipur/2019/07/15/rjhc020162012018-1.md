Judgment / Order
15/07/2019
1. Petitioner has preferred this Criminal Miscellaneous Petition
seeking fair investigation in F.I.R. No.281/2017.
2. Learned Public Prosecutor has submitted report that Police
has already submitted negative final report.
3. In view of the same, the present Criminal Miscellaneous
Petition has become infructuous and the same is accordingly
dismissed as having become infructuous.
4. Stay application stands disposed.
5. Complainant/petitioner would be free to file protest petition,
if so advised.
