This is a transfer matter where the pupil-teacher ratio is 145:2 which is above the prescribed
ratio under the rules made under RTE Act, 2009.
 Therefore, at this stage, there cannot be any
order for transfer of the teacher as the school has only
two teachers and if the petitioner is transferred, it will
not be possible for a single teacher to run the school.
 Therefore, the writ application is dismissed.
 However, this dismissal will not prevent the
petitioner to file a new application for transfer when
the ratio will come within the limit of the aforesaid
Act.
 (Abhijit Gangopadhyay, J.)
