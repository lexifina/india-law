HON'BLE MR. JUSTICE M.N.BHANDARI
Order
06/09/2017
 It is stated that a settlement has been arrived between the
parties and, accordingly, payment would be made. The settlement
aforesaid has been noticed. If settlement has been arrived
between the parties, obviously it would be carried out accordingly.
Hence, I do not find any ground to cause interference in the
impugned order but this writ petition is disposed of with the
following direction:
(1) If settlement has been arrived between the parties then it
would be carried out accordingly. If no settlement exists then
order impugned herein would operate.
(MN BHANDARI) J.
