It appears that there is inadvertent typographical
mistake in the order dated October 8, 2021, which is
corrected in the following manner:
The names of the learned Advocates appearing for
the State in the cause-title of the said order be deleted
and be incorporated by the names of the learned
Advocates “Mr. Srijan Nayak and Ms. Rituparna
Maitra”.
The order dated October 8, 2021, accordingly,
stands corrected to the extent indicated above.
Let this order be treated as part of the order dated
October 8, 2021.
Certified copy of the order dated October 8, 2021, if
already supplied, be corrected accordingly.
Urgent photostat certified copy of this order, if
applied for, be supplied to the parties on priority basis.
