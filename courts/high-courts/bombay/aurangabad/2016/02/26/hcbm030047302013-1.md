PER COURT :-
Heard learned AGP for applicant State and Shri Shinde,
counsel for original claimants.
2] Applications are filed by the State for condonation of delay
which is of 1557 days. It is contention of the State that some time
was consumed for collecting certified copies, some time was
consumed for processing the matters and some time was consumed
for getting sanctions at various levels.
3] In view of these contentions and submissions, this Court holds
that sufficient cause is shown. So applications are allowed. Delay is
condoned.
