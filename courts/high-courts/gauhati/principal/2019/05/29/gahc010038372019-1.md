ORDER
Date : 29-05-2019
Heard Mr. E. Sithiri, learned counsel for the petitioner. Also heard Mr. Y. Doloi,
learned standing counsel for the Transport Department.
The matter pertains to challenge to the gradation list of Enforcement Inspectors in the
Transport Department.
An interim order has been passed by this Court on 11.06.2018 directing the State official
not to act upon the recommendations of the Departmental Selection Board for promotion of
Enforcement Inspectors and Motor Vehicle Inspectors and downward, without leave of this
Court.
Learned counsel for the State prays for six weeks time to file a detailed affidavit so that
the matter can be finally disposed of.
Some of the private respondents have filed Interlocutory Applications for vacating the
aforesaid interim order.

Page No.# 5/5
This Court is of the view that it will be more appropriate if the matter is heard finally
rather than considering application for vacating the stay order since the same has been in
operation since, April 2016.
Accordingly, the matter be listed after six weeks for final disposal.
List the matter on 06.08.2019.
 JUDGE
