Order
22/07/2024
This bail application has been under Section 439 of the Code
of Criminal Procedure, 1973 on 03.07.2024. On the date of filing
of this bail application the Code of Criminal Procedure, 1973 was
repealed by an enforcement of the Bharatiya Nagarik Suraksha
Sanhita, 2023 which came into force w.e.f. 01.07.2024.
Since on 03.07.2024, Section 439 of the Code of Criminal
Procedure, 1973 was not in existence, therefore, this bail
application is not maintainable.
Accordingly, the present bail application is dismissed being
filed under non-existing/repealed provisions.
