2.When the matter came up for hearing on 08.02.2024, this Court passed
the following order:
The learned counsel for the petitioner is not ready with the
case and he does not even possess the Bare Act which is relied up
on to argue this case. That apart, a criminal revision has been
filed against the order passed by the learned Magistrate in an
application filed under Section 315 of Cr.P.C. This order does
not find part in the typed set of papers. Therefore, the learned
counsel for the petitioner is directed to file a consolidated typed
set containing all the papers and get ready to answer the
questions that were posed by this Court.
2.Post this case under the same caption on 12.02.2024.
3.When the matter was taken up for hearing today, there is no
representation on the side of the petitioner. Hence, this criminal original petition
is dismissed for non-prosecution. Consequently, connected miscellaneous
petition is closed.
