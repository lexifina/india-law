P.C.
1. Not on Board. Upon mentioning taken on board.
2. By an Order dated 5th February 2024, this Petition came to be disposed
of as per the list of infructuous matters furnished by the learned G.P., High
Court, Appellate Side. Inadvertently, Petitioner could not file a praecipe as per
the Notice dated 25th January 2024.
3. The learned counsel for the Applicant submits that the Petition has not
become infructuous for the reasons as set out in the Memo of the Application.
4. We accept the contention as urged on behalf of the Petitioner. We set
aside the order dated 5th February 2024 and restore the Petition to the file of
this Court.
5. Order accordingly.
