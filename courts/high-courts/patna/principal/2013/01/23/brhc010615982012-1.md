CORAM: HONOURABLE JUSTICE SMT. SHEEMA ALI KHAN
ORAL ORDER
4. 23-01-2013. Heard learned counsel for the petitioner, learned
counsel for the State Election Commission, Bihar and learned
counsel for the State.
A show cause has been filed on behalf of the State
Election Commission by which they have passed an order dated
4.1.2013 in compliance of the order passed by this Court as
contained in Annexure-1.
Counsel for the petitioner has objection to the
reasons for rejecting the claim of the petitioner. It will always be
open to the petitioner to approach an appropriate forum for
setting aside the order of the State Election commission.
This contempt application is accordingly disposed
of.
ahk/-
 (Sheema Ali Khan, J.)
