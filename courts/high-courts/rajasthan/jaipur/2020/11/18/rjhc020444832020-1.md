Order
18/11/2020
The petitioner by way of this writ petition challenges the
order by which the enquiry was declared unfair.
In the opinion of this court, the order is an interlocutory
order and is not liable to be challenged in writ petition especially
when the main application under Section 33(2)(b) of the Industrial
Dispute Act is still pending before this court.
Granting liberty to challenge along with main order if so
required, the writ petition is dismissed at this stage.
(SANJEEV PRAKASH SHARMA),J
