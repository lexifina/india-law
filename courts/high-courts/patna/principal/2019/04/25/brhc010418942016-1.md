ORAL ORDER
3 25-04-2019 This application has been filed for restoration of
CWJC no.14280/2016 to its original file and number.
Writ petition bearing CWJC no.14280/2016 was
placed for order on office note on 30.08.2016 when this court
granted one week's time for filing fresh set of court fee and
welfare stamp etc. The order was partly complied with within
time. However, there was some shortage on account of non-availability of welfare stamp and same could not be filed, as a
result of which writ petition stood dismissed for non-compliance
of order dated 30.08.2016.

Patna High Court MJC No.3614 of 2016(3) dt.25-04-2019
2/2
Counsel for the petitioner submits that since welfare
stamp was not available, same could not be filed.
Considering the said submission, this court would
direct the petitioner to file welfare stamp within one week from
today. CWJC no.14280/2016 is restored to its original file and
number.
s.hassan/-
