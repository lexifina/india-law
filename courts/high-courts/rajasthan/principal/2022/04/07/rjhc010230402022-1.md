Order
07/04/2022
The matter comes up on an application for correction in the
order dated 06.04.2022 passed by this Court in S.B. Criminal Misc.
2
nd Bail Application No.4310/2022.
Learned counsel for the applicant-petitioner submits that
inadvertently, the number of the FIR in the bail application has
been mentioned as “329/2021, Police Station Ambamata, Udaipur”
whereas, the correct number should have been “329/2019, Police
Station Ambamata, Udaipur”.
For the reasons mentioned in the application, the same is
allowed. It is ordered that the FIR Number in the order dated
06.04.2022 passed by this Court in S.B. Criminal Misc. 2nd Bail
Application No.4310/2022 be read as “329/2019, Police Station
Ambamata, Udaipur” instead of “329/2021, Police Station
Ambamata, Udaipur”.
The application stands disposed of in the above terms.
(VINIT KUMAR MATHUR),J
