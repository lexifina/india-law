 O R D E R
This Crl.M.C. is filed to quash CC No.777/2014 on the
file of the Judicial First Class Magistrate Court, Chittur
arising from Crime No. 3/2012 of Kollengode Forest Range
Office, Palakkad. It is submitted that the offence alleged are
compoundable and the petitioner approached the competent
authority for compounding. The same is dismissed and the
writ petition is pending before this Court as W.P.(C.) No.
5149/2017. Simply because the writ petition is pending
against the order dismissing compounding, this Court
cannot stay the proceedings before the trial court. The
petitioner is free to file appropriate application in the
pending writ petition, if it is permissible as per law.

CRL.MC NO. 7873 OF 2023 3
Granting liberty to the petitioner to file appropriate
application in the pending writ petition if it is permissible,
this Crl.M.C. is closed.
