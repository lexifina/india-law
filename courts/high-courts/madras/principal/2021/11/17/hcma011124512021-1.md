# Madras High Court, A/3563/2021, 2021-11-17

1
Application No.3563 of 2021
in C.S.No.295 of 2012
N.ANAND VENKATESH,J.,
This application has been filed by the applicant/plaintiff seeking for the
leave of this Court to file additional document which is a letter dated
03.09.2011.
2.Heard the learned counsel for the applicant/plaintiff and the learned
counsel appearing on behalf of the defendant/respondent.
3.On a reading of the affidavit filed in support of the application, it is
seen that the letter that is sought to be filed as an additional document was
a letter which was handed over to the CBI when certain documents were
handed over to the CBI. There cannot be any serious objections in allowing
this application and accordingly leave is granted to the applicant/plaintiff to
file letter dated 03.09.2011 as an additional document.
4.Accordingly, this application is allowed.
