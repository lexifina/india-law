# High Court of Madhya Pradesh, MCC/1741/2014, 2014-09-03

M.C.C.No. 1741 / 2014.
3/9/2014.
Shri M.K. Jain, learned counsel for the applicant.
This application has been filed for restoration of Writ
Appeal No.393/2014 which was dismissed in view of common
conditional order passed on 8.5.2014. There being some delay in
filing the application for restoration, application IA No.11848/2014
has been filed seeking condonation of delay. Both the
applications are supported by affidavit of the counsel himself and
there is no reason to disbelieve the same. Finding the same to
be bona fide, both the applications are allowed. Condoning the
delay in filing the application, restoration application itself is
allowed. Writ Appeal is restored to its original number. It be
placed for orders before the appropriate Bench.
Application stands allowed and disposed of.
(Rajendra Menon) (Anil Sharma)
