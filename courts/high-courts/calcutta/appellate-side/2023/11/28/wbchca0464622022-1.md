# Calcutta High Court, CRR/3871/2022, 2023-11-28

D/L1
28.11.2023
Bpg.
 C.R.R.3871 of 2022
In Re: An application under Section 482 of the Code of Criminal
Procedure;
 Saumen Seth and others
 Versus
 The State of West Bengal and another
 Mr. Ranjit Singh.
 …for the petitioners.
Learned advocate appearing for the petitioners do not
intend to press the present revisional application which was filed in
connection with Habra Police Station Case No.689 of 2022.
Accordingly, the revisional application being 3871 of
2022 is dismissed as not pressed.
Pending application, if any, is consequently disposed of.
Petitioners would be at liberty to file afresh after there are
changed circumstances.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
 (Tirthankar Ghosh, J.)
