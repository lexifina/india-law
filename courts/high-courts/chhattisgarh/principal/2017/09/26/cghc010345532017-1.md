Order on Board
26/09/2017
1. Present CRMP has been filed seeking for correction in the order
dated 03.05.2017, passed in MCRCA No. 1383/2016.
2. According to the counsel for the petitioner, there has been an
inadvertent error while recording the Crime number of the case, in
which he has been made an accused. According to the counsel for
the petitioner, the actual Crime number is 198/2016, whereas
inadvertently the Crime number has been recorded as 196/2016 in
the application for grant of bail and prays for suitable correction, so
that he can furnish the bail.
3. The State counsel on verification submits that it appears to be a
clerical error on the part of the applicant and submits no objection in
the correction to be made.

2
4. Accordingly, it is ordered that in the order dated 03.05.2017 in
MCRCA No. 1383/2016 where the Crime number is mentioned as
196/2016, it shall be read as Crime No. 198/2016.
5. It is ordered accordingly. The present CRMP is accordingly allowed.
Let a copy of this order passed in the present CRMP be made part of
the record of MCRCA No. 1383/2016.
Sd/-
(P. Sam Koshy)
