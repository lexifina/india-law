ORDER
The present Review Petition has been preferred against the order dated
03.03.2023, whereby while hearing the writ petition on I.A. No.1808/2023 which
was an application seeking permission to withdraw the petition with liberty to
file afresh, but in the concluding para it got mentioned "the petition is dismissed
as withdrawn without any liberty."
Learned counsel for the Petitioner submits that in the aforesaid I.A.
permission was sought from this Court to withdraw the petition with liberty to
file afresh, if occassion so arises, but inadvertently it had got mentioned that the
permission is granted to withdraw the writ petition without any liberty. As this
error is apparent on the face of the record, the order deserves to be recalled and
necessary modification in the order be directed.
Per contra, Shri Pawan Raghuwanshi, submits that from the record it
appears that some typographical error has occurred while passing the order and
if the order is reviewed and corrections are directed to be made, he has no
objection.
After hearing counsels for the parties and perusing the record, it appears
that the aforesaid concluding para of the order dated 03.03.2023 passed in
W.P. No.12351/2021 had been passed inadvertently as in the application it has
been sought by the Petitioner that he may be permitted to withdraw the petition
with liberty to file a fresh petition.
Accordingly, the review petition is disposed of with a modification in the
order dated 03.03.2023 that in place of "without any liberty" it may be read as
"with liberty to file afresh".
With the aforesaid direction, the petition stands disposed of.
