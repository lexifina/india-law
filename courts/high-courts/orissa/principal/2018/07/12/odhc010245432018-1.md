# High Court of Orissa, WP(C)/7808/2018, 2018-07-12

04. 12.07.2018 Heard learned counsel for the petitioner and
learned counsel for the opposite party no.1.
 In course of hearing, learned counsel for the
petitioner submits that the petitioner may be permitted to
withdraw this writ petition giving liberty to file application for
One Time Settlement before the Bank.
 In such view of the matter, this writ petition is
dismissed as withdrawn giving liberty to the petitioner to file
application before the Bank as submitted. If such an
application is filed, the same shall be considered as per the
existing schemes/ guidelines.
