# High Court of Madhya Pradesh, MCC/2340/2014, 2014-11-11

:: 1 ::
MCC No.2340/2014
11.11.2014.
Shri Ajeet Singh, learned counsel for the applicant.
This application has been filed for restoration of Writ
Appeal No.349/2014, which was dismissed for want of
prosecution on 13.10.2014. The application is supported by an
affidavit sworn in by the counsel for the applicant himself.
Finding reasons indicated in the application to be
bonafide, Writ Appeal No.349/2014 is restored.
MCC stands disposed of.

vinod JUDGE JUDGE
