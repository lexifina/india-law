W.P.No.37815-816/2011, on the file of the Hon’ble High Court

 This Review Petition coming on for Orders this day, the
court made the following:

 3
O R D E R
 None appears for the petitioners. This review petition is
sought to be filed on the ground that there are some apparent
errors in the order of this court. Even if there are any such
errors and in the opinion of the counsel for the petitioners, the
order is illegal, it is a case where he could very well file an
appeal and there is no warrant to reconsider the order.
 The review petition is rejected.
