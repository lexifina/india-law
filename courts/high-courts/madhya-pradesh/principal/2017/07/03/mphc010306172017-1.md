# High Court of Madhya Pradesh, WP/8928/2017, 2017-07-03

WP-8928-2017
(HARJUA @ TOTA @ SARJUA Vs THE STATE OF MADHYA PRADESH)
03-07-2017
Shri Vijay Shukla, learned counsel for the petitioners.
Shri Manoj Kushwaha, learned PL for the
respondents/State.
The petitioner seeks to withdraw this petition with a liberty
to file an appeal against the order dated 28/07/2016 Annexure P/3
passed by the First Civil Judge Class-I Banda District Sagar.
Accordingly, the petition is dismissed as withdrawn with
the liberty as prayed for.
Office is directed to return the certified copy of the
impugned order by retaining a photocopy thereof.
(MISS VANDANA KASREKAR)
