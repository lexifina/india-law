ORAL ORDER
1. In the present application, the writ petitioner
has prayed for quashing and setting aside the order
passed in the application at Exh.81 dated 08.11.2016
in Criminal Revision Application No.65 of 2008 by the
learned Third Additional Sessions Judge at Patan by
rejecting the amendment application.
2. At the outset, the learned advocate appearing
for the respondents has submitted for the very same
prayer, i.e. that the petitioner had filed the
Special Criminal Application No.1194 of 2017 which
was unconditionally withdrawn on 20.02.2017. He has
submitted that in this view of the matter no fresh
petition is maintainable.
3. Learned advocate appearing for the petitioner is
unable to dispute the facts of filing Special
Criminal Application No.1194 of 2017 for challenging

R/SCR.A/2002/2017 ORDER
the very same order with the same identical prayers.
The same was also withdrawn on 20.02.2017.
4. This Court in Special Criminal Application
No.1194 of 2017 has passed the following order:
“Mr. Joshi, the learned advocate appearing
for the applicant does not press this
application ans seeks permission to
withdraw the same.
Permission as prayed for is granted. This
application is disposed of as not pressed.”
4.1 Perusal of the order would clarify that the said
application was unconditionally withdrawn without
reserving any liberty to file appropriate
proceedings.
5. Thus, the present application with the similar
prayers challenging the same orders is not
maintainable and hence the same is rejected. Rule is
discharged.
