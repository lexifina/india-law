 IN

 Nagesh L. Manthen (HUF)., .. Petitioner .

 Shri V. Joglekar for applicant/petitioner
 in support.
 CORAM : S.U.KAMDAR, J.
 DATE : 18TH MARCH, 2005.
 P.C.
 . The learned counsel appearing for the
 applicant craves leave to withdraw the application
 on the ground that the main petition is disposed of
 by an order dated 7.3.2005. He however seeks
 liberty that in an event if the default is committed
 as contemplated in the main order and if the
 petition is admitted then he should be given liberty
 to file fresh application on the same cause of
 action. With the aforesaid liberty the application
 stands dismissed as withdrawn.
