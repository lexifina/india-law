# Allahabad High Court, WRIC/19773/2019, 2019-06-04

Court No. - 33
Case :- WRIT - C No. - 19773 of 2019
Petitioner :- Manita
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Satyendra Kumar Mishra
Counsel for Respondent :- C.S.C.
Hon'ble Manoj Misra,J.
Hon'ble Saurabh Shyam Shamshery,J.
Heard learned counsel for the petitioner and learned
Standing Counsel for the State-respondents.
This is second petition of the petitioner. The first petition,
namely, Writ C No.16518 of 2019 was got dismissed as not
pressed. No liberty was granted to the petitioner to file
fresh petition. No subsequent cause of action has been
disclosed though, according to the learned counsel for the
petitioner, subsequent cause of action has also arisen
because she has moved a representation on 28th May,
2019 before the Superintendent of Police, Amroha (J.P.
Nagar).
Mere filing of a representation would not generate the
cause of action. There should be some incident which may
demonstrate that there is some threat to the petitioner so
as to enable her to move a fresh petition. In case, there is
an incident, then appropriate course for the petitioner is to
lodge a non-cognizale report or a first information report
and thereafter approach the authority concerned.
With the aforesaid liberty, this petition is disposed off.
Order Date :- 4.6.2019.
Rks.
