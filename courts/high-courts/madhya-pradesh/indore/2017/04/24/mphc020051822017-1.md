# High Court of Madhya Pradesh, WP/1248/2017, 2017-04-24

W.P.No.1248 /2017
24.04.2017
Shri R.C.Mehra, learned Counsel for the petitioner.
Shri B.S.Gandhi, learned Counsel for the respondent.
The petitioner has filed the present petition being aggrieved by order
dt. 27.1.2017 by which his application under Order 8 Rule 8 CPC and order
8 Rule 1 CPC has been rejected.
By the aforesaid application, the petitioner wanted to file photocopy
of rent receipt. The Trial Court has rejected the application on the ground
that the order under Section 13(6) has already been passed against the
tenant/defendant. The evidence of parties has been concluded and the case
has been fixed for final arguments.
Shri Mehra, prays for withdrawal of this writ petition with liberty to
file these receipts along with the application under Order 41 Rule 27 CPC
in first appeal in event of judgment and decree passed against him.
This Court has not expressed any opinion on merits. The Appellate
Court is free to decide application under Order 41 Rule 27 CPC if any
filed in accordance with law.
Petition is dismissed as withdrawn.
CC as per rules.
(Vivek Rusia)
 Judge

M.Jilla.
