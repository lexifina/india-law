P.C. :
The Appeal is filed against an order rejecting an application filed
by the appellant under Order 7 Rule 11 of the Code of Civil Procedure
for rejecting the plaint filed by the respondent – plaintiff. On a reading
of the provisions of Order 43 Rule 1 of the Code of Civil Procedure, it
appears that an appeal is not tenable against an order rejecting an
application under Order 7 Rule 11 of the Code of Civil Procedure.
Hence, the Appeal is dismissed with no order as to costs. The points
raised in the appeal are kept open.
