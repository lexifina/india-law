1. Heard Ms Manju Ghatode, learned counsel on
her application for restoration of Criminal Application
(APL) No.433/2021, which was dismissed for non-removal
of office objections.
2. Though this application is coming up for the
first time, Shri R. R. Vyas, learned counsel waives service
for non-applicant No.2 and Ms M. A. Barabde, learned
Additional Public Prosecutor waives service for non-applicant No.1/State. Both the learned counsel fairly stated
that there is no objection for allowing this application. This
fair view is appreciated.
3. The application is allowed.
4. The Criminal Application (APL) No.433/2021
stands restored to the file subject to the counsel for the
applicants Ms Manju Ghatode removing office objections
within a period of ten days from today.
