# High Court of Uttarakhand, WPSS/648/2014, 2014-05-02

WPSS No.648 of 2014
Honíble Sudhanshu Dhulia, J.
Mr. Shivanand Bhatt, Advocate
present for the petitioner.
Mr. N.P. Sah, Standing Counsel
present for the State.
This petition has been filed with
incomplete pleadings. There is no detail
as to the disability of the husband of the
petitioner on which the petitioner seeks
her transfer.
At this stage, petitioner wants to
withdraw the writ petition with liberty to
file a fresh.
In view thereof, the writ petition is
dismissed as withdrawn with liberty to
file a fresh, if cause of action still
survives.
(Sudhanshu Dhulia, J.)
02.05.2014
 JKJ
