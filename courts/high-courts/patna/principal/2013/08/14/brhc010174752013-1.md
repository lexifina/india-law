ORAL ORDER
2 14-08-2013 This application has been filed for restoration of
C.W.J.C. No. 4898 of 2012 to its original file as against the
respondent no.2.
The writ application had stood dismissed as against
the respondent no.2 for non-compliance of the order dated
25.9.2012, whereby the petitioner had been granted three weeks’
time to file a substitution application in relation to the said
respondent. The three weeks’ time having expired on
16.10.2012, in absence of any application for substitution of the
respondent no.2 the writ application stood dismissed as against
him.
While making prayer for restoration it is stated that

Patna High Court MJC No.2386 of 2013 (2) dt.14-08-2013 2
the order dated 25.9.2012 has been complied by the petitioner
albeit with some delay. It is submitted that the substitution
application has already been filed on 30.10.2012 and which fact
is manifests from I.A. No.7264 of 2012 filed in C.W.J.C.
No.4898 of 2012.
In the circumstances set forth in this application the
peremptory period granted by order dated 25.9.2012 is extended
up to 30.10.2012 and as a consequence whereof C.W.J.C.
No.4898 of 2012 stands restored to its original file even as
against respondent no.2.
This restoration application is accordingly allowed.
SKPathak/-
(Jyoti Saran, J)
