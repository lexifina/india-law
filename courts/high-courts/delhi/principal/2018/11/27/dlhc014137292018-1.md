% 27.11.2018
The only ground in this contempt petition for initiation of
contempt proceedings, is that status report has not been filed
within the time granted by this Court.
 Mr. Mishra seeks and is granted two weeks final
opportunity to file status report with advance copy to the
petitioner who may file response thereto, if any, within one
week thereof.
 This contempt petition, accordingly, does not survive for
consideration and is accordingly disposed of with liberty to the
petitioner to file a fresh petition, in case status report is not filed
within time as granted today.
 C.HARI SHANKAR, J
