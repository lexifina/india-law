Judgment / Order
11/07/2018
1. An application for correction in the order dated 05.07.2018
has been moved.
2. It is contended by counsel for the applicant that there is
typographical error in the complaint case. Complaint case
No.363/2015 was mentioned instead of 364/2015 and accordingly,
Bail No.17003/2017 was mentioned instead of 17004/2017.
3. Application for correction is allowed.
4. Considering the contentions in the impugned order dated
05.07.2018 in para No.2, in place of complaint case No.363/2015,
the same be read as 364/2015. Similarly in the title complaint
case No.363/2015 be read as 364/2015.

(2 of 2) [CRLMA-388/2018]
5. Counsel for the petitioner is directed to submit amended
cause-title today itself in Bail Application No.6757/2018.
(PANKAJ BHANDARI),J
