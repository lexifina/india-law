ORDER :
1. This is an Application seeking to set aside the Order dated
August 4, 2025 passed by this Court in the captioned Commercial
Arbitration Application.
2. None of the grounds set out in this Interim Application present a
case warranting review of the Order sought to be reviewed. It has
already been clarified in Paragraph 4 of the Order under review that
any contentions on existential substance need to be addressed in terms
of the Section 16 of the Arbitration and Conciliation Act, 1996 before
the Arbitral Tribunal.
