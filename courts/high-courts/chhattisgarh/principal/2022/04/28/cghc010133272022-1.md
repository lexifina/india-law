Order On Board
28.4.2022
1. Learned State Counsel raises objection with respect to
maintainability of this writ petition on the ground that
petitioner is having efficacious alternative remedy of filing
appeal under Section 44 (2) of the CG Land Revenue
Code, 1959 (for short 'the Code of 1959') as petitioner has
already availed remedy of filing application under the
Code of 1959 and thereafter first appeal under Section 44
(1) of the Code of 1959.
2. After arguing for some time, learned counsel for petitioner

2
seeks permission of this Court to withdraw this petition
with liberty to file appropriate proceedings under the Code
of 1959. However, he prays for return of certified copy of
impugned order Annexure P-1.
3. In view of above submission, writ petition is dismissed as
withdrawn with liberty as prayed for. The Registry is
directed to return back certified copy of impugned order
Annexure P-1 to petitioner, retaining a photocopy of the
same in record.
