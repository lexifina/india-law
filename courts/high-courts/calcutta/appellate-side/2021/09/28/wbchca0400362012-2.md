# Calcutta High Court, CRR/2677/2012, 2021-09-28

Sr.46
 28-09-2021
 Subha.
 Court no. 34
 IN THE HIGH COURT AT CALCUTTA
 CRIMINAL REVISIONAL JURISDICTION
 APPELLATE SIDE
 ( Via Video Conference )
 CRR 2677 of 2012
 In the matter of : Sudhir Mukherjee & Anr. ….petitioners.
In Re : An application under Section 482 of the Code of
Criminal Procedure.
 Mr. Arijit Ganguly
 Mr. Sanjib Kumar Dan
 …..for the State.
 The revisional application has been preferred
challenging the F. I. R registered in connection with Bolpur
Police Station Case No. 262 of 2008 dated 17th December,
2008.
 Mr. Sanjib Kumar Dan, learned advocate appearing
for the State has submitted a report of the Inspector-in-Chage,
Bolpur P.S., Birbhum which reflects that on completion of
investigation, police authorities submitted chargesheet and the
learned Magistrate was pleased to take cognizance of the
offence. Report so submitted by the I/C-in-Charge, Bolpur P.S
be kept with the record.
 Having regard to the contents in the said report, I am
of the view that there has been change of circumstances since

2
the revisional application was preferred before this court.
Accordingly, no interference is called for by this court.
 Thus, the present revisional application being CRR
2677 of 2012 is dismissed.
 All pending applications, if any, in connection with
revisional application, are consequently disposed of.
 Interim order, if any, is hereby vacated.
 All parties are to act on the server copy of this order
duly downloaded from the official website of this court.
 ( Tirthankar Ghosh, J. )
