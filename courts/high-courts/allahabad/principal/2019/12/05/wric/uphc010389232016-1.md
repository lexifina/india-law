Case :- WRIT - C No. - 10237 of 2016
Petitioner :- Zaheer Hasan
Respondent :- State Of U.P. And 2 Others
Counsel for Petitioner :- Mohd. Wasim
Counsel for Respondent :- C.S.C.,Sanjai Singh
Hon'ble Vivek Kumar Birla,J.
Re: Civil Misc. Withdrawal Application No. 4 of 2019
This application is allowed.
Re: Writ Petition
Heard Sri Mohd. Wasim, learned counsel for the petitioner and
Sri L.K. Shukla holding brief of Sri Sanjai Singh, learned
counsel for the respondents.
Learned counsel for the petitioner states that the petitioner does
not wish to press this petition. An application with the same
prayer, which is supported by an affidavit, has also been filed.
Learned counsel for the respondents states that he has no
objection, in case, the withdrawal application is allowed.
Prayer is granted.
Interim order, if any, stands vacated.
This writ petition is accordingly dismissed as not pressed. No
order as to costs.
