# Gauhati High Court, AB/4071/2014, 2014-11-27

AB 4071/2014
BEFORE
HON’BLE MR. JUSTICE C.R. SARMA
Heard Mr. HRA Choudhury, learned senior counsel, assisted by Mr. N. Zaman, learn
ed counsel, appearing for the petitioners and Ms. B. Saikia, learned Addl. Publi
c Prosecutor, Assam, appearing for the State respondent.
Perused the case diary.
By this bail application filed under Section 438 Cr.P.C., 1973, the petitioners
have prayed for pre-arrest bail in connection with Howly P.S. Case No. 467/2014
under Sections 420/ 406 IPC.
Having heard the learned counsel, appearing for both the parties and considering
the evidence so far collected by the Investigating Officer, I find no necessity
for custodial interrogation of the petitioners. Accordingly, the interim order
dated 12.09.2014 is made absolute, subject the condition that the petitioners sh
all appear before the I.O. as and when so required for the purpose of investigat
ion.
Return the case diary.
Bail application is disposed of.
