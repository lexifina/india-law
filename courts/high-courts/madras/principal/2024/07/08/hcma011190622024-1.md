# Madras High Court, Arb Appln/339/2024, 2024-07-08

Arb.Appln.No.339 of 2024
KRISHNAN RAMASAMY, J.
This application has been filed to raise
the order of attachment dated 24.03.2017 made
in I.A.No.19 of 2017 attaching the immovable
property morefully described in the schedule to
the Judges Summons.
2. The learned counsel for the applicant
would submit that the order of attachment was
passed by the learned Arbitrator in a Section 17
application.
3. Further, he would submit that
subsequent to the said order, the dispute
between the parties has been settled amicably
and hence, he requests this Court to allow this
application.
3. Mr.D.Pradeepkumar, learned counsel
takes notice on behalf of the respondent and
would submit that he has no objections in
allowing this application.
4. Considering the above submissions,
this Court is satisfied and is inclined to allow
this application.
5. Accordingly, this Application is
ordered as prayed for.
