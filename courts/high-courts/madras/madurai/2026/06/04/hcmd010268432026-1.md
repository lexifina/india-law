O R D E R
Heard Mr.P.Ranjith Raja for the Civil Revision Petitioner.
2. This Civil Revision Petition challenges the order passed by the
learned Principal District Munsif, Tenkasi, dismissing an application
filed under Section 5 of the Limitation Act to condone the delay in
filing an application under Order IX Rule 7 of the Code of Civil
Procedure.

3. An application under Order IX Rule 7 of the Code does not
require an accompanying application under Section 5 of the
Limitation Act. The defendant, who has been set ex-parte, can appear
before the Court on any subsequent date, and if he shows good cause
for not having appeared on the day on which he was set ex-parte, the
Court will set aside the ex-parte order.
4. Unfortunately, the defendant filed an application under
Section 5 of the Limitation Act, and the learned Judge also
entertained the application and dismissed the same, stating that
sufficient cause had not been made out. When an application under
Order IX Rule 7 need not be accompanied by an application under
Section 5 of the Limitation Act, the order passed by the learned Trial
Judge cannot be sustained.
5. However, Mr.P.Ranjith Raja reports that the suit itself came
to be decreed on 10.03.2026. As the order merges with the decree,
I cannot revise the order now. It is open to the Civil Revision
Petitioner/defendant to file an appropriate application to set aside the
ex-parte decree dated 10.03.2026. In the event he files such an
application, the same shall be considered without reference to the
order impugned herein. It shall be considered on its own merits, if the
