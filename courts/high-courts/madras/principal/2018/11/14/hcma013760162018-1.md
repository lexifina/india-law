ORDER
This Criminal Original Petition has been filed to direct the
second respondent to complete the investigation and file a
final report in Crime No.96 of 2018 on the file of the second
respondent within a reasonable time frame.
https://hcservices.ecourts.gov.in/hcservices/

2. Heard the learned counsel appearing for the petitioner
and the learned Additional Public Prosecutor appearing for the
respondents.
3. The learned counsel appearing for the petitioner would
submit that though the second respondent has registered a case
in the above said crime number on 30.04.2018, no final report is
filed till date.
4. The learned Additional Public Prosecutor appearing for
the second respondent would submit that the second respondent
police may be permitted to file a final report as expeditiously
as possible.
5. In view of the above, the second respondent police is
directed to either file a final report or closure report, as the
case may be, as expeditiously as possible, under due intimation
to the defacto complainant.
6. With the above direction, this Criminal Original
Petition is disposed of.
