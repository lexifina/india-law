# High Court of Rajasthan, CW/4844/2007, 2009-02-04

S.B. Civil Writ Petition No.4844/2007
(Rakesh Kumar Rai Vs. Union of India & ors.)
Date of Order: February 04, 2009
HON'BLE MR. H.R. PANWAR, J.
Mr. P.S. Bhati, for the petitioner.
Mr. Ravi Bhansali, for the respondents.
By an application being IA1712/2009, the petitioner
seeks to withdraw the writ petition with a liberty to file a fresh if
needed.
Learned counsel for the petitioner submits that after
passing the order Annx.2 dated 2-8-2007, the respondent
authority has assured the petitioner for not taking any action in
pursuance thereof and, therefore, the petitioner seeks to
withdraw the writ petition with a liberty to file a fresh if occasion
so arises. Learned counsel for the respondents has no objection
thereto.
The application seeking withdrawal of the writ
petition is allowed.
The writ petition is dismissed as withdrawn with the
liberty to file a fresh if occasion so arises. The interim order is
vacated and the stay petition is also dismissed as withdrawn.
 (H.R.PANWAR), J.
