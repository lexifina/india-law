# Bombay High Court, CAO/707/2025, 2025-07-07

C.A.O. NO. 707/2025 IN M.C.A. ST. NO. 11577/2025
CORAM : REGISTRAR (JUDICIAL)
DATED : 07/07/2025
 The application is taken out for
giving detailed description of the
parties. Office has raised objection
regarding description of parties. In
that regard, counsel for the petitioner
has stated in this application that
inadvertently, counsel for the
petitioner has failed to give detail
description of the parties. Hence,
counsel for the petitioner prays for
providing detailed description of the
parties.
Since the application is formal in
nature, the same is allowed. Necessary
amendment be carried out in the
matter.
 (Premal S. Vithalani)
Dated : 07/07/2025 Registrar (Judicial)
