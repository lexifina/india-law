Mr. R. Sarmah, learned counsel for the petitioners submits that due to
inadvertence some mistakes had occurred in the writ petition and it will be appropriate
for him to withdraw the writ application to be filed again. Accordingly, he seeks to
withdraw the writ petition to liberty to file afresh.
Mr. A. Chakraborty, learned State counsel has no objection.
Accordingly, the writ petition is allowed to be withdrawn with a liberty to file afresh.
