05/Dated: 07/12/2023
 This petition has been filed for quashing the entire criminal
proceeding in connection with Sonari P.S. Case No. 005 of 2016. By way of
filing supplementary affidavit order taking cognizance dated 19.05.2016 is also
challenged.
2. It appears that there are document to be appreciated in the
matter. If such a situation is there, the petitioner is having alternative remedy
to file discharge petition as charge has not been framed as yet.
 3. In view of above, learned counsel for the petitioner seeks
permission to withdraw this petition with liberty to move before the learned
court.
4. Learned counsel for the State has got no objection.
5. Accordingly, this petition is permitted to be withdrawn and
disposed of with the aforesaid liberty. Pending I.A, if any, stands disposed of.
Interim order, if any, stands, vacated.
