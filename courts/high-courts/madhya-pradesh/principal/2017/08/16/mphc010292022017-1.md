# High Court of Madhya Pradesh, WP/8466/2017, 2017-08-16

WP-8466-2017
(SARDAR RAJENDAR SINGH CHANDHOK Vs THE STATE OF MADHYA PRADESH)
16-08-2017
Shri Mukesh Kumar Agrawal, Advocate for the petitioner.
Shri Ashish Barnad, Deputy Advocate General for the
respondents/State.
Heard on I.A. No.11012/2017. which is an application for
withdrawal of the petition.
Learned counsel for the petitioner seeks permission to
withdraw this petition with a liberty to file fresh petition as and
when occasion arises for the current Excise-year.
Permission is granted.
With the aforesaid liberty, petition stands dismissed as
withdrawn.
I.A. No.11012/2017 stands disposed of.
