# Allahabad High Court, CRLAD/544/2015, 2022-04-08

Court No. - 71
Case :- CRIMINAL APPEAL DEFECTIVE No. - 544 of 2015
Appellant :- Masta And 3 Others
Respondent :- State of U.P.
Counsel for Appellant :- Kamini Pandey,Anand Pandey
Counsel for Respondent :- Govt.Advocate
Hon'ble Samit Gopal,J.
Order on Criminal Misc. Delay Condonation Application
No.279758 of 2015
Matter taken up in the revised list. No one appears on behalf of
the appellants.
Sri Ankit Srivastava, learned counsel for the State is present.
The appeal is reported to be beyond time by 896 days.
Vide orders dated 03.09.2015 and 19.09.2015, learned counsel
for the State was directed to file counter affidavit to the delay
condonation application. No counter affidavit has been filed.
I have perused the delay condonation application which is
supported by an affidavit. I do not find good ground for
condoning the delay.
Delay condonation application is rejected.
Order on appeal
Since delay condonation application is rejected, the file be
consigned to record.
