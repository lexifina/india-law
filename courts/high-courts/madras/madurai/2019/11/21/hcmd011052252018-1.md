ORDER
 This petition has been filed to quash the FIR in Crime No. 442
of 2017 on the file of the first respondent police as against the
petitioners.
2. Today, when the matter is taken up for hearing, the learned
Government Advocate (Crl. Side) would submit that the first
respondent has completed investigation and filed final report before
the Judicial Magistrate No.III, Tuticorin and the same has been
taken cognizance in C.C. No. 401 of 2019.
3. The learned counsel appearing for the petitioners submitted
that there is an interim order already passed by this Court not to
file final report.
3. Considering the submission made by on either side, the
prayer sought for in this petition has become infructuous. However,
the petitioner can file appropriate petition for getting appropriate
