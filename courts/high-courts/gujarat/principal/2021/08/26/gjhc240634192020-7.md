CORAM: HONOURABLE MR. JUSTICE PARESH UPADHYAY
Date : 26/08/2021
CAV ORDER
1. This petition was filed apprehending detention under
PASA.
2. Certain information were called for from the detaining
Authority vide order dated 26.03.2021. Before the said
information was provided on this petition, detention order was
passed on 05.04.2021 which was separately challenged by the
petitioner in Special Civil Application No.7254 of 2021. The
execution of the said order was stayed by this Court vide order
dated 13.05.2021. The same is set aside by this Court.
3. No further order needs to be passed on this petition. This
petition is disposed of.
(PARESH UPADHYAY, J)
