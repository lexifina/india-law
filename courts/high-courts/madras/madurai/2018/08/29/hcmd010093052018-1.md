ORDER
This Criminal Original Petition has been filed to direct the
respondent police to file a Final Report before the Judicial
Magistrate Court, Natham, in Crime No.260 of 2014 pending on the file
of the respondent police within a time limit as stipulated by this
Court.
2. Heard learned counsel appearing for the petitioner and learned
Government Advocate (Crl.Side) for the respondent.
3. The learned Government Advocate (Crl.side) would submit that a
report has been filed before the learned Judicial Magistrate, Natham
to the effect that the case is closed as ''undetected''. In any case,
if it is reported as ''undetected'', it is only in the stage of
investigation and the said report could not be taken as a closure
report. Therefore, the respondent is directed to continue the
investigation.
