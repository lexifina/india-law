# High Court of Rajasthan, CRLMB/5160/2016, 2016-05-19

IN THE HIGH COURT OF JUDICATURE FOR RAJASTHAN
 JAIPUR BENCH, JAIPUR
ORDER
SB Cr Misc Fourth Bail Application No.5160/2016
Babulal versus State of Rajasthan
19.5.2016
HON'BLE MR. JUSTICE MN BHANDARI
Mr Anil Upman - for the petitioner
Mr RR Baisla, PP – for the State
Mr Surendra Singh, ASI, PS- Vigyan Nagar, Ajmer - IO
BY THE COURT:
This is the fourth bail application filed by the petitioner. I
find that third bail application was dismissed on 2.11.2015 and no
material change has been pointed by learned counsel for the
petitioner. Hence, fourth bail application is dismissed. It is, however,
with liberty to the petitioner to file fresh bail application if there is
material change or if statements of witnesses have been recorded. If
the statements have already been recorded even prior to dismissal of
this bail application, petitioner would be at liberty to file a fresh bail
application on the basis of the statements so recorded.
(MN BHANDARI), J.
