4 23-08-2022 Heard the parties.
It has been stated by learned counsel for the State in
paragraph 12 of the show cause that it is the petitioner who is at
fault and he has not given the application in the new format
because of this, the order of this Court has not been complied.
The petitioner will file the application in new
format. Thereafter the State will take a decision as per the order
of this Court. If the petitioner is dissatisfied with the order, he
may challenge it in a fresh proceeding.
With the aforesaid observation, this application is
disposed of.
