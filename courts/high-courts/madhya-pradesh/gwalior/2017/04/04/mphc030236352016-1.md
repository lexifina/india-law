# High Court of Madhya Pradesh, WP/6739/2016, 2017-04-04

WP-6739-2016
(VINOD KUMAR SHARMA Vs THE STATE OF MADHYA PRADESH THR)
04-04-2017
None for the petitioner.
Shri C.R.Roman, learned Govt.Advocate for the State.
Petitioner has filed this petition challenging his transfer
from Forest Range, Jaura Beat Chandrapura, to Game Range,
Sabalgarh Khirkhiri Ghat.
Learned Govt. Advocate for the State submits that vide
order dated 5.11.2016 petitioner's transfer has been cancelled,
and therefore, this petition has been rendered infructuous.
In view of this submission that petitioner's transfer has been
cancelled vide order dated 5.11.2016, nothing survives for
adjudication in this petition. Accordingly, this petition is
dismissed as infructuous.
(VIVEK AGARWAL)
