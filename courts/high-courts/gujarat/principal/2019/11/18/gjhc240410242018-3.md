ORAL ORDER
Learned advocate for the applicants is absent.

at bar that charge sheet is filed on 12.02.2019.

to file discharge application and also to file appropriate
proceedings either u/s 397 or 482 of the Code of Criminal

remedy to file discharge application is availed. The present
application stands disposed of with above liberty.
It is clarified that this Court has not examined the
merits of the present application.
