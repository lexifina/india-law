08. 22.03.2010 Nobody appears on call.
On 28.02.2009 the following order was passed:
“No one appears.
Since order dated 18.12.2008 granting
peremptory time to the petitioners to comply with
order dated 24.9.2008 has not been carried out, this
application in respect of O.P. No.2 stands dismissed
and the application will now continue only against
O.P.No.1, the State of Bihar.”
Petitioners assail the order dated 22.06.2007, passed
by the learned Chief Judicial Magistrate, Motihari, whereby
looking to the allegations incorporated in the police report
including the F.I.R., it was found and held that a prima facie case
under Sections 366 and 120B of the Penal Code was made out
against the F.I.R. named accused persons.
This Court finds no infirmity/illegality in the said
order dated 22.06.2007. There is no merit in the application.
It is, accordingly, dismissed.
Sym ( Kishore K. Mandal, J.)
