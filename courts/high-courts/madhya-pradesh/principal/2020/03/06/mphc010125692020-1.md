# High Court of Madhya Pradesh, MP/1340/2020, 2020-03-06

(VISHAL DHAGAT)
JUDGE
The High Court Of Madhya PradeshThe High Court Of Madhya Pradesh
MP-1340-2020
(SACHIN RAIKWAR Vs KU. POONAM @ PURNIMA AND OTHERS)
Jabalpur, Dated : 06-03-2020
Shri Shyam Yadav, learned counsel for petitioner.
Petitioner has filed the present miscellaneous petition being aggrieved
by order dated 06.01.2020 contained in Annexure-P/4.
Learned Claims Tribunal has rejected the application filed by
respondents for examination of Assistant Sub Inspector, R.K. Tiwari.
Application was rejected on the ground that petitioner has not filed any
document of counter FIR which has been registered against the petitioners.
Since no document has been filed, therefore, there is no error in the order
passed by the Claims Tribunal in dismissing the application filed by the
petitioner. However, petitioner will be at liberty to file copy of counter FIR
and file fresh application for examination of Shri R.K. Tiwari. If fresh
application is filed by the petitioner, same will be considered by the Claims
Tribunal.
With the aforesaid liberty, this miscellaneous petition is dismissed.
