Dated this the 20th day of July, 2012
 JUDGMENT
Petitioner made an application to the respondent
Panchayath to construct a LPG Cylinder Storage Godown. That
application for permit was rejected by Ext.P9 order passed by
the first respondent. It is challenging Ext.P9, this writ petition
has been filed.
2. I heard the counsel appearing for the petitioner and the
counsel appearing for the first respondent Panchayath.
3. Reading of Ext.P9 shows that the only reason mentioned
therein is that the Panchayath has received a complaint signed
by 163 residents of the area. Apart from this, no reason
whatsoever has been stated to justify the rejection of the
application of the petitioner. In my view, this order does not
contain any valid reason and for that reason itself Ext.P9 is set
aside.
4. Accordingly, I set aside Ext.P9 and direct the second
respondent to pass orders on the application made by the
