Learned counsel for the petitioner, at the very outset, seeks
permission to withdraw the writ petition with the liberty to file the
same before the Principal Seat at Jodhpur as the industrial plot in
question is situated at Industrial Area, District – Didwana-Kuchaman.
Considering the submission so made, the writ petition is
dismissed as withdrawn with the liberty to file the same before the
Principal Seat at Jodhpur, if so advised.
Pending application(s), if any, shall stand disposed of.
