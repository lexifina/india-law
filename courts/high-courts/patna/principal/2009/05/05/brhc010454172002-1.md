# Patna High Court, CWJC/6244/2002, 2009-05-05

IN THE HIGH COURT OF JUDICATURE AT PATNA
CWJC No.6244 of 2002
PREM KUMAR GUPTA
Versus
THE STATE OF BIHAR & ORS
-----------
6. 5.5.2009 Counsel for the petitioner with reference to the order
dated 18.4.2009 makes prayer for another adjournment.
Such prayer is refused basically because when writ
application was filed on 17.5.2002, the petitioner was required
to file the aforementioned final order dated 10.4.2000. That
having been not done by the petitioner, he cannot be allowed
time till he is satisfied.
This application is accordingly dismissed with liberty
to the petitioner, if so advised, to file fresh writ application.
Narendra/ ( Mihir Kumar Jha, J. )
