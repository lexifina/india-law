ORDER :-
. Heard learned Advocate for the appellant, learned Advocate for
respondent Nos.1 to 5 and learned APP for respondent No.6.
2. Criminal Appeal No.772 of 2019 has been filed by the original
informant under Section 372 of the Code of Criminal Procedure. This
Court by order dated 09.03.2022 has given a detailed order and directed
the action to be taken under Section 390 of the Code of Criminal
Procedure against the respondents – original accused Nos.1 to 5. It
appears that the word admit is then missing, but when the action under
Section 390 of the Code of Criminal Procedure was directed to be taken,
(1)

it presupposes that the appeal is admitted. Now, we need not dwell
upon that, as already a detailed order was passed. Even the State has
filed application for leave to appeal and the same course is then required
to be adopted. Leave is required to be granted to the State also to file
the appeal. Since already there is compliance of the order dated
09.03.2022 under Section 390 of the Code of Criminal Procedure by the
respondents, it need not be once again taken in appeal i.e. filed on
behalf of the prosecution. The same point can be accepted in that case
also.
3. Admit.
4. Call record and proceedings.
5. Matter to come up as per its turn.
