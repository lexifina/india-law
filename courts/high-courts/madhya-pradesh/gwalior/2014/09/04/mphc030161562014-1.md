# High Court of Madhya Pradesh, MCRC/7230/2014, 2014-09-04

M.Cr.C.No.7230/2014
04.09.2014
Shri A.S. Bhadouria, Advocate for the petitioner.
Shri Mukund Bhardwaj, PP for the respondent No.1/State.
This petition under Section 482 of Cr.P.C., has been filed.
It is submitted by learned counsel for the applicant that
applicant has filed an application for anticipatory bail which was
registered in M.Cr.C.No.2401/2014. The same was allowed on
05.05.2014 in which petitioner was directed to move an
application but the applicant could not move the application for
regular bail because there was an strike. The learned Trial Court
has issued non-bailable warrant against him.
It is prayed that the order passed by the Trial Court for
issuing non-bailable warrant be extended.
I have perused the order passed by this Court as well as
the Trial Court.
Considering the aforesaid facts, application is allowed. The
order regarding issuance of non-bailable warrant be set aside
and it is directed that order passed by this Court on 05.05.2014 is
further extended upto 10.09.2014.
(D.K.Paliwal)
