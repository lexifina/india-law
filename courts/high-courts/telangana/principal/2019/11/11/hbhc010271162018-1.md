# High Court for the State of Telangana, WP/12163/2018, 2019-11-11

HONíBLE SRI JUSTICE ABHINAND KUMAR SHAVILI
WRIT PETITION No.12163 of 2018
ORDER :
 Learned counsel for the petitioner has filed a letter
dt.08.11.2019 stating that in view of the subsequent
developments, the petitioner seeks permission of this Court to
withdraw the writ petition with a liberty to the petitioner to file
a fresh writ petition, if necessary.
 Permission is accorded. Accordingly, granting the
aforesaid liberty to the petitioner, this writ petition is dismissed
as withdrawn. No order as to costs.
 As a sequel, miscellaneous petitions pending, if any, in
this writ petition shall stand closed.
