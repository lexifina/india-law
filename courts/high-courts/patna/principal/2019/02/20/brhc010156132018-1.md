ORAL ORDER
2 20-02-2019 It appears that petitioner is one of the applicants for
license of PDS Shop. Annexure-1 is the list of the applicants
which he has mistaken for the merit list.
Learned counsel for the State is correct in saying that
the petitioner has got no cause of action at this stage to file this
writ application because final selection process is still going on.
Further, this court finds that the petitioner has raised a
grievance that name of one Sangita Kumari has been
recommended but on record there is no material to show that
any such recommendation has been made. Petitioner has been
representing the matter before various authorities.

In the opinion of this court at this stage no direction
may be issued.
This Writ Application is dismissed.
