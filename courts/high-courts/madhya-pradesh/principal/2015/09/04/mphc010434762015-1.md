# High Court of Madhya Pradesh, RP/579/2015, 2015-09-04

RP-579-2015
(SYED NASIRUDDIN Vs THE STATE OF MADHYA PRADESH)
04-09-2015
Shri P.K. Mishra, learned counsel for the
petitioner.
Seeking correction in the order dated
29.5.2015 passed in W.P. No. 7879/2015, this
review petition has been filed.
Learned counsel for the petitioner contends
that first and last para, the date of impugned order
has been mentioned as 24th August, 2013, while in
fact, the impugned order is dated 22.5.2015 instead
of 24th August, 2015. It may be permitted to read
accordingly.
Prayer is made seems to be reasonable, hence
it is allowed.
Thus, in first para and last para the date of
impugned order is to be read as 22.5.2015, in order
dated 29.5.2015 passed in W.P. No. 7879/2015.
With the aforesaid observations, this petition
stands disposed of.
(J.K. MAHESHWARI)
JUDGE
