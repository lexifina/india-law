2. 01.03.2011. The petitioner submits that
notwithstanding the order of the Vigilance Officer,
Patna Municipal Corporation dated 20.11.2009 vide
letter no. 784 stopping further construction upon
Plot No.27, 28, Ward No.13 at Bakarganj Bari Path,
P.S. Kadam Kuan in the town of Patna, construction
continues unabated.
Learned counsel for the Municipal
Corporation very fairly submits that if the impugned
order has not been interfered with, varied modified
or set aside by any appellate forum the Municipal
Corporation is bound to implement it.
Counsel for the State similarly submits
that if any such instruction has been issued and the
order has not been very modified or set aside the
Officer-in-Charge is bound to implement the same in
accordance with law.
On the assurance given on behalf of the

Municipal Corporation and the State, the Court has
no occasion to pass any further order at this stage.
The answerability shall lie personally with
the Officer-in-Charge concerned.
The application stands disposed off.
