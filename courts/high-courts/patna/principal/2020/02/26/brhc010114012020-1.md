ORAL ORDER
2 26-02-2020 Heard learned counsel for the petitioner and
learned counsel for the State.
This application has been filed for restoration of Cr.
Misc. No.83798 of 2019 which stood dismissed for non-compliance of order dated 18.12.2019, which was eventually
complied on 09.01.2020 according to the petitioner.
On being satisfied with the reasons mentioned in
this application explaining omission on part of the petitioner, Cr.
Misc. No.83798 of 2019 is restored to its original file and
number subject to the condition that the order dated 18.12.2019
has fully complied on or before 09.01.2020.
Accordingly, this application stands disposed of.
