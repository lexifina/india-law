# Allahabad High Court, WRIC/9994/2018, 2018-03-19

Court No. - 2
Case :- WRIT - C No. - 9994 of 2018
Petitioner :- Naeem Khan
Respondent :- State Of U.P. And 3 Others
Counsel for Petitioner :- Kapil Kumar,Sandhya Singh
Counsel for Respondent :- Kunal Ravi Singh,C.S.C.
Hon'ble Ram Surat Ram (Maurya),J.
Heard Mrs. Sandhya Singh for the petitioner and Sri Rahul Jain, holding
brief of Sri Kunal Ravi Singh for respondent-1.
This writ petition has been filed for quashing the recovery notice dated
10.1.2018, issued in pursuance of the order passed by State Information
Commissioner dated 13.5.2016, by which a penalty of Rs. 25,000/- has
been imposed upon the petitioner for not supplying the information within
time.
A perusal of the order of State Information Commissioner shows that
notices have been issued to the petitioner, but he did not appear before the
State Information Commissioner. The petitioner has filed an application
dated 21.2.2018 for recall of the order dated 13.5.2016, which is pending.
The writ petition is disposed of directing State Information Commissioner
to pass appropriate order on the recall application of the petitioner dated
21.2.2018 within six weeks from the date of producing a certified copy of
this order before him.
Order Date :- 19.3.2018
