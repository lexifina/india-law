3. Petitioner had filed a suit for partition and separate
possession in O.S.No.41/2015 before the Principal
Civil Judge and JMFC, Sankeshwar. In the said suit,
defendant had filed a written statement contending
that one of the properties bearing VPC No.558 had not
been included. Hence the petitioner had filed I.A.No.6
for amendment, which came to be rejected on
25.07.2019. Subsequently, the petitioner filed one
more application in I.A.No.14 seeking for the very
same amendment, which came to be dismissed on
05.02.2025. It is challenging both the orders, the
petitioner is before this Court.
4. I.A.No.6 had been dismissed on 25.07.2019 and had
not been challenged until now. Thereafter the
petitioner filed one more application when the matter

was posted for final arguments, which came to be
dismissed, which is now challenged. I am unable to
accept the submission of learned counsel for the
petitioner that both the orders are now challenged.
The amendment application having been rejected on
25.07.2019, it was required for the petitioner to have
challenged the same within a reasonable period of
time from that date. Instead of doing so, the
petitioner, in order to create one more cause of action,
has filed one more application in I.A.No.14, which
came to be dismissed and thereafter both the orders
have been challenged when the matter is posted for
final arguments.
5. No grounds being made out, the petition stands
dismissed.
