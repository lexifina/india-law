O R D E R
This bail application was filed on 18.10.2019. This
court issued notice to the defacto complainant on
04.11.2019. When this bail application came up for
consideration today, the Registry noted that the process was
not received. Hence, the notice was not sent to the defacto
complainant.
2. The learned counsel for the petitioner submits
that, the petitioner wants time to pay the process. I do not
think that this bail application should be kept pending at
this distance of time. If there is any apprehension of arrest
to the petitioner in crime No. 432 of 2019 of Ollur Police
Station, Thrissur District, the petitioner can file a fresh bail
application in accordance with law.

Bail Appl.No. 7583 of 2019
3
Therefore, this Bail application is dismissed with liberty
to the petitioner to file it again, if he is advised so.
