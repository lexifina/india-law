 State of Jharkhand .................Opposite Party (in both the cases)
CORAM: HON'BLE MR. JUSTICE R.R.PRASAD
For the Petitioner :Mr.Purnendu Kumar Jha
For the State :Mr. Tapash Kabiraj
3/ 14.5.13. Heard learned counsel appearing for the petitioner and learned
counsel appearing for the State.
The ground on which the order dated 20.4.2012 under which
cognizance of the offence punishable under Sections 420, 467, 468, 471, 472,
120B of the Indian Penal Code has been taken is being sought to be quashed
never appears to be tenable as whatever grounds have been taken, those
grounds relate to the defence of the petitioner and therefore, the order taking
cognizance never warrants to be quashed.
However, the petitioner would be at liberty to take all the pleas which
have been taken in this application at an appropriate stage.
Accordingly, this application stands dismissed.
ND/ (R.R.Prasad, J.)
