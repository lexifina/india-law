# High Court of Orissa, ABLAPL/3800/2018, 2018-04-26

05. 26.04.2018 Learned counsel for the petitioner submits that
there is a typographical error in the order dated
27.03.2018 instead of “Balasore Vigilance File No. 24
dated 09.03.2018 it has been reflected as “Bhadrak
Vigilance File No. 24 dated 09.03.2018.
 In view of above, the order dated 27.03.2018 stands
modified to the extent that “Bhadrak Vigilance File No. 24
dated 09.03.2018” be corrected as “Balasore Vigilance File
No. 24 dated 09.03.2018”.
 As prayed for by learned Additional Standing
Counsel for the Vigilance Department list this matter on
03.05.2018.
 Interim order dated 27.03.2018 shall continue till
the next date of listing.
