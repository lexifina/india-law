This is an application moved by the petitioner
seeking amendment to the writ petition. By the said
application, the petitioner seeks to add other grounds
and a prayer clause.
Shri Mishra, the learned counsel appearing
for the sole respondent, opposes the application for
amendment. It is submitted that the petitioner can avail
alternate remedy as according to him there is an
arbitration clause in the agreement.
As the petition is yet to be admitted, the
application for amendment is allowed. It is open for the
respondent to file additional reply, if any, if so desired.
