# High Court of Uttarakhand, WPSS/917/2012, 2012-10-30

WPSS No.917 of 2012
Hon’ble V.K. Bist, J.
 Mr B.S. Adhikari, Advocate for the
petitioner.
 Mr Lalit Miglani, Brief Holder for the
State of Uttarakhand/respondents.
(Delay Condonation Appl. No.10808 of 2012)
 Heard.
 Delay in filing the review application is
condoned. Delay condonation application is
allowed. Review application is treated to be filed
within time.
 Application stands disposed of.
(Review Appl. No.791 of 2012)
 Heard.
 Review application has been filed by the
petitioner for reviewing the order dated
20.07.2012 passed by this Court against the
petitioner. Petition was dismissed on the ground
that petitioner has not challenged the promotional
order. Grounds shown in the review application
are not satisfactory to allow the review
application as there appears no error apparent on
the face of the record in the order dated
20.07.2012.
 Review application is dismissed.
Amendment application no.10809 of 2012 is
rejected.

 (V.K. Bist, J.)
