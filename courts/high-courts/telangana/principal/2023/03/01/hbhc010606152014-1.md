# High Court for the State of Telangana, WP/5402/2014, 2023-03-01

THE HONOURABLE SRI JUSTICE N.V. SHRAVAN KUMAR
WRIT PETITION No.5402 of 2014
ORDER:

 Sri P.Govinda Rajulu, learned counsel for the petitioner
submits that he has given-up vakalatnama to the petitioner
long back.
2. Today, when the matter has been taken up for hearing,
none represented the petitioner. It appears that the petitioner
is not interested in pursuing the Writ Petition. Hence, there is
no other option to this Court except to dismiss the Writ Petition
for non-prosecution.
3. Accordingly, this writ petition is dismissed for non-prosecution.
4. As a sequel, miscellaneous applications, if any pending,
shall stand closed. No order as to costs.
