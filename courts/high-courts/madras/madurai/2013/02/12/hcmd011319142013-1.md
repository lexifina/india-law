 Vs.
1.The Superintendent of Police,
 Madurai District, Madurai.

 Silaiman Police Station, Madurai. ... Respondents
Prayer: Petition filed under Section 482 of the Code of Criminal
Procedure, to direct the second respondent to investigate the case in
Crime No.187 of 2012 and file the final report within a stipulated period.
For Petitioner : Mr.V.Srinivasan
 For Respondents : Mr.S.P.Maharajan
Govt. Advocate (Crl.Side)
ORDER
This petition has been filed to direct the second respondent to
investigate the case in Crime No.187 of 2012 and file the final report
within a stipulated period.
2.Heard both side.
3.At the request of the learned Government Advocate (Criminal Side)
the respondent police is directed to investigate the case in Crime No.187
of 2012 on the file of the respondent police and file a final report
within a period of four weeks from the date of receipt of a copy of this
order.
4. With the above direction, this petition is disposed of.
