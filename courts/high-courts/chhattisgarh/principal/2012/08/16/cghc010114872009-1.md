Heard.
2. This is an application filed by the applicants/plaintiffs
seeking permission to file an appeal under Secdon 96 of Civil
Procedure Code (herein after called the Code') as indigent
persons under Order 44 Rule 1 of the Code against judgment
and order dated 06.05.2006 passed by 2nd Additional District
Judge, Jagdalpur in Case No.2-B/2005.
3. Notice on this application was sent to the State and
also to the respondents. They have not controverted the
contents of the application.
4.' Having perused the contents of the application and the
fact that the applicants were permitted to file a suit, out of
which this appeal arises, as indigent persons before the trial
Court, in our view, the application for filing an appeal as a

is hereby allowed.

which is to be registered in pursuant of this order for record.
7. No cost.
