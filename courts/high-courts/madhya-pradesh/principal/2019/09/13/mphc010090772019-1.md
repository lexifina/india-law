# High Court of Madhya Pradesh, MCC/381/2019, 2019-09-13

HIGH COURT OF MADHYA PRADESH
M.C.C.No.381/2019
JABALPUR : 13/09/2019
Shri S.K.Pathak, Advocate for the applicant.
Mohd. Rizwan Khan, Govt. Advocate for the respondent/State.
Applicant has filed Document No.7140/2019 for taking certain
documents on record.
The documents enclosed are taken on record.
Heard. Perused the record of M.Cr.C.No.22436/2016.
This application has been filed for modification/correction of the
order dated 21.1.2019 passed in M.Cr.C.No.22436/2016.
Having heard learned counsel for the applicant and on perusal of
the record of M.Cr.C.No.22436/2016 it is evident that in first
paragraph of the order dated 21.1.2019 words “Judicial Magistrate First
Class Panna as Criminal Case No.3016/16” has wrongly been
mentioned whereas it should have been “Judicial Magistrate First Class
Rewa in Criminal Case No.363/16”. It is also evident that in the
operating paragraph words “Criminal Offence No.3063/16” have
wrongly been mentioned whereas it should have been “Criminal Case
No.363/16”.
In the circumstances, it is directed that in first paragraph of the
order dated 21.1.2019 passed in M.Cr.C.No.22436/2016, words
“Judicial Magistrate First Class Panna as Criminal Case No.3016/16” be
read as “Judicial Magistrate First Class Rewa in Criminal Case
No.363/16”. It is further directed that in operating paragraph of the
aforesaid order words “Criminal Offence No.3063/16” be read as
“Criminal Case No.363/16”.
 This order shall be read conjointly with the order dated 21.1.2019
passed in M.Cr.C.No.22436/2016.
 With the aforesaid modification, this petition stands disposed of.
 C.C. as per rules.
 (J.P.Gupta)
 Judge
