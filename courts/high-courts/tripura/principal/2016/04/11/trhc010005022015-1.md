# High Court of Tripura, WP(C)/241/2015, 2016-04-11

Case No :WP(C) 0000241/2015
Party Name : ARINDAM GHOSH Vs THE STATE OF TRIPURA
THE HONBLE MR. JUSTICE S.TALAPATRA
Mr. D.K. Biswas, learned counsel appearing for the petitioner has submitted that he has the
instruction to withdraw this petition with leave reserved to the petitioner to file afresh on the
same cause of action, if so requires.
The leave is granted.
Accordingly, this petition stands dismissed as withdrawn with liberty reserved to the
petitioner to approach this Court again on the same cause of action and/or any other cause
of action if those are combined together.
Mr. B.C. Das, learned Advocate General along with Mr. B. Banerji, learned counsel appears
for the respondents.
No order as to costs.
