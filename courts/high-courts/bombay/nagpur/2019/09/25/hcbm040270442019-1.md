Heard.
The learned counsel for the appellant submits that
during the pendency of this appeal, the victim in this crime
has expired and therefore Section 302 of the Indian Penal
Code is also added in this crime against the appellant.
Learned counsel prays to add Section 302 of the Indian Penal
Code in the order of this Court dated 18th September, 2019.
A perusal of the order directing release of the

2 appa858.19
applicant on bail shows that we have only mentioned crime
number and not the offences involved in the said crime.
Therefore, there is no need to modify our said order.
In this view of the matter, the application stands
disposed of.
