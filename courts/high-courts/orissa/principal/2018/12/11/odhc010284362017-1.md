# High Court of Orissa, WP(C)/6299/2017, 2018-12-11

09. 11.12.2018 On 27.08.2018 the following order was passed:
 “Learned counsel for the petitioner requests
for time to file rejoinder.
 List this matter on 11.9.2018.”

 Again on 20.11.2018 the following order was passed.
 “Learned counsel for the petitioner is not
present.
 As a last chance, list this matter on
11.12.2018.”
 Today learned counsel for the petitioner requests for
time to file rejoinder affidavit. We decline the same.
 Accordingly, the writ petition stands dismissed for
default.
 Learned counsel for the petitioner may file the
restoration petition within thirty days failing which the same will
not be considered.
