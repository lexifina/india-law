CORAM:- URMILA JOSHI-PHALKE, J.
DATED :- AUGUST 04, 2023.
Heard.
2. The application is for grant of bail filed under
Section 439 of the Code of Criminal Procedure.
3. After hearing the learned Counsel for the
applicant to some extent and after going through the
investigation papers, this Court is not inclined to grant
bail.
4. Learned Counsel for the applicant seeks to
withdraw the application and submitted that the liberty be
granted him to file an application, if there is no substantial
progress within six months.
5. Hence, the application is disposed of as
withdrawn with liberty to file afresh, if there is no
substantial progress in the trial within one year.
