# High Court of Uttarakhand, AO/171/2010, 2010-08-09

AO No.171 of 2010
Hon’ble Tarun Agarwala, J.
Heard Mr. Kanwaljit Singh, the learned counsel for the
appellants.
This is an appeal filed under Order 43 Rule 1(r) of the Code
of Civil Procedure against the order rejecting the application
under Order 39 Rule 2-A of the C.P.C. The only submission of
the learned counsel for the appellants is that he was not heard on
the application filed under Order 39 Rule 2-A of the C.P.C.,
whereas the order dated 25th February, 2010 indicates that both
the parties were heard.
In view of the aforesaid, this court is not inclined to
interfere in the impugned order on this ground. The appeal is
dismissed. It would be open to the appellants to file a recall
application before the court below in the event they were not
heard.
 (Tarun Agarwala, J.)
Dated 09.08.2010
