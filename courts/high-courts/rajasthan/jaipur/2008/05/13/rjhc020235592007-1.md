# High Court of Rajasthan, CMA/1064/2008, 2008-05-13

IN THE HIGH COURT OF JUDICATURE FOR RAJASTHAN
AT JAIPUR BENCH, JAIPUR
ORDER
S.B.CIVIL MISC. APPEAL NO.1064/2008.
Brij Mohan Agarwal.
VERSUS
Narayani Devi & Others.
13.05.2008.
HON'BLE MR.JUSTICE DALIP SINGH
Mr.Anil Upman, for the appellant.
*****
Learned counsel for the appellant submits
that since the appeal has been filed against
the order passed by the learned M.A.C.T.
against which only a writ petition could be
filed. He wants to withdraw this misc. appeal
with liberty to file a writ petition against
the impugned order.
This appeal is accordingly dismissed as
withdraw with liberty to file writ petition, if
so advised. The Registry is directed to return
the certified copy of the impugned order dated
23.08.2007, after retaining a photostat copy of
the same on record.
(DALIP SINGH),J.
Solanki DS, Jr.P.A.
