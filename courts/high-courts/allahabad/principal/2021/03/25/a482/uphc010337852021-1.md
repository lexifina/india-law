# Allahabad High Court, A482/5487/2021, 2021-03-25

Court No. - 77
Case :- APPLICATION U/S 482 No. - 5487 of 2021
Applicant :- Sumit Kumar Soni
Opposite Party :- State of U.P. and Another
Counsel for Applicant :- Gaurav Singh Tomar
Counsel for Opposite Party :- G.A.
Hon'ble Pankaj Bhatia,J.
This is the second application for the same cause of action. The
applicant had filed an application under Section 482 Cr.P.C.,
which was disposed of vide order dated 23.1.2020 passed in
Application U/s 482 Cr.P.C. No. 3069 of 2020.
In view of the fact that the applicant had already approached
this Court. The second application is not maintainable for the
same cause of action.
The application is rejected.
Order Date :- 25.3.2021
