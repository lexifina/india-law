ORAL ORDER
2 23-03-2018 Heard.
This application has been filed for restoration of M.J.C.No.
3623 of 2014 which stood dismissed for non-compliance of
order dated 22.12.2017, which was eventually complied on
11.01.2018 according to the petitioner.
On being satisfied with the reasons mentioned in this
application explaining omission on part of the petitioner,
M.J.C.No. 3623 of 2014 is restored to its original file and
number subject to the condition that the order dated 22.12.2017
has fully complied on or before 11.01.2018.
Accordingly, this application stands disposed of.
