# High Court of Madhya Pradesh, MCC/1161/2015, 2015-10-28

MCC-1161-2015
(NAND KISHORE VYAS Vs THE REGISTRAR GENERAL)
28-10-2015
 Shri V. Bhide, learned counsel for the petitioner.
 This application has been filed for restoration of W.P.
No.254/2013, which was dismissed for want of prosecution
on 13.01.2015. There being some delay, I.A. No.5535/2015
has been filed.
 Keeping in view the reasons given the application
which is supported by the affidavit of counsel himself and
finding the same to be bonafide, both the applications are
allowed.
 Condoning the delay in filing the restoration
application, the restoration application itself is allowed, W.P.
No.254/2013 is restored to its original file. It be placed for
orders before an appropriate Bench.
 Application stands allowed and disposed of.
(RAJENDRA MENON)
JUDGE
(KESHAV KUMAR TRIVEDI)
JUDGE
