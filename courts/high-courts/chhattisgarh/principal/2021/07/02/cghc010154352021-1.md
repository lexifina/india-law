Shri Rahul Agrawal, counsel for the petitioners.
Heard on MCC application for correction of the order dated 10/06/2021
passed in contempt petition No.1038/2019.
It is stated that in para 2 of the order wrongly it has been mentioned as
khasra No.339/1 but actually it should have been khasra No.369/1 and in
para 2 and 3 name of Jhumuk Lal has wrongly been written as Jhamuk Lal.
On due consideration, MCC is allowed.
Accordingly, it is ordered that in the order dated 10/06/2021 passed in
contempt petition No.1038/2019 in para 2 of the order in place of khasra
No.339/1 it be read as khasra No.369/1 and in para 2 and 3 of the order
name 'Jhamuk Lal' be read as 'Jhumuk Lal'. Sd/-
 (Goutam Bhaduri)
