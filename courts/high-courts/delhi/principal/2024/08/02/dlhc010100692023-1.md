JOINT REGISTRAR (JUDICIAL) BHAWANI SHARMA
 O R D E R
% 02.08.2024
 File is placed before this Court vide order dated 07.02.2024 to
release the amount in favour of decree holder subject to furnishing the
security.
 Report from the SDM, Loni is received. The same is gone
through. As per which, the total valuation of the property is Rs.
2,11,93,200/-.
 It is observed that the amount which is directed to be released is
Rs. 03 Crore plus. Hence, being the lesser value of the property, this
security cannot be accepted for sound security for release.
 Learned counsel for decree holder seeks some time to file the
response to the present report filed through the SDM, Loni. Heard.
Allowed.
 Learned counsel for judgement debtor also seeks some time to
file the response to the present report filed through the SDM, Loni.
 Renotify on 03.10.2024.
 BHAWANI SHARMA
