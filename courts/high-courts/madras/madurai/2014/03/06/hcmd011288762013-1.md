O R D E R
This application is filed seeking for a direction directing the
first and second respondents to register the case based on the complaint
given on 11.12.2008, investigate the same and file a final report within
the period that may be specified by this Court.
2. When the matter was taken up for hearing, the learned counsel
for the petitioner is permitted to withdraw the present application as
not pressed with liberty to file a fresh application after given a fresh
complaint making out cognizable offence against the accused.
3. Hence, this petition is dismissed as withdrawn.
