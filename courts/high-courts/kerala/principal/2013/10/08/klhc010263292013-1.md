J U D G M E N T
S. Siri Jagan, J
The State is the appellant in this appeal.
Certain properties belonging to the first respondent was
acquired by the State for the purpose of the 2
nd
respondent, as per a notification dated 23.11.2003,
issued under Section 4(1) of the Land Acquisition Act.
The land acquisition officer, fixed the land value at
₹2,16,887/- per are. On reference, the Sub Court,
Thiruvananthapuram, in L.A.R. No.456/2005 enhanced
the land value to ₹ 16,54,307/- per are. Challenging the
land value fixed by the Sub Court, the State has filed this
appeal. Now, both sides admit that, for comparable
properties, this court has in L.A.A.Nos.291/2009,
445/2009, 70/2009, 125/2012 and 2452/2008, re-fixed the
land value of ₹ 14,00,000/- per are and therefore, the
same value has to be fixed for the land acquired from the
first appellant also. Accordingly, this appeal is disposed

L.A.A.No.128 of 2013
2
of, re-fixing the land value for the property acquired from
the first respondent as ₹ 14,00,000/- per are.
