10.Ergo, the sequitur is, captioned HCP is allowed. Impugned
preventive detention order dated 08.04.2023 bearing reference H.S.
(M)Confdl.No.56/2023 made by the second respondent is set aside
and the detenu Thiru.Jeyaprakash, aged 35 years, son of
Thiru.Jeyaraman, is directed to be set at liberty forthwith, if not
required in connection with any other case / cases. There shall be no
order as to costs.
