# High Court of Madhya Pradesh, MCC/16/2014, 2014-01-24

M.C.C.No.16/2014
Tarun Kishor Pardhi Vs. State of MP & Ors.
24/01/2014
Shri Vipin Yadav, learned counsel for the applicant.
This application has been filed for restoration of
W.P.No.13936/2013, which was dismissed in view of the
peremptory order passed by this Court.
Keeping in view the grounds raised in the application and
finding the same to be bona-fide, the application for restoration is
allowed. W.P.No.13936/2013 be restored to it's original file. It be
placed for orders before the appropriate bench.
With the aforesaid, the application stands allowed and
disposed of.
(Rajendra Menon)
Judge
