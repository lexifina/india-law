# High Court of Madhya Pradesh, CONCR/4/2014, 2014-07-31

CONCR No.04/14
31/07//2014

Having heard the applicant in person, we find that
this application is wholly misconceived, therefore, no case
is made out for initiating action for contempt against the
respondents.
If wrong statement is made before the court in
W.A.No.688/2013, the applicant should file an appropriate
application in the said case for taking action.
In view of the above, no case is made out for initiating
action for contempt.
 Therefore, this application is dismissed.
 (RAJENDRA MENON) ( ALOK VERMA )
 JUDGE JUDGE
