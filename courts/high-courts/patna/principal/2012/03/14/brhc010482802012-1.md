ORAL ORDER
2 14-03-2012 Petitioner claims that he was appointed as Shiksha Mitra
by Memo No.7 dated 5.12.2005 and was allotted the School.
However, the new Mukhiya did not allow him to join.
First application of the petitioner on record in this regard
is Annexure-3, which is dated 4.6.2008. Thereafter, a
representation, which is Annexure-4, is dated 24.3.2009. Even
after that, petitioner has taken steps to file this writ application
only on 6.3.2012.
Clearly, writ application suffers from gross delay and
laches and is an attempt to abuse the process of the Court.
This writ application is dismissed.

Pradeep/-
(Jayanandan Singh, J)
