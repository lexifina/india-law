ORDER
This criminal miscellaneous case is filed to quash the
proceedings in C.P. No.33/2015 on the file of the Judicial First
Class Magistrate Court-I, N.Paravur, arising from Crime
No.550/2013 of N.Paravur Police Station.
2. When this criminal miscellaneous case came up for
consideration, this Court directed the Registry to get a report
about the present stage of the case. The Judicial First Class
Magistrate Court-I, N.Paravur submitted a report stating that
the case is already committed to the Sessions Court on
24.07.2019. The Sessions Court submitted a report stating
that accused Nos.1, 2 and 4 filed discharge petitions and the
same is pending as Crl.M.P. Nos.65/2020 and 115/2021. The
case is posted for hearing these discharge petitions on
11.10.2024.
3. If that is the case, this Court need not interfere
with the proceedings pending before the trial court. All the

CrlM.C..No.7273/2015
3
contentions raised by the petitioners in this case are left open
and the petitioners are free to raise the same before the trial
court in the discharge petitions at the appropriate stage.
With the above observation, this criminal miscellaneous
case is disposed of.
