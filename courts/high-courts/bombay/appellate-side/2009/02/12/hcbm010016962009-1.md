# Bombay High Court, APPLN/222/2009, 2009-02-12

IN THE HIGH COURT OF JUDICATURE AT BOMBAY
 CRIMINAL APPELLATE JURISDICTION
 CRIMINAL APPLICATION NO. 222 OF 2009
 Mr.Jagdevsingh Gurudevsingh Insa ...Applicant
 (Orig.Accused No.1)
 vs.
 The State of Maharashtra ...Respondent
 Mr.Nitin Pradhan, Senior Counsel i/b. Ms.Subhada Khot
 for the Applicant.
 Mr.Rajesh More, APP for the State.
 CORAM : V.M. KANADE, J.
 DATED : FEBRUARY 12, 2009
 P.C. :-
 1. Heard Counsel for the applicant.
 2. The applicant seeks permission to withdraw this
 application with liberty to file the application if the
 trial is not over within a period of six months.
 3. The application is allowed to be withdrawn with
 liberty as prayed. All contentions of this application
 are kept open. The trial court is directed to decide
 the case, as expeditiously as possible and if possible,
 within six months from today.
 4. The application is disposed of.
 (V.M. KANADE, J.)
