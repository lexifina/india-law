 1. Heard Counsel for the parties.

 : 2 :
 2. Although these Applications are opposed by
 the Respondents, in my opinion, in the interest of
 justice, the same deserve to be allowed. This is
 so because the main matters were dismissed for want
 of service on Respondents. Now that the
 Respondents are appearing before this Court, that
 objection does not survive any longer.
 3. Accordingly, as mentioned earlier, in the
 interest of justice, these Applications are allowed
 in terms of prayer clauses (a) and (b). Appeals
 from Order is restored to the file to their
 original numbers.
 4. Interim relief which was granted earlier
 while entertaining the Appeals from Order will
 continue till the disposal of the Appeals from
 Order.
