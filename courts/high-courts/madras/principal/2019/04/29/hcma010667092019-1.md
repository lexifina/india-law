# Madras High Court, A/3466/2019, 2019-04-29

1
A.No. 3466 of 2019
in
C.S.No. 301 of 2017
R.SUBRAMANIAN, J.
This application has been filed seeking to set aside the order dated
26.02.2019 setting the defendants 1 and 2 exparte.
2. The order came to be passed for non filing of written statement. It is
stated in the affidavit filed along with this application that written statement
along with an application to condone the delay has been filed.
3. Considering the reasons assigned in the affidavit filed in support of this
application, this application is allowed, exparte order dated 26.03.2019 is set
aside.
Registry is directed to number the application for condone the delay in
filing written statement and post on 03.06.2019.
