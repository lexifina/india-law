1. Heard Mr. Nasimuddin Ansari, learned counsel for petitioners as well
as Mr. Shashank Thakur, learned Additional Advocate General,
appearing for the State/respondent.
2. Learned counsel for the petitioners submits that he has filed I.A. No.
03/2026 i.e. application for exemption from depositing of security
deposit.
3. The said application i.e. I.A. No.03/2025- Application for exemption
from payment of security deposit stands rejected.
4. In view of the above, learned counsel for the petitioners prays to
withdrawn the present petition with liberty to file afresh after
depositing the security amount.
5. Accordingly, the present petition stands dismissed as withdrawn
with liberty to file afresh after depositing the security deposit as per
High Court Rules.
