# High Court of Madhya Pradesh, WP/16930/2015, 2016-01-04

WP-16930-2015
(ARVIND KUMAR SHUKLA Vs THE STATE OF MADHYA PRADESH)
04-01-2016
Shri V.K. Dubey, learned counsel for the petitioner.
Shri A.P. Singh, learned Government Advocate for the
respondent/ State.
Smt. Sudha Gautam, learned counsel for the intervener.
The petitioner has filed this petition against the order of transfer
dated 10/09/2015 by which the petitioner has been posted at Barhi.
An application for intervention has been filed and it is
mentioned in the application that subsequently vide another order
dated 21/09/2015, the order dated 10/09/2015 has been modified. By
the aforesaid order, the petitioner has been posted from Pondi to
Naktara. The petitioner has not challenged the order dated 21/09/2015
neither controverted the fact that by order dated 21/09/2015, earlier
order of transfer dated 10/09/2015 has been modified.
In view of the subsequent development and the order dated
21/09/2015, in my opinion, the present petition has become
infructuous. The petitioner is at liberty to file appropriate proceedings
against the subsequent order dated 21/09/2015, if he wants to
challenged the same.
With the aforesaid observation, the writ petition is disposed of.
(S.K. GANGELE)
JUDGE
 MISHRA
