ORDER
This writ petition is filed challenging an order
passed under order 7 Rule 11(d) of the Code of Civil
Procedure.
2. Office has raised an objection regarding
maintainability of this writ petition in view of the
remedy under Section 115 of the Code of Civil
Procedure.
3. Apparently, a revision is maintainable since
any order allowing the Revision against an order
under order 7 Rule 11(d) would result in disposal of
the suit. Therefore, revision under Section 115 of the
Code of Civil Procedure is alone maintainable.
4. Hence, office objection regarding
maintainability is upheld. Petition is dismissed.
Liberty is reserved to the petitioner to file a
revision petition.

4

Office is directed to return the certified copy of
the impugned order to the petitioner after retaining a
photocopy.
