# High Court of Madhya Pradesh, MCRC/6316/2015, 2015-07-23

M.Cr.C. NO.6316/2015
23.07.2015
Shri A. Salim, learned counsel for the applicant.
Ms. Mini Ravindran, P.L for State.
After arguing some time, learned counsel for the
applicant seeks permission to withdraw this bail
application with the liberty that applicant surrender
before the concerned court and apply for regular bail.
This application is dismissed as withdrawan with
the aforesaid liberty and with the direction to the
concerned court, that if such application will file, same
should be disposed of as expeditiously as possible.
Certified copy as per rules.
