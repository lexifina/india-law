This Application coming on this day before this court for hearing the

This application has been filed to direct the respondent to furnish
security for a sum of Rs.6,46,868/-, failing which, to pass an order of
attachment of the immovable properties morefully described in the schedule
to the Judges Summons pending disposal of arbitration proceedings and till
enforcement of the award passed in the arbitration proceedings.
2. The learned counsel appearing for the applicant would submit that
already award has been passed.
3. In such view of the matter, It is for the applicant to enforce the
award as per law.
4. Accordingly, this application is closed. No costs.
