ORAL ORDER
2 24-09-2014 This is an application seeking recall of the order dated
22.08.2014 passed in Criminal Miscellaneous No.26353 of 2014 in
connection with Lakhisarai Mahila P.S. Case No.51 of 2013, pending
before the Chief Judicial Magistrate, Lakhisarai.
Learned counsel for the petitioners seeks permission to
withdraw this application with a liberty to file a fresh application under
Section 438 of the Code of Criminal Procedure, if at all situation so arises.
Permission is granted.
Accordingly, this application stands disposed of as
withdrawn.
Let this order be communicated to the court aforementioned
through FAX at the cost of the petitioners.
