This is an application filed under Section 151 of the Code of Civil Procedure,
1908 for restoration of the accompanying Civil Revision Petition which was
dismissed for default vide an order dated 16.12.2021.
2. This Court has duly perused the order dated 16.12.2021 and from the

Page No.# 2/2
same it appears that on various occasions, the applicant having not appeared
for which this Court had dismissed the said revision application for default.
3. Mr. P. Upadhyay, the learned counsel appearing on behalf of the Applicant
submits that there was certain miscommunication between the applicant and
the earlier counsel for which the applicant was not represented before this
Court. For the ends of justice, this Court recalls the order dated 16.12.2021 by
restoring the accompanying Civil Revision Petition.
4. I.A. stands disposed of.
