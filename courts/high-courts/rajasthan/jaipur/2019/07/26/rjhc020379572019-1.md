HON'BLE MR. JUSTICE PANKAJ BHANDARI
Judgment / Order
26/07/2019
1. Petitioners have preferred this Criminal Miscellaneous
Petition seeking fair investigation.
2. Learned Public Prosecutor submitted a report. As per which
Police has already submitted negative final report.
3. In view of the same, the present Criminal Miscellaneous
Petition has become infructuous and the same is accordingly
dismissed as having become infructuous.
4. Report submitted by the learned Public Prosecutor is taken
on record.
5. However, petitioners would be free to approach the
Magistrate concerned and file protest petition, is so advised.
(PANKAJ BHANDARI),J
