Order
31/08/2024
1. Petitioner has filed an application (1/2024), seeking
withdrawal of this writ petition, in order to file an appeal against
the order dated 08.08.2024, whereby his objections under Order
21 Rule 97 CPC has been dismissed.
2. Counsel for petitioner admits that as per Order 21 Rule 103
CPC, impugned order is appellable.
3. In view of above, the application (1/2024) is allowed and
the present writ petition is ordered to be withdrawn with liberty to
petitioner, to file appeal against the order dated 08.08.2024.
4. All pending application(s), if any, stand(s) disposed of.
