Heard both sides. Mr.Arun Pradesh, learned counsel, takes notice
on behalf of the respondents 1 to 3 / plaintiffs.
2. A.No.349 of 2021 has been filed to condone the delay of 18
days in filing the application to set aside the ex parte order dated
20.11.2020; A.No.487 of 2021 has been filed to set aside the ex parte order
dated 20.11.2020 setting forth the applicant ex parte; and A.No.488 of 2021
has been filed to condone the delay of 795 days in filing the written
statement.
3. Today, when these applications are taken up for hearing, the
learned counsel appearing for the first respondent appeared through Video
Conferencing and made submission that he has no objection in allowing the
above referred applications.
4. It is seen that the application to set aside the ex parte order has
been filed with a delay of 18 days, only because of the reason that the first
defendant has not filed written statement within a stipulated period, the
ex parte order has been passed against him. On the other hand, today, along
with the application filed to set aside the ex parte order, the first defendant
has filed the written statement. Therefore, in order to give a fair opportunity
