# Calcutta High Court, CRR/2279/2012, 2021-09-27

D/L34
September
27, 2021
Bpg.
C.R.R. No.2279 of 2012
(Via Video Conference)
In Re: An application under Section 401 read with Section 482 of the
Code of Criminal Procedure.
 Anup Biswas & Anr.
 Versus
 The State of West Bengal & Anr.
Mr. Arijit Ganguly,
 Mr. Saryati Datta.
 …for the State.
Mr. Saryati Datta, learned advocate appearing for the
State submits the report of the concerned Officer of Chapra Police
Station.
Let the report be kept with the record.
The report reflects that in connection with Chapra Police
Station Case No.439 of 2009 dated 06.10.2009, the accused
persons have been acquitted from the charges. As such, the
revisional application has become infructuous. Thus, no
interference is called for.
Accordingly, CRR 2279 of 2012 is dismissed.
Pending application, if any, is consequently disposed of.
Interim order, if any, is hereby vacated.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
 (Tirthankar Ghosh, J.)
