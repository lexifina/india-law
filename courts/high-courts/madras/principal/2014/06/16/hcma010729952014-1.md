DATED: 16.06.2014
CORAM
THE HONOURABLE MR. JUSTICE T.S.SIVAGNANAM

G.Sundaramoorthy ...Petitioner
vs.
State by the
Inspector of Police
Redhills Police Station
Redhills
Chennai ...Respondent
Criminal Original Petition filed under Section 482 of the
Criminal Procedure Code praying to direct the respondent to file the
final report in Crime No.734/2013 pending on the file of the
respondent police.
For Petitioner : Mr.K.Suthan
For Respondent : Mr.C.Emalias,
 Additional Public Prosecutor
O R D E R
This petition has been filed seeking a direction to the
respondent to file the final report in Crime No.734/2013 pending on
the file of the respondent police.
2. Heard the learned counsel for petitioner and the learned
Additional Public Prosecutor.
3. Considering the facts and circumstances of this case, this
Court considers it appropriate to direct the respondent to file final
report in Crime No.734/2013 as expeditiously as possible, preferably
within a period of three months from the date of receipt of a copy of
this order, if not already filed.
https://hcservices.ecourts.gov.in/hcservices/

4.The Criminal Original Petition is disposed of with the above
direction.
