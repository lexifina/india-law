ORDER
This petition has been filed to direct the respondent police to file
the final report in Crime No.354 of 2012 on the file of the respondent
police.
2.Heard both sides.
3.At the request of the learned Government Advocate (Criminal Side)
the respondent police is directed to complete the investigation in Crime
No.354 of 2012 on the file of the respondent and file the final report
within a period of two months from the date of receipt of a copy of this
order.
4. With the above direction, this petition is disposed of.
