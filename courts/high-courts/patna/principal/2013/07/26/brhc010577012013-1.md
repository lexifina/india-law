ORAL ORDER
3 26-07-2013 Heard learned counsel for the petitioner and learned counsel
for the State.
 This application has been filed for quashing the order dated
10.12.2012 passed by the Sessions Judge, Patna in Criminal Revision
No.374 of 2012 by which he has affirmed the order dated 5.5.2012
passed by the Judicial Magistrate, Ist Class, Patna in Parsa Bazar P.S.
Case No.71 of 2010, G.R. No.2389 of 2010 by which he has rejected
the petition filed by the petitioner under Section 239 of the Code of
Criminal Procedure.
 After some argument, learned counsel for the petitioner seeks
permission to withdraw this application with a liberty to raise all points
before the court below at the appropriate stage.
 Permission is accorded. Accordingly this application is
dismissed as withdrawn with the aforesaid liberty.
Vinay/- (Shivaji Pandey, J)
