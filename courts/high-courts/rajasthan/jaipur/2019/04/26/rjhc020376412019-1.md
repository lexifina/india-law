Order
26/04/2019
Heard on application for correction in the order dated
23.04.2019. Counsel for the petitioner submits that due to
typographically error in para No.2 of the order Section 164 of
Cr.P.C. has been wrongly mentioned, whereas, it should have been
Section 161 Cr.P.C.
Considering the submissions put forth in para No.2 of
the order dated 23.04.2019 Section 164 of Cr.P.C. be read as
Section 161 Cr.P.C.
Ordered accordingly.
The application stands disposed of.
