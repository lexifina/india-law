PER COURT :-
1. Heard both the sides.
2. The learned advocate for the applicant, on instructions
seeks leave to withdraw the application with permission to file the
application, if the trial is not concluded within six months.
3. Leave granted. The application is dismissed as withdrawn.
4. If the trial is not concluded within six months, the applicant
is at liberty to file the application for bail before the trial Court.
5. The trial Court is directed to conclude the trial as
expeditiously as possible and in any case within six months from
today. The trial Court shall conduct this case as expeditiously as
possible by keeping it twice or thrice in a week. Needless to mention,
it is a session as well as special case. The session means once it is
started, it should not be stopped till the conclusion of trial. If the
