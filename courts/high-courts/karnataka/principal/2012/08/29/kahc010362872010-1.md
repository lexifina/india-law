ORDER
This Petition has been filed seeking to set aside the
order dated 10-12-2009 passed by the trial Court wherein
the application filed seeking to recall the order was rejected
and declined to accept the written statement.
2. The learned counsel for the petitioner contends
that an identical order passed by the trial court was
challenged by the 3rd respondent before this Court in Writ
Petition No.23951/2010, wherein by the order dated 2-8-
2011 the Petition was allowed. The order refusing to receive

4
the written statement was set aside and the delay was
condoned. Hence he pleads that an identical order be made
applicable to the petitioners herein.
3. The learned counsel for respondent No.1 is
absent.
4. On hearing the learned counsel and examining
the impugned order I’am of the considered view that the
relief granted in Writ Petition No.23951/2010, requires to
be extended to these petitioners also. Under these
circumstances, the relief claimed being identical the same
relief requires to be granted. For the aforesaid reasons, the
order dated 10-12-2009 passed by Additional Civil
Judge(Junior Division), Chikkaballapur in O.S.No.168/2000,
is set aside. The petitioners are permitted to file their
written statement. Consequently the application filed by the

5
petitioner under Section 151 of CPC is allowed.
 Writ Petition is disposed off accordingly.
