# Madras High Court, A/3010/2015, 2015-04-27

Application No.3010 of 2015
in
C.S.No.769 of 2014
S.VIMALA, J.
This application has been filed to set aside
the ex parte order dated 18.03.2015 against by the
applicant/defendant.
2. Heard both sides.
3. The learned counsel appearing for the
plaintiff/respondent has objected to allow this
application on the ground that it is not
accompanied by the written statement.
4. But the fact remains that this application
has been filed along with an application to reject
the plaint. If at all the application to reject the
plaint is dismissed, then the defendant shall file the
written statement within one week thereafter.
Subject to this condition, this application is allowed
and the ex parte order dated 18.03.2015 is
set aside.
