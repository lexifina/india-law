ORAL ORDER
1. The petitioner is before this Court seeking for the
following reliefs:
a. Call for the records in PCR No.21268/2021 on
the file of the 3rd Additional Chief Metropolitan
Magistrate Bengaluru.
b. Set aside the orders passed therein on
15.06.2024 and restore the PCR No.
21268/2021 on the file of the 3rd Additional
Chief Metropolitan Magistrate Bengaluru.

c. Allow this Petition and permit the petitioner to

d. To pass any such order/s as this Hon’ble Court

2. Notice to respondents is dispensed with since they
were not served in PCR No. 21268/2021. B-report
has been filed. The request for adjournment made by
the petitioner to file objections to B-report has been
rejected by the interim order, though of course on
the ground that the same was pending for some
time.
3. Submission of the counsel for the petitioner is that
the two earlier counsels for the petitioner did not file
objections, as such, a new counsel has entered
appearance. Hence the said submission is accepted.
B-report having been filed, it would be required for
the petitioner to be given an opportunity to file his
objections.

ORDER
i. Criminal petition is allowed. The Order dated
15.06.2024 in PCR No. 21268/2021 passed by
the III Additional Chief Metropolitan Magistrate,
Bengaluru is set aside.
ii. PCR No. 21268/2021 is restored subject to the
petitioner filing the objections to protest memo
by end of day 24.09.2026. It is made clear that
if objections to protest memo is not filed by
24.09.2026, the benefit of this order would
stand rescinded.
