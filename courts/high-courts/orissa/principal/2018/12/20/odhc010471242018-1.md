# High Court of Orissa, WP(C)/15781/2018, 2018-12-20

3. 20.12.2018 Heard Mr. R.C. Jena, learned counsel for the
petitioner.
 The petitioner has filed this application challenging
the order of transfer dated 08.08.2018, by which the
petitioner has been transferred and posted to Baghamari
Unit.
 The order of transfer has been passed in August,
2018, now the petitioner moves the application in
December, 2018, therefore, this Court is not inclined to
entertain this writ application, accordingly, the same
stands disposed of.
