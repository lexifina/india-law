This petition coming on for admission this day, the court passed the
following:
ORDER
Counsel appearing for the petitioners makes a prayer for withdrawal of
miscellaneous petition with liberty to file a fresh petition. It is submitted that
there is legal errors in filing the petition. Petitioners want to file a fresh duly
constituted petition.
For the reasons stated by counsel for the petitioners, prayer is allowed.
Petitioners are permitted to withdraw the petition with liberty to file fresh
petition in accordance with law.
If petitioners file photocopy of the documents, which are filed as certified
copy, then Registry is directed to return certified copy of documents to counsel
for the petitioners.
Miscellaneous petition is dismissed as withdrawn with aforesaid liberty.
C.C. as per rules.
