Order
28/09/2018
The matter comes upon an application for the correction in
the F.I.R. number, which is stated to have been incorrectly
mentioned in the order dated 28/08/2018.
Learned counsel for the petitioner submits that inadvertently,
he has mentioned the F.I.R. number in the bail application as
68/2018, whereas the correct F.I.R. number is 68/2015. He,
therefore, prays that due to bonafide error incorrect number was
mentioned in the bail application filed by the counsel. The same
may kindly be corrected. A certified copy of the F.I.R is also
produced with the bail application and the same shows the F.I.R.
No. 68/2015.

(2 of 2) [CRLMA-66/2018]
Taking into consideration the facts mentioned in the
application, the same is allowed. The number of the F.I.R is
corrected and the same be read as F.I.R. No. 68/2015 instead of
F.I.R. No. 68/2018 in the order dated 28/08/2018.
The application is allowed in above terms.
(VINIT KUMAR MATHUR),J
