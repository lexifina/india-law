1. Heard learned counsel for the petitioner as well as the learned
Public Prosecutor for the State. We are informed by the learned Public
Prosecutor that the petitioner, for the same set of facts, has already filed
a private complaint in which direction under Section 156 (3) of the
Code has been issued on 28th November, 2008. Pursuant to the said
direction, investigation has already been done and report under Section
173 (2) of the Code has been submitted to the concerned Court. These
facts have not been mentioned in the writ petition which has been

2 wp-2667-10
filed on 28th April, 2010.
2. In the circumstances, this petition is dismissed with liberty to the
petitioner to pursue appropriate remedy before the lower court, if so
advised. Those proceedings will have to be decided on its own merits in
accordance with law.
 (A.R.JOSHI, J.) (A.M.KHANWILKAR, J.)
