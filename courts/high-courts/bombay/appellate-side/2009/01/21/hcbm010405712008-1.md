# Bombay High Court, APPLN/4476/2008, 2009-01-21

IN THE HIGH COURT OF JUDICATURE AT BOMBAY
 CRIMINAL APPELLATE JURISDICTION
 CRIMINAL APPLICATION NO. 4476 OF 2008
 Neeru Narayan Swami ...Applicant
 (Orig.Accused No.2)
 vs.
 The State of Maharashtra ...Respondent
 Ms.Ujwal Agandsurve for the Applicant.
 Ms.S.S. Pednekar, APP for the State.
 CORAM : V.M. KANADE, J.
 DATED : JANUARY 21, 2009
 P.C. :-
 1. Heard Counsel for the applicant.
 2. Since the charge-sheet has been filed after the
 present criminal application was filed in this Court,
 liberty is granted to the applicant to file an
 application for bail in the Sessions Court.
 3. This application is allowed to be withdrawn with
 liberty to file an application before the Sessions
 Court. If the application is filed before the Sessions
 Court, the same be heard on merits and in accordance
 with law.
 4. The application is disposed of.
 (V.M. KANADE, J.)
