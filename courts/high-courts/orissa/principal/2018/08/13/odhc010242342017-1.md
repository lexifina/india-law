# High Court of Orissa, CMAPL/498/2017, 2018-08-13

5
p
13.8.2018 This petition has been filed to restore
RVWPET No.183 of 2016.
 None appears for the petitioner.
 By order dated 5.2.2018, this Court issued
notice to the opposite party by registered post with A.D
and directed to file requisites within three days. Since
requisites had not been filed, on 21.3.2018 again this
Court directed to file requisites within ten days. The
matter was listed on 10.4.2018. This Court again
directed to file requisites within fifteen days. Till date
requisites have not been filed. As it appears the
petitioner has no interest in the case.
 The petition is dismissed for non-prosecution. It is open to the petitioner file an
application if fresh cause of action arises.
