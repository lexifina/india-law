Order on Board

1. The challenge made in this writ petition is to the order dated 04.09.2014
whereby the petitioner was declared as surplus and posted to Govt. Primary
School, Pankjam from Govt. Primary School Mendrakhurd.
2. By oder dated 18.09.2014, the interim protection was granted in favour of
the petitioner with respect to the posting. Learned counsel for the petitioner
would submit that subsequently the petitioner has been absorbed in
education department, consequently the employer would be the State
Government. In view of such submission, no further order would be required

2
to be passed at this stage. The State would be at liberty to pass any
appropriate order if any exigency so arises. Since considerable time has
passed, the order dated 04th Sept. 2014 passed by the CEO, Janpad
Panchayat vide Annexure P-1 so far as it relates to the petitioner is set
aside.
3. With the above observation/direction, this writ petition stands disposed of.
