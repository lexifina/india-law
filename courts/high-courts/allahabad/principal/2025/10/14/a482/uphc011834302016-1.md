# Allahabad High Court, A482/37075/2016, 2025-10-14

HIGH COURT OF JUDICATURE AT ALLAHABAD
APPLICATION U/S 482 No. - 37075 of 2016
Court No. - 83
HON'BLE RAJIV LOCHAN SHUKLA, J.
1. Learned A.G.A. for the State submits that after the dismissal
of the present application in default, the file of the Learned
A.G.A. is not tractable now. Even the matter has been restored
and he does not have the necessary papers.
2. Mr. Bharat Bhushan Dubey, Learned counsel for the
applicants is directed to provide a copy of this application and
necessary documents to the Learned A.G.A. for the State
within two days.
3. Learned A.G.A. for the State is directed to obtain
instructions and the present status of the trial.
4. Vide order dated 12.2.2024, Learned A.G.A. had granted
one last opportunity to file a counter affidavit in the matter.
However, no counter affidavit of the Learned A.G.A. is
available on the record.
5. Considering the fact that file of the Learned A.G.A. is not
available and also that application had been dismissed in
default and thereafter restored, one last opportunity is being
granted to the Learned A.G.A. to file a counter affidavit.
