# Allahabad High Court, /2678/2023, 2023-03-23

Court No. - 14
Case :- APPLICATION U/S 482 No. - 2678 of 2023
Applicant :- Dharam Veer Singh Yadav And Others
Opposite Party :- Anti Terrorist Squad Gautam Budh Nagar U.P.
Counsel for Applicant :- Shobhit Nigam
Counsel for Opposite Party :- G.A.
Hon'ble Shamim Ahmed,J.
Heard Sri Shobhit Nigam, learned counsel for the applicants
and Sri Shiv Nath Tilhari, learned A.G.A.-I for the State.
Learned counsel for the applicants submit that there is some
inadvertent mistake due to typing error in the application and he
wants to withdraw the same with liberty to file afresh after
amending the petition.
Sri Shiv Nath Tilhari, learned A.G.A.-I for the State has no
objection to the prayer made by learned counsel for the
applicants.
Accordingly, this application is dismissed as withdrawn with
liberty as prayed for.
Certified copies annexed with this application be returned to the
learned counsel for the applicants after keeping photostat of the
same on the record.
Order Date :- 23.3.2023
Arvind
