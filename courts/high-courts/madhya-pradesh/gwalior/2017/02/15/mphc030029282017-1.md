# High Court of Madhya Pradesh, MCC/53/2017, 2017-02-15

1
MCC No.53/2017
(Brij Kishore v. State of M.P. & Ano.)
15/02/2017
Shri J.P. Kushwah, counsel for the applicant.
This MCC has been filed for restoration of
M.Cr.C.No.7182/2011 which was dismissed for want
of prosecution by order dated 16.12.2016.
As the MCC for restoration of M.Cr.C.No.7182/
2011 is not maintainable, therefore, the applicant
seeks permission of this Court to withdraw the
application with liberty to file an appropriate
constituted application.
With the aforesaid liberty, the application is
dismissed as withdrawn.
 (G.S.Ahluwalia)
(ra) Judge
