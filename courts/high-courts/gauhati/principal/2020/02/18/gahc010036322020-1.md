Date : 18-02-2020
By this Interlocutory Application, the petitioner has sought for correction of an
inadvertent error cropped up in the order dated 03.02.2020 passed in AB No.213/2020.
It is submitted by the learned counsel for the petitioner that inadvertently the case
number has wrongly written as Patacherkuchi PS Case No.387/2019 which ought to have
been Patacherkuchi PS Case No.837/2019.
Accordingly, Patacherkuchi PS Case No.387/2019 appearing in the 2nd paragraph of the
aforementioned order stands corrected and should be read as “Patacherkuchi PS Case
No.837/2019”.
This order shall be a part of the aforementioned order dated 03.02.2020 passed in AB
No.312/2020.
Accordingly, this Interlocutory Application stands disposed of.
