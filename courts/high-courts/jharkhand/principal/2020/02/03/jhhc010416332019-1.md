4/03.02.2020 Heard the parties.
 The petitioner, in this application, has challenged the order dated
11.09.2019, by which processes under Sections 82 Cr.P.C. has been
issued against him.
 Learned counsel appearing for the petitioners submits that the
impugned order is absolutely cryptic, vague and does not reflect any
subjective satisfaction, thus, the same needs to be quashed.
 After going through the record, I find that the order is absolutely
cryptic as the same do not record any subjective satisfaction as to why
process under Section 82 Cr.P.C. is being issued. In absence of any
subjective satisfaction, the order dated 11.09.2019 is bad and is liable to
be set aside.
 Accordingly, this application is hereby allowed. The impugned
order dated 11.09.2019, by which processes under Section 82 of the Code
of Criminal Procedure has been issued, is hereby set aside. The matter is
remitted to the court below to proceed afresh accordingly as per law.
 This criminal miscellaneous petition stands allowed.
