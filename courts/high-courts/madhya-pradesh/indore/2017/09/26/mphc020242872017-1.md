# High Court of Madhya Pradesh, MCRC/10257/2017, 2017-09-26

M.Cr.C. No.10257/2017
26.09.2017
Shri I. Ahmad, learned counsel for the applicant.
Shri K. K. Tiwari, learned Public Prosecutor for the non-applicant – State.
This application under Section 438 of the Cr.P.C. for grant
of anticipatory bail has been filed by the applicant – Anita
Mandloi W/o Kishore Mandloi.
Considering the fact that applicant instead of filing
application before learned Session Judge has filed this
application for anticipatory bail before this Court and, therefore,
she is permitted to withdraw this application with liberty to file
an application before the learned Session Judge.
With the aforesaid liberty, M.Cr.C. No.10257/2017 is
permitted to be withdrawn.
(P. K. Jaiswal)
