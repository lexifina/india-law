# High Court of Madhya Pradesh, MCC/1991/2014, 2014-09-25

MCC No.1991 / 2014.
25/09/2014.
Shri Rahul Diwakar, learned counsel for the applicant.
This application has been filed for restoration of A.R.
No.15/2012 which was dismissed on 24.3.2014 in non-compliance of peremptory order dated 11.10.2013.
Keeping in view the reasons indicated in the application
and finding it to be bona fide, application is allowed. A.R. is
restored to its original number. It be placed for orders before the
appropriate Bench.
Application stands allowed and disposed of.
(Rajendra Menon) (Anil Sharma)
