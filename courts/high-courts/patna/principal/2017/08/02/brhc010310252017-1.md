ORAL ORDER
5 02-08-2017 Heard learned counsel for the petitioners, learned
counsel for the State and learned counsel for the informant.
Learned counsel for the petitioners submits that the
petitioner has challenged the order of cognizance, arising from
Bhabhua P.S. Case No. 310 of 2014 for the offence punishable
under Sections 323, 379, 406, 420, 467, 468, 504 and 506/34 of
the Indian Penal Code in Criminal Revision Case No.57 of 2017
and vide order dated 19.06.2017 the Court below has stayed the
proceeding of the aforesaid case.
In such view of the matter, there is no need to pass
any order as there is no apprehension of arrest. Accordingly,
this application is dismissed.
pawan/-
