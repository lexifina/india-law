# High Court of Madhya Pradesh, MCC/1242/2016, 2016-05-12

MCC NO.1242/2016
12-05-2016
Shri D.K.Tripathi, learned counsel for the applicant.
This application has been filed for restoration of W.A.No.1244/2006,
which has been dismissed for want of prosecution on 18-11-2015. There is
some delay in filing of this application, therefore, I.A.No.6105/2016 has
been filed for condoning the delay.
Delay in filing the application as well as default itself is attributed to
some lapses on the part of the counsel and applications are supported by
affidavits of the counsel and there is no reason to disbelieve its bonafide.
Considering the same, both the applications i.e. application for
condonation of delay and restoration application itself are allowed. Delay is
condoned and W.A.No.1244/2006 is restored to its original file. It be placed
for orders before an Appropriate Bench.
Application stands allowed and disposed of.

 (RAJENDRA MENON) (ANURAG SHRIVASTAVA)
 JUDGE JUDGE
