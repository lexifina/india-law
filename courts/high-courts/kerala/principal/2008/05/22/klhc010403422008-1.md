JUDGMENT
H.L.Dattu,C.J.
After arguing the matter for quite some time, Sri.G.Hariharan, learned
counsel for the appellant seeks leave of the court to withdraw the writ appeal with
liberty to file an appropriate review petition before the learned single Judge.
2. The request of the learned counsel Sri.G.Hariharan appears to be
reasonable and if it is granted it would not cause any prejudice to the other side.
3. Therefore, the writ appeal is disposed of as withdrawn. Liberty is
reserved to the appellant to file an appropriate review petition before the learned single
Judge, if he so desires.
Ordered accordingly.
