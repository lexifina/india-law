# High Court of Jharkhand, Cr.M.P./4115/2019, 2020-02-14

IN THE HIGH COURT OF JHARKHAND AT RANCHI
Cr. M.P. No. 4115 of 2019
----
Anand Kishore Paswan … Petitioner
-versus-The State of Jharkhand … Opposite Party
CORAM : HON’BLE MR. JUSTICE ANANDA SEN
----
For the Petitioners : Mr. Soumitra Baroi, Advocate
For the State : Mr. Sardhu Mahto, APP
----
4/ 14.02.2020 Heard learned counsel for the petitioner and the learned
A.P.P. for the State.
 2. Petitioner, in this criminal miscellaneous petition, has
challenged the order dated 12.07.2018 and 27.11.2018 passed by the
Judicial Magistrate 1st Class, Hazaribagh in Keredari Police Station Case
No. 55 of 2011 (G.R. No.3005 of 2011), by which process under Section
82 of the Code of Criminal Procedure and order of attachment under
Section 83 of the Code of Criminal Procedure, respectively, have been
issued.
3. While I go through both these orders, I am compelled to hold
that there cannot be any order more cryptic than these two orders. Only by
one line orders, process under Section 82 of the Code of Criminal
Procedure and order of attachment under Section 83 of the Code of
Criminal Procedure have been issued. This is not the mandate of law.
Issuing process under Section 82 of the Code of Criminal Procedure and
order of attachment under Section 83 of the Code of Criminal Procedure
are orders of serious implication. It infringes the rights of a person against
whom the said orders are passed. When a right is being infringed by an
order, the same has to be a reasoned one which should be supported by
cogent facts and the law applicable to the given facts.
4. While issuing process under Section 82 of the Code of
Criminal Procedure or the attachment order under Section 83 of the Code
of Criminal Procedure, there has to be subjective satisfaction showing that
the petitioner is evading his arrest and it is not possible for the police to
arrest him. These satisfaction should be based on some material on
record, which should be reflected in the order itself. This is missing in the
order dated 12.07.2018 by which process under Section 82 of the Code of

Criminal Procedure has been issued.
 5. So far as the attachment order under Section 83 of the Code
of Criminal Procedure is concerned, I find that no subjective satisfaction
here also has been recorded. The order is a one line order. Mandatory
provisions of Section 82(3) of the Code of Criminal Procedure has also not
been complied with.
6. In view of the above, both the impugned orders dated
12.07.2018 and 27.11.2018 passed by the Judicial Magistrate 1st Class,
Hazaribagh in Keredari Police Station Case No. 55 of 2011 (G.R. No.3005
of 2011), by which process under Section 82 of the Code of Criminal
Procedure and order of attachment under Section 83 of the Code of
Criminal Procedure, respectively, have been issued, are hereby quashed
and set aside. The matter is remitted to the Court below to proceed afresh
and pass orders in accordance with law.
 7. This criminal miscellaneous petition is, accordingly, allowed.

(Ananda Sen, J.)
