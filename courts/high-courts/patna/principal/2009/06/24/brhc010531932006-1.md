# Patna High Court, MJC/2945/2006, 2009-06-24

IN THE HIGH COURT OF JUDICATURE AT PATNA

 Arjun Prasad Yadav, Son of Late Anup Lal Yadav, Resident of village-
 Phulaut, P.S.-Chansa, District-Madhepura.
 -Petitioner.
VERSUS
1. The State of Bihar.
2. The State Co-operative Land Development Bank through the Regional
Manager, Land Development Bank, Madhepura.
3. Mr. Shashi Shiv Shankar Jha, Branch Manager, Land Development Bank,
Udaa Kishunganj, Biharigank, Madhepura.
4. Mr. Dhananjay Singh, Filed Officer, Land Development Bank, Uda
Kishunganj, Bihariganj, Madhepura.
 -Opposite Parties.
-----------
03 24.06.2009 Perused the letter dated 30.10.2006 of the Branch Manager,
Land Development Bank, Uda Kishunganj, which is said to be
contemptuous. Perused the order of this Court. In my view, no
contempt is made out. It is open to the petitioner to point out the
respondent that he has filed detailed objection, if so advised file a
duplicate thereof, as per the communication itself. The Manager
professes that he has no knowledge of the steps taken by the petitioner
pursuant to the order of this Court, if such an application is filed by the
petitioner the respondents would proceed in accordance with the
direction given in the writ application.
With these observations, this application is disposed of.
 Trivedi/ (Navaniti Prasad Singh, J.)
