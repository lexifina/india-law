ORDER
Date : 04-06-2018
Heard Ms. S. Goswami, learned counsel appearing for the applicant.
By this application under Order IX Rule 4 CPC, the application has prayed for
restoration of RFA No. 07/2008 which was dismissed for non-prosecution by order dated
06.03.2018.
In the opinion of this Court, the restoration application of an appeal is to be done
under appropriate provisions of law and moreover, the affidavit in support of this application
has been left blank, as such, it is not properly verified.
Accordingly, this application stands closed with liberty to the applicant to file an
appropriate application for restoration of the said appeal.
