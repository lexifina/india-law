ORDER
 The counsel for the complainants files a memo
stating that this contempt petition is not pressed. Memo is
placed on record. The petition is accordingly dismissed as
withdrawn.
The complainants have sought liberty to file a fresh
petition. In this regard, it is to be stated that permission
or liberty to file a fresh contempt petition cannot be
granted, because the order dated 16.12 .2019 shows that
it was passed in a regular first appeal granting an order of
injunction. If injunction order granted in the first appeal
is violated, then an application under Order XXXIX Rule 2
of CPC is to be filed in the same first appeal.
Office is hereby directed to return the certified
copies.
