# High Court of Rajasthan, CRLMP/965/2016, 2019-10-18

HIGH COURT OF JUDICATURE FOR RAJASTHAN

----Respondent
For Petitioner(s) : None Present

HON'BLE MR. JUSTICE PANKAJ BHANDARI
Judgment / Order
18/10/2019
1. Petitioner has preferred this Criminal Miscellaneous Petition
under Section 482 Cr.P.C.
2. Learned Public Prosecutor has submitted a report which is
taken on record. As per which Police has submitted negative final
report.
3. In view of the same, Criminal Miscellaneous Petition has
become infructuous and the same is accordingly dismissed as
having become infructuous.
4. Stay application stands disposed.
5. However, petitioner would be free to file Protest Petition, if so
advised.
(PANKAJ BHANDARI),J
