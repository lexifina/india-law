# Allahabad High Court, WRIC/14199/2019, 2021-11-30

Court No. - 40
Case :- WRIT - C No. - 14199 of 2019
Petitioner :- Virendra Shankar Sahani
Respondent :- State of U.P. and Another
Counsel for Petitioner :- Sanjay Agrawal
Counsel for Respondent :- C.S.C.,Habib Ahmad
Hon'ble Ashwani Kumar Mishra,J.
Hon'ble Vikram D. Chauhan,J.
In Re: Delay Condonation Application
Heard.
Cause for delayed filing of substitution application has been
explained to the satisfaction of the Court. Delay is, accordingly,
condoned.
Application stands allowed.
In Re: Substitution Application
Heard.
Let heirs of deceased petitioner as disclosed in prayer clause of
this application be substituted as petitioner nos.1/i to 1/iv and a
note be made that sole petitioner died on 23rd August, 2020.
Application stands allowed.
In Re:- Withdrawal Application
An application supported with affidavit has been filed stating
that petitioner is no longer desirous of pressing this petition and
the same be dismissed as withdrawn.
Application is allowed. Writ petition is dismissed as withdrawn.
Order Date :- 30.11.2021
