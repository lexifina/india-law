P.C.:-
 In this petition, the petitioner
 had challenged the order dated
 28/3/2003 whereby the application
 taken out by the petitioner to set
 aside the order for placing the matter
 for ex-parte hearing dated 4/3/2002
 was dismissed. The writ petition
 challenging this order was filed on
 1/10/2003. It is surprising that it
 is circulated only on 29/7/2004.
 Ad-interim order was passed by this
 court on 29/7/2004. By that order,

 the proceedings in the trial court
 were stayed. However, admittedly on
 16/7/2004, the decree had already been
 passed. Hence, the present petition
 has become infructuous and is
 dismissed as such. The petitioner
 will, however, be at liberty to file
 appropriate proceedings, if he is so
 advised, challenging the decree dated
 16/7/2004.
 (SMT. RANJANA DESAI, J.)
