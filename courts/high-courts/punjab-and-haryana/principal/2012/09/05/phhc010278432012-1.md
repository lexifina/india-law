NAWAB SINGH J.(ORAL)
This is an application for pre-arrest bail under Section
438 Code of Criminal Procedure in case bearing First Information Report
No.258 dated September 03, 2011 registered under Section 406 of the
Indian Penal Code in Police Station Saran, District Faridabad.
Learned State counsel has stated that in this case, the
Police has not challaned the petitioner.
In face of it, counsel for the petitioner has stated that
this petition be dismissed as withdrawn. It is ordered accordingly.
