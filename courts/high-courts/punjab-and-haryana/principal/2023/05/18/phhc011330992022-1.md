CM-5403-CII-2023
 This is an application for withdrawal of the main revision
petition owing to the fact that rent petition has been decided vide order
dated 28.02.2023 (Annexure A-1).
Instead of rendering piecemeal decision, on the application, it
is deemed appropriate that main case itself is heard.
Application stands disposed of, accordingly.
Main case
 Revision petition is directed against impugned order dated
28.10.2022 (Annexure P-1) passed by learned Rent Controller, SBS Nagar
vide which application for amendment of plaint filed by
respondent/landlord in rent petition was allowed.
During pendency of the proceedings, rent petition has itself
been decided and appeal against the final order passed therein is pending
before learned First Appellate Court.
