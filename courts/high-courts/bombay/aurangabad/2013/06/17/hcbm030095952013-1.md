2 2065.2013 WP
2. The application for acceptance of written statement and
setting aside no written statement order is rejected. Heard
learned counsel for respective parties. The learned counsel for
respondent supports the order and submits that there is
inordinate delay in filing the written statement. No proper
reasons for not filing the written statement within the stipulated
period are mentioned. The learned counsel submits that as per
Order 8 Rule (1) of the Code of Civil Procedure, written
statement has to be filed within 30 days.
3. The learned counsel for the petitioners submits that the
application for acceptance of written statement is filed on 98th
day.
3. Considering the above conspectus of the matter, I pass the
following order.
ORDER
A. The impugned order dated 24-08-2012 is quashed
and set aside and the application Exh. 14 is allowed on
condition that petitioners pay cost of Rs. 2,000/- (Rs. Two
thousand only) to respondent within a period of four weeks.
