# High Court of Madhya Pradesh, RP/394/2017, 2017-07-21

RP-394-2017
(AJAY SHARMA Vs THE STATE OF MADHYA PRADESH)
21-07-2017
Shri Anil Sharma, learned counsel for petitioner.
Shri Vivek Mishra, learned Panel Lawyer for respondent-State.
Heard.
Learned counsel for the petitioner submits that there is
typographical error in the order, and the writ petition number, as
is mentioned in paragraph no.2 as 9417/2017, is to be read as
9417/2012. Such prayer is not opposed by Shri Vivek Mishra,
learned Panel Lawyer for respondent-State. Therefore, this
review petition is allowed. It is directed that instead of WP
No.9417/2017, it will be read as WP No.9417/2012.
Let a copy of this order be kept in WP No.251/2013 so as
to read cojointly with order dated 03.07.2017.
(VIVEK AGARWAL)
