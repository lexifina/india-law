# Allahabad High Court, WRIC/53865/2017, 2020-02-28

Court No. - 72
Case :- WRIT - C No. - 53865 of 2017
Petitioner :- Munna And 15 Others
Respondent :- State Of U.P. And 8 Others
Counsel for Petitioner :- Om Shankar Mishra
Counsel for Respondent :- C.S.C.,Brij Kumar Yadav,Charan
Singh
Hon'ble Ashok Kumar,J.
This petition was listed on 18.05.2018 when the counsel for the
petitioners has sent the illness slip therefore the case was
adjourned.
On 29.01.2020 two weeks time was sought by the counsel for
the petitioners to file the rejoinder affidavit. Since no rejoinder
affidavit was filed, the case was adjourned on the request of the
counsel for the petitioner for 20.02.2020.
On 20.02.2020 this Court has passed the following order:-
"Learned Counsel for the petitioner is not present.
Sri Charan Singh, learned counsel for the respondent has raised objection
about the maintainability of this writ petition.
List in the additional cause list on 27.02.2020.
Sri Charan Singh, learned counsel for the respondent will communicate
about this order to the counsel for the petitioner in writing within 48
hours."
Since no one appeared on 27.02.2020 (yesterday), the case was
directed to be listed in the additional cause list today
(28.02.2020).
Today, the counsel for the petitioner is not present.
In view of the aforesaid, the writ petition is dismissed for want
of prosecution.
The interim order, if any, is vacated.
Order Date :- 28.2.2020
SK Srivastava
