2. This is an application under Section 151 of the Code of Civil Procedure praying for
correction of typographical error in the order dated 05.02.2024 passed by this Court in
Transfer Petition (Civil) No.06/2024.
3. In the aforesaid order, the further proceeding of FC (G) Case No.12/2013 pending
in the court of learned Principal Judge, Family Court, Cachar, Silchar was directed to be
stayed.
4. The learned counsel for the applicant submits that the case number should have
been “FC (G) Case No.12/2023”.
5. The error stands corrected.
6. Henceforth, the case number FC (G) Case No.12/2013 appearing in the order
dated 05.02.2024 passed by this Court in Transfer Petition (Civil) No.06/2024 shall be read
as FC (G) Case No.12/2023.
7. This order shall form a part of the order dated 05.02.2024.
With the aforesaid direction, the I.A. stands disposed of.
