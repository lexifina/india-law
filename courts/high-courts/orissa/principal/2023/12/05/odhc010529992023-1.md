 JUSTICE M.S. SAHOO

ORDER
05.12.2023
 Order No. Hybrid Mode
 04. 1. When the matter was taken up on 05.10.2023,
the following order was passed:
“1. Learned counsel for the petitioner seeks
accommodation to advance arguments.
 2. Learned Standing Counsel for the State
submits that he has received the case diary but
seeks further accommodation to obtain the seizure
report.
 3. Learned counsel for the petitioner shall also file
affidavit by the next date regarding his criminal
proclivity of the past, if any.
 4. As prayed for, list on 15.11.2023.”
 2. On 15.11.2023, the following order was passed:
“1. Learned counsel for the petitioner refers to the
earlier order dated 05.10.2023 and submits that
further time may be granted to file affidavit
regarding the allegations of past criminal activity
against the petitioner, if any.
 Prayer is allowed.
 2. Let the affidavit be filed by 28.11.2023 and
copy of the same be served on the learned counsel
for the State to enable him to obtain instruction.
