ORAL ORDER
2 21-09-2021 Initially learned counsel for the petitioner was
reluctant to say as to why the petitioner is looking to withdraw
this application that too without any liberty to file an application
but, subsequently, learned counsel prays that he may be allowed
to withdraw this application with liberty to file an application in
the learned court below.
This Court allows the petitioner to withdraw this
application with the liberty as prayed.
It is made clear that if the petitioner has moved the
learned court below without disclosing the correct fact as to the
pendency of the present application before this Court, the
learned court below shall look into the same and would act in
accordance with law.
The observation is being made considering that

Patna High Court CR. MISC. No.45940 of 2021(2) dt.21-09-2021
2/2
recently the Court has come across number of cases in which it
has been found that the petitioner has moved the learned court
below making a false statement that he had not filed any
application before this court.
This application stands disposed of accordingly.
