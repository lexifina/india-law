# Allahabad High Court, A482/19520/2019, 2019-05-16

Court No. - 67
Case :- APPLICATION U/S 482 No. - 19520 of 2019
Applicant :- Asrar Ahmad
Opposite Party :- State Of U.P. And Anr
Counsel for Applicant :- Sayyed Kashif Abbas Rizvi,Neeraj Seerotiya
Counsel for Opposite Party :- G.A.
Hon'ble Rahul Chaturvedi,J.
Heard learned counsel for the applicant as well as learned AGA for the
State and perused the record.
By means of the present application u/s 482 Cr.P.C. the applicant has
challenged the order dated 26.11.2018 by which the learned Sessions
Judge, Hapur has framed certain charges against the applicant and the
applicant is aggrieved by those charges.
The applicant, if so advised, may file a proper application before learned
Sessions Judge, Hapur for amending the charges or the charges could be
amended at any time of trial.
Under the circumstances, the applicant is directed to move an appropriate
application before learned Sessions Judge, Hapur and the same would be
decided by a well reasoned order strictly in accordance with law within a
period of eight weeks.
With the aforesaid observations, the present application stands disposed
of.
Order Date :- 16.5.2019
