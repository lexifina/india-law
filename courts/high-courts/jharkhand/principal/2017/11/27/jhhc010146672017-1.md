05/27.11.2017 The petitioner in this application has prayed for quashing of the
entire criminal proceedings in connection with Kotwali P. S. Case No.
26 of 2017 including the order dated 28.03.2017 passed by the learned
C.J.M., Ranchi by which cognizance has been taken under Sections
504/506 of the Indian Penal Code.
It appears that initially a First Information Report was instituted
under Sections 323/341 of the Indian Penal Code and being a
cognizable offence the same was investigated but the allegation under
Sections 323/341 of the Indian Penal Code were found to be untrue as
such the final form was submitted only with respect to Sections 504
and 506 of the Indian Penal Code leading to taking of cognizance by
the learned court below vide order dated 28.03.2017.
Since nothing has been pointed out by the learned counsel for
the petitioner which would be contrary to the finding recorded by the
learned Magistrate, I am not inclined to entertain this application
which is accordingly disposed of.
(Rongon Mukhopadhyay, J.)
