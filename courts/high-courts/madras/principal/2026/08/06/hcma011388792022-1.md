2. This case has been listed before this Court for more than two occasions
for the purpose of filing translated copies of relevant documents. However, on
all these occasions, the counsel for the petitioner sought time to file the said
translated copies.
3. Even today, i.e., 06.08.2026, there is no representation for the parties.
Although the learned counsel took sufficient time to file the translated copy of
the documents, he has failed to do so. This Court is unable to proceed with the
case as the documents are in vernacular language.
4. In view of the above, this Writ Petition is dismissed. No costs.
Consequently, connected miscellaneous petition is closed.
