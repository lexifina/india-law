HON'BLE DR. JUSTICE NUPUR BHATI
Order
10/05/2024
1. The instant writ Misc. application has been filed by the
petitioner seeking correction/modification in the order dated
01.05.2024 passed by this Court in SBCWP No.5894/2024.

[2024:RJ-JD:18905] (2 of 2) [CW-5894/2024]
2. For the reasons submitted in the application, the same is
allowed and the order dated 01.05.2024 be read as under.
“(i). The interlocutory application (No.01/2024) has been
filed by the petitioner seeking withdrawal of the present
writ petition with liberty to file fresh writ petition, if
occasion arises.
(ii) For the reasons submitted in the application, the
same is allowed and the petitioner is permitted to
withdraw the present writ petition with liberty to file fresh,
if occasion arises.
(iii) Accordingly, the instant writ petition is dismissed as
withdrawn with the liberty as prayed for. Stay application
as well as all other pending applications, if any, also stand
dismissed.”
3. This order be treated as part and parcel of the order
dated 01.05.2024 passed by this Court in SBCWP
No.5894/2024.
