Judgment / Order

 By an application (APPLW No.3210/2017), learned counsel
for the petitioner wants to withdraw this writ petition, however,
seeks liberty for the petitioner to file fresh writ petition if occasion
so arise.
Hence, this writ petition is dismissed as withdrawn with the
liberty as prayed for.
Stay petition also stands dismissed.
Consequently, the application (APPLW No.3210/2017) is
disposed of.
