# High Court of Madhya Pradesh, MCRC/45093/2019, 2019-12-03

HIGH COURT OF MADHYA PRADESH, BENCH AT INDORE
M CR C No. 45093 / 2019
VIKRAM CHOUHAN VS. NITIN AND OTHERS
--- 1 ---
INDORE, Dated : 03/12/2019
Ms. Archana Maheshwari, learned counsel for the petitioner.
Respondent No.1 is present in person.
The aforesaid petition has been filed u/S. 482 of the Code of
Criminal Procedure, 1973 and it has been stated that the State Government
has given some undertaking before the First Addl. Sessions Judge,
Shajapur in a Revision (Cr.Rev. No. 46/2019 and 47/2019).
Learned counsel for the petitioner has argued before this Court that
the aforesaid undertaking was actually never given by the State
Government. If the undertaking was not given by the State Government,
learned counsel for the petitioner shall be free to file an application where
the so-called application is given and in case such an application is
preferred, the trial Court will pass appropriate order in accordance with
law.
At this stage, it has been pointed out to this Court that the
application preferred before the revisional Court dated 13/7/2019 has
already been decided by order dated 13/7/2019. In case the application has
been decided, the present petitioner does have a remedy under the Code of
Criminal Procedure, 1973 against the order passed by the learned Addl.
District Judge and, therefore, the present petition u/s. 482 of the Code of
Criminal Procedure, 1973 stands dismissed. It is made clear that this Court
has not passed any order on merits in the present case so far as the dispute
in respect of the land in question is concerned. The petitioner shall be free
to avail the remedy available under the law against the order dated
13/7/2019. With the aforesaid, the present petition stands disposed of.
(S. C. SHARMA)
