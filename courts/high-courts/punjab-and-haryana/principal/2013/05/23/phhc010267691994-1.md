2. The learned counsel appearing on behalf of the State points out
that all the same instances relied on by the landowner was with reference to
properties in Abadi as seen from the rough sketch filed before the Court
below. The State was on the other hand providing a same instance of a
transaction just prior to notification that set out a value at Rs.2580/-. The
Court has provided for a compensation which was far above the value of the
property as agricultural land. None of the documents relied on by the
landowners served as an useful exemplar.
