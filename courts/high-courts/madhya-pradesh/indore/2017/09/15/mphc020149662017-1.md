# High Court of Madhya Pradesh, MCRC/6333/2017, 2017-09-15

MCRC-6333-2017
(VESTA Vs THE STATE OF MADHYA PRADESH)
15-09-2017
Shri Manan Dhakad, learned counsel for the applicant.
Shri Suraj Sharma, learned counsel for the
respondent/State.

this application as the application has been rendered
infructuous. According to him, trial is over and the
present applicant has been acquitted from all the
charges.

Accordingly, this application is dismissed as
withdrawn.
