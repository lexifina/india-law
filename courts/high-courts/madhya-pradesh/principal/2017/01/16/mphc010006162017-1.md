# High Court of Madhya Pradesh, MCC/44/2017, 2017-01-16

MCC-44-2017
(SMT. MAIKI Vs SUKRAWATI)
16-01-2017
Shri Sourabh Singh, learned counsel for the applicant.
This is an application for restoration of
W.P.No.13864/2016 which suffered dismissal on account of
peremptory order dated 30.11.2016.
For the reasons and grounds mentioned in the application
for restoration which is duly supported by an affidavit, the
application is allowed.
W.P.No.13864/2016 is restored to its original number.
(VIJAY KUMAR SHUKLA)
