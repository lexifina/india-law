ORAL ORDER
2 14-03-2012 This is repeat application seeking bail in a case instituted
under diverse sections of Indian Penal Code including Sections
395 and 364 IPC. Petitioner’s earlier bail application was
considered and rejected with observation by order dated
16.3.2011 (Annexure-1), a perusal whereof indicates that this
Court directed for his release from jail custody in the event the
prosecution failed to examine all the prosecution witnesses within
the stipulated time.
From the impugned order, it appears that all the
prosecution witnesses were examined inasmuch as the evidence
for prosecution was closed within the time.
This Court, therefore, finds no merit in the application. It
is accordingly dismissed.
Pankaj/- (Kishore Kumar Mandal, J)
