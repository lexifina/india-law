Order
26/03/2019
The instant misc. petition has been moved for correction in
order dated 25.03.2019 passed in S.B.Suspension of Sentence
(Appeal) No.262/2019., wherein the case number was wrongly
mentioned in the Header as “SOSA-46/2019” instead of “SOSA-262/2019”.
For the reasons mentioned in the application, the application
is allowed and it is ordered that in the order dated 25.03.2019,
the case number in the Header be read as ‘SOSA-262/2019’.
