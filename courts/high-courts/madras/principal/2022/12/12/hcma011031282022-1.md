# Madras High Court, A/5673/2022, 2022-12-12

A.No.5673 of 2022
A.No.5673 of 2022
in C.S.No.220 of 2021
SENTHILKUMAR RAMAMOORTHY, J.
The first defendant in the suit has presented this application to set aside
the order dated 18.04.2022 by which the first defendant was set ex parte.
2. The plaintiff has no objection to this application being allowed.
Upon examining the affidavit in support of this application and being satisfied
that sufficient cause is shown, this application is allowed by setting aside the
order dated 18.04.2022 in C.S.No.220 of 2021. Learned counsel for the first
defendant states that an application to condone delay in filing the written
statement is pending. The Registry is directed to list the said application on
the next hearing date. List the matter on 21.12.2022.
