P.C. :-
Heard the learned counsel for the applicants. Heard learned
A.P.P. for Respondent/State. Heard learned counsel for the
respondent No.2.
2. By this application invoking inherent powers of this Court,
the order issuing process has been challenged. Such an order is
amenable to the revisional jurisdiction of the Court. When this
aspect of the matter is pointed out, the learned counsel for the
applicants seeks permission to withdraw the application stating
that he would file appropriate proceedings before the Court of
Sessions, challenging the order issuing process against the
applicants.
3. The application is allowed to be withdrawn and stands
dismissed as such, with liberty to the applicants to file an
application for revision in the Court of Sessions, challenging the
order which has been impugned by filing the present application.

5. The application is disposed of in the aforesaid terms.
