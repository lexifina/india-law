# Calcutta High Court, CRR/797/2020, 2022-03-11

11.03. 2022
 item No.64.
 n.b.

CRR 797 of 2020
Ajmiri Alam & Anr.
Vs.
The State of West Bengal
Mr. Somnath Banerjee
Mr. Pronojit Roy
….for the Petitioners
Mr. Anwar Hossain
Ms. Debjani Sahu
…..for the State
The revisional application has been preferred challenging
the charge-sheet in connection with Suri Police Station Case
No.424 of 2016 dated 3.12.2016.
Earlier report was called for. Today Mr. Anwar Hossain,
learned advocate appearing for the State submits a report prepared
by the Officer-in-Charge, Suri Police Station. Report reflects that
next date has been fixed on 07.03.2022 for examination under
Section 313 of the Code of Criminal Procedure. There has been
change of circumstances since the revisional application was
preferred.
Learned advocate appearing for the petitioner submits
that he has instructions for not to proceed with the revisional
application.
Accordingly, CRR 797 of 2020 is dismissed as not pressed.
All pending connected applications, if any, are
consequently disposed of.

Interim order, if any, is hereby vacated.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
 (Tirthankar Ghosh, J.)
