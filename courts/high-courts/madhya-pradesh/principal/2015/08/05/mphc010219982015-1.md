# High Court of Madhya Pradesh, RP/278/2015, 2015-08-05

RP-278-2015
(MANOHAR JITPURE Vs THE STATE OF MADHYA PRADESH)
05-08-2015
Shri Subodh Kathar, learned counsel for the
applicant.
Shri Pushpendra Yadav, learned Government
Advocate for the respondents/State.
Heard learned counsel for the parties.
We find no error apparent on the face of the record
which warrants any review/recall of the order passed
on 18.09.2014 in W.P. No.13815/2015. While
disposing of the said writ petition, liberty was
granted to the petitioner to file a review application
before the State Government under Rule 8(3) of the
Notaries Rules, 1956.
It is stated that the applicant has filed a review
application but the State Government did not pass
any order on the review application, but simply filed
it.
We find that the State Government has indicated
that there is no need for review and, therefore,
directed for filing the application. If the applicant is
aggrieved, he may take recourse of any remedy
available to him for challenging this order. We find
no ground for review/recall of the order on the basis
of the submission made.
Accordingly, the application is dismissed.
(RAJENDRA MENON) (SUSHIL KUMAR GUPTA)

JUDGE JUDGE
