 ORDER
The present revision petition has been filed challenging an
order under which an application for passing of final decree has been
dismissed granting liberty to the petitioner to file a fresh final decree
application after rectifying the alleged defects in the preliminary decree.
2. In view of the fact that an application for passing a final
decree has been dismissed, the revision petition is not maintainable and
only a regular appeal is maintainable. The petitioner is either at liberty to
file a regular first appeal under Section 96 of the Code of Civil Procedure
or he can rectify the alleged defects in the preliminary decree and
thereafter, file a fresh final decree application.
3. With the above observation, the Civil Revision Petition
stands dismissed. No costs.
