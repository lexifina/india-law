HON'BLE MR. JUSTICE SUDESH BANSAL
Order
04/01/2022
This misc. application under Section 151/152 CPC has been
filed seeking a typographical correction in the order dated
11.02.2016.
Learned counsel for the applicants submits that the
impugned award dated 30.03.2007 which was modified vide order
dated 11.02.2016 was in fact passed by the Motor Accident Claims
Tribunal, Beawar but by typographical error in the operative
portion of the order, it has been mentioned as Motor Accident
Claims Tribunal, Dausa (Camp Bandikui).
Learned counsel for the applicant submits that in the first
part of the order dated 11.02.2016 the name of Tribunal is
correctly mentioned as Motor Accident Claim Tribunal, Beawar,
however in the later part and operative portion of the order
instead of Beawar it has been mentioned as Dausa (Camp
Bandikui) which is just an accidental typographical error. Learned
counsel for the appellant submits if such a typographical error is

(2 of 2) [CMAP-155/2021]
corrected, the same would not affect the merits of the order and
will not cause any prejudice to the respondents.
Heard on the application and perused the record.
The error seems to be typographical and allowed to be
corrected. In the order dated 11.02.2016 wherever the “Motor
Accident Claims Tribunal, Dausa (Camp Bandikui)” occurs the
same be treated and read as “Motor Accident Claims Tribunal,
Beawar”.
Accordingly, the application is allowed.
This order may also be uploaded online and be treated as
part of the order dated 11.02.2016.
(SUDESH BANSAL),J
