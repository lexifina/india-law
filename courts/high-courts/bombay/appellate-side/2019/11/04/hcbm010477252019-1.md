P.C. :
This is an application preferred under Section 438 of
Cr.P.C. The applicant has preferred this application directly
before this Court without moving such application before Special
Court. Learned Counsel for the applicant seeks permission to
withdraw this Application with liberty to prefer an application
before the Special Court. In view of submission, application is
allowed to be withdrawn with liberty to prefer application before
Special Court. All the issues including issue with regards to
maintainability of application are kept open.
