ORDER
This revision is filed challenging an order passed under Order XXI Rule 97
C.P.C. for removing obstruction.
2.Today, this Court is informed that on 19.01.2021 the Execution
Proceedings itself has been executed, delivery too has been given to the
decree holder and the E.P. itself has been terminated.
3.In view of this development, nothing survives in this civil revision petition
and the same is accordingly dismissed as infructuous. No costs.
Consequently, the connected miscellaneous petition is closed.
