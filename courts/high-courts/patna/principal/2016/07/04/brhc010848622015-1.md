ORAL ORDER
2 04-07-2016 By the impugned order dated 14.06.2013 the learned
Subordinate Judge-IV, Patna City has rejected injunction
application filed by the petitioner under Order 39 Rule 1 and 2 of
the Code of Civil Procedure in Title Suit No.191 of 2009.
Since the order impugned in this writ application is
appealable under Order 43 of the Code of Civil Procedure, the
petitioner has got the remedy under the Code itself. The petitioner
may if so advised avail forum of appeal.
This writ application is, therefore, not maintainable and
it is accordingly, dismissed.
