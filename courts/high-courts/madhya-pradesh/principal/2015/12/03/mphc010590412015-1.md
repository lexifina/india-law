# High Court of Madhya Pradesh, MCRC/20469/2015, 2015-12-03

MCRC-20469-2015
(MIRZA AFSAR BAIG Vs THE STATE OF MADHYA PRADESH)
03-12-2015
Shri Atul Upadhyay, learned counsel for the applicant-accused.
Shri Rajnish Choubey, learned Panel lawyer for the respondent-State.
The applicant-accused has filed an application under Section 439
of the Code of Criminal Procedure.
Heard the arguments of both the parties.
On perusal of the record, it is evident that the first bail application
filed by the applicant-accused under Section 439 of the Code of
Criminal Procedure was allowed by this Court vide order dated
24.06.2015 passed in M.Cr.C No. 6926/2015 owing to which this
subsequent application filed by him is not maintainable.
Hence, the application is dismissed.
(M.K. MUDGAL)
JUDGE
