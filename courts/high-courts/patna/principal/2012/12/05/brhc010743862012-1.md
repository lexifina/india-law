ORAL ORDER
02/ 05-12-2012 The present application has been filed for
modification of order dated 29.06.2012 passed in Cr. Misc. No.
20365 of 2012.
The petitioner was granted provisional anticipatory
bail for a period of eighteen months on undertaking to return the
bank loan amount with interest within a period of eighteen
months, but now learned counsel for the petitioner submits that
petitioner is not in a position to return the loan amount with
interest, which is contrary to the undertaking given before this
Court.
In the circumstances, the modification application is
dismissed.
 DKS/-
(Dinesh Kumar Singh, J)
