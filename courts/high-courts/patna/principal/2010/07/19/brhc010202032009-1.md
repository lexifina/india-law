03/ 19.07.2010 Heard learned counsel for the petitioner, learned counsel
for Bihar State Election Authority and learned counsel for the
State of Bihar.
Learned counsel for the petitioner seeks permission to
withdraw this writ petition with a liberty to file an election
petition before the Assistant Registrar, Co-operative Society,
Darbhanga.
Accordingly, this writ petition is dismissed as
withdrawn with the aforesaid liberty.
If the petitioner files the aforesaid election petition
before the authority concerned within fifteen days from today
along with an application for condoning the delay, the authority
