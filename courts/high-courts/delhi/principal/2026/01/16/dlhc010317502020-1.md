1. Appeal under Section 96 C.P.C. has been filed on behalf of the
Appellant against Judgment / Decree dated 09.12.2019, whereby the suit of
the Plaintiff / Appellant has been rejected under Order VII Rule 11 C.P.C.
2. Sole ground on which the impugned Judgment has been challenged is
that there was already an Application under Order VI Rule 17 C.P.C.
pending, which should have been decided before considering the
Application of Respondent under Order VII Rule 11 C.P.C.
3. On this short ground, impugned Judgment is set aside with directions
to learned District Judge, South District, Saket Courts, to first decide the
Application under Order VI Rule 17 C.P.C. before considering the
Application of Respondent under Order VII Rule 11 C.P.C.
4. With aforesaid directions, Appeal along with pending Applications is
disposed of.
