# Calcutta High Court, CRR/3364/2023, 2023-09-08

D/L57
08.09.2023
Bpg.
 C.R.R.3364 of 2023
In Re: An application under Section 482 of the Code of Criminal
Procedure, 1973;
 Shyamchand Mondal
 Versus
 The State of West Bengal and another
 Mr. Kallol Kr. Basu
 Mr. Debapriya Samanta
 Ms. Jannat Ul Firdous.
 …for the petitioner.
Mr. Basu, learned advocate appearing for the petitioner
intends to withdraw the present revisional application and file
afresh with the order which is affecting the present petitioner.
Accordingly, CRR 3364 of 2023 is dismissed as
withdrawn.
Liberty is granted to the petitioner to prefer a fresh
application with an order-sheet which affects the right of the
petitioner.
Department is directed to return the certified copy to the
advocate-on-record of the petitioner on the same being replaced by
photo copy.
Pending application, if any, is consequently disposed of.
All parties shall act on the server copy of this order duly
downloaded from the official website of this Court.
Urgent photostat certified copy of this order, if applied
for, be supplied to the parties upon compliance of all requisite
formalities.
 (Tirthankar Ghosh, J.)
