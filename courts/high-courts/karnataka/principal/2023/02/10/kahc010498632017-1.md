JUDGMENT
 It is seen from the previous order sheets that on several
occasions, there is no representation for the appellant.
 2. Today, the respondent's counsel is absent.

 3. This Court vide order dated 30.11.2022 has passed an
order stating that if there is no representation for the appellant,
necessary orders would be passed for dismissal of the appeal.
 4. Despite the said order, today also there is no
representation for the appellant. Accordingly, in view of the order
dated 30.11.2022, the appeal stands dismissed for non-prosecution.
