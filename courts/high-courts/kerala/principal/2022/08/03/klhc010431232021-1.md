This Crl.M.C. is filed for quashing the FIR. Now it is reported
that a final report has been submitted. Therefore, the learned
counsel for the petitioner wants to withdraw this Crl.M.C. without
prejudice to the right of the petitioner to file fresh Crl.M.C.
Accordingly, this Crl.M.C. is dismissed as withdrawn, granting
liberty to the petitioner to file fresh Crl.M.C., if so advised, to
challenge the final report.
