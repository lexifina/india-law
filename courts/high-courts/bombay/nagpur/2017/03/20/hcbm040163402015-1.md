ORAL ORDER
Heard learned Counsel for the applicant and leaned A.P.P. for
respondent no.2. None for respondent no.1, though duly served.
2. Considering the defence taken by respondent no.1 and the evidence
available on record, I am of the view that the applicant has shown that he
has an arguable case. Therefore, this application deserves to be allowed.
3. The application is allowed and the leave to file an appeal under
Section 378 (4) of the Criminal Procedure Code is granted.
The application is disposed of.
