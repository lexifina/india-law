Order
19/09/2017
1. Impugned order shows that Counsel for the appellants
made a consent concerning applicability of the decision in S.B.
Civil Writ Petition No.300/2016, Smt. Ramesh Bai Vs. The State of
Rajasthan & Ors.
2. Learned counsel for the appellants states that
concession as recorded was not made.
3. If that be so, remedy is to file an application before the
learned Single Judge.
4. We dispose of the writ-appeal as not maintainable
observing that if the appellants file an application before the

(2 of 2)
[SAW-1130/2017]
leaned Single Judge concerning the order dated 03.04.2017
regarding consent made by Counsel for the appellants, the said
application shall be decided by the learned Single Judge as per
law.
