# Allahabad High Court, A482/18459/2020, 2021-01-11

Court No. - 81
Case :- APPLICATION U/S 482 No. - 18459 of 2020
Applicant :- Asif Iqbal
Opposite Party :- State of U.P. and Another
Counsel for Applicant :- Matiur Rehman Khan
Counsel for Opposite Party :- G.A.
Hon'ble Mrs. Manju Rani Chauhan,J.
As per computer record one application U/s 482 No. 15033 of
2014 has been filed by the applicant with the same prayer.
Therefore, learned counsel for the applicant does not wish to
press the present application as this is second application,
therefore, the present application be dismissed as not pressed
with liberty to file a fresh application challenging the N.B.W.
Prayer made for is bona fide. Accordingly, the same is allowed.
The present application is accordingly dismissed as not pressed
with liberty as aforesaid.
Certified copy of the impugned order shall be returned to the
learned counsel for the applicant after retaining photo copy of
the same to be kept on record.
Order Date :- 11.1.2021
