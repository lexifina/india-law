# High Court of Orissa, WP(C)/10235/2016, 2019-11-06

04. 06.11.2019 Heard.
 The petitioner had filed a copy application vide
Annexure-1, which is stated to have been rejected on
25.05.2016 as he could not supply the case number though
asked for, as submitted by learned Additional Standing
Counsel.
 In view of such fact, the writ petition be disposed
of directing the petitioner to file a fresh copy application
along with the case number, etc., so that the copy applied
for can be granted.
