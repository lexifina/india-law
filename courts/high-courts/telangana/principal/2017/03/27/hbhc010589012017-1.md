# High Court for the State of Telangana, CRLRC/841/2017, 2017-03-27

HONOURABLE Dr. JUSTICE B.SIVA SANKARA RAO
CRIMINAL REVISION CASE No.841 of 2017
ORDER :
 The learned counsel for the petitioners seeks
permission to withdraw the Criminal Revision Case with
liberty to file a fresh revision case.
2. Granting permission as sought for, the Criminal
Revision Case is dismissed as withdrawn. The Registry is
directed to return the original papers to the learned counsel
for the petitioners.
3. Miscellaneous petitions, pending if any, shall stand
closed.
