# High Court of Madhya Pradesh, CRR/756/2016, 2016-07-21

- 1 -
Criminal Revision No.756/2016
21/07/2016
Shri M. A. Mansoori, learned counsel for the applicants.
Shri Mukesh Parwal, learned counsel for the respondent/State.
The applicants before this Court have filed this present revision
under Section 397/401 of the Code of Criminal Procedure, 1973 being
aggrieved by order dated 16/03/2016 by which an application preferred
under Section 311 of Code of Criminal Procedure, 1973 has been
rejected by the trial Court.
It has been stated by learned counsel for the applicants that an
application was preferred for recall of witnesses on account of
compromise between the parties and the learned Judge has rejected the
application in a mechanical manner.
This Court has carefully gone through the impugned order passed
by the learned II Additional Sessions Judge, Indore and is of the opinion
that the learned trial Court has certainly erred in rejecting the application
dated 29/01/2016 preferred under Section 311 of the Code of Criminal
Procedure, 1973 in a mechanical manner.
After hearing learned Government Advocate and keeping in view
the factum of compromise between the parties, the impugned order dated
16/03/2016 rejecting the application, is hereby set aside and application
preferred under Section 311 Code of Criminal Procedure, 1973 stands
allowed.
With the aforesaid, revision stands allowed.
