This petition coming on for orders this day, the Court
passed the following:
 ORDER
Learned counsel for the petitioner has placed on
record status report in respect of case bearing No. SA/9/2022, filed
before Debt Recovery Tribunal, Chandigarh. It is stated that case

bearing No. SA/09/2022 has been filed on 25.01.2022 and
tentative next listing date of the same is 31.01.2022.
2. In view of this development, learned counsel for the
petitioner seeks permission to withdraw the present petition, at this
stage, with liberty to file afresh, at appropriate stage, if need so
arises. Prayer being innocuous is allowed.
2. Accordingly, the present petition is dismissed, as
withdrawn. Liberty reserved.
Pending application(s), if any, also stands disposed
of.
