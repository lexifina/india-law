# High Court of Madhya Pradesh, MCC/1052/2017, 2017-04-19

MCC-1052-2017
(NARENDRA COT FIBRE INDUSTRIES PVT. LTD. BURHANPUR Vs THE STATE OF MADHYA
PRADESH)
19-04-2017
Shri K.S. Jha, learned counsel for the applicant.
Shri Ramesh Kushwaha, learned PL for respondents/State.
This application has been filed for restoration of WP
No.16678/2016 which was dismissed due to non-compliance
of common conditional order dated 1.12.2016.
Considering the reasons mentioned in the application, which
is supported by an affidavit seems to be satisfactory and
bonafide, the application for restoration is allowed.
The aforesaid case is restored to its original file. The MCC
stands allowed and disposed of.
Let a copy of this order be kept in the file of WP
No.16678/2016.
(SMT. ANJULI PALO)
JUDGE
