# High Court of Madhya Pradesh, MCC/1758/2014, 2014-09-03

MCC No.1758/2014
3.09.2014
Shri Dinesh Koshal, Counsel for the applicant.
This application has been filed for restoration of MCC
308/2005 which has been dismissed due to want of
prosecution on 8/7/14 There being some delay in filing of
the application, I.A.No.11936/2014 has been filed seeking
condonation of delay in filing the application for restoration.
Keeping in view the reasons given in the application
and finding them to be bonafide, both the applications are
allowed.
Condoning the delay in filing the application for
restoration, the restoration application itself is allowed.
MCC 308/05 be restored to its original file.
It be placed for orders before the appropriate Bench.
With the aforesaid, application stands allowed and
disposed of.
(Rajendra Menon) (A.K.Sharma)
Judge Judge
