Order

The case comes up on application (01/2022) for withdrawal
of the present writ petition in the changed circumstances,
however, seeks liberty to file fresh writ petition, if the occasion so
arises.
The application for withdrawal of the writ petition is not
opposed by learned counsel for the respondents.
For the reasons mentioned in the application, the same is
allowed. The writ petition is dismissed as withdrawn with liberty as
aforesaid.
Stay application as well as other pending applications, if any,
are dismissed accordingly.
