ORAL ORDER
Mr. V. C. Vaghela, learned advocate appearing for the
petitioner seeks permission to withdraw the present application
with a liberty to file revision application under Section 397 of the
Code of Criminal Procedure, 1973 before the learned Sessions
Court for setting aside the order dated 5.5.2018 passed by learned
JMFC, Patdi below application Exh.132. Permission as prayed for
is granted. The present application stands dismissed as withdrawn.
It is hereby made clear that the Revisional Court shall
decide the same on merits only without going into the question of
limitation, if the revision application is preferred on or before
7.9.2018.
(A.J.DESAI, J)
