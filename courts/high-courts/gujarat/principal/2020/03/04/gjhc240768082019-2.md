ORAL ORDER
1. This is an application for condonation of delay in filing
Second Appeal.
2. Learned advocate for the applicant has submitted that an
appeal was filed earlier within limitation but since there were
some discrepancies, the same was withdrawn and the Court
had reserved liberty to file fresh appeal. It is submitted that,
while filing the second matter pursuant to the said liberty,
there has been some delay which be condoned.
3. Mr. Raval, learned advocate for the respondent has
vehemently opposed this application.
4. Having heard learned advocates for the respective
parties and having considered the material on record this

Court finds that the delay needs to be condoned.
5. This application is allowed. Delay is condoned.
