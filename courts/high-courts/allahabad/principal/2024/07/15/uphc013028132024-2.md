# Allahabad High Court, ABAIL/5637/2024, 2024-07-15

Neutral Citation No. - 2024:AHC:112515
Court No. - 73
Case :- CRIMINAL MISC ANTICIPATORY BAIL
APPLICATION U/S 438 CR.P.C. No. - 5637 of 2024
Applicant :- Sandeep Singh
Opposite Party :- State of U.P.
Counsel for Applicant :- Onkar Nath
Counsel for Opposite Party :- G.A.
Hon'ble Vikram D. Chauhan,J.
1. In the present case, charge sheet has been submitted. However,
neither the charge sheet nor summoning order has been filed.
2. It has not been stated in the anticipatory bail application as to
when summoning order has been issued. The anticipatory bail
application does not reflect that there is any apprehension of arrest
at this stage.
3. Accordingly, the present anticipatory bail application is rejected.
4. The applicant is at liberty to file fresh anticipatory bail
application when the summoning order is issued.
Order Date :- 15.7.2024
D. Tamang
