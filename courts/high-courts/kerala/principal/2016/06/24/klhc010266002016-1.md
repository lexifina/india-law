JUDGMENT
V. CHITAMBARESH, J:
The court below has by the order impugned allowed an
application to set aside the ex parte decree after condoning the delay.
Only an order rejecting an application to set aside ex parte decree is
appelable. The impugned order is revisable and an appeal would not
lie. The appeal is dismissed without prejudice to the right of the
appellant to move appropriately.
Registry to return the certified copy of the impugned order to the
appellant, if sought.
