# High Court of Rajasthan, CRLMP/2870/2015, 2015-11-17

{ 1 }
IN THE HIGH COURT OF JUDICATURE FOR RAJASTHAN AT
JODHPUR
ORDER
S.B. Criminal Misc. Petition No. 2870/2015
(Murlidhar Gaur Vs. State of Rajasthan)
Date of Order : : 17.11.2015
HON’BLE MS. JUSTICE NIRMALJIT KAUR
Mr. Varun Gupta, for the petitioner.
Mr. A.S. Rathore, Public Prosecutor, for the State.
This is misc. petition under Section 482 Cr.P.C. against the
order dated 25.07.2015 passed by the learned Special Judge ACD
Court, Pali vide which the cost of Rs.2,000/- was imposed against
the petitioner.
Learned counsel for the petitioner while praying for setting
aside the order dated 25.07.2015 submitted that the said order of
cost has wrongly been passed. It is stated that neither any request
on behalf of the petitioner or any other person was made and nor
any application was moved for any relief. In spite of the same, while
turning down the imaginary request, cost of Rs.2,000/- has been
imposed.
Time was granted to the State to file reply.
Today, learned counsel for the State submits that they do not
wish to file any reply. At the same time, the learned counsel for the
State does not dispute the fact that there was no application on
record seeking any relief. Hence, the Court could not have

{ 2 }
proceeded to decide the said relief, if any and accordingly in these
circumstances, no cost could have been imposed.
In view of the above, this Court deems it proper to set aside
the order dated 25.07.2015 to the extent vide which the cost of
Rs.2,000/- has been imposed.
Accordingly, the present misc. petition is allowed and the order
dated 25.07.2015 passed by the learned Special Judge ACD Court,
Pali is set aside to the extent vide which the cost of Rs.2,000/- was
imposed.
 (NIRMALJIT KAUR), J.
