# Allahabad High Court, SPLA/1765/2009, 2019-04-11

Court No. - 34
Case :- SPECIAL APPEAL No. - 1765 of 2009
Appellant :- Sharda Prasad Srivastava
Respondent :- State Of U.P. Through Secretary Dept. Of
Secondary Edu Andors
Counsel for Appellant :- Siddharth Khare,Ashok Khare
Counsel for Respondent :- C.S.C.,Ramesh Singh,S.D.Kautilya
Hon'ble Sudhir Agarwal,J.
Hon'ble Rajendra Kumar-IV,J.
1. Sri Pratik Chandra, Advocate holding brief of Sri Siddharth
Khare, learned counsel for appellant submitted that pursuant to
direction issued by learned Single Judge vide judgment and
order dated 22.10.2009, which is under appeal, State-respondent has already passed an order which is part of
amendment application.
2. If any subsequent order has been passed by State-respondent
after judgment of learned Single Judge, it provides fresh cause
of action to be challenged by filing a writ petition, but that
order will not affect correctness of judgment of learned Single
Judge passed in earlier writ petition.
3. So far as judgment passed by learned Single Judge which is
challenged in this appeal, is concerned, learned counsel for
appellant could not point out any error therein so as to warrant
interference by this Court. This appeal lacks merit.
4. Dismissed accordingly.
5. Interim order, if any, stands vacated.
Order Date :- 11.4.2019
Manish Himwan
