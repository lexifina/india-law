ORAL ORDER
(PER: HON’BLE MR. JUSTICE H.P.SANDESH)
Though the counsel appearing for the appellant
undertakes to file necessary application within two
days on the last date of hearing, till date not filed the
same. On 11.08.2026 also the counsel for the
appellant informed to the Court that appellant is no
more and sought time to file the necessary
application. Inspite of sufficient time is granted to file
necessary application, the same is not filed before
this Court. Even this Court directed that if such

3
application is filed, registry to put up the same but no
progress in the matter.
Today, once again, the counsel for the appellant
seeks time for the same. Hence, adjourned the matter
on cost of Rs.5,000/- payable in the registry and
necessary application to be filed within 3 days from
today. If application is filed, list the matter on
29.08.2026. If fails to file the application within three
days, the appeal will be dismissed without reference
to the Bench since no steps are taken to bring the LR
of deceased sole appellant on record.
