# High Court of Madhya Pradesh, WP/5479/2017, 2017-06-19

W.P.NO.5479/2017
(Shree Deo Janki v. State of M.P.)
19.06.2017:
Shri A.K. Tiwari, learned counsel for the petitioners.
Shri Girish Kekre, Government Advocate for the
respondent/State.
Learned counsel for the petitioner seeks permission
of this Court to withdraw this petition with liberty to file an
appeal.
Prayer as made by the counsel for the petitioners
seems to be reasonable.
Accordingly, this petition is dismissed as withdrawn
with liberty to the petitioners to file an appeal.
Certified copy of the documents attached with this
petition be returned back to Shri Tiwari on filing
photocopies thereof.
C.C. as per rules.
 (J.K. MAHESHWARI )
 Judge
