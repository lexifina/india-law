Order
02/09/2023
Learned State counsel has submitted the factual report of
the investigation dated 20.08.2023, which is taken on record.
As per the factual report, negative final report has been
proposed by the investigation agency.
Learned State counsel is directed to instruct Investigating
Officer to file outcome of investigation before the concerned
Magistrate within a period of one month.
In view of the aforesaid factual situation, learned counsel for
the petitioner wants to withdraw this petition with liberty to file
fresh, if need so arises.
Accordingly, the instant petition is dismissed as withdrawn
with liberty, prayed for.
