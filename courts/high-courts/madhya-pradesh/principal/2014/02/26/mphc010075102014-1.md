# High Court of Madhya Pradesh, MCC/261/2014, 2014-02-26

M.C.C. No. 261/2014.
1
26.02.2014.
Shri Vinod Kumar Dubey, learned counsel for the
applicant.
This application has been filed for restoration of F.A.
No. 1002/2005 which has been dismissed due to non
appearance on 03/12/2013. There being some delay of 40
days in filing this application I.A. No. 2985/2014 has been
filed seeking condonation of delay.
Both the applications for restoration and application for
condonation of delay are supported by affidavits of counsel
himself. Finding the same to be bona fide and finding the
reasons given in the application to be reasonable applications
are allowed. Condoning the delay in filing this application F.A.
No. 1002/2005 is restored to its original number and list for
order before appropriate Bench.
Copy of this order be kept in the original file of F.A. No.
1002/2005.
With the aforesaid, application is allowed and disposed
of.
(RAJENDRA MENON)
