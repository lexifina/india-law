This application coming on for admission this day, the court passed the
following:
ORDER
The petitioner has filed the present petition under section 482 of the Code
of Criminal Procedure 1973 praying for a direction to modify the order dated
1.7.2023 passed in M.Cr.C. No.24434/2023.
The petition is not maintainable as the petitioner has already preferred an
application for modification of the aforesaid order vide I.A. No.17508/2023 in
M.Cr.C. No.24434/2023 and the same has been allowed.
Considering the aforesaid, this petition is dismissed as not maintainable.
