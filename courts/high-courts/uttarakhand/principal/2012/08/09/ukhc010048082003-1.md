# High Court of Uttarakhand, WPMS/816/2003, 2012-08-09

WPMS No.813 of 2003
Hon’ble Tarun Agarwala, J.
Mr. J. C. Pandey, learned counsel for the petitioner.
Mr. Sharad Sharma, learned senior counsel for the respondents.
Cause shown for the delay in filing the restoration application is
sufficient. The Delay Condonation Application / CLMA No.8115/2012
is allowed. The delay in filing the restoration application is condoned.
Let the same be taken on record.
Heard the learned counsel for the parties on the Restoration
Application No.617/2012. Cause shown in the restoration application
is sufficient. The Restoration Application is allowed. The order dated
20.05.2011, by which the writ petition was dismissed for want of
prosecution, is recalled. The writ petition is restored in its original
number.

 (Tarun Agarwala, J.)
Dated 09.08.2012
