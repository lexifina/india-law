This petition coming on for admission this day, the court passed the
following:
ORDER
This is an application seeking correction of a case number, which is
mentioned in paragraph 12 of the order dated 19.6.2023, passed in Writ Petition
No. 13690/2020.
2. Counsel for the petitioner contends that on account of typographical
error the number of the appeal which is preferred before the Additional
Commissioner, Division Rewa is Case No. 52/Appeal/19-20; whereas on
account of typographical error the same is mentioned as Appeal No.
0021/Appeal/2019.
3. Considering the aforesaid, the number of which is mentioned as
"Case No. 0021/Appeal/2019" be substituted and read as "Case No.
52/Appeal/19-20".
4. This order shall be read conjointly with the order dated 19.6.2023
passed in W.P. No. 13690/2018.
5. With the aforesaid Review Petition stands disposed of.
